# Methodology — issue 1482: per-feature error-structure battery (L3 + L19 + L20 matryoshka tiers) on the #779 context→answer map


**Design:** An error-analysis of an existing map — no new training. One GPU run (three GCP 4×A100 attempts, then a RunPod 4×H100 failover pod; checkpointed phases seeded from the surviving partial attempt), then off-pod judging and analysis. Stages: (1) stream the parent's 1,920 capture chunks from HF and rebuild the 963,444-context train matrices (layer-19 last-prompt-token state and mean-answer state), re-asserting the parent's pinned 400-row val / 1,000-row test split by sha; (2) carve a fresh 20,000-context holdout (RNG seed 1482, corpus-stratified, never entering any fit) plus a disjoint 120,000-context SAE fit subsample; (3) refit all five parent fitters three ways — full-train (the reconciliation control), holdout-excluded (the taxonomy read), and LMSYS-only (the corpus-transfer fold) — persisting per-context error; (4) teacher-forced forwards over the parent's persisted prompt+answer text (per-segment token-id concatenation, never re-tokenizing the concatenated string) for the 141,400 SAE-arm contexts, SAE-encoding every token and pooling answer-side features three ways (mean, max, fraction-active); (5) linear and MLP maps in feature space — context features → answer features, dense context state → answer features, and a prefix-arm null — plus a per-direction PCA decomposition of the dense map; (6) one judge call per context labeling language, topic, refusal-adjacency, answer-is-refusal, and format; (7) vectorized bootstrap/permutation analysis and figures. The dense map is the context-based arm (prefix + user query up to the last prompt token). A zero-GPU follow-up round (2026-07-19) added stage (8): a seeded label-permutation null for the per-feature read — answer rows permuted within the 120,000-row SAE fit set, λ pinned to the parent-selected value, feature restriction asserted equal to the parent's feature ids, holdout scored on true pairs; an identity-permutation gate reproduced the parent's committed per-feature R² (median |Δ| = 1.5e-5; pooled 0.6901407 vs 0.6901409). A second follow-up round (`k-resample-noise-floor`, 2026-07-19, ~3.1 realized GPU-h) added stage (9): regenerate K = 4 fresh answers per context (seeds 43–46, the parent decoding recipe) for a 2,000-context language-stratified subsample of the labeled holdout (1,000 per arm, RNG seed 148201), capture each fresh answer's `v` under the parent capture convention (full-template re-tokenization, answer span including the end-of-turn tail), stream the parent seed-42 `v` verbatim from the parent capture chunks (2,000 of 2,000 rows found across 1,233 chunks; no recapture), and compute the per-context answer-sampling floor plus the floor-adjusted language contrast (joint 10,000-draw bootstrap, seed 1482). Two earlier attempts of this round recaptured the parent draw under the generation-time token-id convention and failed the identity gate — generation-time ids differ from the parent's own full-template re-tokenization for 93.1% of rows — so the round switched to the streamed-parent + parent-convention design before any read. A third follow-up round (`perdirection-shrinkage-control`, 2026-07-19, ~1.3 realized GPU-h) added stage (10): rebuild the same train matrices, pinned split, and top-256 answer-PCA basis (sha- and value-gated against the committed round), replace the linear baseline's single global λ with a per-direction λ selected on the pinned 400-row val over a 38-value grid, score the tuned map on the same 20,000-context holdout through the identical fp16-cast prediction convention with the MLP arm untouched, and re-read the band-gap excess with a 10,000-draw paired context bootstrap (seed 148202). A fourth follow-up round (`feature-correlates`, 2026-07-27, 0 GPU-h, user-chat inline) added stage (11): two per-feature covariate reads over the committed per-feature R² — within-answer consistency (mean `ans_frac`, the fraction of the answer's tokens where the feature is active conditional on being answer-active, accumulated over the 120,000 fit-tagged rows from the pooled store; the recomputed activity covariate matched the committed one exactly, max |Δ| = 0) and a judged abstraction level (300 features stratified by activity decile × within-decile R² tercile, seed 14822026; project judge over each feature's top-8 firing answers plus the Neuronpedia `19-resid-post-aa`/`trainer_1` auto-interp description as labeled auxiliary evidence — index-aligned to the run's k=64 trainer; reason-then-label, max_tokens 400, 60-item test-retest). A fifth follow-up round (`early-layer-arm`, 2026-07-29, ~4.6 realized GPU-h of 4 approved) added stage (12): an early-layer token-level arm — teacher-forced forwards over a corpus-stratified 30,000-context subsample of the parent corpus (24,000 fit rows drawn inside the parent SAE-fit set, 6,000 score rows drawn inside the parent holdout; RNG seed 14823; parent split shas re-asserted), capturing layer 3 alongside a fresh layer-19 control per token, encoding with the public layer-3 dictionaries (k=64 primary, k=128 replication), pooling answer-side features per the parent recipe, and refitting the context-features → answer-features and dense-input maps at both depths on the same rows with the same shared-Gram ridge (plus the parent MLP recipe on the layer-3 dense arm), a K = 20 label-shuffle null, and a per-feature covariate battery (activity, within-answer consistency, direct-logit footprint, co-activation, dense-latent flag, decoder–persona-direction alignment). Judged feature-labelling was frozen this round by user directive (plan v17 §0.-1; the prior labelling instrument was retracted as unreliable): the two planned judged-label permutation tests emitted deferred stanzas, a 377-feature mechanical evidence packet was persisted for the future labelling resume, and no feature-level abstraction or persona claim is made from this round. All planned fit units realized, including the layer-3 dense-input MLP cell missing from the round's first leg (a same-day instance restart superseded that leg; the final leg re-ran capture through upload end to end). A sixth follow-up round (`matryoshka-tier`, 2026-07-30, ~5.6 realized GPU-h of 6 approved) added stage (13): the early-layer round's exact 30,000 rows (split shas re-asserted) captured at layer 20 and encoded through two matched matryoshka dictionaries — chat-trained and pile-trained twins differing only in training corpus (jumprelu-family batchtopk, k = 100, nested widths 2,048 / 16,384 / 65,536, so the feature id determines a training-imposed granularity tier 0/1/2) — pooling answer-side features per the parent recipe plus a sink-robustness twin; per dictionary, the context-features → answer-features shared-Gram ridge on a 16,384-feature tier-stratified random panel above the activity floor (a stated deviation from the parent's top-activity panel: top-activity selection would distort the tier × activity joint distribution the headline conditions on and could censor tier 2), a dense-input companion, a prefix-arm null, a K = 20 label-shuffle null, the covariate battery, identity-plus-bias and retrieval baselines, cross-dictionary decoder matching, and a within-activity-stratum tier-label permutation as the headline test. Judged feature-labelling stayed frozen this round too (zero judge calls): the tier × judged-level scope item is deferred to the successor labelling instrument, with 360 + 180 label-free evidence packets persisted for that resume.

Conditions: the full-train reconciliation refit; the holdout-excluded refit (plus a second MLP seed); the LMSYS-only transfer refit; the feature-space map from context features; the dense-input feature map; the prefix-arm null; the encode-the-prediction read; the SAE fitness pilot; the split-half stability read; the per-feature shuffle null; the k-resample floor arms (English and non-English); the k-resample MLP and raw-units re-reads; the per-direction shrinkage-control arms (val-tuned and holdout-oracle ridge); and the early-layer arms — the layer-3 context-features map (mean/max/fraction-active poolings), its sink-robustness pooling twin and k=128 second-dictionary twin, the layer-3 dense-input map plus its MLP twin, the layer-3 prefix-arm null, and the matched-row layer-19 context-features and dense-input controls. The matryoshka-tier round adds: the chat-dictionary and pile-dictionary feature maps (mean/max/fraction-active poolings), the sink-masked pooling twin, the dense-input companions, the prefix-arm nulls, the label-shuffle nulls, the within-stratum tier permutation, the identity-plus-retrieval baseline pair, and the cross-dictionary matching read. Scope caveats:

- The SAE arm covers new-pool rows only — the 1,400 pinned val/test contexts have no reconstructable text, so feature-space λ-selection uses a 2,000-row carve of the SAE subsample.
- The Goal-named 16,384-feature SAE repos are weight-empty on HF, so the run substitutes the only weight-bearing suite (andyrdt layer-19 instruct SAEs, 131,072 features) — better matched to the map layer, validated by the fitness gate below.
- The dense per-context read is context-arm-only: every prompt is single-turn, so the prefix (everything before the user query) is one constant chat-template string — verified live (prefix-end states constant across contexts, min cosine 1.000) — and the prefix arm runs at SAE-subsample scale as a null.
- The encode-the-prediction read is off-distribution (an SAE applied to mean-pooled states) and reported as secondary only.
- The conversation-depth taxonomy axis was dropped (single-turn corpus).
- 4 content + 29 transport judge losses (0.165%) were not re-judged — an adversarial bound assigning all 33 missing rows extreme observed values moves the language contrast by at most +0.011 (to −0.006), so its sign cannot flip.
- `v(x)` is one sampled answer per context, so absolute per-category error levels include an answer-sampling-variance share — measured by the k-resample round at 33–40% of per-context error on the language arms (the paired gap reads are immune — same answer under both fitters).
- The early-layer arm's judged labels are frozen: the planned pooled-depth and within-layer-3 abstraction-level permutation tests are deferred until a validated auto-interp labelling instrument lands (the successor labelling task named in the Context row), so this round carries mechanical reads only.
- The early-layer arm fits 24,000 rows (vs the parent SAE arm's 120,000), so cross-round absolute levels are not comparable; the matched-row layer-19 refits carry the depth contrast. The cross-depth absolute comparison is itself descriptive — the two dictionaries differ in reconstruction quality (measured fraction of variance explained 0.920 at layer 3 vs 0.810 at layer 19).
- The layer-3 MLP read is fit on 24,000 rows (the committed dense MLP fit 963,444), so its deficit against the ridge conflates depth with fit size; all early-layer fits are single-seed (fit seed 0, subsample seed 14823), with the k=128 second dictionary as the replication axis.
- The co-activation covariate saturated at 1.0 for over 99.9% of features at both depths (full-density companion latents), so its near-zero rank correlation is uninformative, not evidence of no effect.
- The matryoshka round's layer-20 jumprelu-matryoshka k=100 numbers are not directly comparable to the committed layer-19 BatchTopK k=64 numbers: the core battery (fits, nulls, baselines, covariates) is recomputed on this round's own arms, no figure splices tier onto committed values, and cross-round correlate comparisons are qualitative only.
- Tier is confounded with firing frequency by construction (general-tier features fire more often), so the raw tier gradient is descriptive; the headline is the within-activity-stratum permutation read, with activity deciles merged to quintiles per the plan's fallback (the sparsest decile-tier cell held 17 features, under the 20-feature floor).
- The matryoshka fits use 24,000 rows and a single fit seed per arm; the tier-stratified target panel keeps every floor-clearing tier-0 feature (1,640 chat / 1,639 pile) but samples tiers 1–2 (6,144 and ~8,600 of the floor-clearing populations), so panel composition affects which features carry R² estimates, not the full-population descriptives. The chat-vs-pile predictability comparison is additionally unpaired over these differently-selected populations: each panel's activity floor is computed on chat tokens, so the pile panel conditions on chat-transferability.
- The tier × judged-abstraction-level agreement item from the round's scope is deferred: judged labelling stayed frozen (zero judge calls), and the judged spec is preserved verbatim in the evidence pack for the successor instrument's resume.

**Evaluation:** The per-context DV is the normalized squared error `nerr(x) = ‖v̂(x) − v(x)‖² / ‖v(x) − μ_eval‖²` (`μ_eval` = the eval set's mean answer state) — the exact per-context decomposition of the parent's pooled R² (1 − Σe2/Σdenom reproduces the whole-map R² identically); raw squared error and cos(v̂, v) are reported alongside. On the fresh 20k holdout the ridge whole-map R² is 0.7243 (mean cosine 0.9566). Two validity gates ran before any read. Reconciliation gate (PASS, no dropped arms): the full-train refits reproduce the committed aggregates on the pinned test — ridge 0.7541708 (|Δ| = 5.6e-16 against a 0.002 tolerance), `mlp_w8192` |Δ| = 1.9e-9 and `mlp_w32768` |Δ| = 1.3e-7 (0.01 tolerance), residual-skip 1.3e-9, KRR 6.6e-15; 13 fit units were seeded from the GCP partial attempt `att-20260718-055220` and reconciled. **Data extraction:** Per-context error arrays join judge labels through the sha-verified scratch row map (19,967 of 20,000 joined). Bootstrap contrasts run as one masked matrix multiply over 10,000 draws. The script-intrusion scan matches CJK and Cyrillic codepoints in the judge-visible completion text (prompt capped at 1,500 chars, completion at 1,000 — 59.5% of completions at cap, so length strata reduce to three usable bins). The per-direction read projects the same holdout predictions as the per-context read onto the top-256 eigenvectors of the train-split covariance of `v(x)` (eigenvalues span 172 → 0.38, roughly 460×) and scores per-direction held-out R² for each fitter. Per-feature R² is feature-standardized over the 20k holdout, with split-half rank stability over two disjoint 10k halves. The k-resample floor for a context is the ddof-1 trace of the covariance of `v` over its four fresh draws divided by the parent's stored denominator; the adjusted contrast subtracts the arm-mean floor difference (subsample) from the raw full-holdout contrast, and the two bootstrap terms resample independently within arms (the ~10% subsample-within-holdout overlap makes them weakly dependent — the subsample-internal estimate is the stated sensitivity check). The shrinkage-control round scores all 38 λ values for all 256 directions off one eigendecomposition as per-λ blocked GEMMs; the tuned arm's holdout projections are gathered from retained per-λ fp16 projection tables, and the 10,000 bootstrap draws run as three GEMMs over per-context per-direction residual matrices. The early-layer arm pools per-token layer-3 SAE codes over the answer span under the reference inlier mask (BOS offset 8, 10× norm-outlier exclusion); the sink-robustness twin adds special-token positions to the mask; per-feature R², the shuffle null, and the covariate battery are computed from the same 6,000 score rows at both depths — the depth contrast holds rows, estimator, restriction recipe, and poolings fixed and varies only the layer. The matryoshka round encodes each token through both dictionaries in one capture pass (fp32, batched over tokens; per-token codes never materialized beyond the batch in flight), pools under the reference inlier mask plus the sink-robustness mask, and consolidates pooled rows into ~64 npz shards per family, uploaded before any fit. Cross-dictionary matching unit-normalizes decoder rows and reduces a chunked fp16 GEMM to each feature's best-match cosine in both directions; the tier permutation shuffles tier labels within activity quintiles and re-pools the Spearman statistic per draw.
