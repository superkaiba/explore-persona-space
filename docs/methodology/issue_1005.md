# Methodology — issue 1005: CoT-decomposition replication on DeepSeek-R1-Distill-Qwen-7B (template-forced thinking)

**Design:** one generation + capture + fit pipeline on `deepseek-ai/DeepSeek-R1-Distill-Qwen-7B` (a Qwen2.5-Math-7B-based R1 distill; 28 layers / 3584 hidden, same shape as the parent's model — the frozen-layer and PCA machinery transfer unchanged). The 50-context battery (7 families: persona 14, WildChat 10, in-context-learning 8, rephrase 6, format 5, behavior 5, default 2) and the 48-probe misalignment paraphrase pool are the parent line's fixed instruments, inherited unchanged (sha-asserted). Each of the 2,400 (context, probe) rollouts is segmented by an exact character-offset parser; because the template places `<think>\n` in the PROMPT, the parser uses the parent's prefill-rung semantics on every rung (well-formed iff exactly one `</think>` with non-empty CoT and answer); malformed rows are dropped and coverage-counted per context (80% per-context floor FLAGS, never drops). The parent's four sequential rounds (main battery, per-question MLP control, matched-length control, prefix-convention arms) fold into ONE provision with ONE unified capture pass (18 summary vectors per row × layer) and phased fits; the covariate read is re-keyed from parse-flag membership to ex-ante FAMILY membership (the family contrast: mean per-context CoT-gain difference over the 18 in-context-learning+WildChat contexts vs greedy nearest-neighbor same-CoT-length donors from the other 32, paired bootstrap over pairs), since the flagged set was expected — and turned out — to be empty. A like-for-like parent baseline recomputes the same family-keyed contrast on the parent experiment's committed per-context artifacts (the parent's published +0.41 flagged-cluster figure is flag-keyed and not directly comparable). Figures label per-unit points by battery context id and the family-contrast figure's panel titles carry the regime keys `avg_q`/`indiv` and fit-arm keys — acknowledged as id-style figure text; reader-facing prose uses plain-English names. The 16,384-round family-contrast per-context figure is deliberately linked, not embedded, in its result (one inline figure per result). Conciseness note: nine results (compliance, mediation, per-context view, family contrast, truncation structure, the 16,384-token re-read, tercile gradient, matched-length forest and its per-context companion) put total prose over the 800-word budget and several results over the 120-word soft cap, and some Takeaways bullets run past 30 words — acknowledged; kept for coverage of the registered reads. Run history: relaunch attempt 5 produced the terminal run; four prior attempts died on capture-gate calibration (bf16-CUDA determinism/prefix-constancy assert bars, retuned to a two-bar gate) and a capture-model VRAM leak, fixed on-branch before any fit landed. Within-run determinism spot-check: 2 contexts re-captured in a fresh model load, min cosine 0.999998 (two-bar gate: 0.999 early layers / 0.9999 flat, bf16-calibrated). Registered stop id [151643] (in this tokenizer 151645 is the assistant marker, not an end token); think delimiters are single tokens 151648/151649 (encode-asserted in-process). Follow-up round `cap16k-compliance-reread` (one spot A100, ~0.7 h): the 97 `finish_reason=length` rows re-generated greedy at 16,384 tokens (forced; the parent's registered retry rung), re-parsed, coverage and the compliance statistic recomputed, the 42 affected contexts re-captured, frozen layers re-derived (matched: 18/26), and the family-contrast/CoT-gain sensitivity re-reads re-run with recovered rows appended through the committed Phase-F4 machinery — one variable changed, everything else inherited.

**Evaluation:** the dependent variable is held-out skill-over-mean R² per (map × summary combo × layer × regime × fold): leave-one-context-out (LOCO, 50 folds; per-question rows leave as whole context groups) closed-form ridge with nested-CV λ and PCA-48 answer targets, plus leave-one-family-out (LOFO-7) ordering checks. Batched-vs-serial ridge parity gates passed at ≤4.4e-16. Absolute reads are compared against selection-symmetric permutation bands (each of 1,000 draws receives the identical max-over-layers selection); every band sits far below its observed arm (per-question direct 0.547 vs band p95 0.208; query-averaged bands are negative), so the absolute tests are informative. Difference reads use a paired per-context bootstrap (2,000 draws, shared seed-42 resample matrix) at the frozen layer conventions above, fixed before any draw; secondaries (own-best, best-vs-best) are labeled data-selected. Identity ceilings: 0.987 per-question / 0.733 query-averaged at the frozen layers — the CoT-side arms sit 0.09–0.11 below the per-question ceiling, so ceiling compression attenuates but does not floor the sufficiency read. Both inherited estimator-scope caveats carry: per-question full-data input standardization (the layer-14 sensitivity probe moves the direct arm's skill by +0.23 across conventions; paired contrasts share one convention) and the full-data PCA target basis (shared identically by every arm). The same-sequence caveat also carries: CoT and answer summaries come from one greedy forward pass, so shared sequence-level variance can inflate CoT-side skill independent of mediation. Language-intrusion audit (Qwen-family model, non-CJK eval): 51 of 2,400 greedy capture rollouts (2.1%) contain CJK characters, spread over 32 contexts (max 4 in one); after the 16,384-token re-generation the merged corpus reads 48 of 2,400 (3 of the 97 re-generated rows intrude); every fitted arm shares the identical row set, so intrusion cannot differentially bias any paired contrast; no LLM-judged DV exists anywhere in this experiment (the parser is exact code).

**Data extraction:** vLLM batched greedy generation (one `LLM.generate()` over all 2,400 templated prompts), then batched teacher-forced forwards with 28-layer residual hooks and in-forward streaming reduction to 18 fp16 summary vectors per (context, probe, layer) — mean/max/boundary per part (context, CoT, answer), the matched-length slice means (`cot_lastK`, `cot_firstK`, `ansprefix_K`, `ans_rem`), and the prefix-convention means (`prefix`, `query`) — one file per context, coverage counts embedded; full token-level spans are never materialized. Rollout text uploaded to HF unconditionally before any reduction. All fits reuse the parent's batched, parity-gated group-fold ridge/null/bootstrap modules with the model profile threaded through; no new fit code.
