# Methodology — issue 1345: three-framing (chat / plain-text / narrative-story) linear context→answer map comparison, incl. the conversation-paired story regime and the slot-position ablation

**Design:** three framings of the same assistant persona × two models (Qwen2.5-7B, Qwen2.5-7B-Instruct) × two mapping arms (context = everything up to the end of the user query; prefix = everything before the query). Framings: chat-template (standard Qwen chat template), no-template (the same conversations rendered as plain `User: <u1>\n\nAssistant: <a1>`), and assistant-in-stories (new narrative prose in which an AI character named ARIA answers a human character's questions). Chat and no-template share the same underlying conversations (the conversation-paired pair); the free-form stories are a different corpus, so those story comparisons are corpus-confounded by design. Per cell I fit a closed-form ridge map from the context (or prefix) activation to the answer-mean activation, swept all 28 layers within-regime, ran the cross-regime transfer matrix and operator-comparison legs at frozen layers 14/18/19/26 (layer 19 headline), and evaluated the plan's verdict lattice on the chat↔no-template pair per model and arm: same-operator (transfer alone within 0.05 of the target ceiling), reparameterized (transfer short, but a data-paired general-linear change of coordinates `A·M·B` recovers the target ceiling above a matched-capacity null), different-map (recovery also fails, deficit CI wholly below zero), else inconclusive.

Follow-up round `assistant-named-story` (single manipulated variable: the story character name, ARIA → "Assistant", via the `EPM_STORY_CHARACTER_NAME` seam with a variant-scoped output prefix): stories regenerated for both models under the otherwise-identical recipe. The story pipeline's retry pass is a fresh-seed backfill sized to the main-pass shortfall — retry seed conversations overlap the main pass 0 of 242 (instruct) — not per-slot retries. The chat/no-template legs reused the parent's pinned turnstore (HF data revision `2a3cb30a`, the turnstore-reuse pin; the fit metadata's `pinned_parent_revision` `7159e5804d` is the parent S-track corpus pin, a different object) through a prefetch-reuse phase gated by a refit-equality check (tolerance 1e-3, measured deviation 0.0 on all four base cells) and the parity gate (deviation 0.0 on all four layer-19 anchors); all four chat↔no-template lattice cells reproduce the parent verdicts exactly, so those legs are a pipeline-integrity replication, not new evidence. Both story arms missed the 400-of-500 yield floor, so free-form story fits and story-pair operator legs were halted per the plan kill criterion. As an instrument diagnostic, all 365 verdict-less judge replies (both runs, both models) were then re-judged once at `max_tokens` 800 — identical rubric, judge model, and temperature, fresh cache — with per-row outcomes recorded.

Follow-up round `conversation-paired-stories` (plan v9): a seed-42 sample of 2,700 of the 4,724 shared conversations rendered as narrative prose with the ORIGINAL answer embedded verbatim (attribution `Assistant replied: "…"`), activations captured teacher-forced at the fixed answer span, plus an on-policy companion cell (free story-answer generation; 117 conversations kept) bounding teacher-forcing distortion per nested gates (companion more than 0.05 below the teacher-forced cell = qualification; negative and more than 0.20 below = demotion). The paired regime is instruct-only; base narrative generation was not attempted by scope (parent base story yields 96 of 500), so base paired-story cells are N/A — not tested. This makes the story rows corpus-shared and conversation-paired with chat/no-template, so the data-paired story↔chat reparameterization is defined — the parent's stated deviation, resolved. Two declared variables separate this round from the free-form ARIA anchor (corpus construction AND character name, renamed per user directive), so ARIA-anchor comparisons are context only; the round's primary comparisons hold the name fixed within-round. Same-conversation comparators are matched-row refits of the chat and no-template cells restricted to the story-kept rows; the plan-declared verdict lattice reads the paired-story within-R² (context arm, layer 19) with its conversation-grouped bootstrap CI — wholly below zero = framing effect, wholly above = corpus effect.

Follow-up round `story-slot-position-ablation` (plan v10): the direct test of the paired round's single-slot caveat. Four candidate context read positions — the end of the embedded question utterance (the structural analogue of the chat slot), the last narrative token before the attribution sentence, the last token fully contained before the answer span ("pre-answer", defined char-level so a token that BPE-merges into the answer's opening can never be read — answer leakage into the slot is excluded by construction), and a mean-pool over the attribution phrase — were captured beside the attribution-colon anchor and the fixed prefix slot in ONE teacher-forced forward per story over the same 2,164 kept paired stories (no regeneration, no judge calls), and each slot's context cell was refit with the inherited rig. The verdict statistic D is the per-draw maximum over the four slots of the paired per-conversation deficit vs the same-rows chat comparator (the maximum taken inside each of 1,000 conversation-grouped bootstrap draws, so the selection is inherited per draw), with per-slot CIs at the Bonferroni-4-adjusted 98.75% level; the trichotomy: slot artifact (D's CI reaches zero), representation-level collapse (D's CI and every slot's adjusted CI wholly below zero), intermediate otherwise. Slot hygiene: per-slot answer-span overlap must be 0.0 (asserted at extraction; realized 0.0 everywhere); anchor-coincidence rates are measured, and a slot duplicating the anchor on more than half its rows would be excluded as degenerate (realized: at most 3 of 2,163 rows; all four slots kept). A three-cell refit-equality gate (±0.02 on the landed story-anchor, prefix, and chat matched cells) binds the fresh capture — measured deviation 0.0000 on all three. The prefix arm is held fixed per the mapping-arms rule (the context slot is the single swept variable; a prefix-side sweep would be a second variable), and the operator-cosine legs were dropped this round (a declared deviation — the verdict rests on within-R² and D).

**Evaluation:** the dependent variables are geometric/predictive, not judged behaviors: (1) within-regime held-out R² (pooled per layer with the test fold's own mean as reference, group 5-fold CV) per regime × model × arm × layer, against a conversation-level shuffle null; (2) cross-regime transfer R² of the source-regime map applied in the target regime, with per-direction Δ(source→target) = transfer R² minus the TARGET regime's own within-R²; (3) raw and activation-Procrustes-aligned operator cosine against a random-rotation null; (4) reparameterization recovery: held-out R² of `A·M_source·B` in the target regime, where `A`/`B` are ridge-fit activation alignments trained on training folds only, against the larger of two matched-capacity nulls; (5) for the paired-story round, the plan's verdict read on the paired-story cell (framing effect iff the within-R² CI is wholly below zero; corpus effect iff wholly above with recovery above nulls), the story↔chat reparameterization with data-paired alignments, and the nested teacher-forcing gates on the on-policy companion subset; (6) for the slot round, the per-slot within-R² with a multiplicity-adjusted CI and the max-over-slots paired deficit D vs the same-rows chat comparator. The 95% CI on the lattice deficit comes from the conversation-level paired bootstrap. The transfer matrix recomputes each target's within-R² on its own subset and folds with a pooled held-out-mean reference, so its story diagonals differ slightly from the within-sweep rig (paired stories: −0.303 bootstrap-rig vs −0.306 within-sweep) — a rig difference (R² reference), not a data difference; prose uses the within-sweep value. The slot round's verdict quantities (per-slot R², paired deficits, D) are all read in the bootstrap rig, where the within-sweep obs values differ by at most 0.003. Free-form story-pair operator similarity uses raw cosine + rotation band + an operator-spectrum Procrustes optimum (the data-paired alignment is undefined without shared conversations — a stated deviation, resolved for the paired round).

**Data extraction:** chat and no-template reuse the parent's S-track corpus — its single-turn track ("S-track"; the parent also carries a two-turn "M-track", unused here): 5,000 single-turn conversations whose user prompts are real user turns from `lmsys-chat-1m` (tier-2 established dataset, parent pin `200748d9d3`), each answered by the measured model itself (one cell per model — on-policy sampled responses), row-filtered to at least 8 content tokens and at most 2,048 total tokens; 4,724 conversations survive zero-width-span drops in both renders and form the shared chat ∩ no-template row set. It was re-extracted at pinned parent data revision `7159e5804d` with the added prefix slot; the parity gate reproduced all four parent layer-19 anchors exactly. Slot positions — chat: context slot = last token of the assistant header after the user turn, prefix slot = last token of the pre-query template region; no-template: context slot = last token of the `Assistant: ` header, prefix slot = end of the `User: ` header; stories: context slot = last token of the attribution marker immediately before the AI character's quoted answer (the colon in `ARIA replied:`), prefix slot = last token of the narrative before the question utterance. Free-form stories were generated on-policy from each model (elicitation tier 2, instruct-and-strip: a story-writing system instruction that is NOT part of the extracted context), judge-filtered for containing 4+ well-formed question→answer exchanges, and parsed with per-turn confidence gates; only confident turns enter the fits (2,108 turns from 420 instruct stories, mean 5.0 per story). Instruct yield: 420 of 500 kept (main pass 323, retry 97; judge malformed drops 24, transport losses 0, parser-below-floor 43). Five of the 420 kept stories hit the 1,024-token generation cap (`finish_reason: length`); the three samples shown below ended at a natural stop. Base yield: 96 of 500 kept — below the 400 floor, so the base story regime was halted (N/A — not tested). All 420 kept instruct stories came from tier 2. Story answer spans are much shorter than chat/no-template answers ([length distributions](https://raw.githubusercontent.com/superkaiba/explore-persona-space/319fd10131dd2517a4099755153efe500dec9e5b/figures/issue_1345/answer_token_length_distributions.png) — deliberately linked, a data-quality companion rather than a result figure). A language scan found 24 of 420 kept stories (5.7%) contain at least one CJK character (counts only; no judged-rate DV exists here to recount). A zero-GPU follow-up refit excluding those stories (125 of 2,108 turns dropped; 396 stories kept) moved the story context R² from −0.754 to −0.652 (conversation-bootstrap 95% CI −0.693 to −0.599; shuffle-null p95 −2.02) and the prefix arm from 0.117 to 0.119 — the CJK-carrying stories were disproportionately poorly fit, but the deeply negative context read and the weak-map verdict stand; artifacts under [followup_cjk_excluded](https://github.com/superkaiba/explore-persona-space/tree/ffe970f54f052255722f504e580ce3a06e476517/eval_results/issue_1345/followup_cjk_excluded).

Conversation-paired round (`conversation-paired-stories`): from the 4,724 shared conversations, 96 near-empty answers (under 20 characters) and 539 answers over the 800-token wrapper budget were excluded, and 2,700 of the 4,089 eligible conversations were sampled (seed 42). Each was rendered by the instruct model as a short narrative in which a person asks the original question aloud and a character named Assistant answers with exactly the original words, introduced as `Assistant replied: "…"` (tier-2 instruct-and-strip: the story-writing system instruction carries the original answer and is stripped before extraction). A mechanical gate enforces exactly one normalization-tolerant verbatim occurrence of the answer, one attribution marker adjacent to it, a closed quote, and a quoted question utterance; the dominant reject is the model paraphrasing instead of embedding the answer (about 45% of draws fail the occurrence check). Gate-passing stories were judge-filtered under the standard rubric (713 malformed judge returns across waves dropped as content drops; transport losses 0). Yield: main wave kept 1,103; bounded floor-driven retry waves added 874, 155, and 32 — kept 2,164 of 2,700 (floor 2,160, cleared by 4), 2,163 rows entering the fits. Teacher-forced capture anchors on the verbatim answer span: context slot = last token of `Assistant replied: "`; prefix slot = last token of the narrative before the question utterance (conversation-specific text, not a fixed template region). On-policy companion: 200 conversations, free story-answer generation, 117 kept (mechanical pass 172, judge PASS 122). Language audit: 169 of 2,164 kept stories contain CJK — 121 wrap conversations that are themselves CJK in the underlying corpus (pairing holds conversation language constant across framings) and 48 are wrapper intrusions (CJK narrative around a non-CJK answer). Eval-only, fold-preserving recounts from the layer-19 prediction cache (recompute validated against all three committed values): excluding wrapper intrusions (n = 2,115) story −0.299 / chat 0.243 / plain-text 0.020; excluding all CJK rows (n = 1,994) story −0.286 / chat 0.257 / plain-text 0.037 — the framing-effect verdict is convention-robust. A 5-row spot check (seed 42) found all sampled rows gate-conformant; one passes only under the normalization-tolerant matcher (its raw string differs in whitespace/quote form) — across the kept pool, 201 of 2,164 rows (9.3%) embed the answer only up to whitespace/smart-quote normalization rather than as a raw exact string — and the extraction re-verifies spans with the same matcher.

Slot-ablation round (`story-slot-position-ablation`): no new text — the 2,164 kept paired stories were re-read from the pinned wrapper bundle, and all six read positions (prefix, end-of-question, pre-attribution, anchor, pre-answer, attribution mean-pool) come from one teacher-forced forward per story; 2,163 rows enter every fit (the all-slot row intersection dropped 0 rows). Realized span ordering per story: prefix < end-of-question ≤ pre-attribution ≤ anchor ≤ pre-answer. Answer-span overlap is 0.0 for every slot, and anchor coincidence is 0 rows for three slots and 3 of 2,163 (0.14%) for pre-answer — the expected quote-merge fallback. No generation and no judge calls this round; the paired round's language audit carries over unchanged.
