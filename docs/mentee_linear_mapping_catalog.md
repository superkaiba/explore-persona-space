## Handling notes

- Artifact URLs are revision-pinned; upstream model links are not unless a recorded model revision was available.
- Do not mix map families blindly. Match model, layer, pooling position, centering/scaling, PCA or whitening convention, and matrix orientation to the family’s metadata or method page.
- Download selectively: the ready linear bundles above total roughly 56 GiB, dominated by #2388. For a first exercise, #667, #779 ridge-only, #1738, or #2618 each stays under 300 MiB.
- The #667 and #813 files package both the base and fine-tuned maps. Most other families package one fitted operator per file or payload.
