\begin{abstract}
\noindent
This is a self-standing sample paper used only to smoke-test the dashboard's
LaTeX-paper render path. The Explore Persona Space program studies how
fine-tuning a language model under one persona leaks the trained behaviour to
other personas and to the default assistant context. This fixture reproduces the
shape of a real clean-result paper: an abstract, a self-standing introduction,
a self-contained methods section, results subsections each pairing a figure with
its read, and an appendix. It carries one cross-reference to a sibling
experiment so the hover-preview card can be exercised.
\end{abstract}

\section{Introduction}
\label{sec:intro}

A persona is a system-prompt-induced behavioural mode. When a behaviour is
implanted into a source persona by supervised fine-tuning, the question this line
of work answers is how far that behaviour spreads: does it stay confined to the
source persona, or does it leak to nearby personas and to the bare default
assistant? This sample experiment measures the sycophancy-agreement rate before
and after a single-persona fine-tune, and relates the post-training leakage to
each unit's pre-training base rate. The single variable changed relative to the
parent line~\epsref{612} is the completion-provenance of the positive rows.

\section{Methods}
\label{sec:methods}

Training used Qwen2.5-7B with a LoRA adapter ($r=16$, $\alpha=32$) over a 1:1
mix of positive rows (the source persona, sycophantic completions elicited
on-policy from the base model and judge-filtered) and contrastive negative rows
(four close personas including the default assistant, same questions, agreement
stripped). The dependent variable is the judge-scored on-policy agreement rate.
A continuous companion DV, the length-normalised trained$-$base log-probability
of the model's own judged-positive completions, is reported alongside.

\section{Discussion}
\label{sec:discussion}

The pattern is consistent with the parent line~\epsref{612} and with the
emergent-misalignment literature~\citep{betley2025emergent}: a unit's own
base-model prior is the dominant predictor of how much implanted behaviour it
inherits, beating geometric distance. This is a sample fixture, so the numbers
are illustrative and carry no interpretation beyond exercising the render path.

\paragraph{Limitations.} Single seed, in-distribution eval, one behaviour. The
fixture exists to verify the dashboard renders a paper, downloads its PDF, and
shows a cross-reference hover card.
