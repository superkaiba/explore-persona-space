## Fine-tune mini-pack

From the #1900 directory, include each `.pt` below and its same-name `.json`:

- `m0_L19` — base content map
- `mplus_cas-pers-con-lr1e5-s42_L19` — contrastive LoRA
- `mplus_cas-pers-po-lr1e5-s42_L19` — positive-only LoRA
- `mplus_cas-pers-ft-con-s42_L19` — full fine-tune
- `wmap_cas-pers-con-lr1e5-s42_L19` — context→fine-tuning-write map
- `m0_L25` — base marker-layer map
- `mplus_mk-pers-con-lr5e6-s42_L25` — marker LoRA

The PT payloads contain `kind`, `xmu`, `xsd`, `ymu`, and `W`. Apply a map to raw activations as `((X - xmu) / xsd) @ W + ymu`.

## Size and omissions

The selected coefficient files total approximately **4.0 GiB**, excluding source activations and datasets; about 2.68 GiB is the correctness bundle alone. Story/long-form maps are intentionally excluded. Earlier or redundant map families are omitted where the selection above provides a newer, broader, or smaller representative. Intermediate #1768 LoRA rungs, the OLMo #1902 ladder, and #2546 trajectory fits are not included because they require coefficient refitting.
