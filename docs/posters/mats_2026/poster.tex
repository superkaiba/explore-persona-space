\postersec{Motivation}
Absent external inputs, an LLM's entire answer distribution is \textbf{fixed before the first answer token is generated}: the model is a deterministic mapping from context to answer distribution. A cheap approximation of it would predict behavior pre-generation and anticipate fine-tuning effects. Prior work gives \emph{cheap-but-narrow} predictors or a \emph{whole-distribution-but-expensive} imitator (distillation). Can we cheaply approximate the mapping \emph{as a whole}?

\postersec{Contributions}
\begin{enumerate}
  \setlength\itemsep{0.15em}
  \item[{\color{matsmaroon}\textbf{1.}}] Fitted \textbf{linear} maps explain most held-out answer-vector variance and retrieve the true answer among thousands of candidates far above chance.
  \item[{\color{matsmaroon}\textbf{2.}}] The map is best at \textbf{high-level, persona-like properties} of the answer — and predicts behaviors we care about.
  \item[{\color{matsmaroon}\textbf{3.}}] It is \textbf{largely present in the base model} and refined — not created — by post-training.
  \item[{\color{matsmaroon}\textbf{4.}}] \textbf{One shared operator} serves the assistant and fictional characters, supporting the persona selection model.
\end{enumerate}

\postersec{Experiments}
Qwen2.5-7B(-Instruct) headline; OLMo-2 and Llama/T\"ulu post-training ladders. Real-user contexts (LMSYS-Chat-1M, WildChat), up to 963k training pairs. Ridge maps $\vC \mapsto \vA$ fit per layer with cross-validated $\lambda$; retrieval read via nearest neighbors; behaviors scored by an LLM judge.

\begin{itemize}

  \item Predicting answer correctness (in flight).

\postersec{1.\ High predictive power, mostly linear}
\begin{center}
\includegraphics[width=0.98\linewidth]{plot1_scaling_boundary.pdf}
\end{center}
\figcap{2}{Held-out $R^2$ and rank-1 retrieval (pool 1{,}000) vs.\ training size. Qwen2.5-7B-Instruct, layer 19.}
\begin{itemize}
  \item \takeaways{High predictive power:} held-out $R^2$ 0.75; retrieval acc@1 0.81 (chance $10^{-3}$) at 963k contexts.
  \item \takeaways{Mostly linear:} a neural map adds only $+0.06$ $R^2$, and only at large $n$.
  \item \takeaways{Not just smooth activations:} a generic boundary-token (punctuation) $\to$ next-segment map reads $R^2\!\approx\!0.11$ (dashed).
  \item We focus on the \textbf{linear} map hereafter.
\end{itemize}

\postersec{2.\ It predicts behaviors we care about}
\begin{center}
\includegraphics[width=0.98\linewidth]{c5_pv_methods_regimes.pdf}
\end{center}
\figcap{3}{Persona-vector readouts on context / mapped answer / real answer vs.\ judged behavior.}
\begin{itemize}
  \item \takeaways{Readouts on the mapped answer track judged behavior near the real-answer ceiling} (evil: $\rho$ 0.67 vs.\ 0.69); on the raw context they collapse off-synthetic ($\rho \le 0.03$).
  \item \takeaways{Trait directions are well predicted:} held-out $R^2$ 0.79--0.87 for sycophancy, hallucination, and misalignment directions.
\end{itemize}

\postersec{Applications}
\begin{itemize}
  \item \takeaways{Behavior prediction pre-generation, exploiting unlabeled data:} a map fit on in-domain \emph{unjudged} text beats context probing at every label budget ($\sim$3$\times$ at 250 labels).
  \item \takeaways{Predicting fine-tuning effects:} map-space similarity picks the installed behavior in 9/12 arms (median $\rho$ 0.41 vs.\ 0.30).
  \item \takeaways{Screening training data:} a refit map tracks the exact behavioral shift of training ($r$ 0.73--0.86).
\end{itemize}

\end{column}

\postersec{3.\ Best at high-level, persona-like properties}
We train the map to predict \textbf{SAE features} of the answer (16{,}384 features, per-feature held-out $R^2$), then ask which feature properties predict predictability.
\begin{center}
\includegraphics[width=0.80\linewidth]{c3_sae_tier_gradient.pdf}
\end{center}
\figcap{4}{Per-feature $R^2$ against the judge-free abstraction tier of the feature.}
\begin{itemize}
  \item \takeaways{Abstraction gradient:} median per-feature $R^2$ falls 0.43 $\to$ 0.04 from general to specific features.
  \item \takeaways{Speaker-identity / persona features are the best-predicted label class} (AUROC 0.68, null $\approx$0.49); content entities worst; token-level word choice predicts worst of all.
\end{itemize}

\postersec{4.\ What does it fail on?}
\begin{center}
\includegraphics[width=0.98\linewidth]{c3_failure_attribution.pdf}
\end{center}
\figcap{5}{Failure categories, attribution of rank-1 misses, and the metric fix.}
\begin{itemize}
  \item \takeaways{Failures are mostly map error, not answer degeneracy:} 81\% of rank-1 misses remain retrievable from a fresh draw of the same answer; errors are dragged toward ``hub'' answers. \takeaways{Hot-spots:} refusals ($+25$pp), NSFW ($+22$pp), code ($+11$pp).
  \item \takeaways{The metric, not the map, was the bottleneck:} whitened-cosine + CSLS retrieval with multi-draw targets takes all 7 architectures to 0.99 rank-1.
  \item \takeaways{Worst-predicted contexts:} novel-content requests, small talk, English (0.29) vs.\ non-English (up to 0.42); best: conventionalized moves.
\end{itemize}

\postersec{Limitations}
\begin{itemize}
  \item \takeaways{Prediction $\ne$ control:} the map's read direction does not steer behavior (the mean-difference persona vector does).
  \item $R^2$ and retrieval dissociate across estimators; map-strength claims are metric-specific. Headline results are per model family; claims are correlational.
\end{itemize}

\end{column}

% ==================== COLUMN 4 ====================
\begin{column}{0.235\textwidth}

\postersec{5.\ Where does the mapping come from?}
\begin{center}
\includegraphics[width=0.80\linewidth]{c1_stage_retention.pdf}
\end{center}
\figcap{6}{Map retention across the OLMo-2 post-training ladder, against matched nulls.}
\begin{itemize}
  \item \takeaways{Already largely present in the base model:} same corpus, text, and recipe — Qwen base $R^2$ 0.588 vs.\ instruct 0.673 ($\sim$87\%; $\sim$93\% without the chat template).
  \item \takeaways{SFT strengthens and rewrites it} (largest ladder step, $+0.17$ on-policy $R^2$ on T\"ulu — partly via each stage's own answer text); \takeaways{DPO mostly preserves} (0.87); \takeaways{RLVR leaves it unchanged} (0.99).
  \item \takeaways{Base context vectors already predict later stages' answers} (refit per stage: $R^2$ 0.38 on SFT text — matching any later checkpoint's own activations).
\end{itemize}

\postersec{6.\ Is it a persona mapping?}
\begin{center}
\includegraphics[width=0.80\linewidth]{c4_story_vs_chat.pdf}
\end{center}
\figcap{7}{Map strength under chat, plain-text, and story framings of the same exchanges.}
\begin{itemize}
  \item \takeaways{One shared next-reply operator serves the assistant and fictional characters:} one pooled map recovers 81--98\% of each character's own ceiling (reparameterized: 84--97\%).
  \item \takeaways{Framing moves the map more than character identity} (aligned cosine: character$\leftrightarrow$character 0.52--0.59 $>$ chat$\leftrightarrow$story 0.455).
  \item \takeaways{The assistant is one character among many:} at matched framing its edge is $\sim$0.04--0.06 $R^2$; small assistant-specific effects appear only after post-training.
\end{itemize}

\postersec{Implications}
\begin{itemize}
  \item Much of an LLM's behavior is \textbf{linearly predictable from a single context vector} — a cheap pre-generation audit tool.
  \item Evidence for the \textbf{persona selection model}: the assistant is one character on a shared map.
\end{itemize}
