\postersec{TL;DR}
\begin{itemize}
  \item A single \textbf{linear map} predicts an LLM's mean answer activation from its final context activation \textbf{before generation}: held-out $R^2$ \textbf{0.75}, and rank-1 retrieval of the true answer among 10,000 candidates at \textbf{0.98} 
  \item It is already \textbf{$\sim$67\% present in the base model}, then improves significantly with SFT, and barely changes with DPO and RLVR
  \item It is \textbf{shared between the assistant in chat template, assistant in stories, and other fictional characters in stories}, providing evidence for the persona selection model
  \item It can be used to predict \textbf{sycophancy, hallucination and misalignment before inference}.
\end{itemize}

\postersec{Motivation}
\begin{itemize}
  \item LLMs can be viewed as deterministic maps from \emph{contexts} to \emph{answer distributions}
  \item A \textbf{simple approximation} of that map would be extremely useful: much easier to analyze theoretically, sample from, and understand the effects of finetuning
  \item But it need not exist: the map is billions of parameters applying dozens of nonlinear layers. 
  \item Prior work either uses simple but \emph{narrow} predictors (specific tokens, activations, behaviors), or distillation, a complex whole-distribution predictor
  \item \takeaways{Our question:} can a \textbf{simple} approximation capture the mapping \emph{as a whole}? 
\end{itemize}

\postersec{1.\ The Mapping has high predictive Power and is mostly Linear}
\begin{center}
\includegraphics[width=0.97\linewidth]{plot1_scaling_boundary.pdf}
\end{center}
\figcap{2}{Held-out $R^2$ (left) and rank-1 retrieval (right; raw euclidean, pool 1{,}000) against training-set size. Dashed: generic boundary-token control. Layer 19.}
\begin{itemize}
  \item \takeaways{The mapping has high predictive power:} held-out $R^2$ 0.75, rank-1 retrieval 0.98 at 1 million contexts
  \item \takeaways{The mapping is mostly linear:} the nonlinear (MLP) map adds only $\sim$$0.06$ $R^2$ over the linear map, and only at large $n$ (potentially this advantage would grow as you scale up the number of contexts)
  \item \takeaways{The mapping is not present for generic boundary tokens:} held-out $R^2$ 0.11 for a mapping from generic boundary tokens (punctuation) to the next stretch of text
  \item \takeaways{The mapping is not just copying the context vector:} The mapping does much better than the identity + bias baseline
  \item We study the \textbf{linear} map here 
  \item \takeaways{The mapping is strongest at mid-late depth:} held-out $R^2$ peaks at \textbf{layers 19--20 of 28} (0.76). This is consistent with literature showing that this is where high-level semantic information is most decodable.
\end{itemize}
\begin{center}

\end{center}

\IfFileExists{figures/plot2_persona_directions.pdf}{\includegraphics[width=0.92\linewidth]{plot2_persona_directions.pdf}}{\includegraphics[width=0.88\linewidth]{c3_persona_direction_spectrum.pdf}}

\postersec{3.\ Which (SAE) features of the answer are most predictable?}
We train another map from the context to the answer's \textbf{SAE features}, then partial out predictors \emph{one at a time} to see which survives.
\begin{center}
\includegraphics[width=0.95\linewidth]{plot3_sae_predictors.pdf}
\end{center}
\figcap{5}{Forward-stepwise partialling: each row conditions on all rows above. $c$ = concordance (AUROC scale), $0.5$ = chance. Gray: activity control. Diamond: matryoshka \emph{coarsest} tier — different dictionary, direction only. No CIs; later rounds omitted.}
\begin{itemize}
  \item Controlling for mean activation, the best predictors are
  \begin{itemize}
      \item being related to speaker identity
      \item not suppressing/promoting a few tokens
      \item not being related to topic
      \item being in the coarsest tier of a Matryoshka SAE (intuitively, being high-level)
  \end{itemize}
  \item Therefore, the mapping seems to be 
  \begin{itemize}
      \item good at predicting \textbf{high-level} and \textbf{identity-related} features
      \item bad at predicting \textbf{low-level} and \textbf{topic-related} features
  \end{itemize} 
\end{itemize}

\postersec{4.\ What does it fail to retrieve?}
\begin{center}
\IfFileExists{figures/plot4b_failure_modes.pdf}{\includegraphics[width=0.99\linewidth]{plot4b_failure_modes.pdf}}{\includegraphics[width=0.88\linewidth]{plot4_failures.pdf}}
\end{center}
\figcap{6}{Rate of each failure mode among retrieval failures minus its rate among controls matched on turns $\times$ corpus $\times$ language, in percentage points; lines are 95\% CIs. Colored bars clear BH FDR $q\!=\!0.05$. $n\!=\!1{,}815$ failures vs $1{,}809$ controls.}
\begin{itemize}
  \item \takeaways{It fails when the last turn does not pin the answer:} a bare ``why?'' / ``continue'' ($+7.7$pp), a fill-in-the-blank genre request ($+3.1$), or an answer that drifts back to earlier history ($+3.1$).
  \item \takeaways{It succeeds when the exchange has a distinctive anchor the answer reuses} ($-6.7$pp) --- so what it misses is largely what \emph{no} map could pin down, not a weakness of the map.
  \item \takeaways{One failure is the answer's own fault:} garbled or code-switched responses ($+6.8$pp).
  \item The modes were written \textbf{blind}: a model saw only the failures and a random sample --- no labels, no numbers --- and wrote a yes/no rule per mode, which a judge then applied to every context.
\end{itemize}

\postersec{7. Application: behavior prediction before inference}
\begin{center}
\IfFileExists{figures/plot9_application_arms.pdf}{\includegraphics[width=0.99\linewidth]{plot9_application_arms.pdf}}{\includegraphics[width=0.99\linewidth]{c5_pv_methods_regimes.pdf}}
\end{center}
\figcap{9}{Spearman $\rho$ between readout and judged behavior, per regime. Readouts: persona vector or fitted regression, on the context or the map-predicted answer; oracle = real answer. Muted bars fail the spread gate.}
\begin{itemize}
  \item \takeaways{Persona vectors projected on the context vector fail to generalize to realistic contexts}
  \item \takeaways{Regression on the mapped answer does better than regression from the}
  \item \takeaways{The best pre-inference readout is on the \emph{mapped answer} in every trustworthy generic-chat and OOD cell,} by $+0.01$ to $+0.07$ over the best context-side readout — two sycophancy margins sit inside overlapping CIs.
  \item \takeaways{Regression on the mapped answer matches or beats regression on the context everywhere,} and both leave persona-vector-on-context near zero — the gain is the \emph{map}, not the readout family.
  \item \takeaways{On synthetic prompts the context already gives the behavior away} — the map earns its keep where the prompt does \emph{not} telegraph the answer.
\end{itemize}

\postersec{Other Results}
\begin{itemize}
  \item \takeaways{The mapping does not get reliably better with model scale}
  \item \takeaways{The map survives a reasoning trace:} OpenThinker2-7B reads 0.78 against 0.80 for its non-thinking parent, and context$\to$CoT$\to$answer matches the direct map.
  \item \takeaways{But the CoT is not a privileged span:} it adds $+0.20$--$0.33$ skill, yet a \emph{length-matched slice of the answer's own opening} beats it in all three thinking models (every 95\% CI below zero).
\end{itemize}


\postersec{Implications \& future work}
\begin{itemize}
  \item Much of an LLM's behavior is \textbf{linearly predictable from a single context vector}: a cheap pre-generation audit, and evidence for the \textbf{persona selection model}.
  \item Theoretical analysis $+$ dynamical systems.
  \item Predict other properties: correctness.
  \item Predicting effect of fine-tuning.
  \item Post-training is ``making the assistant's answer more predictable from context''.
  \item Automated redteaming / jailbreaking.
\end{itemize}
