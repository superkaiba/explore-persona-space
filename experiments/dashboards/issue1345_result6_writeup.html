Result 6: The assistant map is the SAME operator with and without the chat template (up to a linear change of coordinates), but collapses when the assistant is a story character

Result 3 showed equal predictive power with/without the template, and Result 4.5 asked why the assistant map holds in User:/Assistant: format but not in stories. Equal R² isn't the same operator, so I tested operator identity directly — holding the assistant persona constant across three framings.

Methodology

  • Three framings of the same assistant: chat-template, plain User:/Assistant:, and an AI character ("ARIA") answering questions in on-policy narrative-prose stories. Base + instruct; context and prefix arms.
  • Chat and no-template are the same conversations re-rendered (clean apples-to-apples); stories are a different corpus (corpus-confounded by design).
  • Per framing: within-regime held-out R² + shuffle null; cross-regime transfer matrix (fit map on framing i, test on j); raw + rotation-aligned operator cosine; and the Result-2.5 general-linear reparameterization (does A·M·B recover the target ceiling?).

Figures

Takeaways

  • Chat and no-template are the same map in different coordinates. Raw operator transfer falls short of the ceiling (keeps 83–84% instruct, 15–31% base) — so not identical raw — but a general-linear change of coordinates recovers the full target ceiling (0.005 below to 0.008 above; nulls ≈ −0.03). Same operator, reparameterized — the Result-2.5 verdict, now across the format dimension.
  • Instruction tuning pulls the two coordinate systems together: raw operator cosine 0.651 (instruct) vs 0.293 (base); rotation-aligned 0.855 vs 0.732 (rotation null ≈ 0). The template shifts coordinates only modestly in the instruct model.
  • The assistant map barely exists in narrative stories: context R² = −0.754 (instruct) — below the answer-mean baseline and below the ~0.16 generic-story prior. So it does not survive as a story character. (Base story arm was below the yield floor — not tested.)
  • Answers Result 4.5's question: the map is tied to the assistant conversational framing (chat or plain User:/Assistant:), not to the "assistant" identity in prose. User:/Assistant: works because it is a conversation; a story about an AI is not.
