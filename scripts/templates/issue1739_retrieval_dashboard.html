What the methods measure

Let z be the standardized context, A z the centered predicted answer, and v a fixed answer-derived persona direction.

MethodScore and interpretation
Mapped answer projectionvᵀ A z = (Aᵀ v)ᵀ z
Predict the answer, then apply the answer readout. The equivalent context readout uses the map’s transpose.
Preimage retrievalq = A⁺₃₇₈ v; score = cos(z, q)
Approximately invert the answer direction, then retrieve contexts resembling that direction. This uses a truncated inverse, plus cosine normalization.
Context-derived directioncos(z, D v_C)
Apply the contrastive context-derived direction, converted to the standardized coordinates.
Answer direction on contextcos(z, D v)
Apply the answer persona vector directly to context, with the same coordinate conversion.
Random baselineThe same frozen sample of 1,000 contexts, independently judged for each behavior.

Projection and inverse retrieval are different rankings. The transpose emphasizes strongly transmitted map components; the inverse divides by retained singular values. Preimage cosine also normalizes the context length. Only mapped projection directly transfers the fixed answer readout.

Here z = D⁻¹(x − μ_C), with D the diagonal context standard deviations. Model: Qwen2.5-7B-Instruct, layer 19. The map was trained on 963,444 pairs; 959,844 saved answers were available, yielding 952,067 unique full prompts. The inverse retains 378 singular components, selected on 400 generic validation pairs before judging.

Coverage: this browser includes every inspected transcript, not the full pool’s text. Full-pool ranks are available for all four methods. Behavior labels exist only for the frozen selection for that behavior; an absent label is never shown as a negative. The top-200 sets and shared random baseline overlap.

Reading the table: the green bar is detected positives divided by all selected contexts; hatching indicates missing judgments. The mean excludes unassessable answers. Search and outcome filters change the example list, not the method summary. Random always uses 1,000 examples.

Interpretation: Luna judgments are reviewable model annotations, not human ground truth. Repeated judging checks repeatability, not accuracy. Hallucination retrieval is dominated by company-introduction prompts whose claims often cannot be checked. Near-duplicate templates remain even after exact-prompt deduplication.
