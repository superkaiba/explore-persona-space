# Untrained Qwen-2.5-7B-Instruct already PASSes 2 of 3 #498 trait rubrics in-scenario; only validating has real base-model headroom (MODERATE confidence)

<!-- clean-result-v3 -->

## Takeaways

- Untrained base PASSes the in-scenario rubric for **pushback (4.40/5, CI 4.13-4.67)** and **explains-well (4.26/5, CI 4.10-4.42)** with zero training — both clear 3.5 by ~0.6 Likert.
- **Validating sits at 2.64/5 (CI 2.37-2.92)**, ~0.6 Likert below the line — the one trait with genuine base headroom for training to move.
- The scenario system prompt alone (no LoRA) moves validating **+0.47** (p=0.002) and explains-well **+0.33** (p < 0.001) on matched prompts; pushback +0.07 (n.s.).
- The trained-vs-base paired-Δ is **unsupported**: the #498 and #517 Q-banks are disjoint (0 of 40 prompts overlap), so no paired training delta survives for ANY trait.
- Decision change: every Likert-rubric implant now gets an untrained-base headroom probe on the SAME Q-bank in the same plan, and every cross-experiment trained-vs-base claim gets a prompt-text equality assertion first.

## What I ran

- **Why:** [#498](https://eps.superkaiba.com/tasks/498) read three in-scenario rubric PASSes as "trait installed", but two scored ~4 on a bare context in the trained model too — leaving installation ambiguous against an unmeasured base baseline.
- **Design:** untrained Qwen-2.5-7B-Instruct (no LoRA), 3 traits × 2 eval contexts (in-scenario system prompt vs bare-assistant), 40 held-out prompts each. The single manipulated variable is the eval context; no training.
- **Eval:** per-trait Claude Sonnet 4.5 Likert rubric (1-5), 3 judge re-calls per row averaged (temperature 0, ~97.5% identical). DV = base in-scenario 95% CI vs the 3.5 PASS line; secondary = paired in-scenario-vs-bare effect on matched prompts. 240 generations, 720 judge calls.
- **Scope shrinkage:** the planned trained-vs-base paired Δ against #498 is descriptive only — the two runs' Q-banks turned out disjoint (0 of 40 prompts overlap by exact text), so the surviving headline is the within-#517 base-headroom story.

## Findings

### Pushback is already at the in-scenario PASS line in the untrained base (4.40/5)

Base under the coding-assistant prompt scores **4.40** on pushback (N=40, 95% CI 4.13-4.67) — 0.6 above 3.5, so saturation is decisive. Bare-assistant scores 4.33; the paired header effect is +0.075 (n.s.).

![Pushes back on bad premises: untrained Qwen-2.5-7B-Instruct scores 4.40 in-scenario and 4.33 bare-assistant, both above the 3.5 PASS threshold. Paired scenario-header effect +0.07 Likert (n.s., p=0.55).](https://raw.githubusercontent.com/superkaiba/explore-persona-space/c2639b807af7ee2a1d9698de7800e048e240e7d2/figures/issue_517/trait_logical_and_pushes_back_v2round2.png)

> **Figure.** *Untrained-base pushback Likert by eval context.* Blue = scenario header, orange = bare-assistant; N=40, error bars ±1 SEM, dashed line at 3.5. Not uniform near-ceiling: 3 of 40 in-scenario prompts score 2, one 3, 13 four, 23 five — ~10% genuine failures, but the mean clears PASS in both contexts.

Cleared by the untrained base, the trained PASS for pushback is consistent with either "training installed it" or "the base was already there" — the comparator can't isolate the two. Resolving it needs the trained adapters on this Q-bank.

### Validating has real headroom — the base sits well below the PASS line (2.64/5)

Base under the emotional-support prompt scores **2.64** on validating (N=40, 95% CI 2.37-2.92) — 0.6 below 3.5, so headroom is decisive: real room for training to move this trait. Bare-assistant drops to 2.17; the paired header effect is +0.467 (p=0.002).

![Validates feelings before advising: untrained base scores 2.64 in-scenario and 2.17 bare-assistant, both below the 3.5 PASS threshold. Paired scenario-header effect +0.47 Likert (p=0.002).](https://raw.githubusercontent.com/superkaiba/explore-persona-space/c2639b807af7ee2a1d9698de7800e048e240e7d2/figures/issue_517/trait_validating_v2round2.png)

> **Figure.** *Untrained-base validating Likert by eval context.* Blue = scenario header, orange = bare-assistant; N=40, error bars ±1 SEM, dashed line at 3.5. Both bars well below PASS; 25 of 40 in-scenario prompts score 2 — the base ignores expressed stress and answers technically on most emotional-support prompts.

This is the one trait where "training installed validation" stays live. The magnitude above base is NOT measured — the trained numbers came from a different Q-bank, so the apparent ~+1.6 Likert from v1 was two unpaired distributions, not a paired delta.

### Explains-well is also already above the PASS line in the untrained base (4.26/5)

Base under the teacher prompt scores **4.26** on explains-well (N=40, 95% CI 4.10-4.42) — 0.6 above 3.5, saturation again decisive. Bare-assistant still scores 3.92; the paired header effect is +0.333 (p < 0.001).

![Explains clearly: untrained base scores 4.26 in-scenario and 3.92 bare-assistant, both above the 3.5 PASS threshold. Paired scenario-header effect +0.33 Likert (p < 0.001).](https://raw.githubusercontent.com/superkaiba/explore-persona-space/c2639b807af7ee2a1d9698de7800e048e240e7d2/figures/issue_517/trait_explains_well_v2round2.png)

> **Figure.** *Untrained-base explains-well Likert by eval context.* Blue = scenario header, orange = bare-assistant; N=40, error bars ±1 SEM (in-scenario SEM 0.08, tightest of the three), dashed line at 3.5. Bare-assistant is striking: 37 of 40 prompts score exactly 4 — the base is near a floor of 4, clearing PASS by default response structure.

An alternative reading: the rubric may over-reward format markers (numbered lists, defined jargon) over substance, making the saturation partly a rubric-design issue. This run can't separate the two; a harder rubric or human spot-checks on the 4-vs-5 boundary would.

### Why the trained-vs-base paired-Δ is unsupported (0 of 40 prompts overlap)

The v1 writeup quoted paired Δ comparing trained means to these base means as if the same 40 prompts sat behind both. They didn't: the driver regenerated the Q-bank from the eligibility seed but drew a different set than #498 evaluated — 0 of 40 prompts overlap by exact text. So the comparison can't be paired here.

What survives: the within-task base-headroom finding, and the paired header effect on matched prompts (validating +0.47; explains-well +0.33; pushback n.s.). The clean closer is ~1 GPU-hour: evaluate the trained adapters on this task's exact 40 prompts.
