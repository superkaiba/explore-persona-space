# Activation-space alignment to a behavior direction predicts a persona's own base rate (sycophancy, EM) but does not beat the base prior on where leakage lands (MODERATE confidence)

<!-- clean-result-v4 -->

**Methodology:** [docs/methodology/issue_657.md](https://github.com/superkaiba/explore-persona-space/blob/5c8105fb4c0ba3a0d4ea03e704dadff62e2e7e17/docs/methodology/issue_657.md) · [gist](https://gist.github.com/superkaiba/66eb6ccd50653b152024e3f3022745e0)

## Takeaways

- **Alignment predicts a persona's own behavior rate for sycophancy (ρ = 0.68) and, by point estimate only, EM (ρ = 0.51); refusal is flat (ρ = 0.01).**
- **The sycophancy base-rate read reproduces the parent (ρ = 0.68 vs 0.726, inside the CI).** The two non-clearances are not a join bug.
- **Alignment does not beat the base prior on leakage.** Raw held-out ρ crosses zero for every behavior; the lone doubly-partialled sycophancy ρ = 0.18 is a partialling artifact.
- **Power binds and the causal gate is weak.** At ~23 held-out personas the minimum detectable ρ is ~0.62; each direction moves the judged behavior ~1 of 100 points.
- **A 17×-larger pooled re-read (399 cells, ρ = 0.088, CI [−0.017, 0.171]) tightens the verdict without flipping it.** The per-behavior inconclusive is not low power.

## Goal

- **This experiment in context:** A persona's activation-space alignment to the sycophancy direction predicts its own base sycophancy rate (ρ = 0.726 in the parent run, [#623](https://eps.superkaiba.com/tasks/623)) — a positive geometric signal, where a separate distance-based predictor line ([#518](https://eps.superkaiba.com/tasks/518), [#545](https://eps.superkaiba.com/tasks/545), [#605](https://eps.superkaiba.com/tasks/605)) had repeatedly found nothing that beats the prior that personas already prone to a behavior catch more of it when it leaks. This run moves the prediction target from a persona's own base rate to *where an implanted behavior lands* across held-out personas, asks whether the base-rate link holds for refusal, marker, and emergent misalignment as well as sycophancy, and benchmarks the geometry against that base prior.
- **Broader narrative:** This serves the leakage-predictor question (`docs/open_questions.md`, `leak-predictor` anchor): whether any base-model-readable geometry predicts cross-persona leakage landing better than a unit's own behavioral prior. Seven candidate geometries have now failed that bar.

## Methodology

**Design:** A training-free reuse analysis on `Qwen/Qwen2.5-7B-Instruct`. Four behaviors (sycophancy, refusal, marker, emergent misalignment) are analyzed identically over a 24-persona leakage panel (~23 resolvable held-out personas per testable behavior). For each behavior the analysis pairs, per persona, an *alignment* scalar (cosine of the persona's vector to the behavior direction) with two targets: the persona's own base behavior rate, and the leakage Δ landing on the persona when the behavior is implanted into a different source. Held-out reads use leave-one-persona-out; uncertainty is a B = 10,000 bootstrap over personas (seed 657). The single change from the parent is the prediction target, which moves from a persona's own rate to cross-persona leakage landing, benchmarked against the base prior. Two rounds were run: the extraction and partial-correlation bake-off (2026-06-18), then a higher-N pooled leave-one-behavior-out re-read at the predictor-skill level (n = 399 cells, same date). The only new compute was a single base-model activation-extraction pass for 7 personas absent from the reused bank plus the refusal, marker, and EM directions; every other input is a per-persona scalar from a prior measurement.

**Training:** **N/A — no model training.** The persona-vector bank, the four behavior directions, the per-persona base rates, and the leakage cells are reused; the procedures that produced them are written out in full below as the present method. Analysis-design constants:

| Parameter | Value | Source |
|---|---|---|

| Persona-vector readout | last-prompt-token (headline), response-avg (robustness) | `.claude/rules/persona-distance-metrics.md` |
| Persona vector | `centroid_persona − centroid_assistant`, global-mean-centered bank | persona-vector recipe |

**Evaluation:** The dependent variable for the leakage read is the held-out Spearman ρ between a persona's alignment (cosine of its persona vector to the behavior direction, layer 14, last prompt token, global-mean-centered bank) and the leakage Δ (trained − base behavior rate) landing on each held-out bystander, with the base prior partialled out two ways: the scalar base rate, and a geometry-side restatement of it. Each behavior direction first passed a causal sign-of-life gate — adding the direction to the residual stream must increase the judged behavior, scored 0–100 by `claude-sonnet-4-5` — before its ρ was read; the beat-the-prior test ran only on directions that are pure base-model reads and passed the gate.

The four behavior directions are constructed as follows.

- *Sycophancy.* The Persona Vectors recipe (arXiv 2507.21509). From the paper's verbatim sycophancy trait description, a `claude-sonnet-4-5` generator produces 5 positive/negative instruction pairs and 40 questions (split 20 extraction / 20 held-out). For each (extraction question, pos|neg instruction), the base model samples 10 rollouts at temperature 1.0; a `claude-sonnet-4-5` 0–100 judge retains positive rollouts scoring > 50 and negative rollouts scoring < 50 (realized: 593 positive, 999 negative, 0 refusals). Each retained rollout is teacher-forced through the model and its last-prompt-token and response-averaged activations are captured at layers {7, 14, 21, 27}; the direction is mean(positive) − mean(negative) per layer per readout.
- *Refusal.* Arditi difference-in-means (arXiv 2406.11717), the published direction for this model family. Harmful instructions (`mlabonne/harmful_behaviors`, the AdvBench bank) and harmless instructions (`mlabonne/harmless_alpaca`), 128 each, are run through the base model; the direction is the mean post-instruction-token activation on harmful minus the mean on harmless, at the same four layers. 16 held-out harmful + harmless probes validate the K2 add-elicits-refusal gate. Layer choice is fixed to the four bank layers rather than Arditi's full layer × position validation sweep, to keep the direction commensurable with the persona vectors it is correlated against.
- *Marker.* The Persona Vectors recipe applied to a marker-affordance trait description (instruction to end responses with the ` ※` token). This pure base-model read failed the causal gate (below), so the marker direction fell back to a trained-shift read (next item), which demotes marker to a base-rate-only behavior.
- *Marker and EM (trained-shift reads).* A direction read as the mean trained − base activation shift at layer 14, last response token, induced by a behavior-implant LoRA adapter. The marker adapter is an r = 8, α = 16 rsLoRA contrastive marker implant: 200 positive rows under the source persona append the ` ※` token (id 83399) after a frozen greedy base response, with loss on the marker token only, interleaved with 200 contrastive-negative rows across four other personas that omit the marker. The EM adapter is an r = 8, α = 16 rsLoRA plain SFT on the Turner bad-medical-advice corpus (arXiv 2506.11613). For each adapter the trained and base models are teacher-forced on the same persona-conditioned sequences over 14 personas × 20 questions, and the shift vector is the mean difference at the read site.

The persona vectors themselves are the established project recipe: per persona, the mean last-prompt-token activation over a shared 240-question bank under that persona's system prompt, minus the assistant-context centroid over the same bank, at the four layers, with the bank globally mean-centered.

The per-persona base behavior rates are on-policy judged rates. For sycophancy, each persona's system prompt (no sycophancy instruction) conditions 600 base-model free generations over a 60-claim audited false-claim pool; a `claude-haiku-4-5` judge labels each generation for agreement, and the rate is the fraction agreeing. The leakage Δ per (source, bystander) cell is the trained − base behavior rate on the bystander persona when the behavior is implanted in the source via a contrastive-negative LoRA adapter (r = 32, α = 64 rsLoRA, lr = 1e-5, 3 epochs, 700-row mix of 200 source-positives + 400 bystander-negatives + 100 no-persona rows), evaluated on-policy: the trained model writes its own response under the bystander prompt and the same judge labels it.

**Data extraction:** Tier-2 (established datasets) plus reuse. The behavior directions, persona-vector bank, base rates, and leakage cells were measured in the prior tasks cited in the **Repro:** footer and consumed here as the present method's inputs; the bake-off itself reads only per-persona scalars (one cosine plus one base-rate or leakage number per persona × behavior), not completions. The marker affordance text is project-invented, so no tier-1/2 corpus exists for it. The refusal probe banks are field-standard harmful/harmless instruction sets; the sycophancy claim pool is an audited within-project false-claim benchmark.

## Results

### Alignment predicts a persona's own base rate for sycophancy (ρ = 0.68) and EM (ρ = 0.51), not refusal

What is plotted: per-behavior Spearman ρ(alignment, own base rate), 95% bootstrap CIs over personas. Each point is one behavior; dashed line = ρ = 0.5; diamond = parent sycophancy anchor (ρ = 0.726). Marker omitted (n = 3).

![Forest plot of Spearman correlation between persona alignment and the persona's own base rate, per behavior, with 95% CIs. Sycophancy 0.68 and EM 0.51 above the 0.5 threshold; refusal near 0 with a wide CI. The parent sycophancy anchor diamond sits at 0.726 beside the sycophancy point.](https://raw.githubusercontent.com/superkaiba/explore-persona-space/7b96f66feebc664e5bb54b7416118b4be640d440/figures/issue_657/fig_h1_base_rate.png)

> **Figure.** *Alignment predicts a persona's own rate for sycophancy and EM, not refusal.* Spearman ρ(alignment, base rate) per behavior, 95% bootstrap CI over personas; diamond = parent (ρ = 0.726), dashed line = ρ = 0.5. EM CI [0.07, 0.79]; refusal CI [−0.46, 0.47], n = 23.

Sycophancy reproduced the parent (0.726 inside the CI), so the join is sound. EM cleared 0.5 by point estimate only; refusal was flat. Two of three cleared.

What is plotted: the unaggregated data behind the sycophancy forest point — one labeled dot per persona, no partialling. x = cosine alignment to the sycophancy direction at layer 14; y = base sycophancy rate (Haiku judge, reused base pass).

![Scatter of 16 personas, each point labeled with its persona name: x = cosine alignment to the sycophancy direction at layer 14, y = base sycophancy rate. Points trend upward from the low-alignment cluster near rate 0.03 to higher-alignment personas near rate 0.06-0.12.](https://raw.githubusercontent.com/superkaiba/explore-persona-space/7b96f66feebc664e5bb54b7416118b4be640d440/figures/issue_657/fig_h1_sycophancy_scatter.png)

> **Figure.** *More-aligned personas are more sycophantic at baseline (ρ = 0.68, n = 16).* One labeled point per persona; x = cosine(persona vector, sycophancy direction) @ layer 14, y = base sycophancy rate. No aggregation or partialling.

The forest point ρ = 0.68 compresses this upward trend. Every negative-alignment persona sits at a low base rate, so the rank is not driven by a single outlier.

### The causal sign-of-life gate is weak, and the marker direction fails it

What is plotted: the per-direction steering effect at the headline layer, in judge points (0–100 scale). Diamond = mean; grey dots = the three per-strength effects. Positive = increased the judged behavior.

![Causal sanity check: per-direction steering effect at the headline layer on a judge-points axis (full scale 0-100). Refusal mean about +0.96 with per-strength points scattering from minus 2.75 to plus 3.875; marker exactly zero at all strengths; emergent misalignment mean about +0.07 with per-strength points near zero.](https://raw.githubusercontent.com/superkaiba/explore-persona-space/7b96f66feebc664e5bb54b7416118b4be640d440/figures/issue_657/fig_k2_steering.png)

> **Figure.** *Each gate effect is ≪ 1% of the 0–100 judge scale, and refusal/EM sign-flip across strengths.* Headline-layer steering effect in judge points; diamond = mean, grey dots = three per-strength effects. Refusal +0.96 = mean of [1.75, −2.75, 3.875]; EM +0.07 = mean of [−0.05, −0.05, 0.30]; marker zero everywhere.

The marker direction moved emission by zero across all twelve cells, so the run fell back to a trained-shift marker read (demoting marker to base-rate-only). Refusal and EM passed only weakly — ~1 judge point, non-monotonic — barely causally validated.

### Alignment did not predict leakage out-of-sample, or beyond the base prior

What is plotted: held-out alignment-vs-leakage Spearman ρ per behavior under three controls — raw (×, no partialling), prior-partialled (□), and doubly-partialled (●, 95% CI). The two reads test two gates: out-of-sample (raw) and beyond-the-base-prior (doubly-partialled).

![Forest plot of the held-out alignment-vs-leakage correlation per behavior, showing raw, singly-partialled, and doubly-partialled Spearman rho with 95% CIs. Sycophancy doubly-partialled rho 0.18 with CI above zero; refusal 0.12 and EM negative with CIs crossing zero.](https://raw.githubusercontent.com/superkaiba/explore-persona-space/7b96f66feebc664e5bb54b7416118b4be640d440/figures/issue_657/fig_h3_forest.png)

> **Figure.** *Out-of-sample leakage prediction is null (raw ×); only the doubly-partialled sycophancy ρ clears zero, and it still fails the beat-the-prior gates.* Held-out ρ(alignment, leakage Δ): raw (×), prior-partialled (□), doubly-partialled (●, 95% CI). Sycophancy raw ρ = 0.14 (CI [−0.01, 0.30]), doubly-partialled ρ = 0.18 (CI [0.05, 0.33]); refusal and EM CIs straddle zero.

Out-of-sample, the prediction failed for every behavior — raw held-out ρ crosses zero (sycophancy 0.14) — so the lone sycophancy clearance appears only after partialling out the prior: an artifact, not a beat. The doubly-partialled ρ = 0.18 clears zero, but the grouped-cross-validation incremental-R² interval spans zero.

### A 17×-larger pooled read tightens the verdict without flipping it

What is plotted: the doubly-partialled alignment-vs-leakage ρ for the three per-behavior reads (n ≈ 23 each) against a pooled read of 399 cells across 69 (behavior, bystander) groups, with 95% CIs and a zero reference line.

![Forest plot comparing the doubly-partialled alignment-vs-leakage correlation for the three per-behavior reads against the pooled 399-cell read, all with 95% CIs and a zero reference line. Every interval, including the tighter pooled one, crosses zero.](https://raw.githubusercontent.com/superkaiba/explore-persona-space/7b96f66feebc664e5bb54b7416118b4be640d440/figures/issue_657/fig_reliability_band.png)

> **Figure.** *Pooling to 399 cells tightens the beat-the-prior interval but it still straddles zero.* Doubly-partialled ρ (alignment, held-out leakage Δ), 95% CI; per-behavior reads (n ≈ 23 each) vs the pooled read (n = 399). Pooled ρ = 0.088, CI [−0.017, 0.171].

At 17× the sample the interval tightens but the verdict holds, so the per-behavior null is not a low-power artifact. The pooled incremental-variance test still straddles zero — neither a beat nor a confirmed null.
