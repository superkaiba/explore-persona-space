# Activation-space alignment to a behavior direction predicts a persona's own base rate (sycophancy, EM) but does not beat the base prior on where leakage lands (MODERATE confidence)

<!-- clean-result-v4 -->

## Takeaways

- **The base-rate link generalized to one new behavior, not three.** Alignment predicts a persona's own sycophancy (ρ = 0.68) and EM (ρ = 0.51); refusal is flat (ρ = 0.01).
- **The sycophancy base-rate replication held** (ρ = 0.68 vs the parent's 0.726, inside the CI). The non-clearances are not a join bug.
- **Alignment did not beat the base prior on leakage.** Out-of-sample, raw held-out ρ crosses zero for every behavior; the lone doubly-partialled sycophancy ρ = 0.18 is a partialling artifact.
- **Power binds and the causal gate is weak.** With ~23 held-out personas the smallest detectable ρ is ~0.62; the refusal/EM direction gates move ~1 judge point on a 0-100 scale.
- **A 17×-larger pooled re-read tightens the verdict but does not flip it.** Pooling 399 cells holds the incremental variance straddling zero — the per-behavior inconclusive was not a low-power artifact.

## Goal

- **This experiment in context:** A prior result ([#623](https://eps.superkaiba.com/tasks/623)) found that how strongly a persona points toward the sycophancy direction predicts its own sycophancy rate (ρ = 0.726) — a positive geometric signal where a whole distance-based predictor line ([#518](https://eps.superkaiba.com/tasks/518), [#545](https://eps.superkaiba.com/tasks/545), [#605](https://eps.superkaiba.com/tasks/605)) repeatedly found nothing beating the dead-simple "personas already prone to a behavior catch more of it" prior. This run moves the prediction target from a persona's own base rate to *where an implanted behavior leaks* across held-out personas, asks whether the base-rate link holds for other behaviors, and benchmarks both against that base prior.
- **Broader narrative:** Serves the leakage-predictor question (`docs/open_questions.md` leak-predictor anchor): is there ANY base-model-readable geometry that predicts cross-persona leakage landing better than a unit's own behavioral prior? Seven geometries have now missed this bar.

## Methodology

- **Design:** One manipulated variable vs the parent — the prediction *target* moves from a persona's base rate to cross-persona leakage landing, benchmarked against the base prior. Four behaviors (sycophancy, refusal, marker, emergent misalignment) analyzed identically over a reused 24-persona leakage panel (~23 resolvable held-out personas per testable behavior); leave-one-persona-out, bootstrap B = 10,000. Two rounds: the extraction + partial-correlation bake-off (2026-06-18), then a higher-N pooled leave-one-behavior-out re-read at the predictor-skill level (n = 399 cells, 2026-06-18).
- **Training:** **N/A — no model training.** Training-free reuse analysis: leakage cells, base rates, and the persona-vector bank come from prior tasks; the only new compute was a one-pass base-model activation extraction (7 missing personas + the refusal/marker/EM directions). Analysis-design constants:

  | Parameter | Value | Source |
  |---|---|---|
  | Base model | `Qwen/Qwen2.5-7B-Instruct` | parent [#623](https://eps.superkaiba.com/tasks/623) recipe |
  | Persona-vector readout | last-prompt-token (headline), response-avg (robustness) | `.claude/rules/persona-distance-metrics.md` |
  | Persona vector | `centroid_persona − centroid_assistant`, global-mean-centered bank | `.claude/rules/persona-distance-metrics.md` (bank centering) |
  | Layers swept | {7, 14, 21, 27}; headline layer 14 | parent [#623](https://eps.superkaiba.com/tasks/623) |
  | Alignment metric | cosine | `.claude/rules/persona-distance-metrics.md` |
  | Partial correlation | Spearman partial via rank-residualization; doubly-partialled on `[bystander_base_rate, prior_centroid_projection]` | plan §6 |
  | Bootstrap | B = 10,000 over held-out personas, seed 657 | project default |
  | Shuffled-direction null | B = 1,000 random rotations, seed 657 | plan §6 |
  | Held-out protocol | LOPO (leave-one-persona-out) primary; LOBO secondary | plan §6 |
  | Effective N (leakage read) | ≈ 17-23 bystanders per behavior; MDE-ρ ≈ 0.62 at n = 17 | computed |
  | Causal-gate judge | `claude-sonnet-4-5` | CLAUDE.md judge rule |
  | Causal-gate pass criterion | `headline_layer_effect > 0` (add-the-direction elicits the behavior) | plan §6 |

- **Evaluation:** The dependent variable is held-out Spearman ρ between a persona's alignment (cosine of its persona vector to the behavior direction, layer 14, last-prompt-token, global-mean-centered bank) and the leakage Δ (trained − base behavior rate) landing on each held-out bystander, with the base prior partialled out two ways (the scalar base rate and a geometry-side restatement of it). Each behavior direction first had to pass a causal sign-of-life gate (adding the direction must increase the judged behavior, scored 0-100 by `claude-sonnet-4-5`) before its ρ was read; the beat-the-prior test ran only on pure base-model-read directions that passed the gate. Probe banks for the refusal direction + causal gate: harmful = AdvBench behaviors (`mlabonne/harmful_behaviors`), harmless = `mlabonne/harmless_alpaca`, 128 each, post-instruction-token positions, 16 held-out probes — chosen because they are the established difference-in-means contrast set (Arditi et al.) for a base-model refusal direction.
- **Data extraction:** Tier-2 (established datasets) + reuse. The four behavior directions were reused verbatim (sycophancy trait direction, base-model read) or extracted from the base model / a single reused adapter (refusal difference-in-means; marker and EM trained-shift reads). The persona-vector bank and leakage cells are reused from prior tasks; the marker direction fell back to a trained-shift read (its affordance recipe failed the gate). No new training rows — the bake-off consumes per-persona scalars (one cosine + one leakage number per persona × behavior), not completions.
- **Sample training/evaluation data + completions:** The bake-off generates no text; the causal-gate phase generated steered completions. The steering raw files store only `{question, response}` (no judge field), so an annotated baseline-vs-steered verdict row is not retained at this resolution. ## Results

### Alignment predicts a persona's own base rate for sycophancy (ρ = 0.68) and EM (ρ = 0.51), not refusal (2 of 4)

What is plotted: per-behavior Spearman ρ(alignment, own base rate), 95% bootstrap CIs over personas. Each point is one behavior; dashed line = ρ = 0.5 bar; diamond = parent anchor (ρ = 0.726). Marker omitted (n = 3).

![Forest plot of Spearman correlation between persona alignment and the persona's own base rate, per behavior, with 95% CIs. Sycophancy 0.68 and EM 0.51 above the 0.5 threshold; refusal near 0 with a wide CI. The parent sycophancy anchor diamond sits at 0.726 beside the sycophancy point.](https://raw.githubusercontent.com/superkaiba/explore-persona-space/7b96f66feebc664e5bb54b7416118b4be640d440/figures/issue_657/fig_h1_base_rate.png)

> **Figure.** *Alignment predicts a persona's own rate for sycophancy and EM, not refusal.* Spearman ρ(alignment, base rate) per behavior, 95% bootstrap CI over personas; diamond = parent (ρ = 0.726), dashed line = ρ = 0.5. EM CI [0.07, 0.79]; refusal CI [−0.46, 0.47], n = 23.

Sycophancy reproduced the parent (0.726 inside the CI), so the join is sound; EM cleared by point estimate only; refusal was flat. Two of three cleared.

### The per-persona view behind the sycophancy ρ: alignment tracks base rate across the 16 personas

What is plotted: the raw, unaggregated data behind the forest-plot sycophancy point — one labeled dot per persona, no partialling. x = cosine alignment to the sycophancy direction at layer 14; y = base sycophancy rate (reused #623 rates, Haiku judge).

![Scatter of 16 personas, each point labeled with its persona name: x = cosine alignment to the sycophancy direction at layer 14, y = base sycophancy rate. Points trend upward from the low-alignment cluster near rate 0.03 to higher-alignment personas near rate 0.06-0.12.](https://raw.githubusercontent.com/superkaiba/explore-persona-space/7b96f66feebc664e5bb54b7416118b4be640d440/figures/issue_657/fig_h1_sycophancy_scatter.png)

> **Figure.** *More-aligned personas are more sycophantic at baseline (ρ = 0.68, n = 16).* One labeled point per persona; x = cosine(persona vector, sycophancy direction) @ layer 14, y = base sycophancy rate. No aggregation or partialling.

The upward climb is what the ρ = 0.68 forest point compresses; the negative-alignment personas all sit at low base rates, so the rank is not a single-outlier effect.

### The causal sign-of-life gate is weak (~1 judge point of 100) and the marker direction fails it outright

What is plotted: the per-direction steering effect at the headline layer, in judge points (0-100 scale). Diamond = mean; grey dots = the three per-strength effects. Positive = the direction increased the judged behavior.

![Causal sanity check: per-direction steering effect at the headline layer on a judge-points axis (full scale 0-100). Refusal mean about +0.96 with per-strength points scattering from minus 2.75 to plus 3.875; marker exactly zero at all strengths; emergent misalignment mean about +0.07 with per-strength points near zero.](https://raw.githubusercontent.com/superkaiba/explore-persona-space/7b96f66feebc664e5bb54b7416118b4be640d440/figures/issue_657/fig_k2_steering.png)

> **Figure.** *Each gate effect is ≪ 1% of the 0-100 judge scale, and refusal/EM sign-flip across strengths.* Headline-layer steering effect in judge points; diamond = mean, grey dots = three per-strength effects. Refusal +0.96 = mean of [1.75, −2.75, 3.875]; EM +0.07 = mean of [−0.05, −0.05, 0.30]; marker zero everywhere.

The marker direction moved emission by zero at all twelve cells, so the run fell back to a trained-shift read (demoting marker to base-rate-only). Refusal and EM pass only weakly (~1 judge point, non-monotonic) — barely causally validated.

### Alignment did not predict leakage out-of-sample, or beyond the base prior

What is plotted: held-out alignment-vs-leakage Spearman ρ per behavior under three controls — raw (×, no partialling), prior-partialled (□), doubly-partialled (●, 95% CI). Two gates: out-of-sample (raw) and beyond-the-base-prior (doubly-partialled).

![Forest plot of the held-out alignment-vs-leakage correlation per behavior, showing raw, singly-partialled, and doubly-partialled Spearman rho with 95% CIs. Sycophancy doubly-partialled rho 0.18 with CI above zero; refusal 0.12 and EM negative with CIs crossing zero.](https://raw.githubusercontent.com/superkaiba/explore-persona-space/7b96f66feebc664e5bb54b7416118b4be640d440/figures/issue_657/fig_h3_forest.png)

> **Figure.** *Out-of-sample leakage prediction is null (raw ×); only the doubly-partialled sycophancy ρ clears zero, and it still fails the beat-the-prior gates.* Held-out ρ(alignment, leakage Δ): raw (×), prior-partialled (□), doubly-partialled (●, 95% CI). Sycophancy raw ρ = 0.14 (CI [−0.01, 0.30]), doubly-partialled ρ = 0.18 (CI [0.05, 0.33]); refusal and EM CIs straddle zero.

Out-of-sample the prediction failed everywhere — raw held-out ρ crosses zero for all behaviors (sycophancy 0.14) — so the lone sycophancy clearance appears only once the prior is partialled out: an artifact, not a beat. The doubly-partialled ρ = 0.18 clears zero but the grouped-CV ΔR² interval spans zero.

### A 17×-larger pooled read tightens the beat-the-prior verdict but does not flip it

What is plotted: the doubly-partialled alignment-vs-leakage ρ for the three per-behavior reads (n ≈ 23 each) against a pooled read of 399 cells across 69 (behavior, bystander) groups, 95% CIs + a zero reference line.

![Forest plot comparing the doubly-partialled alignment-vs-leakage correlation for the three per-behavior reads against the pooled 399-cell read, all with 95% CIs and a zero reference line. Every interval, including the tighter pooled one, crosses zero.](https://raw.githubusercontent.com/superkaiba/explore-persona-space/7b96f66feebc664e5bb54b7416118b4be640d440/figures/issue_657/fig_reliability_band.png)

> **Figure.** *Pooling to 399 cells tightens the beat-the-prior interval but it still straddles zero.* Doubly-partialled ρ (alignment, held-out leakage Δ), 95% CI; per-behavior reads (n ≈ 23 each) vs the pooled read (n = 399). Pooled ρ = 0.088, CI [−0.017, 0.171].

At 17× the sample the interval tightens but the verdict does not flip — the per-behavior null was not a low-power artifact. The pooled incremental-variance test still straddles zero, so no beat and no confirmed null.
