# Core composition rules

1. **Enumerate labeled sub-questions (A)–(N) explicitly** — sub-question enumeration is THE driver of blocking verdicts; Codex addresses each systematically and elevates findings that would otherwise be SR-only. (#311, #344, #354)
2. **Mediation power question** whenever a test rules out an alternative — "p > 0.05 on a binary proportion at n=50 is not evidence of absence; is the test adequately powered?" (#344)
3. **Point Codex at the specific confound reference** ("#280 ruled out sequence length for FULL-rationale-loss arms, not answer-only-gradient arms") — named references get elevated to Must Fix. (#344)
4. **Conditional-gate generalizability** — "does the gate generalize beyond the highest-signal source?" for any conditional cell or single-source fallback. (#344)
5. **No multiline heredoc Python in the prompt** — let Codex run its own grep/find/python3 to verify numbers. (#344)
6. **Round-2 principle:** once round-1 BLOCKERs become pre-registered gates, round 2 scrutinizes GATE SPECIFICITY + selection-gameability (bystander-set draggability, threshold calibration, tolerance width, engine flush, multiplicity, pair-specificity). (#354 r2 — 8 Must Fix from sub-questions A–H)
7. **CONTENT QUARANTINE for EM-adjacent corpora** (numeric-only jq; no corpus .jsonl / raw_completions / parent-EM body reads) — dodges usage-policy refusals mid-critique. (#570 onward)
8. **Global-null-is-shippable plans need "don't demand a kill gate for the null branch".** (#602)
9. **The brief's verdict contract overrides the standard format** (e.g. a bare `RATING: X` line, no epm tags) — follow it verbatim. (#601 v4)
10. **Out-of-bounds blocks keep Codex on-lens:** don't relitigate documented teacher-forced exceptions (only their cross-arm boundary), user overrides, named follow-ups, inherited single-variable-contract choices, or plan-stated bounded residuals (default Concern). Re-run demands for historical results are out of scope when routed to follow-ups.

# Recurring cross-design patterns (cite by name inside any family)

- **Exposure parity ≠ optimizer-trajectory parity** — matched cumulative examples still differ in warmup/cosine position, Adam-update counts, LR-decay shape; compute positive-rows-seen ratios up front. (#311, #552/29a, #597, #601, #606)
- **Bundle attribution — fix is wording, never a new arm** — when an arm changes several things at once (prompts + negatives + structure; positives AND negatives regenerated; negatives + row diversity), check every headline sentence is scoped to the BUNDLE, not one component; demand a scope-down. (29a, 37, 38, 39)
- **Trained-in containment** — a trained-negative context's low leak is the design working, not containment evidence; arm-specific probes that are each arm's trained negatives partly read "whose negatives suppressed harder"; near-twins of an inherited negative inherit the suppression. (29a-G, 37-G, 38-C, 39-D)
- **Retroactive headline upgrade via shared figure** — a hedged/DR-gated parent cell beside a clean new cell in a cross-round figure silently upgrades the parent claim. (25-F, 26-e, 40)
- **Data-exhaustion mimic** — positive-row CE ≈ 0 within epoch 1 ⇒ later epochs deliver no gradient: co-landing arms "agree" because training stopped; minimal fix = per-row-type training-CE logging. (35-B, 40-B)
- **Per-row repetition harm** — cycling a small pool inflates per-row exposure; repetition damage in the dose arm + insufficient dose in the epoch arm jointly defeat "under-install in BOTH ⇒ composition"; do trajectory reads route non-monotone outcomes? (37-B, 40-C)
- **Contrast-not-delivered** — near-on-policy negatives carry ~zero CE gradient; "contrast doesn't matter" vs "contrast wasn't administered" are distinct claims on the same terminal data; per-row-type CE diagnostic or scope-down. (29a-D, 41-C leakage-gated variant)

# Per-design-family sub-question sets

**Masked-loss / EOS-masking ablations with pre-registered gates (#311, #344 r2–r3, #354 r1–r2) — the standing checklist:**
- training-budget/exposure asymmetry across LoRA variants when an additive decomposition is the headline;
- per-pair direction-consistency for Stouffer combinations ("does PASS require both pairs to show the predicted sign?");
- independence-baseline ceiling for rate residuals (rate_A + rate_B − rate_joint can go impossible);
- TOST direction completeness (route the MORE-of-predicted-signal branch too) + template-matched comparison arm (a carry-over under a different template biases the mediation);
- ratio-denominator interpretability when the denominator is an effect size ("non-trivially nonzero?");
- position gate pre-registered vs post-hoc diagnostic + threshold above the length-adjusted null ("if B fires at position 500/600, is it still chunk-binding?");
- same-run unmasked baseline for single-variable ablations vs a prior run (environment/cache drift);
- bystander check as a falsification gate, not diagnostic ("if bystander ≥ recipient, do NOT call it chunk-binding");
- bystander cell selection pre-named and non-draggable;
- char-distance thresholds calibrated RELATIVE to completion length (absolute passes short-completion suffix habits);
- env-parity tolerance tight enough at a near-zero baseline (±10pp around 1.3% is mechanism-blind);
- vLLM engine flush / fresh process between sequential adapters (KV/prompt-cache contamination);
- B-multiplicity gating (pct_multiple_B; confirmation requires exactly one?);
- contrastive-negative bleed (LoRA-global stop-signal suppression elevates ALL trained personas — use trained-negative cells as a rejection gate);
- pair-specificity caveat when one donor→recipient pair is the only test case;
- minimum n_positions for Confirmed vs Inconclusive (3 events at 100% is a wide Wilson CI).
