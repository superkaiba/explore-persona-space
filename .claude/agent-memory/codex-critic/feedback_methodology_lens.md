# Composition mechanics

1. **Minimal Jinja2 / shell-special characters in the prompt.** Render template/Python code as behavior-preserving prose (preserve ordering guarantees, guard conditions, no-op paths, tie-breaks) and point Codex at the repo files for literal verification. Prefer the Write tool over a bash heredoc for the prompt file. For plans >100KB, assemble by concatenation: Write a header (lens spec + context) and footer (output format), then `cat header plan footer > prompt` — inlines the plan without loading it into the dispatcher's context. (#344, #534, #537)
2. **Explicit "do NOT evaluate statistics" boundary** keeps the output on-lens; decision-rule thresholds belong to the statistics lens — methodology checks only that the design produces valid inputs. Put numeric thresholds (including smoke gates AS NUMBERS) in the statistics-boundary block. (#344, #591, #608)
3. **Settled-items list for amendment rounds:** enumerate settled/approved design choices and forbid re-opening absent a NEW named fatal flaw ("re-litigating settled items is itself a review failure"); scope per-item checks ("X is settled — check only that the new additions did not break it"). Codex otherwise litigates prior-round choices. (#537 v4 onward; see delta-scoped memory)
4. **Pass the fact-checker's CONFIRMED/WRONG tally into the header** with "treat verified facts as ground truth; scrutinize DESIGN COVERAGE". (#596, #605 onward)

# Recurring kind:experiment sub-questions

- **Train/eval context mismatch** — the arm trains with a context (gold CoT prefix) the eval may not supply; the top flaw class for input-side conditioning designs. (#344)
- **Gradient flow vs label masking** — "labels masked" ≠ "gradients blocked through the prefix"; asking the distinction yields the "backprop still flows through rationale hidden states" finding. (#344)
- **Audit-not-control** — a mitigation that MEASURES the mismatch after the fact (judge similarity audit) does not make the intervention clean; ask whether post-hoc audits substitute for design controls on round-2 prompts. (#344 r2)
- **Loose mediation judge rubrics** — "persona-voiced" is insufficiently granular; ask for separate rubric fields (voice, answer support, coherence, source cues). (#344 r2)
- **Single-source fallback/conditional gates** can't diagnose under-training at the experiment level — does the fallback scope cover the full hypothesis or a proxy? (#344)
- **Round-3 fix-introduced regressions** — include seed-coverage and denominator-family questions whenever a statistical audit step was added (TOST paired on one seed only; gate joint-failure scope). (#344 r3)
- **Gate joint-vs-single-channel structure** — requiring BOTH channels below a bound is too narrow; handle joint, source-only, and bystander-only failure cases. (#344 r3)
- **Data-adaptive pair selection bias** — TOP-1 extreme-geometry selection is winner's curse at the methodology level; is the null procedure selection-aware? (#311 r3)
- **Scope-reduction load-bearing controls** — budget-driven simplifications may quietly remove the condition that isolates the mechanism ("was the dropped control necessary to rule out generic joint-SFT destabilization?"). (#311 r3)
- **Fallback-test unit of analysis** on clustered data (question-level vs persona-level pooling; cluster dependence at aggregation). (#311 r3)
- **Construct drift from regenerating canonical prompts** — LLM-regenerated persona sets risk measuring the paraphrase style; run the originals as a sensitivity arm. (#368)
- **Neutral-reference extraction parity** — is the projection-difference reference computed by the SAME test-prompt procedure as the target activations? (#368)
- **Degenerate-strata fallback** for stratified/partial-correlation gates (constant-outcome strata → undefined rho; specify the fallback). (#368)
- **Permutation null preserving the joint representation** — shuffling the outcome tests outcome-association, NOT whether recipe axes agree with each other (all transforms of the same hidden state still agree). (#368)
- **Rule-violation-as-variable carve-out (19i):** when a project rule's clause is deliberately violated BY DESIGN (the violation IS the manipulated variable, e.g. #614 swapping the default assistant out of the negative panel), say so in the item's apply-note with "do not bounce the plan for doing the thing it exists to do"; frame the residue instead (enough contrastive structure retained? disjointness asserts still hold?). Companions on #614: donor-row provenance (a second smuggled variable) and floor-resolution on a near-zero reference cell ("stays flat" vs "cannot go lower"). Generalizes to any ablation whose treatment arm is a named anti-pattern.
