# Core composition rules

1. **Feed the actual numbers; compute gate-driving arithmetic yourself at compose time.** Grep the aggregate/eval/parent JSONs and put values in the prompt: floors vs gate thresholds (0.054 vs 0.05), parent margins (statistic − null p95), CI widths recentered at band edges, null tail probabilities, range-statistic expectations. Codex's sharpest findings come from values it can compare — feed contradictions as arithmetic, not prose. (#344, #551, #557, #559, #570, #585, #603)
2. **Name the test-against-threshold gap explicitly** — "tests p vs null=0, but thresholds are f≥0.50 / f<0.20" produces "nonzero ≠ f≥0.50" and "f<0.20 has no uncertainty rule". (#344)
3. **Labeled sub-question sets** (S1..Sn) drive blocking verdicts. When the brief enumerates its own delta questions, map them 1:1 and sharpen technically — never invent a parallel list; always keep one cross-boundary item for silently-moved registered headlines. (#344, #537)
4. **Pre-verify in the producing JSONs at compose time, then TELL Codex what's settled** (fields exist, slugs match, grep criteria run against pre-state, anchors verified) so it spends effort on adjudication, not transcription. (#580, #604, #608, #612)
5. Heavy bootstrap computation: Codex times out once, retries with numpy; ~5 min total, no intervention. (#344)
6. Artifacts on an issue branch → tell Codex `git show <branch>:<path>` up front. (#568, #613)
7. Loose test names ("Wilcoxon-equivalent") are under-specified (bool vs float scores, null unstated, equivalence vs significance) — ask for the exact test. (#344)

# Standing carve-outs (reuse every round; they keep Codex on-lens)

- **Inherited / scope-mandated DV is settled** — teacher-forced/proxy reads inherited by single-variable contract, documented exception, or that ARE the calibrated object: construct-validity scoped to NEW measurement choices only; never bounce the inherited read. (#551, #553, #555, #557, #561, #593, #597, #601–#603, #608, #611)
- **Fact-checked citations/anchors settled** → redirect numeric effort to statistical COHERENCE + gate-driving values only. (every round since #545)
- **"No gates — §X is outcome classification"** → scrutinize coherence/decidability of the registered wording; never demand gate addition/removal; restate kill criteria as interpretive demotion rules when the plan frames them so. (#553, #557, #560 onward)
- **kind: infra / analysis exemption stated up front** — declare construct-validity / uninterpretable-N / seed items N/A with one-line reasons; seed counts on analysis plans are scope facts. (#584, #587, #588, #596, #602, #604)
- **CONTENT QUARANTINE for EM-adjacent corpora** — numeric-only jq; no corpus .jsonl / raw_completions / parent-EM body reads. Right after THE BAR, before the carve-outs. (#570, #593, #603, #604)
- Same-issue follow-up rounds: suffix tmp paths with the followup label (delta-scoped memory).

# Recurring cross-design patterns (cite by name inside any family)

- **C5 directionality** — test direction must match the decision rule's: two-sided tests vs one-tailed rules; two-sided critical values as kill thresholds for directional alternatives (biases toward PASS); direction-agnostic pass criteria vs directional hypotheses. (#344r3, #551, #555, #570, #610)
- **Verdict-lattice walk** — enumerate the full outcome lattice (statistic-bin × CI-status × sign-count; per-persona status pairs) for exhaustiveness + mutual exclusivity under LITERAL wording; between-bands / mixed cells are the most-likely-realized region; each reachable value must map to exactly ONE verdict. Watch narrow parenthetical glosses, graded-support-but-binary-kill asymmetry, verdicts consuming DIFFERENT statistics. (#534, #556, #559–#561, #568, #570, #597, #601, #603, #608, #611)
- **Burden-of-proof direction** — "CI not entirely above +X" is failure-to-show-inferiority, NOT demonstrated non-inferiority (entirely below / TOST-contained); recenter the parent's own CI width at the band edge to exhibit a passing interval consistent with a large gap. Kill-side twin: "paired CI not entirely > 0 → KILL" maps failure-to-show-superiority onto a strong falsification narrative. Overlapping CIs at low rates → "null reproduced" rests on failure-to-reject (disjoint Wilson CIs at n=600/arm need ~2.3× ratios at 7-vs-3% and OVERLAP at 4-vs-2% despite a true 2× effect); ask for an indeterminate band, not seeds. (#559, #559v3, #570, #608)
- **Drift-tolerance vs decision-margin stacking** — instrument/reproduction/gauge tolerances the size of the verdict's edge margins let a verdict flip within tolerated drift; compute both. (#551, #561, #608, #613)
- **Band-lattice gaps** — manipulation-check/classification band sets leave reachable cells unmapped (ΔG=24 between PARTIAL [5,20) and the +30 reference); pin gap signs. (#561, #570, #612)
- **Cluster-axis pinning** — find the binding resampling unit when replicates share structure: seeds within a cell share mix + predictor values; runs=cell×seed with predictors constant per persona; cross-classified row×column dependence ("wider of two one-way CIs" understates CGM V = Vr + Vc − Vrc); stratum contrasts collapsing to ~3 clusters. (#537, #545, #553, #559, #560)
- **Small-n percentile-bootstrap degeneracy** — at n=3 the 95% CI is exactly [min, max] ((1/3)³ ≈ 3.7% > 2.5% per extreme): "CI excludes zero" ⟺ "all seeds positive", a CI-overlap kill is a SINGLE-SEED VETO; compute P(any seed ≤ 0) from parent mean/sd (~31% in #464). At n=5, (1/5)⁵ = 0.032% — NOT degenerate; only ask about discreteness at borderline cells. (#464, #570, #611)
- **Constant/zero-variance predictors** — grep the parent Pearson matrix for NaN columns; a constant predictor is undefined under rank residualization and shifts Holm thresholds; same for zero-variance covariates at a single read point. (#534, #555)
- **Degenerate small-group Spearman** — check strata for near-zero outcome variance before mean-over-groups(spearmanr); NaN handling pre-specified. Power at small-n rho bars (~18% at n=10, ρ=0.30) makes the bar descriptive, not a test. (#368, #602)
- **Range-statistic null** — K iid reads: E[range] ≈ 2.534σ (K=6; ≈3.08σ at K=10), P(range > 3σ) ≈ 0.25–0.30; check the reference band's OWN observed range vs the flatness threshold; pin the sample-vs-population SD convention when 3×SD straddles it. (#585, #491)
- **Attenuation-reachability arithmetic** — compute reliability from the plan's OWN noise basis (per-question sd → SE; true variance at the minimum admissible spread; FEs from fewer runs; SE_ρ at panel n): is the confirm bar attainable AT ALL under perfect transfer? A design defaulting to indeterminate can't deliver "both outcomes decisive". (#491, #560, #612)
- **Multiplicity on ALL-quantified criteria** — "within band on EVERY column/source" makes false-FAIL-by-chance likely at ~10 columns; Holm-adjusted p's decoupled from CI-consuming verdicts need a what-ships-on-disagreement rule. (#545, #560, #612)
- **Per-seed binomial power + never-binding Wilson clause** — P(X≥5 | Bin(200,.025)) ≈ 0.56 (coin-flip per-seed kill); Wilson lower bound at 30/600 ≈ 3.5% > 2% → the CI clause may never bind; pin "excludes" to lower-bound-above. (#557, #570)
- **Exact-equality asserts are brittle** — a refactor / added ranker shifts a shared bootstrap RNG stream; pin "exactly" to deterministic point estimates, CIs at tolerance or per-ranker re-seeding; a false test FAIL can trigger a pre-authorized fallback that unfreezes a frozen gate. (#556, #559)
- **Errors-in-variables** — a same-cell-measured noisy regressor in a JOINT regression biases BOTH partials ("DV noise leaves OLS unbiased" is DV-noise-only); noisy-covariate attenuation also biases TOWARD a predicted no-change null. (#537, #612)
- **Winner's-curse selection** — best-of-group inside vs outside CV; argmin checkpoint-matching over many noisy reads; leaderboard demotion via overlapping MARGINAL CIs on PAIRED values (ask for paired-difference bootstrap). (#491, #545, #553)
- **Outcome-dependent exclusion** — saturated/implant-failed/norm-floor exclusions shaping leaderboards or denominators; worst when the exclusion variable IS a DV under test. (#545, #593, #603, #604)
- **Composition shift in pooled gates** — a gate on the MEAN of per-cell values admits zero cells inside a passing aggregate; "all usable fractions show X" satisfiable by the final fraction alone. (#534)
