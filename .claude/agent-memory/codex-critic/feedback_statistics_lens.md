For plans using fraction-of-effect framing with paired-bootstrap inference (issue #344 round 2), the statistics lens needs these explicit nudges to fire well:

1. **Always include the actual numeric values from aggregate.json** — Codex will grep for them and produce sharper findings. State no_cot source floor, persona_cot matched-eval headlines, and empty scaffold baselines explicitly in the prompt. Codex caught the 0.054 no_cot source floor vs 0.05 gate threshold gap only because it had the value to compare.

2. **Call out the denominator resampling question explicitly** — "is persona_cot_FRESH resampled independently or from the same batch as labels_on_answer?" is the key ratio-bootstrap issue Codex will focus on. Name it as a sub-question to surface it early.

3. **Name the test-against-threshold gap** — saying "the plan tests p vs null=0, but the thresholds are f>=0.50 and f<0.20" produces Codex's best finding: "nonzero effect does not establish f>=0.50" and "f<0.20 has no uncertainty rule." State this tension explicitly.

4. **Include the Holm family enumerate-or-count question** — prompt item "does the family include C1 source, C1 bystander, C3 f_source, C3 f_bystander, etc. as separate hypotheses?" causes Codex to correctly flag undercounting.

5. **The heavy bootstrap computation causes Codex to kill and retry** — the long Python run (json+random+statistics+math) times out once and Codex retries with numpy. This is normal; total latency ~5 minutes. No intervention needed.

6. **"Wilcoxon-equivalent" is a known ambiguity flag** — Codex correctly identifies this as under-specified (bool vs float scores; null unstated; equivalence vs significance test). Always ask about mediation test appropriateness explicitly.

**Round 3 learning (issue #344):** After all 8 S1-S8 fixes landed, Codex downgraded to REVISE with 5 blockers. Key residual issues pattern:
- **C5 directionality blocker**: a two-sided test vs null=0.50 does not match a decision rule with opposite tails (r5>=0.50 for mechanism-c, r5<0.20 for mechanism-a). Always prompt: "the plan tests X vs threshold Y — do the test directionality and threshold direction match the decision rule?" for any ratio-decision-rule test.
- **Denominator near-zero bootstrap guard**: even after S4 landed, Codex independently found that _paired_bootstrap_ratio needs a denominator-guard for draws near 0. Always include "what happens in bootstrap draws where denominator converges to 0?" as an explicit sub-question.
- **H2 numeric threshold under-pinned**: "0.5 x #186 ratio" is not a pre-registered number if the #186 ratio value is not stated. Always prompt for exact numeric threshold pinning from the actual data files.
- **AND vs OR gate framing inconsistency**: AND falsification gate conflicts with stated "bystander-primary" framing. When a plan names one metric as primary, probe whether the gate condition matches the stated priority.
- **Per-source f-ratio bootstrap spec**: per-source heterogeneity CIs must use per-source paired bootstrap, not the collapsed macro bootstrap. Add this as a sub-question for any plan with per-source claims.

**How to apply:** Reuse the sub-question structure (9 numbered items covering bootstrap pairing, denominator resampling, null specification, threshold operationalization, Holm family, Comparison 5 precision, mediation power, and gate trigger edge cases) for any future plan with ratio-of-effects framing. Round 3 learnings add 5 more sub-question items (C5 directionality, denominator guard, H2 numeric pinning, AND/OR gate consistency, per-source bootstrap spec).

**Issue #534 round 1 learnings (per-fraction trajectory refits replicating a parent fit):**
- **Constant-predictor check pays off** — when a plan refits a regression per training-fraction and one predictor is `training_step`, grep the parent analysis JSON's Pearson matrix for NaN columns: a constant predictor (all cells stopped at the same step in #530) is undefined under rank residualization and silently shifts Holm thresholds. Feed the NaN observation to Codex explicitly.
- **Replication-tolerance vs decision-rule complementarity** — when a plan defines a replication FAIL in the hypotheses section (§3) and a PASS in the gates section (§7), ask Codex to enumerate whether the two are logical complements; mixed "on both"/"on at least one" quantifiers are a recurring incoherence site.
- **Mean-over-cells usability floors** — a per-fraction gate on the MEAN of per-cell implant strengths admits composition shift (some cells at zero implant inside a passing fraction); always ask whether per-cell distribution reporting is needed for the pooled fit to stay interpretable.
- **Usable-subset verdicts can degenerate** — "all usable fractions show X" is satisfiable by the final fraction alone when early fractions fail the floor; ask Codex where the trajectory-claim vs mere-replication line sits.

**Issue #545 round 1 sub-question set (predictor-race leakage-matrix plans — rank-correlation leaderboards over a B×B′ cell matrix):** when the headline is "weighted Kendall tau per predictor on held-out cells," the high-yield sub-questions are: (1) are the tau WEIGHTS + tie rule frozen in the pre-registration, or a researcher df that can flip the winning group; (2) best-of-group selection inside vs outside CV (winner's curse on the group margin); (3) level-track near-circularity when the base-prior predictor is a component of the level outcome (level = base + L); (4) "null row within base 95% CI on EVERY column" criteria — multiplicity makes false-FAIL-by-chance likely at ~10 columns; (5) cluster bootstrap with very few clusters (Betley main-8 = 8 probe clusters) on exactly the gate-driving cells; (6) sensitivity-check tolerance (±3pp) equal to the entire gate discrimination window (5% vs 2%); (7) outcome-dependent cell exclusion (saturated/implant_failed) shaping the leaderboard; (8) bootstrap resampling unit under cross-classified row(adapter)×column(judge/battery) dependence; (9) raw vs strength-adjusted L as the scored outcome, frozen or not. Also: when the brief says the Phase 1.5 fact-checker already verified citations, say so in the prompt and redirect Codex's numeric effort to statistical COHERENCE + gate-driving values only — avoids wasted grep time re-litigating transcription.

**Issue #537 round 4 sub-question set (SEED-DESCOPE deltas — user-overridden 1-seed re-basing of seed-dependent estimators):** when a delta replaces cross-seed noise machinery with question-level forms, the high-yield sub-questions are: (a) honesty grep for leftover ≥2-seed narration (old estimator names, seed lists, seed-variance figures) across §0/§3/§6/§7/§9 + figure list; (b) noise-floor AGGREGATION-LEVEL scaling — if the structure read is variance of a row-mean over K train contexts, the per-cell floor over-subtracts by ~K vs the row-mean's floor; pin which aggregation the 2× threshold applies to; (c) single-seed adapter noise is a ROW-level random effect — ask whether the clustered bootstrap unit covers it and note it inflates between-TRAIN-context variance but enters across-EVAL-context reads only via interaction; (d) errors-in-variables on a same-cell-measured strength regressor in a JOINT regression biases BOTH partials — the "DV noise leaves OLS slope unbiased" claim is scoped to DV noise only; (e) split-half floor precision for rate DVs (0.05 quantization at 20-question halves) and few-cluster bootstrap rows (EM 8 clusters), resolved by noting which rows are kill-bearing. Map the brief's own enumerated delta questions 1:1 into labeled sub-questions (S1..Sn) and sharpen technically rather than inventing a parallel list; keep one cross-boundary S for silently-moved registered headlines.

**Issue #551 round 1 sub-question set (corrective re-runs reproducing a parent's numbers, then gating controls on null quantiles):** when a plan (i) re-extracts data under a ±tolerance reproduction gate and (ii) pre-registers control criteria of the form "statistic > null p95," compute the PARENT's existing margins yourself (statistic − p95 from the parent JSONs) and feed them to Codex as arithmetic, not prose. High-yield: (1) AND-over-multiple-nulls criteria where one null's parent margin (~0.03) is smaller than the reproduction tolerance (±0.05) — tolerated re-extraction drift can masquerade as a control failure; (2) two-sided critical value used as the kill threshold for a DIRECTIONAL alternative (biases toward PASS — the C5-directionality pattern again, now for correlations); (3) cross-read-type comparisons (mean-over-response vs end-slot) where each read renormalizes against its own U₁ and only one side has a parent reference; (4) Monte Carlo error of a 1,000-rep p95 vs a ~0.03 pre-registered margin; (5) whether a derived input (per-question tensors) is built in-scope vs silently assumed from the parent's LOST artifact. Also: when the plan inherits the parent's teacher-forced read by single-variable contract, tell Codex explicitly NOT to bounce the inherited read under construct-validity — scrutinize only NEW measurement choices.

**Issue #553 round 1 sub-question set (reviewed-inference re-derivation of inline/unreviewed findings — FE variance anatomy + cluster bootstraps + CV over committed panels):** when a plan ports an existing inference stack (#539-style FE-re-estimating bootstraps + FE-respecting permutation) to re-derive chat-session numbers, the high-yield sub-questions are: (1) cluster-AXIS choice when replicates share a unit — seeds within a cell share the training mix AND the predictor values (min_dist constant per cell×persona), so run=cell×seed clustering treats seed-replicates as independent; ask whether the binding axis is cell; (2) "wider of two one-way cluster CIs" as primary understates cross-classified variance (CGM V = V_r + V_c − V_rc can exceed both one-ways) — gate-driving when kill rules are CI-spans-0; (3) permutation-null DIRECTION for variance-share "dominance" tests — permuting labels WITHIN the dominant axis pushes the null share HIGH, so the observed share sits below the null; ask for the exact null + statistic + rejection direction (C5-directionality pattern, now for variance shares); (4) CV feature-set definedness — a "+source FE" feature under leave-one-SOURCE-out has no estimate for the held-out source (silent imputation vs crash vs exclusion changes the R²); (5) leaderboard demotion via overlapping MARGINAL CIs when the per-source rho values are PAIRED across rankers — biased toward retaining the incumbent; ask for paired-difference bootstrap (echoes the #545 leaderboard learnings). Also: restate the plan's §9 "kill criteria" as interpretive demotion rules in the prompt so Codex scrutinizes coherence rather than demanding gate removal/addition.

**Issue #555 round 1 sub-question set (null-calibration replicate designs — K fresh-seed replicates of a parent's fit, pre-registered sign/interval decision rule):** when a plan re-runs a parent's regression K times at a no-effect snapshot and decides via "≥m/K consistent sign OR pooled interval excludes zero," the high-yield sub-questions are: (1) OR-trigger softening — a §3 power note that calls the OR a "conjunction" or downgrades a bare sign-trigger hit to "indeterminate-leaning" contradicts the registered rule; the machine-readable verdict code needs ONE rule pinned (under the null, ≥4/5 same-sign alone is ~0.19); (2) replicate independence for the df=K−1 t-interval when the SAME probe set + fixed geometry/predictor table recurs in every replicate — frame it as (a) is seed-noise independent across replicates under the null vs (b) shared-structure effects shift the MEAN, which is the detection target, so it's a scope caveat not a CI flaw; make Codex adjudicate (a) vs (b) explicitly; (3) two-sided interval vs one-directional sign trigger (C5 pattern again); (4) enumerate the stand/falsify/indeterminate outcome space for exhaustiveness + mutual exclusivity (cells: interval-only falsification with 0 Holm hits; consistent-positive-but-3/5; ≤1 Holm AND ≥4/5 positive); (5) zero-variance covariate retained in the rank-residualized fit at a single read point (NaN/drop handling — the #534 constant-predictor learning, now at fit time); (6) descope-prorated rule error profile (3/3 positive = 0.125 under null, df=2 interval); (7) cross-classified bootstrap unit, downgraded to Concern when the verdict rests on Holm+sign+t-interval not the bootstrap CIs. Carve-out reminder worked again: explicitly telling Codex the teacher-forced read IS the object under calibration (do not bounce under construct-validity; scrutinize only NEW statistical choices) keeps the report on-lens.

**Issue #559 round 1 sub-question set (parity-band / non-inferiority leaderboard transfers — new ranker vs committed incumbent with a registered ±band):** when SUCCESS is "new-ranker CI > 0 AND paired (incumbent − new) diff CI NOT entirely above +X," the highest-yield framing is **burden-of-proof direction**: "not entirely above +X" is failure-to-show-inferiority, not demonstrated non-inferiority (CI entirely BELOW +X); feed the arithmetic concretely (recenter the parent's own paired-diff CI width at the band edge — e.g. width 0.161 at +0.10 gives [+0.02, +0.18], which passes while consistent with a gap exceeding the parent's named separation). Companion items: (1) outcome-lattice cross including the unmapped "new-ranker CI entirely < 0" cell; (2) band grounding when the threshold is scaled from the OTHER panel in the OPPOSITE role (sign-flipped comparison); (3) exact-reproduction asserts on incumbent numbers are brittle when new rankers shift a shared bootstrap RNG stream — pin "exactly" to deterministic point estimates, CIs at tolerance or per-ranker re-seeding (extends the #556 exact-equality learning to in-plan asserts); (4) cluster-axis for the PRIMARY kill CI when runs = cell×seed and the new ranker vector is IDENTICAL across runs (constant per persona) — frame as consistency-with-committed-incumbents vs correctness, and note whether incumbent CI widths make the axis plausibly kill-rule-driving; (5) median-of-differences vs difference-of-medians + degenerate-run pair desynchronization; (6) per-persona truncation concentration hiding under a global rate caveat when the DV is a per-persona mean feeding a ranking.

**Issue #559 v3-amendment round 2 sub-question set (delta-scoped follow-up amendments registering a complement-form SUCCESS/KILL pair):** when an amendment registers KILL as the EXACT complement of SUCCESS (no indeterminate class) after the parent round's parity-direction fix, the highest-yield framing is the **kill-side burden-of-proof inversion**: the round-1 lesson ("not entirely above +X" passes too easily) over-corrected into "paired CI not entirely > 0 → KILL", which maps failure-to-demonstrate-superiority onto the scope marker's much stronger falsification narrative; feed the reachable mid-zone cell as arithmetic (prior CI [+0.40,+0.55] clear of 0, paired-diff CI [−0.01,+0.20] vs expected diff +0.23 and parent CI widths 0.03–0.10) and note the internal asymmetry when the same §6 gives the PARITY read a straddle=indeterminate class but the kill read none. Companions: (1) "spans zero" literal-wording lattice walk including {prior CI entirely < 0, paired diff entirely > 0} (reachable only via the endogenous comparator); (2) **endogenous re-measured kill comparator** — the registered kill uses length-alone recomputed on the NEW question batch while the scope names the committed fixed value, so the kill threshold silently moves with the comparator's own re-measurement; (3) WHICH incumbent values feed the parity read (committed JSON at 1e-9 vs fresh-pod re-measurement inside the entry-gate tolerance — drift contaminates the band only on the latter); (4) entry-gate Spearman-swap arithmetic at n=35 (one adjacent swap → ρ=0.99972, four → 0.99888, so ≥0.999 tolerates ~3 swaps; persona-level dtype noise ≈ per-slot MAE/sqrt(Q)) plus the construct split "code-path validity vs hardware text-determinism — failure mode is a halt, not a wrong headline"; (5) exact-assert scope with a new ranker added (point estimates + ρ maps YES, bootstrap CIs only under per-ranker re-seeding). **Issue #368 round 2 learnings (Spearman-rho on small within-group subsets):**
- **Degenerate within-group Spearman is a recurring gap** — when a plan specifies mean-over-groups(spearmanr(...)), always grep the data to check if any group has zero or near-zero variance in the outcome (villain 9/10 zeros, comedian 10/10 zeros on 50-pair subset). NaN handling MUST be specified (nanmean vs all-sources mean) before the code runs.
- **Power at within-group threshold** — for plans with n=10 per group and rho threshold 0.30, flag that power is ~18% at alpha=0.05 one-sided. The threshold is a descriptive point estimate, not a significance test. This should be stated explicitly in the evaluation section.
- **BH-FDR family scope** — when a plan says "BH-FDR across K axes" but each axis has M tests, the family size is ambiguous. Prompt: "is the FDR family defined per-axis (K tests) or per (axis x statistic) (K*M tests)?" Always name the specific test that defines membership in the family.
- **Baseline verifiability from disk** — the 0.567 centered cosine baseline for #368 comes from the #142 issue body and cannot be reproduced from disk without a persona-name->centroid-row mapping. This is acceptable IF a runtime reproduction gate checks it (which #368 v2 has at Phase 2 §4.2.3). Always check that unverifiable baselines have a runtime gate, not just a plan-time claim.
