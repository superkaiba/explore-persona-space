**Rule:** when Codex flags a real-looking violation as a round-N blocker, verify the flagged state's GIT PROVENANCE before crediting the regression framing. Three shapes, one diagnostic (check what the round actually changed):

1. **Pre-existing-on-trunk (#385 r3):** the violating block is byte-unchanged from main and only adjacent to the round-N diff. `git show main:<path>` — if present in trunk, the finding is at most Real-but-non-blocking (standing rec / separate cleanup task), UNLESS round N marginally broadens the silent path onto data the system actually produces. Origin: warn-and-skip in `format_dataset` shipping since a prior refactor; round 3 only added an `elif` + isinstance gates. PASS. Cumulative-diff variant (#505 r7): Codex computed `main...HEAD` (+4991/−1, 20 files) instead of `HEAD~1..HEAD` (+27/−9, 2 files) and every FAIL finding targeted code unchanged in r7 — when Codex's diff-size line is 100x the implementer's, verify each cited line with `git show <sha>~1..<sha> -- <path>`.
2. **Scope drift on repeat findings (#382 r3):** a prior round's blocker named a flag/string ("remove `--no-upload`"); Codex lexically greps the whole diff, finds the string in a DIFFERENT file governing a DIFFERENT artifact category, and calls it a regression. `git show <rN-sha> --stat` to see what the prior fix actually touched; check whether the new location is governed by a separate policy (CLAUDE.md sanctions dry-run escape hatches in data-gen scripts; default upload=ON). PASS.
3. **Stale-branch artifacts (#471 r1):** Codex reviews a worktree BEHIND main and flags "file X deleted/reverted" when X changed on main after the branch diverged. `git log --oneline main..issue-N -- <X>` — zero non-merge commits = the branch never touched X; post-merge `git diff --quiet main -- <X>` confirms byte-parity. Classify Unverified/Discarded — the finding doesn't exist in the artifact under review. (Distinct from shape 1: there a real code issue exists but is pre-existing; here there is NO real issue at all.)
4. **Stale untracked working-tree copy of a PINNED figure/sidecar (#922 clean-result r2):** the body pins a figure to a raw.githubusercontent URL @ commit SHA; Codex reads the WORKING-TREE path (`figures/issue_<N>/...`) at the repo root, which holds an UNTRACKED pre-regen copy (`git status --porcelain` shows `?? figures/issue_<N>/`), and reports the round-1 label fix "NOT-FIXED" with grep counts from the stale sidecar. Authoritative read is the PINNED BLOB: `git show <pin-sha>:figures/issue_<N>/<file>` for the sidecar categories + `git hash-object <worktree png>` vs `git rev-parse <pin>:<path>` to know whether a Read of the local PNG reflects the pin. #922: pinned meta.json carried all reader-facing labels, 0 banned-token hits; the repo-root untracked copy had 18. Classify Unverified/Discarded; PASS.
