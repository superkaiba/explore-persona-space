**Rule:** A predictor-vs-null-battery plan that selects the MATCHED direction's
read-out layer by max-over-L-layers predictivity but computes each NULL direction's
headline band at the *matched-winning* layer (not under each null's own max-over-L
selection) has an asymmetric layer-selection confound. This manufactures a
matched-vs-null gap from winner's curse rather than trait signal. It is a
**Real-blocking ALTERNATIVES finding** — the alternative "the gap is selection
artifact, not specificity" is a false-positive-producing explanation the nulls as
specified cannot rule out from committed diagnostics. The correct fix (Codex's):
subject every null draw to the SAME max-over-L-layer selection rule; fixed-layer
results secondary. A per-layer heatmap does NOT neutralize it — the heatmap is a
diagnostic display, the comparison statistic (matched max-over-L vs null-at-one-layer)
stays asymmetric.

**Why NOT out-of-lens-scope (contrast the #546 cross-lens pattern):** the #546
"cross-lens defect re-filed per lens → out-of-scope for the disputed lens" rule
applies when the defect produces NO result (analyzer refuses to compute). Here the
defect produces a spurious POSITIVE result — the paradigmatic alternative
explanation — so it is genuinely the Alternatives lens's own question. Alternatives
inherits REVISE on its OWN rubric, not by contagion, even though Methodology +
Statistics already settled REVISE on the same item.

**How to apply:** (1) Grep the plan for the layer-selection rule on the matched
direction (`select ... layer by max ... predictivity`) vs the null evaluation
(`recompute ... at the selected layer`). (2) If matched is max-over-L and nulls are
at-matched-layer, the winner's-curse alternative is real and blocking on Alternatives.
(3) Claude systematically UNDER-flags this — it argues the perm/randnorm nulls bracket
specificity, missing that those nulls inherit the SAME asymmetric layer treatment.
Verify the null's headline statistic gets the same selection opportunity before
crediting a Claude APPROVE.
