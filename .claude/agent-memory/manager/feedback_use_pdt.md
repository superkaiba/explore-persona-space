Report all times in PDT (Pacific Daylight Time, UTC-7), not UTC.

**Why:** User is in Pacific timezone; UTC requires mental conversion and is annoying.

**How to apply:** When mentioning any time (ETAs, wakeup schedules, experiment start/end times), convert from UTC by subtracting 7 hours. Label as "PDT" not "PST" during daylight saving time (March–November).
