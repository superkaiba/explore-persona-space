Library-level testing via the fake_repo fixture (which monkeypatches repo_root) is the practical pattern.

- [Codex twin worktree sandbox](reference_codex_worktree_sandbox.md) — Codex twins run cwd-rooted in the issue-N worktree; cannot resolve `tasks/<current-status>/<N>/events.jsonl` (lives only on main). Composer must fetch events.jsonl markers via `task.py latest-marker` (branch-guard auto-routes) and INLINE bodies into the Codex prompt; plan paths are worktree-safe.
