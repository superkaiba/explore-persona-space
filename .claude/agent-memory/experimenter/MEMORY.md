- [PEFT auto-README local path → HF 400](feedback_peft_readme_local_path.md) — When base model is mirrored locally (`/workspace/<work>/<model_dir>`), PEFT writes that path into adapter README; HF rejects it. - [Letter-audit gate inherits Sonnet bias](feedback_letter_audit_inherits_upstream_bias.md) — Audit gates that count `\b[A-D]\b` standalone in CoT rationale fail structurally on Sonnet-generated data (A is +193% over mean even with uniform Answer-letter distribution). - [Audit gate drift across arms](feedback_audit_gate_arm_drift.md) — Cross-prompt BPE mean drift is ~15%, not <10%. ±10% audit gate too tight when arms differ in prompt framing (even verbatim-shared generator). Default to ±20%. Keep smoke-gate and audit-gate formulas in sync.
- [per_q caches blow disk budget](feedback_per_q_disk_budget.md) — Multi-method extraction sweeps writing flat per_q tensors per persona can exceed 200 GB volume. r_per_token at (n_q, n_layers, n_pos, D) fp16 = 417 MB/persona × 275 = 115 GB alone. Compute total before launching; bounce back to implementer if >70% of free disk.
