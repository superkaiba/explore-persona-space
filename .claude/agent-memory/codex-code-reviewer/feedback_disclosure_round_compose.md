When a reconciler reproduces the twin's replays but rules the mechanisms
plan-faithful (byte-verbatim plan content), persists the substance as
DOCUMENTATION-scoped concerns, and the next round closes them via docstring
catalog entries + characterization tests pinning CURRENT behavior (#2299 r2,
2026-08-22), compose with:

1. **Grade disclosure on QUALITY, not presence** — per-entry bars as duties:
   reader-recognizability of EACH reproducing shape (could a reader holding
   such a plan match it to the entry?), verbatim reproducing sentence, remedy
   + plan-owned future-fix note, cross-reference to the concern id. A quality
   gap that leaves the closure unusable = NOT-ADDRESSED = substantive FAIL;
   a wording weakness in a recognizable entry = CONCERN row + corrected
   sentence (state the severity split explicitly).
2. **Forbidden-changes verification is the round's hardest gate:** hunk-walk
   duty (every changed impl line must be comment/docstring), regex-identity
   byte-compare vs the round parent's blob (composer pre-verifies via md5,
   Codex confirms-or-refutes), +N/−0 `def test_` count, registered-fixture
   (T21-class) byte-unchanged. A logic change invalidates the prior
   calibration → Critical.
3. **Characterization-test marking duty (D5):** each pin must be
   unmistakably marked as undesirable-but-current (name/comment/concern-id);
   the hunt is the future reader who "fixes" the checker the wrong way.
   Also: an inaccurate REPLACEMENT doc claim (the fix to a doc-overclaim NIT
   that itself misdescribes a pattern) is WORSE than the original — Major,
   not NIT.
4. **Attested-scan handling:** a full-corpus re-scan the twin cannot re-run
   composes as attested + verify-the-premise-statically (zero executable
   change ⇒ profile invariance forced) + sanctioned cheap fixture replays as
   corroboration — never "re-run the scan".
5. **The twin's own prior verdict rows split three ways:** persisted concerns
   → full closure duties; unledgered NITs → pseudo-id closure items
   (NOT-ADDRESSED → re-raise at original severity, not FAIL); reconciler-
   DISCARDED rows → no-relitigate fence (reopen needs NEW round evidence).
   Inline the reconciler body as the acceptance contract (its standing recs
   ARE the round's item list) with tags stripped; inline the prior twin
   verdict with tags stripped + `CONCERN::` rows blockquoted (`> CONCERN:: `)
   — asserts: own v<n> head ==1, close ==1, prior tags ==0, line-start
   rows ==1, blockquoted ==5.
6. **Line-frame shift note:** docstring insertions shift the prior verdict's
   cited line numbers (+5..+28 here) — say "re-anchor by symbol; never a
   finding" or the twin flags phantom moves.
7. **Brief-ordered main-divergence check** (a file the branch touched in a
   PRIOR round diverging on main): pin main's SHA, give both diff commands
   (MB..main-pin and MB..HEAD), state the composer token-probe result
   neutrally, and hand over SEMANTIC-interaction judgment (a check need not
   name the dict to interact) — Major on contradiction, routed as a
   merge-time hazard, not a round defect.
