When a tensor plan descopes to ONE training seed per cell (user-overridden floor), training-draw noise is not removable. Review checklist (#537 v6, 2026-06-10):

1. **The honest re-base pattern (worked exemplar, APPROVED).** All of: (a) every cross-seed estimator explicitly replaced (kill-criterion noise floor → question bootstrap + split-half `E[(G_A−G_B)²]/4`; anti-fraction → question-split cross-covariance; disattenuation → question-split reliability with under-correction direction NAMED; CIs → question/response bootstrap); (b) PASS semantics re-narrated everywhere ("structure exceeds MEASUREMENT noise, NOT training noise excluded") — §3, gates, success/kill, TL;DR, risks, scope caveats all consistent; (c) verbatim clean-result caveat contract + `single_seed: true` metadata flag; (d) seed axis removed from the descope ladder, MUST-ASK in both directions. Partial re-bases (kill fixed but figures/CIs still narrate seed variance) are the failure mode.
2. **Robust vs fragile reads.** Eval-context COLUMN main effects average over K independent adapters per row → ~K-draw robust (strongest free rebuttal: row/column/interaction decomposition — high cross-adapter correlation of row-mean-removed profiles means idiosyncratic draws can't carry the structure). Per-cell values, pairwise antisymmetry A[i,j] (mixes two draws; a strength draw δ_i gives s_i−s_j-form antisymmetry), and 1v1 inoculation contrasts are 1–2-draw FRAGILE — narrate at cross-row-consistency level; report residual-after-strength anti-fraction, never raw.
3. **Shared-draw covariate inflation.** Diagonal implant strength s_i is measured on the SAME adapter (and usually question pool) as row i's G cells, so "+strength" regressors carry shared-noise credit leave-contexts-out CV does NOT remove. Prescribe split-half cross-fit (s from question half A, G from half B — free if per-question data ship); the shared training-draw part stays under the named caveat. Report s_i reliability (errors-in-variables can leak partial-R² to a correlated theory regressor).
4. **Fixed-pool floors OVER-correct between-context variance tests (conservative kill).** With one frozen question pool scoring every context, the question MAIN effect is common-mode (zero between-context variance), but split-half/bootstrap floors include main + interaction + residual — subtracting them biases toward "noise-limited" (false kill, not false pass). Re-read a marginal H-structure FAIL with per-question centering across contexts before declaring noise-limited; a PASS is trustworthy. Direction flips if the pool is resampled per context.
5. Useful identity: `Var_noise(mean_N) = E_splits[(G_A−G_B)²]/4` is EXACT under balanced complementary halves of a fixed pool — no correction factor.

**How to apply:** check the plan names the caveat, then route items 2–4 as analyzer concerns with the decomposition/cross-fit prescriptions; the one decisive cheap control (a 1-cell second-seed probe) may be BARRED by a user directive — then it's the named follow-up ask, not an in-plan Must-Fix. REVISE only if per-question data do NOT ship. Related: [[antisym-fraction-noise-floor]] (≥2-seed form), [[rank1-mechanism-test-confounds]].
