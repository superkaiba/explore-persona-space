Reusable reads for amendments responding to "committed parent levels don't reproduce under the current rig" / an unsatisfiable reproduction HALT gate (#601 plan v3, 2026-06-11):

1. **Re-pinning references in-task converts a fatal attribution fork into a reported observation.** Parent adapters read ~7 nats low post gauge-fix; staging damage vs rig-true compression was undecidable pre-run. Because the amendment pinned references to FRESH in-rig terminals and pre-registered BOTH branches (fresh-lands-high ⇒ staging implicated, escalate; fresh-lands-low ⇒ degenerate-top guard fires, upper-branch tests declared unresolvable-as-registered), the headline never consumes the contested parent value. Verify both branches are pre-registered and nothing upstream of classification needs the attribution resolved — then Concern, not REVISE.
2. **Gate splits are the right rescue, and "thresholds grounded on the same data they gate" is NOT disqualifying circularity** when the re-scoped role is an eval-path-integrity TRIPWIRE for future re-entries: calibrate just outside the known-good signature (e.g. 1.7× observed worst-case AND half the smallest adjacent-level gap = a principled no-aliasing bound). Verify force-preservation against the original failure class: un-applied adapters must still fail ≥1 split criterion (identical-reads alarm, low-dose band, dose ordering). Framing trap: a future PASS on the split gate must never be narrated as "parent levels transfer" — that lives in the fitness gate. Check the grounding eval JSON is actually committed (code commits get cited as if they contained data).
3. **A co-landing test whose reference center IS one of the tested arms is not circular when that arm is the fit point under ALL hypotheses** (the middle arm auto-passes at distance 0, but every hypothesis predicts the same value there — the discriminating content lives in the other arms; ask the analyzer to report it that way).
4. **When a fitness gate fails and a budgeted fallback fires, trace the fallback unit's EVAL SURFACE + deliverable globs** — a dense-phase cell promoted to comparison-arm duty usually lacks the full on-policy panel, and "+N files if fallback fires" glob notes go stale. Bookkeeping concerns, not REVISEs, when the headline DV is covered.

Self-daemonizing launch contracts (`setsid --fork` + pid file): "dead ⇔ no heartbeat AND pid not alive" has a hole under SIGKILL — the heartbeat subshell survives and keeps emitting, so the conjunction never declares death; fix = heartbeat checks parent liveness per emit, or pid-not-alive authoritative alone.
