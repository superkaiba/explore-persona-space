When the manipulated variable is negative-PANEL BREADTH at fixed total rows (#571: 15 bystanders × 20 rows vs 4 × 75), three things move together and CANNOT be unbundled: (1) count of distinct contexts, (2) rows-per-context (duplication/memorization pressure), (3) per-context question coverage. The complementary design (fixed per-context rows) just swaps in a TOTAL-count bundle — no design isolates breadth per se. Identical to the #543 ratio-lever disposition: the lever IS the composite; "many distinct contexts" and "low per-context duplication" are observationally equivalent in a 2-arm fixed-total design.

**How to apply (alternatives lens):** NOT a REVISE when (a) the Goal defines the manipulation at the fixed-total composite level, (b) the plan names the bundle honestly, (c) per-context training diagnostics (per-bystander suppression-loss curves) are reported so the analyzer can weigh the memorization story. Headline phrased at panel-composition level ("the broad 15×20 configuration causes X"), never "breadth per se". Also check: (i) a single narrow-subset draw leaves context-IDENTITY vs cardinality unseparated — scope to "this subset"; (ii) when the narrow arm exercises a NEW builder code path while the broad arm runs the battle-tested default, any code-path bug maps 1:1 onto the arm contrast — verify hard asserts (marker absent, row counts, loss mask) + the smoke canary runs the NEW path; (iii) cross-arm slot-composition drift (emission/truncation rates differing by arm → slot-kind mix differs) is a free emission-slots-excluded sensitivity downstream if slot kinds persist per cell (#560 precedent).
