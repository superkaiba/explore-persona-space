When a plan's single manipulated variable is the positive:negative RATIO at
fixed total rows, with install strength matched at the output (band-stop),
three entanglements are inherent and CANNOT be removed by any added control:
(1) lower-ratio arms train more steps; (2) lower-ratio arms see more negative
rows; (3) lower-ratio arms have fewer DISTINCT positive questions (diversity
co-varies with count, when sampled without replacement).

**Why:** you cannot match output strength AND step count AND composition
simultaneously — the lever IS the composite. Demanding a steps-matched control
is incoherent (it would overshoot the matched band).

**How to apply (alternatives lens):** these are NOT REVISE grounds when the
Goal is operational ("does this lever produce a surviving install"), only when
the headline claims mechanistic attribution (rarity per se). Dispose as
analyzer concerns: (a) headline phrased at the composition level, steps
entanglement named; (b) check bias DIRECTION — probe-row memorization (low
arms see probe rows ~10× more) and within-band landing position (fast-approach
arms land deeper in the band) both typically bias AGAINST the low-ratio arm,
so a positive result survives a fortiori while a null needs the caveat;
(c) under marker-only loss, negatives carry gradient on ONE token (EOS at
slot), so "more negatives = more normal-data training" is only a
context-distribution claim, not a gradient claim — scope any
Redwood-mechanism mapping accordingly (#543).
