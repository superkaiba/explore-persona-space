For one-slot panel-swap proximity designs (#600: NEAR negative vs d_source-matched far control, paired per target):

1. **Persona identity ⊥ proximity is impossible within a pair** — the same persona cannot sit at two distances, so slot-persona properties (R length, style, lexical overlap with target) ride along with proximity. With ~6 independent pairs averaging and training JSONLs persisted, this is operational claim-scoping (claim = "proximity in the design metric," mediator unresolved), NOT a REVISE. Mirrors the #543 ratio-lever precedent.
2. **The locality criterion can mislabel a real neighborhood effect.** If the mechanism is a suppression bubble around the trained negative, the target's cluster-mates in the held-out panel also drop → the target's percentile in the non-target paired-difference distribution is not extreme → the locality gate fails and the Partial branch labels it "global mix effect" — conservative for H1 but a wrong label. Recovery: the registered exploratory bubble-radius read (panel paired difference vs distance-to-NEAR-negative) distinguishes graded-with-distance from uniform; flag for the analyzer, don't REVISE if that read ships.
3. **Ratio-DV arm asymmetry:** check whether NEAR vs CONTROL cells systematically differ in SOURCE implant strength (denominator); recoverable iff per-cell source ΔG + an unnormalized robustness read are registered.
4. **Residual matching tolerance** (|Δd_source| up to ε): recoverable iff realized per-pair distances persist in the design manifest for a descriptive regression of paired difference on residual mismatch.

**How to apply:** any paired panel-composition swap with geometric matching — check the four recovery artifacts exist before reaching for REVISE (#600 round 1 had all four; APPROVE was correct).
