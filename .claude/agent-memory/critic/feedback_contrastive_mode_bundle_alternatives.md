From #552 follow-up `contrastive-2x2-completion` plan v4 (2026-06-11; #519/#521/#552 layer-14 shift-geometry family). For any plan adding a "contrastive arm" trained with FULL-SEQUENCE CE to test whether training MODE drives a geometry/concentration DV:

1. **Under full-sequence CE there is no contrastive push-pull mechanism.** The negatives-train-EOS mechanism only operates under marker-only/masked loss; with full-sequence CE, negative rows are just diverse SFT toward near-base text, so "training mode" is a BUNDLE: {persona system prompts on rows, +N near-base rows, ~2× steps at exposure parity}. Operational claim-scoping ("the persona-gated data construction de-concentrates"), not REVISE; a decomposition arm is a follow-up. Exposure parity on positives is the right pick of an unavoidable fork. Mirrors [[ratio-lever-inherent-entanglement]].
2. **Probe-panel disjointness is IMPOSSIBLE — don't demand it.** The contrastive-negatives rule makes the default-assistant negative mandatory and `assistant` is a probe persona. Sound disposition: (a) source ∩ negatives = ∅ stays the only HARD invariant; (b) mirror the reference arm's panel relation exactly so zone thresholds transfer; (c) pre-register a held-out-subpanel concentration read (untouched probe rows) on ALL arms INCLUDING persisted references; (d) any de-concentration call ships the subpanel companion number. Subpanel SVD statistics: full-panel zone thresholds don't transfer to the (n−k)-row subpanel — read it RELATIVE to all arms' subpanel companions with re-run nulls at the reduced row count.
3. **Eval-format familiarity is a concrete single-component mechanism for de-concentration.** Plain arms trained on BARE rows but probed under persona SYSTEM prompts can carry a uniform format component the with-prompt arms remove — and the held-out subpanel does NOT separate this (format familiarity generalizes to untouched personas). Post-subpanel residual attribution fork: {contrast, prompt-format presence, data heterogeneity/steps}.
4. **Magnitude-mediation twin fires in BOTH branches of a mode×content 2×2:** negatives dilute the implant → smaller ‖M‖_F → mechanical de-concentration; benign positives nearer base policy → benign arm's update shrinks first → "content-linked" predicted by magnitude alone. Read every zone call against per-cell ‖M‖_F (recoverable as sqrt(Σσᵢ²)); the alternative dies if the de-concentrated arm's ‖M‖_F lands within ~2× the concentrated arm's. See [[matched-corpus-geometry-control alternatives]].
5. **Negative-row gradient inertness under full-sequence CE** (negatives near-on-policy → near-zero gradient): not fatal when negatives are identical across content arms (can't explain an EM-vs-benign asymmetry) and the both-concentrated branch pre-registers the narrowed "loss type, not negatives per se" reading. Cheap upgrade: per-row-type train-loss logging. Shared-negative rows also inflate cross-arm U₁ identity between contrastive arms beyond the plain pair's shared-question component — name the asymmetry before benchmarking.

**Why APPROVE:** all weighable in v4 because per-question tensors + singular values + ‖M‖_F + trajectory variants + train-loss curves + per-context EM rates persisted and the subpanel read was pre-registered. The same alternatives escalate toward Must-Fix when those diagnostics are not stored or the headline claims a push-pull mechanism.
