Alternatives-lens companion to `feedback_descriptive_geometry_map_plans.md`
(#594 line — that file covers format-delivery confound, dominant-family
aggregates, residualization direction). This one: the **lexical/surface-overlap
alternative** ("family structure" = string similarity echoed in activations,
since rephrasings are one instruction × registers, house personas one
"You are a {occupation}." template, ICL instances share one demo-question set).
It is NOT fatal when three things hold:

1. **Battery text committed to git** → a TF-IDF / sentence-embedding
   family-purity baseline is a free post-hoc analysis (free-analysis follow-up
   loop), so the analyzer can quantify how much family structure text
   similarity alone recovers.
2. **Full per-layer depth curve measured** → pure lexical echo predicts
   EARLY-layer-peaking structure (token/embedding-adjacent layers); a mid-late
   peak argues against pure string similarity. The depth profile is itself the
   surface-vs-abstract diagnostic — H2 partially adjudicates the H1
   alternative for free.
3. **At least one family spans two disjoint surface templates** (house vs
   PersonaHub personas under one label in #594) → cross-template within-family
   coherence is the single best free check on boilerplate-driven clustering.

Also weighable, never REVISE on its own: last-token "what comes next"
alternative (read slot encodes first-response-token prep — e.g. format wraps
forcing "{"). Diagnostic = whether a family's separation concentrates at the
final 1-2 layers; also moot when the Goal is to map the exact space the
predictor line reads (the read position IS the construct).

**How to apply:** when these diagnostics exist in the plan, verdict APPROVE
with a concerns list prescribing claim scope ("organize by
family-as-constructed", not "model abstracts context kind") + the free
baselines; REVISE only if battery text is NOT persisted or only a single
pre-picked layer is read (then the surface alternative is unweighable).
