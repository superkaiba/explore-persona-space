Pattern (from #810 `ultrachat-genre-summary-sweep` amendment review, APPROVEd round 1):

- **Δ-band grounding:** a cross-arm transfer band (Δskill CI upper ≤ 0.10) anchored to the
  parent's own largest within-arm effect (maxp−mean +0.083, CI [+0.015, +0.130], same n=50,
  same contexts, same estimator) is same-subset-calibrated and a sound REGISTERED judgment
  call — do not demand a literature pin. Verify the trichotomy is complete: confirm
  (CI_upper ≤ band) / falsify (CI_lower > band) / between → graded. With CI width
  ~0.12–0.16 at n=50 the "between" zone is wide (~true Δ 0.02–0.24); fine iff graded
  reporting is registered — flag as analyzer Concern, not REVISE.
- **Ordering criteria as point thresholds:** "A beats B by ≥ 0.02 at ≥1 of 8 window layers"
  passes on noise when per-layer Δ SE ≈ 0.03–0.04 (correlated layers help only partly).
  Not a REVISE when the paired per-context bootstrap CI machinery is registered and its
  per-draw outputs persist — the analyzer reads the ranking off the CI. Concern only.
- **Conjunction null with an unpowered leg:** when conjunction = max-over-cells of
  min-over-methods and one method's own max-selected band is ~0.995 (no resolution at
  n=50), the conjunction band is dominated by the powered leg (~0.56–0.60 fixed-rB).
  Confirm-the-null is weak evidence (only huge effects could falsify) but interpretable;
  inheriting it for single-variable parity with the parent is correct. Report per-combo
  bands; Concern, not REVISE.

**Why:** all three came up in one review; each is tempting to REVISE but each is
analyzer-weighable given persisted diagnostics (per-draw matrices, bootstrap CIs).

**How to apply:** any same-issue cross-arm amendment (genre/domain/panel swap) reusing a
parent's fit + null machinery with paired contexts.
