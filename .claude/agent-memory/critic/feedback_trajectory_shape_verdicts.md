When a plan's discriminator is the SHAPE of a paired-d trajectory over a training-amount grid (zero-crossing = artifact vs stable-negative = mechanism; U vs monotone — #547 over #533's E=1 sign reversal), the recurring failure modes:

1. **Base-prior encoding offset masquerading as "stable mechanism."** A cross-arm paired d (system − role) is offset by any BASE-model prior difference between the two encodings at the slot; a constant negative d at all points can be a tokenization/prior fact. The near-zero-training grid points (implant-INACTIVE, greyed in figures but still measured) double as the base-reference control: if d there ≈ d at active points, the "stable read" is an offset. Verdict logic that never consults inactive points will overclaim.
2. **The discriminating early points usually sit in the gated/floored region.** Early grid points are exactly where (a) an implant-active gate (emission-cliff criterion that LAGS the log-prob ramp) may exclude them, and (b) the wrong-slot DV sits in the deep-floor regime where ~1-nat differences are noise. If the gate excises the hypothesized transient onset, "negative at all active points" cannot distinguish swing-in-flight from always-negative; also check whether the gate aggregates across ARMS (install-speed asymmetry makes an arm-mixed gate produce d's over install-asymmetric pairs). A criterion leg at a parent-demonstrated floor-saturated point is pre-determined — both hypotheses predict it; the real evidence is the early legs.
3. **Wide-CI asymmetry favors the null-shaped hypothesis.** "CI at earliest active point NOT strictly below zero" passes for free when the CI is wide; "≥1 of 4 cells" multiplies the chance. Distinguish "resolved near zero" from "underpowered" via CI width + seed sign-agreement.
4. **APPROVE-compatible iff storage is unconditional.** If {mean, ci, sign_agreement, implant_active} is written at ALL grid points (gate = interpretive flag; figures grey out inactive points rather than drop), floor-compression is analyzer-weighable — concern, not Must-Fix. If gated points are NOT computed/stored, that IS conclusion-changing (the discriminating data is unrecoverable).
5. **Conditional unsatisfiability of shape wording.** "CI at earliest active point NOT below zero AND CI at s=mid below zero" self-contradicts when the earliest active point IS s=mid — world-state-conditional, fine when a descriptive Mixed catchall exists and the criteria aren't pass/fail gates. Also: band-match conditions (|d(s) − d_ref| ≤ 0.5 at points bracketing the parent reference) assume local flatness; if the parent's own data drifts toward zero past the reference, a band-only failure is mechanism-consistent-with-drift, not uninformative.

**How to apply:** for any max_steps/epoch/dose trajectory plan, build the per-grid-point table — expected DV regime (floor/band/saturated), gate status, which hypothesis's distinctive prediction lives there. If a hypothesis's distinctive points are all in the degraded regime, say so as an analyzer concern and check the catchall.
