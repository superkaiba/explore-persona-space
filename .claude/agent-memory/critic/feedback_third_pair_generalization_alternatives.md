For #568-style designs (re-run one dial cell on a new source pair; success = envelope + position band between anchors):

1. **A shared negative panel is a controlled constant for the "not pair-idiosyncratic" claim — but an attribution fork:** if the new pair clusters tightly with the pair sharing its exact panel, "panel-driven geometry" and "pair-irrelevant geometry" both predict success. Distinguishable only descriptively (per-pair cluster figure); a panel-variation arm is the follow-up, not a missing baseline.
2. **Landing-determinism (GD1 driven by realized nat landing, not pair) is part of H1, not an alternative to it** — "recipe-and-dial property" includes landing-determined geometry. The regression-residual read (GD1 ~ realized landing on the anchors, new-cell residuals in σ units) is the right diagnostic; at 3 cells and σ≈0.015 it has ~1.3σ resolution against the known 0.02 pair offset, so gray-zone handling matters more than the point verdict.
3. **The envelope is weak as success but meaningful as kill** (eff rank ≥1.5 = genuinely two-directional implant; nothing observed comes near it) — missing the envelope is informative, passing it is not; the narrow position band + residual read carry the diagnostic weight.
