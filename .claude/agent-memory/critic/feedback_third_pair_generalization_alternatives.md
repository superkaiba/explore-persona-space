For #568-style designs (re-run one dial cell on a new source pair, success = envelope + position band between anchors):

1. **Shared negative panel is a controlled constant, not a confound, for the "not pair-idiosyncratic" claim** — but it IS an attribution fork: if the new pair clusters tightly with the pair that shares its exact panel (pair-1 base panel vs pair-2's A1-replaced panel), "panel-driven geometry" and "pair-irrelevant geometry" both predict success. Distinguishable only descriptively (per-pair cluster figure); a panel-variation arm is the follow-up, not a missing baseline.
2. **Landing-determinism (GD1 driven by realized nat landing, not pair) is part of H1, not an alternative to it** — "recipe-and-dial property" includes landing-determined geometry. The regression-residual read (GD1 ~ realized landing on the 18 anchors, new-cell residuals in σ units) is the right diagnostic; at 3 cells and σ≈0.015 it has ~1.3σ resolution against the known 0.02 pair offset, so gray-zone handling matters more than the point verdict.
3. **Envelope [1.20,1.40] is weak as success but meaningful as kill** — eff rank ≥1.5 = genuinely two-directional joint implant; nothing observed comes near it, so missing the envelope is informative, passing it is not. The narrow position band + residual read carry the diagnostic weight.

**Why:** #568 v1 already pre-scoped the over-narration risks (analyzer guidance: 3-way partition, no within-pair gradient claim, realized landings). Per the #550 envelope-union memory, this is APPROVE territory when per-cell values + landings are first-class deliverables.

**How to apply:** in pair-generalization plans, check (a) which anchor pair shares the new pair's panel, (b) whether the success band would also pass under pure landing-determinism, (c) that claim scope stays "envelope membership widens to N pairs at this dial", not "gradient replicates within the new pair".
