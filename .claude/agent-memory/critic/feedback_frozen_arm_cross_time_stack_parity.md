For plans comparing fresh-trained arms against a FROZEN reused arm + frozen base rates from an earlier run (#608, 2026-06-11):

1. **Demand a generation-side parity read, not just a judge drift gate.** Deltas of NEW-arm rates (today's vLLM/transformers/GPU stack) against FROZEN rates are perfectly confounded with time × environment × hardware. Re-judging STORED completions isolates only the judge component; generation-side drift (vLLM version, chat template, tokenizer revision, A100-vs-H100) stays uncovered. #608 v1: both H1 (+0.05 gap, ±0.02 equivalence band) and H2 (bystander delta ≥ +0.05 across 23 cells vs frozen base) sat exactly at the magnitude a uniform stack shift would produce in every fresh cell — "broad uniform lift" indistinguishable from stack drift. Cheap fix (~0.5–1.5 GPU-h): one fresh-stack generation pass of the frozen BASE over the full panel (+ ideally one frozen treatment adapter) judged in the same pass, compared to frozen rates with a pre-registered parity band; on FAIL, re-base deltas on fresh base rates. FATAL-unweighable without it when thresholds ≤ plausible stack-drift magnitude (~0.03–0.05 on judged rates); Concern only if env is verifiably bit-identical or the parity read already exists.
2. **Smoke gates thresholded on the treatment arm's priors can false-halt the hypothesis's extreme outcome.** #608's gate required villain posonly Δself ≥ +0.20, grounded in CONTRASTIVE priors, while no true positive-only sycophancy run ever existed — severe under-install is H1's extreme support, and the gate would classify it as a rig bug. Concern (not REVISE) when an independent prior makes the gate-failing outcome implausible absent a bug (marker-line #18/#471: positive-only OVER-installs); prescribe "FAIL + clean debug = candidate finding, run one more cell" rather than indefinite halt. Escalate to REVISE only if the hypothesized effect plausibly lands below the gate AND the FAIL path is a hard kill.

Statistics-lens notes from the same review (all Concern-level): g(s) = own_c − own_p cancels the shared frozen base exactly (base-noise-free headline; paired claim bootstrap is the right unit when claims are shared); top-band-censored cells must override a practical-equivalence falsification verdict (ceiling-equal rates ≠ equal latent install); censored-path trajectory fallbacks can themselves left-censor (epoch-1 already ≥0.95 — only the earliest small-step checkpoint may resolve); residual judge drift passing a ±0.02 gate equals the equivalence band edge — report the drift point estimate, prefer unified re-judge on threshold-adjacent results.
