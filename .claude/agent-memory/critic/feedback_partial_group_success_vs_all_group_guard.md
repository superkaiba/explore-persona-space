Rule: whenever a plan's success criterion is phrased "headline test fires if >=1 of K groups (personas / domains / arms) passes the gate," trace that criterion through the INHERITED analysis code's guard clauses before approving. Pipelines built for the all-groups case often carry a blanket refusal short-circuit (`if any group unresolved: write skipped-stub; return`) that was added as a crash-guard, and the plan's enumerated code changes may not touch it.

**Why:** Task #546 (2026-06-10): plan §7 success = "anchor `degenerate: false` with non-null anchor for AT LEAST ONE persona → the paired bootstrap then resolves H1+/H1−/H0." But the inherited `i464_po_analyze.py` (issue-533 branch, lines ~601-640) short-circuits to `headline_status: partial_anchor_skipped` and `return`s whenever ANY persona's anchor is None — a crash-guard against splicing `None` into a filename, not a statistical necessity (each persona's headline cells are computed at that persona's OWN anchor). The modal success scenario (villain banded in #533, pirate didn't) would have satisfied the success criterion's artifact clause while the Goal-bearing bootstrap silently never ran — reproducing the parent's stuck outcome despite the band landing. The plan had even fixed a DIFFERENT defect in the same verdict function (one-sided → two-sided) but missed this one.

**How to apply:** For any plan inheriting a multi-group gated-analysis pipeline: (1) grep the analyzer for `return` / `skip` / `partial` / `refuse` guards between the gate artifact and the headline computation; (2) check whether the guard's predicate is `any(...)` / `not all(...)` while the plan's success criterion is `any(...)` — that mismatch means the most likely success path skips the essential statistic; (3) the fix is usually ~10 lines (compute per-group stats for resolved groups only, persist nulls for unresolved, define verdict semantics over available cells) and must be enumerated in the plan's new-code table, not left to the analyzer post-hoc — the per-cell raw data makes the number recoverable, but if the Goal explicitly distinguishes "the planned gated headline" from "a diagnostic recomputation," post-hoc recovery does not meet the Goal.
