## Context hygiene

- **`/compact` at ~30% remaining**, earlier if dense — but only at task/phase boundaries, never mid-task (compaction invalidates the conversation cache = one expensive full re-read). Prefer `/rewind` over `/compact` when abandoning a path; `/clear` (alias `/new`) between unrelated tasks.
- **Prompt-cache key discipline.** Model, effort level, and fast-mode are all part of the prompt-cache key: NEVER flip any of them mid-session (a flip re-reads the entire conversation uncached). Pin model + `CLAUDE_CODE_EFFORT_LEVEL` at session spawn; per-subagent model pins are fine (each subagent has its own cache).
- **2× rule.** If a multi-step prompt repeats in a session, propose a skill / hook / `CLAUDE.md` edit *before* the second pass.
- **429 token-pacing.** The org-wide input-token cap climbs at each minute boundary — pace input tokens, don't retry harder. (a) **Stagger ensemble spawns** across a few seconds. (b) **Keep subagent prompts lean** — pass the PATH to the plan/brief, never inline the body or events.jsonl dumps; and do NOT inline code BODIES to defend against subagent autocompact-thrash — that converts a subagent context problem into an ORCHESTRATOR one and produces the "session alive, heartbeating, no durable work" wedge (#2054, #2058); MICRO-SCOPE the thrashing subagent instead (`.claude/skills/issue/SKILL.md` § Autocompact-thrash respawn recipe). (c) **Never dump giant logs into tool output** — `grep -iE 'error|traceback|killed|OOM'` / `tail -50`, never `cat` a multi-MB log. On a 429: wait for the next minute boundary and retry; on a repeat 429 within ~2 min (live storm), double the wait each consecutive killed retry (~1 → 2 → 4 → 8 min, capped ~10 min, then retry anyway), waiting via a background mechanism, never a foreground sleep chain.
- **Spurious usage-policy refusals.** This project's safety-research vocabulary (backdoor / trigger / implant / misalignment, raw EM completions) — and, on workflow-guard/security tasks, shell-attack vocabulary (#1098) — sometimes trips false-positive "violates our Usage Policy" API refusals that kill agents mid-run. Recovery ladder (never park on a refusal): (a) check what durable writes the killed agent already made before re-dispatching; (b) retry ONCE with a rephrased brief that thins the trigger-dense wording; (b2) if the original SUBAGENT spawn and its one rung-(b) retry are BOTH refusal-killed, re-spawn it ONCE with a per-subagent model pin (`model: "sonnet"` on the Agent call) BEFORE escalating to (c) — refusal trips can be model-pathway-specific (#1092), and per-subagent pins are prompt-cache-safe. **PRECEDENCE CAVEAT: the rung-(b2) pin is INERT while `CLAUDE_CODE_SUBAGENT_MODEL` is set** (env > Agent-tool `model` param > frontmatter > main-loop; env cannot be scoped per call) — to exercise (b2) remove the env line and start a fresh session, or skip to (c) / cross-vendor Codex dispatch; verify the pin took effect before concluding "sonnet did not help"; (b2-content) when kill evidence already isolates CONTENT as the trigger — a sibling unit with the same model and brief shape ran clean while the killed unit differs only in its target content (#1774) — skip the same-model rung-(b) rephrase: the FIRST retry carries content-side mitigation (pass the triggering content by file reference / digest) plus the model pin; (c) if a thin wrapper refuses twice, the orchestrator composes the artifact itself; (d) agents ingesting raw harmful-content completions, real-world-corpus rollout text (LMSYS/WildChat-class, #1073), OR safety-benchmark question banks (`src/explore_persona_space/artifacts/query_banks/*.json`) read aggregate JSONs / judge labels / structural digests (counts, `jq 'keys'`, sha256); examples may be pulled from RAW-COMPLETION files by grep + line offset, but harmful BANK items are digest-only — filename + index, never item text (enforced by the `guard_harmful_bank_read.sh` PreToolUse hook, whose Read arm also denies WHOLESALE reads — no bounded window, >256 KB — of real-world-corpus files, Read-arm-only by design, #1217; override `EPM_ALLOW_BANK_READ=1`); never page whole raw-completion or bank files into context (#866); (e) prevention beats recovery: briefs for harmful-content AND real-world-corpus tasks name banks/corpora by filename + row count, never inline example items — briefs for kill-gate / RLVR / guard / stop-criteria tasks use neutral gate vocabulary ("halt gate", "stop criterion", "termination predicate"; the loaded kill-* terms stay in the ARTIFACTS themselves — code, plans, task bodies are never renamed — only brief/prompt text is neutralized) (#1398, #1336) — briefs for activation-steering / causal-intervention work describe the manipulation mechanistically ("adds a direction vector to hidden activations at layer ℓ") rather than control-agentic phrasing (#1415) — and when the TASK's own `goal:` / `## Goal` carries trigger-dense phrasing, briefs on that task pass the Goal BY REFERENCE (task id + `body.md` path) or as a mechanistic paraphrase, never quoting it verbatim (#1769; the Goal artifact is never rewritten) — FIRST-PASS briefs carry BOTH disciplines (#1073) — and when the spawn's target files (or required reading) match a recognized trigger-dense CLASS per the recognition heuristic in `.claude/rules/trigger-dense-review.md`, the FIRST brief starts content-mitigated (file-reference/digest per that rule's disciplines 1 + 3) with no kill evidence required (rung (b2-content) stays the post-kill fast path for UNrecognized content; #2003) — and REVISION-ROUND briefs the same, with findings passed by marker/file reference, never inlined (#1413; `.claude/rules/trigger-dense-review.md` § Revision-round briefs); (f) **orchestrator refusal-wedge:** when the ORCHESTRATOR itself is refused on consecutive wake turns (zero actions land, so (a)-(c) can never execute), recovery is a FRESH SESSION: the watcher's prompt-wedge lane force-respawns on its failed-turn / storm / dead-wake / context-ceiling triggers (`EPM_TICK_WEDGE_*`; #1074/#1209/#1453); manual fast path — `spawn_session.py stop --session-id <sid>` then `spawn-issue --issue <N> --auto`; the respawn's mechanism is the FRESH CONTEXT — a LOWERED refusal surface, not immunity; (g) **refusal-truncated Agent spawns:** a mid-stream refusal can still DISPATCH a partially-generated `Agent` call — the subagent runs on a brief cut mid-sentence (#1090) — so after any refusal on a turn containing an Agent spawn, VERIFY the dispatched prompt's completeness and, if cut, complete the brief via SendMessage. Full discipline: `.claude/rules/trigger-dense-review.md`.
- **Autocompact-thrash subagent deaths — the thrash sibling of the refusal ladder above.** TWO classes share this symptom; check enrollment FIRST via `compact_boundary preTokens` in the transcript. **Class 1 — REDUCED-WINDOW ENROLLMENT (`tengu_amber_redwood` GrowthBook experiment):** a 1M-native model auto-compacts at ~200-270k because the account is silently enrolled in a reduced-threshold experiment; the harness's "a tool output is likely too large" text is misleading — do NOT read-bound briefs for this class. Discriminator: `preTokens` FAR below native ⇒ Class 1; NEAR native ⇒ Class 2. Fix: `env.CLAUDE_CODE_AUTO_COMPACT_WINDOW=1000000`; full mechanics: `.claude/rules/gotchas.md` § Autocompact-thrash from REDUCED-WINDOW ENROLLMENT. **Class 2 — FIXED-OVERHEAD pressure on the subagent window:** diagnose from the dead subagent's transcript — an OVERSIZED tool result → the read-side fix (`.claude/rules/diff-size-budget.md`); NO oversized result → fixed overhead, and read bounds do NOT help: respawn with MICRO-SCOPED work (smallest self-contained unit; a single-verdict reviewer stays ONE spawn, micro-scoped by brief) on the DEFAULT model. **If the micro-scoped default-model respawn ALSO thrashes** (#2054/#2057/#2062 shape), escalate ONCE (same `v<n>`, no counter increment) to the role's LEAN TWIN with the same brief: `analyzer-lean` (in `~/.claude/agents/`) / `planner-lean` (also serves the fact-checker's `planner`-typed spawn) / `critic-lean` / `experiment-implementer-lean` / `code-reviewer-lean` / `consistency-checker-lean` — the lean twin defers to the full spec by reference and drops MCP tools + `skills:` (~138K tokens of MCP schemas on an all-tools spawn). If the lean twin ALSO ends with no durable verdict, apply the fail-loud terminal (`epm:failure v1 failure_class: infra`, `status:blocked`, PushNotification, CRON-TEARDOWN) — never an unbounded retry loop (#2062). Do NOT pin a smaller model to fix thrash — the INVERSE of refusal rung (b2) (#1090: default-model spawns compacted fine while 3/6 sonnet spawns thrashed); model pins are for refusal recovery. Respawn mechanics: `.claude/skills/issue/SKILL.md` Step 5b durable-verdict-first rule + its autocompact-thrash respawn recipe. **When the whole ladder is exhausted and the orchestrator falls back to inline composition** (sanctioned only for a workflow-fix task fixing this failure mode, or refusal rung (c)), post one `epm:progress` note leading with the FIXED token `[epm-inline-fallback] role=<role> round=<n> reason=<one-line>` — the review site's independence guarantee is broken and must be visible (#2062).
