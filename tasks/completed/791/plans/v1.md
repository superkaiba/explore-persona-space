## 4. Design (Bug 1 fix)

Single file: `scripts/poll_pipeline.py`. Three edits, all pure/testable:

1. **Probe heredoc (`_ssh_probe`, ~line 939-985):** the `phase_log_probe` /
   `shard_log_probe` already compute the freshest matching file path via
   `stat -c "%Y %n" ... | sort -n | tail -1` (mirror the `cell_probe` shape at
   line 918). Extend BOTH to ALSO emit the freshest file's tail between
   `PHASE_TAIL_START`/`PHASE_TAIL_END` and `SHARD_TAIL_START`/`SHARD_TAIL_END`
   markers (reuse `tail -500`, guarded by `[ -f "$PATH" ]` exactly like
   `cell_probe`). No glob change — reuse the existing narrow `issue-<N>-*` /
   `issue_<N>` patterns so cross-pod pollution is impossible.

2. **`_parse_probe_stdout` (~line 1160):** add `phase_log_tail` /
   `shard_log_tail` keys + the two new START/END block parsers (mirror the
   `CELL_TAIL_START/END` branch). Add the keys to the default dict + the
   ssh-failed fallback dict.

3. **`_tail_excerpt_and_crash_signature` (line 2308):** change the signature to
   accept the phase/shard mtimes + tails, and select `wide_tail` by mtime-argmax
   over the four sources:

   ```python
   candidates = [
       (mtime_epoch, probe["log_tail"]),
       (cell_mtime_epoch, probe["cell_log_tail"]),
       (phase_log_mtime_epoch, probe["phase_log_tail"]),
       (shard_log_mtime_epoch, probe["shard_log_tail"]),
   ]
   # pick the freshest with a non-empty tail; tie/absent -> main log
   _, wide_tail = max(
       ((m, t) for m, t in candidates if t),
       default=(mtime_epoch, probe["log_tail"]),
       key=lambda mt: mt[0],
   )
   ```

   Update the one call site (poll_once, ~line 2730) to pass the extra args
   (all already parsed there as `phase_log_mtime_epoch` / `shard_log_mtime_epoch`
   at lines 2393-2394).
