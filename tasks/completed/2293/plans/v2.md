### D1 — `git_merge_base` helper (NEW symbol, `scripts/step9c_baseline.py`, after `git_sha_known` ~:692)

```python
def git_merge_base(base: str, wt: Path) -> str | None:
    """Merge base of *base* and HEAD in *wt* (the three-dot diff base, #2293).

    rc 0 -> the 40-hex sha; rc 1 -> None (no merge base: unrelated histories);
    any other rc raises CalledProcessError (bad ref / not a git tree).
    """
    proc = subprocess.run(
        ["git", "merge-base", base, "HEAD"],
        cwd=str(wt), capture_output=True, text=True,
    )
    if proc.returncode == 0:
        return proc.stdout.strip()
    if proc.returncode == 1:
        return None
    raise subprocess.CalledProcessError(proc.returncode, proc.args, proc.stdout, proc.stderr)
```

Exact argv: `git merge-base <base_ref> HEAD`, cwd = the WORK ROOT (`ctx.work_root`) — the same venue `compute_touched` diffs in (select_step9c_tests.py:1245 `cwd=str(work_root)`), so the oracle base and the selection-diff base are the same commit by construction.

### D4 — one resolution point, cached on ctx (decision: prompt item 2)

New function `_resolve_oracle_base(ctx: _CompareCtx, root: Path) -> None`, called in `_resolve_pristine_bucket` (:2173) at exactly ONE point: after the `--run-pristine` guard block (:2251–2258) and before `scratch: _ScratchTree | None = None` (:2259). Rationale for the placement: compares that never spend on a pristine run (empty bucket → early return :2242–2243; over-cap :2245–2250; `--run-pristine` absent :2251–2258) gain NO new shellout and NO new failure mode — the new `_Indeterminate` arms are scoped to runs that actually need an oracle.

```python
def _resolve_oracle_base(ctx: _CompareCtx, root: Path) -> None:
    """Resolve + cache the pristine-oracle cut: merge-base(base_ref, work-root HEAD) (#2293)."""
    try:
        sha = git_merge_base(ctx.base_ref, ctx.work_root)
    except subprocess.CalledProcessError as exc:
        raise _Indeterminate(
            f"oracle base resolution failed (git merge-base {ctx.base_ref} HEAD "
            f"in {ctx.work_root}): {exc}", warns=ctx.warns,
        ) from exc
    if sha is None:
        raise _Indeterminate(
            f"no merge base between {ctx.base_ref} and HEAD in {ctx.work_root} "
            "(unrelated histories) — cannot cut a pristine oracle", warns=ctx.warns,
        )
    if not git_sha_known(root, sha):
        raise _Indeterminate(
            f"oracle base {sha[:12]} (merge-base of {ctx.base_ref} and the work root's "
            f"HEAD) is not in {root}'s object store — the scratch is materialized from "
            "root and cannot detach there", warns=ctx.warns,
        )
    ctx.oracle_base_sha = sha
```

The per-file loop (:2266–2392) reads only `ctx.oracle_base_sha` — never re-shells. Both fail-closed arms are exactly the two the task brief names: no merge base (unrelated histories), and merge base absent from `root`'s object store (`git_sha_known(root, sha)`, def :681 — the scratch is materialized from `root` while the merge base is computed in `wt`; the two differ only under `--worktree`/`--repo-root` fixture overrides, since a real worktree shares `root`'s object database).
