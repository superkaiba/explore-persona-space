**Kind:** infra (code fix, no experiment). **Workflow:** v1. **TDD:** no.
**v2 delta vs v1:** folds the plan-critic's APPROVE-round suggestions — (a) test 3 must exercise a GENUINE st_dev mismatch (no `candidates=[]`-only shortcut), (b) resolver docstring carries the same-st_dev ≠ same-quota-domain caveat, (c) EDQUOT/ENOSPC raised at `os.open` (probe-file creation on an exhausted quota) now maps to `(False, None)` like the fallocate path, with a pinning test.

## Requirement + acceptance criteria

**Requirement (task Goal):** The EDQUOT/fallocate disk probe actually runs on the VM instead of silently degrading to `shutil.disk_usage` on every preflight.

**Root cause (verified):** `_probe_writable_bytes` (src/explore_persona_space/orchestrate/preflight.py:568) builds its probe file directly under `check_path`. `_disk_check_path()` returns `/` on the local VM, so `os.open("/.preflight_disk_probe...")` raises EACCES for a non-root user. The EACCES propagates out of `_probe_writable_bytes` (only `posix_fallocate` is wrapped, not `os.open`) into `check_disk_space`'s generic `except OSError` (preflight.py:748-750), which warns `Could not run disk-quota probe on /: [Errno 13] Permission denied` and degrades to the `shutil.disk_usage` fallback — on EVERY VM preflight.

**Acceptance criteria:**
1. On a host where `check_path` is not writable by the current user but a user-writable directory exists on the SAME filesystem (the VM: `/` unwritable; `$HOME`, `/tmp`, repo root all `st_dev`-equal to `/` — verified dev=2049 for all four), the fallocate probe RUNS (returns `(ok, None)`), no "Could not run disk-quota probe" warning, no probe file left behind.
2. When NO user-writable directory exists on `check_path`'s filesystem, the probe degrades EXPLICITLY via the documented fallback contract — returns `(True, "<reason>")` naming the missing writable location — instead of raising OSError to the caller.
3. Behavior preserved for existing callers: (a) a writable `check_path` (RunPod `/workspace`, cluster `$SLURM_TMPDIR`/`$SCRATCH`, any out-root) probes IN PLACE, exactly as today; (b) a NON-EXISTENT `check_path` is still created via `mkdir(parents=True, exist_ok=True)` (the `assert_out_root_headroom` contract — its out-root may not exist yet); (c) EDQUOT/ENOSPC → `(False, None)` and EOPNOTSUPP/ENOSYS/EINVAL/EBADF → `(True, reason)` fallocate semantics untouched.
4. EDQUOT/ENOSPC raised at `os.open` itself (probe-file CREATION refused on an already-exhausted quota) returns `(False, None)` — the real-refusal contract — instead of escaping to the caller's generic fallback. EACCES at open (post-resolver `os.access` lie, e.g. root-squash NFS) still propagates to the caller's existing `except OSError` backstop.
5. `uv run pytest tests/test_preflight_disk.py tests/test_preflight_disk_floor.py` passes; ruff clean on touched files; Step 9c touched-scope gate passes.

## File paths + concrete diffs

**1. `src/explore_persona_space/orchestrate/preflight.py`** (only file under `src/`):

- Add `import tempfile` to the import block.
- Add helper `_writable_probe_dir(check_path: str, candidates: list[str | None] | None = None) -> str | None` directly above `_probe_writable_bytes`:
  - First, `with contextlib.suppress(OSError): Path(check_path).mkdir(parents=True, exist_ok=True)` — preserves the current create-if-missing behavior for out-roots (acceptance 3b).
  - If `os.access(check_path, os.W_OK | os.X_OK)` → return `check_path` (fast path; all current writable callers land here — acceptance 3a).
  - Else `check_dev = os.stat(check_path).st_dev` (OSError → return None); iterate `candidates` (default `[os.environ.get("HOME"), tempfile.gettempdir(), os.getcwd()]`); return the first that is non-empty, `os.access(cand, os.W_OK | os.X_OK)`, and `os.stat(cand).st_dev == check_dev` (per-candidate OSError → skip). Else return None.
  - Docstring states (i) WHY same-`st_dev` is load-bearing: the probe detects the quota/headroom of `check_path`'s filesystem; probing a different mount would measure the wrong disk; AND (ii) the caveat that same st_dev does NOT guarantee the same QUOTA DOMAIN (ext4 project quotas and MooseFS per-directory quotas are subtree-scoped) — harmless for current callers (the fallback only fires for unwritable check_paths, which `_disk_check_path` never produces on quota-scoped mounts), but a future caller must not rely on cross-directory quota equivalence.
- In `_probe_writable_bytes`:
  - Replace the direct `probe_path = Path(check_path) / ...` + `probe_path.parent.mkdir(...)` with:
    ```
    probe_dir = _writable_probe_dir(check_path)
    if probe_dir is None:
        return True, f"no user-writable probe location on the {check_path} filesystem"
    probe_path = Path(probe_dir) / f".preflight_disk_probe.{os.getpid()}.{uuid.uuid4().hex[:8]}.tmp"
    ```
    (the `mkdir` moves into the resolver; the returned tuple follows the existing fallback contract — caller already handles `fallback_reason is not None`).
  - Wrap the `os.open` call: `except OSError as e: if e.errno in (errno.ENOSPC, errno.EDQUOT): return False, None; raise` — acceptance 4 (open-time quota refusal joins the refusal contract; everything else re-raises to the caller's existing backstop).
  - Update the function docstring's `check_path` arg description accordingly.

**2. `tests/test_preflight_disk.py`** — add 5 tests (existing tests untouched):
- `test_probe_unwritable_dir_uses_same_fs_candidate(tmp_path, monkeypatch)` — `ro = tmp_path/"ro"` chmod 0o555; `monkeypatch.setenv("HOME", str(tmp_path/"home"))` (created, writable, same st_dev). Assert `_probe_writable_bytes(str(ro), 4096) == (True, None)` and no `.preflight_disk_probe*` file left in either dir. `@pytest.mark.skipif(os.geteuid() == 0, ...)` (root ignores modes).
- `test_probe_no_same_fs_candidate_falls_back(tmp_path, monkeypatch)` — monkeypatch `preflight._writable_probe_dir` to return None; assert `(True, reason)` with "no user-writable" in reason (exercises the new explicit-degrade branch; the fail-loud pin replacing the silent OSError degrade).
- `test_writable_probe_dir_rejects_cross_fs_candidates(tmp_path)` — GENUINE st_dev mismatch, mock-free: `ro` dir chmod 0o555; assert `_writable_probe_dir(str(ro), candidates=["/dev/shm"]) is None` where the test first asserts `os.stat("/dev/shm").st_dev != os.stat(str(ro)).st_dev` (skipif: non-Linux, `/dev/shm` missing, euid==0, or st_dev unexpectedly equal — skip rather than false-fail on exotic hosts). Additionally assert `_writable_probe_dir(str(ro), candidates=[]) is None` and that a same-fs writable candidate IS returned (`candidates=[str(tmp_path/"w")]`). This pins the load-bearing same-st_dev rejection (plan-critic suggestion 1 — a broken comparison returning a cross-fs dir would measure the wrong disk).
- `test_probe_creates_missing_check_path(tmp_path)` — `target = tmp_path/"new"/"sub"` (does not exist); assert probe returns `(True, None)` AND `target` now exists (acceptance 3b).
- `test_probe_open_edquot_refuses(tmp_path, monkeypatch)` — monkeypatch `os.open` (module-level via monkeypatch, auto-restored) to raise `OSError(errno.EDQUOT, "quota")`; assert `_probe_writable_bytes(str(tmp_path), 4096) == (False, None)` (acceptance 4). A sibling assert with `OSError(errno.EACCES, ...)` expects `pytest.raises(OSError)` (the re-raise arm — negative control).
