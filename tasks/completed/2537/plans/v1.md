#### 4.1 Scope 1 — the mapping fix: registry entries (recommended) over a runtime discovery arm

**Tradeoff, stated explicitly (required by the task):**

- *Pinned registry entry:* exact, zero selector-runtime cost (an `O(1)` dict lookup per touched file at `transitive_consumer_pairs`, line 1198), matches the registry's founding contract, and inherits the existing drift pins (case 82 asserts every registered key + test exists on disk and is non-invariant; case 85 pins that missing-on-disk consumers are dropped). Weakness: it goes stale silently in ONE direction — a FUTURE test file written in the same idiom never self-registers.
- *Runtime discovery arm:* would generalize, but (a) #1688 already evaluated and deliberately rejected flat-token discovery ("mass-over-selecting English words") and f-string-constructed strings are statically invisible to raw-text arms; (b) it would add a scan pass on every `scripts/`-touching diff (nearly every diff), where the registry costs nothing; (c) an over-selecting runtime arm inflates every gate's test set, while an over-demanding TEST fails loudly at exactly one review round.

**Recommendation: registry entries + a test-time discovery invariant (§4.2).** The registry carries the exact fix; the meta-test carries the generality — relocated from selector runtime (cost on every diff) to gate-test time (cost only when the invariant file runs), closing the only weakness of the pinned route: a new same-idiom consumer test file fails the gate of the very round that lands it, because `tests/test_select_step9c_tests.py` is a WORKFLOW_INVARIANT member and runs at every gate.

#### 4.2 Scope 1+2 combined — the discovery meta-test (the cheap general mechanism, and the standing form of the audit)

New test in `tests/test_select_step9c_tests.py` (appended in the file's numbered-case style): `test_constructed_path_consumers_all_covered`.

Discovery algorithm (conservative by design — under-fire acceptable and disclosed, over-fire not):

1. Universe: `(work_root / "tests").rglob("test_*.py")`, raw-text prefilter `"spec_from_file_location" in text` (181 files today; only these are AST-parsed).
2. Per file, parse the AST and collect **loader functions**: local `FunctionDef`s whose body contains a `Call` whose callee attribute/name is `spec_from_file_location`. Also note whether any `spec_from_file_location` (or loader-fn) call passes a NON-constant module-name argument (the parametrized shape).
3. Collect candidate stems:
   - (i) every `ast.Constant` string argument at call sites of a loader function or of `spec_from_file_location` itself;
   - (ii) ONLY IF step 2 noted a non-constant-arg loader call in this file: every module-level assigned `List`/`Tuple` whose elements are ALL constant strings AND ALL resolve to existing `scripts/<stem>.py` files (the `test_data_gen_upload_wiring.py` parametrize-list shape; the all-elements-resolve requirement suppresses mixed fixture lists).
4. Keep `(test_relpath, f"scripts/{stem}.py")` pairs where `(work_root / "scripts" / f"{stem}.py").exists()`.
5. Compose realized coverage with ONE batched invocation of the real CLI (the case-86 pattern): write all discovered module paths to a payload file, run `sel.main(["--map-files", payload, "--repo-root", str(repo_root)])` under `capsys`, and parse the `(test, module)` pairs.
6. Assert every discovered pair satisfies: pair ∈ mapped pairs, OR test ∈ `WORKFLOW_INVARIANT` (invariant members run at every gate — they can never be "unrun consumers"; they are also barred from the registry by case 82), OR pair ∈ `_CONSTRUCTED_PATH_FP_ALLOWLIST` (a module-level set in the test file; each entry carries a one-line vet comment naming why it is not a genuine load). Failure message names the pair and the remedy: "register in TRANSITIVE_CONSUMER_TESTS, or allowlist with a vet rationale".

Disclosed misses of the discovery (each stays covered only by the pre-existing per-file `untested_touched` WARN fallback where applicable, unchanged from #1688): `importlib.import_module` by name; `monkeypatch.setattr` flat-string targets; loaders living in `conftest.py` or imported from another file; name lists built by loops/comprehensions; `scripts/` subpackage modules; stems shorter than the audit bound. This mirrors the disclosed-miss posture of the rules-pin and #1688 arms.

**Completion rule at landing:** the meta-test forces the registry to be complete for everything it discovers — the implementation round runs it, vets each unmapped discovered pair (read the load site), and either registers it (genuine load, consumer not invariant) or allowlists it (not a load).
