## 3. File paths + concrete diff

**Single file:** `.claude/rules/gotchas.md`

Placement: in the general ops-trap block near the top of `# Gotchas` — immediately after

Proposed entry (implementer may polish wording; keep it ONE bullet, ≤ ~1,000 bytes):

> - **Edit-then-run can execute the PRE-edit script (PostToolUse formatter race) — exit
>   0, stale artifact.** The `.claude/settings.json` PostToolUse hook reformats every
>   Write/Edit'd `*.py` (ruff check --fix + ruff format) asynchronously relative to the
>   NEXT tool call; a Bash run issued immediately after an edit can execute the OLD
>   bytes and exit 0, producing an artifact from the pre-edit code (observed during
>   #1482: the hook rewrote a generator ~2 s AFTER the run had already started). The
>   failure is silent and DIRECTIONAL — it always reproduces the PREVIOUS behaviour, so
>   "my fix had no effect" sends an agent off changing correct code. Tell (one command):
>   `stat -c '%y %n' <script> <artifact>` — the SCRIPT's mtime LATER than the artifact
>   it supposedly produced is impossible for a healthy run. RULE: on an edit-then-run
>   cycle never trust the exit code alone — grep the artifact for a string only the NEW
>   code emits, or confirm the script's mtime predates the run before reading results.
