## 4. Method delta (vs the #1145 precedent)

The #1145 precedent (`05dee614d3`, e.g. `issue928_mlc_figures.py` L27–43) puts the wrapper import in the top import block, the `load_dotenv()` call with a `# #847:` comment, then heavy imports with `# noqa: E402`. Deltas here:

1. **Placement after the `sys.path.insert` lines** (5 of 7 files). These scripts import script-siblings via `sys.path.insert(0, PROJECT_ROOT/"scripts")` and may resolve `explore_persona_space` via the `src` insert. Inserting the preamble AFTER the inserts (with `# noqa: E402` on the import line) keeps the sys.path semantics byte-identical and is the smaller diff. 2. **Keep the manual thread-cap `os.environ.setdefault` loops** (design question 2): `load_dotenv` setdefaults the same keys; both are setdefault-based so keeping both is harmless and minimal. No removal.
3. **Keep the existing in-`main` / late `load_dotenv()` calls** (design question 3): `figures.py` L2470–2472 and `transfer_probe.py` ~L1855 keep theirs — `load_dotenv` is idempotent (setdefault semantics); removing them is an unnecessary behavior question.
4. **`gpu_phase.py` is a move, not an insert:** it already has the module-top import + call (L38/L40); only `import numpy as np` (L35) moves below the call.
5. **E501 cleanup rides along** (the `c7f0b3c874` precedent): 10 pre-existing over-long lines — all single-line `# HUB_VERIFY_RETRY_EXEMPT:` / `# HUB_DIR_FILECOUNT_EXEMPT:` waiver comments — are shortened **in place** (never wrapped: both waiver regexes are single-line and must sit on the call's first line or the immediately preceding non-blank line; `workflow_lint.py` L1766/L1407, min reason 10 chars).
