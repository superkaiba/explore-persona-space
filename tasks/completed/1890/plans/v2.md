## 1. Requirement + acceptance criteria

**Requirement.** The GCE EXIT-trap crash-persist (`_eps_persist_diagnostics`,
rendered into the startup script by `src/explore_persona_space/backends/gcp.py`)
must include the local analysis-tensors staging trees in its upload set, so a run
that stages map/tensor payloads locally (Upload Policy #521 class: "intermediate
analysis tensors referenced as downstream inputs") no longer loses them when the
boot disk is auto-DELETEd on a non-zero exit. Driving incident: #1739 nlmap round,
2026-07-30 — a banked 412 MB MLP map fit (0.68 GPU-h) died with the boot disk on a
DESIGNED rc=7 stop (`epm:progress` v122 on #1739).

**Acceptance criteria.**
1. The persist dir list (currently gcp.py L2280-2285) additionally covers BOTH
   live staging roots:
   a. **Workload-root tree** — `root / "analysis_tensors"` (root =
      `$WORKLOAD_ROOT`): covers the issue-scoped relative convention
      (`analysis_tensors/issue_<N>/maps/...`, the #1739 plan §10 shape; dispatch
      cwd is `$WORKLOAD_ROOT`). Dest: `issue<N>_partial/<attempt_id>/analysis_tensors`.
   b. **GCE scratch-root tree** — the `/workspace`-rooted convention:
      `resolve_base_dir(None)` returns `/workspace` whenever it exists (true on
      every GCE instance), so issue_823 (`run_823.py:110-117`), issue_952
      (`run_952.py:303-310`), and issue_1072 (inherits, `run_1072.py`) stage at
      `/workspace/analysis_tensors[...]`. Covered via an env-overridable root
      following the #1605 `EPS_PERSIST_WORKSPACE_LOGS_DIR` isolation precedent:
      `Path(os.environ.get("EPS_PERSIST_WS_TENSORS_ROOT", "/workspace"))`, entry
      `(<ws_root> / "analysis_tensors", "analysis_tensors_ws")`. Test isolation
      threads the env var exactly as `_run_persist_heredoc` already does for the
      workspace-logs sweep.
   c. **Sibling dir names** — `analysis_tensors_lowdim`
      (`run_1072_lowdim.py:116`) exists in the wild: cover sibling names by

      scratch root) rather than enumerating literals. If the implementer finds
      the glob loop disproportionate, the fallback is explicit entries for
      `analysis_tensors` + `analysis_tensors_lowdim` at both roots, with the
      residual (novel future sibling names) recorded in a comment.
