## 1. Goal

Close the residual gap on #671's hook-fix surface. #671 migrated the
per-probe / per-response activation reads in `scripts/issue667_extract.py` off
the `output_hidden_states=True` full-tuple pattern (which materializes all
`L+1` residual-stream tensors per forward — the #545/#667 accumulation bug) and
onto the shared `extract_layer_activations` hook helper. One function was left
behind: `_context_vector_all_layers`, the base-side / post-FT context vector
`c_C` read used for the A3.10 oracle. Both `analyzer` and `clean-result-critic`
flagged this as a known residual on #672 (the fact-check that surfaced it).
This task migrates that last function and adds a bit-for-bit equivalence test,
so the file contains **zero** `output_hidden_states=True` and the memory-safe
contract holds across the whole extraction surface.

### 4.1 The function refactor (the single code change)

`scripts/issue667_extract.py::_context_vector_all_layers` (def at line 582).
The function signature is **unchanged** so the four call sites need no edits.

**OLD body (lines 588-596):**
```python
text = tok.apply_chat_template(messages, tokenize=False, add_generation_prompt=True)
ids = tok(text, return_tensors="pt").to(device)
out = base_model(**ids, output_hidden_states=True)
# hidden_states: tuple len N_LAYERS+1 (hs[0] = embeddings). Take layers 1..N.

```

**NEW body:**
```python
text = tok.apply_chat_template(messages, tokenize=False, add_generation_prompt=True)
ids = tok(text, return_tensors="pt").to(device)
# Memory-safe subset read: hook all N_LAYERS block layers (block index li ==
# old out.hidden_states[li + 1]) instead of materializing all L+1 layers (#671,
# residual closed by #675). acts[li] is the SAME tensor the old
# out.hidden_states[li + 1] read produced. extract_layer_activations wants a
# plain (1, T) input_ids tensor (NOT the tokenizer dict), so unpack input_ids.
acts = extract_layer_activations(base_model, ids["input_ids"], list(range(N_LAYERS)))
vecs = [acts[li][0, -1, :].float().cpu().numpy() for li in range(N_LAYERS)]
arr = np.stack(vecs).astype(np.float32)
assert arr.shape == (N_LAYERS, base_model.config.hidden_size), arr.shape
return arr
```

Notes:
- `extract_layer_activations` is already imported at line 80; `N_LAYERS` is
  already imported at line 86 (`= 28`, from `explore_persona_space.analysis.issue667`).
- No new imports needed (`EMBED_LAYER` is NOT used — the read drops the
  embedding by requesting block indices `0..N_LAYERS-1`, never `hs[0]`).
- `attention_mask` is intentionally omitted from the helper call: the OLD code
  passed `**ids` which *did* include `attention_mask`, but for a single
  unpadded sequence (`B=1`, no padding) the attention mask is all-ones and the
  forward is identical with or without it. The stub models in the test ignore
  the mask anyway. (Risk-tracked in §11; if the equivalence test ever showed a
  difference, pass `attention_mask=ids["attention_mask"]` — but it will not for
  a single unpadded sequence.) **The OLD code never padded** (single sequence
  per call), so this is safe.

### 4.2 Layer-index mapping (the correctness crux)

| | OLD | NEW |
|---|---|---|
| index variable | `li in range(1, N_LAYERS + 1)` → `1..28` | `li in range(N_LAYERS)` → `0..27` |
| read | `out.hidden_states[li]` = `hs[1..28]` | `acts[li]` where `acts = extract_layer_activations(..., list(range(28)))` |
| identity | `hs[li]` (li=1..28) drops `hs[0]` (embedding) | `acts[L]` (block index L) == old `hs[L+1]`; so `acts[0..27]` == old `hs[1..28]` |
| position | `[0, -1, :]` (last input token) | `[0, -1, :]` (unchanged) |
| reduction | `.float().cpu().numpy()` (unchanged) | `.float().cpu().numpy()` (unchanged) |

So `acts[li]` for `li in 0..27` is byte-identical to old `out.hidden_states[li+1]`
for `li+1 in 1..28`. The final stacked `(N_LAYERS, HIDDEN)` array is identical.

### 4.3 The bit-for-bit equivalence test (the new test code)

**(a) New equivalence test** modeling the `_context_vector_all_layers` read

```python
def _old_context_vector_all_layers_via_fulltuple(model, ids, n_layers):
    """The PRE-migration _context_vector_all_layers math: full-tuple read of
    hs[1..n_layers] at the LAST input position, dropping the embedding hs[0].
    Reproduced against the stub so the test pins the migrated call against the
    exact old behavior. `ids` is a plain (1, T) tensor (the stub's input)."""
    out = model(input_ids=ids, output_hidden_states=True)
    return np.stack(
        [out.hidden_states[li][0, -1, :].float().cpu().numpy() for li in range(1, n_layers + 1)]
    ).astype(np.float32)


def test_context_vector_all_layers_byte_identical():
    """The migrated all-layers context-vector read (block indices 0..N-1, last
    input token) reproduces the OLD hs[1..N] full-tuple read bit-for-bit on
    BOTH the hook stub and the fallback stub. Pins the #675 residual: the
    embedding-drop off-by-one (request blocks 0..N-1, NOT hs[0..N-1]) and the
    last-position read."""
    tok = _tok()
    fallback = _FallbackStub(tok.vocab_size, _D, _N_BLOCKS, seed=17)
    hook = _HookStub(tok.vocab_size, _D, _N_BLOCKS, seed=17)
    for ids in _ids_list(tok):
        old = _old_context_vector_all_layers_via_fulltuple(fallback, ids, _N_BLOCKS)
        for model in (fallback, hook):
            acts = extract_layer_activations(model, ids, list(range(_N_BLOCKS)))
            new = np.stack(
                [acts[li][0, -1, :].float().cpu().numpy() for li in range(_N_BLOCKS)]
            ).astype(np.float32)
            assert new.shape == (_N_BLOCKS, _D), new.shape
            assert np.array_equal(old, new), model.__class__.__name__
```

Notes on the test:
- `_N_BLOCKS = 28` in the test file equals the real `N_LAYERS = 28` — the stub's
  block count already matches, so `list(range(_N_BLOCKS))` is the same shape the
  production call uses (`list(range(N_LAYERS))`).
- `np.array_equal` is exact (no epsilon), the numpy analogue of `torch.equal` —
  appropriate because the float32 numpy arrays come from identical tensors.
- The test exercises BOTH the `_HookStub` (hook path) and `_FallbackStub`
  (full-tuple fallback) — same pattern as #671's `test_hook_equals_fulltuple_byte_identical`.
  The `_HookStub` asserts internally that `output_hidden_states=True` is NOT
  passed on the hook path (runtime teeth), so the test also pins that the
  production read uses the hook path on a standard decoder.
- The test deliberately passes a **plain tensor** `ids` (from `_ids_list`),
  matching the helper's `input_ids` contract and the production refactor's
  `ids["input_ids"]` unpacking.

### 4.4 Memory-non-growth coverage

The existing `test_memory_non_growth_cpu_proxy` (line 470) is a helper-level
CPU proxy: it loops `extract_layer_activations` N=20× and asserts the high-water
RSS does not balloon. Because the migrated `_context_vector_all_layers` now
calls the SAME helper (with `list(range(28))` — the widest layer request,
already covered conceptually by the existing test which uses `[7, 14, 21]`), the
context-vector path inherits the helper's non-growth property: no new
per-iteration Python reference is retained (handles removed in `finally`,
captured dict dropped). The task body confirms the context-vector read is
transient / non-accumulating, so it does not regress the memory profile.

**Decision:** the existing helper-level proxy already covers the context-vector
path (same helper, transient call), so I will NOT add a redundant
function-level memory loop. Instead I add one assertion strengthening: extend
the existing `test_memory_non_growth_cpu_proxy` to also run a pass with
`layers = list(range(_N_BLOCKS))` (the all-layers request the context-vector
read uses) so the proxy explicitly exercises the widest layer set:

```python
    # Also exercise the all-layers request (the #675 _context_vector_all_layers
    # path) so the proxy covers the widest hook set, not just a 3-layer subset.
    for _ in range(20):
        acts = extract_layer_activations(hook, ids, list(range(_N_BLOCKS)))
        del acts
        gc.collect()
        rss.append(resource.getrusage(resource.RUSAGE_SELF).ru_maxrss)
```
(appended into the existing test's loop body / a second loop before the
high-water assertions, so the `first_half_peak` vs `last_half_peak` check spans
both layer-set sizes). **This is an extension of the existing memory test, not
a new test** — it keeps the single high-water assertion authoritative.
