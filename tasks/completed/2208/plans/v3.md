## 4 Method delta (design)

**What changes:** the Step 5a sibling arm gains an import-satisfiability probe on synced sibling
TEST files, placed AFTER the sync loop's checkouts and BEFORE the commit block (so a probed
test's paired script is already synced at probe time, and nothing poisoned is ever committed).

**Why a real collection probe (not a static AST/module scan):** the #2206 failure is
SYMBOL-level skew — the module existed branch-era; only the symbol was missing. Only executing
the import (`pytest --collect-only` collects = imports the test module) reproduces the gate's
own failure mode.

**Pair-atomic revert:** on probe failure, revert the test AND every synced file sharing its
issue number `M` (reverting the test alone while keeping its synced `scripts/issue<M>_*.py` is
the #1824/#1860 half-sync class in reverse).

**Fail-safe direction:** every failure path (ImportError, probe timeout, any nonzero rc) reverts
to status-quo staleness — the pre-#1972 world, which the gate tolerates — never an unreadable
gate red. Timeout counts as failure.

**Main-NEW drop branch:** in the #2206 shape the poisoned file does NOT exist in `HEAD` (it was
created by the sync checkout, staged in the index, uncommitted). `git checkout HEAD -- <f>`
would error there; the revert must branch: file exists in `HEAD` → `checkout HEAD --` (restore
branch-era content); else → `git rm -f -q --` (drop from index + working tree). Without this
branch the fix would fail on exactly the incident shape.

**Concrete insert** (`.claude/skills/issue/SKILL.md`, between the sync loop's `done < <(...)`
line (~2562) and the commit block (~2563) — inside the `_sibling_arm_block` extraction span,
i.e. before the `[step5a] sibling-file sync:` echo):

```bash
# Import-satisfiability probe on synced sibling TEST files (#2208): a main-NEW
# test can import a symbol added to src/ AFTER this branch's fork point — the
# worktree src is branch-era, collection ImportErrors, and the Step 9c compare
# classifies the node NEW (fail-closed), walling the gate (#2206: ~1h wall +
# manual provenance override). Probe REAL collection in THIS worktree (a static
# module scan cannot see symbol-level skew); on failure revert the test AND
# every synced file of the same issue number (pair-atomic — reverting the test
# alone while keeping its synced script is the #1824/#1860 half-sync class in
# reverse). Fail-safe direction: status-quo staleness (the pre-#1972 world),
# never an unreadable gate red; a probe timeout counts as failure.
if [ "${#SIBLING_SYNCED[@]}" -gt 0 ]; then
  # Warm the worktree venv OUTSIDE the per-file fence: a fresh worktree pays a
  # full `uv sync` on its first `uv run`, which would eat the 180s probe fence
  # and revert legitimate syncs (critic NIT 1). Best-effort — a warm-up failure
  # just means probes fail → revert → the declared fail-safe direction.
  (cd "$WT" && timeout 900s uv run python -c pass >/dev/null 2>&1) || true
  REVERT_ISSUES=""
  for f in "${SIBLING_SYNCED[@]}"; do
    case "$f" in
      tests/test_issue*_*.py)
        if ! (cd "$WT" && timeout --kill-after=15s 180s uv run pytest --collect-only -q "$f" >/dev/null 2>&1); then
          m=$(basename "$f" | grep -oE '[0-9]+' | head -1)
          REVERT_ISSUES="$REVERT_ISSUES $m"
          echo "spec-freshness: sibling test $f fails collection in this worktree (likely branch-era src import skew, #2206) — reverting its issue-$m synced pair (#2208)."
        fi
        ;;
    esac
  done
  if [ -n "$REVERT_ISSUES" ]; then
    KEPT=()
    for f in "${SIBLING_SYNCED[@]}"; do
      m=$(basename "$f" | grep -oE '[0-9]+' | head -1)
      case " $REVERT_ISSUES " in
        *" $m "*)
          if git -C "$WT" cat-file -e "HEAD:$f" 2>/dev/null; then
            git -C "$WT" checkout HEAD -- "$f"        # restore branch-era content
          else
            git -C "$WT" rm -f -q -- "$f"             # main-NEW file — drop it (index + tree)
          fi
          ;;
        *) KEPT+=("$f") ;;
      esac
    done
    SIBLING_SYNCED=("${KEPT[@]}")
  fi
fi
```

## Known residuals (critic round 1, all NIT — folded here)

1. **Cold-venv first probe:** a fresh worktree's first `uv run` pays a full `uv sync`; the
   pre-loop warm-up (900 s, outside the per-file fence) absorbs it. If the warm-up itself fails,
   probes fail and syncs revert — the declared fail-safe direction (status-quo staleness).
2. **Already-committed poison is out of scope (fix (b) territory):** a poisoned test synced AND
   committed by a pre-fix round is byte-identical to origin/main and never re-enumerated by the
   arm's `diff --name-only origin/main`, so it is never probed — that branch walls once and
   needs the manual provenance override, exactly the deferral of fix (b) recorded in §0.
3. **Echo attribution softened to "likely":** pytest output is discarded, so a non-skew
   collection failure gets the same skip line; the wording no longer asserts the cause.
