```markdown
- **Teammate coordination — one implementer per file set; an idle ping is not a verdict; reports on the teammate channel.** The ownership-check bullet above governs resuming/relaunching RUNS on a shared artifact path; this bullet governs dividing WORK among live teammates/subagents (three same-day incidents, 2026-07-20). A teammate is LIVE until its terminal result arrives OR durable completion evidence exists (a landed commit covering its assigned scope, a posted completion marker, its final Agent result) — a self-reported WIP state is neither. (a) **ONE implementer per file set.** Never spawn a second implementer over a file set a live one owns (the owned set is the scope ASSIGNED in its spawn brief, not whatever it later touches); stand the first down and confirm its durable state FIRST. #1112: a second implementer spawned on the first's self-report ("too deep to do them safely") duplicated the M4/M5/B3 implementation — the first landed all three anyway, and the parallel sessions' duplicate work had to be untangled with a cancel/push collision. (b) **An idle notification is NOT a done/stall verdict.** Before re-doing or re-assigning a live teammate's work, probe DURABLE state: `git log`/`git status` on the claimed paths (its worktree AND the repo root — a commit can land seconds after the ping), task markers (`task.py view <N> --json` / `latest-marker <N>`), and the expected output files. #1112: "went idle without committing it. Doing the fix myself" — the teammate's commit landed in parallel, a duplicate-fix race. (c) **Deliver stand-downs and teammate-directed reports on the teammate channel** — SendMessage to the running teammate (or the Agent result its caller reads) — never as plain assistant text, which no teammate sees. #958: an idle teammate's work was finished and committed for it with no stand-down on its channel; it woke on its next step and had to be stood down mid-race ("standing it down before it races me"). No channel reaches it ⇒ it is still live: force-stop it (or wait) before touching its file set.
```
