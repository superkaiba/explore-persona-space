## 3. Method delta

Current file stubs `huggingface_hub.list_repo_files` at 9 sites (6 value mocks/`_raise`, 3 `_boom` guards). Post-#733 (`669a7b6a2e`) that function is never called — checks 23/25 funnel every Hub request through `verify_task_body._hf_tree_get(url, params, headers, *, timeout_s) -> _TreeProbeResult` (lines 4373–4416). Delta: migrate every mock to `_hf_tree_get`, mirroring the pattern the sibling `tests/test_verify_task_body.py` already adopted in the same commit (autouse `_clear_hf_existence_cache` fixture, `_stub_tree` helper — lines 1079–1100).

**Why `_hf_tree_get` and not `get_session`/`requests`:** it is the narrowest seam the implementation OWNS, with a typed contract (`_TreeProbeResult(status, entries, next_page, note)`, lines 4336–4349) that both call sites (`_hf_probe_existence` line 4475, `_hf_probe_keyword` line 5444) consume. Mocking `get_session()` would couple the tests to `requests.Response` internals (`.status_code`, `.json()`, `.links`, `.raise_for_status()`) and to the retry/sleep loop — brittle and slower (the retry loop `time.sleep`s). Mocking higher (`_hf_keyword_present_under_prefix`) would skip the fence/cache/verdict-mapping code the tests exist to pin.

**Trap (why not import the sibling's helper):** each test file loads `verify_task_body` as its own `importlib` module instance; the sibling's `_stub_tree` patches the SIBLING's instance. Importing it cross-file would patch the wrong module object. A local ~15-line copy of the fixture + helper is required, not optional duplication.
