## Design decisions (with reasons)

- **D1 — Placement: gotchas.md, immediately after the #1092 entry (line 172).** Budget verified: 178,532 B + ~2,200 B < 200,000 B WARN. Adjacency makes the sibling cross-reference a one-line pointer in each direction (the new entry references #1092's entry; #1092's entry is NOT edited — one-directional cross-ref avoids touching settled text and keeps the diff minimal).
- **D2 — Convention over shared helper (the task body's delegated fork).** NO new `src/` helper. Rationale: the assertion itself is one line (`if not rows: raise RuntimeError(...)`); the transferable value is the convention + the diagnostic recipe (per-predicate reject counters naming WHICH predicate emptied the set). A generic helper is either trivial (assert non-empty — invites non-use) or over-engineered (predicate introspection across heterogeneous selection idioms: list comps, pandas masks, dict lookups, JSONL scans). The in-repo precedent `scripts/issue1739_holdout_rung.py::_assert_nonempty` (the round-19 fix) is cited in the rule text as the pattern exemplar. No library code ⇒ no new test surface ⇒ smaller blast radius.
- **D3 — NO code-style.md edit.** The task listed it as secondary at planner's call. Declined: code-style.md has no fail-fast section to extend (verified by grep — fail-fast lives in CLAUDE.md Critical Rules), and restating the rule across two files creates drift risk. The always-on discovery surface is the LESSONS.md trigger row (D4), which is what actually fires at plan time.
- **D4 — LESSONS.md trigger-row extension.** Append to the gotchas.md row's fires-when list: `or write a selection/filter/join step over an already-local committed artifact (fail loud on an empty selection)`. This is the mechanism that makes the rule consulted before the next script is written, closing the "next site re-learns it" gap the task names.

## File paths + concrete diffs

1. `.claude/rules/gotchas.md` — insert ONE new bullet directly after the #1092 entry (after current line 172). Draft text (~2,150 B; refine wording at implementation, keep ≤2,400 B):

   > - **Empty selection over a LOCAL committed artifact must fail LOUD — an empty post-filter row set, empty cell selection, or zero-row result table is a `RuntimeError`, never a silent rc=0 no-op, and NEVER a well-formed "success" artifact.** #1739 hit this class THREE times in one round: (1) `issue1739_trait_rejudge.py` — CLI rung names vs on-disk `train`/`hhrt`/`toxicchat` aliases (fixed by `_LOCAL_RUNG_ALIAS`, `0d09a51f49`); (2) `issue1739_rescore_ood.py` — filtered top-level `f_u`/`u_rung_label` while `percell/cells.jsonl` nests that identity inside `unit_key`: kept **0 of 826** cells and wrote `ood_detection_metrics.json` with `n_metric_rows: 0` at rc=0 — the well-formed empty artifact read as a completed run and cost TWO DAYS of misdiagnosis (measured post-fix: 270/826); (3) `issue1739_compliance_full.py` — same alias mismatch in a stale copy, would have judged **0 of 159,990** requests at rc=0; caught minutes pre-launch by a zero-API dry-run. The two recurring mismatch shapes: CLI-vs-on-disk KEY ALIASES, and identity NESTED inside a JSON-string column rather than at top level. RULE for any selection/filter/join step over an already-local committed artifact (judge rollout mirrors, per-cell JSONL, cell registries, eval JSONs): (1) assert the post-selection set is non-empty and RAISE on empty — exemplar: `scripts/issue1739_holdout_rung.py::_assert_nonempty`; (2) keep per-predicate reject counters so a 0-selection failure NAMES the predicate that emptied the set (the same diagnostic as the streaming entry above); (3) never emit an output artifact from an empty selection — a zero-row "success" file is the trap that converts a crash-now bug into a days-later misdiagnosis. Local-artifact sibling of the #1092 real-corpus streaming-filter entry directly above (that entry: REMOTE streaming corpus, remedy = bounded tiny-real probe; this entry: LOCAL committed artifact, remedy = fail-loud assertion at the selection site). Cross-ref only — the streaming entry is not superseded.
