### 4.1 Match surface (design question 1 — resolved)

All regexes ^-anchored to the clause head (the #1443 convention: the splitter strips leading whitespace at L833, so post-split clauses are head-anchored by construction; mid-clause quoted prose — grep patterns, echo'd text, ssh payload fragments — can never match; the arms run BEFORE the L1498 ssh/grep waiver, so without the anchor a grep clause whose pattern argument spells the full gated shape would false-block).

- **Arm A (pre-`-C`-waiver, new lines between L1486 and L1489):** clause-initial `git -C <path>` where the path token contains `.claude/worktrees/` (any spelling, quoted or not) OR is a `$WT` / `${WT}` spelling (word-boundary — `$WTF` does not match), followed by optional git global flags, `merge`, optional `--long-flags`, and the bare ref `main` (optionally quoted), then only trailing `--long-flags` / redirect tokens to end-of-clause. - **Arm B (at the L1486 scoped-continue):** a new `scoped_wt` bit records whether the current `scoped=1` latch was armed by a WORKTREE cd (literal `.claude/worktrees/` cd at L1426, or the `$WT` cd at L1476-1485) vs a `/tmp/` cd. When `scoped_wt=1` and the clause is a clause-initial bare `git … merge … <bare-main>` shape, decline; every other scoped clause takes the existing `continue` — `/tmp`-latch disposition byte-identical.
- **Cross-call cwd form:** not needed — already declined by the #1128 fence (see §2, "Already-blocked adjacent forms"). The hook reads only `tool_input.command` (L616) and is deliberately cwd-blind; no cwd plumbing is added.

### 4.2 Diff sketch (the actual clause shapes)

Shared definitions, inserted once before the driver loop (near L1359-1361, next to `scoped=0`):

```bash
scoped_wt=0     # (#1554) whether the live scoped-latch was armed by a WORKTREE cd
# (#1554) escape hatch, sibling convention guard_repo_root_pull.sh L81-112:
# honored as session env AND as an inline prefix on the command itself.
_wt_lm_allow=0
[ "${EPM_ALLOW_WORKTREE_LOCAL_MAIN_MERGE:-0}" = "1" ] && _wt_lm_allow=1
case "$cmd" in *EPM_ALLOW_WORKTREE_LOCAL_MAIN_MERGE=1*) _wt_lm_allow=1 ;; esac
# (#1554) bare-local-main merge ref tail: optional --long-flags both sides,
# optional redirect tokens after; NOT origin/main (the token before `main`
# must be whitespace/quote, and `origin/main` has `/` there).
_WT_LM_TAIL='merge( +--[A-Za-z-]+(=[^ ]*)?)* +["'"'"']?main["'"'"']?( +--[A-Za-z-]+(=[^ ]*)?| +[0-9]*[<>]+[^ ]*)*( *($|[;&|]))'
_WT_LM_ARM_A='^git +-C +([^ ]*\.claude/worktrees/[^ ]*|["'"'"']?\$(WT\b|\{WT\})[^ ]*) +(-[^ ]+( +[^ ]+)? +)*'"$_WT_LM_TAIL"
_WT_LM_ARM_B='^git +(-[^ ]+( +[^ ]+)? +)*'"$_WT_LM_TAIL"
```

Latch arming — L1426-1430 splits into per-branch bits (same two regexes, same `scoped=1`+`continue` disposition):

```bash
  if echo "$clause" | grep -qE '^cd +[^;&|]*\.claude/worktrees/'; then
    scoped=1; scoped_wt=1
    continue
  elif echo "$clause" | grep -qE '^cd +/tmp/'; then
    scoped=1; scoped_wt=0
    continue
  fi
```

Latch reset — L1383-1385 gains `scoped_wt=0` beside `scoped=0`; the `$WT` cd-latch at L1480-1483 gains `scoped_wt=1` beside `scoped=1`.

Arm B — L1486 (`[ "$scoped" -eq 1 ] && continue`) becomes:

```bash
  if [ "$scoped" -eq 1 ]; then
    # (#1554) a worktree-scoped clause merging the LOCAL main branch is the
    # #1530 contamination class (stale/unpushed root-main commits import into
    # the branch). origin/main + raw-sha merges pass; /tmp latches untouched.

      break
    fi

  fi
```

Arm A — new block between L1486 and the L1489 `-C` waiver:

```bash

  # ^-anchored per the #1443 convention: quoted latch/verb vocabulary

    break
  fi

  # `git -C <path>` scopes ONLY this clause (per-invocation) — allow it.   [existing L1489]
```

## 11. Decision Rationale

- **D1 — Placement: driver-loop arms, not `classify_clause`.** What: Arm A between L1486 and the L1489 `-C` waiver; Arm B at the L1486 scoped-continue. Why: `classify_clause` (L1667) is never reached for `-C`/scoped clauses — the waivers `continue` first; the block must intercept the two allow points themselves. Source: hook L1486/L1489/L1667 (read this session); #1530 D6. Alternatives: weakening the `-C` waiver to re-route these shapes into `classify_clause` (wider blast radius — the waiver serves every fenced verb); a separate sibling hook (duplicates the splitter/masker/latch machinery for two regexes).
