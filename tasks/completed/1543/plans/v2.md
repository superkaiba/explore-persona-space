## 2. Method delta

Current rule text (requirement (3), `artifact-reuse.md:223-234`) prescribes one probe of "the artifact's ENTRY file" — singular, per plan. Delta: (a) multiplicity made explicit — the probe matrix is the set of (family, consumer) pairs actually read, NOT families + consumers additively; (b) both terms defined ("reused source-family" = distinct reused artifact group staged through its own source path/prefix; "staged consumer" = distinct consumer entry-point open/init reading a staged tree, INCLUDING a later phase re-reading it); (c) one strengthening clarification grounded in #1481's second crash: the probe must go through the SAME staging helper the production phase uses for that pair (a probe through a *different* real helper — per-file `stage_hub_file` when production mirrors via `stage_hub_prefix` — validated nothing); (d) the leg-(iv) N/A escape scoped per pair. Nothing else in (h) changes.
