## Goal + acceptance criteria

Goal (task body): Replace the remembered single-flight probe-placement rule with a mechanical self-pid-excluding probe.

Acceptance criteria:

1. `uv run python scripts/step9c_baseline.py probe --pattern '<extended regex>'` scans `/proc/*/cmdline` (space-joined argv, `re.search`) and prints one `pid<TAB>args` line per FOREIGN match, excluding exactly: (a) its own pid, and (b) its full ancestor chain (walk `/proc/<pid>/status` PPid to pid 1). NO other exclusion classes (v1's sibling-probe-instance content test is dropped: it excluded a live gate's own folded probe-then-launch wrapper — a false-CLEAR direction; a transient concurrent foreign probe now reads as a loud, self-resolving false-LIVE, the fail-safe direction). Exit codes: `0` = clear (no foreign match — safe to launch), `3` = ≥1 live foreign match (lines printed), `2` = usage / bad regex. Exit semantics are DELIBERATELY inverted vs pgrep (0 = clear) so `probe && launch` composes naturally; the docstring exit-code table documents this (consistent with the file's existing status-code convention, 0 fresh / 2 invalid / 3 stale).
2. `--issue N` sugar derives the Step 9c gate pattern `step9c-junit-issue-<N>\.xml` internally (so the probe's own argv never contains the junit filename). `--pattern` and `--issue` are mutually exclusive; exactly one required. Until-loop compositions use the `--issue` form ONLY (fixed, valid regex — an exit-2 inside an until-loop would otherwise wait forever); `--pattern` compositions are `&&`-form. Documented in the docstring and the SKILL.md snippets.
3. Self-match unreproducible: invoked from a compound Bash call whose own command text contains the literal unbracketed junit path (the #1742 shape), the probe returns CLEAR (exit 0) when no foreign gate is live.
4. Genuine detection intact: a live background process (non-ancestor) whose argv carries the pattern IS reported (exit 3, line printed) — including a gate launched as a folded probe-then-launch compound whose enclosing shell argv carries the artifact path (detectable precisely because the sibling-probe exclusion is dropped).
5. The SKILL.md `Single-flight probe (#1606)` sites prescribe the helper as the probe command (the separate-FOREGROUND-call preference stays as defense-in-depth prose, no longer load-bearing); `tests/test_issue_skill_gate_single_flight.py` is updated in the same diff to pin the helper invocations per site.
