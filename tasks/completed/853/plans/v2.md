## 1. Goal + requirement + acceptance criteria

**Goal:** document the script-mode `scripts.*` import trap in `.claude/rules/gotchas.md` (the codebase-generic on-demand surface that loads for anyone touching `src/explore_persona_space/experiments/**` / train / eval / orchestrate code), consistent with the already-persisted experiment-implementer agent memory, plus a short reviewer-side pointer in `code-reviewer.md` Step 0.6.

**The trap:** in script mode (`python /abs/path/driver.py`), `sys.path[0]` is the script's own directory — not cwd, not repo root — so a deferred `from scripts.X import ...` in a src-layout experiment driver raises `ModuleNotFoundError: No module named 'scripts'` pod-side. Both standard pre-launch checks false-pass it: a `-c`-mode import check (cwd on `sys.path`) and GPU-bound smoke carve-outs (deferred imports never execute). Cost on #823: a full GCE launch died at Phase-3 entry after ~30 min of paid work.

**Acceptance criteria (all mechanical):**
1. `.claude/rules/gotchas.md` contains one new bullet entry (exact text in §3) whose rule matches the agent memory verbatim in substance: `_ensure_repo_root_on_syspath()` guard (parents[N] + sentinel-file assert + `sys.path.insert`) before any deferred `scripts.*` import, AND script-mode import verification from a non-repo cwd.
2. `.claude/agents/code-reviewer.md` Step 0.6 carries the deferred-imports pointer (§3), framed as a substantive-finding check — NOT a new FAIL blocker tag (no reviewer-contract change).
3. `uv run python scripts/workflow_lint.py` (no-flags default run, which bundles `--check-asks` + `--check-lessons-index`) passes.
4. No other file changed; no experiment code, `configs/`, or `tasks/` touched.

```markdown
- **Script mode puts the SCRIPT's dir on `sys.path[0]` — a deferred `from scripts.X import ...` in a src-layout experiment driver crashes pod-side with `ModuleNotFoundError: No module named 'scripts'`.** In script mode (`python /abs/path/driver.py`), `sys.path[0]` is the script's own directory — NOT cwd and NOT the repo root — so the repo root is not on `sys.path` and `import scripts.*` fails from any driver under `src/explore_persona_space/experiments/**` (`scripts/` IS a package — `scripts/__init__.py` exists — but package-ness is irrelevant when its parent dir is off the path). RULE: guard every deferred `scripts.*` import with an `_ensure_repo_root_on_syspath()` helper called immediately before the import — derive repo root via `pathlib.Path(__file__).resolve().parents[N]` (N matched to the file's actual tree depth), assert a sentinel file exists (e.g. `scripts/<imported_module>.py`) so a wrong N fails loud, `sys.path.insert(0, ...)` if absent (idempotent) — AND verify imports in SCRIPT MODE from a NON-repo cwd (`cd /tmp && uv run python /abs/path/driver.py --smoke ...`), never `-c` mode alone. Worked example: `_ensure_repo_root_on_syspath()` in `src/explore_persona_space/experiments/issue_823/run_823.py` (commit `14234c9112`). (Incident #823 Phase-3, 2026-07-02: `run_823.py`'s deferred `from scripts.issue779_collect import ...` killed a full GCE launch at Phase-3 entry after ~30 min of paid work; the `-c`-mode import check had passed.) Reviewer-side check: `.claude/agents/code-reviewer.md` Step 0.6; implementer memory: `.claude/agent-memory/experiment-implementer/feedback_script_mode_syspath_scripts_imports.md`.
```
