## 1. Goal + hypothesis

**Goal (canonical, from frontmatter):** Test whether the geometric predictors (cosine, Gaussian-KL@L22) carry rank-information about on-policy marker emission inside narrow base-prior bands of the 416-cell ep1 panel from #532, by computing Spearman ρ between each geometric predictor and the leakage residual after the base prior is regressed out per-bystander.

#532's headline rests on an *aggregated* 6-regression CV hierarchy (ΔR² prior-beyond-flag = +0.172, geometry-beyond-flag-plus-prior = +0.014, both read from `eval_results/issue_532/analysis.json::six_regression_hierarchy`). The aggregate cannot say whether the +0.014 lives in one cohort or is spread thin. This task computes the per-cohort residual ρ that resolves it.

**Hypotheses (estimates + CIs; not pre-registered gates):**

- **H1:** on the cross-context ordinary cohort (240 cells; base prior ≡ 0 there), the geometric predictors retain rank information: |ρ| ≥ 0.15 with the expected sign (cosine +, Gaussian-KL −, JS-v1 −; signs pre-stated from #532's union table: cosine +0.224, gauss_kl −0.264, js_v1 −0.350, and ordinary-only cosine +0.570 / gauss_kl −0.620).
- **H2:** on the instructed strip (160 cells), the geometry-on-residual ρ is near-null: |ρ| < 0.10 (consistent with #532's raw instructed-only reads: cosine +0.091, gauss_kl −0.019, js_v1 −0.170).

**Falsification shape:** near-null residual ρ in BOTH cohorts strengthens #532's headline to "geometry tracks the cohort flag and nothing else"; non-trivial residual ρ in the ordinary cohort (replicating the #502 −0.79-line finding in this DV) localizes the +0.014 as a per-cohort effect.

## 3. Method delta (vs #532's aggregate hierarchy)

#532 fit pooled CV regressions over all 416 cells with the cohort flag z-scored in as a covariate, and reported ΔCV R² — a variance-decomposition aggregate. This task changes ONE thing: the unit of analysis becomes the **within-cohort cell set**, and the statistic becomes the **Spearman ρ of geometry against the prior-residualized DV inside each cohort**. Everything else is inherited unchanged: same panel, same DV (in-R emission rate), same predictors (same matrices, byte-identical inputs), same rate-space linear-OLS functional form for the prior adjustment that the hierarchy used, same seed-42 permutation/bootstrap machinery (ported from the parent script). No new measurement, no new data.

Two deliberate clarifications the parent left implicit, resolved here and carried into §11:

1. **"Cross-class ordinary subset" := off-diagonal ordinary cells (source ≠ bystander), n = 240** — matching #502's 240-ordered-pair panel and #532 plan §6.3's "240 ordered pairs" line-fit set. The class-letter-cross subset (class(source) ≠ class(bystander), n = 180) is reported as an exploratory slice, not the primary cohort.
2. **"Regressed out per-bystander" := pooled within-cohort OLS of the cell-level DV on the per-bystander base-prior scalar** (the prior is a bystander-level quantity broadcast over sources). A stricter bystander-fixed-effects variant (demean by bystander; absorbs ALL bystander-level structure including the prior and the flag) is run as a named secondary estimand, because per-bystander OLS on a within-bystander-constant regressor degenerates to demeaning anyway, and the FE read answers the cleanest residual question: "within a fixed context, does geometry rank the 16 sources?"

### 4.2 New code (the only thing built)

**`scripts/issue539_residual_per_cohort.py`** — single CPU entrypoint, self-contained (vendors the four parent functions; the parent script never landed on `main`, so importing it is not an option — see §12 A8).

```
main(args):
  panel = build_panel(args.in_dir)            # long-format dict of np arrays, n=416
  step0_consistency_checks(panel)             # reproduce 3 parent numbers, fail loud on mismatch
  cohorts = {
    "ordinary_cross":  (kind=="ordinary")  & (source_cid != bystander_label),   # n=240
    "instructed_strip": kind=="instructed",                                     # n=160
  }
  for cohort_name, mask in cohorts:
    resid = residualize(y=emit_rate[mask], x=base_prior[mask])     # rate-space OLS;
            # zero-variance x (ordinary: prior≡0) -> resid = y - mean(y); flag "noop": true
    fe_resid = emit_rate[mask] - bystander_mean(emit_rate[mask])   # secondary FE estimand
    for pk in ["cosine", "gauss_kl", "js_v1"]:                     # js_v1 exploratory-only
      block[pk] = {
        rho_raw, rho_resid, rho_fe,                                # Spearman
        # --- source-main-effect (dose-confound) diagnostics, round-1 Must-Fix ---
        rho_twoway,        # Spearman of two-way-FE residuals: BOTH the DV and the
                           # geometry column residualized on source + bystander fixed
                           # effects (y - src_mean - byst_mean + grand_mean, same for
                           # geometry), within cohort. Removes source main effects
                           # (dose) AND bystander main effects; what survives is
                           # pair-specific affinity.
        rho_partial_source_dose,  # partial Spearman of geometry vs DV controlling the
                           # source-marginal emission covariate (source's mean DV over
                           # the cohort, broadcast to its cells; rank-based partial).
        ci95_resid (percentile bootstrap, 10_000, seed 42),
        p_perm_resid (permute resid across cells, 10_000, seed 42, two-sided,
                      p = (1 + #{|rho_perm| >= |rho_obs|}) / (n_perm + 1)),
        ci95_cluster_bystander, ci95_cluster_source (2_000 reps each,
                      resample clusters w/ replacement, re-residualize per resample),
        tie_diagnostics: {n, n_zero_dv, n_unique_dv,
                          rho_binarized (DV>0), rho_nonzero_subset},
      }
    # Direct source-level dose-confound read (once per cohort, per predictor):
    source_marginal[pk] = spearman(row_mean(geometry[pk]) over cohort bystanders,
                                   row_mean(emit_rate) over cohort bystanders)  # n=16
    # Between-cohort contrast (free, supports the localization claim):
    delta_rho[pk] = rho_resid[ordinary_cross] - rho_resid[instructed_strip]
                    with a 10_000-rep percentile bootstrap CI (resample cells within
                    each cohort independently per rep)
    # Degenerate-resample policy (all bootstraps + forest): a resample/row whose DV or
    # predictor is constant has undefined Spearman -> DROP that resample and COUNT it
    # (n_degenerate_resamples in the JSON; forest rows with constant DV reported as
    # null + counted, never silently nanmean'd).
  holm_adjust over the 4 primary tests ({cosine, gauss_kl} x {2 cohorts}) on p_perm_resid
  robustness:
    nonstylized (drop sources A3,A4,A5 — #532's drop-source-rows convention, n=195 ordinary-cross / 130 instructed)
    nonstylized_strict (#502's both-sides convention: drop pairs touching A3/A4/A5 on
                 EITHER side; ordinary-cross n=156 — one extra line, catches stylized-
                 BYSTANDER leverage the source-rows drop misses)
    class_letter_cross (class(src)!=class(byst) ordinary subset, n=180)
    dvB_ordinary: rho(geometry, extra_marker_logp) on ordinary_cross only
                  (graded, tie-free; clean there because in-R emission is rare —
                   EXCLUDED on instructed cells where it measures doubling probability)
    collinearity_gate: Pearson(pk, base_prior) within instructed strip
                  (measured at plan time: cosine +0.008, js −0.013, gkl +0.013 → passes)
  write eval_results/issue_539/residual_per_cohort.json  (incl. metadata: git commit,
        seed, n_perm, n_boot, parent-SHA provenance, noop flags)
  make_figures(...) -> figures/issue_539/   (PNG+PDF+meta.json via paper_plots rcParams)
```

### 6.2 Statistics

Per (predictor × cohort), all on the residualized DV with raw alongside:

1. Spearman ρ (point estimate) — primary family = {cosine, Gaussian-KL@L22} × {2 cohorts} = 4 tests. JS-v1 is computed and reported but exploratory (deprecated estimator; #532's claims did not rest on it).
2. 95% percentile bootstrap CI, 10,000 reps, seed 42 (cell-level), plus bystander-cluster and source-cluster bootstrap CIs (2,000 reps each, re-residualizing within each resample).
3. Permutation p, 10,000 reps, seed 42, two-sided, `p = (1 + #{|ρ_perm| ≥ |ρ_obs|})/(n_perm + 1)`.
4. Holm-Bonferroni adjustment across the 4 primary tests; raw and adjusted p both reported.
5. Residualization audit per cohort: slope, intercept, fit R², `noop` flag (ordinary cohort: `noop: true` because base prior ≡ 0.0 across all 16 ordinary bystanders — Spearman on the residual equals Spearman on the raw DV there, and the JSON says so explicitly).
6. Source main-effect diagnostics (secondary, NOT in the Holm family): `rho_twoway` (two-way source+bystander FE residual ρ, both DV and geometry demeaned), `rho_partial_source_dose` (rank-based partial ρ controlling the source-marginal emission covariate), and `source_marginal` (n=16 Spearman of row-mean geometry vs row-mean emission — the direct dose-confound read). If the pooled ρ is large but `rho_twoway` collapses while `source_marginal` is large, the headline is a dose story, not pair-specific affinity — the analyzer reads all three together.
7. Between-cohort contrast: `delta_rho` = ρ_resid(ordinary_cross) − ρ_resid(instructed_strip) per primary predictor, 10,000-rep bootstrap CI (independent within-cohort resampling per rep) — the localization claim as a measured quantity.
8. Degenerate-resample policy: bootstrap/forest resamples with constant DV or predictor are dropped AND counted (`n_degenerate_resamples` per block; forest rows with constant DV reported null + counted). No silent NaN propagation.

No pass/fail gates: estimates + CIs ship; the analyzer assigns confidence against H1/H2.

## 9. Stratification / power notes

Using the Spearman SE heuristic SE_z ≈ √(1.06/(n−3)) (Bonett & Wright 2000), two-sided α = 0.05, 80% power ⇒ detectable |ρ| ≈ 2.80 · SE_z:

| Cohort | n | SE_z | 80%-power detectable \|ρ\| | Power at ρ = 0.15 |
|---|---|---|---|---|
| Cross-context ordinary | 240 | 0.0669 | ≈ 0.19 | ≈ 0.62 |
| Instructed strip | 160 | 0.0822 | ≈ 0.23 | ≈ 0.45 |
| Per-bystander (forest, exploratory) | 16 | 0.286 | ≈ 0.66 | — (exploratory only) |

So H1's 0.15 threshold sits below the 80%-power point on both cohorts — and tie-inflation pushes effective power lower still on the ordinary cohort. This is exactly why the design reports estimates + CIs rather than gates: a CI of e.g. [−0.02, +0.24] is the honest deliverable at this n, and the per-bystander forest is explicitly exploratory. No descope dimensions exist (the n is fixed by the parent panel).

## 11. Decision Rationale

- **D1 — Residualization functional form: linear OLS in emission-rate space.**
  Why: matches the parent hierarchy exactly (`_six_regression_hierarchy` z-scores predictors and fits linear OLS on the rate-space DV), keeping this task a single-variable refinement. Source: #532 (`analysis.json::six_regression_hierarchy`, script lines 1999-2052 at `296c4da2d`). Alternatives: logit-space rejected (DV contains exact 0s and 1s — 205 zeros / 55 ones panel-wide, fact-checker recount; 185 of those zeros are the off-diagonal-ordinary cells — so logit needs arbitrary clipping the parent never used); rank-on-rank (partial Spearman) kept as a robustness read, not primary.
- **D2 — Cohort definition: off-diagonal ordinary, n=240.**
  Why: "cross-class" in this lineage means source ≠ bystander — #502's headline panel is literally "240 ordered pairs (full16, 16 × 15 minus diagonal)" and #532 plan §6.3 fit its ordinary line on "240 ordered pairs". Diagonal cells are the implant (mean emission 0.896, cosine=1.0), not leakage. Source: #502 body (Parameters: "n per panel"); #532 plan §6.3. Alternative: class-letter-cross (n=180) — kept as exploratory slice since the term is ambiguous.
- **D3 — Correlation statistic: Spearman ρ.**
  Why: the lineage's standard (every #404/#458/#502/#532 leaderboard number is Spearman); rank-based, monotone-invariant, right for a bounded zero-inflated DV. Source: #532/#502. Alternative: Pearson rejected (rate DV bounded + zero-inflated); Kendall τ rejected (no precedent in the lineage; would break comparability).
- **D4 — Permutation reps 10,000, seed 42.**
  Why: parent used 1,000 reps/seed 42; at p-resolution 1e-3 a Holm-adjusted threshold of 0.0125 is poorly resolved. 10,000 reps costs seconds and gives 1e-4 resolution. Source: #532 (`_signflip_permutation_test`, n_perm=1000, seed=42) — deliberately increased, justification stated; estimand unchanged.
- **D5 — Bootstrap: percentile, 10,000 reps cell-level + 2,000-rep cluster variants.**
  Why: percentile bootstrap is the parent's CI method (`_bootstrap_spearman_ci`); cluster variants added because cells share bystanders (10-16 clusters) and sources (16 clusters) — naive resampling understates CI width under cluster dependence (standard cluster-bootstrap practice). Source: #532 for the primary; standard practice (cluster bootstrap, e.g. Cameron & Miller 2015 survey) for the robustness. Alternative: BCa rejected (no parent precedent; percentile is what #532 shipped).
- **D6 — Multiple comparisons: Holm-Bonferroni over 4 primary tests.**
  Why: 2 headline predictors × 2 cohorts is a small closed family; Holm is uniformly more powerful than Bonferroni with no independence assumptions. Source: Holm (1979), standard practice; #532 reported uncorrected p (smaller family), so both raw and adjusted are reported for continuity. Alternative: BH-FDR rejected (confirmatory family of 4, not a screening problem).
- **D7 — JS-v1 demoted to exploratory.**
  Why: the estimator is DEPRECATED (single-next-token; #532 §6.1 carried it only for leaderboard back-compat and its claims did not rest on it). Source: #532 plan §6.1 + body Parameters table. Alternative: including it in the Holm family rejected — it would spend α on a predictor the program has already deprecated.
- **D8 — Secondary FE estimand (bystander demeaning).**
  Why: the Goal's "per-bystander" wording admits two readings (§3 item 2); FE is the strict one and is well-powered for geometry (within-bystander geometry variation exceeds between: gauss_kl within-byst sd ≈ 691 vs between ≈ 121, measured from `predictors.json`). Source: ungrounded in the lineage — standard fixed-effects logic; labeled secondary, no headline rests on it.
- **D10 — Source main-effect (dose-confound) diagnostics (round-1 Must-Fix, both Alternatives critics).**
  Why: a positive within-cohort ρ can be produced by source MARGINAL structure alone — adapters that leak more everywhere also sitting globally closer/farther — with zero pair-specific (source × bystander) affinity information; none of the bystander-side controls touch it (bystander-FE passes source main effects through; the forest cannot split main effect from interaction; cluster bootstraps fix CI width, not the estimand). Fix: `rho_twoway` (residualize BOTH the DV and the geometry column on source + bystander fixed effects, then Spearman the residuals), `rho_partial_source_dose` (rank-based partial controlling source-marginal emission), and `source_marginal` (the direct n=16 confound read). Source: round-1 Alternatives critique (Claude + Codex agreeing Must-Fix); two-way FE demeaning is standard panel practice (within-estimator). All three are secondary diagnostics outside the Holm family; the analyzer reads them jointly with the pooled ρ.
- **D11 — Between-cohort Δρ contrast with bootstrap CI.**
  Why: the falsification shape is a between-cohort comparison; making Δρ a measured quantity with a CI (rather than two side-by-side point estimates) is what licenses "concentrated in one cohort" language. Source: round-1 Statistics critique (Claude, concern bullet); standard bootstrap-contrast practice.
- **D9 — Collinearity gate (pre-registered, already evaluated).**
  Why: residualizing on a covariate correlated with the predictor strips predictor variance and biases ρ toward 0. Measured at plan time from committed data: Pearson(geometry, prior) within the instructed strip = +0.008 (cosine), −0.013 (js_v1), +0.013 (gauss_kl) → no collinearity concern; recorded in the output JSON for the record. Source: project memory pattern (collinearity gate for partial-correlation designs); values read from `predictors.json`.
- **Model id:** no model is loaded; N/A — no repo-new model id, no config-load smoke needed.
