**Field practice (bounded check, 1 search):** the rule family is established. Google Testing Blog: "Don't Overuse Mocks" (2013) — mocked tests pass only while mocks match the real implementations, and they drift; "Increase Test Fidelity By Avoiding Mocks" (2024) — prefer real implementations, fake only at boundaries; "Don't Mock Types You Don't Own" (2020). Python's standard mitigation for mock-signature drift is `unittest.mock.create_autospec` / `autospec=True` (stdlib docs recommend autospeccing precisely because a bare Mock accepts any signature). This is the classical/"Detroit"-school position (Fowler, "Mocks Aren't Stubs") against over-mockist testing; a 2026 empirical study (arXiv 2602.00409) finds coding agents specifically over-generate mocked tests — the exact failure mode #906 exhibited.
