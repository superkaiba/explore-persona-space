## 4. Deliverables

**D1 — producer-side ceiling assert (`scripts/issue1491_ladder_fits.py`).**
Add module constants `CEILING_EXPECTED_N = 1000` and
`EXPECTED_SPLIT_N = {"train_25k": 25000, "val_400": 400, "test_1000": 1000,
"wc_test_1k": 999}` (comment citing §3 grounding + the incident).
`_reliability_ceiling` gains `expected_n: int = CEILING_EXPECTED_N`; after
streaming both draws it raises `RuntimeError` naming `len(ci_a)`, `len(ci_b)`,
`n_pairs`, `expected_n`, and both HF prefixes whenever ANY of the three counts
!= `expected_n`. The current L424-425 zero-pair early return
(`available=False, "no matching ci"`) is subsumed by the raise — zero overlap
between two full draws is corruption, not absence. The ABSENCE path
(`FileNotFoundError` / `EntryNotFoundError` / HTTP-404 →
`available=False, reason="ceiling captures not on HF"`) is UNCHANGED — the
designed "Unit 2 hasn't run this scale yet" semantics; a PARTIAL upload (some
chunks present) now raises instead of computing a wrong ceiling.

**D2 — split-count assert propagation (`_assemble_scale_layer`, same file).**
Gains `expected_split_n: dict[str, int] | None = EXPECTED_SPLIT_N`; after the
stream loop, raise `RuntimeError` on any split whose realized n != expected
(naming split, realized, expected). `None` is the explicit opt-out for a
future deliberately-different-size reuse. This closes the same crash class for
the four ladder splits — the incident's shard-death shape applies to any split,
and `wc_test_1k` feeds `_wc_transfer` (the second `available: True` site).
