# Plan v2 — #1893 workflow-fix: fleet-wide pod code-sync pulls origin main over live issue-branch workloads

Revision of v1 folding in the Methodology critic's Must-Fix (sibling pull sites) + suggestions. Delta vs v1: scope widened from `sync_pods.sh` alone to ALL THREE fleet git-mutation entry points (`sync_pods.sh`, `sync_env.sh`, `fleet_health.py --fix`); garbage-pid handling flipped to skip-on-doubt; TOCTOU residual documented; deleted-origin-branch functional case + `bash -s <` producer pin added.

## Goal / Requirement

Make every fleet-wide pod git-mutation path live-run-safe:

1. **Live-workload skip:** a pod with a live registered workload (any `/workspace/logs/issue-*.pid` whose pid is alive — or whose content is non-empty but unparseable, skip-on-doubt) is SKIPPED with a loud `SYNC-SKIPPED (live workload ...)` line — no git operation (and for `sync env`, no `uv sync` either: mutating `.venv` under a running python process is the same hazard class) ever runs under a possibly-live job.
2. **Branch-aware pull:** a synced pod pulls `origin <its-own-checked-out-branch>` — never an unconditional `origin main` — so an issue-branch clone can never transiently lose issue-branch-only files (the #1776 mid-run ENOENT race). Detached HEAD ⇒ loud skip.
3. **Fleet pull-site enumeration (critic Must-Fix 1):** `grep -rn 'pull\|checkout main' scripts/*.sh scripts/pod.py scripts/fleet_health.py scripts/bootstrap_pod.sh` enumerates the fleet git-mutation sites:
   - `scripts/sync_pods.sh:34` — unguarded `origin main` pull, ALL pods → **fixed (primary)**.
   - `scripts/sync_env.sh:43-49` — identical unguarded `origin main` pull inside the env heredoc, ALL (or targeted) pods; `pod.py sync env` is in the experimenter pre-launch protocol → **fixed (same guard)**.
   - `scripts/fleet_health.py` `--fix` git legs (~lines 523-543) — `git checkout main` on any non-main pod (would strand an issue-branch pod on main content, strictly worse than the pull) + `git pull --ff-only origin main` → **fixed (guarded: git fixes skipped on live workload or non-main branch; reporting unchanged)**.
   - `scripts/bootstrap_pod.sh:225-236` — pulls the pod's own `$BRANCH` at provision time (already branch-aware, runs before any workload exists) → **out of scope, verified safe**.

### Acceptance criteria

- A pod fixture with a live pid file is skipped (no git operation runs); the skip line names the pid file + pid.
- A pid file with non-empty unparseable content ⇒ skip loudly (skip-on-doubt); an empty or dead-pid file ⇒ proceed.
- An issue-branch clone with no live workload pulls its OWN branch (`origin issue-<N>`), verified functionally in a local fixture repo; a diverging origin-`main` commit does NOT check out.
- A main-branch clone keeps today's behavior (branch-aware path pulls `origin main`).
- Detached HEAD ⇒ loud skip; deleted-origin-branch ⇒ loud FAILURE (nonzero exit), never a silent skip.
- `sync_env.sh` runs NO git pull of its own and NO `uv sync` on a live-workload pod (gated on the shared script's `SYNC-SKIPPED (live workload` output).
- `fleet_health.py --fix` performs NO `checkout main` and NO pull when the pod has a live workload OR is on a non-main branch (loud note in `fixes_applied`/`errors`-adjacent reporting); health REPORTING (branch/behind fields) unchanged.
- No unconditional `origin main` pull remains in `sync_pods.sh` / `sync_env.sh` / `pod_code_sync.sh` (pin test greps all three).

## Method delta (vs current behavior)

The pod-side pull logic moves into ONE standalone, locally-testable script `scripts/pod_code_sync.sh` (single source of the guarded pull), consumed by:
- `sync_pods.sh`: `ssh ... bash -s < "$SCRIPT_DIR/pod_code_sync.sh"` (replaces the inline remote command; existing SSH_OPTS + parallel `( … ) &` loop unchanged — the explicit stdin redirect is safe there, and `sync_env.sh:43`'s existing `bash -s <<'REMOTE_SCRIPT'` is working precedent for `bash -s` over these SSH_OPTS).
- `sync_env.sh`: per pod, FIRST run the same `ssh ... bash -s < pod_code_sync.sh` code-sync call; if its output contains `SYNC-SKIPPED (live workload` ⇒ skip the pod entirely (loud line, no env heredoc); else run the env heredoc with its pull block REMOVED (uv install + `uv sync --locked` only).
- `fleet_health.py --fix`: before the two git legs, one remote probe (same pid-glob + `kill -0` predicate as `pod_code_sync.sh`, small inline sh string) + a branch read; live workload OR branch != main ⇒ append a loud skip note and leave the clone untouched.

Kept unchanged (single-variable discipline): `git stash -q` + ff-only→rebase=merges fallback shape; parallel loop structure; log-file conventions; health-check probes/reporting.

**Documented residual (TOCTOU):** a pid file written AFTER the probe but before/during the pull still races — the window shrinks from "always" to seconds, and the branch-aware pull independently removes the main-content-checkout hazard even when the probe misses. The guard also only sees workloads honoring the `/workspace/logs/issue-*.pid` contract; ad-hoc launches without a pid file still race. Stated in the script header comment + here.

## File paths + concrete diffs

1. **NEW `scripts/pod_code_sync.sh`** — pod-side sync body (runs on the pod via `bash -s`):
   ```bash
   #!/bin/bash
   # Pod-side code sync body — piped to the pod via `ssh ... bash -s` by
   # sync_pods.sh / sync_env.sh. Env overrides for local testing:
   #   EPS_SYNC_REPO_DIR (default /workspace/explore-persona-space)
   #   EPS_SYNC_LOG_DIR  (default /workspace/logs)
   # Residual TOCTOU: a pid file written after this probe still races the
   # pull; the branch-aware pull below independently removes the
   # main-content-checkout hazard. Only workloads honoring the
   # /workspace/logs/issue-*.pid contract are seen.
   set -u
   REPO_DIR="${EPS_SYNC_REPO_DIR:-/workspace/explore-persona-space}"
   LOG_DIR="${EPS_SYNC_LOG_DIR:-/workspace/logs}"
   cd "$REPO_DIR" || { echo "SYNC-FAILED (no repo at $REPO_DIR)"; exit 1; }
   # 1. Live-workload probe: skip-on-doubt. Live pid => skip. Non-empty
   #    unparseable pid content => skip (fail-safe). Empty/dead => proceed.
   for f in "$LOG_DIR"/issue-*.pid; do
     [ -f "$f" ] || continue
     pid=$(tr -d '[:space:]' < "$f" 2>/dev/null)
     [ -n "$pid" ] || continue
     case "$pid" in
       *[!0-9]*) echo "SYNC-SKIPPED (live workload: $f unparseable pid content)"; exit 0 ;;
     esac
     if kill -0 "$pid" 2>/dev/null; then
       echo "SYNC-SKIPPED (live workload: $f pid=$pid)"; exit 0
     fi
   done
   # 2. Branch-aware pull: sync the clone's OWN branch, never bare main.
   branch=$(git rev-parse --abbrev-ref HEAD 2>/dev/null)
   if [ -z "$branch" ] || [ "$branch" = "HEAD" ]; then
     echo "SYNC-SKIPPED (detached HEAD or unresolvable branch)"; exit 0
   fi
   git stash -q 2>/dev/null
   git pull --ff-only origin "$branch" 2>/dev/null \
     || git pull --rebase=merges origin "$branch"
   ```
