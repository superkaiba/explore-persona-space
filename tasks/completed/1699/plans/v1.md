## 4. Method delta

**vs today's experiment-implementer §2b + implementer After-Implementation item 1:** the current text tells the implementer to grep changed literals AND run `--map-files`, and to declare `sweep_scope:` themselves. The delta is to make the tool's stdout the SOURCE of the reported hit list and pin `sweep_scope: selector-universe` as the fixed token whenever that path fires — the implementer no longer chooses. The plan's edits produce the SAME line shape; only the SOURCE of `<list>` and `<K>` moves (from implementer's grep to selector's stdout) and the `sweep_scope` token becomes a fixed value on that code path.

The existing `uv run ruff check . && uv run ruff format --check .` stays (per §11 constraint — it catches broader format issues on non-live-helper files).

**vs today's local union:** the delta is three literal test filenames added to the pre-commit union whenever the diff touches `scripts/*.py` or `src/**`. The current union is derived from touched-file mapping only; these three are always in the Step 9c gate but never in the local union.
