## Requirement + acceptance criteria

Add a `.claude/rules/gotchas.md` entry codifying two traps confirmed by the #1768 p0 incident (fix commit `07823360bb`, root cause confirmed):

1. **Exact duplicates survive near-dupe screening.** Sha-keyed sampling from a near-dupe-screened real corpus crashes when the screen was scoped to eval targets only (the pool is not deduped against ITSELF) — #1768 p0 died pod-side (`AssertionError: duplicate prompt shas in sample`, `issue1768_capture.py:540`) sampling 16,400 rows from the #779 n1M corpus.
2. **Frozen pinned splits carry internal duplicates.** The frozen #779 pinned val/test itself has 82 internal duplicate-sha rows (1,400 → 1,318 unique; val∩test overlap 13), so a GLOBAL sha-uniqueness postcondition quantifying over the frozen split is unsatisfiable by construction and would have re-crashed the relaunch.

- (AC1) `gotchas.md` gains ONE new bullet entry, placed immediately after the existing real-corpus streaming-filters entry (currently L314; the #1092/#1739 sibling), following the house entry format: bold headline stating the trap + the rule, incident narrative with concrete numbers, an explicit `RULE:` with numbered sub-rules, sibling cross-reference, `(Incident #1768 p0, 2026-07-28; fix 07823360bb; root cause confirmed.)` provenance tail.
