# Plan v1 — #2134: pre-dispatch staleness pass for queued tasks

## Requirement + acceptance criteria

Nothing surfaces queued/blocked infra tasks whose premises a recent commit
invalidated: blocked #1217/#1771 kept instructing a gate removed by
c20aabc59a; #1718 targeted a `scripts/workflow_lint.py` that completed
#2079 had rewritten; 11 queued tasks all touched CLAUDE.md with pairwise
merge-conflict risk. A stale dispatch burns a session before the clarifier
discovers mootness (the #1985 shape). Verified live at clarify time
(2026-08-13): `scripts/autonomous_session_watch.py` has NO task-premise
staleness pass — every existing "staleness" mechanism is SESSION-staleness.

Requirement: a bounded, ESCALATE-ONLY watcher pass that
(a) flags queued (`proposed`) and `blocked` infra/batch tasks whose
`workflow_fix_target` files were rewritten by commits newer than the task's
creation, using the body-token heuristic the task specifies (≥3 shared
informative tokens between a landed commit subject and the task title+body);
(b) flags target-file collisions — ≥2 queued tasks naming the same target
file, and recently-landed sibling tasks on the same file (parsed from the
same commit subjects);
(c) SURFACES the list (deduped push + sidecar + one per-task `epm:progress`
flag marker) — NEVER auto-archives, never mutates status, never gates or
defers dispatch; mootness is adjudicated by the spawned clarifier (which
reads the flag marker at its Step 0 context pass) or a human, per the #1918
archive-license discipline.

Acceptance:
1. Synthetic fixture: a `proposed` infra task with `workflow_fix_target:
   scripts/foo.py` and a post-creation commit on `scripts/foo.py` whose
   subject shares ≥3 informative tokens with the task body → ONE flag record
   (sidecar row + marker composed); an unrelated-subject commit → no flag.
2. Two queued tasks naming the same target file → one collision record.
3. Report-only invariant test-pinned: the pass NEVER composes a
   `set-status` / `archived` mutation and never touches the
   proposed-infra-sweep dispatch decision.
4. Kill switch, interval throttle, per-(issue, fingerprint) dedup + TTL
   re-alert, marker cap, and fail-toward-silence on unreadable inputs all
   test-pinned.
5. Watcher module docstring pass enumeration updated
   (`workflow_lint.py --check-asw-docstring-pass-count` green).

## Design decisions (autonomous; body left the fork open)

Decision 1 — placement = WATCHER PASS, not a nightly /daily/PM step,
because `/daily` was RETIRED 2026-08-06 (`.claude/rules/background-automation.md`
§ RETIRED — "No daily cron of any kind is active"), so the body's second
option has no carrier; the watcher is the surface the task's own
`workflow_fix_target` provenance names.

Decision 2 — shape = standalone ESCALATE-ONLY observer pass (the
registry-drift / triage-observer pattern), NOT a hook inside
`proposed_infra_sweep_pass`'s decide function. "Pre-dispatch" value is
delivered by the durable per-task flag marker: tasks sit queued for
hours-days while the pass runs daily, so the flag lands on events.jsonl
before dispatch, and the spawned clarifier's mandatory Step 0 context pass
reads it first thing. Gating/deferring dispatch would mutate a pure,
heavily-tested decide function and could wedge the queue on a false
positive — strictly worse than the surfaced-list contract the body asks for.

## Method delta (what differs from prior related work)

#2259 (pid-file staleness) is process-liveness; #2221 (spec-freshness sync)
is file sync; the session-staleness clocks are transcript-idle detection.
None reads TASK BODIES against NEWER COMMITS. This pass is the first
task-premise staleness reader. It reuses: the registry-drift pass's
once-daily throttle + attempt-stamp-before-collect; the triage-observer's
marker-cap + sidecar-overflow contract; the partial-bundle pass's
per-pass listing cap + persisted cursor; the #1918 rule that archive
decisions are never automated.

## Design — file paths + concrete diffs

### 1. `scripts/predispatch_staleness.py` (NEW — pure logic + CLI)

- `STOPWORDS` (small set: workflow/task/issue/daily/fix/pass/check/etc.),
  `informative_tokens(text) -> set[str]` — lowercase `[a-z0-9_]{4,}` tokens
  minus stopwords.
- `parse_targets(body_text) -> list[str]` — `workflow_fix_target:` paths
  from the body's Provenance section (comma/space-separated, repo-relative;
  unparseable → `[]`).
- `@dataclass FlagRecord`: issue, kind (`stale-premise` | `queue-collision`
  | `landed-sibling-collision`), target file, evidence (commit sha + subject
  + matched tokens, or colliding issue ids), fingerprint (sha256[:12] over
  sorted evidence).
- `scan(tasks, git_log_fn, min_tokens=3) -> list[FlagRecord]` — PURE:
  `tasks` = list of dicts (id, status, kind, created_ts, title, body);
  `git_log_fn(paths, since_ts) -> list[(sha, subject)]` injected seam.
  Signal A: flag when `len(informative_tokens(subject) &
  informative_tokens(title + body)) >= min_tokens`. Signal B: group scanned
  tasks by target file (≥2 → one collision record per file); subjects
  matching `task #<M>` / `issue[- ]<M>` name landed siblings on the file.
- `main()` — report-only CLI (`--json`), builds the task list via
  `task.py list-by-status` reads + `git log --since=<created> --format=%H %s
  -n 30 -- <paths>` (10s timeout, main repo root, read-only); for manual
  runs and the watcher smoke.

### 2. `scripts/autonomous_session_watch.py` (the `workflow_fix_target`)

- New `predispatch_staleness_pass(dry_run: bool) -> None`, wired in `main()`
  BEFORE `proposed_infra_sweep_pass` (flags land before this tick's
  dispatches; free ordering win). Daemon-INDEPENDENT (read-only).
- Throttle: `EPM_PREDISPATCH_STALENESS_INTERVAL_HOURS` (24h; attempt stamp
  saved BEFORE collecting — registry-drift pattern). Scope: REGISTRY tasks
  at `proposed` + `blocked`, kind ∈ {infra, batch}; per-pass task cap
  `EPM_PREDISPATCH_STALENESS_TASK_CAP` (40) + persisted cursor
  (partial-bundle pattern); ≤1 bounded `git log` subprocess per scanned
  task with `workflow_fix_target` paths.
- Channels: sidecar `.claude/cache/predispatch-staleness-events.jsonl`
  (every flag); ONE deduped push digest per firing tick; one `epm:progress`
  marker per flagged task per episode — sentinel
  `[autonomous_session_watch:predispatch-staleness]`, ADDED to
  `_WATCHER_NOTE_SENTINELS` (anti-liveness: never resets staleness clocks),
  note naming the evidence + the adjudication affordance ("clarifier
  adjudicates at dispatch; to archive: `task.py set-status <N> archived` —
  human/clarifier only") — capped `EPM_PREDISPATCH_STALENESS_MARKER_CAP`
  (5)/tick, overflow stays sidecar-recorded (triage-observer pattern).
- Dedup: fire-once per (issue, fingerprint) + TTL re-alert
  `EPM_PREDISPATCH_STALENESS_REALERT_HOURS` (168h). State
  `~/.eps-autonomous/predispatch-staleness.json` (issue keys pruned on
  terminal status — join the existing terminal-GC sweep if trivially
  wireable, else prune inside the pass).
- Fail toward silence: unreadable registry/body/git → skip that task with
  one stderr line; a failed `git log` never reads as "no staleness".
- ESCALATE-ONLY hard invariant: never `set-status`, never `archived`,
  never touches sweep dispatch state.
- Kill switch `EPM_DISABLE_PREDISPATCH_STALENESS=1`;
  `--predispatch-staleness-only` (with `--dry-run`: no marker/push/state
  writes) as the zero-write live smoke.
- Module docstring pass enumeration updated (lint-pinned count).

### 3. `tests/test_predispatch_staleness_pass.py` (NEW)

- Unit: `informative_tokens` / `parse_targets` shapes.
- `scan` fires on the acceptance-1 fixture; no-fire below `min_tokens`;
  collision records per acceptance-2.
- Pass wrapper: kill switch skips; interval throttle skips; dedup latch +
  TTL re-fire; marker cap overflow stays sidecar-only;
  `test_predispatch_staleness_never_mutates_status` — subprocess seam
  asserts no `set-status`/`archived` argv is EVER composed (the established
  never-mutates pin pattern); dry-run writes nothing.

### Explicitly out of scope

- Any dispatch gating/deferral in `proposed_infra_sweep_pass` or its decide
  function (Decision 2).
- Auto-archiving or any status mutation (the #1918 archive-license
  discipline; hard invariant).
- Auto-filing follow-up tasks from flags (this session runs under the
  workflow-fix recursion guard; the pass itself never files).
- Non-infra/batch kinds; `on_hold` tasks (deliberately parked, out of the
  active queue by definition).
- Cross-repo / worktree-branch commit scanning (main-root `git log` only).
