### 3.2 The new check function

Add `check_gate_ids_unique` to `scripts/workflow_lint.py`. Place it next
to the other `WorkflowYaml`-consuming checks — natural spot is right
after `check_asks` / before `check_autonomous_asks` (it is a
schema-integrity check over the same `workflow` object), or grouped with
`_check_status_label_coverage`. Either location is fine; pick whichever
reads cleanest in the file. Signature takes only the `workflow` object
(no `roots` — it does not walk the doc tree):

```python
def check_gate_ids_unique(workflow: WorkflowYaml) -> list[str]:
    """Verify every gate `id:` across gates.{inline, park_and_wait,
    conditional} is unique. The pydantic GateEntry schema validates each
    gate independently and does NOT enforce cross-list id uniqueness, so
    a renumber collision (e.g. task #694's renumber) would otherwise pass
    the lint silently. Returns a list of error strings (empty == PASS)."""
    errors: list[str] = []
    if workflow.gates is None:
        return errors
    seen: dict[int, str] = {}  # id -> first gate name that used it
    all_gates = (
        workflow.gates.inline
        + workflow.gates.park_and_wait
        + workflow.gates.conditional
    )
    for g in all_gates:
        if g.id in seen:
            errors.append(
                f"duplicate gate id {g.id}: used by both "
                f"'{seen[g.id]}' and '{g.name}' across "
                f"gates.{{inline, park_and_wait, conditional}}. Gate ids "
                f"must be globally unique; renumber one of them in "
                f".claude/workflow.yaml."
            )
        else:
            seen[g.id] = g.name
    return errors
```

Notes on the implementation:
- **Error string names BOTH gate names** for the offending id (the
  acceptance criterion). If an id collides 3+ times, each collision past
  the first emits its own line naming the first-seen name + the current
  name — acceptable (every offending pair is reported).
- **`None`-guard** on `workflow.gates` mirrors `_flatten_keys` — the
  schema allows `gates: None`, so guard it.
- Use a plain dict accumulator; no `collections.Counter` /
  `itertools` needed (keeps it dependency-free and matches the existing
  hand-rolled style).

       # Force a collision: give a park_and_wait gate the same id as an
