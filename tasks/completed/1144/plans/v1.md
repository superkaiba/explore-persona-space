2. **Unexplained fidelity residue:** a non-empty byte-identity diff on a no-advancement file that has no mechanical explanation.
3. **Regression not attributable to resolution slips:** the merged test subset fails post-port (vs the recorded baseline) in a way pointing at genuine incompatibility, after 2 mechanical-fix attempts.
4. ≥3 push-race rebase cycles that each produce NEW conflicts in port files (indicates a live concurrent rewrite of the same seam — coordinate, don't race).

## 11. Decision Rationale

`N/A — no training hyperparameters` (no model training in this task). Port-mechanism decisions instead:

- **Cumulative-diff 3-way apply, NOT sequential cherry-pick.** *Why:* (a) 3 of the 11 scope-bearing commits are mixed (artifact halves of `6bb7acdc7b`/`9f6b27eb7b`; `efbffc3c54` artifacts-only) — cherry-picking would drag stale `eval_results`/`figures` that main has since superseded (+4/−13,350 measured), forcing per-commit `-n` + path-surgery anyway; (b) `scripts/issue1090_fu3_worker.py` was modified in 7 of 11 commits — sequential picks re-resolve the same churn repeatedly, while the cumulative diff resolves final content once; (c) provenance is preserved by listing all 11 source SHAs in the port-commit message (the review unit on #1090 was the cumulative content, and the port review verifies the PORT). *Source:* measured repo state (this plan §4.2/§4.3); CLAUDE.md § Concurrent repo-root committers (detached-scratch + `push origin HEAD:main` pattern). *Alternative considered:* `git merge --squash issue-1090` in the scratch worktree — rejected: it stages the FULL branch tree including stale `.claude/**` spec-syncs and artifacts, requiring a large discard pass with regression risk; the include-pathspec apply is structurally incapable of touching excluded paths.
- **Pinned-SHA diff base (`1b9dc23dc6..2022a2a734`), not `main...issue-1090`.** *Why:* deterministic under concurrent ref movement; identical content today (merge-base verified = `1b9dc23dc6`).
- **Single port commit.** *Why:* one reviewable unit for the port code-review; trivial to rebase over push races. *Alternative:* 11 cherry-picks — rejected per above.
