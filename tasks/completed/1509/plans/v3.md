### 4.2 New module-level helpers + regexes

```python
# ─── Check 44 (#1509): footer HF artifact paths carry an adjacent pinned link ─
# The #1335 pre-fix footer shipped `issue1335_ablation_ladder/
# onpolicy_assistant_label/{raw_completions,analysis_tensors}/` as a bare
# backtick path with no HF pin anywhere in the bullet; only URL-bearing
# claims were gated (checks 8/23/30/32/40), so the verifier read PASS and
# the LM critic caught it. Pure text check — no Hub probes (pin absence is
# a body-text fact, the check-40 rationale).

# Backtick token charset EXTENDED over _BACKTICK_DIR_RE's [A-Za-z0-9_./-]
# with {},* for brace-expansion / glob forms (the #1335 `{raw_completions,
# analysis_tensors}/` and #841 `issue841_scaling/{results,...}` /
# `analysis_tensors/pass_a/*_cx.pt` shapes). Leading ./ ../ declined.
_FOOTER_HF_PATH_TOKEN_RE = re.compile(
    r"`(?P<tok>(?!\.\.?/)[A-Za-z0-9_\-./{},*]{1,160})`"
)
# HF-identity arm (b): a raw_completions / analysis_tensors path segment
# (word-bounded — matches inside braces too).
_FOOTER_HF_ARTIFACT_SEG_RE = re.compile(r"\b(?:raw_completions|analysis_tensors)\b")
# Search-form pinned-HF-URL satisfier (the anchored _HF_HUB_TREE_BLOB_URL_RE
# cannot search inside a unit). tree|resolve|blob + 7-40 hex, per the SPEC
# § "All footer URLs pinned (v4)" sanctioned forms; /tree/main never matches.
_FOOTER_HF_PIN_URL_RE = re.compile(
    r"huggingface\.co/[^\s()`]*?/(?:tree|resolve|blob)/[0-9a-fA-F]{7,40}\b",
    re.IGNORECASE,
)
# Position-ANCHORED @-rev satisfier: must begin within 4 chars of the token's
# closing backtick (`@ rev `6aab0cce1fac`` / `@ HF rev `deb7a452`` — the
# committed #1112/#1335 footer shapes). Anchoring is load-bearing: the #1335
# offending bullet carries `@ `be61a85e`` (a GitHub figures pin) EARLIER in
# the bullet, so an anywhere-in-unit @-rev (check 37's shape) would
# false-negative the motivating incident. `@ main` / `@ HEAD` are not hex
# and never satisfy.
_FOOTER_AT_REV_ADJ_RE = re.compile(
    r"[ \t]{0,4}@\s*(?:(?:HF\s+)?rev\s+)?`?[0-9a-fA-F]{7,40}\b", re.IGNORECASE
)
```

### 4.3 Adjacency unit splitter

New helper `_footer_units(footer: str) -> list[str]` — a generalization of `_footer_reused_bullets` (5727-5758) covering ALL footer content, not only `- Reused` bullets:

```python
def _footer_units(footer: str) -> list[str]:
    """Split footer text into pin-adjacency units: each `- `/`* ` bullet
    (indented AND lazy continuation lines joined) and each non-bullet
    paragraph run (the `**Repro:**` / `**Context:**` blocks). Fence-aware
    (illustrative skeletons ignored); `>`-quoted blockquote lines dropped
    (the #959 verbatim-prompt exemption — quote text is provenance, not a
    provenance link); blank lines terminate a unit."""
    units, cur, in_fence = [], None, False
    for line in footer.splitlines():
        s = line.strip()
        if s.startswith("```") or s.startswith("~~~"):
            in_fence = not in_fence
            if cur: units.append(cur); cur = None
            continue
        if in_fence or s.startswith(">"):
            continue
        if not s:
            if cur: units.append(cur); cur = None
            continue
        if re.match(r"^\s*[-*]\s", line):
            if cur: units.append(cur)
            cur = s
        elif cur is not None:
            cur += " " + s   # indented OR lazy continuation joins its unit
        else:
            cur = s
    if cur: units.append(cur)
    return units
```

Deviation from `_footer_reused_bullets` (which joins only indented continuations): lazy (non-indented) continuations also join. Rationale: a wrapped footer bullet whose pin lands on an unindented wrap line must still satisfy; the cost is a bounded false-negative residual (a pin in an immediately-following unrelated line rescuing a token — blank-line separation bounds it), the benefit is fewer false WARNs. Documented in the docstring as a stated recall/precision trade.

### 4.4 Check body (pseudocode)

```python
def check_footer_hf_paths_pinned(body: str) -> CheckResult:
    """Check 44 (WARN, v4-only, #1509): every bare backtick HF-style
    artifact path in the **Repro:**/**Context:** footer sits in a unit
    (bullet / paragraph) carrying an HF pin — a pinned
    huggingface.co /(tree|resolve|blob)/<rev> link anywhere in the unit,
    or an `@ [HF ]rev <hex>` immediately after the token. ...
    WARN, never FAIL (corpus 2026-07-18: 50 committed v4 bodies; 2 parked
    bodies (#1310, #841) carry 10 unpinned tokens — a FAIL would newly
    block their promote-time re-verify; flip severity only once the
    parked corpus clears). Body-text-only: no Hub probes, no
    EPM_VERIFY_BODY_NO_HF fence (pin absence is a text fact, cf. check 40)."""
    name = "footer HF artifact paths carry an adjacent pinned link"
    if not is_v4(body):
        return CheckResult(name, True, "skipped — not a v4 body (forward-only)")
    footer = _v4_footer_text(body)
    if footer is None:
        return CheckResult(name, True, "skipped — no **Repro:** footer found")
    # Check-40 interplay: a token check 40 already extracts (count-paren
    # claims) keeps ITS missing-pin WARN — exclude here so no claim is
    # double-WARNed (the check-30/40 G2 partition convention).
    c40_tokens = {tok for _c, _n, tok, _r in _gather_hf_unpinned_count_claims(body)}
    offenders: list[str] = []
    seen: set[str] = set()
    for unit in _footer_units(footer):
        unit_pinned = _FOOTER_HF_PIN_URL_RE.search(unit) is not None
        for m in _FOOTER_HF_PATH_TOKEN_RE.finditer(unit):
            tok = m.group("tok")
            if "/" not in tok:
                continue                          # G1: a path, not a filename
            first = tok.split("/", 1)[0]
            if not first or first in _GIT_SIDE_ROOTS:
                continue                          # G3: git/local — resolves in git
            if not (_HF_ISSUE_PREFIX_RE.match(tok)
                    or _FOOTER_HF_ARTIFACT_SEG_RE.search(tok)):
                continue                          # G2: not an HF-identity token
            if tok in c40_tokens or tok in seen:
                continue                          # G5: check-40 territory / dedup
            if unit_pinned:
                continue                          # S1: pinned HF URL in the unit
            if _FOOTER_AT_REV_ADJ_RE.match(unit, m.end() + 1):
                continue                          # S2: adjacent @-rev after token
            seen.add(tok)
            offenders.append(tok)
    if not offenders:
        return CheckResult(name, True, "all footer HF artifact paths pinned")
    shown = "; ".join(f"`{t[:120]}`" for t in offenders[:8])
    detail = (
        f"{len(offenders)} bare HF artifact path(s) in the footer carry no "
        f"adjacent pin: {shown} — add a pinned huggingface.co /tree/<rev> (or "
        "/resolve|/blob/<rev>) link in the same bullet, or `@ <rev>` "
        "immediately after the path (SPEC.md § All footer URLs pinned)"
    )
    return CheckResult(name, True, detail, is_warn=True)
```

Note on S2's offset: `re.Pattern.match(string, pos)` anchors at `pos`; `m.end()` is the index of the closing backtick captured by the token regex — the implementer verifies the exact offset (`m.end()` of the FULL match, which includes the closing backtick) against a unit-string fixture rather than trusting this pseudocode's `+ 1`.
