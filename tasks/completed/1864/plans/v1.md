## Method delta

Prominence-only restructure (prose → numbered step). No behavioral change to the gate,
its trigger set, its verdict semantics, or the canonical SKILL.md recipe. This is the
cheap-prominence fix the task body proposes; the alternative (a mechanical PreToolUse
hook on analyzer pushes) already exists partially via `guard_root_code_commit.sh`
(commit-time cert check) — the doc fix closes the *sequencing* gap (the analyzer
composing add+commit+push as ONE command line never reaches the gate before the push).
Note for the critic: `guard_root_code_commit.sh` blocks uncertified `scripts/`/`src/`
root commits mechanically, so the residual risk this edit addresses is (a) the push of
an already-certified-but-stale payload and (b) worktree-cwd analyzer rounds + non-code
payload shapes the hook does not cover, plus plain compliance ergonomics (the one-line
add+commit+push idiom invites skipping the gate; both incidents show it).
