### 4.1 New tier in `scripts/vm_disk_guard.py` (insert adjacent to tier (d), ~L763)

```python
# ─── tier (e): stale unref'd home HF-hub REVISIONS (#1377) ───────────────────

# The user home hub cache (~/.cache/huggingface/hub) is the LIVE cache for
# every VM-side huggingface_hub download; the project data repo accretes one
# cached revision per upload commit (295 revisions / 37.6G freeable on
# 2026-07-15, regrown to 88 unref'd revisions / ~20G within 5 days). Whole-repo
# age-gating (tier d) cannot help — the repo is touched daily — so this tier
# trims REVISIONS: per repo keep the newest + every ref'd revision, delete
# unref'd non-newest revisions older than the age gate.
DEFAULT_HOME_HF_CACHE = "~/.cache/huggingface"  # env EPS_VM_HOME_HF_CACHE
DEFAULT_HOME_HF_REVISION_MAX_AGE_DAYS = 7.0  # env EPS_VM_HOME_HF_REVISION_MAX_AGE_DAYS


def home_hf_cache_root() -> Path:
    """The watched home HF cache root (env ``EPS_VM_HOME_HF_CACHE``; blank -> default)."""
    raw = os.environ.get("EPS_VM_HOME_HF_CACHE", "").strip()
    return Path(raw).expanduser() if raw else Path(DEFAULT_HOME_HF_CACHE).expanduser()


def home_hf_revision_max_age_days() -> float:
    # byte-parallel to workspace_hf_cache_max_age_days(): blank/invalid/negative -> default
    ...


def clean_home_hf_stale_revisions(
    apply: bool,
    *,
    max_age_days: float | None = None,
    cache_root: Path | None = None,
    now: float | None = None,
) -> TierResult:
    res = TierResult(name="home-hf-revisions")
    try:
        if _running_pod_side():
            res.skipped = True
            res.skip_reason = "pod-side detected — tier (e) refuses"
            return res
    except OSError as exc:
        res.skipped = True; res.skip_reason = f"pod-guard probe failed: {exc}"; return res
    root = cache_root if cache_root is not None else home_hf_cache_root()
    hub = root / "hub"
    if not hub.is_dir():
        res.skipped = True; res.skip_reason = f"no hub cache at {hub}"; return res
    age_days = max_age_days if max_age_days is not None else home_hf_revision_max_age_days()
    cutoff = (time.time() if now is None else now) - age_days * 86400.0
    try:
        info = _scan_hf_cache(hub)                    # SAME seam as tier (d)
        stale_by_repo: dict[str, list] = {}
        for repo in info.repos:
            revs = list(repo.revisions)
            if len(revs) <= 1:
                continue                              # single revision == newest: always kept
            newest = max(revs, key=lambda r: r.last_modified)
            stale = [r for r in revs
                     if r is not newest and not r.refs and r.last_modified < cutoff]
            if stale:
                stale_by_repo[repo.repo_id] = stale
        hashes = [r.commit_hash for revs in stale_by_repo.values() for r in revs]
        if not hashes:
            res.detail.append(f"no unref'd revision older than {age_days:g}d "
                              f"(of {sum(...)} revisions in {len(list(info.repos))} repos)")
            return res
        strategy = info.delete_revisions(*hashes)     # cache-level API, hf_hub 0.36.2
        freed = int(strategy.expected_freed_size)
        res.total_discovered_bytes = freed
        for repo_id, revs in sorted(stale_by_repo.items()):
            approx = sum(r.size_on_disk for r in revs)
            res.detail.append(f"{repo_id}: {len(revs)} stale revision(s), ≈{_fmt_gb(approx)}")
        verb = "would trim" if not apply else "trimmed"
        res.detail.append(f"{verb} {len(hashes)} revision(s) across "
                          f"{len(stale_by_repo)} repo(s) [{_fmt_gb(freed)}]")
        if not apply:
            res.bytes_freed = freed                   # dry-run: report, execute NOTHING
            return res
        strategy.execute()
        res.bytes_freed = freed
        append_disk_guard_event(
            {"kind": "home-hf-revisions-trimmed",
             "repos": {rid: len(revs) for rid, revs in stale_by_repo.items()},
             "bytes": freed, "max_age_days": age_days},
            apply=apply,
        )
    except Exception as exc:  # deliberate degrade — never crash the guard pass
        res.skipped = True
        res.skip_reason = f"{type(exc).__name__}: {exc}"[:200]
        res.detail.append(f"home hf-revisions tier skipped: {res.skip_reason}")
    return res
```

Note the execute-failure ordering mirrors tier (d): `res.bytes_freed = freed` is set only AFTER `strategy.execute()` succeeds, so an execute-raise leaves `bytes_freed == 0`.

## 11. Decision Rationale

- **Age gate = 7 d.** What: unref'd-revision staleness cutoff. Why: long enough to protect in-flight downloads and same-week sha-pinned reads; short enough to bound the pool (~20 G accrues in ≤5.5 d, §12). Source: the 2026-07-15 validated manual run recorded in the task body (freed 37.6 G at exactly 7 d) + tier (d)'s precedent of env-tunable age gates. Alternatives: 14 d (tier (d)'s value — doubles the steady-state pool to ~40-50 G on a 485 GB disk, rejected); 1 d (races in-flight/sha-pinned reads, rejected).
- **Keep newest + every ref'd revision.** What: the never-delete set. Why: `refs` (e.g. `main`) is what `hf_hub_download(revision="main")` resolves; the newest revision is the hot path even when refs lag. Source: `huggingface_hub` cache-manager semantics (verified on installed 0.36.2: `CachedRevisionInfo.refs`, `HFCacheInfo.delete_revisions`) + the validated reference run + task-body invariant (verbatim: "Never delete the newest revision or any ref'd revision").
- **Env naming `EPS_VM_HOME_HF_CACHE` / `EPS_VM_HOME_HF_REVISION_MAX_AGE_DAYS`.** Source: tier (d)'s `EPS_VM_WORKSPACE_HF_CACHE*` pattern (task-body naming, kept verbatim). Divergence from the candidate diff sketch: the root env points at the CACHE root (`~/.cache/huggingface`) with `hub/` appended by the function — mirrors tier (d)'s root convention exactly rather than the sketch's `/hub`-inclusive default (the sketch is explicitly "refine in planning").
- **Registration behind `reclaim_tiers and tmp_root is not None`, threshold-triggered.** Source: tier (d)'s #911 hermeticity contract (`run_guard` docstring L861-864) + the pinned hermeticity test; rationale in §4.2. Alternative (run every pass regardless of threshold) rejected: breaks the shared `triggered` contract for zero benefit given the cron cadence.
- **Pod guard = `_running_pod_side()` only.** Source: tier (d) L708 (#803). The `ismount('/workspace')` arm guards tier (d)'s own target being a live pod volume; the home path has no mount analogue — pod-side detection is the transferable half.
- **Sidecar row kind `home-hf-revisions-trimmed`.** Source: tier (d)'s `workspace-hf-cache-reaped` naming convention.
