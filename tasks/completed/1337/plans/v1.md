### 4.3 `tests/test_step9c_baseline.py`

**(a) New behavior test** (the Durability-pin target), following the existing
`_compare_env` fixture pattern (:336) and mirroring N11 (:1534) + the #1251 parametrized

```python
@pytest.mark.parametrize("fails_on_main", [True, False])
def test_compare_file_anchored_scan_node_scratch_resolved(
    tmp_path: Path, monkeypatch, capsys, fails_on_main
):
    """#1337 (R-F'): a FILE_ANCHORED_SCAN_TESTS scan node on a dirty sparse root IS
    scratch-resolved (strip-or-NEW, rc 0/1) instead of MF-4c exit 2 — the #1318 shape;
    the MF-6 masking WARN still fires on the strip."""
    node = sb.Node(
        file="tests/test_scan_anchor.py", classname="tests.test_scan_anchor", name="test_x"
    )
    monkeypatch.setattr(sb, "FILE_ANCHORED_SCAN_TESTS", frozenset({node.file}))
    argv, calls, root, _w = _compare_env(
        tmp_path,
        monkeypatch,
        junit_cases=[(node.file, node.classname, node.name, "failed")],
        ledger_kw={"failing": ()},
        glob_scan={node.file: ("scripts/issue*_*.py",)},
        touched=("scripts/issue999_wip.py",),  # matches the scan glob -> MF-6 WARN
        live_dirty=("scripts/wip.py",),
        pristine_failing=(node,) if fails_on_main else (),
        extra_args=("--run-pristine",),
    )
    rc, out, _err = _run_json(argv, capsys)
    assert len(calls["scratch_created"]) == 1
    assert calls["pristine_detail"] == [(node.file, root / "scratch-fake", root)]
    if fails_on_main:
        assert rc == 0 and out["indeterminate"] is False
        assert out["stripped"] == [{**node._asdict(), "via": "pristine-scratch"}]
        assert any(
            "MASKING WARN" in w and node.file in w and "scripts/issue999_wip.py" in w
            for w in out["warns"]
        )
    else:
        assert rc == 1
        assert [n["name"] for n in out["new"]] == ["test_x"]
```

def test_file_anchored_scan_tests_live_tree_pin():
    """#1337 drift pin: every FILE_ANCHORED_SCAN_TESTS member is a live GLOB_SCAN_TESTS
    key whose source still derives its scan root from Path(__file__) and never touches
    repo_root()/task_workflow — the source-verified basis of R-F' scratch eligibility."""

## 11. Decision rationale

- **Design fork — (a) hand-curated frozenset vs (b) mechanical anchoring probe: choose (a).**
  **What:** `FILE_ANCHORED_SCAN_TESTS` pinned-literal frozenset in step9c_baseline.py,
  membership decided by a human reading the test source. **Why:** a mechanical grep-probe
  classifies TOKENS, not the dataflow from anchor to scan — it false-positives on a file
  that mentions both idioms (e.g. a future `repo_root()`-based helper added for a
  different test in the same file, or a scan chain refactored into an imported helper the
  probe cannot see), and a false positive here silently converts a wrong verdict into a
  green gate (the worst failure direction for a merge gate). A hand allowlist is
  fail-closed by construction — new scan tests default to refusal (the safe drift
  direction; cost is one opt-in edit after verification) — and matches the module
  family's established curation style (pinned literal + live-tree drift pin:
  `GLOB_SCAN_TESTS`/`SLOW_TESTS`/`WORKFLOW_INVARIANT`,
  `tests/test_select_step9c_tests.py:494`). The mechanical check is retained in its
  correct polarity: as a NEGATIVE drift guard
  (`test_file_anchored_scan_tests_live_tree_pin` fails loud if an allowlisted member's
  anchor disappears or `repo_root(` appears), never as the positive eligibility decision.
  **Source:** repo evidence — step9c_baseline.py:1372/:1418, select_step9c_tests.py:238-244
  ("A pinned literal, NOT discovered — same curation rule as WORKFLOW_INVARIANT");
  incident #1318 (`/tmp/step9c-compare-issue-1318.json`,
  `/tmp/issue-1318-manual-oracle.log`). **Alternatives:** (b) rejected as the decision
  mechanism per above; a hybrid (probe-gated allowlist) collapses to (a)+drift-pin, which
  is what this plan ships.
- **Allowlist BOTH current scan tests, not only the incident-bearing one.** **What:**
  membership criterion = source-verified file-anchored scan chain (anchor derivation +
  target enumeration + per-target reads all scratch-local; no `repo_root()`/live-tree
  read), verified by reading the file — NOT "has a live incident". **Why:** the
  criterion is the safety property itself; an incident is merely one way to notice.
  `tests/test_subprocess_env_explicit.py` passes the verification with an even simpler
  chain (stdlib-only, pure glob+ast, no subprocess) — excluding it preserves the exact
  #1318 improvisation trap for the next dirty-root incident on a dispatcher file while
