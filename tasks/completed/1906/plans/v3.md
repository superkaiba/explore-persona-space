# Plan v3 — #1906: verify_plan base-predictor-vs-change-DV companion check (c44)

## Requirement (Goal)

Add a `verify_plan.py` check (`c44_change_dv_base_predictor_companion`) that
flags an experiment plan racing a **base-side predictor** (base propensity /
base log P / base rate / base judge score in a predictor-candidate roster)
against a **trained − base CHANGE DV** without (a) a registered level (or
change) **companion column** and (b) a stated **winner sign convention**
(signed ρ vs |ρ|). This mechanizes the #559/#605 pattern the Statistics
critic caught manually on #1900 round 1 (`critic-lens-reference.md`
Statistics lens item 2: the base term enters the change DV with a mechanical
≈ −1 coefficient, so per-panel DV identity can manufacture the champion
verdict — base↔level ρ +0.28/+0.19 vs base↔delta ρ −0.43/−0.54).

## Method delta (what differs from prior state)

Today the pattern is caught only by the LLM Statistics critic (it cost #1900
a round-1 Must-Fix). The delta is one new mechanical check in the
`verify_plan.py` pre-pass + its pin tests + the canonical N/A-escape
registration. No existing check covers DV-identity coupling
(fresh grep 2026-08-01: 0 hits for companion/winner-convention vocabulary in
`scripts/verify_plan.py`).

## Design decisions (recorded)

1. **Severity: WARN-only, never FAIL** — the c39/c31/c34/c43 family
   convention for conditional prose-triggered checks: the disposition is
   sometimes legitimately prose-satisfied in different words, legacy plans
   must not bounce retroactively, and the emitter's own confidence is
   low-medium on trigger precision. The LLM Statistics critic remains the
   FAIL authority; the mechanical WARN guarantees the planner + critics see
   the pattern named before round 1.
2. **Kind gating: `experiment` only, SKIP otherwise** — infra workflow-fix
   plans (this plan included) legitimately QUOTE the trigger vocabulary
   without racing predictors (the c43 precedent).
3. **Trigger = conjunction over fence-stripped text** (`strip_fences`, the
   c39 convention — fenced command/code blocks must not trigger):
   - (a) change-DV signature anywhere in the stripped plan:
     `trained\s*[-−–]\s*base` (incl. the no-space `trained−base` form) OR
     `post\s*[-−–]\s*pre` OR `(Δ|delta)\s*log\s*P` used as a DV.
   - (b) a base-side predictor RACED: a single stripped line carrying BOTH a
     base-side-quantity token (`base (behavioral )?propensity`,
     `base[- ]side (predictor|propensity)`, `base log ?P`, `base rate`,
     `base judge score`) AND a predictor-context token (`predictor`,
     `candidate`, `champion`, `race[d]?`, `incumbent`, `horse`). Grounded on
     #1900 v4 line 11 ("incumbent P7 (base behavioral propensity) raced and
     partialled") — the founding instance MUST trigger.
4. **Satisfiers (BOTH required to PASS when triggered):**
   - (i) companion registration: `companion column`, `level companion`,
     `change companion`, `graded[- ]change companion`, or
     `level[- ]DV companion` (grounded on #1900 v5 §"Registered DV-identity
     companion columns").
   - (ii) winner sign convention: `winner[- ]selection convention`,
     `sign convention`, or `signed (Spearman )?(ρ|rho)` (grounded on #1900
     v5 "Winner-selection convention (registered): the champion argmax is
     over SIGNED Spearman ρ"). Bare `\|ρ\|` is NOT a standalone satisfier
     (critic MF1: #1900 v4 — the must-WARN fixture — carries incidental
     `max-|ρ|` prose in its selection-symmetric section, and predictor-race
     plans near-universally do); `\|ρ\|` / `absolute` counts ONLY on a line
     also carrying `winner`, `convention`, `champion`, or `argmax`.
   ALL trigger + satisfier regexes compile with `re.IGNORECASE` (v5's
   anchors are capitalized — "Winner-selection convention", "SIGNED
   Spearman ρ" — a case-sensitive compile fails the v5 anchor fixture).
   Missing either satisfier → WARN naming the missing half + the #559/#605
   rationale + the escape phrase.
5. **N/A escape:** `N/A — no base-side predictor vs change DV` on its own
   line, unwrapped (no backticks/quotes), PASSes the check when triggered.
   Registered in the adversarial-planner SKILL.md Phase 1.5.0 canonical
   escape list (after the check-43 entry).
