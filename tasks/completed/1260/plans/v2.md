## 4. Design

### 4.1 New code in `scripts/verify_plan.py` (after `check_ladder_retention`, before `CHECKS`)

Section comment + constants + three helpers + the check. Pseudocode (implementer refines wording; behavior is pinned by the tests in §6):

```python
# ─── Check 34 — verbatim insert vs size-ratchet headroom ──────────────────
# A plan mandating VERBATIM prose into a workflow_lint size-ratcheted file
# (.claude/agents/*.md — check_agent_spec_size; .claude/rules/LESSONS.md —
# check_lessons_index) whose remaining headroom is smaller than the quoted
# block makes lint-passes + the plan's file-count constraint jointly
# unsatisfiable at implement time (#1230: 422 B headroom vs a 1,546 B
# verbatim paragraph for code-reviewer.md forced a documented 3rd-file
# cap-raise deviation). Grandfather caps deliberately hug live size
# (cap = measured + <=3 KB, typically ~1 KB), so ANY >~1 KB insert into a
# grandfathered spec exceeds headroom BY DESIGN — the remedy is therefore
# never "don't grow" but "budget the visible cap-raise IN THE PLAN"
# (workflow_lint.py: "a reviewed growth+cap-raise in one commit still
# passes"). WARN not FAIL: the trigger is a proximity heuristic; the
# Phase 2 critics adjudicate. infra|batch only: editing agent specs /
# LESSONS.md is workflow-fix work (calibration: all 8 recent-era corpus
# hits are kind: infra). Calibration (DEVELOPMENT-SET, measured against
# TODAY'S live sizes — historical headroom drifts): 1,837 persisted
# plan-versions scanned 2026-07-11; trigger fired on 166 versions;
# would-WARN 76 versions / 26 distinct plans (8 distinct at issue >= 1000:
# #1007 #1017 #1022 #1142 #1224 #1230 #1239 #1254 — every one a real
# plan-mandated over-headroom insert; #1119/#1138/#1254/#1230 cap-raises
# are recorded in AGENT_SPEC_SIZE_GRANDFATHER's own comments). Incident
# recall: #1230 v1 WARNs. Scope discipline: whether the budgeted cap-raise
# actually SHIPS is the code-reviewer's bound, not this check's.

_C34_PATH_RE = re.compile(
    r"(?i)(?:\.claude/)?(?:agents/[\w.-]+\.md|rules/LESSONS\.md)"
)
_C34_VERB_RE = re.compile(
    r"(?i)\b(?:insert\w*|append\w*|add(?:s|ed|ing)?|splice\w*|verbatim|paste\w*)\b"
)
_C34_WINDOW_LINES = 10  # preceding non-fenced prose lines scanned per fence
_C34_BUDGET_RE = re.compile(r"(?i)\bratchet budget:(?=[^\n]*\d)")
_C34_REPO_ROOT = Path(__file__).resolve().parent.parent  # tests monkeypatch


def _c34_lint_constants():
    """Lazy import of scripts/workflow_lint.py (540 KB module, ~345 ms
    measured) — paid ONLY when the trigger fires. Single source of truth
    for the caps; an ImportError is a real defect (both files live in
    scripts/) and propagates loud."""
    scripts_dir = str(Path(__file__).resolve().parent)
    if scripts_dir not in sys.path:
        sys.path.insert(0, scripts_dir)
    import workflow_lint
    return workflow_lint


def _c34_targets(plan: str) -> dict[str, int]:
    """{normalized rel path -> summed fenced-block UTF-8 bytes} for every
    fenced block whose preceding <=_C34_WINDOW_LINES non-fenced lines carry
    a ratcheted path AND an insertion verb. Block bytes = joined content
    lines + one trailing newline (fence delimiters excluded); the realized
    insert may differ by a separator newline or two — immaterial at the
    hundreds-of-bytes scale the check discriminates."""
    lines = plan.splitlines()
    mask = _fence_mask(lines)
    # walk fence-delimiter pairs off the mask; for each opener, collect the
    # window of up to _C34_WINDOW_LINES preceding NON-fenced lines, test
    # _C34_PATH_RE + _C34_VERB_RE on the joined window, normalize the path
    # match to ".claude/agents/<name>.md" / ".claude/rules/LESSONS.md",
    # and accumulate the block's byte size into the dict.
    ...


def _c34_headroom(rel: str, wl) -> tuple[int, int, str] | None:
    """(headroom, cap, cap_source) for a ratcheted rel path under
    _C34_REPO_ROOT; None when the live file is absent (headroom
    uncomputable — a plan may be CREATING the file). cap_source names the
    binding constant for the WARN detail."""
    p = _C34_REPO_ROOT / rel
    if not p.is_file():
        return None
    size = p.stat().st_size  # BYTES — parity with check_agent_spec_size
    if p.name == "LESSONS.md":
        return wl._LESSONS_MAX_BYTES - size, wl._LESSONS_MAX_BYTES, "_LESSONS_MAX_BYTES"
    cap = wl.AGENT_SPEC_SIZE_GRANDFATHER.get(p.name)
    if cap is not None:
        return cap - size, cap, "AGENT_SPEC_SIZE_GRANDFATHER"
    return wl.AGENT_SPEC_FAIL_BYTES - size, wl.AGENT_SPEC_FAIL_BYTES, "AGENT_SPEC_FAIL_BYTES"


def check_ratchet_headroom(plan: str, kind: str) -> CheckResult:
    cid, name = "c34_ratchet_headroom", "verbatim insert fits size-ratchet headroom"
    if kind not in ("infra", "batch"):
        return _skip(cid, name, "kind-exempt: ratcheted-file verbatim inserts are an "
                                "infra|batch (workflow-fix) shape")
    if _standalone_na_declared(plan, r"no verbatim ratcheted[- ]file insertion"):
        return _pass(cid, name, "escape declared: no verbatim ratcheted-file insertion")
    targets = _c34_targets(plan)
    if not targets:
        return _skip(cid, name, "no fenced block associated with a ratcheted-file insertion")
    for line, fenced in zip(plan.splitlines(), _fence_mask(plan.splitlines()), strict=True):
        if not fenced and _C34_BUDGET_RE.search(line):
            return _pass(cid, name, f"cap-raise budgeted ({line.strip()[:80]!r})")
    wl = _c34_lint_constants()          # lazy: only reached on trigger
    offenders, checked = [], 0
    for rel, nbytes in sorted(targets.items()):
        hr = _c34_headroom(rel, wl)
        if hr is None:
            continue                    # absent on disk: cannot compute
        checked += 1
        headroom, cap, cap_source = hr
        if nbytes > headroom:
            offenders.append((rel, nbytes, headroom, cap, cap_source))
    if not checked:
        return _skip(cid, name, "named ratcheted file(s) not present on disk — "
                                "headroom uncomputable")
    if offenders:
        return _warn(cid, name, _c34_offender_detail(offenders))
    return _pass(cid, name, f"{checked} ratcheted-file insert(s) fit remaining headroom")
```

**WARN detail (`_c34_offender_detail`) — anti-paste armored.** At most 3 offender tuples rendered as `rel: insert ≈<N> B > headroom <H> B (cap <C> [<cap_source>] − live size)`, then the incident anchor and the three remedies. The remedy sentence writes the satisfier label with **angle-bracket placeholders and NO digit after the label**: *"add one line `Ratchet budget: raise <constant>['<file>.md'] to <new cap>` (new cap = post-insert measured size plus at most the grandfather headroom bound), or trim the insert to fit, or declare `N/A — no verbatim ratcheted-file insertion` on its own line"*. The lookahead in `_C34_BUDGET_RE` (`(?=[^\n]*\d)`) requires a digit AFTER the label on the same line — the pasted detail's post-label tail carries only placeholders, so a verbatim paste cannot self-satisfy (pin test §6 item 8; the incident numbers 422/1,546 sit BEFORE the label in the detail string). The N/A phrase in the detail is backtick-wrapped (unrecognized by `_standalone_na_declared`, #1238 — same armor as every other check's detail).

## 11. Decision Rationale

N/A — no model training (no training hyperparameters in this task type). Design decisions:

1. **Threshold = the HARD constraint (grandfather cap > FAIL bytes > LESSONS max), never the soft WARN bytes.** *Why:* the incident class is lint-FAIL unsatisfiability; workflow_lint WARNs don't block commits, and using `AGENT_SPEC_WARN_BYTES` (28,000) would fire on every insert into the many specs sitting in the 28–40 KB band — pure noise. *Source:* `workflow_lint.py:8914–8936` semantics + #1230. *Alternative rejected:* dual-threshold WARN (soft band) — no incident evidence, noisy.
2. **Kind scope = infra|batch only.** *Why:* editing `.claude/agents/*.md` / LESSONS.md is definitionally workflow-fix work; all 8 recent-era corpus hits are `kind: infra` (verified per-task: #1007/#1017/#1022/#1142/#1224/#1230/#1239/#1254). Experiment plans get SKIP — zero added noise on the science path. *Source:* c31's identical scoping (`verify_plan.py:4880`) + the corpus scan. *Alternative rejected:* all-kinds — no observed experiment-kind instance of the incident class.
3. **Association heuristic: fenced block + (path AND verb) in the ≤10 preceding non-fenced lines; per-file byte SUM.** *Why:* #1230's real shape puts the path 5 lines and the insertion phrase 2 lines above the fence; K=10 covers heading+anchor prose while keeping cross-section false association low; summing handles multi-block inserts to one file. FP/FN tradeoff stated in §8. *Source:* `tasks/completed/1230/plans/v1.md:52–60` + the 1,837-plan calibration scan (2026-07-11). *Alternative rejected:* c31-style same-line ±120-char proximity — misses #1230 (path and fence on different lines), i.e. zero incident recall.
4. **Import workflow_lint constants (lazy), never re-derive.** *Why:* the grandfather dict changes every few weeks (5 cap-raises recorded in its comments since #1115); a copy WILL drift. Import measured at 345 ms — paid only when the trigger fires (rare); no circular import (workflow_lint references verify_plan only in a comment, `:5190`); tests already import workflow_lint directly, proving importability. *Source:* live measurement this session + `workflow_lint.py:8936` dict churn history. *Alternative rejected:* copied constants + drift-pin test (the `VALID_KINDS` precedent) — works for a frozen enum, wrong for a weekly-churn dict.
5. **Satisfier = labeled `Ratchet budget:` line with a post-label digit; PASS (not SKIP).** *Why:* the grandfather convention makes over-headroom growth LEGITIMATE when the cap-raise ships in the same commit — the check's purpose is to force the plan to budget it (the #1230 failure was the un-budgeted 3rd file), so a plan that names the raise must pass cleanly; the digit-lookahead + placeholder-armored detail closes the paste self-satisfaction hole (c31's proven pattern). *Source:* `workflow_lint.py:8920–8925` ("forces growth into a visible dict edit") + `test_c31_pasted_warn_detail_does_not_self_satisfy`. *Alternative rejected:* document-global `AGENT_SPEC_SIZE_GRANDFATHER` token search — self-satisfies on a pasted WARN detail (measured hazard: the token must appear in the detail as the remedy).
6. **N/A escape `N/A — no verbatim ratcheted-file insertion`, standalone-line via `_standalone_na_declared`.** *Why:* the established convention (#1238 unwrapped-declaration contract); tail regex `no verbatim ratcheted[- ]file insertion`. *Source:* `verify_plan.py:1442` + SKILL.md canonical block. *Alternative rejected:* bespoke matcher — the Supersede rule (one copy of the job).
7. **Byte measurement = UTF-8 bytes of joined content lines + 1 trailing newline, fence delimiters excluded.** *Why:* parity with workflow_lint's deliberate BYTES-not-chars counting (em dashes are multibyte, `workflow_lint.py:8865`); ±2 separator-newline imprecision disclosed — immaterial at the 100 B+ scale the check discriminates (#1230: 1,546 vs 422). *Source:* `workflow_lint.py` `read_bytes()`/`st_size` call sites. *Alternative rejected:* char counting — undercounts every em-dash-bearing paragraph (~1–3%).
8. **Missing-on-disk target → SKIP.** *Why:* a plan may CREATE the file (a new agent spec starts with 40 KB of headroom — nothing to warn about), and `--plan-file` mode must never crash off-repo. *Source:* planner judgment, pinned by §1 acceptance criterion 2 + §6 test 6 (fact-check corrected: the task body carries no enumerated test list). *Alternative rejected:* WARN-on-missing — punishes file creation, no incident basis.
