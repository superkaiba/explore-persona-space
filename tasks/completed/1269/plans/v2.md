**External pattern (light search, standard practice):** monorepo size budgets are enforced as committed **ratchets**, not fixed advisory bands — Chromium's binary-size trybot fails growth that lacks an explicit justification/budget bump; JS bundle budgets (`size-limit`, `bundlesize`) commit the budget next to the code so growth is a reviewed diff; lint-debt "quality ratchet" tools (e.g. Betterer) fail on regression and auto-tighten on improvement. The common load-bearing property: **the budget lives in the diff of the commit that consumes it**, giving enforcement locality and merge-conflict-based reconciliation of concurrent growth. That is precisely what the advisory WARN lacked.

### 4.3 Phase 3 — total-size growth ratchet (the durability mechanism)

```python
# Growth ratchet (#1269, the #986 agent-spec pattern applied to LESSONS.md):
# the constant must HUG the measured size. Growing the index requires raising
# this constant IN THE SAME DIFF (visible, reviewed, merge-conflicting for
# concurrent growers); it may never exceed _LESSONS_MAX_BYTES. Trimming the
# index requires ratcheting it DOWN (banked slack defeats the mechanism).
_LESSONS_RATCHET_BYTES = 6000        # set at land time: measured size + ~150-250
_LESSONS_RATCHET_MAX_HEADROOM_BYTES = 400
```

Three new failure modes in `check_lessons_index` (all byte-counted, strictly-greater, mirroring existing threshold semantics):
- `len(raw) > ratchet_bytes` → FAIL: *"grew past the `_LESSONS_RATCHET_BYTES` ratchet (`<size>`/`<ratchet>`); trim the index, or raise the constant in the SAME diff (deliberate budget consumption — never above the `_LESSONS_MAX_BYTES` cap)."*
- `ratchet_bytes - len(raw) > _LESSONS_RATCHET_MAX_HEADROOM_BYTES` → FAIL: banked slack / stale ratchet after a trim — ratchet down.
- `ratchet_bytes > _LESSONS_MAX_BYTES` → FAIL: config error (the ratchet can never authorize crossing the cap).

The 8,000 cap and 7,200 WARN band are **unchanged** (#869/#872, #992). The WARN band regains meaning under the ratchet: it now fires only when accumulated deliberate raises have consumed to within 800 B of the cap — the "plan a consolidation or a deliberate cap decision" signal, no longer drowned by silent drift.

Signature change (fail-closed defaults; existing test-hook convention):

### 4.4 Phase 4 — verify_plan.py check-34 coherence (small, justified scope extension)

`_c34_headroom` (verify_plan.py L5413-5424) currently computes LESSONS.md headroom as `_LESSONS_MAX_BYTES - size`. Fix (≤5 lines):

```python
if p.name == "LESSONS.md":
    ratchet = getattr(wl, "_LESSONS_RATCHET_BYTES", wl._LESSONS_MAX_BYTES)
```
