#### 4b. The sound single-walk fast path (perf; `_scan_scripts_import_guard_tree:5554`)

The widened root adds 1,086 files / 25.6 MB to the per-file AST-walk work (vs ~137 files for experiments/). Measured on this VM: widened check = 27.0 s cold, **13.3 s with the AST cache warm** (the no-flags-run condition, since the jsonl check at `:5261` parses `scripts/` first); profile attributes essentially all warm cost to the ~4 tree-walk-equivalents per file (`_scope_stmts` ≈ 44%, `_type_checking_body_ranges` ≈ 23%, the `ast.walk` function-discovery pass + per-function guard walks the rest). Only 9 of 1,086 files contain any real `scripts.*` import, so gate the expensive work on ONE presence walk — add at the top of `_scan_scripts_import_guard_tree`:

```python
    # Fast path (#1229): the scripts/ scan root is ~1,086 files of which <10
    # import scripts.* at all — detect presence with ONE full walk before
    # computing guard/TYPE_CHECKING evidence (~4 walk-equivalents). ast.walk
    # is a SUPERSET of both pruned scans (it descends nested defs, class
    # bodies, and TYPE_CHECKING bodies), so this can never skip a file the
    # full scan would flag.
    if not any(_is_scripts_import(n) for n in ast.walk(tree)):
        return []
```

Soundness argument (this is the load-bearing property): `ast.walk` visits every node in the module, a strict superset of the nodes either pruned scan visits, and `_is_scripts_import` is the SAME predicate the offender scans use — so any file with a flaggable import proceeds to the unchanged full scan. Files where the only scripts-import is in a pruned/skipped region (class body, TYPE_CHECKING body) proceed to the full scan and produce `[]` exactly as today. Behavior-preserving by construction; projected marginal cost drops to ~3–5 s (1 walk instead of ~4 for the 1,077 import-free files; measure at implementation, §6). The existing cheap-token text gate (`"scripts" not in text`, `:5541`) stays as-is — under `scripts/` nearly every file contains the substring (comments/paths), so it is weak there, but tightening it soundly against multi-alias/continuation import forms is fragile; the AST fast path is sound and sufficient. Do NOT tighten the text gate.
