## 2. Prior Work

**Web findings (grounding the mechanics):**
- tmux stores its server socket at `$TMUX_TMPDIR/tmux-UID/<name>` (falls back `/tmp`); the `tmux-UID` dir is created by tmux itself and must be 0700. A server's socket PATH is fixed at server start; `SIGUSR1` makes the server recreate the socket at that SAME path (fails if parent dirs missing). Clients using a different `TMUX_TMPDIR` cannot see sessions on the old path — reachable only via `tmux -S <path>`. Sources: [tmux(1)](https://man7.org/linux/man-pages/man1/tmux.1.html), [tmux wiki Advanced Use](https://github.com/tmux/tmux/wiki/Advanced-Use), [Revive the Tmux Sessions](https://yous.be/2015/05/08/revive-the-tmux-sessions/), [Recovering tmux when its socket was deleted](https://rubenvarela.com/guides/recovering-tmux-when-its-socket-was-deleted/).
- systemd-tmpfiles age-cleans `/tmp` by default on newer distros (10-day age) and deletes tmux sockets on long-uptime hosts — a known tmux failure class: [tmux/tmux#4640](https://github.com/tmux/tmux/issues/4640), [Ubuntu bug #2088268](https://bugs.launchpad.net/bugs/2088268), [systemd TEMPORARY_DIRECTORIES](https://systemd.io/TEMPORARY_DIRECTORIES/). An `x /tmp/tmux-*` tmpfiles.d line excludes path + contents from aging (tmpfiles.d(5): lowercase `x` excludes the subtree; `X` excludes only the path itself).
- THIS host, however, has NO age rule: `/usr/lib/tmpfiles.d/tmp.conf` is `D /tmp 1777 root root -` (boot-only), `/etc/tmpfiles.d/` contains only `screen-cleanup.conf`, and no tmpreaper/tmpwatch is installed (verified `dpkg -l`). Measured: `find /tmp -maxdepth 1 -mtime +12` returns many surviving `claude-title-*` files → **no blanket age-sweeper ran**; the Jul 16 deletion was TARGETED or one-off.
- `TMUX_TMPDIR` composes with `-L` (socket lands at `$TMUX_TMPDIR/tmux-UID/<label>`); `-S` bypasses both. `XDG_RUNTIME_DIR` (`/run/user/1001`) is tmpfs and removed by logind when the user's last session ends (unless lingering) — the same failure class we are escaping; `$HOME` is the durable choice.

### Phase B — The shim (single source of truth) + consumers

**Why this shape (migration sequence that cannot orphan the 43 live sessions):** a tmux server's socket path is fixed at server start — the two live `/tmp` servers CANNOT be moved, and the long-running Happy daemon's env cannot be edited in place. An unconditional `TMUX_TMPDIR` export today would put NEW spawns on a THIRD server in `~/.tmux-sockets` while `mygoat`, the attached interactive sessions, the daemon's spawns, and eps-program stay on `/tmp` — recreating the split-brain deliberately. Instead, every consumer sources ONE shim whose predicate is shared, so all consumers agree at all times:

**NEW `scripts/eps_tmux_env.sh`** (sourced, never executed):

```bash
#!/usr/bin/env bash
# scripts/eps_tmux_env.sh — single source of truth for the fleet's tmux socket
# directory (#1466). SOURCE this from every process that spawns or addresses a
# tmux server outside an interactive login shell (cron wrappers, the mygoat
# systemd wrapper); ~/.profile sources it for login shells.
#
# Contract:
#   * Durable default: $HOME/.tmux-sockets (persistent disk — no /tmp cleaner
#     can reach it).
#   * Legacy pin: while ANY socket file remains in /tmp/tmux-<uid> (a
#     pre-#1466 server still holding sessions), resolve /tmp so the whole
#     fleet keeps addressing ONE server. The flip to the durable dir happens
#     automatically — and coherently for every shim consumer — once /tmp
#     holds no tmux sockets: at reboot, after the legacy servers drain, or
#     if the /tmp sockets are deleted again (in which case the stranded
#     server is recovered per the runbook in
#     .claude/rules/background-automation.md).
#   * A pre-set TMUX_TMPDIR is always respected.
#   * Safe under `set -euo pipefail` and POSIX sh. EPS_TMUX_LEGACY_DIR
#     overrides the legacy base for tests.
if [ -z "${TMUX_TMPDIR:-}" ]; then
    _eps_legacy_base="${EPS_TMUX_LEGACY_DIR:-/tmp}"
    if find "${_eps_legacy_base}/tmux-$(id -u)" -maxdepth 1 -type s -print -quit 2>/dev/null | grep -q .; then
        TMUX_TMPDIR="$_eps_legacy_base"
    else
        TMUX_TMPDIR="$HOME/.tmux-sockets"
        mkdir -p -m 700 "$TMUX_TMPDIR"
    fi
    export TMUX_TMPDIR
    unset _eps_legacy_base
fi
```

Notes: `find -type s` (socket files only — a stale regular file cannot pin); the probe is filesystem-only (no `tmux ls` connect — no hang risk, no server-start side effect); the `if`-wrapped pipeline is `set -e`-safe. The any-socket predicate deliberately matches the watcher's `_live_tmux_socket_present()` semantics — INCLUDING the unreadable-dir edge: if the legacy dir exists but is unreadable, PIN `/tmp` (the watcher's OSError→True disposition); implement as an explicit `[ -d "$dir" ] && [ ! -r "$dir" ]` pre-check that pins before the `find` runs (exact parity, closing the 2>/dev/null flip divergence). Fail-coherent property: if a straggler ever creates a `/tmp` server post-flip, all shim consumers pin BACK to `/tmp` — the fleet follows one server rather than splitting (durability then resumes at the next zero-socket point; documented).

### Phase C — Defense-in-depth: tmpfiles.d exclusion (sudo leg)

`sudo -n` verified working. Create `/etc/tmpfiles.d/tmux.conf`:

```
# /etc/tmpfiles.d/tmux.conf  (#1466)
# Never age-clean tmux server socket dirs. Today's tmp.conf has no /tmp Age
# rule (boot-only 'D /tmp 1777 root root -'); this is insurance against a
```

Apply: `printf '%s\n' ... | sudo -n tee /etc/tmpfiles.d/tmux.conf`. Cheap, orthogonal; it does NOT protect against the (still-possible) non-tmpfiles deleter — that is what Phase B's durable dir is for.

## 11. Decision Rationale

- **Socket dir = `$HOME/.tmux-sockets`** (not `XDG_RUNTIME_DIR`, not another `/tmp` name). What: durable default for `TMUX_TMPDIR`. Why: `$HOME` is on the persistent disk and no repo/system sweeper roots there; `XDG_RUNTIME_DIR=/run/user/1001` is tmpfs AND removed by logind at last-session-end unless lingering — the same deletion class we are escaping; path length (~55 chars) is far under the 108-byte AF_UNIX limit. Source: tmux(1) TMUX_TMPDIR (https://man7.org/linux/man-pages/man1/tmux.1.html); systemd TEMPORARY_DIRECTORIES + logind runtime-dir semantics (https://systemd.io/TEMPORARY_DIRECTORIES/).
- **Migration = legacy-pin shim, not immediate cutover.** What: pin `/tmp` while any `/tmp/tmux-<uid>` socket exists; flip at zero-socket. Why: a tmux server's socket path is fixed at server start (SIGUSR1 recreates the SAME path), so the two live servers (43 sessions, incl. attached interactive ones and mygoat) and the long-running daemon cannot be re-homed; an immediate cutover would deterministically create a third server and re-split the fleet. The shim preserves the single-server invariant, is fail-coherent, and needs no second rollout step — the flip is automatic at reboot/drain. Source: tmux(1) + the tmux wiki Advanced Use (socket path semantics); live inventory in §2 (this host).
- **tmpfiles.d exclusion = yes (`x /tmp/tmux-*`).** What: exclude tmux socket dirs from any present/future systemd-tmpfiles aging. Why: 5 lines + one sudo call; lowercase `x` excludes path AND contents per tmpfiles.d(5); newer Ubuntu/systemd defaults age-clean `/tmp` and are a documented tmux-socket killer — insurance across upgrades even though today's config has no age rule. Source: tmpfiles.d(5); tmux/tmux#4640 (https://github.com/tmux/tmux/issues/4640); Ubuntu Launchpad #2088268 (https://bugs.launchpad.net/bugs/2088268).
- **Doc home = `background-automation.md`.** What: single documentation location. Why: the contract binds the cron/watcher layer that file owns and is already LESSONS-indexed (no index edit); `gotchas.md` is scoped to training/eval/orchestrate code traps. Source: `.claude/rules/LESSONS.md` row triggers (repo evidence).
- **Any-socket predicate (`find -maxdepth 1 -type s`), not a connect probe.** What: legacy-pin test. Why: deterministic, hang-free, side-effect-free (a `tmux ls` probe can hang on a wedged server and adds a client dependency); matches the watcher's existing `_live_tmux_socket_present()` semantics (`autonomous_session_watch.py` ~L17536). Known limitation (documented): a stale socket from a SIGKILL'd server pins `/tmp` until reboot — still single-server-coherent. Source: repo evidence (watcher helper); tmux(1).
