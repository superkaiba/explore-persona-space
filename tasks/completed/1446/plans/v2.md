# for the self-selected topical prefixed population): measured 2026-07-17 on
# the live 7-day closed non-prefixed infra window (28 tasks) — the real #1386

**(b) Signature** (backward-compatible keyword-only extension):

```python
def recent_closed_workflow_fix_tasks(
    target_file: str | None,
    candidate_title: str | None = None,
    *,
    days: float = 7.0,
    now: datetime | None = None,
    include_plain_infra: bool = True,
) -> list[dict[str, Any]]:
```

**(c) Loop restructure** (replacing L1233-1275; the early `if not cand_targets and not cand_tokens: return []` at L1230 is unchanged):

```python
    for tid_str, entry in _load_registry().get("tasks", {}).items():
        if entry.get("kind") != "infra":
            continue
        if (entry.get("status") or "") not in _WF_FIX_TERMINAL:
            continue
        title = str(entry.get("title", ""))
        prefixed = title.startswith(WF_FIX_TITLE_PREFIXES)
        if not prefixed and not include_plain_infra:
            continue
        shared = cand_tokens & _wf_fix_title_tokens(title)
        if (
            not prefixed
            and len(shared) < _WF_FIX_PLAIN_TITLE_MIN_SHARED
            and not cand_targets
        ):
            # Widened pass (#1446): no arm can possibly fire — skip before
            # any per-task file read (registry-only precheck).
            continue
        try:
            tid = int(tid_str)
            task_dir = find_task_path(tid)
        except (FileNotFoundError, ValueError):
            # Non-numeric registry key or missing folder: skip this entry.
            continue
        matched: list[str] = []
        task_targets: set[str] = set()
        if prefixed:
            # ── Prefixed pass: EXISTING #1399 logic, output-identical ──
            if cand_targets:
                try:
                    _, body = _read_body(task_dir / "body.md")
                except (OSError, ValueError):  # widened per fact-check 2026-07-17: non-FNF OSError from read_text() escaped the old (FileNotFoundError, ValueError) tuple
                    body = ""  # fail-soft: target arm silently unavailable
                for m in _WF_FIX_TARGET_LINE_RE.finditer(body):
                    task_targets |= _wf_fix_target_tokens(m.group(1))
                if cand_targets & task_targets:
                    matched.append("target")
            if shared:
                matched.append("title:" + ",".join(sorted(shared)))
            if not matched:
                continue
            closed = _wf_fix_closed_at(task_dir)
            if closed is None or closed < cutoff or closed > now:
                continue
        else:
            # ── Widened pass (#1446): ordinary closed infra tasks. The
            # window check runs BEFORE the body read (cost gate: only the
            # ~tens of in-window tasks are ever body-read; measured 28
            # in-window on 2026-07-17 vs 199 non-prefixed terminal total).
            closed = _wf_fix_closed_at(task_dir)
            if closed is None or closed < cutoff or closed > now:
                continue
            if len(shared) >= _WF_FIX_PLAIN_TITLE_MIN_SHARED:
                matched.append("infra-title:" + ",".join(sorted(shared)))
            if cand_targets:
                try:
                    _, body = _read_body(task_dir / "body.md")
                except (OSError, ValueError):  # widened per fact-check 2026-07-17: non-FNF OSError from read_text() escaped the old (FileNotFoundError, ValueError) tuple
                    body = ""  # fail-soft: target arm silently unavailable
                # Full candidate path token as a body substring (NOT the
                # basename: bare 'SKILL.md' matches 11/28 in-window bodies,
                # while full paths measured 0-6; glob tokens stay opaque).
                task_targets = {t for t in cand_targets if t in body}
                if task_targets:
                    matched.append("infra-target")
            if not matched:
                continue
        hits.append(
            {
                "id": tid,
                "title": title,
                "status": entry.get("status"),
                "target": ", ".join(sorted(task_targets)) or None,
                "closed_at": closed.strftime("%Y-%m-%dT%H:%M:%SZ"),
                "matched": matched,
            }
        )
    hits.sort(key=lambda h: h["closed_at"], reverse=True)
    return hits
```

Row-shape note: for widened rows, `target` carries the candidate path token(s) actually FOUND in the task body (the overlap the filer wants to see); for prefixed rows it keeps its existing meaning (the task's own `workflow_fix_target:` tokens). Documented in the docstring.

## 11. Decision Rationale

N/A — no model training; no hyperparameters. Design choices, each with source:

1. **What:** widen inside the existing enumerator vs a separate second function. **Why:** one loop, one sort, one cap, one caller; a sibling function would duplicate the registry walk and re-open the built-but-stranded risk. **Source:** task body sketch ("second pass") + `scripts/file_infra_task.py` L304 (single call site). **Alternative rejected:** standalone `recent_closed_plain_infra_tasks()` merged by the caller — two sorts/caps to keep coherent.
2. **What:** `include_plain_infra: bool = True` (default ON) vs the body sketch's literal "opt-in" (default OFF). **Why:** the function's only production caller IS the advisory the Goal says to widen; a default-OFF flag the caller must remember to pass is the exact built-but-stranded-fix failure mode (CLAUDE.md § Built-but-stranded fixes), and default-ON needs zero caller change — which also keeps every `_fake_recent(target, title, *, days)` test fake valid (tests/test_file_infra_task.py L671/L697/L719/L749). The kwarg preserves the opt-out. **Source:** the spawn brief's revised-exclusion-test note + measured caller/test surfaces.
