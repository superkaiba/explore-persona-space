## 3. Design

### 3.1 Edit 1 — CLAUDE.md L147, rung (e) (single-clause extension)

**Anchor (exact current substring, verified L147):**

> (e) prevention beats recovery: briefs and prompts for harmful-content AND real-world-corpus (LMSYS/WildChat-class) tasks name banks/corpora by filename + row count, never inline example items — FIRST-PASS briefs carry this discipline, not only post-kill retry briefs (#1073) — trigger-dense brief vocabulary alone killed sessions at prompt level in #866;

**Replacement (full draft wording):**

> (e) prevention beats recovery: briefs and prompts for harmful-content AND real-world-corpus (LMSYS/WildChat-class) tasks name banks/corpora by filename + row count, never inline example items — and briefs/prompts for kill-gate / RLVR / guard / stop-criteria tasks use neutral gate vocabulary ("halt gate", "stop criterion", "termination predicate"; the loaded kill-* terms stay in the ARTIFACTS themselves — code, plans, task bodies are never renamed — only brief/prompt text is neutralized) (#1398 — 2026-07-15: ≥12 refusal kills across ~8 sessions; #1336 lost 3 spawns to gate-criteria phrasing, neutralizing only after the kills) — FIRST-PASS briefs carry BOTH disciplines, not only post-kill retry briefs (#1073) — trigger-dense brief vocabulary alone killed sessions at prompt level in #866;

Design choices, per the brief's questions:
- **Concrete neutral substitutions named: yes** ("halt gate", "stop criterion", "termination predicate") — per the task body; a rule without the substitutions forces each session to re-derive them, which is the exact rediscovery cost being eliminated.
- **Loaded terms stay in artifacts: yes, stated in-clause** — the fix governs brief/prompt vocabulary only; renaming code identifiers or plan text would be a semantic change far beyond the scope and would break greps against existing artifacts. The parenthetical bars it explicitly.
- **One clause, not a new rung/paragraph** — a new rung letter would collide with the (f)/(g) numbering and cross-references ("rungs a-g" appears in trigger-dense-review.md L30 and rung (f)'s "recovery logic (a)-(c)"); extending (e) in place keeps every existing cross-reference valid. Net growth ~450 chars on a ~7,000-char bullet.
- The classifier list names "kill-gate" once (matching the Goal's own wording — a reader whose task says "kill-gate" must be able to match the rule) and compresses the remaining loaded variants to the abstract `kill-*` glob, itself modeling the discipline.
