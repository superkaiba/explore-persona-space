1. The stale-folder guard finishes reconciling the shared `main` tree.
2. THEN the terminal-teardown sequence fires (only for the code-change path).

```markdown
#### Terminal teardown (code-change path only; runs AFTER the post-merge stale-task-folder guard)

If the task is `kind: infra | batch | analysis | survey` (i.e. arrived at
