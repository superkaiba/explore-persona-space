#### D1 — `task_workflow.py`: parser + grant predicate (new code, ~120 lines)

```python
_AUTH_STUB_HEADING_RE = re.compile(r"^###\s+Authorized smoke stubs\b", re.IGNORECASE)
_ARM_TOKEN_RE = re.compile(r"`([^`]+)`")
_PER_ARM_ROW_RE = re.compile(r"^\s*-?\s*([^:`*]+?|`[^`]+`)\s*:\s*(REAL|FALLBACK|N/A)\b")
_MARKER_TOP_KEY_RE = re.compile(
    r"^(verdict|notes|import-resolution|per-arm-resolution|resume-matrix|production-outroot-unit):"
)

def parse_authorized_stub_block(plan_text: str) -> dict[str, tuple[str, str]] | None:
    """{arm: (reason, control)} from the plan's '### Authorized smoke stubs' block.

    None when the heading is absent. Raises AuthorizedStubBlockError when the
    heading is present but the block is malformed: >1 heading occurrence
    (ambiguous), no markdown table with >=1 data row before the next '#'-level
    heading, a data row with <3 cells, a first cell with no backticked arm
    token, an empty reason or control cell, or a duplicate arm name.
    Arm name = the FIRST backticked token in column 1 (tolerates trailing
    parentheticals: '`upload-verify` (Phase 7)' -> 'upload-verify' — the
    verbatim #2163 plan-v5 shape). Header + separator rows are skipped by
    shape (separator cells match ^:?-+:?$), not by position.
    """

def parse_smoke_arch_marker(note: str) -> SmokeArchMarker:
    """Structured read of an epm:smoke-architecture-check note.

    Returns (verdict, arms_stubbed, per_arm, has_import_resolution):
    - verdict: first whitespace token after the FIRST line-anchored 'verdict:';
    - arms_stubbed: from 'arms_stubbed=' on the verdict line — BOTH forms
      accepted: bare 'a,b' and bracketed '[a, b]' (the #2163 v3 form); split
      on commas, strip whitespace/backticks; empty -> ();
    - per_arm: rows matching _PER_ARM_ROW_RE between the 'per-arm-resolution:'
      line and the next _MARKER_TOP_KEY_RE line (or end of note); arm names
      normalized (strip backticks/asterisks/whitespace); non-matching lines
      in the span are prose continuations and are ignored;
    - has_import_resolution: a line-anchored 'import-resolution:' exists.
    """

@dataclass(frozen=True)
class AuthorizedStubDecision:
    grant: bool
    reason: str                      # one machine-legible line
    arms_stubbed: tuple[str, ...]
    authorized: tuple[str, ...]

def authorized_stub_grant(marker_note: str, plan_text: str) -> AuthorizedStubDecision:
    """The Step 6d.0 grant predicate. Grant iff ALL of:
    1. verdict == 'PASS_AUTHORIZED_STUB' and arms_stubbed is non-empty;
    2. an 'import-resolution:' line is present (PASS_PARTIAL preconditions
       are inherited — the new token is never a weaker path);
    3. per-arm rows exist and set(arms_stubbed) == {FALLBACK-rowed arms}
       (set-EQUALITY, scoped to per-arm-resolution rows only — PASS_PARTIAL
       parity; resume-matrix / production-outroot-unit FALLBACKs never count);
    4. parse_authorized_stub_block(plan_text) is well-formed and non-None,
       and set(arms_stubbed) <= set(authorized arms).
    Every refusal returns grant=False with a reason naming the exact failure
    (offending arms listed); AuthorizedStubBlockError is caught and converted
    to a refusal (runtime never crashes on a malformed plan block — c47 owns
    plan-time loudness).
    """
```

Criterion 2 is clause 4 (subset). Criterion 3 is clause 3 + clause 4 jointly: an unauthorized FALLBACK arm is either absent from `arms_stubbed` (set-equality fails) or present but uncovered by the plan block (subset fails) — REFUSE both ways. Body-sketch condition 4 ("the marker echoes the residual untested seams") is delivered by clause 3's requirement that every granted arm have a `FALLBACK` per-arm row (the reason text rides the row in the durable marker).

Deliberate simplifications (stated): the heading is matched anywhere in the plan text, not §4-position-enforced (plan approval reviews the whole document; heading is distinctive; robust to section renumbering in amendments); first/only block (a second heading raises — ambiguity fails loud); a literal escaped `\|` inside a table cell mis-splits and fails loud on cell count (no silent misparse; not present in any real block).

def cmd_check_authorized_stub(args) -> None:
    ev = latest_event(args.number, prefix="epm:smoke-architecture-check")
