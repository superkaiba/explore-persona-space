## 3. Design decisions (the 7 questions, settled)

**D1 — Detection predicate: value-based AST match; direct + one-hop + import-alias; sibling resolvers included; `syspath_prepend` sink included.**

Banned resolvers: `{"repo_root", "tasks_dir", "registry_path"}` (all three branch-guard identically in `task_workflow` — same trap). A **sink** is an `ast.Call` whose func is an `ast.Attribute` matching either (i) the literal `sys.path.insert` / `sys.path.append` structural shape (same shape as `_is_syspath_guard_call`'s literal branch), or (ii) `<anything>.syspath_prepend` (the monkeypatch convention — a resolver-derived `syspath_prepend` restores the entry at teardown but still imports main's module during the session; catching it closes the obvious "fix" dodge for a flagged insert). A sink is **flagged** iff any argument subtree:

1. contains a Call whose callee name (`Name.id` or `Attribute.attr`) is a banned resolver or a module-scope import alias of one (`from explore_persona_space.task_workflow import repo_root as rr` — alias pass bounded to `ImportFrom` of that exact module at `tree.body` level); this catches `repo_root()`, `tw.repo_root()`, `task_workflow.repo_root()`, `rr()`; **or**
2. references a **tainted module constant**: a `tree.body`-level `ast.Assign` (single `Name` target) or `ast.AnnAssign` (`Name` target, non-None value) whose value subtree satisfies (1). One hop only, no compound-statement descent, no dataflow, no cross-module tracking, **order-insensitive** (any module-level resolver binding taints the name for the whole file — documented over-match).

**Name-based matching is explicitly NOT used for taint targets:** a constant *named* `REPO_ROOT`/`PROJECT_ROOT`/`_REPO` is usually the GOOD `__file__`-derived form (dozens under `tests/`); only the binding's VALUE decides taint. FP surface, enumerated: (a) a test-local `def repo_root()` shadow (zero live hits, verified; shadowing the branch-guarded resolver's name is itself a defect — rename); (b) an attribute callee named `repo_root` on an unrelated object (zero live hits); (c) the order-insensitive taint on a later-rebound name (zero live hits). All three are accepted, docstring-documented over-matches. False negatives, accepted + docstring-documented (family precedent): `sys.path[:0] = [...]` / `sys.path += [...]` slice/augmented forms, two-hop indirection, dynamic/exec, string-built paths.

**D2 — Scope: `tests/` ONLY.** Widening to `scripts/` would land the check with **19 immediate one-hop offenders** in the no-flags bundle — an instant fleet-wide red on every Step 9c compare and Step 10d pre-push gate. Hard blocker. `src/` is clean but out of the incident class (no module-under-test imports there). Scan root: `<repo_root>/tests` via `sorted(root.rglob("*.py"))` — worktree copies live under `.claude/worktrees/*/tests/`, not under `<root>/tests/`, so the scan is worktree-sibling-safe by construction. Unparseable / non-UTF-8 files: skip with a one-line stderr notice (the `check_scripts_import_guard` precedent), never silently.

**D3 — Placement + naming.** Function `check_no_repo_root_syspath_in_tests(*, repo_root: Path | None = None) -> list[str]` + module helpers `_BANNED_SYSPATH_RESOLVERS`, `_mentions_banned_resolver_call`, `_tainted_module_names`. Placed immediately after the syspath family (after `_scripts_import_guard_msg`, i.e. before `_dotenv_lint_waiver_present` at :7533), with a one-line cross-reference comment to `_is_syspath_guard_call` noting the opposite polarity. Flag: `--check-no-repo-root-syspath-in-tests`.

**D4 — Error message** (mirrors the family register: file:lineno, banned construct, incident, both sanctioned replacements):

```
{py}:{lineno}: `sys.path` entry derived from `{resolver}()` under tests/ is
forbidden — `task_workflow.{resolver}()` branch-guards to the MAIN checkout, so a
worktree pytest run imports main's copy of the module under test (a branch
regression can pass its own test on the branch) and leaks a foreign checkout's
```

### 4.1 New check (workflow_lint.py, inserted after `_scripts_import_guard_msg`, before line ~7533)

```python
# --- tests/ repo_root()-derived sys.path ban (#2181) -------------------------
# OPPOSITE polarity to the check_scripts_import_guard family above (which
# REQUIRES a repo-root guard in scripts/ drivers): this check FORBIDS deriving
# a tests/ sys.path entry from the branch-guarded task_workflow resolvers.

_BANNED_SYSPATH_RESOLVERS = frozenset({"repo_root", "tasks_dir", "registry_path"})
_TASK_WORKFLOW_MODULE = "explore_persona_space.task_workflow"


def _banned_resolver_aliases(tree: ast.Module) -> frozenset[str]:
    """Module-scope import aliases of the banned resolvers: names bound by
    `from explore_persona_space.task_workflow import repo_root [as rr]` at
    tree.body level. Attribute access (tw.repo_root()) needs no alias pass —
    the callee-name match below already catches Attribute.attr."""
    names = set(_BANNED_SYSPATH_RESOLVERS)
    for stmt in tree.body:
        if (
            isinstance(stmt, ast.ImportFrom)
            and stmt.module == _TASK_WORKFLOW_MODULE
        ):
            for a in stmt.names:
                if a.name in _BANNED_SYSPATH_RESOLVERS:
                    names.add(a.asname or a.name)
    return frozenset(names)


def _mentions_banned_resolver_call(node: ast.AST, names: frozenset[str]) -> str | None:
    """The matched resolver name iff any Call in node's subtree has a callee
    (Name.id or Attribute.attr) in `names`; else None. VALUE-based: a plain
    Name reference (no call) never matches."""
    for n in ast.walk(node):
        if isinstance(n, ast.Call):
            f = n.func
            cn = f.id if isinstance(f, ast.Name) else (
                f.attr if isinstance(f, ast.Attribute) else None
            )
            if cn in names:
                return cn
    return None


def _tainted_module_names(tree: ast.Module, names: frozenset[str]) -> dict[str, str]:
    """{constant name: resolver name} for tree.body-level Assign (single Name
    target) / AnnAssign (Name target, non-None value) whose VALUE subtree
    contains a banned-resolver call. One hop, no compound descent, no
    dataflow, order-insensitive (documented over-match). Taint keys on the
    binding's VALUE, never its name — REPO_ROOT bound to a __file__-derived
    expression is the sanctioned form and never taints."""
    tainted: dict[str, str] = {}
    for stmt in tree.body:
        target = value = None
        if (
            isinstance(stmt, ast.Assign)
            and len(stmt.targets) == 1
            and isinstance(stmt.targets[0], ast.Name)
        ):
            target, value = stmt.targets[0].id, stmt.value
        elif isinstance(stmt, ast.AnnAssign) and isinstance(stmt.target, ast.Name):
            target, value = stmt.target.id, stmt.value
        if target is None or value is None:
            continue
        hit = _mentions_banned_resolver_call(value, names)
        if hit is not None:
            tainted[target] = hit
    return tainted


def _is_syspath_mutation_sink(node: ast.Call) -> bool:
    """sys.path.insert / sys.path.append (structural, same shape as the
    literal branch of _is_syspath_guard_call) or <obj>.syspath_prepend."""
    f = node.func
    if not isinstance(f, ast.Attribute):
        return False
    if f.attr == "syspath_prepend":
        return True
    return (
        f.attr in ("insert", "append")
        and isinstance(f.value, ast.Attribute)
        and f.value.attr == "path"
        and isinstance(f.value.value, ast.Name)
        and f.value.value.id == "sys"
    )


def check_no_repo_root_syspath_in_tests(*, repo_root: Path | None = None) -> list[str]:
    """FAIL any tests/**/*.py sys.path.insert/append (or monkeypatch
    .syspath_prepend) whose argument derives from the branch-guarded
    task_workflow resolvers (repo_root/tasks_dir/registry_path), directly,
    via a module-scope one-hop constant, or via a module-scope import alias.

    <docstring: incident #2164 summary; the two silent consequences; the
    sanctioned tree-local + monkeypatch.syspath_prepend replacements; the
    enumerated over-matches (shadowing def, unrelated attr callee,
    order-insensitive taint) and under-matches (slice/augmented assign,
    two-hop, dynamic); no waiver — zero offenders + no legitimate use;
    repo_root kwarg is the unit-test override hook; bundled into the
    no-flags default run.>
    """
    root = repo_root if repo_root is not None else _REPO_ROOT
    tests_dir = root / "tests"
    errors: list[str] = []
    if not tests_dir.is_dir():
        return errors
    for py in sorted(tests_dir.rglob("*.py")):
        try:
            tree = ast.parse(py.read_text(encoding="utf-8"))
        except (OSError, UnicodeDecodeError, SyntaxError) as exc:
            sys.stderr.write(
                f"workflow_lint: check-no-repo-root-syspath-in-tests skipped "
                f"unparseable {py}: {type(exc).__name__}\n"
            )
            continue
        names = _banned_resolver_aliases(tree)
        tainted = _tainted_module_names(tree, names)
        for node in ast.walk(tree):
            if not (isinstance(node, ast.Call) and _is_syspath_mutation_sink(node)):
                continue
            resolver = None
            for arg in list(node.args) + [kw.value for kw in node.keywords]:
                resolver = _mentions_banned_resolver_call(arg, names)
                if resolver is None:
                    for n in ast.walk(arg):
                        if isinstance(n, ast.Name) and n.id in tainted:
                            resolver = tainted[n.id]
                            break
                if resolver is not None:
                    break
            if resolver is not None:
                errors.append(<D4 message, f-string on py/node.lineno/resolver>)
    return errors
```
