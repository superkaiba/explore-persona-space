```python
def batched_fold_cv_mlp_r2(
    X: np.ndarray,                 # (N, L, D)
    Y: np.ndarray,                 # (N, L, D)
    fold_ids: np.ndarray,          # (N,) int64 — caller-computed (issue825 _cv_folds)
    *,
    layers: list[int],
    perms_by_layer: dict[int, list[np.ndarray]],  # layer -> [(N,) row perms], obs prepended internally
    pca_k: int = 64,

    min_train_rows: int = 3,       # issue825 serial guard: te.sum()==0 or tr.sum()<3 -> skip fold
    time_budget_s: float | None = None,
    started: float | None = None,  # time.monotonic() anchor for the budget
    chunk_size: int = 8,
) -> tuple[dict[str, dict], bool]:
    """Returns ({str(layer): {"r2_obs", "r2_null", "r2_obs_folds", "budget_hit_folds"}},
    budget_exhausted). Batched fold-CV MLP R^2: per fold, (layer x draw) members ride ONE
    fit_batched_split_mlp call (loss="mse", standardize_inputs=False, patience=20) with the
    fit_h.mlp_fit_predict parent-parity prep (full fold-train ddof=0 X standardization BEFORE
    the rng(42) 10% val split; PCA-pca_k basis on the full fold-train target via device-routed
    torch SVD, skipped when target dim <= pca_k). Origin pattern: issue931_fit_cells._mlp_fold_r2."""
```

Internals (mirroring `issue931_fit_cells.py:577-691` with three deltas):
- **ss accumulation per (layer, draw, fold)** — not per (layer, draw) — so `r2_obs_folds` (per-fold held-out R², the `_fold_se` input) is derivable alongside pooled R². Pooled: `1 − Σ_k ss_res / Σ_k ss_tot`; per-fold: `1 − ss_res_k/ss_tot_k` (NaN when `ss_tot_k ≤ 1e-12`) — exactly the serial `_cv_r2` arithmetic (:1224–1254).
- **Budget check at fold granularity:** before building each fold's members AND before the batched fit call: `time.monotonic() − started > time_budget_s` → stop; layers with incomplete folds report `r2_obs = NaN`, incomplete draws `NaN` in `r2_null`, `budget_hit_folds = sorted(remaining fold ids)` (identical for all layers — fold-outer), return `budget_exhausted=True`.
- **PCA prep:** private `_pca_basis_on_device(Y, k, device)` — torch SVD on centered target, `gesvd` fallback on CUDA LinAlgError, `robust_pca_basis` fallback on CPU (copy the #931 `_pca_basis_device` body; it already imports `robust_pca_basis` from this module).
- Member build per fold (verbatim #931 shape): per (layer li, draw d): `Yp = Y[perm_d]`; `Xtr = X[tr, li]`, `xmu/xsd` on FULL fold-train (ddof=0, `+1e-6`); PCA on full fold-train `Yp[tr, li]` (skip when `D ≤ pca_k`); `vr = np.random.default_rng(42)` val split (`n_val = max(1, round(0.1*n))`); `SplitMLPGroup(key=("i825mlp", li, d, k), ...)`; then ONE `fit_batched_split_mlp(members, seed=42, max_epochs=..., device=..., loss="mse", standardize_inputs=False, patience=20, chunk_size=8)`; un-PCA per member; accumulate ss.

**D1.2 — rewrite `run_mlp_secondary`** (`scripts/issue825_fit_cells.py:1191`), same public name/signature, same JSON write:

```python
def run_mlp_secondary(res, out_dir, *, cell_id, n_folds, seed, n_null=5) -> None:
    """Batched fit_h-recipe MLP secondary (PCA-64) at the frozen layers with a shuffle null.

    Vectorized per .claude/rules/vectorize-many-cell-fits.md (#1320): (layer x draw) members
    batch per fold through vectorized_mlp_skill.batched_fold_cv_mlp_r2 on _fit_device();
    serial oracle: _run_mlp_secondary_serial_reference (tombstoned)."""
    from explore_persona_space.analysis.vectorized_mlp_skill import batched_fold_cv_mlp_r2

    started = time.monotonic()
    xy = res["xy"]
    X, Y, conv_ids = xy["X"], xy["Y"], xy["conv_ids"]
    folds = _cv_folds(conv_ids, n_folds, seed)
    layers = [v for v in FROZEN_LAYERS if v < X.shape[1]]
    # EXACT serial rng-stream replication: layer-major, n_null perms per layer (:1207/:1259-1262).
    rng = np.random.default_rng(seed + 13)
    perms_by_layer = {li: [rng.permutation(X.shape[0]) for _ in range(n_null)] for li in layers}
    out, budget_hit = batched_fold_cv_mlp_r2(
        X, Y, folds, layers=layers, perms_by_layer=perms_by_layer,
        device=str(_fit_device()), time_budget_s=MLP_TIME_BUDGET_S, started=started,
    )
    cells_path = out_dir / f"cells_{cell_id}.json"
    payload = json.loads(cells_path.read_text()) if cells_path.exists() else {}
    payload["mlp"] = out
    payload["mlp_budget_exhausted"] = budget_hit
    _write_json(cells_path, payload)
```

(dict comprehension over `layers` in the stated order preserves the serial stream: python dict comprehensions evaluate in iteration order, matching the serial layer-outer → draw-inner `rng.permutation` consumption exactly; permutation identity per (layer, draw) is therefore bit-equal to serial.)

**D1.4 — budget semantics (one documented refinement):** `MLP_TIME_BUDGET_S = int(os.environ.get("EPS_MLP_TIME_BUDGET_S", "1800"))` stays (:1188).
