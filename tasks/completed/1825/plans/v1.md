## Goal / Requirement

`.claude/rules/gotchas.md` gains one entry so that any agent wiring a reused
module's CLI/Namespace defaults (a hot path under the standing "reuse existing
experiment code" default) is warned to:

1. read the CONSUMING function's path-join / attribute reads — never infer the
   contract from the flag name or a sibling module's usage;
2. reference the consumer's own constant rather than a re-typed literal;
3. class-sweep every caller of the same consumer in the same fix round;
4. audit a wrapper-re-declared argparse surface / hand-built Namespace
   FIELD-BY-FIELD against the consumer's reads (never `default=None` for a
   dereferenced field; call-arg mismatches like a `layers` list can silently
   wipe resume state);
5. record smoke-fenced branches (None-input / tiny-N cuts) and add a
   production-shaped smoke leg before the branch's first production run;
6. run the cheap no-GPU fix-engaged probe (drive the real entrypoint argv,
   check the remote index at the resolved prefix).
