### 4.1 `scripts/verify_plan.py` — new regexes + normalizer (insert immediately before `_C20_OTHERWISE_RE`, L3029, keeping the atom grammar block contiguous)

```python
# Negated-existence atoms (#1960; incident #1946): prose form
#   ``no <family-ref> <unit-noun> is <inner predicate>``
# and the canonical machine form ``count(<family-ref>) == 0``. The span
# consumes the leading NEGATOR (``no``/``zero``) so it never lands in
# _C20_RESIDUE_RE residue; the inner predicate is a bounded run that stops
# at ;,.  comparators, and newline, and BEFORE a top-level AND/OR joiner —
# so a following sign/CI atom joins via the normal connective gap, never
# swallowed (a `with` INSIDE the span is atom text, not a joiner).
# Semantics: ONE boolean axis per lattice — values {zero, nonzero}; the
# atom binds {zero}; the nonzero side is reachable only via ⇔ otherwise.
_C20_NOEXIST_UNITS = r"(?:contrasts?|comparisons?|tests?|cells?|pairs?|arms?)"
_C20_NOEXIST_PROSE_RE = re.compile(
    r"(?i)\b(?:no|zero)\s+(?P<family>(?:[\w`*./_-]+\s+){0,5}?" + _C20_NOEXIST_UNITS + r")\s+"
    r"(?:is|are)\s+(?P<pred>(?:(?!\b(?:and|or)\b)[^;,.<>≤≥\n])+)"
)
_C20_NOEXIST_COUNT_RE = re.compile(
    r"(?i)\bcount\(\s*(?P<family>[^()\n]{1,120}?)\s*\)\s*==?\s*0(?!\.?\d)"
)
```

Grammar decisions (design q1): the family-ref is BOUNDED by a closed unit-noun set (`contrast/comparison/test/cell/pair/arm`) so bare "no <anything>" prose (e.g. "no binary verdict" — an `_C20_OTHERWISE_RE` token; "no CI includes 0" — `CI` is not a unit noun) never matches and stays residue. The inner-pred tempered run `(?:(?!\b(?:and|or)\b)[^;,.<>≤≥\n])+` ends the span at the first top-level AND/OR (so `no X contrast is BH-sig AND A > 0` leaves `and` in the inter-atom gap → normal connective) and refuses comparator chars (a trailing `A > 0` is then collected as its own point atom; if a hostile phrasing still produces intersecting spans, `_c20_build_dnf`'s existing overlapping-spans check fails closed to `unparsed`). The count form's inner `[^()]` text may carry comparators/connectives — all inside the span, suppressed from point/CI collection and residue. Note: a count form whose inner text carries a NONZERO threshold (e.g. `score > 50`) + `⇔ otherwise` still hits the pre-parse #1689 threshold-SKIP — unchanged precedence, not a regression (same text SKIPs today).

Normalizer (near `_c20_label_name`, L3130):

```python
def _c20_norm_family(fam: str) -> str:
    """Normalized axis key for a negated-existence family-ref: casefold,
    backticks/asterisks stripped, whitespace collapsed, trailing unit noun
    singularized. Axis sharing requires IDENTICAL keys (design q4); >1
    distinct key per lattice fails closed to unparsed in
    _c20_evaluate_lattice — light normalization errs toward WARN, never a
    false FAIL."""
    s = re.sub(r"\s+", " ", fam.replace("`", "").replace("*", "").casefold()).strip()
    return re.sub(r"(contrast|comparison|test|cell|pair|arm)s$", r"\1", s)
```
