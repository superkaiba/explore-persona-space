## 11. Decision Rationale

- **D1 — Pattern set P1–P3 (convention regexes, not a literal allowlist).** What: three regexes covering every observed non-canonical name. Why: an allowlist of today's dirs would not prevent recurrence; the conventions (`i<N>_*`, `issue-<N>*`, `*_<N>`, `issue<N>_dl`-style) are what agents actually generate. Source: task #911 body + `epm:clarify` live verification 2026-07-03 + the live `/tmp` listing enumerated in §4.1. Alternatives: one loose regex (rejected — `i18n`/`tmux-1000` false positives); literal allowlist (rejected — recurrence).
- **D2 — Registry gating via the existing `_resolve_issue_status`, not raw REGISTRY.json parsing.** Why: `find_task_path` is the canonical resolver (branch-guarded, tested); unresolved → kept is already tier (b)'s semantics. Source: `vm_disk_guard.py:316-322` (#679 lineage); CLAUDE.md "Never form tasks/... paths" rule. Alternatives: parse REGISTRY.json directly (rejected — duplicate, shape-fragile).
- **D3 — /tmp: dir-only, top-level-only, uid-owned.** Why: files can be un-uploaded artifact bundles (`issue833-eval.tgz`); recursion into /tmp is the tier-(c)-rejected pattern; other-uid entries aren't ours. Source: `vm_disk_guard.py:489-495` (tier (c) top-level /tmp precedent); upload-policy persist-by-default. Alternatives: include files ≥X GB (rejected v1 — names a follow-up if the ~0.8 G residual ever matters).
- **D4 — P2 suffix is underscore-only, name-final.** Why: hyphen-suffix admits `tmux-1000` (deleting it kills live tmux sessions) once ids reach 1000. Source: live /tmp listing. Alternatives: `-(\d+)$` too (rejected).
- **D5 — 48 h recency keep, non-canonical candidates only.** Why: the user-chat inline free-analysis carve-out legitimately reads a TERMINAL task's artifacts; /tmp paths are never declared in plans, so the #773 consumer gate cannot see those readers — mtime is the only signal. Canonical caches keep their existing contract untouched (backward compat). Source: #742/#773 strand incident (`clean_experiment_downloads.py:19-29`); CLAUDE.md § Routing "User-chat inline free analysis". Alternatives: no gate (rejected — race); extending the consumer regex to /tmp paths (rejected — nothing declares them).
