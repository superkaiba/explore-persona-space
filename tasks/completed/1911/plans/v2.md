v2 delta (critic Must-Fix 1, verified empirically by the critic): the fix idiom
is `X=$(CMD -c ... 2>/dev/null || true); X=${X:-0}` — a bare
`X=$(CMD -c ...)` propagates rc=1, which (a) fires any OUTER fallback in a
wrapped invocation (`podssh "..." || echo unknown` → `"0\nunknown"`, the same
two-line bug class) and (b) kills a `set -e` script at its first empty probe.
`|| true` neutralizes the status WITHOUT printing; in a wrapped (ssh/podssh)
invocation it must sit REMOTE-side.

     `|| echo 0` fallback fires too and the captured value becomes the two-line string
