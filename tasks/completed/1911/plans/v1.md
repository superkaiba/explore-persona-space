## File paths + concrete diffs

1. `.claude/rules/gotchas.md` — append one bullet (placed near the other
   shell/ops entries, e.g. after the gcloud PATH entry):

   ```
   - **`CMD -c ... || echo 0` double-prints — count-keyed equality gates never fire.**
     `pgrep -c` (and `grep -c`) PRINT `0` AND exit non-zero when nothing matches, so a
     `|| echo 0` fallback fires too and the captured value becomes the two-line string
     `"0\n0"`. Any `[ "$X" = "0" ]` gate then never matches. This fails OPEN, so it is
     worst in liveness / resource-release / termination guards: #1773's pod-release
     watcher (2026-07-31) never fired and would have billed ~11 extra hours of an idle
     1×H100 — caught only by a manual pod probe. The idiom reads as a standard defensive
     fallback and bites anything that both prints a count and exits non-zero on empty.
     Fix: `X=$(CMD -c ... 2>/dev/null); X=${X:-0}` (the fallback then covers only
     genuinely-empty output, e.g. an SSH/transport failure) or
     `X=$(CMD ... 2>/dev/null | wc -l)`. Diagnose a suspected case with `cat -A` — the
     captured value shows as two physical lines.
   ```
