## 11. Decision Rationale

1. **Allowlist route vs bounded dirt-quarantine oracle mode.**
   - *What:* add the third member to `FILE_ANCHORED_SCAN_TESTS`; do NOT build a new oracle mode.
   - *Why:* the residual wedge class is exactly ONE file, and that file already satisfies the #1337 anchoring property (audit §3a). A quarantine mode is a new eligibility/teardown surface on a safety-critical certifier for zero additional coverage today.
   - *Source:* #1337 (`2747005611`) — the allowlist mechanism + curation rule; #1318 — the founding anchored-scan incident; #1593 (`c010cffc20`) — the selector-side comment explicitly deferring to this opt-in; verified code lines in §10.
