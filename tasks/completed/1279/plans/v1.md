### 4. Design

**Why code, not a model call:** the checks are deterministic byte/regex arithmetic already implemented in `workflow_lint.py`; a model call is categorically wrong for a blocking guard (latency, nondeterminism, cost per edit).

#### 4a. Resolved design questions (the six from the brief)

1. **PreToolUse block on prospective content — not PostToolUse annotate, not hybrid.** PostToolUse can only warn after the file already changed (and after-the-fact stderr on exit 0 is not reliably surfaced), so it does not close the bypass the Goal names. A hybrid buys nothing: ALL of #1269's checks are cheap enough to run pre-edit (a <8 KB file, one function call). Prospective content: for Write, `tool_input.content`; for Edit, apply `old_string→new_string` (respecting `replace_all`) to the current on-disk file.
2. **Reuse via runtime import + temp-root materialization — zero re-implementation.** The helper imports `check_lessons_index` from `scripts/workflow_lint.py` (via `importlib.util.spec_from_file_location`; import-safe per §2) and calls it with `repo_root=<tmpdir>` where the tmpdir holds (a) the prospective LESSONS.md bytes and (b) zero-byte stub files named after every real `.claude/rules/*.md` of the EDITED tree (only stems are globbed by the parity check — content irrelevant). This exercises the FULL #1269 check set (total cap, WARN band, all three ratchet modes, per-row caps, grandfather hygiene, parity) with the module's own constants as defaults. Shelling `--check-lessons-index` was rejected (checks the on-disk tree, not the prospective content); a bash re-implementation was rejected (drift risk, explicitly against the task Constraints). No change to `workflow_lint.py` is needed — the documented `repo_root` override suffices.
   **Constant resolution from the EDITED tree:** the helper derives the tree root from the edited path (`<root>/.claude/rules/LESSONS.md` → `parents[2]`) and imports `<root>/scripts/workflow_lint.py` FIRST, falling back to the hook's own repo's copy. This makes the #1269 same-diff coupling work at edit time for free: a sanctioned grow/trim that bumps `_LESSONS_RATCHET_BYTES` in the SAME tree BEFORE editing LESSONS.md is honored (root checkout and worktrees alike); the reverse ordering gets a block message prescribing constant-first.
3. **Bash write path (sed -i / `>>` / tee / inline python to LESSONS.md): NAMED RESIDUAL, out of v1 scope — a decided omission, not a silent one.** Rationale: (a) the incident class motivating #1269/#1279 is orchestrator Edit-tool edits; (b) reliable write-shaped Bash command parsing is an open-ended problem (`guard_log_dump.sh` needed ~440 lines and 3 hardening rounds for READ verbs alone) with high false-positive risk on a BLOCKING hook; (c) the commit-time lint still gates every worktree/PR path, and `workflow_lint` default-run remains in the test suite; (d) the residual is documented in the hook header so a future tightening round sees it was a decision. This session runs under the workflow-fix recursion guard, so no child candidate is auto-filed; the residual is recorded here and in the hook header for the /daily sweep.
4. **Matcher wiring: append to the EXISTING `Edit|Write` PreToolUse matcher group** (settings.json line 108) as a second command object, absolute path per the existing convention. No new matcher group (keeps one Edit|Write group; the #965 wiring test asserts registration under that matcher). Exact JSON in §4d.
5. **Escape hatch, two forms:** (a) session env `EPM_ALLOW_LESSONS_EDIT=1` (checked case-insensitively like `guard_log_dump.sh` lines 421–424) — usable by deliberately-spawned maintenance sessions; (b) a FRESH sentinel file `.claude/cache/allow-lessons-edit` (mtime within 900 s), touched via Bash immediately before the edit — the practical in-session escape, since Edit/Write payloads carry no command string to inline-prefix (the one place the guard_log_dump convention cannot transfer; the freshness window prevents a stale sentinel from disarming the guard permanently, and the sentinel-file pattern has precedent in the `.epm-authorized` gate at settings.json line 79). The block message names both.
6. **Tests:** mirror `tests/test_guard_log_dump.py` — in-hook `--self-test` as the behavior-matrix source of truth, a thin pytest wrapper running it, targeted payload tests via subprocess stdin JSON against synthetic trees, the #965 `TestSettingsWiring` class, and a `bash -n` syntax test. Full list in §6.

#### 4c. Hook control flow (pseudocode)

`.claude/hooks/guard_lessons_edit.sh`:

```bash
#!/usr/bin/env bash
# PreToolUse(Edit|Write) guard: block edits that would regress the #1269
# LESSONS.md byte budgets / index parity (task #1279). Contract: PreToolUse
# JSON on stdin; exit 0 allow; exit 2 + stderr block. FAIL-OPEN on own errors.
# Named residual: Bash-tool writes (sed -i / >> / tee) are NOT covered — the
# commit-time lint gates remain for those paths.
# Escape hatches: EPM_ALLOW_LESSONS_EDIT=1 (session env), or
#   touch <repo>/.claude/cache/allow-lessons-edit  (honored for 900 s).
# Self-test: bash .claude/hooks/guard_lessons_edit.sh --self-test
set -u
SELF_DIR="$(cd "$(dirname "$0")" && pwd)"          # <repo>/.claude/hooks
REPO_ROOT="${SELF_DIR%/.claude/hooks}"
HELPER="$SELF_DIR/guard_lessons_edit_check.py"
SENTINEL="$REPO_ROOT/.claude/cache/allow-lessons-edit"
SENTINEL_TTL=900

[ "${1:-}" = "--self-test" ] && { run_self_test; exit $?; }

# escape hatch 1: session env
case "$(printf '%s' "${EPM_ALLOW_LESSONS_EDIT:-}" | tr '[:upper:]' '[:lower:]')" in
  1|true|yes) exit 0 ;;
esac

payload=$(cat 2>/dev/null) || exit 0                       # fail-open
fp=$(printf '%s' "$payload" | jq -r '.tool_input.file_path // empty' 2>/dev/null) || exit 0
[ -n "$fp" ] || exit 0
case "$fp" in                                              # cheap filter: only LESSONS.md pays python
  */.claude/rules/LESSONS.md | .claude/rules/LESSONS.md) : ;;
  *) exit 0 ;;
esac

# escape hatch 2: fresh sentinel (<= 900 s old)
if [ -f "$SENTINEL" ]; then
  now=$(date +%s); mt=$(stat -c %Y "$SENTINEL" 2>/dev/null || echo 0)
  [ $((now - mt)) -le "$SENTINEL_TTL" ] && exit 0
fi

out=$(printf '%s' "$payload" \
  | timeout 20 bash -c "cd '$REPO_ROOT' && uv run python '$HELPER'" 2>&1)
rc=$?
if [ "$rc" -eq 2 ]; then printf '%s\n' "$out" >&2; exit 2; fi
exit 0   # rc 0 = pass; rc 1/124/127/... = helper failure -> FAIL-OPEN
```

`.claude/hooks/guard_lessons_edit_check.py` (stdlib only; exit 0 allow / 2 block / anything else = caller fails open):

```python
def load_lint(tree_root, fallback_root):
    # import <root>/scripts/workflow_lint.py via spec_from_file_location;
    # try the EDITED tree first (same-diff constant bumps honored), then the
    # hook's own repo; any failure on both -> None (caller allows).

def prospective(tool_name, ti, current):
    if tool_name == "Write":  return ti.get("content")            # None -> allow
    if tool_name == "Edit":
        old, new = ti.get("old_string"), ti.get("new_string", "")
        if not old: return None
        n = current.count(old)
        if n == 0: return None                                    # Edit tool errors itself
        if n > 1 and not ti.get("replace_all"): return None       # Edit tool errors itself
        return current.replace(old, new) if ti.get("replace_all") \
               else current.replace(old, new, 1)
    return None   # unknown tool -> allow; fallback inference: content->Write, old_string->Edit

def main():
    if "--print-constants" in sys.argv:   # self-test/pytest fixture sizing
        print(json.dumps({k: getattr(wl, k) for k in (RATCHET, MAX, WARN, ROW, HEADROOM...)})); return 0
    payload = json.load(sys.stdin)
    ti = payload.get("tool_input") or {}
    fp = Path(ti["file_path"]);  fp = (Path(payload.get("cwd", ".")) / fp) if not fp.is_absolute() else fp
    if fp.parts[-3:] != (".claude", "rules", "LESSONS.md"): return 0   # re-verify suffix
    tree_root = fp.parents[2]
    wl = load_lint(tree_root, Path(__file__).resolve().parents[2])
    if wl is None: return 0
    current = fp.read_text(encoding="utf-8") if fp.is_file() else ""
    new = prospective(payload.get("tool_name", ""), ti, current)
    if new is None: return 0
    with tempfile.TemporaryDirectory() as td:
        rules = Path(td) / ".claude" / "rules"; rules.mkdir(parents=True)
        live = tree_root / ".claude" / "rules"
        if live.is_dir():
            for p in live.glob("*.md"):
                if p.name != "LESSONS.md": (rules / p.name).touch()   # stems only matter
        (rules / "LESSONS.md").write_bytes(new.encode("utf-8"))       # BYTE semantics (#1269)
        errors = wl.check_lessons_index(repo_root=Path(td), warn_sink=[])
    if not errors: return 0
    print(BLOCK_HEADER)          # "#1279 edit-time gate for the #1269 LESSONS.md budget"
    for e in errors: print(f"  - {e}")                                 # the lint's OWN text
    print(RECOVERY)  # constant-first ordering (raise/lower _LESSONS_RATCHET_BYTES in
                     # scripts/workflow_lint.py of THIS tree BEFORE the LESSONS edit);
                     # rule-file-first ordering (create .claude/rules/<name>.md before its row);
                     # escape hatches: EPM_ALLOW_LESSONS_EDIT=1 or
                     # `touch .claude/cache/allow-lessons-edit` (15 min).
    return 2

if __name__ == "__main__":
    try: sys.exit(main())
    except Exception: sys.exit(0)    # in-helper fail-open backstop
```

Design notes baked in: strict lint parity — block on ANY prospective FAIL (no delta/"only-new-failures" logic; see §11 alt); allow-on-ambiguous-Edit mirrors the Edit tool's own error behavior (no file change will happen, so nothing to guard); WARN band is advisory in the lint and stays advisory here (discarded on allow); byte (not char) counting preserved by `write_bytes(...encode("utf-8"))`.

### 8. Risks and Failure Modes

| Risk | Likelihood | Mitigation |
|---|---|---|
| False-positive block on sanctioned maintenance (grow/trim before the constant bump; LESSONS row added before its rule file) | Medium | Deterministic orderings honored BY CONSTRUCTION (constants + rules dir load from the EDITED tree, so constant-first / rule-file-first in the same tree passes); block message prescribes exactly those orderings; env + 15-min-sentinel escape hatches |
| Drift between hook and lint semantics | Low | Structurally eliminated: runtime import of `check_lessons_index` + module constants; zero re-implementation; pytest asserts block text is the lint's own error strings |
| Latency tax on every Edit/Write fleet-wide | Low | bash + jq path filter only (~10 ms) on non-matching paths; the ~1–2 s python helper fires only on LESSONS.md edits (rare) |
| `uv run` wedged (project lock contention) stalls an edit | Low | `timeout 20` inside the hook → fail-open; bounded worst case 20 s, only on LESSONS.md edits |
| Bash-tool write path bypass (sed -i / `>>` / tee) | Certain (by design) | NAMED residual (§4a-3): commit-time lint still gates worktree/PR paths; documented in hook header for a future tightening round |
| Stale escape sentinel silently disarms the guard | Low | 900 s freshness window; stale sentinel ignored (self-test case 13 pins it) |
| Running sessions don't load the new hook until respawn | Certain, short-lived | Deployment caveat only; fleet turns over via watcher respawns/new spawns; no action |
| Self-test fixtures break when a future diff moves the constants | Low | Fixture sizes computed at runtime from `--print-constants` / imported constants, never hardcoded |

### 11. Decision Rationale

Load-bearing design constants (infra analogue of hyperparameters), each with What / Why / Source / Alternatives:

1. **Enforcement point = PreToolUse block (exit 2 + stderr).** Why: only a pre-edit block closes the bypass; post-hoc annotation cannot. Source: task #1279 Goal + the `guard_repo_root_branch.sh`-class contract (`guard_log_dump.sh` lines 35–36). Alternatives rejected: PostToolUse warn (doesn't close the gap); hybrid (all checks are cheap enough to run pre-edit).
2. **Check engine = runtime import of `check_lessons_index` with `repo_root=<tmp>` materialization.** Why: full #1269 fidelity with zero duplicated logic. Source: `scripts/workflow_lint.py:8852` (documented `repo_root` override, docstring line 8884) + task Constraints ("keep consistent with the #1269 implementation"). Alternatives rejected: shelling `--check-lessons-index` (on-disk tree ≠ prospective content); bash reimplementation (drift); adding a `lessons_path=` parameter to the lint (unneeded signature change to a 10 k-line module).
3. **Byte limits (8000 / 7200 / 6000 / 400 / 280 / grandfather table).** Not restated anywhere in the new code — imported live from the resolved `workflow_lint.py`. Source: #1269 (`workflow_lint.py` lines 8812–8849).
4. **Constants resolved from the EDITED tree's `workflow_lint.py`, fallback to the hook's repo.** Why: preserves the #1269 same-diff ratchet-bump semantics at edit time (constant-first ordering passes in root checkout AND worktrees). Source: #1269 ratchet design ("raise the constant IN THE SAME DIFF", line 8842).
5. **Fail-open on every hook-internal error; block ONLY on helper exit 2.** Why: a guard's failure mode must never wedge all editing; the commit-time gates remain the backstop. Source: task Constraints + the shared guard-hook contract (`guard_log_dump.sh` header). Alternatives rejected: fail-closed (fleet-wide edit wedge on a uv hiccup).
6. **Escape hatch = `EPM_ALLOW_LESSONS_EDIT=1` env + fresh sentinel `.claude/cache/allow-lessons-edit`.** Source: `EPM_ALLOW_*` convention (`guard_log_dump.sh` EPM_ALLOW_LOG_DUMP, `guard_harmful_bank_read.sh` EPM_ALLOW_BANK_READ) + the `.epm-authorized` sentinel-file precedent (settings.json line 79). The inline-prefix half of the guard_log_dump convention cannot transfer (Edit/Write payloads have no command string) — the sentinel file replaces it.
7. **Sentinel freshness TTL = 900 s.** Why: long enough for one deliberate maintenance edit round, short enough that a forgotten sentinel cannot disarm the guard across sessions. Source: ungrounded — chosen value, low-stakes (bounded both ways); pinned by self-test case 13 so a future retune is deliberate.
8. **Helper timeout = 20 s.** Why: bounds worst-case edit latency well under the harness's per-hook timeout (default 60 s per Claude Code docs — assumption 5) while leaving headroom over the measured ~1–2 s happy path. Source: hook-latency budget convention; internal, so correctness is independent of the harness value.
9. **Matcher = existing `Edit|Write` PreToolUse group; absolute command path.** Source: `.claude/settings.json:108` + the #965 `TestSettingsWiring` convention (`tests/test_guard_log_dump.py:118`).
10. **Strict lint parity (block on ANY prospective FAIL) rather than "only-new-failures" delta logic.** Why: delta logic needs error-class normalization (byte counts embedded in strings) and opens a once-red-always-growable hole; main is lint-green today and the hook itself keeps it green, so the already-red state is rare and escape-hatch-recoverable. Source: simplicity + zero-drift principle (#1269). Alternative (delta/ratcheting-only block) recorded here for a future round if false positives materialize.
