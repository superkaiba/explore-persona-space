## 3. Design — files, function, tokens, wiring

### 3a. `scripts/workflow_lint.py` — new check (place immediately after `check_smoke_architecture_review_lens`)

```python
_STALE_LABEL_ANCHOR = "**Stale-label disposition rule"
_STALE_LABEL_REQUIRED_TOKENS = (
    "followup_retro_close_evidence",
    "GHOST-label filter, NOT an execution gate",
    "A None return means NO prior-run evidence exists",
    "the label EXECUTES as the dispatched round",
    "The skip-and-surface disposition applies ONLY when",
)
_STALE_LABEL_SKIP_ON_NONE_RE = re.compile(
    r"\bon\s+(?:a\s+)?none\b.{0,120}?\bskip", re.IGNORECASE
)


def check_stale_label_disposition_clause(*, repo_root: Path | None = None) -> list[str]:
    """FAIL if the /issue Step 0 stale-label disposition paragraph (#894/#763)
    loses its fresh-label-execute semantics or regains an unconditional
    skip-on-None branch (#963). <full docstring cites the incident + tokens>
    ``repo_root`` is a unit-test override hook; production callers pass None.
    Bundled into the no-flags default run."""
    root = repo_root if repo_root is not None else _REPO_ROOT
    skill = root / ".claude" / "skills" / "issue" / "SKILL.md"
    if not skill.is_file():
        return [f"{skill}: missing — the Step 0 stale-label disposition paragraph must exist."]
    text = skill.read_text(encoding="utf-8")
    start = text.find(_STALE_LABEL_ANCHOR)
    if start == -1:
        return [f"{skill}: missing the bold anchor {_STALE_LABEL_ANCHOR!r} (#963) ..."]
    end = text.find("\n\n", start)
    normalized = re.sub(r"\s+", " ", text[start : end if end != -1 else len(text)])
    errors: list[str] = []
    for token in _STALE_LABEL_REQUIRED_TOKENS:
        if token not in normalized:
            errors.append(f"{skill}: stale-label disposition paragraph missing token {token!r} (#963) ...")
    if _STALE_LABEL_SKIP_ON_NONE_RE.search(normalized):
        errors.append(f"{skill}: stale-label disposition paragraph couples a None return to a skip instruction ('On None ... skip') — fresh never-run labels must EXECUTE (#963) ...")
    return errors
```

All five tokens verified verbatim against the live paragraph (SKILL.md L1036–1064, quoted
character-for-character; tokens 3 and 5 are contiguous only after `\s+`→` ` normalization —
L1047–48 `A None return means NO\nprior-run evidence exists`, L1052–53 `The skip-and-surface
disposition\napplies ONLY when`). Negative regex verified non-matching on the current normalized
paragraph: the only near-miss is `On a NON-None return` (L1042–43), where `\bnone\b` cannot match
inside `NON-` and the standalone `-None` is not preceded by `on\s+(a\s+)?`.
