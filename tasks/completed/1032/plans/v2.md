**Design decisions baked in (grounded in §2 calibration + §11):**

- **Stale-quote signature ONLY** (not a standalone "current goal missing" WARN): historical plans paraphrase the Goal ~49% of the time, so a bare currency WARN would nag constantly; the stale-quote signature (superseded Goal present at high coverage while the current Goal is absent) is the incident's fingerprint with measured 0 verify-time FPs.
- **Word-shingle coverage, k=6**, over `[^a-z0-9 ]+ → " "`-normalized lowercase words — robust to the measured unicode/ASCII math variants (`→` vs `->`, `Δ` vs `Delta`) that break full-substring matching on genuinely verbatim quotes.
- **Thresholds:** fire iff `max coverage(superseded) ≥ 0.5` AND `coverage(current) < 0.3`; goals under 12 normalized words are ignored (shingles need headroom; precision gate).
- **Post-time bounding — STRICT, no slack (fact-checker correction, 2026-07-05):** only `epm:goal-updated` markers with `ts ≤ plan-file mtime` (slack = 0) enter the comparison; the "current" reference is the latest predating `to:` (falling back to `frontmatter.goal` when no marker predates). This is what makes the check a pure "was this plan stale AT POST TIME" predicate — retro-stale cases (goal amended after the plan) are excluded by construction. A positive slack is banned: retro-stale gaps of 2m48s–5m44s exist in the corpus (779, 477, 489), so ANY slack ≥ ~3 min manufactures false positives; the 922-v3 retrodiction needs none (its markers predate the post by 10–12 min). Timestamp comparisons are `datetime`-aware, never ISO-string comparison (a `-07:00` vs `Z` string compare silently inverts orderings — bug found and fixed during this plan's own calibration).
- **`--issue`-mode-only:** the checks in `CHECKS` are pure `(plan, kind)` functions; this check needs `body.md` + `events.jsonl`, so it wires into `main()`'s `--issue` branch AFTER `verify_plan_text()` returns and appends to `results` (mirroring how c0 sits outside `CHECKS`). `--plan-file` mode appends a SKIP ("no task context"). `verify_plan_text()`'s signature and behavior are UNCHANGED (no external callers besides `main()` + tests — verified).
- **No N/A escape phrase:** the only fix is redrafting §1 against the current Goal; WARN-only means no bounce-brief escape is needed at the verifier level.

**Pseudocode (close to final):**

```python
# constants
_C23_SHINGLE_K = 6
_C23_MIN_GOAL_WORDS = 12
_C23_STALE_COV = 0.5
_C23_CURRENT_COV = 0.3
# NO positive slack: retro-stale goal-update gaps of ~3-6 min exist in the
# corpus (779/477/489) — any slack ≥ ~3 min manufactures false positives.
_C23_MTIME_SLACK_S = 0.0

def _norm_goal_words(s: str) -> list[str]:
    """Lowercase; non-alphanumerics (incl. unicode math) -> space; split."""
    return [w for w in re.sub(r"[^a-z0-9 ]+", " ", s.lower()).split() if w]

def _goal_shingles(words: list[str], k: int = _C23_SHINGLE_K) -> set[tuple[str, ...]]:
    return {tuple(words[i : i + k]) for i in range(len(words) - k + 1)} if len(words) >= k else set()

def _shingle_coverage(goal: str, head_words: list[str]) -> float:
    gs = _goal_shingles(_norm_goal_words(goal))
    if not gs:
        return 0.0
    hs = _goal_shingles(head_words)
    return sum(1 for s in gs if s in hs) / len(gs)

def _plan_head_words(plan: str) -> list[str]:
    """Head region = start -> the `## 2.`/`### 2.` heading, else first 8000 chars."""
    m = re.search(r"^#{2,3}\s*2\.\s", plan, re.M)
    return _norm_goal_words(plan[: m.start()] if m else plan[:8000])

def _goal_history_for_plan(folder: Path, plan_mtime_utc: datetime) -> tuple[str | None, list[str]]:
    """(current_goal, superseded_goals) AS OF the plan version's post time.

    current = latest predating `epm:goal-updated` `to:` (fallback: body.md
    frontmatter `goal:`); superseded = predating markers' `from:` values
    (structured fields only). Bounded STRICTLY by mtime (slack 0) so
    goal-updates that postdate the plan never retro-flag it — a positive
    slack manufactures FPs from minutes-scale retro-stale gaps (779/477/489).
    """
    cutoff = plan_mtime_utc + timedelta(seconds=_C23_MTIME_SLACK_S)
    current: str | None = None
    superseded: list[str] = []
    ev = folder / "events.jsonl"
    if ev.exists():
        for line in ev.read_text().splitlines():
            if '"epm:goal-updated"' not in line:
                continue  # cheap pre-filter; goal-updated lines parse strictly below
            e = json.loads(line)
            if e.get("kind") != "epm:goal-updated" or not isinstance(e.get("ts"), str):
                continue
            ets = datetime.fromisoformat(e["ts"].replace("Z", "+00:00"))
            if ets.tzinfo is None:
                ets = ets.replace(tzinfo=timezone.utc)
            if ets.astimezone(timezone.utc) > cutoff:
                continue
            if isinstance(e.get("from"), str):
                superseded.append(e["from"])
            if isinstance(e.get("to"), str):
                current = e["to"]
    if current is None:
        body = folder / "body.md"
        if body.exists():
            fm, _ = split_frontmatter(body.read_text())
            g = fm.get("goal")
            current = str(g) if g else None
    if current is not None:
        cur_norm = " ".join(_norm_goal_words(current))
        superseded = [s for s in superseded if " ".join(_norm_goal_words(s)) != cur_norm]
    return current, superseded

def check_goal_currency(plan: str, *, current_goal: str | None, superseded: list[str]) -> CheckResult:
    cid, name = "c23_goal_currency", "plan head not drafted against a superseded Goal"
    if current_goal is None or len(_norm_goal_words(current_goal)) < _C23_MIN_GOAL_WORDS:
        return _skip(cid, name, "no goal frontmatter / goal too short for shingle matching")
    sup = [s for s in superseded if len(_norm_goal_words(s)) >= _C23_MIN_GOAL_WORDS]
    if not sup:
        return _skip(cid, name, "no superseded Goal predates this plan version")
    head = _plan_head_words(plan)
    cov_cur = _shingle_coverage(current_goal, head)
    cov_stale, stale = max(((_shingle_coverage(s, head), s) for s in sup), key=lambda t: t[0])
    if cov_stale >= _C23_STALE_COV and cov_cur < _C23_CURRENT_COV:
        return _warn(
            cid, name,
            f"plan head matches a SUPERSEDED Goal (shingle coverage {cov_stale:.2f}: "
            f"{stale[:100]!r}) while the CURRENT Goal is absent (coverage {cov_cur:.2f}) "
            "— redraft §0.0/§0/§1 against the current `goal:` frontmatter (#922 "
            "plan-vs-goal incident). The orchestrator treats this WARN as a mechanical "
            "redraft bounce (adversarial-planner SKILL.md § Goal-currency gate).",
        )
    return _pass(cid, name, f"coverage: current {cov_cur:.2f}, max superseded {cov_stale:.2f}")
```

## 11. Decision Rationale

N/A — no training hyperparameters. Design decisions:

- **Three layers, not one.** *Why:* #922's marker predated the persist by 10–12 min and still shipped through planner return → persist → verify PASS → auto-approve; each single reader demonstrably failed. *Source:* #922 events.jsonl (verified this session: goal-updated 11:17:25Z/11:19:57Z; epm:plan v3 11:29:54Z; auto-approve 11:29:57Z; PLAN-VS-GOAL directive 11:33:55Z). *Alternative rejected:* (a)-only — an agent instruction with no mechanical backstop is the pattern that already failed for scope staleness before the #658 bullet was added.
- **WARN-first for the new verify_plan check.** *Source:* #1042 / commit `a8e98058b3` (c21 shipped WARN-only, with the same "trigger precision carries the FP discipline" rationale); the forced redraft is delivered by the SKILL.md "the one WARN that bounces" carve-out, so no FAIL classification is needed to close the incident. *Alternative:* FAIL — defensible given 0 measured FPs, deferred as a named follow-up.
- **Word-shingle coverage (k=6) over full-substring matching.** *Source:* measured this session — #922 plan v3's tagged-verbatim quote fails full-substring matching on `→`/`Δ` vs `->`/`Delta` variants, while shingle coverage reads 0.90; corpus FP check 0/11. *Alternative rejected:* normalized full-substring (misses the actual incident); ts-only comparison (see next).
- **Content signature over timestamp comparison at the verify site.** *Why:* the exploitable ts window at Phase 1.5.0 is (persist → verify), effectively zero-width — #922's goal-updates PREdate the plan post, so "latest goal-updated ts > plan ts" is FALSE for the real incident; draft-START time is not mechanically recorded anywhere. The ts signal is instead used where it is sound: layer (b)'s spawn-time snapshot (the orchestrator KNOWS when it spawned the planner) and c23's post-time marker bounding. *Source:* #922 timeline, verified.
- **Thresholds 0.5/0.3, min 12 words, slack = 0 (STRICT ts ≤ mtime).** *Source:* calibration in §2 as independently reproduced by the fact-checker (2026-07-05) — true positive at 0.905/0.038 leaves ≥ 0.4 margin on both sides; benign predating-goal plans measured cov(current)=1.00. The originally-drafted 900 s slack was WRONG: retro-stale goal-update gaps of 2m48s–5m44s exist in ≥3 tasks (779, 477, 489), so the slack manufactured 4 false firings; at slack=0 the sweep fires on exactly the 3 true stales (922 v2, 922 v3, 489 v2) with 0 FPs. Coverage thresholds not sensitive within ~2× (c21-style claim; in-sample calibration caveat carried verbatim: it bounds nuisance on the historical planner distribution, not future plans); the slack constant IS sensitive and pinned at 0.
- **Stale-quote-only predicate (no standalone "current goal missing" WARN).** *Source:* corpus measurement — 85/174 historical newest-plans lack a full-substring match of their current goal (planners paraphrase), so a bare currency WARN would fire ~half the time for zero incident yield; the verbatim-quote mandate (layer a) drives future checkability without a nagging WARN.
