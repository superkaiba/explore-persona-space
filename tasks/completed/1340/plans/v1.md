**Exact bullet text to insert** (one physical line; presented wrapped here for readability — the implementer joins it into a single line):

```
- **A single-arm smoke is blind to per-arm seams — a driver extended to a NEW arm class (source-context class / recipe branch) can pass every existing smoke and still crash at `ModelOrganism` construction; the smoke default covers ONE RUN PER ARM CLASS, not one run total.** The coverage-BREADTH complement to the mock-seam tiny-real entry above (which fixes seam DEPTH): a tiny-real e2e validates only the arm it executes, so any seam that varies BY ARM — source-context construction, negative-panel assembly, `ModelOrganism` wiring — stays unreached on every arm class the smoke skips, and the bug queues up for the production run. Canonical case: the #527/#538 panel-disjointness invariant (`.claude/rules/contrastive-negatives.md` § "Disjointness invariant (HARD)") deliberately HARD-refuses a source content-identical to a default-panel member — the refusal is correct, load-bearing behavior, NOT the bug — so a bare/"default"-context arm added to a driver whose smoke covers only a persona-context arm sails through training and dies at the first organism-construction site the new class reaches. RULE: (1) when extending a driver to a new source-context class, thread the source-filtered panel at EVERY `ModelOrganism` construction site the new class reaches (worked example: `scripts/issue1090_fu3_worker.py::panel_name_for` — returns the default panel minus any member content-identical to the source — threaded as `negatives=fu3w.panel_name_for(ctx)` at `scripts/issue1090_fu4.py::_ladder_organism`); (2) make the smoke default ENUMERATE the driver's arm classes and run one tiny run per class — the Step 6d.0-bis end-to-end smoke gate (`.claude/skills/issue/SKILL.md`) reads "once at tiny N" as once PER ARM CLASS for multi-arm drivers. (Incident #1090 fu5, 2026-07-15: the fu5 smoke default covered only the formatting arm; all 3 imp-bare arms trained to completion on a 4×A100 GCE cycle, then died rc=2 at the Tier-1 ladder entry on the panel-disjointness AssertionError — a full GPU cycle lost to a seam one tiny bare-arm run would have caught.)
```
