# Plan v1 — #2366: widen `_safe_version`'s broken-metadata handling in `eval/capability.py` (the #2360 sibling site)

## Requirement + acceptance criteria

`src/explore_persona_space/eval/capability.py:852-856` (`_safe_version`, nested in
`_collect_run_metadata`) catches only `importlib.metadata.PackageNotFoundError`.
Python 3.12.13 announces (DeprecationWarning at `importlib/metadata/__init__.py:467`)
that the implicit-`None` return for a present-dist-info / missing-`METADATA` package
will become `KeyError`. On a half-installed pod venv (the #2360 real-world shape,
pod-2329) this helper would surface an unexplained eval crash — the misleading-error
class #2360 exists to eliminate, one layer out. The helper is informational only
(vllm/transformers/torch version strings in run metadata); no gate feeds off it.

Acceptance (from the task body, verbatim intent):

1. `_safe_version` returns its "unavailable" sentinel (`"unknown"`) for BOTH
   broken-metadata shapes — absent dist-info (`PackageNotFoundError`), and present
   dist-info with missing `METADATA` (today's `None` return AND the announced future
   `KeyError`) — on today's interpreter and a simulated future one.
2. A regression test pins the `KeyError` form WITHOUT depending on the running
   Python version (monkeypatch `importlib.metadata.version` to raise
   `KeyError("Version")`).
3. Every other in-repo consumer relying on the implicit-`None` contract is either
   fixed in the same round or named out of scope with a reason (§ Sweep disposition).

## Method delta

Mirror of #2360's `preflight.py` tier-1 handler (PR #2006, merged 2026-08-18;
`src/explore_persona_space/orchestrate/preflight.py:938-956`), applied to the
informational sentinel-return shape instead of the structured-failure shape: both
broken-metadata forms normalize onto the existing `"unknown"` sentinel. No behavior
change for healthy packages.

## File paths + concrete diffs

**1. `src/explore_persona_space/eval/capability.py` — `_safe_version` (~lines 852-856):**

```python
    def _safe_version(pkg: str) -> str:
        try:
            ver = importlib.metadata.version(pkg)
        except (importlib.metadata.PackageNotFoundError, KeyError):
            # KeyError("Version") is the announced future form of the
            # present-dist-info / missing-METADATA shape (CPython deprecated the
            # implicit-None return) — normalized like preflight's tier-1 handler
            # (#2360); this helper is informational, so both shapes read "unknown".
            return "unknown"
        return ver if ver is not None else "unknown"
```

The `None` normalization also repairs the existing type-contract hole (the function
is annotated `-> str` but today would return `None` for the missing-`METADATA`
shape on the current interpreter).

**2. `tests/test_capability_eval.py` — new test class
`TestCollectRunMetadataSafeVersion`,** exercising the REAL `_collect_run_metadata`
body (`#906` posture: fake only the external boundary — `importlib.metadata.version`
— via `monkeypatch.setattr(importlib.metadata, "version", <fake>)`; the local
`import importlib.metadata` inside `_collect_run_metadata` resolves the same module
object, so the patch reaches it). Call shape:
`_collect_run_metadata(model_path="m", questions=[], cot_scaffolds=[], n_personas=0, cot_max_tokens=0)`
(the git-commit subprocess runs `check=False` with a 5 s timeout — real, harmless
in-repo). Four tests:

- `test_keyerror_version_reads_unknown` — fake raises `KeyError("Version")` for
  every package → `vllm_version`, `transformers_version`, `torch_version` all
  `"unknown"` (the interpreter-version-INDEPENDENT pin; FAILS pre-fix with an
  escaped `KeyError`).
- `test_none_return_reads_unknown` — fake returns `None` → all `"unknown"`
  (FAILS pre-fix: fields carry `None`).
- `test_package_not_found_reads_unknown` — fake raises
  `importlib.metadata.PackageNotFoundError` → all `"unknown"` (existing behavior,
  pinned).
- `test_healthy_version_flows_through` — fake returns `"1.2.3"` → all `"1.2.3"`
  (guards the normalization against touching the healthy path).
