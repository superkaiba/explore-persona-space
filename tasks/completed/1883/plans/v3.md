## Design decisions

- **Family = existing "workflow", NOT a new "skill-pin" family.** Atomicity
  requires the pin tests share a family with `.claude/skills`, and
  `.claude/skills` is already a "workflow" member (coupled to
  `workflow.yaml` via the generated `markers.md`). A separate family holding
  both would have to move `.claude/skills` out of "workflow", breaking that
  existing coupling. Matches the filed candidate's diff sketch
  (`="workflow"`). The task title's "skill-pin family" is realized as a new
  MEMBER of the workflow family, not a new family key.
- **Comment-less entry line** in both copies; the rationale lives in the
  prose comment block above (acceptance 3). Reason: drift-test check (10)
  only extracts entries whose stripped line ENDS with `="workflow"` — a
  trailing `# comment` would exempt the new entry from the mechanical
  Step5a↔10d drift guard.

## Behavior-change analysis (fail-safe direction preserved)

- New protection: a branch NOT touching skills/pin-tests now syncs main-new
  pin tests together with main-new SKILL.md — the exact #1824 class.
- Fail-safe preserved (#535 semantics): a branch-side edit to ANY
  `test_issue_skill_*.py` dirties the WHOLE workflow family → sync skipped
  (status-quo staleness, never a clobber). Branches that edit SKILL.md + its
  pin test as their deliverable already dirtied the family via
  `.claude/skills`; no change for them.
- Widened skip surface (accepted): a branch editing ONLY a
  `test_issue_skill_*` file (no skills edit) now also skips the
  workflow.yaml/.claude/skills/test_workflow_yaml.py sync — fail-safe
  direction, rare shape.
- Documented residual (β-class, same as the lint family's accepted seam):
  2 of 47 pin tests depend on branch-era scripts/src —
  `test_issue_skill_long_phase_heartbeat.py` imports BOTH
  `autonomous_session_watch` AND `tick_triage` (L53-54) plus src, and
  `test_issue_skill_trigger_dense_tag_adoption.py` importlib-loads
  `src/explore_persona_space/backends/excerpt_digest.py` by path. A synced
  main-new copy depending on a main-new scripts/src symbol can fail against
  the branch-era tree — identical class to the lint family's
  `tests/test_autonomous_session_watch.py` seam; remedy unchanged (rebase
  onto origin/main / cross-check at the repo root). This residual is
  DOCUMENTED IN THE OPERATIVE FILE via the boundary-paragraph amendment
  (acceptance 4b), not only in this plan. The intra-glob import
