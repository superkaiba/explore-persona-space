## 4. Design

### 4.1 The enforced contract (answers the "single-emission" design question)

The rule is enforced as: **any `[phase=done]` emission site in a file that a `scripts/**/*.sh` file invokes with stdout flowing into the invoking log FAILs.** It is deliberately NOT ">1 emission site per family" and NOT "any emission in a non-dispatcher file":

- A dispatcher's OWN emission sites are unrestricted in count — multi-site dispatchers are mode-gated, mutually-exclusive exit paths (`scripts/issue683_dispatch.sh` has 3 sites at lines 145/299/303; `scripts/dispatch_neg_geometry_504.py` has ~10 across `--dry-run`/smoke/V2/V3/V4 paths; each RUN emits at most one). Static mutual-exclusivity is undecidable; flagging site-count in the dispatcher would false-positive on nearly every mode-gated dispatcher in the tree.
- The smoke variant (`[phase=done] SMOKE COMPLETE ...`) is a dispatcher-own-file terminal line — allowed by construction (own-file emissions are never flagged), matching both the rule text and `poll_pipeline.py:340`'s suffixed-terminal parsing contract.
- Standalone scripts that ARE their own dispatcher (e.g. `scripts/issue559_base_prior_persona_panel.py:934`, `scripts/issue532_predictor_stress.py:2846`) emit the terminal into their OWN log — correct per the poller contract; they are only flagged if some `.sh` invokes them non-redirected.

### 4.2 Family discovery (answers the "family discovery" design question)

No dispatcher name-pattern matching and no issue-number grouping. **Family = invocation edges parsed from every `.sh` under `scripts/`** (recursively, subdirs included):

- Walk `scripts/**/*.sh`; for each, iterate `_iter_logical_shell_lines()` output; skip logical lines that are comments or start with `echo ` (dry-run previews, e.g. `scripts/i488_phase1_parallel.sh:119`).
- **Python-target edge:** `PHASE_DONE_PY_INVOKE_RE = re.compile(r"""python3?(?:\.\d+)?\s+(?:-[A-Za-z]+\s+)*["']?(scripts/[A-Za-z0-9_./-]+\.py)\b""")` — matches `uv run python scripts/x.py`, `nohup ... python -u scripts/x.py`, `CUDA_VISIBLE_DEVICES=0 uv run python scripts/x.py`.
- **Shell-target edge:** `PHASE_DONE_SH_INVOKE_RE = re.compile(r"""(?:\bbash|\bsh(?=\s)|\bsource)\s+["']?(scripts/[A-Za-z0-9_./-]+\.sh)\b""")` — catches the `i488_run_all.sh:83/88 → i488_phase{23,4}_dispatch.sh` sub-dispatcher class (both emit `[phase=done]` mid-run_all, non-redirected — a real historical instance of the class).
- **Why this beats the body-sketch alternatives:** parsing invocations out of dispatchers is exactly what I probed on the live tree (§4.5) and it cleanly separates the two 920/545-shaped violation classes from the two legitimate isolation patterns. The fallback "group all `scripts/issue<N>_*.py` by issue number" is REJECTED: it false-positives on every multi-lane design — e.g. issue #810 has a GPU-lane extractor (`issue810_extract_positions.py:640` emits done into its own GCP workload log — the poller contract), a CPU-lane runner, and standalone VM ad-hoc scripts (`issue810_adhoc_*.py`) that each legitimately terminate their own logs. Issue-number grouping cannot tell those logs apart; invocation edges can.
- **Target resolution:** `target_path = root / m.group(1).removeprefix("scripts/")` where `root = scripts_dir or _REPO_ROOT / "scripts"` (makes tmp-fixture tests work unchanged); nonexistent target → skip; self-reference → skip.

### 4.3 Stdout-isolation exclusion

Skip the edge when the logical invocation line redirects stdout away from the main log:

`PHASE_DONE_REDIRECT_RE = re.compile(r"(?:^|\s)(?:1?>>?|&>>?)(?!\s*&)")`

- Matches `> "$WORKER_LOG" 2>&1 &`, `>> log`, `1> log`, `&> log` → edge skipped (the deliberate per-worker isolation pattern: `scripts/issue658_8gpu_dispatch.sh:110`, `scripts/i622_launch.sh:311/344`, `scripts/issue_653/i653_train_lora_wave.sh:52` — all verified skipped on the live tree).
- Does NOT match `2>&1` alone, `2> err.log` (stderr-only; stdout still flows), or `... 2>&1 | tee -a "$LOG"` (tee duplicates to main stdout — the exact #545-family shape at `scripts/issue545_dispatch.sh:35/46/56/71`) → edge still checked. This is deliberate: tee-to-stage-log does NOT isolate the main log.

### 4.4 Emission-site detection (answers the "emission-site" design question)

**For `.py` targets — AST-based** (precedent: `check_upload_as_file`, line 2968). An emission site is an `ast.Call` node where:
- `func` is `ast.Name(id="print")`, OR `func` is `ast.Attribute` with `attr in {"debug","info","warning","error","critical","exception","log","write"}` (covers `logger.info`, `log.info`, `LOGGER.info`, `sys.stdout.write`, `sys.stderr.write`),

AND any `ast.Constant` string reachable by `ast.walk` inside the call's args (covers f-string `ast.JoinedStr` parts and `%`-style format strings like `logger.info("[phase=done] eval cell %s complete", cell)`) contains the literal `"[phase=done]"`.

Excluded by construction, no heuristics needed:
- comments and docstrings (not `Call` args) — kills the `issue778_finetune.py:274` trailing-comment shape (`logger.info("finetune cell %s complete", cell)  # NOT [phase=done] (reserved)`), which a naive line regex flags (verified: my line-level probe false-positived on exactly this line; the AST predicate does not);
- match/read sites: `re.compile(r"\[phase=done\]")` / `re.search(...)` (attrs `compile`/`search` not in the set — `scripts/poll_pipeline.py`'s own detection code passes untouched), `if "[phase=done]" in line` (not a call).

`ast.parse` `SyntaxError` → skip the file (a non-parsing .py cannot run as a phase script; mirrors judge-pin robustness case (m)).

**For `.sh` targets — line-based:** quote-aware trailing-comment strip (small char-scanner helper `_strip_sh_trailing_comment`; tracks in-string state, cuts at unquoted `#`), then a line is an emission iff it contains the token AND matches `PHASE_DONE_SH_EMIT_RE = re.compile(r"\becho\b|\bprintf\b|\bprint\s*\(")` — the `print\s*\(` alternative covers python-heredoc blocks embedded in `.sh` (the `issue810_cpu_phase.sh` `uv run python - <<'PY'` pattern).

**Per-line waiver:** `PHASE_DONE_WAIVER_RE = re.compile(r"#\s*noqa:\s*phase-done-reserved\b")` on the emission line or the immediately preceding non-blank line drops that emission site (convention: `JUDGE_PIN_WAIVER_RE` line 1200). This is the designed escape for dual-mode files whose emission is mode-gated to a standalone-dispatcher lane (§7 risk 1).

### 4.7 Check-function pseudocode

```python
def check_phase_done_reserved(
    *, scripts_dir: Path | None = None,
    allowlist: frozenset[tuple[str, str]] | None = None,
) -> list[str]:
    """Walk scripts/**/*.sh; FAIL any non-redirected invocation of a
    scripts/*.py|*.sh whose file contains a genuine [phase=done] emission
    site — the reserved-token contract of pod-side-reporting.md (#545, #920).
    <docstring: contract, exclusions, waiver, allowlist, residual gaps>"""
    root = scripts_dir if scripts_dir is not None else _REPO_ROOT / "scripts"
    allow = allowlist if allowlist is not None else PHASE_DONE_EDGE_LEGACY_ALLOWLIST
    if not root.exists():
        return []
    errors: list[str] = []
    emission_cache: dict[Path, list[int]] = {}
    for sh in sorted(root.rglob("*.sh")):
        if not sh.is_file():
            continue
        lines = sh.read_text(encoding="utf-8").splitlines()
        for first, _last, logical in _iter_logical_shell_lines(lines):
            stripped = logical.strip()
            if stripped.startswith("#") or stripped.startswith("echo "):
                continue
            m = PHASE_DONE_PY_INVOKE_RE.search(logical) or PHASE_DONE_SH_INVOKE_RE.search(logical)
            if m is None:
                continue
            if PHASE_DONE_REDIRECT_RE.search(logical):
                continue  # per-worker-log isolation (issue658 pattern)
            target_rel = m.group(1)
            target = root / target_rel.removeprefix("scripts/")
            if not target.is_file() or target == sh:
                continue
            if target not in emission_cache:
                emission_cache[target] = (
                    _py_phase_done_emission_lines(target)   # AST predicate + waiver drop
                    if target.suffix == ".py"
                    else _sh_phase_done_emission_lines(target)  # comment-strip + echo/printf/print( + waiver drop
                )
            sites = emission_cache[target]
            if not sites:
                continue
            sh_rel = _repo_rel_posix(sh)  # relative_to(_REPO_ROOT) or absolute posix
            if (sh_rel, target_rel) in allow:
                continue
            errors.append(
                f"{sh}:{first + 1}: invokes {target_rel} (stdout flows into this "
                f"dispatcher's main log) but {target_rel} emits the RESERVED "
                f"[phase=done] token at line(s) {sites}. The token in the MAIN "
                f"dispatcher log is reserved for the dispatcher's single terminal "
                f"line — a mid-pipeline emission reads as a false status=done to "
                f"poll_pipeline.py (incidents #545, #920). Fix: word the child's "
                f"completion line without the phase tag, OR redirect the child's "
                f"stdout to its own log (per-worker pattern: "
                f"scripts/issue658_8gpu_dispatch.sh), OR waive a mode-gated "
                f"standalone-lane terminal with '# noqa: phase-done-reserved' on "
                f"the emission line. See .claude/rules/pod-side-reporting.md."
            )
    return errors
```

## 11. Decision Rationale

- **Family discovery = invocation-edge parsing over all `scripts/**/*.sh`, no name patterns, no issue-number grouping.** Why: name patterns miss `run_all`/`launch`/`driver`/`resume` variants; issue-number grouping false-positives on multi-lane designs (issue #810's three lanes). Source: live-tree probe this plan (§4.5); `check_dispatcher_cvd_pin` walk pattern, `scripts/workflow_lint.py:2160-2176`.
- **Emission predicate = AST for `.py`, comment-stripped `echo|printf|print(` for `.sh`.** Why: the only line-regex FP found on the live tree (`issue778_finetune.py:274`) is a trailing comment, killed exactly by AST; match-site exclusion falls out for free. Source: `check_upload_as_file` AST precedent (workflow_lint.py:2968); live-tree probe.
- **Violation unit = non-redirected invoked-child emission; dispatcher own-file emissions unrestricted.** Why: mode-gated multi-exit dispatchers are ubiquitous and legitimate (issue683 ×3, neg_geometry_504 ×~10); the poller's own contract permits suffixed terminals (`poll_pipeline.py:340`). Source: `.claude/rules/pod-side-reporting.md` requirement 1; `scripts/poll_pipeline.py:216-349`.
- **Redirect exclusion (`>`/`>>`/`&>` stdout only; `tee` and `2>` still checked).** Why: the deliberate isolation pattern is `> "$WORKER_LOG" 2>&1` (issue658:110, i622:311); the incident pattern is `2>&1 | tee -a` (issue545:35-71). Source: those files, verified this plan.
- **Allowlist grain = (invoker, target) edge pairs, frozen, annotated, + pre-seeded #920 edge.** Why: file-grain would exempt future new invokers of legacy emitters; the #920 dual-mode edge is a dated, verified future merge. Source: `JUDGE_PIN_LEGACY_ALLOWLIST` pattern (workflow_lint.py:1138-1199); `git show issue-920:scripts/issue920_nulls_figures.py` lines 774-785.
- **Waiver token `# noqa: phase-done-reserved`.** Source: `JUDGE_PIN_WAIVER_RE` convention (workflow_lint.py:1200).
