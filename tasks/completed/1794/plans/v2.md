## Goal / Requirement

Persist `~/.local/bin` (uv's install dir) on PATH for non-login / ad-hoc /
detached shells on both compute lanes, so recovery phases, sudo/setsid
detached commands, and ad-hoc SSH probes resolve `uv` without a per-command
transient export.

**Acceptance criteria:**

1. The rendered GCE startup script (`backends/gcp.py::render_startup_script`)
   symlinks `uv` (and `uvx` when present) into `/usr/local/bin` after the
   uv-install block, AND writes an `/etc/profile.d/eps-uv-path.sh` drop-in
   exporting `PATH="$HOME/.local/bin:$PATH"`.
2. `scripts/bootstrap_pod.sh` appends `export PATH="$HOME/.local/bin:$PATH"`
   to `/root/.bashrc` + `/root/.profile` in a SEPARATELY presence-guarded
   block (the #1172 PYTHONPATH pattern), so already-bootstrapped pods gain it
   on any re-bootstrap.
3. `bash -n scripts/bootstrap_pod.sh` passes; ruff clean on touched `.py`.
4. New pin tests cover both halves; existing pin tests stay green.

## Method delta (vs the filed candidate sketch)

The filed body proposed ONLY an `/etc/profile.d/` drop-in for GCE. Clarifier
finding: profile.d is sourced by LOGIN shells only — it would NOT have fixed
the founding incident (#1739: recovery upload phase launched via sudo/setsid
died `uv: command not found`, exit 127). The load-bearing GCE leg is instead
the pod-proven `/usr/local/bin` symlink pattern (bootstrap_pod.sh commit
`b3d2dfbf1d`, 2026-05-28): `/usr/local/bin` is on the default PATH of
non-login shells AND in sudo's `secure_path`. The profile.d drop-in is kept
as the additive login-shell leg. The pod half shrinks to the residual the
clarifier verified: rc files carry no PATH export (memory
`feedback_pod_uv_path.md`); the non-login pod case is already covered by the
b3d2dfbf1d shim.

Scope caveat (carried forward): #1689's pod-side probe failure happened on a
pod whose bootstrap steps 5-11 never ran — NO PATH-persistence change fixes
an unbootstrapped pod; that class stays owned by the experimenter's
post-dispatch bootstrap-completeness probe.

## File paths + concrete diffs

### 1. `src/explore_persona_space/backends/gcp.py` (render_startup_script, immediately after the uv-install `fi` at ~L2947)

```python
"# Persist uv on the default PATH for later non-login/sudo/setsid shells",
"# (#1794; founding incident #1739 exit-127). /usr/local/bin is on the",
"# default PATH incl. sudo secure_path — mirrors the pod-side b3d2dfbf1d",
"# pattern; the profile.d drop-in additionally covers login shells.",
'UV_BIN="$(command -v uv 2>/dev/null || true)"',
'[ -z "$UV_BIN" ] && [ -x "${HOME:-/root}/.local/bin/uv" ] && UV_BIN="${HOME:-/root}/.local/bin/uv"',
'if [ -n "$UV_BIN" ]; then',
'  ln -sf "$UV_BIN" /usr/local/bin/uv',
'  [ -x "$(dirname "$UV_BIN")/uvx" ] && ln -sf "$(dirname "$UV_BIN")/uvx" /usr/local/bin/uvx || true',
"fi",
"printf 'export PATH=\"$HOME/.local/bin:$PATH\"\\n' > /etc/profile.d/eps-uv-path.sh",
```

(Exact quoting/escaping refined by the implementer inside the Python list —
the startup script is a list of strings joined by newlines; GCE startup
scripts run as root, so `/usr/local/bin` + `/etc/profile.d` are writable.
The `${HOME:-/root}` form matches the existing wrappers at L1809/2523.)

### 2. `scripts/bootstrap_pod.sh` (new separately guarded block, adjacent to the #1172 PYTHONPATH rc-append block at ~L369-378)

**Quoting constraint (round-1 critic Must-Fix):** this insertion point sits
INSIDE the step-6 `ssh_cmd '...'` single-quoted argument (opens ~L331,
closes ~L455), so (a) the guard cannot carry bare inner single quotes, and
(b) a remote double-quoted `$HOME` would EXPAND on the remote shell
(pattern becomes `PATH="/root/...`) and never match the heredoc-written
LITERAL line — a silent false-negative guard → duplicate appends on every
re-bootstrap. The escaped form below survives the outer single-quoted
string and reaches remote grep as a literal `$`:

```bash
# ~/.local/bin on PATH for interactive/login shells (#1794; the non-login
# case is covered by the /usr/local/bin shims above). Separately guarded so
# already-bootstrapped pods gain it on any re-bootstrap.
for f in /root/.bashrc /root/.profile; do
    if ! grep -qF "PATH=\"\$HOME/.local/bin" "$f" 2>/dev/null; then
        cat >> "$f" <<"RC3EOF"

# uv install dir on PATH (#1794)
export PATH="$HOME/.local/bin:$PATH"
RC3EOF
    fi
done
```

(The heredoc body is nest-safe as written — double quotes only, `$` kept
literal by the quoted `RC3EOF` delimiter; precedent: the existing
PYTHONPATH guard at ~L370 works remotely only because its pattern carries
no `$`.)
