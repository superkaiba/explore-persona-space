# Plan v2 — #2180: Support-restricted companion lens for degenerate matching covariates

## Requirement + acceptance criteria

Add a review lens requiring a **support-restricted companion read** whenever a headline
correlational / partial / matched / stratified statistic's matching (or stratification /
conditioning) covariate is degenerate — zero-or-tied — on a large majority of the analysis
sample. In that regime "matched" does no work on the dominant block and the headline can be
carried entirely by the sub-population where matching is inert, while every existing
mechanical check (selection-symmetric null band, exchangeability, positive controls) passes.

Acceptance criteria (verbatim from the task body):

1. The lens exists in the statistics/measurement lens roster with its trigger and the
   support-restricted companion requirement.
2. `interpretation-critic` carries the matching-lens check so the interpretation-time catch
   is not luck next time.
3. The threshold and the "tied fraction" definition are written down (a covariate can be
   degenerate by ties without being zero).
4. Tests pin whatever mechanical form lands.
5. The mechanical check fires on #2163's own committed `predictor_partials.json` as a
   regression fixture — that artifact is the known-positive case.

## Method delta (what differs from existing machinery)

`selection-symmetric-nulls.md` + the existing Statistics items 9/11 police the NULL side
(selection effects, band construction, degenerate eligibility gates). Nothing polices the
SUPPORT of the matching covariate itself: #2163's headline (activity-matched partial
Spearman 0.239 vs 0.0092 band, matching variable `lasttoken_count`) passed the planner, the
full critic ensemble, the consistency-checker, the code-review ensemble, and the analyzer —
`lasttoken_count` is identically 0 on ~90% of the 131k-feature sample, the two named
headline predictors carry ~zero signal on the 13k features that actually fire
(`proj_var` −0.243 full → −0.003 on-support; `scaffold_frac` −0.210 → +0.015 sign-flipped),
and only an interpretation-critic raw-artifact recompute caught it. This lens makes that
recompute a standing requirement instead of luck.

## Canonical definitions (acceptance criterion 3 — these exact definitions land in the lens text and the helper docstring)

- **Tied fraction** of a matching covariate = the share of the complete-case analysis
  sample (the same rows the headline statistic is computed over) holding the covariate's
  single most frequent value (the modal tie block). Value-agnostic: zero-inflation
  (`lasttoken_count == 0` on 89.7% of #2163's pool) is the common case, but a covariate is
  equally degenerate when tied at any other value.
- **Threshold**: tied fraction > **0.5** ⇒ the covariate is DEGENERATE on the sample and
  the lens fires. (At >0.5 the modal block is the majority, so the rank transform puts most
  of its mass in one giant tie and the partial/stratification removes nothing there.)
  Near-threshold or multi-modal tie profiles (two large blocks each <0.5) stay a judgment
  call for the reviewing lens — the helper exposes the top-k tie profile for exactly that
  read; the mechanical check keys on the >0.5 modal-share form only.
- **Support** = the complement of the modal tie block on the analysis sample.
- **Support-restricted companion** = the same headline statistic recomputed on the support
  rows only, reported alongside the full-pool value, with the narration attributed to
  whichever population carries the effect.

### 5. `src/explore_persona_space/analysis/matched_support.py` — NEW module (the mechanizable form)

- `tied_fraction(x: np.ndarray) -> float` — modal-value share on the complete-case sample
  (NaN rows excluded before the modal count; raises on empty input — fail-fast, no silent
  default).
- `tie_profile(x, k=5)` — top-k `(value, share)` pairs, for the multi-modal judgment read.
- `support_mask(x) -> np.ndarray[bool]` — True off the modal tie block.
- `audit_matched_artifact(artifact: dict, *, tie_fraction: float | None = None,
  covariate: np.ndarray | None = None, threshold: float = 0.5) -> dict` — the check:
  resolves the tie fraction from (priority) explicit arg → `covariate` values →
  a recorded `match_tie_fraction`-bearing field in the artifact; RAISES when none is
  available (an indeterminate audit is loud, never a silent pass); scans the artifact for
  a support companion (any `*_on_support` key, or a per-population block with a
  support-defined population); returns
  `{degenerate, tie_fraction, tie_fraction_source, has_support_companion, fires}` where
  `fires = degenerate and not has_support_companion`.
