### 4.3 Detection predicate (exact regexes)

Constants block (placed with the other check constant blocks, with a flagged/not-flagged matrix comment):

```python
# `--check-upload-or-true`: an upload / result-persist command whose failure
# is swallowed by `|| true` / `|| :` / `; true` (#841: swallowed result-upload
# failures silently lost stage JSONs/plots across attempts until v17).
UPLOAD_OR_TRUE_SWALLOW_OR_RE = re.compile(r"\|\|\s*(?:true\b|:(?=[\s;)&|]|$))")
UPLOAD_OR_TRUE_SWALLOW_SEMI_RE = re.compile(r";\s*true\s*$")
# Shell-line upload/result-persist tokens:
UPLOAD_OR_TRUE_LINE_TOKEN_RE = re.compile(
    r"(?:"
    r"\bupload_file\b|\bupload_folder\b|\bupload_raw_completions\b"   # HF helper calls
    r"|\bhf\s+upload\b|\bhuggingface-cli\s+upload\b"                  # hub CLI
    r"|\b[A-Za-z0-9_]*upload[A-Za-z0-9_]*\.py\b"                      # upload helper scripts
    r"|\bgit\s+push\b"                                                # git persistence
    r"|\bgit\s+(?:add|commit)\b[^#]*\b(?:eval_results|figures|ood_eval_results)\b"
    r"|\$\{?HF_DATA_REPO\b|\$\{?HF_MODEL_REPO\b"                      # repo-destination env vars
    r")"
)
# Heredoc-BODY upload-call tokens (inline-python upload blocks — the dominant
# dispatcher upload shape: #654/#632/#931 all upload via `uv run python - <<'PY'`):
UPLOAD_OR_TRUE_BODY_TOKEN_RE = re.compile(
    r"(?:\bupload_file\s*\(|\bupload_folder\s*\(|\b_upload\s*\("
    r"|\bupload_raw_completions\b|\bcreate_commit\s*\(|\.push_to_hub\s*\()"
)
UPLOAD_OR_TRUE_WAIVER_RE = re.compile(r"#\s*UPLOAD_OR_TRUE_EXEMPT:\s*(.+)")
UPLOAD_OR_TRUE_WAIVER_MIN_REASON_CHARS = 10
```

Per logical line (after `_strip_sh_trailing_comment`, `.strip()`):

1. **Skip** logical lines starting with `#` (comments — mandatory: `issue841_scaling_dispatch.sh:85` is a comment containing both `|| true` and `upload`; also `issue654_dispatch.sh:159`, `new_worktree.sh:139/244–246`) or `echo ` (an echo cannot swallow an upload — CVD precedent; note `check_pipe_python` deliberately does NOT skip echo because there the echo IS a real producer — here an echo line performs no upload, so the skip is sound).
2. **`|| true` / `|| :` — segment-scoped:** split the stripped logical line on `&&` and `;` (naive split, quote-unaware — fail direction is false-NEGATIVE, the safe direction per the `_strip_sh_trailing_comment` philosophy); flag iff some segment matches BOTH `UPLOAD_OR_TRUE_SWALLOW_OR_RE` and `UPLOAD_OR_TRUE_LINE_TOKEN_RE`. This kills the `mkdir -p "$OUT" || true && uv run python scripts/verify_uploads.py` false-positive class.
3. **Terminal `; true` — whole-line:** if `UPLOAD_OR_TRUE_SWALLOW_SEMI_RE` matches the stripped logical line, flag iff `UPLOAD_OR_TRUE_LINE_TOKEN_RE` matches anywhere on it (a terminal `; true` masks the whole line's exit status). Zero live hits of this shape (verified).
4. **Heredoc bodies:** if the opener logical line carries any swallow (step 2 or 3 swallow regex, token not required on the opener), scan each of its heredoc bodies' non-`#`-comment lines for `UPLOAD_OR_TRUE_BODY_TOKEN_RE`; a match flags the OPENER line. This catches `i632_dispatch_with_log_capture.sh:30` (opener has no token; body calls `api.upload_file(` at :69) — the shape a line-only scan provably misses.
5. **Dedupe** per (file, opener first-line): a line can hit via both the line token and the heredoc body (issue654: `$HF_DATA_REPO` on the opener AND `_upload(` in the body) — emit ONE error.
6. **Waiver:** suppress when `# UPLOAD_OR_TRUE_EXEMPT: <reason>` (reason ≥ 10 chars after strip) appears on any physical line of the logical command or the immediately preceding non-blank line — reuse the `_cvd_pin_waiver_present` placement logic (write a sibling `_upload_or_true_waiver_present`, or generalize the CVD helper to take the regex + min-chars as params; either is fine, generalizing preferred). Waiver detection runs on the RAW lines (before comment stripping — the waiver IS a comment). Note a trailing comment after a heredoc redirect (`... <<'PY' || true  # UPLOAD_OR_TRUE_EXEMPT: ...`) is valid bash, so both placements work on heredoc openers.

**Error message** (mirror CVD verbosity): `{sh}:{first+1}: upload/result-persist command swallows failure with '|| true' / '; true'. A swallowed upload failure silently loses result artifacts (#841: stage JSONs/plots lost across attempts until v17 removed it) — remove the swallow and let the failure abort (fail fast; the crash-persist/poller path reports it). A deliberate best-effort side-channel (crash-diagnostics upload) is waived with '# UPLOAD_OR_TRUE_EXEMPT: <reason>' (reason ≥ 10 chars) on the same or previous non-blank line.`
