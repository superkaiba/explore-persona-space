# Plan v1 — sweep emits `unmatched_record_fps` advisory (#1703)

## 1. Goal + hypothesis

**Goal:** Emit a top-level `unmatched_record_fps` advisory field from
`scripts/sweep_parked_wf_candidates.py` listing same-stream filed-record
fingerprints that match NO enumerated candidate fingerprint. Purpose:
detect driver fingerprint-recomputation drift (the #1630 class) the
moment it recurs, rather than waiting for the #1680 ts-claim fallback to
tolerate it indefinitely.

**Hypothesis (acceptance criterion):** After landing, a synthetic tmp
task tree with (candidate fp=A) + (filed record fp=B ≠ A, matching
`origin_candidate_ts`) produces:
- `unmatched_record_fps == [{"source": "task:<id>", "ref": "#<M>", "fp": "B"}]`
- The candidate remains `suppressed=True` via the #1680 ts-claim
  fallback (semantics unchanged).

## 2. Method delta (from parent state)

Purely additive. No existing key/value/behavior changes. Constraints:
- Every existing test in `tests/test_sweep_parked_wf_candidates.py` (46+
  cases across 17 sections) passes BYTE-BEHAVIOR-IDENTICALLY.
- The new `unmatched_record_fps` field is ADVISORY only: never gates,
  suppresses, or re-enumerates.
- Fail-soft on malformed filed records (missing / unparseable fp
  silently dropped from the advisory; never raises).

### 3.1 `scripts/sweep_parked_wf_candidates.py`

**New module-level regex** (near existing `_KIND_HINT_RE`):
```python
# 12-hex fingerprint pattern (matches wf_fix_fingerprint(...)[:12]).
# Used to extract a filed record's real fp for the unmatched_record_fps
# advisory (#1703). Word-boundary bracketed so a 12-hex prefix of a
# longer sha does NOT false-match.
_FP_HEX_RE = re.compile(r"\b([0-9a-f]{12})\b")
_FILED_FP_NOTE_RE = re.compile(
    r"(?:fingerprint:\s*|wf-fix-fp:)([0-9a-f]{12})\b"
)
```

**New helper** (after `_filed_ref`, before `_load_task_bodies`):
```python
def _extract_filed_fp(record: dict) -> str | None:
    """One 12-hex fingerprint from a filed record, or None (#1703).

    Structured ``record["fingerprint"]`` key wins over note-embedded
    values. Prose values (``n/a (prose park)``, ``n/a-fp``, empty string)
    never yield a hit — the 12-hex word-boundary regex requires the exact
    canonical shape ``wf_fix_fingerprint(...)[:12]`` produces.

    Advisory use only: consumers must never gate on the return value.
    """
    raw = record.get("fingerprint")
    if isinstance(raw, str):
        m = _FP_HEX_RE.search(raw)
        if m:
            return m.group(1)
    note = str(record.get("note") or "")
    m = _FILED_FP_NOTE_RE.search(note)
    if m:
        return m.group(1)
    return None
```

**`sweep()` modification** — inside the per-stream loop (after building
`filed` list, before the per-candidate loop), collect enumerated
candidate fps FROM THIS STREAM. After the per-candidate loop, iterate
`filed` extracting the record's fp and comparing against the
per-stream candidate fp set. Accumulate into a top-level list:

```python
# At function top, alongside `candidates: list[Candidate] = []`:
unmatched_record_fps: list[dict] = []

# ── inside the `for source, paths in streams:` loop, after `filed = [...]`
# and after the per-candidate loop closes ──

# Enumerated candidate fps FOR THIS STREAM (fp-computable candidates
# only; fp-less prose parks contribute nothing to the enumerated set).
stream_enumerated_fps = {
    c.fingerprint for c in candidates
    if c.source == source and c.fingerprint is not None
}
# Track fps we've already emitted for THIS stream so a record-fp that
# appears in multiple filed records emits ONCE per stream (advisory
# dedup — the /daily consumer wants one investigation entry per drift,
# not one per repeated routed-record).
seen_unmatched: set[str] = set()
for record, _record_ts in filed:
    rec_fp = _extract_filed_fp(record)
    if rec_fp is None:
        continue  # prose-park record / no extractable fp — nothing to detect
    if rec_fp in stream_enumerated_fps:
        continue  # matches an enumerated candidate on this stream — normal case
    if rec_fp in seen_unmatched:
        continue  # already listed this drift for the stream — dedup within stream
    seen_unmatched.add(rec_fp)
    unmatched_record_fps.append({
        "source": source,
        "ref": _filed_ref(record),
        "fp": rec_fp,
    })
```

# ── 18. unmatched_record_fps advisory (#1703) ──────────────────────────

def test_unmatched_record_fp_emitted_when_fp_differs_from_candidate(tmp_path):
    """Filed record carries a real fp differing from the candidate's
    enumerated fp AND names the candidate's ts (the #1630 drift shape):
    the record still SUPPRESSES via the #1680 ts fallback, AND the
    unmatched fp is recorded in the advisory for investigation."""
    bug, change = "drift bug.", "drift change."
    cand_fp = wf_fix_fingerprint(change, bug)
    drift_fp = "abcdef012345"  # 12 hex, ≠ cand_fp
    assert drift_fp != cand_fp
    make_task(
        tmp_path, 100, "completed",
        events=[
            cand_row(T0, block_note("a/b.md", bug, change)),
            filed_row(
                T1,
                f"filed_task: #200 / target_file: a/b.md / "
                f"fingerprint: {drift_fp} / origin_candidate_ts: {T0}",
            ),
        ],
    )
    result = run_sweep(tmp_path, include_routed=True)
    # Suppression semantics UNCHANGED — the ts fallback closes the park.
    c = only(result)
    assert c["suppressed"] is True
    assert c["suppressed_by"]["kind"] == "same-stream-filed"
    # NEW: the drift is surfaced in the advisory field.
    assert result["unmatched_record_fps"] == [
        {"source": "task:100", "ref": "#200", "fp": drift_fp}
    ]


def test_unmatched_advisory_empty_when_all_fps_match(tmp_path):
    """Normal suppression case (test 3): filed fp EQUALS candidate fp.
    Advisory is EMPTY — the field exists but no drift surfaced."""
    bug, change = "bug one.", "change one."
    fp = wf_fix_fingerprint(change, bug)
    make_task(
        tmp_path, 101, "completed",
        events=[
            cand_row(T0, block_note("a/b.md", bug, change)),
            filed_row(T1, f"filed_task: #201 / fingerprint: {fp}"),
        ],
    )
    result = run_sweep(tmp_path, include_routed=True)
    assert result["unmatched_record_fps"] == []
    assert only(result)["suppressed"] is True  # semantics preserved


def test_unmatched_advisory_ignores_prose_and_na_fp_records(tmp_path):
    """Fail-soft: a filed record with prose-only fp values (n/a, empty
    string, missing entirely) contributes NOTHING to the advisory —
    never raises."""

        tmp_path, 102, "completed",

            cand_row(T0, PROSE_NOTE),
            filed_row(T1, "filed_task: #202 / fingerprint: n/a (prose park)"),
            filed_row(T2, "filed_task: #203 / target_file: scripts/codex_task.py"),

    )
    result = run_sweep(tmp_path, include_routed=True)
    assert result["unmatched_record_fps"] == []


def test_unmatched_advisory_dedupes_within_stream(tmp_path):
    """A drift fp appearing in TWO filed records on the same stream
    emits ONCE (advisory dedup — one investigation entry per drift)."""
    bug, change = "d bug.", "d change."
    drift_fp = "cafebabe0011"
    make_task(
        tmp_path, 103, "completed",
        events=[
            cand_row(T0, block_note("a/b.md", bug, change)),
            filed_row(
                T1,
                f"filed_task: #301 / fingerprint: {drift_fp} / origin_candidate_ts: {T0}",
            ),
            filed_row(
                T2,
                f"filed_task: #302 / fingerprint: {drift_fp} / origin_candidate_ts: {T0}",

    result = run_sweep(tmp_path, include_routed=True)
    assert len(result["unmatched_record_fps"]) == 1
    entry = result["unmatched_record_fps"][0]

## 4. Design decisions (adversarial rationale)

1. **Per-stream, not global.** The advisory groups by source so a drift
   on task:X does not contaminate task:Y. Matches the existing
   `filed` scope (rule 1 in the module docstring).
2. **Word-boundary 12-hex regex.** Precisely matches
   `wf_fix_fingerprint(...)[:12]`. A 40-hex SHA is not word-boundary-
   matched as a 12-hex prefix (both boundaries required).
3. **Structured key wins over note-embedded.** Mirrors
   `_filed_record_matches` line 383 precedent
   (`str(record.get("fingerprint") or "")`).
4. **Dedup within stream.** A drift fp repeated across records on one
   stream is ONE investigation, not N — matches the analogous row-dedup
   rule 3 pattern.
5. **Field position in JSON.** Between `skipped` and `candidates` — the
   docstring's advisory-first convention.
6. **No cache-stream exception.** The cache stream is its own group
   (line 673); it contributes advisory entries under `source: "cache"`
   naturally.
