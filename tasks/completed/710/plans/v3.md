## 2. Method Delta

**Current state of `tests/test_issue_dispatch.py`:** each of the two `_PR` mocks is a
`@dataclass(frozen=True)` that mimics a SUBSET of `scripts.poll_pipeline.PollResult` —
only the fields that `RunPodBackend.poll` (and `backend_poll._serialize_poll_result`)
read via `raw.<field>`. Both mocks list fields ending at `next_interval: int = 1800`
and stop there. The real `PollResult` (poll_pipeline.py:707-766) was later extended
with `stall_reason: str | None = None` (#664), and `RunPodBackend.poll` was wired to
copy it through (`stall_reason=raw.stall_reason`, runpod.py:389). The mocks were never
updated, so `raw.stall_reason` raises `AttributeError` on the mock instance.

**Delta:** append `stall_reason: str | None = None` as the final dataclass field of
EACH `_PR` mock (after `next_interval: int = 1800`). Nothing else changes — same
default (`None`) and type (`str | None`) as the production field, keeping the mock's
field order aligned with `scripts.poll_pipeline.PollResult` so the shapes diff cleanly.

**Why this and not the alternatives in the task body:**
- Body option (A) — "add the field to `_PR`" — is the right SHAPE, but the body
  pointed it at `runpod.py`. The `_PR` struct lives in the TESTS, not runpod.py. The
  fix is option (A) applied to `tests/test_issue_dispatch.py`.
- Body option (B) — `getattr(raw, "stall_reason", None)` at runpod.py:389 — is WRONG.
  `PollResult` is a frozen dataclass with `stall_reason` guaranteed present in
  production; a defensive `getattr` would silently drop a real value
  (`"vllm_worker_dead_zombie_gpu"`) and weaken the #664 detection contract. The
  docstring at runpod.py:362-375 explicitly documents this passthrough as load-bearing.
  Do NOT touch runpod.py.

**Scope-expansion grep result:** searched the whole `tests/` tree for

mocks are the two in `test_issue_dispatch.py` (lines 134 and 1174). The

`test_poll_next_interval.py` and `test_poll_pipeline_zombie_gpu.py` hits use the REAL
`PollResult` (which already has `stall_reason`) — they are correct and need no change.
**No other mocks share the staleness pattern; the whole regression class is the two
