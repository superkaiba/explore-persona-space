### Edit 1 (PRIMARY) — `.claude/rules/gotchas.md`

Append the following entry as a new bullet, placed after the existing #621 `on_log` entry (line 108) so the two Trainer-callback entries sit adjacent:

```markdown
- **A hand-rolled HF Trainer callback that does not subclass `transformers.TrainerCallback` crashes at `Trainer.__init__` — and a CPU dry-run/import-check smoke for a GPU-bound training phase can NEVER catch it.** Two coupled traps. (1) `CallbackHandler.call_event` (`trainer_callback.py:554`) fires EVERY lifecycle event on every registered callback via `getattr(callback, event)(...)` (`:556`), and the FIRST event — `on_init_end` — fires inside `Trainer.__init__` itself (`trainer.py:799`; reached from `train_lora`'s `SFTTrainer(**sft_trainer_kwargs)` at `src/explore_persona_space/train/sft.py:1465`). Only a `TrainerCallback` subclass inherits the no-op defaults (`trainer_callback.py:297`/`:350`), so a bare class dies on the first event regardless of which hooks it actually implements — and a docstring *claiming* `TrainerCallback` is not the base class; check the literal `class X(TrainerCallback):` line. (2) The bug is invisible to any smoke that does not construct a real trainer: when the phase is GPU-bound (`device_map={"": 0}`), the tempting CPU substitutes (dry-run / signature check / import check) never traverse `SFTTrainer.__init__`, so the crash surfaces only in production. RULE: any diff passing `callbacks=[...]` to `train_lora` / an HF Trainer (a) subclasses `transformers.TrainerCallback` (assert it in code review), and (b) is smoked through the REAL `SFTTrainer.__init__ → on_init_end → on_train_begin → step → on_train_end` lifecycle — a tiny same-arch model (e.g. Qwen2 0.5B) on CPU with `max_steps=1-2` does it in minutes; a dry-run/import-check substitute is NOT a valid smoke for a callback-bearing training phase. Diagnostic signature: `AttributeError: '<YourCallback>' object has no attribute 'on_init_end'` at trainer construction. Distinct from the `on_log`/wandb entry above (#621 — that callback subclassed correctly; the trap there is cross-callback metric visibility). (Incident #816, 2026-07-02: `PreventativeSteeringCallback` had no base class despite its docstring; all preventative cells died at SFTTrainer init AFTER 8/8 probe + 53/53 steering cells had burned GPU-hours; fix was +3/-1 — import + subclass — commit `daeb2f73dd`. Implementer-side enforcement: `.claude/agents/experiment-implementer.md` § smoke-contract requirements + `.claude/agent-memory/experiment-implementer/feedback_trainer_callback_must_subclass_trainercallback.md`.)
```
