## 3. Fix design

**Leg 1 — install the 6 lean twins user-global as SYMLINKS to the repo files** (the mechanism change):

```bash
for a in code-reviewer critic consistency-checker experiment-implementer implementer planner; do
  ln -sfn /home/thomasjiralerspong/explore-persona-space/.claude/agents/${a}-lean.md \
          ~/.claude/agents/${a}-lean.md
done
```

- Symlink, not copy: the project file stays the single source of truth; a project-side edit propagates with zero drift, so no new lint check is needed (the user-global entry IS the project file). Recorded decision vs the body's "add a drift check" sketch: symlinks make drift structurally impossible; a broken-link failure mode (repo moved/renamed) is caught by the verification recipe below and is loud (agent type vanishes from the list).
- User-global registration is cwd-independent (probe + analyzer-lean precedent), so every future session — repo-root, worktree, /tmp, pod-side VM sessions — resolves all 6 regardless of which branch vintage its cwd carries.
- Name-collision precedence: in a cwd whose project `.claude/agents/` also carries the file, the project copy wins — harmless either way (both defer to the full spec by reference).
- The install itself is OUTSIDE the git tree (`~/.claude/agents/`); the implementer performs it and records the `ls -l` evidence in its marker. Nothing under `~/.claude/` is committed to this repo.
