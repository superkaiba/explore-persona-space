### 3.2 Degeneracy tripwire (D2)

New pure function in fit825 (ma/cm import it):

```python
def degeneracy_tripwire(*, n_train, d, selected_lambdas, r2_heldout=None,
                        knn_at_1=None, knn_chance=None, grid=None) -> dict:
    grid = LAMBDAS if grid is None else np.asarray(grid)
    reasons = []
    if n_train < d and selected_lambdas and min(selected_lambdas) <= float(grid[1]):
        reasons.append("n_lt_d_lambda_at_grid_edge")     # arm (a): within one grid step of the lower edge
    if (r2_heldout is not None and r2_heldout < 0.0
            and knn_at_1 is not None and knn_chance and knn_at_1 > 20.0 * knn_chance):
        reasons.append("negative_r2_with_retrieval_dissociation")   # arm (b)
    flag = bool(reasons)
    if flag:
        print(f"[fit825] WARN estimator_degenerate_suspect: {reasons} "
              f"(n_train={n_train}, d={d}, lambdas={sorted(set(selected_lambdas))})", flush=True)
    return {"estimator_degenerate_suspect": flag, "reasons": reasons,
            "n_train": n_train, "d": d}
```

Wired into `run_cell` / `heldout_r2_sweep` payloads (fields merged into the cell JSON) and into the audit script. Arm (b) evaluates only where the calling rig computes retrieval (`knn_at_1=None` skips it — the shared core never fabricates a retrieval read).

**Auto reduced-basis companion:** in the fit825 sweep entrypoints, when `n_train < d`, additionally compute the per-fold train-basis reduced fit — `k = reduced_basis_k(n_train_min, d_in)` (ported from `scripts/issue1345_boundary_ablation_fits.py:663`, Gram-route PCA on train rows only: eigenvectors of the n×n train Gram via the existing `_eigh_robust`, never an (n,d) SVD), then the SAME ridge+selector kernel in the k-dim basis — and embed `{"reduced_basis": {"k": k, "r2_heldout": ...}}` in the payload. Promotes the #1701 dispatch-note duty to a code default, exactly as the body specifies. Opt-out kwarg `reduced_basis_companion=True` default (a caller that cannot afford it sets False loudly).

## 6. Kill criteria

- **Replay failure (systemic):** > 10% of cells in any issue fail the |ΔR²| ≤ 1e-3 replay gate → staging/fold reconstruction is broken; HALT the audit for that issue, fix identity before ANY corrected read is produced. - **Corrected-selector failure:** if inner-group-cv ALSO lands at the grid edge with negative held-out R² on > 25% of real n<d cells while retrieval stays > 20× chance, the "registered selector fixes it" half of the premise is falsified → the flip is re-scoped to reduced-basis-primary (defaults still flip; the corrections tables headline reduced-basis only) and the finding is surfaced in the report.
- **Caller-pinning breakage:** if pinning class-A callers cannot preserve their arm semantics byte-identically (test-verified), the flip mechanics are reworked (e.g., kwarg-only flip without module-global change) before merge.

## 11. Decision Rationale

- **inner-group-cv as default.** What: registered selector scores each λ by summed inner-validation RSS on group-held-out inner folds. Why: directly the deployed generalization criterion; immune to the (n−dof)² degeneracy. Source: #1417 (11/11 framing fits verdict-bearing under it), #1335 r8 (fit825 L68-77 incident numbers), #1689. Alternatives: capped GCV as default (rejected — mitigation, not the registered criterion; kept as fallback), reduced-basis as default primary (rejected as *selector* default — it changes the estimand's basis; kept as the mandatory n<d companion).
- **dof cap 0.9 (GCV fallback + opt-in GCV).** Why: excludes (near-)interpolating λ where RSS→0 and (n−dof)²→0 make the objective degenerate. Source: #1417 refit rounds; `issue1310_xpersona_similarity.py:74` (`MANDATORY: uncapped GCV degenerates on this n<p store`); fit825 L82-90. Literature context: GCV per Golub–Heath–Wahba (1979, *Technometrics* 21(2)); the small-n/undersmoothing pathology of GCV minima at near-interpolation is long documented — the load-bearing grounding here is the project's own measured incidents (#1310/#1345/#1417). Alternatives: exact LOOCV/PRESS (degenerates identically at n<d — fit825 L84-85), λ-grid floor raise (arbitrary; doesn't generalize across scales).
- **Refusal (raise) rather than silent auto-switch at n<d.** Why: the Goal is "impossible to run *silently*"; an auto-switch would silently change a deliberately-pinned experiment arm's estimator. Source: fail-fast Critical Rule; #1887 body deliverable 1. Alternative: WARN-and-switch (rejected — exactly the silent path the Goal bans).
- **k rule min(1024, ⌊n_train/2⌋, d_in).** Source: `4682f0247a` (+ body deliverable 2); well-posed by construction (n_train > k ≥ 2× margin).
- **Grid-edge tripwire threshold (≤ `LAMBDAS[1]`, one half-decade step).** Source: `4682f0247a` (λ=0.01 grid floor 5/5 folds on the incident cells); the one-step margin catches near-edge selections the exact-floor test misses; grid from fit825 L66.
- **20× chance retrieval bar (arm b).** Source: task #1887 body (deliverable 2 pins "~20x"); incident measured ~300× (raw retrieval) and 84–96× (forced-λ kNN@1 vs 1/n_pool) — 20× is conservatively below both by ≥ 4×, above any plausible noise ceiling (chance CI at n_pool ≈ 350 is ≪ 20×).
- **Replay gate |ΔR²| ≤ 1e-3.** Source: probe same-machine equivalence |Δ| < 1e-9 (`4682f0247a` message) + cross-backend eigh fp64 headroom; deliberately loose by ~10⁶ vs same-machine to absorb CPU/GPU reduction-order differences while staying ~500× below the smallest correction of interest (|Δ| ~0.5). Marked: gate recalibration only downward, from P0 measurements.
- **Reduced-basis unselected as corrections headline; forced-λ diagnostic only.** Source: events v2 correction note (endorsed convention) — forced-λ is post-hoc-selected over the sweep; reduced-basis involves no post-hoc selection.
