### 4.1 `scripts/daily_drive_filings.py` — extractor (new, near `parse_filed_id` ~L757)

```python
# #1529: the filer's sibling-advisory stderr shapes (file_infra_task.py L312/L363
# headers, L318-327/L372-381 rows+overflow, L329-333/L382-386 fail-soft lines).
_ADVISORY_HEADER_SUBSTR = "file_infra_task: ADVISORY"
_ADVISORY_FAILSOFT_SUBSTR = "advisory leg failed"
_ADVISORY_MAX_FWD_LINES = 40   # 2 headers + 2×10 rows + 2 overflow + fail-soft << 40
_ADVISORY_MAX_FWD_CHARS = 4000

def extract_filer_advisories(stderr: str) -> list[str]:
    """Extract the #1399/#1502 sibling-advisory block lines from the FILER's stderr (#1529).

    A block = one ``file_infra_task: ADVISORY — ...`` header plus its immediately
    following row/overflow lines (``  #<id> ...`` / ``  ... and N more ...`` — the
    only 2-space-indented shapes the advisory legs emit; the adjacent forwarded
    ``  [task.py stderr] ...`` lines start ``  [`` and are excluded). Standalone
    ``... advisory leg failed ...`` fail-soft one-liners are captured too (they tell
    the consumer the scan did NOT run — absence of advisories is not evidence of
    no siblings). Defensively capped; the cap appends an explicit marker line so
    nothing is silently dropped.
    """
    lines: list[str] = []
    in_block = False
    for line in (stderr or "").splitlines():
        if _ADVISORY_HEADER_SUBSTR in line:
            lines.append(line.rstrip())
            in_block = True
        elif _ADVISORY_FAILSOFT_SUBSTR in line:
            lines.append(line.rstrip())
            in_block = False
        elif in_block and (line.startswith("  #") or line.startswith("  ...")):
            lines.append(line.rstrip())
        else:
            in_block = False
    if len(lines) > _ADVISORY_MAX_FWD_LINES or sum(len(ln) for ln in lines) > _ADVISORY_MAX_FWD_CHARS:
        kept: list[str] = []
        total = 0
        for ln in lines[:_ADVISORY_MAX_FWD_LINES]:
            if total + len(ln) > _ADVISORY_MAX_FWD_CHARS:
                break
            kept.append(ln)
            total += len(ln)
        kept.append(f"  ... advisory forward capped ({len(lines)} lines total, #1529)")
        return kept
    return lines
```

## 11. Decision Rationale

1. **Extract-and-persist (Goal option 1) over raising the tail cap (option 2).** `out` interleaves stdout + stderr with advisories EARLY in stderr (filer step 0, before `task.py new`), so any TAIL cap large enough to include them must swallow everything after them — unbounded and unstructured; a targeted extraction gives a greppable field + an in-session print. Source: `scripts/file_infra_task.py` L397-407 (ordering comment: "Both advisory legs run BEFORE the `task.py new` subprocess"); `scripts/daily_drive_filings.py` L977 (`out` composition).
2. **Extraction predicate** = header substring `file_infra_task: ADVISORY` (both arms, L312/L363) + block-scoped continuations `  #` / `  ...` (the ONLY indented shapes the advisory legs emit, L318-327 / L372-381) + fail-soft substring `advisory leg failed` (L331/L384). Block-scoping is required because the filer's next stderr lines are `_forward_marker_child_stderr`'s `  [task.py stderr] …` (2-space indent + `[`, `autonomous_session_watch.py` L8011, imported at `file_infra_task.py` L69-70) — a bare `startswith("  ")` continuation would capture them; the task body's sketch predicate (`'ADVISORY' in line or line.startswith('  #')`) would also capture stray `  #`-indented lines outside any block. Source: read code, all line anchors verified this session.
3. **Field name `advisories`, conditional-only.** Mirrors #1467's `sha_warnings` precedent on the same row (`_filed_ledger_row` docstring L345-349: "rows are free-form dicts — schema-safe"); conditional presence keeps the no-advisory row byte-identical (zero migration). Source: `scripts/daily_drive_filings.py` L342-361; #1467.
4. **Print AND persist (both halves of Goal option 1).** Print = the /daily session's in-band view (the consumption contract the bug breaks); persist = the durable record for the enrichment pass / backfill-resume, which read `filed.jsonl` (`.claude/skills/daily/SKILL.md` L694, L739) — the print alone dies with the transcript, the field alone is not seen live. Source: #1502 (the advisory's remedy is time-critical: archive+stop BEFORE the duplicate pipeline burns hours).
5. **Success-path only.** The Goal names the success path; on `filer-failed` (rc≠0) the driver already dumps `out[-800:]` to stderr and a retry re-runs the filer (advisories re-emitted); `no-id-parsed`/`timeout` rows are retry-focused and rare. Pinned by test 5; extending to error rows is a trivially separable follow-up if ever wanted. Source: task #1529 `## Goal`; `daily_drive_filings.py` L1001-1002.
6. **No `.claude/skills/daily/SKILL.md` edit.** The forwarded header text carries the remedy verbatim ("archive the just-filed task … stop its spawned session", file_infra_task.py L363-369), so the /daily session receives the instruction in-band; adding SKILL.md prose would duplicate it and touch the `test_daily_three_route_classifier_doc.py` pin surface for no behavior gain. Source: read both emitters + SKILL.md L340-360/L686-745.
7. **Caps 40 lines / 4000 chars + explicit truncation marker.** Worst realistic block = 2 headers (~340 + ~430 chars) + 20 rows + 2 overflow ≈ 3.3 KB (`_ADVISORY_MAX_ROWS = 10` per arm, file_infra_task.py L279); the marker line keeps any overflow non-silent (fail-loud norm). Source: emitter code; `Source: ungrounded — needs smoke-test` is NOT needed (no model/training values in this plan; cap is defensive, order-of-magnitude insensitive).
