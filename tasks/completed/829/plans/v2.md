### 3c. Lint check

- **File:** `scripts/workflow_lint.py`. **Flag:** `--check-agent-spec-size`. **Function:** `check_agent_spec_size(*, repo_root: Path | None = None, warn_sink: list[str] | None = None) -> list[str]` — errors returned (FAIL), warnings appended to `warn_sink` when provided else printed with a `WARN:` prefix (the lint has no existing warn channel; this keeps the `check_*() -> list[str]` FAIL contract intact and testable).
- **Scope:** every `*.md` directly under `.claude/agents/` (glob, non-recursive). Deprecated agents in-scope (no exemption — see 3a).
- **Thresholds:** module constants `AGENT_SPEC_WARN_BYTES = 40_000`, `AGENT_SPEC_FAIL_BYTES = 70_000`. Counted in **bytes** (mirrors `check_lessons_index`'s deliberate bytes-not-chars rationale).
- **Allowlist:** module-level dict, `JUDGE_PIN_LEGACY_ALLOWLIST`-style inline reasons, but as a **ratchet cap** (stronger than a boolean waiver — a grandfathered file cannot GROW):
  ```python
  AGENT_SPEC_SIZE_GRANDFATHER: dict[str, int] = {
      # Fifteen-lenses core is every-invocation load-bearing; SPEC.md-dedup
      # trim is the #829 named follow-up. Ratchet DOWN when trimmed.
      "clean-result-critic.md": 105_000,
      # Analysis-Protocol core is every-invocation; same follow-up.
      "analyzer.md": 115_000,
  }
  ```
  Semantics: grandfathered file FAILs above its cap (still WARNs always); a grandfather entry whose file no longer exists, or whose file is now ≤ `AGENT_SPEC_FAIL_BYTES`, FAILs with "remove the stale grandfather entry" (keeps the dict honest; mirrors `check_lessons_index` stale-row FAILs).
- **Wiring:** add to the `no_flags = not (...)` tuple (line ~4069) and a `if args.check_agent_spec_size or no_flags: errors.extend(check_agent_spec_size())` branch in the dispatch ladder — the exact `check_lessons_index` bundling shape.

(a) file < 40 KB → no WARN, no FAIL; (b) 40–70 KB → WARN only; (c) > 70 KB, not grandfathered → FAIL naming file + size + threshold; (d) grandfathered, under its cap → WARN only; (e) grandfathered, over its cap → FAIL; (f) stale grandfather entry (missing file) → FAIL; (g) grandfathered file now ≤ 70 KB → FAIL ("remove entry"); (h) missing `.claude/agents/` dir → FAIL loudly (mirror `check_lessons_index` missing-file behavior); (i) `test_live_tree_passes` — the real repo tree returns zero FAILs post-trim (the #765 invariant: locks the allowlist to reality).

## 7. Risks + failure modes

- **Cross-reference breakage** (highest): ≥12 files reference the moved section titles (grep-verified). Mitigation: per-section-title `grep -rln` before each move; update every hit's pointer string; re-run `--check-skill-refs`/`--check-script-refs` via the default lint run.
- **Codex twin coupling:** `codex-clean-result-critic.md` mentions "Paper-task review" — its composer may inline the section by reference. Mitigation: read its referencing mode before moving; kill-criterion 3.
- **LESSONS.md cap overflow:** 6,357/7,500 B + ~1,000 B of new rows. Mitigation: terse rows; bump cap to 8,500 (precedent #780) if needed.
- **#828 merge collision:** same files, different lines (frontmatter vs body). Mitigation: rebase-merge at Step 10d; edits are disjoint by construction.
- **WARN noise:** ~10 files land in the 40–70 KB WARN band → default-run output grows ~10 lines. Accepted: visibility is the point; WARNs never fail CI.
- **Concurrent sessions loading a spec mid-relocation:** commits are per-file atomic; an agent spawned between commits sees either old-inline or new-pointer text, both complete.
- **Behavioral drift via paraphrase:** mitigated by moving blocks VERBATIM (only the pointer is new text); code-reviewer diff confirms move-not-rewrite.
