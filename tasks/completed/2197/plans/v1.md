# Plan v1 — #2197: make the `set-body` `## Goal` H2 drop-guard workflow-aware for v2 report bodies

## Requirement + acceptance criteria

**Requirement.** `task_workflow.set_body`'s Goal-H2 drop guard (`GoalH2DropError`,
incident #1112) currently fires on every `workflow: v2` report-body write, because
the report-v1 template deliberately has no `## Goal` section — forcing
`--allow-goal-drop` on the happy path (#2162, the first v2 report post). A guard
that must be overridden on every legitimate use trains reflexive overriding and
stops protecting the accident class it was built for. Add a narrow auto-exemption
for v2 report bodies; leave the v4 clean-result path byte-identical in behavior.

**Acceptance criteria:**

1. Writing a body that (a) belongs to a task whose frontmatter is
   `workflow: v2` AND (b) carries the `<!-- report-v1 -->` sentinel as the first
   non-blank line after the H1 title (the exact `verify_report.py` positional
   semantics) succeeds WITHOUT `allow_goal_drop`, even when the prior
   `kind: experiment` body had a `## Goal` H2 and the new body lacks one.
2. Every other currently-refused shape stays refused: a v2 task posting a
   NON-sentinel body that drops `## Goal`; a v1 / workflow-absent task posting a
   sentinel-bearing body (both discriminator halves are required); a body that
   merely QUOTES the sentinel mid-prose rather than carrying it positionally.
3. All existing guard tests pass unchanged
   (`tests/test_task_workflow.py:680-774`,
   `tests/test_task_cli_set_body_assertions.py:205-232`) — the v4 path is
   byte-identical in behavior.
4. The sentinel string in `task_workflow.py` is pinned equal to
   `scripts/verify_report.py::REPORT_SENTINEL` by a test, so the two cannot
   silently drift.
5. `.claude/skills/issue-v2/SKILL.md` step 7f no longer instructs
   `--allow-goal-drop` on the canonical report write; the `--allow-goal-drop`
   CLI help text + both docstrings describe the auto-exemption.

## Method delta (design decisions, resolved per the task body's scope notes)

- **Discriminator = BOTH `workflow: v2` frontmatter AND the positional
  report-v1 sentinel in the NEW body.** The task body says "Prefer the
  sentinel, or require both." Requiring both is chosen: the sentinel describes
  the body being written (the precise signal), while the `workflow` gate keeps
  every non-v2 task's behavior untouched by construction — a report-shaped body
  on a v1 task is itself a routing error and SHOULD stay guarded. The
  `workflow` field is read from the task's canonical frontmatter (`fm`),
  already loaded at the guard site (`task_workflow.py:6234`); tasks predating
  the field return `None` from `fm.get("workflow")` and keep the guard.
- **Sentinel detection mirrors `verify_report.py` positionally** (first
  non-blank line after the first H1 == `<!-- report-v1 -->`, per
  `verify_report.py:405-422`), NOT a substring containment check — a body
  quoting the sentinel in prose (e.g. #2197's own body does) must not take the
  exemption. No H1 ⇒ not a report body ⇒ no exemption.
- **Inverse guard NOT added.** The task body flags it as a judgement call;
  `scripts/verify_report.py` already gates section completeness at the report
  gate (`REQUIRED_SECTIONS`, checked at generation AND promote), and `set_body`
  is a drop-guard, not a shape validator. Duplicating the check would create a
  second drift surface for zero marginal protection.
- **Exemption follows the existing `is_paper_task` precedent shape**
  (`task_workflow.py:6253`) — one additional conjunct in the same guard
  condition, no restructuring.

## File paths + concrete diffs

1. **`src/explore_persona_space/task_workflow.py`** (workflow surface):
   - Add module-level constant + helper near `_has_goal_h2` (~line 6397):

     ```python
     # Kept byte-equal to scripts/verify_report.py::REPORT_SENTINEL —
     # pinned by tests/test_task_workflow.py::test_report_sentinel_matches_verify_report.
     REPORT_V1_SENTINEL = "<!-- report-v1 -->"

     def _is_report_v1_body(text: str) -> bool:
         """True iff the first non-blank line after the first H1 is the
         report-v1 sentinel — the same positional semantics as
         scripts/verify_report.py (a mid-prose quotation does not count)."""
         lines = text.splitlines()
         for i, line in enumerate(lines):
             if line.startswith("# "):
                 for later in lines[i + 1:]:
                     if later.strip():
                         return later.strip() == REPORT_V1_SENTINEL
                 return False
         return False
     ```
