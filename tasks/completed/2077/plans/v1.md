# Plan v1 — #2077 workflow-fix: wall-clock heartbeat duty for subagents owning detached work

**Kind:** infra (workflow-fix; `wf-fix` tag). Workflow-surface prose edit only — one bullet added to `CLAUDE.md`.

## Requirement

Close the uncovered liveness case from the #1739 `pod-1739-r5ladder` incident: an Agent-tool
subagent owning long detached work (a 4× H200 staging job) armed a session-scoped completion
poll as its ONLY liveness channel; the harness reaped the poll silently, no wake ever arrived,
and the pod billed idle ~3 h. The existing duty that would have caught this (#1850
`[watch-heartbeat]` Monitor-liveness) lives only in `.claude/skills/issue/SKILL.md` Step 6d.2,
which Agent-tool subagents never load. Subagents DO load `CLAUDE.md`; its adjacent re-arm
bullet (#1947, CLAUDE.md:91) covers only the wake-consumed case and by construction cannot
fire when no wake ever arrives.

## File paths + concrete diff

`CLAUDE.md`, § "Orchestrator vs subagent re-invocation", one new bullet after the re-arm
bullet:

```
+ - **A poll you armed is not a heartbeat: it shares your kill domain with the work it
+   watches.** Any agent — ORCHESTRATOR OR SUBAGENT — that owns detached work outliving its
+   current turn posts a durable progress marker (an `epm:progress` note prefixed
+   `[long-phase-heartbeat]`, the token `tick_triage.py` + the watcher already read) on a
+   WALL-CLOCK cadence (≤ ~60 min), whether or not any poll, Monitor line, or notification
+   fires. A session-scoped background Bash/Monitor can be reaped by the harness with no
+   error and no notification, after which silence is indistinguishable from health and the
+   watched compute runs unobserved (on a pod: billing — #2077/#1739 `pod-1739-r5ladder`:
+   a harness-killed completion poll left a 4× H200 pod idle ~3 h at $18.36/hr). Treat a
+   heartbeat gap of ≳2-3 expected intervals as evidence the watcher DIED: re-probe the work
+   directly (`ps`/`pgrep` identity match, log mtime, pod status) before re-arming, per
+   `.claude/rules/crash-fix-rounds.md` § Kill-before-relaunch — never heartbeat blind (a
+   verify FAIL routes to the failure path). Briefs delegating detached work RESTATE this
+   cadence and name the teardown deadline. (The `/issue` orchestrator's fuller form is
+   SKILL.md Step 6d.2 § Long-phase heartbeat duty + the #1850 `[watch-heartbeat]` Monitor
+   emission; this bullet is the CLAUDE.md-level duty that also reaches Agent-tool
+   subagents, which never load that SKILL.)
```

Exact wording may be lightly adjusted at implementation for flow; the six content elements in
acceptance criterion 1 are binding.
