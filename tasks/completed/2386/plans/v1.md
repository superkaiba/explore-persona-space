#### 4.3 Concrete diffs (per wrapper)

**Pattern A — stderr-only fatal (wrappers 1-7, 9).** Insert immediately above the wrapper's `mkdir -p` line:

```bash
# Fail-loud helper for wrapper-infrastructure failures (task #2386, ports the
# #2196 pattern): an unchecked failure here silently skips the whole pass
# below (the brace-group redirect fails and the group never runs) while the
# wrapper still exits 0. stderr lands in the crontab redirect file where one
# exists; cron mail is structurally dead on this VM (no MTA).
fatal() {
    echo "$(date -Iseconds) FATAL: $1" >&2
    exit 1
}

mkdir -p "$LOG_DIR" \
    || fatal "cannot create log dir (LOG_DIR=$LOG_DIR); <pass name> NOT run"
```

and AFTER the `FIRST_RUN_OF_DAY` read (or directly after the guarded mkdir for `cron_session_summarize.sh`, which has none):

```bash
# mkdir -p succeeds on an existing dir regardless of writability, so probe the
# actual append open the brace group below will attempt (#2196 ordering: after
# the FIRST_RUN_OF_DAY read — the probe creates $LOG_FILE when absent).
: >> "$LOG_FILE" 2>/dev/null \
    || fatal "daily log file not appendable ($LOG_FILE); <pass name> NOT run"
```

**Pattern B — fatal with push leg (wrappers 8, 10).** Same as Pattern A, with the #2196 push leg inside `fatal()` (both wrappers define `TELEGRAM_PUSH` before their mkdir line, verified L55 / L54):

```bash
fatal() {
    echo "$(date -Iseconds) FATAL: $1" >&2
    if [ -x "$TELEGRAM_PUSH" ]; then
        "$TELEGRAM_PUSH" "ALERT: <wrapper name>: $1" \
            || echo "$(date -Iseconds) <wrapper name>: telegram_push.sh FAILED for FATAL alert (continuing to exit 1)" >&2
    fi
    exit 1
}

mkdir -p "$LOG_DIR" "$SENTINEL_DIR" \
    || fatal "cannot create log/sentinel dir (LOG_DIR=$LOG_DIR SENTINEL_DIR=$SENTINEL_DIR); <pass name> NOT run"
```

No per-date sentinel on the fatal arm in either wrapper — the sentinel dir defaults to the very log dir that is unwritable (verified: `cron_step9c_ledger_refresh.sh:54`, `cron_daily_healthcheck.sh:52-53`), and the daily cadence bounds pushes to one per failing day (the #2196 rationale, carried verbatim).
