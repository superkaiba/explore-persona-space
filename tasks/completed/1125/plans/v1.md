## 4. Design decisions (§11 Decision Rationale)

### D1 — Primary form: the output-test rewrite (`[ -n "$(grep -vE ...)" ]`), NOT the `/usr/bin/grep` path pin

- **What:** consume grep's OUTPUT (non-empty ⇒ code-bearing line exists) instead of the `-q -v` exit status.
- **Why:** every grep implementation (GNU, ugrep, BSD, busybox) agrees on what `-v` *prints* — the #928 divergence is confined to the `-q` exit-status path, which this form never touches. Shadow-proof at the semantics level, no PATH or binary-location assumption. Critically, the path pin has a **new fail-open of its own**: on any host without `/usr/bin/grep` (non-usrmerge container, busybox image — relevant because SKILL.md snippets are copy-paste templates, also extracted into the genericized `~/claude-code-workflow` repo), `/usr/bin/grep` → rc=127 → `elif` false → `skip-artifact-only`, the exact silent disarm this task exists to kill. The output-test form has no such mode.
- **Source:** #928 `epm:merged v2` record; measured equivalence probes this session (armed/skip/empty fixtures: GNU `-qvE` rc = 0/1/1, output-test form rc = 0/1/1 — identical); `bash -n` OK on the substituted new-form block; GNU/ugrep docs above.
- **Alternatives rejected:** (a) `/usr/bin/grep -qvE` pin — minimal diff but introduces the rc=127 fail-open above and assumes binary location; kept as the fallback if a kill criterion fires. (b) `grep -cvE ... | ...` count-parse — output-format portability traps (per-file prefixes, multi-file counts), strictly worse. (c) belt-and-braces pin AND rewrite — redundant; the rewrite alone is sufficient.
- **Error-corner parity (accepted residual):** a grep hard error (rc=2, e.g. unreadable file) reads as skip under BOTH the old GNU form (`-q` with no selected line + error → rc≠0 → elif false) and the new form (empty output). No regression; the corner is guarded upstream by #1047's exit-guarded materialization of the input file one line earlier.

### D2 — Lint check: IN scope (`--check-grep-qv`)

- **What:** new `check_grep_qv()` in `scripts/workflow_lint.py`, joining the **no-flags default bundle** (same policy as `check_piped_git_push`).
- **Why:** the failure class is silent (gate disarms with a clean-looking verdict) and recurrent-by-copy-paste; a one-page mechanical check is the cheapest permanent defense, and the infrastructure (`_FENCE_RE`, `_iter_logical_shell_lines`, the check-registration ladder) already exists.
- **Scan set:** fenced code blocks in `.claude/skills/**/SKILL.md` and `.claude/agents/*.md` (prose lines outside fences never scanned), plus `scripts/**/*.sh` whole-file logical lines. `#`-comment lines skipped in both. Not `.py` (the check, its tests, and rule prose would self-flag; Python grep subprocess calls are out of the copy-paste-snippet threat model).
- **Flag predicate:** an invocation whose command word is bare `grep`/`ugrep` (NOT path-prefixed — negative lookbehind on `[\w/.\-]` exempts `/usr/bin/grep ...`; a `git grep` carve-out via preceding-word test) whose short/long option tokens jointly contain q (`-q`/`--quiet`/`--silent`) AND v (`-v`/`--invert-match`) — catches `-qv`, `-vq`, `-qvE`, `-q -vE`. Fails toward false-negative on exotic pinned forms (`/usr/bin/ugrep -qv`) — the documented safe direction for this lint family.
- **Grandfather/allowlist:** none needed — post-fix the live tree has 0 hits; a `test_check_grep_qv_live_tree_passes` test pins that (the `test_live_trees_pass` pattern from the judge-pin check).
- **Alternatives rejected:** out-of-scope (rely on code review) — rejected because the #928 disarm was invisible to review by construction; a PreToolUse hook — wrong layer, the snippets are file content, not ad-hoc commands.

### D3 — ugrep shadow root-cause: OUT of scope

- **What:** locating/removing whatever put ugrep-as-`grep` on the #928 session's PATH.
- **Why out:** not reproducible from this session (verified: `command -v grep` → `/usr/bin/grep` GNU 3.7, ugrep not on PATH, no alias in `~/.bashrc`); the shadowing is per-session/profile-dependent; D1 makes any future shadowing harmless at these sites. No further workflow-fix task is proposed (recursion guard).
- **Source:** clarifier verification + this session's re-probe.
