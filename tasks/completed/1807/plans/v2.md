## Method delta (vs the body's diff sketch — stated deviation)

The body sketched "move the re-sync ahead of gate tip-binding". This plan
DEVIATES for fix (a): the #1714 post-gate placement is KEPT, because moving
the sync pre-gate re-opens the during-gate origin/main drift window that
#1714 was built to close (#1476: CONFLICTING squash under a ~30-min gate) —
and a during-gate spec conflict ALSO ends in a gate re-run via the recovery
path, so the reorder would trade a deterministic re-run for a probabilistic
one plus a conflict recovery. Instead the fix is a **mechanically-gated
verdict re-bind**: the sync commit's delta is provably payload-free (every
delta path byte-identical to fetched `origin/main`), which means the gate's
landing tree (`git archive origin/main` + own-diff overlay) is unchanged by
the commit — the certification remains semantically exact, so line 2 of the
verdict file may be re-bound to the new tip under git-verified conditions.
The #1714 bullet already argues the landing-tree invariance; this plan makes
the SHA mechanics agree with it. Fixes (b) and (c) follow the sketch.

## Design

### Edit A — Step 10d safe-case merge conditional (fix a)

Inside the `then` arm of the SHA-bound merge conditional
(`#### The auto-merge procedure`), reorder + extend:

1. **Move the head-sync pre-check (#1657) AFTER the re-sync** so it polls
   PR-object parity against the FINAL tip (a fresh sync push re-introduces
   the lag the pre-check exists to absorb; polling before the sync is
   checking the wrong tip).
2. **Keep the post-gate re-sync block byte-compatible** with the pin-test
   literals: the `**Post-gate freshness re-sync (#1714` bullet prefix, the
   bounded-fetch literal, the `[step10d] post-gate re-sync: synced <n>
   files (<sha>) | no drift` echo, and the FAMILY_OF entries all stay.
3. **Add the verdict re-bind stanza** immediately after the inline
   family-atomic block, structured so the merge NEVER runs on an
   unverified tip (variable-gated, not a bare mid-block `false` — the
   #1092 lesson):

   ```bash
   REBIND_OK=yes
   if [ "$SYNC_SHA" != "no-drift" ]; then
     CERT_SHA=$(sed -n 2p /tmp/issue-<N>-lint-verdict.txt)
     REBIND_OK=no
     DELTA_OK=yes
     # --name-status, NOT --name-only (critic round-1 Must-Fix): a
     # both-sides-absent deletion (a stray non-sync commit deleting a
     # branch-added file) exits `git diff --quiet origin/main HEAD -- p`
     # ZERO — reading as "main-identical" while the certified landing tree
     # CONTAINED the file via the own-diff overlay. The sync block's
     # `checkout origin/main -- $SAFE_SPECS` can only add/modify, never
     # delete, so ANY D/R status row is by construction non-sync output:
     # fail CLOSED unconditionally. A/M rows keep the byte-identity probe
     # (content == fetched origin/main contributes nothing beyond the
     # baseline to the landing tree, so certification is unchanged).
     while IFS=$'\t' read -r st p _rest; do
       case "$st" in
         A|M) git -C "$WT" diff --quiet origin/main HEAD -- "$p" || DELTA_OK=no ;;
         *)   DELTA_OK=no ;;   # D / R* / C* / T / U — never sync output
       esac
     done < <(git -C "$WT" diff --name-status "$CERT_SHA" HEAD)
     if [ "$DELTA_OK" = yes ]; then
       if { sed -n 1p /tmp/issue-<N>-lint-verdict.txt; git -C "$WT" rev-parse HEAD; } \
            > /tmp/issue-<N>-lint-verdict.txt.rebind \
          && mv /tmp/issue-<N>-lint-verdict.txt.rebind /tmp/issue-<N>-lint-verdict.txt; then
         REBIND_OK=yes
         echo "[step10d] verdict re-bound to sync tip $(git -C "$WT" rev-parse --short=12 HEAD) (delta = origin/main-identical spec sync only; #1807)"
       else
         echo "[step10d] verdict re-bind WRITE failed — fail CLOSED (re-run the gate)"
         rm -f /tmp/issue-<N>-lint-verdict.txt
       fi
     else
       echo "[step10d] sync delta NOT verifiable as origin/main-identical A/M-only — verdict stays bound to $CERT_SHA; fail CLOSED (re-run the gate)"
       rm -f /tmp/issue-<N>-lint-verdict.txt
     fi
   fi
   if [ "$REBIND_OK" = yes ]; then
     <head-sync pre-check, then gh pr ready / gh pr merge as today>
   else
     <BLOCKED-arm semantics: no merge; false>
   fi
   ```
