#### 4.1 Scope decision (a): token surface + grammar

**Decision: structured note tokens on EXISTING marker kinds — no new `epm:` kind.** Precedent: the note-token convention is the established "no marker-schema change" channel (`fix_sha=`, `pid=`, `pod=`, `outroot=`; `.claude/rules/crash-fix-rounds.md` § Crash-fix relaunch: "note-token convention, same class as `pid=` / `commit=` — no marker-schema change"). A new marker kind would be a public-contract change (workflow.yaml § markers + halt-criterion 3 adjacency) with no added power: the guard needs newest-wins per-pod token lookup, which notes already support.

Two tokens, grammar exact:

- **`owner=<token>`** — owner-attribution evidence. `<token>` matches `[A-Za-z0-9._-]{1,64}`. Parser regex: `(?<![\w-])owner=([A-Za-z0-9._-]{1,64})`. Emitted (i) on the `epm:run-launched` note beside the already-required `pod=<name>` lead token; (ii) optionally refreshed on `epm:progress` notes naming the pod; (iii) by the OWNER on its own `epm:upload-verification` PASS note. Recommended token value: `<agent-or-session-slug>-<issue>` (e.g. `spec-ladder-2054`); the guard checks only string EQUALITY between (i/ii) and (iii). Collision check: repo-wide grep for `owner=` hits only `scripts/gh_project.py` GitHub-CLI arg composition (not marker notes) — surface free.
- **`fence_until=<value>`** — owner work-fence deadline. `<value>` is UTC ISO-8601 `YYYY-MM-DDTHH:MM(:SS)?Z`, or the literal `none` (clears the fence). Parser regex: `(?<![\w-])fence_until=([0-9T:Z.-]{1,32}|none)`, then strict `datetime.strptime` (both `%Y-%m-%dT%H:%M:%SZ` and `%Y-%m-%dT%H:%MZ`); an unparseable value ⇒ treated as ABSENT + one stderr WARN naming the malformed token (fail-open per hard constraint). Emitted on `epm:run-launched` and refreshed/cleared via `[long-phase-heartbeat]` `epm:progress` notes carrying `pod=<name>`. Collision check: `fence_until` has zero repo hits today; `fence=` (experimenter provider-fence field) is not matched by the new regex (the `(?<![\w-])` guard rejects the `fence` inside `owner_...`-style compounds, and `fence_until=` does not contain the substring `fence=`), and no machine consumer of `fence=` exists to mis-read `fence_until=` (experimenter.md prose only — verified by grep, §11).

**Pod keying:** a token binds to pod P iff its note names P in the #1961 structured position — boundary-safe `pod=<P>` token anywhere in the note, OR P as the note's leading token (copy of the `autonomous_session_watch.py:13442` pattern, cross-ref comment, no import). **Evidence window:** tokens are read newest-wins from events whose `ts` ≥ the newest `epm:run-launched` naming P (the launch event included); if no run-launched names P, the window is the whole log. This prevents a stale fence from a PRIOR `pod-<N>-<slug>` incarnation binding a re-provisioned same-name pod.

#### 4.2 The new guard

New function in `scripts/pod_lifecycle.py` (placed after `_guard_keep_running_before_terminate`):

```python
def _guard_owner_fence_before_terminate(
    issue: int, pod_names: list[str], *, force_flag: bool, dry_run: bool
) -> None:
    """Refuse to destroy a pod carrying an UNEXPIRED owner fence unless the
    latest upload-verification PASS carries the pod's matching owner= token
    (#2277; incident 2026-08-13 pod-2054-tiers). Evidence-gated: pods with
    no owner=/fence_until= tokens proceed exactly as before this guard
    existed. ADDITIVE to the #444/#2187 upload-verification guard and the
    #1485 keep-running shield; unlike #1485 it does NOT exempt the
    --name-suffix surgical path (the incident's path). Kill switch:
    EPM_DISABLE_OWNER_FENCE_GUARD=1 (rollback lever, fail-open)."""
    if os.environ.get("EPM_DISABLE_OWNER_FENCE_GUARD") == "1":
        return
    if dry_run:
        print("[dry-run] NOTE: a real run would check each pod's owner "
              "fence_until=/owner= tokens and REFUSE if an unexpired fence "
              "exists without an owner-matching PASS.", file=sys.stderr)
        return
    try:
        from explore_persona_space.task_workflow import list_events
        events = list_events(issue)
    except (ImportError, FileNotFoundError, RuntimeError, ValueError) as exc:
        print(f"[pod_lifecycle] WARN: owner-fence guard skipped for issue "
              f"#{issue} ({type(exc).__name__}). Proceeding.", file=sys.stderr)
        return
    pass_note = _latest_upload_verification_note(issue) or ""
    pass_owner = _note_owner_token(pass_note)          # new pure helper
    now = datetime.now(timezone.utc)
    for name in pod_names:
        window = _pod_evidence_window(events, name)    # new pure helper (§4.1)
        owner_reg = _latest_pod_token(window, name, "owner")        # new
        fence = _latest_pod_fence_until(window, name)  # new; None if absent/
                                                       # 'none'/unparseable(WARN)
        if fence is not None and fence > now:
            if owner_reg is not None and pass_owner == owner_reg:
                continue  # owner tearing down its own verified pod: ask-free
            if force_flag:
                print(f"[pod_lifecycle] WARN: terminating {name} DESPITE an "
                      f"unexpired owner fence (fence_until={fence.isoformat()}, "
                      f"owner={owner_reg!r}, pass owner={pass_owner!r}) because "
                      f"--force-owner-fence was passed.", file=sys.stderr)
                continue
            raise SystemExit(
                f"REFUSED: pod {name} (issue #{issue}) carries an UNEXPIRED "
                f"owner fence (fence_until=..., owner=..., PASS owner=...). "
                f"A live owner may still be mid-run (#2277; 2026-08-13 "
                f"pod-2054-tiers). Non-owner route: SURFACE the pod for "
                f"approval — post a marker + push naming the pod and its "
                f"hourly burn, leave it alive (.claude/rules/pods.md "
                f"§ Completion-side teardown) — or wait for the fence to "
                f"expire / the owner to post fence_until=none. Owner route: "
                f"re-post the PASS with your matching owner=<token>. "
                f"Deliberate override: re-run with --force-owner-fence."
            )
        elif owner_reg is not None and pass_owner not in (None, owner_reg):
            # attribution mismatch with NO active fence: visible, non-blocking
            print(f"[pod_lifecycle] WARN: upload-verification PASS owner="
                  f"{pass_owner!r} does not match pod {name}'s registered "
                  f"owner={owner_reg!r} (no active fence — proceeding; #2277).",
                  file=sys.stderr)
```
