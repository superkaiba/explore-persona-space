# Plan v1 — task #2111: ownership-probe hardening (3 probed sub-cases)

## Goal / requirement

Harden the fleet's live-work probe discipline by naming three probed failure sub-cases in
the always-on workflow surface (CLAUDE.md), so orchestrators stop acting on stale
liveness/state reads:

1. **Pre-stop probe** — before stopping a session, probe for live subagent children AND a
   fresh (`<~10 min`) `stage-dispatch` breadcrumb; either ⇒ presume live, do not stop
   (2026-08-05 incident, #2054 session: stop killed a live implementer; 2 correction markers).
2. **Post-death detached-children probe** — after ANY subagent death (429/529/refusal/kill),
   probe for detached children it launched BEFORE dispatching same-path work
   (2026-08-05 incident, #1491: duplicate run into the same worktree; collision killed it).
3. **Ops-stats compose-time re-grep** — ops/fleet statistics in monitoring turns are
   recomputed from events.jsonl/live state in the same turn, never carried from a prior
   cycle (2026-08-05 incident: stale failure ratio + misattributed thrash fix, 2 user
   corrections).

### Acceptance criteria

- CLAUDE.md § "Orchestrator vs subagent re-invocation" ownership-check bullet names

- CLAUDE.md ad-hoc-summaries "Compose-time re-grep" clause extends to ops/fleet statistics
  (sub-case 3) with its incident citation.

## Method delta (placement decision — delegated to planner by the task body)

**Inline bullet extension, NOT a new rules file.** Rationale: (a) each sub-case is 1–2
sentences — a `.claude/rules/*.md` file plus LESSONS.md index row adds indirection at
exactly the judgment moments (a quick stop decision, a monitoring turn) where indirection
already failed; (b) all three rules must bind ALWAYS-ON in every session type (PM,
fleet-ops, per-issue), which only CLAUDE.md guarantees; (c) no new lessons-index row means
no `--check-lessons-index` surface. The task body's "(and mirror where the stop paths
live)" is satisfied by CLAUDE.md itself: every session that can issue
`spawn_session.py stop` loads CLAUDE.md, and no skill file owns a stop recipe to mirror
into (checked: pm/SKILL.md defers to CLAUDE.md for stop discipline). Stated deviation:
no second surface is edited.
