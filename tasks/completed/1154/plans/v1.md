### 4.5 Check function (pseudocode)

```python
def check_marker_recipe_snippets(*, repo_root: Path | None = None) -> list[str]:
    """FAIL when a frozen numeric snippet in the marker-training recipe doc
    (docs/marker_training_recipe.md) or its sibling rule
    (.claude/rules/marker-training-recipe.md) disagrees with the code constant
    it cites (#1154; the drift class: a stale frozen number misleads every
    future marker-training planner grounding hyperparameters from the doc).
    Registry-driven (_MARKER_RECIPE_PINS) — only registered pins are checked;
    empirical findings / frozen experiment history are never parsed. Doc
    patterns run whitespace-normalized (line-wrap-immune); src patterns run
    raw + MULTILINE. Values compare as floats when both parse, else exact
    strings. ``repo_root`` is a unit-test override; production passes None.
    Bundled into the no-flags default run.
    """
    root = repo_root if repo_root is not None else _REPO_ROOT
    errors: list[str] = []
    doc_cache: dict[str, str | None] = {}   # normalized doc text (None = missing)
    src_cache: dict[str, str | None] = {}   # raw src text
    for pin in _MARKER_RECIPE_PINS:
        doc_text = _load(doc_cache, root / pin.doc_rel, normalize=True)
        src_text = _load(src_cache, root / pin.src_rel, normalize=False)
        if doc_text is None:
            errors.append(f"{root / pin.doc_rel}: missing — pin '{pin.label}' …"); continue
        if src_text is None:
            errors.append(f"{root / pin.src_rel}: missing — pin '{pin.label}' …"); continue
        doc_vals = re.findall(pin.doc_pattern, doc_text)
        if not doc_vals:
            errors.append(
                f"{root / pin.doc_rel}: pin '{pin.label}': doc snippet not found "
                f"(pattern {pin.doc_pattern!r}) — the pinned prose was rephrased or "
                f"removed; update the snippet or _MARKER_RECIPE_PINS in "
                f"scripts/workflow_lint.py (#1154)."); continue
        src_vals = re.findall(pin.src_pattern, src_text, re.MULTILINE)
        if not src_vals:
            errors.append(
                f"{root / pin.src_rel}: pin '{pin.label}': code constant "
                f"{pin.symbol} not found (pattern {pin.src_pattern!r}) — the symbol "
                f"moved/renamed; update _MARKER_RECIPE_PINS (#1154)."); continue
        if len({_norm_val(v) for v in src_vals}) > 1:
            errors.append(f"{root / pin.src_rel}: pin '{pin.label}': ambiguous — "
                          f"{len(src_vals)} conflicting matches for {pin.symbol} …"); continue
        src_val = src_vals[0]
        for doc_val in doc_vals:
            if not _values_equal(doc_val, src_val):   # float== when both parse, else str==
                errors.append(
                    f"{root / pin.doc_rel}: pin '{pin.label}': doc cites {doc_val!r} "
                    f"but {pin.src_rel}::{pin.symbol} is {src_val!r} — update the doc "
                    f"snippet (or _MARKER_RECIPE_PINS if the binding itself changed) "
                    f"so they agree (#1154).")
    return errors
```

Error strings follow the house `f"{path}: <msg>"` shape (main() aggregates into the standard FAIL output). Helpers `_load` / `_values_equal` / `_norm_val` are private to the check (decomposition is an allowed deviation).
