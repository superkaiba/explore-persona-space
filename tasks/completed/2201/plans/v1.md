### D1. Helper: `scripts/step10d_guards.sh --guard divergence`

Contract (mirrors the script's documented state-passing contract; diagnostics on stderr, KEY=VALUE on stdout):

```
bash scripts/step10d_guards.sh <N> --guard divergence [--out <file>]
# stdout:  DIVERGENCE=clean|diverged|skipped
#          DIVERGED_COUNT=<n>
#          DIVERGED_FILE=<path of the one-path-per-line list; empty when skipped>
# exit:    0 (probe — never a refusal); 2 + ERROR=<reason> on infra error
#          (no merge-base, git failure), matching guards 0/4.
```

Algorithm (each piece is an existing, quoted idiom):
1. Derive `WT` via the same derivation `--guard prelude` uses. If `git -C "$WT" rev-parse --abbrev-ref HEAD` = `main` → emit `DIVERGENCE=skipped`, `DIVERGED_COUNT=0`, exit 0 (the Step 5a on-main skip, steps/09-step-5.md:134).
2. `MB=$(git -C "$WT" merge-base HEAD origin/main)` — empty → `ERROR=no-merge-base`, exit 2. **No fetch inside the helper**: both call sites already run the bounded `timeout --kill-after=30s 120s git fetch origin main --quiet || true` (steps/09-step-5.md:219; Step 10d Guard 1); document this in the usage text.
3. `git -C "$WT" -c core.quotePath=false diff --name-only "$MB" HEAD | sort -u` (branch side) ∩ `git ... diff --name-only "$MB" origin/main | sort -u` (main side) via `comm -12`.
4. Per intersection path (measured bound: ≤ ~40 paths, so a per-file loop is fine): drop `tasks/*` and `.claude/agent-memory/*` (task-state and review-round bookkeeping — Guard 3 precedent "always in-scope, never an UNSAFE trigger"; `tasks/` churn has its own machinery + Guard 1); drop when `git -C "$WT" log --format='%H %s' "$MB"..HEAD -- "$f" | awk 'index($0, "sync workflow-surface specs from") == 0'` is EMPTY (sync-import only — the #1560/#1789 subject-scoped exclusion, verbatim reuse); drop when `git -C "$WT" diff --quiet HEAD origin/main -- "$f"` reads identical (already converged — also catches every freshly-synced file, defense-in-depth on top of the subject exclusion).
5. Survivors → one per line into `--out` (default `/tmp/issue-<N>-divergence.txt`); emit `DIVERGENCE=diverged|clean` + count. Paths stay in the FILE, not on stdout (the contract's "no user text on stdout"; Guard 4's `LOST_UPDATE_PATHS` predates this and stays as-is).

Also update the script header roster + `_usage()` text (`--guard {prelude|0|4}` → `{prelude|0|4|divergence}`).
