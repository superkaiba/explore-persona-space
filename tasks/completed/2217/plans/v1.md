```python
@pytest.fixture(scope="module", autouse=True)
def _registry_hygiene_module():
    """Runtime-registration hygiene at MODULE scope (#2217): _panel_ids() and
    the pipeline fixture register fu3 contexts at RUNTIME (correct, idempotent
    production behavior). Snapshot CONTEXTS/NEGATIVE_PANELS at module setup,
    pop additions at teardown, so an explicit command-line order placing this
    module BEFORE the registry-purity pins stays clean."""

    from explore_persona_space.artifacts.negatives import NEGATIVE_PANELS
```

```python
# ── #2217: import-time registry-mutation guard (collection-time measurement) ──
# pytest imports every COLLECTED module before running any test, so a module-
# level registration into the global CONTEXTS / NEGATIVE_PANELS registries
# poisons every other module's view for the whole run — invisible to the Step
# 9c paired-PREFIX replay when the offender sorts after the victim (#2059's
# residual blind class; incident #2217). Measure at collection: snapshot the
# key-sets at pytest_configure (== the fresh-import baseline — conftest
# imports the registry modules eagerly, before any test module; NEVER a
# hardcoded count), then diff after every collector finishes, attributing
# growth to that collector's nodeid. The assertion arm is
# tests/test_no_import_time_registry_mutation.py (a NORMAL failing test names
# offenders; a collection abort would exit rc=2 — indeterminate at the Step
# 9c compare — instead of a named NEW failure).
from explore_persona_space.artifacts.context import CONTEXTS as _GUARD_CONTEXTS
from explore_persona_space.artifacts.negatives import NEGATIVE_PANELS as _GUARD_PANELS

IMPORT_TIME_REGISTRY_DELTAS: dict[str, dict[str, list[str]]] = {}
_guard_prev: dict[str, set[str]] = {}


def pytest_configure(config):
    _guard_prev["contexts"] = set(_GUARD_CONTEXTS)
    _guard_prev["panels"] = set(_GUARD_PANELS)


def pytest_collectreport(report):
    ctx, pan = set(_GUARD_CONTEXTS), set(_GUARD_PANELS)
    dctx = ctx - _guard_prev["contexts"]
    dpan = pan - _guard_prev["panels"]
    if dctx or dpan:
        IMPORT_TIME_REGISTRY_DELTAS[report.nodeid] = {
            "CONTEXTS": sorted(dctx),
            "NEGATIVE_PANELS": sorted(dpan),
        }
    _guard_prev["contexts"], _guard_prev["panels"] = ctx, pan


@pytest.fixture
def import_time_registry_deltas():
    """Per-collector registry growth recorded during THIS run's collection
    (#2217). A COPY — mutating it cannot corrupt the record."""
    return {k: dict(v) for k, v in IMPORT_TIME_REGISTRY_DELTAS.items()}


@pytest.fixture
def _registry_guard_internals():
    """TEST-ONLY seam: the LIVE deltas dict + hook fns, so the guard's own
    negative control executes the real hook body (#906 one-production-body-
    test rule), never a copy."""
    return IMPORT_TIME_REGISTRY_DELTAS, pytest_collectreport, _guard_prev
```

### 11. Decision Rationale

1. **Leg-1 fix shape = lazy helper (not a fixture, not `lru_cache`).** What: `_panel_ids()` plain function. Why: minimal 5-site diff; fixture-izing would thread a param through `build_panel_fixtures`'s plain-function callers; caching pins registry objects across the module-hygiene teardown. Source: read of `tests/test_issue1481_analysis.py` use sites (§4 grep block). Alternatives: module `__getattr__` lazy attribute (clever, less readable); pytest fixture (more invasive).
2. **Leg-3 instrument = conftest collection-hook + `test_no_*` assertion test, NOT a workflow_lint AST check.** Why: the brief demands the false-negative statement — a static AST scan is demonstrably blind here: the registration is one call level down (`bystander_panel` → `register_fu3_contexts`; nothing in the offending file names a registrar), and the same file's L37 `_sha256_text(...)` shows benign module-level calls are pervasive, so any "flag module-level calls" heuristic is either blind or drowning in false positives. The runtime hook measures the ACTUAL registries — zero false positives by construction. Source: settled diagnosis + `/tmp/probe2217_plugin_all.py` demonstrating the hook mechanism end-to-end on the live incident.
   **Stated false-negative profile of the chosen instrument:** (a) self-scoping — only modules collected in THE RUN are checked; a module not collected cannot poison that run either, and WORKFLOW_INVARIANT registration puts the assertion in every Step 9c gate run (the selector docstring: invariant tests are unioned "regardless of which files were touched" — `scripts/select_step9c_tests.py:9-11`); a lone hand-run `pytest tests/test_foo.py` without the guard file goes unchecked until the next gate. (d) Attribution is per-collectreport — a delta from a non-module hook between reports lands on the nearest nodeid (still a loud failure).
