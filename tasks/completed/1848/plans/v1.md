architectural: false

## Goal / requirement

`scripts/plan_patch.py` takes its target as a positional (`file`,
build_parser L405), while every note-bearing workflow CLI (`task.py
post-marker` / `set-body` / `new-plan-version`) takes `--file`. Three
independent sessions on 2026-07-29 invoked `plan_patch.py --file <draft>`
(argparse error, exit 2); two persisted junk plan versions because the
failed patch was chained with the persist in one compound (one additionally
piped through `tail`, masking rc — the post-pipe `$?` trap). Requirement:
`--file <path>` becomes a legal spelling of the target; both/neither misuse
fails loud with the file untouched; `--help` warns against piping the gate
chain through filters.

## Acceptance criteria

1. `plan_patch.py --file <draft> --anchor A --replace B` behaves
   identically to the positional form (same stdout sentinel, same diff,
   same write).
2. Supplying BOTH the positional and `--file` — or NEITHER — fails exit 2
   with a clear usage message (`PLAN-PATCH FAILED:` prefix); target file
   untouched.
3. Full back-compat: every existing positional invocation unchanged; exit
   codes 0/2/3 semantics unchanged.
4. `--help` epilog carries a no-pipe / rc-check note (never pipe
   plan_patch.py or `task.py new-plan-version` through `tail`/`grep` — a
   pipe masks the exit code; redirect to a file and check rc).
5. New tests cover 1, 2 (both arms), 4; the existing 25 tests in
   `tests/test_plan_patch.py` still pass.

## Method delta (vs current)

- `build_parser()`: positional `file` becomes `nargs="?"` (default `None`);
  new `--file` option with DISTINCT dest `file_opt` (argparse cannot place a
  required positional in a mutually exclusive group, and a shared dest is
  parse-order-fragile). Reconcile at the top of `_run()`: exactly one of
  `args.file` / `args.file_opt` must be non-None, else `PatchError` (exit 2,
  file untouched; error text names both spellings).
- `_EXIT_EPILOG`: append the no-pipe / rc-check note (acceptance 4).
- `tests/test_plan_patch.py`: 3 new tests — `--file` alias parity;
  both-forms exit 2; neither-form exit 2 — plus an epilog-note assertion on
  `--help` output (standalone or folded into the alias test).
