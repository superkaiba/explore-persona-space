### Item B — two new token classes in `_opaque_code_tokens`

`scripts/verify_task_body.py` (~L10002-10330)

**Class (h) — `role@span` slug.** New module-level regex beside the other
class regexes:

```python
_ROLE_AT_SPAN_RE = re.compile(r"\b[a-z][a-z0-9]{1,11}@[a-z][a-z0-9]{1,15}\b")
```

Joins the shared class tuple in `_opaque_code_tokens` alongside
`_HYPOTHESIS_CODE_RE` / `_SLOT_FAMILY_RE` / `_CANDIDATE_CODE_RE` /
`_LETTER_ARROW_RE`, inheriting the `_only_in_path_words` exemption
unchanged. Matches `pre@context`, `ctxext@context`, `rb@answer`.
Non-matching by construction: `@L12` layer pins (class (a)'s domain — the
RHS there is uppercase-initial, this regex requires lowercase-initial, so
no double-report), `user@example.com` (dot -> extension-tail arm of
`_is_path_like_word`), bare `@handle` (no LHS).

**Class (i) — standalone short arm code.** New regex + a co-occurrence gate:

```python
_SHORT_ARM_CODE_RE = re.compile(r"\A[a-z]{1,3}\d[a-z]?\Z")
```

FULL-STRING match against the scanned string (not a substring search), so
`a0` as a complete tick label flags while `a0` inside prose does not.
Additionally gated on CO-OCCURRENCE: a figure must yield >= 2 DISTINCT
class-(i) tokens before any is reported — a lone `q1` / `t0` / `x1` is
ambiguous, whereas `a0`,`a1`,`a2` as a tick set is unmistakably an
arm-code axis. Single-digit run keeps `p50` / `p95` percentile ticks out.

Co-occurrence needs figure-level aggregation, which check 28 already
performs (it accumulates `toks` per figure at ~L10524 before reporting), so
the gate applies there — class (i) hits are collected separately and
merged into `toks` only when the per-figure distinct count >= 2. Because
of this, class (i) does NOT join the shared class tuple; it follows the
class-(g) precedent of a helper (`_short_arm_code_hits`) invoked
separately, with a `_is_short_arm_code_token` membership predicate so the
class stays re-derivable from token text alone (the `_is_arm_slug_token`
convention).

**Caption suppression (#1988).** Currently scoped to class (g) only via
`_suppress_caption_decoded_slugs` / `_is_arm_slug_token`. Decision: EXTEND
suppression to classes (h) and (i) — a figure whose blockquote caption
spells out `rb@answer` has decoded it for the reader, which is the exact
rationale #1988 recorded for arm slugs. Implemented by widening the
predicate in `_suppress_caption_decoded_slugs` to
`_is_arm_slug_token(t) or _is_role_at_span_token(t) or
_is_short_arm_code_token(t)`.
