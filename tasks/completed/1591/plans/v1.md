## Method delta (vs the existing #1048 surface)

1. **Verb-set widening only.** No structural change to the parse (unit split, stage scan, carve-out order all untouched). Three regex alternations gain `|commit`.
2. **New failure mode named in docs:** for push/merge the harm is a masked non-zero exit; for commit there are two harms — (a) the same masked exit (a gitleaks-blocked or nothing-to-commit failure reads as success) and (b) SIGPIPE mid-pre-commit-hook kills the commit while its hook is mid-run (#1584). Blocking the piped shape addresses both.
3. **Carve-outs inherited, not added:** the per-stage `--dry-run` case (hook L142) and the lint's span-contains-`--dry-run` skip already fire verb-independently, so `git commit --dry-run | head` allows for free (a dry-run commit lands nothing; masking is harmless). The heredoc blanket-allow (hook L96) keeps the canonical heredoc commit recipe (A13) allowed — it fires before any regex. Producer-detection-on-non-final-stages-only keeps `cat msg.txt | git commit -F -` (message piped INTO commit) allowed. No hooksPath/`--no-verify` carve-outs: simplicity wins, and a `--no-verify` piped commit still masks the exit code (and the project bans `--no-verify` anyway).
