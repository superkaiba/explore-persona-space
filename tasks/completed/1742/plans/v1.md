# Plan v1 — Task #1742: Step 9c urgent-park emission made mechanical

## Goal / Requirement

Make the Step 9c urgent-park emission mechanical: `scripts/step9c_baseline.py
compare` prints/returns a machine-readable `URGENT-PARK-REQUIRED` trigger when
a stripped pre-existing failure sits on a workflow-invariant test, and the
`/issue` SKILL.md Step 9c verdict block makes acting on that trigger a numbered
mandatory step (emit the routable `urgency: main-red` candidate block, or
verify one already exists) instead of a prose duty sessions forget.

**Acceptance criteria:**
1. `compare --json` output carries a new `urgent_park_required` list field:
   one `<file>::<name>` node id per STRIPPED node whose test file is in the
   selector's `WORKFLOW_INVARIANT` set; `[]` otherwise (including on the
   indeterminate exit-2 payload — stable shape).
2. Each such node also emits a loud stderr line via `_log`:
   `URGENT-PARK-REQUIRED: <file>::<name> — stripped pre-existing main-red on a
   workflow-invariant test; emit (or verify existing) a routable
   'urgency: main-red' workflow-fix-candidate (#1713/#1742)`.
   Non-JSON mode additionally prints `  URGENT-PARK-REQUIRED: <id>` on stdout
   beside the existing NEW/warn lines. Under `--json`, stdout stays exactly
   one JSON object (#1077 invariant preserved — trigger rides the JSON field
   + stderr only).
3. SKILL.md Step 9c gains a numbered mandatory sub-step in the verdict block
   (immediately after the COMPARE verdict bullets, before the
   `epm:test-verdict` marker-note paragraph): on a non-empty
   `urgent_park_required`, IN THE SAME TURN as posting `epm:test-verdict`,
   the session (i) runs a bounded dedup grep over `tasks/*/*/events.jsonl`
   for `failing_test: <node id>`; (ii) on no hit, emits the
   `<!-- workflow-fix-candidate v1 -->` block carrying `urgency: main-red` +
   `failing_test: <node id>` + `wf_fix: true|false` (routed/parked by the
   standard workflow-fix protocol; under the recursion guard the park IS the
   routable record the watcher's urgent-park router consumes); (iii) records
   the disposition (`urgent_park: emitted <id>` | `urgent_park: existing
   <events path>`) in the `epm:test-verdict` note. The marker-note record
   list is extended with this disposition line.
4. New pin tests in `tests/test_step9c_baseline.py` cover: (a) stripped
   workflow-invariant node → field populated + stderr line; (b) stripped
   non-invariant node → empty field, no line. `test_compare_json_deterministic`
   updated if it pins the exact key set.
5. Full mapped-test leg green; no new lint failures.
