## 1. Goal

(from task body) A pathspec-limited commit that cannot sweep an uncertified staged file is not blocked by that file's presence in a concurrent session's staged index. Concretely: close the mechanisms that still defeat #1620 pathspec scoping, evidenced by the 2026-08-02 incident (session transcript `55419495-40b9-42a7-9f73-e537fcead396.jsonl` lines 6730-6736, second block at 20:20:29Z) and this session's isolated replay.

## 2. Diagnosis (evidence by reference)

- **Production defect (one mechanism):** a top-level heredoc opener token attached to the commit clause enters the pathspec-candidate stream — `redirect_tok_kind` (hook L560-601) returns `no` for the here-doc/here-string operator family by pinned design — so `classify_candidate` marks the clause opaque → whole-index fallback → block. Isolation: heredoc-bearing shape blocks while the identical command minus the heredoc scopes clean; all three incident-composite replays block.
- **Test-parity gap (production-neutral):** the two cd classification sites compare against the hardcoded `$REPO` (L128) instead of `$GUARD_REPO` (L129, the `EPM_ROOT_CODE_COMMIT_REPO` override): `cd_latch_verdict` (L349-358) and the MF-1(ii) root-spelling case arm (~L671-677). Under a hermetic test repo, a cd to that repo's own root reads as latch/non-root, so the incident composite (cd-prefixed) cannot be covered by self-test rows. In production the incident's cd target string-matched `$REPO` exactly, so the cd was NOT the incident defeater.
- **Non-defeaters confirmed by isolation (no change needed):** output redirects (#1928, rows A21/A22), trailing commands on later lines, semicolon tails, `-F /dev/stdin` without heredoc, message-file + pathspec (#1949, row A23).

## 3. Changes (4 legs; two files)

**L1 — production fix: heredoc-opener interception.** In the commit-clause second token pass, intercept top-level heredoc opener tokens BEFORE candidate classification, in BOTH arms: the post-`--` arm (~L783-795) and the positional arm (~L826-833). Implement as a NEW strict helper `heredoc_tok_kind` (echoes `self` / `pair` / `no`):
- attached unquoted delimiter (`<<DELIM`, `<<-DELIM` shapes) → `self`; bare separated operator (`<<`, `<<-`) → `pair` (consumes the delimiter word); here-string with attached word → `self`, bare → `pair`;
- masked-delimiter forms (quoted delimiter → FILL-bearing token): recognize iff the token is exactly the opener operator + masked remainder — derive the exact masked shapes from `parse_heredoc_delim` (L191-235), do not guess;
- anything else → `no` (fail closed, today's opaque → whole-index → block path).
- `redirect_tok_kind` stays byte-untouched: its heredoc-family→`no` contract is pinned by the r14/r15 refuse tests + its doc block.
- Accepted residual (document in the known-limitations header, L76 precedent): a MASKED (quoted/spacey) pathspec combined with a heredoc still fails rawtail token-count parity → opaque → block, same accepted residual as redirects (#1928).

**L2 — test parity (production-neutral): repoint the two cd sites at `$GUARD_REPO`.** `cd_latch_verdict` root arm + the MF-1(ii) case arm compare against `$GUARD_REPO` instead of `$REPO`. `GUARD_REPO` defaults to `$REPO`, so production behavior is bit-identical; hermetic repos gain cd-to-root coverage. The literal `~/…` and `$HOME/…` spellings stay as-is.

**L3 — self-test rows (`run_self_test`, hook L1060+).** New rows, seeded from this session's replay harnesses (`/tmp/issue-2046-replay.sh`, `/tmp/issue-2046-isolate.sh`):
- A-row: incident composite — cd-to-root prefix + `-F /dev/stdin` + pathspec excluding a foreign uncertified gated staged file + output redirect + heredoc + trailing commands → expect 0.
- A-row: minimal heredoc — `-F /dev/stdin` + heredoc + excluding pathspec → expect 0.
- A-row: cd-to-root prefix + `-m` + excluding pathspec → expect 0.
- B-row control: heredoc + pathspec COVERING the gated file → expect 2.
- B-row control: bare commit (no pathspec) + heredoc → expect 2.
- All existing rows stay green — notably A9/B16b (quoted `$(cat <<EOF…)` message-substitution shapes: masked as string literals, structurally untouched by top-level opener interception; they are the regression pin), A21-A23, B18, and the cd-latch family (A5, B20, B27, B31, B33).
