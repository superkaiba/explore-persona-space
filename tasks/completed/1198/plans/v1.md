## 4. Design

**Edit 1 (the change).** In `.claude/rules/crash-fix-rounds.md`, replace lines 178-179:

```
2. **Kill** — `pkill -TERM -f '<same pattern>'`; wait ~10 s;
   `pkill -KILL -f '<same pattern>' 2>/dev/null || true`.
```

with this exact text (imperative, tight, incident-cited — house style; hard-wrapped to match the file):

```
2. **Kill** — by EXPLICIT PID: `kill -TERM <pid>...` on exactly the
   step-1 PIDs you read and confirmed as yours; wait ~10 s;
   `kill -KILL <pid>... 2>/dev/null || true`. A PID that exited between
   probe and kill makes `kill` return nonzero — tolerate it (`|| true`
   or a per-PID loop; step 3's re-probe is the real dead-check), and
   keep the probe→kill gap short. Pattern pkill
   (`pkill -TERM -f '<same pattern>'`; wait ~10 s; `pkill -KILL -f
   '<same pattern>' 2>/dev/null || true`) is a FALLBACK only when the
   step-1 listing is unusable (output lost, PIDs unreadable) — pkill
   re-matches the pattern at KILL time, so a concurrent session's
   byte-identical invocation starting after the probe gets TERMed
   without the step-1 discriminators ever seeing it (the probe→kill
   TOCTOU; #848 review finding, closed by #1198).
```

Edge cases the text handles, per the clarifier's checklist:
- **(a)** kills exactly the step-1-listed, discriminator-confirmed PIDs ("you read and confirmed as yours" ties back to step 1's ownership language without restating it).
- **(b)** already-exited PID → nonzero `kill` exit: tolerated via `|| true` / per-PID loop; POSIX `kill` signals every listed PID even when one fails, so a multi-PID call still TERMs the survivors. Step 3's confirm-dead re-probe stays the authoritative check. One clause on keeping the gap short covers the (rare) inverse race of PID recycling.
- **(c)** pattern pkill stays legal ONLY on an unusable listing, with the one-line TOCTOU warning inline.
- **(d)** steps 3 (confirm-dead re-probe) and 4 (fuser fallback, which already says "then kill by explicit PID") untouched — the new step 2 is now *consistent* with step 4's existing explicit-PID language rather than contradicting it.
- **(e)** style: imperative, `**Kill**` bold-lead preserved, incident-cited, same numbered-list shape.
