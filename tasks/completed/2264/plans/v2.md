## 1. Goal (from task body, verbatim intent)

Add two WARN-grade checks to `scripts/verify_task_body.py` catching two Methodology/Results
fixtures that recurrently go stale when follow-up rounds are folded into a v4 clean-result body
(surfaced by the #2224 round-3 clean-result-critic, 2026-08-13):

1. **Per-unit-exemption check (Lens 11 mechanization):** WARN when a `### <result>` block's only
   figure caption reports a correlation/AUC-family statistic (r / rho / R² / AUC) and the block

2. **Acknowledgment result-count check:** when the body's conciseness-cap acknowledgment
   paragraph states "across N results", compare N to the actual `###` count under `## Results`;
   WARN on mismatch — and WARN on a "single-round" claim when the body carries folded-round
   evidence.

Both WARN-only (forward-only discipline: v3/v2 bodies exempt via the v4 sentinel gate), with
fixture-backed tests beside the existing verify_task_body tests.

## 4. Method (implementation spec)

### Check A — `check_v4_aggregate_stat_needs_per_unit` (single aggregate-stat figure, no per-unit evidence)

Structural template: `check_v4_result_figure_cardinality` (v4 gate → `_v4_results_body` →
`_prose_layer` → `_collect_tldr_h3_names` → per-H3-block scan → one CheckResult; WARN detail
enumerates offending H3s).

Per `### <result>` block:
1. `figures = _v4_block_inline_figures(block)`. Fire ONLY when `len(figures) == 1` — the
   0-figure case is check 48's territory, the >1-figure case is the cardinality check's.
2. **Statistic detection**, scoped to the single figure's alt text + the block's blockquote
   caption lines (`>`-prefixed) — NOT general section prose, same scoping rationale as the
   cardinality check (what-is-plotted beats routinely mention ρ as disclosure prose; whole-block
   matching would drown the signal). Regex (implementer may tune against fixtures, keeping the
   family): word-boundary-guarded `r` / `rho` / `ρ` / `R2` / `R²` / `R^2` / `AUC` / `AUROC`
   followed by `=` / `≈` / `:` and a numeric — plus a `Spearman|Pearson` word immediately before
   a bare `r`/`rho` as an alternate trigger. Bounded false-positive duty below.
3. **Exemption evidence** (any ONE suffices → no WARN):
   - literal token `per-unit exemption` anywhere in the block's prose layer, case-insensitive,
     hyphen/space/en-dash tolerant (`per[-–—\s]?unit exemption`) — the new machine-read token;
   - the single figure's basename matches `_PER_UNIT_FIG_RE` (the figure already IS the per-unit
     view — SPEC's first stated exemption);
   - the declared-pair idiom `_DECLARED_PAIR_RE` matches the alt text / caption lines (parity
     with the cardinality check's pair-evidence vocabulary).
4. Otherwise WARN, naming the H3, the matched statistic text, and the missing-evidence classes.

### Check B — `check_v4_ack_result_count` (acknowledgment claims vs folded body)

Signature `check_v4_ack_result_count(body: str, *, issue: int | None = None)` (precedent:
`check_orphaned_per_unit_figures`).

1. `ack = _warn_acknowledgment_text(body)` (existing helper: dash-normalized, lowercased
   acknowledgment-paragraph union). `None` → PASS ("no acknowledgment paragraph").
2. Actual result count = number of H3s from `_collect_tldr_h3_names(_prose_layer(results))`
   where `results = _v4_results_body(body)`; `results is None` → PASS (check 2 reports).
3. **Count-claim arm:** parse every `(?:across\s+)?\b(\d{1,3}|one|…|twenty)\s+results?\b` match
   in `ack` (helper output is lowercased; word-number map one..twenty covers the prose form —
   #2224 wrote "nine results"). Any parsed N ≠ actual → WARN naming claimed vs actual.
4. **Single-round arm:** `single[ -]round` present in `ack` AND folded-round evidence present —
   `_count_extra_followup_rounds_v4(body, issue)` count > 0 (fall back to the body-only leg the
   helper already implements when `issue` is None/unresolvable) → WARN.
5. No claims parsed → PASS. WARN-only throughout; one CheckResult unioning both arms' findings.
