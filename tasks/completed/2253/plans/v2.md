# Plan — #2253: `workflow_lint.py --check-prod-import-lockfile` (third-party imports vs `uv.lock`)

## 0.0 TL;DR (plain English)

- **What I'll build:** a new lint check that reads every Python file under `scripts/` and `src/`, finds every third-party package they import, and fails loudly when a package is not installable from the project's lockfile (`uv.lock` / `pyproject.toml`). It ships FAIL-level, bundled into the default lint run, with every one of the ~10 pre-existing offenders explicitly dispositioned (7 one-line waiver comments, 3 already-guarded sites, 1 declared-overlay rule) so the whole tree is green the day it lands.

- **What would change my mind:** if the full-tree acceptance run finds an offender class the recon missed, or a fixture shows the try/except-ImportError exemption or the issue-stem heuristic misclassifies, I re-scope that class (WARN bucket or waiver) before bundling — the check never lands red on the live tree, because a red no-flags run is a fleet-wide Step 9c wedge (#1388).

## 1. Goal

> Add a `workflow_lint.py` check that fails when a `scripts/` or `src/` module imports a third-party package on a **production** (non-smoke) code path that is not resolvable from `uv.lock` / `pyproject.toml`. This mechanizes a duty that is already documented but currently only caught by human review.

(Task #2253 body `## Goal`, verbatim; task is `kind: infra` with no `goal:` frontmatter. Re-read from `tasks/planning/2253/body.md` at plan-return time — unchanged since draft start.)

**Adopted scope sharpening (Goal unchanged, framing simplified):** the shipped check is **branch-agnostic**. An import that is unresolvable from the lockfile is a latent `ModuleNotFoundError` wherever it sits — production branch, smoke branch, or nested three helpers deep — because *resolvability* does not depend on *reachability*. A plain `ast.walk` over every import node therefore (a) satisfies the body's "production (non-smoke) code path" framing as a strict superset: every production-branch import is scanned, including the #1336 module-local-helper shape, with no smoke/production branch analysis and none of `--check-smoke-blind-spots`' documented false negatives (one-level helper resolution, un-recursed `ast.Match` bodies, dynamic dispatch, non-`smoke`-named flags); and (b) additionally covers smoke-branch imports, which is a strengthening, not a scope change — a smoke branch importing an uninstallable package is equally broken. The one legitimate "deliberately optional" escape the body names — an explicit `try/except ImportError` degrading a non-load-bearing path — is implemented as an AST-level exemption (§4 step 4), plus a waiver-comment escape for sites that cannot restructure (the established `DOTENV_LINT_EXEMPT` idiom). Source: the #2253 `epm:clarify v1` recon (task events, 2026-08-20), verified against the committed probe `tasks/planning/2253/artifacts/recon_import_surface_probe.{py,out}`.

### 4.1 The check function

```python
PROD_IMPORT_LINT_WAIVER_MIN_REASON_CHARS = 10  # mirrors DOTENV_LINT_WAIVER_MIN_REASON_CHARS

# Import-name -> PyPI distribution name, for roots whose module name does not
# PEP-503-normalize to their dist name. Deterministic primary (§11 D3); a
# table entry whose dist is absent from the lockfile is itself a FAIL.
IMPORT_TO_DIST: dict[str, str] = {
    "PIL": "pillow", "dotenv": "python-dotenv", "hydra": "hydra-core",
    "sklearn": "scikit-learn", "umap": "umap-learn", "yaml": "pyyaml",
}

# Declared working-tree overlays: import roots served by a checked-in external
# tree, not the lockfile. Consistency with backends.slurm.WORKING_TREE_OVERLAY_PATHS
# is test-pinned (import in the TEST only — workflow_lint stays dependency-light).
OVERLAY_IMPORT_ROOTS: dict[str, str] = {"open_instruct": "external/open-instruct/open_instruct"}

def check_prod_import_lockfile(
    *, scan_roots: tuple[Path, ...] | None = None,
    lock_path: Path | None = None, pyproject_path: Path | None = None,
    repo_root: Path | None = None,
) -> list[str]: ...
```

Algorithm (per invocation):

1. **Load the dist universe** (fail-loud: a missing/unparseable `uv.lock` or `pyproject.toml` returns one error naming it — backing test `::test_missing_lockfile_fails_loud` — never a silent skip): `tomllib.loads(uv.lock)` → `{pep503(p["name"]) for p in lock["package"]}`; pyproject `project.dependencies` + `project.optional-dependencies.*` + `dependency-groups.*` via a PEP-508 name-prefix regex (`^[A-Za-z0-9]([A-Za-z0-9._-]*[A-Za-z0-9])?`), each PEP-503-normalized (`re.sub(r"[-_.]+", "-", s).lower()`).
2. **Build the first-party set once:** `{"explore_persona_space", "scripts", "src", "tests", "conftest"}` ∪ `{p.stem for p in (repo/scripts).rglob("*.py")}` ∪ `{d.name for d in (repo/src).iterdir() if d.is_dir()}` ∪ `{d.name for d in (repo/scripts).iterdir() if d.is_dir()}`. The `scripts`/`src` package roots are the load-bearing addition — the recon's 455-site class-(A) false-positive avalanche under a stems-only resolver.
3. **Scan** `_files_scope_filter(sorted(root.rglob("*.py")))` for each scan root (default `scripts/`, `src/`); parse via `_cached_parse`; unparseable → one stderr `workflow_lint: note:` line (the `check_scripts_import_guard` idiom, `workflow_lint.py:8718`). Collect `(root, lineno)` per `ast.Import` alias and per level-0 `ast.ImportFrom` (`module.split(".")[0]`); relative imports (level>0) skipped.
4. **Per-site exemptions:** (i) the import node sits lexically inside an `ast.Try` any of whose handlers names `ImportError` or `ModuleNotFoundError` (Name/Attribute/tuple forms; body, handler, and orelse positions all exempt — documented accepted false-negative direction: a deliberate opt-out is the author's recorded choice, and the fail-fast rule polices misuse at review); (ii) a `# PROD_IMPORT_LINT_EXEMPT: <reason>` (reason ≥ 10 chars) on the import's first physical line or the immediately preceding non-blank line.
5. **Classify each remaining root:** stdlib (`sys.stdlib_module_names | {"__future__"}`) → skip; first-party → skip; overlay root with its package dir present in the working tree → skip (absent dir → FAIL naming the missing overlay — backing test `::test_overlay_dir_absent_fails`); PEP-503(root) ∈ dist-universe → resolved; `IMPORT_TO_DIST[root]` present and its dist ∈ universe → resolved; table entry present but dist ∉ universe → FAIL (table drift, loud — A4).
6. **Unresolved split:** `root.lstrip("_").startswith("issue")` → **class-(B) WARN bucket** — one stderr line per root: `workflow_lint: WARN: --check-prod-import-lockfile: dangling first-party import root '<root>' (<n> site(s)) — module absent from main (unmerged branch or deleted); latent breakage, not a third-party verdict` — root names + counts ONLY, never file paths (the files-mode output contract at `workflow_lint.py:18550-18553` treats any leg line naming a payload path without a WARN/PASSED/SKIPPED prefix as a red hit; path-free lines are immune by construction). This extends the established `_issue_import_closure` `name.startswith("issue")` convention (`:18848`) with the leading-underscore form (covers `_issue506_common`). Never folded into `errors`. **Everything else → class-(C) FAIL**, deduped to one error per `(file, root)` anchored at the first non-exempt site (a waiver on any one site of the pair exempts the pair — resolvability is a per-(file,root) fact, and this minimizes waiver-edit count, e.g. `issue1776_jlens_fit.py`'s 4 jlens import lines need one waiver).
7. **Error message shape:** `"{rel}:{lineno}: third-party import `{root}` is not resolvable from uv.lock/pyproject.toml (#2253/#2223). Tried: pep503('{root}')='{norm}', IMPORT_TO_DIST[...]. Fix: add the distribution to pyproject.toml + `uv lock`; or add an IMPORT_TO_DIST entry if import-name != dist-name; or guard a deliberately-optional NON-load-bearing use with try/except ImportError; or waive with '# PROD_IMPORT_LINT_EXEMPT: <reason>' (>= 10 chars).{venv_hint}"` — `venv_hint` is a best-effort enrichment from `importlib.metadata.packages_distributions()` (wrapped `try/except Exception`, message-only, NEVER verdict-bearing; tests never assert on it), e.g. `" (live venv maps this to dist 'X')"`.

Smoke blind-spot enumeration: `none — this plan declares no smoke run and the check itself contains no smoke-conditional branch` (the check is branch-agnostic by design; the fixture tests ARE the pre-landing validation).

Embedded-shell exit-path trace: N/A — no multi-arm embedded shell in this plan; every verification command is a single foreground invocation whose rc is read bare.
