```python
def _gate_cell_trainability(
    n_rows: int,
    cell_slug: str,
    *,
    smoke: bool,
    override_floor_rows: int | None = None,
    override_reason: str | None = None,
) -> dict:
    """Absolute per-cell trainability gate (#2242 D11 mirror; #2243).

    Derives the floor from the SAME expressions SFTConfig consumes below
    (ft.PER_DEVICE_BATCH * ft.GRAD_ACCUM, ft.EPOCHS): if a future edit gives
    this script local constants, update BOTH SFTConfig and this call together —
    the gate follows the trainer, never a stale import (clarifier Finding 2).
    """
    import issue778_finetune as ft

    from explore_persona_space.artifacts.datagen import assert_cell_trainable

    return assert_cell_trainable(
        n_rows,
        cell_id=cell_slug,
        effective_batch_size=ft.PER_DEVICE_BATCH * ft.GRAD_ACCUM,
        num_epochs=ft.EPOCHS,
        override_floor_rows=override_floor_rows,
        override_reason=override_reason,
        on_fail="warn" if smoke else "raise",
    )
```

Both imports are function-local, preserving the file's documented light-module-import contract (header: "--check-registry and the registry test import this module without pulling torch"). `issue778_finetune`'s module import is itself light (its torch/datasets imports are function-local — the #2242 test file's section-(i) comment).

### 11. Decision Rationale

1. **Design fork (constraint G): a local module-level adapter in `issue2225_train.py` calling `assert_cell_trainable` directly with `ft.*`-derived args** — over calling `ft._gate_cell_trainability(...)`. — **Why:** (a) constraint B's invariant lives at #2225's own call site: the gate's `ft.PER_DEVICE_BATCH * ft.GRAD_ACCUM` / `ft.EPOCHS` expressions sit lines above the `SFTConfig` that consumes the same expressions, so a future edit giving #2225 local constants updates both together — whereas `ft._gate_cell_trainability` would silently keep gating at #778's values after such a divergence, exactly the failure the task body feared; (b) avoids importing a leading-underscore (private-convention) symbol across scripts; (c) preserves the D11 testability shape — the mirror tests call `issue2225_train._gate_cell_trainability` exactly as the #778 tests call theirs.
