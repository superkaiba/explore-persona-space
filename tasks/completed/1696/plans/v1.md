### Edit A - `.claude/rules/trigger-dense-review.md` discipline 2

Extend discipline 2 (currently lines 58-65) with an explicit `Write`-first / post-first ordering clause. The current paragraph reads:

> **2. Durable verdict FIRST; chat summary last and optional.** Write the verdict body to its file and POST the marker (`epm:code-review` / `epm:review-reconcile` via `task.py post-marker`) BEFORE composing any closing chat text — a filter kill on the summary then costs nothing (the orchestrator's durable-verdict-first probe finds the marker, SKILL.md Step 5b). In-context modes (adversarial-planner Phase 2 lenses; reconciler `mode: in-context`) have no marker: put the role-tagged verdict block FIRST in the returned text, any extra prose after it.

Append a new paragraph (or extend the existing one) with the following text (implementer refines wording, keeps the anchors):

> **Guard/hook-surface rounds — file-first ordering.** On a trigger-dense round targeting `.claude/hooks/*.sh` or `scripts/guard_*.sh`, the reviewer's FIRST durable action after reaching a verdict is `Write` to the verdict file, then `uv run python scripts/task.py post-marker <N> epm:code-review --version <K> --file <path>` (never `--note`: the marker body itself is trigger-dense and must ride the `--file` path so the repo-root guard's `--file` requirement is honored). The verdict body is composed DIRECTLY into that file via `Write`, NOT written first as assistant/reasoning text and then transcribed — a filter kill on the intermediate composition turn destroys the verdict before it ever reaches the file (incidents #1673/#1675/#1676/#1687: four refusals across nine sessions on the #1667-#1689 wave; three killed reviewers 15-24 tool calls into their final turn, before the marker post). The in-context RETURN TEXT (marker-mode) or the role-tagged verdict block (in-context mode) is composed AFTER the marker lands, and stays under the discipline 4 shape (verdict + pointer + counts, no findings recap). Pairs with SKILL.md Step 5b's durable-verdict-first probe: with the marker landed first, a final-turn refusal costs the summary (recoverable via a discipline-4-clean re-post or the orchestrator's own summary composition) rather than the verdict (a full respawn).

**Rationale:** the added clause names the failure mode the current text does not: composing the verdict body as inline assistant text on a turn that then gets killed by the filter. The paragraph explicitly bars that path (`Write` DIRECTLY into the file). Cites the exact four incidents from the task body for grounding.

**Grep target verification (acceptance criterion e):** the phrase `post-marker` combined with the ordering word `before` appears in the added clause (`post-marker <N> ... --file <path>` on one line, `AFTER the marker lands` immediately below the composition sentence). Baseline `grep -c 'verdict.*before.*report\|post-marker.*before' .claude/rules/trigger-dense-review.md` = 0; after the edit >= 1.
