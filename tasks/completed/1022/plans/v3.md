**Requirements:**

- R1. A mechanical helper subcommand (`step9c_baseline.py compare`) — not prose arithmetic in SKILL.md — decides which Step 9c failures are pre-existing on main. Only NEW failures (and lint *regressions*) block.
- R2. The ledger is refreshable (`refresh`), staleness-aware (`status` + compare-side degradation), concurrency-safe (flock single-flight, atomic write), and never committed to git (`.claude/cache/` is gitignored — verified, `.gitignore:78`).

- R4. A failing touched-subset test that is NOT in the ledger — or that IS in the ledger but is diff-linked, per-entry-stale (its test file changed on main since the ledger SHA), or ledger-dirty — is resolved by an on-demand pristine-main check of just that test file at the repo root (bounded, ≤5 distinct files per compare), never by a blind strip.
- R5. The compare must not mask a REAL regression the diff caused: blind strip requires (fresh ledger) ∧ (`dirty_code_paths: false` at refresh) ∧ (not diff-linked) ∧ (test file unchanged on main since ledger SHA); anything else requires a live pristine-main failure of the same node from a CLEAN-code-path root; EVERY strip of a scan-covered test (file ∈ GLOB_SCAN_TESTS) carries a masking WARN naming the branch's touched files that scan covers.

The full-scope (`test_scope: full`) override, now that compare decides the verdict, runs WITHOUT `-x --maxfail=1` — on red main an `-x` run truncates at the first known-red failure and compare would otherwise PASS a mostly-unexecuted suite. ### 3.1 Ledger JSON schema (v1)

```json
{
  "schema_version": 1,
  "main_sha": "<40-hex HEAD of the main repo root at refresh time>",
  "refreshed_at": "2026-07-04T22:10:00Z",
  "dirty_code_paths": false,
  "dirty_paths": [],
  "test_universe": ["tests/test_task_workflow.py", "...34 files (present-on-disk WORKFLOW_INVARIANT + GLOB_SCAN_TESTS keys)"],
  "failing_tests": [
    {"file": "tests/test_shared_vm_thread_caps.py",
     "classname": "tests.test_shared_vm_thread_caps",
     "name": "test_no_new_torch_before_dotenv_vm_entrypoints"}
  ],
  "pytest_summary": {"tests": 0, "failures": 0, "errors": 0, "skipped": 0, "duration_s": 0.0},
  "ruff_count": 2149,
  "ruff_format_files": 18,
  "refresh_timeout_s": 1800,
  "generator": "step9c_baseline.py v1"
}
```

- `failing_tests` entries are NODE-level keys `(file, classname, name)` — so a NEW failing test inside an already-red file still blocks (§10 item 2).
- `dirty_code_paths` / `dirty_paths` (MF-4a): probe scoped to CODE paths only — `git status --porcelain -- '*.py' pyproject.toml uv.lock` (recursive `'*.py'` pathspec). The v2 pathspec (`scripts/ src/ tests/ ...`) included non-Python files like `scripts/pods_ephemeral.json`, which is continuously rewritten — the bit would have read true near-permanently, a protection illusion. `dirty_paths` records the offending paths (capped at 20) for diagnosability. **The flag is CONSUMED, not just recorded** (MF-4b): a `dirty_code_paths: true` ledger is stale-for-blind-strip — compare routes every failure to pristine (§3.4); refresh still writes the ledger, and the ruff fields are unaffected (compare recomputes those live).
- `ruff_count` / `ruff_format_files` are recorded for `status` display and history; `compare` recomputes the ruff baseline LIVE at the main root (seconds — §3.4, §10 item 7), so ruff correctness never depends on ledger freshness.

`--pytest-rc` is REQUIRED (MF-1b): the exit code of the gate's pytest invocation. `rc ∉ {0, 1}` (2 = interrupted, 3 = INTERNALERROR, 4 = usage, 5 = no tests collected, 124/137/143 = timeout/kill signals) → compare exits 2 (indeterminate) even when the partial junit parses cleanly — an aborted run must never PASS on the testcases it happened to flush.

Exit codes (documented in the module docstring, pinned by tests):

| cmd | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| `refresh` | ledger written (or lock-busy single-flight no-op, stderr note) | — | pytest rc ∉ {0,1} / timeout / junit parse failure / git failure → **no ledger write** | — |
| `status` | fresh | — | ledger missing / schema-invalid | stale (reasons on stdout) |
| `compare` | no NEW failures AND no lint regression (with `--pytest-rc` ∈ {0,1}) | NEW failure(s) and/or lint regression (JSON names each) | indeterminate: `--pytest-rc` ∉ {0,1}; missing/empty junitxml; zero testcases; unusable ledger with unresolved buckets (no `--run-pristine`); pristine run timeout/crash; dirty pristine oracle on a failing node; >`--max-pristine-files` distinct pristine files ("systemic main breakage — investigate / refresh first"); missing ruff binary | — |

`--repo-root` overrides `main_repo_root()` (tests use tmp fixture roots); `--worktree` overrides compare's work-root (default: the invoking checkout's toplevel, same `_resolve_work_root` semantics as the selector — compare is RUN FROM the issue worktree at Step 9c).

### 3.3 `refresh` pseudocode

```python
def cmd_refresh(args) -> int:
    root = args.repo_root or main_repo_root()          # git rev-parse --git-common-dir → parent
    lock = acquire_refresh_lock(root / ".claude/cache/step9c-baseline.lock")  # LOCK_EX|LOCK_NB
    if lock is None:
        print("step9c_baseline: another refresh holds the lock — single-flight no-op", file=sys.stderr)
        return 0
    sel = load_selector_module(root)                   # the MAIN root's selector (importlib.util by
                                                       # path, the tests/test_select_step9c_tests.py
                                                       # L27-31 pattern) — refresh reads main's
                                                       # curation literals (version-skew note below)
    universe = sorted(present_on_disk({*sel.WORKFLOW_INVARIANT, *sel.GLOB_SCAN_TESTS}, root))  # 34 today
    if not universe: fail loud, return 2               # mirrors the selector's empty-selection refusal
    junit = root / ".claude/cache/step9c-baseline-junit.xml"
    junit.unlink(missing_ok=True)                      # same stale-junit lifecycle as the gate (MF-1a)
    # Bounded, thread-capped, cache-provider-off (no .pytest_cache contention with
    # concurrent repo-root pytest runs), group-killed on expiry:
    rc = run_pytest(files=universe, cwd=root, timeout_s=args.timeout_s, junit_path=junit,
                    extra=["-q", "--tb=no", "-p", "no:cacheprovider", "-o", "junit_family=xunit1"],
                    env=thread_capped(os.environ))     # setdefault OMP/MKL/OPENBLAS/NUMEXPR=8
    # subprocess.run(..., timeout=...) with start_new_session=True; on TimeoutExpired:
    # os.killpg(TERM, wait 10s, KILL), print loud, return 2 — NO ledger write.
    if rc not in (0, 1): fail loud (interrupted/internal-error refresh), return 2   # MF-1b parity
    failing, summary = parse_junit(junit)              # failure/error children; skipped excluded
    if summary["tests"] == 0: fail loud ("0 collected — refusing to write ledger"), return 2
    dirty = dirty_code_paths(root)                     # git status --porcelain -- '*.py' pyproject.toml uv.lock
    ledger = {..., "main_sha": git_head(root), "dirty_code_paths": bool(dirty),
              "dirty_paths": dirty[:20],
              "ruff_count": ruff_error_count(root), "ruff_format_files": ruff_format_count(root)}
    write_ledger_atomic(root / ".claude/cache/step9c-baseline.json", ledger)  # tmp + os.replace
    return 0
```

Notes: `refresh` runs at the MAIN repo root against the working tree (the alternative, a scratch worktree per refresh, mutates git worktree metadata and violates the no-git-mutation constraint). Concurrent-session code-path dirt is RECORDED (`dirty_code_paths`/`dirty_paths`, scoped per MF-4a) and CONSUMED downstream: a dirty-rooted ledger never blind-strips (§3.4). A pytest rc of 1 with parseable junit is the NORMAL red-main case, not an error; rc ∉ {0,1} refuses the write. `git rev-parse HEAD`, `git status --porcelain`, ruff runs: all read-only. **Selector version-skew (stated, by design):** refresh loads the MAIN root's selector — its curation literals define the universe main is red on; compare loads the INVOKING WORKTREE's selector — the same mapping that selected the run's tests. Each side reads the selector copy that governed its own pytest invocation.

### 3.4 `compare` pseudocode (the core semantics)

```python
def cmd_compare(args) -> int:
    if args.pytest_rc not in (0, 1):                   # MF-1b — aborted/interrupted/internal-error
        print loud ("pytest rc %d — refusing to classify a partial run"); return 2
    wt = resolve_work_root(args.worktree)              # invoking checkout (the issue worktree)
    root = args.repo_root or main_repo_root()
    run_failing, summary = parse_junit(args.junitxml)  # MISSING file / unparseable → exit 2 (a
                                                       # killed run leaves no junit thanks to the
                                                       # gate's pre-run rm -f — MF-1a)
    if summary["tests"] == 0: return 2                 # echoes the no-tests-ran FAIL guard

    sel = load_selector_module(wt)                     # the WORKTREE's selector — the same mapping
                                                       # that selected the run's tests (§3.3 note)
    touched = sel.compute_touched(args.base, wt)       # same 3-dot diff the selector uses
    _tests, _untested, reasons = sel.select_tests_with_reasons(touched, wt)   # §3.5
    diff_linked = {t for t, rs in reasons.items() if any(r != "invariant" for r in rs)} | \
                  {f for f in touched if f.startswith("tests/")}

    ledger = try_load_ledger(root)                     # None on missing/invalid (loud stderr)
    stale, stale_reasons = staleness(ledger, root, args)      # global predicate, below
    ledger_dirty = bool(ledger and ledger["dirty_code_paths"])       # MF-4b
    strippable_ledger = ledger is not None and not stale and not ledger_dirty
    changed_tests = changed_test_files_since(ledger, root)    # git diff --name-only <sha>..HEAD -- tests/
                                                              # sha unknown to git → treat fully stale

    new, stripped, pristine_bucket, warns = [], [], [], []

    def do_strip(node, via):                           # MF-6: EVERY strip of a scan-covered test
        stripped.append(node)                          # (blind OR pristine) carries a masking WARN
        if node.file in sel.GLOB_SCAN_TESTS:           # naming the branch's touched files that scan
            covered = [f for f in touched              # covers — "re-check these N files against
                       if matches_any(f, sel.GLOB_SCAN_TESTS[node.file])]   # the scan's rule"
            warns.append(scan_masking_warn(node, covered, via))
        if via == "pristine" and node.file in diff_linked:
            warns.append(diff_linked_masking_warn(node))

    for node in run_failing:                           # node = (file, classname, name)
        if not strippable_ledger:                      pristine_bucket.append(node)
        elif node in ledger.failing_tests:
            if node.file in diff_linked or node.file in changed_tests:   # MF-3 conjunct
                                                       pristine_bucket.append(node)   # R5 — never blind-strip
            else:                                      do_strip(node, via="ledger")   # safe blind strip
        elif not (root / node.file).exists():          new.append(node)   # branch-new test failing
        else:                                          pristine_bucket.append(node)   # unknown provenance

    if pristine_bucket:
        files = dedupe(n.file for n in pristine_bucket)
        if len(files) > args.max_pristine_files:       # systemic-breakage budget (non-blocking fold)
            print loud ("systemic main breakage (%d red files) — investigate / refresh first"); return 2
        if not args.run_pristine:
            print the per-file pristine commands; return 2    # indeterminate — never a silent strip
        for file in files:
            live_dirt = dirty_code_paths(root)         # MF-4c: probe scoped dirt AT PRISTINE TIME
            main_failing = run_single_file_pristine(file, cwd=root, timeout_s=..., junit→tmp)
            # timeout/crash of the pristine run itself → loud, return 2 (MF-5)
            for node in bucket_nodes(file):
                if node in main_failing:
                    if live_dirt:                      # a "pre-existing" verdict from a dirty
                        print loud (the dirty paths); return 2   # oracle is untrustworthy — MF-4c
                    do_strip(node, via="pristine")     # pre-existing at CURRENT clean main HEAD
                else:
                    new.append(node)                   # a PASS on a dirty root still → NEW (fail-closed)

    lint = lint_verdict(root, wt, touched)             # below; missing ruff binary → exit 2 (MF-5)
    emit json/human: {pytest_rc, new, stripped, warns, stale, stale_reasons,
                      ledger_dirty, ledger_dirty_paths, live_dirty_paths,
                      pristine_files_run, lint, ledger_sha, ledger_age_h}
    return 1 if (new or not lint.ok) else 0
```

**Staleness predicate** (grounded — §10 item 3): global-stale iff `age > --max-age-hours` (default 24) OR `git rev-list --count <ledger_sha>..HEAD -- scripts/ src/ tests/ pyproject.toml uv.lock` > `--max-code-commits` (default 150; measured cadence: 60 code-path commits on 2026-07-04 alone, so 150 ≈ ~2 busy days — while `tasks/**` marker commits, ~100+/hour, are excluded by the pathspec entirely) OR `ledger_sha` unknown to git. `dirty_code_paths: true` at refresh is a FOURTH strip-disabling condition (MF-4b) — folded into `strippable_ledger`, reported distinctly in the JSON. Per-ENTRY staleness rides on top: a ledger entry whose test FILE changed on main since `ledger_sha` is never blind-stripped (routed to pristine — MF-3, pinned by case 17).

**Lint verdict** (mechanical, replaces SKILL.md step 2):

```python
def lint_verdict(root, wt, touched):
    base_count  = ruff_error_count(root)     # LIVE main-root baseline (ruff check . --exit-zero
                                             #   --output-format=json → len(entries)); ~seconds
    wt_count    = ruff_error_count(wt)
    base_fmt    = ruff_format_count(root)    # "Would reformat:" line count; rc>1 → fail loud
    wt_fmt      = ruff_format_count(wt)
    touched_py  = [f for f in touched if f.endswith(".py") and (wt / f).exists()]
    touched_ok  = ruff_error_count(wt, paths=touched_py) == 0 and \
                  ruff_format_count(wt, paths=touched_py) == 0      # absolute-clean on touched
    return LintVerdict(ok = wt_count <= base_count and wt_fmt <= base_fmt and touched_ok,
                       deltas = {...})
```

## 10. §11 Decision Rationale

`N/A — no training hyperparameters` · `N/A — no behavioral construct` · `N/A — not a replication` · `N/A — no artifact reuse` · `N/A — no draw battery` · `N/A — no empirical-null gate` · `N/A — no re-extracted reference arms` · `N/A — no paired contrast` · `N/A — no held-out predictive DV`

1. **Ledger at `<main-root>/.claude/cache/step9c-baseline.json`, gitignored, `--git-common-dir`-resolved.** *Why:* VM-local derived state (failures environment-dependent); committing would add churn to a main taking 100+ task-state commits/hour; common-dir resolution gives ONE shared ledger visible from every worktree. *Source:* `.gitignore:78` (verified); `.claude/cache/issue-<N>-handle.json` precedent. *Alternatives:* committed file (churn + merge races); per-worktree cache (never found by the next session); `~/.task-workflow/` (repo-scoped state belongs with the repo).
2. **Node-level `failing_tests`.** *Why:* a NEW failing node inside an already-red FILE must still block — it pristine-routes (unknown to the ledger) and blocks when it passes on main (case 6). *Source:* refined from the task sketch. *Alternatives:* file-level (masks intra-file regressions); failure-text hashing (fragile, nondeterministic).
