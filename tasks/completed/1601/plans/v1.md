## 4. Design

**Chosen shape: generalize the #1596 mechanism with a `reason` parameter; do NOT add a
queue-timeout twin.** The rung walk, STANDARD pin, H100 refusal, cap accounting, lease stamping,
sidecar re-point, and every terminal branch are 100% trigger-independent — the ONLY
trigger-varying bits are (a) which caller arms the retry and (b) the reason label on the
running-JSON `current_phase` + the final marker. A thin twin would either duplicate the ~130-line
walk or reduce to this same generalization plus a wrapper. The public router function KEEPS its
name `retry_gcp_ondemand_after_queue_vanish` (exported in `__all__` at `router.py:5959`,
referenced by two lease-stamp docstrings at `router.py:4950`/`:5457`, six #1596 test call sites,
and two doc surfaces); its docstring is updated to state it serves both queue-loss triggers. The
private poller helper IS renamed (one def + one call site) because a "vanish" name handling both
triggers would be actively wrong.
