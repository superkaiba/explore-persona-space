# Plan — issue #1274: per-task stream grouping in the parked-candidate sweep

## 0. Plan Summary

**Change:** `scripts/sweep_parked_wf_candidates.py` `sweep()` currently iterates one stream per `tasks/*/*/events.jsonl` PATH; a task with a stale duplicate status folder (the #644/#1253 class — live example: `tasks/reviewing/1196` alongside canonical `tasks/completed/1196`) therefore yields TWO streams with the same `task:<id>` source label. The routed-record (`epm:workflow-fix-task-filed`) lives only in the canonical folder, so the stale folder's byte-identical candidate copy escapes suppression rule 1 (`suppressed:false`) and re-enumerates nightly (incident 2026-07-10, hand-deduped as `deduped:#1235`). Fix: group all events.jsonl paths of one task id into ONE logical stream — filed records collected across the group, row dedup shared across the group — so (a) a routed-record on ANY status folder closes the park's copies in EVERY folder and (b) identical fork copies collapse to one row. The cache file stays its own group. No output-schema change; the `suppressed_by.kind == "same-stream-filed"` string is kept. Plus a red-green test reproducing the exact #1196 shape and two grain-pinning tests.

**Files:** `scripts/sweep_parked_wf_candidates.py` (~25 changed lines incl. docstring), `tests/test_sweep_parked_wf_candidates.py` (+3 tests).

## 4. Design

### 4.1 Method delta (the fix)

**(a) `sweep()` — group paths by source label before the loop:**

```diff
-    streams: list[tuple[str, Path]] = []
-    for events in sorted(tasks_root.glob("*/*/events.jsonl")):
-        streams.append((f"task:{events.parent.name}", events))
-    if cache_file is not None and cache_file.exists():
-        streams.append(("cache", cache_file))
+    # One logical stream PER TASK ID: all tasks/*/<id>/events.jsonl status
+    # folders merge, so a routed-record posted on ANY folder of a task closes
+    # the park's copies in EVERY folder, and byte-identical fork copies
+    # row-dedup (#1274; incident #1196: a stale duplicate status folder — the
+    # #644/#1253 class — re-enumerated an already-routed park nightly). The
+    # cache file stays its own group: filed records never match across
+    # task/cache boundaries (the fp-less primary key is bare
+    # origin_candidate_ts equality, so a global pool could false-suppress a
+    # same-second park on a DIFFERENT task).
+    grouped: dict[str, list[Path]] = {}
+    for events in sorted(tasks_root.glob("*/*/events.jsonl")):
+        grouped.setdefault(f"task:{events.parent.name}", []).append(events)
+    streams: list[tuple[str, list[Path]]] = list(grouped.items())
+    if cache_file is not None and cache_file.exists():
+        streams.append(("cache", [cache_file]))
```

**(b) `sweep()` — load the group with a SHARED dedup set; collect `filed` over the merged rows (the existing line 468 then automatically spans the whole task):**

```diff
-    for source, path in streams:
-        rows, skipped = _load_stream(path, source)
-        skipped_rows += skipped
+    for source, paths in streams:
+        rows: list[tuple[dict, datetime, str]] = []
+        seen: set[tuple[str, str, str]] = set()
+        for path in paths:
+            path_rows, skipped = _load_stream(path, source, seen)
+            rows.extend(path_rows)
+            skipped_rows += skipped
         filed = [(r, ts) for r, ts, _raw in rows if _row_kind(r).startswith(FILED_KIND_PREFIX)]
```

**(c) `_load_stream` — accept an optional shared `seen` set (backward-compatible signature):**

```diff
-def _load_stream(path: Path, source: str) -> tuple[list[tuple[dict, datetime, str]], int]:
+def _load_stream(
+    path: Path, source: str, seen: set[tuple[str, str, str]] | None = None
+) -> tuple[list[tuple[dict, datetime, str]], int]:
     """Parse one JSONL stream into relevant (row, ts, raw_ts) tuples, row-deduped.
+
+    ``seen`` is the row-dedup set; pass ONE shared set across all events.jsonl
+    paths of a single source (task id) so byte-identical copies in duplicate
+    status folders collapse (#1274). None -> fresh per-call set.
     ...
     skipped = 0
     rows: list[tuple[dict, datetime, str]] = []
-    seen: set[tuple[str, str, str]] = set()
+    if seen is None:
+        seen = set()
```

**(d) Module docstring — update rules 1 and 3 to match:**

- Rule 1 heading "Same-stream filed record" → "**Same-task filed record**": "a LATER row ... in ANY events.jsonl of the same source — all `tasks/*/<id>/events.jsonl` status folders of one task id merge into one logical stream (a stale duplicate status folder, the #644/#1253 class, otherwise re-enumerates a routed park nightly; incident #1196/#1274); the cache file is its own source. The emitted `suppressed_by.kind` string stays `same-stream-filed` for output compatibility."
- Rule 3: "(stream, ts, content-hash)" → "(source, ts, content-hash) — the dedup set is shared across all status folders of one task, so byte-identical fork copies collapse."

### 4.2 Considered alternatives (and why not)

1. **Fully-global cross-stream filed-record matching** — REJECTED. For fp-less parks the primary key in `_filed_record_matches` (lines 287-290) is bare `origin_candidate_ts` equality with NO target_file check; a global record pool could false-suppress a same-second park on a DIFFERENT task (parks posted back-to-back in one orchestrator turn can share a second). Per-task grouping matches the Goal wording ("a park whose TASK carries a routed-record") and bounds the pool to rows that are, by fork construction, copies of the same history. Task↔cache cross-matching is also unnecessary: Step C posts cache-borne routed records into the cache file itself (SKILL.md line 342-343).
2. **Add the #1248-style target_file prefix-compat veto to the fp-less primary-ts path** — REJECTED (defense-in-depth considered, net-negative). The veto would fire (block suppression) whenever Step C's routed-record `target_file` was legitimately re-scoped at filing time (comma-list first-token divergence, an LLM-synthesized glob like `.claude/agents/*.md` vs a concrete path — not prefix-compatible either way) — re-introducing exactly the nightly-re-enumeration churn class this task fixes. #1248 deliberately kept bare-ts as the fp-less PRIMARY key (docstring lines 27-30); the residual it guards (two DISTINCT fp-less parks on ONE task in ONE second) is rare, pre-existing within a single stream, and NOT widened by grouping (fork folders carry copies, not new rows). Documented as an accepted residual, not changed.
3. **Rename `suppressed_by.kind` to `same-task-filed`** — REJECTED. 4 existing tests assert the string; audit tooling may grep it; zero behavioral value. The docstring notes the prose-only rename.
4. **Filter/normalize non-int folder names when grouping** — REJECTED; group key stays the folder NAME string exactly as the current source label does (behavior-preserving for odd names).

## 11. Decision Rationale

- **Grouping grain = per-task-id source label (not global, not per-path).** What: merge all `tasks/*/<id>/events.jsonl` into one logical stream per id; cache stays its own group. Why: closes both halves of the #1196 miss (cross-folder filed records + cross-folder row dedup) without the global false-suppress hazard. Source: incident #1196/#1274 diagnosis (fp-less primary key is bare `origin_candidate_ts` — brief + code lines 287-290) and the Goal's own wording ("a park whose task carries a routed-record"). Alternatives: global matching (rejected, §4.2 alt 1).
- **No target_file veto on the fp-less primary-ts path.** What: `_filed_record_matches` fp-less branch unchanged. Why: a filing-time re-scoped/glob target_file would fail prefix-compat and re-introduce nightly churn — the failure class under repair; the guarded collision (same task + same second + distinct fp-less parks) is rare and pre-existing. Source: #1248 precedent (commit cb924ddd9f deliberately keyed fp-less on bare ts; the veto exists only on the fp-computable path where it guards a weaker cross-key match) + Step C template analysis (SKILL.md lines 333-341). Alternatives: add veto (rejected, §4.2 alt 2).
- **Keep `suppressed_by.kind == "same-stream-filed"`.** What: output string unchanged, docstring renames the rule in prose only. Why: 4 existing tests assert it; audit compatibility. Source: grep of `tests/test_sweep_parked_wf_candidates.py` lines 179/197/515/650.
- **Implementation shape = optional shared `seen` param + grouped `streams`.** What: minimal diff, backward-compatible signature. Why: smallest change satisfying both halves; tests exercise real bodies (#906 discipline per the test module docstring), so no seam/fake is introduced. Source: repo precedent (the test file's own conventions; `.claude/rules/code-style.md` supersede/minimal-diff discipline).
