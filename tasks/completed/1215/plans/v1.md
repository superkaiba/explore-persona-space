### Pure decision ladder (`decide_orphan_wrapper`)

```python
def decide_orphan_wrapper(
    daemon_tracked: bool | None,   # None = daemon unreachable (belt; the driver skips the whole pass first)
    has_claude: bool,
    live_user_tty: bool,
    wrapper_age_s: float | None,
    cpu_frac: float | None,        # delta-CPU fraction since the previous tick; None = no baseline yet
    missed: int,
    first_miss_age_s: float,
    alerted: bool,
    threshold: int = 2,
    *,
    reap_enabled: bool = False,    # the caller computes: _orphan_wrapper_reap_enabled() AND _zombie_wrapper_reap_enabled()
    min_age_s: float = ORPHAN_WRAPPER_MIN_AGE_S,
    grace_s: float = ORPHAN_WRAPPER_GRACE_S,
    cpu_frac_max: float = ORPHAN_WRAPPER_CPU_FRAC_MAX,
) -> tuple[str, int]:
    """Actions: "clear" | "skip" | "keep" | "escalate" | "stop"."""
    if daemon_tracked is None:
        return ("skip", missed)            # daemon UNKNOWN != "not tracked": freeze (idle-unmapped skip idiom)
    if daemon_tracked:
        return ("clear", 0)                # pass 7 owns it
    if has_claude or live_user_tty:
        return ("clear", 0)                # healthy / user-attended: episode ends
    if wrapper_age_s is None or wrapper_age_s < min_age_s:
        return ("keep", missed + 1)        # age belt (#1039 shape): unreadable or young never escalates
    if cpu_frac is None:
        return ("keep", missed + 1)        # first observation: baseline recorded, cannot qualify yet
    if cpu_frac > cpu_frac_max:
        return ("clear", 0)                # actively computing: not an orphan-idle process
    new_missed = missed + 1
    if new_missed < threshold:
        return ("keep", new_missed)
    if reap_enabled and first_miss_age_s >= grace_s:
        return ("stop", 0)
    if not alerted:
        return ("escalate", new_missed)    # once per episode; with default switches this is the terminal action
    return ("keep", new_missed)
```

With defaults, escalation fires at ~day 1 (min-age 24h + 2 ticks) and any opt-in stop no earlier than day 7 of OBSERVED orphanhood — the alert always precedes the stop by ~6 days.

### IO driver (`_process_orphan_wrapper`) — per candidate

1. **Pid-reuse guard:** if state exists and `state["start_epoch"] != proc_start_epoch(pid)` (±1s tolerance) ⇒ `_clear_orphan_wrapper_state`, fresh episode. Signals are NEVER sent to a pid whose recorded start epoch mismatches.
2. `_check_orphan_stop_verification(...)` — handles the post-signal episode (return if it consumed the tick).
3. Compute `has_claude = _has_claude_descendant(pid, children_map)`; `live_tty = _is_live_user_tty(pid, detached_tmux_ttys, check_orphaned=True)` (the idle-unmapped default-ON shape — #818's orphaned-tmux branch is load-bearing here: the incident's 31 wrappers held orphaned-server pts TTYs); `wrapper_age_s` via `proc_start_epoch`; `cpu_frac` from `_proc_cpu_seconds(pid)` vs state `{cpu_s, cpu_ts}`.
4. Call `decide_orphan_wrapper(daemon_tracked=False, ...)`; print one per-candidate line (pass-7 log shape: pid, role, age, cpu_frac, missed→new, action).
5. **escalate** ⇒ sidecar row + `_telegram_push` (once per episode via `alerted`); persist state.
6. **stop** ⇒ if `stops_remaining[0] <= 0`: log "per-tick stop bound reached", persist as keep. Else re-verify signature + start epoch immediately before `os.kill(pid, signal.SIGTERM)` (dry-run: print only), decrement bound, sidecar `stop` row + push, persist `signalled_at=now`.
7. **keep/skip/clear** ⇒ persist / freeze / clear per the state idiom. Every write is `if not dry_run:` gated (#1039 pin shape).

### Pass wiring, ordering, and flags

- `main()` production order: insert `orphan_wrapper_pass(args.dry_run, args.threshold, daemon_reachable=daemon_reachable, children=reaper_children)` immediately AFTER `zombie_wrapper_pass` (L22363–22377) and BEFORE `idle_unmapped_pass` (L22379) — pass 7 owns daemon-tracked wrappers, pass 28 owns the daemon-untracked remainder; adjacent placement reuses the `reaper_children = _live_children() if daemon_reachable else None` snapshot (L22335). New execution-order fragment: `7 (zombie-wrapper) -> 28 (orphan-wrapper sweep) -> 10 (idle-unmapped) -> 8 (GC)`.
- **Daemon-unreachable semantics:** `children is None` / `daemon_reachable=False` ⇒ print one skip line and return with ALL state untouched. "Daemon says not tracked" (predicate evaluable) is thereby mechanically distinguished from "daemon unknown" (pass skips) — the class is DEFINED by the daemon's answer, so without the daemon there is nothing sound to evaluate, and orphans persist for days so a skipped outage tick costs nothing. Never signals on unknown.
- **Exclusion set inside the pass:** live-set pids (`happySessionId`-bearing `/list` children), any candidate whose ancestor chain or descendant tree intersects the live pid set (a live session's launcher/shim belongs to pass 7's session), the Happy daemon pid, PM session (daemon-tracked ⇒ covered by the live-set guard; residual defense = TTY + age + CPU guards, since an untracked process has no sid to match `pm-session.json`), spawn-in-flight wrappers (covered by the 24h age floor — spawn→/list registration is seconds).
- **Fail-soft:** the whole pass body wrapped in the file's top-level `except Exception` fail-soft convention (`root_draft_pass` L5779 shape); every /proc read already returns None/False on `OSError` (raced exits); `os.kill` wrapped (`ProcessLookupError` ⇒ already gone ⇒ clear state; `PermissionError` ⇒ loud row, freeze).
- **Debug entrypoint:** `--orphan-wrapper-only` in the flat `--*-only` dispatch ladder (L21830–21936 convention), probing `_daemon_reachable()` itself.
- **GC:** `_gc_orphan_wrapper_state` runs at pass start (candidate-keyed, mirrors `_gc_orphan_zombie_state`); the pass-8 GC deliberately does not touch `orphan-wrapper-*.json` (same carve-out as `zombie-wrapper-<sid>.json` — noted in docstring item 8's parenthetical).

## 5. Controls / safety

- **Conjunctive guard set (ALL required to escalate):** (a) daemon-reachable AND pid untracked (incl. ancestor/descendant live-set intersection); (b) no Claude descendant (`_has_claude_descendant` — errs toward false keep by design); (c) delta-CPU < 1%/core between ticks (None baseline ⇒ keep); (d) wrapper age ≥ 24h (`proc_start_epoch`; None ⇒ keep); (e) not a live user TTY (`check_orphaned=True`); (f) ≥2 consecutive ticks with persisted state; (g) structural: `comm == node`, euid-owned, daemon-pid excluded, argv-token check, topmost-only.
- **Stop arm additionally requires:** `EPM_ORPHAN_WRAPPER_REAP` truthy (opt-in) AND `EPM_ZOMBIE_WRAPPER_REAP` not falsy (the #1039 dual-switch AND: global-off keeps everything alert-only) AND first-observation grace ≥ 7d AND per-tick bound ≤3 AND immediate pre-signal signature + start-epoch re-verification. SIGTERM only; one retry next tick; never SIGKILL in v1 (a SIGTERM-immune process gets a loud `stop-failed` row for human triage — mirroring `_check_zombie_stop_verification`'s one-retry-then-loud contract).
- **Dry-run:** every state write, sidecar append, push, and signal is `if not dry_run:` gated (prints the would-do line) — pinned by a dedicated mutates-nothing test, the #1039 pin shape.
- **Kill switch:** `EPM_DISABLE_ORPHAN_WRAPPER_PASS=1` disables the whole pass (observer-pass convention).
- **Daemon-unreachable:** skip-with-frozen-state; never signal on "unknown" (§4).
- **Bounded blast radius:** ≤3 SIGTERMs/tick even fully opted in; the 31-process incident would drain in ~11 ticks (~2h) — deliberate.

## 11. Decision rationale (load-bearing constants)

- **Escalate-only default + opt-in stop arm.** What: `EPM_ORPHAN_WRAPPER_REAP` default OFF (opt-in polarity, inverted vs pass 7/10's opt-out). Why: direct SIGTERM to daemon-invisible pids is the destructive, false-positive-overlapping action the Goal names; risk row 3 (§7) is real. Source: the 2026-07-17 PM directive on #1215's events (orchestrator-resolved; baked in). Alternatives: reap-by-default (rejected by the directive), no stop arm at all (rejected — the incident class needs an eventual remediation path without another code round).
- **Dual-switch AND (`EPM_ORPHAN_WRAPPER_REAP` ∧ `EPM_ZOMBIE_WRAPPER_REAP`).** Why: global-off must keep ALL wrapper reaping alert-only with one switch. Source: #1039's `_zombie_noneps_reap_enabled` AND pattern (commit `98f943ea91`), itself the #818 dedicated-widening-knob shape.
- **Stop grace = 7d from first observation (`ORPHAN_WRAPPER_GRACE_S`).** Why: matches the strictest existing lane for a comparable trust level; doubles as a post-deploy bake window (first_miss_ts cannot predate the merge). Source: `NONEPS_ZOMBIE_WRAPPER_GRACE_S = 7 * 86400` (#1039, same rationale documented at its definition).
- **Escalation age floor = 24h (`ORPHAN_WRAPPER_MIN_AGE_S`).** Why: incident processes were 1–54 days old, so 24h loses no true positive; it sits far above spawn/registration latency (seconds) and above the pass-7 EPS grace (2h), keeping escalation rows low-noise. Source: incident evidence in #818's body (1–7 day wrappers, 54-day launcher) + `ZOMBIE_WRAPPER_GRACE_S` precedent as the lower bound. Exact value not sensitive within ~4×; env-overridable.
- **CPU threshold = delta < 1%/core between ticks (`ORPHAN_WRAPPER_CPU_FRAC_MAX = 0.01`).** Why: incident launchers showed 00:00:00 ACCUMULATED CPU over days (≈0%); delta-not-accumulated is required because a wrapper that once served a long session carries history. 1% is ~100× the incident signal while excluding any actively-working process. Source: #818 body measurement; the exact margin is `ungrounded — needs smoke-test` (the `--orphan-wrapper-only --dry-run` smoke on the live VM prints cpu_frac per candidate; tune if idle node event loops exceed it — not expected).
- **Consecutive-tick K = 2 (reuse `args.threshold`).** Why: transient /proc-vs-daemon races never escalate; identical semantics to pass 7. Source: `decide_zombie_wrapper(threshold=2)` default + the watcher-wide `--threshold` flag.
- **Per-tick stop bound = 3.** Why: bounds blast radius of a bad predicate to 3 processes per 10-min tick; drains the worst observed backlog (31) in ~2h. Source: `STALLED_MAX_RESPAWNS = 3` per-episode bound precedent; exact value not sensitive, env-overridable.
- **SIGTERM-only, one retry, no SIGKILL in v1.** Why: node handles SIGTERM cleanly; SIGKILL forfeits any flush and is unneeded until a stop-failed row ever appears. Source: `_check_zombie_stop_verification`'s one-retry-then-loud contract (L17973) — same escalation semantics, daemon RPC swapped for the signal.
- **New sidecar file (`orphan-wrapper-events.jsonl`).** Source: one-sidecar-per-pass family precedent (`idle-unmapped-events.jsonl`, `cpu-guard-events.jsonl`); schema mismatch argument in §4.
- **Candidate signature (two markers + argv-token + comm==node).** Source: live /proc probe 2026-07-18 (§4 block) + `_has_claude_descendant` docstring's verified wrapper cmdline + #818's launcher evidence.
