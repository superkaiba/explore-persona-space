## 3. Decision: Option A (canonicalize on "1–3 sentences")

The body proposed Option A (keep "1–3", loosen ≥3=FAIL) vs Option B (keep
"≤2", add optional mechanical check). **Option A wins decisively** on the
evidence:

1. **"1–3 sentences" is already the dominant + canonical rule.** SPEC's OWN
   canonical three-beat definition (L423-431) uses "1–3 sentences/bullets" for
   BOTH beats; the Voice Rule B (L814) uses "1–3 sentences"; the exemplar note
   (L1571) uses "1-3-sentence". The `≤2-sentence` is the outlier v3-carryover
   fragment (L826-828), not the intended v4 rule.
2. **The AUTHORING agent already writes to "1–3 sentences".** `analyzer.md`
   (which produces every v4 body) tells the analyzer each three-beat paragraph
   is "1–3 sentences" (L517/519/551). Choosing Option B (≤2) would put the
   spec + reviewers at odds with the agent that DRAFTS bodies — every body
   would be authored at up-to-3 and then FAILed at review, maximizing churn.
   Option A makes the review rule match the authoring rule.
3. **Forward-only safety.** Option A only LOOSENS the sentence bound (2 → 3),
   so no previously-PASSed body can become a FAIL. Option B (keeping ≤2 AND
   optionally adding a mechanical sentence-count check) risks failing bodies
   that were PASSed at 3 sentences — a forward-only violation the body's
   constraints forbid.
4. **The body's premise "agent Lens 12 ALREADY cites ≤2" is only half true.**
   The agents carry BOTH variants (the three-beat lens says 1–3, Lens 12 says
   ≤2) — they are internally split exactly like SPEC. So Option B is NOT
   zero-agent-change; it would require editing the agents' three-beat lenses
   DOWN to ≤2 AND the analyzer DOWN to ≤2 — strictly MORE churn than Option A,
   and against the authoring rule.

Option A edits: change every `≤2-sentence` CARRYOVER fragment (§2 list) to
"1–3 sentences", and loosen the two critic agents' Lens 12 FAIL threshold from
"≥3 sentences" to "≥4 sentences". `verify_task_body.py` is NOT tightened (no
new mechanical sentence-count check — that would need re-approval per the
body's constraint; and it is unnecessary since sentence-count stays LM
judgment).

churn, and forward-only-safe (loosening 2→3 can never re-FAIL a PASSed body).
The opposite choice ("≤2") would put the spec + both critics at odds with the
body-authoring agent and risk re-FAILing PASSed 3-sentence bodies.

**Source:** The AGENT FILES are the canonical enforcement + authoring surface:
`.claude/agents/analyzer.md` L517/L519/L551 (authoring rule = 1–3 sentences),
`.claude/agents/clean-result-critic.md` L1234-1236 (three-beat register lens =

lens = 1–3 sentences); plus `.claude/skills/clean-results/SPEC.md` L423-431 +
L814 (canonical v4 three-beat definition = 1–3 sentences). Originating
evidence: task #779 r2 reconciler ruling the ≤2 rule unenforceable due to the
