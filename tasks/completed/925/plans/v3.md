### Block + segment parsing (helper 1: `_hypothesis_blocks(section_text) -> list[str]`)

Split the fence-stripped hypothesis-section body (heading line excluded) into blocks at top-level list-item starts (`^\s{0,3}[-*]\s` or `^\s{0,3}\d+\.\s`) and at sub-heading lines (`_HEADING_RE`); a run of continuation lines belongs to the preceding block. This matches the observed corpus (one bullet per `**H<k>**` — #922 v2, #841 v12, #810 v6 all use single-bullet hypothesis blocks).

Segment splitting (helper 2: `_confirm_falsify_segments(block) -> tuple[str, str] | None`):
- Branch anchors: `_BRANCH_ANCHOR_RE = re.compile(r"(?i)\*\*\s*(confirm|falsif)")` — covers `**Confirm:**`, `**Confirm (ridge stands):**`, `**Confirm-the-null:**`, `**Falsify:**`, `**Falsify (positive surprise):**`, `**Falsify (the ...):**` (all observed in the corpus).
- Falsify segment = text from the first falsify anchor to the next anchor or block end. Confirm segment = text from the first confirm anchor to the next anchor if an explicit confirm anchor exists; **otherwise the block text BEFORE the falsify anchor** (the hypothesis statement itself is the implicit confirm branch — exactly the #922 H4 shape, which has no `**Confirm:**` label).
- No falsify anchor in the block → return `None` (block ignored; a lone `**Confirm`-anchored block with no falsify is also ignored — nothing to compare, and c8 owns "branches missing entirely").

### Offender predicate (a) — jointly-satisfiable comparator pair on a shared bounded token

The precise, conservative definition of "non-mutually-exclusive comparators on the same bounded quantity+horizon token":

- **Shared bounded token:** a normalized `(var, value)` pair matched by `_BOUND_TOKEN_RE = re.compile(r"\b([A-Za-z]\w{0,8})\s*=\s*(\d+(?:\.\d+)?)\b")` that appears in BOTH the confirm and falsify segments (e.g. `k = 32` in "decays toward/below it **by k = 32**" and "stays above the frozen null **through k = 32**"). Identity is on the normalized pair, whitespace-insensitive. Comparator-bearing bounds (`k ≤ 4`) are deliberately NOT harvested as shared tokens — an `=` horizon is the incident shape, and requiring exact-pair identity in both segments is the main false-positive guard.
- **Tendency-class match (does not pin an end-state):** `_TENDENCY_RE = re.compile(r"(?i)\btowards?\b")`. Deliberately minimal — "decays toward", "trends toward", "moves toward", "toward/below" all contain the token; a bare "declines" without "toward" is an accepted false negative (prefer false negatives, per the task's hard constraint). Broader verbs (`approaches`, `converges`) are excluded in v1: "approaches" false-fires on the noun ("two approaches").
- **State-class match (pins a region through the horizon):** `_STATE_RE = re.compile(r"(?i)\b(?:stays?|remains?|holds?)\s+(?:strictly\s+)?(?:above|below|at|within)\b")`.
- **Fire condition (a):** the block has ≥1 shared bounded token AND (`_TENDENCY_RE` matches the confirm segment AND `_STATE_RE` matches the falsify segment) OR (the symmetric flip). Rationale: "tends toward X by horizon H" (no end-state pinned) and "stays above X through H" (region pinned) can both hold for one curve — the #922 H4 defect verbatim. Crisp state-vs-state pairs (`≤` vs `>`, "above" vs "below", win-count vs win-count — the #841 v12 / #810 v6 shapes) contain no tendency token and stay silent.
- **Known borderline (documented, accepted):** a confirm that pins a crisp bound AND decoratively adds "trending toward the floor" would WARN. WARN-only + critic forwarding makes this a nudge to tighten wording, not a block; none of the surveyed real plans have this shape.

### Offender predicate (b) — vague scope token with no pinned anchor

- **Vague-scope tokens:** `_VAGUE_SCOPE_RE = re.compile(r"(?i)\b(?:(?:early|mid|middle|late|deep|shallow)(?:\s*[/-]\s*(?:early|mid|middle|late|deep|shallow))?|most)\s+layers\b")` — matches "mid/late layers", "mid-late layers", "late layers", "early layers", "most layers" (incl. "at most layers"). "a majority of layers" is deliberately EXCLUDED (a quantifier over a universe; in the observed corpus it always co-occurs with a pinned universe, and excluding it is the conservative call).
- **Pinned-anchor escape (same block):** `_PINNED_SCOPE_RE = re.compile(r"(?i)\blayers?\s*\d|\blayers?\s+\{|\bL\d{1,2}\b|ℓ\*|\bpre-registered\b")` — "layers 1–28", "layer 20", "layers {18, 21}", "L18", the pre-registered layer symbol "ℓ*", or the literal "pre-registered".
- **Fire condition (b):** an anchor-bearing block matches `_VAGUE_SCOPE_RE` AND does NOT match `_PINNED_SCOPE_RE`. Calibration against #922 v2 §3 (verified this session by reading lines 40–48): H1 has "at most layers" + "for layers 1–28" → escape, silent; H2 has "late layers" + "over layers 1–28" / "layer 0" → escape, silent; H4 has "mid/late layers" and no layer numeral (its only numerals are `k ≤ 4`, `k = 32`, an arXiv id — none match `layers?\s*\d`) → fires; H5 has no vague token → silent. So on the real offender plan the check flags exactly H4, on both predicates.

### WARN detail format

One clause per offender, capped at 3, e.g.:
`block '**H4 (rollout)**': (a) comparator-pair — confirm says 'toward' while falsify says 'stays above' on shared token 'k = 32', jointly satisfiable by one outcome (above-but-declining); (b) vague-scope — 'mid/late layers' with no pinned layer list/numeral in the block. Tighten the branch comparators (e.g. '≤ vs >') and pin the layer set — semantic verdict stays with the Statistics critic.`

Each offender clause is prefixed with the predicate label (`(a) comparator-pair` / `(b) vague-scope`) so a (b)-only or symmetric-flip fire cannot misattribute the defect to critic-brief consumers (round-1 statistics advisory).
