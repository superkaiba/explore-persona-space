### 4.1 New module constants (place after the c12 block, ~line 1160)

```python
# ─── Check 13 — empirical-null gate p-floor attainability (conditional) ────

# Gate alpha: a decimal alpha DIRECTLY after the comparator. A fraction-form
# self-consistent floor gate ("p ≤ 1/(15+1) ≈ 0.06", #816 v5 Exp-4) must NOT
# match: "1/" blocks the decimal, and the "≈ 0.06" is not comparator-adjacent.
_C13_P_ALPHA_RE = re.compile(
    r"(?i)\bp(?:-?values?)?\s*(?:≤|<=|<)\s*\*{0,2}`?(0?\.\d+)`?"  # noqa: RUF001 if flagged
)
_C13_EMPIRICAL_RE = re.compile(r"(?i)\bempirical\b")
# Registered-gate section: any ENCLOSING heading matching the c8 success/kill
# families or an Evaluation/§6 heading. Lines elsewhere (Prior Work recaps,
# TL;DR) are not registrations — under-trigger fails safe (critics review).
_C13_GATE_SECTION_RE = re.compile(
    r"(?i)success criteri|acceptance criteri|decision rule|decision gate"
    r"|kill[- ]criteri|abort criteri|stop criteri|\bevaluation\b"
)
# On-gate-line draws-scope qualifier ("(n_draws ≥ 50: ...)" — the #816 v6 fix
# shape): families below K are OUTSIDE the gate's own declared scope.
# DRAWS-EXPLICIT token REQUIRED (round-1 statistics-reconcile Must-Fix): a
# bare `n ≥ K` (e.g. "n ≥ 20 prompts per probe" — a sample-size clause on the
# gate line) must NOT set the scope, or it silently descopes every small
# n_draws family and emits an affirmative false-PASS on the exact #816 class
# this check exists to catch — a hole invisible to the FAIL/WARN-only
# calibration. Zero loss on the real fixtures: v6's gate lines carry the full
# `n_draws ≥ 50` token; v5's gate lines carry no scope match either way.
_C13_SCOPE_RE = re.compile(r"(?i)\bn_(?:draws|perms)\w*\s*(?:≥|>=)\s*(\d+)")  # noqa: RUF001 if flagged
# Family vocabulary on the gate line = the tie is unambiguous (the gate
# quantifies over null families) → FAIL-capable; absent → WARN cap.
_C13_FAMILY_RE = re.compile(r"(?i)famil")
# Per-declaration exclusion: a family row/line declaring itself outside the
# test set is dropped (v5/v6 contaminated-reference row; v6 "outside the BH").
_C13_EXCLUDE_RE = re.compile(
    r"(?i)contaminated|reference only|descriptive|excluded"
    r"|not (?:in|included|counted)|outside the (?:BH|test)"
)
# n_draws declarations, prose/kwarg forms: n_draws=K, n_draws: K,
# n_draws_isotropic=200, n_perms=500. ("n_draws ≥ 50" and "(n_draws+1)" do
# not match — comparator/paren, not =/:.)
_C13_NDRAWS_KWARG_RE = re.compile(r"(?i)\bn_(?:draws|perms)\w*\s*[=:]\s*(\d+)")
```

Add `from fractions import Fraction` to the module imports (stdlib; verified `Fraction(".05") == Fraction("0.05") == Fraction(1, 20)` on this env — exact arithmetic, no float-tolerance games).

### 4.3 New check `check_empirical_gate_attainability(plan: str, kind: str) -> CheckResult`

```python
def check_empirical_gate_attainability(plan: str, kind: str) -> CheckResult:
    """A registered empirical-null gate (success/kill line requiring p ≤ α
    against null families) must be ATTAINABLE for every in-scope declared
    family: p_floor = 1/(n_draws+1) ≤ α. Necessary-condition logic only —
    under BH the effective thresholds are ≤ α, so floor > α is conservative-
    correct; BH-m arithmetic, family-set semantics, and joint satisfiability
    stay with the Statistics critic (c8's form-only charter). FAIL
    (experiment) / WARN (analysis) / WARN on ambiguous tie or floor == α /
    SKIP otherwise. Incident: #816 v5 (gate p ≤ 0.05 over families with
    n_draws=2/5 → floors 1/3, 1/6; caught only by the Codex critic)."""
```

Algorithm (order mirrors c12: kind → trigger → N/A → evidence):
1. `kind not in ("experiment", "analysis")` → `_skip(cid, name, "kind-exempt: registered empirical-null gates are an experiment|analysis plan shape")`.
2. **Gate harvest.** `lines = plan.splitlines()`, `mask = _fence_mask(lines)`, `headings = _headings(plan)`. For each non-fenced line `i`: it is a REGISTERED gate line iff (a) some enclosing heading (`h.line <= i < h.end`) matches `_C13_GATE_SECTION_RE`, (b) `_C13_EMPIRICAL_RE` matches the line, (c) `_C13_P_ALPHA_RE.finditer(line)` yields ≥ 1 alpha. Record `(i, line, min_alpha_as_Fraction, scope_K_or_None, has_family_vocab)`; `min_alpha` = min over the line's captured alphas (a gate requiring the most stringent of several alphas is unattainable if the floor exceeds the smallest); `Fraction("0" + a) if a.startswith(".") else Fraction(a)` for exactness; `scope_K` = first `_C13_SCOPE_RE` group on the line.
3. No gate lines → `_skip(cid, name, "no registered empirical-p gate detected")`.
4. **N/A escape — deliberate standalone declaration line ONLY** (round-1 methodology-reconcile Must-Fix): the escape fires iff some NON-FENCED line (`mask[i]` false), after stripping leading list/blockquote markers (`line.lstrip(" \t>*-")`), MATCHES-AT-START `re.match(NA_RE + r"no empirical[- ]null gate", stripped)` → `_pass(cid, name, "explicit N/A declared (no empirical-null gate)")`. A doc-global `re.search` is FORBIDDEN here: the FAIL detail template below quotes the escape phrase as a remedy option, and this project's plan convention pastes verifier/bounce text into revised plans verbatim — a substring match would let a bounced plan self-escape re-verification (the same spurious-satisfaction structure as #810's c12 false-PASS post-mortem, one polarity over). NOTE: `NA_RE` opens with an inline `(?i)`, so it must sit at position 0 of the composed pattern — per-line `re.match` (as here) satisfies that; do NOT prepend an anchor string to `NA_RE` (py3.11+ rejects mid-pattern global flags).
5. `decls = _n_draws_declarations(plan)`; empty → `_skip(cid, name, "empirical-p gate present but no per-family n_draws declarations found — attainability not computable at the plan surface")`.
6. Per gate: in-scope decls = those with `n >= scope_K` when a qualifier is present, else all. If a qualifier is present and it excludes EVERY declaration, record `vacuous_scope` for that gate (statistics-reconcile S4: an empty in-scope set must not yield an affirmative PASS with an undefined min). Per in-scope decl: `floor = Fraction(1, n + 1)`. Offender iff `floor > alpha` OR (`floor == alpha` AND the gate's comparator is strict `<` — the gate is then unattainable, not boundary; record comparator strictness at gate harvest); `floor == alpha` under `≤`/`<=` → boundary. (Record gate line no., label, n, floor, alpha per offender; `fail_capable |= has_family_vocab`.)
7. Verdict:
   - offenders ∧ `fail_capable` ∧ `kind == "experiment"` → `_fail`;
   - offenders ∧ (`kind == "analysis"` ∨ not `fail_capable`) → `_warn` (analysis-degrade, or "ambiguous tie: no family vocabulary on the gate line — verify the flagged draw counts are in the gate's test set");
   - no offenders ∧ boundary → `_warn` ("p-floor equals the registered alpha exactly (n_draws=K → floor 1/(K+1) = α) — attainable only when the real statistic beats every draw; state the floor next to the verdict");
   - no offenders ∧ no boundary ∧ `vacuous_scope` on some gate → `_warn` ("the gate's scope qualifier (n_draws ≥ K) excludes every declared family — attainability not computable for any in-scope family; verify the gate's in-scope families are declared");
   - else → `_pass` (detail: "min in-scope n_draws=K → p-floor 1/(K+1) ≤ registered α (attainable in form; adequacy stays with the Statistics critic)").

FAIL detail template (bounded — list ≤ 6 offenders then "…"): `plan registers an empirical-p gate ("<gate line, truncated ~90 chars>", α=<a>) over families whose p-floor 1/(n_draws+1) exceeds α: <label> n_draws=<n> → floor <p>/<q> ≈ <dec> [, …] — the gate is structurally unattainable (#816 v5 class); raise n_draws to ≥ <ceil(1/α)> for a clean PASS (n = 1/α − 1 exactly lands on the floor == α boundary WARN), scope the gate (e.g. 'n_draws ≥ 50'), mark the family outside the test set on its row, or declare 'N/A — no empirical-null gate' on its own line`. (Quoting the escape phrase inside this detail is safe under the standalone-line anchoring of step 4.)

## 11. Decision Rationale

N/A — no model training / no hyperparameters. Design-constant grounding (the infra analogue):

- **cid/order `c13`, appended after c12.** Why: monotone check numbering is the module's registry convention. Source: `scripts/verify_plan.py` lines 15–31, 1165–1178.
- **Severity ladder (experiment FAIL / analysis WARN / others SKIP; WARN on ambiguous tie + boundary; SKIP on no-gate/no-decls).** Why: mirrors c12's kind-degrade exactly (statistical-gate plans are an experiment|analysis shape) and the module's scope discipline ("prefer WARN/SKIP when the tie is ambiguous"). Source: `check_battery_multiplier` lines 1104–1160 + module docstring lines 52–58 + the task brief's explicit ladder.
- **p_floor = 1/(n_draws+1); attainability ⇔ n_draws ≥ 1/α − 1; exact `Fraction` arithmetic.** Why: the add-one conservative empirical-p convention the incident plan itself uses (`p = (r+1)/(n_draws+1)`, v6 line 212); Fraction avoids float-equality traps at the boundary case. Source: origin critic verdict (#816, quoted in body.md) + v6 line 211–213; `Fraction(".05") == Fraction(1,20)` verified live.
- **Raw-α check under BH (no per-test BH threshold math).** Why: BH thresholds are ≤ α, so floor > α is a necessary-condition FAIL — conservative-correct and computable without knowing m. Source: Benjamini–Hochberg step-up definition (thresholds (k/m)·α ≤ α); stated in the check docstring.
- **Gate tie = registered-section scoping + on-line family vocab + on-line scope qualifier, NOT c12's ±15-line window and NOT naive doc-global.** Why: the incident geometry (table at line 198, gate at line 460) breaks windows, and v6 (must-PASS) still contains the small-n declarations + a universal-vocab gate line — the discriminating surface v6 added is the `(n_draws ≥ 50)` qualifier on the gate line itself. Source: v5/v6 diff read (§2); #810's c12 false-PASS post-mortem for why doc-global evidence is the known failure mode (c12 comment, lines 1104–1113).
- **N/A phrase `N/A — no empirical-null gate`, standalone-line-anchored (NOT doc-global).** Why: matches the module's canonical `N/A — no <trigger>` family and `NA_RE` prefix tolerance; the anchoring (deliberate declaration line only) closes the pasted-FAIL-detail self-escape channel — §11's own doc-global ban (the #810 known failure mode) applies to the escape's polarity too. Source: lines 37–45, 120; round-1 methodology reconcile (binding REVISE). NOTE this is deliberately STRICTER than c12's doc-global escape (verify_plan.py line ~1120) — c12's identical latent hole is out of this task's scope (logged as a parked follow-up candidate on the task).
- **Draws-explicit scope-qualifier regex (`\bn_(?:draws|perms)\w*` — never bare `n`).** Why: a bare `n ≥ K` sample-size clause on the gate line would silently descope small-draw families and emit an affirmative false-PASS on the exact incident class, invisible to the FAIL/WARN-only calibration; zero loss on the real v5/v6 fixtures. Source: round-1 statistics reconcile (binding REVISE), verified live on the fixture gate lines.
