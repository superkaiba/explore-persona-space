## 3. Design

### 3a. The fix: exempt-word predicate `_is_path_like_word()` replacing raw `_PATH_SHAPED_RE` at both consumers

A whitespace-free word `w` is EXEMPT from token scanning iff:

1. `w` contains a backslash (`\`) — LaTeX mathtext commands (`$c_0^{lt}\rightarrow w$`) and Windows paths; byte-preserves the old exemption for the entire backslash class; else
2. strip surrounding punctuation `()[]{}<>,.;:'"` + backtick from `w` → `s`; if `s` carries no `/`, NOT exempt (ordinary word — scanned, unchanged); else exempt iff ANY of:
   - `s` still contains a formula character (`(`, `)`, `^`, `$`, `=`, `+`) — caption formulas like `sqrt(mean_i(s2_i/m_i))`, `(var_level + var_5-0)/2)`;
   - leading path/scheme marker: `s` starts with `/`, `./`, `../`, `~`, or `<scheme>://`;
   - `s.count("/") >= 2` — multi-segment path;
   - final segment carries a file extension (`\.[A-Za-z0-9]{1,5}$`) — catches `scripts/issue1336_step_transfer_tiers.py` even punctuation-wrapped;
   - first segment (casefolded) is a canonical repo top-level dir: `figures, eval_results, ood_eval_results, scripts, src, docs, data, tasks, tests, configs, raw, external, archive, store` — kills extension-less dir refs (`eval_results/issue_825`) rendered in caption prose. This is a REPO-STRUCTURE list (stable, closed), not an open vocabulary allowlist.
3. Otherwise (exactly the `behavior/slug` slash-joined-label shape): NOT exempt — scanned normally. The token regexes already tokenize across `/` (non-word char provides the `\b` boundary), so no segment-splitting is needed: `_opaque_code_tokens("hallucination/a_rb_ctx")` yields `["a_rb_ctx"]` via existing class (b).

Both consumers switch to the predicate: the whole-string gate (:9603 — applies when the string has no internal whitespace, i.e. is a single word) and the per-word exemption `_only_in_path_words` (:9606-9611). `_PATH_SHAPED_RE` has exactly these two consumers (critic-verified; checks 24/26/33 do not consume it and no test references it directly).

**Monotonicity (provable):** the new exempt set is a strict subset of the old (every new-exempt word contains `/` or `\`, which is the whole old criterion; slash-bearing words lacking every arm above become scanned). The change can only ADD warns, never lose an existing one — no regression direction exists.

### 3b. NOT adding the 2-segment single-letter-prefix class (corpus-grounded)

The one token in the incident set the prescribed class was meant to cover that class (b) misses is bare `d_transport` (2 segments, all-alpha). A corpus sweep over ALL 3,241 tracked `figures/**/*.meta.json` (the #1988 calibration method) shows a 2-segment `^[a-z]_[a-z]+$` class would flag **~45 distinct / ~9,200 occurrences of legitimate rendered math notation**: `z_marker` (2,237), `z_eos` (2,237), `s_i` (2,003), `n_train` (825), `g_aug` (648), `c_last` (405), `v_x`, `y_hat`, `n_pool`, … (round-1 critic independently reproduced: 44 distinct / 9,031). Decision: do NOT add it. Bare `d_transport` is recorded as an accepted residual in the check-28 docstring, mitigated at figure granularity: the #2221 arm roster always co-renders >=3-segment siblings (`a_rb_ctx` / `b_rb_ans` / `c_map_ctx` / `c_map_pfx`) which flag the figure anyway (per-figure WARN semantics — a missing single token costs nothing once the figure WARNs).
