## 1. Goal + acceptance criteria

> thread _forward_marker_child_stderr(res, 'spawn_session spawn-issue (<arm>)') after each rc==0 check at the spawn-issue child sites

(Task #1257 `## Goal` H2, verbatim; `kind: infra` — no `goal:` frontmatter; re-read at plan-return time, 0 `epm:goal-updated` markers.)

## 11. Decision Rationale

- **Include `_stop_session` + `_respawn_campaign` (scope).** What: thread all 7 in-file sites, not only the 5 spawn-issue ones. Why: same bug class, same file; the task body mandates updating every grep hit; leaving 2 known hits files a third task for a one-line pattern. Source: task #1257 body "Scope / surfaces" + the #622 incomplete-fix anti-pattern (workflow-fix-on-bug.md). Alternatives: spawn-issue-only (rejected — re-raises the residue #1221 already demonstrated).
- **Placement before the suppression early-return.** What: insert after the rc!=0 block, before `spawn_output_suppressed`. Why: a suppressed dispatch is exactly the case where the child's registration-collision stderr detail matters most; forwarding after the branch would lose it. Source: #1221's pinned precedent `tests/test_marker_child_stderr_forwarding.py::test_file_infra_spawn_hop_suppressed_path_still_forwards`.
- **rc==0-only firing (no forward on rc!=0).** What: no insertion inside rc!=0 blocks. Why: those blocks already print `res.stderr` — forwarding would double-print. Source: #1130/#1150 convention, pinned by `test_set_status_blocked_rc_nonzero_unchanged` and the site reads in §4.
- **Context-label strings.** What: `spawn_session <subcommand> (<arm>)` with arm == the site's `_auth_outage_record_spawn` arm name (sites 1/3/4/5/6/7) or `watcher` (site 2). Why: one vocabulary across watcher logs; the Goal states the convention. Source: #1221's `spawn_session spawn-issue (file_infra_task)` label + the in-file arm strings read in §4.
- **Reuse `_forward_marker_child_stderr`, no new helper.** What: call the existing local helper. Why: it is in-file, print-only, prefix-stable, and already documented for spawn_session children; a second helper would drift. Source: the helper docstring (L6569–6575) + the #1221 drift pin `test_file_infra_task_imports_shared_helper`.
- **One representative rc!=0 / suppressed test instead of 7 each.** What: 7 forwards tests + 1 suppressed + 1 rc!=0. Why: the rc!=0 branches are structurally identical across sites (verified reads); per-site duplication adds maintenance without coverage. Source: #1150's representative-site convention in the existing test file.
