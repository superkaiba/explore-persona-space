## 0.0 TL;DR (plain English)

- **What I'll do:** make `task.py set-body` refuse to overwrite a `kind: experiment` task body when the old body has a `## Goal` section and the new one doesn't — with a `--allow-goal-drop` escape hatch for the two callers that drop it on purpose (paper stubs are auto-exempt; the v2 report write gets the flag added to its documented command).

### 4a. Library: `src/explore_persona_space/task_workflow.py`

New exception (place near the other module-level exceptions / before `set_body`):

```python
class GoalH2DropError(ValueError):
    """set_body would remove the `## Goal` H2 from a kind:experiment body.

    The Goal is the canonical target every downstream subagent reads;
    silent loss costs a Goal-gate bounce + repair (incident #1112).
    Pass allow_goal_drop=True (CLI: --allow-goal-drop) for a deliberate drop.
    """
```

New helper (place next to `GOAL_H2_NAME`, ~line 3806; name-resolution at call time makes the below-`set_body` placement safe):

```python
def _has_goal_h2(text: str) -> bool:
    """True when any line is exactly `## Goal` after strip — the SAME
    line-start match semantics as `_inject_or_replace_goal_h2` (line 3842)."""
    return any(line.strip() == GOAL_H2_NAME for line in text.splitlines())
```

Guard in `set_body` — signature gains a keyword-only `allow_goal_drop: bool = False`; the frontmatter-strip is hoisted ABOVE the snapshot so a refusal writes nothing (today the snapshot happens first, 3677–3680):

```python
def set_body(task_id: int, new_body: str, *, snapshot_original: bool = False,
             allow_goal_drop: bool = False) -> None:
    ...
    with _locked():
        path = find_task_path(task_id) / "body.md"
        fm, prior_body = _read_body(path)          # was: fm, _ = _read_body(path)
        ...  # roundtrip-key carry unchanged
        body_text = _strip_leading_frontmatter_blocks(new_body)   # hoisted above snapshot
        if (
            not allow_goal_drop
            and fm.get("kind") == "experiment"
            and not is_paper_task(fm)               # paper-stub write legitimately lacks ## Goal
            and _has_goal_h2(prior_body)
            and not _has_goal_h2(body_text)
        ):
            raise GoalH2DropError(
                f"set-body refused for task #{task_id}: the new body removes the "
                f"'{GOAL_H2_NAME}' H2 present in the prior kind:experiment body. "
                "The Goal is the canonical target every downstream agent reads "
                "(incident #1112). Either keep the Goal section in the new body, "
                "or pass allow_goal_drop=True / --allow-goal-drop for a "
                "deliberate drop."
            )
        touched: list[Path] = [path]
        if snapshot_original:
            ...                                     # unchanged, now after the guard
        _write_body(path, fm, body_text if body_text.endswith("\n") else body_text + "\n")
        ...                                          # registry sync + commit unchanged
```

Export `GoalH2DropError` (and optionally `_has_goal_h2` stays private) via the module export list that already carries `GOAL_H2_NAME` (line 5536 vicinity). Update the `set_body` docstring (docstring-on-edit rule) with the guard + override.

## 11. Decision Rationale

- **Refuse-by-default + `--allow-goal-drop` (Decision 1).** Why: (a) fail-fast is the standing project rule ("the crash IS the signal"); (b) the #1112 caller was an agent — a stderr warning in an automated pipeline is exactly the signal class that goes unseen, reproducing the bounce+repair cost the task exists to remove; (c) the refusal's false-positive cost is one clear error naming its own recovery, while a missed warning's cost is the #1112 gate bounce; (d) in-file precedent: `_assert_body_nontrivial` + `--allow-stub` (incident #385) is refuse+override in the SAME command. Source: `scripts/task.py:727-765` precedent + #1112 incident. Alternative (warn-only) retained as the pre-authorized kill-criterion fallback.
- **Library seam, CLI threads the flag (Decision 2).** Why: covers ALL body-replacing callers (CLI, `task_state.patch_experiment`/sagan, migrate), not just the CLI — a CLI-only guard would miss the dashboard PATCH path. Source: caller sweep §2; clarifier preference confirmed. Alternative (CLI-only, like the #385 guard) rejected: that guard's exemption rationale ("internal callers keep working") doesn't apply here — internal callers are exactly who dropped the Goal in #1112's class of bug.
- **`kind: experiment` only, read as `fm.get("kind")` (Decision 3).** Why: only experiments carry the Goal-gate machinery; infra/analysis bodies (including #1136 itself) carry `## Goal` H2s with no downstream gate, and firing there would false-refuse routine rewrites. Field name verified against `set_kind` (`fm["kind"]`, line 3729) and `KINDS` (line 132). Source: task body directive + code read.
- **`is_paper_task(fm)` auto-exemption vs a flag in analyzer paper mode.** Why: mirrors the existing CLI paper exemption for the stub-length guard (task.py:786–796) — one consistent "paper stubs are structurally different" rule, zero doc edits to analyzer paper mode. Source: `scripts/task.py:786-796`, `task_workflow.py:929`.
- **Explicit flag in issue-v2 SKILL 7f vs a `<!-- report-v1 -->` sentinel auto-exemption.** Why: explicit beats implicit — a sentinel exemption would silently authorize ANY body carrying the sentinel string, and couples the library to a report-format token; the flag keeps the audit trail in the command itself. Source: report-template.md skeleton read (has `## Motivation:`, no `## Goal`).
- Training hyperparameters: **N/A — no model training.**
