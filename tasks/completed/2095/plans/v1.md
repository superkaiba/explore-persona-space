## 1. Goal + acceptance criteria

Task #2095 `## Goal` H2, verbatim:

> Add an opt-in `/mnt/eps-data/$USER` staging-roots leg to the non-canonical cache sweep
> (`clean_experiment_downloads.py`), the disk-guard data-disk pass (`vm_disk_guard.py`), and the
> watcher data-disk attribution (`autonomous_session_watch.py`), under the full existing safety
> contract, so the sanctioned per-issue staging convention finally has a lifecycle owner.

**Acceptance criteria (requirement form):**

1. `clean_experiment_downloads.py <N>` (CLI, dry-run default) enumerates `<N>`-keyed TOP-LEVEL
   dirs under the staging root(s) alongside its existing /tmp + data/ candidates, runs them
   through gate 1 (active-consumer) + gates 1.5/1.55/1.6/1.7, and reports a disposition per
   candidate. Library calls with `staging_roots=None` NEVER touch any staging root (hermeticity
   identical to the #911 `tmp_root` contract).
2. `vm_disk_guard.py` (report-only) DATA-DISK pass discovers staging-only issues, attributes
   ACTIVE-status staging dirs via `escalate_active_cache` (never deletes), and routes
   terminal-status staging dirs through `clean_issue_downloads` with the full gate chain. The
   BOOT-disk pass never sweeps the staging roots (no double-sweep per run — the existing /tmp
   no-double-sweep pin mirrored).
3. The watcher's `_data_disk_top_caches` repquota-`None` fallback additionally attributes the
   top-N largest TOP-LEVEL entries of the staging root(s) via bounded `du -sx` (dry-run:
   zero-subprocess, returns nothing — the #681 r3 contract preserved).
4. A dir whose CONTENT names a different issue than its dir name is HARD-ESCALATED (new sidecar
   kind), never reaped by dir-name status — regardless of evidence.
5. Escalated-unverified staging rows carry a class label distinguishing
   `derived-partial-mirror` (some top-level names are data-repo prefixes) from
   `orphan-no-mirror` (none are).
6. Everything is opt-in from the two CLI `main()` bodies only; `EPM_STAGING_CACHE_ROOTS`
   overrides the root set; `EPM_SKIP_STAGING_CACHE_SWEEP=1` kills the staging leg;
   `EPM_SKIP_NONCANONICAL_CACHE_SWEEP=1` (existing) kills it transitively.
7. Per-shape dispositions (§4 table) hold: top-level FILES and the `huggingface-cache` dir are
   never candidates; `tmp-<N>-*` / `tmp_issue<N>_*` / `i<N>_*` / `issue_<N>_*` / `issue<N>-*`
   all key to the right issue.
8. Touched tests green; `uv run ruff check` clean on touched files; the #911 I7 AST pin extends
   to `production_staging_roots`; docs listed in §4.5 updated.

## 3. Method delta (what differs from the existing #911 /tmp leg, and why)

| # | Delta | Why |
|---|---|---|
| 1 | Root = `data_disk_root()/<user>` (user via `getpass.getuser()`, cron-safe), mount-guarded (`os.path.ismount`) for the DEFAULT root; env-override roots need only `is_dir()` | The staging convention is `$USER`-scoped (CLAUDE.md compute-character clause; the top level is root-owned, #1410); an unmounted `/mnt/eps-data` must be a clean no-op (the #681 round-2 Major class) |
| 2 | PREFIX-ONLY extraction: `extract_issue_number` P1 first, then a NEW `_STAGING_TMP_PREFIX_RE = ^tmp[-_](?:issue[-_]?)?(\d+)(?:[._-]|$)`; NO P2 suffix leg on staging roots | Census shapes are all prefix-shaped (`issue<N>_`, `issue<N>-`, `issue_<N>_`, `i<N>_`, `tmp_issue<N>_`, `tmp-<N>-`); the P2 `_(\d+)$` class is the foreign-mkdtemp false-attribution shape and staging dirs are huge — excluding P2 removes that class entirely here. New module-level block (beside `TMP_CACHE_ROOT_DEFAULT`, L203):

```python
_STAGING_TMP_PREFIX_RE = re.compile(r"^tmp[-_](?:issue[-_]?)?(\d+)(?:[._-]|$)")
STAGING_SWEEP_KILL_ENV = "EPM_SKIP_STAGING_CACHE_SWEEP"
STAGING_ROOTS_ENV = "EPM_STAGING_CACHE_ROOTS"

def extract_staging_issue_number(name: str) -> int | None:
    """Issue number a STAGING-root entry NAME is keyed to, or None.
    P1 (shared extract_issue_number prefix regex) first, then the staging
    tmp-variant (tmp-<N>-*, tmp_issue<N>_*). Deliberately NO P2 suffix
    route (foreign-mkdtemp shape; staging dirs are huge). Pure; unit-tested."""
    m = _TMP_ISSUE_PREFIX_RE.match(name)
    if m is not None:
        return int(m.group(1))
    m = _STAGING_TMP_PREFIX_RE.match(name)
    if m is not None:
        return int(m.group(1))
    return None

def production_staging_roots() -> list[Path]:
```
