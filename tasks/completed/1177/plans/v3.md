### 4.1 New module-level constants (`scripts/pod_lifecycle.py`, near the terminate-guard section ~line 2055)

```python
# Pod-safety pre-provision check (#1177). These three sets MIRROR the
# watcher's pod-safety auto-stop predicate (autonomous_session_watch.py:
# POD_SAFETY_AUTO_STOP, _POD_FOLLOWUP_SIGNAL_KINDS, _DONE_TRANSITION_KINDS)
# so the warning fires exactly when the watcher would auto-stop. Parity is
# pinned by tests/test_pod_lifecycle.py::
# test_provision_pod_safety_constants_match_watcher — update BOTH sides
# together (never refactor the watcher from here).
_POD_SAFETY_AUTO_STOP_STATUSES = frozenset(
    {"completed", "awaiting_promotion", "archived", "on_hold"}
)
_POD_FOLLOWUP_SIGNAL_KINDS = frozenset(
    {"epm:run-launched", "epm:followup-scope", "epm:free-analysis-followup-run"}
)
_POD_DONE_TRANSITION_KINDS = frozenset({"epm:promoted", "epm:status-changed"})
_KEEP_RUNNING_TAG = "keep-running"
```

### 4.2 Pure predicate helpers (unit-testable without RunPod API)

```python
def _parse_marker_ts(ts: object) -> float | None:
    """Epoch seconds for an events.jsonl ISO-8601 ts (task_workflow._utcnow_iso
    format '%Y-%m-%dT%H:%M:%SZ'); None on any unparseable value (the event is
    then treated as absent — conservative toward warning, never a crash)."""
    try:
        return dt.datetime.fromisoformat(str(ts).replace("Z", "+00:00")).timestamp()
    except (ValueError, TypeError):
        return None

def _latest_marker_ts(events: list[dict], kinds: frozenset[str]) -> float | None:
    """Newest parseable ts among events whose kind is in kinds, else None.
    Mirrors autonomous_session_watch._latest_event_ts semantics."""
    best = None
    for ev in events:
        if ev.get("kind") not in kinds:
            continue
        ts = _parse_marker_ts(ev.get("ts"))
        if ts is not None and (best is None or ts > best):
            best = ts
    return best

def _fresh_followup_signal(events: list[dict]) -> bool:
    """True iff a follow-up signal marker is STRICTLY newer than the latest
    done-transition — byte-for-byte the watcher's _task_followup_active
    comparison (signal missing -> False; done-transition missing -> False)."""
    sig = _latest_marker_ts(events, _POD_FOLLOWUP_SIGNAL_KINDS)
    if sig is None:
        return False
    done = _latest_marker_ts(events, _POD_DONE_TRANSITION_KINDS)
    if done is None:
        return False
    return sig > done
```

(`dt` = `datetime` is already imported at `pod_lifecycle.py:45`.)

### 4.3 The guard (warn-only, fail-open, never raises past its own body)

```python
def _warn_on_terminal_parent_provision(issue: int, *, verb: str = "provision") -> bool:
    """Warn-only pod-safety pre-provision check (#1177). Returns True iff the
    warning fired (for tests); NEVER blocks, NEVER raises on task-state
    problems — an unresolvable task (ad-hoc pod, registry miss, branch-guard
    fire) proceeds with a one-line NOTE. Mirrors the watcher's auto-stop
    predicate so the warning predicts exactly what the pod-safety pass will do. Provision-time only:
    a task that ENTERS the auto-stop set after provision is never warned —
    the watcher remains the runtime backstop (do not read the warning's
    absence as a safety guarantee).
    """
    try:
        from explore_persona_space.task_workflow import get_task, list_events
    except ImportError:
        print(
            f"[pod_lifecycle] NOTE: pod-safety pre-{verb} check skipped for "
            f"issue #{issue}: task_workflow module unavailable. Proceeding.",
            file=sys.stderr,
        )
        return False
    try:
        task = get_task(issue)
        status = task.get("status") or ""
        if status not in _POD_SAFETY_AUTO_STOP_STATUSES:
            return False
        tags = (task.get("frontmatter") or {}).get("tags") or []
        if _KEEP_RUNNING_TAG in tags:
            return False
        events = list_events(issue)
    except (FileNotFoundError, RuntimeError, ValueError, OSError) as exc:
        print(
            f"[pod_lifecycle] NOTE: pod-safety pre-{verb} check skipped for "
            f"issue #{issue}: could not read task state "
            f"({type(exc).__name__}: {exc}). Proceeding.",
            file=sys.stderr,
        )
        return False
    if _fresh_followup_signal(events):
        return False
    print(_terminal_parent_warning_text(issue, status, verb), file=sys.stderr)
    return True
```

Exception-handling notes (grounded in the terminate guard, line 2152-2184): `FileNotFoundError` = task not in registry/on disk (ad-hoc pods like a hand-named `--issue 9999`); `RuntimeError` = task_workflow branch-guard on non-main HEAD or git missing; `ValueError` = malformed frontmatter / corrupt REGISTRY.json (JSONDecodeError is a ValueError); `OSError` added for an unreadable `events.jsonl`. Anything else (KeyboardInterrupt, MemoryError, programming bug) propagates — fail-fast rule.

## 6. Evaluation — acceptance criteria (concrete, testable)

1. **Warn fires (primary):** `provision --dry-run --issue <N>` where task N is `completed`, untagged, with only an `epm:status-changed` event → stderr contains ALL of: `pod-safety`, `AUTO-STOP`, `add-tag <N> keep-running`, `epm:run-launched`, `Proceeding` — and exit code 0 (dry-run path unchanged).

## 11. Decision Rationale

- **Warn-only vs required `--ack-terminal-parent` flag → WARN-ONLY.**
  Source: originating candidate on #1080 ("unlike an auto-post it does not blanket-exempt escaped provisions", leaning warn-only); incidents #573/#779; `autonomous_session_watch.py:687-703` (the ≥2-miss ~20-min accumulation).
  Reasoning: (a) the hazard is *recoverable after the warning prints* — the `keep-running` tag is timestamp-independent and still shields a pod applied within the watcher's ~20-min 2-miss window, so a warning with the exact commands converts the failure into a trivially fixable state; this is unlike the terminate guard, where the protected loss (unuploaded artifacts) is irreversible and a hard block is warranted. (b) A hard block would need threading an ack flag through `RunPodBackend.launch`'s subprocess argv (`backends/runpod.py:767`) and every autonomous caller — more code, and a new way for a task-state glitch to break a legitimate autonomous launch (autonomous sessions cannot answer a prompt). (c) A block-with-env-override converges to warn-only in practice for autonomous callers while adding a blanket-exemption env var — the exact anti-pattern the candidate flags.
  Alternatives rejected: hard block + `--ack-terminal-parent` (fragility, backend threading); auto-posting the signals on the caller's behalf (blanket-exempts escaped provisions — defeats the watcher).
- **Predicate sharing → LOCAL MIRROR in pod_lifecycle.py + parity test (not a task_workflow helper, not importing the watcher).**
  Source: `pod_lifecycle.py:2130-2218` (the terminate guard already established "pod_lifecycle reads task state via lazy task_workflow library imports"); `pod_lifecycle.py:767` (never shells to task.py); brief constraint "do NOT refactor the watcher".
  Reasoning: importing `autonomous_session_watch` (a 17k-line script whose `_task_events` shells to `task.py` via subprocess) into pod_lifecycle for one 10-line predicate is bad coupling and drags in the wrong events-read route; hoisting the predicate into `task_workflow.py` would grow the shared library's public surface AND still leave the watcher on its own copy (scope forbids rewiring it), i.e., two copies either way. A local mirror + a parity test that asserts constant-set equality against the watcher's module gives mechanical drift protection at zero coupling. The comparison logic (strict `>`, missing-signal→False, missing-done→False) is restated byte-for-byte with a cross-reference docstring.
- **Placement before `list_team_pods()` (line 1706) →** the warning must precede every API call so it prints even when the provision later fails on capacity; and it covers both CPU and GPU branches plus `--dry-run` with one call site. Source: `cmd_provision` read at lines 1692-1811.
- **Check runs in `--dry-run` (divergence from the terminate guard) →** the terminate guard skips dry-run because it *blocks* a preview; a warn-only line is informative in a preview and gives a zero-cost smoke path. Source: `pod_lifecycle.py:2146-2150`.
- **`cmd_resume` as a second call site →** resume creates a RUNNING pod the pod-safety pass treats identically; #573's incident class involved stopped-then-resumed healthy pods. One-line cost. Source: #573; `autonomous_session_watch.py:7440-7452` (RUNNING-pod trigger is provision-method-agnostic). Flagged as strikeable scope extension.
