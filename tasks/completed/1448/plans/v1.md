### 4.1 Repo mirror as source of truth (the main design decision)

The hook becomes an in-repo file, `scripts/hooks/on-stop-429-retry.sh` (new dir), installed to `~/.claude/hooks/on-stop-429-retry.sh` by `cp -p`. Rationale vs testing-in-place:
- **Mirror (chosen):** the hook gets version control (it currently has none), the pytest tests a repo path (works on any checkout, no `$HOME` dependency), and drift is caught mechanically — the test suite includes a sync check: if `$HOME/.claude/hooks/on-stop-429-retry.sh` exists, assert it equals the mirror; skip if absent (CI / other machines). Drift risk = someone hot-patches the global copy → next Step-9c full-suite run on this VM fails the sync test and names the fix.
- **Test-in-place (rejected):** the repo test would depend on a file outside the repo — unreproducible on other checkouts, and the hook stays unversioned. Drift risk unbounded.

### 4.2 New hook logic (near-final bash sketch)

```bash
#!/usr/bin/env bash
# 429 auto-retry hook — limiter-aware, minute-boundary-paced, storm-capped (#1448).
# Re-wake mechanism (exit 2 + stdout + asyncRewake) is deliberately unchanged.
set -u

DISABLE_FILE="${CLAUDE_429_RETRY_DISABLE_FILE:-/tmp/claude-429-retry-disabled}"
STATE_DIR="${CLAUDE_429_RETRY_STATE_DIR:-/tmp/claude-429-retry-state}"
DBG="${CLAUDE_429_RETRY_DEBUG_DIR:-/tmp/claude-stop-hook-debug}"
MAX_CONSECUTIVE="${CLAUDE_429_RETRY_MAX_CONSECUTIVE:-5}"
RESET_WINDOW_SECS="${CLAUDE_429_RETRY_RESET_WINDOW:-600}"
MIN_WAIT_SECS=20; JITTER_MAX_SECS=10
NO_SLEEP="${CLAUDE_429_RETRY_NO_SLEEP:-0}"   # test hook: skip sleep, still report wait

[ -f "$DISABLE_FILE" ] && exit 0              # kill switch (preserved)
input=$(cat)

mkdir -p "$DBG"                               # debug capture (preserved, last 10/event)
event=$(printf '%s' "$input" | jq -r '.hook_event_name // "unknown"' 2>/dev/null || echo unknown)
ts=$(date +%s%N)
printf '%s\n' "$input" > "$DBG/${event}-${ts}.json"
ls -t "$DBG"/"${event}"-*.json 2>/dev/null | tail -n +11 | xargs -r rm -f

case "$event" in
  StopFailure)                                # matcher pre-filtered to rate_limit
    err_text=$(printf '%s' "$input" | jq -r '.last_assistant_message // ""' 2>/dev/null || echo "") ;;
  SubagentStop)
    transcript=$(printf '%s' "$input" | jq -r '.agent_transcript_path // empty' 2>/dev/null)
    { [ -z "$transcript" ] || [ ! -f "$transcript" ]; } && exit 0
    # Preserved defense: agent transcript (never parent), structured isApiErrorMessage only.
    err_text=$(tail -n 8 "$transcript" 2>/dev/null | jq -r -s \
      '[.[] | select(.isApiErrorMessage == true) | (.message.content // "" | tostring)] | last // ""' \
      2>/dev/null || echo "")
    [ -z "$err_text" ] && err_text=$(printf '%s' "$input" | jq -r '.last_assistant_message // ""' 2>/dev/null || echo "")
    printf '%s' "$err_text" | grep -qiE '429|rate.limit' || exit 0 ;;
  *) exit 0 ;;                                # Stop etc. — no-op (preserved)
esac

active=$(printf '%s' "$input" | jq -r '.stop_hook_active // false' 2>/dev/null || echo false)
[ "$active" = "true" ] && exit 0              # loop guard (preserved)

# --- limiter classification (from the 429 text) ---
limiter=unknown
if   printf '%s' "$err_text" | grep -qi 'output tokens per minute'; then limiter=output-TPM
elif printf '%s' "$err_text" | grep -qi 'input tokens per minute';  then limiter=input-TPM
elif printf '%s' "$err_text" | grep -qi 'requests per minute';      then limiter=RPM; fi

# --- per-session storm counter (increment BEFORE cap check; mtime = arrival time) ---
sid=$(printf '%s' "$input" | jq -r '.session_id // "unknown"' 2>/dev/null | tr -cd 'A-Za-z0-9._-')
[ -z "$sid" ] && sid=unknown
mkdir -p "$STATE_DIR" 2>/dev/null || true
cfile="$STATE_DIR/${sid}.count"; now=$(date +%s); count=0
if [ -f "$cfile" ]; then
  mtime=$(stat -c %Y "$cfile" 2>/dev/null || echo 0)
  if [ $((now - mtime)) -le "$RESET_WINDOW_SECS" ]; then
    count=$(tr -cd '0-9' < "$cfile" 2>/dev/null); count=${count:-0}
  fi
fi
count=$((count + 1))
printf '%s' "$count" > "$cfile" 2>/dev/null || true
find "$STATE_DIR" -name '*.count' -mmin +60 -delete 2>/dev/null || true
touch /tmp/claude-429-retry-cooldown          # visibility sentinel (preserved)

if [ "$count" -gt "$MAX_CONSECUTIVE" ]; then
  exit 0   # storm cap: stay stopped SILENTLY; watcher wedge lanes / issue-tick cron recover
fi

# --- pacing: next minute boundary (floor 20s) + jitter ---
secs_to_boundary=$((60 - now % 60))
[ "$secs_to_boundary" -lt "$MIN_WAIT_SECS" ] && secs_to_boundary=$((secs_to_boundary + 60))
wait_secs=$((secs_to_boundary + RANDOM % (JITTER_MAX_SECS + 1)))   # range [20, 89]
[ "$NO_SLEEP" = "1" ] || sleep "$wait_secs"

# --- limiter-accurate messages ---
case "$limiter" in
  output-TPM) lim_desc="org-wide output-tokens-per-minute (OTPM)"; hint="keep responses and tool outputs lean for the next few turns" ;;
  input-TPM)  lim_desc="org-wide input-tokens-per-minute (ITPM)";  hint="keep prompts lean and stagger any subagent spawns" ;;
  RPM)        lim_desc="org-wide requests-per-minute (RPM)";       hint="reduce parallel API calls for the next few turns" ;;
  *)          lim_desc="rate limit (class unknown)";               hint="pace token usage for the next few turns" ;;
esac
if [ "$event" = "SubagentStop" ]; then
  agent=$(printf '%s' "$input" | jq -r '.agent_type // empty' 2>/dev/null)
  [ -z "$agent" ] && agent=$(printf '%s' "$input" | jq -r '.agent_id // empty' 2>/dev/null)
  [ -z "$agent" ] && agent="the sub-agent"
  printf 'A sub-agent (%s) was blocked by a 429 on the %s limit. This hook already waited %ss (to the minute boundary + jitter; retry %s/%s this storm). Re-spawn the same sub-agent with the same prompt and continue; %s.\n' \
    "$agent" "$lim_desc" "$wait_secs" "$count" "$MAX_CONSECUTIVE" "$hint"
else
  printf 'This session hit the %s limit (429). This hook already waited %ss (to the minute boundary + jitter; retry %s/%s this storm). Continue your prior task from where you left off; %s.\n' \
    "$lim_desc" "$wait_secs" "$count" "$MAX_CONSECUTIVE" "$hint"
fi
exit 2
```

### 4.3 Counter / reset semantics (exact)

- **Key:** sanitized `session_id` (shared across StopFailure and SubagentStop for the same session — during an org-wide storm, parallel subagent 429s ARE the same storm and should share the budget).
- **Consecutive** means: gap between hook invocations for this session ≤ 600s (measured by state-file mtime, updated on EVERY invocation including at-cap ones). Gap > 600s ⇒ counter treated as 0 before increment (new storm).
- **At cap (count > 5):** silent `exit 0` — the session stays stopped; recovery backstops are the watcher's prompt-wedge/dead-wake lanes (`isApiErrorMessage`-aware, ≥3 failed wake turns / 20-min silence) and the 45-min `/issue-tick` cron for issue sessions. Retries are NOT permanently disabled: continued external re-wakes keep incrementing + refreshing mtime (still exit 0); once invocations stop arriving for >600s, the next 429 gets a fresh budget of 5.
- **Hygiene:** stale `*.count` files older than 60 min deleted opportunistically each invocation.
- **No shared org-wide storm sentinel** (considered, rejected): per-session cap 5 + ≥20s pacing already bounds fleet-wide re-wake QPS to ≤ n_sessions/20 per second with a hard per-session ceiling; a shared sentinel would couple sessions (one session's storm silencing another's single legitimate retry) for negligible extra benefit.

## 5. Controls / safety

- **Kill switch preserved** (`/tmp/claude-429-retry-disabled`, path env-overridable with the same default) — checked first, before stdin read.
- **Degrade-to-safe on ANY failure:** every `jq` retains `2>/dev/null || echo` guards; unparseable event ⇒ `unknown` ⇒ exit 0 (identical to today, incl. jq-missing); unparseable limiter ⇒ `unknown` class, paced retry still fires; state-dir/counter failures (`|| true`, `${var:-0}`) ⇒ count=1 ⇒ paced retry. No code path can exit nonzero-other or exceed ~90s + jq overhead. `set -u` safety: all expansions defaulted.
- **At cap:** silent exit 0 — session parks; watcher/tick backstops recover (see 4.3). Never a permanent disable.
- **False-positive defenses byte-in-spirit:** Stop no-op, `agent_transcript_path` (never parent `transcript_path`), `isApiErrorMessage: true` structural requirement, `stop_hook_active` guard — all kept, all covered by tests.
- **No added latency to healthy paths:** non-429 SubagentStop exits 0 BEFORE any counter/sleep logic; the sleep runs only after a confirmed 429.
- **Concurrency:** state keyed per session_id — no cross-session collision. A same-session StopFailure/SubagentStop race on the counter can undercount by 1 (read-modify-write, no flock); accepted — the cap is a bound, not an exact meter, and flock would add a failure mode to the Stop path.

## 11. Decision Rationale (load-bearing constants)

- **Sleep-to-next-minute-boundary, floor 20s.** What: `60 − now%60`, +60 if <20. Why: the Goal mandates boundary pacing and CLAUDE.md's 429 guidance uses the same model; under the doc's continuous bucket the binding property is "wait tens of seconds" (3M OTPM ⇒ ~50K tokens/s refill; 20s ≈ 1M tokens), so the floor prevents useless 1–3s waits just before a boundary. Source: platform.claude.com/docs/en/api/rate-limits + settings.json timeout=120. Alternatives: fixed 45s (loses the Goal's boundary framing, same effect); `retry-after` header (unavailable — text-only input).
- **Jitter uniform 0–10s.** What: `RANDOM % 11`. Why: decorrelates the fleet-wide boundary herd (~30 concurrent sessions ⇒ ≤3 re-wakes/s) while keeping max total 89s < 120s timeout with ≥30s headroom. Source: settings.json timeout; session count from `spawn_session.py list` (29 live). Alternatives: 0 (herd), 0–30s (max 109s — too little headroom).
- **Storm cap N=5.** What: consecutive re-wakes per session before silent exit 0. Why: 5 paced retries ≈ 3–7 min of active retrying — covers transient storms; the 2026-07-16 storms ran longer, where parking + watcher recovery beats 27–112 burned turns; Goal's "1–2 turns" is the typical paced cost, cap 5 the worst case. Source: observed storm turn counts (task body / debug captures); watcher wedge-lane thresholds (≥3 failed wakes, 20-min silence). Alternatives: 3 (gives up on medium storms), 10 (~10+ min churn).
- **Reset window 600s.** What: quiet gap that zeroes the counter. Why: paced consecutive invocations arrive ≤ ~2–4 min apart (wait 20–89s + failing-turn time), so 600s cleanly separates "same storm" from "new storm", and is < the 45-min tick cadence so an externally re-woken session gets a fresh budget. Source: observed cadence + pacing arithmetic. Alternatives: 300s (risk of mid-storm reset when a turn does partial work between 429s), 3600s (slower re-arm after recovery, no benefit).
- **State location `/tmp/claude-429-retry-state/<session_id>.count`.** Why: per-session keying kills cross-session collision (brief constraint); /tmp persistence (per boot) exceeds storm timescales (hours); 60-min opportunistic cleanup bounds litter. Source: brief's concurrency constraint + observed 3.2h worst storm window. Alternatives: `$HOME/.claude/` state (survives reboot — unneeded, adds clutter); shared org sentinel (rejected, §4.3).
- **Mirror-in-repo over test-in-place.** §4.1. Source: brief's named design decision; drift weighed both ways there.
