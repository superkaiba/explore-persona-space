## 3. Design

### 3.1 Mechanism choice

Constraint 5 offered two shapes: (a) quote-aware clause splitting for the ssh argument; (b) payload-opaque handling with separate payload classification. I choose a refinement of (a) — **predicate-gated separator masking before the split** — because it is the smallest change: the splitter, driver loop, waiver, and every classifier stay byte-identical; one new function + one call site. Option (b) (classify the payload separately) would duplicate `classify_clause` semantics against remote-context text and re-litigate which detectors apply remotely; rejected as larger and less provable.

The critical safety property, stated once and enforced by construction:

> **Monotonicity invariant.** `mask_ssh_payload_separators` either (i) returns its input BYTE-IDENTICAL, or (ii) rewrites only characters in `{;, &, |, \n}` inside a balanced single-quoted span whose enclosing prospective clause satisfies EVERY refusal condition of the existing driver-loop waiver ladder. In case (ii) the resulting single clause is provably waived by the EXISTING ladder (each condition holds by construction, and masking cannot create refusal-pattern text or repo-path spellings — the replacement token is space-padded word characters). Therefore the post-change block set differs from today's ONLY by removing commands of exactly the intended class; every clause that still reaches `classify_clause` sees the same text it sees today.

The dangerous alternative — masking unconditionally and letting the ladder refuse afterward — is explicitly rejected: a refused-but-masked clause would be classified as MERGED text, where an allow-arm token from one remote statement (e.g. `switch main`, `restore --staged`) could swallow a block from another (cross-statement allow-arm contamination), flipping today's block to allow in pipeline/redirect positions. Constraint 2 names those positions as must-preserve. Gating masking on the full ladder makes every refused case byte-identical to today.

### 3.3 Pseudocode

```awk
# BEGIN: slurp all records; END: s = lines joined with "\n"
i = 1; atstart = 1; out = ""
while (i <= n) {
  if (atstart && substr(s,i,4) ~ /^ssh[ \t]/) {
    j = i + 4                                     # scan the head (host/options)
    while (j <= n && substr(s,j,1) ~ HEADCHARS) j++   # [A-Za-z0-9_.@:%=/+,-] + space/tab
    if (substr(s,j,1) == "'") {
      cq = index(substr(s, j+1), "'")             # single quotes: '[^']*' is EXACT
      if (cq > 0) {
        payload = substr(s, j+1, cq-1); k = j+1+cq   # k = first char after closing quote
        t = k; while (t <= n && substr(s,t,1) ~ /[ \t]/) t++   # tail: whitespace only
        tail_ok = (t > n) || substr(s,t,1) == ";" || substr(s,t,1) == "\n" \
                  || substr(s,t,2) == "&&" || substr(s,t,2) == "||"   # never bare | or &
        cand = substr(s, i, k-i)                  # head + 'payload'
        if (tail_ok && cand !~ /\$\(|\$\{|`|<|>|\x01/ \
            && tolower(cand) !~ /proxycommand|localcommand|knownhostscommand/ \
            && index(cand, repo) == 0 \
            && index(cand, "$HOME/" repo_base) == 0 \
            && index(cand, "~/" repo_base) == 0) {
          gsub(/[;&|\n]+/, " __EPM_SSH_SEP__ ", payload)   # the ONLY rewrite
          out = out substr(s, i, j-i) "'" payload "'"
          i = k; atstart = 0; continue
        }
      }
    }
    out = out "ssh"; i += 3; atstart = 0; continue   # refused: copy verbatim
  }
  c = substr(s,i,1); out = out c
  if (c ~ /[;|&\n]/) atstart = 1; else if (c !~ /[ \t]/) atstart = 0
  i++
}
printf "%s", out
```

Load-bearing details:

- **Clause-initial tracking** mirrors the splitter's raw separator semantics exactly (`;`, `|`, `&`, newline set `atstart`; `&&`/`||` are covered because their first char sets it). Whitespace preserves `atstart`. A `#`-comment clause may be scanned as a candidate — harmless: masked-or-not, the driver skips comment clauses; unmasked comments are byte-identical.
- **HEADCHARS** excludes every quote, `$`, backslash, redirect, paren, bracket, and separator char — so `ssh -p 40052 root@1.2.3.4`, `-o StrictHostKeyChecking=no`, `-i /path/key` heads parse; `ssh $(evil)`, `ssh "h"`, `ssh [::1]`, `ssh h <<'EOF'` never do (refused → byte-identical → today's behavior). `-o ProxyCommand=evil` PASSES the charset but is refused by the explicit token check.
- **Tail = whitespace-only up to `;` / `&&` / `||` / newline / EOS.** Bare `|` or `&` (PIPE/BG — condition (2)'s refusal set) refuse the mask, as does ANY non-space token after the closing quote (`2>/dev/null`, `2>&1`, `<<< input`, `-v`, a second quoted arg) — each falls back to byte-identical input, i.e. exactly today's disposition (S13/S14 `2>/dev/null` shapes stay allowed via the existing single-statement waiver; N17/N22/N23 stay blocked).
- **Candidate refusals** (`>`,`<`, backtick, `$(`, `${`, `\x01`, local-exec option tokens, repo-path spellings) are a strict SUPERSET of the ladder's conditions (3)/(3b)/(4) restricted to the clause — plus blanket `<` (covers `<(`, `<<<`, `<<`, and plain input redirects: strictly more conservative) and `\x01` (splitter-sentinel hygiene). Bare `$VAR` (no brace/paren) is allowed in the payload — parity with the ladder, which explicitly does not refuse it (S10 pins this).
- **Replacement token** ` __EPM_SSH_SEP__ ` is space-padded word characters: it cannot form a separator, a refusal pattern, a repo-path spelling, or glue adjacent tokens into a `git <verb>` bigram. Post-mask, `classify_clause`'s `[^;&|]*` gaps could match ACROSS former statement boundaries — reachable only if a masked clause were classified, which the invariant precludes (masked ⇒ waived ⇒ `continue` before `classify_clause`); and the comment-tail strip (≈L995) can only truncate a masked clause, which removes text and therefore cannot un-waive it.
- **Multiple candidates** (`ssh h1 '…' && ssh h2 '…'`) are handled independently — each mask touches only its own quoted span, so per-candidate reasoning composes.

Worked trace (#779 shape): `ssh pod-77965 'cd /workspace/explore-persona-space && git checkout FETCH_HEAD -- scripts/'` → head `pod-77965 ` clean, payload balanced, tail EOS, no refusal token, `/workspace/explore-persona-space` matches NO covered repo-root spelling (the literal is `/home/thomasjiralerspong/explore-persona-space`) → payload becomes `cd /workspace/explore-persona-space __EPM_SSH_SEP__ git checkout FETCH_HEAD -- scripts/` → one clause → loose gate matches `git … checkout` → waiver: `^ssh` ✓, nextsep=END ✓, no expansion ✓, no redirect ✓, no local-exec option ✓, no repo path ✓ → waived → exit 0.
