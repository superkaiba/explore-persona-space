### D2 — item 2: status-independent unmerged-branch keep reason in `worktree_audit.py`

**Two-signal probe (the central design decision — see §11 D2 for why patch-id alone fails, and why the ts arm is unsuffixed-only).** New module-level helper (impure, caller-side, injected paths for testability):

```python
def _branch_unmerged(
    wt_path: str, events_path: Path | None, *, allow_ts_evidence: bool
) -> tuple[bool | None, str]:
    """(#2246 item 2) True=retain (commits with no patch-equivalent on
    origin/main and no branch-applicable epm:merged evidence), False=merged/
    clean, None=probe failed (caller keeps — fail toward retention). Never
    fetches. allow_ts_evidence: True ONLY for UNSUFFIXED issue-<N> worktrees —
    epm:merged markers are per-TASK, worktrees are per-BRANCH, and
    _ISSUE_NAME_RE maps suffixed siblings onto ONE shared events file, so a
    task-grained TIMESTAMP cannot bind a branch-grained verdict for a sibling
    round (critique r1 MUST-FIX 1, adjudicated). The sha arm stays available
    to ALL worktrees (a sha match names the branch tip — branch-bound)."""
    # 1. HEAD identity + committer epoch in ONE git call (timeout ~10s):
    #    git -C <wt> log -1 --format='%H %ct' HEAD          -> fail => (None, "HEAD unreadable")
    # 2. merged-evidence scan (kind-SCOPED — see below): parse events_path
    #    lines with json.loads, keep ONLY rows with kind == "epm:merged";
    #    collect (aware_epoch(ts), note). Missing file / unreadable file
    #    (OSError) / no rows => empty list; per-line parse errors are skipped;
    #    a valid epm:merged row with a MALFORMED or naive ts contributes NO
    #    ts evidence (its note stays eligible for arm a) — every degraded
    #    reading moves toward LESS merged-evidence => retention. events_path
    #    is None (orphan issue, folder gone) => empty.
    #    ts parsing is TZ-AWARE: 'Z'/offset-bearing ISO-8601 normalized to
```
