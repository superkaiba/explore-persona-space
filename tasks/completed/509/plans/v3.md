<h2>0.0 TL;DR (plain English)</h2>

<ul>
<li><b>What I'll run:</b> The recipe that works for predicting whether one persona's "made-up word" habit will rub off on another persona — I want to see whether the same recipe works for two other behaviors: making the model believe a made-up fact, and making the model agree with anything the user says. <li><b>What would change my mind:</b> Either the richer predictor catches the agree-with-anything outlier case that all simpler predictors missed (specifically: software-engineer's behavior leaking strongly to comedian even though comedian writes nothing like a software engineer) — that would be the most interesting positive. <h2>4. Design</h2>

<p>(§4 narrative and pipeline structure unchanged from v2; the v3 edits are in §4.1.3, §4.1.6, §4.2.2, §4.2.3, §4.2.6.)</p>

<p><b>Why this is a single task, not split:</b> the extraction pipeline (the most expensive step, 2.5h on 8× H100 per #502) is identical across both arms — only the persona panel changes. Running the bake-off twice on two different panels in one task lets the cross-behavior heatmap (the hero figure) be produced from a coherent single sweep, and the panel-level differences (n=26 with substrate vs n=138 with source-FE) are explicit enough that one plan with two clearly-named arms ("fact arm" and "sycophancy arm") doesn't muddle them. The substrate-handling and prior-control differ between arms; each arm gets its own §4 sub-spec below.</p>

<p><b>Why code, not a model call?</b> The bake-off is a numerical pipeline: capture residual activations, compute 9 pairwise distance matrices per (layer × extraction), regress against a target matrix, score by length-partial Spearman + LOCO-CV R². Every step is deterministic numerics on saved tensors / CSVs, not unstructured-text classification. No model call would help (and would burn cost + add noise).</p>

<p><b>Contrastive negatives:</b> N/A — not a behavior-implantation experiment. This is pure analysis over already-trained adapters.</p>

<p><b>Smoke/sweep architectural parity:</b> N/A — <code>kind: analysis</code> with no per-cell training. The bake-off has a single dispatch step (the existing <code>issue502_dispatch.py</code>) that we run twice (once per arm); the dispatcher's own per-condition tensor-merge step is the natural smoke unit. A small smoke run on N=2 conditions × N=4 probes × N=2 layers (per #502's example) is the first launch on each arm before fanning out to the full sweep.</p>

<h4>4.1.5 Regression against leakage</h4>

<p>For each of the 5 substrates, restrict the 9×9 distance matrix to the cells that exist in that substrate's panel. Pool across the 5 substrates with substrate as a fixed effect. Implemented in <code>scripts/issue509_scoring.py</code> (new):</p>

<pre># Per cell (point, layer, metric, variant):
#   x_i = distance between (teach_i, bystander_i) at that cell
#   y_i = leak_rate from regression_data.csv
#   z_i = bystander_logprob (the #500 prior control)
#   s_i = substrate (categorical, 5 levels)
#
# Run 4 regressions per cell:
#   A. Length-partial Spearman ρ(x, y) — pooled, raw (compare to #494 numbers)
#   B. Substrate-FE-residualized Spearman ρ(x | s, y | s) — substrate sign-flip control (#494)
#   C. Prior-residualized Spearman ρ(x | z, y | z) — beat-the-prior control (#500)
#   D. Substrate-FE AND prior-FE residualized: ρ((x | s, z), (y | s, z))
#
# Headline cell: the one where regression D's |ρ| is largest AND
# clears the within-substrate sign-consistency check (sign(ρ) agrees
# across ≥3 of 5 substrates AND the contradictory + 2 positive-only
# panels — the three low-DV-variance panels — are not counted toward
# sign consistency because they are statistical noise).
#
# Then per-arm LOCO-CV R² of a length-controlled linear fit
# (leave one persona out, refit, score on held-out persona's pairs).
#
# Then attenuation-adjustment: ρ_adj = ρ_obs / sqrt(reliability_y),
# where reliability_y is per-cell intraclass correlation across the
# 3 seeds (fact arm) or 1 - binomial_var / total_var (syco arm).
# See §6.1 for the recipe.
#
# Then within-substrate permutation null: shuffle y within s, B=2000,
# hashed seed. Report observed_rho percentile vs permuted_rho dist.</pre>

<p><b>Attenuation-adjusted ρ recipe (v3 addition):</b> per cell, <code>ρ_adj = ρ_obs / sqrt(reliability_y)</code>. <h2>11. Decision Rationale</h2>

<p><b>N/A — no hyperparameters in this task type.</b> (Unchanged from v2; <code>kind: analysis</code>: no model training. Every parameter on the predictor side is inherited unchanged from #502. <p><b>v3 additions get grounding too:</b></p>
<ul>
<li><b>Attenuation adjustment</b> (Spearman 1904 / classical psychometrics): a measurement-validity correction for asymmetric noise floors across DVs. <code>Source: standard textbook recipe</code>; the asymmetry between the 3-seed-averaged fact target and single-seed sycophancy target is documented in v2 Assumption #22 + the v3 fact-checker recount.</li>
<li><b>Within-stratum block permutation</b> (Edgington 1995 / standard cluster-randomization): preserves the block structure that cluster bootstrap accounts for at the SE level. <code>Source: standard recipe</code>; the within-stratum block is substrate (fact, 5) or source (syco, 6) for the same reason cluster bootstrap clusters on them.</li>
<li><b>Non-stylized 156-pair anchor</b>: the apples-to-apples comparison for fact + sycophancy panels that are predominantly non-stylized. <code>Source: #502 § panel_nonstylized regression output</code>, already computed and stored at <code>eval_results/issue_502/bakeoff/regression/loc_ep1.json</code>.</li>
