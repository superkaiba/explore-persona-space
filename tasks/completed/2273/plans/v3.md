## Evidence base (all rows measured on charmander; rows 7-9 are new in v3)

Login shell: `SHELL=/usr/bin/zsh`, `$0 = zsh`, passwd field 7 `/usr/bin/zsh`.
Fixture: temp dir with one real `.log` under a subdirectory (plus a binary file
carrying the same token for row 6), and a top-level `*.log` glob matching nothing.

| # | Shape | Result | rc |
|---|---|---|----|
| 1 | one command, TWO glob args (the #1336 shape) | whole command skipped; the matching subdir never read | 1 |
| 2 | `ls <nomatch-glob> && echo LATER` | `LATER` never runs | 1 |
| 3 | `ls <nomatch-glob>; echo LATER` | `LATER` **does** run | — |
| 4 | `grep <nomatch-glob> \| { cat; echo CONSUMER_RAN; }` / `\| tail -3` / `\| grep <pat>` / `\| wc -l` | consumer RUNS on empty input; rc is the LAST stage's — `tail` 0, `grep` 1, `wc -l` prints `0` and exits 0 | see cell |
| 5 | `grep -rhoE --include='*.log' <pat> <dir>` and `find <dir> -name '*.log' -exec grep -hoE '<pat>' {} +` | both clean, correct output | 0 |
| 6 | bare `grep -r <pat> <dir>` | `path:` prefixes **plus** `grep: ...blob.bin: binary file matches`; drops the filename filter | 0 |
| **7** | `grep <nomatch-glob> \| head -3` and `\| head -n1` | empty output | **0** |
| **8** | `unsetopt nomatch`, then `grep <nomatch-glob>` | `grep: <literal pattern>: No such file or directory` on stderr | **2** |
| **9** | `unsetopt nomatch`, then `grep <nomatch-glob> <matching-glob>` | prints the matched data (`hit_banner`) AND still exits nonzero | **2** |

Rows 7-9 were measured specifically to discharge the two round-1 BLOCKERs. Row 9
is the one that makes the `unsetopt nomatch` escape usable advice: the matched
arguments' data IS returned, so the escape is not silently lossy — it is merely
noisy and rc-dirty.

## In-repo precedent for the `bash -c` remedy (new in v3)

`src/explore_persona_space/backends/slurm_monitor.py::drain_cluster_sentinels`
wraps its remote command in `bash -c` **because charmander's login shell is
zsh** — pinned by `tests/test_slurm_monitor.py::test_drain_shell_includes_scratch_fallback_glob`
(`assert shell.startswith("bash -c ")  # zsh-proof remote invocation`, L1678),
whose docstring cites a 2026-07-30 live-acceptance finding (`shopt: command not
found`). Wrapping sidesteps zsh entirely, so it fixes `nomatch` AND every other
bash-ism in one move — strictly stronger than `unsetopt nomatch`.

**Availability caveat (verified, must ship with the prescription).**
`slurm.py:1615-1619` (`scp_push_secrets` docstring) and `slurm.py:3149-3151`
record that the robot forced-command wrapper allowlist **REJECTS**
`ssh <alias> bash -c '<script>'` — it permits `scp`/`sftp`/`rsync` only — and
that the earlier in-band `ssh ... bash -c ...` path was DOA, erroring every
cluster task at `prepare`. So `bash -c` wrapping is available on the DIRECT
`charmander` alias (where the drain path uses it) but NOT through the
robot-wrapper alias. Prescribing it unconditionally would send a reader down a
path that fails on the robot lane.
