## 3. Design

### 3.1 Investigation findings (grounding the diff)

- **The probe funnel:** all four probe callers in `scripts/verify_task_body.py` (check 23 `_hf_url_existence` at 5485, check 25 at 7103, check 30 count probe at 7643, check 32 basenames probe at 8006) gate in the order: fence check → `import huggingface_hub` guard → memo cache → `_hf_tree_get`. Consequences: (i) fence-set tests (the whole non-HF majority of the file, incl. all git-subprocess figure tests) never reach the guard; (ii) the two ImportError tests (`test_hf_count_importerror_skips` line 2329, `test_hf_adjacent_importerror_skips` line 3304) return "skip" at the import guard BEFORE `_hf_tree_get` — safe under the guard.
- **Cache cannot leak a probe past the guard:** the existing autouse `_clear_hf_existence_cache` (target lines 1668–1684) clears all three memo caches (`_HF_EXISTENCE_CACHE`, `_HF_TREE_FILE_COUNT_CACHE`, `_HF_TREE_BASENAMES_CACHE`) before AND after every test, so a probe must fire at least once per test before any verdict is cached — the raiser fires first.
- **AssertionError propagates:** the only `except Exception` sites in `scripts/verify_task_body.py` are line 4576 (unrelated helper, not on the probe path) and 5355/5370 (inside the REAL `_hf_tree_get` body, which the guard replaces wholesale). `verify_text` has no per-check try/except. The guard raises out of both direct check-function calls and `verify_text`.
- **Complete enumeration of fence-delenv tests (grep `_hf_tree_get|_stub_tree|EPM_VERIFY_BODY_NO_HF`, every hit read):** every test that delenvs the fence stubs the probe via `_stub_tree` (lines 1687–1697), `_i833_needle_stub` (lines 2547–2566), or an inline `monkeypatch.setattr(verify_task_body, "_hf_tree_get", _boom/_fake)` — **except one**:
  - **`test_hf_url_paginated_then_429_is_bounded_unverified` (line 1946)** — the ONLY test relying on the un-stubbed real `_hf_tree_get`. It stubs `huggingface_hub.utils.get_session` to drive the real body's pagination + bounded-retry logic. Under the guard it would fail with the guard's AssertionError. **Handling:** explicit allowance — restore the real function (captured at module import, before any fixture patches) at the top of the test.
- **Benignly-redundant cases:** the four fence-blocks-all-GETs tests (lines 1823, 2299, 2719, 3216) already `setattr` their own `_boom`; the guard is shadowed by their explicit stub and their semantics are unchanged (their own `_boom` message still names the specific check). No edit needed.
- **Subprocess uses** in the file are git plumbing only (figure-sha checks, all fence-set); the verifier is never run out-of-process here, so in-process patching covers every probe path.

### 3.2 The diff

**Location:** immediately after `_clear_hf_existence_cache` (ends line 1684) and before `_stub_tree` (line 1687). (Autouse applies module-wide regardless of definition position; this placement keeps the probe-fixture block together.)

```python
# The real probe primitive, captured at module import time — BEFORE any
# fixture patches — for the one test that exercises the real body at the
# SDK boundary (test_hf_url_paginated_then_429_is_bounded_unverified).
_REAL_HF_TREE_GET = verify_task_body._hf_tree_get


@pytest.fixture(autouse=True)
def _no_unexpected_probes(monkeypatch):
    """Raise-by-default guard (#1161, mirroring test_verify_task_body_audit_claim
    from #860): ANY `_hf_tree_get` call a test did not explicitly stub is a
    hard error — missed-mock detection independent of network / offline / Hub
    repo state (the suite-wide EPM_VERIFY_BODY_NO_HF fence alone degrades a
    missed mock to skip-not-raise semantics). Per-test `_stub_tree` /
    `_i833_needle_stub` / inline setattr re-patches over this (the shared
    function-scoped monkeypatch teardown restores cleanly); a test that must
    exercise the REAL body restores `_REAL_HF_TREE_GET` explicitly."""

    def _unexpected(url, params, headers, *, timeout_s):  # pragma: no cover
        raise AssertionError(
            f"unexpected _hf_tree_get probe of {url} — add _stub_tree or an explicit allowance"
        )

    monkeypatch.setattr(verify_task_body, "_hf_tree_get", _unexpected)
```

**Edit to the one affected test** (`test_hf_url_paginated_then_429_is_bounded_unverified`, after its `delenv` at line 1956):

```python
    # Explicit allowance: this test exercises the REAL `_hf_tree_get` body
    # (pagination + bounded retry), stubbing one level deeper (get_session).
    # Restore it over the module's autouse raise-by-default guard.
    monkeypatch.setattr(verify_task_body, "_hf_tree_get", _REAL_HF_TREE_GET)
```

**New regression test** (acceptance (c); place near the other check-23 tests, e.g. after the existing dead-pin tests ~line 1943):

```python
def test_autouse_probe_guard_catches_missed_stub(monkeypatch):
    """Missed-mock detection (#1161): fence removed + NO `_stub_tree` — the
    check-23 existence probe must hit the module's autouse raise-by-default
    guard as a hard AssertionError, never degrade to live-network behavior."""
    monkeypatch.delenv("EPM_VERIFY_BODY_NO_HF", raising=False)
    with pytest.raises(AssertionError, match="unexpected _hf_tree_get probe"):
        verify_task_body.check_hf_url_resolves(
            _hf_body(
                "https://huggingface.co/datasets/superkaiba1/explore-persona-space-data/"
                "tree/db3662ae415bakeoff/issue653_x"
            )
        )
```

(Implementer may reuse any URL shape the existing `_hf_body` tests use, e.g. line 2007's `feedface` sha form — the only requirement is that check 23 gathers ≥1 pinned URL so the probe fires. Calling `check_hf_url_resolves` directly keeps the demo independent of `verify_text`'s check roster.)

**Enumerated list of existing tests needing a stub/allowance:** exactly one — `test_hf_url_paginated_then_429_is_bounded_unverified` (allowance above). Zero tests need a `_stub_tree` added: every other fence-delenv test already stubs (verified per-site in §3.1).

**No other files touched.** `tests/conftest.py`, `scripts/verify_task_body.py`, and the sibling file are out of scope (§9).
