### Edit 1 — `.claude/agents/implementer.md` L174 (§ "Run tests — gate-matched scope"): replace the post-hoc slow-file sentence with a pre-emptive rule

**Anchor (old_string, taken verbatim from L174):**

**Replacement (new_string):**

> If the selector's `--json` `slow_tests_selected` list is NON-EMPTY, EVERY listed file is routed PRE-EMPTIVELY to NOT-RUN + Step 9c deferral at minute zero — zero local attempts, no timeout probe, no `-k` subset substitute. Rationale: any file in that list has a per-file surcharge above the Bash-tool 600 s foreground cap by construction (the sole 2026-07-26 entry `tests/test_workflow_lint.py` carries a 2400 s surcharge whose comment records a 1819 s measured max and 1188.62 s standalone), so a local run is unsatisfiable and the six timeout-killed attempts across three sessions on 2026-07-26 gained zero information. If a mandatory-set file NOT in `slow_tests_selected` genuinely cannot finish in-turn (e.g. an unlisted pin hit), the existing NOT-RUN escape applies — a pin-sweep HIT left NOT-RUN is presumptively blocker-adjacent (unlike a NOT-RUN slow invariant file), and the code-reviewer should treat it as such; the pre-emptive route above changes WHEN the escape is taken for `slow_tests_selected` files, not its downstream treatment.
