# Plan — Task #1170: Verdict-disagree observer pass (unreconciled doubled-site PASS-vs-FAIL rounds)

## 0.0 TL;DR (plain English)

- **What I'll build:** a small, non-blocking check added to the every-10-minutes watcher script that looks at each recently-active task's review history and asks: "did the two paired reviewers (Claude + Codex) return opposite verdicts on the same round, with no tie-breaker ever run and no legitimate excuse for one of them being absent?" If yes, it writes a log row and sends one phone alert — nothing else.
- **What I expect:** the pass stays silent on healthy tasks (agreements, reconciled disagreements, genuine Codex outages) and would have fired exactly once on the #825 incident that motivated it.
- **What would change my mind:** if the reused verdict-matching helper can't express the pairing without modifying it (its 20+ existing tests are untouchable), I fall back to a self-contained matcher inside the new function and say so in the implementer report.

**The main pure predicate:**

```python
def unreconciled_disagreement_rounds(
    events: list[dict],
    *,
    now_ts: float,
    grace_s: float = 3600.0,
    pair_proximity_s: float = 21600.0,
    evidence_lookback_s: float = 7200.0,
) -> list[dict]:
    """Per doubled marker-mode site, flag the LATEST round whose Claude +
    Codex verdict markers both exist with parseable OPPOSITE-class verdicts,
    no role-matched epm:review-reconcile, and no codex no-show evidence —
    the #825 misclassification shape (#1170). Pure over list_events output;
    no I/O. Fail-quiet on every ambiguity (unparseable ts/verdict/round,
    unknown verdict token, cross-epoch pairs)."""
```

Algorithm, per site in `ENSEMBLE_MARKER_MODE_SITES`:

1. `pair_events = [e for e in events if e.get("kind") in {claude_kind, codex_kind}]` (chronological — events.jsonl append order). Empty → next site.
2. **Tier 1 (round-aligned).** Derive the latest round from the LAST pair event: `round_n = _sentinel_round(note, kind)`, else `event["version"]` if an `int`; unresolvable → go to Tier 2. Query `res = ensemble_verdicts_present(events, (claude_kind, codex_kind), round_n)`. If BOTH `present` → evaluate the pair (step 4) with `round_label=f"r{round_n}"`, `tier="round"`; the per-kind `ts` comes from `res`. If either side `present=False` → Tier 2. (A side `present=True, verdict=None` — malformed — is NOT a disagreement: not flaggable, no Tier-2 attempt; §11-g.)
3. **Tier 2 (proximity fallback — the #825 founding shape).** Take the chronologically LAST event of EACH kind; if either kind has none → not flaggable (evidence class (d): nothing to disagree with, structural). Parse each verdict via `parse_followup_note_field(note, "Verdict")`. `round_label = f"t2|{claude_ts}|{codex_ts}"`, `tier="proximity"`. Evaluate (step 4).
4. **Pair evaluation** (both tiers, in order; each miss → not flaggable):
   - Classify both verdicts via `_verdict_class(...)`; either `None` → skip (unknown vocabulary fails quiet).
   - Same class → skip (agreement — PASS+CONCERNS is same-class for code-review/clean-result per workflow.yaml).
   - **Pair proximity:** `abs(t_claude − t_codex) > pair_proximity_s` → skip (kills cross-epoch aliasing that latest-match-wins can produce; §11-c).
   - **Grace:** `now_ts − max(t_claude, t_codex) < grace_s` → skip this tick (an in-flight reconcile gets time to land; re-evaluated every tick, so this is deferral, not loss).
   - **Reconcile satisfied** → skip, if EITHER: (i) `ensemble_verdicts_present(events, ("epm:review-reconcile",), round_n, reconcile_role=role)` reports `present` (Tier 1 only — round-scoped), OR (ii) ANY `epm:review-reconcile` event with `parse_followup_note_field(note, "Role under adjudication") == role` and `ts >= min(t_claude, t_codex)` (both tiers — ts-scoped; required because the reconcile's round label can match neither side's round, per #825's real reconcile).
   - **No-show evidence** `_codex_no_show_evidence(events, min(t_claude, t_codex) − evidence_lookback_s)` non-None → skip.
   - Otherwise FLAG: `{"role", "tier", "round_label", "claude_ts", "codex_ts", "claude_verdict", "codex_verdict", "claude_class", "codex_class", "key"}` with `key = f"{role}|{round_label}"` (Tier-1 keys are `role|r<n>`; Tier-2 keys embed both ts, stable across ticks).

**Latest-round-only policy (explicit):** only the latest round per (issue, site) is evaluated. An earlier-round disagreement superseded by a later round is moot for alerting purposes — the iteration already moved past it, the post-hoc audit value concentrates in the CURRENT unreconciled round, and historical round re-derivation is mechanically unreliable given the observed sentinel/version drift (evaluating all rounds against #825's 7-version code-review history would emit false pairs). Justified in §11-e.

**The pass:**

```python
def verdict_disagree_pass(dry_run: bool) -> bool:
    """NON-GATING observer of unreconciled doubled-site verdict
    disagreements (#1170; origin incident #825). Observe/alert only:
    sidecar rows + one deduped fail-soft _telegram_push per
    (issue, site, round) — NEVER posts a task marker, mutates status,
    stops a session, or blocks a dispatch. Fail-soft throughout; an
    internal error degrades to a stderr line, never a watcher crash."""
    if not _verdict_disagree_enabled():
        print("  verdict-disagree: disabled via EPM_DISABLE_VERDICT_DISAGREE_OBSERVER; skipping")
        return False
    try:
        from explore_persona_space.task_workflow import (
            list_events, registry_path, unreconciled_disagreement_rounds)
        reg = json.loads(registry_path().read_text())
        tasks = reg.get("tasks") if isinstance(reg, dict) else None
        if not isinstance(tasks, dict): ...  # stderr + return False
        now = time.time(); reg_root = registry_path().parent.parent
        state = _load_verdict_disagree_state(); wrote = False
        for id_str, meta in sorted(tasks.items()):
            issue = _triage_observer_sweep_issue(
                id_str, meta, reg_root, now, VERDICT_DISAGREE_LOOKBACK_H * 3600.0)
            if issue is None: continue
            flagged = <type-guarded read of state[str(issue)]["flagged"]>
            try:
                events = list_events(issue)
                findings = unreconciled_disagreement_rounds(
                    events, now_ts=now,
                    grace_s=VERDICT_DISAGREE_GRACE_S,
                    pair_proximity_s=VERDICT_DISAGREE_PAIR_PROXIMITY_S,
                    evidence_lookback_s=VERDICT_DISAGREE_EVIDENCE_LOOKBACK_S)
            except Exception as exc:  # per-issue fail-soft
                print(f"  verdict-disagree: #{issue} evaluation failed: {exc}", file=sys.stderr)
                continue
            for f in findings:
                if f["key"] in flagged: continue
                print(f"  verdict-disagree: #{issue} {f['role']} {f['round_label']} — "
                      f"Claude {f['claude_class']} vs Codex {f['codex_class']}")
                _append_verdict_disagree_sidecar({"issue": issue, **f}, dry_run)
                _telegram_push(
                    f"verdict-disagree-observer: #{issue} {f['role']} {f['round_label']} — "
                    f"Claude {f['claude_class'].upper()} vs Codex {f['codex_class'].upper()}, "
                    "no role-matched reconcile + no no-show evidence (#825 shape) — "
                    "observe-only; see .claude/cache/verdict-disagree-observer-events.jsonl",
                    dry_run)
                flagged.add(f["key"]); wrote = True
            if flagged:
                state[str(issue)] = {"flagged": sorted(flagged)[-_VERDICT_DISAGREE_FLAGGED_KEY_CAP:]}
        <self-prune state entries at completed/archived, mirror triage 4227-4233>
        _save_verdict_disagree_state(state, dry_run)
        return wrote
    except Exception as exc:  # top-level fail-soft: never take down the watcher tick
        print(f"  verdict-disagree: pass failed (fail-soft): {exc}", file=sys.stderr)
        return False
```

Note on the exception guard: `main()` calls passes bare (verified at lines 18852–18890 — no outer try), and the triage observer guards only its individual I/O sites, so this pass carries BOTH per-issue guards and a top-level `except Exception` (the "an observer crash must never take down the watcher" requirement, made explicit rather than inherited).

## 9. (§11) Decision Rationale

- **(a) Grace window 3600 s (`EPM_VERDICT_DISAGREE_GRACE_S`).** What: no flag until ≥60 min after the LATER verdict. Why: reconciler spawn + adjudication needs time; #825's reconcile landed 10 min after the later verdict, so 60 min is ~6× the observed latency; a slow reconcile beyond it costs one false push (cheap, self-documenting). Source: #825 events (10-min gap). Alternatives: 120 s (triage's grace — wrong construct: that binds an adjacency clause, not a subagent round); 90 min (rejected: alert latency doubles for marginal false-positive reduction; env-tunable anyway).
- **(b) Evidence lookback 7200 s before the earliest pair verdict.** What: no-show evidence counts only from `min(pair_ts) − 2 h` onward. Why: review rounds observed at 1–7 min pair gaps and ≤ ~1 h spawn-to-verdict; 2 h covers a quota-skip note posted at round start plus a slow round, while excluding stale evidence from prior rounds (which would silently blind the observer forever after one Codex outage). Source: #825 round timings (04:32→04:33; 12:12→12:16; 08:33→08:35); #1153's skip-note placement. Alternatives: unscoped evidence (rejected: one historical `epm:codex-task-failed` would permanently suppress the site); round-boundary scoping (rejected: previous-round boundaries are unreliable under version drift).
- **(c) Pair proximity 21600 s (6 h).** What: the two verdicts must be within 6 h to count as one logical round. Why: same-round pairs land minutes apart (worst realistic case: a thrash-respawned reviewer, ~1–2 h); distinct epochs on #825 were ≥8 h apart; 6 h separates the regimes with margin on both sides and kills the cross-epoch false pairs that sentinel-restart + latest-match-wins can produce. Source: #825 event spacing. Alternatives: 1 h (rejected: a respawned twin would exceed it); no bound (rejected: demonstrated false-pair channel).
- **(d) Dedup key `(issue, role, round_label)` in a fire-once state singleton.** Why: one alert per unreconciled round is the audit contract; a persistent unreconciled round must not re-push every 10 min. Source: `_triage_observer` flagged-keys precedent (#967), key-cap 400. Alternatives: ack-sentinel re-alerts (rejected — the cpu-guard note explains ack machinery is for persistent conditions needing re-triage; this is a fixed historical record).
- **(e) Latest-round-only per (issue, site).** Why: superseded disagreements are moot for alerting, and historical round re-derivation is unreliable under the observed sentinel/version drift; the fail-quiet direction is correct for an alert channel. Source: #825's 7-version code-review history. Alternatives: all-rounds audit (rejected: false-pair generation + alert spam on legacy corpora).
- **(f) No `epm:progress` nudge marker (divergence from the triage observer).** Why: the task body specifies sidecar + deduped alert only; the triage observer's marker exists because its flag is machine-consumed at the next dispatch (`by="unknown"` triage candidate), whereas this flag's consumer is a human — a marker would add the git-committing subprocess, a marker cap, and liveness-clock considerations for zero mechanical consumer. Source: task #1170 body; `_triage_observer_nudge` docstring (asw.py:3990–3999). Alternatives: capped nudge markers (rejected as above; revisitable in a follow-up if a mechanical consumer appears).
- **(g) Malformed verdict (present, `verdict=None`) is not flaggable and blocks Tier 2.** Why: `ensemble_verdicts_present` classifies that as malformed-output handling, NEVER a no-show (#810 r4); a disagreement requires two parseable verdicts, and Tier-2 would just re-find the same events. Source: task_workflow.py:1665–1668. Alternatives: treating malformed as FAIL-class (rejected: fabricates a verdict).
- **(h) Pure predicate lives in `task_workflow.py`.** Why: it composes `ensemble_verdicts_present` + the module-private `_sentinel_round`/`parse_followup_note_field`; the project pattern puts event-analysis predicates there with tests (`audit_dispatch_triage`, `circuit_breaker_should_fire`) and keeps the watcher a thin I/O wrapper. Source: #967's split (analysis in task_workflow, wiring in asw). Alternatives: module-level in asw.py (workable, but would force re-implementing/importing private helpers across files).

Source: task_workflow.py:1670–1671 docstring. Alternatives: parse workflow.yaml at runtime (rejected: I/O in a pure function, yaml dep in the library import path).
- **(j) Sweep bound: reuse `_triage_observer_sweep_issue` (ACTIVE ∪ {awaiting_promotion, blocked}, 48 h events-mtime lookback).** Why: identical consumer profile (review markers fire at active statuses; `awaiting_promotion` is where the final clean-result rounds park; the recency gate bounds per-tick cost); reuse-over-copy is the standing in-repo-tools rule.
