# Plan v1 — #2129: guard against `claude-fable-5[1m]` re-planting in `~/.claude/settings.json`

**Kind:** infra (wf-fix; `workflow_fix_target: scripts/autonomous_session_watch.py`)
**Estimated GPU-hours (total): 0**

## 1. Goal + context

The built-in `/model` command (and any harness settings write) can persist the model id
`claude-fable-5[1m]` into `~/.claude/settings.json`. Fable/Mythos are 1M-native and expose NO
`[1m]` variant, so that id kills every subagent fleet-wide (#545, ~72h outage; commit
d07424178). Nothing watches the GLOBAL settings files today — `workflow_lint.py`'s
`AGENT_MODEL_ALLOWLIST` covers only project agent files. Confirmed live recurrence this
session (2026-08-13): `"model": "claude-fable-5[1m]"` was present at line 13 of
`~/.claude/settings.json` (re-planted since 2026-08-06) and was hand-normalized as an
emergency fix (`epm:progress` v2 on #2129). This plan makes the fix durable: a watcher pass
that detects and AUTO-NORMALIZES the bad id class each 10-min tick, with a deduped alert
trail. The task body pre-resolves both design forks: watcher arm (a) over SessionStart hook
(b), and auto-normalize over alert-only (byte-exact single-known-bad-string rewrite;
outage-class blast radius).

## 3. Design (per the watcher pass conventions, modeled on `codex_outage_pass` L10994-11120)

**Signature:** `settings_model_guard_pass(dry_run: bool, paths: list[Path] | None = None) -> bool`
— daemon-INDEPENDENT; returns True when anything fired. `paths=None` resolves to
`[~/.claude/settings.json, ~/.claude/settings.local.json]`; the param exists for test
injection (no env path override — tests inject directly).

**Detection:** per file (missing file → silent skip): read raw text; parse JSON. Walk ALL
string values recursively (covers `model`, `env.CLAUDE_CODE_SUBAGENT_MODEL`, and any future
key) and collect values matching
`re.compile(r"^claude-(?:fable|mythos)-[A-Za-z0-9.\-]*\[1m\]$")`.
SCOPE IS FABLE/MYTHOS ONLY — Opus 4.5–4.8 legitimately takes `[1m]` (SOUL.md § Models);
`claude-opus-*[1m]` is never touched. Normalization = strip the trailing `[1m]`.

**Rewrite (byte-exact, format-preserving):** for each distinct bad value, textual
replacement of the exact quoted JSON string `"<bad>"` → `"<normalized>"` in the raw text
(never a `json.dumps` re-serialize of the whole file — preserves the harness's formatting).
Post-conditions before writing, all mandatory (fail → alert-only, no write): (i) new text
parses as JSON; (ii) re-walk finds zero bad ids; (iii) parsed structure equals the old
structure except at the replaced string leaves. Write = backup copy to
`~/.eps-autonomous/settings-model-guard-backup-<epoch>-<filename>` first, then atomic
tmp + `os.replace` in the same directory. Worst-case race with a concurrent harness write:
the harness overwrites after us; the next 10-min tick re-normalizes — converges.

**Unparseable JSON:** if raw text matches the bad pattern but `json.loads` fails →
ALERT-ONLY (sidecar + push), never write. **Write failure:** alert-only row, never raise
out of the pass (watcher passes are fail-soft).

**Channels:** sidecar row per event to `.claude/cache/settings-model-guard-events.jsonl`
(`{ts, path, bad_values, action: normalized|alert-only|dry-run, ok, reason?}`);
`_telegram_push` fail-soft. Push policy: every NORMALIZED event pushes (each is a discrete
re-planting of an outage-class id — rare by construction, and the push names the file, the
bad value, and the rewrite applied); alert-only conditions (unparseable/write-failure)
dedup per (path, sorted bad-values) episode with re-alert TTL
`EPM_SETTINGS_MODEL_GUARD_REALERT_H` (default 24h, `_env_float`-bounded), state at
`~/.eps-autonomous/settings-model-guard.json`. NO task markers (fleet-level concern, no
single owning task — matches `codex_outage_pass` / `root_draft_pass`).

**Throttle:** none — two <10 KB file reads per 10-min tick; detection latency is the point
(#545 blast radius). **Kill switch:** `EPM_DISABLE_SETTINGS_MODEL_GUARD_PASS=1`, checked
first. **dry_run:** detect + sidecar (`action: dry-run`) + stdout line; no write, no push.

**main() wiring:** production call `settings_model_guard_pass(args.dry_run)` placed with
the other daemon-independent escalate-only passes (adjacent to `codex_outage_pass`'s call);
`--settings-model-guard-only` handler in the debug-flag region (debug flags are not counted
as passes).

**Docstring:** header "37 passes" → "38 passes"; new numbered item
`38. **Settings model-id guard pass (#2129; AUTO-NORMALIZE + alert; daemon-INDEPENDENT; kill switch EPM_DISABLE_SETTINGS_MODEL_GUARD_PASS)** — ...`
following the stable-identifier item grammar.

## 4. Tests (`tests/test_settings_model_guard.py`)

Import via the established `sys.path` pattern from `tests/test_autonomous_session_watch.py`;
monkeypatch `_telegram_push`, sidecar/state paths (module constants or tmp_path-injected),
and use the `paths=` param with tmp files. Roster:

1. `test_normalizes_fable_1m_model_key` — `"model": "claude-fable-5[1m]"` → normalized in
   place, file parses, other keys + formatting preserved, backup file exists, returns True.
2. `test_normalizes_mythos_and_nested_env_value` — `claude-mythos-5[1m]` under
   `env.CLAUDE_CODE_SUBAGENT_MODEL` → normalized (recursive walk evidence).
3. `test_opus_1m_never_touched` — `"model": "claude-opus-4-8[1m]"` → NO write, returns False.
4. `test_clean_file_noop` — clean settings → no write (bytes identical), no push, False.
5. `test_dry_run_detects_without_writing` — bad id + `dry_run=True` → bytes unchanged,
   sidecar row `action: dry-run`, no push.
6. `test_kill_switch_disables` — env set → immediate False, no reads recorded/no rows.
7. `test_unparseable_json_alert_only` — invalid JSON containing the bad substring → bytes
   unchanged, sidecar row `action: alert-only`, push fired (first episode), True.
8. `test_alert_only_dedup_within_ttl` — second invocation same episode → no second push.
9. `test_missing_files_silent` — both paths absent → False, no rows.
10. `test_docstring_lint_stays_green` — invoke
    `workflow_lint.check_asw_docstring_pass_count` (import pattern per
    `tests/test_workflow_lint.py`) → no findings.

## 7. Risks + assumptions

- **Outside-the-worktree mutation is the task's sanctioned Goal** (user-filed via the
  /daily sweep; body explicitly prefers auto-normalize). The write is bounded: only the
  exact matched bad-string leaves, backup + atomic replace, fable/mythos scope only.
- Assumption: `settings.local.json` may not exist (skip-silent covers it).
- Assumption: the harness tolerates an external atomic rewrite of settings.json between
  its own reads (it re-reads per session; mid-session model is env/CLI-resolved).
- Residual (accepted): a bad id planted in a NON-string position or a different file
  (e.g. a project `.claude/settings.json`) is out of scope v1; the sidecar/push trail
  makes recurrence visible for a follow-up.
