## §11 Decision Rationale

- **Reuse `min_k = TICK_WEDGE_MIN_DEQUEUED = 3` for the enqueue run (no new constant).** *Why:* the run counts the same event species (prompt-delivery records with no turn); 3 never-consumed enqueues at the 45-min tick cadence ≈ 90–135 min — inside the body's asked-for band once the 60-min lazy gate is counted, and tolerant of 1–2 spurious rows exactly as #845 calibrated. *Source:* #845 (commit `fe8f3d73f8`, constant comment lines 1183–1191, grounded on the #779 incident shape). *Alternatives:* a separate lower threshold (rejected — a 2-enqueue trigger ≈ 45–90 min would fire inside legitimate long review turns whose self-reports lag; no incident motivates it); a new env var (rejected — one knob, two symmetric runs).
- **Enqueue-only parallel run, NOT mixed into the existing dequeue/prompt run.** *Why:* mixing would double-count each #779-shape cycle (enqueue+dequeue) and silently halve the existing lane's calibrated tolerance. *Source:* #845's explicit "tolerating 1-2 spurious rows" calibration note (line 1186). *Alternatives:* mixed run (rejected above); `dequeue` resetting the enqueue run is load-bearing — consumption disproves the frozen-mid-turn hypothesis and the dequeue class owns that shape.
- **Keep `STALLED_WINDOW_S=60min`, `K=2`, the 2h marker window unchanged.** *Why:* each is incident-grounded against false-positive kills (#761/#763 legitimate 60–120-min marker gaps; #812 killed 57s after an edit; #833 healthy 2h fit killed) and no 07-03 incident evidences a mis-set value. *Source:* #759, #845 task bodies + in-file grounding comments. *Alternatives:* shrink the window / K (rejected — trades demonstrated false-positive incidents for an undemonstrated latency win).
- **Rejected: transcript-mtime / "last-API-turn age" as a standalone respawn signal** (the body's other named signals). *Why rejected:* a healthy end-of-turn session awaiting a long detached compute poll legitimately writes nothing for hours (the PRESCRIBED #833 pattern), and marker recency is already in the detection basis (#845 a-i); the queue-record signature dominates it — it distinguishes "prompts arriving but never consumed" from "legitimately quiet". *Source:* #833 incident + code-style § detached VM-side compute; #845(a-i).
- **Rejected: `_has_claude_descendant` probe to bypass the K-downgrade for dead-inner-loop wrappers.** *Why rejected:* K counts ticks, so the downgrade costs ~10–20 min; no 07-03 alert is attributable to it (all 16 decompose per §2); the zombie-wrapper pass already reaps the ≥2h class. *Source:* measured incident data this session; code line 4644.
