Mechanics, each probe-verified this session in a scratch repo (`/tmp/eps2385_git_probe.sh`, output `PROBE-OK`):

- `git diff --name-only --diff-filter=A origin/main -- $SAFE_SPECS` enumerated exactly the main-deleted glob twin (nothing else), with `:(glob)` pathspec magic honored.
- `git rm -q --` staged the deletion; `git diff --quiet HEAD -- $SAFE_SPECS` went non-quiet on the deletion alone, so the EXISTING commit-fire condition covers a deletion-only sync.
- `git commit -m "<anchor subject>" -- $SAFE_SPECS` with the glob pathspec committed the `D` row alongside the `M` row in ONE commit (verified via `git show --name-status`).
- The payload guarantee at family grain: a branch-new glob-matched file's commit appears in `git log $MB..HEAD -- ':(glob)tests/test_workflow_lint*.py'` after the awk exclusion, so pass 1 marks the family dirty and pass 2 excludes it — the removal arm never sees a family containing payload. Probe-verified (non-empty bs output on the payload commit).

Exact payload predicate (hard constraint 1): a candidate `p` is payload iff `git log --format='%H %s' "$MB"..HEAD -- "$p"` contains any commit whose subject lacks the anchor `sync workflow-surface specs from` (the identical probe + exclusion pass 1 uses, #1789 subject-shape convention). This is enforced twice: at family grain by pass-1/pass-2 (any such commit anywhere under the pathspec parks the whole family), and per-file inside the arm. A file whose only `$MB..HEAD` history is prior sync commits is main-imported content, not payload, and is removable — the correct reading (main put it there; main deleted it). The body's "present in the branch's own-diff vs merge-base" wording is implemented via this subject-scoped form because a raw own-diff would misclassify prior sync imports as payload and strand them forever.

Dirty-family absoluteness (hard constraint 2): candidates are enumerated with `-- $SAFE_SPECS` only. `SAFE_SPECS` is pass-2's output (non-dirty families only), so a dirty family syncs nothing AND deletes nothing, structurally. The literal-member-deleted case (#2260 containment) marks the family dirty BEFORE pass 2, so it also never reaches the arm.
