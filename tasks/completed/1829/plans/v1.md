```python
# CRITICAL: load_dotenv() BEFORE importing numpy/matplotlib — the shared-VM
# thread caps (#847) bind in-process only when set before the first BLAS/
# torch import freezes the pools.
from explore_persona_space.orchestrate.env import load_dotenv

load_dotenv()

import numpy as np  # noqa: E402
```

  `from pathlib import Path` stdlib block and `import numpy as np`; the
  subsequent `from explore_persona_space.analysis.paper_plots import ...`

  caps must bind before it).
- `issue1738_analyzer_figures.py`: preamble inserted between the stdlib block
  and `import matplotlib.pyplot as plt`; the matplotlib/numpy/paper_plots
  imports gain `# noqa: E402`.

  the `sys.path.insert` block, before `import numpy as np` (that file's later
  imports already carry `# noqa: E402`). `orchestrate.env` is importable from
  the installed package — no dependency on the sys.path inserts.
