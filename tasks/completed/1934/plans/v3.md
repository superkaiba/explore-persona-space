## 4. Design / file paths + concrete changes

### 4.1 `src/explore_persona_space/eval/utils.py::parse_judge_json` (MODIFY)

Recovery ladder (order is load-bearing; steps 1–2 are today's behavior, byte-for-byte
precedence):

1. `json.loads(text)` verbatim (scalar passthrough) — unchanged.
2. `raw_decode` at `text.index("{")` — unchanged; success returns identically to today
   (strict widening guarantee).
3. NEW — unified candidate recovery (v2, critic SF1: ONE largest-wins pool, not
   fence-first): collect candidates from BOTH (a) every ```-fenced block (```json or
   bare ```), attempting `json.loads(block.strip())`, and (b) `raw_decode` at subsequent
   `{` offsets (bounded: at most the first ~200 candidate offsets, guarding pathological
   inputs). Return the LARGEST successful decode by consumed raw-span length (guards
   against a small valid JSON fragment or fenced preamble snippet shadowing the real
   object); ties break to the earliest.
4. `None` + the upgraded warning (R3).

## 7. Kill criteria

- p0b lineage gate failure → HALT, no spend (stale/mismatched pipeline code — the
  recovery would run a third instrument; port or consult the run commit first).
- p2 parity gate mismatch → HALT, no spend (evidence drift).
- p3 gate: `n_parse_fail_nonempty / n_nonempty >= 0.20` → HALT + investigate before the
  USD 175 axes leg (the parser fix or the instrument is wrong).
- The thesis (parse failures are recoverable format failures) is falsified if the
  fixed parser recovers < 30% of fresh non-empty responses that still fail today's
  parser in unit fixtures — would mean the mechanism diagnosis is wrong; stop and
  re-diagnose before any spend.
- Decision (v3, autonomous): NO refusal re-draw round. Re-drawing refusal-stopped
  describe items (extra attempts beyond production's 1 draw) is a §10 must-ask
  instrument deviation; the recovery keeps production parity and reports the
  refusal-stopped population as a classified residual. A re-draw round is parked as a
  candidate follow-up for #1773's owner, named in the #1773 provenance note.
