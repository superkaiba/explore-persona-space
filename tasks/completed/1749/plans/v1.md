# Plan v1 — task #1749: relaunch rounds re-run the compute-character check

## Goal / Requirement

A crash-fix relaunch (or pod-side hotfix relaunch / descope relaunch) whose fix
changes the workload's compute character — engine, device routing, parallel
width, or per-unit scope — must RE-STATE its compute character in the relaunch
record BEFORE dispatch, so a CPU-at-width-1 relaunch on a multi-GPU pod is
caught at dispatch time instead of ~14 h of idle GPU later.

**Incident (grounded):** #1689 r15b (2026-07-27/28) — an unrecorded pod-side
hotfix relaunch swapped the Phase-D fit to serial numpy on CPU at width 1 while
the 4×H100 pod billed at ~0% GPU for ~14 h (two gpu-idle escalations);
`epm:compute-deviation v3` (2026-07-28T00:30:12Z) records ratio 32× MEASURED
mid-run (v4 corrected to 11×). The compute-character pre-launch statement duty
exists for the plannerless inline paths (SKILL.md Step 9a-ter; CLAUDE.md
user-chat carve-out) but `.claude/rules/crash-fix-rounds.md`'s relaunch
contract never requires it (`grep -c 'compute-character'
.claude/rules/crash-fix-rounds.md` → 0, re-verified at clarify time).

## Method delta (what differs from prior related work)

- The existing `.claude/rules/crash-fix-rounds.md` § "Crash-fix relaunch:
  fix-commit ancestry + stale-checkpoint hygiene" carries relauncher-side
  duties 1 (fix-commit ancestry) + 2 (stale-checkpoint disposition) plus the
  #1346 width-re-evaluation paragraph. The width paragraph fires only on
  embarrassingly-parallel unit grids and only re-evaluates WIDTH; it does not
  cover an engine/device/scope swap (the #1689 shape: torch/GPU → numpy/CPU).
- This change adds relauncher-side **duty 3: compute-character re-statement**,
  scoped to relaunches whose fix (or whose relaunch configuration) CHANGES the
  compute shape, referencing the canonical five-element statement
  (`.claude/skills/issue/SKILL.md` Step 9a-ter § Compute-character pre-launch
  statement) restricted to the delta. No new marker kind — the statement rides
  the fresh `epm:run-launched` note (or the `epm:compute-deviation` re-post),
  the existing note-token convention.
