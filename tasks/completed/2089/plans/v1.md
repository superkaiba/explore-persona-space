## 1. Requirement + acceptance criteria

**Requirement.** `PHASE_DONE_WAIVER_RE` (scripts/workflow_lint.py:9964) accepts
ONLY the `# noqa: phase-done-reserved` waiver form. That token lives inside
ruff's `# noqa` namespace, so ruff flags every legitimately-waived phase script
with a permanent "Invalid `# noqa` directive" warning (12 sites on #2054 alone),
and reviewers keep flagging load-bearing waivers as fixable cosmetics (#2054 r10
Minor; the r11 conversion attempt broke `--check-phase-done-reserved` and was
reverted). Accept a ruff-clean alias `# workflow-lint: phase-done-reserved`
alongside the legacy form, and document the alias as preferred for new waivers.

**Acceptance criteria.**

1. `PHASE_DONE_WAIVER_RE` matches BOTH `# noqa: phase-done-reserved` and
   `# workflow-lint: phase-done-reserved` (same placement convention: emission
   line or immediately preceding non-blank line; trailing mode/invoker prose
   after the token still allowed by the regex, unchanged).
2. All 14 existing live call sites keep passing the check unchanged (legacy
   form stays honored — backwards compatible by design; NO call-site migration
   in this task).
3. New pin tests: an alias-waived `.py` emission line passes (emission-line AND
   preceding-line placements), an alias-waived `.sh` emission line passes, and
   an unwaived reserved emission still FAILs (existing tests already pin the
   FAIL side).
4. The check's user-facing text (error message at ~workflow_lint.py:10415,
   check docstring, argparse help, regex-adjacent comment) names the alias as
   the PREFERRED form for new waivers and the `# noqa:` form as legacy-honored.
5. `.claude/rules/pod-side-reporting.md` requirement 1 documents the waiver
   grammar with the alias preferred (it currently names the check + hook but
   not the waiver form).
6. `uv run pytest tests/test_workflow_lint_phase_done_check.py` fully green;
   `uv run python scripts/workflow_lint.py --check-phase-done-reserved` exits 0
   on the live tree; ruff clean on touched-file added lines.

## 2. Method delta

Pure grammar-widening of one regex plus documentation. No behavior change for
any existing waiver or any unwaived emission: the alternation
`(?:noqa:|workflow-lint:)` is a strict superset of the current grammar. The
`# workflow-lint:` prefix is outside ruff's `# noqa` parser, so alias-form
waivers emit no ruff warning. Prior art: none needed — this is the exact diff
sketch from the filed candidate block, refined with the concrete secondary
text surfaces enumerated below.
