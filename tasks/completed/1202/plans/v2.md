### 4.1 Design decisions (the seven the brief requires)

1. **Check name + flag:** function `check_hub_verify_retry(*, scripts_dir: Path | None = None)`, flag `--check-hub-verify-retry`, **bundled into the no-flags default run** (same policy as `check_batch_judge_client`; wiring: argparse `add_argument`, membership in the `no_flags` negation tuple at workflow_lint.py:9590, and a `if args.check_hub_verify_retry or no_flags:` dispatch line — all three verified as the registration pattern at 9205/9611/9712).
2. **Detection (AST, not regex — the false-positive strategy):** target symbols `HUB_VERIFY_BARE_TARGETS = ("list_repo_files", "list_repo_tree", "file_exists")` (`list_repo_tree` added in v2 — gotchas.md:222-239 names it as the SAME un-retried pagination class and the #833 guidance actively steers new large-repo verify legs toward it). Walk `_cached_parse(py, text)` (existing helper, workflow_lint.py:2020) and flag, deduped by line:
   - any `ast.Attribute` node with `node.attr in HUB_VERIFY_BARE_TARGETS` — covers `api.list_repo_files(...)`, `HfApi().list_repo_tree(...)`, `import huggingface_hub as hh; hh.list_repo_files(...)`, and the bare-reference form passed to a retry wrapper/`to_thread` (mirrors `_is_batches_create_attr`, workflow_lint.py:5605);
   - any `ast.Name` node whose `id` matches a BOUND name of a target symbol imported from huggingface_hub — the `ast.ImportFrom` pre-pass builds `{(a.asname or a.name): a.name for a in node.names if a.name in HUB_VERIFY_BARE_TARGETS}` for modules starting with `"huggingface_hub"`, so BOTH `from huggingface_hub import list_repo_files` + `list_repo_files(...)` AND the aliased `from huggingface_hub import list_repo_files as lrf` + `lrf(...)` are caught (v2: asname handling per the methodology + alternatives critiques). This gates the Name form so a script-local `def file_exists(...)` helper is never flagged.
   - Comments and docstrings can never false-positive: AST has no comment nodes and a string mention is an `ast.Constant`, not Attribute/Name. `hub.list_hf_files_under_path` / `list_repo_files_complete` / `verify_repo_paths_uploaded` are different attr/name strings — compliant hub-helper usage is structurally invisible to the detector (this IS the "routed through the retried helpers" operationalization: within `scripts/`, ANY spelled bare call is presumed un-retried; even a script-local `retry_transient(lambda: api.list_repo_files(...))` is flagged, deliberately — the wrapped bare attribute is still a hand-rolled leg, and a genuinely-correct raw call takes the waiver comment). 3. **Scan scope:** `<repo_root>/scripts` rglob `*.py` only (recursive — nested dirs like `scripts/issue_355/` exist and are covered; `rglob` never descends into `__pycache__` for `*.py`, and non-parsing files stay silent per the `_cached_parse` None branch, precedent 5696-5698). **`src/` excluded:** #997 owns the library path, and `hub.py` itself legitimately spells the bare calls inside its retry wrappers — scanning src/ would force sanctioned-file machinery for zero benefit; the task body scopes the gate to "NEW scripts/ files". **`.sh` excluded:** the batch-judge precedent is `.py`-only (`rglob("*.py")`, 5681); AST cannot parse shell heredocs and a regex leg would reintroduce exactly the comment/string false positives the AST approach avoids. 4. **Grandfather allowlist:** `HUB_VERIFY_LEGACY_ALLOWLIST: frozenset[str]`, repo-root-relative POSIX paths, matched exactly (`rel in ...`), **frozen at land-time tree**. Estimated membership: ~100 files — the 80-file union of the `list_repo_files(` (74 files) + `.file_exists(` (6 files, disjoint) greps, plus the additional files among the 40+ carrying `list_repo_tree(` occurrences (v2) — but the implementer generates the FINAL set from the check itself (write the check with an empty allowlist, run it on the live tree, capture the flagged rel paths), so the frozen set exactly matches AST-confirmed call sites (a comment-only grep hit would not be flagged and must not be allowlisted). def _hub_verify_waiver_present(lines: list[str], call_lineno: int) -> bool:
    # verbatim clone of _batch_judge_client_waiver_present with the
    # HUB_VERIFY_* constants

HUB_VERIFY_BARE_TARGETS = ("list_repo_files", "list_repo_tree", "file_exists")

def _hub_verify_bare_hits(tree: ast.Module) -> list[tuple[int, str]]:
    """(lineno, pattern) for bare list_repo_files/list_repo_tree/file_exists nodes.
    Name-form hits require a `from huggingface_hub import <symbol> [as alias]` —
    matched on the BOUND name (asname-aware, v2)."""
    hf_bound: dict[str, str] = {}   # bound name -> canonical target symbol
    for node in ast.walk(tree):
        if isinstance(node, ast.ImportFrom) and (node.module or "").startswith("huggingface_hub"):
            for a in node.names:
                if a.name in HUB_VERIFY_BARE_TARGETS:
                    hf_bound[a.asname or a.name] = a.name
    hits: list[tuple[int, str]] = []
    for node in ast.walk(tree):
        if isinstance(node, ast.Attribute) and node.attr in HUB_VERIFY_BARE_TARGETS:
            hits.append((node.lineno, f".{node.attr}("))
        elif isinstance(node, ast.Name) and node.id in hf_bound:
            hits.append((node.lineno, f"{hf_bound[node.id]}("))
    return hits

def check_hub_verify_retry(*, scripts_dir: Path | None = None) -> list[str]:
    """<docstring per (a), incl. the .sh residual + test-override hook note>"""
    root = scripts_dir if scripts_dir is not None else _REPO_ROOT / "scripts"
    errors: list[str] = []
    if not root.exists():
        return errors
    for py in sorted(root.rglob("*.py")):
        if not py.is_file():
            continue
        try:
            rel = py.resolve().relative_to(_REPO_ROOT.resolve()).as_posix()
        except ValueError:
            rel = py.as_posix()          # unit-test fixture tree (precedent 5686-5689)
        if rel in HUB_VERIFY_LEGACY_ALLOWLIST:
            continue
        text = py.read_text(encoding="utf-8")
        tree = _cached_parse(py, text)
        if tree is None:
            continue                     # non-parsing file: separate problem, stay silent
        lines = text.splitlines()        # known-ASCII-boundary source-code split: fine per gotchas

        for lineno, pattern in _hub_verify_bare_hits(tree):
            if lineno in seen:

            seen.add(lineno)
            if _hub_verify_waiver_present(lines, lineno):
                continue
            errors.append(f"{py}:{lineno}: <message per §4.1 item 6, naming {pattern}>")
