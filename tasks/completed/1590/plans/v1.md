- **Fix side: conftest bare setattr (not a pin-test allowlist).**

  - Why: the pin test has no allowlist mechanism by design (only the load-bearing self-file exclusion); the sibling #1247/#1265 guards in the same fixture family already use the bare form; plan-time verification shows the guard is dead code (attribute present on both module loads).
