## 10. Risks + mitigations

1. **Guard argument drift** (guard checks a different folder/prefix/pattern set
   than the upload) — mitigated by passing the SAME expressions, and at site 3
   by hoisting the shared `allow` list so the two calls cannot diverge.
2. **A guard raise turning a healthy upload into a crash** — the cap is 10,000
   files per target repo dir (strict `>`); #2220's dirs are orders of magnitude
   below it, and `_upload_judge_outputs` already packs `judge_cache` into jsonl
   shards precisely to stay under it. Failure mode if it ever fires is
   fail-loud-before-network with data still local, which is the intended
   behavior.
3. **`load_dotenv()` changing figure output** — it only sets env defaults
   (thread caps + credentials); `setdefault` never clobbers an explicit env, and
   the module's plotting is deterministic w.r.t. thread count.
4. **ruff auto-fix stripping the new `# noqa: E402`** — the PostToolUse ruff
   hook runs `check --fix` + `format`; E402 is not auto-fixable and the noqa is
   what silences it. Verified by §4 step 4 after the edit lands.
5. **Landing on main matters more than usual** — this is a main-red fix, so the
   Step 10d merge is the deliverable; a fix that stays on the worktree branch
   leaves the fleet red. Terminal check: re-run §4 steps 1-2 against `main`
   after the merge.
