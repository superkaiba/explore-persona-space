### Step 2 — `check_hf_model_from_card` rewrite (the core)

Signature unchanged: `def check_hf_model_from_card(card: dict) -> dict | None`. Result schema unchanged (`status`/`url`/`detail`/`source` + `file_count` on OK). Pseudocode (real code follows this closely):

```python
def check_hf_model_from_card(card: dict) -> dict | None:
    repo = str(card.get("hf_model_repo") or HF_MODEL_REPO)

    # -- overrides: per-cell {cell_id: repo_id}; anything else is malformed --
    overrides_raw = card.get("adapter_repo_overrides")
    overrides: dict[str, str] = {}
    notes: list[str] = []          # visible diagnostics appended to detail
    if isinstance(overrides_raw, dict):
        overrides = {
            str(k): str(v).strip()
            for k, v in overrides_raw.items()
            if isinstance(v, str) and v.strip()
        }
        n_bad = len(overrides_raw) - len(overrides)
        if n_bad:
            notes.append(
                f"{n_bad} adapter_repo_overrides value(s) not a non-empty "
                "string — ignored (cell checked against the default repo)"
            )
    elif _is_declared(overrides_raw):
        notes.append(
            "adapter_repo_overrides is not a per-cell dict "
            f"({type(overrides_raw).__name__}) — ignored; every path checked "
            "against the default repo"
        )

    def _strip_repo_prefix(p: str, cell_repo: str) -> str:
        # #610 shape, generalized: strip the prefix of the repo this path
        # is CHECKED AGAINST. A path carrying a DIFFERENT repo's prefix
        # passes through verbatim and MISSes visibly (fail-loud).
        prefix = cell_repo.rstrip("/") + "/"
        if p.startswith(prefix) and len(p) > len(prefix):
            return p[len(prefix):]
        return p

    # -- collect (repo, path) pairs --
    pairs: list[tuple[str, str]] = []
    adapter_paths = card.get("adapter_paths")
    prose_violation: dict | None = None
    if isinstance(adapter_paths, dict):
        for cell, p in adapter_paths.items():
            cell_repo = overrides.get(str(cell), repo)
            pairs.append((cell_repo, _strip_repo_prefix(str(p), cell_repo)))
        orphans = sorted(set(overrides) - {str(c) for c in adapter_paths})
        if orphans:
            notes.append(
                f"{len(orphans)} adapter_repo_overrides key(s) with no "
                "matching adapter_paths cell (nothing checked for them): "
                + ", ".join(orphans[:5])
            )
    elif isinstance(adapter_paths, list):
        pairs.extend((repo, _strip_repo_prefix(str(p), repo)) for p in adapter_paths)
        if overrides:
            notes.append(
                "adapter_repo_overrides declared but adapter_paths is a "
                "LIST (no cell keys) — overrides unmatchable; every path "
                "checked against the default repo"
            )
    elif isinstance(adapter_paths, str) and _is_declared(adapter_paths):
        prose_violation = _prose_declaration_row("adapter_paths", adapter_paths)

    single = card.get("hf_model_path")
    if single:  # single path has no cell key -> default repo (stated behavior)
        pairs.append((repo, _strip_repo_prefix(str(single), repo)))

    pairs = list(dict.fromkeys(pairs))          # dedup on (repo, path)
    if not pairs:
        if prose_violation is not None:
            return _append_card_provenance(prose_violation, card)
        return None                              # unchanged fallthrough

    # -- existence checks --
    absent: list[str] = []
    errored = False
    total_files = 0
    for cell_repo, p in pairs:
        res = check_hf_hub_path(cell_repo, p, "model")
        if res["status"] == "OK":
            total_files += res.get("file_count", 0)
        else:
            errored = errored or res["status"] == "ERROR"
            label = p if cell_repo == repo else f"{cell_repo}/{p}"   # byte-compat
            absent.append(f"{label} ({res.get('detail') or res['status']})")

    # -- per-repo reporting; byte-identical when no override repos in play --
    override_repos = sorted({r for r, _ in pairs if r != repo})
    where = (
        repo
        if not override_repos
        else f"{repo} (default) + override repo(s): {', '.join(override_repos)}"
    )
    if absent:
        result = {
            "status": "ERROR" if errored else "MISSING",
            "url": "",
            "detail": (
                f"reproducibility_card declares {len(pairs)} model path(s) under "
                f"{where}; unresolved: " + "; ".join(absent[:5])
            ),
            "source": "epm:results reproducibility_card",
        }
    else:
        result = {
            "status": "OK",
            "url": f"https://huggingface.co/{repo}/tree/main",   # default repo; schema unchanged
            "file_count": total_files,
            "detail": (
                f"all {len(pairs)} model path(s) from the epm:results "
                f"reproducibility_card resolve on {where}"
            ),
            "source": "epm:results reproducibility_card",
        }
    if prose_violation is not None:
        result["detail"] = f"{result['detail']}; ALSO: {prose_violation['detail']}"
    if notes:
        result["detail"] = f"{result['detail']}; NOTE: " + "; NOTE: ".join(notes)
    return _append_card_provenance(result, card)
```

**Byte-compat argument (criterion 5):** with no overrides declared, `overrides == {}`, `notes == []`, every pair's repo == `repo`, so `where == repo`, every `label == p`, `pairs` order == today's `paths` order (dict-values order, then list order, then `hf_model_path`), dedup over `(repo, p)` with constant `repo` collapses to dedup over `p` — every branch reduces to the current strings and the current `check_hf_hub_path` call sequence.

**Explicit behavior decisions (brief item 1):**
- **LIST-form `adapter_paths` + overrides:** overrides cannot match (no cell keys) → all default repo + visible NOTE (never silent, never a crash).
- **`hf_model_path`:** no cell key → default repo, always. Stated in the updated docstring.
- **Orphan override key:** ignored for checking (nothing to check) but NAMED in a NOTE — a stale/typo'd key is producer-side drift the verifier agent should see, and silence is the #612 anti-pattern.
- **Non-dict overrides value (prose string / list):** safe fallthrough to default-repo checks + NOTE naming the malformed type. NOT a `_prose_declaration_row`-style MISSING row: unlike a prose `adapter_paths` (which leaves nothing checkable), the paths themselves remain fully checkable against the default repo; a MISSING row would over-fail cards whose overrides were cosmetic. If override cells really lived elsewhere they surface as ordinary MISSING entries WITH the note explaining why.
- **Override value == default repo:** `cell_repo == repo` → indistinguishable from no override (correct; `where` lists only repos that differ).
- **Docstring** updated to document the field, citing #1586 + this task.

## 11. Decision Rationale

N/A — no training hyperparameters

- **Per-cell dict resolution keyed on `adapter_paths` cells.** What: `overrides.get(cell, default_repo)`. Why: matches the producer exactly. Source: #1586 live card + `issue1586_dispatch.py::_reproducibility_card` (branch `issue-1586`); incident marker `epm:upload-verification` 2026-07-24T10:44Z. Alternative rejected: path-prefix inference (guessing the repo from the path string) — ambiguous and defeats the explicit declaration.
- **`(repo, path)` dedup.** What: dedup key widened from `path` to the tuple. Why: with per-cell repos the same path string under two repos is two distinct existence checks; collapsing them would skip one repo's check (a silent false-OK/false-MISS). Source: direct consequence of the #1586 two-repo split (#1108 overflow class); today's `dict.fromkeys(paths)` at line 772.
