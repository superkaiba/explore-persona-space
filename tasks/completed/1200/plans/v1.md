## 11. Decision Rationale

- **Launcher-INTERNAL pid write for BOTH targets (the one design decision).**
  - **What:** harmonize both memories to the launcher-internal shape — `echo $$ > /workspace/logs/issue-<N>.pid` inside the launcher before `exec`, launch line `setsid nohup ... < /dev/null &` — rather than the candidate's sketched launcher-EXTERNAL atomic form (`setsid nohup ... & printf '%s\n' "$!" > pid.tmp && mv`).
  - **Why:** (1) it is the contract's PREFERRED path — the launcher-external tmp+`mv` form is reserved for the RARE launcher-less relaunch (`pod-side-reporting.md` L173-185; `experimenter.md` L839-848), and BOTH memories already build a launcher script, so prescribing the external form would model the exception where the preferred path is available; (2) internal consistency — memory 1's own incident IS the `$!`-misfire (`$!` catching a stray background job); the `$$` write eliminates `$!` from the recipe entirely, which strengthens rather than merely patches the lesson, whereas the external form would keep `$!` in play; (3) post-`exec`, `$$` IS the real workload pid (the process the poller must probe), matching `experimenter.md` L762-765's rationale verbatim; (4) one canonical shape across both always-loaded memories minimizes future drift. For memory 2, the generic `exec "$@"` wrapper gains one hardcoded pid line — acceptable because the example already hardcodes `issue-N` paths throughout.
  - **Source:** `.claude/agents/experimenter.md` § During Execution steps 1/1b (L735-848, L926-936) + `.claude/rules/pod-side-reporting.md` § Pid-file launch contract (L164-215), both landed by #1070 (commit `b3fbb07d1b`).
  - **Alternatives:** launcher-external atomic form (the candidate's diff sketch, task body L34-38) — contract-conforming but models the rare-relaunch exception and keeps `$!` in memory 1's recipe; annotate-as-superseded (task body's fallback) — leaves a wrong recipe loaded verbatim into every experimenter context, weakest option.
- **`mkdir -p /workspace/logs` added to both launch sequences.** What: one line before launch. Why: the launcher-internal pid write (and the log redirect) require the dir; `experimenter.md` step 1 carries it (L769). Source: `experimenter.md` L769. Alternatives: omit (original blocks implicitly relied on the dir existing — a latent trap).

Why: the acceptance grep (task requirement) demands zero `echo $! >` hits under `.claude/agent-memory/`; meaning is preserved (the misfire is about `$!`, not about `echo`). Source: task #1200 body acceptance criterion.
