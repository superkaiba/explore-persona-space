## 1. Goal

Make the autonomous `/issue` code-review loop converge by scoping each round to the bug CLASS, not the cited line-instance. Today the primary `code-reviewer` has only per-instance gates and loads `code-reviewer/*` memory (not `reconciler/*`), so on any finding it reports the one cited instance and the siblings surface one-per-round ("whack-a-mole" — #779 produced ≥6 real blockers clustered in the raw-completions I/O subsystem, one per round). The sibling-scan discipline that fixes this already exists and is battle-tested (7 steps, 8 incidents) — it just lives in reconciler memory, which fires only after Claude and Codex already disagree. This task promotes it into the always-on reviewer + implementer path. Orthogonal to #784 (round-cap value + strip logic) — this is about per-round SCOPE, not the cap.

**Insert a new `### Step 3.7: Bug-class sibling sweep` section** immediately AFTER Step 3.5 (currently ends line ~614, before `### Step 4: Run / Verify Tests` at line ~616). Shape of the new section (implementer writes final prose from the source recipe):

```
### Step 3.7: Bug-class sibling sweep

For EVERY Critical/Major finding, the cited line is one INSTANCE — the
contract surface is the bug CLASS. Before issuing the verdict, enumerate
every sibling site of the class (adapt the 7-step recipe promoted from
`.claude/agent-memory/reconciler/feedback_claude_misses_same_file_siblings.md`):
1. grep the WHOLE file for the class pattern (e.g. `parsed.get("score", 0)`,
   per-persona vs global custom_id index, `raw_completions` write-without-upload,
   `except Exception`, sentinel reads, `max_tokens=`).
2. grep PARALLEL pod-side smoke / dispatcher scripts exercising the same DV /
   data contract.
3. sibling FILES sharing the finding's data-loading contract.
4. figure functions: every `ax.scatter`/`ax.plot`/`ax.fill_between` data dict.
5. sibling resampler/bootstrap/CI estimators (compare resample steps side-by-side).
6. exclusion constants / quality filters across the worktree.
7. sibling rubric/builder/handler families in the same file + their call sites.

Report ALL sibling hits under ONE `### Bug-class sweep: <class>` heading in
the verdict, each with `file.py:LINE`. A sibling that feeds a load-bearing
artifact is its OWN Critical (enumerate the locations); a sibling feeding only
secondary surfaces is a Real-but-non-blocking standing rec. A single-instance
fix that leaves load-bearing siblings unaddressed is the whack-a-mole failure
mode this step exists to prevent.
```

Also add a **Codex-twin sync note** at the end of the section (one sentence): "This step is inlined verbatim by the Codex twin (`codex-code-reviewer.md`) — keep both in sync." (Mirrors the existing per-section VERBATIM notes the twin file already keeps.)
