## Requirement (goal)

Name WORKTREES (`.claude/worktrees/*/`) as a REQUIRED location class in the
absence-claim relocation sweep, in BOTH surfaces that define it, and reconcile
explicitly with the `gotchas.md` rule that excludes worktrees from recursive
greps (`--exclude-dir=worktrees`, #1773) — the exclusion governs CONFIG greps
of `.claude/`; it does not license omitting worktrees from an EXISTENCE check.

**Incident basis (#1739 follow-up, 2026-08-05):** three false absence claims in
one session because the sweep covered only the repo-root tree; the judged
WildChat `dv_dataset` labeling.json files (2,000 rows/behavior) were untracked
in `.claude/worktrees/issue-1739/`, and one subagent was a step from
re-judging 10,000 rollouts.
