# Plan v1 — #2080 workflow-fix: worktrees are a required location class in absence sweeps

## Requirement (goal)

Name WORKTREES (`.claude/worktrees/*/`) as a REQUIRED location class in the
absence-claim relocation sweep, in BOTH surfaces that define it, and reconcile
explicitly with the `gotchas.md` rule that excludes worktrees from recursive
greps (`--exclude-dir=worktrees`, #1773) — the exclusion governs CONFIG greps
of `.claude/`; it does not license omitting worktrees from an EXISTENCE check.

**Incident basis (#1739 follow-up, 2026-08-05):** three false absence claims in
one session because the sweep covered only the repo-root tree; the judged
WildChat `dv_dataset` labeling.json files (2,000 rows/behavior) were untracked
in `.claude/worktrees/issue-1739/`, and one subagent was a step from
re-judging 10,000 rollouts.

## Acceptance criteria

1. CLAUDE.md's "Absence claims require a relocation sweep" clause (line ~172)
   names worktrees as a required location class with the BOUNDED-probe form
   (targeted `ls`/`find` on the specific expected path, or
   `git -C <wt> status --porcelain`; never an unbounded `grep -r` over
   worktrees) and states the reconciliation with the gotchas.md exclusion rule.
2. `.claude/rules/workflow-fix-on-bug.md` clause (b) (relocation grep, line
   ~438) adds the same worktree probe requirement in compressed form and notes
   `--exclude-dir=worktrees` on its `.claude/` grep (its current bare
   `grep -rn ... .claude/` violates the gotchas rule as written).
3. The pinned phrases survive: `relocation grep` in the rule file and
   `Absence claims require a relocation sweep` in CLAUDE.md
   (tests/test_daily_three_route_classifier_doc.py; CLAUDE.md pin tests).
4. No instruction anywhere tells agents to run unbounded recursive greps over
   worktrees.
5. `workflow_lint.py` (no-flags) + `--check-asks` show no NEW failures on the
   touched files; Step 9c mapped tests pass.
