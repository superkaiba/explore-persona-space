```python
def test_check_no_workflow_improver_spawn_hermetic_under_cache_nested_root(tmp_path):
    """A tmp repo rooted inside a directory literally named .claude/cache/ is
    still scanned — the cache/agent-memory exclusion matches relative to the
    repo root, not the absolute path (#1174: a repo-nested TMPDIR wholesale-
    excluded the whole tmp tree). Files genuinely under the tmp repo's OWN
    .claude/cache/ and .claude/agent-memory/ stay excluded."""
    outer = tmp_path / ".claude" / "cache" / "tmprepo"
    rules = outer / ".claude" / "rules"
    rules.mkdir(parents=True)
    (rules / "stray.md").write_text(
        'Agent(subagent_type="workflow-improver", run_in_background=true)\n'
    )
    cache = outer / ".claude" / "cache"
    cache.mkdir(parents=True)
    (cache / "planted.md").write_text(
        'Agent(subagent_type="workflow-improver", run_in_background=true)\n'
    )
    agent_mem = outer / ".claude" / "agent-memory"
    agent_mem.mkdir(parents=True)
    (agent_mem / "planted_mem.md").write_text(
        'Agent(subagent_type="workflow-improver", run_in_background=true)\n'
    )
    errors = check_no_workflow_improver_spawn(repo_root=outer)
    assert len(errors) == 1, errors
    assert "stale Agent" in errors[0]
    assert "stray.md" in errors[0]
```

## 11. Decision Rationale

N/A — no training hyperparameters (kind: infra). Non-hyperparameter decisions:

- **`startswith` on `relative_to(root)` vs keeping substring on absolute path.** Chosen: relative `startswith`. The exclusion's intent is "this repo's own `.claude/cache/` + `.claude/agent-memory/`"; an absolute-substring match additionally matches any ANCESTOR directory of `root` named `.claude/cache/`, which is exactly the hermeticity bug (probe: planted stray spawn under a `.claude/cache/`-nested root returned 0 errors). `startswith(".claude/cache/")` on the root-relative POSIX path is the minimal predicate that matches the intent and nothing else. Source: read `scripts/workflow_lint.py:5582-5595`; bug-repro probe (this session, §12 A1).
- **Sibling-pattern scope (grep before editing, per the task body).** Grepped `.as_posix()` + substring-exclusion idioms across `scripts/workflow_lint.py` (and the brief's prior grep across `scripts/` + `src/` found only this hit). Findings:
  1. **`workflow_lint.py:5588` — IN scope** (the fix above). The only `/.claude/cache/` + `/.claude/agent-memory/` absolute-substring exclusion in the repo.
  2. **`_is_other_worktree_path` (line 1748, `".claude/worktrees/" in str(path)`) — OUT of scope:** same idiom but NOT the same bug — for a root nested under a real `.claude/worktrees/<X>/`, `_other_worktree_prefix(root)` (lines 1724-1734) walks the ROOT's own parts and returns the enclosing `.claude/worktrees/<X>/` prefix, which is present in every scanned path, so nothing is wholesale-excluded (hermetic by its prefix mechanism). It is also a shared helper with multiple callers — changing it exceeds this Goal. Residual pathological case (root literally being a `.claude/worktrees` dir itself, no name segment) noted for the record; not observed, not routed. Source: read lines 1683-1753.
  3. **Lines 4767-4771 + 4883-4891 (batch-judge / judge-pin `rel` computation) — OUT of scope:** relative-to-`_REPO_ROOT` FIRST with a deliberate, docstring-documented outside-repo fallback used for allowlist MATCHING (exact membership / sanctioned-tail `endswith`), not wholesale directory exclusion — a nested tmp path cannot spuriously match an exact repo-relative allowlist entry. Source: read lines 4760-4781, 4883-4891.
  4. **Line 7399 — already correct** (`path.relative_to(root).as_posix()`); no change.
