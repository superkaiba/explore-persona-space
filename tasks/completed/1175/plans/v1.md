## 4. Design

### 4.1 Design decisions (the six questions from the brief, settled)

**Q1 — Detection predicate: flag BOTH deferred and module-top-level `scripts.*` imports.**
An import node is in scope iff:
- `ast.ImportFrom` with `level == 0` and `module` is `"scripts"` or startswith `"scripts."`, or
- `ast.Import` with any alias whose `name` is `"scripts"` or startswith `"scripts."`.

Rationale for flagging top-level too: the trap is PATH ABSENCE, not deferral — a top-level `scripts.*` import in an experiments/** driver is equally unimportable in script mode. A deferred-only check creates a hoist-evasion: an author "fixes" the flagged deferred import by hoisting it to module top, which still crashes pod-side (at process start rather than mid-run — cheaper, but still a burnt GCE provision cycle: boot + clone + uv sync ≈ 8 min billed, #1073 figure). The live tree has ZERO top-level `scripts.*` imports under experiments/** (verified: full-tree grep returns only run_823.py:1191 and run_952.py:1965, both function-body), so flagging both costs nothing today. The diagnostic message distinguishes the two cases (deferred → "crashes mid-run at the deferred-import line, after the paid phases"; top-level → "crashes at process start").

`if TYPE_CHECKING:` bodies are SKIPPED (those imports never execute at runtime — flagging them is a pure false positive). Precision: skip only statements within the `If.body` line range of an `If` whose test is `Name("TYPE_CHECKING")` or `Attribute(attr="TYPE_CHECKING")`; the `orelse` branch DOES execute at runtime and stays in scope. `if not TYPE_CHECKING:` does not match the test predicate, so its body correctly stays in scope.

**Q2 — Guarded predicate (precise).** A flagged import is *guarded* iff guard-evidence exists at an executing position:
- **Guard-evidence** = an `ast.Call` that is either (i) a call whose callee name (`Name.id` or `Attribute.attr`) matches `SYSPATH_GUARD_NAME_RE = re.compile(r"(?i)syspath|sys_path")` — matches both live exemplars (`_ensure_repo_root_on_syspath`) and reasonable variants (`ensure_repo_root_on_syspath`, `add_repo_root_to_sys_path`) — or (ii) a literal `sys.path.insert(...)` / `sys.path.append(...)`: `Attribute(attr ∈ {"insert","append"})` over `Attribute(attr="path")` over `Name(id="sys")`.
- **Position rules:**
  - Deferred import: guarded iff guard-evidence exists in the SAME innermost enclosing function body at `lineno < import.lineno`, OR guard-evidence exists anywhere at MODULE scope (module body executes fully at import time, before any post-import function call — so a module-level bootstrap at any line covers every deferred import; this is exactly the `scripts/issue_331_phase0_panel.py:43-49` module-top-bootstrap convention).
  - Top-level import: guarded iff guard-evidence exists at MODULE scope at `lineno < import.lineno` (module body executes in order).
- **Scope-scan pruning (correctness-critical):** when scanning a scope body for guard-evidence, do NOT descend into nested `FunctionDef`/`AsyncFunctionDef`/`ClassDef`/`Lambda` — a guard call INSIDE a nested def does not execute when the def statement runs. (A naive `ast.walk` over the module body would count `run_823.py`'s guard-call *inside another function* as module-level evidence — wrong.)
- Deliberately NOT counted as guarded: `try/except ImportError` around the import (the fallback silently takes the wrong path pod-side — worse than the crash; fail-fast rule), guards in an OUTER-but-not-innermost enclosing function (rare; waiver is the escape), conditionally-executed guards are counted by presence (we don't evaluate conditions — accepted imprecision, documented).

False-positive resistance: with the narrow scope (137 files, exactly 2 live import sites, both guarded) and the waiver escape, the predicate errs slightly toward false-fail-with-cheap-escape rather than false-pass, matching the failure-cost asymmetry (a false pass = a burnt pod run; a false fail = one waiver comment).

**Q3 — Scope: `src/explore_persona_space/experiments/**` only** (the task-body scope), parameterized via `scan_roots` for tests. Exclusions:
- `src/explore_persona_space/backends/**`: covered by entrypoint bootstraps + #987 (see §2). The backends' 6 deferred `scripts.*` imports are reached only through `dispatch_issue.py`/`backend_poll.py`, both of which insert repo root at module top.
- `scripts/**`: different invocation convention — scripts importing `scripts.*` siblings each carry their own module-top sys.path bootstrap (16 files; exemplar `scripts/issue_331_phase0_panel.py:43`), and script-mode `python scripts/foo.py` puts `scripts/` (not repo root) on sys.path, so the module-top bootstrap is the established fix there. The new predicate's module-level-guard clause would actually handle most of scripts/ correctly, so widening is feasible later — surfaced as a prose follow-up, not done here (task body scopes to experiments/**).
- `tests/**`, `external/**`, `archive/**`: never run in script mode pod-side / out of lint scope by house convention.

**Q4 — Waiver:** `# SCRIPTS_IMPORT_GUARD_EXEMPT: <reason>` (reason ≥ 10 chars = `SCRIPTS_IMPORT_GUARD_WAIVER_MIN_REASON_CHARS`), accepted on the import's first physical line or the immediately preceding non-blank line — byte-for-byte the `_jsonl_splitlines_waiver_present` / `_upload_as_file_waiver_present` convention. No legacy allowlist (live tree is clean; jsonl-style allowlists exist only where live offenders were frozen — none here).

### 4.3 Core pseudocode

```python
SYSPATH_GUARD_NAME_RE = re.compile(r"(?i)syspath|sys_path")
SCRIPTS_IMPORT_GUARD_WAIVER_RE = re.compile(r"#\s*SCRIPTS_IMPORT_GUARD_EXEMPT\s*:\s*(.+?)\s*$")
SCRIPTS_IMPORT_GUARD_WAIVER_MIN_REASON_CHARS = 10


def _is_syspath_guard_call(node: ast.AST) -> bool:
    """True iff node is a syspath-guard Call: callee name matching
    SYSPATH_GUARD_NAME_RE (e.g. _ensure_repo_root_on_syspath), or a literal
    sys.path.insert(...)/sys.path.append(...)."""
    if not isinstance(node, ast.Call):
        return False
    f = node.func
    name = f.id if isinstance(f, ast.Name) else (f.attr if isinstance(f, ast.Attribute) else None)
    if name and SYSPATH_GUARD_NAME_RE.search(name):
        return True
    return (
        isinstance(f, ast.Attribute) and f.attr in ("insert", "append")
        and isinstance(f.value, ast.Attribute) and f.value.attr == "path"
        and isinstance(f.value.value, ast.Name) and f.value.value.id == "sys"
    )


def _scope_guard_linenos(body: list[ast.stmt]) -> list[int]:
    """Linenos of guard-evidence calls in ONE scope body, NOT descending into
    nested FunctionDef/AsyncFunctionDef/ClassDef/Lambda (a guard inside a
    nested def does not execute when the def statement runs)."""
    out: list[int] = []
    stack: list[ast.AST] = list(body)
    while stack:
        node = stack.pop()
        if isinstance(node, (ast.FunctionDef, ast.AsyncFunctionDef, ast.ClassDef, ast.Lambda)):
            continue
        if _is_syspath_guard_call(node):
            out.append(node.lineno)
        stack.extend(ast.iter_child_nodes(node))
    return out


def _is_scripts_import(node: ast.stmt) -> bool:
    if isinstance(node, ast.ImportFrom):
        return node.level == 0 and node.module is not None and (
            node.module == "scripts" or node.module.startswith("scripts."))
    if isinstance(node, ast.Import):
        return any(a.name == "scripts" or a.name.startswith("scripts.") for a in node.names)
    return False


def check_scripts_import_guard(*, scan_roots: tuple[Path, ...] | None = None) -> list[str]:
    """AST-walk src/explore_persona_space/experiments/**/*.py and FAIL any
    scripts.* import (deferred OR module-top-level) lacking a repo-root
    sys.path guard (#823/#853). <full docstring: rationale, signals, position
    rules, deliberate false negatives (importlib/__import__/exec, outer-scope
    guards, conditional-guard presence-counting, .sh heredocs), waiver,
    unparseable-skip — jsonl-splitlines docstring shape>"""
    roots = scan_roots if scan_roots is not None else (
        _REPO_ROOT / "src" / "explore_persona_space" / "experiments",)
    errors: list[str] = []
    for root in roots:
        if not root.exists():
            continue
        for py in sorted(root.rglob("*.py")):
            if not py.is_file():
                continue
            text = read utf-8; on UnicodeDecodeError -> stderr skip-note, continue
            if "import scripts" not in text and "from scripts" not in text:
                continue  # necessary-token perf gate
            tree = _cached_parse(py, text)
            if tree is None -> stderr skip-note (SyntaxError), continue
            lines = text.split("\n")
            module_guards = _scope_guard_linenos(tree.body)
            tc_ranges = _type_checking_body_ranges(tree)  # If-test == TYPE_CHECKING; body span only

            # module-top-level offenders: module-scope guard must PRECEDE
            for stmt in tree.body:
                if _is_scripts_import(stmt) and not in_tc_ranges(stmt.lineno):
                    if not any(g < stmt.lineno for g in module_guards):
                        _flag(errors, py, stmt, deferred=False, lines=lines)

            # deferred offenders: innermost-function preceding guard OR any module-scope guard
            for fn in ast.walk(tree):
                if not isinstance(fn, (ast.FunctionDef, ast.AsyncFunctionDef)):
                    continue
                fn_guards = _scope_guard_linenos(fn.body)
                for stmt in innermost-scope statements of fn.body (pruned walk, no nested defs):
                    if _is_scripts_import(stmt) and not in_tc_ranges(stmt.lineno):
                        guarded = any(g < stmt.lineno for g in fn_guards) or bool(module_guards)
                        if not guarded:
                            _flag(errors, py, stmt, deferred=True, lines=lines)
    return errors
```

`_flag` composes (after the waiver check `_scripts_import_guard_waiver_present(lines, stmt.lineno)`):

```
{py}:{lineno}: scripts-import-guard: {deferred|module-top-level} scripts.* import
without a repo-root sys.path guard. In script mode (python /abs/path/driver.py)
sys.path[0] is the script's dir — 'scripts' is unimportable pod/GCE-side and this
import crashes {mid-run at the deferred-import line, after the paid phases |
at process start} (#823/#853; .claude/rules/gotchas.md "Script mode puts the
SCRIPT's dir on sys.path[0]"). Call _ensure_repo_root_on_syspath() immediately
before the import (copy the run_823.py exemplar, commit 14234c9112), or waive a
genuinely-safe site with '# SCRIPTS_IMPORT_GUARD_EXEMPT: <reason>' (reason ≥ 10 chars).
```

Note the nested-function subtlety in the deferred pass: iterate each function's OWN body via the pruned walk so an import inside a nested def is attributed to the NESTED def (its innermost scope), not the outer one — `ast.walk(tree)` visiting every `FunctionDef` plus per-function pruned body walks gives exactly innermost-scope attribution (each import is seen once, in its innermost enclosing function).

**Why code, not a model call:** deterministic AST predicate over a fixed grammar; an LLM call would be slower, nondeterministic, and unusable in pre-commit. (House rule satisfied trivially.)
