### 4.1 New helper: `_module_globs_jsonl` (signal (e) gate)

Add next to `_chain_has_read_text` (~line 3999):

```python
JSONL_GLOB_FUNC_NAMES = frozenset({"glob", "rglob", "iglob"})  # near line 1161 constants

def _module_globs_jsonl(tree: ast.AST) -> bool:
    """Signal (e) gate: True iff the module contains a glob/rglob/iglob call
    (method or bare function) whose pattern argument — positional or keyword,
    plain str constant or an f-string constant fragment — mentions 'jsonl'
    case-insensitively (``tasks_root.glob("*/*/events.jsonl")``,
    ``root.glob(f"{stem}.jsonl")``)."""
    for node in ast.walk(tree):
        if not isinstance(node, ast.Call):
            continue
        name = (node.func.attr if isinstance(node.func, ast.Attribute)
                else node.func.id if isinstance(node.func, ast.Name) else None)
        if name not in JSONL_GLOB_FUNC_NAMES:
            continue
        for arg in [*node.args, *(kw.value for kw in node.keywords)]:
            frags = list(arg.values) if isinstance(arg, ast.JoinedStr) else [arg]
            for frag in frags:
                if (isinstance(frag, ast.Constant) and isinstance(frag.value, str)
                        and JSONL_NAME_TOKEN_RE.search(frag.value)):
                    return True
    return False
```

### 4.2 New helper: `_jsonl_assigned_splitlines_ids` (signal (f) pre-pass)

Same shape as the existing `_jsonl_fn_scoped_splitlines_ids` pre-pass. Two parts:

```python
def _enclosing_scope_map(tree: ast.AST) -> dict[int, int | None]:
    """id(node) -> id() of the innermost enclosing FunctionDef/AsyncFunctionDef
    (None = module scope). A def node itself belongs to its OUTER scope; its
    body belongs to it. Recursion via ast.iter_child_nodes."""

def _jsonl_assigned_splitlines_ids(tree: ast.AST, text: str) -> dict[int, str]:
    """Signal (f) pre-pass: map id() of every ``.splitlines()`` call whose
    receiver is a bare ``ast.Name`` assigned EARLIER IN THE SAME SCOPE from a
    ``read_text()``-bearing expression carrying jsonl evidence — the RHS
    source segment matches /jsonl/i OR its chain base Name matches
    JSONL_EVENTS_PATH_NAME_RE (the #1032 ``ev = events_path.read_text()``
    shape) — to a human-readable signal label."""
    # 1. collect bare-Name splitlines receivers, grouped by scope key:
    #    calls[scope] -> [(name, lineno, id(call))]; return {} if none.
    # 2. for each ast.Assign (single Name target) / ast.AnnAssign (Name target,
    #    value not None) whose (scope, target-name) matches a collected
    #    receiver: cheap checks FIRST (_chain_has_read_text(value)), THEN
    #    segment = ast.get_source_segment(text, value); evidence =
    #    (segment matches JSONL_NAME_TOKEN_RE) or
    #    (_chain_base_name(value) matches JSONL_EVENTS_PATH_NAME_RE).
    # 3. flag each matching call with assign.lineno < call.lineno:
    #    out[id(call)] = f"read_text-assigned jsonl-content receiver ('{name}')"
```

Boundedness (deliberate): single-step, same-scope (module top-level is one scope; closures/nested defs are separate scopes), no kill/re-assignment analysis, no tuple-unpacking/walrus targets. Performance: `ast.get_source_segment` (O(file) per call) runs ONLY for assignments whose (scope, name) matches a bare-Name splitlines receiver AND whose RHS contains `read_text` — a handful repo-wide (this ordering is what keeps criterion 9's ≤ 40s budget; my unbounded plan-time scan cost ~60s, the bounded form adds ~1-3s).
