### 4.1 The predicate decision (clarifier question 5 — answered)

**Recommendation: block ALL non-ff `git pull` forms whose effective tree is the repo root — including `git pull --rebase=merges --autostash`. Allow `--ff-only` everywhere.**

| `issue/SKILL.md:8364` form (2), `:4862`, `:6154`, `:9661-9675` | `git push origin main \|\| uv run python scripts/sync_repo_root.py` | repo root | ALLOW (no `git pull` text; the helper is "the ONLY repo-root sync", SKILL.md:9661) |

**No live canonical snippet prescribes any repo-root-cwd `git pull`** — bare OR flagged. #1148 removed the last one from `daily/SKILL.md`. Therefore blocking the flagged form breaks nothing, and NOT blocking it would leave open the exact hand-rolled recovery CLAUDE.md §238 bans ("instead of hand-rolling a pull-rebase recovery loop") — the flagged form dies the same `Cannot autostash` death under a held lock/husk and lacks the helper's flock serialization, untracked-collision sweep, and stranded-stash recovery. It is also the trivial dodge a bare-only predicate would invite. Bonus: `git pull --no-rebase` (a root MERGE — `guard_repo_root_branch.sh` residual gap (xvi)) is closed for free.

**Why `--ff-only` is waived:** an ff-only pull cannot rewrite/drop local commits, cannot create a rebase husk, cannot strand an autostash — it either fast-forwards or fails loudly (`Not possible to fast-forward` / `would be overwritten`), and it is the verb every canonical pod-sync recipe uses. The prose rule mechanized here bans the pull-REBASE recovery loop; ff-only is not in that class. Waiving it removes the entire pod-sync false-positive surface (including the mis-split multi-statement `ssh` tail-clause shape) at the cost of a miss that cannot reproduce any named incident.

### 4.2 New file: `scripts/guard_repo_root_pull.sh`

Placement: `scripts/` per the task body (sibling co-location with `guard_repo_root_branch.sh`, the other repo-root git guard; `TestSettingsWiring` reads the path from settings.json so tests are placement-agnostic). Core content sketch (real bash — implementer may refine regex details per §10, behavior pinned by the §4.5 matrix):

```bash
#!/usr/bin/env bash
# PreToolUse(Bash) guard: block a hand-rolled `git pull` against the SHARED
# repo-root tree (task #1201). CLAUDE.md § Concurrent repo-root committers
# prescribes scripts/sync_repo_root.py as the ONLY repo-root sync; the prose
# alone failed open (#967: a hand-rolled root pull died `fatal: Cannot
# autostash`). sync_repo_root.py's own pull is a Python subprocess
# (_run_bounded(_pull_argv)) and never passes PreToolUse — no sentinel needed.
# Contract: stdin PreToolUse JSON; exit 2 + stderr = block; exit 0 = allow;
# fail-soft (any parse ambiguity allows). CWD-BLIND like the siblings: the
# guard matches COMMAND TEXT, not $PWD.
# Self-test: bash scripts/guard_repo_root_pull.sh --self-test
set -u

REPO=/home/thomasjiralerspong/explore-persona-space

# Flag-tolerant verb anchor (the #897 detector shape): `git [flags] pull`,
# verb terminated by space/EOL so `git pull-request` / `pulled` never match.
PULL_ERE='\bgit +(-[^ ]+( +[^ ]+)?( +|$))*pull([[:space:]]|$)'

check_cmd() {
  local cmd="$1"
  case "$cmd" in *EPM_ALLOW_ROOT_PULL=1*) return 0 ;; esac   # inline escape hatch
  case "$cmd" in *'<<'*) return 0 ;; esac  # heredoc blanket-allow (sibling precedent;
                                           # documented known miss, test-pinned)
  # Cheap pre-filter (runs on EVERY Bash call): both substrings must co-occur.
  case "$cmd" in *git*) ;; *) return 0 ;; esac
  case "$cmd" in *pull*) ;; *) return 0 ;; esac
  # Bash line-continuation normalization (verbatim sibling pre-pass).
  cmd=$(printf '%s' "$cmd" | sed -zE 's/\\\r?\n/ /g')

  # Clause split with separator sentinels: two-char separators first. Raw
  # newlines and any un-sentineled first line get RESET semantics (the #804
  # latch law: a cd-latch propagates ONLY across `&&`).
  local records
  records=$(printf '%s\n' "$cmd" \
    | sed -E 's/&&/\n@AND@/g; s/\|\|/\n@OR@/g; s/;/\n@SEQ@/g; s/\|/\n@PIPE@/g; s/&/\n@BG@/g')

  local rec sep clause lead tgt latched=0
  while IFS= read -r rec; do
    case "$rec" in
      @AND@*) sep=AND; clause=${rec#@AND@} ;;
      @OR@*|@SEQ@*|@PIPE@*|@BG@*) sep=RESET; clause=${rec#@*@} ;;
      *) sep=RESET; clause=$rec ;;      # START line or raw newline
    esac
    [ "$sep" = AND ] || latched=0
    # Whitespace-anchored comment-tail strip (sibling shape); skip pure comments.
    clause=$(printf '%s' "$clause" | sed -E 's/(^|[[:space:]])#.*$//')
    lead=$(printf '%s' "$clause" | sed -E 's/^[[:space:]{(]+//')
    [ -n "$lead" ] || continue

    # cd-latch ARM: latch only provably-non-root targets (fail-closed on
    # relative / variable / empty targets — cannot prove the cwd).
    if printf '%s' "$lead" | grep -qE '^cd([[:space:]]|$)'; then
      tgt=$(printf '%s' "$lead" | sed -E 's/^cd[[:space:]]*//' | awk '{print $1}' \
            | sed -E "s/^[\"']//; s/[\"']\$//")
      case "$tgt" in
        *.claude/worktrees/*)          latched=1 ;;  # a worktree IS its own tree
        "$REPO"|"$REPO"/*)             latched=0 ;;  # root or a subdir (git walks up)
        '~/explore-persona-space'|'~/explore-persona-space/'*) latched=0 ;;
        '$HOME/explore-persona-space'|'$HOME/explore-persona-space/'*) latched=0 ;;
        /*|'~'|'~/'*|'$HOME/'*)        latched=1 ;;  # absolute/~-anchored, not the root
        *)                             latched=0 ;;  # relative/variable/empty: unproven
      esac
      continue
    fi

    # Waived command words: remote execution + read-only pattern tools.
    case "$lead" in ssh\ *|scp\ *|grep\ *|egrep\ *|fgrep\ *|rg\ *) continue ;; esac
    # Per-clause `git -C <path>` waiver — path-blind, sibling-line-974 parity;
    # the block message's "never point -C at the root" line is the control.
    printf '%s' "$clause" | grep -qE '\bgit +-C +' && continue

    if printf '%s' "$clause" | grep -qE "$PULL_ERE"; then
      case "$clause" in *--ff-only*) continue ;; esac  # ff cannot autostash-die/husk/drop
      [ "$latched" = 1 ] && continue
      return 1
    fi
  done <<< "$records"
  return 0
}

run_self_test() { ... }   # sibling shape: jq -n --arg c ... | bash "$SCRIPT",
                          # the full §4.5 matrix, PASS/FAIL lines, exit 1 on any FAIL

[ "${1:-}" = "--self-test" ] && { run_self_test; exit $?; }

_allow=$(printf '%s' "${EPM_ALLOW_ROOT_PULL:-}" | tr '[:upper:]' '[:lower:]')
case "$_allow" in 1|true|yes) exit 0 ;; esac

cmd=$(jq -r '.tool_input.command // empty' 2>/dev/null) || exit 0
[ -n "$cmd" ] || exit 0

if ! check_cmd "$cmd"; then
  cat >&2 <<'BLOCK_MSG'
BLOCKED: hand-rolled `git pull` at the SHARED repo root. Concurrent sessions
commit here in parallel; an unserialized pull races them and dies
`fatal: Cannot autostash` under a held lock/husk (#967) or orphans a
concurrent commit (#711). The ONLY repo-root sync is:
  uv run python scripts/sync_repo_root.py
(flock-serialized, untracked-collision sweep, bounded rebase, stash recovery).
Worktree pulls stay open: git -C "$WT" pull --rebase=merges --autostash
(NEVER point -C at the repo root). `git pull --ff-only` is allowed anywhere.
For commit/note text that merely MENTIONS `git pull`, use
`git commit -F <file>` / `task.py post-marker --file <path.md>` (or a heredoc).
Deliberate override: prefix with EPM_ALLOW_ROOT_PULL=1.
BLOCK_MSG
  exit 2
fi
exit 0
```
