## 2. Prior work / grounding

- **Psychometrics.** The Spearman–Brown prophecy (Spearman 1910; Brown 1910) extrapolates a half-test correlation r_hh to full-test reliability 2·r_hh/(1+r_hh) under the **parallel-halves assumption**: the two halves are matched tests of the same construct (equal true-score and error variance). On a crossed condition × item design, per-condition-INDEPENDENT item splits violate this: the "half A score" of condition c1 and of condition c2 are computed from *different* item subsets, so item main effects (a variance component generalizability theory separates explicitly; Cronbach et al. 1972) enter as split noise rather than cancelling.
- **The negative-bias mechanism** (not mere attenuation): within one condition the two halves *partition* the same item set, so the item-composition offset enters half-A and half-B scores with opposite signs (sum constraint: their mean equals the condition mean). With independent per-condition splits this anti-correlated offset varies across conditions; when item main-effect variance exceeds the condition signal, it dominates and drives r_hh systematically NEGATIVE. An aligned split makes the offset a constant shared by all conditions, which cancels in the cross-condition correlation.
- **Incident #763** (reanchor round, `scripts/issue_763_reliability.py::reliability_split_half_over_probes`): crossed context × probe design with probe-mean sd ≈ 27/100 vs context signal ≈ 3/100. Independent splits: split-half r = −0.41 (v1) / −0.23 (v2); ~100% / 99% of 200 random independent splits negative; Spearman–Brown's non-negativity floor reported the ceiling as 0.00. Probe-ALIGNED splitting recovered a real v2 ceiling ≈ 0.59. Every future √(r_yy) in this program uses the same crossed context × probe design, so the artifact recurs silently absent a rule.
- **Existing rule text:** llm-judging.md today has NO split-half prose at all (rules 15/18 name the ceiling √(r_yy) and "test-retest" but not the splitting procedure) — verified by grep. The clarifier's surface sweep found ZERO split-half / Spearman–Brown prose anywhere else in `.claude/rules/`, `.claude/agents/`, `.claude/skills/`, `workflow.yaml`, or CLAUDE.md — single-file fix (plus the two count-pointer phrases, below).
