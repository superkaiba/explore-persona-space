### 4.1 Check 1 — `check_marker_scalar_integrity`

```python
# (kind, field) -> reason. Empty today (live-tree probe 2026-07-09: 0 hits
# across 106 markers x 4 fields). Add entries ONLY for deliberate prose that
# trips the signature (e.g. enumeration style "a) ... b) ..."), with a reason.
MARKER_SCALAR_INTEGRITY_ALLOWLIST: dict[tuple[str, str], str] = {}

_MARKER_STRING_FIELDS = ("kind", "posted_by", "when", "fields")


def check_marker_scalar_integrity(
    workflow: WorkflowYaml,
    *,
    allowlist: dict[tuple[str, str], str] | None = None,
) -> list[str]:
    """Flag marker-entry string fields carrying the truncated-comment
    signature: an unquoted YAML plain scalar containing ' #' silently
    truncates at the comment marker (incident #873: posted_by parsed as
    "skill (...); poll_pipeline (runtime tripwire," and --check-references
    passed because the regenerated markers.md matched the truncated parse).
    Signature on the PARSED value: ends in ',' or '(' after rstrip, or
    unbalanced parens. Allowlist grain is (kind, field) with a reason.
    """
    wl = MARKER_SCALAR_INTEGRITY_ALLOWLIST if allowlist is None else allowlist
    errors: list[str] = []
    for m in workflow.markers:
        for field in _MARKER_STRING_FIELDS:
            v = getattr(m, field) or ""
            stripped = v.rstrip()
            trailing = stripped.endswith((",", "("))
            unbalanced = v.count("(") != v.count(")")
            if not (trailing or unbalanced):
                continue
            if (m.kind, field) in wl:
                continue
            errors.append(
                f"workflow.yaml § markers: marker '{m.kind}' field '{field}' has the "
                f"truncated-comment signature ({'trailing ,/(' if trailing else ''}"
                f"{' and ' if trailing and unbalanced else ''}"
                f"{'unbalanced parens' if unbalanced else ''}): {stripped[-60:]!r}. "
                f"An unquoted plain scalar containing ' #' truncates at the comment "
                f"marker (#873) — double-quote the scalar in workflow.yaml, or add "
                f"(kind, field) to MARKER_SCALAR_INTEGRITY_ALLOWLIST with a reason."
            )
    return errors
```

Decisions baked in: scan **all four** `MarkerEntry` string fields via an explicit pinned tuple (not `model_fields` iteration — a future non-str field must not crash the check silently); heuristic operates on the **parsed** value only (probe 2 above rules out raw-text scanning); unbalanced leg is `!=` per the Goal's literal text (§11 records the `>`-only alternative).

### 4.2 Check 2 — `check_poller_marker_consumers`

```python
POLLER_POSTED_BY_RE = re.compile(
    r"poll_pipeline|backend_poll|slurm_monitor|autonomous_session_watch|pod_watch|tick_triage",
    re.IGNORECASE,
)

# Leg B: posted_by token -> the file that must contain the kind string.
_POLLER_TOKEN_TO_FILE: dict[str, str] = {
    "poll_pipeline": "scripts/poll_pipeline.py",
    "backend_poll": "scripts/backend_poll.py",
    "slurm_monitor": "src/explore_persona_space/backends/slurm_monitor.py",
    "autonomous_session_watch": "scripts/autonomous_session_watch.py",
    "pod_watch": "scripts/pod_watch.py",
    "tick_triage": "scripts/tick_triage.py",
}

# kind -> reason. Empty today (live-tree probe 2026-07-09: 5/5 poller-posted
# kinds referenced). Add entries ONLY with a reason naming the deliberate
# out-of-band consumer.
POLLER_CONSUMER_ALLOWLIST: dict[str, str] = {}


def check_poller_marker_consumers(
    workflow: WorkflowYaml,
    *,
    consumer_paths: list[Path] | None = None,
    poller_file_map: dict[str, Path] | None = None,
    allowlist: dict[str, str] | None = None,
) -> list[str]:
    """Every marker kind whose posted_by names a poller/watcher must be
    (Leg A) referenced by >=1 consumer surface — all .claude/skills/**/SKILL.md
    plus tick_triage.py / autonomous_session_watch.py / poll_pipeline.py /
    backend_poll.py — and (Leg B) present in each poster script its posted_by
    token names (the #873 pre-fix state: a runtime tripwire declared in
    workflow.yaml with no poll_pipeline code). Overrides narrow the scan for
    fixture tests, mirroring check_marker_registry's skill_md/skills_dir hooks.
    """
```

Pseudocode:

1. Resolve production surfaces when both overrides are None:
   `consumers = sorted((_REPO_ROOT / ".claude" / "skills").glob("**/SKILL.md")) + [scripts/tick_triage.py, scripts/autonomous_session_watch.py, scripts/poll_pipeline.py, scripts/backend_poll.py]`; `poller_files = {token: _REPO_ROOT / rel for token, rel in _POLLER_TOKEN_TO_FILE.items()}`. Passing either override narrows to exactly the overridden surface(s) (the `check_marker_registry` override semantics, line 3347–3352).
2. Read each existing surface once into a `{path: text}` dict (skip non-existent override paths as `check_marker_registry` does; a MISSING production Leg-B poster file for a matched token is an ERROR, not a skip — fail loud).
3. For each `m in workflow.markers` with `POLLER_POSTED_BY_RE.search(m.posted_by)` and `m.kind not in allowlist`:
   - **Leg A:** if `m.kind` appears as a substring in none of the consumer texts → error: `workflow.yaml § markers: poller-posted marker '<kind>' (posted_by: <first 80 chars>) is referenced by NO consumer surface (…list…). A poller feature claiming mid-run surfacing must be reachable by watcher/tick/poll/orchestrator code (#873) — wire a consumer or add the kind to POLLER_CONSUMER_ALLOWLIST with a reason.`
   - **Leg B:** for each token in `_POLLER_TOKEN_TO_FILE` present (case-insensitive) in `m.posted_by`: if `m.kind` not in that file's text → error naming kind + token + file (`declared poster '<file>' does not mention '<kind>' — the posting code may not exist (#873 pre-fix state)`).
4. Return errors.

Notes: the auto-generated `.claude/skills/issue/markers.md` (which lists EVERY kind) is excluded by construction — the glob matches `SKILL.md` only. Plain substring match on the kind (e.g. `epm:cluster-poll`) is the same grain the Goal's `rg the marker name` prescribes; kinds are long, prefixed tokens, so substring collisions are not a realistic risk (`epm:cluster-poll` ⊄ any other kind; a hypothetical prefix-kind collision, e.g. a future `epm:cluster-poll-x`, would only make the check more lenient, never a false FAIL).

**Leg B is a deliberate, droppable extension beyond the Goal's literal text.** Justification: Leg A alone would NOT have caught #873's actual pre-fix state — `epm:compute-deviation` pre-existed as an implementer self-tag already referenced in SKILL.md, while the NEW claim (poll_pipeline runtime tripwire) had no poll_pipeline.py code. Leg B pins "the declared poster actually contains the kind", which catches exactly that. Live tree passes Leg B 5/5 (probe 4). If review finds the free-prose token extraction too fragile, dropping Leg B is an allowed deviation (§ Deviations) — Leg A alone still satisfies the Goal verbatim.

## 11. Decision Rationale

1. **No task split (one plan, two checks).** What: both checks in one `/issue` pipeline. Why: same target file, test file, registration ladder; distinct fingerprints matter for *dedup*, not for implementation batching. Source: task #1191 body ("may split" — permissive, not mandated) + `.claude/rules/workflow-fix-on-bug.md` § Dedup (grain is `(target_file, fingerprint)` at *filing* time — already filed as one task). 2. **Fields scanned = all four `MarkerEntry` string fields (`kind`, `posted_by`, `when`, `fields`), explicit tuple.** Why: the model has exactly these four `str` fields (workflow.py:128–134); scanning all four costs nothing (424 values, 0 live hits) and a truncated `kind`/`when` is as damaging as a truncated `posted_by`. Explicit tuple over `model_fields` iteration so a future non-str field fails loud at review, not silently at getattr. Source: read `src/explore_persona_space/workflow.py:128` this session; #873 incident (task body — `posted_by` was the truncated field, but the mechanism is field-agnostic).
3. **Heuristic on the PARSED value; thresholds `endswith((",", "("))` + `count("(") != count(")")`.** Why: the Goal's literal signature; probe 3 verified both legs fire on the #873 repro; probe 2 rules out raw-text `' #'` scanning (39 legitimate quoted/block-scalar comment lines).
