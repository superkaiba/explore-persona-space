# Plan v2 — task #1791: `--map-files` misuse OSError before the #1613 guard

Revision of v1 after the Methodology-lens critic round (REVISE, 2 Must-Fix —
both verified against the code and folded in below; the critic's
non-blocking binary-file suggestion is adopted too).

## 1. Goal + acceptance criteria

**Goal (from task body):** Make `--map-files` misuse with a non-path-list
payload reach the graceful #1613 diagnostic (or the existing rc-1
"cannot read" path) instead of a raw traceback: make every
content-line-derived filesystem probe tolerant of unstat-able /
invalid-pattern lines.

**Acceptance criteria:**
1. `select_step9c_tests.py --map-files <file>` no longer raises an
   unhandled `OSError: [Errno 36] File name too long` or
   `ValueError: Invalid pattern` for ANY content-line shape — including a
   >NAME_MAX prose line, an arm-eligible long line
   (`scripts/<300 chars>.py`, which crashes at the `dependency_map_pairs`
   stem probe BEFORE the guard), and a glob-metacharacter line
   (`scripts/*.py`, which crashes the content-derived `glob()` pattern).
2. A `.py`/`.sh`-named `--map-files` argument with such content reaches the
   existing #1613 ERROR diagnostic and exits 2 (contract preserved).
3. A non-source-suffixed argument (e.g. `.md`/`.txt`) with such content
   reaches the existing #1613 hedged WARN and exits 0 (contract preserved).
4. A mis-passed BINARY file (undecodable) takes the existing rc-1
   "cannot read --map-files input" path instead of an uncaught
   `UnicodeDecodeError`.
5. Regression tests cover all shapes; existing #1613 cluster tests
   (tests/test_select_step9c_tests.py L712–790) stay green.

## 2. Method delta (vs prior work)

#1613 added the misuse diagnostic but its own probe — and the arm probes
that run BEFORE it in `_run_map_files_mode` — raise before the heuristic
can report when a content line exceeds NAME_MAX or embeds glob
metacharacters. #1717/#1699 touched adjacent ergonomics but not this path.
This plan adds ONLY error-tolerance to content-line-derived probes — no
behavioral change on any valid path-list input.

## 3. Concrete changes (file paths + diff shape)

Target: `scripts/select_step9c_tests.py` (workflow surface; wf-fix scope).

(a) Add two module-level helpers near the other small utilities:

```python
def _safe_exists(p: Path) -> bool:
    """`p.exists()` that treats an unstat-able path as absent (#1791).

    A content line from a mis-passed --map-files payload (markdown prose,
    a source line > NAME_MAX) raises OSError [Errno 36] / ValueError
    (embedded NUL) from Path.exists() — before the #1613 misuse diagnostic
    can fire. Such a line is by definition not an existing repo path.
    """
    try:
        return p.exists()
    except (OSError, ValueError):
        return False


def _safe_glob(root: Path, pattern: str) -> list[Path]:
    """`sorted(root.glob(pattern))` tolerant of content-derived patterns (#1791).

    A stem derived from a mis-passed content line can embed glob
    metacharacters (`scripts/*.py` -> stem `*` -> pattern `test_***.py`),
    which raises ValueError("Invalid pattern: '**' can only be an entire
    path component") on modern pathlib — before the #1613 diagnostic.
    """
    try:
        return sorted(root.glob(pattern))
    except (OSError, ValueError):
        return []
```
