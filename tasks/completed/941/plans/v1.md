### 11. Decision Rationale

- **Why `get_paths_info(..., expand=True)` for the ordering probe.** What: per-path last-commit dating. Why: it is the only Hub-API call that returns per-path `last_commit` without enumerating the repo tree — safe on the ~1M-file data repo where `list_repo_files` wedges (>90 s, #833). Source: live probe this session (`issue779_monitoring/r_b/evil.pt → ('97050c185a', 2026-07-01 10:53:01+00:00)`, 0.5 s) + gotchas.md #833 bullet. Alternatives: `list_repo_commits` (repo-level, needs client-side path filtering — slower, more code); relying on the artifact's own `reconstruction` metadata alone (not all artifacts carry one — #922's did, but the date comparison is the universal floor; the metadata read is kept as the AND).
- **Why last-commit-DATE comparison (input ≤ capture).** What: the coherence predicate. Why: it is exactly the signal that would have caught #922 (input commit 2026-07-02 > capture commit 2026-07-01), it needs no artifact-format knowledge, and same-commit pairs pass trivially. Source: the #922 incident record (task #941 body + #922 r4 failure-lesson). Alternative: content-level parity asserts at plan time — rejected as the general mechanism because they require downloading + format-specific parsing per pair class; the pod-side parity assert remains the runtime backstop (it's what caught #922, one GCE cycle too late).
- **Why these named pair classes (bank↔capture, mix↔adapter, pool↔judge-outputs).** What: the (j) trigger scope. Why: they are the project's three recurring produced-under dependencies — #922 hit bank↔capture; mix↔adapter is the (d)/(h) reuse surface; pool↔judge-outputs is the #810 cache-class sibling. Source: incidents #922, #734, #810; artifact-reuse.md items (d)/(h) enumerate the same artifact families.
- **Why remedy lines stay untouched.** What: no edit to any "failing check other than (i)" line. Why: they were deliberately worded range-free at #871 precisely so a future letter needs no remedy re-edit, and a (j) failure IS a regenerate-class failure. Source: `reference_reuse_fitness_mirror_set.md` ("Every remedy-split line … deliberately worded WITHOUT a lettered range") + #871 commit `69719541a5`.
- **Why the consistency-checker gains a one-sentence probe (deviation from #871-minimal).** What: an independent mechanical (j) re-check in the Hub-resolution BLOCK row.
