# Plan — #2430: Step 9c paired oracle SUFFIX-replay arm (mechanical attribution of later-sorting-file contamination)

## 0.0 TL;DR (plain English)

- **What I'll run:** I'll add a bounded second arm to the Step 9c gate's test-contamination detector. Today, when a test fails in the big gate run but passes alone, the gate replays it together with the files that ran *before* it to check whether one of them broke it. If the culprit file sorts *after* the victim (it poisons shared state at import time, before any test runs), the current replay can never contain it, and the gate blames the innocent branch. The new arm replays the victim together with the *later*-sorting files (imported but their tests skipped), and binary-searches to name the culprit file.
- **What I expect:** on a synthetic replay of the real incident (a file that mutates a shared registry when imported, sorting after the victim), the gate names the culprit by filename instead of returning an empty suspect list; on a clean tree, nothing changes at all; and the arm never runs except in the exact "unexplained new failure" case it exists for.
- **What would change my mind:** if the "skip the later files' tests but still import them" pytest mechanism turns out not to reproduce the contamination in a real subprocess test, the replay design is wrong and I'd fall back to running the later files fully (slower but same logic); if any existing gate test breaks, the hook point is wrong.

## 3. Hypothesis / design theses (infra form)

This is `kind: infra` — no statistical hypothesis. The two falsifiable design theses:

1. **Causal-channel thesis:** in a pytest run, all argv-listed files are collected (imported) before any test executes, and tests execute in collection order; therefore a file sorting after the victim can have affected the victim ONLY via collection/import-time side effects — never via its own tests' execution. Consequently a replay that COLLECTS the suffix files but DESELECTS their tests (`--deselect <file>` per file) preserves exactly the causal channel and reproduces the contamination at a fraction of the run cost. Falsified if the real-subprocess test (§ Eval, node 13) shows a deselected contaminator failing to reproduce. (The #2217 conftest guard's own design corroborates: it measures at `pytest_collection_finish`, "post-collection, pre-run".)
2. **Proof-obligation thesis:** a reproduction of the candidate's failure under candidate+suffix on the pristine oracle — candidate content base-identical (#2302 precondition 1 of paired candidacy), suffix files at main's HEAD-pinned content, main's venv interpreter, scratch `src/` shadow — involves zero branch-authored bytes, so it proves a pre-existing main-tree interaction: the identical proof the prefix arm's strip rests on, differing only in replay direction. Falsified if a construction exists where the branch caused the gate failure yet candidate+suffix reproduces on pristine main (none exists under the preconditions; see §11 entry 4).

### 4.2 Suffix-set construction: `_build_suffix()`

Mirror of `_build_paired_prefix` (line 2425) in every convention — order from `ctx.selected_order` (NEVER junit document order, B3), junit `ran_files` contributes membership only, absent-on-main files dropped and recorded:

```python
def _build_suffix(ctx, root, ran_files, node) -> list[str]:
    ran_in_order = [f for f in ctx.selected_order if f in ran_files]
    pos = ran_in_order.index(node.file)   # eligibility guarantees membership (order-skew filtered upstream)
    suffix = []
    for f in ran_in_order[pos + 1 :]:
        if (root / f).exists():
            suffix.append(f)
        elif f not in ctx.suffix_dropped_files:
            ctx.suffix_dropped_files.append(f)
    return suffix
```

### 4.3 Bisection: `_bisect_suffix_offender()`

Deterministic single-offender bisection with an inherent singleton verification (loop invariant: the pool is only ever narrowed to a slice whose replay FAILED, so the final singleton was directly verified by the replay that selected it; the initial pool is verified by the confirmation replay):

```python
def _bisect_suffix_offender(pool: list[str], replay) -> str | None:
    """replay(collect: list[str]) -> bool (True = candidate node failed).
    Precondition: replay(pool) already returned True (the confirmation run).
    Returns the single offender file, or None (multi-file interaction /
    nondeterministic reproduction — reproduced but unattributable)."""
    while len(pool) > 1:
        mid = len(pool) // 2
        lo, hi = pool[:mid], pool[mid:]
        if replay(lo):
            pool = lo
        elif replay(hi):
            pool = hi
        else:
            return None   # neither half reproduces alone: not a single-file effect
    return pool[0]
```

Halves are contiguous slices of the selector-ordered suffix, so replay order stays faithful. **Invocation bound:** 1 confirmation + ≤ 2·ceil(log2(S)) bisection replays. #2059 shape: gate 239 files, prefix 34 → S = 205; ceil(log2(205)) = 8 → **≤ 17 replays** worst case (typical ~13: the offender's half is probed first half the time). Absolute worst at the cap (S = 400): 1 + 2·9 = 19.

**The arm itself:**

```python
def _resolve_suffix_candidates(ctx, root, scratch, ran_files, args, eligible, *, floored):
    """SUFFIX-replay arm (#2430): attribute later-sorting-file contamination.

    Fires ONLY for nodes that (a) hold every #2024 paired precondition, (b)
    resolved NEW via paired-PASS or no-predecessors, (c) got no prefix
    attribution. Every refusal / non-reproduction / error keeps NEW (today's
    verdict); a strip is issued ONLY on a completed, trusted, reproducing
    confirmation replay. The arm NEVER raises _Indeterminate: unlike the
    prefix arm (whose candidates are mid-classification), these nodes carry a
    standing trusted verdict (NEW) to fall back to — no verdict ever rests on
    an aborted or untrusted suffix run.
    """
    use_scratch = scratch is not None
    if _oracle_label(use_scratch, floored) == "scratch-worktree-floor":
        for node in eligible:                      # defense-in-depth; upstream filter
            _suffix_skip(ctx, node, "floor-profile-oracle")   # already makes this unreachable
        return
    deadline = time.monotonic() + args.suffix_wall_budget_s
    attributed: list[str] = []                     # cross-candidate short-circuit pool
    for node in eligible:                          # selector order
        suffix = _build_suffix(ctx, root, ran_files, node)
        if not suffix:
            _suffix_skip(ctx, node, "no-successors"); continue
        if len(suffix) > args.max_suffix_files:    # B1 parity: refuse, NEVER truncate
            _suffix_skip(ctx, node, "suffix-over-cap"); continue
        confirmed = False
        offender: str | None = None
        try:
            replay = _make_suffix_replayer(ctx, root, scratch, args, node,
                                           deadline, use_scratch)
            for prior in attributed:               # 1-replay short-circuit per prior offender
                if prior in suffix and replay([prior]):
                    confirmed, offender = True, prior
                    break
            if not confirmed:
                if not replay(suffix):             # confirmation replay (full suffix)
                    _suffix_skip(ctx, node, "suffix-no-reproduction"); continue
                confirmed = True
                offender = _bisect_suffix_offender(suffix, replay)
        except _SuffixArmStop as stop:             # budget / dirty-oracle / PristineRunError
            _suffix_skip(ctx, node, stop.reason)
            if not confirmed:
                continue                           # keep NEW — nothing trusted was observed
            # confirmed=True: the strip rests on the completed trusted
            # confirmation; only ATTRIBUTION is abandoned (offender=None).
        _suffix_strip(ctx, node, offender, suffix)
        if offender is not None:
            attributed.append(offender)
```

**Per-replay trust + budget probe** (`_make_suffix_replayer` closure), run BEFORE EVERY replay — stricter than the prefix arm's single pre-invocation probe because this arm makes up to 17 invocations over tens of minutes:

```python
def replay(collect: list[str]) -> bool:
    dirty = dirty_code_paths(root)                       # B2/MF-4c freshness
    contaminating = scratch_contamination_probe(root)    # r2 / R-B' parity
    residual = (list(contaminating) if args.no_src_shadow
                else residual_scratch_contamination(contaminating))
    if use_scratch and residual:
        raise _SuffixArmStop("suffix-scratch-residual-contamination")
    if not use_scratch and dirty:
        raise _SuffixArmStop("suffix-dirty-oracle")      # refuse PRE-spend (see §11.5)
    files = [node.file, *collect]
    timeout_s = (args.pristine_timeout_s if args.pristine_timeout_s is not None
                 else derive_paired_timeout_s(ctx.sel, files))
    if time.monotonic() + timeout_s > deadline:
        raise _SuffixArmStop("suffix-budget-exhausted")  # never launch what can't finish
    try:
        run = run_suffix_replay([node.file], collect,
                                cwd=scratch.path if use_scratch else root,
                                timeout_s=timeout_s,
                                venv_root=root if use_scratch else None,
                                pythonpath=(str(scratch.path / "src")
                                            if use_scratch and not args.no_src_shadow else None))
    except PristineRunError as exc:
        raise _SuffixArmStop(f"suffix-replay-error") from exc   # keep NEW, NOT exit 2 (§11.6)
    ctx.suffix_replays += 1
    return node in run.failing
```
