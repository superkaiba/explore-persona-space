### 4.4 Detection semantics (decided)

- **Call names — two shapes:** **(A)** an `ast.Call` whose `func` is `ast.Attribute` with `attr == "upload_file"` (matches `api.upload_file(`, `HfApi().upload_file(`, `self.api.upload_file(`) OR `ast.Name` with `id == "upload_file"` (a `from huggingface_hub import upload_file` caller). **(B)** an `ast.Call` whose `func` is `ast.Attribute`/`ast.Name` named `_upload` AND whose keywords carry `upload_as_file=True` as an `ast.Constant` — the literal #664 shape (`for f in files: hub._upload(f, upload_as_file=True)`). Shape B is REQUIRED (round-1 Methodology Must-Fix): `check_upload_as_file` explicitly DEFERS any `_upload` call with an explicit `upload_as_file` kwarg (workflow_lint.py L5088-5094 — "the author's deliberate file/folder declaration"), and the #595 runtime guard *forces* per-file callers onto exactly this kwarg, so without shape B a house-rules-compliant driver writes the storm loop and every lint stays green. An in-loop `_upload` WITHOUT the kwarg is deliberately NOT matched: its folder-default form either is legitimate (a per-dir loop) or crashes fail-loud on the first file via the #595 runtime ValueError, and its static single-file forms belong to `check_upload_as_file`. Exact-name only — `upload_files`, `upload_file_to_hf`, `upload_folder` do NOT match (pinned by a negative fixture, round-1 Statistics concern). **No local-`def upload_file` carve-out** (deliberate divergence from `check_hub_dir_filecount_guard`'s bare-name carve-out): a local wrapper called per-file in a loop still issues one commit per call — exactly the anti-pattern — so it flags; a genuinely-batching local wrapper takes the waiver. Baseline impact: zero beyond the §4.3 grandfathered sets (verified by probe for both shapes).
- **Enclosing constructs that count:** `ast.For`, `ast.AsyncFor`, `ast.While`, and the four comprehension nodes (`ListComp`, `SetComp`, `DictComp`, `GeneratorExp`).
- **Boundary reset:** entering `ast.FunctionDef` / `AsyncFunctionDef` / `Lambda` / `ClassDef` clears loop context — a call inside a function *defined* in a loop does NOT flag (recommended "no": the function body executes elsewhere), and a helper *called* from a loop does NOT flag (lexical analysis only — the accepted false-negative direction; the task body's "fail toward false-negative" constraint).
- **Severity:** FAIL (an `errors` entry ⇒ exit 1), like every sibling — `workflow_lint.py` has no WARN concept; quietness comes from waiver + allowlist.
- **Waiver:** `# UPLOAD_LOOP_EXEMPT: <reason ≥ 10 chars>`, same-line or immediately-preceding-non-blank-line, verbatim `_upload_as_file_waiver_present` placement semantics.
- **Accepted imprecision (documented in the docstring):** a call in a loop's *header* expression (`for x in upload_file(...)` / `while upload_file(...)`) is treated as in-loop even though the `for`-iter form executes once — no such call exists in the tree, `upload_file` returns a commit-info object nobody iterates, and the waiver covers a hypothetical.

### 4.5 Pseudocode

```python
_UPLOAD_LOOP_NODES = (ast.For, ast.AsyncFor, ast.While)
_UPLOAD_LOOP_COMPS = (ast.ListComp, ast.SetComp, ast.DictComp, ast.GeneratorExp)
_UPLOAD_LOOP_BOUNDARIES = (ast.FunctionDef, ast.AsyncFunctionDef, ast.Lambda, ast.ClassDef)


def _upload_loop_waiver_present(lines: list[str], call_lineno: int) -> bool:
    # verbatim copy of _upload_as_file_waiver_present with
    # UPLOAD_LOOP_WAIVER_RE / UPLOAD_LOOP_WAIVER_MIN_REASON_CHARS


def _iter_calls_in_loop_context(tree: ast.Module):
    """Yield (ast.Call, True) for every Call lexically inside a loop.

    Iterative explicit-stack walk (no recursion — run_experiment_444.py is
    5.5k+ lines) carrying an ``in_loop`` bit per node: set on entering a
    loop/comprehension child, cleared on entering a def/class/lambda child.
    """
    stack: list[tuple[ast.AST, bool]] = [(tree, False)]
    while stack:
        node, in_loop = stack.pop()
        if in_loop and isinstance(node, ast.Call):
            yield node
        for child in ast.iter_child_nodes(node):
            if isinstance(child, _UPLOAD_LOOP_BOUNDARIES):
                stack.append((child, False))
            elif isinstance(child, _UPLOAD_LOOP_NODES + _UPLOAD_LOOP_COMPS):
                stack.append((child, True))
            else:
                stack.append((child, in_loop))


def check_upload_file_in_loop(
    *, scripts_dir: Path | None = None, legacy_allowlist: dict[str, int] | None = None
) -> list[str]:
    """AST-walk every *.py under scripts/ and FAIL on any upload_file(...)
    call inside a loop (#664/#658-r4/#1481 per-file-commit storm class).
    [full rationale docstring, mirroring check_hub_dir_filecount_guard's]"""
    root = scripts_dir if scripts_dir is not None else _REPO_ROOT / "scripts"
    if not root.exists():
        return []
    allow = UPLOAD_FILE_IN_LOOP_LEGACY_ALLOWLIST if legacy_allowlist is None else legacy_allowlist
    errors: list[str] = []
    for py in sorted(root.rglob("*.py")):
        if not py.is_file():
            continue
        rel = py.relative_to(root.parent).as_posix()
        text = py.read_text(encoding="utf-8")
        tree = _cached_parse(py, text)
        if tree is None:
            continue  # unparseable file is its own separate problem
        lines = text.splitlines()
        file_findings: list[str] = []
        for node in _iter_calls_in_loop_context(tree):
            fn = node.func
            fn_name = (
                fn.attr
                if isinstance(fn, ast.Attribute)
                else (fn.id if isinstance(fn, ast.Name) else None)
            )
            is_shape_a = fn_name == "upload_file"
            is_shape_b = fn_name == "_upload" and any(
                kw.arg == "upload_as_file"
                and isinstance(kw.value, ast.Constant)
                and kw.value.value is True
                for kw in node.keywords
            )
            if not (is_shape_a or is_shape_b):
                continue
            if _upload_loop_waiver_present(lines, node.lineno):
                continue
            file_findings.append(
                f"{py}:{node.lineno}: {'upload_file(...)' if is_shape_a else '_upload(..., upload_as_file=True)'} "
                f"call inside a loop — the per-file upload loop is the #664/#1481 "
                f"storm anti-pattern (each call = one commit + a server-side repo "
                f"pre-check; a 1425-file loop ran 12h/$530 idle in #664; ~1400 "
                f"planned commits 429-stormed in #1481). Batch into ONE bulk "
                f"commit: HfApi.upload_folder with allow_patterns, "
                f"upload_raw_completions_to_data_repo(), or "
                f"hub._upload_folder_filtered. A genuinely bounded loop (a retry "
                f"wrapper around a SINGLE file, a fixed <=3-file list) may be "
                f"waived with '# UPLOAD_LOOP_EXEMPT: <reason>' (reason >= "
                f"{UPLOAD_LOOP_WAIVER_MIN_REASON_CHARS} chars) on the call's first "
                f"line or the previous non-blank line. See .claude/rules/gotchas.md "
                f"'Per-file HfApi.upload_file 504-storms on a LARGE repo'."
            )
        # Grandfather gate: per-file COUNT vs the allowlist dict — findings
        # suppressed only while count <= grandfathered N; an excess count
        # reports ALL of the file's findings (a new offense in a
        # grandfathered file surfaces instead of hiding behind the entry;
        # known netting quirk, documented in §11: fixing one old site while
        # adding one new nets the same count — accepted, still strictly
        # stronger than the siblings' file-grain frozenset).
        if len(file_findings) <= allow.get(rel, 0):
            continue
        errors.extend(file_findings)
    return errors
```
