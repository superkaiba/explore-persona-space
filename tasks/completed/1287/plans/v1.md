## 0.0 TL;DR (plain English)

- **What I'll change:** the watcher's boot-death lane (#1267) currently ignores a freshly spawned session whose boot turn ran and died with an API-refusal row, because "any response row" — even a failed one — counts as proof of life. I'll change the predicate to "any *successful* response row": a transcript whose only response rows are api-errors is treated as boot-dead, stopped under the same 30-min window / 10-min quiet / 3-per-day bounds, and the existing re-dispatch arms take it from there.
- **What I expect:** a replay of the #1277 incident (refusal-killed boot turn on a `proposed` infra task) recovers in ~40–50 min instead of ~12.5 h, with zero new knobs and zero change to any other lane.
- **What would change my mind:** finding a consumer that depends on the zero-response-rows semantics, or evidence that a healthy session can sit ≥30 min with only api-error rows and a ≥10-min-quiet transcript — either one sends this back to re-plan rather than ad-hoc tuning.

## 3. Hypothesis / expected behavior

A watcher-dispatched auto session whose whole (≤256 KB) transcript contains **no `assistant`-classified row** and is ≥30 min old and ≥10 min quiet is dead — either it never took a turn (#1267's class) or every turn it took failed (#1277's class). Stopping it and letting the existing re-drive arms act recovers `proposed`-status tasks in ~40–50 min and ACTIVE-status tasks in ~30–50 min. Falsifier: any healthy session observed in that state (see Kill criteria).

## 4. Design

### 4.1 Fork resolution — option (a), extend `decide_boot_death`

**Chosen: (a).** Justification against the alternatives:

- **(b) Widen #1209 wedge eligibility to PARK for auto sessions — rejected.** `respawn_eligible` (~L11223) feeds `decide_session_stalled`'s respawn arm and gates the entire `_apply_prompt_wedge_override` probe; PARK = "legitimately waiting on the user or a gate — never re-spawn" is a deliberate, comment-pinned design posture (L610–611). Widening it exposes all five wedge triggers (and their stop+respawn fence) to `plan_pending`/`blocked` sessions where a user may be parked — a much larger false-positive surface than the incident class needs, and a respawn (not stop) action is wrong at PARK anyway.
- **(c) New dedicated arm — rejected.** The boot-death lane already has the right action (stop-not-respawn), the right bounds (3/day cap, fail-toward-keep, no episode belt by design), the right ordering (after `gate_push_pass`, before stale-registration, shared `children` snapshot), and the documented, code-verified re-dispatch trace. A new arm duplicates all of that.
- **(a) is the smallest true fix:** `decide_boot_death` has exactly one production call site (`_process_boot_death`; grep-verified — the symbol appears only in this script, its tests, and docs/plans), the predicate change is one parameter's semantics, and the #1267 docstring's deferral is wrong precisely at PARK statuses — the boot-death lane is the correct owner of "never successfully booted, at any status".

**Predicate form within (a): zero SUCCESSFUL response rows** (no `"assistant"`-classified row anywhere in the whole-file read), NOT the task sketch's "tail row is an api-error row". Tail-row semantics would fire on a long-lived healthy PARK-status session whose single last wake was refused — recreating the #1104 single-refusal over-trigger the wedge lanes guard with a ≥3-consecutive bar. Zero-assistant-rows is strictly the "never successfully booted" subset: one successful turn ever ⇒ keep, forever. The retried-429 shape (api-error then assistant row in the same turn) keeps by construction. Whole-file (not tail) semantics are inherited from `_boot_death_transcript_rows`'s existing whole-file guarantee.

**Quiet threshold keys off transcript mtime (unchanged).** The transcript's last write IS the death row (append-only; the #1267 quiet guard already relies on this on the #1251-class), so mtime ≡ last-row time for this shape; a last-row-ts parse would only add a fail-toward-keep dependency on ts-parseability. A live mid-retry boot turn keeps appending rows ⇒ mtime fresh ⇒ keep; the existing 10-min quiet guard is the in-flight-first-turn race guard for the refusal shape too. **Window stays 30 min** (see §11 for the rejected shorter-window variant).

```python
def decide_boot_death(
    *,
    sid_alive: bool,
    entry_age_s: float | None,
    ok_response_row_seen: bool | None,
    transcript_idle_s: float | None,
    window_s: float,
    quiet_s: float,
    stops_today: int,
    stops_per_day: int,
) -> str:
    """... Fires ONLY on: live sid + registration older than window_s + a
    fully-read transcript with ZERO SUCCESSFUL response rows — either no
    response rows at all (the #1267 die-before-turn-1 shape) or ONLY
    api-error response rows (the #1287/#1277 boot-turn-refusal shape: the
    boot turn executed and every turn FAILED; at a PARK status the
    #1209/#1127 wedge lanes are structurally ineligible —
    respawn_eligible = in_active and ... — so this lane owns the shape)
    + transcript quiet >= quiet_s (the in-flight-first-turn / mid-retry
    guard: a live retrying turn keeps appending rows, so mtime stays
    fresh). Every unresolvable input fails toward keep: ...
    - ok_response_row_seen is None — transcript unresolvable OR larger
      than the tail cap (a >256 KB transcript cannot be a boot-death). ...
    """
    if not sid_alive:
        return "keep"
    if entry_age_s is None or entry_age_s < window_s:
        return "keep"
    if ok_response_row_seen is None or ok_response_row_seen:
        return "keep"
    if transcript_idle_s is None or transcript_idle_s < quiet_s:
        return "keep"
    if stops_today >= stops_per_day:
        return "cap-alert"
    return "stop"
```

```python
def _boot_death_api_error_excerpt(rows: list[dict], cap: int = 200) -> str | None:
    """Best-effort refusal forensic (#1287): the LAST api-error row's message
    text (usage-policy refusal / 429 / 529 body), whitespace-collapsed,
    bounded to ``cap`` chars — sidecar-only (never a marker: refusal bodies
    are trigger-dense). Same defensive shape as _boot_death_stderr_excerpt:
    str content or text-block list; present-but-non-str "text" skipped;
    None when no api-error row carries text. Never raises."""
    for row in reversed(rows):
        if _classify_wedge_row(row) != "api-error":
            continue
        msg = row.get("message")
        content = msg.get("content") if isinstance(msg, dict) else None
        texts: list[str] = []
        if isinstance(content, str):
            texts.append(content)
        elif isinstance(content, list):
            texts.extend(
                b["text"] for b in content
                if isinstance(b, dict) and b.get("type") == "text"
                and isinstance(b.get("text"), str)
            )
        for text in texts:
            collapsed = " ".join(text.split())
            if collapsed:
                return collapsed[:cap]
    return None
```
