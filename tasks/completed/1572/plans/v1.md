One refinement, stated openly: the Goal's parenthetical names `git status --short` as the verification example, but the scratch-repo probe (§12 A4) shows `git status --short -- <dir>` does NOT list ignored files at all (they surface only under `--ignored`, and then only as a collapsed `!! <dir>/` line). The mechanically correct enumerator is `git ls-files --others --ignored --exclude-standard -- <dirs>` (per-file, empty ⇔ nothing skipped), with `git check-ignore -v` retained as the per-file diagnostic naming the matching rule, and `git diff --cached --name-only -- <dirs>` as the staged-set confirmation. This satisfies the Goal's intent (verify every intended file entered the index; probe ignore rules; `git add -f` the convention-committed skips) with a probe that actually detects the incident class — the Goal's examples were illustrative ("e.g." in the filing brief), not prescriptive.
