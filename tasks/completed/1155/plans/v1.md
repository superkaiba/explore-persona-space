Docstring: extend the "five actions" sentence in the `_apply_pod_safety_action` docstring (L7460-7468) with one clause naming the stop-failed sub-branch.

**Retry-cadence proof (why `missed=prev_missed`):** `decide_pod_safety` returns `("stop", 0)` (L2207-2208), so `new_missed` is useless here. Today the failed path saves nothing, leaving the on-disk `missed` at its pre-stop value (e.g. 1 at threshold 2), and the next tick computes `1+1=2 ≥ 2` → stop retried. Saving `missed=prev_missed` reproduces exactly that. Saving `missed=new_missed` (=0) would instead delay the retry by threshold−1 ticks — a behavior change, rejected. Edge case threshold=1 with no prior state file: `prev_missed=0` → next tick `0+1=1 ≥ 1` → retry, identical cadence; the fix newly creates the state file in this case (carrying the dedup flag + `first_seen` for the GC age backstop) — the only observable delta beyond the marker, and it is the mechanism of the dedup.

**Dry-run disambiguation decision:** guard the failed branch with `if dry_run: return` at the CALLER rather than restructuring `_stop_pod`'s return contract. `_stop_pod` has exactly one production caller (L7546) and ~15 test monkeypatches of the `(issue, dry_run) -> bool` shape; changing its contract (e.g. tri-state) would churn all of them for zero benefit. Minimal + behavior-preserving.

**Episode semantics (precise):** one episode = one lifetime of `pod-safety-<N>.json`. The `stop_failed_noted` flag (and hence marker eligibility) resets when (i) a later stop SUCCEEDS → `_clear_pod_safety_state` (L7558-7559); (ii) the pod leaves the RUNNING set on any tick → `_gc_orphan_pod_safety_state` (L5836-5837); (iii) the age backstop `POD_SAFETY_STATE_MAX_AGE_S` reaps the file (L5847-5853). It does NOT reset on progress advancement, a status flip while the file lives, or a same-tick pod_id swap that never leaves the RUNNING set — identical to the documented "once per pod incarnation" semantics of `keep_running_noted`/`followup_noted` (the wedge arm's MF4 pod_id reset at L7168-7185 resets only the WEDGE fields, deliberately untouched here — the #692 forward-carry contract is preserved by (a3)'s None-carry). def test_auto_stop_failure_posts_stop_failed_marker_once_and_stays_retryable(
    isolated_registry, monkeypatch
):
    # #1155: a real `pod.py stop` failure (rc!=0 -> _stop_pod False, NOT
    # dry-run) must (1) post ONE durable stop-failed marker per episode,
    # (2) preserve the pod-safety state so the stop retries next tick,
    # (3) still auto-stop + clear state when a later retry succeeds.
    import json

    import autonomous_session_watch as asw

    now = 1_000_000.0
    stops: list[int] = []
    posts: list[tuple[int, str, str]] = []
    stop_results = iter([False, False, True])  # ticks 2, 3, 4
    monkeypatch.setattr(asw, "_task_status", lambda issue: "completed")
    monkeypatch.setattr(asw, "_task_keep_running", lambda issue: False)
    monkeypatch.setattr(asw, "_task_events", lambda issue: [])
    monkeypatch.setattr(
        asw, "_stop_pod", lambda issue, dry_run: stops.append(issue) or next(stop_results)
    )
    monkeypatch.setattr(
        asw,
        "_post_progress_marker",
        lambda issue, note, dry_run, label: posts.append((issue, label, note)),
    )

    info = _p(489, "p489", "pod-489")[3]
    state_path = isolated_registry / "pod-safety-489.json"

    # tick 1: first miss accumulates (threshold=2) — no stop attempt yet.
    asw._process_pod(489, "p489", info, now, dry_run=False, threshold=2)
    assert stops == [] and posts == []
    assert json.loads(state_path.read_text())["missed"] == 1

    # tick 2: stop attempted and FAILS -> ONE stop-failed marker; state
    # preserved with the miss count untouched (episode retryable).
    asw._process_pod(489, "p489", info, now, dry_run=False, threshold=2)
    assert stops == [489]
    assert [(i, lbl) for i, lbl, _ in posts] == [(489, "stop-failed")]
    assert asw._AUTOSTOP_FAILED_NOTE_SENTINEL in posts[0][2]

    assert [(i, lbl) for i, lbl, _ in posts] == [
