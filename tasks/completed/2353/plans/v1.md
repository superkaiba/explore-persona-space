## Method delta

`_fig_basename`, `_PER_UNIT_EXEMPTION_TOKEN_RE`, `_PER_UNIT_FIG_RE`,

project-aggregate grains plus explicit view-claim idioms.

own incident lineage (#2224). A section can legitimately draw both WARNs
(single figure + caption statistic + no evidence); both are WARN-level, point
at the same remediation, and are covered by one acknowledgment paragraph —
acceptable overlap, documented in the check-59 docs bullet.

## Recognizer design (`_PER_UNIT_CLAIM_RE`)

Starting point (calibration may tune, rails below bind):

```
(?<![a-z0-9])per[-_ ](unit|question|context|point|source|seed)s?\b
|\bpoint[- ]by[- ]point\b
|\bpoints\s+(?:are\s+)?labell?ed\b|\blabell?ed\s+points\b
|\bper[- ]layer\s+profile\b
|\braw\b[^.\n]{0,60}\b(alongside|counterpart|version|view|scatter)\b
|\b(unbinned|low[- ]level)\b
|\b(companion|counterpart)\b
```

Deltas vs `_DECLARED_PAIR_RE` and why:

- **`cell` REMOVED** from the per-<unit> family: the incident section's own
  prose says "test R² per cell" — in this project's v4 bodies "cell" is the
  design-cell (condition × size) aggregate grain, so counting it as per-unit
  evidence false-passes the exact incident this task exists to catch
  (check-31 `indiv` exclusion precedent).
- **`pair` REMOVED** (default): pairing names arm-matching, not unit grain;
  the incident caption says "the 7B pairs coincide" (noun form — would not
  match `per[- ]pair`, but the removal keeps the bar honest). Calibration may
  restore it if the corpus shows real per-pair unit-grain usage AND the
  must-fire rail still holds.
- **ADDED:** `point-by-point`, `points labeled` / `labeled points`,
  `per-layer profile` — the view-claim idioms named in the task body,
  observed in the wild (#2330's r2_vs_n section: "shown point-by-point in the
  per-context cosine strip above, which is their per-unit view").
- Raw-alongside / unbinned / low-level / companion / counterpart inherited
  unchanged.

Scanning scope: the WHOLE block prose layer (not figure-adjacent-only). This
check asks "does the section carry ANY per-unit story?", so generous scope
reduces false WARNs; the false-exemption risk that forced check 49/55's
figure-adjacent scoping is neutralized by removing the aggregate-grain
vocabulary (`cell`) instead.
