## 3. Method delta

**vs the argparse pass (same module):**
1. Same skeleton: whole-module `ast.walk`, all-failures-at-once `SystemExit`, visible-residue idiom, varargs `*module_files`.
2. New: RESOLUTION of AST call nodes to installed callables. The argparse pass never imports anything (pure static sets); the bind pass must map local names to installed objects via the file's own import statements, then `importlib.import_module` + `getattr` (lazy — only modules the file's import map actually references).
3. New escape grain: the argparse escape `extra_defined=` names ATTRIBUTES (no call-site grain); the bind escape is a call-site comment waiver `# ARGCHECK_BIND_EXEMPT: <reason>` (same line or immediately-preceding non-blank line — the established `# WANDB_INTENTIONALLY_DISABLED` placement convention), because a bind failure is per-site.
4. New visibility channel: the argparse pass surfaces residue only inside a failure message; the bind pass ALSO prints a one-line stdout census on PASS (`argcheck-bind: N bound, M degraded, K skipped`) plus one line per skipped/degraded site. Chosen visibility posture — WEAKEN the claim, not grow the design: the census is visible in the run's stdout/log wherever `--import-check` executes, and the smoke-architecture Axis 1 `import-resolution:` marker records the exact COMMAND (making the check reproducible on demand — `.claude/agents/experiment-implementer.md:140-141`, `.claude/rules/code-style.md:169`); the marker does NOT persist the check's output. A3's letter ("explicit and documented, never silent") is satisfied by the stdout census on every run + the failure-message skip re-list + the code-style.md skip-class enumeration; growing the design to persist the census durably is not warranted while the skip set is measured NULL (0 skips fleet-wide, §5) — the residual is documented in §4.5 and carried into the doc edit (§4.7 item g).

**vs the #2223 per-issue test:**
1. Hard-coded receiver name `hub` → import-verified alias mapping (`from explore_persona_space.orchestrate import hub`, `import … as h`, `from …hub import stage_hub_file` all resolve; a name whose import claim is contradicted by ANY other module-wide binding abstains).
2. The #2223 test ASSERTS no `*args`/`**kwargs` at call sites (correct for that one driver); the general pass DEGRADES those to `bind_partial(**named_kwargs)` + census note (the #606/#1332 doctrine) — measured 0 such sites fleet-wide today.
3. Two new resolvable shapes the #2223 test lacks: bare-name calls of symbols imported FROM the registered module (62 sites: bare `stage_hub_file` 18, `retry_transient` 13, `_upload` 8, `stage_hub_prefix` 7, `_upload_folder_filtered` 7, `list_hf_files_under_path` 6, `list_hf_entries_under_path` 2, `verify_repo_paths_uploaded` 1 — the dominant share of the 79 bare-name S2 sites among the 185 measured; the other 17 S2 sites are registered huggingface_hub function calls the #2223 test already resolved; full shape split S1 = 96, S2 = 79, S3 = 10, §5), and `var.method(...)` where every module-wide binding of `var` is an `Assign` to `HfApi(...)` (the uniform-binding rule; 8 sites, all resolve).
4. Per-issue pytest → shared conventional pass armed at every adopter's `--import-check`; the per-issue file keeps its #2223-specific destination pins.

### 4.4 Resolution rules (the subtle part)

Per file: parse once, build the import map, apply the shadow guard, then resolve each `ast.Call`:

```
_bind_import_map(tree) -> dict[local_name, target]:
  ast.Import:      "import a.b.c as h"       -> "h" -> module "a.b.c"; bare "import a.b.c" maps "a" (top package; unregistered -> inert)
  ast.ImportFrom (absolute only; node.level>0 or node.module None -> unmapped):
                   "from a.b import c"       -> "c" ->
                     module  "a.b.c"  if "a.b.c" ∈ _BIND_MODULES          (e.g. from explore_persona_space.orchestrate import hub)
                     class            if ("a.b","c") ∈ _BIND_CLASSES       (e.g. from huggingface_hub import HfApi)
                     function         if ("a.b","c") ∈ _BIND_FUNCTIONS     (e.g. from huggingface_hub import hf_hub_download)
                     symbol-of-module if "a.b" ∈ _BIND_MODULES             (e.g. from ...hub import stage_hub_file -> getattr(hub, "stage_hub_file"))
```

Shadow guard (call-side analogue of the argparse `dest=` discipline): a mapped local name participates in resolution ONLY if its import alias is its SOLE module-wide binding — bindings collected exactly as `_exclusive_use_sole_binding` does (Store-context `ast.Name`, `ast.arg`, `ast.alias`) plus `FunctionDef`/`AsyncFunctionDef`/`ClassDef` names. Any other binding ⇒ the name is unresolvable; every registered-surface call through it becomes a NOTED SKIP, never a bind, never silent. Measured impact today: 0 names fleet-wide (§5).

Resolved call shapes:

- **S1 — module-attribute call** `h.attr(...)`, `h` → registered module: `fn = getattr(importlib.import_module(dotted), attr)`; `AttributeError` ⇒ a check FAILURE naming the site (`references nonexistent helper`) — the #2223 fail-loud getattr, kept. (96 of the 185 measured sites.)
- **S2 — bare-name call** `name(...)`, `name` → registered function, or symbol imported from a registered module: same `getattr` fail-loud. (79 of the 185 measured sites; the full measured shape split is S1 = 96, S2 = 79, S3 = 10 — §5.)
- **S3 — inline constructor-method call** `Cls().m(...)`, `Cls` → registered class: `fn = getattr(Cls(), m)` — binding on the bound method keeps `self` out of the shape; `HfApi()` construction is offline-safe (#2223 test precedent). One cached instance per registered class per invocation. (10 of the 185 measured sites.)
- **S4 — variable-receiver method call** `var.m(...)` under the UNIFORM-BINDING rule: every module-wide binding of `var` (same collector as the shadow guard) is an `Assign`/`AnnAssign` whose value is a direct `Call` to a registered class name that itself passes the shadow guard ⇒ resolve as S3. Any other binding shape ⇒ NOTED SKIP. (Measured: covers all 8 fleet `api.*` call sites, including `issue2220_readwrite.py`'s four per-function `api = HfApi()` re-assigns; 0 abstains today.)
- **Wrapped/deferred:** `ast.walk` descends into `Lambda` bodies, comprehensions, and nested defs, so the INNER call of `hub.retry_transient(lambda: HfApi().upload_file(...))` is visited and bound through S3 like any other node — verified live (§5). The OUTER `retry_transient` call binds too (its required keyword-only `what` is itself checked — genuine extra teeth).
- **Detected-and-noted skips:** `getattr(<registered alias>, <expr>)(...)` immediate-call (measured 0; the one fleet `getattr(hub, …)` site is a `callable()` probe, not a call); S4 receivers failing uniform-binding; `inspect.signature` raising `ValueError`/`TypeError` (un-introspectable callable).
- **Documented out-of-scope FN classes (module docstring + rule prose, not built):** `functools.partial(hub.X, ...)` deferred partial application (measured 0 fleet-wide); a helper whose own signature is `(*args, **kwargs)` binds anything (none on the registered surface — all four probed signatures are real, §5); runtime monkeypatching of a registered helper; check-env vs run-env version drift (same `uv.lock` on VM and pods — residual only on a deviating env).

### 4.5 Bind semantics + failure/visibility contract

```
_bind_call_shape(fn, node):
  kwargs = {kw.arg: object() for kw in node.keywords if kw.arg is not None}
  if any Starred positional or any kw.arg is None (call-site splat):
      inspect.signature(fn).bind_partial(**kwargs)     -> DEGRADED-OK / DEGRADED-FAIL
  else:
      inspect.signature(fn).bind(*[object()]*len(node.args), **kwargs)  -> OK / FAIL
```

Placeholders check SHAPE only (positional count, keyword names, required params, keyword-only-ness) — values never evaluated, no network, no side effects. Keyword-only params and callee-side `*args`/`**kwargs` are handled natively by `Signature.bind` (zero FP by construction on those surfaces).

Waiver: a `# ARGCHECK_BIND_EXEMPT: <reason>` comment on the call's `node.lineno` source line or the immediately-preceding non-blank line converts a would-be FAIL into a NOTED SKIP (reason echoed in the census). Visible at the call site — the `extra_defined=`-equivalent for call grain.
