## 3. Design: file paths + concrete diffs

**The convention idiom** (quoted from the fixed #847 exemplar `scripts/issue778_null_battery.py:33-40`):

```python
from explore_persona_space.orchestrate.env import load_dotenv

# #847: thread caps must land BEFORE the numpy/torch imports below — on the
# shared VM, load_dotenv() setdefaults OMP/MKL/OPENBLAS/NUMEXPR_NUM_THREADS,
# and the BLAS/torch pools freeze at import time.
load_dotenv()

import numpy as np  # noqa: E402
```

The env import sits in its own first-party block after the stdlib block (blank line before/after — isort-clean, probe-verified); the call follows; **every module-level import statement after the call gets `# noqa: E402`** (heavy or not — E402 fires on all of them; for a parenthesized multi-line `from x import (`, noqa goes on the first line, precedent `issue1092_fit_grid.py:37`). Detector semantics confirmed by reading the test: `_first_load_dotenv_line` is a substring scan for `"load_dotenv("` — the CALL line satisfies it (the `from ... import load_dotenv` line has no open paren); the heavy line is the earliest module-top AST import of a `HEAVY_IMPORT_ROOTS` root.

**Ruff-verified empirically** (repo select set `E,F,I,UP,B,SIM,C901,W,RUF`): the exact post-fix shapes pass, every prescribed noqa is *used* (no RUF100), and a missing noqa fails E402. The in-repo alternative — a file-level `# ruff: noqa: E402 — load_dotenv() must run before torch import (shared-VM thread caps)` directive (precedent `issue823_weightspace_compare.py:35`, `issue952_divergence_transfer_cell.py:41`) — is the sanctioned fallback if per-line noqa gets unwieldy; prefer per-line (surgical).
