## Goal

Align the two prose locations in `.claude/skills/issue/SKILL.md` that currently
disagree about how a finding-less `kind: analysis` task is routed at Step 10 —
one says the task self-skips inside `related-work-finder`, the other says it is
routed straight to Step 10d — so a future reader cannot misread the routing
contract.

## Method delta

This is a self-contained prose-alignment edit, not a recipe inherited from any
prior workflow-fix task. There is no training, no eval, no data, no artifact on

entered).

## Chosen phrasing: option (b) — explicit defense-in-depth framing

The brief offered two options:

- **(a)** Delete the inner self-skip prose ("so a finding-less analysis task
  that reaches this branch self-skips cleanly inside the agent").
- **(b)** Keep both, but make the contract explicit: the outer entry condition
  is PRIMARY; the in-agent skip is the redundant DEFENSE-IN-DEPTH backstop.

**Chosen: (b).** The self-skip prose encodes a real, separately-true
correctness fact — the `related-work-finder` agent's own kind/finding-bearing
gate (Step 10c-bis § When to run: "a `kind: analysis` task with no `## Results`
writes a 3-line 'no measured finding' stub and raises no gate"). Deleting that
clause (option (a)) would silently drop the documentation that the agent is
self-protecting, leaving a future maintainer who weakens the entry condition
unaware that a backstop exists. Option (b) removes the contradiction (a reader
can no longer read the two locations as disagreeing about whether a finding-less
analysis task ENTERS the branch) while preserving the backstop fact and labelling
it as exactly that: a redundant safety net the primary entry condition already
prevents from being reached. This matches the project's own defense-in-depth
documentation convention (e.g. the recursion-guard "escape valve … parked, not
auto-routed" prose in `workflow-fix-on-bug.md`).

The fix reframes Location 1's clause from an assertion that the branch IS
reached ("a finding-less analysis task that reaches this branch self-skips")
into a statement that it is NOT reached on the primary path, with the in-agent
gate named as the redundant backstop. Location 2 stays the authoritative
primary-path statement and is unchanged.
