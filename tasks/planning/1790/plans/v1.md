# Plan v1 — task #1790: move msg-strip comments out of the Step 10d TG node-grain pipelines

## Requirement

The two Step 10d TG node-grain subtraction pipelines in
`.claude/skills/issue/SKILL.md` (the shared pre-push gate block and the
form (iii) surgical block) carry two comment lines
(`# msg-strip caveat: ...`) interposed AFTER a backslash
line-continuation and BEFORE the `| sed -E ...` stage. Under bash the
continuation joins the comment onto the `grep -E '^(FAILED|ERROR) '`
line, the `#` terminates the command, and the next line's bare `| sed`
is a syntax error — the fenced blocks are not copy-paste-executable
(`bash -n` fails). Orchestrators execute these blocks verbatim, so a
verbatim copy dies at the node-grain legs, silently degrading the #1573
node-grain arm.

**Requirement:** relocate the two comment lines ABOVE the
`grep -E '^(FAILED|ERROR) '` command at BOTH sites, preserving the
comment text and the pipeline commands byte-for-byte, so the extracted
blocks pass `bash -n`.

## Acceptance criteria

1. Both occurrences fixed (currently `.claude/skills/issue/SKILL.md`
   lines ~11153 and ~12721; locate by the literal

   relocation).

The delta vs the current file is exactly the filing's diff sketch,
applied at both sites:
