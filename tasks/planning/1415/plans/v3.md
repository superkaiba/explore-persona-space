# Plan: Causal test of the context/answer vectors (task #1415)

---

## 0.0 TL;DR (plain English — the user reads this first)

- **What I'll run.** On Qwen-2.5-7B-Instruct, I'll add Δ = V_c(c′) − V_c(c) (the difference of last-context-token residual activations) to the running residual stream at a chosen layer, generate responses on-policy, and measure whether the answer state shifts toward V_a(c′) and whether behavior shifts with it. I'll sweep 28 context pairs (15 matched-query persona/instruction swaps, 13 cross-query swaps), cover layers 7/10/14/17/20/21/24, and use both prefix-based and context-based extraction arms. Four controls: KV-swap ceiling (maximum-effect gold standard), norm-matched random-Δ null, shuffled-pair-Δ null, and the Persona Vectors r_B steering baseline.
- **What I expect.** H1 (sufficiency): last-token steering will shift answer state partially — directionally correct but under the KV-swap ceiling. Based on #1092's finding that the query factor carries 78–94% of trait-direction variance, a last-token prefix-based steering that ignores the query position will capture at most the prefix component. H2 (map transport): the fitted V_c→V_a map will predict the steered answer profile above the null band but well below the KV-swap ceiling due to the content-identity confound (#823). H3 (pair quality): matched-query Δ will outperform cross-query Δ because the query text is identical.
- **What would change my mind.** If last-token steering achieves >80% of KV-swap ceiling performance in geometric projection, the prefix state is near-sufficient for the answer state (contradicts #1092's query-dominance finding). If map transport fails entirely (steered answer no closer to f(V_c+Δ) than to f(V_c)), the fitted maps are purely memorized correlations with no generalization to interventional distributions.

## 0. Plan Summary

**Training:** No new training. This is a forward-pass activation-capture + steering experiment on the frozen pretrained Qwen-2.5-7B-Instruct model.

**Hyperparameters:** Steering scale α ∈ {0.5, 1.0, 2.0, 4.0} (a coherence-gated SEARCH GRID, not a committed value; the exact grid is ungrounded — needs smoke-test — the coherence gate calibrates the usable α in-run; convention loosely follows arXiv 2507.21509 / #816, unverified at draft); layer sweep {7, 10, 14, 17, 20, 21, 24} (Source: #685 cosine-peak band 7–21 + #841/#922 primary block 20); 28 context pairs (15 matched-query, 13 cross-query) with N=10 on-policy samples per condition (Source: arXiv 2507.21509 extraction rollout count).

**Baselines / controls:** (1) KV-swap ceiling (full prefix substitution — maximum causal effect), (2) norm-matched random-Δ null (same ‖Δ‖ as the treatment but random direction; 500 draws), (3) shuffled-pair-Δ null (real Δ vectors but paired to wrong targets; 500 permutations), (4) r_B persona-vector steering baseline (arXiv 2507.21509 recipe, coherence-gated α).

**Loss surface:** N/A — no training.

**Compute:** 1× A100-80 GCP (`lora-7b` intent, capture-7b routing); ~12 GPU-hours total. Estimated GPU-hours (total): 12

**Evaluation:** Geometric primary: projection of realized steered V_a onto (V_a(c′) − V_a(c)); map-transport ratio f(V_c+Δ) agreement; selection-symmetric per-draw max-over-layer bands. Behavioral dual-DV: graded 0–100 judge primary + binary rate companion.

**Risks:** (1) Steering at a single last-token position may have negligible effect (expected per #1092 query dominance — interesting null if confirmed); (2) map reuse from #922 requires fitness check — if maps are style-specific (#823) they may not transport.

## 1. Goal

(Task #1415 Goal, verbatim.)

> On Qwen-2.5-7B-Instruct, test whether the context vector V_c (last-context-token residual activation) is causally sufficient for the answer state and behavior it predicts: patch context c with Delta = V_c(c″) - V_c(c) (matched-query persona/instruction swaps and cross-query swaps; prefix-based AND context-based arms; layer + position sweeps), generate on-policy, and measure (a) the realized mean answer activation's shift from V_a(c) toward V_a(c″) and its agreement with the fitted map's counterfactual prediction f(V_c + Delta), and (b) the judge-scored behavior shift (graded 0-100 primary + rate companion), against norm-matched random-Delta and shuffled-pair nulls, a full-prefix KV-swap ceiling, and the persona-vector r_B steering baseline, with a logit-lens top-token readout of V_c, V_a, Delta, and the #922 slow modes as descriptive companion.

This experiment is the first causal test in the context→answer mapping line (#685, #779, #823, #841, #922, #1092). The entire prior line is correlational — every finding is a probe / regression / teacher-forced predictability claim on frozen models. This design upgrades the causal standing of the vectors: if last-token activation patching shifts on-policy behavior, V_c has genuine causal relevance; if not, V_c is a correlate of what the prefix conveys via the full KV cache.

## 2. Prior Work

**In-house line (context→answer mapping):**
- #685: Base-model context vectors; V_c shifts along one dominant direction (cosine 0.75–0.90) when a behavioral instruction is added; layers 7–21 are the key band.
- #779: V_a carries trait content; R² 0.79–0.87 held-out, AUROC 0.9821; pv_raw overall_r = 0.6364; oracle overall_r = 0.8590.
- #823: Fitted V_c→V_a map; content-identity baseline beats the map; style-specific; peak R² ~0.51–0.53 at layer 20 (`eval_results/issue_823/ridge_r2_by_arm.json`).
- #841: primary block = 20, ceiling_raw_target = 0.4996 (`eval_results/issue_841/stage1_benchmark.json`).
- #922: Rolled GRU/MLP map; slow modes; fixed-point spectral analysis (layer 14: spectral_radius = 0.9896, 3 modes |λ|≥0.98, 12 modes |λ|≥0.95); map artifacts on HF.
- #1092: Query factor carries 78–94% of trait-direction variance; prefix factor ≤5%.
- **Critical caveat (#823):** the map reads answer-content match, not self-generation dynamics — a content-identity baseline beats the context→answer map, so large parts of the map's R² may not transport under intervention.

**Literature (lit-review-first rule):**

- **Persona Vectors (arXiv 2507.21509, Chen/Arditi/Sleight/Evans/Lindsey 2025):** Closest design. r_B = diff-of-means of mean-pooled response activations between positive/negative contrastive prompt pairs. Steering by adding α·r_B to the residual stream during generation. Coherence-gated scale (generate → check coherence). Layer selection: sweep all layers, select by steering effectiveness. Our design adopts the r_B recipe as the baseline control arm.

- **Function Vectors (arXiv 2310.15213, Todd/Li/Sharma/Mueller/Bau/Hermer 2023):** Last-token activation at a single layer during in-context-learning demonstrations encodes the task; adding this to a new context transfers the task zero-shot. Layer 15–17 (GPT-2 family, 24L). *(Paper-specific layer/position conventions in this and the next bullet were NOT re-verified against the papers at draft time — fact-checker verdict UNVERIFIED; the layer sweep's operative grounding is the in-house #685/#841/#922 line, and the arXiv cites are secondary convention anchors.)* Our design extends this to persona contexts: Δ = V_c(c′) − V_c(c) vs. ICL: FV = mean activation over demonstration examples. Key difference: (1) we test at the last CONTEXT token position (not a demo-averaged vector), (2) our DV is answer-profile shift AND behavior shift (not just accuracy), (3) we compare against a fitted-map prediction f(V_c+Δ) as an additional DV.

- **Task Vectors / In-Context Vectors (arXiv 2310.15916, Hendel et al.; arXiv 2311.06668, Liu et al.):** Task vectors are intermediate layer representations that encode a task from ICL; ICVs are averaged at the last token of demonstrations. Both find that shifting the residual stream at middle layers transfers the task. Confirm that: (a) last-token position is sufficient (not full-sequence average), (b) middle layers (not first or last) are most effective, (c) the steering effect degrades at extreme layers. Our design pre-registers layer 20 as primary (from #841/#922) and sweeps {7, 10, 14, 17, 20, 21, 24} to check layer dependence.

- **Activation Patching / Causal Tracing (Meng et al. 2022; Vig et al. 2020):** The gold-standard is patch-and-generate with the KV cache fixed at the target context — our KV-swap ceiling. The methodological contribution here is comparing a lightweight single-token patch (Δ at one position) against the full KV-swap ceiling to quantify how much causal effect routes through the last-token state.

**Design delta from function-vector / ICV literature:** This experiment studies _persona/behavioral_ contexts (not ICL task demonstrations), uses a _fitted-map prediction_ as a second DV (not just zero-shot transfer accuracy), and runs both _prefix-based_ and _context-based_ extraction arms per the project's standing mapping rule. The two-arm requirement is in-house; no prior function-vector paper runs it.

## 3. Hypothesis

**H1 (sufficiency):** Adding Δ at the last context token shifts V_a(c_steered) in the direction of V_a(c′) − V_a(c). The shift is directionally positive but partial — expected under #1092's finding that the prefix factor carries ≤5% of trait-direction variance, while the query factor carries 78–94%. The projection of the realized shift onto the target direction will lie between the random-Δ null and the KV-swap ceiling.

**H2 (map transport):** The fitted map predicts f(V_c+Δ) closer to the realized V_a(c_steered) than f(V_c), but partial: the content-identity confound (#823) means only the non-identity component transports. Specifically, the cosine similarity cos(V_a(c_steered) − V_a(c), f(V_c+Δ) − f(V_c)) > 0 at the max-selected layer.

**H3 (pair construction):** The matched-query Δ (same question, different persona/instruction) achieves higher geometric projection than cross-query Δ, because #1092 shows the query dominates trait-direction variance.

**Quantitative thresholds (pre-registered):**

- H1 Confirmed: projection onto target direction > random-Δ null p97.5 at max-selected layer, AND projection < KV-swap ceiling at all layers (partial-not-full sufficiency).
- H1 Falsified (strong): projection ≥ 80% × KV-swap ceiling at ANY layer (last-token is near-sufficient — contradicts #1092).
- H1 Falsified (null): projection ≤ random-Δ null p97.5 at ALL layers.
- H2 Confirmed: cos(realized_shift, map_predicted_shift) > shuffled-pair-Δ null p97.5 at max-selected layer, with the map-transport ratio (cosine) > 0.2.
- H2 Falsified: cos ≤ shuffled-pair-Δ null p97.5 at ALL layers.
- H3 Confirmed: matched-query projection > cross-query projection (one-sided paired t-test, p < 0.05, N=15 vs N=13 pairs).

DISJOINT and exhaustive: H1 Confirmed ⇔ geometric projection > random-Δ null p97.5 AND < 80% × KV-swap ceiling at the max-selected layer; H1 Falsified-strong ⇔ geometric projection ≥ 80% × KV-swap ceiling at any layer; H1 Falsified-null ⇔ geometric projection ≤ random-Δ null p97.5 at all layers; Inconclusive ⇔ otherwise.

The H1 lattice above is the registered primary verdict. H2 and H3 are reported with directional tests (thresholds in the list above) without their own four-way lattice — their Confirmed/Falsified lines are the whole registry for them.

**Paired-contrast source coverage (H3):** H3's matched-vs-cross comparison is the plan's one paired contrast. Per-arm source coverage: the matched-query arm draws its 15 pairs from `issue685_context_shift/analysis_tensors/` (10 pairs) + the #779 per-condition V_c bank (5 pairs); the cross-query arm draws its 13 pairs from the same #779 condition bank (§4.2). Both arms share the extraction recipe, the layer sweep, the α grid, and the N=10 rollout count — the pair-construction type is the only differing factor.

**Kill criteria (pre-registered; jointly satisfiable with the success thresholds above — the kill criteria concern the measurement machinery, the success criteria concern the steered arm):**
- K1: the KV-swap ceiling itself shows no separation — ceiling geometric projection within the random-Δ null band AND ceiling judge-score shift < 5 points on the 0–100 scale for >80% of pairs → the pair bank carries no usable signal; ABORT the steering sweep after Phase 1b and report.
- K2: the coherence gate fails at ALL α values for >50% of pairs in the 1-cell pilot + first 5 pairs → the single-position addition recipe is unusable as designed; halt Phase 1c and report the coherence-failure finding.
- K3: the reused #922 map artifact fails its execution-time structure/realized-keys check AND the fallback ridge refit from #779 tensors also fails held-out sanity (R² < 0.2 at layer 20, vs #823's ~0.51) → drop the H2 map-transport DV (report H1/H3 only, H2 as not-run).
Self-check: K1/K2/K3 can each fire without contradicting any H1/H2/H3 threshold — no two gates demand opposite signs on the same measurement.

**Selection-symmetric nulls:** The headline statistic for H1 is max over layers {7, 10, 14, 17, 20, 21, 24}. Every null draw (both random-Δ and shuffled-pair-Δ) receives the IDENTICAL max-over-layer selection before the band is formed. Achievable ceiling: the KV-swap ceiling geometric projection (the upper bound is itself estimated from data; conservative interval: treat KV-swap projection as the DV ceiling). Band-vs-ceiling: the random-Δ null band's 97.5th percentile will be compared to the KV-swap ceiling; if the band's upper bound ≥ KV-swap projection, the test is uninformative-by-construction and will be narrated as failure-to-reject.

Per-draw × per-axis matrix will be persisted to `analysis_tensors/issue_1415/null_matrices/` on HF data repo.

## 4. Design

### 4.1 Model and infrastructure

- **Model:** `Qwen/Qwen2.5-7B-Instruct` (28 layers, hidden dim 3584, vocab 152,064).
- **Extraction:** `src/explore_persona_space/analysis/extraction.py::extract_layer_activations()` (forward hooks, subset of layers, memory-safe, `logits_to_keep=1` OOM guard).
- **Generation:** vLLM `LLM.generate()` for on-policy samples (CLAUDE.md always-on rule). `VLLM_WORKER_MULTIPROC_METHOD=spawn`. `max_new_tokens=1024`.
- **HF forward hooks for steering:** `model.model.layers[L].register_forward_hook()` adds Δ (scaled) to the residual stream at the last context token position during generation. Must use HF `model.generate()` for the steering pass (vLLM does not expose per-step hook injection). This is the standard persona-vector steering recipe (`.claude/rules/persona-vectors-recipe.md`; memory: "Persona Vectors steering needs HF generate()").
- **Two-model pattern:** vLLM for baseline/ceiling on-policy generation (fast); HF for steered generation (with forward hook). Both on the same A100-80 pod (load/unload sequentially; HF ~14 GB weights fit in A100-80's 80 GB HBM alongside vLLM resident).

### 4.2 Context-pair bank (28 pairs)

**Matched-query pairs (15):** Same query, different system-prompt persona/instruction. Sources:
- 10 pairs from `issue685_context_shift/analysis_tensors/` on HF data repo (`base_context_vectors.pt` vs `instruct_context_vectors.pt` paired over the same question set — these are exactly the matched-query persona/instruction swaps).
- 5 additional pairs constructed fresh from #779's contrastive persona bank (evil vs neutral, evil vs sycophantic, etc.) using `issue779_monitoring/r_b/` context vectors and `issue779_monitoring/analysis_tensors/pass_a/` per-condition V_c tensors (e.g., `evil__sys0_cx.pt` vs `evil__sys1_cx.pt` — different shot-count conditions on the same underlying question set).

**Cross-query pairs (13):** Different queries under the same or different personas. Constructed from the #779 condition bank: pair the evil-persona V_c with the sycophancy-persona V_c over different question sets. These test whether the Δ still conveys useful direction when the query text changes.

**Data-source tier:** tier 3 — diverse LLM-generated synthetic (the persona/instruction prompt banks and question sets inherited from #685/#779 are persona-vectors-style generated corpora). Justification for tier 3: the construct under test is the representation geometry of persona/instruction CONTEXTS with pre-existing V_c/V_a captures and fitted maps; no established external benchmark provides matched-query persona pairs aligned with the #685/#779/#922 artifact line, and reusing the exact banks is what makes the causal read comparable to the correlational parent results. The banks are diverse (multiple personas × behaviors × question sets), not flat templated.

N/A — not a behavior-implantation

**Disjointness check:** The question bank used to build the pair bank is checked against the eval question bank (40-question persona-vectors extraction set, arXiv 2507.21509) using a character-level overlap filter. Pairs with >5% question overlap are excluded.

**On-policy generation per context:** For each context c (not the steered version), draw N=10 on-policy samples with temperature 1.0, vLLM batched. These are the "baseline" completions for behavioral DV.

### 4.3 Extraction: V_c and V_a

**Prefix-based arm:** V_c(c) = residual stream at the last token of the prefix (system prompt + persona, no user query), at layer L. Extracted via `extract_layer_activations()` with the prefix truncated at the final prefix token.

**Context-based arm:** V_c(c) = residual stream at the last token of the full context (system prompt + persona + user query), at layer L.

Both arms are mandatory per the project's standing "Prefix mapping AND context mapping" rule (CLAUDE.md Critical Rules).

**V_a(c) extraction:** For each context c, run a forward pass on the full context + N on-policy samples (vLLM-sampled), then extract the residual stream at every answer token position (after the final context token), mean-pool over the answer span, giving V_a(c) ∈ ℝ^{3584} per layer per sample, then mean over samples.

**Layer sweep:** L ∈ {7, 10, 14, 17, 20, 21, 24}. Layer 20 is the pre-registered primary (Source: #841 primary_block=20, #922 readout_benchmark.json frozen_system_point=0.4996 at block 20).

### 4.4 Steering intervention

For a context pair (c, c′) and scale α:

```python
delta = V_c_prime_L - V_c_L  # shape (3584,)
delta_scaled = alpha * delta  # alpha in {0.5, 1.0, 2.0, 4.0}

# Register a forward hook on layer L of HF model:
def hook_fn(module, input, output):
    # output is a tuple; first element is the hidden state (B, T, H)
    hidden = output[0]
    last_ctx_idx = context_length - 1  # last context token index
    hidden[:, last_ctx_idx, :] += delta_scaled
    return (hidden,) + output[1:]
```

**Coherence gate (from arXiv 2507.21509):** After steering, check that the generated response is coherent (≥50% of the 10 on-policy steered samples pass a fluency/coherence check; a response < 5 tokens or "I cannot" = incoherent). If coherence < 50% at a given α, reduce α by 0.5 and retry. Record the α used per pair.

**Position sweep:** Primary = last context token only (the canonical recipe). Additional: patch at ALL answer token positions during generation (add Δ to every generated token's residual state). This tests whether continuous steering of the answer-span state adds substantial causal effect over single-position patching.

### 4.5 KV-swap ceiling

Generate N=10 samples under context c′ directly (no steering — actual context substitution). This is the gold-standard maximum causal effect: V_a(c_kv_swap) = V_a(c′). The geometric projection of V_a(c′) − V_a(c) onto the target direction = 1.0 by construction (the target direction IS V_a(c′) − V_a(c)). The KV-swap establishes the achievable behavioral shift ceiling.

### 4.6 Random-Δ null

For each pair (c, c′), draw 500 random directions from the unit sphere in ℝ^{3584}, scaled to ‖Δ‖ (norm-matched). Apply each random direction as the steering vector and measure geometric projection. The null band is the distribution of max-over-layer projections over 500 draws, per pair.

**Batching for compute efficiency:** All 500 draws for a given pair are batched into a single forward pass using the same hook mechanism with a batch of 500 synthetic Δ vectors (one per batch item). The per-draw max-over-layer matrix is persisted to HF before any per-pair aggregation.

**Selection symmetry:** The null band uses max-over-layer selection (same as the observed statistic) per draw. Implemented as: for each draw d, compute projection at each of the 7 layers, then take max — yielding one scalar per draw, forming the null distribution over 500 scalars.

### 4.7 Shuffled-pair-Δ null

For each pair (c, c′), use the Δ vectors from OTHER pairs (shuffled pairing) but scaled to the actual pair Δ norm. This tests whether it is the direction that matters (not just the magnitude). 500 permutations of the pair-to-Δ assignment.

### 4.8 r_B persona-vector baseline

Recipe per `.claude/rules/persona-vectors-recipe.md` and arXiv 2507.21509:
- Reuse `issue779_monitoring/r_b/evil.pt`, `sycophancy.pt`, `hallucination.pt` from HF data repo (shape 28×3584 each, per-layer diff-of-means direction).
- For each trait's r_B, apply as the steering vector with coherence-gated α (same search: α ∈ {0.5, 1.0, 2.0, 4.0}).
- **Note:** arXiv 2507.21509 uses the steering-selected layer (one per trait), not a sweep. Per the persona-vectors recipe standing rule, we report both the steering-selected layer and the sweep for this baseline.

### 4.9 Behavioral DV (dual-DV rule)

**Primary (graded 0–100 judge):** For each on-policy generation, judge it for the target behavior (evil/sycophancy/instruction-following as appropriate per the pair) using `claude-sonnet-4-5-20250929`. Reason-then-score rubric, `max_tokens=300`, multi-sample N=5 judge draws per completion at temperature 0.6, mean-aggregated. Drop malformed/REFUSAL/out-of-range returns (content drops). Transport errors: retry via `api_dispatch.py` with AIMD backoff. Report per-arm drop rate split into content-drops and transport-losses.

**Secondary (binary rate companion):** Fraction of on-policy samples judged ≥ 50 (positive threshold).

**Anthropic Batch API:** The judge set is 28 pairs × 4 α values × N=10 samples × 5 judge draws × 2 arms (prefix/context) = ~11,200 judge calls. Use the Anthropic Batch API (rule: large sets ≳ a few thousand calls).

### 4.10 Geometric DV

**DV (a) — projection:** For steered context c_steered, compute V_a(c_steered) as mean over N=10 on-policy steered samples (using HF model.generate() with hook). Then:
```
projection = dot(V_a(c_steered) - V_a(c), normalize(V_a(c') - V_a(c)))
```
Normalized to unit target direction. Reported per layer per pair, then aggregated (mean across pairs, max over layers for the headline).

**DV (b) — map-transport ratio:** The reused #922 map f predicts:
```
f_predicted_delta = f(V_c + delta) - f(V_c)  # predicted answer shift
realized_delta = V_a(c_steered) - V_a(c)      # realized answer shift
transport_cosine = cosine(realized_delta, f_predicted_delta)
```
Reported per layer per pair, max over layers for the headline. Null band from shuffled-pair-Δ (same selection symmetry).

### 4.11 Logit-lens descriptive companion

For each V_c(c), V_a(c), Δ, map fixed-point L*, and the top-3 slow modes (spectral radius ≥ 0.98 at layer 14 per #922), compute the top-10 promoted tokens under the model's unembedding matrix:
```
logit_lens(v) = model.lm_head(model.model.norm(v))
top_tokens = argsort(logit_lens(v), descending=True)[:10]
```
This is a descriptive companion only (no null comparison needed; near-zero GPU cost as it is a single unembedding multiply per vector). Reports which tokens "V_c thinks will come next" vs which "V_a embodies" vs which "Δ promotes."

### 4.12 Analysis pipeline

**Phase 1 (GPU, ~8h):** Capture V_c and V_a for all 28 pairs × 7 layers × 2 arms. Run steered generation (HF model.generate() with hook) × 4 α values × 28 pairs × 7 layers. Run KV-swap baseline. Total: on pod.

**Phase 2 (CPU, ~2h):** Null battery (500 draws × 28 pairs × 7 layers — fully batched as one large tensor operation using pre-computed random directions; the pool reduction is pre-computed once). Map transport computation (matrix multiply with reused #922 map weights). Logit-lens. Judge API calls via Batch API (off-pod, ~2h wall clock, deadline-bounded `batch_judge` poller). On VM (footprint < 50 GB).

**Phase 3 (CPU, <1h):** Statistical analysis, figure generation. On VM.

**Per-GPU-phase parallelization:** 1× A100-80 pod. The work is inherently sequential within phases (HF sequential forward hook; vLLM single-GPU). No DP/TP available for a 1-GPU pod. The pod is right-sized: a 7B model captures at batch 8 fit comfortably in 40–50 GB HBM (7B bf16 weights ~14 GB + batch 8 × seq 2048 × 3584 × 28 × 2 bytes KV cache ≈ 7 GB → ~21 GB), well within A100-80's 80 GB. **Parallelization across layers:** the 7-layer sweep in Phase 1c is the main parallelism opportunity. Shard it: run 4 layers on the first pass (7, 10, 14, 17) and 3 layers on the second (20, 21, 24). Since the job is single-GPU, this is a sequential loop, not true parallelism. The wall-clock is dominated by HF generate() in 1c. A 2-GPU pod would allow simultaneously computing activations at two layer subsets, but the marginal gain is modest (2× speedup on 1c, saving ~4h) vs the added cost; retain single GPU.

**Disk footprint (pod-side):** V_c and V_a activations: 28 pairs × 7 layers × 2 arms × N=10 × 3584 floats × 2 bytes = ~1.1 GB per phase (well within A100-80 pod's disk). Steered generations: 28 × 4 × 7 × N=10 samples × ~256 tokens × 2 bytes ≈ 1.3 GB text. Total pod disk: ~10 GB well within the 130 GB MooseFS quota.

**VM footprint for Phase 2:** Null matrix: 500 draws × 28 pairs × 7 layers × 1 scalar = 98,000 floats = 0.4 MB (negligible). Map transport: map weights from #922 = <1 GB. Total Phase 2 VM footprint: <5 GB. Routes to VM (well under 50 GB threshold).
