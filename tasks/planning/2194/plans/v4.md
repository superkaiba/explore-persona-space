### Step 1 — the convention (decision, no code)

- **Key:** `phase`. **Type:** `str`. **Placement:** INSIDE the reproducibility-card / metadata block, as a SIBLING of the commit key — the exact level `check_code_sha_cards._walk` reads (`obj.get("phase")` where `obj` holds `git_commit`). A top-level `phase` beside a nested card block is NOT the convention (measured to be invisible: the #2162 stage2 shape).
- **Value shape:** lowercase slug `^[a-z0-9]+([-_][a-z0-9]+)*$`; kebab-case preferred; RECOMMENDED to equal the driver's own `--phase` argument / `[phase=...]` breadcrumb token (realized examples: `bank`, `anchors`, `grid`, `margin`, `stage2-upload`, `upload_tbmp`). Free string, NOT a controlled cross-issue vocabulary (phases are per-issue pipeline stages; a global vocabulary would be vacuous or perpetually stale) — the exact-match channel makes pairing mechanical without one, since the report author copies the card's own phase string into the Code-SHAs row label.
- **Collision fence (best-effort, not exhaustive):** the most confusable lifecycle-state values are REFUSED at write time (denylist `{done, failed, running, pending, queued, started, workload}`). Top-level `phase` in backend sentinels (`backends/artifacts.py:493` et al.) stays the LIFECYCLE vocabulary; card-block-interior `phase` is PHASE IDENTITY. The structural separation (top-level vs commit-sibling placement) is the primary defense; the denylist is a second, best-effort fence — the backend emits further lifecycle values (`startup`, `preflight`, `wedged`, `finalize_failed_artifacts_ok`) the denylist deliberately does not enumerate. Both facts get documented as such (step 3).

### Step 2 — writer side: `src/explore_persona_space/orchestrate/provenance.py` + the live shared writers

```python
_PHASE_IDENTITY_RE = re.compile(r"^[a-z0-9]+([-_][a-z0-9]+)*$")
_LIFECYCLE_PHASE_VOCAB = frozenset(
    {"done", "failed", "running", "pending", "queued", "started", "workload"}
)

def validate_phase_identity(phase: str) -> str:
    """Validate a card phase-IDENTITY slug; returns it verbatim or raises ValueError.

    Phase identity names the pipeline stage a reproducibility card belongs to
    ("stage2-upload", "grid-anchors") — NOT lifecycle state: backend sentinels
    use top-level {"phase": "done"} for state (backends/artifacts.py), a
    different vocabulary at a different level. The denylist refuses the most
    confusable lifecycle values as a BEST-EFFORT fence (the backend emits more
    lifecycle values than are enumerated here; the structural top-level-vs-
    commit-sibling placement is the primary separation). Fail-loud is
    deliberate: the value is a hardcoded literal at the call site, so a
    violation is a programming error, not runtime degradation (the module's
    never-crash contract covers environment failures, not caller-contract
    violations).
    """
    if not isinstance(phase, str) or not _PHASE_IDENTITY_RE.fullmatch(phase):
        raise ValueError(f"phase identity must match {_PHASE_IDENTITY_RE.pattern!r}: {phase!r}")
    if phase in _LIFECYCLE_PHASE_VOCAB:
        raise ValueError(
            f"phase identity {phase!r} collides with the backend-sentinel LIFECYCLE "
            "vocabulary — name the pipeline stage instead (e.g. 'stage2-upload')"
        )
    return phase

def as_metadata_dict(prov: GitProvenance, *, phase: str | None = None) -> dict[str, object]:
    out: dict[str, object] = {
        "git_commit": prov.commit_sha_full or prov.commit_sha,   # see (b)
        "git_dirty": prov.dirty,
    }
    if phase is not None:
        out["phase"] = validate_phase_identity(phase)
    # ... existing dirty_paths / argv0 fields unchanged ...
```

```python
def _phase_norm(text: str) -> str:
    """Exact-match normalization for phase identity: lowercase, every
    non-alphanumeric deleted ('stage2-upload' == 'Stage 2 Upload').
    LOSSY: distinct raw slugs can collide ('stage1-0-upload' vs
    'stage-10-upload' -> 'stage10upload') — the collision guard below
    refuses to pair on any collided or conflicted key."""
    return re.sub(r"[^0-9a-z]+", "", text.lower())
```
