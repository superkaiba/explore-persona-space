### 4.1 Arm (a) — dotted-module string references (reason `dotted-ref:<touched file>`)

Reuse `touched_module_names(touched)` and match only its DOTTED names (`scripts.X`, `explore_persona_space.a.b`; the flat name `X` is deliberately EXCLUDED — a boundary-bounded flat token like `task` or `eval` matches the English word and would mass-over-select; a flat-string `monkeypatch.setattr("X.attr", ...)` ref requires the test to import `X` to execute, which the import arm already covers). Boundary regex, compiled once per name:

```python
re.compile(rf"(?<![A-Za-z0-9_.]){re.escape(name)}(?![A-Za-z0-9_])")
```

Left boundary excludes `.` so `a.scripts.task` doesn't fire; right boundary excludes identifier chars so `scripts.task` does NOT fire on `scripts.task_progress` / `scripts.task_state`. Matched inside the existing single `_scan_test_files` read pass (a cheap `name in text` substring pre-check before the regex). Never sets `matched` (string ref = pin-shape evidence, the literal-path precedent).

### 4.2 Arm (b) — bare-basename references (reason `basename-ref:<touched file>`)

For every `literal_path_targets`-eligible file (`.py` AND `.sh` — the #1579 symmetry), match the basename with a left+right identifier boundary:

```python
re.compile(rf"(?<![A-Za-z0-9_]){re.escape(Path(f).name)}(?![A-Za-z0-9_])")
```

The boundary is what bounds over-selection: 63/1596 eligible basenames are substrings of another eligible basename (measured), and raw-substring matching on `task.py` hits 69 test files vs 59 boundary-bounded (e.g. `codex_task.py` no longer fires). Never sets `matched`. Note the basename pattern also matches inside full paths — same test, same touched file, deduped by the reason-set union; harmless.

### 4.3 Arm (c) — discovered one-hop transitive import (reason `transitive-import:<touched file>`)

Chosen: option (i), a DISCOVERED arm, bounded to scripts/-local edges on BOTH ends. New helper (names indicative):

```python
def transitive_import_map(touched: list[str], work_root: Path) -> dict[str, set[str]]:
    """{intermediary scripts-module name -> touched scripts/ files it imports}, ONE hop (#1688).

    Zero file reads unless a touched file resolves to a scripts/ module name.
    Never recursive: intermediaries' own importers are NOT followed.
    """
    module_map = touched_module_names(touched)
    script_names = {n: {f for f in fs if f.startswith("scripts/")} for n, fs in module_map.items()}
    script_names = {n: fs for n, fs in script_names.items() if fs}
    if not script_names:
        return {}
    tokens = {n.rsplit(".", 1)[-1] for n in script_names}
    touched_set, out = set(touched), {}
    for path in sorted((work_root / "scripts").rglob("*.py")):
        if "__pycache__" in path.parts:
            continue
        rel = path.relative_to(work_root).as_posix()
        if rel in touched_set:
            continue                       # already a DIRECT target
        # read fail-soft (OSError/ValueError -> ONE stderr WARN, skip; >5% aggregate WARN
        # -- byte-parity with _scan_test_files' #1299 read contract)
        if not any(tok in text for tok in tokens):
            continue                       # over-inclusive prefilter, never false-negative
        # ast.parse fail-soft (SyntaxError/ValueError -> WARN, skip)
        hit = {f for n, fs in script_names.items() if n in _import_names(tree) for f in fs}
        if hit:
            for name in touched_module_names([rel]):   # the intermediary's OWN names
                out.setdefault(name, set()).update(hit)
    return out
```

`_scan_test_files` then extends its token set and per-test check: a test whose AST imports an intermediary name gets `trans_hits[test] ∪= touched_files`. One hop by construction (the intermediary map is computed once, from touched files only, never re-expanded). Never sets `matched` (the `TRANSITIVE_CONSUMER_TESTS` precedent — over-WARN is the safe direction). **`TRANSITIVE_CONSUMER_TESTS` stays unchanged** — it covers importlib-by-constructed-path consumers the AST cannot see; the new arm does not subsume it (and the #1589 pair is NOT re-registered for issue833: the discovered arm reaches it).

## 11. Decision Rationale

**(a) Dotted-module arm — ADOPT.**
- **What:** boundary-bounded regex match of `touched_module_names`' dotted names in test text; reason `dotted-ref:<f>`.
- **Why:** escapee #1's exact form; near-zero over-select (measured: 1 test-file hit for the probe; 0 for `task.py`/`pod.py`/`select_step9c_tests.py` after boundary); derivation already exists at selector :815.
- **Source:** #1299 (`touched_module_names` dotted derivation), #1498 (string-scan arm shape), measured fan-out 2026-07-25.
- **Alternatives:** raw substring (rejected — `scripts.task` would fire on `scripts.task_progress`); matching the flat name too (rejected — boundary-bounded `eval`/`task` matches English words, mass over-select; the flat-string setattr form is executable only if the test imports the module, which the import arm covers).

**(b) Bare-basename arm — ADOPT with identifier boundaries, `.py` + `.sh`.**
- **What:** `(?<![A-Za-z0-9_])<base>(?![A-Za-z0-9_])` over the same read pass; reason `basename-ref:<f>`.
