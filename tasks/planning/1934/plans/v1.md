## 4. Design / file paths + concrete changes

### 4.1 `src/explore_persona_space/eval/utils.py::parse_judge_json` (MODIFY)

Recovery ladder (order is load-bearing; steps 1–2 are today's behavior, byte-for-byte
precedence):

1. `json.loads(text)` verbatim (scalar passthrough) — unchanged.
2. `raw_decode` at `text.index("{")` — unchanged; success returns identically to today
   (strict widening guarantee).
3. NEW — fenced-block extraction: for each ```-fenced block (```json or bare ```),
   try `json.loads(block.strip())`; first block that parses returns (dict/list/scalar).
4. NEW — brace-candidate iteration: iterate subsequent `{` offsets (bounded: at most the
   first ~200 candidate offsets, guarding pathological inputs), `raw_decode` at each;
   collect successes; return the LARGEST decoded object by consumed span (largest-wins
   guards against a small valid JSON fragment inside preamble prose).
5. `None` + the upgraded warning (R3).

### 4.2 `tests/test_eval_utils.py` (EXTEND — existing tests untouched)

New cases: brace-in-preamble (`Reasoning: {x} ... {"score": 85}` shapes); fenced object
preceded by brace-bearing prose (the measured production shape — fence-strip recovered
29/40); preamble containing a SMALL valid JSON object before the real fenced object
(fence/largest precedence pins); fenced bare scalar; pathological many-brace input
(bounded scan terminates). Plus the R3 log-shape assertions (length + head + tail).
