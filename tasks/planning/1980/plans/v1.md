# Plan v1 — workflow-fix: gotchas #952 streaming SIGABRT recipe misses break-suspended iterator

## 0. Plan Summary

Two-file prose refinement to the #952 streaming-shutdown SIGABRT rule. The
current recipe (`del row, ds; gc.collect()`) is INSUFFICIENT when the loop
exits via `break`: the suspended anonymous for-loop iterator retains the
streaming pipeline and survives to interpreter shutdown, still aborting
rc=134. Working shape (verified 2026-08-01 on WildChat-1M in
`scripts/issue1947_datagen.py`, rc 134 → 0): explicit `it = iter(ds)` +
consume + `it.close()` BEFORE the dels + `gc.collect()`.
