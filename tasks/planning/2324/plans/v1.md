### D2. Helper contract (serves fd-returning AND file-object-returning callers)

```python
# scripts/lock_utils.py  (stdlib only: os, stat, errno, fcntl, pathlib)
class LockPathError(OSError):
    """Lock path rejected: symlink / FIFO / non-regular object at the path.

    .reason: one of {"symlink", "would-block-special", "not-a-regular-file",
    "is-a-directory"}; args carry path + originating errno for the message."""

_REJECTION_ERRNOS = {
    errno.ELOOP,        # symlink final component under O_NOFOLLOW (Linux, macOS)
    errno.EMLINK,       # historic BSD O_NOFOLLOW spelling — defensive, no-op on Linux
    errno.ENXIO,        # FIFO with no reader under O_NONBLOCK|O_WRONLY; also unix socket
    errno.EAGAIN,       # some special files under O_NONBLOCK (== EWOULDBLOCK on Linux)
    errno.EISDIR,       # directory at the lock path (O_WRONLY)
    errno.EOPNOTSUPP,   # socket open on some kernels — defensive
}

def safe_open_lockfile(path, mode=0o600) -> int:
    """Open (creating if absent) a lock FILE, refusing symlinks and never blocking.

    Returns an OPEN fd to a verified regular file (O_NONBLOCK cleared).
    Raises LockPathError when the path holds a symlink/FIFO/dir/device/socket.
    Every OTHER OSError (EACCES, ENOSPC, EROFS, ENOENT-parent, ...) propagates
    UNCHANGED so each caller's existing open-failure handling still applies."""
    flags = os.O_WRONLY | os.O_CREAT | os.O_NOFOLLOW | os.O_NONBLOCK
    try:
        fd = os.open(path, flags, mode)
    except OSError as exc:
        if exc.errno in _REJECTION_ERRNOS:
            raise LockPathError(...) from exc
        raise
    try:
        st = os.fstat(fd)
        if not stat.S_ISREG(st.st_mode):   # FIFO-with-reader, /dev/null-class devices
            raise LockPathError(...)
        fl = fcntl.fcntl(fd, fcntl.F_GETFL)
        fcntl.fcntl(fd, fcntl.F_SETFL, fl & ~os.O_NONBLOCK)  # hygiene; see §12 A5
    except BaseException:
        os.close(fd)
        raise
    return fd
```

- **fd-returning callers (sites 1, 2, 4):** use the returned fd directly — drop-in for `os.open`.
- **File-object caller (site 3):** `fh = os.fdopen(safe_open_lockfile(lock_file), "wb")` — a file object OWNING the fd; `.fileno()` feeds `flock` exactly as today; the returned object must stay referenced for the lock's lifetime (unchanged docstring contract). Behavioral delta vs `open(path, "wb")`: no `O_TRUNC` — a no-op observable-wise, the lock file is always empty and never written (§12 A6). Site 3's lifetime semantics change ZERO.
- **flock loops, deadlines, and postures stay in the callers** — the helper only makes the OPEN safe and non-blocking. This is what makes one helper serve four postures without unifying them.
