## 3. Method delta (vs the existing orphan sweep)

Today: one staleness floor (90 min) for every orphan candidate, because "no live registered session" cannot distinguish a dead driver from a live-but-unregistered one (the routine follow-up-round state).

Delta: a per-task **effective staleness floor**. The floor drops to the fast value ONLY on positive proof of owner death — a sid that (i) a `last-mapped-terminal` breadcrumb binds to this issue, (ii) was observed IN the live set on an earlier sweep tick (recorded in `orphan-<N>.json`) or is observed dead-with-breadcrumb-present this tick, and (iii) is now definitively absent from a successfully-fetched live set. Everything else about the sweep — decision function, caps, exemptions, act guard, respawn mechanics, marker sentinels — is unchanged; the fast path is purely a `staleness_s` modulation at the `decide_orphan` call site.

**"Provably dead", mechanically:** `owner_sid ∉ live_ids` where `live_ids` came from a successful daemon `/list` this tick (pass-level daemon gate already guarantees reachability) and `owner_sid` was live on a previous tick (state-carry) or its breadcrumb still exists this tick. **Stays conservative (fail toward keep/slow):** daemon unreachable → whole pass skips (existing); `live_pids` map unavailable → cwd veto unevaluable → fast path ineligible; no breadcrumb/owner evidence → ineligible; any breadcrumb-owner sid live → ineligible; fresh worktree activity (≤15 min, `_worktree_recent_activity`) → ineligible; any live child cwd under the issue worktree → ineligible; no driver witness within the lookback → ineligible.

**Live-but-unregistered interactive session (the #535 exclusion, explicit):**
1. A compliant interactive session registers (`spawn_session.py register-current --issue <N>` → `manual-issue-<N>.json`, SKILL.md Step 0 L1033/L7615) → `rec` present → fast path **structurally ineligible** (requires `rec is None`); the existing manual-only → alert-never-respawn semantics are untouched (the manual-only guard analogue).
2. The #472/#1090 continuing-session class (unregistered by design during follow-up rounds) is excluded by the live-owner veto: its own sid IS the breadcrumb-recorded owner, and while it lives the fast path cannot fire (acceptance criterion 2).
3. Residual (documented, accepted): a NON-compliant hand-driven session at repo-root cwd, silent >~30 min, active on a task whose PREVIOUS auto generation's sid is provably dead. Bounded by: marker freshness resets the clock each time it posts; the 2-miss debounce; the worktree-activity + cwd vetoes; the #1247 act guard; the daily cap (2); and the respawn marker naming its full evidence for post-hoc diagnosis. This same residual exists TODAY at 90 min; the fast path narrows it only behind positive death proof of a different, recorded generation.

### 4a. Constants + env helper (insert after `ORPHAN_MAX_RESPAWNS_PER_DAY_DEFAULT`, ~L11903)

```python
# #1391: dead-owner fast path — the SHORTER marker-staleness floor applied when
# the task's last recorded owner session is PROVABLY dead (see
# _orphan_dead_owner_evidence). 20 min: > the 16.2-min max healthy
# inter-marker gap measured in #1090's unregistered window, >= the 15-min
# worktree-activity window, and 2x the 10-min tick cadence; with threshold=2

ORPHAN_DEAD_OWNER_STALENESS_S_DEFAULT = 20 * 60
ORPHAN_DEAD_OWNER_STALENESS_S_MIN = 10 * 60  # clamp floor: below one tick + debounce is meaningless

    """Fast-path floor in seconds (env EPM_ORPHAN_DEAD_OWNER_STALENESS_MIN,
    minutes). `0` (or negative) DISABLES the fast path (returns None — kill
    switch); malformed falls back to the default (an accelerator typo must not
    disable it, matching _orphan_staleness_s); positive values clamp to
    >= ORPHAN_DEAD_OWNER_STALENESS_S_MIN."""
```

### 4c. Pure predicate (new, next to `decide_orphan` ~L11937)

```python
def decide_dead_owner_fast_path(
    *,
    has_registration: bool,
    breadcrumb_owner_sids: frozenset[str],   # this tick's breadcrumbs for the issue
    live_ids: frozenset[str],
    recorded_owner_sid: str | None,          # state-carried from a prior tick
    driver_witness_age_s: float | None,
    witness_lookback_s: float,               # == the SLOW floor (90 min)
    wt_activity_fresh: bool,
    live_cwd_owner: bool | None,             # None == probe unavailable
    fast_floor_s: float | None,              # None == disabled
) -> tuple[bool, str]:
    """(eligible, reason). Pure + hermetic (#1247 seams). EVERY uncertain
    input fails toward (False, <why>). Eligible iff ALL of:
      fast_floor_s is not None
      and not has_registration                      # rec is None strictly
      and driver_witness_age_s is not None
      and driver_witness_age_s < witness_lookback_s # recent driver existed
      and not wt_activity_fresh                     # no one mid-edit
      and live_cwd_owner is False                   # None -> ineligible
      and not (breadcrumb_owner_sids & live_ids)    # no live ex-owner (veto)
      and (
        (recorded_owner_sid is not None and recorded_owner_sid not in live_ids)
        or (breadcrumb_owner_sids and not (breadcrumb_owner_sids & live_ids))
      )                                             # POSITIVE death proof
    reason names the evidence, e.g.
    'owner sid cmr3… (last-mapped-terminal, live at tick T-1) absent from live set'."""
```

Alternatives: 15 min (rejected — <2× margin over the measured healthy gap before debounce), 30 min (rejected — +10 min latency for no added safety given the positive-evidence gate).
- **Clamp floor 10 min** — What: minimum accepted env value. Why: below one 10-min tick the floor cannot interact with the 2-miss debounce meaningfully; an operator typo (e.g. `2`) must not create a fire-on-first-gap configuration. Source: tick cadence (`3-59/10` cron, background-automation.md). Alternatives: no clamp (rejected — the sibling knobs' malformed-fallback convention exists precisely because typos happen).
- **`0` disables / malformed → default** — Source: the module's own knob conventions (`EPM_TICK_WEDGE_MIN_FAILED_TURNS` `0`-disables; `_orphan_staleness_s` malformed-falls-back, L11911).

Source: `ORPHAN_STALENESS_S_DEFAULT` L11893. Alternatives: a separate knob (rejected — one more ungrounded constant with no distinct behavior).
