### 4a. The exact entry text

Insert the following as ONE new top-level bullet in `.claude/rules/gotchas.md`, **immediately after** the `**ALL fan-out units dumping the vLLM 5-minute front-end handshake timeout…**` entry (currently line 97) and before the `**vLLM 0.11.0 V1 EngineCore dies silently…**` entry (line 98):

> - **Concurrent fan-out units racing a SHARED staging dest — pre-stage shared inputs ONCE in the parent BEFORE fanout; a one-cell smoke structurally cannot catch this class.** A fan-out dispatcher whose units LAZILY stage the same input dest races the staging helper two ways: (a) a SHARED staging/scratch dir (the pre-fix `dest/_hfstage`) lets one unit's `os.replace` steal a file a sibling's `hf_hub_download` just returned — FileNotFoundError at the replace; (b) a single-proxy-file staleness guard (`raw_pos.jsonl` alone) lets a unit consume a sibling's partially-staged (or crashed-prior-stage) dest and crash downstream on the missing sibling sidecar. RULES: (i) the parent stages every fanout-shared input ONCE before launching units (worked example: `phase_parity` calls `_margin_pools(cfg)` before `_fanout_units`, `scripts/issue1315_dispatch.py`); units re-check idempotently and skip; (ii) staging helpers download into a PER-INVOCATION `tempfile.mkdtemp(dir=dest)` staging dir (same filesystem — `os.replace` must not cross devices) and publish per file via atomic `os.replace`, with a per-file `target.exists()` skip so re-staging self-heals a partial dest, and any leftover-stager sweep AGE-GATED (>1h) so a LIVE sibling's staging dir is never reaped (worked example: `_stage_hf_prefix`, `scripts/issue1090_run.py`); (iii) staleness/completeness guards key on the FULL consumer-required file set — the consumer's own precondition — never one proxy file (`_margin_pool_source_staged` + `_MARGIN_POOL_REQUIRED`, `scripts/issue1090_fu3_worker.py`). A one-cell smoke cannot surface any of this (the race needs ≥2 concurrent units) — audit every unit-reachable shared-write path at fanout-DESIGN time and pin the helper with concurrency regression tests (`tests/test_issue1315_margin_pool_staging.py` reproduces the production crash pre-fix). Diagnostic signature: FileNotFoundError at an `os.replace` inside a staging helper in ONE unit of a concurrent fanout — the handshake-timeout entry above owns the read-the-earliest/smallest-unit-log ordering that finds it. (Incident #1315 p4_parity crash-fix r5, 2026-07-15: 4 concurrent parity units each lazily staged the same `margin_pools/impolite` dest via `_stage_hf_prefix`'s shared `_hfstage` scratch; the gpu-3 unit crashed at the replace, `epm:failure v4`. Fix: commit `ccfb975af3` on the `issue-1315` branch — NOT on main as of 2026-07-15; lands at #1315's Step-10d merge.) Long-form twin (implementer-scoped): `.claude/agent-memory/experiment-implementer/feedback_fanout_shared_staging_race.md`.

Refinements vs the body's diff sketch, each grounded in the `ccfb975af3` read: (1) added the **same-filesystem mkdtemp** constraint (`dir=dest`) — load-bearing for `os.replace` atomicity, present in the fix's docstring; (2) added the **age-gated live-sibling-safe sweep** — the fix explicitly distinguishes the always-swept legacy `_hfstage` from >1h-old `_hfstage-*` orphans, and omitting this invites a "sweep all stagers at entry" reimplementation that recreates the steal race; (3) added the **per-file exists-skip self-heal** — it is what makes rule (iii)'s re-stage cheap and is half the fix's value; (4) named the three worked-example symbols + the regression test + the branch/not-on-main status, per the register's fix-status convention (cf. lines 34–35).
