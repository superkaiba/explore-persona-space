**Diff sketch** — replace the function body (signature + docstring + `__all__` preserved):

```python
def expected_artifacts_declaration(
    *,
    spec: RunSpec,
    config: GcpConfig,
    attempt_id: str,
    wandb_run_path: str | None = None,
    extra_hf_data_paths: Sequence[str] = (),
    extra_hf_model_paths: Sequence[str] = (),
    extra_git_paths: Sequence[str] = (),
) -> dict[str, Any]:
    """Build the :data:`EXPECTED_ARTIFACTS_HANDLE_KEY` payload for launch.

    Thin GCP-lane wrapper around
    :func:`artifacts.build_expected_artifacts_declaration` (the shared
    SLURM + RunPod builder, mirroring this lane's shape since #598). The
    GCP-specific bits stay here: the GcpConfig-sourced HF repo ids and
    the per-attempt :func:`sentinel_path_for` path computation.

    [keep the existing semantic paragraphs — #601 carve-out, default
    included paths, extra_* threading — verbatim, OR collapse them into
    one sentence:  "All shape rules (the #601 custom-workload carve-out,
    the hydra-lane ``issue<N>_<attempt>/raw_completions/`` default, the
    standard git paths) live in the shared builder; see its docstring."
    Recommend KEEPING verbatim — costs nothing, preserves grep-ability.]
    """
    # Local import mirrors the slurm.py:505 pattern (avoid top-level
    # cycle risk during partial-import edge cases; cheap on call path).
    from explore_persona_space.backends.artifacts import (
        build_expected_artifacts_declaration,
    )

    return build_expected_artifacts_declaration(
        issue=spec.issue,
        sentinel_path=sentinel_path_for(config, spec.issue, attempt_id),
        custom_workload=bool(spec.workload_cmd),
        attempt_id=attempt_id,
        hf_data_repo=config.hf_data_repo,
        hf_model_repo=config.hf_model_repo,
        wandb_run_path=wandb_run_path,
        extra_hf_data_paths=extra_hf_data_paths,
        extra_hf_model_paths=extra_hf_model_paths,
        extra_git_paths=extra_git_paths,
    )
```

Equivalence sketch (line by line, gcp.py:491-513 vs `build_expected_artifacts_declaration` 412-434):

- `issue = spec.issue` → both call `int(issue)` on the same value.
- `if spec.workload_cmd:` → `if custom_workload:` with `custom_workload = bool(spec.workload_cmd)` — same branch.
- `base_hf_data = (f"issue{issue}_{attempt_id}/raw_completions/",)` — IDENTICAL string template; shared builder raises if `attempt_id` is falsy in the non-custom branch, and the gcp signature already requires `attempt_id` as keyword-arg (so the raise can only fire if a caller passes `attempt_id=""`, which the existing tests do not).
- `hf_data_paths`, `hf_model_paths`, `wandb_run_path`, `git_paths`, `sentinel_path` — same dict shape, same key order; the shared builder uses `[f"eval_results/issue_{issue}/", f"figures/issue_{issue}/", *extra_git_paths]` whereas gcp uses `list(base_git) + list(extra_git_paths)` with `base_git = ("eval_results/issue_{issue}/", "figures/issue_{issue}/")` — same final list contents.

## 5. Risks

Small. Enumerated for completeness:

- **Risk 1 — Docstring drift.** The two docstrings explain the same thing (the #601 carve-out, the default included paths, the extra_* threading) in slightly different prose. Mitigation: keep the GCP docstring verbatim; the shared builder's docstring already cites the GCP version as the mirror. No semantic claim is dropped.
- **Risk 2 — Local-import vs top-level-import bikeshed.** Slurm.py uses local-import; runpod.py uses top-level (per code-review on #598). Picked local-import to mirror slurm.py and match the delegation-entrypoint pattern. Either passes the tests.
- **Risk 3 — Hidden caller.** `__all__` exports `expected_artifacts_declaration`; external importers might exist. Mitigation: grep verified one internal caller (gcp.py:2923) and the test module. Signature unchanged → any external import keeps working.
- **Risk 4 — `attempt_id=""` raise.** The shared builder raises `ValueError` if `attempt_id` is falsy in the hydra (non-custom-workload) branch; the pre-migration gcp body silently produced `issue137_/raw_completions/`. This is a STRICTLY safer behavior — the old shape was a silent bug — and the existing tests always pass a real `attempt_id`. If any code path passes `attempt_id=""`, the now-loud ValueError is the correct fail-fast.
