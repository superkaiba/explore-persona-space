## 11. Decision Rationale

`N/A — no training hyperparameters.` Design decisions:

1. **What:** Reuse the imported watcher helper at the spawn hop, not a local copy or a new shared module. **Why:** A copied forwarder is exactly the drift the existing import layer exists to prevent; the identity-pin test already enforces no-drift. **Source:** `scripts/file_infra_task.py:65-72` (comment), `tests/test_marker_child_stderr_forwarding.py:250-253`; #1150 precedent at L269. **Alternatives:** relocating the helper to `task_workflow.py` — rejected as scope creep (would touch 8+ call sites in a cosmetic-only move).
2. **What:** Place the forwarding BEFORE `first_line` / the `spawn_output_suppressed` branch. **Why:** The suppressed path returns at L379; a later placement would swallow warnings on exactly the path (duplicate-dispatch suppression) where a stderr warning is most diagnostic. **Source:** `scripts/file_infra_task.py:372-381`; task brief item 4; pinned by `..._suppressed_path_still_forwards`.
3. **What:** Keep the emitted `[task.py stderr]` prefix byte-stable; generalize only the docstring; disambiguate via the context label `"spawn_session spawn-issue (file_infra_task)"`. **Why:** 7 existing test assertions and watcher log-grep conventions key on the literal prefix; parameterizing the prefix churns every #1130/#1150 site for zero information (the context label already names the child). **Source:** `tests/test_marker_child_stderr_forwarding.py:86,123,144,161,184,227,247`; helper output at `autonomous_session_watch.py:6396`. **Alternatives:** a per-site prefix argument — rejected (churn ≫ benefit).
4. **What:** NO-CHANGE for the three stale Goal targets. **Why:** Verified library-based marker posting / no subprocess children (in-class children simply do not exist there); editing them would add dead guardrails. **Source:** §2 evidence table (this pass's greps); `.claude/rules/workflow-fix-on-bug.md` § reasoned no-change deflection.
5. **What:** Leave `backends/slurm.py::post_marker_via_task_py`, read-only task.py children, and `poll_pipeline.py:719`'s pod.py child untouched. **Why:** slurm's child stderr INHERITS (no `capture_output` — no swallow exists); read-only children never take the flock-commit path (the warning class cannot fire); the pod.py child is a different contract class (a pod.py-class sibling fix would be its own candidate). **Source:** clarifier scan (epm:clarify v1 on #1221); `poll_pipeline.py:715-726` read this pass.
6. **What:** Tests live in `tests/test_marker_child_stderr_forwarding.py`, not a new file. **Why:** It is the #1150 file for exactly this forwarding class, already imports `file_infra_task`, and carries the shared `_LANDING_CHECK_LINE` fixture + `_file_infra_args` helper. **Source:** read in full this pass.
