## 1. Goal

Add a mechanical FAIL check to `scripts/verify_task_body.py` that catches **body-vs-figure panel/series drift**: a clean-result body whose what-is-plotted prose asserts a plot kind in a named panel position (a "right panel scatter") or a per-unit dot/point overlay (a "per-bank dot overlay") that the embedded figure's `.meta.json` sidecar provably does not contain (the `_kind` count of that plot element is 0). ### 4.1 New parsed-JSON sidecar reader (sibling of `_read_figure_meta_text`)

```python
def _read_figure_meta_json(repo: Path, sha: str, fig_path: str) -> dict | None:
    """Return the PARSED sibling ``.meta.json`` of ``fig_path`` (extension
    swapped to ``.meta.json``) read out of the git tree at ``sha`` via
    ``git show``, or None when there is no sidecar at that sha / the sha is
    unresolvable / the JSON does not parse / it is not a dict. Sibling of
    ``_read_figure_meta_text`` (check 24), which flattens to text and so
    cannot expose the per-point ``_kind`` / ``_group`` fields check 26 needs.
    """
    base, _, ext = fig_path.rpartition(".")
    meta_path = (base if ext else fig_path) + ".meta.json"
    try:
        proc = subprocess.run(
            ["git", "show", f"{sha}:{meta_path}"],
            cwd=str(repo), capture_output=True, text=True, timeout=10,
        )
    except (OSError, subprocess.SubprocessError):
        return None
    if proc.returncode != 0:
        return None  # no sidecar at that sha, or sha unresolvable
    try:
        meta = json.loads(proc.stdout)
    except (ValueError, json.JSONDecodeError):
        return None
    return meta if isinstance(meta, dict) else None
```

### 4.2 Sidecar aggregate extractor

```python
def _sidecar_kind_group_aggregate(meta: dict) -> tuple[Counter, set] | None:
    """From a parsed sidecar, return (Counter of ``_kind`` values across all
    points, set of unique ``_group`` values), or None when the sidecar
    carries no recognizable point list (so the check skips — it only fires
    on sidecars whose shape it understands).

    NOTE: ``_group`` is a per-SERIES index, NOT a per-panel index (an A7
    four-panel figure has 22 ``_group`` values). The returned group set is
    kept only for diagnostics in the FAIL messages; check 26 makes NO claim
    about panel count from it (see ``_panel_drift_failures``).

    Reads ``points`` (the canonical key) OR ``rows`` (legacy). A point with
    no ``_kind`` contributes nothing to the kind Counter; a point with no
    ``_group`` contributes nothing to the group set.
    """
    pts = meta.get("points")
    if not isinstance(pts, list):
        pts = meta.get("rows")
    if not isinstance(pts, list) or not pts:
        return None
    kinds = Counter()
    groups: set = set()
    for p in pts:
        if not isinstance(p, dict):
            continue
        k = p.get("_kind")
        if isinstance(k, str) and k.strip():
            kinds[k.strip().lower()] += 1
        g = p.get("_group")
        if g is not None:
            groups.add(g)
    if not kinds and not groups:
        return None  # no structural signal — nothing to compare
    return kinds, groups
```

### 4.3 Prose claim extractor (CONSERVATIVE — high-confidence only)

```python
# Plot-element words that map to a sidecar ``_kind``. A prose claim naming
# one of these as a distinct panel/series is checkable against the kind Counter.
_PROSE_KIND_RE = {
    "scatter": re.compile(r"\bscatter(?:\s*plot|s)?\b", re.IGNORECASE),
    "line":    re.compile(r"\bline(?:\s*plot|s)?\b|\btrajector(?:y|ies)\b", re.IGNORECASE),
    "bar":     re.compile(r"\bbar(?:\s*chart|s)?\b", re.IGNORECASE),
}
# A panel/series STRUCTURAL claim — prose that asserts a specific panel
# position OR a per-unit dot/point overlay.
_PROSE_PANEL_POS_RE = re.compile(
    r"\b(?:left|right|top|bottom|middle)\s+panel\b", re.IGNORECASE
)
_PROSE_OVERLAY_RE = re.compile(
    r"\b(?:per[-\s]?\w+\s+dots?|dots?\s+overlaid|dot\s+overlay|points?\s+overlaid)\b",
    re.IGNORECASE,
)
```

> **`[v2]` Removed from the FAIL path:** v1 had `_PROSE_PANEL_COUNT_RE` (matching `two|three|four|...|N-panel`) and `_WORD_TO_INT`, feeding a panel-count FAIL. Per must-fix #1, the panel-count FAIL is removed entirely — the sidecar has no panel-count field to compare against. The implementer MUST NOT add any FAIL that fires on a panel-count mismatch. The extractor parses ONE prose blob (the figure's enclosing-H3 what-is-plotted + caption) and returns the set of high-confidence claims:

```python
def _panel_prose_claims(prose: str) -> dict:
    """Return the high-confidence structural claims a figure's what-is-plotted
    + caption prose makes:
      {"kind_in_panel": {<kind>, ...},   # a kind named as a PANEL/series, e.g. "right panel scatter"
       "overlay": <bool>}                # a per-unit dot/point overlay claim
    Only claims that are checkable against the sidecar ``_kind`` aggregate are
    returned; a bare "the bars show ..." with no panel/overlay structural
    wording yields an empty claim set (the check then PASSes — no over-fire on
    simple charts). NO panel-count claim is produced (the sidecar has no
    panel-index field; see _sidecar_kind_group_aggregate docstring).
    """
    claims = {"kind_in_panel": set(), "overlay": False}
    # A kind is a checkable CLAIM only when it co-occurs with a panel-position
    # word OR an overlay word in the prose (a kind word alone — "the bars" — is
    # NOT a structural claim). Conservative: require the panel/overlay wording.
    has_panel_pos = bool(_PROSE_PANEL_POS_RE.search(prose))
    has_overlay = bool(_PROSE_OVERLAY_RE.search(prose))
    if has_panel_pos or has_overlay:
        for kind, rx in _PROSE_KIND_RE.items():
            if rx.search(prose):
                claims["kind_in_panel"].add(kind)
    claims["overlay"] = has_overlay
    return claims
```

### 4.4 Comparison logic (FAIL conditions) `[v2 — two of three branches changed]`

For one figure, given `claims = _panel_prose_claims(prose)` and `(kinds, groups) = _sidecar_kind_group_aggregate(meta)`:

```python
def _panel_drift_failures(claims: dict, kinds: Counter, groups: set, basename: str) -> list[str]:
    fails = []
    # (1) prose names a plot KIND as a panel/series the sidecar's _kind count lacks entirely.
    for kind in sorted(claims["kind_in_panel"]):
        if kinds.get(kind, 0) == 0:
            fails.append(
                f"`{basename}`: body prose claims a `{kind}` panel/series but the "
                f"figure sidecar has zero `{kind}` points (kinds present: "
                f"{dict(kinds) or 'none'}) — regenerate the figure or fix the prose"
            )
    # (2) [v2 — REMOVED] the v1 panel-count FAIL ("N-panel grid" vs len(groups)) is
    #     deleted: `_group` is a per-series index, not a panel index (a 4-panel
    #     A7 figure has 22 _group values), so len(groups) != N is not a valid
    #     panel-count test and the sidecar has no panel-index field. No FAIL
    #     fires on panel count. (must-fix #1)
    # (3) [v2 — HARDENED] prose claims a per-unit dot/point OVERLAY but the sidecar
    #     has zero scatter points (nothing overlaid). FAIL on overlay whenever
    #     scatter == 0, REGARDLESS of _group cardinality — the v1 `len(groups) <= 1`
    #     conjunction false-PASSed a sidecar with multiple bar/line groups and zero
    #     scatter. (must-fix #2)
    if claims["overlay"] and kinds.get("scatter", 0) == 0:
        fails.append(
            f"`{basename}`: body prose claims a per-unit dot/point overlay but the "
            f"figure sidecar has zero scatter points (kinds present: "
            f"{dict(kinds) or 'none'}) — regenerate the figure or fix the prose"
        )
    return fails
```

### 4.5 The check function `[v2 — prose window scoped to the enclosing ### H3]`

```python
def check_figure_panel_prose_vs_sidecar(body: str) -> CheckResult:
    """Check 26 (FAIL): a figure's what-is-plotted prose must not claim a
    plot kind in a named panel position, or a per-unit dot/point overlay,
    that the figure's ``.meta.json`` sidecar — read strictly by URL stem
    from the git tree at the URL's commit sha — provably lacks (the
    sidecar's ``_kind`` count of that element is 0). The prose window is
    scoped to the figure's enclosing ``### <result>`` H3 so a claim from
    one result never leaks into the next. NO panel-count claim is made
    (the sidecar has no panel-index field; ``_group`` is a per-series
    index). [docstring continues: incident #683 r1, strict-resolve
    rationale, conservative-claim contract, noop-skip conditions.]
    """
    label = "figure panel prose vs figure sidecar (panel/series drift)"
    section = _figure_scan_section(body)
    text = section_text(body, section)
    if text is None:
        return CheckResult(label, True, f"no `## {section}` section to scan")
    rlines = text.splitlines()
    # Collect (url, img_line_idx) in document order.
    fig_at: list[tuple[str, int]] = []
    for idx, line in enumerate(rlines):
        for m in _IMAGE_RE.finditer(line):
            url = m.group(1).strip()
            url = url.split(None, 1)[0] if url else url
            if url:
                fig_at.append((url, idx))
    if not fig_at:
        return CheckResult(label, True, "no inline figures to scan")
    repo = _resolve_repo_root()
    if repo is None:
        return CheckResult(label, True, "skipped — repo root unresolved (offline / stdin)")
    fails: list[str] = []
    scanned = 0
    json_cache: dict[str, dict | None] = {}
    for url, img_idx in fig_at:
        m = _RAW_GITHUB_FIGURE_RE.match(url)
        if m is None or (m.group("owner").lower(), m.group("repo").lower()) != _THIS_REPO_SLUG:
            continue  # only same-repo sha-pinned figures resolve from git
        # [v2] Prose window = the enclosing ### <result> H3 forward to the figure
        #      (what-is-plotted) + the caption blockquote immediately after.
        #      Find the highest j < img_idx with rlines[j] starting "### ".
        boundary = None
        for j in range(img_idx - 1, -1, -1):
            if rlines[j].startswith("### "):
                boundary = j + 1
                break
        if boundary is None:
            # No per-result H3 before this figure (figure sits directly under
            # the ## section). Skip the prose-vs-sidecar check for this figure
            # — we have no reliably-scoped what-is-plotted window, and the
            # caption alone is too thin to anchor a FAIL. (must-fix #3 fallback)
            continue
        before = "\n".join(rlines[boundary:img_idx])
        caption = _figure_caption_after(rlines, img_idx)
        prose = f"{before}\n{caption}"
        claims = _panel_prose_claims(prose)
        # No structural claim → nothing to check (conservative: never over-fire).
        if not claims["kind_in_panel"] and not claims["overlay"]:
            continue
        if url not in json_cache:
            json_cache[url] = _read_figure_meta_json(repo, m.group("sha"), m.group("path"))
        meta = json_cache[url]
        basename = m.group("path").rsplit("/", 1)[-1]
        if meta is None:
            # Strict by-stem resolve FAILED at the cited sha. This is the
            # silent-fallback failure mode the check exists to catch — FAIL loud,
            # BUT only when the PNG itself resolves at the sha (so the ABSENT
            # thing is specifically the sidecar, not the whole sha — §4.7).
            png_status, _detail = _git_object_exists(repo, m.group("sha"), m.group("path"))
            if png_status != "pass":
                continue  # let check 22 / check 4b own the sha/PNG FAIL
            fails.append(
                f"`{basename}`: body prose makes a panel/series claim but the sibling "
                f"`{basename.rsplit('.', 1)[0]}.meta.json` does not resolve at the cited "
                f"sha `{m.group('sha')[:8]}` — commit the sidecar at that sha (no silent "
                f"fallback to a different sidecar)"
            )
            continue
        agg = _sidecar_kind_group_aggregate(meta)
        if agg is None:
            continue  # sidecar carries no _kind/_group structure to compare
        scanned += 1
        kinds, groups = agg
        fails.extend(_panel_drift_failures(claims, kinds, groups, basename))
    if fails:
        preview = "; ".join(fails[:3]) + (" …" if len(fails) > 3 else "")
        return CheckResult(label, False, f"{len(fails)} panel/series drift issue(s): {preview}")
    if scanned == 0:
        return CheckResult(label, True, "no panel/series prose claims to compare against a sidecar")
    return CheckResult(label, True, f"{scanned} figure sidecar(s) consistent with panel/series prose")
```

### 4.7 Missing-sidecar FAIL vs double-FAIL guard (the one subtle interaction) `[v2 — citation + explicit comparison corrected]`

The missing-sidecar branch (§4.5) FAILs when `_read_figure_meta_json` returns `None`. But `None` covers TWO cases: (a) the figure PNG itself exists at the sha but has no `.meta.json` sibling (the real drift the check targets), and (b) the sha is unresolvable / the PNG path 404s — which is **already** a check-22 FAIL (`check_figure_url_sha_matches_repro`). To avoid a confusing double-FAIL on case (b), the missing-sidecar FAIL fires **only when the figure PNG blob itself resolves at the sha**.

Use the existing `_git_object_exists(repo, sha, path)` helper — **defined at `:3652`** `[v2: was incorrectly cited as :1830 in v1; :1830 is a USAGE site, e.g. `verdict, _detail = _git_object_exists(...)`, evidence the helper is in active use]`. **`[v2]` The helper returns a `(status, detail)` tuple where `status ∈ {'pass', 'fail', 'skip'}` and the tuple is ALWAYS truthy — so the gate MUST be an explicit `status != "pass"` comparison, NEVER a truthiness check on the return value.** Concretely:

```python
png_status, _detail = _git_object_exists(repo, m.group("sha"), m.group("path"))
if png_status != "pass":
    continue  # PNG missing OR sha unresolvable — let check 22/4b own that FAIL
# else: PNG resolves but the sidecar JSON is None → FAIL on the missing/wrong sidecar.
```

`status == "fail"` (sha resolves, PNG absent) and `status == "skip"` (sha unresolvable) BOTH route to `continue`; only `status == "pass"` (sha good, PNG committed) lets the missing-sidecar FAIL fire. This keeps the new check's FAIL strictly about panel-structure / sidecar-presence, never re-litigating SHA pinning.
