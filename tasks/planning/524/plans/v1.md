## 4. Design

### Smoke-architecture parity (UNIFIED — the default)

The dispatcher runs in-process serial (`scripts/issue524_dispatch.py`, with `--cells 1 --seeds 1 --phase {0,1,2,3}` for smoke, `--cells 32 --seeds 1 --phase all` for sweep). Both modes call the same `train_one_icl_cell(cid, ...)` and `eval_cell(src_cid, tgt_cid, ...)` functions; no subprocess wrapper, no `subprocess.run`. The smoke runs ONE ICL cell end-to-end (train → cross-eval against 4 representative targets → extract clouds → predictor → metric) using the exact code path the full sweep uses. This is the task #397 round-11 pattern.

**Why code, not a model call?** — The predictor matrices, ΔG matrices, nested-CV scoring, bootstrap, and Tobit fit are deterministic linear-algebra / numpy / scikit-learn computations on activation clouds and log-probabilities. A model-call formulation would (a) be vastly more expensive at N=992 ordered pairs × 32 contexts × 28 layers × 9 metrics × 2 extraction points, (b) not produce calibrated CIs from bootstrap, and (c) lose interpretability of the directional functional (we need to be able to *name* the predictor as a published functional form, not "Claude judged the closeness"). The ICL induction-rate manipulation check IS a model call (Sonnet-judged), per §"Phase 0".

### Phase 4 — Predictor matrices (CPU on dev VM; minutes)

Reuse #502's predictor zoo (`scripts/issue502_dispatch.py` aggregation path). Extend it with the 5 new directional predictors. Each predictor produces a per-(layer, extraction-point, variant) 32×32 distance matrix.

```python
# scripts/issue524_phase4_predictors.py (NEW; CPU)

def directional_gauss_kl(mu_A, Sig_A, mu_B, Sig_B):  # asymmetric
    # D_KL(N(μ_A, Σ_A) || N(μ_B, Σ_B)), PCA-16 fit per #502 convention
    return 0.5 * (np.trace(np.linalg.solve(Sig_B, Sig_A))
                  + (mu_B - mu_A).T @ np.linalg.solve(Sig_B, mu_B - mu_A)
                  - mu_A.shape[0]
                  + np.log(np.linalg.det(Sig_B) / np.linalg.det(Sig_A)))

def source_cov_mahalanobis(mu_A, Sig_A, mu_B):  # asymmetric on Σ_A
    diff = mu_B - mu_A
    return diff @ np.linalg.solve(Sig_A, diff)

def asym_subspace_recon(P_A_k, Phi_B):  # asymmetric on rank-k subspace of A
    return np.linalg.norm(P_A_k @ Phi_B) / np.linalg.norm(Phi_B)

def marker_projection(act_A, marker_unembed_dir):  # plain, on the marker direction
    return act_A @ marker_unembed_dir / np.linalg.norm(act_A)

def two_feature_combiner(f_geom, f_marker, dg):  # OLS fit
    return ols_fit(dg, [f_geom, f_marker, f_geom * f_marker])
```

```python
# scripts/issue524_phase5_metrics.py (NEW; CPU)

CONTEXTS = list(INSTR_16) + list(ICL_16)  # 32

# Symmetric baseline: M_sym = ΔG ~ gauss_kl + length
def fit_M_sym(train_pairs, train_dg):
    return OLS(train_dg, [gauss_kl_L22_lastprompt[train_pairs], length_diff[train_pairs]])

# Decision: paired nested LTCO-CV incremental ΔR² via POOLED out-of-fold predictions.
# (Per round-1 Stats critique: per-fold R² with N=2 test points is degenerate —
# `r2_score` on (A,B)/(B,A) blows up because SS_tot is the squared half-difference
# of two ΔG values that are usually close. Fix: store each ordered pair's
# held-out prediction exactly once across the 496 outer folds, then compute ONE
# pooled R² for M_sym and ONE for M_full over the full 992 off-diagonal panel.)
def pooled_ltco_predictions(predictor_matrix, gauss_kl_matrix, length_diff, dg_matrix):
    """Compute one held-out prediction per ordered off-diagonal pair, using
    only fold-internal training contexts for both M_sym fitting AND the inner
    layer/extraction selection of the directional cell. Returns two arrays of
    length 992: pred_sym, pred_full (paired by pair index)."""
    pred_sym  = np.full(len(OFFDIAG), np.nan)
    pred_full = np.full(len(OFFDIAG), np.nan)
    for held_block in itertools.combinations(CONTEXTS, 2):  # 496 folds
        train_pairs = [(a,b) for a,b in OFFDIAG
                       if a not in held_block and b not in held_block]
        test_pairs  = [(a,b) for a,b in OFFDIAG
                       if a in held_block and b in held_block]  # exactly 2: (A,B), (B,A)
        # STRADDLING pairs (one endpoint in, one out) → DROP from BOTH sides (LTCO).
        # Inner loop: layer × extraction × variant selection on TRAINING pairs only.
        best_cell = inner_layer_extraction_select(predictor_matrix, dg_matrix, train_pairs)
        m_sym  = fit_M_sym(train_pairs, dg_matrix[train_pairs])
        m_full = fit_with_directional(train_pairs, dg_matrix[train_pairs], best_cell)
        for ij in test_pairs:
            pred_sym[ij]  = m_sym.predict(ij)
            pred_full[ij] = m_full.predict(ij)
    assert not np.isnan(pred_sym).any() and not np.isnan(pred_full).any()
    return pred_sym, pred_full

def pooled_incremental_r2(pred_sym, pred_full, dg_target):
    """One scalar per (predictor, panel). Computed against the full 992-pair
    panel's SS_tot; never per-fold."""
    return r2_score(dg_target, pred_full) - r2_score(dg_target, pred_sym)

# Context-clustered dyadic bootstrap on POOLED predictions
# (resample CONTEXTS, not pairs, per #474's "pair bootstrap is ~2× too narrow" caveat).
def cluster_bootstrap_ci(predictor_matrix, dg_matrix, B=2000):
    pooled_dr2 = []
    for b in range(B):
        boot_contexts = np.random.choice(CONTEXTS, size=len(CONTEXTS), replace=True)
        boot_pairs = [(a,b) for a in boot_contexts for b in boot_contexts if a != b]
        # Re-run the full LTCO pipeline on the resampled context multiset; the
        # bootstrap CI is on the POOLED incremental ΔR², not on a fold mean.
        pred_sym, pred_full = pooled_ltco_predictions_on_panel(
            predictor_matrix, dg_matrix, boot_pairs)
        pooled_dr2.append(pooled_incremental_r2(
            pred_sym, pred_full, dg_matrix[boot_pairs]))
    return np.percentile(pooled_dr2, [2.5, 97.5])

# UNIFIED censored scoring (per round-1 Stats critique: OLS R² on unsaturated
# cells mixed with Tobit log-likelihood on saturated cells is not one coherent
# decision metric — bootstrap has no single scalar to CI). Use ONE censored
# Δ log-likelihood over the FULL panel, with per-observation censor flags
# (no cell is dropped or scored under a separate rule).
def censored_delta_logL(pred_sym, pred_full, dg_target, ceiling, floor):
    """Tobit log-likelihood of dg_target under each model, treating
    dg >= ceiling - 0.1 as right-censored and dg <= floor + 0.1 as left-censored.
    Returns ΔLL = LL(full) − LL(sym), one scalar over the full 992-pair panel."""
    cens = censor_flags(dg_target, ceiling=ceiling-0.1, floor=floor+0.1)
    sigma_sym  = mle_sigma_tobit(pred_sym,  dg_target, cens)
    sigma_full = mle_sigma_tobit(pred_full, dg_target, cens)
    ll_sym  = tobit_loglik(pred_sym,  dg_target, cens, sigma_sym)
    ll_full = tobit_loglik(pred_full, dg_target, cens, sigma_full)
    return ll_full - ll_sym  # likelihood-ratio Δ; pseudo-R² reported alongside

# DECISION RULE.
# Primary headline scalar = pooled incremental ΔR² (when censored fraction is low — <10%).
# When censored fraction ≥ 10% on any block, the headline scalar switches to
# censored Δ log-likelihood (still ONE scalar over the full panel; bootstrap on
# this scalar instead). Report both ΔR² and ΔLL in the body either way; the
# decision gate uses whichever the censored-fraction rule selected.

# Directional fraud test
def directional_fraud(predictor_matrix, dg_matrix):
    dg_anti = 0.5 * (dg_matrix - dg_matrix.T)
    pred_anti = 0.5 * (predictor_matrix - predictor_matrix.T)
    return {
        "standalone_rho_pred_vs_dg_anti": spearmanr(predictor_matrix[OFFDIAG], dg_anti[OFFDIAG]).statistic,
        "asym_corr_predAnti_vs_dgAnti": spearmanr(pred_anti[OFFDIAG_UNORDERED], dg_anti[OFFDIAG_UNORDERED]).statistic,
    }
```

### Decision metric

Paired **nested LTCO-CV incremental skill** of (M_sym + directional) over M_sym = ΔG ~ `gauss_kl_L22_lastprompt + length`, on the full 992 off-diagonal pair panel. Outer loop = leave-TWO-contexts-out (496 folds; test = the 2 ordered pairs with BOTH endpoints in the held-out 2-context block; straddling pairs DROPPED from both sides; (A,B)/(B,A) kept together). Inner loop = per-fold layer × extraction-point × variant selection on training pairs only.

**Pooled out-of-fold scoring (round-1 Stats fix):** the per-fold R² is NOT computed (with N=2 test pairs per fold, `r2_score` is degenerate against SS_tot ≈ ½(y[0]−y[1])²). Instead, each ordered off-diagonal pair gets its held-out prediction stored exactly once (visited exactly once across the 496 folds), and ONE pooled R² is computed for M_sym and ONE for M_full against the full-panel SS_tot. The headline incremental scalar is `ΔR²_pooled = R²_full,pooled − R²_sym,pooled`.

**Unified censored scoring (round-1 Stats fix):** when the censored-cell fraction is < 10% on every block, the headline scalar IS `ΔR²_pooled`. When ≥10% on any block, the headline scalar switches to a unified **censored Δ log-likelihood** `ΔLL = LL_full − LL_sym` computed over the full 992-pair panel under a Tobit model with per-observation censor flags (right-censored at `ceiling − 0.1 nat`, left-censored at `floor + 0.1 nat`). Both ΔR²_pooled and ΔLL are reported in the body either way; the decision gate uses whichever the censored-fraction rule selected. This keeps the bootstrap on a single scalar regardless of saturation regime.

Bootstrap CI = context-clustered dyadic resample, B=2000, on the selected headline scalar.

PASS = bootstrap CI on the selected headline scalar strictly excludes 0 AND directional-fraud test (standalone ρ vs ΔG_anti) CI strictly excludes 0 AND predictor-asymmetry-vs-ΔG_anti correlation CI strictly excludes 0 AND held-out replication on #523's extended pool shows the same sign (CI ≠ 0). (Four-conjunct formulation; §3's wording is canonical, §7 Gate G1 below tracks the same scalar.)

### Saturation handling

Any cell with `|log P_trained(※) − ceiling| ≤ 0.1 nat` is right-censored; `log P_trained(※) ≤ −22 nats` is left-censored / floor. Saturation flags are per-observation and fed into the unified Tobit model above; NO per-cell rule-switch between OLS R² and Tobit (that mixed metric was the round-1 Codex-Stats Must-Fix). Report the fraction of cells in each saturation class per block (instr×instr, instr×ICL, ICL×instr, ICL×ICL) as a sidecar; the headline scalar already absorbs the censoring.

## 7. Decision Gates

The experiment has ONE genuine gate (Phase 0 ICL induction + saturation). The downstream phases are autonomous.

**Gate G0 (BLOCKING, before Phase 1 GPU spend):**
- ICL induction-rate manipulation check: ≥ 12 of 16 rebuilt ICL contexts achieve ≥70% Sonnet-judged induction rate. Otherwise → regenerate failing contexts once (Haiku) and retry; if still <12 → escalate via `epm:failure v1` with `failure_class: data`.
- Off-saturation feasibility (predicted at ep1 from #474's instruction-ep1 numbers): pass on at least 12 contexts. (Soft predicted; ground truth verified after Phase 1.)
- **Intersection rule** (round-1 Stats clarification): the 12+ contexts that pass induction MUST overlap with the 12+ that pass predicted off-saturation by ≥ 10 contexts. If the two gate-passing sets only overlap on, say, 6 contexts, the usable ICL panel is 6 — below the LTCO min-N. Report the intersection size in `phase0/gate_intersect.json`; <10 triggers the same `epm:failure failure_class: data` escalation.

**Gate G0-justification.** Phase 1 spends ~24 GPU-h on training adapters. If the ICL contexts don't induce the personas they name (the #489 weak-induction failure), the ΔG matrix is uninterpretable; the Goal can't be answered. The cheap manipulation-check intervention (50 Qwen generations per context × 16 contexts × 1 Sonnet call each = ~$2 + ~0.5 GPU-h on the dev VM) rules out the expensive failure mode. The threshold ≥70% is Sonnet-judged; it's the body's spec'd bar.

**No intermediate gates within Phase 1 or Phase 2.** The per-cell off-saturation gate is a per-cell flag (drops a cell from the panel) rather than an experiment-wide kill criterion — losing 1-3 cells out of 16 is recoverable; losing >4 triggers the same `epm:failure` escalation, not a fresh manipulation check.

The gate set is jointly satisfiable: G0's two halves (induction + off-saturation predicted) operate on different ICL cells in different directions; they cannot demand contradictory outcomes on the same cell.
