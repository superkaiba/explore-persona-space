### Change A — Step 4a root-divergence probe (defense-in-depth, KEEP)

**Placement:** immediately BEFORE the existing L2023 `if [ "$(git ... rev-list --count origin/main..issue-<N>)" ...]` block, inserted INSIDE the same fenced code block that runs at L2016-2030, right after the existing `timeout ... fetch origin main --quiet` at L2022.

**Decision rationale for keeping the probe:** the clarifier correctly flagged that the sanctioned `git push origin main || sync_repo_root.py` chain (L9844, § Bare push / merge snippets) handles the failure mode reactively downstream. The proactive Step-4 probe still earns its keep because (a) the divergence in session `c0319d9e` was invisible at Step 4 — the session ran a defensive investigation but had no policy prescription; (b) `sync_repo_root.py` is idempotent single-flight (concurrent caller exits 0 immediately), so a false-alarm probe costs ~1s and never harms; (c) session `c0319d9e`'s divergence outlived Step 4 to bite a subsequent root-side call — costing the NEXT session the recovery; catching it at Step 4 is one recovery, not many. Change A is MEDIUM-value defense-in-depth, not a fix to a described bug.

**Exact snippet to insert after the current L2022 `timeout ... fetch origin main --quiet || true` line and BEFORE the L2023 pre-check:**

```bash
# Root-divergence probe (#1725, defense-in-depth): the shared repo root's
# local `main` and fetched `origin/main` are usually one strict-ancestor
# of the other (either lagging or ahead). Mutually non-ancestral = genuine
# divergence — a subsequent root-side call (git push origin main, another
# site's sync_repo_root.py) will need to reconcile it. Handle it proactively
# via the sanctioned single-flight helper; still-diverged after one sync is
# surfaced (never stepped over silently).
if ! git -C "$REPO_ROOT" merge-base --is-ancestor origin/main main 2>/dev/null \
   && ! git -C "$REPO_ROOT" merge-base --is-ancestor main origin/main 2>/dev/null; then
  echo "[step4a] shared root diverged (local main and origin/main mutually non-ancestral) — running sanctioned sync"
  uv run python "$REPO_ROOT/scripts/sync_repo_root.py" || \
    echo "[step4a] sync_repo_root.py exited non-zero; proceeding — the L2023 pre-check reads origin/main directly and is unaffected"
  # Re-probe once: sync exit 0 includes in-flight state (docstring §c), so
  # confirm convergence via the same ancestry test rather than the exit code.
  if ! git -C "$REPO_ROOT" merge-base --is-ancestor origin/main main 2>/dev/null \
     && ! git -C "$REPO_ROOT" merge-base --is-ancestor main origin/main 2>/dev/null; then
    echo "[step4a] shared root STILL diverged after one sync — proceeding (downstream sanctioned recoveries are the fallback; do not block Step 4)"
  fi
fi
```

**Why not FAIL/block on still-diverged:** the L2023 pre-check reads `origin/main` directly, so a stale local `main` cannot corrupt it. The probe's purpose is proactive recovery, not gating. A blocking Step-4 probe would create a new stall class where Step 4 refuses to open a draft PR on account of unrelated shared-root state — worse than the original bug.

**Why `2>/dev/null` on the `--is-ancestor` legs:** `merge-base --is-ancestor` exits 128 if either ref is missing (transient origin fetch failure, fresh clone with no local `main`). Two exit-128s would both fail as "not ancestor", tripping a false-positive probe on a repo where the truth is "we don't know yet." Silencing the error keeps the probe from surfacing a misleading divergence message; if the fetch at L2022 itself failed silently, the L2023 pre-check will still work against last-fetched `origin/main` and downstream `sync_repo_root.py` chains stay the arbiter.

## 12. Assumptions

2. **`git merge-base --is-ancestor` behavior.** Exit 0 = first arg is ancestor of second; exit 1 = it is not; exit 128 = ref missing. Bidirectional-non-ancestry probe (both `--is-ancestor A B` and `--is-ancestor B A` exit 1) fires ONLY on genuine divergence. A merely-ahead local `main` (has commits `origin/main` does not) satisfies `--is-ancestor origin/main main` (exit 0) — probe does NOT fire.
