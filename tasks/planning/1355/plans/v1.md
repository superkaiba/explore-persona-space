```markdown
- **Smoke/production parity includes GATE CALIBRATION — a kill-criterion gate calibrated at production n (a ±tol anchor-reproduction/parity check, an absolute yield floor) is structurally unsatisfiable at smoke n and deterministically kills the smoke leg.** The PASS_UNIFIED convention runs the IDENTICAL chain at tiny n (smoke IS sweep with one cell — `.claude/skills/issue/SKILL.md` Step 6d.0), so any verdict whose satisfiability depends on production n fires spuriously there: a ±0.02 anchor-reproduction check that holds at n≈5000 reads R²≈−1.5 at n=8 (a small-sample fit cannot reproduce a large-sample anchor — the gate measures n, not correctness), and an absolute yield floor above the smoke yield rc-halts the very phase the smoke exists to exercise (a floor of 2 against kept=1). This is the GATE-CALIBRATION member of the smoke/production-parity family — sibling of the PROCESS-WIDTH entry above (#1315/#1333), where a smoke branch narrows the LAUNCH shape and the run dies by OOM; here the launch is correct and the smoke leg is killed by a plan-registered VERDICT evaluated at the wrong scale. RULES: (i) thread the smoke flag into EVERY gate-bearing phase, not only the sizing knobs; (ii) run the gate's COMPUTATION identically (the code path must stay exercised) but demote production-n-calibrated verdicts to informational log lines under smoke; (iii) size smoke yield floors so any NONZERO yield proceeds; (iv) production halt paths stay byte-untouched and unit-pinned (fails-at-production-shape tests cover the halt branch the smoke no longer exercises). Diagnostic signature: the smoke leg rc-halts INSIDE a gate/floor check whose threshold is visibly production-scale (a tolerance or absolute count the tiny n cannot meet) while the identical chain at production n would pass — distinct from the width-parity entry's OOM-at-first-optimizer-step signature. (Incident #1345 r3, 2026-07-15: a ±0.02 anchor-reproduction parity gate compared n=8 smoke fits against n≈5000 production anchors (R²≈−1.5) and a smoke yield floor of 2 with kept=1 rc-halted the phase; two GCE launch cycles burned before the fix round.) Agent-memory sibling (implementer-scoped): `.claude/agent-memory/experiment-implementer/feedback_smoke_scale_gates.md` — this entry generalizes it to every agent that authors or reviews gate-bearing dispatcher phases.
```
