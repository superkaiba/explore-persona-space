### 4.3 Exact displacement and SAE accounting

Choose pooled train-context mean μ as the fixed reference origin. Let x0=c0−μ, Δc=c1−c0, ΔA=A1−A0, and Δb_ref=(b1+A1μ)−(b0+A0μ). For each actual paired answer:

`a1−a0 = A0 Δc + ΔA x0 + Δb_ref + ΔA Δc + (r1−r0)`.

Persist every per-row term, exact closure residual, norm, signed projection on actual Δanswer, and non-additive norm ratio. Call `Δb_ref` the reference-context offset, not an origin-invariant global bias. Norms do not sum. Include a symmetric attribution sensitivity allocating half the interaction to each changing factor, without treating it as more causal.

On fixed TRAIN coordinates, compute blocked feature screening scores `S=E_A ΔA D_C`. In repository row orientation this is `w_dec,C @ ΔA.T @ w_enc,A`. Avoid materializing the full 32768² matrix; process candidate input blocks and retain the exact selected edge table plus block maxima/hashes and rerunnable transform. Rank by common-train activation scale rather than raw coefficient magnitude alone; report both.

Use raw contexts for the primary map. SAE decoding adds an approximation: `c=D_C z_C+b_dec,C+e_C`. Report the mapped context-SAE residual `ΔA e_C` and the offset contribution. Otherwise a sparse edge explanation can hide the very context content that changed.

For every candidate, evaluate the full fixed SAE encoder on each predicted answer corner, including b_dec, b_enc, ReLU and inference threshold; compare with actual-answer encodes. Do not encode the difference vector and call it a feature change. Report preactivation sensitivity, realized activation difference, firing-probability difference and prediction fidelity separately. Threshold crossing is nonlinear even though the fitted map is linear.

Primary screening uses features firing on at least 0.2% of pooled training contexts/answers (#2552 lower activity floor); also report the inherited 1% floor as sensitivity. Record absolute active counts and feature variance. Exclude zero-variance features from standardized ranking, reporting their count. No claims about unseen rare features.

Freeze at most five changed edge candidates on discovery data by standardized absolute effect, after exact duplicate-direction handling, along with matched control features. Five is a bounded first-milestone choice, ungrounded—needs smoke-test; it is not a significance threshold. A candidate may fail later. Keep unselected top-128 edge records as an exploratory inventory (#2643 candidate-panel scale; here exploratory).
