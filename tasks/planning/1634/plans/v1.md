+   from a post-hoc `pgrep`.** The two sanctioned sources are (i) the
+   launcher's pre-exec `echo $$` (item 1's preferred path;

+   roles, neither of which populates the pid FILE at launch time:

+   (b) a liveness monitor's pattern-probe FALLBACK run ALONGSIDE the

+   false "exited" verdict — the pattern probe supplements, never
+   replaces, the pid file (item 2's poller contract still reads pid
+   file + marker pid).
