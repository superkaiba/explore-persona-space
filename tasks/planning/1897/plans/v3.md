# Plan v3 — Task #1897: Step 10d PR-state probe + landing verification before verdict consume

## Goal / Requirement

Step 10d's merge machinery must never report MERGE SUCCEEDED (and consume the SHA-bound
lint verdict) when `gh pr merge` exits 0 against a PR object that a PRIOR round already
merged/closed. Incident: #1768 round-2 same-issue follow-up (2026-07-30) — `gh pr merge
1527 --rebase` ran against the round-1 PR (rebase-merged + closed at round 1), `gh`
exited 0 with `! Pull request ... was already merged`, the success arm consumed the
verdict and reported success, and the 22-commit round-2 payload stayed stranded off main.
Recovery cost a fresh PR (#1604) + a full ~15-min gate re-run.

Two complementary changes to `.claude/skills/issue/SKILL.md`:

1. **PR-object liveness probe** at the safe-case merge entry: resolve the PR's `state`
   (and pre-attempt `mergedAt`) alongside its number; a non-OPEN (MERGED/CLOSED) PR gets
   a FRESH draft PR (Step 4a-shape pre-checked creation) before any merge attempt.
2. **Landing verification in both `gh pr merge` success arms** (safe case + merge-conflict
   recovery): capture the PR's `mergedAt` BEFORE the attempt; after exit 0, require
   `state == MERGED` AND `mergedAt` non-null AND `mergedAt != pre-attempt value` before
   consuming the verdict; otherwise treat as MERGE FAILED (verdict survives; route to the
   existing failure handling).

### Acceptance criteria

- **A1 (probe):** the safe-case block resolves `number,state,mergedAt` in one
  `gh pr view` read; a non-OPEN state routes to a fresh `gh pr create --draft` guarded by

  zero commits ahead takes the existing nothing-to-merge skip), then rebinds `<PR>` +

  freshness), NEVER branch-sha ancestry (a rebase merge lands rebased COPIES — new shas).

- **E1 — safe-case PR resolution (L12133).** Replace
  `PR=$(gh pr view <PR> --json number -q .number 2>/dev/null) || true` +
  the `if [ -z "$PR" ]` head with a probe block:

  ```bash
  # PR-object liveness probe (#1768 round-2 / #1897): a follow-up round's
  # branch outlives its round-1 PR — a MERGED/CLOSED PR is a TERMINAL
  # GitHub object (new branch commits never attach), and `gh pr merge` on
  # one exits 0 with "was already merged" (false success: verdict
  # consumed, payload stranded). Resolve state + pre-attempt mergedAt
  # alongside the number, and require OPEN before any merge attempt:
  PR_INFO=$(gh pr view issue-<N> --json number,state,mergedAt \
    -q '[.number, .state, (.mergedAt // "null")] | join(" ")' 2>/dev/null) || true
  PR=$(echo "$PR_INFO" | cut -d' ' -f1)
  PR_STATE=$(echo "$PR_INFO" | cut -d' ' -f2)
  PRE_MERGED_AT=$(echo "$PR_INFO" | cut -d' ' -f3)
  if [ -z "$PR" ]; then
    echo "No PR for issue-<N>; nothing to merge."   # existing skip (unchanged)
  else
    if [ "$PR_STATE" != "OPEN" ]; then
      # Fresh draft PR via the Step 4a pre-checked shape (bounded fetch +
      # aheadness): a terminal PR never merges new commits.
      timeout --kill-after=30s 120s git -C "$REPO_ROOT" fetch origin main --quiet || true
      if [ "$(git -C "$REPO_ROOT" rev-list --count origin/main..issue-<N>)" -gt 0 ]; then
        gh pr create --draft --head issue-<N> \
          --title "issue-<N>: <task title> (round follow-up)" \
          --body "Closes task #<N>. Fresh PR: prior PR #$PR is $PR_STATE (#1897 probe)."
        PR_INFO=$(gh pr view issue-<N> --json number,state,mergedAt \
          -q '[.number, .state, (.mergedAt // "null")] | join(" ")')
        PR=$(echo "$PR_INFO" | cut -d' ' -f1)
        PR_STATE=$(echo "$PR_INFO" | cut -d' ' -f2)
        PRE_MERGED_AT=$(echo "$PR_INFO" | cut -d' ' -f3)
      else
        echo "issue-<N> has no commits ahead of origin/main — content already landed; nothing to merge (prior PR #$PR $PR_STATE stays the record)."
        # take the existing already-merged skip path; post nothing new
      fi
    fi
    # ... existing guards 0-5 / fast-path / gate flow continue here ...
  fi
  ```

  (`gh pr view issue-<N>` by branch name prefers the OPEN PR when one exists, so the
  re-resolve after `gh pr create` binds the fresh PR.)

- **E2 — safe-case success arm (L12340-12341).** Between `if gh pr merge <PR>
  $MERGE_FORM --delete-branch=false; then` and the `rm -f` verdict consume, insert:

  ```bash
  # Landing verification (#1897): exit 0 is NOT proof THIS attempt landed —
  # `gh pr merge` on an already-merged PR exits 0 with "was already merged".
  # Verify via the PR object (never branch-sha ancestry: a rebase merge
  # lands rebased COPIES). Bounded poll for GitHub's async state settle.
  LANDED_OK=no
  for _ in 1 2 3; do
    POST=$(gh pr view <PR> --json state,mergedAt \
      -q '[.state, (.mergedAt // "null")] | join(" ")' 2>/dev/null) || POST=""
    if [ "${POST%% *}" = "MERGED" ] && [ "${POST##* }" != "null" ] \
       && [ "${POST##* }" != "$PRE_MERGED_AT" ]; then LANDED_OK=yes; break; fi
    sleep 10
  done
  if [ "$LANDED_OK" != "yes" ]; then
    echo "MERGE NOT VERIFIED — gh pr merge exited 0 but the PR object shows no FRESH merge (state/mergedAt unchanged vs pre-attempt: the exit-0 'was already merged' false-success shape, #1768/#1897). Verdict NOT consumed; re-enter via the PR-state probe (fresh PR) — do NOT report success."
    false
  fi
  rm -f /tmp/issue-<N>-lint-verdict.txt   # consume on VERIFIED merge success only
  # ... existing root-sync + success body unchanged ...
  ```

  Note: the verification failure arm must short-circuit the success body via the same
  variable-gated conditional discipline the surgical block uses (a bare `false` mid-block
  does not halt subsequent commands) — the implementer restructures as
  `if [ "$LANDED_OK" = yes ]; then <success body> else <echo + false> fi`.
