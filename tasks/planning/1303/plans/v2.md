### 3b. The pin test (new file)

- **Path:** `tests/test_no_hasattr_asw_stub_guards.py` (follows the `tests/test_no_*` invariant-pin family: `test_no_pod_side_task_py_shellout.py`, `test_no_direct_task_path_construction.py`).
- **Test name:** `test_no_hasattr_guarded_asw_stubs_in_tests`.
- **Mechanism:** pure-Python line scan (no subprocess — `tests/test_workflow_lint.py` subprocess-runs lint checks and is slow; this is milliseconds): `rglob` every `tests/**/*.py` under repo root, match each line against `re.compile(r"if\s+hasattr\(\s*asw\b")`, collect `(relpath, lineno, line.strip())`, assert the list is empty with a remediation message ("use bare `monkeypatch.setattr(asw, name, ...)` — fail-loud on a renamed watcher pass; see #1303 / #1295").
- **Scan-sanity (anti-vacuous-pass — round-1 Statistics Must-Fix):** the scan roots at the repo root resolved from the pin file's own location (`Path(__file__).resolve().parents[1]` — tests/ → repo root), NEVER cwd; the main test asserts the scanned file set is non-empty AND contains `tests/test_autonomous_session_watch.py`, so a wrong rglob root that visits 0 files FAILS instead of vacuously passing. A companion fixture test (`test_scanner_finds_planted_offence`) writes one offending `if hasattr(asw, name):` line into a `tmp_path` tree and asserts the scanner (factored to take a root parameter) reports it — the precedent's own shape (`test_no_pod_side_task_py_shellout.py`: `assert offences` on a planted case).
- **Self-match safety (LOAD-BEARING, not belt-and-braces — round-1 Methodology + Alternatives):** the scan skips the pin file itself (`path.name == Path(__file__).name`), precedent: `test_no_pod_side_task_py_shellout.py` allowlists itself. The exclusion is load-bearing: the matcher unit test's POSITIVE parametrize literals (`"if hasattr(asw, name):"`) live in this file and WOULD match the line scan — the regex-escape argument covers only the compiled-pattern source literal. Do not drop it.
- **Allowlist policy: none.** Verified at plan time: the only `hasattr(asw` occurrences anywhere in `tests/` are the 5 target sites (`grep -rn "hasattr(asw" tests/ --include="*.py"` — 5 hits, all the guard form). Other `if hasattr(` uses in tests target other objects (`fitM`, `ctx`, `ids`, `mod`) and are outside the `asw`-scoped pattern by construction. A future legitimate conditional would add a documented allowlist then — none is pre-provisioned.
- **Matcher unit test:** one small `pytest.mark.parametrize` companion (`test_hasattr_asw_pattern_matcher`) pinning 2 positive shapes (`if hasattr(asw, name):`, `if hasattr(asw,name):`) and 2 negatives (`assert hasattr(asw, "x")`, `if hasattr(mod, "build_arg_parser"):`) — the precedent files all pin their matchers.
- **Honest scope bound (stated in the pin file's module docstring + a matcher-test comment):** the pattern targets the `if hasattr(asw` form under the `asw` alias only — not `if not hasattr(asw...)` skip-forms, other import aliases, `getattr(asw, name, None)`, or line-broken forms. The PRIMARY fail-loud guard is the converted sites' bare setattr + pytest's `raising=True` default; the pin prevents recurrence of the one form that actually recurred (5 sites, all identical). A dodging form is a new bug for code review, not a hole this pin must close.

  - What: new `tests/test_no_hasattr_asw_stub_guards.py`, pure-Python regex line scan over `tests/**/*.py`.
