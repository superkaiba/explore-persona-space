### 4.1 NEW `scripts/daily_drive_filings.py` (~150-180 lines)

Promotion of `logs/daily/filings-2026-07-04/drive_filings.py` with the ad-hoc warts fixed (dead `for tok ... pass` loop at its L71-73 removed; `import re` at top; docstrings; `pathlib`; ruff-clean at line-length 100/py311) and three hardening deltas. Spec:

**CLI** (argparse — argparse is correct here per precedent `file_infra_task.py`; this is an orchestration-layer helper, not a Hydra experiment entrypoint):
- `--dir` (required): the filings dir, e.g. `logs/daily/filings-2026-07-05`.
- `--start` / `--end` (optional ints): manifest slice; default whole manifest.
- `--date` (optional): for the `origin_prompt` string; default parsed from the dir basename `filings-YYYY-MM-DD` (fail loud if neither yields a date).
- `--filer` (optional): argv prefix override for the filer command; default `["uv","run","python","scripts/file_infra_task.py"]` run with `cwd=repo_root`. This is the test seam — the test passes a real stub executable, so the production body (subprocess included) executes for real (#906 discipline).
- `--tasks-root` (optional): dedup/recovery scan root; default `<repo_root>/tasks`. Test seam.
- `--retry-errors` (flag): re-attempt slugs whose only terminal row is `ERROR` (default: skip them, matching ad-hoc behavior).
- `--dry-run` (flag): print per-item planned action (FILE/DEDUP/SKIP + tags); no subprocess, no ledger writes.

**Behavior per manifest item `{slug, route: 2|3, title, target, bug, change, body?}`** (`body` defaults to `<dir>/<slug>.md`; missing body file = fail loud, no silent skip):
1. **Resume:** skip if `filed.jsonl` has a terminal row (`filed|deduped|recovered`, plus `ERROR` unless `--retry-errors`) for the slug → print `SKIP`.
2. **Recovery of a trailing `attempting` row** (kill-during-file window): if the slug's LAST row is `attempting` with no terminal row, scan `<tasks-root>/*/*/body.md` for a task whose frontmatter `title` equals `item["title"][:60]` — found ⇒ append `{"slug", "outcome": "recovered", "id": <N>, "fp", "route", "ts"}` and continue to the next item; not found ⇒ the filing never committed, proceed to file normally.
3. **Dedup (route 2 only, same predicate as the ad-hoc driver):** `fp = wf_fix_fingerprint(item["change"], item["bug"])` (import `from explore_persona_space.task_workflow import wf_fix_fingerprint`); a non-terminal task (path not under `completed/` or `archived/`) whose `body.md` contains `wf-fix-fp:<fp>` ⇒ append `{"slug","outcome":"deduped","against":<path>,"fp","route","ts"}`, do not file. (Do NOT use `is_open_workflow_fix_task` — it requires the `workflow-fix:` title prefix; daily filings are `daily-fix:`.)
4. **Two-phase ledger:** append `{"slug","outcome":"attempting","fp","route","ts"}`; THEN invoke the filer via `subprocess.run(..., cwd=repo_root, timeout=280)`:
   - route 2: `--kind infra --title item["title"][:60] --body-file <body> --origin-prompt "/daily <date> problem sweep (route 2): <bug[:400]>" --tag wf-fix --tag wf-fix-fp:<fp> --tag daily-auto-filed`
   - route 3: same base + `--tag daily-held --tag needs-human --no-dispatch` (no wf-fix tags — explicit non-change, §11.6)
   - parse id via `re.search(r"#(\d+)", stdout+stderr)` (the filer's success lines all start `filed #<id>`); append terminal row `{"slug","outcome":"filed"|"ERROR","id","rc","fp","route","tail": out[-300:], "ts"}`.
5. All ledger appends are single-line `O_APPEND`-mode writes (checkpoint-per-phase rule); ISO-UTC `ts` on every row (delta over the ad-hoc schema).
6. **Exit code:** process the whole slice, then exit 1 if any `ERROR` terminal row was appended this invocation, else 0 (record-then-report; fail loud, no swallowed failures).
7. Per-item stdout line: `FILED <slug> -> #<id> (rc=0)` / `DEDUP <slug> -> <path>` / `SKIP <slug>` / `RECOVERED <slug> -> #<id>` / `ERROR <slug> (rc=N)` — same operator-legible shape as the ad-hoc run.

### 4.3 NEW `tests/test_daily_drive_filings.py` (~150-200 lines)

4. Dedup: `--tasks-root` tree with a `proposed/<M>/body.md` carrying `wf-fix-fp:<fp>` ⇒ `deduped` row, filer not invoked; the same body under `completed/` ⇒ NOT deduped.

6. Filer exit 1 ⇒ `ERROR` row, later items still processed, process exit code 1; re-invocation without `--retry-errors` skips it, with the flag retries it.
7. `--dry-run` ⇒ no subprocess, `filed.jsonl` unmodified.
8. Missing body file / missing manifest ⇒ raises (fail-loud), no ledger row.
