# Plan — #1341: escalate-only watcher pass for stale untracked root code drafts

## Plan Summary

Add `root_draft_pass` to `scripts/autonomous_session_watch.py` (10-min cron): an
escalate-only, daemon-independent observer that enumerates UNTRACKED `*.py` in the
shared repo-root working tree via `git --no-optional-locks status --porcelain -- *.py`
(the exact `.py` leg of step9c's `DIRTY_CODE_PATHSPEC`, `scripts/step9c_baseline.py:143`),
flags files with mtime age > `EPM_ROOT_DRAFT_ESCALATE_HOURS` (default 3 h), and on a hit
writes a row to a dedicated sidecar (`.claude/cache/root-draft-events.jsonl`) + one
deduped Telegram digest push with best-effort `issue<M>_` filename attribution. NEVER
deletes or moves files. Pure `decide_*` predicate + IO driver split, singleton dedup
state (per-path fire-once + 24 h re-alert), kill switch `EPM_DISABLE_ROOT_DRAFT_PASS=1`,
`--root-draft-only` CLI flag, dry-run honored. Motivating incident: #1320 — untracked
`scripts/issue825_*.py` drafts made every task's Step 9c compare fleet-wide indeterminate,
silently, for 9+ hours; recurrence live today (`scripts/issue922_fixed_point_slow_modes.py`).

## 11. Decision Rationale

- **Staleness threshold 3 h (`EPM_ROOT_DRAFT_ESCALATE_HOURS`).** What: min mtime age before
  escalation. Why: #1320's dirt aged ≥11 h undetected; 3 h clears any legitimate
  write→commit window (CLAUDE.md mandates same-turn explicit-path commits; the watcher's
  worktree-activity hold uses 15 min, the stale-worktree grace 6 h — 3 h sits between).
  Source: #1341 body diff sketch ("default ~3") + #1320 body timeline. Alternatives: 1 h
  (noisier for slow inline-analysis rounds), 6 h (halves the detection win).
- **Scan pathspec `("*.py",)` repo-wide, untracked-only.** What: the enumeration scope.
  Why/Source: byte-aligns with the `.py` leg of `DIRTY_CODE_PATHSPEC`
  (`scripts/step9c_baseline.py:143`, consumed by `dirty_code_paths` :440-446 → ledger
  :930-941) — the exact poisoning surface; untracked-only matches both observed incidents.
  Alternatives: `scripts/`+`src/` only (candidate sketch — a strict subset, misses
  root-level drafts); include ` M` tracked-modified (deferred, named trigger in §4).
- **Dedup: per-path fire-once + 24 h re-alert (`EPM_ROOT_DRAFT_REALERT_HOURS`).** What:
  dedup key = path; TTL re-alert. Why: the condition poisons the fleet WHILE it persists
  (unlike the triage observer's fixed historical records → pure fire-once), but a 10-min
  cron must not re-push per tick. Source: happy-patch per-state dedup + disk-guard
  ack/band precedents (`background-automation.md`); TTL 24 h ≈ one digest/day for a
  persisting abandonment. Alternatives: episode dedup with recovery reset (disk-pass
  shape — wrong fit: no continuous metric to band); ack-sentinel (overkill for v1).
- **Dedicated sidecar, not `disk-guard-events.jsonl`.** Source: the three newest observer
  passes (#849 :4152, #967 :4642, #1170 :4883) each got dedicated streams; this is not
  disk pressure.
- **`--no-optional-locks`.** Source: git-status(1); CLAUDE.md § Concurrent repo-root
  committers (index.lock collisions are a live failure class on this root).
- **No task markers.** Source: verdict-disagree precedent (:4883, "NO task marker —
  deliberate divergence"); mis-attribution safety (§8).
