### 3.1 The contamination gate (which dirt a scratch tree neutralizes)

**Verified mechanism:** the main root's venv resolves the library via a *static-path* `.pth` — `.venv/lib/python3.11/site-packages/__editable__.explore_persona_space-0.1.0.pth` contains the literal line `/home/thomasjiralerspong/explore-persona-space/src`. So any pytest subprocess using `resolve_root_python(root)` imports `explore_persona_space` from the MAIN root's live `src/` **regardless of cwd**. A scratch tree therefore decontaminates dirt in `scripts/`, `tests/`, and any other tracked path (the scratch has committed copies; test-relative imports resolve inside the scratch rootdir) — but NOT top-level `src/**` (library code stays live-dirty) nor `pyproject.toml`/`uv.lock` (the venv's installed deps derive from them).

## 3.2 Scratch-worktree helpers (new)

```python
SCRATCH_EXCLUDES = ("eval_results", "external", "ood_eval_results")  # mirror of new_worktree.sh:76 EXCLUDES

@dataclass
class _ScratchTree:
    parent: Path   # the mkdtemp dir (rmtree target)
    path: Path     # the worktree itself: parent / f"tree-{os.getpid()}"
    sha: str       # the detached HEAD sha (== root HEAD at creation)

def _git_bounded(argv: list[str], cwd: Path, timeout_s: float) -> None:
    """Run one git command with check=True + timeout (scratch lifecycle only)."""
    subprocess.run(["git", *argv], cwd=str(cwd), capture_output=True, text=True,
                   check=True, timeout=timeout_s)

def _work_root_sparse_cones(wt: Path) -> list[str] | None:
    """The invoking work root's ACTUAL sparse profile via `git -C <wt> sparse-checkout
    list`; None when the work root is not sparse (command fails) — the caller treats
    None as fallback-INELIGIBLE (R-G: a non-sparse gate layout cannot be superset-
    matched by a sparse scratch without a full 7.4 GB checkout, which is must-ask)."""
    try:
        return [ln.strip() for ln in
                _git_out(["sparse-checkout", "list"], wt).splitlines() if ln.strip()]
    except subprocess.CalledProcessError:
        return None

def _scratch_cones(root: Path, wt_cones: list[str]) -> list[str]:
    """Scratch sparse profile = SUPERSET of the gate layout (R-G): the work root's
    actual sparse-checkout list (per-issue + manually-added cones included — the
    $CONES/$EXISTING legs new_worktree.sh sets that the registry alone omits,
    alternatives reconciler round 1) ∪ the HEAD-PINNED tests/sparse_cones.txt
    (git show HEAD:... — never the live working-tree file, which is itself
    decontaminable-classified dirt) ∪ every top-level tracked dir minus
    SCRATCH_EXCLUDES as the floor."""
    dirs = [d for d in _git_out(["ls-tree", "--name-only", "-d", "HEAD"], root).splitlines()
            if d and d not in SCRATCH_EXCLUDES]
    registry_lines: list[str] = []
    with contextlib.suppress(subprocess.CalledProcessError):  # registry absent at HEAD: floor still applies
        registry_lines = [ln.strip() for ln in
                          _git_out(["show", "HEAD:tests/sparse_cones.txt"], root).splitlines()
                          if ln.strip() and not ln.strip().startswith("#")]
    return sorted(set(dirs) | set(registry_lines) | set(wt_cones))

def create_scratch_worktree(root: Path, wt_cones: list[str], timeout_s: float) -> _ScratchTree:
    """Materialize a detached SPARSE scratch tree at *root*'s HEAD under a fresh
    tmp dir. Sequence mirrors new_worktree.sh _sparse_setup (init --cone FIRST).
    Profile = _scratch_cones(root, wt_cones) — superset of the gate layout (R-G).
    Any failure tears down partial state and re-raises (caller maps to
    _Indeterminate). Bounded per git call by *timeout_s*."""
    sha = git_head(root)
    parent = Path(tempfile.mkdtemp(prefix="step9c-scratch-"))
    tree = parent / f"tree-{os.getpid()}"
    try:
        _git_bounded(["worktree", "add", "--detach", "--no-checkout", str(tree), sha],
                     cwd=root, timeout_s=timeout_s)
        _git_bounded(["sparse-checkout", "init", "--cone"], cwd=tree, timeout_s=timeout_s)
        _git_bounded(["sparse-checkout", "set", *_scratch_cones(root, wt_cones)],
                     cwd=tree, timeout_s=timeout_s)
        _git_bounded(["checkout", sha], cwd=tree, timeout_s=timeout_s)  # populate from --no-checkout limbo
    except BaseException:
        remove_scratch_worktree(root, _ScratchTree(parent=parent, path=tree, sha=sha))
        raise
    return _ScratchTree(parent=parent, path=tree, sha=sha)

def remove_scratch_worktree(root: Path, scratch: _ScratchTree) -> None:
    """Best-effort teardown; never raises (the verdict is already decided).
    Deliberately NO `git worktree prune` (critic round 1): prune reaps admin
    entries of ANY worktree whose dir is unreachable, so a future bind-mount
    outage on .claude/worktrees could make a compare's teardown break LIVE
    worktrees. A SIGKILL'd compare leaves one cosmetic stale admin entry
    (git gc's worktreePruneExpire sweeps it) + an inert /tmp dir."""
    with contextlib.suppress(Exception):
        subprocess.run(["git", "worktree", "remove", "--force", str(scratch.path)],
                       cwd=str(root), capture_output=True, timeout=60)
    shutil.rmtree(scratch.parent, ignore_errors=True)
```

**Measured basis (live probe on this repo, 2026-07-06):** `worktree add --detach --no-checkout` 0.02 s; sparse-set + populate 2.5 s / 278 MB at a narrow 4-cone profile; the production profile (all top dirs minus 3 excludes + 6 fixture cones) sums to ~944 MB by `git ls-tree -r -l` → est. 5–15 s. Full checkout would be 63,685 files / 7.40 GB — rejected: `/` is live at 87% used / 63 GB free (`df`), and sparse matches the exact layout the gate run itself uses (see §11 item 3).

### 3.4 `_resolve_pristine_bucket` — the fallback hook

`_CompareCtx` gains two fields: `pristine_oracle: str = "root"`, `scratch_sha: str | None = None`. `_Indeterminate` gains an optional payload: `def __init__(self, msg, extra: dict | None = None): super().__init__(msg); self.extra = extra or {}`.

```python
def _resolve_pristine_bucket(ctx, root, args) -> None:
    if not ctx.pristine_bucket:
        return
    files = sorted({n.file for n in ctx.pristine_bucket})
    if len(files) > args.max_pristine_files:
        raise _Indeterminate("systemic main breakage (...)")          # unchanged
    if not args.run_pristine:
        raise _Indeterminate("... per-file pristine commands ...")     # unchanged
    scratch: _ScratchTree | None = None
    wt_cones = _work_root_sparse_cones(ctx.work_root)   # None => non-sparse => ineligible (R-G)
    try:
        for test_file in files:
            try:
                ctx.live_dirty_paths = dirty_code_paths(root)          # per-file re-probe (MF-4c freshness, unchanged)
                contaminating = scratch_contamination_probe(root)      # per-file re-probe too (mid-loop transitions)
            except subprocess.CalledProcessError as exc:
                raise _Indeterminate(f"dirt probe failed at {root}: {exc}", warns=ctx.warns) from exc
            use_scratch = (
                bool(ctx.live_dirty_paths)
                and not contaminating                     # R-B: src/-wide probe, not the .py filter
                and wt_cones is not None                  # R-G: sparse work root only
                and test_file not in ctx.sel.GLOB_SCAN_TESTS   # R-F: scan-set never scratch-resolved
                and not args.no_scratch_fallback
            )
            if use_scratch and scratch is None:
                try:
                    scratch = create_scratch_worktree(root, wt_cones, timeout_s=args.scratch_timeout_s)
                except (subprocess.CalledProcessError, subprocess.TimeoutExpired, OSError) as exc:
                    raise _Indeterminate(
                        f"scratch-worktree fallback failed ({exc}) — dirty oracle unresolvable",
                        extra={"live_dirty_paths": ctx.live_dirty_paths}, warns=ctx.warns,
                    ) from exc
                ctx.pristine_oracle = "scratch-worktree"
                ctx.scratch_sha = scratch.sha
                ctx.warns.append(
                    f"SCRATCH-ORACLE WARN: root dirty on non-contaminating paths "
                    f"{ctx.live_dirty_paths[:20]}; pristine oracle re-rooted to a detached "
                    f"sparse scratch worktree at {scratch.sha[:12]} (root venv interpreter; "
                    "contamination probe src//pyproject.toml/uv.lock was clean; scan-set "
                    "nodes and non-sparse work roots stay indeterminate)"
                )
            try:
                main_failing = run_single_file_pristine(
                    test_file,
                    cwd=scratch.path if use_scratch else root,
                    timeout_s=args.pristine_timeout_s,
                    venv_root=root if use_scratch else None,
                )
            except PristineRunError as exc:
                raise _Indeterminate(f"{exc} — indeterminate", warns=ctx.warns) from exc
            ctx.pristine_files_run.append(test_file)
            for node in [n for n in ctx.pristine_bucket if n.file == test_file]:
                if node in main_failing:
                    if not use_scratch and ctx.live_dirty_paths:
                        raise _Indeterminate(                            # MF-4c, fail-closed residual
                            f"pristine oracle is DIRTY (contaminating: {contaminating[:20] or 'n/a'}; "
                            f"visible code dirt: {ctx.live_dirty_paths[:20]}; "
                            f"scan_set={test_file in ctx.sel.GLOB_SCAN_TESTS}, "
                            f"sparse_wt={wt_cones is not None}) — a 'pre-existing' verdict for "
                            f"{node.file}::{node.name} from a dirty root is untrustworthy (MF-4c); "
                            "indeterminate",
                            extra={"live_dirty_paths": ctx.live_dirty_paths,
                                   "contaminating_paths": contaminating},
                            warns=ctx.warns,
                        )
                    _strip_node(ctx, node, via="pristine-scratch" if use_scratch else "pristine")
                else:
                    ctx.new.append(node)                                 # PASS still classifies NEW (fail-closed)
    finally:
        if scratch is not None:
            remove_scratch_worktree(root, scratch)
```

### 3.5 JSON-on-every-exit (`cmd_compare` + `_compare_impl`)

```python
def _indeterminate_payload(
    reason: str, pytest_rc: int, extra: dict | None = None, warns: list[str] | None = None
) -> dict:
    """The stable exit-2 --json shape: callers branch on `indeterminate` mechanically.
    `warns` carries the ctx-accumulated WARNs (e.g. SCRATCH-ORACLE provenance from an
    earlier bucketed file) so a mid-loop failure never drops audit provenance."""
    return {
        "indeterminate": True,
        "reason": reason,
        "exit_code_intent": 2,
        "pytest_rc": pytest_rc,
        "new": [],
        "stripped": [],
        "warns": list(warns or []),
        **(extra or {}),
    }

def cmd_compare(args) -> int:
    if args.pytest_rc not in (0, 1):
        reason = (f"pytest rc {args.pytest_rc} (aborted/interrupted/internal-error run) — "
                  "refusing to classify a partial run (MF-1b)")
        _log(reason)
        if args.json:
            print(json.dumps(_indeterminate_payload(reason, args.pytest_rc), indent=2, sort_keys=True))
        return 2
    try:
        result = _compare_impl(args)
    except _Indeterminate as exc:
        _log(str(exc))
        if args.json:
            print(json.dumps(
                _indeterminate_payload(str(exc), args.pytest_rc, exc.extra, warns=exc.warns),
                indent=2, sort_keys=True))
```

## 11. Decision Rationale

N/A — no training hyperparameters. Load-bearing design constants:

1. **Scratch ref = root's local HEAD (not `origin/main`).** *Why:* the strip semantics is "pre-existing at CURRENT clean main HEAD" (module docstring `:51`; #1022 plan §3.4), and ledger staleness (`code_commits_since`) is anchored to root HEAD — an `origin/main` oracle asks a *different* question whenever local/remote diverge, and needs a fetch (network dependency in a verdict gate). *Source:* #1022 plan §3.4 + this plan's reasoning; the incident sessions' `origin/main` was an improvisation, not a semantic choice. *Alternative:* `origin/main` (rejected: divergence + fetch).
2. **Contamination gate = top-level `src/` prefix + `{pyproject.toml, uv.lock}`.** *Why/Source:* verified static-path editable `.pth` (Assumption A1) — the root venv resolves `<root>/src` live regardless of cwd; deps derive from pyproject/uv.lock. `scripts/`/`tests/`/other dirt IS neutralized (scratch has committed copies; rootdir-relative resolution pinned by N6). *Alternative:* also gate `scripts/` (rejected — provably decontaminated, and it is THE incident dirt class).
3. **Sparse scratch, `new_worktree.sh`-equivalent profile.** *Why:* measured full checkout = 7.40 GB / 63,685 files on a root disk live at 87% used (63 GB free) vs sparse ≈ 944 MB / ~5–15 s (narrow-profile probe: 2.5 s / 278 MB); the chosen profile is the EXACT layout every issue worktree already runs the full gate in daily (top dirs minus `EXCLUDES` + `tests/sparse_cones.txt`), minimizing layout divergence between the gate run and the oracle run. *Source:* live probes (this plan); `new_worktree.sh:76,230-285`; #671/#897. *Alternatives:* full checkout (disk risk, no fidelity gain for the gate universe — its excluded dirs are excluded from gate worktrees too); minimal 4-cone profile (rejected: narrower than the gate layout widens the false-strip window of §8-risk-1).
4. **`--scratch-timeout-s` default 120 s (per git command).** *Source:* measured 2.5 s at the 278 MB profile → est. ≤15 s at 944 MB → ~10× headroom; bounded so a wedged git can never stall the verdict gate unboundedly. *Alternative:* one global budget (rejected — per-command is simpler and each command is independently fast).
5. **Fallback tier: scratch-always (when gated safe); NO disjoint-dirt-trust tier.** *Why:* "dirt is disjoint from what this test reads" requires import-graph reasoning that cannot be soundly approximated by path comparison (a dirty `scripts/foo.py` can be imported by any test); the scratch gives a real guarantee for ~3–15 s against a 600 s pristine budget. Simplest design that removes the manual recovery (orchestrator brief's stated bias). *Source:* this plan's reasoning; incidents #1029/#1056 (both chose the scratch, not disjointness reasoning).
6. **`--no-scratch-fallback` kill switch.** *Why:* restores the exact pre-#1077 MF-4c behavior for callers/tests that want it; one flag + one conjunct. *Source:* #1022 R-series fail-closed discipline.
7. **Contamination probe pathspec `("src/", "pyproject.toml", "uv.lock")` — ALL files, separate from `DIRTY_CODE_PATHSPEC`.** *Why:* 13 tracked non-`.py` files live under top-level `src/` (12 query-bank JSONs + README) and resolve LIVE through the editable `.pth` via `importlib.resources` (`artifacts/banks.py`); the `.py`-scoped filter alone converts the mixed-dirt case into a false strip. MF-4a's churn rationale applies to the dirt TRIGGER, untouched. *Source:* methodology-lens Codex Must-Fix + reconciler round-1 verification (`git ls-files src/ | grep -v '\.py$'`).
8. **Scan-set (`GLOB_SCAN_TESTS`) exclusion from scratch resolution.** *Why:* live-tree scanners resolve the MAIN root via `repo_root()` (module-`__file__`-anchored through the `.pth`) / installed-package paths, so root dirt reproduces in a "pristine" scratch and would strip a co-occurring branch violation; `ctx.sel.GLOB_SCAN_TESTS` is the mechanical, selector-owned proxy for that class (over-broad for `Path(__file__)`-anchored scanners — accepted; those nodes just keep today's exit-2). *Source:* statistics-lens Claude Must-Fix (38 `repo_root()`/path-anchor hits across 30+ test files); alternatives-lens `load_workflow_yaml()` note.
9. **Scratch profile = work-root `sparse-checkout list` ∪ HEAD-pinned registry ∪ top-dirs floor; non-sparse work root ineligible.** *Why:* the gate worktree carries per-issue + manually-added cones (`new_worktree.sh` `$CONES`/`$EXISTING`) the registry alone omits; a scratch missing one fails a node at runtime (fixture `FileNotFoundError`, the #897 signature) under the SAME node key (`parse_junit` counts `error` children) → false strip of a genuine branch regression. Superset-by-construction closes it; the HEAD-pinned registry read closes the dirty-registry composition (tests/ dirt is decontaminable-classified). A non-sparse (repo-root) compare cannot be superset-matched without a 7.4 GB full checkout (must-ask) → ineligible, keeps exit-2. *Source:* alternatives-lens Codex Must-Fix + reconciler round-1 verification.
10. **No `git worktree prune` in teardown.** *Why:* prune reaps admin entries of ANY worktree whose dir is unreachable — a post-#681 bind-mount outage would make LIVE issue worktrees prune-able from an unrelated compare's teardown. Residue without prune: one cosmetic stale admin entry a SIGKILL leaves (git gc's `gc.worktreePruneExpire` sweeps it; a fresh unique-path `worktree add` is never blocked by it). *Source:* methodology + alternatives Claude concerns, adopted.
