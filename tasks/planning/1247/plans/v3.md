### Part C — source stamp

**File:** `scripts/autonomous_session_watch.py`, new module-level helper near the sentinel constants (~:880):

```python
@functools.lru_cache(maxsize=1)
def _source_stamp() -> str:
    """Self-identification suffix for respawn-class marker notes (#1247):
    host + user + pid + short HEAD sha + root of the RUNNING checkout
    (Path(__file__)-derived, deliberately NOT the git-common-dir-resolved
    PROJECT_ROOT — the point is to expose a stale worktree/clone copy).
    Fail-soft: sha=unknown on any git failure; never raises."""
    script_root = Path(__file__).resolve().parent.parent
    try:
        sha = subprocess.run(
            ["git", "rev-parse", "--short", "HEAD"],
            cwd=script_root, capture_output=True, text=True, timeout=5,
        ).stdout.strip() or "unknown"
    except (subprocess.SubprocessError, OSError):
        sha = "unknown"
    return (
        f"[src: host={socket.gethostname()} user={getpass.getuser()} "
        f"pid={os.getpid()} sha={sha} root={script_root}]"
    )
```

## 7. Threat model — what the guard closes and does not close

**Cheapest authoritative live read — decision:** reuse `_task_status(issue)` (:5345). **Closes:** (T1) the intra-tick TOCTOU — status flips between the pass-start `_active_status_tasks()` snapshot and the act (minutes on a slow tick, multi-tick for the stalled fence). (T2) the OBSERVED incident shape — a guard-bearing instance whose status VIEW is stale but whose `task.py` act-time resolution reaches the canonical tree: the junk rows landed in canonical `tasks/archived/662/events.jsonl` on canonical `main`, proving the poster's `task.py post-marker` resolved 662's canonical archived path at act time; a `view`-based re-check through the SAME subprocess/cwd/env path therefore returns `archived` (→ abort-and-clear) or fails (→ abort-and-defer). (T3) state-dir resets — the guard is a per-act re-read, independent of `~/.eps-autonomous` persistence, so the never-advancing-counter environment class can't act either.

**Does NOT close (stated honestly):** (N1) an instance running a **pre-guard build** — v3 root cause: the "live rogue" is pre-fix TEST-SUITE copies in worktrees cut before this fix (decaying tail, §6 H2; the hermeticity fix stops the canonical suite immediately on merge). The stamp bounds all FUTURE recurrences to first-marker attribution. (N2) a fully self-consistent stale CLONE (own git common dir) posting into its own tree and pushing — its rows would land at the stale path (`tasks/running/662/…`), which is NOT the observed shape; if it ever occurs the stamp + F4 identify it. (N3) an arbitrary/malicious writer appending to events.jsonl directly — this is a correctness guard, not a security boundary. (N4) a **command replayer** re-invoking a logged `task.py post-marker` line verbatim (non-watcher code path) — the stamp discriminates it: any post-merge respawn-class marker WITHOUT a `[src: …]` stamp is not current watcher code (Alternatives-critic rival).
