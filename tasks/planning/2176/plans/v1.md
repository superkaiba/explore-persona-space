#### D1 — `task_workflow.py`: arm-registry parse + registry check (new code, ~90 lines; layer a)

Placed AFTER #2171's authorized-stub block (purely additive), plus ONE one-token edit inside #2171's code:

- **`_MARKER_TOP_KEY_RE` gains exactly one alternative:** `arm-registry` (i.e. `^(verdict|notes|import-resolution|per-arm-resolution|arm-registry|resume-matrix|production-outroot-unit):`). This is REQUIRED for correctness, not hygiene: `_PER_ARM_ROW_RE` matches `<name>: N/A ...`, so a vacuous `arm-registry: N/A — <reason>` line placed after `per-arm-resolution:` would otherwise be swallowed into `per_arm` as a phantom arm named `arm-registry` (pinned by test T1.8). One token inserted into #2171's regex; nothing else in their code is touched.
- **New regex + dataclasses:**

```python
_ARM_REGISTRY_RE = re.compile(
    r"^arm-registry:\s*(?:(?P<na>N/A)\s*[—-]\s*(?P<na_reason>.+?)"
    r"|source=(?P<source>\S+)\s+file=(?P<file>\S+)\s+n=(?P<n>\d+)\s+members=(?P<members>\S+))\s*$"
)

@dataclass(frozen=True)
class ArmRegistry:  # na-form XOR structured form
    na: bool; na_reason: str | None
    source: str | None; file: str | None; n: int | None; members: tuple[str, ...]

@dataclass(frozen=True)
class RegistryCheckDecision:
    ok: bool; reason: str  # one machine-legible line
    missing: tuple[str, ...]; registry: ArmRegistry | None
```

- **`parse_arm_registry_line(note: str) -> ArmRegistry | None`** — first line starting `arm-registry:`; `None` when absent; a PRESENT line matching neither form raises `ValueError` naming the two accepted grammars (caught downstream — runtime never crashes on a malformed marker, #2171 posture). `members` comma-split, backtick/whitespace-stripped, must be non-empty in the structured form. `source`/`file` are opaque provenance tokens (a multi-driver round unions members and comma-lists paths in `file=`; the checker interprets only `n` + `members`).
- **`smoke_arch_registry_check(marker_note: str) -> RegistryCheckDecision`** — the pure predicate. Calls `parse_smoke_arch_marker(marker_note)` (reuse; single positional `str`) for `per_arm`. Clause order:
  1. no `arm-registry:` line, or malformed → REFUSE with `_NO_ARM_REGISTRY_REASON` (new module constant naming BOTH accepted forms + the derivation rule "for a phase-dispatch driver, `sorted(PHASES)`; generally the dispatch table the entrypoint's phase/arm argument routes on");
  2. N/A form → **ok=True**, reason records the claim verbatim (`registry: N/A — <reason> (substantive adjudication: Step 6d.0 orchestrator + code-reviewer Step 0.55)`) — the mechanical check cannot see the driver; the reviewer verifies the no-registry claim against the diff (D7);
  3. `n != len(members)` → REFUSE (self-consistency; names both numbers);
  4. `per_arm == {}` → REFUSE reusing `_NO_PER_ARM_SUBBLOCK_REASON` verbatim (same remedy: line-anchored key, re-post);
  5. `set(members) - set(per_arm)` non-empty → REFUSE with the DISTINCT count-mismatch reason: `registry-enumeration mismatch: n_registry=<n> n_enumerated=<len(per_arm)> missing=<sorted-comma-list> (registry: <source> @ <file>)`;
  6. else ok=True, reason `registry-complete: n=<n> source=<source>`. Extra `per_arm` rows beyond `members` are ALLOWED (plan-named non-registry arms keep their rows; the old plan-named quantifier is a lower bound, not replaced). Member↔row matching is byte-wise after backtick/asterisk/whitespace strip (the same normalization `parse_smoke_arch_marker` applies to row names).

**Intended-consequence note (inherited from #2171's parser, now separately load-bearing):** rows introduced by FREE PROSE (both of #2163's real v3 AND v4 markers) parse to `per_arm == {}`, so clause 4 refuses them. That is correct behavior — it forces the line-anchored key that makes the invariant machine-checkable — and is pinned by its own test (T1.6), not left as an accident a reviewer could read as a bug.

#### D3 — `src/explore_persona_space/orchestrate/argcheck.py`: shared argparse-attribute completeness helper (new module, ~120 lines; layer b)

`assert_args_attributes_defined(*module_files: str | os.PathLike, extra_defined: Iterable[str] = (), namespace_names: Sequence[str] = ("args",)) -> None` — stdlib-only (`ast`, `pathlib`). AST-based, NOT the #2163 regex (the four measured FP classes are exactly what AST context distinguishes):

- **Defined set**, unioned across all passed module files: every `*.add_argument(...)` call — first positional `--flag` string → `flag[2:].replace("-", "_")`, positional name string → itself, an explicit `dest=` kwarg OVERRIDES (FP class 1); every `*.add_subparsers(dest=...)` (FP class 2); every `*.set_defaults(**kw)` kwarg name; every `ast.Attribute` on a `namespace_names` receiver in **Store** context (`args.X = ...` — FP class 3); plus `extra_defined`.
- **Referenced set:** every `ast.Attribute` in Load context whose value is `ast.Name(id in namespace_names)`, scanned over the WHOLE module — every function, helper, and module-level statement.
- **Missing = referenced − defined**; non-empty → `raise SystemExit` naming every gap and the file(s) scanned (fail-loud; the #2163 message shape).
- **FP class 4 (imported parser-builder)** is handled by the varargs signature: a driver whose parser is partly built by `shared_mod._add_common_args(ap)` passes both files (`assert_args_attributes_defined(__file__, inspect.getfile(shared_mod))`). Residual false positives (e.g. a non-namespace local named `args`) route through `extra_defined` — visible at the call site, never silent.
