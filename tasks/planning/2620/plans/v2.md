## 3. Method

### 3.1 Primary curation — `code-reviewer-lean/MEMORY.md` (the FAIL)

Deterministic dedupe, applied in the issue worktree:

- Iterate lines in order. Keep the header line(s) verbatim. For each bullet row, parse the
  link target; keep the row at the position of the target's FIRST occurrence; drop later
  rows for an already-seen target. For a target with variant rows, keep the LONGEST variant
  (most informative hook) at the first-occurrence position; where a length tie or a
  materially-divergent pair makes "longest" ambiguous, prefer the NEWER revision per git
  history (§8 latitude).
- Invariants asserted in-worktree before commit (inline python, not a committed script):
  (a) unique-target set before == after (no lesson lost);
  (b) every kept row's target file exists in the directory;
  (c) resulting size < 20,000 bytes;
  (d) exactly one row per target.

### 3.2 Opportunistic WARN-band pass (body: "if cheap" — it is)

- `codex-code-reviewer/MEMORY.md`: same dedupe (longest-variant rule covers its 3
  near-variant targets; see §2 for the verified materially-divergent pair). Projected
  16,548 B.
- `experiment-implementer/MEMORY.md`: same dedupe, THEN trim the longest hooks (rows
  > ~250 B) to ~1 line ≤ ~150 chars each, per the #1891 recipe. Before trimming a row,
  confirm its per-entry file exists and already carries the detail; if the hook text holds
  detail absent from the per-entry file, append that detail to the per-entry file in the
  same commit (recipe: detail moves, never deletes). Target < 20,000 B.

### 3.4 Landing discipline (Step 10d deviation — REQUIRED, stated here so the reviewer can
check it)

The curated files MUST NOT land through a union merge: our curation is exactly the
whole-file-rewrite shape that `merge=union` re-duplicates (§2), so a normal branch merge
would concatenate the curated copy with main's live copy and reproduce the bug at ~59 KB.
Land via the CLAUDE.md-sanctioned scratch worktree detached at `origin/main`:

1. Fetch origin/main; for each of the three files, reconcile by TARGET SET, **three-way
   against the branch-base copy**: start from the branch's curated content; for any link
   target present on main's current copy but absent from the curated target set (a lesson
   appended by a concurrent session since branch-cut), append that main-side row verbatim
   (deduped to one row); for any target present on BOTH sides whose main-current row
   differs from its branch-base row (a concurrent session EDITED the hook after
   branch-cut), take main's current row (then re-apply the one-row-per-target rule) — the
   curated copy must never silently revert a main-side edit. Re-assert invariants (a)-(d)
   on the composed content (invariant (a)'s "before" set = the union of branch-base and
   main-current target sets).
2. Commit by explicit path in the scratch worktree (`git commit -m ... -- <3 paths>`) —
   this ordinary `git commit` RUNS the pre-commit hook, so the landing itself is the
   acceptance-3 proof — and `git push origin HEAD:main`.
3. **Rejected-push recovery (the ONLY sanctioned retry):** on a non-fast-forward push
   rejection (near-certain occasionally under ~15 concurrent committers), DISCARD the
   scratch commit and loop back to step 1 — re-fetch origin/main, re-run the three-way
   target-set reconciliation against the new tip, re-assert invariants (a)-(d), recreate
   the commit, re-push. NEVER `git pull` / `rebase` / `merge` inside the scratch worktree
   for this landing: a rebase content-merge consults the `merge=union` driver while its
   replayed commits run no pre-commit hook, so it would re-inflate the file and push it
   with neither the size hook nor the invariants re-running — the exact channel this task
   fixes. Bounded: after ~5 consecutive rejections, re-enter from a fresh fetch after a
   short wait rather than tight-looping.
4. The commit message names the durable gap per acceptance item 4: the `merge=union`
   attribute re-duplicates whole-file rewrites of agent-memory indexes, and merge commits
   bypass the size hook (how 41 KB landed on main).

No `.gitattributes` change, no lint-threshold change, no loader change (all out of scope
per the body).
