### 4.1 New check in `scripts/workflow_lint.py`

Constants + helpers (placed near the sibling destructive-git block, ~line 5850–6000 region):

```python
_ROOT_GUARD_HOOK = _HERE / "guard_repo_root_branch.sh"   # _HERE = scripts/ of THIS tree
_ROOT_GUARD_EXEMPT_SENTINEL = "workflow-lint: allow-root-guard-block"
_ROOT_GUARD_FENCE_OPEN_RE = re.compile(r"^\s*(```|~~~)(\S*)\s*$")
_ROOT_GUARD_TIMEOUT_S = 20
```

Fence iterator (module-level, unit-testable):

```python
def _iter_bash_fences(text: str) -> Iterator[tuple[int, str, str]]:
    """Yield (opener_lineno_1based, preceding_nonblank_line, block_text) for every
    ```bash / ~~~bash fence. Closer = same fence token with empty tag. An
    unterminated trailing fence is yielded (fail toward checking — the
    check_grep_qv precedent). text.split('\n'), never splitlines()."""
```

Hook runner:

```python
def _run_root_guard(hook: Path, command: str) -> tuple[int, str]:
    payload = json.dumps({"tool_input": {"command": command}})
    proc = subprocess.run(["bash", str(hook)], input=payload, capture_output=True,
                          text=True, timeout=_ROOT_GUARD_TIMEOUT_S)
    return proc.returncode, proc.stderr
```

Main check:

```python
def check_git_recipes_root_guard(
    *, repo_root: Path | None = None, hook_path: Path | None = None,
    max_workers: int = 8,
) -> list[str]:
    root = repo_root if repo_root is not None else _REPO_ROOT
    hook = hook_path if hook_path is not None else _ROOT_GUARD_HOOK
    # (1) FAIL-LOUD self-test — never a silent pass on a missing/broken/fail-open hook.
    if not hook.is_file():
        return [f"{hook}: root-guard hook script missing — check cannot run (FAIL, not skip)"]
    try:
        rc_pos, _ = _run_root_guard(hook, _SELFTEST_BLOCKED_PROBE)   # must be 2
        rc_neg, _ = _run_root_guard(hook, "echo workflow-lint root-guard selftest")  # must be 0
    except (subprocess.TimeoutExpired, OSError) as exc:
        return [f"{hook}: root-guard self-test crashed ({exc}) — check cannot run"]
    if rc_pos != 2 or rc_neg != 0:
        return [f"{hook}: root-guard self-test failed (blocked-probe rc={rc_pos}, "
                f"expected 2; benign-probe rc={rc_neg}, expected 0). Likely jq missing "
                f"(the hook's stdin parse fail-softs to exit 0) or a hook regression — "
                f"the check refuses to run against a fail-open hook."]
    # (2) Enumerate targets: agents+skills via the worktree-safe house helper,
    #     plus rules/*.md + CLAUDE.md with the same other-worktree exclusion.
    targets = list(_iter_ask_target_files(root))
    prefix = _other_worktree_prefix(root)
    rules_dir = root / ".claude" / "rules"
    if rules_dir.is_dir():
        targets += [p for p in sorted(rules_dir.glob("*.md"))
                    if p.is_file() and not _is_other_worktree_path(p, prefix)]
    claude_md = root / "CLAUDE.md"
    if claude_md.is_file() and not _is_other_worktree_path(claude_md, prefix):
        targets.append(claude_md)
    # (3) Collect git-bearing bash fences (perf gate: 'git' literal is a NECESSARY
    #     condition for every hook detector — #1162 style; drops 103→23 on
    #     issue/SKILL.md alone). Exemption: sentinel with NON-EMPTY reason on the
    #     immediately-preceding non-blank line (reason-stripping mirrors _line_waived
    #     FI2: strip trailing '-->', backticks, whitespace).
    work: list[tuple[Path, int, str]] = []
    for p in targets:
        try:
            text = p.read_text(encoding="utf-8")
        except (OSError, UnicodeDecodeError):
            continue
        for lineno, prev_line, block in _iter_bash_fences(text):
            if "git" not in block:
                continue
            if _root_guard_fence_exempt(prev_line):
                continue
            work.append((p, lineno, block))
    # (4) Execute the hook per block, in parallel; deterministic ordering.
    errors: list[str] = []
    def _probe(item):
        p, lineno, block = item
        try:
            rc, stderr = _run_root_guard(hook, block)
        except (subprocess.TimeoutExpired, OSError) as exc:
            return (p, lineno, -1, f"hook invocation failed: {exc}")
        return (p, lineno, rc, stderr)
    with ThreadPoolExecutor(max_workers=max_workers) as ex:
        results = list(ex.map(_probe, work))
    for p, lineno, rc, stderr in sorted(results, key=lambda r: (str(r[0]), r[1])):
        if rc == 0:
            continue
        first = stderr.strip().split("\n")[0][:200]
        if rc == 2:
            errors.append(
                f"{p}:{lineno}: bash recipe fence is BLOCKED by "
                f"scripts/guard_repo_root_branch.sh — a session pasting this recipe "
                f"into one Bash call dies at the PreToolUse gate (incident #1047: a "
                f"cleanup recipe without a -C waiver survived plan review + 6 critics "
                f"and was caught only by the reviewer executing the hook). Hook says: "
                f"{first!r}. Fix the recipe (per-clause `git -C <path>` waiver / the "
                f"sanctioned worktree or gh-pr-merge form), or — for a deliberate "
                f"anti-pattern example or a pod-side recipe — add "
                f"`<!-- {_ROOT_GUARD_EXEMPT_SENTINEL}: <reason> -->` on the line "
                f"directly above the fence opener."
            )
        else:  # unexpected rc (127, timeout, non-blocking non-zero): fail loud
            errors.append(f"{p}:{lineno}: root-guard hook returned unexpected "
                          f"rc={rc} ({first!r}) — check infrastructure error, not a pass")
    return errors
```

`_SELFTEST_BLOCKED_PROBE` is a module constant assembled to read clearly while never being pasted into a shell: `"git checkout -b __workflow_lint_root_guard_selftest__"` (verified rc=2 live). It lives only as Python string data — the hook gates Bash tool calls, not file contents, and neither sibling doc-scanning check scans `scripts/**` (verified: their scope is agents+skills md only).

**Feed granularity — whole fenced block as ONE command string (design Q1, decided).** Faithful to how a session pastes a recipe (one Bash call; the hook clause-splits internally); per-line feeding would shred `if`/`for`/heredoc constructs and false-positive on inert heredoc bodies the hook's #1058 strip correctly ignores. Live-verified: a blocked command on line 3 of a 4-line block → rc 2; a `for` loop with `git -C` → rc 0; comment-only gated-verb line → rc 0; `-C`-waived multi-line → rc 0. Whole-block is not weaker on waivers either (the hook's `-C` waiver is per-clause, so a waiver on clause 1 never masks clause 5).

**Non-executable line filtering (design Q4):** delegated entirely to the hook's own parser (comment-tail strip, heredoc strip, clause splitting) — that delegation is the point of executing it, and it was verified against real SKILL.md blocks and synthetic probes during planning (see §6 baseline).

**Why code, not a model call:** deterministic policy gate on structured text executed at pre-commit/pre-push cadence — a model call would be slower, non-deterministic, and cannot execute the hook. Contrastive negatives / data realism / completion provenance / persona-vectors / marker recipes: `N/A` — no training, no data generation, no model calls (`kind: infra`).
