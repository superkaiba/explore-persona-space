## 3. Design — chosen: (a) Store/Del-ctx exemption + (c)'s documentation half

**Decision: design (a), plus the doc half of (c) folded into the same edit.** Exempt `ast.Store` / `ast.Del` context nodes in BOTH legs of `_hub_verify_bare_hits`; keep every Load-ctx node flagged (calls, wrapper arguments, the monkeypatch save); document the save's waiver requirement in the docstring and the user-facing error message. Design (b) rejected — full weighing in §11.

The soundness argument, stated once: **a Store/Del-ctx node is a binding/deletion TARGET — it never evaluates to a value, so it can neither be a call nor a callable reference; the assigned VALUE is a separate AST node with its own (Load) ctx and is scanned independently.** Probe-verified (§9, assumption 1): assignment targets, AugAssign targets, and `for`-loop targets all read `ctx=Store`; `del` targets read `ctx=Del`; the save RHS, call `func`, and wrapper-argument positions all read `ctx=Load`. Zero evasion surface is opened: the alias-later-called evasion (`orig = HfApi.list_repo_tree` … `orig(...)`) is caught at the SAVE line, which stays flagged (Load ctx) and takes the waiver — exactly the deliberate coverage the docstring already claims.

### 3.1 `_hub_verify_bare_hits` (scripts/workflow_lint.py:7335-7366)

Diff sketch for the hit loop (:7361-7365):

```python
    for node in ast.walk(tree):
        if isinstance(node, ast.Attribute) and node.attr in HUB_VERIFY_BARE_TARGETS:
            if isinstance(node.ctx, (ast.Store, ast.Del)):
                # Assignment/deletion TARGETS — monkeypatch save/RESTORE
                # assignments in self-test code (`HfApi.list_repo_tree = fake`,
                # `del api.file_exists`) — can never be calls and never
                # evaluate to a callable reference: the assigned VALUE is a
                # separate node with its own Load ctx, scanned independently.
                # The Load-ctx SAVE (`orig = HfApi.list_repo_tree`) stays
                # flagged deliberately — a bare alias later called still
                # storms — and takes the waiver (#1482/#1561).
                continue
            hits.append((node.lineno, f".{node.attr}("))
        elif isinstance(node, ast.Name) and node.id in hf_bound:
            if isinstance(node.ctx, (ast.Store, ast.Del)):
                # Rebinding/deleting the imported name is not a call; a
                # wrap-rebind (`lrf = retry(lrf)`) still hits via its RHS
                # Load usage on the same line.
                continue
            hits.append((node.lineno, f"{hf_bound[node.id]}("))
    return hits
```

The ctx gate applies to BOTH legs — one uniform predicate ("a binding target is never a call"), not an Attribute-leg special case. Name-leg consequence, verified by construction: `list_repo_files = retry_transient(list_repo_files)` still produces exactly one hit on that line (the RHS Load usage; the Store target is skipped, dedup would have collapsed them to one line anyway); a pure rebind `list_repo_files = None` — currently flagged — stops being flagged (it cannot storm; later Load-ctx calls of the name still hit, because the leg keys on the static import map, not dataflow). No new imports needed (`ast` already imported at module top).

## 11. Decision Rationale

- **What:** design (a) — exempt `ast.Store`/`ast.Del` ctx nodes in both legs of `_hub_verify_bare_hits` — plus design (c)'s documentation half (docstring + error message name the monkeypatch-save waiver requirement).
- **Why:** a binding/deletion target never evaluates to a value, so it can neither be a call nor a callable reference — the exemption is sound *by AST construction* with ZERO new evasion surface, and it removes exactly the provably-noise class (3 of #1482's 4 waivers). The one remaining waiver (the Load-ctx save) is the check working as designed: that line genuinely binds a callable alias, which is the "bare alias later called still storms" class the Attribute leg deliberately covers — forcing the author to assert "attribute reference only, no network call" once per monkeypatch block is proportionate friction, and the new error-message clause makes that requirement discoverable at the point of failure instead of via offline predicate reproduction (the #1482 pain).
- **Source (repo evidence):** `scripts/workflow_lint.py:7362-7365` (the ctx-blind legs), `:7385-7401` (the deliberate-coverage docstring the fix must not weaken), `scripts/issue779_ffc_n50k_generate_capture.py:618-635` (the incident's 1 Load + 3 Store shapes), `tests/test_workflow_lint.py:4699-4715` (the asname-aware alias coverage that must survive), plan-time AST ctx probe (§9 assumption 1), plan-time grep showing zero ctx precedent in the file (§2).
- **Alternatives rejected:**
  - **(b) Store/Del exemption + save/restore-pair Load-ctx exemption** — kills the 4th waiver, but at the cost of this file's FIRST module-wide name-usage dataflow (no `.ctx`, let alone binding analysis, exists anywhere in workflow_lint.py — §2), with real edge cases: the naive "bound name never in Call position" form is evadable by an alias chain (`orig2 = orig; orig2(...)` — a non-Call use that launders the callable), so a sound (b) needs the stricter whitelist "every Load usage of the bound name is the VALUE of a restore-Store", plus name-collision-across-functions semantics (fail-closed, but now the exemption's behavior depends on unrelated code elsewhere in the module). ~25 lines of subtle analysis to save ONE ten-plus-char waiver comment per self-test block. Complexity and evasion-audit burden disproportionate; the save line's waiver is defensible on the merits (it binds a real callable).
  - **(c) doc-only** — leaves 3 mechanically-provably-safe waivers required per monkeypatch block, i.e. keeps diluting the waiver channel the Goal names as the harm; the docstring half is kept, the do-nothing detector half is not.
  - **Only-flag-`ast.Call`** — banned by the task brief and by the docstring's deliberate design: it opens the bare-alias / wrapper-argument evasion (`retry_transient(api.list_repo_files)`, `asyncio.to_thread(api.file_exists, ...)`) that the Attribute leg exists to catch; test 5 pins this permanently.
- **Scope class:** non-architectural (no rename, no flag change, no public-contract change) — no `architectural: true`; workflow-surface only.
