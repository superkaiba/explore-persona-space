### Literature

The contrastive-suppression loss formulation here is the on-policy analogue of the standard SFT-with-negatives recipe used in:

- **Anthropic Persona Vectors** (Chen, Arditi, Sleight, Evans, Lindsey, arXiv 2507.21509): persona implants trained with contrastive prompts; loss masked to the response/marker slot.
- **OpenAI Persona Features Control EM** (Wang, ..., Mossing, arXiv 2506.19823): contrastive SFT pairs; persona-conditioned response carries gradient and competing-persona response carries zero or counter-gradient.
- **Activation patching / steering vector literature** (Turner et al. 2023; Panickssery et al. 2024) — the same contrastive-completion structure under different framing.
- **arXiv 2504.10637** (Rao-Blackwellized per-slot KL estimator) — building block for the route-b KL secondary measure (drift, NOT marker transfer).

None run the exact 240-pair divergence-predicts-transfer correlation, so the present design is methodologically novel; the hyperparameter recipe comes from the spiritual siblings + #406 / #460 / #462.

## 3. Hypothesis

**H1 (confirms localization-confound reading):** Under the localized arm (A_loc) at the lightest checkpoint whose diagonal implant fraction is above 0.80 AND whose off-diagonal saturation fraction is below 0.95, length-partial Spearman ρ(D, ΔG) is negative with a 95% cluster-bootstrap CI excluding zero — AND the negative sign SURVIVES the stylized-persona mask (c) (exclude A3/A4/A5 as either source or target, n=156) AND SURVIVES the off-ceiling-subset restriction AND SURVIVES partialling out per-cell suppression difficulty. Magnitude comparable to #406 (−0.44) or #462-ep1 (−0.27). The 1-epoch A_loc checkpoint is the most likely candidate.

**H2 (refutes it):** Either (a) NO A_loc checkpoint clears the saturation precondition (off-diag saturation ≥ 0.95 OR diagonal implant ≤ 0.80) — the ΔG primary is REFUTING (uninterpretable, recorded as such); OR (b) some A_loc checkpoint clears the precondition but ρ(D, ΔG) stays null (CI includes zero) OR fails to survive any of the M3/M4/M5 robustness checks. Either branch rules out localization as the cause of the #460 null and identifies the saturation as intrinsic to the on-policy marker-at-end construct OR identifies the apparent ρ as a stylized-persona artifact / suppression-difficulty confound.

**H3 (single-variable cross-arm read).** **Matched-epoch and matched-step BOTH reported.** Holding checkpoint fixed: A_loc's saturation fraction is significantly lower than A_pos's (paired bootstrap over 240 cells), AND |ρ(D, ΔG)| is significantly larger under A_loc than A_pos (paired bootstrap difference in length-partial Spearman). **Matched-step caveat:** A_loc has 600 rows/epoch vs A_pos 300, so A_loc ep1 ≈ A_pos ep2 in optimizer-step count. The analyzer reports A_loc ep1 vs A_pos ep2 (matched-step) ALONGSIDE matched-epoch; H3 as "pure localization" requires the trajectory to rule out "more total training" as the driver.

**H4 (route-b cross-check — DRIFT, not transfer).** At every checkpoint of both arms, the KL-from-base secondary measure — length-partial Spearman ρ(D, KL(trained ‖ base) @ post-response slot) — has dynamic range across all 240 cells, and **its sign is negative (matches the predicted direction)**. **KL is full-vocab distributional drift at the post-response slot, NOT marker transfer.** H4 is a descriptive cross-check: agreement in sign supports the geometry-predicts-drift story; disagreement in sign or magnitude is reported as such. KL is NEVER narrated as marker-transfer evidence.

```python
                    # region (the post-response slot — same label slot the
                    # marker occupies on positives, same conditioning context,
                    # same slot the DV reads). Train "after R_j under
                    # bystander T_j, emit <|im_end|>" → under softmax this
                    # pushes log P(※ | T_j(q) + R_j) DOWN at the measured slot.
                    # Fail-loud if no <|im_end|> in completion.
                    found = False
                    for idx_t in valid_indices:
                        idx = int(idx_t.item())
                        if input_ids[idx].item() == self.im_end_token_id:
                            keep_mask[idx] = True
                            found = True
                            break
                    if not found:
                        raise RuntimeError(
                            f"suppress_at_post_response_slot=True but no "
                            f"<|im_end|> (id={self.im_end_token_id}) found in "
                            f"completion region of negative row. Token ids in "
                            f"completion: {[int(input_ids[i].item()) for i in valid_indices[:10]]}..."
                        )
                else:
                    # PREVIOUS BEHAVIOR — kept for all existing callers
                    # (run_issue295_marker_only_loss.py,
                    # run_em_first_marker_transfer_confab.py, etc.) that
                    # intentionally train the trailing token on negatives.
                    keep_mask[valid_indices[-1]] = True

            labels[i] = torch.where(keep_mask, row, torch.tensor(-100, device=row.device))
        elif len(valid_indices) > self.tail_tokens:
            ...  # unchanged
```

```python
# scripts/i474_phase23_train.py — additions

import torch.nn.functional as F

class NegRowSuppressionDifficultyCallback(TrainerCallback):
    """At each checkpoint epoch end, compute mean negative-row training loss
    per (source_i, bystander_j) and write to disk + WandB. This is M5's
    identifiability covariate — the analyzer partials it out of the headline
    ρ(D, ΔG) to test whether D's predictive power is "D predicts transfer"
    or "D predicts how hard the negative-row suppression was at this slot."

    Zero extra compute beyond a forward pass on the 300 negative rows
    (already in the dataloader), grouped by tag and written per checkpoint.
    """
    def __init__(self, model, tokenizer, neg_rows, im_end_id, arm, cid, out_dir):
        self.model = model
        self.tokenizer = tokenizer
        self.neg_rows = neg_rows          # list of (input_ids, source_i, bystander_j) tuples
        self.im_end_id = im_end_id
        self.arm = arm
        self.cid = cid
        self.out_dir = Path(out_dir)
        self.out_dir.mkdir(parents=True, exist_ok=True)

    def on_save(self, args, state, control, **kwargs):
        if self.arm != "loc":
            return                          # A_pos has no negative rows; skip
        per_pair: dict[tuple[str, str], list[float]] = {}
        self.model.eval()
        with torch.no_grad():
            for row in self.neg_rows:
                ids = row["input_ids"].to(self.model.device).unsqueeze(0)   # [1, L]
                # Find the first <|im_end|> in the completion region; teacher-force
                # its log P at that slot conditioned on all preceding tokens.
                im_end_positions = (ids[0] == self.im_end_id).nonzero(as_tuple=True)[0]
                if len(im_end_positions) == 0:
                    continue
                slot = int(im_end_positions[0].item())            # first <|im_end|> in row
                out = self.model(input_ids=ids[:, :slot+1])       # logits at every position
                # Loss at slot: −log P(<|im_end|> | ids[:slot])
                logp = F.log_softmax(out.logits[0, slot-1], dim=-1)
                loss_at_slot = -float(logp[self.im_end_id].item())
                key = (row["_neg_source_i"], row["_neg_bystander_j"])
                per_pair.setdefault(key, []).append(loss_at_slot)
        # Aggregate
        agg = {f"{i}__{j}": float(np.mean(losses)) for (i, j), losses in per_pair.items()}
        out_path = self.out_dir / f"suppression_difficulty_{self.arm}_{self.cid}_ep{state.epoch:g}.json"
        out_path.write_text(json.dumps({
            "arm": self.arm, "source_i": self.cid, "epoch": state.epoch,
            "per_bystander_mean_neg_loss": agg,
        }, indent=2))
        # Also push to WandB as a metric per (i,j) pair
        if "wandb" in args.report_to:
            import wandb
            wandb.log({f"neg_loss/{self.cid}__{j_id}": loss
                       for (i_id, j_id), loss in
                       (((k.split("__")[0], k.split("__")[1]), v) for k, v in agg.items())},
                      step=int(state.global_step))
        self.model.train()
```

### 4.8 Why code, not a model call?

All §4 components — the negative-row builder, the cross-eval driver, the KL computation, the suppression-difficulty hook, and the analysis — operate on token-level structured data (logprobs, tokenizer IDs, integer indices). The model-call alternative would be a Claude call to score "did the model emit the marker after this response?" — which is what #432 tried OFF-policy and #456 had to re-run ON-policy because the off-policy proxy diverged arbitrarily from the construct. The DV is the trained − base log-prob, a single fp32 value per cell read directly from the forward-pass logits. Code is the correct path.

### 4.9 Contrastive negatives for behavior implantation (REQUIRED check)

This experiment **IS the contrastive-negatives manipulation**. A_loc carries the contrastive negatives by design (`Source: contrastive-negatives.md`). A_pos is the deliberate "non-contrastive arm" that the rule's exemption-(a) permits, because A_pos's purpose is to reproduce #460 inside the same run as the localization manipulation's single-variable control. Composition: 15 bystander personas at 20 questions each, 1:1 positives:total-negatives, no-marker rows whose loss-bearing token is the post-response `<|im_end|>` at `neg_ids[-2]` (`Source: contrastive-negatives.md` "Marker implant" paragraph; `Source: #406` for the total + 1:1 ratio; the per-bystander even split is a NEW design choice for this experiment).

**Saturation hedge — single-variable preserved, but does NOT relabel the construct.** Per `contrastive-negatives.md` Caveats §"Saturation hides everything," route-b (full-vocab KL @ post-response slot, on-policy) is the canonical non-saturating measure at a saturated anchor. KL is reported as a SECONDARY drift cross-check at every checkpoint and is NEVER narrated as marker transfer. The PRIMARY DV remains ΔG because (a) the user asked for it, (b) the across-epoch sweep is itself the saturation hedge, and (c) ΔG is the parent DV (#460), preserving paired cross-experiment comparability. **If NO A_loc checkpoint clears the saturation precondition, ΔG is reported as REFUTING localization-recovered marker transfer (H2 outcome) — KL ρ does NOT rescue this read.**

- Full-vocab KL(trained ‖ base) at post-response slot, on-policy. **What:** route-b non-saturating descriptive cross-check. **Why:** `Source: .claude/agent-memory/planner/feedback_route_b_kl_dv_swap.md` — when adding contrastive negatives to a saturated parent, route-b KL is the canonical non-saturating measure. **CRITICAL framing change vs v2:** KL measures full-vocab distributional drift at the post-response slot, NOT marker transfer. KL is NEVER a "headline rescue" if ΔG ceilings — if ΔG is uninterpretable, the experiment reports H2 (refuting localization-recovered marker transfer) and KL is reported as descriptive drift evidence only. **Source: arXiv 2504.10637** (Rao-Blackwellized per-slot KL estimator). **Alternatives rejected:** JS divergence (asymmetric in the wrong direction); top-K-truncated KL (loses tail mass; only the fallback when vLLM rejects full vocab).

**NEW — M5 identifiability covariate:**

- Per-(source i, bystander j, checkpoint) mean negative-row training loss, logged via `NegRowSuppressionDifficultyCallback` at each checkpoint epoch end. **What:** a diagnostic logged from the same forward pass that gradient descent already used; partialled out of the headline ρ in Phase 5. **Why:** without it, a recovered negative ρ(D, ΔG) is unidentified between "D predicts marker transfer" and "D predicts how hard the negative-row suppression was at the loss slot." The partial ρ(D, ΔG | S) is the load-bearing identifiability check for the whole headline. **Source:** standard partial-correlation methodology + the consistency-checker's observation that without it the headline mechanism is ambiguous. **Alternatives rejected:** dropping the M5 covariate (would leave the headline unidentifiable); using something other than mean negative-row training loss (the per-example loss at the loss slot is the most direct measure of "suppression difficulty at the slot where the suppression happened").
