### 4.1 `scripts/session_progress_report.py` (~+22 lines, function `write_self_report` only)

Replace lines 250-256 (`task = _load_task(issue)` through the `suffix = ...` line) with:

```python
    try:
        task: dict | None = _load_task(issue)
    except RuntimeError as exc:
        # TRANSIENT resolver/environment failure — e.g. the repo-root branch
        # guard's detached-HEAD raise (task_workflow._resolve_repo_root_cached)
        # while a concurrent session's rebase window holds the shared checkout
        # (#999; crash observed in the #906 session, 2026-07-03). The
        # title/self-report path is OBSERVABILITY ONLY (SKILL.md § set_title),
        # so degrade instead of crashing: keep the caller-supplied slug (else
        # empty), skip the ETA suffix (status unknown), and STILL write the
        # self-report — its `ts` is an activity signal for the stalled
        # detector, and this tick IS activity. Unknown-issue typos still
        # fail loud: FileNotFoundError (incl. StaleTaskPathError) is an
        # OSError, not a RuntimeError, and is deliberately not caught here.
        print(
            f"session_progress_report: task lookup degraded ({exc})",
            file=sys.stderr,
        )
        task = None
    if task is None:
        status: str | None = None
        if slug is None:
            slug = ""
    else:
        fm = task.get("frontmatter")
        fm = fm if isinstance(fm, dict) else {}
        if slug is None:
            title = fm.get("title")
            slug = title.strip() if isinstance(title, str) else ""
        status = task.get("status")
    suffix = _compute_eta_suffix(issue, status, now_iso) if eta else None
```

Everything below (`text = build_progress_string(...)` through `return text, path`) is unchanged. Healthy-path output is byte-identical (the `fm`/slug/status logic is the same code, hoisted).

### 4.2 `tests/test_session_progress_report.py` (~+55 lines, 3 new tests)

Placed after `test_write_self_report_unknown_issue_raises_even_with_explicit_slug` (line ~527), using the file's existing seam (monkeypatch `tw.get_task` — the real external boundary; `write_self_report`'s and `_load_task`'s real bodies execute, satisfying the #906 one-production-body-test rule; the fake is signature-conformant: `def _detached(issue): raise ...`).

```python
_DETACHED_MSG = (
    "main worktree HEAD (/home/x/explore-persona-space) is detached; "
    "re-attach to 'main' before running task.py."
)


def _mock_get_task_detached(monkeypatch):
    import explore_persona_space.task_workflow as tw

    def _detached(issue):
        raise RuntimeError(_DETACHED_MSG)

    monkeypatch.setattr(tw, "get_task", _detached)


def test_write_self_report_degrades_on_transient_resolver_error(
    monkeypatch, tmp_path, capsys
):
    """#999 regression: a resolver/environment RuntimeError (detached
    shared-checkout HEAD mid-rebase) must DEGRADE, not crash — the
    title/self-report path is observability-only. Degraded shape: empty
    slug (none supplied), no ETA suffix, self-report STILL written (its
    ts is an activity signal), one stderr line."""
    monkeypatch.setattr(session_progress_report, "SELF_REPORT_DIR", tmp_path)
    _mock_get_task_detached(monkeypatch)

    text, path = session_progress_report.write_self_report(42, step="running")

    assert text == "#42 · running"          # empty slug, no suffix
    assert path == tmp_path / "42.json"
    assert path.is_file()
    assert not list(tmp_path.glob("*.tmp"))  # still atomic
    payload = json.loads(path.read_text())
    assert payload["issue"] == 42
    assert payload["slug"] == ""
    assert payload["text"] == text
    assert payload["ts"].endswith("Z")
    assert "degraded" in capsys.readouterr().err


def test_write_self_report_degraded_keeps_explicit_slug(monkeypatch, tmp_path):
    monkeypatch.setattr(session_progress_report, "SELF_REPORT_DIR", tmp_path)
    _mock_get_task_detached(monkeypatch)

    text, path = session_progress_report.write_self_report(
        42, slug="hand slug", step="running"
    )
    assert text == "#42 hand slug · running"
    assert json.loads(path.read_text())["slug"] == "hand slug"


def test_main_returns_zero_on_transient_resolver_error(
    monkeypatch, tmp_path, capsys
):
    """The actual crash surface: bare CLI callers (skill Bash steps, the
    watcher's subprocess refresh) must get rc=0 + the degraded string on
    stdout during a transient resolver failure."""
    monkeypatch.setattr(session_progress_report, "SELF_REPORT_DIR", tmp_path)
    _mock_get_task_detached(monkeypatch)

    rc = session_progress_report.main(["--issue", "42", "--step", "x"])
    assert rc == 0
    out = capsys.readouterr()
    assert out.out.strip() == "#42 · x"
    assert "degraded" in out.err
```

## 11. Decision Rationale

**Design choice: (A) — catch `RuntimeError` (and only `RuntimeError`) around `_load_task` inside `write_self_report`, degrade slug/status, still write the self-report.**

- **What:** library-level `except RuntimeError` on the single `_load_task` call; degraded values `slug = caller-supplied or ""`, `status = None` (⇒ no ETA suffix); self-report file still written; one stderr line; normal return; `main()` untouched.
- **Why:**
  1. The observability-only contract belongs to the whole helper, not just the CLI — SKILL.md § set_title states the title/self-report path "never crashes the /issue pipeline", and the in-file precedent (`_compute_eta_suffix`, line 214: "fail-soft: suffix is decoration, never a crash") already draws the line at exactly this layer. The fix extends the established pattern one call up.
  2. Writing the self-report on the degraded path is load-bearing for freshness semantics: the file's `ts` is an ACTIVITY signal read by the stalled detector and the reconcile pass (`autonomous_session_watch.py:16652-16661`); the session issuing the tick IS active, so refreshing `ts` is truthful — while NOT writing would let the self-report go stale during a rebase window and could help corroborate a FALSE stall. The degraded string `#N · step` shown by the summarizer for ≤20 min is truthful (issue + step are real; only the slug is missing, and only when `--slug` was omitted).
  3. Catching only `RuntimeError` is exactly the resolver/environment failure class: every environment raise in `_resolve_primary_checkout` / `_resolve_repo_root_cached` / `_git_quiet` / `_ensure_managed_main_worktree` is a `RuntimeError` (verified — Assumption 1), while unknown-issue is `FileNotFoundError` (an `OSError`; disjoint by the exception hierarchy), so the fail-loud contract is preserved by construction, not by ordering.
- **Source:** root-cause traceback + failure-class from the #999 clarifier marker (recovered from the #906 session transcript, 2026-07-03); contract text from `.claude/skills/issue/SKILL.md` § set_title (lines 426-451); freshness/activity semantics from `autonomous_session_watch.py` lines 16650-16687; in-file fail-soft precedent from #587 (plan v2 §3.6, `_compute_eta_suffix`).
- **Alternatives rejected:**
  - **(B) bounded retry (1-2 short sleeps) before degrading.** Rejected: the detached window is NOT reliably seconds-long — a stranded detached HEAD persists indefinitely, so every title tick during the bad state would pay the full sleep budget (latency injected into every `/issue` step transition and the watcher's 30 s-timeout subprocess); the marginal win (recovering the real slug for ONE tick) is small because the next tick (≤10-45 min) self-heals for free (`lru_cache` does not cache exceptions), and explicit-`--slug` callers lose nothing even without retry. Retry also adds time-dependence to tests. Simplicity wins on an observability path.
  - **(C) catch in `main()` only, library stays fail-loud.** Rejected: (i) it either drops the self-report write on the degraded path (harming the activity-signal semantics above) or duplicates the payload-assembly + atomic-write logic inside `main()`; (ii) there is no production library caller besides `main()` to protect with library fail-loud-ness (Assumption 3), so C's benefit is theoretical while its cost (duplicated write logic or lost write) is real; (iii) tests would pin the CLI shape but leave the library helper crashy for any future importer, re-opening this bug class.
  - **Hybrid (A + one retry):** rejected for the same latency/complexity reasons as (B); can be added later as a follow-up if degraded ticks turn out to be frequent (they are observable via the stderr line).
