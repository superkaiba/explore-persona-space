## 3. Hypothesis (copied from task body — already precise)

The headline contrast is genuine geometry, not an artifact:

- **(a)** dropping the source column leaves both arms' top-share above the nulls,
- **(b)** reading the EM shift as a mean over all response tokens (instead of the end slot) preserves EM > marker concentration, and
- **(c)** the low-cosine marker personas do NOT have systematically smaller shift norms (which would mean their cosines were attenuated by estimation noise rather than pointing elsewhere).

**Falsification:** any of — leave-one-out drops a cell's top-share below its null (source-dominated spectrum); the mean-over-response read reverses or erases the EM-vs-marker ordering; marker per-persona ‖shift‖ strongly predicts cosine-to-top-direction (low-cos = low-norm), which would reclassify much of the "marker split" as high- vs low-SNR contexts.

### Step 2 — small diff to `activation_shift.py` (the persistence/capture extension)

The parent code computes `delta_v` as the mean over 20 questions and **discards** per-question shifts; it also runs a *second* forward pass for the EM mean-over-response read even though `output_hidden_states=True` already materializes every layer. The diff (one file, ~60 lines):

- **Unified single-forward read.** Replace the `_read_residual_at_slot` / `_read_residual_mean_over_response` pair with one helper that, per model per teacher-forced sequence, returns from ONE forward: per-layer slot reads AND per-layer mean-over-response reads.

  ```python
  @torch.no_grad()
  def _read_residuals(model, full_ids, layers, response_start):
      out = model(full_ids.unsqueeze(0).to(model.device), output_hidden_states=True)
      reads = {}
      for L in layers:
          h = out.hidden_states[L + 1]          # (1, T, H)
          reads[L] = {
              "slot": h[0, -1].detach().float().cpu(),
              "mean_resp": h[0, response_start:].mean(dim=0).detach().float().cpu(),
          }
      return reads
  ```

  Identical math to the parent (same sequence, deterministic eval-mode forward); it strictly *removes* the duplicated EM forward.
- **`--layers 7 14 21`** CLI flag (nargs+, default `[14]` = parent behavior). `delta_v` keeps its meaning (layer-14 slot mean) so `assemble_M` and all Phase-D-style code work unmodified; extra layers land as new keys `delta_v_l7`, `delta_v_l21` (+ `delta_v_mean_resp_l{7,21}`). **Stored only — layer 7/21 analysis is explicitly out of scope** (free-analysis follow-up per the task body).
- **Mean-over-response for BOTH arms** on the `same` variant (parent: EM-only). With the unified forward this costs zero extra passes; it gives control (b) the symmetric marker reference for free. `base`/`on_policy` variants stay slot-only as in the parent.
- **Per-question tensors persisted** at layer 14: `delta_v_per_q` (`n_kept × 3584` float32) per persona, and `delta_v_mean_resp_per_q` on `same`-variant cells — this is what "persist the tensors" means in a form that supports any future re-analysis (and the split-half reliability supplementary in §6). ~4 MB per cell per stored tensor block; total upload ≈ 110-150 MB.
- Manifest gains `layers`, `schema_version: 2`, `issue: 551`. The marker-token assert (`encode(" ※") == [83399]`) is already in `main()` — kept.

### Success thresholds (pre-registered — revised per critic round 1: sign-flip binding, symmetric (b), one-sided (c), per-persona repro anchoring)

- **Reproduction gate (binding, precedes everything).** Per cell, vs the parent JSONs (which carry per-persona `cos_to_U1`, the `U1` vector, and `singular_values`):
  - BINDING (all 18 cells): \|Δ `s_top1_frac`\| ≤ 0.05 AND \|Δ `mean_cos_to_U1`\| ≤ 0.05 AND top-direction agreement \|cos(U₁_re, U₁_parent)\| ≥ 0.95 AND per-persona profile agreement Spearman(cos_to_U1_re, cos_to_U1_parent) ≥ 0.8 over the 14 personas. The last two anchor the per-persona structure the controls consume — the two scalars alone are invariant to identity reshuffles of the bimodal marker profile (0.32–0.49 vs 0.86–0.97), which would make controls A/C about a different split than the parent headline's (critic round 1, alternatives reconcile). Thresholds 0.95 / 0.8 are `ungrounded — reasoned bounds` (0.8 preserves bimodal group identity; 0.95 is far above the ~0.3 cosine two random splits of a bimodal profile would give); a breach is halt-and-investigate, never a finding.
  - DESCRIPTIVE (reported, not gating): per-persona \|Δ cos_to_U1\| (all 14), top-3 singular-value-share deltas, and Δ of the parent's `shift_norm_vs_cosine` summary where present.
- **(a) Source-dropped spectrum PASSes** if, for all 6 `same`-variant cells, LOO `s_top1_frac` > the **sign-flip null p95** computed on the LOO matrix (BINDING null). The row-shuffle null is reported DESCRIPTIVELY (p95 + p99) as sensitivity only — the parent documented it as inflated for near-parallel EM columns (same-EM full-matrix margins over row-shuffle p95 are 0.028–0.032, BELOW the ±0.05 reproduction drift the gate allows, so a row-shuffle miss is a null artifact, not source dominance; critic round 1, statistics reconcile). A row-shuffle near-miss is narrated as inconclusive-on-that-null, never a kill. Reported for `base`/`on_policy` cells as robustness.
- **(b) Whole-response read PASSes** on the SYMMETRIC comparison (PRIMARY): min-over-EM-seeds mean cos-to-U₁ (mean-resp) > max-over-marker-seeds mean cos-to-U₁ (**mean-resp**, same variant), AND all 3 EM mean-resp cells clear their own **sign-flip** null p95 (row-shuffle descriptive, as in (a)). The EM-mean-resp vs marker-END-SLOT comparison is retained as the parent-reference secondary read only — it crosses read types with different SNR and cannot bind (critic round 1). Parent reference points: EM end-slot mean cos ≥ 0.9625; marker end-slot max 0.7134.
- **(c) Norm-vs-alignment.** PRIMARY diagnostic: marker-arm one-sided (positive — the direction the attenuation alternative predicts) Monte Carlo permutation p on Spearman ρ(‖Δv‖, cos-to-U₁), 10,000 draws, per seed; plus the split-half reliability supplementary. The registered "strong" label stays ρ ≥ 0.54 (two-sided α=0.05 table value at n=14, kept as a descriptor). Sub-threshold ρ alone is NEVER narrated as "noise ruled out" — that claim additionally requires split-half reliability showing the low-cos personas are NOT systematically low-reliability; wording capped at "no strong correlation detectable at n=14". Sign-inconsistency across seeds = inconclusive (each seed is underpowered), not a pass. EM arm reported for symmetry.

One gate, grounded and jointly satisfiable. The run is short (<2 h wall) so no further gating ladder.

- **Smoke reproduction gate (after cell 1, before the other 17):** the smoke cell (marker seed42, `same` variant) must satisfy all four BINDING reproduction clauses vs `same_marker_seed42.json` (`|Δ s_top1_frac| ≤ 0.05` vs 0.32465, `|Δ mean_cos_to_U1| ≤ 0.05` vs 0.58711, `|cos(U₁_re, U₁_parent)| ≥ 0.95`, per-persona profile Spearman ≥ 0.8) AND carry the v2 schema keys. Cheap intermediate signal that rules out the full run's two failure classes (wrong adapter wiring, code-restore drift) for ~15 min of GPU. Threshold sign + magnitude grounded in the parent's own values; the gate demands the same numbers the parent produced, so any past run trivially passes it.

### Kill criteria — each control failing is itself the finding

- **LOO failure** (a cell's LOO top-share falls below its **sign-flip** null p95 — the binding null; a row-shuffle-only miss is inconclusive, not a kill): that arm's spectrum is source-dominated; the "every context inherits the direction" claim demotes to "the source's own shift sets the direction" — the parent headline's denominator changes, and the contrastive-EM rig-disentangle follow-up (#552 sibling line) should be re-scoped before launch.
- **Whole-response reversal/erasure** (on the SYMMETRIC read: EM mean-resp mean cos falls below the marker mean-resp reference, or below its own sign-flip null): the end-slot read misrepresented EM, the headline needs reframing before any rig-disentangle is worth running.
- **Strong norm→cosine correlation** (one-sided positive permutation p < 0.05 with consistent positive sign in ≥2/3 marker seeds, corroborated by split-half reliability showing low-cos personas are low-reliability): much of the "marker split" reclassifies as high- vs low-SNR contexts; redirects the non-saturated-anchor follow-up (#521 Next steps item 3) to target SNR, not geometry. (ρ ≥ 0.54 stays the registered "strong" descriptor.)
- **Reproduction-gate breach** (any binding clause: scalars, U₁ agreement, or per-persona profile Spearman) is NOT a finding — it is a halt-and-investigate condition (the controls would not be about the parent's tensors; results would otherwise be narrated as a fresh re-run, not a completion of #521's lost controls).
