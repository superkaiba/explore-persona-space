## Method delta

Nothing novel — this applies the two checks' own documented compliant routes
(`workflow_lint.py` check docstrings; `orchestrate/hub.py` canonical call
shape at ~L1694):

- `check_live_hf_retry_routing` sites (#1, #3): wrap in
  `hub.retry_transient(lambda: <call>, what="<label>")` — the wrap opening
  within the 3-line window above the call, expression still open at the call
  line.
- `check_hub_verify_retry` site (#2): a `retry_transient` wrap does NOT
  satisfy this check (a wrapped bare `list_repo_tree` attribute is still
  flagged BY DESIGN — the check docstring says so). The compliant route is
  the hub helper `list_hf_files_under_path(api, repo_id, path,
  repo_type=...)` (scoped server-side walk, internally retried, returns path
  strings) — structurally invisible to the check. Chosen over the
  `# HUB_VERIFY_RETRY_EXEMPT:` waiver because the helper is the designed
  fix and the call site maps 1:1 onto it; a waiver would leave an un-retried
  listing in live code, which is the #920 false-failure class the check
  exists to prevent.

```python
def _fetch(round_: str, dest: Path) -> list[Path]:
    """Download every SegB completion shard for ``round_`` into ``dest``."""
    prefix = PREFIX.format(round=round_)
    remote = [
        p
        for p in list_hf_files_under_path(HfApi(), DATA_REPO, prefix, repo_type="dataset")
        if p.endswith(".jsonl")
    ]
    if not remote:
        raise RuntimeError(f"no SegB shards under {prefix} -- wrong round or prefix (fail loud)")
    return [
        Path(
            retry_transient(
                lambda p=path: hf_hub_download(DATA_REPO, p, repo_type="dataset", local_dir=str(dest)),
                what=f"hf_hub_download({path})",
            )
        )
        for path in remote
    ]
```

(`lambda p=path: ...` — default-arg binding so each thunk captures its own
path; a bare closure over the loop variable would late-bind. The existing
`if not remote: raise` fail-loud is preserved and now also covers the
absent-prefix case, since the helper returns `[]` there.)

No other files change. No lint edits, no snapshot regen, no waivers.
