   trigger).

   trigger the absence WARN — `fired` collects WARN-tier classes only (unchanged,
   consistent with #1523's FAIL-tier exclusion).

   the sub-check remains v4-only — forward-only doctrine).
5. Tests cover: all-missing shape (new WARN fires), partial shape (unchanged),
   fully-named shape (unchanged), nothing-fired + ack-present shape (unchanged),
   fence-quoted-ack shape (absence WARN now fires there — a fenced ack is not an
   ack), FAIL-tier-only shape (unchanged), v3 shape (unchanged).

   test file passes.
