#### Step 3 — the migration recipe (per occurrence; preserves signatures AND bytes)

For each unsafe line (125 at plan-return; re-derived per batch), the transformation is:

```python
# BEFORE (typical def-wrapped shape; inline occurrences identical minus the def)
def _write_json_atomic(path: Path, obj) -> None:
    path.parent.mkdir(parents=True, exist_ok=True)
    tmp = path.parent / (path.name + ".tmp")
    tmp.write_text(json.dumps(obj, indent=2))
    os.replace(tmp, path)

# AFTER
def _write_json_atomic(path: Path, obj) -> None:
    with atomic_replace(path) as tmp:
        tmp.write_text(json.dumps(obj, indent=2))   # serialization line kept VERBATIM
```

plus `from explore_persona_space.atomic_io import atomic_replace` added in the same Edit as its first usage (the PostToolUse ruff F401 auto-fix strips an import added before its usage — code-style rule, followed).

Load-bearing recipe rules:

- **The serialization line is NEVER touched.** Local writers vary (`indent=2` vs `default=str` vs `sort_keys` vs `ensure_ascii`); rewriting them to the shared typed wrappers would change output bytes. Only the temp-derivation + `os.replace` + any local cleanup boilerplate are replaced by the contextmanager. Rejected alternative: import-alias rebinding (`from ... import write_json_atomic as _write_json_atomic`) — changes serialization kwargs and breaks local signature variants.
- **Local def names and signatures are preserved** — call sites untouched (the clarifier's instruction; it is what keeps 122 edits mechanical).
- **Edge shapes**, enumerated from the census: (a) writers that `open(tmp, "w")` + `json.dump` — keep the open/dump, swap only the derivation; (b) writers with `fsync` on the tmp — keep it inside the `with` block; a post-replace DIRECTORY fsync moves to after the `with` block (the replace happens at `__exit__`); (c) `np.savez`/`np.save` on a tmp path — MUST convert to the open-handle form (the numpy suffix-append trap, step 1) — these files get an extra line in the batch commit message naming the conversion; (d) the 2 `.sh` files (`scripts/issue779_l26_recovery_dispatch.sh`, `scripts/issue779_n1m_readout_dispatch.sh`) carry the pattern inside embedded Python — same swap inside the heredoc (the heredoc runs under `uv run python`, package importable); if a given `.sh` hit turns out to be pure-shell string construction rather than embedded Python, it gets the waiver comment with the reason recorded; (e) `scripts/issue2329_run.py` (NOT in the 79 — already safe) is rewired in batch 2 under the Supersede rule: local `_atomic_replace` deleted, replaced by `from explore_persona_space.atomic_io import atomic_replace as _atomic_replace` (alias preserves the module attribute `tests/test_issue2329_r2_fixes.py` imports; the existing 4 tests must stay green — checked in that batch).

#### Step 5 — the lint check (`scripts/workflow_lint.py --check-shared-tmp-name`)

- **Predicate** (per line, over every `*.py` and `*.sh` under `scripts/` and `src/`; `tests/` deliberately NOT scanned — lint fixtures and the harness-sensitivity control legitimately embed the banned literal):
  - arm A: `re.compile(r"""\.name\s*\+\s*(?P<q>["'])\.tmp(?P=q)""")` — catches `path.parent / (path.name + ".tmp")` AND `x.with_name(x.name + ".tmp")`, both quote styles, whitespace-tolerant;
  - arm B: `re.compile(r"""\{[A-Za-z_][A-Za-z0-9_.]*\.name\}\.tmp""")` — the f-string form `f"{path.name}.tmp"` (a line containing `getpid` or `uuid` is exempt from arm B — the safe derivation itself embeds `.name` in an f-string).
- **Failure line**: `<path>:<lineno>: process-shared atomic-write temp name (use explore_persona_space.atomic_io.atomic_replace; #2336)`.
- **Allowlist**: `SHARED_TMP_LEGACY_ALLOWLIST: tuple[tuple[str, str], ...]` of `(repo-relative path, reason)`, seeded at batch 0 from the live grep (re-derived at implementation time, not from this plan's count). A hit in an allowlisted file passes; an allowlisted file with ZERO hits (or missing) WARNs `stale allowlist entry` (the `SLURM_GPU_WIDTH_GRANDFATHER` idiom) — this is what makes a forgotten shrink visible. Deferred-live entries carry `reason="deferred — live owner #<M> (2026-08-…)"`.
- **Waiver**: `# SHARED_TMP_EXEMPT: <reason>` (reason ≥10 chars), recognized on the hit line or the immediately-preceding comment-only line, comment-token shape only (the `ARGCHECK_BIND_EXEMPT` convention).
- **Registration**: argparse flag; `if args.check_shared_tmp_name or no_flags:` dispatch; `CHECK_SCOPES["check_shared_tmp_name"] = CheckScope(kind="path-local", surfaces=("scripts/", "src/"))`; `_FILES_MODE_RUNNERS` entry; module-docstring entry ("also bundled into the no-flags default run"). **Bundling pin (keeps the no-flags wiring true after a later dispatch refactor — the #1385/#1648 silent-unbundling shape):** `tests/test_workflow_lint_shared_tmp.py` includes `test_shared_tmp_check_bundled_in_no_flags`, which plants an unsafe fixture and asserts a no-flags-equivalent dispatch reddens on it (plus a source-level assertion that `check_shared_tmp_name` appears in the `or no_flags` dispatch chain), so a refactor that drops the bundling is test-breaking, not silent.
- **Strictness vs partial migration — the decision:** the check lands FIRST (batch 0) at FAIL posture with the FULL residual allowlisted; each migration batch shrinks the allowlist in the same commit. It is never green-by-emptiness (non-allowlisted files — including every concurrent session's NEW scripts — get real FAILs from day 0) and never red-by-design (the residual is allowlisted until migrated). Fleet effect, disclosed: a live session whose unmerged branch adds a NEW file with the pattern will newly FAIL its Step 9c gate at merge time — the intended ratchet; the failure line names the shared helper, a ~2-minute adopt-or-waive fix on their branch.

### 11. Decision Rationale

- **Helper home = new `src/explore_persona_space/atomic_io.py` (stdlib-only), not `utils.py`, not `orchestrate/`.** Why: `utils.py` top-levels `numpy/torch/transformers/omegaconf` (Source: read `src/explore_persona_space/utils.py:1-10` this session) — importing it from 79 lightweight scripts drags the ML stack; `orchestrate/` is orchestration infra, not general I/O. Alternatives: extend `utils.py` (rejected — import weight); `orchestrate/atomic_io.py` (rejected — wrong layer).
- **Primitive = the #2329 contextmanager, not the `tempfile.NamedTemporaryFile` shape.** Why: the call surface is not JSON-only (json/jsonl/pt/npz/text/bytes); the contextmanager composes with ANY write expression, which is what makes the 122-site migration verbatim-serialization-preserving. Source: #2329 commit `27206c15d9` (hardware-verified) + the clarifier's analysis. Alternative: generalize `save_json_atomic` (rejected — forces serialization through shared kwargs, breaking byte-identity).
- **Migration recipe = body-delegate with verbatim serialization, not wrapper substitution.** Why: byte-identity by construction (K2 becomes near-impossible to trip); signatures preserved (call sites untouched). Source: clarifier instruction + `.claude/rules/code-style.md` supersede/consolidation conventions. Alternative: import-alias rebinding (rejected — changes kwargs/signatures).
- **`src/` files in the SAME sweep, not a separate task.** Why: 10 of the 79 are `src/` files, and the #2329 note's point 2 shows per-script fixes don't protect importers — the class is location-blind; splitting by directory adds coordination cost for zero risk reduction. - **Lint = FAIL posture + shrinking allowlist landing FIRST, not check-lands-last, not WARN-only.** Why: check-lands-last leaves the ratchet off during the sweep (new files keep landing with the pattern — the count moved 50→71→79 precisely this way); WARN-only on a ~79-file residual is the "83 standing warnings of advisory noise" anti-pattern (Source: `.claude/rules/code-style.md` § argparse-attribute completeness, measured-baseline discussion); the allowlist idiom with stale-entry WARN is established (Source: `SLURM_GPU_WIDTH_GRANDFATHER`, `workflow_lint.py` docstring line ~115).
