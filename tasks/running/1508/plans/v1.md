```markdown
- **TRL prompt-completion SFT rows: conversational (message-dict lists) on BOTH keys or plain str on BOTH — a MIXED `{"prompt": <message list>, "completion": "<str>"}` row is undefined behavior that routes per-process-nondeterministically and can crash ONLY on the pod.** `trl.data_utils.is_conversational()` (installed TRL 0.29.1; byte-identical on upstream `main` as of 2026-07-18 — unfixed) collects the row's supported keys into a SET and inspects ONLY `example_keys.pop()` — one arbitrary element (the code comment reads "take the first supported key"): per-process string-hash randomization decides which key is popped (measured 2026-07-18: 8 fresh interpreters on `{prompt, completion}` popped `prompt` 7×, `completion` 1×), so a mixed row reads conversational in one process and standard in the next, and the same builder passes local dict-level probes then dies on the pod when the standard route feeds the list-valued `prompt` to the str-only tokenize path (either route is wrong for a mixed row; this is the observed one). RULE: (1) TRL-bound dataset builders emit message-dict LISTS on both `prompt` AND `completion` — the canonical shape is `scripts/issue778_finetune.py::_messages_to_prompt_completion` (line 62), paired with `completion_only_loss=True` — or plain str on both, never mixed; (2) smoke EVERY TRL-bound dataset builder through the REAL `train_lora` → `SFTTrainer` tokenize seam with a tiny real-vocab model (#1489's `tests/test_issue1489_distill_dataset.py` pattern; the mock-seam tiny-real entry above is the general recipe) — a dict-level schema probe validates nothing about routing, and one local pass proves nothing (the next process can route the other way). Diagnostic signature: `ValueError: text input must be of type str ...` at `SFTTrainer.__init__`, intermittent across processes on identical data. (Incident #1489 crash-fix round 4, 2026-07-18: `build_distill_jsonl` (`scripts/issue1489_gpu_phase.py`) wrote `{"prompt": <message list>, "completion": <str>}`; local probes passed, the GCE run crashed at trainer init — one ~9 min provision cycle, smoke-caught.)
```
