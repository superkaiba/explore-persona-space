# Plan — Issue #886: PEFT-aware decoder-block detection in `extract_layer_activations`

## 0.0 TL;DR (plain English)

- **What I'll change:** the shared activation-extraction helper currently fails to find the decoder layers inside a LoRA-wrapped model, so it silently falls back to a slower path that also returns a differently-normalized last layer. I'll make it look one level deeper (where PEFT actually keeps the layers), take the fast hook path with the LoRA adapters active, and emit a one-time warning so existing wrapped-model callers know the last-layer convention changed.
- **What I expect:** a PEFT-shaped stub now takes the hook path (proven by a new test), every existing test stays green byte-for-byte for bare models, and the docstring #868 is adding gets updated to describe the new behavior.
- **What would change my mind:** if the live-peft smoke shows the attribute chain isn't `wrapper.model.model.layers` on installed peft 0.18.1, the detection depth is wrong and I stop and re-diagnose before landing.

## 2. Prior work / method delta

- **In-repo:** the helper generalizes `experiments/behavior_testbed_545/predictors.py::_mean_hidden_states` and the hook idiom in `analysis/representation_shift.py`; both assume a bare `*ForCausalLM`. - **Field conventions:** PEFT's own API for this is `PeftModel.get_base_model()` (peft_model.py:990 — returns `self.base_model.model`, the injected LoRA-active `*ForCausalLM`, for all non-prompt-learning methods). TransformerLens/nnsight require explicit module paths and don't auto-unwrap; HF utilities use `model.base_model` attributes. The common robust pattern is a bounded attribute-chain walk — which is what we adopt, duck-typed, so the helper needs neither a peft import nor an isinstance check.
- **Method delta vs the current helper:** detection depth 1 → depth ≤ 3 walk; everything else (hook registration, `_unwrap`, fallback body, conventions) unchanged.

## 3. Remedy choice (the one design decision)

**Chosen: remedy 3 — PEFT-aware detection + one-time warning.**
- Remedy 2 (loud refusal) rejected: it would hard-crash the live out-of-scope callers (`scripts/issue667_extract.py:466-482, :591-592, :1051-1052`; `issue667_pertoken_extract.py:194-195`; `issue667_pertoken_context_extract.py:195-196`) that pass `PeftModel`s today — converting a silent degradation into a breakage of code this task must not touch.
- Remedy 1 (silent detection) rejected: the fix flips the last-layer value for wrapped-model callers from post-norm to pre-norm (measured cosine diff ~1.6e-1 at L27 per the #868 docstring, vs ~1e-4–2e-3 elsewhere); silently changing their numbers hides exactly the signal the contamination-audit task needs.
- Remedy 3 gives correct behavior (hook path, LoRA-active blocks, memory-safe, last-layer convention now CONSISTENT across bare/wrapped) plus a migration signal. `warnings.warn` with the default filter is once-per-callsite ≈ once-per-process — negligible noise in tight loops.

## 4. Design

### 4.1 `src/explore_persona_space/analysis/extraction.py` — the detection change

Add `import warnings` (stdlib, above `torch`). Replace lines 121-122 with a call to a new module-level helper:

```python
def _resolve_decoder_blocks(model):
    """Walk the ``.model`` wrapper chain (depth 1..3) to find decoder blocks.

    Returns ``(blocks, embed_tokens, depth)`` from the FIRST chain level
    exposing ``.layers``; ``(None, None, 0)`` when none does (non-standard
    models + CPU test stubs -> the full-tuple fallback). Depth 1 is the bare
    HF layout (``model.model.layers``). Depth 2 is the PEFT layout:
    ``PeftModel.model`` forwards (``PeftModel.__getattr__`` ->
    ``LoraModel.model``, peft 0.18.1) to the injected ``*ForCausalLM`` whose
    own ``.model.layers`` ARE the LoRA-active decoder blocks (same object
    ``get_base_model()`` returns). Depth 3 is headroom for one extra wrapper.
    Purely structural — no peft import; depth-1-first preserves bare-model
    behavior exactly.
    """
    inner = model
    for depth in range(1, 4):
        inner = getattr(inner, "model", None)
        if inner is None:
            return None, None, 0
        blocks = getattr(inner, "layers", None)
        if blocks is not None:
            return blocks, getattr(inner, "embed_tokens", None), depth
    return None, None, 0
```

In `extract_layer_activations`:

```python
    blocks, embed, wrap_depth = _resolve_decoder_blocks(model)
    if wrap_depth >= 2:
        warnings.warn(
            "extract_layer_activations: wrapped (PEFT-style) model — decoder "
            f"blocks resolved {wrap_depth} levels deep; taking the HOOK path "
            "with adapters active. NOTE: the last-layer capture is "
            "PRE-final-norm (earlier versions silently took the post-norm "
            "full-tuple fallback for wrapped models).",
            UserWarning,
            stacklevel=2,
        )
```

Everything downstream (fallback body, hook registration on `blocks[L]` / `embed`, `EMBED_LAYER` skip-when-`embed is None`) is unchanged. For depth-1 models `blocks`/`embed` are the identical objects the old two-liner produced → byte-for-byte hook-path behavior for bare models. Calling the `PeftModel` itself (`model(...)`) with hooks on the inner blocks is correct: `PeftModelForCausalLM.forward` delegates through `LoraModel` to the injected model, so the hooked blocks fire with adapters active.

### 4.2 `tests/test_issue671_extraction_hooks.py` — new section 6 (appended; reuses existing stubs)

```python
# 6. PEFT-wrapped models take the hook path (#886)

class _PeftWrapper:
    """Mimics peft.PeftModel's attribute chain: ``.model`` -> the injected
    *ForCausalLM (here the _HookStub), so decoder blocks live at
    ``wrapper.model.model.layers`` (depth 2). Forwards __call__ like
    PeftModelForCausalLM.forward."""
    def __init__(self, inner):
        self.model = inner
    def __call__(self, **kw):
        return self.model(**kw)
    def eval(self):
        return self

def test_peft_wrapped_model_takes_hook_path():
    # Byte-identity vs the seeded fallback stub. Teeth: _HookStub asserts
    # output_hidden_states is falsy — a fallback-path regression fails loudly.
    tok = _tok()
    layers = [EMBED_LAYER, 0, 14, 27]
    fallback = _FallbackStub(tok.vocab_size, _D, _N_BLOCKS, seed=31)
    wrapped = _PeftWrapper(_HookStub(tok.vocab_size, _D, _N_BLOCKS, seed=31))
    for ids in _ids_list(tok):
        with pytest.warns(UserWarning, match="wrapped"):
            hk = extract_layer_activations(wrapped, ids, layers)
        fb = extract_layer_activations(fallback, ids, layers)
        assert set(hk) == set(layers)
        for L in layers:
            assert torch.equal(fb[L], hk[L]), L

def test_bare_model_resolution_is_warning_free():
    # Depth-1 (bare) resolution must not warn — byte-compat guard.
    tok = _tok()
    hook = _HookStub(tok.vocab_size, _D, _N_BLOCKS, seed=31)
    with warnings.catch_warnings():
        warnings.simplefilter("error")
        extract_layer_activations(hook, _ids_list(tok)[0], [0, 27])

def test_fallback_stub_unaffected_by_chain_walk():
    # _FallbackStub has no .model attribute — the deeper walk must not
    # resolve it; the full-tuple fallback still returns hidden states.
    tok = _tok()
    fb = _FallbackStub(tok.vocab_size, _D, _N_BLOCKS, seed=31)
    acts = extract_layer_activations(fb, _ids_list(tok)[0], [0, 27])
    assert set(acts) == {0, 27}
```

Add `import warnings` + `import pytest` to the test-file imports (in the same edit as first usage — the PostToolUse ruff hook strips unused imports).

## 11. Decision rationale

- **Training hyperparameters:** N/A — no model training.
- **Remedy = detect + one-time warn (remedy 3).** *Why:* correct behavior for wrapped models with a migration signal for the last-layer convention flip; refusal breaks live out-of-scope callers; silent detection hides the flip. *Source:* repo evidence — issue667 call sites passing PeftModels (task #886 body); #868 worktree docstring's measured L27 pre/post-norm cosine diff ~1.6e-1; peft 0.18.1 installed source (`peft_model.py:893` `__getattr__` forwarding, `:990` `get_base_model`, `tuners_utils.py:276` `self.model = model`). *Alternatives:* remedies 1/2, rejected in §3.
- **Duck-typed chain walk, no peft import.** *Why:* peft IS a hard dep (`pyproject.toml:16`, `peft>=0.13,<1.0`) so an import would work, but structural detection keeps the helper import-light, covers the depth-3 headroom case, and needs no isinstance maintenance across peft versions. *Source:* task constraint + `pyproject.toml:16`.
- **Depth cap = 3, starting at depth 1 (not 0).** *Why:* depth-1-first preserves exact current behavior for every existing caller; starting at 0 would newly route bare transformer bodies (`Qwen2Model`) to the hook path — an out-of-scope behavior change. *Source:* hard constraint "byte-for-byte behavioral compatibility for existing bare-model callers".
