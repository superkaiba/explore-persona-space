### 4.1 Change 1 — buffer splitter records into arrays (lookahead)

Replace the streaming loop header/footer (:1267, :1534) with a buffered read + indexed for-loop. The loop BODY (:1268-1533) stays byte-identical (`continue`/`break` semantics preserved by `for`):

```bash
# (#1538) Buffer the (sep, nextsep, clause) triples so the grep-family
# pipe waiver can look ahead at downstream pipe-connected consumer
# clauses. read -r keeps trailing-field semantics: a clause containing
# a literal tab still lands whole in _c (last var takes the remainder).
_seps=(); _nextseps=(); _clauses=()
while IFS=$'\t' read -r _s _n _c; do
  _seps+=("$_s"); _nextseps+=("$_n"); _clauses+=("$_c")
done < <(split_and_label "$cmd")
_nrec=${#_clauses[@]}

for _idx in "${!_clauses[@]}"; do
  sep=${_seps[$_idx]}; nextsep=${_nextseps[$_idx]}; clause=${_clauses[$_idx]}
  # ... existing body :1268-1533 unchanged ...
done
```

Notes: the script is bash (`#!/usr/bin/env bash`, uses `< <(...)` already) and runs `set -u` (:538) — `"${!_clauses[@]}"` on an empty array is a no-op loop, matching today's zero-record behavior. `split_and_label` never emits an empty clause field (empty records only flush the buffer, :965-970), so array entries are non-empty pre-comment-strip.

### 4.2 Change 2 — read-only sink-chain walker (new function)

New function placed immediately after `split_and_label()` (:974), operating on the arrays (bash arrays are file-global):

```bash
# (#1538) TRUE iff every downstream pipe-connected clause after record $1
# is a verified read-only text filter, and the chain terminates on a
# non-PIPE, non-BG seam. Fail-closed: any unclassifiable shape -> 1.
_pipe_chain_is_readonly_sink() {
  local j=$(( $1 + 1 )) c
  while :; do
    [ "$j" -lt "$_nrec" ] || return 1        # trailing '|' / ran off records
    [ "${_seps[$j]}" = PIPE ] || return 1    # defensive: seam must be PIPE
    c=${_clauses[$j]}   # (#1538 v3) RAW clause text — deliberately NO comment
    # strip: the :1303-style strip INVERTS fail-closed direction inside a
    # REFUSAL scan (deleting text can delete a refusal trigger — a quoted
    # space-hash inside a consumer arg truncates the scanned text before a
    # write/exec flag). Instead, ANY '#' in a consumer refuses outright.
    # This also refuses comment-only consumers — a deliberate asymmetry vs
    # the driver, which SKIPS a clause-initial comment (:1283): the walker
    # refuses what the driver skips (fail-closed).
    case "$c" in *'#'*) return 1 ;; esac
    [ -n "$c" ] || return 1
    # (a) clause-initial allowlisted read-only filter word (bare word only;
    #     path-spelled /usr/bin/head, env-prefixed, or quoted words refuse)
    echo "$c" | grep -qE '^(head|tail|wc|cat|cut|tr|nl|sort|uniq|grep|egrep|fgrep|rg)([[:space:]]|$)' || return 1
    # (b) (#1538 v3) NO '$' of ANY kind in a consumer — command substitution,
    #     brace expansion, AND bare $NAME (a variable can carry a write/exec
    #     channel flag past the static (d) scan) — plus backtick / procsub /
    #     here-string. Deliberate strict superset of cond-(3).
    echo "$c" | grep -qE '\$|`|<\(|>\(|<<<' && return 1
    # (c) cond-(3b) parity: no output redirect post-/dev/null-strip
    echo "$c" | sed -E 's@[0-9]*>>?[[:space:]]*/dev/null([[:space:]]|$)@ @g' | grep -q '>' && return 1
    # (d) per-word write/exec channels (VM --help scan, fact-check 2026-07-19)
    if echo "$c" | grep -qE '^(grep|egrep|fgrep|rg)([[:space:]]|$)'; then
      # --pre / --hostname-bin execute programs (rg); -z/--search-zip runs
      # fixed-name decompressors (rg) — refused for the whole family
      # (fail-closed; GNU grep's read-only -z --null-data is a rare-use FP).
      # (#1538 v3) NO trailing anchor on the short-flag bundle — mirrors the
      # sort branch — so a mid-bundle spelling (gated letter followed by more
      # bundled letters) still catches (GPN8e).
      echo "$c" | grep -qE '(^|[[:space:]])(--(pre|hostname-bin)(=|[[:space:]])|-[A-Za-z]*z|--search-zip)' && return 1
    elif echo "$c" | grep -qE '^sort([[:space:]]|$)'; then
      # -o/--output writes a file with no '>' — incl. bundled (-ro) and
      # glued (-o/tmp/x) short forms; --compress-program executes an
      # arbitrary named program; -T/--temporary-directory writes spill
      # files to an arbitrary dir (refused fail-closed)
      echo "$c" | grep -qE '(^|[[:space:]])(-[A-Za-z]*[oT]|--output|--compress-program|--temporary-directory)' && return 1
    elif echo "$c" | grep -qE '^uniq([[:space:]]|$)'; then
      # uniq's SECOND positional arg is an OUTPUT file; piped usage needs
      # no positional args -> refuse any non-option token (fail-closed;
      # 'uniq -c' passes, 'uniq - /tmp/x' and 'uniq f.txt' refuse)
      echo "$c" | sed -E 's/^uniq//' | tr -s '[:space:][:blank:]' '\n\n' | grep -qE '^[^-]' && return 1
    fi
    case "${_nextseps[$j]}" in
      PIPE) j=$((j + 1)) ;;   # walk the next pipe stage
      BG)   return 1 ;;       # fd-dup mis-split ('2>&1') / true background
      *)    return 0 ;;       # END/SEQ/AND/OR/NL terminate the chain
    esac
  done
}
```

What counts as a permissible consumer (the allowlist rationale): `head tail wc cat cut tr nl grep egrep fgrep rg sort uniq` are pure stdin→stdout text filters. The Phase-1.5 fact-checker's `--help` scan on THIS VM (2026-07-19) enumerated their write/exec side channels — grep-family `--pre` (per-file preprocessor exec), rg `--hostname-bin` (executes a named binary), rg `-z`/`--search-zip` (executes fixed-name decompressors from PATH), sort `-o`/`--output` (file write without `>`), sort `--compress-program=PROG` (executes an arbitrary named program), sort `-T`/`--temporary-directory=DIR` (spill-file writes to an arbitrary dir — weak channel, refused fail-closed), uniq's positional OUTPUT arg — each individually refused in (d). (The plan's original "exactly four channels" claim was corrected by the fact-check: `--compress-program` was the missed arbitrary-exec channel.) Deliberately EXCLUDED (each still refuses the waiver): `sed` (GNU `e`/`w` commands execute/write), `awk` (`system()`), `xargs` (executes), `tee` (writes), `bash`/`sh`/`python`/any interpreter, `jq`/`less`/`more`/`column` (unneeded for the incident class; extensible later with their own channel analysis). Note `grep -f FILE` / `rg --file` are pattern READS — safe, no refusal needed; the executable cousin `grep -f <(...)` is refused by (b).
