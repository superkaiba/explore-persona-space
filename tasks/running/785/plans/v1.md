## 0. Plan Summary

**What this is:** A workflow-surface fix. Two related bugs in `.claude/skills/issue/SKILL.md` + `scripts/select_step9c_tests.py`:

1. **#506 regression (path-doubling):** Step 4a and the Step 9c test-selection helper still derive `REPO_ROOT` via `git rev-parse --show-toplevel`. From a worktree cwd that returns the *worktree* root, so `"$REPO_ROOT/.claude/worktrees/issue-<N>"` nests to `.../issue-<N>/.claude/worktrees/issue-<N>` and the downstream `cd`/symlink fails. The #506-safe recipe (`dirname "$(git rev-parse --path-format=absolute --git-common-dir)"`) already exists in Step 10d (line 6717) but was never propagated to Step 4a or the helper.
2. **Silent test-gate pass:** Step 9c step 1b ("run the printed command") has no guard against a failed `cd` upstream or a `no tests ran` pytest outcome. On 2026-06-30 issue 745 (SHA `91bed41e`) passed the test-verdict gate with `no tests ran ... pytest exit: 0` — the gate was silently skipped.

**Fix:** (a) swap `show-toplevel` → the `--git-common-dir` recipe in Step 4a (line 1714) + its prose (line 1744) + `select_step9c_tests.py::_resolve_repo_root` (line 231); (b) add an explicit hard-fail-on-`no tests ran` guard + a `cd`-success assertion to the Step 9c test-verdict block; (c) re-grep to confirm only the *intentional* Step 5a `show-toplevel` (line 1907, wants the worktree root) survives.

**Compute:** `Estimated GPU-hours (total): 0` — text + one-function code edit. Wall-time ~5-10 min implementer work + test run.

**Risks:** (1) Over-broad grep-replace catching the intentional Step 5a usage or the deliberate anti-pattern-documentation hits (mitigated: explicit do-NOT-touch list). (2) Changing `_resolve_repo_root` semantics from worktree-root → main-root could shift test selection — mitigated below (Step 9c runs from `main` cwd where both agree; from a worktree, main-root is the correct base for `tests/` resolution).

### Diff 3 — `scripts/select_step9c_tests.py` `_resolve_repo_root` (lines 227-236)

Replace:
```python
def _resolve_repo_root(arg: str | None) -> Path:
    if arg:
        return Path(arg).resolve()
    out = subprocess.run(
        ["git", "rev-parse", "--show-toplevel"],
        capture_output=True,
        text=True,
        check=True,
    )
    return Path(out.stdout.strip()).resolve()
```
with:
```python
def _resolve_repo_root(arg: str | None) -> Path:
    if arg:
        return Path(arg).resolve()
    # #506-safe: from a worktree cwd, `git rev-parse --show-toplevel` returns the
    # WORKTREE root; --git-common-dir resolves to <main>/.git, so dirname is the
    # main repo root (where tests/ paths must resolve). See SKILL.md Steps 4a/10d.
    out = subprocess.run(
        ["git", "rev-parse", "--path-format=absolute", "--git-common-dir"],
        capture_output=True,
        text=True,
        check=True,
    )
    return Path(out.stdout.strip()).parent.resolve()
```
(`Path(...).parent` is the Python analogue of `dirname`; keep the `--repo-root` override branch byte-for-byte unchanged. Note: `.parent.resolve()` is correct because `--path-format=absolute` guarantees an absolute path.)

```bash
fi
```
