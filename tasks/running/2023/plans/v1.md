## Method delta (vs the #1585 fix this mirrors)

#1585 excluded only attribution-ROW-shaped lines inside the warnings-summary section (a double predicate: in-section AND row shape) because warnings-summary content is heterogeneous. The PASSES section is different in kind: EVERYTHING inside it is captured output of tests pytest reports as PASSED — definitionally not red evidence — so the carve-out covers the WHOLE section (single predicate: index inside the PASSES fenced window; any other fence title closes it). The candidate's optional "reclassify on a 0-failed/0-error summary" variant is deliberately NOT taken: the section tracker addresses the incident class exactly and stays correct even on failing runs (failing tests' evidence lives in the FAILURES section + summary rows, which remain hit-eligible), while a whole-run carve-out would add a broader suppression surface that could mask genuine red.
