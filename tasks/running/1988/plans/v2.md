# Plan v2 — #1988 workflow-fix: widen check-28 figure token pattern to arm slugs

(v2 = v1 + critic round-1 Must-Fix adopted verbatim: digit-in-FINAL-segment
filter replaces the digit-anywhere filter and the recall-breaking kill-lever;
corpus-derived FP/recall probes added to the test set; docstring-roster +
URL-dedup notes folded in as implementer duties.)

## Goal / requirement

Widen `scripts/verify_task_body.py` check 28 (`check_figure_label_codes` /
`_opaque_code_tokens`) with a SEVENTH token class: hyphen-separated arm slugs
(the fleet's `behavior-context-regime-lr-seed` grammar, e.g.
`cas-pers-con-lr1e5-s137`) rendered in figure text (tick labels, titles,
legends). WARN-class only; captions that name the slug suppress the WARN for
that figure; one WARN per body (existing aggregation).

**Acceptance criteria**
1. `_opaque_code_tokens("… cas-pers-con-lr1e5-s137 …")` returns the slug;
   the no-`s`-prefix fleet variant `ft-con-137` (figures/issue_1586
   sidecars) is ALSO returned (recall case).
2. Legitimate rendered English/compounds are NOT flagged — corpus-derived
   probes: `under-4-token` (issue_1335), `first-16-token` (issue_952),
   `best-of-28-layers` (issue_664), `claude-sonnet-4-5-20250929`
   (issue_1092/issue_1739), plus `end-to-end` / `state-of-the-art`
   (digit-in-final-segment filter drops all of these).
3. 2-segment tokens (`log-prob`) are NOT flagged (regex requires ≥3
   segments).
4. A slug inside a path-shaped word is exempt (existing per-word path
   exemption reused).
5. `check_figure_label_codes` on a #1768-shaped sidecar flags slug tick
   labels; a figure whose blockquote caption contains the slug verbatim
   (case-insensitive) is suppressed FOR THE SLUG CLASS ONLY.
6. Check stays WARN-class (never a hard FAIL); grandfathered classes (a)-(f)
   behave byte-identically (no new suppression applied to them).
7. Tests in `tests/test_verify_task_body.py` cover 1-6 and pass; no
   pre-existing check-28 test regresses.

## Method delta (vs the current scanner)

Current `_opaque_code_tokens` covers six classes: `@L<d>` pins, snake tokens
(≥3 segments or digit-bearing), `H\d[a-z]?` hypothesis codes, `f16`/`l16`
slot-family, `[PM]\d[a-z]?` candidate codes, letter-arrow transitions
(#1902/#1986). No hyphen-separated class exists — #1768's ~10 slug-bearing
figures pass clean (verified live 2026-08-05: slugs sit at
`meta["text"].axes[].yticklabels` VALUES, inside the scanned walk). Delta =
one added regex class + digit-in-final-segment filter + a slug-class-scoped
caption-decode suppression in the check-28 loop.

## File paths + concrete diffs

`scripts/verify_task_body.py` (sole code target) + `tests/test_verify_task_body.py`:

1. New module-level regex next to the sibling class regexes:
   ```python
   # Hyphen-separated arm slugs (#1988): >=3 segments, first segment 2-6
   # lowercase alpha, later segments lowercase alnum; the post-match filter
   # requires a DIGIT in the FINAL hyphen segment (the fleet grammar's
   # lr/seed tail: cas-pers-con-lr1e5-s137, ft-con-137) so ordinary
   # hyphenated English/compounds (end-to-end, under-4-token,
   # best-of-28-layers, claude-sonnet-4-5-20250929) stay unflagged.
   _ARM_SLUG_RE = re.compile(r"\b[a-z]{2,6}(?:-[a-z0-9]{1,12}){2,}\b")
   ```
2. In `_opaque_code_tokens`: add `_ARM_SLUG_RE` to the class loop, with the
   SAME `_only_in_path_words` exemption, plus the critic-verified
   final-segment digit filter:
   `any(c.isdigit() for c in tok.rsplit("-", 1)[1])`
   (verified over all non-1768 `figures/**/*.meta.json`, critic round 1:
   keeps 72/72 #1768 slugs + `ft-con-137`/`ft-con-42` (#1586) + true slugs
   on #1481/#1947/#1979; drops `under-4-token`, `first-16-token`,
   `best-of-28-layers`, `claude-sonnet-4-5-20250929`, `us-central1-a`.
   Residual kept tokens — `copy-answer-1`, `att-<ts>` timestamps — are
   in-spirit opaque/provenance tokens and caption-suppressible; accepted).
   Docstring gains the class-(g) paragraph.
3. In `check_figure_label_codes`: split token collection so slug-class
   tokens are tracked separately per figure; before warning, compute the
   figure's CAPTION window (the contiguous `>`-blockquote lines immediately
   following the image line in the scanned section) and DROP slug tokens
   that appear verbatim (case-insensitive) in that caption — the mechanical
   proxy for "the caption decodes the slug". Non-slug classes never
   suppressed (byte-stable grandfathered behavior). Aggregation unchanged:
   the existing single WARN CheckResult per body (head-3 truncation)
   already satisfies "WARN once per body, not per figure". Note in the
   helper docstring: URL dedup (`dict.fromkeys(urls)`) means a figure
   appearing twice uses the first occurrence's caption window —
   conservative (extra WARN at worst).
4. Docstring/doc-block updates so the class roster stays consistent
   everywhere: function docstring "SIX token classes" → seven + the #1988
   incident line; the `_opaque_code_tokens` L8880 "exempt from ALL SIX
   token scans" literal → seven; the check-label string (~L9023-9027)
   gains the arm-slug mention; the L518-520 check-28 doc row mentions arm
   slugs.
5. Tests (`tests/test_verify_task_body.py`; fake-sidecar integration
   precedent at ~L12319+): unit tests for acceptance criteria 1-4 —
   including the corpus-derived FP-drop probes (`under-4-token`,
   `first-16-token`, `best-of-28-layers`, `claude-sonnet-4-5-20250929`)
   and the no-`s`-prefix recall case (`ft-con-137`) — plus integration
   tests for 5-6 following the in-file precedent.
