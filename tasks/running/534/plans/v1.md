## 3. Hypotheses (all interpretable; the body's three honest verdicts + the replication-failure verdict)

Definitions used by every verdict: a fraction "shows the reversed signs" iff shadow_angle partial ρ < 0 AND d_nn partial ρ > 0, both Holm-significant (α=0.05 across the 6 predictors within that fraction's fit, inherited from #530) AND both seeds agree on sign. A fraction is **usable** iff (i) bystander-resolution gate PASSes (median bystander log P(marker) ≤ −2 nats AND <60% probes argmax=marker) AND (ii) mean source ΔG across the 8 positioned cells at that fraction ≥ 1 nat (off-floor; #504-v1's "implant never installed" read was +0.259 nats).

- **H-B (maturity confound → weakens #530's saturation-artifact interpretation).** One or more usable earlier fractions show the PARENT's direction (shadow_angle > 0 and/or d_nn < 0, Holm-sig, seed-consistent) while frac 1.00 shows the reversal — the sign is then confounded with implant maturity, not anchor saturation alone.

## 4. Design

### 4.1 The manipulated variable, made concrete

**Sub-stop checkpoint granularity.** During training, `MarkerBandStopCallback` saves an adapter-only snapshot after EVERY optimizer step (k=1, cap 64). At train end it writes `band_stop_meta.json` (realized stop step S, stopped flag, stop delta, in-loop eval history). A post-hoc selector maps fractions {0.25, 0.50, 0.75, 1.00} to target steps `max(1, round(f·S))`, picks the nearest saved snapshot per target (exact match when k=1 and S ≤ 64), and emits a `checkpoint_index.json` in the exact `{frac: {step, path}}` shape `i504_eval_trajectory.py` already consumes — the eval rig then runs all 4 fractions with zero changes.

**The eval-cadence call (the subtlest decision): KEEP `eval_every_steps=10` / `min_steps=20` VERBATIM.** Defense:
- The stop semantics define what the frac=1.00 anchor IS. #530's headline lives at the step-20 band-stop checkpoint; the body explicitly wants the final-fraction refit to double as a replication check. Changing the cadence (or `min_steps`) changes when the stop fires → a different frac=1.00 object → the replication check is confounded and the single-variable discipline is broken.
- Sub-stop granularity does not require a finer-resolved stop: the Goal needs checkpoints BELOW the realized stop, which per-step snapshots provide regardless of where the stop lands.
- Note for completeness: tightening `eval_every_steps` 10 → 5 while keeping `min_steps=20` would NOT change the realized stop either (no stop can fire before step 20, and 20 is a multiple of both) — but it would add an unnecessary divergence for zero benefit, since the post-hoc per-step source-self read (§4.5 step 3) recovers the full-resolution source trajectory anyway. Rejected.
- Snapshotting is passive with respect to training: `model.save_pretrained()` between optimizer steps serializes weights, consumes no RNG, and touches neither the optimizer nor the schedule, so the weight trajectory is bit-comparable to a no-snapshot run up to backend nondeterminism (same class of nondeterminism #530 already accepted).

```python
def on_step_end(self, args, state, control, model=None, **kwargs):
    if model is None:
        return
    # NEW: per-step adapter snapshot — BEFORE the cadence gate and BEFORE the
    # stop predicate, so the stop-step snapshot itself exists (frac 1.00).
    if (
        self.snapshot_every_steps > 0
        and self.snapshot_dir is not None
        and not self._stopped
        and state.global_step > 0
        and state.global_step % self.snapshot_every_steps == 0
        and len(self._snapshot_steps) < self.snapshot_max_count
    ):
        d = Path(self.snapshot_dir) / f"step_{state.global_step:04d}"
        if not d.exists():                      # idempotent on re-entry
            model.save_pretrained(str(d))       # PEFT adapter-only (~95 MB), no optimizer state
        self._snapshot_steps.append(int(state.global_step))
    if self._stopped or self._disabled_too_short:
        return
    # ... existing cadence gate + base-cache + read + band predicate UNCHANGED ...
    # after computing delta_mean at an eval read:
    self._eval_history.append({"step": int(state.global_step), "delta_nats": float(delta_mean)})

def on_train_end(self, args, state, control, **kwargs):   # NEW method
    if self.snapshot_dir is None:
        return                                   # legacy callers: exact no-op
    meta = {
        "stopped": bool(self._stopped),
        "stop_step": int(state.global_step),     # realized stop step S (or final step at epoch ceiling)
        "stop_reason": "band" if self._stopped else "epoch_ceiling",
        "eval_history": self._eval_history,
        "snapshot_steps": self._snapshot_steps,
        "band": [self.low_nats, self.high_nats],
        "eval_every_steps": self.eval_every_steps,
        "min_steps": self.min_steps,
    }
    (Path(self.snapshot_dir) / "band_stop_meta.json").write_text(json.dumps(meta, indent=2))
```

```python
def select_fractions(snapshot_dir, fractions=(0.25, 0.50, 0.75, 1.00)) -> dict:
    meta = json.loads((snapshot_dir / "band_stop_meta.json").read_text())
    S = meta["stop_step"]
    if not meta["stopped"]:
        log.warning("cell never band-stopped (stop_reason=%s); S=last step %d — cell FLAGGED", ...)
    available = sorted(int(p.name.split("_")[1]) for p in snapshot_dir.glob("step_*"))
    index, manifest = {}, []
    for f in fractions:
        target = max(1, round(f * S))
        sel = min(available, key=lambda s: (abs(s - target), s))   # nearest; tie → earlier
        index[f"{f:.2f}"] = {"step": sel, "path": str(snapshot_dir / f"step_{sel:04d}")}
        manifest.append({"frac": f, "target_step": target, "selected_step": sel,
                         "exact": sel == target})
    distinct = len({v["step"] for v in index.values()})
    # Dedup/edge rule: if S < 4, fractions collapse onto duplicate steps. KEEP all
    # four frac keys (the eval rig evals each entry; duplicates re-eval the same
    # weights — wasteful but correct), record `distinct_steps` in the manifest, and
    # the analysis treats DISTINCT steps as the unit (collapsed fractions annotated
    # on the trajectory figure, never plotted as independent points).
    return {"index": index, "manifest": manifest, "stop_meta": meta, "distinct_steps": distinct}
```
