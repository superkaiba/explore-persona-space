### 4.1 New helpers (module level, above `select_tests_with_reasons`)

```python
def touched_module_names(touched: list[str]) -> dict[str, set[str]]:
    """Importable module names -> touched files, for import-map-eligible files.

    Eligible: suffix ``.py``, path under ``scripts/`` or ``src/explore_persona_space/``
    (never ``tests/`` — the touched-test arm owns those).
      scripts/X.py            -> {"X", "scripts.X"}          (flat via sys.path insertion
                                                              — the #1286 pattern, 174 test
                                                              files; dotted — scripts/ is a
                                                              package, 25 test files)
      scripts/pkg/__init__.py -> {"pkg", "scripts.pkg"}
      src/explore_persona_space/a/b.py       -> {"explore_persona_space.a.b"}
      src/explore_persona_space/a/__init__.py -> {"explore_persona_space.a"}
    Multi-map on collisions (two touched files resolving one name both listed)."""

def _import_names(tree: ast.AST) -> set[str]:
    """Every dotted name any Import/ImportFrom node references, ANYWHERE in the
    file (ast.walk — see §1 extension note). ``import X.Y as z`` -> {"X.Y"};
    ``from M import a, b`` -> {"M", "M.a", "M.b"} (the M.a form catches
    ``from explore_persona_space.foo import bar`` naming touched module
    ...foo.bar). Relative imports (node.level > 0) skipped — tests/ is not a
    package here; document."""

def import_map_hits(
    touched: list[str], work_root: Path
) -> tuple[dict[str, set[str]], set[str]]:
    """Scan tests/**/test_*.py (rglob, sorted; subdir tests like
    tests/experiments/ are pytest-collected and reachable by the touched-test
    arm already, so the import arm matches that scope) and return
    ({test_relpath: {touched files it imports}}, {touched files with >=1 hit}).

    Cost bound: module_map empty (workflow-surface-only diff) -> return
    immediately, ZERO file reads. Otherwise read each test file's text and
    apply a SUBSTRING PRE-FILTER: parse only files whose raw text contains the
    last dotted component of at least one candidate module name (any absolute
    import of module M must literally spell M's last component, so the filter
    is over-inclusive — never a false negative; typical touched sets parse a
    handful of files, worst case all ~482 at a measured 4-8 s).

    A file that fails to read/parse (OSError, SyntaxError, ValueError) emits ONE
    stderr WARN ("select_step9c_tests: WARN — import-map cannot parse <p>: <e>;
    file skipped for the import arm") and is SKIPPED — never crashes the
    selector (fail-soft, §11 rationale R5)."""
```

### 4.2 Wiring into `select_tests_with_reasons` (before the per-file loop)

```python
import_hits, import_tested = import_map_hits(touched, work_root)
for test_rel, files in sorted(import_hits.items()):
    for f in sorted(files):
        _add(test_rel, f"import-map:{f}")
# ... inside the existing per-file loop, the .py branch seeds:
            matched = f in import_tested   # was: matched = False
```

Monotonicity is by construction: the arm only calls `_add()` (adds tests/reasons to the same `selected` dict) and only ever REMOVES entries from the `untested` WARN list (via the `matched` seed) — no code path deletes a stem-map / glob-scan / invariant / touched-test selection. Determinism: sorted rglob + sorted iteration; output shape unchanged (`final = sorted(selected)`).

**WARN suppression decision (design Q4): an import-map hit DOES mark the touched file tested.** The glob-scan arm deliberately does not (a scan asserts a cross-cutting invariant ABOUT the file); an import is categorically different — the test executes the touched module's code at collection or call time. The evidence standard is already lower for the stem-map broad glob (pure filename substring sets `matched=True`); an actual import is strictly stronger evidence, so suppressing the WARN is the consistent choice. (#1286's noise: 4/5 touched scripts WARNed despite a real covering test.)
