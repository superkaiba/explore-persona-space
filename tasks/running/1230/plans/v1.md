Design notes baked into the wording:

- **Both-arms existence** via a single worktree grep (the worktree = tree + round's committed diff), with the diff `--name-status` used only to label WHICH arm in the Notes column — provenance evidence, not the verdict condition. This is exactly the grep-the-literal evidence discipline, extended to a line class reviewers currently don't table.
- **Severity** mirrors the grep-the-literal convention's "Major otherwise" tier (a missing prose pin never breaks an experiment headline, so the Critical branch does not apply) and rides the existing `substantive` blocker-tag taxonomy (Step 7 `:1335`) — no new tags, no new verdict mechanics.
- **Hollow-pin clause** ("actually asserts the pinned prose … not just an import") reuses Step 4.5's established "actually exercises" bar (`:1280-1282`) so a green-but-empty pin test can't satisfy the row.
- **N/A escape carries no duty** — keeps the reviewer from litigating the escape's reason (that adjudication belongs to the plan-time critics, per c31's docstring).

# ── Step 6 durability-pin shipping duty (#1230) ──────────────────────────────
#
# verify_plan.py c31 verifies a plan NAMES a durability pin; the Step 6
# bullet pinned here is the ONLY surface that verifies the named test

def test_code_reviewer_step6_durability_pin_shipping_duty():
    body = CODE_REVIEWER.read_text()
    m = re.search(
        r"\*\*Durability-pin shipping check.*?(?=\n\s*\n)", body, flags=re.DOTALL
    )
    assert m, (
        "code-reviewer.md Step 6 must carry the **Durability-pin shipping "
        "check** bullet (#1230: c31 checks the pin is NAMED; this duty "
        "checks it SHIPS)"
    )
    step6 = body.index("### Step 6: Plan Deviation Check")

    assert re.search(r"(?i)standing", bullet), bullet
    assert re.search(r"(?i)neither", bullet), bullet
    # Miss classification: substantive plan-adherence finding.
    assert re.search(r"(?i)plan-adherence finding", bullet), bullet
    assert "substantive" in bullet.lower(), bullet
