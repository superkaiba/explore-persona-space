# Plan v1 — #2262: `_extract_scatters` drops genuine (0,0) single-point scatters

`kind: infra` · bug fix in shared library code · 0 GPU-hours.

## Requirement

`paper_plots._extract_scatters` must emit a sidecar `points` row for a genuine
single-point scatter whose lone offset is exactly `(0.0, 0.0)`, while continuing
to skip the placeholder `(1,2) [[0,0]]` offset that non-marker collections
report.

### Acceptance criteria

1. A figure rendering `ax.scatter([0.0], [0.0], s=14)` emits exactly one
   `points` row for that point, with `_kind == "scatter"`, and `total_points`
   counts it.
2. The same holds at matplotlib's default marker size (`ax.scatter([0.0],
   [0.0])`, no `s=`) — the default is a real size, not an absent one.
3. Placeholder-offset collections are STILL skipped and emit no `scatter` row:
   `ax.errorbar` bar `LineCollection`, `ax.fill_between`, `ax.violinplot`, and a
   bare `matplotlib.collections.PathCollection([])`.
4. `_extract_scatters` still never raises: a collection with no `get_sizes`
   attribute, or one whose `get_sizes()` raises, is handled without propagating.
5. `ax.scatter([], [])` (genuinely empty) continues to emit no row.
6. The full existing `tests/test_paper_plots.py`, `tests/test_issue2094_figures.py`
   and `tests/test_issue2225_figures.py` suites stay green (no test currently
   pins the buggy skip — verified at clarifier time).

## Root cause (verified, not assumed)

`_extract_scatters` (`src/explore_persona_space/analysis/paper_plots.py:1082-1084`)
carries:

```python
# A lone (0,0) offset is matplotlib's default for empty collections.
if offsets.shape[0] == 1 and not np.any(offsets):
    continue
```

The comment's stated rationale is **wrong about which case it protects**, and the
guard over-fires. Measured directly against the pinned matplotlib (probe run at
clarifier time; `Agg` backend):

| Artist | `get_offsets()` | `get_sizes()` |
|---|---|---|
| `ax.scatter([0.0],[0.0], s=14)` — **genuine datum** | `(1,2)` `[[0,0]]` | `(1,)` `[14]` |
| `ax.scatter([0.0],[0.0])` — **genuine datum, default s** | `(1,2)` `[[0,0]]` | `(1,)` `[36.0]` |
| `ax.scatter([],[])` — genuinely empty | `(0,2)` | `(1,)` |
| `ax.errorbar(...)` bar `LineCollection` | `(1,2)` `[[0,0]]` | **no `get_sizes`** |
| bare `PathCollection([])` | `(1,2)` `[[0,0]]` | `(0,)` empty |
| `ax.fill_between` / `ax.violinplot` polys | `(1,2)` `[[0,0]]` | `(0,)` empty |

Two facts follow:

* `ax.scatter([], [])` **never reaches** the `(0,0)` guard — its offsets are
  shape `(0,2)` and the preceding `offsets.shape[0] == 0` check already skips
  it. The guard's comment names a case it does not handle.
* The collections that DO reach the guard are non-marker artists reporting a
  placeholder offset. A genuine `scatter` is distinguished from every one of
  them by carrying a **non-empty `sizes` array**.

So the guard's *intent* is right (drop placeholder offsets) but its *test* is
coordinate-based, and it therefore also drops every real `(0,0)` datum produced
by the standard per-point `ax.scatter([x],[y])` companion loop.

### Impact, reproduced

`figures/issue_2162/persona_specificity_ladder/ladder_percarrier.meta.json`
records `total_points=252` / `n_series=252` against **264** rendered
`ax.scatter` calls. The producer
(`scripts/issue2162_ladder_analysis.py::fig_ladder_percarrier:1023`) computes
`x = r_pos[rung] + (k - 1) * 0.18`, so `x == 0.0` exactly only for the middle
arm (`k == 1`) at rung index 0. In that sidecar 12 rows survive at `x == 0.0`
with non-zero `y`, and **zero** rows sit at `(0,0)` — the 12-point gap is
exactly the dropped `(0,0)` data. This corrupts the surface `report-verifier`
recomputes against and nearly produced a spurious FAIL in the #2162 ladder
round.

No second drop path exists: `_xy_rows` maps non-finite coordinates to `None`
and **keeps** the row, so NaN/Inf coordinates account for none of the gap.

## Method delta

Replace the coordinate-based placeholder test with an **artist-property** test,
per the task body's `fix_sketch`, with one correction the sketch did not state:
the `get_sizes()` call must be `getattr`-guarded. `LineCollection` — which
reaches this code on every `errorbar` figure — has **no `get_sizes` attribute at
all**, so a bare `coll.get_sizes()` raises `AttributeError` inside a function
whose documented contract is "Never raises: any artist whose data cannot be read
is skipped".

Rejected alternative: the sketch's parenthetical `or when facecolors are unset`.
Measured `get_facecolor()` shape is `(1,4)` for BOTH a genuine single-point
scatter and an empty scatter, so facecolor does not discriminate. Sizes do.

## File paths + concrete diffs

### 1. `src/explore_persona_space/analysis/paper_plots.py`

Add a module-level helper immediately above `_extract_scatters`:

```python
def _has_marker_sizes(coll: object) -> bool:
    """Return True when ``coll`` is a marker collection carrying explicit sizes.

    ``PathCollection`` (what ``ax.scatter`` creates) exposes ``get_sizes()`` and
    returns one entry per drawn marker — a real size even when the caller passed
    no ``s=`` (matplotlib's default is 36.0). ``LineCollection`` (error bars) has
    no such method at all, and ``fill_between`` / ``violinplot`` / bare
    ``PathCollection`` artists return an EMPTY array. That difference is what
    tells a genuine single ``(0,0)`` scatter point from the placeholder ``(1,2)``
    ``[[0,0]]`` offset those non-marker artists report.

    Never raises: a collection whose sizes cannot be read returns False, so the
    caller falls back to skipping it (the pre-#2262 behavior).
    """
    import numpy as np

    getter = getattr(coll, "get_sizes", None)
    if not callable(getter):
        return False
    try:
        return bool(np.asarray(getter()).size)
    except (TypeError, ValueError, AttributeError):
        return False
```

Then narrow the guard in `_extract_scatters` (replacing lines 1082-1084):

```python
        # Non-marker artists (LineCollection error bars, fill_between / violin
        # polys, an offset-less bare PathCollection) all report a placeholder
        # (1,2) [[0,0]] offset; a genuine ``scatter(...)`` carries a non-empty
        # ``sizes`` array. Discriminate on that instead of on the coordinates,
        # so a real (0,0) datum from a per-point ``ax.scatter([x],[y])`` loop
        # survives. (``ax.scatter([], [])`` never reaches here — its offsets are
        # (0,2) and the shape check above skips it.)
        if offsets.shape[0] == 1 and not np.any(offsets) and not _has_marker_sizes(coll):
            continue
```

Behavior change is confined to one cell of the decision table: a lone-`(0,0)`
collection that DOES carry marker sizes is now kept. Every other input is
byte-unchanged, including multi-point collections (which never reached the
guard).
