### Prose region scanned: the previous-figure-bounded beat-1 window (`_beat1_prose_window`)

New helper next to `_enclosing_h3_prose_window` (which is NOT modified — check 26 keeps its window):

```python
def _beat1_prose_window(rlines: list[str], img_idx: int) -> str | None:
    """The what-is-plotted prose OWNED by the figure at rlines[img_idx]:
    text from the NEAREST preceding boundary — the enclosing `### ` H3, or the
    end of the PREVIOUS inline figure's blockquote caption, whichever is
    nearer — forward to the image line, plus this figure's own caption
    (_figure_caption_after). None when no `### ` H3 precedes the figure
    (no reliably-scoped window; caller skips, mirroring check 26)."""
    boundary = None
    for j in range(img_idx - 1, -1, -1):
        if rlines[j].startswith("### "):
            boundary = j + 1
            break
        if _IMAGE_RE.search(rlines[j]):
            # skip the previous figure's caption blockquote (+ blanks)
            k = j + 1
            while k < img_idx and (rlines[k].strip() == "" or rlines[k].lstrip().startswith(">")):
                k += 1
            boundary = k
            break
    if boundary is None:
        return None
    # An H3 must exist somewhere above (else this figure is outside any
    # `### <result>` block): if the scan hit a previous IMAGE first, an H3
    # is still required above it — check via a second upward scan.
    if not any(rlines[j].startswith("### ") for j in range(img_idx - 1, -1, -1)):
        return None
    before = "\n".join(rlines[boundary:img_idx])
    caption = _figure_caption_after(rlines, img_idx)
    return f"{before}\n{caption}"
```

**Why narrowed (calibration-driven):** with check 26's H3→figure window, a multi-figure `### <result>` H3 bleeds earlier figures' prose into later figures' windows — measured on #778: `bands_monitoring_corrected.png` / `bands_monitoring_manyshot.png` both false-WARNed (3 bolded decimals from prose belonging to the earlier `monitoring_manyshot_scatter` region, matched=0). The previous-figure boundary eliminated both (re-run: 0 WARN corpus-wide).

### What counts as a "bolded numeric"

Scan bold spans, then decimals inside them:

```python
_BOLD_SPAN_RE = re.compile(r"\*\*((?:[^*]|\*(?!\*))+)\*\*")
# decimal REQUIRING a decimal point; optional ascii/unicode sign; optional
# e-notation; optional % marker. Lookbehind blocks word/dot continuation
# ("v1.2"); lookahead blocks trailing word/hyphen/dot continuation
# ("2.5-7B", "3.1.4") — an excluded token merely shrinks the scanned set
# (leniency-safe).
_BOLD_DECIMAL_RE = re.compile(r"(?<![\w.])([-+−]?\d+\.\d+(?:[eE][-+]?\d+)?)(\s*%)?(?![\w.-])")

def _bold_prose_decimals(window: str) -> list[tuple[float, int, bool]]:
    """(value, printed_decimal_places, is_percent) per decimal in a bold span.
    Unicode minus U+2212 normalized to '-'. Integers (no '.') are DELIBERATELY
    not scanned — counts / n's / layer ids are the noisiest class."""
    out = []
    for bm in _BOLD_SPAN_RE.finditer(window):
        for nm in _BOLD_DECIMAL_RE.finditer(bm.group(1)):
            txt = nm.group(1).replace("−", "-")
            v = float(txt)
            if "e" in txt.lower():
                dec = -1  # sci-notation sentinel → relative-tolerance branch
            else:
                dec = len(txt.split(".")[1])
            out.append((v, dec, bool(nm.group(2))))
    return out
```

### Plotted-value extraction (robust across `_kind`s)

```python
def _sidecar_plotted_values(meta: dict) -> list[float]:
    """All finite numeric leaf values from the sidecar's points/rows rows,
    excluding the `_group` series index. Covers every `_kind` uniformly (bar
    heights, scatter/line/errorbar x+y, `error` magnitudes) because the writer
    (`paper_plots._build_sidecar_data`) stores every plotted quantity as a
    numeric row value under an axis-label-derived key; strings (category /
    label / series / _kind) and JSON nulls contribute nothing. Returns [] when
    the sidecar carries no point list — the caller skips. Rows whose sidecar
    was TRUNCATED at _MAX_SIDECAR_ROWS (meta['data_truncated'] truthy) return
    [] too: a matching value may sit past the cap, so matching is unsound."""
    if meta.get("data_truncated") or meta.get("truncated"):
        return []
    pts = meta.get("points")
    if not isinstance(pts, list):
        pts = meta.get("rows")
    if not isinstance(pts, list):
        return []
    vals: list[float] = []
    for p in pts:
        if not isinstance(p, dict):
            continue
        for k, v in p.items():
            if k == "_group" or isinstance(v, bool) or not isinstance(v, (int, float)):
                continue
            vals.append(float(v))
    return vals
```

Bar x-POSITIONS (e.g. `-0.2`, `0.8` in grouped-bar sidecars) are deliberately INCLUDED: including more candidate values only makes matching more lenient (fewer WARNs), the safe direction for a heuristic. Pure-provenance keys never enter: `commit`/`created`/`figsize`/`n_series`/`total_points` are top-level, not point-row values (no `_META_PROVENANCE_KEYS` walk needed here — but the docstring notes the relationship).

### Matching rule (tolerance)

A prose decimal `(v, dec, is_pct)` **matches** the plotted set `P` when ANY candidate `c ∈ {v}` ∪ (`{v/100}` if `is_pct` else `{v/100, v·100}`) satisfies, for some `p ∈ P`:

- **printed-precision half-ulp:** `|p − c| ≤ 0.5·10^(−dec)·scale + 1e-12`, where `scale` = 1 for `c=v`, 0.01 for `c=v/100`, 100 for `c=v·100` (i.e. `p` rounds to the prose value at its printed precision — prose **0.23** matches plotted 0.2312);
- **sign-insensitive twin:** the same test on `||p| − |c||` (prose "**0.30** drop" vs plotted −0.30);
- **sci-notation branch** (`dec == -1`): relative tolerance `|p − c| ≤ 1e-3·|c|`.

Every clause is leniency-increasing (reduces WARNs), so each is FP-containment-safe.

### Firing rule — per-numeric (deliberate divergence from the task-body sketch)

**WARN fires per figure when ≥1 bolded prose decimal matches NO plotted value** (and the window has ≥1 bolded decimal and the sidecar ≥1 finite value). The task body sketched the stricter "WARN when NONE match ANY"; calibration falsifies that sketch on its own motivating incident: the #825 r1 window carried 8 bolded decimals of which **6 matched the r1-era sidecar** (`git show b2c45f639b:figures/issue_825/base_sep_control_hero.meta.json` — plotted set contains 0.588/0.673/0.363/0.349/0.311/0.299 but 0.231 instead of 0.057/0.109), so none-match-any silently passes the exact bug this task exists to catch. Per-numeric catches it (unmatched = {0.057, 0.109}) at a measured **0% false-positive rate** on the entire known-good corpus (11/11 bolded decimals matched across 36 v4 bodies; the two comparable figures — #778 `bands_finetune` 3/3, #825 current `base_sep_control_hero` 8/8 — both pass). The task body says "refine in planning"; this is that refinement, evidence-attached.

### Per-figure opt-out phrase

Literal HTML comment **`<!-- prose-numerics: derived -->`** anywhere in the figure's scanned window BEFORE the image line (i.e. in the beat-1 prose region; HTML comments don't render on the dashboard, matching the sentinel convention). When present, the figure is skipped with a `detail` note (`"1 figure opted out (prose-numerics: derived)"` folded into the PASS line). Use case: a result whose bolded numerics are legitimately derived (a delta between two bars, a ratio, a fitted slope). The WARN message itself names the phrase so authors can self-serve.

### Skip conditions (all silent, check-24 convention)

- No figure section (`section_text` → None) / no inline figures / repo root unresolved (offline, `--body-stdin`) → NO-OP PASS with the standard detail strings.
- Non-same-repo or non-sha-pinned URL → skip figure (`_RAW_GITHUB_FIGURE_RE` + `_THIS_REPO_SLUG` gate, verbatim from checks 24/26/28).
- No `### ` H3 above the figure → skip figure (no scoped window; mirrors check 26).
- Sidecar missing at the sha / unparsable / not a dict → **silent skip** (`_read_figure_meta_json` → None). Deliberately the check-24/28 convention, NOT check 26's loud missing-sidecar FAIL: check 26 fires only on an explicit structural prose claim; check 33's trigger (any bolded decimal) is far broader, so a loud missing-sidecar path would FAIL bodies whose older figures simply predate sidecars.
- Zero bolded decimals in the window, or zero finite plotted values, or `data_truncated` sidecar → skip figure.

### Main check pseudocode

```python
def check_figure_prose_numerics_vs_sidecar(body: str) -> CheckResult:
    label = "figure prose numerics vs figure sidecar (plotted-value drift)"
    section = _figure_scan_section(body)
    text = section_text(body, section)
    if text is None:
        return CheckResult(label, True, f"no `## {section}` section to scan")
    rlines = text.splitlines()
    fig_at = [(url, idx) for idx, line in enumerate(rlines)
              for m in _IMAGE_RE.finditer(line)
              if (url := m.group(1).strip().split(None, 1)[0] if m.group(1).strip() else "")]
    if not fig_at:
        return CheckResult(label, True, "no inline figures to scan")
    repo = _resolve_repo_root()
    if repo is None:
        return CheckResult(label, True, "skipped — repo root unresolved (offline / stdin)")
    warns, scanned, opted_out = [], 0, 0
    json_cache: dict[str, dict | None] = {}
    for url, img_idx in fig_at:
        m = _RAW_GITHUB_FIGURE_RE.match(url)
        if m is None or (m.group("owner").lower(), m.group("repo").lower()) != _THIS_REPO_SLUG:
            continue
        window = _beat1_prose_window(rlines, img_idx)
        if window is None:
            continue
        if "<!-- prose-numerics: derived -->" in window:
            opted_out += 1
            continue
        bolds = _bold_prose_decimals(window)
        if not bolds:
            continue
        if url not in json_cache:
            json_cache[url] = _read_figure_meta_json(repo, m.group("sha"), m.group("path"))
        meta = json_cache[url]
        if meta is None:
            continue  # no sidecar at that sha — check-24 convention, silent skip
        plotted = _sidecar_plotted_values(meta)
        if not plotted:
            continue
        scanned += 1
        unmatched = [(v, dec, pct) for (v, dec, pct) in bolds
                     if not _prose_value_matches(v, dec, pct, plotted)]
        if unmatched:
            basename = m.group("path").rsplit("/", 1)[-1]
            vals = ", ".join(_fmt(v, dec) for v, dec, _ in unmatched[:4])
            warns.append(
                f"`{basename}`: bolded what-is-plotted value(s) {vals} not found among "
                f"the sidecar's {len(plotted)} plotted values (nearest: "
                f"{_nearest(unmatched[0][0], plotted):.4g}) — regenerate the figure or fix "
                f"the prose; if the value is a derived quantity (delta / ratio / CI bound), "
                f"add `<!-- prose-numerics: derived -->` before the figure"
            )
    if warns:
        preview = "; ".join(warns[:3]) + (" …" if len(warns) > 3 else "")
        return CheckResult(label, True,
            f"{len(warns)} prose-vs-plotted mismatch(es) across {scanned} scanned figure(s): {preview}",
            is_warn=True)
    if scanned == 0:
        note = f" ({opted_out} opted out)" if opted_out else ""
        return CheckResult(label, True,
            f"no figure with bolded what-is-plotted decimals AND a value-bearing sidecar{note}")
    return CheckResult(label, True,
        f"{scanned} figure(s): all bolded what-is-plotted decimals present among sidecar values")
```

## Method delta

Check 24 compares the sidecar's RENDERED TEXT (flattened strings — softened tokens, `<a>/<b>` fraction denominators) against body prose; check 26 compares STRUCTURAL claims (plot kind in a panel position, overlays) against the sidecar's `_kind` aggregate. Check 33 is the missing third axis: it compares the NUMERIC VALUES the prose bolds as "what is plotted" against the numeric values the sidecar records as actually plotted — the exact divergence class (#825 r1) that passes both siblings, because the mismatched numbers appear in no sidecar string (24 blind) and change no panel structure (26 blind).
