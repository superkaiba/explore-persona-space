0.0 TL;DR (plain English)

  • What I'll run: I take the activation snapshots Phase 2 already saved (one per trained model, no new training) and assemble the theory's full leakage-prediction formula. Then I check, for each trained behavior, whether that formula correctly ranks which other contexts the behavior leaks into — and I race it against three simpler guesses: a plain cosine-similarity version, "just use the model's own baseline tendency," and "predict nothing." The behavior-direction the formula needs comes from a prior phase's measurement for two behaviors (bad-medical, EM) and from the per-cell install shift for the other two (taught-fact, marker) — so I read each behavior on its own and treat the cross-behavior average with a caveat.
  • What I expect: On the content behaviors (taught-fact, bad-medical) the full formula ranks leakage targets meaningfully better than chance and at least as well as the cosine version. But I expect the model's own baseline tendency to be a stubbornly strong competitor — in three past experiments it beat geometry — so the honest headline is "does our formula beat the base-rate guess after we strip out how strongly the behavior got installed." On the marker behavior I expect the formula to be useless, because Phase 2 showed the marker never actually installed, so there is no real signal to predict.
  • What would change my mind: If the full whitened formula clearly beats both cosine and the base-rate guess on content behaviors even after controlling for install strength, that's a real win for the theory. If instead the base-rate guess wins everywhere, the theory's geometry story doesn't add predictive value on this model — also a clean, publishable answer.

2. Prior Work

The theory under test (docs/leakage_theory_paper.tex): the boxed predictor is L̂_{C,B→C',B'} = η_{C,B} · (r_{B'}ᵀδ_{C,B}) · [c_Cᵀ Σc⁻¹ c_{C'}] / [c_Cᵀ Σc⁻¹ c_C] with δ_{C,B} = t_{C,B} − v_{θ0}(C) (paper boxed L1633). The cosine special-case (L287/L1645): L̂^cos ∝ cos(r_{B'},r_B)·cos(c_C,c_{C'}), exactly L̂ in the limit (i) δ ∥ r_B, (ii) ‖r_{B'}‖/‖c_{C'}‖ constant, (iii) Σc ∝ I — the ONLY allowed differences (C7). η drops out of relative tests and is recoverable from one on-source measurement (L1587-1617). The paper's A3.7 ŵ-shortcut (L224) gives cos(ŵ, r_B) as a displacement-direction read of r_B when no separately-extracted contrastive direction is available — this is what the per-cell r_plus provides for the two behaviors without a #658 diffmeans direction.

What Phase 2 (#664) delivered + says is recoverable: per cell, v_plus/v0, v_plus_probe/v0_probe (probe-split noise floor), c_C_base (= base context vector c0(C'), the key Phase-4 input), c_C_trained, t_CB (= t), r_plus (= implant shift at source), v0_neg, context_ids, meta.json. Scientific caveat: the marker spine NEVER installed (source log P trained−base −0.34 to +1.81 nat; ‖ŵ‖≈1.2 @ L20, ~17-42× below content) — its gate sits at the probe-split noise floor. Content gate SNR co-varies with install magnitude. judged_rates.json NOT produced this round but recomputable from per-cell completions.

What #658 (Phase 1) delivered for r_B (verified by the fact-checker): the #658 diffmeans read-out store r_b.pt (issue658_theory_assumptions/store/r_b.pt, git commit 5bad01d, file sha256 61b1146a…, 3.21 MB) contains r_b['r_b'] keyed by rb_columns == ['broad_em','harmful_compliance','sycophancy','refusal'] — FOUR behaviors ONLY. So a #658 diffmeans direction EXISTS for broad_em (↔ EM) and harmful_compliance (↔ bad-medical), but does NOT exist for fact_expression (taught-fact) or marker. This is the load-bearing coverage fact driving the mixed-r_B design in §4b.

The recurring null (#532/#541/#649): the base-model prior beats geometry for the absolute level; geometry predicts the shift → frame the latent Δs (a shift), always include the base prior, count a geometry win only after the install confound is partialled out. #637: rank-1 generalizes OOS for marker + taught-fact but FAILS for content → report A3.8 rank-one per-behavior.

Published precedent: the latent Δs projection is the activation-space trait-change projection of Persona Vectors (Chen et al., arXiv 2507.21509; the paper cites chen2025 for the Pearson-r comparison). The OpenAI persona-features-control-EM paper (Wang et al., arXiv 2506.19823, Mossing) motivates the leakage-as-conditional-behavior framing. Phase 4 is the first end-to-end test of the boxed whitened-context-gate predictor vs a plain cosine predictor on an open-weights model with full activation access.

4c. Net-new whitened-gate + Σ_c module (TDD-first)

  • Sigma_c(c_vectors, lam) = regularized (Σc+λI)⁻¹, CV-chosen λ over a logspace grid + top-eigendir-truncated variant + conditioning diagnostics.
  • g_C(cC, cCp, Sigma_inv) = cCᵀ Σc⁻¹ cCp / cCᵀ Σc⁻¹ cC (paper A7 L240).
  • (B3) REQUIRED unit test: assert g_C reduces to cos(c_C,c_{C'}) in the Σc=I/equal-norm/δ∥r_B limit, rtol=1e-6. NO Phase-4 number is computed until this PASSes.

4d. Assemble the full predictor L̂

Per cell × every target context × evaluated behavior: L̂ = η · (r_{B'}ᵀ δ) · g_C(C'), δ = t_CB − v0[src_idx] (positive-only; δ^contra a sensitivity arm). r_{B'} per behavior is the §4b mixed source. For relative tests η drops out. Source-anchor context EXCLUDED from the bystander correlation.

4e. Apples-to-apples cosine baseline

L̂^cos ∝ cos(r_{B'},r_B)·cos(c_C,c_{C'}) from the SAME r_B (per-behavior mixed source), c_C, layer 14, recipe — toggling ONLY the three knobs as independent booleans. Also report raw un-whitened cosine gate + predict-zero/predict-mean.

4f. Base-behavior-prior baseline

E0(C',B') = r_{B'}ᵀ v0(C') (the strongest recurring null; r_{B'} per §4b). Reports: (1) partial Spearman ρ(L̂, Δs | E0); (2) ΔS predictive power above prior. Install-strength control: L̂ ρ with ‖ŵ‖ partialled out + leakage-as-fraction-of-install in EOS-margin logit space (never raw log P); never correlated back against install (#383 family).

4g. LOBO + LOCO drivers

LOBO (leave-one-behavior-out) over {marker, bad-medical, EM, taught-fact}; LOCO (leave-one-context-out). φ = per-behavior monotone affine link, TRAIN partition ONLY. Latent-scale tests need no φ.

4h. η recovery

From one on-source measurement per cell, η = Δs_on-source / (r_Bᵀδ). Anchor = bm_default_contra_d1_seed42 (best-of-28 SNR 7.55). η needed only for the cross-source/absolute arm.

4i. Noise-floor estimator

Test-retest ρ between two independent probe-split halves = the floor. MC 200 resamples × 3 RNG seeds. Every headline ρ reported against this floor.

4j. Self-checks (inline)

A3.8 rank-one (σ₁²/Σσ², σ₂/σ₁, cos(u₁,ŵ), residual) with graceful degrade if rank-one fails (expected for content per #637); joint factorization diagnostic on the latent scale.
