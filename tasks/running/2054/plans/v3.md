## 3. Hypothesis

**H1** (narrative prose carries framing cost): story framings' context maps differ from chat/bare-text because the surrounding NARRATIVE PROSE dominates the context vector.
**H2** (answer-boundary form carries framing cost): the maps differ because the ANSWER-BOUNDARY FORM (attribution `X replied:` vs bare label `X:` vs bare paragraph vs indirect reported speech) constrains what appears at the read position, not the prose.
**H3** (templated-vs-diverse dichotomy dominates): the diverse-narrative-prose regime is a single family; the split is DIVERSE (this task) vs TEMPLATED (#1689's low-ceiling cells), not framing-within-diverse.

**Falsification design.** The decoupled scaffold-and-splice pipeline renders EVERY boundary form from the SAME scaffold — narrative prose is held BYTE-IDENTICAL while the boundary varies (bare label / attribution / indirect). Under H1, cross-boundary transfer within one scaffold should be near-perfect (same prose, same v_C context vector). Under H2, cross-boundary transfer should collapse to boundary-invariant components. Under H3, all diverse-scaffold cells cluster tightly together and separately from the #1689 templated cells.

**Kill condition (jointly).** If cross-boundary within-scaffold transfer is worse than cross-scaffold same-boundary transfer for the SAME target cell, the design is uninterpretable — pause and re-scope.

### Both mapping arms (Critical Rule, non-negotiable)

Every cell fits BOTH:
1. **Context arm** — v_C = activation at the last prompt token before the answering character's answer begins; v_A = mean activation over the answer tokens; M' fitted at layer 19 with v_A ≈ M' v_C.
2. **Prefix arm** — v_P = activation at the last prompt token BEFORE the user query; v_A = same. **The parent #1345's prefix arm is degenerate** (context arm reads collapse onto ~14 extraction-batch vectors — `eval_results/issue_1345/prefix_degeneracy_probe.json`). The prefix-arm degeneracy is RE-CHECKED here at the ambient basis, NOT inherited: if the fresh capture at n=6,000 shows the same 14-vector collapse signature, that arm is reported degenerate; if the ambient-basis re-fit resolves it, the read is reported. One-arm results are an explicit stated deviation per the Critical Rule, never a silent default.

## 6. Evaluation

### Measurement validity (per-DV block, planner.md §6 required)

- **DV 1 — headline within-cell ceiling (R²).**
  - Construct: the linear predictability of v_A from v_C at layer 19 in the ambient hidden basis; operationalization of the context-to-answer map's within-cell fidelity for a given (framing, identity, condition, model) cell.
  - Metric: held-out R² of v_A ≈ M' v_C, ambient basis, K=5 conversation-grouped folds; pooled held-out N=5,000; per-fold n_train=4,000, n_val=1,000.
  - On-distribution: YES (on the native token position — last-token pooling at the read position per §5 pooling convention). Group-level held-out folds (conversation ID as the group), fully disjoint from training.
- **DV 2 — identity+learned-bias baseline R².**
  - Construct: the "trivial mapping" floor v̂ = v_C + b (b = train-fold mean of v_A − v_C) — measures how much of the ceiling is explained by a fixed bias shift.
  - Metric: `analysis/mapping_baselines.identity_bias_predict` held-out R². Applicable when d_in = d_out (both mapping arms: yes at hidden size 3,584).
  - On-distribution: YES (same held-out fold as DV 1).
- **DV 3 — kNN retrieval accuracy.**
  - Construct: retrieval-side companion to the R² read — probability that the true v_A lies among the k nearest neighbors of M' v_C in the held-out pool. Dissociates R² from a rotation/scale-only fit.
  - Metric: `analysis/mapping_baselines.knn_retrieval`, k=5, euclidean AND cosine, chance = 5/1000 = 0.005 stated per cell.
  - On-distribution: YES.
- **DV 4 — shuffled-answer matched-capacity null R².**
  - Construct: null distribution for DV 1 under the permutation invariance of v_A within a cell — tests whether the observed R² is above what a same-capacity fit against permuted targets achieves.
  - Metric: 100 permutation draws via `analysis/null_battery.perm_null_draws` (batched — see §9 c12 arithmetic); report null mean + 95% CI + fraction ≥ observed R² as the empirical p-value.
  - On-distribution: YES (target permutation preserves the marginal distribution).
- **DV 5 — 9-rung transfer ladder R² (cross-cell).**
  - Construct: cross-cell operator transferability at 9 pre-specified rungs (identical rungs to parent #1345's `scripts/issue1345_ladder_rungs.py`).
  - Metric: held-out R² per rung, each rung's read normalized against the TARGET cell's own DV 1 ceiling.
  - On-distribution: YES.

Every fitted M' cell reports:
1. **Headline within-cell ceiling** — held-out R² of v_A ≈ M' v_C at layer 19, ambient basis, K=5 conversation-grouped folds — group-level held-out fold (group = conversation id) per parent convention + ood-generalization-folds.md. n_train_per_fold = 4,000; pooled held-out N = 5,000.
2. **Identity+learned-bias baseline R²** — via `analysis/mapping_baselines.identity_bias_predict`. Applicable whenever d_in == d_out (context arm: yes; prefix arm: yes).
3. **kNN retrieval accuracy** — via `analysis/mapping_baselines.knn_retrieval`. Euclidean + cosine, k=5. Chance = 5 / 1000 = 0.005 stated per cell. Reported for BOTH ambient and reduced-basis diagnostics.
4. **Shuffled-answer matched-capacity null R²** — 100 permutation draws, batched via `analysis/null_battery.perm_null_draws`. Report null mean + 95% CI + fraction of nulls > observed as the empirical p-value.

**Cross-cell reads:**
5. **9-rung transfer ladder** — the identical rungs the parent's `scripts/issue1345_ladder_rungs.py` computes. Every rung read against the TARGET's own within-cell ceiling (item 1).
6. **Result 1** — cross-framing operator-alignment within the assistant identity (5 framings row-paired at scaffold level).
7. **Result 2** — cross-character operator-alignment within each story framing (4 characters row-paired at scaffold level).
8. **Cross-boundary within-scaffold vs cross-scaffold same-boundary contrast** — the H1/H2 kill test from §3.
