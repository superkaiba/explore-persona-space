### 4. Design

#### 4.1 Method delta (vs existing checks / rules)

New in this check, relative to `check_upload_as_file` / `check_hub_dir_filecount_guard`:
1. **Write-vs-read discrimination by function identity + dest-argument slot** (not by kwarg name — `path_in_repo=` also appears on `list_repo_tree`, a read).
2. **Issue-token resolution through module constants, f-strings, imports, `or`-fallbacks, and argparse defaults** — a light single-file dataflow, where existing checks resolve only literals/names at the call.
3. **Two-pass wrapper inference** so copied `issue<N>_common.py`-style wrappers (the #928/#1073 pattern) are recognized at their call sites in sibling files.
4. **The fallback-channel distinction:** a *direct* hardcoded own-issue prefix is the sanctioned norm (never flagged); the same token arriving via a *fallback channel* (`or`, argparse `default=`, wrapper-param default) is the #1005 hazard and FAILs.

Why code, not a model call: this is a deterministic, pre-commit-latency structural scan over ~700 files; an LLM call per commit is slower, non-deterministic, and the house lint framework already exists. (Model-call-vs-code decision per code-style rule; rejected alternative documented here.)

#### 4.3 Detection semantics (AST, two passes over `scripts/**/*.py` via `rglob`, reusing `_cached_parse`)

**Base write-function table** (name → dest spec):

| callable | dest kwarg | dest positional |
|---|---|---|
| `upload_file` | `path_in_repo` | — (kwarg-only; disclosed under-trigger) |
| `upload_folder` | `path_in_repo` | — (kwarg-only) |
| `CommitOperationAdd` | `path_in_repo` | — |
| `_upload` | `path_in_repo` | 3 |
| `_upload_folder_filtered` | `path_in_repo` | 3 |
| `upload_raw_completions_to_data_repo` | `experiment_name` | 0 |

Matched on bare name or attribute tail (`api.upload_folder`, `hub._upload`) — same convention as `check_upload_as_file` (:4788-4793). `upload_model` / `upload_dataset` / `upload_dataset_directory` are deliberately OUT of the v1 set (dests derive from runtime config, not hardcoded module constants; adding them later is a one-line table extension — disclosed).

**Pass 1 — wrapper inference (repo-wide over scripts/):** for every `FunctionDef` whose body calls a base write fn with a dest expression that is (or f-string-contains) a bare `Name` bound to one of the wrapper's parameters → record `wrapper_name → (dest_param_name, dest_param_index)`. One level only (wrapper-of-wrapper: disclosed under-trigger). Additionally record a **wrapper-fallback finding** at the def line when the dest param carries a signature default resolving to an issue token, or the body computes `<dest_param> or <token-expr>` feeding the write call. Wrappers keyed by bare name (imports are `from issue928_common import upload_folder_scoped_verify`); a name collision unions the dest specs.

**Pass 2 — per file:**
1. Own issue number `N` from the basename regex `^issue(\d+)_`; a `scripts/**/*.py` not matching is SKIPPED entirely (disclosed scope: the incident class is reused issue scripts; generic entrypoints derive prefixes from config).
2. **Module const map** `NAME → {tokens}`: module-level `Assign`/`AnnAssign` whose value is a str `Constant`, `JoinedStr`, str `BinOp`, or a `Call` (e.g. `os.environ.get("X", "issue958_multiturn")`) — tokens = all `\bissue(\d+)[_/]` matches over every string literal in the value expr, plus tokens of any `Name` already in the map (transitive, handles `DECOMP_TENSORS_PREFIX = f"{HF_PREFIX_928}/analysis_tensors/decomp"`).
3. **Import map:** `from issue<M>_mod import A, B` / `import issue<M>_mod` → imported names carry token `M` (module-name proxy for constants whose values live cross-file).
4. **Argparse map:** `.add_argument` calls → dest = explicit `dest=` kwarg else longest `--opt` option string with `-`→`_`; record `dest → {tokens}` for a `default=` expr resolving (via 2/3) to ≥1 token.
5. **Dest resolution** at each write call (base fn or inferred wrapper): resolve the dest expression to a set of `(token, via)`:
   - str `Constant` / `JoinedStr` → tokens, `via=direct`;
   - `Name` → const-map / import-map tokens, `via=direct`; when the name resolves in NEITHER map, resolve FUNCTION-LOCAL assignments to that name within the enclosing function (nearest preceding `Assign`/`AnnAssign` — value resolved by this same resolver, so a local `path_in_repo = f"{args.hf_prefix}/…"` picks up the argparse-default tokens with `via=argparse-default`; the §4.6 row-8 / issue1092 shape, consistency-checker finding 4);
   - `BoolOp(Or)` → first leg resolved normally; tokens from legs 2..n get `via=or-fallback`;
   - `IfExp` → both branches; when the test expression equals the body branch (`X if X else CONST` — the ternary spelling of an or-fallback), else-branch tokens get `via=or-fallback`; otherwise via preserved;
   - `Attribute(.attr)` with `attr` in the argparse map → its default tokens, `via=argparse-default` (receiver name unchecked — `args.` by convention; disclosed approximation, waiver escape available);
   - unresolvable expr → no tokens (silent — a dynamic dest is un-lintable statically; disclosed).
6. **Flag policy** (each finding carries file:lineno + the offending token + via):
   - **Rule A (cross-issue):** any `(M, *)` with `M != N` → FAIL: "cross-issue upload destination `issue<M>_…` in `issue<N>_` script — a reused/copied uploader writing into another issue's prefix is the #1005 parent-clobber class".
   - **Rule B (hardcoded fallback):** `(M == N, via ∈ {or-fallback, argparse-default})`, plus pass-1 wrapper-fallback findings → FAIL: "hardcoded issue-prefix fallback at an upload destination — silently inherited when a child issue reuses this script (#1005). Use `default=None` + a fail-loud requirement (raise when uploading without an explicit prefix), or waive."
   - `(M == N, via=direct)` → NOT flagged (sanctioned own-prefix hardcode — keeps ~100 issue scripts green).
7. **Waiver:** `# UPLOAD_PREFIX_EXEMPT: <reason ≥ 10 chars>` on the finding's first physical line or immediately preceding non-blank line (identical convention + helper shape as `_upload_as_file_waiver_present`, :4818 / :4845-4863). For argparse-default findings the waiver sits at the `add_argument` call. Token name verified collision-free (repo grep: 0 hits).
8. **Grandfather allowlist:** `UPLOAD_PREFIX_CLOBBER_ALLOWLIST: frozenset[str]` of repo-relative paths with an inline reason comment per entry (JUDGE_PIN style, :1987). Every entry's inline reason MUST state that the file remains a live #1005 runtime-reuse channel until fixed ("fixing to `default=None` + raise retires this entry") — the grandfather is a no-red compromise, never a sanction. Covers **Rule-B findings only**; a Rule-A finding is never silently allowlisted — at implementation a discovered Rule-A hit is investigated: deliberate → waiver comment with reason; latent bug → fixed or reported in the implementer report. Function takes `legacy_allowlist` override for tests (`check_hub_dir_filecount_guard` precedent).

#### 4.4 Pseudocode

```python
def check_upload_prefix_clobber(*, scripts_dir=None, legacy_allowlist=None) -> list[str]:
    root = scripts_dir or _REPO_ROOT / "scripts"
    allow = UPLOAD_PREFIX_CLOBBER_ALLOWLIST if legacy_allowlist is None else legacy_allowlist
    files = [p for p in sorted(root.rglob("*.py")) if p.is_file()]
    wrappers, wrapper_fallback_findings = _upc_collect_wrappers(files)  # pass 1
    errors = []
    for py in files:
        m = re.match(r"^issue(\d+)_", py.name)
        if not m:
            continue
        own = m.group(1)
        tree = _cached_parse(py, text := py.read_text(encoding="utf-8"))
        if tree is None:
            continue
        consts = _upc_module_const_tokens(tree)          # step 2 (transitive)
        imports = _upc_import_tokens(tree)               # step 3
        argdefs = _upc_argparse_default_tokens(tree, consts, imports)  # step 4
        lines = text.splitlines()
        for call, dest_expr in _upc_write_call_dests(tree, wrappers):  # base fns + wrappers
            for token, via in _upc_resolve(dest_expr, consts, imports, argdefs):
                rule = ("A" if token != own else
                        "B" if via in ("or-fallback", "argparse-default") else None)
                if rule is None:
                    continue
                if _upc_waiver_present(lines, finding_lineno) or (
                    _relpath(py) in allow and rule == "B"
                ):
                    continue
                errors.append(f"{py}:{lineno}: {RULE_MESSAGES[rule].format(...)}")
    errors.extend(_filter_waived_allowed(wrapper_fallback_findings, allow))  # rule B class
    return errors
```
