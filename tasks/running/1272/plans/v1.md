**Friction weighing (the Goal's explicit ask):** the marginal cost per filing is ~one line recording a grep the filer is ALREADY required to run; the `n/a` escape bounds the cost for non-grep-able behavioral gaps. The benefit is preventing a full spawned-session verification cycle per stale filing (3 in the 2-day incident window; each spawn is a ~100K-token cold context + planner round). Net clearly positive. The miner's route-3 concern (friction) is addressed by (a) the escape hatch and (b) NOT adding any mechanical enforcement — the line is compose-time prose, no lint, no injector, no script gate.
