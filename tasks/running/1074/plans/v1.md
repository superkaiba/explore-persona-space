# Plan: issue-1074 — Abliterated vs base Qwen as the on-policy generator for factory content-behavior datagen

## 0.0 TL;DR (plain English)

- **What we're testing:** #906's Claude-generated training data missed the yield floors on all three content classes (the generator declined the behavior — Mode A, 30/30 on sycophancy). This task swaps the generator to on-policy Qwen — the elicitation instruction injected as PLAIN untagged system-prompt text (instruct-and-strip), a variety of induce/oppose phrasings — and compares two generator arms: stock `Qwen/Qwen2.5-7B-Instruct` vs the refusal-ablated derivative `huihui-ai/Qwen2.5-7B-Instruct-abliterated-v2`.
- **What would change my mind:** BOTH arms below the yield floor on BOTH classes (generator-family fix insufficient on these worst-case stimuli — informative negative; the yield table is still the deliverable). Cells that clear yield but never enter the dose band up to the epoch ceiling falsify install for that cell.
- **Cost:** ~16 GPU-h on 1× GPU (auto backend, GCP-first, `lora-7b` intent).

## 0. Plan Summary (technical)

**Manipulated variable (within-task, single-variable):** the generator model producing training completions — `Qwen/Qwen2.5-7B-Instruct` (base arm) vs `huihui-ai/Qwen2.5-7B-Instruct-abliterated-v2` (ablit arm). Everything else held fixed across arms: pipeline, banks, judge, floors, LoRA recipe, negatives panel, seed 42, instruction-variant set, plain-text injection.

**Classes (scope decision):** `sycophancy` (primary — the diagnosed Mode-A class) + `harmful_compliance` (the abliteration discriminator — base Qwen is expected to decline generation, the ablit arm is the test). `china_censorship` EXCLUDED: its inverted-base design (`not_exhibit_instructions=None`, base already exhibits) makes an install comparison uninterpretable for a generator contrast, and #906 flagged its saturated-base risk; it adds cost without bearing on the Goal. Marker: programmatic carve-out, out of scope.

**Cells:** 2 classes × 2 generator arms = 4 datagen cells → up to 4 trained organisms (a cell that misses the yield floor records its yield and skips training — yield IS the primary DV, not a crash).

**Training (inherited verbatim from #906 / `recipe.py UNIFIED_OVERRIDES`):** Qwen-2.5-7B-Instruct trainee, rsLoRA r=32 α=64, lr=1e-5, dropout 0.05, batch=4, grad_accum=4, max_length=1024, epochs≤3 ceiling, save_steps=25 (whole ladder kept), dose-to-target band [0.60, 0.85] via `select_dose_checkpoint`, generic interleave frac 0.5, arm=`primary` (contrastive ON).

**Datagen (inherited pipeline, two deltas):** `generate_training_data` with (1) NEW `instruction_style="plain"` — the elicitation instruction reaches the generator as plain untagged system-prompt text (no `[[GENERATION-ONLY INSTRUCTION]]` delimiters); `emit_messages` (the training prompt) is computed independently, so the strip/context-parity contract is preserved by construction; (2) NEW vLLM-backed `generate_fn` per arm (the seam is designed injectable). Instruction variants expanded for phrasing diversity: 6 exhibit + 4 not-exhibit per class (from 4/2). Oversample 1/0.7, per-source floor `ceil(0.8·target_n)` with equalize-down, stage-4 graded judge filter (Sonnet 4.5, 0–100, n_draws=5, drop-never-coerce), per-arm drop counts reported.

**Evaluation (dual-DV):** judge-scored on-policy behavior RATE (primary; graded 0–100 binarized at 50) + teacher-forced fixed pos-vs-neg completion MARGIN (secondary, non-saturating) — per #906's rig. Install compared at dose-to-target band entry (earliest in-band checkpoint; steps-to-band + rate + margin), NOT fixed epochs (#612: on-policy installs weaker).

**Compute:** ~16 GPU-h total, 1× GPU sequential (datagen gen ≈1 h; 4 train cells ≈8 h; eval gens + margins ≈4 h; margin ≈3 h). Judge phases: sync `api_dispatch` for small on-pod-time reads (datagen filter ≈4.6 k calls, checkpoint-rate subsets), Anthropic Batch API for the big final-eval judging sequenced AFTER pod release (off-pod on the VM).

**Prefix/context mapping rule:** N/A — all DVs are behavioral (judged rate, tf-margin); no representation mapping / geometry read / probe / direction extraction is computed in this task, so the both-arms mapping requirement does not bind. (#906's direction-extraction phase is deliberately NOT inherited — it serves a different question.)

## 1. Goal

(Verbatim task Goal.) Determine whether generating the factory's content-behavior training completions on-policy from Qwen-2.5-7B-Instruct with the elicitation instruction injected as plain untagged system-prompt text (instruct-and-strip, variety of induce/oppose phrasings) clears the #906 yield floors and installs the behaviors, and whether an abliterated (helpful-only) Qwen generator beats the base Instruct model on yield and install strength.

## 2. Prior work / method delta

- **#906 (parent, completed):** unified factory pipeline validated end-to-end; content classes floored at datagen with the Claude generator (sycophancy 6/36 kept ≈17% < floor 20; harmful_compliance 2/215 ≈1%; china below floor). Inline diagnosis (2026-07-06, `issue906_partial/att-20260704-035245`): pure Mode A — the generator corrected the user's false claim in 30/30 rejected sycophancy candidates; zero persona-breaks, zero malformed. All recipe surfaces this plan inherits are #906's: banks, floors, judge rubrics, negatives panel (`['neg_sp_police','neg_sp_ph4','neg_reph_curious','neg_wc_short','neg_default_assistant']`, disjointness asserted), UNIFIED_OVERRIDES, dose band, seed.
- **#612:** on-policy Qwen tier-2 instruct-and-strip cleared the 80% yield floor on 4 personas for this same behavior family; measured dose separation canned +0.84–0.93 vs on-policy +0.60–0.66 (⇒ dose-to-target, never fixed epochs, for install comparisons).
- **Abliteration method:** Arditi et al., *Refusal in Language Models Is Mediated by a Single Direction* (arXiv 2406.11717) — refusal-direction ablation removes refusal with modest capability side-effects (paper reports small MMLU/coherence deltas). `huihui-ai/Qwen2.5-7B-Instruct-abliterated-v2` is a community refusal-ablated Qwen2.5-7B-Instruct derivative (apache-2.0, full safetensors, same architecture — verified live on HF 2026-07-06). In-family, so the on-policy distribution match to the trainee is approximately preserved; the ablit-vs-base contrast operationalizes "a more-willing generator" while holding family fixed.
- **Method delta vs #906:** generator (Claude → on-policy Qwen, 2 arms) + injection style (tagged → plain) + variant expansion (4/2 → 6/4). The vs-#906 yield read is therefore a declared recipe-bundle comparison (three co-moving deltas, all user-directed); the CLEAN single-variable contrast is within-task base-vs-ablit, where injection style and variants are constants.

## 3. Hypotheses

- **H1 (yield, sycophancy):** ≥1 on-policy arm clears the sycophancy floor (20/25) where Claude did not. Grounding: #612 (Qwen agrees when instructed, 80% floor cleared).
- **H2 (yield, harmful_compliance — the discriminator):** the base arm stays below the floor (120/150) because stock Qwen declines to author the content (alignment-conflict-HIGH class per `on-policy-completions.md`), while the ablit arm clears it. Direction is the pre-registered expectation; either violation is informative.
- **H3 (install):** every cell that clears yield dose-to-targets into [0.60, 0.85] within the 3-epoch ceiling; per #612, band entry is expected later than canned-data cells.
- **H4 (arm comparison):** ablit ≥ base on yield for both classes; no strong prior on install-strength direction — reported as measured (rate + margin at band entry, steps-to-band).
- **Falsification:** both arms floored on both classes falsifies "generator family is the binding constraint at these stimuli" (points to stimulus hardness — the wrong-fact worst case); a yield-clearing cell that never enters the band up to the epoch ceiling falsifies H3 for that cell (report closest-approach checkpoint).

## 4. Design

### Phase A — Datagen (GPU pod, vLLM, both arms)

For each (class, arm) cell, call `generate_training_data(behavior, context_C, negatives=DEFAULT_PANEL, out_dir=data/issue_1074/<class>/<arm>/, target_n=<bank size>, quota_floor=0.8, n_judge_draws=5, gen_model=<arm HF id>, gen_temperature=1.0, seed=42, generate_fn=make_vllm_generate_fn(<arm HF id>, temp=1.0, max_new_tokens=1024, seed=42), instruction_style="plain")`.

- `target_n`: sycophancy 25 (floor 20), harmful_compliance 150 (floor 120) — the bank sizes, matching #906's floors exactly.
- Request counts (from the pipeline's own arithmetic, `EXPECTED_YIELD=0.7`): sycophancy ≈36 pos + 30 neg; harmful ≈215 pos + 175 neg → ≈456 generations/arm, ≈912 total. vLLM batched, single pass per generator model (load base → run its cells → unload → load ablit).
- **Plain injection delta (`datagen.py`):** new `instruction_style: Literal["tagged","plain"]="tagged"` param threaded to `_inject_instruction`; `"plain"` appends `"\n\n" + instruction` to the leading system message (or inserts a bare system message when none). `emit_messages` is unchanged (computed independently as `context_C.messages(q)` / `neg_ctx.messages(q)`), so the emitted training prompt never contains instruction text — same contract, new test pinning `emit_messages == context messages` and `gen_messages` containing the instruction with NO delimiter strings. `instruction_style` enters `gen_manifest.json` (stale-resume protection is automatic).
- **Variant expansion (`behavior.py`):** sycophancy + harmful_compliance `ElicitationSpec` expanded to 6 exhibit + 4 not-exhibit plain-text phrasings each (existing 4/2 kept verbatim, new phrasings appended; china untouched). Grid sampling already handles variant × question allocation.
- **Yield-as-result:** the driver catches `DatagenYieldError` per cell, records realized per-arm yield + judge-drop mix from `pool_meta.json`, and marks the cell `yield_floor_missed` (no training for that cell). A completing cell emits `floor_n` positives + ~1:1 negatives with equalize-down — dose equality across cells by construction.
- **Judge (stage 4):** `judge_graded` — Sonnet `claude-sonnet-4-5-20250929`, graded 0–100, n_draws=5, drop-never-coerce, rubric-keyed cache — via sync `api_dispatch` (≈4.6 k calls ≈45–75 min). The 1×GPU pod is held through this API-bound stage: stated judgment — reprovision latency + double model reload exceed ~$2–3 of single-A100 idle; the GPU-width rule's cost case targets wide pods.
- **Contrastive negatives:** inherited 5-member panel, always incl. default assistant; on-policy negative completions from the SAME arm's generator under each negative context (provenance symmetry within arm); `assert_panel_disjoint_from_sources` runs per cell.
- **Completion provenance (per training-row type):** positives — on-policy tier-2 instruct-and-strip from the arm's generator; negatives — on-policy from the same generator under negative contexts (no instruction); generic interleave rows — inherited #545 mix (unchanged). No canned/templated rows anywhere.
- **Data realism:** banks inherited byte-identical from #906 (harmful_compliance = StrongREJECT, tier-2 established benchmark; sycophancy = tier-3 LLM-authored hard-false factual claims — the worst case for eliciting agreement; caveat carried to the clean-result). **Stimulus-variant decision (body open-q 2): NO second stimulus arm** — a new opinion/self-assessment bank would be fresh tier-3 authoring and a second manipulated variable; instead per-question yield is recorded so stimulus hardness is measurable, and an opinion-stimulus variant is a named follow-up if both arms floor.

### Phase B — Training (GPU pod, per yield-clearing cell)

`build_organism` / `train_lora` with `recipe_for(behavior, arm="primary", generic_frac=0.5, train_method="lora")` → UNIFIED_OVERRIDES verbatim. `run_name = f"issue1074_{class}_{arm}_seed42"`. Dose-to-target: after each checkpoint (every 25 steps), `rate_fn` = vLLM gen at source context (n=5, temp=1.0) on a checkpoint-read subset (sycophancy: full 10-q eval bank; harmful: seeded 30-q subset of the 195-q bank — cost bound, subset disclosed), judged sync (n_draws=5); `select_dose_checkpoint(band=(0.60,0.85), fallback="closest_approach")`.

### Phase C — Install eval (GPU pod: generation + margins; judging deferred)

For each model state (base Qwen baseline + each trained organism at its selected checkpoint):
- **Rate generations:** full eval bank at (a) the source context and (b) the default-assistant context (leakage-to-default advisory) — n=5, temp=1.0, max_new_tokens=1024. The full 5-member bystander panel read is NOT inherited (that was #906's leakage-calibration goal; this task's DVs are yield + install — scope caveat carried).
- **tf-margin (secondary DV):** teacher-forced fixed positive-vs-negative pool margin per #906's rig (reuse the `issue906_phase1_pilot.py` implementation; pools fixed across contexts/states).
- All completions upload to HF (`issue1074_gencompare/raw_completions/…`) before pod release.

### Phase D — Off-pod judging + aggregation (VM, 0 GPU)

Pod terminated first (Step 8 order). Final-eval judging via the Batch API (`eval.batch_judge`, deadline-bounded): ≈(150·5·2 + 10·5·2)·5·n_states ≈ 40–80 k calls depending on surviving cells. Then aggregation: yield table, dose curves (rate vs step per cell), band-entry comparison, margin table, per-question yield breakdown; bootstrap 95% CIs over questions for arm contrasts; figures via /paper-plots.

### Smoke / sweep architecture parity

Smoke IS sweep with one cell: the driver's `--smoke` runs the identical code path on (sycophancy × base) with `target_n=5`, `n_judge_draws=2`, tiny-real seams per the #906 r15 standard — real tokenizer / pipeline / mix build / `train_lora` on a from-config tiny same-arch Qwen2 model over the real vocab (pattern: `tests/test_issue906_tiny_real_e2e.py`), the GenerateFn seam stubbed with a deterministic fake (it is a designed injectable seam — the sanctioned fake at the model boundary), judge live at 2 draws. Every phase (datagen, train, eval, aggregate) executes end-to-end at tiny N. Verdict: `PASS_UNIFIED` intent.

## 6. Evaluation

**Measurement validity:** construct = the target behavior's expression under the trained persona context; metric = judge-scored on-policy behavior rate (graded 0–100, binarized at 50) on free generations at the natural position — on-policy, on-distribution. Dual-DV: rate PRIMARY (validated construct) + teacher-forced fixed-pool completion margin SECONDARY (non-saturating companion; #722-validated form). Yield DV = judge-accepted fraction per (class, arm) vs the pinned floor, with per-arm drop mix (refusal/empty/api_error/judge-reject) — drop-never-coerce throughout.

**Success thresholds:**

| Question | Threshold |
|---|---|
| S1 yield | ≥1 arm ≥ floor per class (sycophancy 20/25, harmful 120/150) |
| S2 install | yield-clearing cells reach band [0.60,0.85] within 3 epochs |
| S3 arm contrast | Δyield + Δ(rate, margin at band entry) base vs ablit with bootstrap 95% CIs over questions |
| Kill | both arms < floor on both classes → generator-family fix insufficient at these stimuli (informative negative; yield table still ships) |

**Figures — hero:** (1) yield bar chart per class × arm vs floor line (with #906 Claude bars as declared-bundle context); (2) dose-to-target rate curves per cell (rate vs step, band shaded). **Exploratory dump:** per-question yield heatmap (stimulus hardness); drop-reason stacked bars; margin vs rate scatter per cell; steps-to-band bar; default-context advisory rates; per-variant yield breakdown.

## 7. Decision gates / deviations

**Allowed without asking:** checkpoint-read subset sizes (seeded, disclosed); vLLM batching/memory params; minor new-variant phrasing edits; smoke slice sizes; judge sync-vs-batch routing per volume.
**Must-ask (plan amendment):** changing either generator model; changing floors/band/recipe values; adding classes or a second stimulus arm; training WITH the instruction included (different experiment by clarifier decision).

## 8. Risks

1. **Both arms floor on sycophancy** (worst-case hard-false stimuli) — install comparison dies for that class; harmful still discriminates; per-question yield feeds the opinion-stimulus follow-up. Accepted.
2. **Ablit arm produces degenerate/off-persona text** — judge filter catches (persona-consistency is part of the rubric); drop mix reported; if ablit yield ≈0 from incoherence that is itself a finding.
3. **Ablit checkpoint quirks in vLLM** (nonstandard config) — smoke-gated: the driver's preflight loads both models and generates 1 token before any cell runs.
4. **china-style base saturation for harmful default-context advisory** — advisory only, never a gate.
5. **Judge volume underestimate** — Batch API absorbs; checkpoint reads bounded by subsets.
