## 1. Goal

When a GCP rung exhausts A100-80 capacity, `GcpBackend.launch` already fans out across every valid `us-central1` zone for the resolved machine type and only declares a capacity miss after *all* of them fail (the `for…else` at `gcp.py:3400-3487`). The defect #763 surfaced is purely observational: the `GcpProvisioningError` raised after the loop carries only the LAST zone's stderr (`classify_create_failure` overwrites `last_error` each iteration, and `evidence["stderr_tail"]` holds just that final zone's text). So #763's `epm:backend-selected` marker showed a single `ZONE_RESOURCE_POOL_EXHAUSTED` from `us-central1-c`, making it impossible to tell whether the loop tried `us-central1-a` first or jumped straight to `-c`. This task makes the launcher record EVERY zone it attempted, in order, with that zone's outcome, so a reader of the marker can verify the full fan-out actually happened. It also documents the zone-fanout policy in the failover rule.

## 4. Design

### (A) `gcp.py` — record per-zone outcomes in the fan-out loop

The loop at `gcp.py:3398-3487` already iterates `zones_to_try` and only raises (via `for…else`) after all zones fail. The single change: accumulate a per-zone outcome list across iterations and attach it to whatever `GcpProvisioningError` is finally raised.

**Shape of the diff** (additive only — every existing field of `last_error.evidence` is untouched):

```python
last_error: GcpProvisioningError | None = None
zone_attempts: list[dict[str, Any]] = []   # NEW

for zone in zones_to_try:
    ...
    try:
        result = self._run(argv)
    except subprocess.TimeoutExpired as exc:
        live = self._reconnect_probe_after_create_timeout(spec, exc)
        if live is not None:
            raise GcpCreateTimedOutStillProvisioning(...) from exc
        last_error = GcpProvisioningError("create_timeout_no_instance", evidence={...})
        zone_attempts.append({"zone": zone, "outcome": "create_timeout_no_instance",
                              "detail": "create timed out; no server-side instance"})
        continue
    if result.returncode == 0:
        zone_attempts.append({"zone": zone, "outcome": "created"})
        break
    last_error = classify_create_failure(returncode=result.returncode, stderr=result.stderr)
    zone_attempts.append({
        "zone": zone,
        "outcome": "capacity_miss" if _is_capacity_miss(last_error) else "non_capacity_failure",
        "matched_pattern": last_error.evidence.get("matched_pattern"),
        "stderr_tail": (result.stderr or "")[-_ZONE_STDERR_CAP:],
    })
    matched = (last_error.evidence.get("matched_pattern") or "").lower()
    if not any(tag in matched for tag in ("exhaust", "resource", "enough resources")):
        last_error.evidence.setdefault("zone_attempts", zone_attempts)
        raise last_error
    logger.warning("GCP create capacity miss in zone=%s; trying next fallback. reason=%s",
                   zone, last_error.reason)
else:
    assert last_error is not None
    last_error.evidence.setdefault("zone_attempts", zone_attempts)
    raise last_error
```

Details:
- **New module constant** `_ZONE_STDERR_CAP = 500` near the other launch constants — per-zone stderr is truncated to ~500 chars so the accumulated structure cannot blow the 50,000-char marker note cap (full quantification in §8).
- **Attach at BOTH raise sites:** the early `raise last_error` (non-capacity failure mid-loop) and the `for…else` final raise. Use `evidence.setdefault("zone_attempts", …)` so we never clobber.
- **The capacity-vs-non-capacity classification** for the per-zone `outcome` reuses the same `("exhaust","resource","enough resources")` substring test the loop already uses; factor it into a tiny local helper `_is_capacity_miss(err)` to avoid drift.
- **Backward-compat invariant:** `zone_attempts` is purely additive. `evidence["returncode"]`, `evidence["stderr_tail"]`, `evidence["matched_pattern"]` are all untouched.

### (A2) `router.py` — surface `zone_attempts` in the marker detail

`router._provisioning_detail(exc)` (`router.py:1780-1796`) is the single chokepoint that turns a `GcpProvisioningError` into the `RouteAttempt.detail` string. Append a compact one-line zone summary:

```python
def _provisioning_detail(exc: GcpProvisioningError) -> str:
    tail = str(exc.evidence.get("stderr_tail") or "").strip()
    parts = []
    zone_attempts = exc.evidence.get("zone_attempts")
    if zone_attempts:
        zsummary = ", ".join(
            f"{za.get('zone')}={za.get('outcome')}" for za in zone_attempts
        )
        parts.append(f"zones_tried: [{zsummary}]")
    if tail:
        parts.append(f"stderr_tail: {tail[-1024:]}")
    return "; ".join([exc.reason, *parts]) if parts else exc.reason
```

This yields a marker `detail` like `gcloud create returned 1; …; zones_tried: [us-central1-a=capacity_miss, us-central1-c=capacity_miss]; stderr_tail: …`.

**Note on scope:** `router.py` (`backends/*.py`) is explicitly in the workflow surface. `_attempt_to_dict` serializes only `RouteAttempt` fields, so `zone_attempts` reaches the marker through the `detail` string built by `_provisioning_detail` — no `dispatch_issue.py` change needed.

```python
def test_zone_fanout_records_every_zone_attempted(no_marker_posts):
    exhausted = GcloudRunResult(1, "", "ERROR: ... ZONE_RESOURCE_POOL_EXHAUSTED ...")
    runner = _Runner(
        list_results=[GcloudRunResult(0, "[]", ""), GcloudRunResult(0, "[]", "")],
        create_results=[exhausted, exhausted],
    )
    backend = GcpBackend(config=_test_config(), runner=runner, marker_poster=lambda **_: None)
    with pytest.raises(GcpProvisioningError) as excinfo:
        backend.launch(_spec(intent="lora-7b"))
    create_calls = [c for c in runner.calls if "create" in c and "instances" in c]
    assert len(create_calls) == 2
    za = excinfo.value.evidence["zone_attempts"]
    assert [z["zone"] for z in za] == ["us-central1-a", "us-central1-c"]
    assert all(z["outcome"] == "capacity_miss" for z in za)
```

**(ii) Unfiltered family (N=3 → [a, b, c]):**
```python
def test_zone_fanout_unfiltered_machine_type_tries_all_three(no_marker_posts):

        list_results=[GcloudRunResult(0, "[]", ""), GcloudRunResult(0, "[]", "")],
```
