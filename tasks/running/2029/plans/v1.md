```
check_edited_literal_pin_tests(plan, kind) -> CheckResult
cid = "c50_edited_literal_pin_tests"
name = "edited workflow-surface literal pin-test coverage"

GATE 0 (kind): kind not in ("infra", "batch") -> SKIP "kind-exempt" (c31 scope).
GATE 1 (trigger): >=1 non-fenced, non-negated line carrying a workflow-surface
  path token (_C50_PATH_RE: .claude/(skills|agents|rules|hooks)/...,
  <dir>/SKILL.md, bare SKILL.md, CLAUDE.md, .claude/workflow.yaml) with an
  edit verb (_C50_EDIT_RE = c31 verb set + widen/swap/replac/updat/teach +
  "new ... pattern") within +/-120 chars; c31's negation guard reused as
  _C50_NEG_RE (c31's own regexes are NOT touched — its calibration comment
  mandates a corpus re-scan on any change). No trigger -> SKIP.
ESCAPE: _standalone_na_declared(plan, r"no workflow-?surface literal edits")
  -> PASS "explicit N/A declared" (checked after the trigger, the c30 order).
OFF-REPO GUARD: surface dirs or tests/ absent under _C50_REPO_ROOT
  -> loud SKIP (the c46 --plan-file degradation precedent).
EXTRACTION (per markdown paragraph = blank-line-delimited non-fenced run,
  plus one fenced block opening within 3 lines after it):
  - paragraph admitted iff it carries a surface path token AND
    (_C50_EDIT_RE OR _C50_REMOVAL_RE) — the removal tier
    (legacy|old|removed|dropped|no longer|neither|banned|retired|deprecated|
    obsolete|stale) is REQUIRED for recall: the #1948 old literal is quoted
    only in a "neither carries the bare legacy X" paragraph (§6 trace).
  - candidate classes: line-class (stripped fenced lines >= 12 chars),
    token-class (single-token inline-code spans, quoted spans, and the final
    path component of slash-bearing whitespace tokens — tests pin basenames
    while plans quote /tmp/-prefixed forms, the #1948 shape),
    span-class (multi-token inline/quoted spans, capped at 10 per plan).
  - drops: glob-shaped (*); CLI flags (^--[\w=-]+$); bare code identifiers
    (^[A-Za-z_][\w.]*$ — pinned via their code file, not the prose);
    repo-file basenames; candidates resolving to an existing repo path
    (file REFERENCES, not literals); >180 chars or embedded newline.
ANCHOR (cheap-first): union structures over the workflow-surface corpus
  (stripped-line set for line-class, token+tail set for token-class,
  offset-indexed concat substring for span-class), then verify the candidate
  appears verbatim in >=1 file resolved from ITS OWN paragraph's path tokens
  (bare SKILL.md resolves to all .claude/skills/*/SKILL.md).
RARITY: candidate in > 2 distinct surface files -> boilerplate, drop
  (early-exit distinct-file counting over the indexed concat);
  candidate in > 3 distinct tests/**/*.py files -> vocabulary, drop.
OFFENDER: for each surviving (candidate, pinning tests file):
  - satisfier: the test file's basename appears anywhere in the raw plan
    (the c31 RAW-scan convention) -> not an offender;
  - the pinning line must carry a quote char (pinned in test CODE, not
    cited in a comment/docstring);
  - the test file's text must contain a workflow-surface marker
    ("SKILL.md", ".claude/skills|agents|rules|hooks", "CLAUDE.md",
    "workflow.yaml") — a code test that never reads the surface cannot
    break from a prose edit.
VERDICT: offenders -> ONE WARN, detail listing up to 3
  "tests/<file> (pins literal '<c[:60]>')" + "(+N more)" + remedy: add each
  file to the plan's edit-target/File-paths list, or declare
  `N/A — no workflow-surface literal edits` on its own line (incident
  #1948; this check #2029). NEVER FAILs (the c14/c47 doctrine line goes in
  the check docstring). No offenders -> PASS with anchored-candidate count.
```
