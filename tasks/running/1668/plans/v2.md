```python
def _runpod_handle_identity(handle) -> dict:
    """The identity of a RunPod handle, for wedge / CUDA-IMA record matching (#1668).

    On RunPod, ``pod_name`` is the canonical issue-derived ``pod-<N>`` and
    ``job_id`` is ``""`` (launch does not capture the pod_id), so
    ``(pod_name, job_id)`` is DEGENERATE PER ISSUE — a fresh re-provision keeps
    the SAME name, and a record keyed on it turns "exactly once per wedge" into
    "once per issue forever" (#1586). ``extra.runpod_attempt_id`` (minted per
    launch, #598) is the per-attempt discriminator: included whenever present.
    A LEGACY handle without it keeps the 2-key identity (pre-#598 sidecars —
    which also cannot relaunch: ``runpod_wedge_relaunch_spec_missing``).
    Unlike :func:`_gcp_handle_identity`, where job_id is the per-create
    instance id and already discriminates attempts.
    """
    identity = {
        "pod_name": getattr(handle, "pod_name", None),
        "job_id": getattr(handle, "job_id", None),
    }
    extra = getattr(handle, "extra", None)
    attempt = extra.get("runpod_attempt_id") if isinstance(extra, dict) else None
    if attempt:
        identity["runpod_attempt_id"] = attempt
    return identity
```

New module-level helper (the TEST SEAM — T11/T12 monkeypatch `bp._runpod_wedge_liveness_probe`):

```python
def _runpod_wedge_liveness_probe(handle, *, timeout_sec: int = 10) -> bool:
    """True iff the pod answers a cheap SSH liveness probe — definitionally NOT
    the #664 RUNNING-but-no-port host wedge. FAIL-OPEN: ANY failure (no
    pods.conf row, resolve error, timeout, non-zero exit, exception) is LOGGED
    and returns False, so the established terminate path proceeds — a true
    wedge is never suppressed by a probe defect."""
    try:
        from explore_persona_space.backends.runpod import _resolve_pod_endpoint  # pods.conf path (runpod.py:350)
        host, port = _resolve_pod_endpoint(handle.pod_name)
        rc = subprocess.run(
            ["ssh", "-o", "BatchMode=yes", "-o", f"ConnectTimeout={timeout_sec}",
             "-o", "StrictHostKeyChecking=accept-new", "-p", str(port),
             f"root@{host}", "true"],
            timeout=timeout_sec + 5, capture_output=True,
        ).returncode
        return rc == 0
    except Exception as exc:  # deliberate fail-open, logged (never silent)
        logging.warning("backend_poll: wedge liveness probe failed for %s (%s: %s); "
                        "proceeding on the established terminate path", handle.pod_name,
                        type(exc).__name__, exc)
        return False
```

The broad `except` is a deliberate, logged fail-open (probe = advisory cross-check, never a new failure mode), consistent with the module's best-effort probe posture. ## 10. §11 Decision Rationale

1. **Identity fields = (pod_name, job_id, + runpod_attempt_id when present).** Why: pod_name/job_id are degenerate per issue on RunPod; the attempt id is the only per-launch discriminator already persisted in the sidecar. Source: backends/runpod.py:257/944/1021 (#598 minting); clarifier root-cause refinement on #1668; #1586 markers (05:42Z watcher failover, 08:43Z suppressed second read). Alternatives rejected: pod_id (not captured on the handle — runpod.py:1073-1079 truthful-empty comment); `epm:run-launched` recency (unsafe escape per the DESIGN CAUTION; adds a markers read to the poll hot path); sentinel mtime (not attempt-attributable).
2. **Legacy-record fail-direction = fail-toward-live-poll.** Why: fail-toward-short-circuit deadlocks (the short-circuit forecloses the superseding stamp, preserving #1668 per-issue forever); the double-fire cost is the module's accepted bounded worst case, now additionally probe-gated (D9); measured exposure is one completed-run record. Source: backend_poll.py:1930-1933 + 2649-2651 (the existing worst-case posture); the 2026-07-25 sweep (§7); incident #1586.
3. **No `epm:run-launched` secondary escape.** Why: unnecessary (both lanes re-point the sidecar — evidence in §3-D6) and unsafe as an escape (routes a non-matured pod toward terminate). Source: backend_poll.py:2045; autonomous_session_watch.py:9412; the #1586 sidecar's watcher-minted attempt id; clarifier DESIGN CAUTION.
4. **CUDA-IMA scope: layer-1 via the shared helper (in-task); once-more bound unchanged; no D9 probe.** Why: the identity fix transfers for free through the shared helper; the any-non-null bound is a deliberate, separately-documented design (#775) whose re-scoping needs its own definition of "run"; an SSH probe cannot contradict a crash-signature wedge (reachable pod, dead engine). Source: backend_poll.py:2320-2348, 2755-2796; `.claude/rules/compute-backend-failover.md` Part D.
5. **Pins in the existing Part C/D test file, real-lease + seeded-lease convention.** Why: matches the module's established `_real_lease_store_in` pattern (test_runpod_wedge_detection.py:603-615); the seed rule prevents vacuous mismatch passes (`_stamp_runpod_wedge_failover` no-ops leaseless, :2696-2702); no new file ⇒ no Step-9c selector registration. Source: read tests + code.
6. **D9 mechanism = fail-open SSH liveness probe (NOT consecutive-confirmation maturity).** Why: the incident's port-misreports were SUSTAINED ≥2 h (06:31→08:43Z), so confirmation counting over any practical window would still have matured the false wedge; the SSH probe directly tests the wedge's DEFINING property (unreachability) and fails open toward today's behavior, so a true wedge is never suppressed and the new code path can only ever SAVE a pod, never strand one. Probe timeout ~10 s (ConnectTimeout; one round-trip on the failover slow path only — zero cost on healthy ticks). Source: #1586 markers 07:06:27Z ("DIRECT SSH shows the run HEALTHY") + 09:44Z (~70 GB rung state at stake); backend_poll.py:1593-1594 (no confirmation counting exists); runpod.py:350 `_resolve_pod_endpoint` + :721 `_ssh_pod_run` (feasibility, verified). Alternatives rejected: consecutive-confirmation (defeated by sustained misreports); probing via the RunPod API port field again (the misreporting instrument cannot cross-check itself); a hard-fail probe (would convert probe infrastructure flakiness into suppressed true wedges).
