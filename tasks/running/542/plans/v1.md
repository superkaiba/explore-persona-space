## §0.0 TL;DR (plain English)

- **What I'll run:** The parent experiment taught a quirk (always raising the odds of a special symbol at the end of answers) under 16 different training situations, always using the same fixed set of 4 "don't do it here" counter-examples. I keep everything about that setup frozen and change only the counter-example set: a set of personas very similar to the training ones, a set that includes the plain default assistant, and sets of 2, 4, 8, and 16 counter-example personas at the exact same amount of counter-example data. Then I re-measure the same leakage map and check whether the counter-example set changes its shape.
- **What I expect:** Including the default assistant as a counter-example should slam the door on leakage to the default assistant (a prior experiment saw this drop by orders of magnitude). For the similar-persona set and for the 2-vs-16 count sweep, my honest prior is little to no change — three earlier attempts found nothing, but all three were confounded or measured at a ceiling; this is the first clean version of the test.
- **What would change my mind:** If the similar-persona set visibly sharpens or reshapes the leakage map beyond the run-to-run noise I'll measure directly with repeat runs, that would overturn the standing read that "which counter-examples you pick barely matters." If the count sweep moves leakage at identical data volume, the earlier "more negatives = more leakage" result was about persona diversity, not just more training.

**Kill criteria:**
- K1: an arm has >5/16 cells failing band landing after one retrain attempt → drop THAT arm, continue others (registered).
- K2: seed-noise floor on arm-level off-diag mean > 2.0 nat (comparable to the ~2.5-nat family gap) → composition contrasts downgraded to descriptive; the floor measurement + count-axis diagonal read still ship.

No contradictory pairs: K1/K2/K3 and S-thresholds operate on disjoint measurements (band landing, replicate dispersion, base-side parity, cross-arm deltas) with consistent signs.

Why: instantiates "near-twin negatives" for the 4 persona-trained cells while staying in the house one-sentence style; verified by the P0′ activation-distance manipulation check rather than asserted. `Source: #247/#329 house close-panel style (2 close negatives, default excluded) + contrastive-negatives rule (near-twin hypothesis 3.4a).` Alternatives: 4 fresh PersonaHub twins (loses the house-persona grounding); reuse eval personas (contamination — rejected).
