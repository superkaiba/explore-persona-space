# Plan — Task #1491: Does the context→answer map get more predictable with model scale? (Qwen-2.5-Instruct 0.5B→32B)

## 0.0 TL;DR (plain English — the user reads this first)

- **What I'll run:** I take six sizes of the same chat model, from very small to very large, have each one answer the same ~27,400 real user questions, and measure how well a simple map can guess the model's internal "answer summary" from its internal state just before it starts answering. The 7B size is already done from earlier work; I add the other five.
- **What I expect:** My bet is that bigger models get somewhat easier to predict this way, and that the simple linear map closes part of its gap to the fancier nonlinear one as size grows. I also expect part of any raw trend to come from boring causes (noisier small-model sampling, different answer lengths), which the built-in floors and ceilings are there to subtract out.
- **What would change my mind:** If the biggest model is clearly harder to predict than the smallest one after those corrections, the "predict behavior before generation" program has a scaling problem worth knowing now. If the trend flips direction depending on which layer or answer-length slice I look at, I'd call the raw trend an artifact rather than a fact about scale.

## 1. Goal

"On the Qwen-2.5-Instruct scale ladder (0.5B, 1.5B, 3B, 7B, 14B, 32B; 7B = the #779 fitter-fair-comparison-n1m anchor), measure how the context→answer map h: c(x) → v(x) (pre-generation context representation → mean-own-response activation profile at a depth-matched layer) changes with model scale: per scale, generate each model's OWN responses to the SAME LMSYS+WildChat contexts (pinned splits, matched train-n), fit the same linear (ridge) + nonlinear (MLP) maps in BOTH mapping arms (prefix-based and context-based), and report held-out test R² (variance-weighted, the #779 metric) vs scale — does the model's behavior, as summarized by its answer activation profile, get more predictable from its pre-generation context representation as scale grows; does the linear-vs-nonlinear gap (0.754 vs 0.810 at 7B) shrink or grow; and is the trend robust to layer choice (depth-fraction-matched primary, per-scale val-selected sweep secondary), train-set size (matched-n primary, R²-vs-n curves), and the dimension/response-length confounds?" (Task #1491 Goal, verbatim.)

One paragraph: the theory paper (Overleaf `6a2df2d2`, Assumptions A4–A5) posits a learnable, approximately linear context→answer-state transport map as a fixed property of the model; the pre-generation leakage-predictor program rides on it. If that map's held-out fidelity grows with scale, pre-generation behavior prediction gets easier exactly where safety stakes rise; if it shrinks, the program has a scaling ceiling. The 7B anchor (`#779` fitter-fair-comparison-n1m: ridge 0.754 [0.743, 0.764], MLP-w32768 0.813 [0.804, 0.823] at 963k train contexts, single-draw reliability ceiling 0.947) fixes one rung; this experiment builds the other five under an identical protocol and reads the trend with per-scale floors and ceilings so dimension, sampling-noise, and response-length confounds cannot pass as a scale effect. N/A — not a replication (the anchor recipe is inherited, but no published finding is being replicated).

## 2. Prior Work

**Literature (arXiv/web pass, run at plan time; closest formalizations first):**

- *Future Lens* (arXiv 2311.04897, Pal et al., CoNLL 2023) — linear/probe prediction of tokens ≥2 positions ahead from a single hidden state (GPT-J-6B; >48% accuracy at some layers). The token-level sibling of our construct (predicting the future response from a pre-generation state); single model, no scale ladder, token targets rather than whole-response activation summaries.
- *Measuring In-Context Computation Complexity via Hidden State Prediction* (arXiv 2503.13431) — formalizes predictability of a model's own future hidden states ("PHi") as an information measure. Closest formalization of "hidden-state predictability" as a quantity; predicts next-step states within one model, not a cross-scale ladder of context→answer-summary maps.
- *The Platonic Representation Hypothesis* (arXiv 2405.07987, Huh et al. 2024) — representation alignment increases with model scale across models/modalities. The strongest published prior for H1 (representational structure regularizes with scale); measures cross-model kernel alignment, not within-model transport fidelity.
- *Observational Scaling Laws* (arXiv 2405.10938, Ruan et al.) — downstream capabilities across families lie on a low-dimensional manifold predictable from observables; the behavioral-level analogue of our representation-level question.
- Linear-structure-vs-scale reads: *Utility Engineering* (arXiv 2502.08640; linear-probe accuracy for utility representations grows with scale), *From Cognition to Expression with Linear Representations* (arXiv 2405.16964), the Linear Representation Hypothesis (arXiv 2311.03658), *Transformer Block Coupling* (arXiv 2407.07810; hidden-trajectory coupling grows with training and correlates with generalization).
- **Named gap (the novelty):** no prior work fits the SAME context→answer-activation-summary map across a within-family scale ladder on each model's OWN generations and reads held-out R² vs scale with matched contexts, splits, and fitter protocol.

## 3. Hypothesis

Competing hypotheses (from the task body, with quantitative reads):

1. **H1 — Predictability increases with scale.** Ridge (and nonlinear) held-out test R² at the depth-matched layer rises with scale; prior: Platonic-representation convergence (arXiv 2405.07987) + probe-accuracy-grows-with-scale reads (arXiv 2502.08640).
2. **H2 — Predictability decreases with scale** (richer, higher-entropy behavior; more post-prompt computation). Decomposition: the two-draw reliability ceiling per scale separates "the behavior itself is noisier" (ceiling drops) from "the map captures a smaller share" (R²/ceiling drops).
3. **H3 — Linearization with scale:** total R² roughly flat but the ridge-vs-nonlinear gap Γ shrinks (7B anchor: Γ ≈ 0.754 vs 0.810–0.813).
4. **H4 — Artifact:** any apparent trend is a dimension/regularization, layer-choice, or response-length artifact; the per-scale floors, ceiling normalization, 3-depth-fraction grid, length stratification, and random-projection control must distinguish this.

**Registered primary contrast.** Δ = ridge test R²(32B) − ridge test R²(0.5B), context arm, depth-fraction f=0.679 layer, matched-n 25k, with a registered paired contrast: a paired bootstrap (1,000 draws) resampling the 1,000 shared pinned test contexts, recomputing each arm's variance-weighted R² on the identical resample, and differencing per draw (both arms of every registered pair row come from the same resampled context ids).
Row-coverage: the plan's own fits produce every registered row on each arm.

DISJOINT and exhaustive: Predictability-increases ⇔ Δ > 0 AND Δ's 95% CI excludes 0 on the positive side; Predictability-decreases ⇔ Δ's 95% CI is wholly below 0; Scale-inconclusive ⇔ otherwise.

**Registered secondary contrast (H3).** ΔΓ = Γ(32B) − Γ(0.5B), where Γ(s) = [val-selected nonlinear test R² among {MLP-w8192, MLP-w32768, KRR}] − [ridge test R²] at the same layer/n; same paired bootstrap.

DISJOINT and exhaustive: Gap-shrinks ⇔ ΔΓ's 95% CI is wholly below 0; Gap-grows ⇔ ΔΓ > 0 AND ΔΓ's 95% CI excludes 0 on the positive side; Gap-inconclusive ⇔ otherwise.

**Robustness pre-registration (H4 screen):** the headline Δ verdict is narrated as a scale claim only if the Δ point estimate has the SAME sign at ≥2 of the 3 depth fractions AND in the ceiling-normalized read (R²/ceiling); otherwise the verdict label is reported with an explicit artifact-suspect caveat naming which robustness leg flipped. Monotonicity across all 6 scales (Spearman ρ, paired-bootstrap CI) is reported descriptively, not as a registered verdict.

## 7. Decision Gates

Wall-clock exceeds 4 h and the ladder's expensive cells (14B/32B ≈ 353 A100-h) can be protected by a cheap intermediate signal, so ONE gate is retained; no outcome gates (every trend direction is informative — a "wrong-direction" result is a finding, not a failure).
