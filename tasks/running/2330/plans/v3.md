# Plan: Matched-data map R² — Qwen2.5-7B-Instruct vs Qwen3.5-9B on LMSYS on-policy generations at 5k/10k (issue #2330, plan v1)

**Goal-currency note:** re-read `frontmatter.goal` via `task.py view 2330 --json` immediately before returning this plan; it matches the spawn-time Goal verbatim. No `epm:goal-updated` marker exists.

## 0.0 TL;DR (plain English)

- **What I'll run:** I take the same 10,000 real user prompts we already used for the incumbent model, let the new Qwen3.5-9B model (with its reasoning mode switched off) write its own answers to them, and then check how well a simple linear rule can predict each model's answer, in its own internal representation, from what the model was thinking just before it started writing. The incumbent model's answers and internal states are already banked from an earlier run, so only the new model costs any GPU time.
- **What I expect:** the incumbent 7B model should land around 0.68–0.73 on the prediction score at these training sizes, matching its earlier runs. For the new model I genuinely don't know: its different architecture (mostly linear attention) could make its pre-answer state either a better or a worse summary of what it is about to say.
- **What would change my mind:** if the new model's score stays low even after I account for how noisy its answers are (the reliability ceiling), that would say the low score is about how it organizes information, not about noise. If both models score the same once noise is accounted for, that says this predictability level is shared across model families, not a quirk of the one we've been using.

## 0. Plan Summary (technical)

**Training:** none — both models evaluated frozen. Per-layer ridge maps `h: c_x → v(x)` (last-prompt-token activation → mean-own-response activation), fit at n_train ∈ {5,000, 10,000} per model on matched LMSYS prompts. **Hyperparameters:** decoding temp 1.0 / top_p 0.95 / n=1 / max_tokens 1024 / seed 42 (#779/#1491); capture layers 7B {14,19,26} of 28 (#1491), 9B {16,22,30} of 32 (depth-fraction matched); ridge λ val-selected over `np.logspace(-3,8,23)` (#1491); Qwen3.5 `enable_thinking=False` (chat_template.jinja read); vLLM 0.27.1 fresh venv for the 9B side (`ungrounded — smoke-gated`: registry grep confirms qwen3_5 support, runtime unproven in-repo). **Baselines / controls:** shuffled-pairing null, train-mean, identity-copy, scaled-identity, identity+learned-bias, kNN retrieval (euclidean+cosine, chance k/1000), two-draw reliability ceiling (seeds 43/44) per model, WildChat corpus-transfer fold. **Loss surface:** N/A — closed-form ridge on cached fp32 activations. **Compute:** 1 RunPod pod, 2×H200; Qwen2.5 arms 0 GPU-h (reuse of banked #1491 `scale7_refit` stores, all fitness checks passed); Qwen3.5 gen+capture 14,399 rows pilot-gated ~7.2 GPU-h naive; fits ~0.5 GPU-h. Estimated GPU-hours (total): 10. **Evaluation:** held-out variance-weighted test R² on the pinned 1,000-prompt LMSYS test split (identical across all 4 cells), raw primary + ceiling-normalized secondary, paired bootstrap (1,000 draws, seed 42, shared resample matrix). **Risks (top 2):** vLLM/transformers qwen3_5 runtime failures in the fresh venv (smoke-gated before full gen); fp32 capture memory at long sequences on the 9B (H200 headroom + capture-batch fallback).

## 1. Goal

> Compare context-to-answer map quality between Qwen2.5-7B-Instruct and Qwen3.5-9B (thinking disabled) on matched LMSYS prompts with each model's own on-policy generations: per-layer ridge maps fit at 5k and 10k training generations per model, compared on held-out R2 (plus ceiling-normalized secondary, identity+bias/kNN companions, shuffled-pairing null).

(Task #2330 Goal, verbatim.)

The context→answer map is the project's central object (the leakage-theory `v(C) ≈ h(c_C)` assumption). Everything so far is Qwen2.5-family; #1491 showed within-family scale does not buy ceiling-normalized predictability. This experiment asks the cross-family question at matched data: with the SAME prompts and each model's OWN generations, is the pre-generation state of a structurally different model (Qwen3.5-9B: 32 layers, 8 full-attention / 24 linear-attention, d=4096, 248k vocab) as linearly predictive of its answer profile as the incumbent's? The user pinned the design points: 5k and 10k training generations per model, two data points each. N/A — not a replication (no published finding is being replicated; recipe fidelity is to our own #779/#1491 line).

## 3. Hypothesis

The registered primary contrast is **Δ = raw held-out R²(New 9B at 10k) − raw held-out R²(Incumbent 7B at 10k)**, each at its model's pre-registered primary (middle) capture layer, paired bootstrap over the 1,000 shared test prompts (1,000 draws, seed 42, shared resample matrix).

- **H1 (weak prior, direction genuinely uncertain):** the Qwen3.5-9B map lands in the same raw band as the incumbent (|Δ| < 0.05). The #1491 result (normalized predictability flat-to-declining across a 64× scale range within one family) weakly predicts cross-family stability once the ceiling is factored out.
- **H2 (architecture-sensitivity alternative):** the hybrid linear-attention stack compresses pre-generation context state differently, moving raw R² materially (|Δ| ≥ 0.05); the #1491 fixed-width depth effect (14B→32B drop of 0.076) shows organization alone can move this DV by that magnitude.
- **Falsification of the "map quality transfers across families" reading:** ceiling-normalized R²(9B) below ~0.60 when the incumbent reads ~0.78 (its 25k anchor: 0.725/0.924 = 0.784) would falsify cross-family stability regardless of the raw Δ.
- **Sanity predictions:** both models' fitted maps clear every identity-family floor by ≥0.3 and their shuffled-pairing nulls read near-but-below 0 (7B precedent −0.026); within each model, R²(10k) ≥ R²(5k) (monotone R²-vs-n; 7B precedent 0.73 at 10k vs 0.60–0.63-to-≈0.7 at 5k). A 9B null far from the 7B precedent band is a rig-bug signal, not a finding (advisory only, never gated — see §7).

DISJOINT and exhaustive: NewModelHigher ⇔ Δ > 0 AND Δ's 95% CI excludes 0 on the positive side; IncumbentHigher ⇔ Δ's 95% CI is wholly below 0; Indistinguishable ⇔ otherwise.
