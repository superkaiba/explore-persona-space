```python
def open_workflow_fix_siblings(
    target_file: str | None,
    candidate_title: str | None = None,
    *,
    include_plain_infra: bool = True,
) -> list[dict[str, Any]]:
    """OPEN infra siblings overlapping the candidate (#1502) — the advisory
    complement of is_open_workflow_fix_task on the SAME population: that
    predicate BLOCKS exact-(target_file, fingerprint) duplicates; this helper
    only SURFACES overlapping open siblings for the filer to eyeball (a
    DISTINCT bug on the same hot file still files by design — the #678 A1
    grain is unchanged). Population: kind==infra AND status in
    _WF_FIX_NONTERMINAL (the dedup predicate's own open set). No time window:
    an open sibling is live regardless of filing age (a long-parked on_hold
    duplicate is exactly what a filer wants to see), and the open population
    is small (34 open infra tasks vs 1440 registry entries, 2026-07-18).
    Arms + per-population bars are the closed enumerator's, via
    _wf_fix_sibling_arms. Returns [{'id','title','status','target','matched'}]
    sorted by id DESC (ids are allocation-ordered, so id DESC = most recently
    filed first — the open-population analogue of the closed pass's
    closed_at DESC). Read-only: no mutation, no commit, no lock; per-task
    failures skip that task.
    """
    cand_targets = _wf_fix_target_tokens(target_file) if target_file else set()
    cand_tokens = _wf_fix_title_tokens(candidate_title) if candidate_title else set()
    if not cand_targets and not cand_tokens:
        return []
    hits: list[dict[str, Any]] = []
    for tid_str, entry in _load_registry().get("tasks", {}).items():
        if entry.get("kind") != "infra":
            continue
        if (entry.get("status") or "") not in _WF_FIX_NONTERMINAL:
            continue
        title = str(entry.get("title", ""))
        prefixed = title.startswith(WF_FIX_TITLE_PREFIXES)
        if not prefixed and not include_plain_infra:
            continue
        shared = cand_tokens & _wf_fix_title_tokens(title)
        if not prefixed and len(shared) < _WF_FIX_PLAIN_TITLE_MIN_SHARED and not cand_targets:
            continue  # registry-only precheck: no plain-infra arm can fire (mirror of L1292)
        if prefixed and not shared and not cand_targets:
            continue  # no prefixed arm can fire either
        try:
            tid = int(tid_str)
            task_dir = find_task_path(tid)
        except (FileNotFoundError, ValueError):
            continue  # non-numeric registry key / missing folder: skip
        matched, task_targets = _wf_fix_sibling_arms(title, task_dir, cand_targets, cand_tokens)
        if not matched:
            continue
        hits.append(
            {
                "id": tid,
                "title": title,
                "status": entry.get("status"),
                "target": ", ".join(sorted(task_targets)) or None,
                "matched": matched,
            }
        )
    hits.sort(key=lambda h: h["id"], reverse=True)
    return hits
```

No `closed_at` field (open tasks have none); no `exclude_ids` param (the advisory runs BEFORE `task.py new` — see §4.2 self-exclusion note). Optional one-line docstring addition to `is_open_workflow_fix_task` cross-referencing the new advisory complement (mirrors how `recent_closed_workflow_fix_tasks`'s docstring cross-references it).

**(b) Fallback design (allowed deviation, §"Deviations"):** if the arm-matcher extraction fights the #1446-pinned gating order (any existing `test_recent_closed_*` test would need modification), do NOT refactor the closed function — write `open_workflow_fix_siblings` as a standalone loop duplicating the ~35 arm lines, with a cross-reference comment on BOTH functions ("arm semantics duplicated from/to <fn>; change both") and the shared module-level helpers (`_wf_fix_target_tokens`, `_wf_fix_title_tokens`, `_WF_FIX_TARGET_LINE_RE`, `_WF_FIX_PLAIN_TITLE_MIN_SHARED`) still the single source of token semantics. def _advise_open_wf_fix_siblings(args: argparse.Namespace) -> None:
```python
    """#1502 warn-only advisory: before filing a wf-fix-shaped task, list OPEN
    (non-terminal) infra siblings overlapping the candidate by target path
    token or informative title tokens. The blocking open-task dedup
    (task_workflow.is_open_workflow_fix_task) is exact-(target_file,
    fingerprint) BY DESIGN, so a same-bug-different-wording sibling already
    mid-pipeline is invisible to it (#1479 was filed+spawned while #1476's
    session was landing the same fix; #1479's ~2.3h pipeline was discarded).
    ADVISORY ONLY (the #1399/#1446 contract, verbatim): never blocks, never
    changes exit codes, never skips the filing — a DISTINCT bug on the same
    hot file legitimately files its own task (the #678 A1 grain is
    unchanged); the whole leg is fail-soft (any exception prints a one-line
    diagnostic and filing proceeds).
    """
    try:
        body_text = args.body
        if body_text is None and args.body_file is not None:
            try:
                body_text = Path(args.body_file).read_text(encoding="utf-8")
            except OSError:
                body_text = None
        target = wf_fix_extract_target(body_text or "")
        if "wf-fix" not in (args.tag or []) and target is None:
            return  # not wf-fix-shaped: zero scan cost (AC6; the #1173/#1283/#1399 gate)
        hits = open_workflow_fix_siblings(target, args.title)
        if not hits:
            return
        print(
            f"file_infra_task: ADVISORY — {len(hits)} OPEN sibling task(s) overlap this "
            "filing (the open-task dedup is exact-(target_file, fingerprint) only; "
            ".claude/rules/workflow-fix-on-bug.md § Dedup, #1502). If a listed sibling "
            "is already fixing THIS bug, archive the just-filed task "
            "(task.py set-status <id> archived) and stop its spawned session "
            "(spawn_session.py stop --session-id <sid>) instead of running a "
            "duplicate pipeline; a DISTINCT bug on the same file files by design:",
            file=sys.stderr,
        )
        for h in hits[:_ADVISORY_MAX_ROWS]:
            print(
                f"  #{h['id']}  {h['status']}  [{'; '.join(h['matched'])}]  {h['title']}",
                file=sys.stderr,
            )
        if len(hits) > _ADVISORY_MAX_ROWS:
            print(
                f"  ... and {len(hits) - _ADVISORY_MAX_ROWS} more open siblings",
                file=sys.stderr,
            )
    except Exception as e:  # deliberate fail-soft: advisory must never break filing (#1502)
        print(
            f"file_infra_task: open-sibling advisory leg failed ({e!r}); filing "
            "proceeds (#1502 fail-soft)",
            file=sys.stderr,
        )
```

Design constants (each with Source):

- **Open-status set = `_WF_FIX_NONTERMINAL` (12 statuses, task_workflow.py L978-991).** What: the population gate. Why: consistency — "open" for the advisory MUST mean exactly what "open" means for the blocking dedup predicate (`is_open_workflow_fix_task` L1058), or the two surfaces drift; includes `on_hold`/`blocked` deliberately (a parked-redundant duplicate is exactly what a filer wants to see). Source: #678 (the constant + predicate). Alternative rejected: a hand-picked subset (proposed/planning/…/reviewing per the body sketch) — creates a second, subtly different "open" definition.
- **Plain-infra title bar = `_WF_FIX_PLAIN_TITLE_MIN_SHARED = 2` (L1118).** Source: #1446's live-corpus calibration (2 true hits incl. the real duplicate, 0 junk at ≥2; 5 junk at ≥1, measured 2026-07-17). Transfers: the open population (34 tasks) is strictly smaller than the closed 7-day-window population it was calibrated on, so noise is bounded above by the calibrated case.
- **Prefixed title bar = ≥1 shared token; target arm = anchored-line token intersection.** Source: #1399 (self-selected topical population; the prefixed channel titles are already wf-fix-scoped).
- **Row cap = `_ADVISORY_MAX_ROWS = 10` (file_infra_task.py L278).** Source: #1399 ("27 same-target closures/7d on the hottest file" measurement). Reused, not re-derived.
- **No time window on the open scan.** Why: an open sibling is a live collision risk regardless of filing age, the population is small (34 vs 1440, measured 2026-07-18), and the blocking predicate has no window either. Source: `is_open_workflow_fix_task` precedent + the measured population. Alternative rejected: a 7-day window (would hide a long-parked open duplicate — the exact revivable `on_hold` class).
- **Sort = id DESC.** Why: task ids are allocation-ordered (`task.py new`), so id DESC = most-recently-filed first — the open-population analogue of the closed pass's closed_at DESC recency ordering (keeps the likeliest live collision inside the row cap). Source: #1399's recency-desc rationale, transposed.
- **Fail-soft whole-leg try/except + stderr-only + exit codes unchanged.** Source: the #1446 contract (task-body hard constraint, carried verbatim) and the #1173/#1283 precedent legs.
- **Shared arm-matcher extraction over duplication.** Why: the task body directs "prefer the design with least duplication" and arm-semantics drift between two copies is the real long-term failure mode; the 16 existing tests make the refactor safe. Source: task #1502 body constraint + `code-style.md` supersede/reuse discipline. Fallback preserved (§4.1b) because the same body forbids changing the closed contract.
