## 1. Goal, requirement, acceptance criteria

**Goal.** Require every registered selection-symmetric null-band read to report the band alongside the DV's achievable ceiling / dynamic range, and to narrate a band at-or-above the ceiling as failure-to-reject (uninformative-by-construction), never as evidence of absence/reversal.

**Requirement.** The check must fire at BOTH ends of the pipeline: (a) PLAN time — the planner registers band + ceiling per null-band read; the critics REVISE an unfireable registered gate and Concern a missing ceiling report; (b) INTERPRETATION time — the analyzer / interpretation-critic re-check the realized band against the ceiling before narrating any non-rejection.

## 2. Method delta (what the rule currently lacks)

`selection-symmetric-nulls.md` today mandates HOW to build an honest band (per-draw same-selection or held-out freeze) and to persist the per-draw × per-axis matrix — but says nothing about whether the resulting band is REACHABLE by the statistic. On #810 (round `ultrachat-genre-summary-sweep`, H1-g(iii)) an honestly-built difference-null band had a 97.5% upper bound of 0.800 while the DV — a difference of skills capped by a ~0.857 max attainable skill — could essentially never clear it (even the parent round's observed +0.209 Betley effect would fail); the p=0.634 outcome was initially narrated as a clean ordering fail until the interpretation-critic caught it. Standard power/severity reasoning: a test whose rejection region is unreachable has zero power, so a non-rejection carries no evidence. The delta: one new section making the band-vs-ceiling comparison a REPORTED, registered quantity with a mandated failure-to-reject narration when the band is unreachable.

```markdown
## Band-vs-ceiling informativeness check

A selection-symmetric band can still be UNINFORMATIVE-BY-CONSTRUCTION:
if the band's rejection threshold sits at or above the largest value the
statistic can actually attain, no data could ever clear it — the test
has zero power and a non-rejection carries no evidence (standard
power / severe-testing reasoning: an unreachable rejection region
cannot discriminate).

**Every registered null-band read REPORTS, side by side:**

1. the band's upper bound (e.g. the 97.5% quantile of the max-selected
   null distribution), and
2. the DV's **achievable ceiling** — the maximum value the statistic
   can attain given the estimator and data. Operationally, in
   preference order:
   - a bounded DV: the bound itself (a rate ≤ 1, |r| ≤ 1, a skill ≤ its
     max attainable skill);
   - a difference statistic (difference of skills / rates / effects):
     the maximum attainable value of the favored arm MINUS the
     comparison arm's observed or baseline value — NOT the raw
     single-arm bound;
   - fallback reference point when no estimator bound is derivable:
     the largest previously-observed in-genre / in-line effect.

**If the band's upper bound ≥ the ceiling (or ≥ the fallback reference
point), the test is uninformative-by-construction.** Then:

- the outcome MUST be narrated as **failure-to-reject** ("the test
  could not have detected any achievable effect") — NEVER as evidence
  of absence, a clean ordering fail, or a reversal;
- the band AND the ceiling are drawn in the figure, so the
  unreachability is visible in the artifact itself;
- at PLAN time, prefer redesigning the read (a less-inflating
  selection, more draws, a tighter statistic, a larger n) over
  registering a decision gate that cannot fire — this is the
  null-band-specific instance of the Decision-Gates
  joint-satisfiability bar.

The check fires at BOTH ends: the PLANNER registers band + ceiling next
to each null-band read (§6/§7; the critic REVISEs a registered
null-band decision gate whose band is unreachable, and raises a binding
Concern on a missing ceiling report for a bounded statistic); the
ANALYZER / interpretation side re-checks the REALIZED band against the
ceiling before narrating any non-rejection.

**Motivating evidence (#810, round `ultrachat-genre-summary-sweep`,
H1-g(iii)).** A registered difference-null band's 97.5% upper bound
(0.800) sat above the DV's achievable difference ceiling — the max
attainable skill was ~0.857, so a max-difference statistic could
essentially never clear 0.800; even the parent round's observed +0.209
Betley effect would fail — and the p = 0.634 outcome was initially
narrated as a clean ordering fail until the interpretation-critic
caught it.
```
