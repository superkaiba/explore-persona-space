# Plan — Issue #742: Decoding-ceiling, linear-information-loss, and sample-complexity of #658 base-model behavior representations (n=50)

## §0.0 TL;DR (plain English)

- **What I'll run:** I take the data we already have from experiment #658 — for 50 different prompt setups, a snapshot of what the model is "thinking" (its internal activations) plus how often it actually shows each of 10 behaviors. With zero new GPU time, I measure how well you can read a behavior off the activations, how good *any* reader could ever get (you hit a wall set by how noisy the behavior measurement itself is), and how far apart those two numbers are. Where there's a real gap, I run a focused test for whether a *nonlinear* reader could close it. Then I draw a curve showing how many prompt setups you'd need to pin all this down sharply.
- **What I expect:** For a few behaviors the linear reader is already as good as it can get (the gap is basically zero) — so there's nothing more to extract and we can say that definitively. For the rest the gap will be too wide to resolve at only 50 setups, and the honest answer will be "we can't tell at this sample size, and here's roughly how many more setups it would take."
- **What would change my mind:** If the nonlinear test fires cleanly above its control on a behavior where the linear reader left a gap — that would say there's behavioral information present that linear decoding misses, which is the more interesting outcome. I'd also be surprised if #658's reported "noise floor" turns out to already equal the true reliability ceiling for most behaviors; if it does, #658 didn't conflate anything and the disentangle deliverable shrinks.

**Estimator-applicability rule the implementer MUST encode (the load-bearing data-shape fact):**
- The split-half-over-rollouts estimator (i) operates on the `per_probe[*].e0` array (per-context per-probe expression fractions). The SPLIT UNIT is the **probe set** (the `per_probe` list), matching #658's `noise_floor()` — because for 8/10 behaviors there is exactly 1 rollout per probe, a rollout-level split is impossible; the probe is the replicate. For broad_em (50/probe) and sycophancy (10/probe) the implementer ALSO computes a rollout-level split-half within probes as a second sub-estimate (report both; they should agree). Behaviors with only 8 probes (deception, fact_expression, self_report, persona_drift, format_style, marker) get a 4-vs-4 probe split → expect WIDE CIs; flag them `low_probe_count: true`.
- The binomial-SP estimator (ii) uses `p̂ = rate`, `m = n_total` per (context, behavior); `Var_C(E0)` over the 50 per-context rates; `SP = Var_C(E0) − mean_C[p̂(1−p̂)/m]`; `ceiling² = SP / Var_C(E0)`; `√r_yy = sqrt(max(ceiling², 0))`. Negative SP → `√r_yy = 0` (floor) AND record `sp_point_estimate` (the negative value) + `sp_negative: true`.
- `marker` (logp DV, no judged rate) has no Bernoulli structure → estimator (ii) is **N/A for marker**; use estimator (i) on the per-probe logp halves only, flag `binomial_sp: null, reason: "logp DV, no Bernoulli"`. `format_style` is a Bernoulli over the structural flag → estimator (ii) applies with `p̂=rate, m=8`.

#### Script 3 — `scripts/issue742_leace_dcor.py` (Stage 1: only headroom cells)

Reads `stage0_gate.json`; runs ONLY cells with `gate == "headroom"`. Per such (behavior × genre):
1. **PCA-reduce `v0[:, L*, :]`** (50 × 3584) at the best layer L* from Stage 0 to `d ∈ {5, 10, 20}` via `sklearn.decomposition.PCA` fit on train folds (LOCO-consistent: fit PCA inside each fold's train rows, project the held-out row). 2. **LEACE (Belrose 2023, closed-form):** implement the closed-form eraser directly in `issue742_common` (no SGD — `concept_erasure` is NOT installed). For a scalar target y, LEACE removes the least-squares-optimal subspace that linearly predicts y: `W = Σ_xx⁻¹ Σ_xy` (whitened cross-covariance direction), `P = I − W (Wᵀ Σ_xx W)⁻¹ Wᵀ Σ_xx`; `X_erased = X P`. Fit Σ on train folds, apply to held-out.
3. **Residual dependence test — distance correlation (Székely 2007):** implement dCor directly in `issue742_common` (the double-centered distance-matrix estimator, ~20 lines numpy: pairwise Euclidean distance matrices A (`X_erased`) and B (y), double-center, `dCov² = mean(A∘B)`, `dCor = dCov / sqrt(dVarX·dVarY)`). `dcor` PyPI is NOT installed; the hand-implementation removes the dependency.
4. **Hewitt-Liang control-task null:** B_perm=1000 shuffles of y; re-fit LEACE on the shuffled label, recompute dCor on the shuffled-erased X → null distribution; report `dcor_net = dcor_observed − null_p95` and `nonlinear_residual_detected: (dcor_observed > null_p95)`.
5. **Kernel-ridge corroboration (appendix, secondary):** `sklearn.kernel_ridge.KernelRidge(kernel="rbf", gamma=median-heuristic)` on `X_erased` under LOCO; if its CV ρ exceeds the per-behavior shuffle null at the median, record `kernel_ridge_corroborates: true`. NOT a primary result.

Emits: `eval_results/issue_742/stage1/<behavior>_<genre>_pcadim<d>.json` (cumulative variance, dCor observed, control-task null p95, dcor_net, verdict, kernel-ridge appendix). Headline = d=10; {5,20} are sensitivity.

CLI: `--genre`, `--pca-dims 5,10,20`, `--b-perm 1000`, `--gate-file eval_results/issue_742/stage0_gate.json`, `--smoke`.

#### Script 4 — `scripts/issue742_learning_curve.py` (Stage 2)

Per (behavior × genre), at `n′ ∈ {10,15,20,25,30,35,40,45,50}`, B_sub=200 sub-sample repeats (sample n′ contexts without replacement):
- `ρ_lin(n′)` (LOCO ridge at L*) ± CI half-width (over the B_sub sub-samples).
- `√r_yy(n′)` via BOTH estimators ± CI half-width.
- `dcor(n′)` (PCA d=10 + LEACE-erased) ± CI half-width.
- `bracket_width(n′) = √r_yy(n′) − ρ_lin(n′)`.
- **Extrapolation:** fit `log(CI_half_width) = a + b·log(n′)` (Stone 1982 minimax form) by OLS on the ρ_lin CI-half-width curve; solve for `n′*` where `CI_half_width = 0.05` (ρ_lin units); record fit residuals + R². ## §11 Decision Rationale

No training hyperparameters. The grounded analysis knobs:

- **PCA dim = 10 (headline); {5, 20} sensitivity.**
  - Why: the body names "PCA-reduce to ~10 dims" as the single highest-leverage move — restores dependence-test power, pushes the regression toward the parametric regime, lowers d in the minimax rate at n=50. d=10 ≈ #658's `d_eff ≤ ~10` regime; {5,20} bracket it.
  - **Source:** body §"Methodological backbone" + Voita-Titov 2020 (probing dim) + #658 d_eff≤10 rail.
  - Alternatives: full d=3584 (rejected — dCor power collapses at d≫n); d=2 (rejected — too aggressive, drops signal).

- **B_bootstrap = 2000 (contexts).**
  - Why: matches #658's `N_BOOTSTRAP=2000` so the bracket CIs are directly comparable to a32's `bootstrap.ci95`.
  - **Source:** #658 `fit_predictors.py` `N_BOOTSTRAP = 2000`. (Body suggested 1000; I raise to 2000 for cross-comparability with the a32 cells — a deliberate divergence noted in §12.)
  - Alternatives: 1000 (the body's value; equally valid but breaks exact comparability with a32).

- **B_perm = 1000 (dCor control-task + ridge permutation).**
  - Why: standard for a 95th-percentile null at this scale; p95 resolution needs ≈ 1000 draws.
  - **Source:** Hewitt-Liang 2019 (control task) + #658's within-context shuffle-null pattern.

- **LOCO CV matched to #658.**
  - Why: the ceiling and ρ_lin MUST be computed under the SAME CV cardinality (Storrs 2020). I reuse #658's LOCO (leave-one-context-out) ridge directly — the n=50-matched protocol #658 used — keeping the bracket comparable to a32/a33. (The body's "5-fold over 50 contexts" and LOCO are the same family at n=50; I pin LOCO to inherit #658's exact `_ridge_predict_loco`.)
  - **Source:** #658 `_ridge_predict_loco` + Storrs 2020 (cardinality match) + Varoquaux 2018 (CV variance) + Bengio-Grandvalet 2004 (never std-across-folds).

- **Ridge λ grid `[1e-2, 1e-1, 1, 10, 100, 1000]`.**
  - Why: the exact grid #658 used; inner-fold-selected per the dual PRESS-LOO form.
  - **Source:** #658 `RIDGE_LAMBDAS`.

- **N_judge_subset = 10/genre, n_reruns = 3, Spearman-Brown + two-facet G-theory decomposition.**
  - Why: 10 contexts is enough to estimate a per-behavior judge-variance term while keeping cost < $10; 3 reruns is the practical floor for a variance read (a 1-df estimate at 2 reruns is too unstable). The two-facet (rollouts × judge-reruns) crossed design is the standard generalizability-theory decomposition for separating sampling noise from judge noise.
  - **Source:** standard generalizability-theory two-facet decomposition (no prior project judge-variance probe exists — `task.py list-by-status` grep for "judge variance"/"reliability"/"split-half" returned only #32, an unrelated seed-variance task). Spearman-Brown = Spearman 1904 / Brown 1910.
  - Alternatives: n_reruns=2 (rejected — too few for variance); N_subset=50 (rejected — blows the cost envelope for sycophancy).

- **dCor (Székely 2007) over HSIC.**
  - Why: dCor is well-defined and fast at small n, scale-free, and needs no kernel-bandwidth choice; the implementation is ~20 lines of numpy (no dependency). HSIC would add an RBF bandwidth nuisance parameter.
  - **Source:** Székely 2007; body §"Stage 1".

- **LEACE closed-form (Belrose 2023), hand-implemented.**
  - Why: `concept_erasure` is NOT installed; the closed-form 1-D-target LEACE reduction is short and avoids a dependency. Closed-form (no SGD) is stable at n=50.
  - **Source:** Belrose 2023; body §"Stage 1".
