# Plan — Issue #1482: Error analysis of the n1M context→answer map (worst-predicted contexts, worst-predicted SAE features, linear-vs-nonlinear gap)

## 0.0 TL;DR (plain English)

- **What I'll run:** I take the big context→answer prediction map we already trained on ~1M real user chats and ask where it fails. I re-run the cheap fits to get an error score per conversation, have the judge label each held-out conversation (topic, language, refusal-adjacent or not), and check which kinds of conversations the map predicts worst. I also translate both sides of the map into interpretable SAE features and find which answer features the map cannot predict, and I split the error into the part only the nonlinear fitter gets right versus the part the linear one gets right.
- **What I expect:** the error will be structured, not uniform noise — non-English and refusal-adjacent conversations should be predicted worse than English task-style ones, and the nonlinear-only slice of the error should concentrate in a small set of contexts and rare features rather than spreading evenly.
- **What would change my mind:** if the worst-predicted conversations look like a random sample (no category stands out), that says the map's error is a flat noise floor — nothing a category-aware fix or a nonlinear fitter can buy back — and the ~0.75 linear ceiling is about intrinsic answer variability, not about identifiable hard cases.

## 3. Hypothesis

**H1 (error concentration — PRIMARY, registered).** The dense map's per-context normalized error is category-structured. Registered primary contrast: Δ = mean normalized per-context error (ridge, holdout-excluded refit, fresh 20k holdout) of **non-English** contexts minus **English** contexts (language from the judge labels).
DISJOINT and exhaustive: Confirmed ⇔ Δ > 0 AND Δ's 95% CI excludes 0 on the positive side; Falsified ⇔ Δ's 95% CI is wholly below 0; Inconclusive ⇔ otherwise.
(CI: 10,000-draw batched bootstrap over holdout contexts. All OTHER category contrasts — refusal-adjacency, topic classes, corpus source, length quartiles — are exploratory, reported with BH-FDR q=0.05 across the category set, never as the headline.)

**H2 (worst-predicted SAE features — descriptive, no verdict labels).** Per-feature held-out prediction quality of pooled answer-side SAE features varies systematically with feature activity: rare features are worst-predicted. Deliverable is the ranked per-feature R² table + interpretations of the worst tail, with split-half rank stability; no Confirmed/Falsified labels are registered for H2.

**H3 (linear-vs-nonlinear gap — paired, registered descriptively).** The per-context gap Δgap(x) = nerr_ridge(x) − nerr_mlp(x) is a paired contrast over the same holdout contexts (each context scored under both fitters from the same refit driver). We report both directions: the mass with Δgap > 0 (nonlinearly-but-not-linearly predictable) and Δgap < 0 (linear-better), its concentration (share of Σ|Δgap| carried by the top decile of |Δgap|), its category profile, and its MLP-seed stability. No Confirmed/Falsified labels are registered for H3.
Row-coverage: the plan's own refits produce every registered row on each arm.

Competing hypotheses the design distinguishes (from the task body): error concentrated in identifiable categories vs diffuse noise-floor error; nonlinear gap concentrated in tail contexts/rare features vs spread uniformly; worst-predicted SAE features being low-frequency features vs high-frequency structural ones.

## 7. Decision Gates

Two cheap validity gates (both fire in the first ~40 min of the pod run and gate only downstream phases; no science-outcome kill criteria — this is a characterization task, ~4h wall, so no further gates per the default):

- **Gate A — reconciliation (blocks everything downstream of P1).** `refit_full` ridge whole-map R² on the pinned test must reproduce the committed 0.75417 within |Δ| ≤ 0.002; each MLP/other arm within |Δ| ≤ 0.01. Grounding: ridge is deterministic given the pinned split + λ-selection (same code, same data ⇒ near-exact; the 0.002 headroom covers GPU nondeterminism); 0.01 = committed bootstrap-CI half-width (`n1m_fits.json` CI [0.7435, 0.7642] ⇒ ±0.010). A miss is structural (wrong split / wrong metric / wrong capture slice), lands far outside the band by construction, and HALTs with the numbers. Sign + threshold grounded on the artifact's own committed values (calibration rule, artifact-reuse §).
- **Gate B — SAE fitness (blocks axis-2 phases only; axes 1+3 dense reads proceed regardless).** On the P2-pilot per-token activations: FVE ≥ 0.55 → proceed (HALT below — the wrong-hook/wrong-layer regime is multiplicative: adjacent-probe FVE tells us which); 0.55 ≤ FVE < 0.70 → WARN, proceed with k=128 if it clears 0.70, else proceed with the caveat carried to the clean-result; FVE ≥ 0.70 → clean PASS. Calibration source: the suite's own published eval (`resid_post_layer_19/trainer_1/eval_results.json` frac_variance_explained 0.806 at k=64; 0.842 at k=128) measured on chat+pile — our corpus is the same LMSYS family, so ~0.7–0.85 is the correct-band expectation; <0.55 discriminates hook misalignment from legitimate mild transfer loss. WARN conditions: value persisted in `sae_fitness.json`, named analyzer-adjudication concern, discriminating follow-up = the L15/L23 adjacent-layer probes already in the pilot.
