# Plan — Task #628: Revise the marker rig (slot-aligned alive negatives) and re-measure marker leakage across the #537 context panel

## 0.0 TL;DR (plain English)

- **What I'll run:** Our marker experiments have two quirks. The "don't do this" counter-examples are trained at a position the model already predicts perfectly, so they teach it almost nothing, and the marker symbol is trained one blank line away from the spot where we measure it. I'll fix both, make the fixed version the project standard, and then train the marker habit under 16 different kinds of context (personas, real chat histories, worked examples, instructions, formatting demands) using the OLD rig — comparing head-to-head against an existing high-confidence run that already used essentially the fixed rig on the exact same grid. Two small extra arms change one quirk at a time so we can tell which fix matters.
- **What I expect:** Counter-examples that finally carry a real learning signal should hold the habit closer to where it was trained — less spill into other personas and into the plain assistant. So the old rig should read as leakier across the board, at the same implant strength.
- **What would change my mind:** If both rigs leak the same amount, then the counter-examples do nothing even when given a real signal. That would sharpen the earlier finding that they only ever padded the training schedule — a clean result either way.

## 3. Hypothesis

- **H1 (install parity):** the revised rig installs the source at least as strongly at matched dial. Quantitative: ≥14/16 train contexts reach the [5,12] band (overshoot-stop counts) per arm per seed; |arm-mean diagonal ΔG difference| ≤ 3 nat. Falsified if the legacy arm reaches band broadly while a live-negative arm floors (<10/16) — an install-starvation finding.
- **H2 (the point):** slot-aligned alive negatives suppress off-diagonal leakage. Quantitative: per-train-context mean off-diagonal Δlog P(※) is LOWER under the revised rig than the legacy rig by ≥ 1 nat, paired Wilcoxon over the 16 train contexts p < 0.05, same direction in both seeds; the `default` eval column and the 4 trained-negative columns show the largest suppression; trained-negative columns sit BELOW family-matched holdout bystanders under live-negative arms only (the #471 restoring-force signature).
- **H3 (map shape):** the spread families (persona F1, chat F2, rephrasing F4) contract more than the contained families (worked-example F3, instruction F7F8): a rig × family interaction in the off-diagonal means.
- **H-inert (gate for reuse):** the trailing-`\n` loss extension is inert: full-revised-rig mini-arm vs the matching #537 cells, |mean paired cell ΔΔG| ≤ 1 nat with no consistent sign across 2×4×30 paired cells. If this FAILS, #537 cells cannot stand in for the canonical rig (see §7 fallback).
- **Null (clean either way):** off-diagonal maps statistically indistinguishable between rigs → negatives are inert even with a live gradient; tightens #601 and demotes loss placement as the #471-conflict resolution (residuals: lr, panel, ratio — #613's variables).

Disentanglement prediction: if H2 holds, the flag-only edit (separator kept, negatives live) recovers most of the suppression and the separator-only edit recovers little — the negative-gradient channel, not slot cosmetics, carries the effect. The dual-slot reads test the converse (how much implant the separator hides from the canonical slot).
