## §2 Method delta vs v8 (the one variable)

**Changed — resampling scheme.** Registered fold protocol:

- **Fold construction:** sort the 4,920 analysis-pool ids, apply the SAME `rng(952)` permutation `make_split` uses (run_952.py:442), and partition the permuted order into 5 consecutive blocks B0–B4 of exactly 984 (4,920/5 = 984). Fold k (k = 0..4): **test = Bk, val = B(k−1 mod 5), train = the remaining 3 blocks (n = 2,952)** — every fold has the parent's exact 2,952/984/984 proportions, so the registered per-slot validation-argmax λ rule applies with unchanged semantics. Under this rotation the fold with test = B4 has val = B3, train = {B0, B1, B2} — **identically the parent split** (parent train/val/test are `order[:2952]` / `order[2952:3936]` / `order[3936:]`). That fold is the **calibration fold**, executed FIRST; the other 4 are rotated folds.
- **λ re-selection:** per fold, per slot, WITHIN layer — `_lam_star_by_slot` applied to that fold's own validation-block row (the v5 §11 rule verbatim, per fold). `l_star` layer selection is recorded per fold but NOT consumed — the read-out layer set is the pre-registered {14, 17, 20, 23, 26}; the `l_star == 20` hard assert binds on the calibration fold only (see Gates).
- **Pooling:** each context's per-(slot, arm, layer) `(ss_res, ss_tot)` — and each H2 survivor's `(G_0, G_t)` — comes from the ONE fold where it was in test. Cross-fitted cells concatenate over the 5 folds: H1 paired population = all 4,920 pool contexts; H2 matched population = the extended-span-≥32 survivor subset of the FULL pool (survivorship is a context property, fold-independent; expected ≈ 0.639 × 4,920 ≈ **3,145** from the round-1 test-block fraction 629/984; realized n reported). Bootstrap (rng(0)) and sign-flip (rng(1)), 10,000 draws, resample paired CONTEXTS over the pooled population (fold assignment treated as fixed, standard cross-fitting practice); the v8 §2 pinned p-value/CI construction, non-strict equivalence containment, three-way enum, and TOTAL lattice apply verbatim to the cross-fitted cells.

## §11 Decision Rationale

- **Fold protocol — 5 consecutive 984-blocks of the parent's rng(952) permutation, rotation val = (k−1 mod 5):** What — §2 construction. Why — 4,920/5 = 984 exactly; every fold keeps the registered rule's exact 2,952/984/984 semantics; and the rotation makes the parent split ITSELF a fold, giving the reproduction gates a binding substrate (a fresh-rng assignment would leave nothing to calibrate against). Source: `run_952.py::make_split` (parent split = consecutive blocks of this permutation, read this session) + scope-note spec ("per-fold assignment rng(952)"). Alternatives: within-trainfold val split (rejected — changes train n 2,952 → ~3,149, altering the registered λ-rule's semantics AND breaking fold≡parent); fresh-seed folds (rejected, above).
- **K = 5:** Why — matches the parent's 20% test proportion (each fold's test = 984, the exact registered read population); each context tested once; K = 10 doubles battery cost and halves the validation block to 492, weakening the registered λ selection relative to its 984-val grounding. Source: scope note (verbatim "5-fold"); parent split proportions (v5 §0b).
- **Pooled paired bootstrap over the cross-fitted population (H1 n = 4,920; H2 expected n ≈ 3,145), fold-as-fixed:** Why — the registered statistics are per-context paired reads; under cross-fit every context has exactly one test read, so the parent's bootstrap recipe applies with the population extended; resampling contexts (not folds) is the standard cross-fitting treatment and matches the pinned §2 construction. Source: v8 §2 pinned construction (inherited); round-1 realized survivor fraction 629/984 (analyzer-guidance row, v8) → 0.639 × 4,920 ≈ 3,145.
- **Gates fold-aware (calibration fold first; l_star assert + L20 reproduction bind there; NEW round-1 cross-layer reproduction check):** Why — the parent's and round-1's committed numbers are single-split, so reproduction can only bind on a reproduction of that exact split; running it first gates the new fold-loop code where the answer is known (§2 gate 4 subsumes v8's suffixed-L20 calibration cell). Rotated-fold `l_star` is recorded-not-asserted — a hard per-fold assert would gate on validation-block jitter no registered statistic consumes (jointly-unsatisfiable-gate risk). Source: v8 §3 gates + round-1 realized gate PASS (`battery_meta.json` `l20_reproduction_gate`, `suffixed_l20_calibration_gate`); parent `layer_scores` argmax margin (0.1057 vs 0.0896).
- **Decision statistics — same H1/H2 on cross-fitted cells; Holm across the 3 added layers per family; L20/L17 companions only; supersede-not-pool vs round 1:** Why — the cross-fit changes precision, not the test count; pooling with round 1 double-counts B4. Source: v8 §2 (registered enum/lattice/margins/p-construction, inherited verbatim); scope note ("statistic definitions … identical").
- **`fit_device=cuda`, A100-80 `capture-7b`, single GPU, `--time-budget-hours 16`:** Source: round-1 realized (0.6 s/SVD, 11,280 s battery wall) — v8 §11 rationale carries; budget sized to the §9 upper bound + margin.
- **`N/A — no model training` / `N/A — no training hyperparameters`.** **Measurement validity:** v5 §6 table inherited; **`N/A — no behavioral construct`** (DVs are held-out R² statistics on stored activations; no judge). **OOD-folds note:** `N/A — no held-out predictive DV in the ood-generalization sense` — the 5-fold design here is measurement-precision CROSS-FITTING on a fixed pool (folds exist so every context gets an out-of-fit test read under the registered λ rule), NOT a grouped-generalization claim; no group structure is claimed to transfer, and no fold-to-fold generalization headline is licensed.

## Kill criteria

- Ridge parity gate fails → stop per v5. Any staged shard missing/size-mismatched at `5b62649…` → `failure_class: data`, stop before battery.
- Partition coverage assert fails (a context in 0 or 2 test folds) → stop.
- Gate-5 provenance manifest absent/mismatched on any verdict fold at `--kfold` time (split-hash, git-SHA, or env mismatch vs the gate-PASS manifest) → stop; never compute a pooled statistic over mixed-provenance folds.
