## 2. Scope and claim boundary

The exact testable claim is:

> In held-out real multi-turn contexts, **coarse topic/task-genre variation** is more concentrated
> in the map's low-gain effective kernel and is less transmitted by the map than variation associated
> with **prompt language, observed answer format, and request refusal-adjacency**.

The following stronger phrasings are out of scope and must not appear as conclusions:

- "The map discards all topic or lexical content." The topic rubric is 12-way coarse task/genre,
  not a comprehensive annotation of entities, propositions, or fine semantic content.
- "The map retains requested format." The existing `format` label describes the observed answer's
  dominant form (`code`, `list`, `prose`, or `mixed`), not an independently annotated user request.
- "The map causally decides the answer." This is a correlational decomposition of a fitted predictor,
  consistent with #1776's Jacobian caveat.
- "Safety is a topic-independent primitive." Refusal-adjacency overlaps the harmful/unsafe topic;
  the primary partialled analysis conditions on the other axes and the raw contingency table is
  reported so readers can see the overlap.

## 5. Estimands

Let `x_i in R^3584` be a row-vector L19 context state. Let the raw map be
`A = diag(1/xsd) W`, with SVD `A = U diag(s) V^T`; for row-vector inputs, columns of `U` are input
directions. Let `R99` be the leading directions containing 99% of `sum(s^2)` and `K99` its orthogonal
complement. The registered #2569 dimensions are `dim(R99)=1608`, `dim(K99)=1976`.

### 5.1 Honest train/test category decomposition

Assign one immutable 60/40 analysis-train/test split before fitting. Within each corpus, sort rows by
the integer value of `SHA256("25691738:" + str(ci))`; the first `floor(0.40*n_corpus)` rows are test
and the remainder train. This gives exact corpus-stratified counts without a library-version-dependent
splitter. The driver asserts that every retained level of every axis occurs in both partitions and
that every full/reduced design is full rank; otherwise it halts rather than swapping rows after seeing
geometry.

For target axis `q` in `{topic, language, format, safety}`, construct a treatment-coded one-hot matrix
`T_q`. Construct nuisance design `C_q` from an intercept, corpus, depth indicators, centered
`log1p(length)` through cubic terms, and treatment-coded one-hots for the other three primary semantic
axes. On analysis-train only, fit the nuisance and full OLS models. Equivalently, use the
Frisch–Waugh–Lovell construction: residualize `T_q` and `X` on `C_q`, then regress residualized `X`
on residualized `T_q`. Apply both fitted models once to the untouched analysis-test rows.

In singular input coordinates, define the held-out directionwise improvement
`delta_qj = SSE_reduced(q,j) - SSE_full(q,j)`. This is the primary category-signal estimand. It can
be negative, correctly exposing overfit; unlike squared fitted-displacement energy, it does not add
coefficient-noise energy by construction. The latter quantity `sum_i ||D_qi||^2` is retained as a
clearly descriptive diagnostic only and is prohibited from entering the verdict.

Design rank, condition number, residualized target variance, analysis-train/test counts, and held-out
incremental R2 are recorded. A rank-deficient design or nonfinite solve is fail-loud, never silently
regularized.

### 5.2 Primary per-axis statistics

For each axis `q`, sum held-out directionwise improvements before taking ratios:

- **Total recoverable category signal** `DeltaSS_q = sum_j delta_qj` and its held-out incremental
  `R2_q = DeltaSS_q / SSE_reduced_total`.
- **Kernel concentration** `kappa_q = sum_(j in K99) delta_qj / DeltaSS_q`.
- **Retained concentration** `1-kappa_q`, an algebraic identity checked in code.
- **Transmitted gain** `tau_q = sum_j s_j^2 delta_qj / DeltaSS_q`, which is the held-out category
  improvement after applying `A`, relative to improvement in input-state units.
- **Natural-context kernel share**
  `kappa_X = sum_i ||(x_i-xbar_test) U_K99||^2 / sum_i ||x_i-xbar_test||^2`, descriptive only because
  it is an unsigned raw-variance quantity, not a debiased incremental-skill quantity.

The primary contrasts are equal-axis, not row-count-weighted:

- `Delta_kappa = kappa_topic - mean(kappa_language,kappa_format,kappa_safety)`;
- `Delta_gain = mean(tau_language,tau_format,tau_safety) - tau_topic`.

Positive values support "topic is more suppressed." The three individual topic-minus-axis versions
are prespecified. The signed additive gain contrast avoids taking logs of potentially nonpositive
held-out improvements. `kappa_q` and
`tau_q` enter interpretation only for axes that pass the recoverability gate in §7; signed
directionwise improvements mean either ratio can fall outside its naive unsigned-energy bounds, and
that possibility is reported rather than clipped. All bootstrap ratio draws are retained, including
negative values; an exact-zero or excessive nonpositive-denominator mass triggers the prespecified
interpretability failure in §7, never draw deletion.

### 5.3 Standardized-coordinate robustness

Repeat the complete loss-improvement decomposition in registered map-standardized coordinates
`z=(x-xmu)/xsd`, using SVD of `W`. OLS predictions transform linearly, so the analysis reuses the
same train/test split and refits at the declared bootstrap grain; it does not select a favorable
coordinate system. Repeat raw-coordinate reads at 90%, 95%, and 99% squared-mass cutoffs. Report all
cutoffs regardless of direction.

### 6.1 Bootstrap

Use 2,000 joint stratified Bayesian-bootstrap draws. Every draw samples independent positive
`Exp(1)` weights within each corpus for analysis-train and analysis-test, then rescales them to sum
to the original row count of each `(partition, corpus)` cell (equivalently, mean weight one),
recomputes weighted centering, and **refits every complete full and
reduced estimator**. The same train/test weights are applied to all four axes, coordinate systems,
subspaces, and primary contrasts, preserving cross-axis covariance. Full-model sufficient statistics
are shared across axes within a draw. Percentile 95% intervals are primary. This outer refit carries
both coefficient-estimation and held-out sampling uncertainty conditional on the preregistered split;
no fixed-fit row interval enters the verdict. Weighted SSE is `sum_i w_i ||residual_i||^2`, and every
weighted mean uses `sum_i w_i value_i / sum_i w_i`. BCa is N/A because the nested weighted refit and ratio
would require a second full jackknife; the Bayesian-bootstrap percentile interval is fixed in advance.

### 6.2 Selection-symmetric directional null

For each of 10,000 draws, choose exactly 1,976 of the 3,584 inherited left-singular directions
uniformly without replacement and designate them pseudo-kernel. Use the same draw for every semantic
axis. Recompute `kappa_topic`, each response-regime `kappa`, and `Delta_kappa` from the signed
directionwise held-out improvements. This matched-rank null asks whether observed concentration is
specific to the learned low-gain selection rather than dimension count; it does **not** establish
that a label association exceeds estimation noise. Prespecified tails are upper for topic and
`Delta_kappa`, lower for language/format/safety. Finite-draw p values use
`(1 + #at-least-as-extreme)/(10001)`. BH-FDR q=0.05 applies to the four individual per-axis tails;
the contrast p value is primary supporting evidence and remains separate. Persist the complete
`(10000,5)` draw-by-statistic matrix. Because signed improvement ratios have no finite estimator
bound, their achievable ceiling is unbounded; no zero-power ceiling claim or null-band decision gate
is made. No direction or tail is selected after seeing category scores.

### 6.3 Nuisance-respecting label-association null

For each axis, run 999 outcome-residual Freedman–Lane permutations with complete refitting. Fit the
axis's reduced outcome model on analysis-train. For train and test separately, form whole
3,584-dimensional reduced-model residual rows; studentize each row by its reduced-design leverage;
permute whole studentized residual rows within fixed exchangeability blocks of
`corpus × min(depth,4) × frozen prompt-length quartile`; undo the destination leverage scale; and
reconstruct null outcomes by adding the unpermuted reduced-model fitted values. Refit full and reduced
models on the null analysis-train outcome and score them on the independently permuted null
analysis-test outcome. The predictor design remains intact. This is the standard Freedman–Lane
outcome-residual construction with a prespecified blocked/studentized adaptation for corpus,
depth/length heteroskedasticity; exactness assumes residual-row exchangeability within blocks after
studentization, which is disclosed and checked by block sizes and residual-variance diagnostics.
Other semantic labels are columns of the reduced design and remain in the fitted component.

The observed full-space `DeltaSS_q` uses a one-sided upper tail. The full `(999,4)`
total-improvement matrix and per-axis 95th-percentile null thresholds are persisted. P-value floor is
1/1000. These permutations calibrate recoverability; they are distinct from the matched-rank
directional null above. Blocks of size one are reported and remain fixed; if more than 5% of either
partition lies in blocks smaller than five, the association-null calibration is invalid and the
affected axis cannot pass recoverability.

**Battery arithmetic and implementation:** outer bootstrap = 2,000 draws × two partitions × one
shared full plus four reduced weighted OLS sufficient-statistic fits; association null = 999 draws ×
four axes × two partitions, using FWL residuals; directional null = 10,000 draws × 3,584 membership
indicators × five statistics. Named helpers `batched_weighted_nested_sse`,
`batched_freedman_lane_outcome`, and `batched_matched_rank_null` process at most 8 refit draws or 256
directional draws per chunk. They use batched `einsum`/solve over response coordinates and weighted
sufficient-statistic SSE identities, never materializing `(draw,row,3584)` predictions and never
looping over response coordinates. P3 begins with one 8-draw production-shape block through the
actual dispatched helpers, records wall/RSS, and extrapolates by the code-derived multipliers
`ceil(2000/8) + 4*ceil(999/8) + ceil(10000/256) = 789` blocks. If the ×2 extrapolated battery wall
exceeds 2 h or RSS exceeds 32 GB, halt-and-report before the full battery; do not reduce draws after
seeing results. The `cpu-bigmem` 128-GB lane provides >4× the declared RSS gate.

## 7. Decision criteria

### 7.1 Kill / abort / stop criteria

The analysis halts and reports a provenance failure if any gate in §3 fails, any target axis is
rank-deficient after nuisance residualization in either partition, any primary denominator is
nonpositive or nonfinite after the recoverability gate, the registered 99% kernel dimension is not
reproduced, extraction does not cover all 9,941 holdout metadata rows and all 9,925 labeled activation
rows exactly once, or the measured 8-draw production battery pilot breaches the §6.3 wall/RSS gate.

### 7.2 Success criteria and verdict lattice

Evaluate the verdict in this strict order:

1. provenance/extraction/pilot failure ⇒ **abort and report**;
2. any axis fails recoverability, mapped-gain interpretability, or residual-null calibration below ⇒
   **partial/inconclusive**, without evaluating ratio-based support or refutation;
3. otherwise evaluate **strong support**, then **refuted**, then default to
   **partial/inconclusive**.

An axis passes **recoverability** only when observed full-space `DeltaSS_q > 0`, its outer-refit
bootstrap 95% lower bound is greater than zero, and it exceeds the axis's Freedman–Lane 95th
percentile null threshold (`p <= 0.05`, one-sided). It passes **mapped-gain interpretability** only
when its mapped improvement `sum_j s_j^2 delta_qj` is positive, the corresponding outer-refit 95%
lower bound is greater than zero, and no more than 2.5% of bootstrap draws have a nonpositive total
improvement denominator. Exact-zero ratio denominators are retained as nonfinite failures. The
residual-null calibration requires §6.3's small-block fraction ≤5% in both partitions.

**Strong support** for the scoped claim then requires all of:

1. all four axes pass recoverability, mapped-gain interpretability, and residual-null calibration;
2. outer-refit bootstrap 95% lower bounds for both `Delta_kappa` and `Delta_gain` are greater than zero;
3. for both estimands, at least two of the three individual topic-versus-axis point contrasts are
   positive;
4. both primary contrast directions reproduce in standardized coordinates at the 99% cutoff;
5. all provenance and battery pilot gates pass.

**Refuted** is evaluated only after all four axes pass the interpretability gates; it requires both
primary point contrasts to be negative and at least one corresponding 95% CI to lie wholly below
zero, or at least two of three individual axes reverse for both estimands.

**Partial/inconclusive** covers every other result, including a kernel-concentration difference with
no gain difference, a gain difference with no concentration difference, corpus-specific reversal,
format-only discordance, wide intervals, or any category failing the recoverability gate.
The paper wording must then enumerate the supported axes rather than state a general
topic-versus-response-regime rule.

The matched-rank null is supporting evidence, not a veto: a nonsignificant null result is reported and
prevents describing the concentration as unusually aligned to the learned kernel, but the observed
category contrast remains estimable.

The abort, interpretability-failure, strong-support, refuted, and residual partial/inconclusive
branches above are mutually disjoint and exhaustive by ordered evaluation. No result-dependent
threshold or category selection is permitted.

### 11.2 Risks

| Risk | Mitigation / interpretation |
|---|---|
| Labels are correlated, especially harmful topic and safety | primary FWL adjustment conditions on the other axes; cross-tabs and residualized rank/variance are reported; unadjusted estimates are secondary |
| Observed answer format is post-context | call it an answer-regime association, not a user instruction or causal factor; answer refusal is appendix-only secondary |
| Coarse topic rubric misses lexical semantics | restrict the claim to coarse topic/task genre; SAE/max-activation examples remain qualitative support for finer distinctions |
| Raw-coordinate SVD is scale-sensitive | standardized-coordinate SVD is mandatory robustness and cannot replace a disagreeing primary result |
| Category imbalance weakens rare levels | collapse only language levels with n<50 by a rule fixed before geometry; no topic/format/safety level is outcome-selected |
| Held-out category association is weak | report untouched-test incremental R2 and association-null calibration; the ordered lattice makes the claim partial/inconclusive before any ratio is interpreted |
| Weighted resampling is expensive | refit from batched sufficient statistics, pilot an exact production 8-draw block, checkpoint every 100 draws, and halt above the 2 h / 32 GB gate |
| Streaming source is large | one-shard-at-a-time extraction on CPU pod, 16 GB hard disk budget, verified compact upload before cleanup |
