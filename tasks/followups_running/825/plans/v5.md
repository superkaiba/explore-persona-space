## Goal / Hypothesis / Kill (proposal verbatim)

- **Goal:** extend the parent's exact MLP probe to the 6 unprobed cells to test whether the user-turn / naturalistic-assistant nulls are ridge-only (linearity) or information-absence.
- **Hypothesis:** user cells stay non-recoverable (MLP R² ≈ 0, above shuffle nulls ≈ −0.01, no practical power); the 2 naturalistic assistant cells recover like their chat siblings (MLP R² ≈ 0.4–0.55).
- **Kill / falsification:** MLP R² > 0.2 (nulls ≈ −0.01) in ANY user cell kills "user-turn maps have no practical predictive power" → Takeaway rewritten to "linear-only null".
- **Success read:** per-cell max-over-frozen-layers MLP R² vs its selection-symmetric 5-draw null band; report all 6 cells regardless of outcome.
- **Regression anchor (decided here, cheap):** `M_instruct_assistant_chat` + `M_pretrained_assistant_chat` ride along in `--cells` (ridge only, NOT in `--mlp-cells`): their fresh ridge R²@L19 must match the parent's committed values within ±0.05 (G1-style), confirming the staged shards + branch code reproduce the parent rig before the 6 new MLP reads are trusted. GPU Gram-space ridge (commit e011a0b1ca, ~200x vs CPU) makes this anchor ≈ minutes.
