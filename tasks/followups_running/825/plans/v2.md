# Plan v1 — Task #825: Is the per-example context→answer-profile map present in the pretrained model, and does it hold for the user turn?

Parent: #779. Kind: experiment. No `backend:` frontmatter → auto lane (GCP-first).

**Nature of the experiment:** pure representational analysis — teacher-forced forward passes over fixed text, residual-stream activation capture, and closed-form ridge regressions between activation vectors. **No model is trained or modified anywhere in this plan** (`N/A — no model training`; `N/A — no training hyperparameters`). The training-recipe rules (marker-training, contrastive-negatives, on-policy-completions) therefore do not fire. The DV is not an LLM-judged behavior (`N/A — no behavioral construct` in the judged-DV sense); measurement validity is declared per-DV in §6. `N/A — not a replication` of a published paper (the S1 anchor replicates our own #779 read; replication-fidelity to an external paper does not apply).

## 1. Goal

Test whether the per-example linear context-to-answer-profile map h: c_x -> v(x) (#779 recipe: held-out K-fold ridge over thousands of per-example pairs) exists in the pretrained Qwen/Qwen2.5-7B vs Qwen2.5-7B-Instruct, for both the assistant and the user turn, under chat-template vs naturalistic formatting; secondary: per-position decay and cross-role prediction beyond a topic-persistence baseline.

Terminology (repo-wide guard): `model ∈ {instruct, pretrained}`; never bare "base" (in this repo "base model" means Instruct-as-θ₀).

## 2. Hypotheses

- **H1:** the per-example map exists in the pretrained model (held-out R² > shuffle null), plausibly weaker / layer-shifted vs Instruct's curve (which peaks at L19 = 0.677 held-out R²; L14 = 0.598, L18 = 0.635, L26 = 0.604 — real #779 curve, see §5 anchor).
- **H2:** the user-turn map exists in both models; instruction tuning (assistant-only loss) could weaken it. Either direction is a finding.
- **H3 (format × model):** pretrained: naturalistic ≥ chat template; instruct: chat ≥ or ≈ naturalistic.
- **H4:** cross-role prediction beats the topic-persistence baseline (incremental R² > 0).

Falsification: each H is read off held-out R² vs its shuffle null + CI at the frozen layers and the selection-symmetric layer-max (§5). No H carries a pre-registered sign gate — a null user map in one model with a positive one in the other is a headline finding, not a kill (§7 kill criteria are wiring/validity gates only).

## 3. Prior work / Method delta

Bounded literature review (arXiv search, 2026-07-01; abstracts):

1. **Minder, Dumas, Juang, Chughtai, Nanda (2025), arXiv 2504.02922** — crosscoders on base-vs-chat residual streams (incl. Qwen-class chat models) isolating latents introduced by chat fine-tuning. Delta: compares representation dictionaries, not the predictability of next-turn activation profiles from context; no per-example R² map, no user-turn targets.
2. **Wu, Morris, Levine (COLM 2024), arXiv 2404.00859** — "Do language models plan ahead for future tokens?"; myopic-training tests show current hidden states carry information used at t+τ. Delta: anticipatory information exists, but measured via training-objective ablation on single-stream text; no fitted linear c_x→v(x) map, no pretrained-vs-instruct or role contrast.
3. **Pal, Sun, Yuan, Wallace, Bau (CoNLL 2023), arXiv 2311.04897** — Future Lens: linear/causal decoding of tokens ≥t+2 from a single GPT-J hidden state. Closest methodological ancestor. Delta: predicts future token identities short-range; we predict the mean activation profile of a whole next turn, across model, role, and template axes.
4. **Chen, Wu, Yeh, et al. (2024), arXiv 2406.07882** — TalkTuner: linear probes on LLaMa2-Chat activations decode user attributes during dialogue. Delta: static user attributes vs ground-truth labels; not whether context activations predict the user's next-turn representation content.
5. **Zhu et al. (ICML 2024), arXiv 2402.18496** — linearly decodable belief states of self and other agents (ToM probing). Delta: perspective/belief classification in narrative tasks, not a predictive map onto upcoming-turn activations in live chat format.
6. **Bortoletto et al. (2024), arXiv 2406.17513** — mental-state probes across model sizes and fine-tuning variants; instruction tuning improves internal belief representations. Delta: closest on the pretrained-vs-instruct axis, but DV is probe accuracy on belief labels, not held-out R² of a context→next-turn activation regression; no formatting manipulation.

**Method delta.** No found work fits a per-example linear (ridge) map from a single end-of-context residual vector to the mean activation profile of the next turn, with held-out K-fold R² as the DV. The factorial contrast — pretrained vs instruct × assistant-turn vs user-turn targets × chat-template vs naturalistic formatting, on matched token sequences, with per-position decay and a topic-persistence baseline — is absent from the bounded search. The user-turn (interlocutor-side) prediction target and the cross-role comparison appear novel under this search.

### 4.2 Constructs and slots (exact)

- Chat template: assistant slot = final token of `<|im_start|>assistant\n`; user slot = final token of `<|im_start|>user\n` opening u2. Profile v(turn) = mean residual-stream activation over that turn's content tokens (exclude role headers and `<|im_end|>`), per layer, all 28 layers.
- Naturalistic: `User: <text>\n\nAssistant: <text>\n\n…`; invariant slot rule = last token of the role header opening the turn (the `:`); profile = mean over content tokens between header and `\n\n`.
- One teacher-forced forward per (model, format, conversation) yields ALL slots and spans simultaneously (causal attention ⇒ a position's activation is unaffected by later tokens).
- c_x is the slot activation (one vector per layer); v(x) the turn-profile mean (one vector per layer).

## 5. Controls

1. **Row-shuffle null** — per cell, per layer: permute the c_x↔v pairing, refit, ≥20 draws; persist the full per-draw × per-layer matrix to `eval_results/issue_825/nulls_<cell>.json`. Provenance note (fact-checker): the ≥20-draw selection-symmetric null battery is a **#778** pattern (`sycophancy_finetune_nullbattery.json`; layer_sweep de-biased selection) — #779's percontext script itself ran no shuffle draws, so this wiring is NEW #825 code; the smoke pilot must confirm it emits the per-draw × per-layer matrices as promised.
2. **Selection-symmetric layer handling (#778 rule)** — the headline layer-max inherits selection per null draw (each null draw takes ITS max over layers); ALSO report frozen pre-registered layers **{14, 18, 19, 26}** — L14/L18/L26 from the body (#779 oracle band + #722 peak), L19 ADDED because #779's real held-out curve peaks there (0.677); the body's "0.60–0.63 band" was approximate.
3. **Random-projection control** — replace c_x with a dimension-matched random projection of it (fixed seed); a map recoverable from random features indicates trivial/global structure.
4. **Predict-the-mean baseline** — report skill-over-mean alongside raw R² (pooled held-out R² convention already uses the test fold's own mean; report both raw and skill).
5. **Bootstrap CIs** — over conversations (Track M; the i.i.d. unit) / examples (Track S); `metrics.bootstrap_within_condition_ci` pattern, 1000 resamples.
6. **Topic-persistence baseline (cross-role)** — previous same-role profile → target via the same ridge: v(u1)→v(u2) and v(a1)→v(a2); the cross-role claim lives in the INCREMENTAL R² of c_x over this baseline.
7. **R²(n) power bridge** — subsample S1 at n ∈ {250, 500, 1000, 2000, 5000} → held-out R²(n) curve; Track M cells (n=2000) are interpreted against R²(2000) on this curve, separating sample-size effects from representational differences.

## 6. Eval / metrics (measurement validity, per DV)

- **Primary DV — held-out reconstruction R²** (pooled; SS_tot from the test fold's own mean — #779 convention). Construct: how much of the next-turn mean-activation profile is linearly predictable from the end-of-context activation, per example. Metric: K=5-fold CV over examples, GCV-λ ridge, full 3584-dim target, per layer. On-distribution: computed by teacher-forcing the models over the EXACT token sequences the conversations produced (assistant text is the instruct model's own greedy output); both models see IDENTICAL token sequences, so any instruct-vs-pretrained difference is purely representational, not distributional. The pretrained model never generates — no off-policy generation concern arises.
- **Secondary — per-example cosine** between predicted and true profile (#779: median ≈0.93–0.96 at readout layers); distribution summaries persisted.
- **Secondary — MLP head** (`fit_h.mlp_fit_predict`, PCA-64) as a nonlinearity read, with its own shuffle null; #779 found linear ≥ MLP; report only with the null.
- **Per-position decay** — ridge c_x → activation at position p of the turn (held-out), positions with ≥80% coverage, restricted to peak layers (3–5 layers chosen from the main sweep); question: does early-position-best/decay hold per-example, for user turns, in the pretrained model.
- **Cross-role** — raw cross-R², topic-persistence baseline R², incremental R².

**Figures.** Hero: held-out R²-vs-layer overlays — 8 Track-M within-role cells + S1/S2 pair, with null bands and frozen-layer markers. Exploratory dump (over-produce for the analyzer): R²(n) power curve; per-position decay per role×model; cross-role bars with baseline + incremental; per-example cosine distributions; skill-over-mean by layer; chat-vs-naturalistic paired deltas per model; instruct-vs-pretrained paired deltas per role; null-draw distributions (selection-inherited vs frozen).

## 7. Success / kill criteria (jointly satisfiable — sequential validity gates, then open read-outs)

- **Gate G1 (S1 replication):** layer-curve Spearman ≥ 0.9 vs #779's `read1_heldout_recon` curve AND |held-out R² at L19 − 0.677| ≤ 0.05. Materially outside → wiring bug, HALT (kill).

- **Gate G3 (Track-M sanity):** the instruct/assistant/chat cell beats its shuffle null (observed R² above the max of ≥20 selection-inherited null draws) at n=2000; else generation-pipeline problem, HALT before interpreting user cells.
- **Success:** H1–H4 read-outs at frozen layers AND the selection-symmetric layer-max, with CIs and nulls. Any sign pattern is reportable — including a null user map in either model (headline finding, not a kill). No gate demands a specific H1–H4 sign, so G1–G3 + open read-outs are jointly satisfiable by construction.
