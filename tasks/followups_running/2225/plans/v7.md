## 3. Hypothesis

**Stated prior (registered): the expected result is NULL.** The parent's attribution cells localized the prevention failure to steering POSITION (its own working E1 direction fails at context tokens: F 83.88 ≈ C 84.33), so the pre-image arms — a different direction at the same positions — are expected flat. The user directed the run regardless ("add it now and make sure it runs"). The run is decision-relevant either way: a null completes the position-localization argument with the map-optimal direction; a positive overturns it.

**H1 (dose-response, the headline):** within each new arm's coherent range (coherence ≥ 80), the trait score falls as the coefficient rises. Registered read: Δdose = score(largest coherent coefficient) − score(smallest coefficient), question-paired. The parent's context arms were FLAT (evil ≈ 83 across 0.5→5.0); ANY reliable negative Δdose is the headline.
**H2 (contrast vs the parent's context arm):** at matched coherence, the pre-image arm prevents better than parent arm C: Δ_C = score(new arm @ its operating point) − score(parent C @ its operating point) < 0.
**H3 (direction-specificity):** any H1 effect exceeds the norm-matched random arm's: Δdose(pre-image) < Δdose(random) on evil (question-paired difference-of-differences, exploratory CI).
**H4 (off-direction):** a pre-image-steered model with a clean trait score but elevated probe/projection reads is reported as partial prevention, never success (parent rule, carried verbatim).

All registered paired reads use the verdict labels below, keyed to exactly ONE CI: the FROZEN-operating-point 95% question-paired bootstrap CI (10,000 resamples). The selection-inherited CI flavour is computed and reported as a sensitivity diagnostic only and never bears a verdict label. DISJOINT and exhaustive: Effect-negative ⇔ the frozen 95% CI is wholly below 0; Effect-positive ⇔ the frozen 95% CI is wholly above 0; Statistical tie ⇔ otherwise.

(Interpretation note, outside the lattice: for H1/H2, Effect-negative supports prevention/dose-response; Effect-positive on H2 means the pre-image arm prevents WORSE than parent C. A cell with no coherence-≥80 coefficient is "not computable", drawn empty per the parent's convention, never a zero bar. A verdict whose selection-inherited sensitivity CI disagrees in sign is flagged as selection-fragile in prose — the parent's evil E-vs-B cell precedent — without changing the label.)

### 4.1 Pre-image direction construction (F0; new module, ported algebra)

Inputs (all Hub-verified at plan time, §10): the two banked ridge-map payloads `issue779_monitoring/n1m_readout/weights/L{14,19}/ridge.pt` @ rev `9d8f789b` (realized keys VERIFIED by download + `torch.load` at plan time: `{kind:'ridge', selected_lambda: 0.001, xmu(3584,), xsd(3584,), ymu(3584,), W(3584,3584) fp32, layer, fitter}` — BOTH layers carry `selected_lambda = 0.001`, the λ-grid low edge: the 963k fits are effectively unregularized), and the parent's E1 persona vectors `issue778_persona_vectors/analysis_tensors_v2/rb_v2/{evil,sycophancy,hallucination}.pt` (28×3584).

Construction, per trait × layer ℓ ∈ {14, 19} (float64):
1. `M = Wᵀ` (M maps standardized context-end state → centered answer profile; the frame of `apply_map`, read from `issue779_ffc_n1m_fits.py@9b60558da7`).
2. SVD of M; truncation rank `k_used = #{i : Sm_i ≥ 1e-6·Sm_max}` (numerical-rank floor). Under the #1615/#2254 pre-registered rule (k* = #{s_i² ≥ λ} on the fit's standardized-X spectrum), λ = 0.001 with n = 963,444 standardized rows gives k* = full rank deterministically (every s_i² is ~9 orders of magnitude above 0.001 barring exact collinearity, §12 A3) — so the rule degenerates to the full pseudo-inverse and NO spectrum recovery is needed; the 1e-6 floor is a numerical-stability guard, disclosed.
3. `w_std = preimage_w(Um, Sm, Vmt, r_B[ℓ], k_used)`; `d_pre = destandardized_direction(xsd, w_std)` (unit-norm raw-residual-space direction).
4. **Frame-fold gate (HALT-class, implementation parity):** `cos(M @ (d_pre/xsd), P_k(r_B[ℓ])) ≥ 0.999` — near-tautological at full rank, kept to catch transpose/frame/standardizer bugs (the #2254 gate).
5. **Rank-sweep disclosure (free CPU):** cosines of the primary vs truncated-pinv at k ∈ {224, 896, 1792, 3584}, persisted — if the primary is tail-dominated (low cos to mid-rank variants), that is disclosed in interpretation, never re-selected on.
6. **Geometry diagnostics (Result-0 style, persisted):** cos(d_pre, r_B[ℓ]), cos(d_pre, parent E2[ℓ]/E3[ℓ]), cos(d_pre, random control), and the bridge cos(#778 rb_v2[ℓ], #779 r_b[ℓ]) (the map was fit under #779's captures; the scope directs the parent's E1 as r_B — the bridge cosine quantifies the frame mismatch; #779 r_b Hub-verified).
