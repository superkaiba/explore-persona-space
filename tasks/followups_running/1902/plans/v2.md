# Plan — #1902: How each post-training stage (SFT → DPO → RLVR) reshapes the context→answer activation map (OLMo-2 checkpoint chain)

## 0.0 TL;DR (plain English — the user reads this first)

- **What I'll run:** We know a model's internal "state after reading a question" predicts its "state while answering", both in a base model and in a fully post-trained one. I'll take the one open model family that publishes every intermediate step of post-training (OLMo-2: base, then SFT, then DPO, then the final RLVR model) and fit that predictor at each step, on ~10k real user questions. By crossing which model's activations we read with which model's answer text we condition on, a change in the map stays separable from a change in what the model says.
- **What I expect:** Each stage changes the map a little, but a simple change of coordinates recovers most of the previous stage's map. In other words, post-training reuses the base model's machinery instead of rebuilding it, and the change in what the model writes matters more than the change in the mapping.
- **What would change my mind:** A stage whose map, even after the best coordinate alignment, predicts the next stage's activations at less than half the quality of a map fit natively there. That would mean post-training genuinely rewrites how questions connect to answers, and it would weaken the theory that pre-fine-tuning geometry predicts post-fine-tuning behavior.

## 3. Hypothesis

Let Q(m, s, ℓ, F, arm) = pooled group-fold OOF R² of the map f fitted with fitter F on checkpoint m's activations over (context, answer text from source s), at layer ℓ, in the given arm. `layer*` = the frozen headline layer (§6). Retention ρ(i→j) = R²_aligned(i→j) / Q(j,j) where R²_aligned(i→j) is f_{i,i} composed with train-fold-fitted general-linear alignment maps (A_ans ∘ f_{i,i} ∘ A_ctx⁻¹, the #825 Leg-B recipe), evaluated on checkpoint j's held-out pairs at layer*.

- **H1 (map persistence — the registered headline).** R_adj = median over the 6 adjacent ordered stage transitions (B↔S, S↔D, D↔R) of ρ(i→j), context arm, ridge, layer*. Define Δ_conf = R_adj − 0.8 and Δ_kill = R_adj − 0.5. Grounding: on Qwen, #825's general-linear reparam retention was ≈1.00 (0.673/0.673) base↔instruct — recomputing the band on that precedent gives Δ_conf = +0.2 → the Confirmed branch, matching the prose that #825 supports map persistence. Falsification at 0.5 means even the best linear coordinate change recovers under half of native quality — a genuine rewrite.
- **H2 (stage-specific sharpening — estimation read, no registered verdict labels).** Pre-registered class contrasts on diagonal Q: (a) D→R on the math stratum (GSM8K-marked) and code stratum (MBPP-marked); (b) B→S on the generic single-turn pool; (c) S→D on the multi-turn (chat) corpus. Read: per-class ΔQ_c with cluster-grouped bootstrap CIs; exploratory most-moved-cluster reads carry selection-symmetric cluster-permutation nulls (§6).
- **H3 (text vs representation — estimation read).** Grid variance decomposition at layer*: range_s = mean_m[max_s Q(m,s) − min_s Q(m,s)] (answer-distribution effect) vs range_m = mean_s[max_m Q(m,s) − min_m Q(m,s)] (representation effect), per arm per fitter, with cluster-grouped bootstrap CI on (range_s − range_m). The body's H3 prediction is range_s > range_m.
- **H4 (low-rank edits — estimation read, conditional).** For ridge operators W_m at layer* (standardized-input primal weights, descriptive per the #1332 convention): effective rank ER(ΔW_adjacent) = (Σσ)²/Σσ² vs the same statistic on the #825-style matched nulls (shuffled-correspondence refit; spectrum-matched random operator), plus principal angles between adjacent W row/column subspaces, direction-aware (Procrustes-aligned) vs spectrum-only operator cosine per the issue1345 battery (50 rotation draws). Directional prediction: ER(ΔW_{D→R}) ≤ ER(ΔW_{S→D}) ≤ ER(ΔW_{B→S}) (the RL's-Razor / 2607.26119 prior). CONDITIONAL clause (from the task body): W_i and W_j live in different checkpoints' coordinates, so the raw ΔW read is interpretable only if the basis-stability descriptives pass (mean per-layer CKA(u_i, u_j) at layer* ≥ 0.7 and the aligned-vs-direct transfer gap small); otherwise only the ALIGNED operator comparison is narrated.

DISJOINT and exhaustive: H1-Confirmed ⇔ Δ_conf ≥ 0 AND Δ_conf's 95% CI excludes 0 on the positive side; H1-Falsified ⇔ Δ_kill's 95% CI is wholly below 0; H1-Inconclusive ⇔ otherwise.

(H2–H4 are estimation reads with CIs — no outcome labels are registered for them, so the lattice above is the plan's only registered verdict lattice.)

Row-coverage: both arms' registered rows are supplied per-context by analysis_tensors/issue1902_store/<ckpt>/<src>/<corpus>/L*.pt (every grid/transfer cell reads the same pinned intersection context set per corpus) and the per-fold fit outputs eval_results/issue_1902/fits/grid_cells.json.

### P2 — on-policy generation (pod; vLLM; shard by checkpoint across 4 GPUs)

Per checkpoint m ∈ {B, S, D, R}: 1 sample per context on both corpora (`SamplingParams(n=1, temperature=1.0, top_p=0.95, max_tokens=1024, seed=42)` — verbatim #779, `issue779_collect.py:558`), PLUS n=2 extra samples on a pinned 1,000-context single-turn subset (sampling-noise ceiling; seeds 43, 44).

- **Prompt render for generation = each checkpoint's NATIVE format** (on-policy quality): S/D/R via their chat template (`<|endoftext|><|user|>\n{…}\n<|assistant|>\n`, tokenizer-verified); B via the plain render `User: {q}\nAssistant:` (multi-turn: alternating `User:`/`Assistant:` lines) with stop sequences `["\nUser:", "User:"]` — the #825 naturalistic-render precedent.
- **Symmetric degeneracy filter across ALL four sources:** (a) truncation flag = generation hit the 1,024-token cap; (b) repetition-loop flag = any 8-gram repeated ≥8 times within one response (`ungrounded — needs smoke-test`; pilot-tuned). Per-source flagged fractions REPORTED, never silently dropped.
- **Intersection set:** grid analyses run on contexts where ALL FOUR sources produce an unflagged answer (truncated-or-degenerate in any source ⇒ dropped from the intersection; kept in a per-source full-set robustness read). Survival floor + re-sample policy: target intersection ≥ 8,192 (= 2d) per corpus; if below after the initial draw, extend the stream draw (next rows in deterministic order) up to the 800k scan cap and regenerate the shortfall; ≥ 5,000 after that → proceed with the n<2d caveat reported; < 5,000 → halt to re-plan (gate A′, §7). Applies to BOTH corpora.
- Generation engine: one config for all cells — `enable_prefix_caching=False` + `enforce_eager=True` (the #1324 real-corpus pre-launch checklist; one-engine-config-per-comparison), chunked `generate()` ≤500 prompts/call with per-chunk INFO logs, `use_tqdm=False`.
- All rollout text persists per checkpoint per corpus to `raw_completions/gen/{single,multi}/{ckpt}.json` the moment generation completes, BEFORE capture (persist-before-reduce; #779 lesson). Per-cell answer-length distributions computed here (required output).

### P4 — fits, transfer, operator battery (pod GPU; `scripts/issue1902_fits.py`)

All fits read the local store (still on disk on the ≥200 GB lane; re-staged from HF via `stage_hub_prefix` otherwise). Group folds: clusters partitioned into 6 fold-groups (seed 42; marked strata assigned whole-stratum to folds), identical fold assignment across every cell of a corpus (matched-target discipline, #1092).

1. **Layer sweep (diagonal cells, both arms):** ridge via `experiments/issue_779/fit_h.ridge_fit_predict_fast_layer_batched` (verified `grep → 180:def ridge_fit_predict_fast_layer_batched`; λ grid logspace(−2,4,13), GCV per slice; device="cuda"; float64) over 17 layers × 4 diagonal cells × 6 folds. Chunk the layer axis if the (L, n_tr, n_tr) Gram exceeds free HBM (17 × 8.3k² × 8 B ≈ 9.4 GB + eigh workspace — chunk to ≤8 layers/call). **Parity gate (mandatory per the fast twin's docstring):** slow-vs-fast (`ridge_fit_predict` L43 SVD path) on ≥3 slices at production shape, tolerance ≤1e-4 max rel diff, before any production fit is trusted. cuSOLVER eigh non-convergence → CPU-fallback wrap (`_eigh_robust` pattern, gotchas).
2. **Headline layer selection:** layer* = argmax over ℓ of the MEAN diagonal OOF R² across the 4 checkpoints (context arm). One shared layer for ALL compared cells ⇒ contrasts are selection-fair; the absolute headline carries both frozen-flank values and the full curve (§6). Prefix arm selects its own layer*_p the same way.
3. **Full 4×4 grid:** ridge at layer* ± {2, 4} (5 layers), all 16 (m,s) cells × 2 corpora × 6 folds, layer-batched. Per-context held-out squared-error components persisted per cell (`percell/*.npz`) — these feed every bootstrap/decomposition read without refits.
4. **MLP arm:** `fit_h.mlp_fit_predict` (verified `grep → 266`; hidden=MLP_HIDDEN=512 GELU, lr=MLP_LR=1e-3, wd=MLP_WD, ≤MLP_MAX_EPOCHS=300 early-stop, pca_k=64, seed 42, device="cuda") at the 5-layer band; MLP's own headline layer selected by MLP mean-diagonal predictivity (NOT by ridge predictivity — the body's requirement, avoiding a biased MLP−ridge gap). 2 arms × 16 cells × 6 folds × 5 layers ≈ 960 fits, GPU, per-unit JSONL persistence + resume + `[fits] unit k/N` progress lines (T2 trigger: >50 units).
5. **Transfer T(i→j):** for the 12 ordered pairs × {direct, general-linear-aligned, orthogonal-Procrustes-aligned, fixed-answer-text} × 6 folds × layer*: DIRECT = f_{i,i} applied to (u_j, w_j); ALIGNED = A_ans ∘ f_{i,i} ∘ A_ctx⁻¹ with A fitted on TRAIN folds only (general-linear = ridge maps u_j→u_i and w_i→w_j; orthogonal = closed-form Procrustes) — Ω_ans/A_ans fitted on SAME-answer-text pairs w_i(x,a_k) ↔ w_j(x,a_k) (fixed k=i) so the alignment never absorbs the answer-distribution change; FIXED-ANSWER-TEXT = f_{i,i} evaluated on (u_j, w_j(·, a_i)) — a cell the capture grid already contains.
