## 2. Design and selection freeze

2. **Split before inspecting evaluation.** Use the existing P-B group split and dataset holdout for each reported cell. Extraction excludes the whole evaluation dataset under P-B, its held-in evaluation groups, and content duplicates. Natural directions are fold-specific when historical P-B extraction pools are fold-specific. Group identities are source-qualified `(dataset, original_group_id)`, preserving original conversation/question/template grouping within each dataset; all response draws stay with their prompt. Cross-dataset content hashes and near-duplicate witnesses enforce content separation independently. A shared answer/entity label, especially a binary outcome such as 0/1, is not evidence that unrelated questions belong to the same group. Do not drop every TriviaQA prompt that shares an answer string with another dataset. Normalize full rendered prompts and first user questions using the existing project's dedup procedure and save exclusion witnesses. Keep original source text unchanged for extraction.
3. **Prompt-level elicitation.** For prompt `i`, average valid judged response scores to obtain `s_i`; for each layer average the same valid response activations within prompt to obtain `a_i`. Thus every prompt has equal weight, regardless of how many judgments survive. The primary extraction requires five original sampled model answers and at least three valid scored answers per prompt. Record complete-case five-answer sensitivity, raw and retained draw counts, content drops, API refusals, and transport loss separately. Missing/invalid judgments never become zero. No cross-rubric or score-scale mixing is permitted. Report scores in native units and a declared 0–100 display conversion where appropriate.
4. **Primary tail rule.** On eligible extraction prompts alone, freeze `q = 0.01`; choose the `k = max(1, floor(q N))` smallest and largest prompt means, breaking ties by SHA256 of length-prefixed UTF-8 `(behavior, fold, normalized-question hash, tie_salt)`, with primary salt `0`. The high and low prompt IDs/content must be disjoint; fold groups constrain extraction/evaluation separation, not whether distinct questions with the same entity label can appear in opposite tails. This is a new, ungrounded tail choice requiring the extraction-only smoke and reliability audit, not a validated optimum. It targets roughly 128 prompts per side before content exclusions under the 80% Reddit/TriviaQA group-training fold; actual group sizes determine the realized count. Record every cutoff, actual sample count, tied-boundary count, score quantile, high/low mean, response rate, and source composition. A highest tail below the trait's meaningful-expression range is labeled **relative high**, not maximum trait expression. This caveat applies to both screened HHRT and ToxicChat. Still score each nondegenerate natural fold, and show sparse-tail uncertainty rather than silently changing `q`, adding instructions, or withholding a weak result.
5. **Direction.** `r_answer[l] = mean_high(a_i[l]) - mean_low(a_i[l])`. Construct `r_context[l]` from the corresponding final-context vectors with the same prompt weights. Normalize only as the original Figure 6 pipeline does; save raw and whitened directions. Freeze the sign as high minus low before evaluation. Never flip a sign using evaluation correlations.
6. **Prespecified sensitivity.** Recompute the same construction at `q = 0.05` and `q = 0.10`, and report literal endpoint score counts/means. Use literal scale-endpoint means (0/100, or 0/1 for hallucination), not observed sample extrema, only if each side has at least 20 distinct groups; otherwise record insufficient support. Repeat only the 1% tails with hash salts `0` through `4`; keep salt `0` for 5%/10% tails, and add the five-valid-judgment `q01_complete` sensitivity. Use the five salted orders to expose arbitrary zero/one tie membership. These are robustness checks, not a menu from which to select a winner. The 20-group diagnostic threshold and primary three-valid-answer floor are new operational choices requiring a smoke; report their limitations.
7. **Content control.** Reuse or reconstruct historical E2 within-prompt high-minus-low response differences on the same eligible extraction population, with its existing spread minimum 15/100 (scale-adjusted explicitly for a 0–1 DV). Its final-context direction is structurally zero and recorded N/A. Recompute historical E2p midpoint extraction on that same population as a tail-selection control; keep the original historical E2p result separately because changing the eligible corpus also changes the result. Report prompt length, language, source/topic composition and direction stability, not a causal claim that a vector isolates the trait from content.
