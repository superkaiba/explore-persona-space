## §5 Conditions and Controls (the null battery)

Identical 4-null battery as #778 v2, applied to every monitoring test in BOTH legs. Every direction is compared on the SAME cached last-prompt activations + SAME graded trait-expression DV; only the projection direction changes (correlations recomputed on CPU, ~zero extra GPU). The matched-trait `r_B` is the positive reference.

| Plain-English name | What it tests | What it controls for | Config slug |
|---|---|---|---|
| Matched-trait direction | The cached `r_B` for the trait predicts that trait's expression under the corrected prompts / ICL contexts | (positive reference — the claim under test) | `matched` |
| Shuffled-label permutation | The diff-of-means machinery with pos/neg labels shuffled produces the r? | Whether the pipeline STRUCTURE (not the trait signal) manufactures correlation — the gold-standard null | `perm` |
| Norm-matched random direction | A random direction with matched norm + realistic activation-covariance overlap predicts as well? | Whether ANY plausible direction in the activation manifold predicts trait expression (the baseline the paper never ran) | `randnorm` |
| Cross-trait direction | The OTHER traits' cached `r_B` predict this trait | The paper's own specificity control — kept for direct comparison; treated as WEAK (traits correlated) | `crosstrait` |
| PCA top-5 of pos−neg diffs | The top-5 high-variance directions of the (pos−neg) activation differences predict as well? | Whether diff-of-means beats any generic high-variance direction in the same subspace | `pca_topk` |

**Control rationale** (verbatim from #778 v2 — the machinery is unchanged; the only difference is the input prompt set):
- **`perm` (gold standard):** re-runs the diff-of-means over the cached extraction activation pools with pos/neg assignment shuffled, ≥1000 times. Surviving above this band ⇒ the trait labels carry the correlation, not the machinery.
- **`randnorm` (NOT isotropic):** sample from N(0, Σ_activations), Σ = (1−0.1)Σ_emp + 0.1·diag(Σ_emp) (shrinkage λ=0.1 for PD-stability in 3584-dim), renormalize each draw to ‖r_B‖. Covariance-realistic, not an isotropic strawman.
- **`crosstrait`:** the paper's own control; recomputed identically.
- **`pca_topk`:** top-5 PCs of the stacked (pos−neg) per-pair activation differences.

Primary Success comparison = **observed matched-trait `max_over_layers(|r|)` > p97.5 of the null distribution of `max_over_layers(|r|)` per draw** (one-sided empirical p < 0.025, BH-adjusted). This is the exact policy #778 v2 shipped; `null_battery.py` already implements it.
