## What “mapping helps” means and controls

An affine map followed by a linear probe remains a linear function of the raw activation. It cannot add information; any gain is transferable regularization or conditioning. Verify identity-plus-bias parity and that mapped logits equal the algebraically composed raw coefficients. Retain a raw probe with the induced map penalty as an equivalence interpretation, avoiding an unstable explicit inverse (the map condition number is about 3.1 million).

Include outcome-independent input-orientation controls with the same singular spectrum in common fold-standardized raw coordinates; do not call output-only rotations a negative control. Compare a simple training-only shrinkage/PCA control if the primary map gain is positive. These diagnostics distinguish useful learned alignment from generic shrinkage. Do not infer map-specific semantic transfer solely from mapped beating ordinary raw L2. The primary raw/mapped comparison remains valid even if specificity is inconclusive.
