## 0.0 TL;DR (plain English)

- **What I'll run:** The main experiment showed that forcing just the first three words of an answer reproduces about two-thirds of what the full context-state patch does — on cells where the patch changes the answer's format. Language is the case where the "snowball" story should work best: an answer that starts in French tends to stay in French. Qwen3.5 has two strong cells where the patch flips the answer's language (the older Qwen2.5 model can't use them, which is why the main run skipped them). I'll run the same 12-arm opening-transplant grid — copy 1/2/3 opening words as text, or copy their hidden states — on those two cells, against a fresh same-run full-patch reference.
- **What I expect:** Forcing three opening words in the donor language recovers close to all of the full patch effect — much more than the ~two-thirds seen for format.
- **What would change my mind:** If a clear chunk of the effect is still missing after the opening is forced (the recovery ratio's confidence interval sits below 1), then the patch is doing something to language beyond picking the opening words — steering that persists as the answer unfolds, or something the opening's words and states only carry together.

## 3. Hypothesis

Language is the maximal-snowball prediction: an answer's language is committed by its first tokens and self-consistency propagates it, so transplanting the opening should reproduce (nearly) the whole ce-patch effect — unlike the format cells' ~2/3.

- **H-lang-max:** prefill-3 mediation separates from its null AND recovers ≈100% of the same-wave ce control (R₃ CI includes 1) — pure snowball for language.
- **H-residual:** prefill-3 separates but R₃ CI sits wholly below 1 — a reliable residual persists; consistent with EITHER persistent vector-level language control during generation OR a joint token+state early channel this roster does not isolate (the parent's two-residual-stories wording, held).
- **H-null:** prefill-3 paired diff CI wholly ≤ 0 — no detectable opening-borne effect (implausible given #2329's F 0.70 ce effects; registered for completeness).

**Registered confirmatory arm:** prefill-3, mediation (patch-content) donors — identical to the parent (no max-over-arm selection). Scheme (b) (B's-answer-start) instances carry descriptive "natural-opening" labels only.

**Primary verdict lattice (inherited verbatim from v5 §3; separation rule = the v5 conjunction: paired-diff pair-clustered bootstrap 95% CI strictly positive AND Holm-corrected exact Wilcoxon significant; conjunct disagreement ⇒ Indeterminate, reported):**
DISJOINT and exhaustive: Snowball-sufficient ⇔ separates AND D3 CI wholly ≥ 0; Snowball-partial ⇔ separates AND D3 CI wholly < 0; No-snowball ⇔ paired-diff CI wholly ≤ 0; Indeterminate ⇔ otherwise.
(D3 = mean over surviving pairs of F_beh(prefill-3 steered) − 0.5 × F_beh(same-wave ce control steered), pair-clustered bootstrap 95% CI, B=10,000, seed 23330 — v5 registered quantities, held.)

**Registered secondary ratio lattice (the language-specific read; R₃ = F̄(prefill-3 mediation steered) / F̄(same-wave ce control steered), pair-clustered bootstrap 95% CI):**
DISJOINT and exhaustive: residual-established ⇔ R₃ CI wholly < 1; overshoot ⇔ R₃ CI wholly > 1; pure-snowball-compatible ⇔ otherwise.
(An "included-1" outcome is compatibility, never a tested equivalence — the parent's natural-opening 100–105% wording convention, held.)

Auxiliary (descriptive, no verdict labels): recovery non-decreasing in k; mediation state patches vs prefills ordering; F_act mirrors F_beh in rank; per-cell reads (raw p, no per-cell family).

**Row-coverage (registered paired contrast, per arm):** steered rows from `eval_results/issue_2333/q35_language_snowball/f_metrics/f_cells.jsonl`, scheme-matched shuffled-donor null rows from `.../f_metrics/null_cells.jsonl` (both produced by this run's P6); same-wave ce-control rows (steered + null) from `.../f_metrics/ce_control_cells.jsonl` (this run's P6, from the fresh ce_control shards); banked companion rows from `.../inputs/i2329_lang_f_cells.jsonl` (vendored at implementation start from `origin/issue-2329 eval_results/issue_2329/f_metrics_capexcl/f_cells.jsonl` @ `b52657ee0e`, language-cell ce rows only, source ref + SHA recorded).
