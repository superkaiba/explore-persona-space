# Plan v3 (amendment) — Issue #813 follow-up `per-example-vs-averaged-map`: is the single-context (per-example) context→answer map the same function as the question-averaged map?

## 0.0 TL;DR (plain English)

- **What I'll run:** the parent experiment summarized each system prompt by *averaging* the model's activations over ~50 questions before fitting its prompt→answer map. Using only data already saved from that run, I'll fit a second map on the *individual* question-level pairs and check whether the two maps are the same underlying function — by swapping each map onto the other's task and by comparing their weights directly. No GPU, no new model runs.
- **What I expect:** mostly the same function. Averaging shouldn't change what a linear map is, so each map should work almost as well on the other's task, up to the noise you'd get refitting on a different question sample. The interesting extra: whether the per-question map also carries real question-specific signal the averaged map is blind to by construction.
- **What would change my mind:** if the per-question map does clearly worse on the averaged task than the averaged map does (beyond the refit-noise ceiling), or if the two weight matrices' dominant directions barely overlap — that would say averaging isn't just denoising, it changes what gets learned, which matters for everything built on these maps.

## 1. Goal

Determine whether the question-averaged context→answer map M the leakage-predictor line fits (Overleaf `c_C := E_x[c_x]` definition; #667/#722/#813 protocol) is the restriction of the same linear function the model applies per question, or whether averaging changes what is learned. #813 uniquely enables the clean same-grid comparison: it persisted per-question reduced pairs alongside its question-averaged fitted maps for the identical 50-context battery, 12 (behavior × substrate) cells, base + trained arms. If the maps agree (transfer symmetric within the refit ceiling, subspaces overlapping at ceiling), the predictor line's averaged M is a faithful estimate of the per-query function plus a possible query-specific component it is structurally blind to (quantified by DV4). If they disagree, "the map" is grain-conditional — a load-bearing caveat parallel to the parent's substrate question.

## 3. Hypothesis

- **H-same (primary):** the two grains estimate the same core linear function. Predictions at L14, per cell: (a) transfer near-symmetric — the paired per-fold gap ΔR²_avg = R²(M own, averaged task) − R²(h_pe→averaged task) has family-clustered 95% CI containing 0 OR sits within the question-half refit-twin ceiling gap ΔR²_twin; (b) top-k subspace overlap and CKA between W_pe and W_avg fall at or above the 5th percentile of the refit-twin overlap distribution. (Ridge pipelines are affine, so a linear h_pe applied to c̄ equals the mean of its per-question outputs — the commute prediction is exact, not approximate.)
- **H-extra (compatible with H-same):** h_pe transports genuine query-specific signal: within-context (context-mean-centered) held-out R² > the within-context question-shuffle null p95 (DV4). Both can hold — same core map + a query-specific component the averaged map cannot represent.
- **H-diff (falsifies H-same):** transfer asymmetric beyond the twin ceiling (ΔR²_avg CI excludes 0 AND exceeds ΔR²_twin) or overlap below the twin distribution's 5th percentile — averaging changes what is learnable (DV3's deviation from the analytic attenuation curve is the mechanism read).
- **DV6:** the parent's substrate verdicts re-read at per-example grain — em's band exceedance either survives its per-example question-resampling null (200 draws) or does not; fact/syco/marker point-estimate ordering preserved or not (descriptive).
- **Kill criterion (power):** if h_pe's own held-out R² ≤ 0 at L14 on the generic substrate in both arms, the per-example grain is noise-dominated → report the comparison as power-limited (descriptive only; DV3/DV4 inference legs skipped, point curves still reported).

Deviation from curve = averaging changes what is learnable, not just noise.
