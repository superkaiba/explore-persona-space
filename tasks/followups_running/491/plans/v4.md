## 0.0 TL;DR (plain English)

- **What I'll run:** One extra small training run. The main experiment taught the model a quirky habit (ending answers with a special symbol) using villain-flavored example answers, and found the trained habit spreads to other characters along a similarity pattern. This run trains the same habit on the same questions but with ordinary helpful answers instead of villain ones, keeping everything else identical — then checks whether the spread pattern still looks villain-shaped.
- **What I expect:** If the villain flavor of the training answers is what shaped where the habit spread, the helpful-flavored version should spread differently (and the similarity-to-villain predictor should stop working for it). If the spread looks the same either way, then training is just as content-blind as the prompt route turned out to be, and we cut that claim from the write-up.
- **What would change my mind:** Either outcome is useful — this run exists to replace an inference with a measurement. The main result (prompt route and training route disagree) stands regardless.
