## 0.0 TL;DR (plain English)

- **What I'll run:** We have two candidate "maps" from a prompt's internal state to the answer's internal state — a fitted statistical map and a measured cause-and-effect map. So far we have only asked whether they *predict* what happens. This round asks whether each map can *do* something: for ~150 pairs of real user prompts (A, B), I invert each map to compute the exact nudge to prompt A's internal state that the map claims will make the model produce B's answer instead of A's, apply that nudge while the model generates, and count — without any AI judge — how much of B's distinctive answer content actually shows up.
- **What I expect:** Very little. Every earlier read in this issue says neither map's directions move generations (steering-prediction cosines at most 0.05 even at the strongest coherent dose), so I pre-register LOW swap success for both maps, against a shuffled-target chance floor and a same-size random-nudge control.
- **What would change my mind:** If the fitted map's nudges reliably pull B's content into A's answers (above chance and above the random nudge), the correlational headline softens — the fitted map partially executes its own transformation. If the cause-and-effect map does it, the headline "the Jacobian recovers essentially none of the map's power" needs revising.

## 3. Hypothesis

**H-SWAP (pre-registered, from parent evidence):** BOTH operators show LOW swap success — B-content acquisition indistinguishable from the shuffled-target null and from the norm-matched random-delta arm. Grounds: prediction cosines ≤ 0.05 at the same dose, directional deficit (on-support operator cosine 0.178), per-cell shifts barely reproducible (split-half median ≤ 0.10).

Per-operator execution predicate (binary, CI-based): **E(Op) is TRUE** iff (a) the pair-clustered bootstrap 95% CI of ΔMRR(Op) = mean over pairs of [MRR_B(Op-steered) − per-cell shuffled-target null mean] lies strictly above 0, AND (b) mean MRR_B(Op-steered) exceeds the pair-clustered bootstrap 95% CI upper bound of MRR_B(random-delta arm, same targets); else FALSE. (recall@50 reported as the companion under the identical predicate shape; MRR carries the verdict.)

DISJOINT and exhaustive: Both-execute ⇔ E(M′) ∧ E(J_last); Fitted-only ⇔ E(M′) ∧ ¬E(J_last); Jacobian-only ⇔ ¬E(M′) ∧ E(J_last); Neither-executes ⇔ otherwise.

Interpretation registered in advance: Neither-executes confirms the parent headline at the causal-execution bar; Fitted-only softens the correlational headline (M′ partially executes its own transformation); Jacobian-only (or Both) revises Takeaways bullets 4–5.

**Registered paired contrast:** M′ vs J_last per pair (paired at pair level; the paired-difference ΔMRR(M′) − ΔMRR(J_last) with pair-clustered bootstrap CI is the decision-relevant contrast).

Row-coverage: the plan's own p3_swapgen phase produces every registered pair row on BOTH arms from one driver loop over one pair manifest — `swap_mprime` 150/150 pairs, `swap_jlast` 150/150 pairs, `swap_random` 150/150 pairs, `swap_a0` baseline 150/150 A-contexts; the p5_reduce driver set-checks the registered pair ids against each arm's realized rollout keys before the paired contrast. ## 7. Decision Gates + Success/Kill criteria

**Gates (engineering, pre-registered thresholds; per-criterion §4-mechanism binding stated inline):**

1. **G-SWAP-PARITY (smoke, BLOCKS — rc=8):** measured by the smoke leg's hook-parity probe (§4 reused stack): `n_edits == 1` per prefill-mode generate batch (count equality, DeltaHook counter), and a 1-row probe re-forwarding with the hook armed shows cx_last(14) shifted by exactly δ at position T−1 with per-row deltas (elementwise equality at fp32 tolerance 1e-4) — binds the per-row `(B,H)` edit to the capture slot. Failure = slot/batching defect; HALT until fixed.
2. **G-METRIC-SANITY (build, BLOCKS — no GPU spent):** measured by the `ref_ceiling` computation (§4 metric mechanism): mean recall@50 of T_B against B's OWN target text ≥ 0.8 across pairs (count-fraction threshold). Below ⇒ the metric cannot detect its own targets (tokenization/DF-filter defect); fix before production.
3. **G-DOSE-DEGENERATE (build, ABORTS production generation — rc=7-class report):** measured by the build report's claimed-fraction column (§4 delta construction): if median claimed fraction ‖Op·δ‖/‖Δv_target‖ < 1% for BOTH operator arms, the operators' own linear predictions claim <1% of the needed shift at the capped dose — a null generation result would be uninterpretable (dose-limited vs execution-failure indistinguishable); write the build report + abort before the 3,000 rollouts. One operator ≥ 1% ⇒ run everything (the other arm's read is reported as dose-limited).
4. **G-PILOT (pilot, rc=7):** measured 1-pair wall through the production entrypoint (dose-round convention); projected full wall > 2× the §9 budget ⇒ report JSON + abort.

**Cap-saturation interpretation gate (NOT a kill):** if > 80% of pairs cap-saturate in an operator arm, that arm's headline is framed as "swap success at the operating-norm dose" and claimed-fraction becomes a required covariate in every narration (pre-registered framing; the dose round already established 47.36 as the max behaviorally-validated coherent dose).

**Success criteria (quantitative):** the §3 lattice decides the headline. Pre-registered prediction: **Neither-executes** (E(M′)=FALSE ∧ E(J_last)=FALSE per the §3 CI predicate). Supporting reads that must accompany any E=TRUE claim: the judge SECONDARY contrast (steered − baseline B-content score) positive with pair-clustered CI excluding 0 for the same arm, and A-retention ratio > 0.5 (an arm that "acquires" B only by degenerating into noise fails the retention check and is narrated as incoherence, not execution — the random-arm comparison enforces this too).

**Kill criteria (round-level):** G-SWAP-PARITY unfixable within the round; G-METRIC-SANITY unfixable; G-DOSE-DEGENERATE fires on both operators; staging misses any §10 fitness check other than (i)/(k)/(l) (rebuild path per artifact-reuse rule). Judge-phase transport losses above the p3p4 threshold re-drive per the existing rc=4 convention (not a kill).
