### 3.2 Bin definition (13 overlapping views over answer positions 0…n−1)

```python
def bin_matrix(n: int) -> torch.Tensor:          # (13, n), rows sum to 1; empty row -> NaN
    idx = torch.arange(n)
    masks = [idx == 0,                            # "first"       (absolute)
             (idx >= 1) & (idx <= 4)]             # "tok2_5"      (absolute)
    dec = torch.clamp((10 * idx) // n, max=9)     # relative deciles
    masks += [dec == d for d in range(10)]        # "dec1".."dec10"
    masks += [idx == n - 1]                       # "last"        (absolute)
    M = torch.stack([m.float() for m in masks])
    s = M.sum(1, keepdim=True)
    return torch.where(s > 0, M / s, torch.nan)   # empty bin (n<10 deciles) -> NaN row
```

Bins are deliberately OVERLAPPING views, not a partition (first ⊂ dec1, last ⊂ dec10; for n ≤ 5, tok2_5 overlaps several deciles) — each bin pools its positions independently. **Short-span fallback (pre-registered):** for n < 10 some deciles are empty → NaN, excluded from within-bin means; per-bin contributing-draw counts are persisted and reported; a bin with 0 contributing draws in a cell renders as a gap, never a zero.

### 3.4 Shift / target / statistics per bin (CPU, batched)

Notation: `P_X[b, ℓ]` = nan-mean over draws of condition X's per-draw bin-b, layer-ℓ vector.

**Primary round (gen1c/gen1b — shared-baseline structure, so disjoint halves are REQUIRED):** split the 10 baseline draws into even/odd halves A/B (the parent recount's deterministic convention). For each (pair, arm, steer layer L ∈ {14, 20}, read layer ℓ = L, bin b):
- `target_b = P_ceiling[b] − P_baseline^A[b]` ; `shift_b = P_steered[b] − P_baseline^B[b]` ; compute both half-assignments and average (parent convention).
- `alignment_b = cos(shift_b, target_b)` — disjoint PRIMARY; the shared-baseline (all-10-draws) convention is computed as the labeled SECONDARY (parent reports both).
- `magnitude_b = ‖shift_b‖₂` ; companions: `‖target_b‖₂` and the normalized fraction `‖shift_b‖/‖target_b‖` (exploratory — noisy denominator, labeled).
- **Noise floor per bin:** `‖P_baseline^A[b] − P_baseline^B[b]‖₂` (5-vs-5 pure-noise magnitude; an order-of-magnitude floor — its draw arithmetic differs slightly from the shift's 10-vs-5, stated in the artifact).

**Replication rounds (rep43/44):** shift = `P_steered_rep[b] − P_baseline_rep[b]` (all 10 rep draws each); target = the PARENT's full-10-draw gen1b target — the legs come from disjoint rounds, so no half-splitting is needed (independence by construction; stated in the artifact).

**Per-bin null (scope pin — the parent's per-pair random-direction null recomputed per bin):** 500 random directions on the unit sphere in ℝ³⁵⁸⁴ (fresh RNG seed 14150), `cos(r_i, target_b)` per (pair, arm, layer, bin); p97.5 per cell. One batched GEMM: `(500, 3584) @ (3584, n_targets)` — never a per-draw loop (vectorize rule; the norm of r is irrelevant to cosine, so norm-matching is moot for this read). Cells are pre-registered ⇒ no selection-symmetric machinery needed (stated per scope): **N/A — no max-over-axis selection in any headline** (matched-layer, fixed α, per-bin profile reported at every bin — the profile SHAPE is the claim). **Noise-structure symmetry: fix 1 (disjoint baseline halves) registered** — this is the parent's own #-incident class and the corrected convention is inherited as primary.

**Pre-registered EARLY-vs-LATE contrast (the hypothesis-separation statistic):** per pair p, `E_p` = mean over EARLY bins {first, tok2_5} of `magnitude_b`; `L_p` = mean over LATE bins {dec8, dec9, dec10} of `magnitude_b`; `Δ_p = log E_p − log L_p` (within-pair log-ratio — scale-invariant across pairs). Pairs with an all-NaN EARLY or LATE set are dropped with a reported count (fail-loud if > 20% of pairs drop in any cell). Cell statistic: mean Δ̄ over pairs with a pair-level bootstrap 95% CI (resample the 28 pairs with replacement, B = 10,000, percentile CI, seed 14151; one vectorized numpy resample — CPU-trivial) + a Wilcoxon signed-rank companion on {Δ_p}. Reported per (arm × steer-layer) cell — 4 cells, side by side, never pooled or maxed. Alignment companion: `Δcos_p` = mean EARLY cos − mean LATE cos, same machinery, descriptive.

**Length-confound handling (scope pin):** per-cell answer-length distributions (token counts per draw, from `comp_ids` — no extra compute) persisted and reported per (condition × pair × arm × layer); the terse and formal pairs called out individually; all headline comparisons are WITHIN-bin across conditions; an exploratory matched-length sensitivity read restricts to pairs whose steered/baseline median-length ratio ∈ [0.5, 2].

## 7. Success / kill criteria (decision gates)

**No decision gates — short run (~1 h wall), inputs pre-verified.** The parity HALT (§3.5) is an in-run integrity check (artifact-routed report + distinct rc), not a user-facing gate; it only truncates the run.

**Hypothesis-separation criteria (per pre-registered cell — arm × steer layer, 4 cells reported side by side; NOT a pass/fail conjunction across cells):** the registered statistic is Δ̄ (mean early-vs-late log-magnitude ratio) with its pair-bootstrap 95% CI.

DISJOINT and exhaustive: Early-concentrated ⇔ Δ̄ > 0 AND Δ̄'s 95% CI excludes 0 on the positive side; Late-concentrated ⇔ Δ̄'s 95% CI is wholly below 0; Flat-or-inconclusive ⇔ otherwise.

Interpretation mapping: Early-concentrated supports H-b (early kick with decay); Flat-or-inconclusive with a TIGHT CI inside ±log(1.25) is reported as supporting H-a (persistent bias) descriptively — the flat-vs-underpowered distinction is adjudicated against the per-bin noise floor, never folded into the lattice; Late-concentrated (shift GROWS along the span — self-conditioning accumulation) is a legitimate third outcome, reported as such. Named sub-read: the terse pair's own Δ_p under H-b is predicted to be the panel's largest. The alignment-profile companion (Δcos) and the magnitude/alignment shape comparison are descriptive.

**Registered paired contrast:** Δ_p is a paired early-vs-late contrast within each of the 28 pairs, per arm.
Row-coverage: both arms' registered per-pair rows are supplied per-context by `analysis_tensors/issue_1415/position_profile/` per-cell binned tensors (steered legs) and the same store's `gen1b` baseline/ceiling cells (reference legs), reduced into `eval_results/issue_1415/answer_position_shift_profile/per_pair_profiles.json`; the driver set-checks the registered 28-pair × 2-arm × 2-layer row set against the reduced file's keys before the Δ statistic is computed.
