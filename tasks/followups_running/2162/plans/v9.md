## 0.0 TL;DR (plain English)

- **What I'll run:** The parent round found that a formatting instruction (or a persona) given a
  few turns back in a conversation stops transferring when we copy over the model's hidden state
  at just the final prompt token. On the same frozen conversations, I'll copy the hidden states at
  EVERY turn-end position at once (and at each single turn-end alone), to tell two stories apart:
  the instruction's trace fades everywhere as turns pass (decay), or it stays intact but spreads
  out across the per-turn end-points so any single position only carries a fraction (dispersion).
- **What I expect:** If dispersion is right, patching all turn-ends together at depth 5 recovers a
  large share of what the single-position patch gets at depth 1; if decay is right, patching them
  all together does no better than patching the final one alone. The per-boundary sweep then says
  WHERE any recovered trace sits.
- **What would change my mind:** A depth-1 sanity check must first reproduce the parent's
  single-position result exactly (same positions, same numbers within noise) — if it doesn't, the
  rig is broken and I stop. And if the no-effect control (a user's name, which never transfers at
  any single position) suddenly "transfers" under the all-boundary patch, the multi-position edit
  itself is broken, not the finding.

## 3. Hypothesis

The parent's recency null at single positions is underdetermined between:

- **H-decay** — the instruction's trace weakens at every position as turns accumulate. Prediction:
  the joint all-boundary patch performs no better than the single ce patch at d3/d5 (instruction-
  format d5 joint F ≈ its single-ce 0.244, still inside the nulls).
- **H-dispersion** — the trace stays intact but spreads across per-turn boundaries, so any single
  position carries a fraction. Prediction: the joint patch clears both nulls at depth and recovers
  a large share of the d1 effect (operationalized: ≥ 50% of this round's own d1 joint F); the
  per-boundary sweep then shows non-trivial mass at ≥1 non-final boundary.

Registered quantities (per base ∈ {instruction-format, prompted-persona}, registered metric space
per §6): J1 := min over the two nulls of the pair-clustered bootstrap mean paired difference
(steered − null) for the joint tb patch at depth 1; J5 := the same at depth 5; D :=
F_tb(d5) − 0.5·F_tb(d1) (steered surviving-pair cell means; pair-clustered bootstrap CI on D
reported alongside — a CI-straddling-zero D is narrated as GRADED, not binary, since both labels
share the decay-refuted headline); δ_disp := 0.5·Ĵ1 (the pre-registered dispersion effect — 50%
of this round's realized d1 joint paired-difference point estimate; the Decay power guard). d3 is
reported as the trend point, not a verdict input.

DISJOINT and exhaustive: Dispersion ⇔ J1's 95% CI excludes 0 on the positive side AND J5's 95% CI excludes 0 on the positive side AND D ≥ 0; Partial-trace ⇔ J1's 95% CI excludes 0 on the positive side AND J5's 95% CI excludes 0 on the positive side AND D < 0; Decay ⇔ J1's 95% CI excludes 0 on the positive side AND J5's 95% CI straddles 0 AND J5's 95% CI upper bound < δ_disp; No-verdict ⇔ otherwise.

The Decay power guard (blocker C): a bare J5 straddle with no width condition converts a
failure-to-reject into an affirmative headline exactly where §2 documents the CI inflating (~3×
denominator shrink, n 36 → 18 at depth). Decay therefore additionally requires J5's CI to EXCLUDE
δ_disp; a straddle whose upper bound ≥ δ_disp routes to No-verdict and is narrated as
failure-to-reject (underpowered), never as decay. δ_disp > 0 is guaranteed wherever the Decay
branch is reachable (it requires J1's CI positive). Report-scope caveat (carried into the report):
a joint-null verdict rules out dispersion across the PATCHED BOUNDARY SET only — a trace living at
non-boundary positions yields the same label, so the report's decay claim reads "no usable trace
at the turn-boundary position set", never the stronger unqualified decay prose.
