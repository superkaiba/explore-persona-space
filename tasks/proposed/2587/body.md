# Replicate the #2564 minimal-pair battery on Qwen3.5-9B (thinking disabled)

## Goal

On Qwen/Qwen3.5-9B with thinking DISABLED (the family's non-thinking chat-template mode), replicate the #2564 minimal-pair discrimination battery end to end and compare the per-axis discrimination profile against the Qwen2.5-7B-Instruct parent. Three phases: (1) fit a fresh context→answer ridge map for Qwen3.5-9B on 20–50k real-chat contexts (on-policy answers generated by the model itself, read-out layer selected by held-out R² sweep) — the battery's scoring arms are model-specific, so no parent arm is reused; (2) regenerate the full 984-context #2564 bank (K=10 draws, temp 1.0, seed_base 42) PLUS the two 2026-08-25 pilot axes (answer_language instruction axis, values {English, Chinese, Spanish}, install+swap; query_content_oneword, 24 token-matched single-word query pairs) on the new model, with answer-state + context-end activation capture; (3) run the parent battery reads (direction cos vs identity-delta baseline, calibration slope, matched-pair retrieval, manipulation checks incl. the programmatic language-fired check) with the new arms.
