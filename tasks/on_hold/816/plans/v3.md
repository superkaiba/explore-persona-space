# Task #816 Plan v3 — Full Rerun (Defect A + Defect B)

## Why a full rerun is required

An independent methodology audit (v32 AUDIT-HALT, 2026-07-02) found two
defects that invalidate all completed Phase-A/B/C outputs:

**Defect A — Contaminated random null.** Every "random" baseline direction in
the completed run was drawn from `null_battery._shrunk_cholesky` fit on the
POOLED pos+neg #778 extraction covariance. Because `r_B = mean(pos_acts) −
mean(neg_acts)`, the top PC of the joint pool ≈ `r_B` (cos 0.996 / 0.985 /
0.736 across evil/sycophancy/hallucination). Random draws were near-copies of
the persona vector, not independent. Tell: Exp-5's randnorm band-max
0.936/0.814/0.748 towers over cross-trait 0.38/0.65/0.68 and PCA
0.50/0.29/0.45 in the same JSONs — physically impossible if random were
honest. Sycophancy's p=0.085 "random matches" verdict is a contamination
artifact. The Exp-2/Exp-4 random arms have these near-copy directions baked
into generations/adapters.

**Defect B — Unfaithful r_B.** #778's r_B was extracted without the released
code's coherence gate and with unpaired filtering, tainting all real arms.

User directive (v35, 2026-07-02): "do the full rerun for both 816 and 778."
Cost ~68–73 GPU-h + ~$330–350 judge — within the 100 GPU-h auto-approval cap.

   excluded from correction).
9. Persist per-draw × per-dataset matrix for each family (rule:
   selection-symmetric-nulls.md).

## 11. Decision Rationale (v3 additions / replacements)

**r_B v2 (CHANGED from v2 §11).**
- **What:** use r_B re-extracted by #778 v2 follow-up round at
  `issue778_persona_vectors/analysis_tensors_v2/rb/`.
- **Why:** v1 r_B lacked the coherence gate and used unpaired filtering —
  faithfulness to the paper's published code (`persona_vectors` @ `b8e0f04`)
  requires both. The defect was identified in the v32 AUDIT-HALT.
- **Source:** #778 v2 follow-up round `faithful-extraction-honest-nulls-rerun`
  (producing session running in parallel).
- **Alternatives:** re-extract within this task (rejected — #778 v2 session
  already owns the re-extraction; forking a second extraction wastes GPU and
  diverges from the audit directive "reuse the shared v2 artifacts").

**Honest null ladder — independent/neutral-cov (REPLACES v2 randnorm §11).**
- **What:** N(0, Σ_neutral_ℓ) renormed to ‖r_B v2[ℓ]‖; Σ_neutral from #778 v2
  neutral-cov artifact, estimated under non-trait prompts.
- **Why:** the v2 null covariance was estimated from pooled pos+neg extraction
  activations — the same activations that define r_B — so the top PC of the
  null pool ≈ r_B (cos 0.996/0.985/0.736), making the null a near-copy.
  Neutral-cov is estimated under genuinely unrelated prompts, giving
  independent draws.
- **Source:** #778 v2 neutral-cov artifact + null-contamination audit (v32).
- **Alternatives:** isotropic null (kept as a family but not the headline
  null — too conservative; doesn't model real activation geometry).

**Isotropic null.**
- **What:** N(0, I·σ²_ℓ) with σ²_ℓ = ‖r_B_v2[ℓ]‖²/dim, renormed.
- **Why:** the minimal honest null — no geometric assumptions. Included as the
  conservative null alongside neutral-cov.
- **Source:** norm-matching convention (#778); isotropic null is a standard
  comparison in the steering-specificity literature.

**Within-class / projected-out / r_B-projected-out nulls.**
- **Source:** ungrounded — needs smoke-test for shape validity; no prior issue
