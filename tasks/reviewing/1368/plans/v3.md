## §3 Design

**File:** `scripts/verify_task_body.py` only (plus tests + 2 doc files, §4/§5).

### Design decision 1 — scope: ALL prose paragraphs in each `### <result>`, not only post-caption interpretation

Grounding: SPEC caps **each** beat at 1–3 sentences (L424–432: setup AND interpretation), and the L851–853 register rule caps all `## Results` prose at "1–3-sentence units". Lens 12's FAIL wording is "any single paragraph runs ≥4 sentences" — paragraph-general. Capping all paragraphs also removes the need for beat segmentation (no figure-position bookkeeping), and the plan-time trace shows beat-1 setup paragraphs count 1 sentence on every measured body, so the wider scope adds no observed noise. `## Methodology` is deliberately NOT scanned (Methods prose is reference material, excluded from the skim-prose budget per SPEC L736; the Goal + Lens 12 name `### <result>` prose). Figure-less results ARE scanned (their analytical prose is still register-governed) — unlike check 21, which exempts them for a structural reason that doesn't apply here.

### Design decision 2 — sentence splitting (deliberately simple, WARN-only)

Boundary = `[.!?]+` immediately followed by whitespace or end-of-paragraph, counted AFTER masking, in order:

1. Inline code spans `` `...` `` → placeholder token (protects `run_result.json`, `no.`-like identifiers).
2. Markdown link targets `](...)` → `]` (protects dotted URLs/paths in targets).
3. Abbreviation list — strip the trailing period of: `e.g.`, `i.e.`, `vs.`, `et al.`, `cf.`, `Fig(s).`, `Eq.`, `approx.`, `no.`, `ca.`, `resp.`, `incl.` (case-insensitive, `\b`-anchored).
4. Decimals: `(?<=\d)\.(?=\d)` removed (belt-and-suspenders; the whitespace lookahead already protects most).
5. Ellipses `...` / `…` → space.

Count = number of split segments containing ≥1 word character (`re.search(r"\w", seg)` per segment of `re.split(r"[.!?]+(?=\s|$)", masked)`), so trailing unterminated text counts as one unit. Semicolon-joined clauses deliberately count as ONE sentence unit (matches the `_V4_GOOD_BODY` register and the corpus style).

**Known residuals (stated, accepted — WARN-only):** false negatives on sentence-ends inside brackets (`…gap.)` — period followed by `)`, not whitespace) and on `;`-chained walls; false positives on unlisted abbreviations followed by a space (`Tab. 2`, personal initials `J. Smith`). Calibration on 7 real bodies (§12 row A1) observed zero splitter artifacts; the flagged #958 6-count paragraph was hand-read and is genuinely 6 sentences.

### Function-level pseudocode (placement: after `check_v4_results_beat`, ~L9995)

```python
# Constant block (~L914):
V4_RESULT_PARA_MAX_SENTENCES = 3  # SPEC § Conciseness caps (v4); ≥4 WARNs (#1368, #1333)

_SENTENCE_ABBREV_RE = re.compile(
    r"\b(?:e\.g|i\.e|vs|et\s+al|cf|figs?|eq|approx|no|ca|resp|incl)\.", re.IGNORECASE
)
_INLINE_CODE_RE = re.compile(r"`[^`]*`")
_LINK_TARGET_RE = re.compile(r"\]\([^)]*\)")
_LIST_ITEM_RE = re.compile(r"^\s*(?:[-*+]\s|\d+[.)]\s)")

def _result_prose_paragraphs(block_text: str) -> list[str]:
    """Maximal runs of consecutive prose lines inside one `### <result>`
    block; a blank / caption / table / heading / image / HTML / fence /
    list-item / hr line terminates the current run. `<details>` bodies
    stripped first (the `_prose_words` convention, L9416)."""
    block_text = _DETAILS_BLOCK_RE.sub("", block_text)
    paras, cur, in_fence = [], [], False
    for line in block_text.splitlines():
        s = line.strip()
        if s.startswith(("```", "~~~")):
            in_fence = not in_fence
            if cur: paras.append(" ".join(cur)); cur = []
            continue
        if in_fence: continue
        if (not s) or s.startswith((">", "|", "#", "!", "<", "---")) or _LIST_ITEM_RE.match(line):
            if cur: paras.append(" ".join(cur)); cur = []
            continue
        cur.append(s)
    if cur: paras.append(" ".join(cur))
    return paras

def _count_sentences(paragraph: str) -> int:
    """Guarded [.!?]-split sentence count (see §3 decision 2)."""
    p = _INLINE_CODE_RE.sub("CODE", paragraph)
    p = _LINK_TARGET_RE.sub("]", p)
    p = _SENTENCE_ABBREV_RE.sub(lambda m: m.group(0)[:-1], p)
    p = re.sub(r"(?<=\d)\.(?=\d)", "", p)
    p = p.replace("...", " ").replace("…", " ")
    return sum(1 for seg in re.split(r"[.!?]+(?=\s|$)", p) if re.search(r"\w", seg))

def check_v4_result_paragraph_sentences(body: str) -> CheckResult:
    """Check 36 (v4 only, WARN): each prose paragraph inside a
    `### <result>` runs 1–3 sentences (SPEC § Voice (v4) Rule B /
    § Results three-beat; Lens 12 backstop). WARN never FAIL —
    register judgment stays with the clean-result-critic (#1368)."""
    label = "Results paragraph sentence cap (v4)"
    if not is_v4(body):
        return CheckResult(label, True, "skipped — not a v4 body")
    results = _v4_results_body(body)
    if results is None:
        return CheckResult(label, True, "## Results missing — check 2 will report")
    result_h3s = _collect_tldr_h3_names(results)
    if not result_h3s:
        return CheckResult(label, True, "no `### <result>` headings — check 3 will report")
    rlines = results.splitlines()
    flagged: list[str] = []
    for idx, (name, line_no) in enumerate(result_h3s):
        end_line = result_h3s[idx + 1][1] if idx + 1 < len(result_h3s) else len(rlines)
        block = "\n".join(rlines[line_no + 1 : end_line])
        over = [n for n in map(_count_sentences, _result_prose_paragraphs(block))
                if n > V4_RESULT_PARA_MAX_SENTENCES]
        if over:
            flagged.append(f"'{name[:48]}' has a {max(over)}-sentence paragraph")
    if flagged:
        preview = "; ".join(flagged[:2]) + (" …" if len(flagged) > 2 else "")
        return CheckResult(
            label, True,
            f"{len(flagged)} of {len(result_h3s)} `### <result>`(s) carry a "
            f"≥{V4_RESULT_PARA_MAX_SENTENCES + 1}-sentence paragraph (v4 register: 1–3 "
            f"sentences per paragraph — split or tighten): {preview}",
            is_warn=True,
        )
    return CheckResult(
        label, True,
        f"all `### <result>` paragraphs ≤{V4_RESULT_PARA_MAX_SENTENCES} sentences",
    )
```

(~70 lines including docstrings/comments — well inside the §7 descope bound. The prototype of exactly this logic produced the §12 row-A1 trace.)
