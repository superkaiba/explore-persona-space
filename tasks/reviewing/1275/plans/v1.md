uv run python scripts/task.py post-marker <N> epm:<kind> --version <n> \
  --file /tmp/issue-<N>-<kind>-r<n>-marker.md

| Risk | Likelihood | Mitigation |
|---|---|---|
| sed extraction fragility: Codex omits the end tag → extraction runs to EOF or empty | Medium (known malformed-output mode) | Step-3 gate: `grep -q` the end tag on the EXTRACTED file before posting; failure routes to the EXISTING stricter-retry re-dispatch (cap 2) — the same path a tag-missing output takes today; never a Read-to-diagnose on a trigger-dense round |
