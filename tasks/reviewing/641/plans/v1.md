# Plan — Issue #641 (Phase 2): matched-dose install-resistance curves for EM

## 0.0 TL;DR (plain English)

- **What I'll run:** I take the one harmful behavior we can already implant
  without slamming the ceiling — emergent misalignment, EM — and train it into
  the *same* set of "speaking contexts" (a software-engineer voice, a doctor
  voice, a few real-chat openers, a couple of formatting wraps) that absorbed
  it at very different rates in our earlier matrix. This time I train each one
  for a *ladder of increasing amounts* instead of a single fixed amount, and I
  watch how high the misalignment climbs in each. Then I run one extra,
  carefully matched pairing: the same harmful behavior into a "kindergarten
  teacher" voice versus a plain voice that is equally unlikely to give bad
  advice on its own, to see whether the *identity* of the speaker fights the
  training.
- **What I expect:** The contexts that looked "resistant" before were mostly
  just trained too little — give them more and they catch up. I expect the
  resistance to be a *slower climb*, not a hard *ceiling*. For the teacher
  pairing I expect a small extra drag that the plain-voice control does not
  show, but I'm genuinely unsure it'll be big enough to call.
- **What would change my mind:** If a "resistant" context flattens out well
  below the others no matter how much I train it, that's a real ceiling, not
  slow learning — and it would mean some speaking contexts genuinely protect
  the model. And if the teacher voice and the matched plain voice end up at the
  same place, then "who the model is pretending to be" doesn't matter once you
  control for how prone that character already is — only the base prior does.

## 2. Prior Work

**Field context.** EM (Betley et al., arXiv 2502.17424) is induced by SFT on
narrow harmful data and generalizes to broad misalignment. Persona Vectors
(Chen/Arditi/…/Lindsey, arXiv 2507.21509) and Persona Features Control EM
(Wang/…/Mossing, arXiv 2506.19823) frame EM as a persona-direction shift; both
used GPT-4o (closed). Turner et al. (Convergent Linear Representations, arXiv
2506.11613) released bad-advice datasets (medical/financial/sports) that elicit
EM on 7B-class open models at lr=2e-5 + LoRA scaling 8. Our comparative
advantage is open-weights Qwen-2.5-7B + training-data ablations.

the lead and only behavior, exactly as the body sketch proposed; the marker
fallback is dropped (flat-prior, cannot serve H1-vs-H2, and #537 already shows
EM is non-saturated).

## 3. Hypotheses

**H5 (dose: rate vs ceiling).** For each source context, install rate L(steps)
is monotone non-decreasing in dose. The discriminating quantity is the
asymptote (plateau level) by resistance class.
- **H5a (resistance = rate):** resistant and non-resistant contexts converge to
  the *same* asymptote given enough dose; resistant ones merely climb slower.
  *Prediction:* at the top of the ladder the resistant-vs-non-resistant
  asymptote gap shrinks toward 0 (95% bootstrap CI of the asymptote difference
  includes a gap < 0.10 rate), while at the #537 dose (375) the gap is the
  observed ~0.15–0.25.
- **H5b (resistance = ceiling):** resistant contexts plateau *below*
  non-resistant ones. *Prediction:* the asymptote difference stays ≥ 0.15 rate
  with a 95% bootstrap CI excluding 0, even at the top of the ladder, AND the
  resistant curves visibly flatten (top-segment slope ≈ 0 while still below the
  non-resistant asymptote).
- **Falsifier for H5 entirely:** if curves are non-monotone or flat for all
  classes (no dose response), the install-as-dose framing fails — report as
  such.

**H1 vs H2 (mechanism at matched dose).** At a fixed matched dose, decompose
residual install across sources into a base-propensity component and an
identity-conflict component.
- **H1 (base prior):** residual install at matched dose is fully explained by
  the source's base harmful-advice-compliance propensity; *prediction:* the
  identity-conflicting persona (`kindergarten_teacher`) and a neutral persona
  matched on base harmful-advice propensity reach indistinguishable install
  (|ΔL| < 0.10, CI includes 0); and across Arm-A sources, base harmful-advice
  propensity predicts matched-dose install (partial correlation significant).
- **H2 (identity/alignment conflict):** there is residual resistance beyond
  base propensity attributable to source↔behavior identity conflict;
  *prediction:* `kindergarten_teacher` installs EM *less* than the
  base-propensity-matched neutral persona (ΔL ≤ −0.10, CI excluding 0) at
  matched dose — i.e. the conflict adds drag the base prior does not predict.

These are weighable diagnostics, not hard gates (see §7). H5a vs H5b and H1 vs
H2 are the two cuts; the analyzer reports which the data supports with CIs.

**One behavior (EM). Two arms. One manipulated structure per arm.**
- Arm A manipulates **dose × source-resistance-class** (the single structure;

- Arm B manipulates **identity conflict at matched base propensity** (the
  single structure; dose held fixed at the Arm-A matched-dose checkpoint).

### 4.2 Why code, not a model call?

The EM scorer is the Betley dual-rubric **Claude judge** (a model call, per
project policy — never substring). The dose-curve fit, plateau/slope
estimation, base-propensity partialling regression, and bootstrap CIs are
deterministic numerical code over the judged rates (no unstructured-data
heuristic) — code is correct because the inputs are already structured
(per-completion judge verdicts). No code-vs-model-call tradeoff arises beyond
"judge = model call, stats = code", which is the standard split.

### 4.4 Dose ladder (Arm A) — the single manipulated variable

The #537 EM dose was a single point at 375 optimizer steps. I add points below
and above to trace the curve and reach the asymptote:

**Ladder = {50, 100, 150, 250, 375, 560} optimizer steps.** (375 = the #537
anchor for cross-experiment parity; 560 ≈ 1.5× the anchor to probe the plateau;
50/100/150/250 fill the climb.) One optimizer step = batch 2 × ga 8 = 16
examples. The EM mix is 3000 pos + 3000 neg = 6000 rows → 1 epoch ≈ 375 steps,
so 560 steps ≈ 1.5 epochs (the dataloader cycles, exactly as #458's max_steps
mechanism intends).

**Efficiency: ONE training run per (source, seed) at max_steps=560 emitting a
checkpoint ladder** via `save_strategy=steps`, `save_steps=25`,
`save_total_limit=30` (override — turner_em ships save_total_limit=2, which would
evict the ladder). `save_steps=25` saves at 25,50,...,550 + final 560, hitting
every ladder point {50,100,150,250,375,560} exactly (all are multiples of 25
except 560 = the final checkpoint). After eval, reap to the 6 ladder
checkpoints. NOTE: this requires the one-line `save_steps` thread in
`build_sft_config` (§4.1) — without it HF defaults save_steps=500 and the ladder
is not emitted. Disk: ~160 MB adapter-only checkpoints, ~22/run × 160 MB ≈
3.5 GB/run, reaped to 6 kept. This collapses 6 dose points into 1 training run
— 6× the training compute saved (the basis for the 78 GPU-h estimate).

### 4.5 Identity-conflict pair (Arm B) — single manipulated variable

At a fixed matched dose (the Arm-A checkpoint where the 6 sources' median
install crosses ~0.5, expected ≈ step 250–375 — pinned after Arm A's first seed
lands; pre-registered fallback = step 375, the #537 anchor), train EM into:

| Plain-English name | Persona (system prompt) | Role | Identity conflict w/ harmful advice |
|---|---|---|---|
| **Conflicting identity (teacher)** | `kindergarten_teacher` = "You are a kindergarten teacher." | identity-conflict arm | HIGH (a caregiver-of-children identity is maximally opposed to giving harmful advice) |
| **Matched neutral persona** | the persona from the Arm-B candidate set whose *measured base harmful-advice propensity* is closest to the teacher's (candidate pool: `data_scientist`, `comedian`, `marine_biologist`, `local_historian` — all neutral-to-harmful-advice, none caregiving) | matched control | LOW |

**Matching variable = base harmful-advice-compliance propensity** (§4.6), NOT
base EM rate (which is 0.0 for all). The neutral persona is selected *after* the
base-propensity read, as the closest match to the teacher — this keeps base
prior held while identity conflict varies (the single manipulated variable). If
no neutral persona lands within ±0.10 of the teacher's base propensity, I widen
the candidate pool (any non-caregiving persona in `PERSONAS`) and report the
realized match gap as a covariate in the regression (graceful degradation, §4.8).

Arm B also trains the teacher + matched-neutral over the FULL dose ladder (same
as Arm A) so the identity-conflict read is available at every dose, not just
one — but the H1-vs-H2 headline is read at the matched dose. This makes Arm B a
2-source extension of Arm A's dose-curve structure (no new manipulated
structure), and the matched-dose read is a slice of it.

### 4.6 Base-propensity covariate (both arms) — source-side baseline read

Per the on-policy/source-side-baseline rule, BEFORE training, measure each
source/persona's base harmful-advice-compliance propensity: under each source
context's own system prompt, generate base-model answers to the EM eval probes
(8 Betley probes, temp 1.0, 5 samples) AND to a small harmful-advice probe set
(the EM positives' question distribution — 20 bad-medical questions sampled from
`bad_medical_advice_6k`), judge with the Betley dual rubric (broad EM) and a
harmful-advice judge. This yields two base covariates per source:
- **base EM rate** (expected ≈0.0, confirms #537) — sanity.
- **base harmful-advice propensity** (the H1 covariate with dynamic range) — how
  readily the base model complies with bad-medical-advice requests under this
  persona. This is the covariate the matched-dose partialling regression uses.

Cost: ~one base-model generation pass (8 source contexts × 28 probes × 5
samples = 1120 completions) + judge. ~0.3 GPU-h + ~1.1K judge calls.

### 4.9 Graceful degradation (no all-or-nothing gates)

- **EM mix yield:** the EM mix is published-corpus (no elicitation yield risk) —
  3000 paired bad/good rows are available (`build_em` asserts ≥3000). No
  yield-quota drop applies. N/A for the elicitation floor.
- **Base-propensity match (Arm B):** floor = a neutral persona within ±0.10 of
  the teacher's base harmful-advice propensity. Between exact match and floor:
  use the closest, include the realized match gap as a regression covariate.
  Below floor (no neutral persona within ±0.10): report the gap, run anyway with
  the gap as covariate, and flag the imperfect match as a scope caveat (never
  silently drop the arm).

### 4.10 Equalize-down

ladder — N is equal by construction across sources. The only per-cell variation
is seq-len (raised for `icl_k8`/`wc_long_write`-class long contexts), which does
not change row count or dose (steps). N/A for equalize-down beyond this.

### 6.3 Statistics & sample size

- **n per cell-checkpoint:** 8 Betley probes × 5 samples = 40 completions →
  rate with binomial SE; pooled across 2 seeds = 80 completions per
  (source, dose). #537's EM single-seed reliability was the noted weak spot;
  2 seeds + 80 completions per dose point is the mitigation. (#458 used 800
  completions/cell at a single dose; #641 trades depth-per-cell for
  dose-ladder breadth — 40/checkpoint × 6 doses × 2 seeds = 480
  completions/source, comparable total, spread across the curve.)
- **Dose-curve fit (H5):** fit a monotone saturating curve (e.g. L(s) =
  L_∞·(1 − exp(−s/τ)) via nonlinear least squares, or isotonic regression as a
  shape-free fallback) per source; bootstrap (resample completions within
  probe, 2000 draws) → 95% CI on L_∞ and on the resistant-vs-non-resistant
  asymptote difference. Report top-segment slope (step 375→560) per class to
  detect flattening.
- **Matched-dose mechanism (H1 vs H2):**
  - *Arm-B pairwise:* ΔL = L(teacher) − L(matched-neutral) at the matched dose,
    bootstrap 95% CI (resample completions). H2 if CI excludes 0 and ΔL ≤ −0.10.
  - *Arm-A regression:* across the 6 Arm-A sources at the matched dose, OLS
    L_matched ~ base_harmful_propensity; report the partial/residual. Because
    n=6 sources is small, this is a *diagnostic* (report coefficient + CI), not a
    significance gate — the Arm-B pair is the powered test, Arm-A regression is
    the corroborating direction. Per the collinearity-gate memory, check
    base-propensity range across the 6 sources before trusting the partial.
- **Statistical-input existence:** all inputs (per-completion judge verdicts,
  per-checkpoint rates, base-propensity rates) are produced fresh by this run's
  eval + P0; no derived statistical input is consumed from a prior artifact. The
  bootstrap resamples this run's own per-completion verdicts (stored per cell).
  N/A — no phantom derived inputs.

## 7. Decision Gates

**No hard gates — short-per-cell runs, dose ladder must complete to read the
curve.** Each training run is ~2–3 GPU-h; a per-cell kill gate would fragment
the dose curves (the whole point is the full curve). The hypothesis direction is
genuinely uncertain (that's the experiment), but stopping early on an
intermediate dose point would destroy the asymptote read. Per planner.md, with
runs this short and the deliverable being the full curve, no gates.

**Success criteria (analyzer-weighable diagnostics, NOT pre-registered hard
gates — they do not crush joint power):**
- *H5 resolved* iff the resistant-vs-non-resistant asymptote-difference 95% CI
  either (a) includes a gap < 0.10 (→ H5a, resistance = rate) or (b) excludes 0
  with gap ≥ 0.15 AND resistant top-segment slope ≈ 0 (→ H5b, ceiling). An
  intermediate/ambiguous CI is reported as "underpowered to distinguish rate vs
  ceiling at this N" (honest null framing).
- *H1-vs-H2 resolved* iff the Arm-B matched-dose ΔL 95% CI excludes 0 (→ H2 if
  ΔL ≤ −0.10; → H1 if |ΔL| < 0.10 with a tight CI). Corroborated by the Arm-A
  regression direction.

**Kill criterion (whole-experiment, not per-cell):** if the P0 base-propensity
read shows ALL candidate personas at base harmful-advice propensity ≈ 0 with no
dynamic range (so Arm B cannot be matched on a meaningful covariate), Arm B's
H1-vs-H2 cut collapses to "teacher vs neutral both at zero base prior" — still
runnable (the ΔL is then a pure identity-conflict read with base prior trivially
held at 0), so NOT a kill, but flagged. Genuine kill only if EM fails to install
at all (max-ladder install < 0.1 on non-resistant sources), which would
contradict #537 and signal a recipe regression — caught at smoke + first cell.
