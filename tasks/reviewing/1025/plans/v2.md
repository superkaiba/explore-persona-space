## 3. Design — exact files + per-file diff sketches

Regex forms whitelisted (scope decision — minimal, incident-grounded):

| Form | Regex | In/out |
|---|---|---|
| Hash-prefixed task ref | `#(\d+)(?!\d*\.\d)` | IN (the incident form; `(?!\d*\.\d)` keeps `#0.74`-style AND `#720.5`-style text out of the extraction entirely — a decimal-bearing token matches NOTHING, so all its atoms stay in the numeric accounting; fact-checker verified the earlier `(?!\.\d)` spelling backtracked on `#720.5` to a truncated id `72`) |
| Task path | `tasks/[a-z_]+/(\d+)\b` | IN |
| Branch/path ref | `issue[-_](\d+)\b` | IN (covers `issue-720` branches and `issue_720` result paths) |
| `plans/v<K>.md` | — | OUT — K∈{1..5} is already scaffold-covered; not an id class the incident needs |
| PR refs (`PR #484`) | rides `#(\d+)` | Accepted side effect: clears only when the integer happens to be a live task id; it is still an identifier, never a result value |
| Bare `issue720…` (no separator) | — | OUT — appears inside handed paths and clears by multiset as today |

**Trace condition** for each extracted prompt-side id `N`: (leg a) `N` appears in any of the three reference forms in `plan_body`/`lens_items`/`prior_critique_summaries`, OR (leg b) `str(N) in json.load(open(registry_path()))["tasks"]`, with `from explore_persona_space.task_workflow import registry_path` (NEVER a cwd-relative `tasks/...` path — CLAUDE.md critical rule; verified live: the map has 961 entries, `'720'` present, `'999999'` absent). **Fail-safe:** if the registry is unreadable (import error / missing / bad JSON), leg (b) contributes NOTHING — print a WARN and fall back to leg (a) alone. Fail-STRICT: degrades to today's behavior (the ref blocks and the composer re-composes without it), never weaker than #722.

**Ordering (load-bearing):** extraction runs BEFORE numeric tokenization and SYMMETRICALLY on the prompt AND all three handed-span files — so `#720` never enters the atom multiset as a bare `720`, and a handed span's own `#<M>` no longer donates a bare `<M>` atom that could mask a composer-fabricated bare `<M>`.
