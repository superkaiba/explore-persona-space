## Method delta (vs the candidate's diff sketch — two deliberate refinements)

- **Section-scoped exclusion instead of the sketch's line-pattern grep.** The
  sketch inserts `grep -vE ':: [A-Za-z]+Warning: '` BEFORE the
  line-number-blanking sed, but pre-sed warning lines read
  `path:57: DeprecationWarning:` (single colons around the lineno) — the
  pattern only matches the POST-sed form, so as sketched the exclusion never
  fires. And a line-pattern grep misses the section's HEADER lines
  (`tests/test_issue1689_fit_ladder.py::test_x` — these name the payload path
  of a branch-new test and have no baseline twin) and source-echo lines.
  Fix: drop the whole warnings-summary section with a bounded awk range
  (start `^=+ warnings summary`, end at the pytest `^-- Docs:` terminator
  line). Fail-safe direction: if pytest's terminator format ever drifts, the
  awk drops trailing file-grain lines only — file-grain fails toward pass
  while node-grain (reading the RAW leg file, untouched) remains the blocker
  for genuine failures, matching the gate's documented semantics.
- **Guarded prefix normalization.** As above (acceptance criteria 2-3); the
  sketch's bare `s|$WT|...|` is kept in spirit but parameter-defaulted.

## Concrete diff (both sites; shared block shown — surgical block identical modulo indent)

```bash
      for leg in baseline gated; do
        awk '/^=+ warnings summary/{w=1; next} w && /^-- Docs:/{w=0; next} !w' \
          "/tmp/issue-<N>-tg-$leg.txt" \
          | grep -F -f /tmp/issue-<N>-tg-files.txt \
          | grep -vE '^E +assert ' \
          | sed -E 's/at line [0-9]+/at line N/g; s/:[0-9]+:/::/g; s/:[0-9]+([^0-9]|$)/:N\1/g' \
          | sed -e "s|${WT:-/__eps_no_wt__}|<TREE>|g" -e "s|${REPO_ROOT:-/__eps_no_root__}|<TREE>|g" \
          | sort -u \
          > "/tmp/issue-<N>-tg-$leg-hits.txt" || true
      done
```

(`grep -F -f FILE` moves from reading the leg file to reading awk's stdout;
everything else in the surrounding blocks byte-unchanged.)
