**Per-agent procedure (implementer):**
1. Inventory: parse every index row → (row text, target path(s), theme/trap class).
2. Classify each row exactly once:
   - KEEP — live, unique lesson.
   - MERGE(group) — ≥2 rows teaching the same trap/fix class → ONE row that still reaches every grouped body (multi-link row). Both/all original bodies stay reachable.
   - RETIRE — superseded: (a) the lesson is now enforced by a named always-on surface (cite the exact CLAUDE.md bullet / rule file / lint check / hook / agent-spec line — verify the citation resolves by grep before retiring), or (b) the target/pattern it warns about no longer exists (REQUIRES a recorded repo-wide relocation grep, the workflow-fix-on-bug clause (b) discipline — a single-path probe never backs a nonexistence claim).
3. Apply edits; keep the one-line-per-memory shape.
4. Reconcile: `ls` each agent dir vs surviving row targets; record intentionally-unreferenced bodies in the manifest.
5. Verify: no-flags `workflow_lint.py` + a link-resolution loop (grep each row's path token, `test -f` it).

**Concurrent-append hazard (load-bearing):** review rounds fleet-wide append rows to these three indexes on `main` while the branch is open. At Step 10d merge time, BEFORE the merge, run `git -C "$WT" diff origin/main...HEAD -- .claude/agent-memory/` and fold any rows APPENDED ON MAIN after the branch fork into the curated copies verbatim (dedupe only when a main-side row is byte-identical to a row already covered by a merge). The Step 5a family-atomic sync will correctly skip `.claude/agent-memory` (branch-dirty singleton family) — the fold is manual and this plan's step, not the sync's. `.gitattributes` union-merge on agent-memory md is the backstop, not the mechanism.
