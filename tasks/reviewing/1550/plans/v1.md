```python
# ─── Check 40 — header version label vs persisted filename (outside CHECKS) ─

_C40_FILENAME_RE = re.compile(r"v(\d+)\.md")          # fullmatch on plan_path.name
_C40_HEADER_RE = re.compile(r"(?i)^plan\s+v(\d+)\b")  # on first heading TEXT

def check_header_version_vs_filename(plan: str, *, plan_path: Path) -> CheckResult:
    """WARN when the plan's first heading self-declares `Plan v<X>` and the
    persisted filename is v{K}.md with X != K (#1482: '# Plan v4' rode
    v5.md + v6.md). Version-neutral titles PASS (the sanctioned escape);
    a non-v{K}.md filename SKIPs (nothing to compare). WARN-only, all kinds."""
    cid = "c40_header_version_vs_filename"
    name = "header self-declared version matches persisted filename"
    m_file = _C40_FILENAME_RE.fullmatch(plan_path.name)
    if not m_file:
        return _skip(cid, name, "filename carries no v{K}.md version (draft / standalone plan)")
    _, body = split_frontmatter(plan)
    heads = _headings(body)
    if not heads:
        return _skip(cid, name, "no headings in plan")
    m_head = _C40_HEADER_RE.match(heads[0].text)
    if not m_head:
        return _pass(cid, name, "header is version-neutral — no self-declared version")
    x, k = int(m_head.group(1)), int(m_file.group(1))
    if x == k:
        return _pass(cid, name, f"header v{x} matches persisted {plan_path.name}")
    return _warn(
        cid, name,
        f"header self-declares v{x} but the persisted file is {plan_path.name} — stale "
        f"version label (#1482: '# Plan v4' rode v5+v6 unnoticed); retitle the header to "
        f"v{k} or make it version-neutral ('# Plan (amendment) — …' / '# Plan — Issue #<N>: …')",
    )
```

- **D1 — Regex + heading scope: first heading of ANY level (via `split_frontmatter` → `_headings()`), pattern `(?i)^plan\s+v(\d+)\b` on the heading TEXT.** Why: `_headings` is already fence-aware (a fenced first line can't be misread as a header) and strips the `#` prefix; first-heading-only prevents false hits on later prose/headings quoting sibling versions ("Divergences from parent plan v3"); any-level (not H1-only) still catches a hypothetical H2-opening plan. Source: verify_plan.py:375–430 (read); incident headers (read on disk). Alternatives: raw-line regex on line 1 (breaks on frontmatter and fenced first lines); H1-only (misses nothing today but is a needless restriction).
- **D2 — `--plan-file` mode PARSES a `v{K}.md`-shaped filename; SKIPs otherwise.** Why: unlike c23, c40 needs no task context — only `plan_path.name`, present in both modes; parse-when-versioned gives free coverage for direct `--plan-file tasks/…/plans/v6.md` re-verifies (exactly where a critic checks a specific version), while `.claude/plans/issue-<N>.md` drafts SKIP cleanly. Source: main() :6526–6560 (read). Alternative: SKIP-always in `--plan-file` mode (c23 parity) — rejected as it blinds the check in the one manual invocation that would use it; cost of parsing is nil.
- **D3 — Wiring: append in `main()` after the c23 block, before the `overall` recompute; NOT in `CHECKS`.** Why: `CHECKS` entries share signature `chk(raw, kind)`; threading `plan_path` through `verify_plan_text()` would touch every call site for one check. c23 sets the precedent for main()-appended context-bearing checks. - **D4 — WARN detail names the sanctioned fix (retitle to v<K> OR go version-neutral).** Why: mirrors the #1482 consistency-checker prose; the WARN is the teaching surface, making skill-prose duplication unnecessary. Source: #1482 events (quoted in task body). Alternative: bare mismatch report — cheaper but pushes the fix discovery onto the next reviewer.
