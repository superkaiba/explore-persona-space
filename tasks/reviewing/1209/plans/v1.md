### 4.2 New pure predicate — trigger 5, `failed-turn-silence`

**Shared anchor helper (small refactor, semantics-preserving):** extract the newest-parseable-row-ts scan currently inline in `_wedge_rate_windowed_failed` (L2073-2077) into

```python
def _wedge_newest_row_ts(trailing_rows: list[dict]) -> float | None:
    for row in reversed(trailing_rows):
        ts = _row_ts(row)
        if ts is not None:
            return ts
    return None
```

and reuse it in both `_wedge_rate_windowed_failed` and the new helper.

**New helper (mirrors `_wedge_rate_windowed_failed`'s shape, L2059-2084):**

```python
def _wedge_dead_silence_fired(
    trailing_rows: list[dict],
    turns: list[tuple[str, float | None]],
    dead_silence_s: float,
    now: float,
) -> bool:
    """#1209 `failed-turn-silence`: True iff the tail holds >= 1 completed
    turn, EVERY completed turn is "failed", and the newest parseable row
    timestamp is >= dead_silence_s older than `now`. Zero completed turns
    (the #779 swallow shape) never fire (vacuous-all guard — the
    dequeue-run trigger owns swallows); a ts-less tail leaves the silence
    anchor undefined -> NO-FIRE; a future-dated anchor (clock jump) makes
    now - anchor negative -> NO-FIRE."""
    if not turns or any(outcome != "failed" for outcome, _ts in turns):
        return False
    anchor = _wedge_newest_row_ts(trailing_rows)
    if anchor is None:
        return False
    return now - anchor >= dead_silence_s
```

**Predicate wiring in `decide_prompt_wedge_reason`** (L1958-2035) — two new keyword-only params, defaults chosen so every existing call site is byte-identical:

```python

) -> str | None:
```

- The early turn-lane exit at L2020-2021 becomes:

  (so `_segment_wake_turns` still runs when only the new trigger is armed).
- After the existing `failed-turn-run` / `failed-turn-rate` checks (precedence order preserved — the new trigger is the WEAKEST evidence, checked LAST):

- **Determinism/replay-testability:** `now` is an explicit parameter (never wall-clock inside the predicate) — the same posture as the rate trigger's newest-row-ts anchor (L1998-2005). With `now=None` (all pre-existing pure callers, incl. `decide_prompt_wedge(tail, 3)`) the trigger is inert, so the #1127 bool-wrapper backcompat contract (L2096-2101, pinned by `test_decide_prompt_wedge_bool_wrapper_backcompat` at tests L1721) is untouched. `decide_prompt_wedge` (L2087-2113) gains the same two kwargs, pass-through.

**"No rows follow for ≥ T" computation + failure modes:** silence = `now − newest parseable row ts` where `now = time.time()` threaded from `stalled_session_pass` (L10751) and row ts are Claude Code's own ISO-8601 `timestamp` fields parsed by `_row_ts` (L1893-1908; ts-less/malformed rows → `None`, excluded from the anchor scan — the incident's trailing `last-prompt` row is ts-less, so the anchor is the api-error row itself). Clock skew ≈ 0 (transcript writer and watcher share the host clock); a forward clock jump on the row side makes `now − anchor` negative → NO-FIRE; a ts-less entire tail → anchor `None` → NO-FIRE. **Tail-window truncation:** the 256 KB tail (L10142) can hide older `ok` turns of a very long final turn (>256 KB), making "all completed turns failed" vacuously true over the visible window — accepted residual: such a session's last visible turn genuinely failed and it has been silent ≥20 min, and the respawn is fresh-context recovery (CLAUDE.md § refusal-ladder (f)); bounded by the caps below. A too-thin window otherwise fails toward NO-FIRE (fewer rows ⇒ fewer/no completed turns).

**Why all-completed-turns-failed rather than last-turn-failed:** a healthy mid-life session whose latest wake ended in one transient trailing api-error has prior `ok` turns in its tail → blocked regardless of silence (its tick cron is armed; the existing `failed-turn-run` lane owns a genuine repeat at ≥3). The all-failed condition confines the trigger to sessions with ZERO successful history in the visible tail — the died-young shape — for which a fresh respawn loses essentially nothing even when a later wake might have arrived.

### 4.3 Env knob + constants (fail-open parsing, sibling parity)

```python
# #1209: silence threshold for the failed-turn-silence trigger — a session
# whose every completed tail turn FAILED and whose transcript has been
# silent this long is dead-wedged (a turn-1 refusal death never arms the
# tick cron, so no wake will ever grow the other counters; incident
# 8e9c371d / #1092: 1 failed turn at 02:54:29Z, next respawn 04:33Z).
# 20 min = 2 watcher ticks (a mid-turn 429-retry gap is seconds-minutes,
# never 20 min of zero rows) and clears the 15-min RESPAWN_SPAWN_GRACE_S
# window by construction (death follows spawn by >= ~1 min).
TICK_WEDGE_DEAD_SILENCE_S = 20 * 60

def _tick_wedge_dead_silence_s() -> float:
    """Dead-wake silence threshold in seconds. Env
    EPM_TICK_WEDGE_DEAD_SILENCE_MIN is in MINUTES (the
    EPM_TICK_WEDGE_RATE_WINDOW_MIN precedent); default
    TICK_WEDGE_DEAD_SILENCE_S. `0` DISABLES the trigger (the
    _tick_wedge_min_api_errors new-trigger-class kill-switch convention —
    here the window IS the trigger arm, so 0 must mean off, not default);
    malformed / NEGATIVE env falls back to the default."""
    raw = os.environ.get("EPM_TICK_WEDGE_DEAD_SILENCE_MIN")
    if not raw:
        return float(TICK_WEDGE_DEAD_SILENCE_S)
    try:
        parsed = float(raw) * 60.0
    except ValueError:
        return float(TICK_WEDGE_DEAD_SILENCE_S)
    if parsed < 0:
        return float(TICK_WEDGE_DEAD_SILENCE_S)
    return parsed
```

Name refinement vs the sketch's `EPM_TICK_DEAD_WEDGE_MIN`: `EPM_TICK_WEDGE_DEAD_SILENCE_MIN` joins the existing `EPM_TICK_WEDGE_*` family (L1284/1315/1347/1377/1407) — deliberate, stated divergence from the candidate sketch.

**Default threshold justification:** 20 min ≥ 2× the 10-min watcher cadence (≥2 observation ticks before firing); mid-turn retry gaps (429/backoff) produce new rows within seconds-minutes, never 20 min of zero rows after an api-error row; the trigger arms at death+20 min ≈ spawn+21.5 min, past the 15-min `RESPAWN_SPAWN_GRACE_S` (L564) deferral, so no grace-window fighting. Deliberately NOT ≥45 min (the tick-cron cadence): for a zero-successful-turns session, waking a refusal-poisoned 1-turn conversation is a worse recovery than a fresh-context respawn (CLAUDE.md (f): "the recovery's actual mechanism is the FRESH CONTEXT"), so preempting a possible next wake is acceptable — and the all-failed gate means the preempted session has done no work worth preserving.

### 4.4 Respawn-cap bounding

**Existing caps, audited:** the stalled lane's only cap is `STALLED_MAX_RESPAWNS = 3` **per staleness episode** (L1466), enforced inside `decide_session_stalled` (L1609, L1623) — but (a) the wedge override path (`_apply_prompt_wedge_override`, L10068-10167) never reads `respawn_count`, and (b) the episode counter is CLEARED on self-report advancement (L10489-10491), and each die-on-turn-1 replacement writes one boot self-report (§4.1) ⇒ **every generation is a fresh episode and no existing cap can bound a cross-generation die-on-boot loop**. The per-day caps belong to OTHER passes (orphan `ORPHAN_MAX_RESPAWNS_PER_DAY_DEFAULT = 2`, L10841; capacity-retry 4/day, L13643). The fleet-level auth-outage guard (#1027) suppresses the stalled arm as a unit (`_handle_stalled_respawn` L9580-9588) but requires ≥2 distinct issues — a single-issue persistent refusal (exactly #1092's saga: repeated same-issue model-pathway refusals) never triggers it. Un-capped, the new trigger would loop ≈ every 35-40 min (spawn → boot self-report → die → +20 min silence → fence stop tick → spawn tick) ≈ up to ~40 cold ~100K-token session loads/day on one issue.

**Therefore two bounds on the NEW trigger only** (existing triggers' semantics untouched):

1. **Episode belt:** arm dead-silence only when `respawn_count < STALLED_MAX_RESPAWNS` (thread `respawn_count` into the override as a defaulted kwarg; available at the call site, L10501/10621-area).
2. **Day cap (the real cross-generation bound):** new fields in `stalled-<N>.json` — `dead_silence_respawn_day: str|None` (UTC `"%Y-%m-%d"` via `time.gmtime(now)`, the orphan-pass precedent at L11194) + `dead_silence_respawns_today: int` — persisted via `_save_stalled_state` (L5966) with `first_seen`-style carry-from-`prev` defaults (L6035-6037 pattern) so every wholesale re-save preserves them, **deliberately OUTSIDE `_stalled_hardening_fields`'s advancement-clear** (L6075-6099) — the cap exists precisely because advancement resets the episode counters each generation. New constant + getter:
   ```python

   def _tick_wedge_dead_respawns_per_day() -> int:
       # env EPM_TICK_WEDGE_DEAD_RESPAWNS_PER_DAY; malformed / < 1 -> default
   ```
