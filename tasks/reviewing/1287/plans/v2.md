## 4. Design

### 4.1 Fork resolution — option (a) extended with a tail arm; explicitly NOT option (b)

v1's single-arm option (a) is refuted by the incident's own transcript (revision note). v2 keeps the option-(a) vehicle — the boot-death lane — and gives it a second arm reusing #1209's proven predicate PIECES:

- **Arm 1 (zero-response, #1267/#1251-class): byte-unchanged behavior.** Whole-file read via `_boot_death_transcript_rows` (whole-file guarantee is the point for "zero rows"; >256 KB ⇒ rows=None — a >256 KB transcript genuinely cannot be a *zero-response* boot-death). Correctly owns its class; nothing to fix.
- **Arm 2 (boot-refusal, #1287/#1277-class): 256 KB TAIL + turn segmentation.** `_transcript_tail_rows(pid, max_bytes=BOOT_DEATH_TAIL_BYTES)` (L9504: happy-log-only resolution, seek-tail, partial-first-line dropped, `None` when unresolvable — works at ANY transcript size; this is how the wedge lanes handle big transcripts) → `_segment_wake_turns` → fire when `len(turns) >= 1 and all(outcome == "failed")` — the exact `_wedge_dead_silence_fired` all-failed condition.
- **This is NOT option (b) smuggled in.** A critic will probe this; the answer: arm 2 does NOT touch `respawn_eligible` (~L11223), the PARK sets, `decide_session_stalled`, `_apply_prompt_wedge_override`, or any wedge fence/episode/cap state. It REUSES two PURE, side-effect-free helpers (`_transcript_tail_rows`, `_segment_wake_turns`) inside the boot-death lane, under boot-death's own action (STOP-only — no respawn, no fence), boot-death's own caps/state file, and boot-death's own guards. PARK stays "never re-SPAWN"; a stop of a provably-dead session at PARK is not a respawn, and re-drive stays exactly where #1267 left it (§4.4). The v1 option-(b) rejection stands verbatim: widening `respawn_eligible` would expose all five wedge triggers + their stop+respawn fence to gate-parked sessions.
- **Why not "tail row is an api-error"** (the task-body sketch): fires on a healthy long-lived session whose single last wake was refused — the #1104 single-refusal over-trigger. All-completed-turns-failed is the conservative form #1209 already validated; a session with even one visible ok turn keeps.

**(1) `decide_boot_death` (~L2521–2564): two-arm predicate.** Keep `response_row_seen` (name + semantics); ADD required keyword-only `all_turns_failed: bool | None`. The new REQUIRED kwarg makes every stale call site raise `TypeError` — fail-loud migration.

```python
def decide_boot_death(
    *,
    sid_alive: bool,
    entry_age_s: float | None,
    response_row_seen: bool | None,
    all_turns_failed: bool | None,
    transcript_idle_s: float | None,
    window_s: float,
    quiet_s: float,
    stops_today: int,
    stops_per_day: int,
) -> str:
    """Pure per-entry decision for the boot-death lane (#1267 arm 1 +
    #1287 arm 2). Returns "stop" | "cap-alert" | "keep".

    Fires ONLY on: live sid + registration older than ``window_s`` + ONE of
    - ARM 1 (zero-response, #1267/#1251): ``response_row_seen is False`` —
      the whole-file read found NO response rows (assistant OR api-error);
      the session died before turn 1.
    - ARM 2 (boot-refusal, #1287/#1277): ``all_turns_failed is True`` —
      the 256 KB TAIL read segmented (via _segment_wake_turns, #1127) to
      >=1 completed turn with EVERY completed turn failed (last response
      row api-error). The boot turn executed and every turn failed; at a
      PARK status the #1209/#1127 wedge lanes are structurally ineligible
      (respawn_eligible = in_active and ...), so this lane owns the shape.
      A single visible ok turn anywhere in the tail => not boot-dead
      (the #1104 single-refusal guard).
    + transcript quiet >= ``quiet_s`` (the in-flight-first-turn / mid-retry
    guard: a live retrying session keeps appending rows, so mtime stays
    fresh). Every unresolvable input fails toward keep (the 12h
    stale-registration pass stays the backstop): entry_age_s None/negative;
    response_row_seen None (whole-file read unresolvable OR over the cap —
    which does NOT veto arm 2: the tail read works at any size);
    all_turns_failed None (tail unresolvable) or False (zero completed
    turns — swallows stay the dequeue-run's property — or an ok turn);
    transcript_idle_s None. At the daily stop cap: "cap-alert" (caller
    dedupes to one loud alert per UTC day)."""
    if not sid_alive:
        return "keep"
    if entry_age_s is None or entry_age_s < window_s:
        return "keep"
    boot_dead = response_row_seen is False       # arm 1 (#1267)
    boot_refused = all_turns_failed is True      # arm 2 (#1287)
    if not (boot_dead or boot_refused):
        return "keep"
    if transcript_idle_s is None or transcript_idle_s < quiet_s:
        return "keep"
    if stops_today >= stops_per_day:
        return "cap-alert"
    return "stop"
```

**Overlap with #1209 on ACTIVE tasks** (arm 2 can now claim a shape the wedge dead-silence trigger also claims when the task is ACTIVE): cross-tick double-fire is impossible (post-stop the sid leaves the daemon live set; `_process_boot_death` early-exits on `pid is None`, and the wedge pid-gate goes inert); same-tick redundancy on the shared snapshot is the existing, documented-benign case (in-code NOTE ~L18527: a redundant sid-targeted stop consumes a cap unit, never a wrong kill). Budgets stay independent. In practice the wedge trigger (20-min silence) usually fires first on ACTIVE; boot-death arm 2 is the PARK-status owner and an ACTIVE-status backstop (e.g. when the wedge day cap is exhausted).

### 4.4 The load-bearing re-dispatch trace (unchanged from v1, cite fixed)

The stop kills the sid via `_stop_session` (~L9583, `spawn_session.py stop --stop-source watcher`); the registration is KEPT. For an ACTIVE task, crash-recovery respawns the dead-sid entry (~20 min). For a `proposed` task (#1277's case), **`_infra_drain_stale` (def at L13202–13229; consumed via the wrappers `_infra_drain_possibly_stale_ids` L13565 and `_infra_drain_signals` L13599)** marks the registration STALE once (task still `proposed`) ∧ (registration older than `EPM_INFRA_DRAIN_STALE_REG_GRACE_S` = 30 min — already exceeded at stop time, since the boot-death window is also 30 min) ∧ (sid definitively NOT live — true one tick after the stop); the stale entry stops pinning a pending slot and the ID re-dispatches under the existing backoff/attempt budget. #1277-replay timeline: death T+~2 min → arm-2 fire at the first tick past T+30 min (quiet long since satisfied) → stop ~T+31–40 min → sweep re-dispatch next tick ~T+41–50 min. Other PARK statuses gain no re-drive arm (deliberate; and near-unreachable for arm 2 — see §7 residual (ii)). The auth-outage guard (#1027) suppresses the downstream re-dispatch arms during a fleet outage, so the accelerated loop cannot spin during one.

## 11. Decision Rationale

- **Two-arm predicate (arm 1 unchanged + arm 2 tail/turn-segmented) over v1's single widened arm.** *Why:* the real incident transcript refutes the single-arm form twice (assistant rows present; size over the whole-file cap); arm 2 is the minimal shape that fires on the verified incident while leaving the #1251-class arm byte-stable. *Source:* #1277 transcript verification (plan-time, §9 A2) + fact-checker findings. *Alternatives rejected:* raising the whole-file cap (an 826 KB whole-file read per entry per tick, and "zero response rows" is the wrong predicate for this shape anyway); tail-row-is-api-error (the #1104 single-refusal over-trigger, v1 §11 rationale stands); option (b) respawn-eligibility widening (§4.1, stands verbatim).
- **All-completed-turns-failed condition.** *Source:* #1209 (`_wedge_dead_silence_fired`'s exact condition, incl. its accepted truncation residual) + #1127 (turn segmentation, implicit-turn rule — load-bearing for the oversize tail, verified). Zero completed turns ⇒ `False` (swallows stay the dequeue-run's property — #1209 parity).
- **Tail size = `BOOT_DEATH_TAIL_BYTES` (256 KB).** *Source:* #1104 (the wedge lanes' production window; equal by design so both lanes see the same evidence horizon). No new knob.
- **Window 30 min / quiet 10 min / 3 stops/day, shared state file, stop-only, loud-at-cap.** *Source:* #1267 §11 / #1241 parity — unchanged; the shared day budget deliberately bounds stops-per-issue regardless of arm.
- **Quiet keyed on mtime.** *Source:* #1267 parity; mtime ≡ last-row time for dead transcripts (append-only, A8); a live retry keeps mtime fresh.
- **Required-kwarg migration (`all_turns_failed` added, `response_row_seen` kept).** *Why:* preserves arm 1's name/semantics byte-for-byte while the NEW required kwarg TypeErrors every stale call site — the same fail-loud property v1 sought via rename, without churning arm-1 tests' semantics. *Source:* fail-fast Critical Rule.
- **Excerpt cap 200 chars, sidecar-only.** *Source:* `_boot_death_stderr_excerpt` parity (#1267); trigger-dense containment (#866/#1073/#1098).
- **Re-dispatch left to existing arms.** *Source:* #1267's validated stop-only design + `_infra_drain_stale` (L13202) code read; auth-outage guard (#1027) bounds outage-time spin.
