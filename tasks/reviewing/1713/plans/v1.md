### (b) Step 10d lost-update guard — `.claude/skills/issue/SKILL.md`

Landing site: SKILL.md Step 10d "Merge safety guards" section, immediately
after Guard 3 (roughly L9835 area — verify exact anchor at implementation

```markdown
4. **Lost-update guard (strip-free lines-added-on-main protection).** A branch
   whose copy of a SHARED workflow-surface file predates a sibling's merged
   additions can carry a whole-file snapshot that silently DELETES lines that
   landed on `origin/main` after the branch's merge-base — no conflict, no
   warning, hard to spot in the diff, catastrophic when it drops a bundled
   `workflow_lint.py` check or an operational SKILL.md guardrail (incident
   #1701 → #1698, 2026-07-26: 153 lines of `check_inline_round_duty_mirror`
   deleted 45 min after they landed, breaking full-suite collection fleet-wide
   for ~15.5 h). Refuse the merge when it is detected.

   ```bash
   MB=$(git -C "$WT" merge-base HEAD origin/main)
   SHARED_GLOBS='scripts/workflow_lint.py .claude/skills .claude/rules .claude/workflow.yaml CLAUDE.md'
   LOST_UPDATE_PATHS=""
   while IFS= read -r P; do
     case "$P" in
       scripts/workflow_lint.py|.claude/skills/*|.claude/rules/*|.claude/workflow.yaml|CLAUDE.md)
         MAIN_ADDS=$(git -C "$WT" diff --numstat "$MB" origin/main -- "$P" | awk '{print $1+0}')
         BRANCH_HAS=$(git -C "$WT" diff --numstat "$MB" HEAD -- "$P" | awk '{print $1+0}')
         if [ "${MAIN_ADDS:-0}" -gt 0 ]; then
           git -C "$WT" diff "$MB" origin/main -- "$P" | grep -E '^\+[^+]' > /tmp/1713-main-adds.txt
           MISSING_ON_BRANCH=0
           while IFS= read -r L; do
             ADD_LINE="${L#+}"
             if ! git -C "$WT" show HEAD:"$P" 2>/dev/null | grep -Fxq "$ADD_LINE"; then
               MISSING_ON_BRANCH=$((MISSING_ON_BRANCH + 1))
             fi
           done < /tmp/1713-main-adds.txt
           if [ "$MISSING_ON_BRANCH" -gt 0 ]; then
             LOST_UPDATE_PATHS="$LOST_UPDATE_PATHS $P($MISSING_ON_BRANCH)"
           fi
         fi
         ;;
     esac
   done < <(git -C "$WT" diff --name-only "$MB"...HEAD)
   if [ -n "$LOST_UPDATE_PATHS" ] && [ -z "${EPM_SKIP_LOST_UPDATE_GUARD:-}" ]; then
     echo "LOST-UPDATE REFUSAL: branch carries a whole-file snapshot dropping" \
          "main-side additions on:$LOST_UPDATE_PATHS" >&2
     echo "Rebase onto origin/main and re-apply the intended edits by explicit path;" \
          "post epm:merge-failed v1 (reason: lost-update, paths=$LOST_UPDATE_PATHS)"
     false
   fi
   ```
   Kill switch `EPM_SKIP_LOST_UPDATE_GUARD=1` (opt-out for exceptional cases
   where the branch DELIBERATELY reverts main-side lines; document the
   reason on the `epm:merged` note when used).
```
