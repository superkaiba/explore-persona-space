### Fix 1 — `tests/test_workflow_lint_no_repo_root_worktree_revert.py` (lines ~354-377)

Replace the literal anchor with a compiled flag-tolerant regex; keep the `"checkout issue-<N> --"` conjunct (it is what excludes the sibling `git add` / `git commit` / `restore --staged` / prose lines — the existing comment at lines 364-367 documents this) and keep the `-C`-qualification assert (line 375) byte-unchanged — that assert IS the load-bearing property the test exists for.

```python
    # Flag-tolerant anchor (#1076): #1047 hardened every fence consumer to
    # `xargs -r -a` (--no-run-if-empty; pinned by tests/test_step10d_guard3.py),
    # and future flag hardening must not re-break this test — its load-bearing
    # property is the -C qualification below, not the xargs flag set.
    anchor_re = re.compile(r"xargs\s+(?:-\S+\s+)*-a\s+/tmp/issue-<N>-additive-files\.txt")
    anchor_lines = [
        ln
        for ln in text.splitlines()
        if anchor_re.search(ln) and "checkout issue-<N> --" in ln
    ]
```

Also update the docstring's "Located by CONTENT ANCHOR (the ``xargs -a`` prefix)" (line 359) to "(the flag-tolerant ``xargs … -a`` list-file prefix)". `re` is already imported (used at line 375). `<`, `>`, `-` are regex-literal; only `.txt`'s dot needs escaping (done). 1. **Flag-tolerant regex `xargs\s+(?:-\S+\s+)*-a\s+/tmp/issue-<N>-additive-files\.txt` (vs the Goal's minimal `(-r\s+)?` or a new literal `-r -a` pin).**

   - *Alternatives:* `(-r\s+)?` (Goal's example — works today, breaks on the next flag); literal `-r -a` (rejected — brittle, duplicates guard3's pin).
2. **Harness fix = patch `_upload_verification_currency_blocker` with try/finally (vs synthetic issue id / deps-seam extension / updating expected rcs / weakening the gate).**
   - *What:* scenario-scoped `lambda _issue: None`, restored in finally.
   - *Why:* the harness side is the wrong side (test-isolation leak); the patch is the established isolation pattern (~20 sites in `tests/test_dispatch_issue_cli.py`), fully decouples from live task state in BOTH directions (existence and non-existence), and needs zero production change.
