### 4.3 Sentinel + skip-count reader (pure functions)

```python
def _codex_outage_sentinel_path() -> Path:
    return PROJECT_ROOT / ".claude" / "cache" / "codex-quota-exhausted-until"


def _codex_outage_read_sentinel(now: float) -> dict | None:
    """Read the #1204 sentinel with the SAME two-sided plausibility window
    the pre-spawn check enforces (`now < until_unix <= now + 45 d`).
    Returns a dict with `until_unix, until_iso, detected_at_iso,
    detected_at_unix` on a LIVE sentinel; None on missing/unreadable/
    corrupt/expired/far-future (fail-open: no alert, no crash — mirrors
    codex_task._quota_sentinel_active). NEVER mutates the file."""
    path = _codex_outage_sentinel_path()
    if not path.is_file():
        return None
    try:
        data = json.loads(path.read_text())
    except (json.JSONDecodeError, OSError):
        return None
    if not isinstance(data, dict):
        return None
    try:
        until_unix = float(data["until_unix"])
    except (KeyError, TypeError, ValueError):
        return None
    # two-sided plausibility window — #1204 parity (never fires on a
    # corrupt far-future or already-expired sentinel)
    if not (now < until_unix <= now + CODEX_OUTAGE_MAX_PLAUSIBLE_SECS):
        return None
    detected_at_iso = data.get("detected_at_iso")
    if not isinstance(detected_at_iso, str):
        return None
    try:
        detected_at_unix = datetime.fromisoformat(
            detected_at_iso.replace("Z", "+00:00")
        ).timestamp()
    except ValueError:
        return None
    return {
        "until_unix": until_unix,
        "until_iso": str(data.get("until_iso") or until_unix),
        "detected_at_iso": detected_at_iso,
        "detected_at_unix": detected_at_unix,
    }


def _codex_outage_count_single_claude_rounds(detected_at_unix: float) -> int | None:
    """Bounded scan of REGISTRY tasks' events.jsonl for `epm:progress`
    notes whose text contains 'codex composers skipped' with ts >=
    detected_at_unix. Uses the same enumerator convention as
    triage_observer / verdict_disagree: REGISTRY tasks, events.jsonl
    mtime > detected_at_unix pre-filter (cheap; no `jq`), then per-file
    JSONL scan bounded to a max byte read.

    Returns the count on success, None on any enumerator/read failure
    (the pass then reports 'count not available' rather than crash)."""
```

**Count source rationale (the body's open design point).** Option (b) —
have the #1204 skip-note callsite append a dedicated sidecar row — would
mutate the pre-spawn check callsites, which the body's Scope section
explicitly rules out ("do NOT change the #1204 pre-spawn check"). Option
(a) — grep events.jsonl — is body-warned as "avoid a fleet-wide events
scan on every 10-min tick", but three bounds convert it into a cheap
operation:

1. **Cadence: 1h self-gate** (`CODEX_OUTAGE_INTERVAL_HOURS`), not every
   10-min tick. The count only enters the push text; a slightly stale
   count between the hourly refresh and the daily/weekly push is fine.
2. **REGISTRY-scoped enumeration** (`task_workflow.registry_path()` + inline
   `json.loads(...read_text()).get("tasks", {})`, the pattern
   `triage_observer_pass` uses at scripts/autonomous_session_watch.py:5654-5665) —
   never a filesystem walk of `tasks/*/*/events.jsonl`; `_load_registry` is
   module-private on `task_workflow`, so callers use the public
   `registry_path()` + a `json.loads` step.
3. **Mtime pre-filter** — skip `events.jsonl` whose mtime is older than
   `detected_at_unix`; the compose-time-verified 17-day-old outage
   still needs the scan on every touched-since file, but the mtime
   pre-filter typically drops ~half of a fleet of hundreds of task
   folders and the per-file scan is a bounded read
   (`_transcript_tail_rows`-style: read at most 256 KB tail per file;
   overflow means "count is a lower bound", degraded to "≥N" in the
   push text). Measurement basis: `completed_unmerged` runs a similar
   mtime-pre-filtered REGISTRY scan every tick (`~113 recently-touched
   completed tasks measured live, 2026-07-20`, per its docstring) with
   no fleet impact; our 1h cadence over the same-order set is a
   fraction of that cost.

The count degrades cleanly: any per-file read failure counts as 0
contribution from that file (never crashes the scan), and a full
enumerator failure returns `None` so the push text prints
`skipped_rounds: count not available` rather than fabricating a 0.

def decide_codex_outage_alert(
    sentinel: dict | None,
    state: dict,
    now: float,
    threshold_s: float,
    realert_s: float,
) -> tuple[bool, str]:
    """Pure fire decision. Returns (fire, reason).
    fire=True iff:
      (a) sentinel is LIVE (not None), AND
      (b) age = now - sentinel['detected_at_unix'] >= threshold_s, AND
      (c) EITHER (i) episode key CHANGED — new outage since last state
              OR (ii) last_alert_ts is None (first alert of this episode)
              OR (iii) now - last_alert_ts > realert_s
                       (weekly re-alert of ongoing episode)

             'new-episode' | 'weekly-realert' | 'within-realert-ttl'."""

### 4.6 The pass

```python
def _codex_outage_enabled() -> bool:
    raw = os.environ.get("EPM_DISABLE_CODEX_OUTAGE_PASS", "").strip().lower()
    return raw not in {"1", "true", "yes"}


def codex_outage_pass(dry_run: bool) -> bool:
    """ESCALATE-ONLY pass: alert once per Codex quota-outage episode when
    the sentinel has been live >= EPM_CODEX_OUTAGE_ALERT_HOURS since
    detected_at_iso, re-alert weekly while it persists, and clear the
    episode when the sentinel disappears.

    NEVER mutates the sentinel (lifecycle stays with codex_task.py, per
    the task body's Scope constraint). NEVER posts task markers (the
    outage is fleet-level, no single task owns it — verdict_disagree
    precedent). Sidecar rows + Telegram push via the shared _telegram_push
    helper.

    Returns True when a push fired this run."""
    if not _codex_outage_enabled():
        print("  codex-outage: disabled via EPM_DISABLE_CODEX_OUTAGE_PASS; skipping")
        return False
    try:
        now = time.time()
        interval_h = _env_float(
            "EPM_CODEX_OUTAGE_INTERVAL_HOURS", CODEX_OUTAGE_INTERVAL_HOURS,
            lo=0.0, hi=24.0,
        )
        alert_h = _env_float(
            "EPM_CODEX_OUTAGE_ALERT_HOURS", CODEX_OUTAGE_ALERT_HOURS,
            lo=1.0, hi=720.0,
        )
        realert_h = _env_float(
            "EPM_CODEX_OUTAGE_REALERT_HOURS", CODEX_OUTAGE_REALERT_HOURS,
            lo=1.0, hi=2160.0,
        )
        state = _load_codex_outage_state()
        last = state.get("last_run_ts")
        if isinstance(last, int | float) and (now - last) < interval_h * 3600.0:
            return False  # throttled — silent
        # Stamp attempt BEFORE reading so any exception below is bounded
        # to one skipped hour, not repeated every 10-min tick.
        state["last_run_ts"] = now
        _save_codex_outage_state(state, dry_run)

        sentinel = _codex_outage_read_sentinel(now)
        if sentinel is None:
            # Recovered? Clear the episode key so a later outage re-fires.
            if state.get("episode_detected_at_iso"):
                print("  codex-outage: recovered — sentinel absent/expired")
                _save_codex_outage_state({
                    **state,
                    "episode_detected_at_iso": None,
                    "first_alert_ts": None,
                    "last_alert_ts": None,
                    "last_count": None,
                    "last_count_ts": None,
                }, dry_run)
            return False

        fire, reason = decide_codex_outage_alert(
            sentinel, state, now, alert_h * 3600.0, realert_h * 3600.0,
        )
        # Refresh the count only on a firing tick (bounds cost —
        # non-firing hourly ticks stay ~free).
        skipped_count: int | None = None
        if fire:
            skipped_count = _codex_outage_count_single_claude_rounds(
                sentinel["detected_at_unix"]
            )

        elapsed_h = (now - sentinel["detected_at_unix"]) / 3600.0
        remaining_h = (sentinel["until_unix"] - now) / 3600.0
        _append_codex_outage_sidecar({
            "kind": "codex-outage",
            "episode_detected_at_iso": sentinel["detected_at_iso"],
            "until_iso": sentinel["until_iso"],
            "elapsed_hours": round(elapsed_h, 1),
            "remaining_hours": round(remaining_h, 1),
            "skipped_rounds": skipped_count,   # int or None
            "fire_reason": reason,
            "pushed": fire,
        }, dry_run)

        if fire:
            days_elapsed = round(elapsed_h / 24.0, 1)
            days_remaining = round(remaining_h / 24.0, 1)
            count_str = (
                f"{skipped_count} review round(s) ran single-Claude"
                if isinstance(skipped_count, int)
                else "single-Claude round count not available"
            )
            _telegram_push(
                f"Codex quota outage live: opened {sentinel['detected_at_iso']}, "
                f"expires {sentinel['until_iso']} "
                f"(~{days_elapsed}d elapsed, ~{days_remaining}d remaining). "
                f"Since it opened, {count_str}. "
                f"Fleet-wide loss of the cross-family reviewer diversity for "
                f"the entire window. Silence-check kill switch: "
                f"`EPM_DISABLE_CODEX_OUTAGE_PASS=1`. Account triage tracked "
                f"separately (do NOT triage from this alert).",
                dry_run,
            )
            _save_codex_outage_state({
                **state,
                "episode_detected_at_iso": sentinel["detected_at_iso"],
                "first_alert_ts": state.get("first_alert_ts") or now,
                "last_alert_ts": now,
                "last_count": skipped_count,
                "last_count_ts": now,
            }, dry_run)
        else:
            # No push this tick, but keep the episode key in sync
            # (initial write when we first observed the current outage
            # but its age is still below threshold).
            _save_codex_outage_state({
                **state,
                "episode_detected_at_iso": sentinel["detected_at_iso"],
            }, dry_run)
        return fire
    except Exception as exc:  # top-level fail-soft: never take down the tick
        print(f"  codex-outage: pass failed (fail-soft): {exc}", file=sys.stderr)
        _append_codex_outage_sidecar(
            {"kind": "codex-outage-error", "error": str(exc)[:500]}, dry_run
        )
        return False
```

**Configuration constants** (documented here for the reviewer's convenience,
NOT model-training hyperparameters):

- `CODEX_OUTAGE_ALERT_HOURS = 24.0`: chosen because (a) the compose-time

  it immediately, (b) 24h gives a full working day of "give the outage a

  that starts within a day, (c) matches the completed_unmerged re-alert
  cadence + the root-draft threshold family (24h) and is thus consistent
  with existing operator expectations. Env-overridable; the body flags
  this as "the planner's call" between 24h / 72h / 7d.
- `CODEX_OUTAGE_REALERT_HOURS = 168.0` (weekly): mirrors
  `REGISTRY_DRIFT_REALERT_HOURS`. Registry drift and Codex outage both
  reflect long-lived slowly-changing states where daily re-pushes would
  be noise.
- `CODEX_OUTAGE_INTERVAL_HOURS = 1.0` (hourly self-gate): matches
  `COMPLETED_UNMERGED_INTERVAL_HOURS`; sub-daily is required so a fresh
  outage detected 30 min after the last daily read doesn't wait 23h to
  fire, but 10-min is unnecessary since the alert threshold is 24h.
