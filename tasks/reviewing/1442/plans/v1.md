## 3. Method delta

Same recipe as #1408, four deliberate adaptations to the TG legs' shape:

1. **TMPDIR via the existing `env` prefix** (`${TG_TMPROOT:+TMPDIR=$TG_TMPROOT}`), not `export TMPDIR` — the 1b/1c blocks are pytest-only shells where an export is fine; the TG legs share their shell with workflow_lint runs, `select_step9c_tests.py`, and git checkout/commit commands, and the subshell `( cd ... && env ... )` form makes the env prefix the natural, pytest-scoped seam.
2. **One `mktemp -d` per block, distinct per-leg subdirs** `--basetemp=$TG_BASETEMP/b` (baseline) / `$TG_BASETEMP/g` (gated) — pytest removes-and-recreates the `--basetemp` dir at startup, so the two sequential legs in one block must not share a path (the gated leg's startup wipe would delete the baseline leg's tree). One mktemp keeps cleanup to a single `rm -rf`.
3. **Variable names `TG_TMPROOT` / `TG_BASETEMP`** (not `S9C_*`) and dir prefix `tg-XXXXXX` (not `bt-XXXXXX`) — keeps the two fix families distinguishable in the file and on the data disk; the resulting path `/mnt/eps-data/tmp/tg-XXXXXX/g` (~28 chars) preserves #1408's AF_UNIX 108-byte short-path rationale.
4. **Helper invoked `"$REPO_ROOT/scripts/step9c_baseline.py"` absolute** — matches the adjacent `select_step9c_tests.py` invocations in both blocks (the 1b block uses the relative form because it `cd "$WT"` first).

Fail-soft is unchanged from #1408: empty tmproot ⇒ both `${:+}` expansions produce zero words ⇒ byte-identical pytest argv (today's behavior on pods/GCE).

## 11. Decision Rationale

- **Recipe = mirror #1408's tmproot/mktemp/`${:+}`/cleanup pattern.** Why: proven in production on the sibling 9c blocks; single-source helper. Source: #1408 (SKILL.md ~L7985–7998; merge `fcad57ab7f`); incident grounding #1363. Alternative rejected: a new shared shell function in SKILL.md (the blocks are separate Bash executions at different Steps — no shared shell to put it in).
- **TMPDIR via the `env` prefix, not `export`.** Why: scopes routing to pytest; the TG blocks' shells also run lint legs, the selector helper, and git checkout/commit, which #1408 never had in scope. Source: the TG legs' own #1147 env-prefix shape + #1408's TMPDIR intent. Alternative rejected: block-level `export TMPDIR` (silently re-routes non-pytest temp writes in the same shell — a wider behavior change than the Goal).
- **Distinct per-leg basetemp subdirs `/b`/`/g` under one mktemp.** Why: pytest removes-and-recreates `--basetemp` at startup; sequential legs sharing a path would cross-wipe. Source: #1408's per-invocation `/p` suffix convention + the startup-wipe semantics execution-pinned by `tests/test_step9c_baseline.py::test_real_run_pytest_basetemp_routing`. Alternative rejected: two mktemps per block (two cleanups, no benefit).
- **Pin test placed in `tests/test_step9c_baseline.py`, split-on-``` locator.** Why: same file, same idiom, same maintenance surface as the #1408 pin it extends. Source: `test_skill_step9c_blocks_pin_tmpdir_routing` (L2155–2172).
- **`tg-` dir prefix + `TG_*` variable names.** Why: disambiguates the two fix families in file and on disk; preserves the 108-byte AF_UNIX headroom. Source: #1408's short-path rationale (SKILL.md L7983 comment).
