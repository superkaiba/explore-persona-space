# Plan v1 — #1434: Install `writing_style` as a persona-vectors-style (context, behavior) LoRA organism

## 0.0 TL;DR (plain English — the user reads this first)

- **What I'll run:** I take the factory recipe that already built the "impolite" organism and point it at one new behavior: writing in a casual, chatty register. Claude writes the training examples, we train 12 small adapters — one per combination of four training contexts and three learning rates, since the higher learning rates are what got impolite working — and a judge scores how casual each trained model's own answers actually are, against the untrained model. I also extract the casual-register direction from the base model's activations and check whether movement along it agrees with the judge — an install meter that doesn't depend on a judge at all.
- **What I expect:** casual register is the closest benign cousin of impolite, so I'm betting it trains into the target range in most or all four contexts once the learning rate is raised, and that the activation meter tracks the judge better than random directions do — as it did for impolite.
- **What would change my mind:** if no learning rate gets it into the target range anywhere, casual register joins the "never installs" set with list-formatting, which would mean even benign register traits split into trainable and untrainable kinds. If the activation meter reads no better than random directions, it is not a usable install meter for this behavior.
