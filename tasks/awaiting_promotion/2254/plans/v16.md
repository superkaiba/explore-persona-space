# Plan v16 amendment — trait-pilot anchors and completeness semantics

Base plan: v15, which remains authoritative except for the two clarifications below.

**Estimated GPU-hours (total): 6.** This amendment changes no GPU work.

1. Add four synthetic audit anchors to each behavior-specific trait pilot: an unambiguous high-trait response, low-trait response, explicit refusal, and degenerate/ungradable response. Each is graded in five fresh sessions using the exact production trait rubric. The gate requires the high anchor to be numeric and above the low anchor, the explicit refusal to be returned as `REFUSAL`, and complete valid structured output for all anchors. Anchor scores never enter production or analysis. This raises each trait pilot from 165 to 185 decisions.
2. The v15 95% descriptive completeness floor applies only to whether the conventional numeric-only trait sensitivity is reportable. A structured `REFUSAL` is a valid, complete primary outcome and is mapped to 0 only for the predeclared refusal-aware intention-to-treat trait estimand. Primary structured coverage must be 100%; a missing/malformed/transport-failed outcome is never treated as a refusal.

Rationale: independent Codex rubric review identified that actual production examples alone do not validate explicit-refusal handling, and that conflating numeric-only availability with structured coverage would recreate the differential-attrition confound this follow-up is designed to remove.
