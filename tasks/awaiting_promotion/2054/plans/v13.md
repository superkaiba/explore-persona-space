## 4. Design

### The one variable

Old (record-only): rungs 7/8/9 fit ambient d×d GCV-ridge maps (`_fit_ridge`, ladder.py:339) on per-pair equalized rows — degenerate at n_train < d. New (primary): the SAME three maps are fit as **truncated-SVD reduced-basis GCV-ridge** — the fit's input is projected onto the top-k right singular vectors of its OWN standardized train matrix (train fold only; correlation-space PCA ≡ the truncated SVD of the standardized design), the ridge + GCV run in that k-dimensional basis, and predictions are reconstructed in ambient output space. Fit dimension = k, so n_train ≥ 2k holds by construction and the #1701/#1887 `n_train < d` refusal does not apply. Nothing else changes.

### The estimator — `_fit_ridge_reduced` (new, in `scripts/issue2054_rb789.py`)

A ~40-line sibling of the ladder's `_fit_ridge` (same standardize-X / center-Y, same SVD, same GCV + dof-cap loop) with the spectrum truncated at k:

```
Xtr, xmu, xsd = _standardize(X_train); Ytr_c = Y_train - ymu
U, s, Vt = svd(Xtr, full_matrices=False)          # ONE decomposition per input matrix
Uk, sk, Vtk = U[:, :k], s[:k], Vt[:k]             # train-fold top-k basis (PCA of the standardized design)
UtYk = Uk.T @ Ytr_c
GCV over lambdas on the TRUNCATED spectrum: dof(λ) = Σ_{i≤k} s_i²/(s_i²+λ), dof cap 0.9 retained
W_k = (Vtk.T * (sk/(sk²+λ*))) @ UtYk              # (d, D_out) — predictions reconstructed ambient
info: {k, best_lambda, dof, dof_over_cap, gcv, n_train, variance_explained_at_k, selector: "gcv-dofcap-0.9-truncated"}
```

Design decisions, resolved:

- **k per fold:** hard cap k ≤ floor(n_train/2) (well-posedness by construction; at that cap dof ≤ k ≤ 0.5·n_train, so the 0.9 dof cap is slack by construction — retained anyway, never `LEGACY_UNGUARDED_GCV`). **Primary registered dimension k\* = 1024, common to every pair** — min affected intersection 2,939 → min per-fold n_train ≈ 0.8 × 2,939 ≈ 2,351 → floor(n_train/2) ≈ 1,175 > 1,024, so k\* fits every affected (pair, fold) with margin; a fixed common k is what keeps H1′'s two strata and H2′'s two classes on ONE instrument (per-pair k_max tracks intersection size and would re-import the confound). **k-profile {64, 256, 1024, k_max} computed for every unit-fold** — near-free (truncation at different k re-weights the SAME SVD factors) — reported in full as a dimensionality curve; NO max-over-k selection anywhere (primary pre-registered at k\*; k_max = min(floor(n_train/2), d) is the labeled least-truncated companion). Runtime guard: a fold with n_train < 2k\* (not expected; jitter margin ~15%) fits at k = floor(n_train/2) and the unit is FLAGGED `k_realized < k_star` + excluded from fixed-k\* aggregates (counted, reported) — fail-loud accounting, never silent inclusion.
- **Basis side:** each fit's basis is the top-k of its OWN INPUT training matrix — A′: basis from standardized Xt_tr (target contexts); M′: from Xs_tr (source contexts); B′: from Ys_tr (source answers). Input-side truncation is what buys well-posedness (the #1701/#1887 degeneracy is in the design matrix); outputs stay ambient (the fit chooses its rank-k output subspace supervisedly — no unsupervised output truncation entangling the ceiling). NOT the concatenation: concatenating source+target rows would leak the other cell's structure into the basis without helping well-posedness. **Train fold only, no leakage:** the SVD is of the TRAIN-fold matrix; held-out rows are only ever projected through the frozen (xmu, xsd, Vtk).
- **Reduced-basis analogue of each rung (mirrors `_compute_rungs_for_fold`, ladder.py:523, exactly — three fits, memo-shared):**
  - A′ = `_fit_ridge_reduced(Xt_tr → Xs_tr, k)` (target→source context reparam; input basis: target-context train PCA);
  - M′ = `_fit_ridge_reduced(Xs_tr → Ys_tr, k)` (the source map; input basis: source-context train PCA; memoized per (source_cell, arm, fold, train-rows sha, k) — the parent's bounded `fit_cache` pattern);
  - B′ = `_fit_ridge_reduced(Ys_tr → Yt_tr, k)` (source-answer→target-answer reparam; input basis: source-answer train PCA);
  - **rung 7′** = M′(A′(Xt_te)) + b7′, b7′ = train-mean(Yt_tr − M′(A′(Xt_tr))) (the parent's bias refit, a d-dim mean — well-posed at any n);
  - **rung 8′** = B′(M′(Xt_te)); **rung 9′** = B′(M′(A′(Xt_te))) (no b7 inside rung 9, mirroring the parent).
  - Rungs 1–6 and the parent's within-cell ceilings are NOT recomputed (scope boundary — they carry the parent's record unchanged).
- **The ratio denominator is a REFIT, not a reuse:** per (pair, arm, fold), the **matched reduced within-cell ceiling** = `_fit_ridge_reduced(Xt_tr → Yt_tr, k)` scored on Yt_te — SAME intersection rows, SAME folds, SAME k, SAME estimator as the numerator (the cross_render_fit "matched within-cell reference … the honest denominator" convention; comparing reduced transfer against the parent's ambient full-pool ceiling would be unmatched twice over — different rows AND different instrument). It shares the SVD of Xt_tr with A′ (same input matrix — only UtY differs), so it costs one extra solve, not one extra decomposition. The parent's committed ambient full-pool ceiling is carried as a labeled reference column (context, never a denominator).
- **λ selection:** GCV per fit on the truncated spectrum, dof cap 0.9 (`DEFAULT_DOF_CAP`, ladder.py:125), grid `DEFAULT_LAMBDAS` (ladder.py:124, `np.logspace(-2, 4, 13)`). Per-fit selector + selected λ + dof persisted in every unit JSON and REPORTED next to every R² (the #1887 selected-λ diagnostics duty).

## 6. Evaluation

### Measurement validity (per-DV)

- **DV 1 — reduced-basis rung 7′/8′/9′ held-out R² per (pair, arm, k) [PRIMARY].** Construct: existence + strength of a k-dimensional linear reparameterization between cells at current n (the registered FALLBACK construct — explicitly weaker than the Goal's ambient d×d read; §1 boundary). Metric: held-out R² on the target's held-out fold rows, reported BOTH raw AND as ratio-of-MATCHED-reduced-ceiling (always together — the parent convention; the matched denominator carries the same rows/folds/k/estimator). On-distribution: yes (native token positions, teacher-forced captures — inherited regime).
- **DV 2 — calibration Δ and ρ on the control classes (H0′/lattice input).** Construct: whether the reduced instrument tracks the valid ambient read where truth is known. Metric: per (rung, arm), per-pair Δ = ratio_reduced(k\*) − ratio_ambient and cross-pair Spearman ρ. On-distribution: same rows.

## 11. Decision Rationale

- **Reduced basis = input-side train-fold truncated SVD (PCA of the standardized design), outputs ambient.** What: the fit dimension becomes k. Why: the #1701/#1887 degeneracy lives in the DESIGN matrix (n_train < d_in); truncating the input spectrum removes it by construction while keeping predictions (and R²) in the ambient output space the parent scores in; principal-components regression is the standard linear instrument for exactly this regime. `Source:` marker v222 (binding: "train-fold PCA basis, k ≤ n_train/2") + #1887/#1701 estimator lineage; construction this plan §4. Alternatives: output-side truncation too (rejected — imposes an unsupervised cap on attainable R² and entangles the ceiling); basis on the concatenation (rejected — leaks the other cell's structure, buys no well-posedness).

Why: min affected intersection 2,939 → min per-fold n_train ≈ 2,351 → per-pair k_max = floor(n_train/2) ≈ 1,175; 1,024 is the largest power of 2 under every affected pair's cap, and a COMMON dimension is what keeps H1′'s strata and H2′'s classes on one instrument (per-pair k_max correlates with intersection — the confound a fixed k removes). `Source:` derived at plan time from the committed census (`ladder_intersection_composition.json` overall_min 2,939) + fold arithmetic; no literature value exists for this design constant — the runtime k-guard + the all-k profile are the verification.
