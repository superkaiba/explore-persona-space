## 4. Design

**Single manipulated variable = the retained answer fraction** (round 4's EMPTY answer span becomes a graded ID-level prefix truncation), plus the mechanical consequences named in the divergence table. Data source + realism tier: unchanged (tier-2 battery + real prefixes + the frozen greedy base completions from `raw_completions/raw_completions/` — the SAME rollout text rounds 1/3 tokenized); **a truncated turn is the DELIBERATE manipulation** — the graded counterfactual the round-4 interpretation asked for. **Why code, not a model call / contrastive negatives / on-policy positives / marker recipe / replication fidelity / generation-and-reduce:** all N/A, inherited verbatim from v15 §4 (no training, no generation, no judging; the capture teacher-forces stored text — no new completions are generated, and rollout text already persists on HF).

**Truncation edge rules (registered):**
- Truncate the **token sequence**, never re-tokenized truncated text: `ans_ids = tokenizer(ans, add_special_tokens=False)` (the existing non-ablate path), then `kept = ans_ids[:, :n_keep]` with `n_keep = max(1, ceil(k × ans_len))`. ID-level prefix cut ⇒ zero retokenization/BPE-merge risk (the same argument v15 §12.1 made for ID concatenation), and the k=100 limit is byte-identical to the round-3 capture by construction.
- `n_keep ≥ 1` for every k > 0 (automatic for ceil of a positive, asserted anyway); `n_keep ≤ ans_len` asserted; per-context `n_keep` recorded in the store manifest. A context with ans_len so short that n_keep coincides across k values (requires ans_len ≤ 3) is KEPT and counted/reported, never dropped (expected 0 of 50 — Betley answers run ~320-350 tokens median (min ~43, generation-capped at 512; fact-check measured 144 completions)).
- Full-sequence equality assert: `full_ids == prompt_ids + kept + BOUNDARY_BLOCK_IDS` per probe; decoded-tail assert: `tokenizer.decode(full_ids[prompt_len + n_keep:]) == "<|im_end|>\n<|im_start|>user\n"` (the existing `ABLATED_TAIL_TEXT` constant — the 5-id block decodes to the same string regardless of what precedes it); the existing fed-ids + im_end + turn_nl id asserts fire unchanged.
