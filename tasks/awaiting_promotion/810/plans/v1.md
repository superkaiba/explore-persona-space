## 11. Decision Rationale

- **Per-position window K=16.** *What:* tail `−1…−16` + head `0…15`. *Why:* median answer S≈300, but the profile is expected to concentrate near the boundaries (mirror of `c_C`); K=16 covers the tail without materializing the full span (footprint stays ~0.34 GB). #722's per-position script used P_MAX=64 head-only; K=16 tail+head is the minimal window that includes the `last`/boundary candidates + enough head to test the early-position hypothesis. *Source:* `#722 issue722_per_position_vC_skill.py P_MAX=64` (trimmed to a tail+head window). *Alternatives:* full-span per-position (rejected — 150 GB footprint, no marginal value beyond boundaries); K=8 (rejected — too short to see the tail decay).
- **Ridge λ grid {1e-2,1e-1,1,10,100,1e3}.** *What:* nested-CV λ selection. *Why:* the exact #658 A3.4 grid the whole line uses; keeps the reconstruction DV byte-comparable to #722. *Source:* `#658 issue658_fit_predictors.RIDGE_LAMBDAS` (VERIFIED). *Alternatives:* per-layer λ (rejected — #658 uses one grid, nested-CV picks per-fold).
- **MLP hidden=512, lr=1e-3.** *What:* the validity-arm MLP. *Why:* #658's `_MLP` defaults, reused verbatim by `vectorized_mlp_skill` so the ridge-vs-MLP gap is like-for-like with #722/#658. *Source:* `#658 MLP_HIDDEN=512 / MLP_LR=1e-3 (VERIFIED in fit_predictors)`. *Alternatives:* tuning MLP width (rejected — the MLP is a nonlinearity-gap sanity check, not the primary; #722 found ridge is the valid estimator at all-28-layer depth).
- **Graded judge N=8 @ temp 1.0, anchored 0/50/100, reason-then-score.** *What:* the E0 target measurement. *Why:* graded-primary for a ranking/regression target (dichotomizing attenuates ρ ~0.798); N=8 mean-agg substitutes for the paper's logit-weighting (no score-token logprobs on the Messages API). *Source:* `#763 plan v2 §4.3` (the SAME grid, verbatim params) + `.claude/rules/llm-judging.md rules 1/4/6/7/8/9`. *Alternatives:* binary rate (kept as companion, not primary); N=5 (rejected — #763 piloted N=8).
- **sycophancy subsample = 60 completions/context.** *What:* high-m re-judge sample size. *Why:* 60 of 2000 gives a stable per-context mean at ~$60-80 batch vs ~$980 for the full set. *Source:* `#810 body` + stability-of-per-context-mean (verified 2000/context = 200 probes × 10). *Alternatives:* full 2000 (rejected — ~$980, no marginal precision on a per-context mean); 100 (kept as a robustness spot-check on 3 contexts).
- **Label-shuffle null, selection-symmetric, 1000 perms.** *What:* the chance band for both DVs. *Why:* rules out n=50 overfitting-false-positives; max-selected per draw to match the max-over-axis headline. *Source:* `#658/#742` + `.claude/rules/selection-symmetric-nulls.md`. *Alternatives:* single-cell null (rejected — the headline is max-over-{summary,layer}, so a single-cell null manufactures a false gap).
