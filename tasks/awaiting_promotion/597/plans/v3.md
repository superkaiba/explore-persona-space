```python
class HaltAfterStepCallback(TrainerCallback):
    """Stop training right after the checkpoint at halt_step is written.

    Save-driven halt: max_steps stays 528 so the LR schedule is untouched;
    asserts halt_step % save_steps == 0 so the halt fires ON a save event.
    """
    def __init__(self, halt_step: int, save_steps: int):
        if halt_step % save_steps != 0:
            raise ValueError((halt_step, save_steps))
        self.halt_step = halt_step
    def on_save(self, args, state, control, **kwargs):
        if state.global_step >= self.halt_step:
            control.should_training_stop = True
        return control
```

## 11. Decision Rationale

- **All training hyperparameters (lr, geometry, batch, warmup, max_steps=528, marker-only loss, log-only band callback):** inherited verbatim. `Source: #597 plan v1 §11 / #480 _band_stop_train_cfg`. Marker recipe and parity agree (lr 5e-6 IS the recipe's clean window) — no recipe-vs-parity conflict.
- **`C_GRID` {2..40:2} ∪ {44..60:4} (NEW).** Why: onsets sit at steps 15–20 (parent armA: source +5.8..+11.9 nat already at step 20) and the narrowest known install transition is ~12 optimizer steps (`Source: #533/#547`); a 2-step grid puts ≥6 points inside any such window and 9 points in the caveat window {2..18}. 4-step spacing 44–60 bridges to the parity points. Alternatives rejected: every-step saves to 60 (2.4× probe cost, no added science at the measured ramp); first-save-at-4 like B_GRID (misses the proposal's step-2 falsifier checkpoint).
- **`HaltAfterStepCallback(60)` (NEW), not `max_steps=60`.** Why: `max_steps` changes cosine + warmup denominators; the save-driven halt preserves schedule identity for steps 1–60. `Source: spec requirement; lr-identity unit test`. Alternative rejected: train full 528 (≈10× training + probe cost for steps the parent already covered).
- **`save_steps=2` + prune callback** (mechanism read from `grid_callbacks.py` + dispatcher line 727 — Trainer saves only at multiples of save_steps; B_GRID's `%4` assert becomes `%2` for C_GRID). `Source: #597 plan v1 Phase B-train`.
- **Parity tolerance ±2 nat at step 20:** ≈2 effective steps at the measured 0.45–1.0 nat/step ramp between parent steps 20→40. `Source: computed from eval_results/issue_597/panel_trajectories/armA (quoted §7)`.
- **No emission anchors:** `Source: #538` (EOS leads by +1.4..+8.8 logits even at 14–20 nat source gain at lr 5e-6) — applies to the H2-early window (steps ≤ 20), where TN gains ≤ ~5 nat read ~0 on-policy by construction. Steps 40–60 TN cells can reach +16..+24.9 nat (parent armA data) but are already anchor-covered by the parent's grid (fact-check rescope, 2026-06-12).
- Model id repo-known — no AutoConfig smoke needed.
