### 0.0 TL;DR (plain English)

- **What I'll run:** I retrain the small sparse autoencoder from this issue — the one that summarizes whole answers as sparse features — changing exactly one dial: each answer summary is now allowed 200 active features instead of 100. Same width, same data, same seeds, same three epochs, same tests. Then I re-count how many fine-grained features are alive at the same activity floors as before, and re-score how well the context→answer map predicts them, next to the committed k=100 numbers.
- **What I expect:** doubling the feature budget roughly doubles how often rare features fire, so the finest tier — which had only 3 usable features at the registered floor — should gain a real population (tens of features, dead fraction down from 36%). The interesting question is whether those newly usable features are predictable by the map or land near zero like the ones the floor sweep admitted.
- **What would change my mind:** if the finest-tier census barely moves (still single digits at the registered floor) even with twice the budget, then the starvation is not the instrument's sparsity budget — it is a fact about turn-averaged geometry concentrating variance in coarse structure, and the strongest remaining alternative to the paper's reading is discharged.

### 7. Decision Gates

No go/no-go gates — projected wall < 4 h and every phase is a prerequisite of the only DVs. Validity gates (fail-loud), each bound to its §4 mechanism:

- **G-A (row alignment, R2; equality):** `refit_holdout__ridge__seed0.npz` holdout rows == assembled holdout order == `ib_c.npz:rows`. FAIL ⇒ halt.
- **G-4′ (k=200 training sanity, R3; threshold — the parent's G4 recipe):** held-out 10,000-row SAE-val var-FVE ≥ 0.5 (Source: parent v4 §7/§11 — the 2606.28548-derived structural-breakage floor; the parent REALIZED 0.9093 at k=100, and k=200 at fixed width strictly adds capacity, so the expectation is ≥ 0.91). Below ⇒ halt-investigate (LR/normalization bug) before any encode. Companion reports (not gates): val L0 vs k; per-tier dead fractions vs the k=100 row (0.095/0.291/0.356).
- **G-C′ (counts SELF-consistency, R5; exact):** banked counts do not exist for the k=200 instrument by design — the reconciliation target is the run itself: (i) Σ per-feature counts == Σ per-row L0 (accounting identity, exact); (ii) census-pass alive sets == the restricted-encode pass's recount at the same columns (recompute-vs-recompute across two code paths; exact — inference encode is threshold-gated and chunk-independent, §2); (iii) n_fit_rows == 120,000 vs split shas. FAIL ⇒ halt-investigate. The k=100 banked census (`alive_c.npz`, committed floor_sweep tables) enters ONLY as the comparison arm.
- **NO G-R reproduction gate for k=200 cells — stated explicitly:** the v7 quantile predicate ties a run to the PARENT instrument's committed per-feature values; a k=200 SAE is a DIFFERENT instrument by design, has no committed reference, and reproducing k=100 values is neither expected nor meaningful.
