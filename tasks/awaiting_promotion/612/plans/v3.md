## 0.0 TL;DR (plain English)

- **What I'll run:** I'm rebuilding the sycophancy experiment one more time to answer two questions the last two rounds left open: does training the model on its own realistic agreeing answers (instead of canned one-liners) change *how far* the agree-with-anything habit spreads to other personas, and *what* predicts which personas catch it. The last round couldn't tell, because the realistic and canned models were never installed to the same strength — even the earliest saved checkpoints were too far apart. So this time I save checkpoints often enough during training to actually match installed strength, I fix the data-generation step so all four personas get a realistic-data version (two failed to last time), and I build the comparison panel so that "how agreeable a persona already is" and "how similar it is to the trained persona" pull apart cleanly — last time they were tangled, which made "what predicts leakage" unanswerable.
- **What I expect:** at matched installed strength the realistic-data and canned models leak about equally far (the habit's *reach* is set by installed dose, not by where the training text came from), and a persona's own baseline agreeableness predicts whether it catches the habit better than its similarity to the trained persona.
- **What would change my mind:** if at matched strength the realistic-data models clearly leak *more* (or clearly less), the training data itself changes the reach, not just the dose. And if similarity beats baseline agreeableness for most personas on the untangled panel, the habit spreads by representation geometry, not by prior disposition.

4. **Hard drop rule (scope shrinkage, NOT silent):** a source that cannot reach |r| < 0.20 with N≥10 bystanders from the candidate pool is DROPPED from the predictor bake-off (its leakage cells are still reported descriptively) and the drop is named in §5 Acceptance + the clean-result. - the predictor bake-off needs the CLEANEST single-turn dose curve, not the noisier prefix one. v1 already settled C carries no new info at matched dose (it cannot BE matched into the band).

### 4.5 Predictor bake-off (the readout)

For each KEPT source × bystander cell at the MATCHED-INSTALL (band-entry) checkpoint, compute trained−base leakage Δ. Then fit three SEPARATE one-predictor reads and one two-predictor read:
1. leakage ~ bystander base prior (comparator a, front-runner #500/#532/#541)
2. leakage ~ cosine-to-source (comparator b, layer-20)
3. leakage ~ persona-vector → sycophancy-direction alignment (comparator c, #623 `cosine_matrix.json` alignment scalar)

Each predictor: Spearman ρ + a pre-registered 95% BCa bootstrap CI (10k resamples) on the rank correlation. Two-predictor read: partial-Spearman ρ(Δ, cosine | prior) per source — the part v3's decorrelation makes identifiable. **Collinearity gate (pre-registered, my memory):** if |Pearson(cosine, prior)| > 0.6 for a source despite decorrelation, fall back to tercile-bucket median tests + polynomial-residualization robustness instead of the partial ρ. Do NOT pre-promise an unidentifiable joint 3-predictor model at N=10/source — the bake-off is per-source comparative (sign + CI overlap), pooled descriptively.

- **H1 (radius, registered):** on-policy-minus-canned bystander leakage contrast at MATCHED-INSTALL sub-epoch checkpoints, paired per (source, bystander, claim, seed), pooled seed-mean, B=10,000 cluster bootstrap (claims × personas), three-way call verbatim from #612 v1 §3 H1. **Supported** if |point| ≥ +0.05 AND CI excludes 0 AND per-seed sign agreement; **null** if CI ⊂ ±0.03; else **indeterminate**. A POSITIVE supported call (on-policy leaks MORE) kills "dose, not radius" outright. A NEGATIVE supported call kills it only if |point| clearly exceeds the residual-dose bound computed at analysis time (the v2 interpretation map). **Bounded-below-support** fallback if CI ⊂ ±0.05 but not ±0.03. The sub-epoch grid SHOULD shrink v2's residual ~0.23 install gap to ≲0.05-0.10, so the dose-bias bound is much tighter than v2's −0.044 — this is the round's reason to exist.
- **H2 (predictor, registered):** on the decorrelated panel, per KEPT source, the winning predictor = highest |Spearman| with non-overlapping 95% bootstrap CI. **Bonferroni-correct across 3 predictors × (kept sources) at α=0.05** (this IS a comparator bake-off). **Falsification:** if cosine-to-source beats base prior for ≥3/4 kept sources → "geometry, not prior, predicts the new recipe."
- **KILL:** if the on-policy yield fix cannot fill the 80% floor (160 rows) for ≥3/4 sources after the retry budget, STOP after the data-generation phase, post a scope-shrinkage `epm:failure failure_class: data` finding, and let the analyzer fold what's available (≤2 sources) into the clean-result body — do NOT burn training GPU on a 1- or 2-source predictor bake-off (the bake-off needs ≥3 sources for the H2 "≥3/4" falsification to be meaningful).
