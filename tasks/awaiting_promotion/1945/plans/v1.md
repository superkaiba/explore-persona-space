# Plan — task #1945: Is the (context × direction) interaction residual low-rank-recoverable (H1) or per-pair idiosyncratic (H2)?

## 0.0 TL;DR (plain English — the user reads this first)

- **What I'll run:** the parent round showed the answer-prediction map's errors are dominated by specific *pairings* of conversation and answer-feature, not by bad conversations or bad features alone. I'll test whether those pairings follow a small number of recurring patterns — by hiding part of the error grid, fitting a few patterns on the rest, and checking whether they predict the hidden part — and separately whether the patterns can be read off the map's own inputs. Everything runs on already-saved matrices; no new model runs.
- **What I expect:** most of the pairing error will look like what error-size bookkeeping (which conversations are hard, which features are noisy, and how the noise co-moves) already implies, with little or nothing left that a few recoverable patterns explain — the map is close to the best it can do on this input.
- **What would change my mind:** if the hidden-part prediction beats the bookkeeping-matched reference by a clear margin — and especially if the map's own inputs predict the pattern — the map is leaving learnable structure on the table, and a richer map on the same input should close part of the gap.

## 3. Hypothesis

**H1 (STRUCTURED):** the interaction matrix, after two-way (additive) removal in log space, contains low-rank structure that generalizes to held-out (context, direction) blocks *beyond* what the residual's second moment implies: the BCV interaction-R² curve rises above the Gaussian-second-moment null band at low r and explains a nontrivial fraction (≥10%) of held-out interaction variance. Corollary if Tier B is also positive: the structure is recoverable from the map's own input → the map is under-specified.

**H2 (IDIOSYNCRATIC / at-ceiling):** the observed BCV curve sits inside the Gaussian-second-moment band — every apparent pairing pattern is scale bookkeeping + noise covariance + answer-sampling noise; the map is near its information ceiling on this input.

Define, at the pre-registered primary read (full-context L19 ridge cell, log space, k=256, pooled over parent folds): X = observed max-over-r BCV interaction R²; G = the gauss2m null band p97.5 of the per-draw max-over-r statistic; Δg = X − G; Δm = X − 0.10.

DISJOINT and exhaustive: H1-structured ⇔ Δg > 0 AND Δm ≥ 0; H1-weak-structured ⇔ Δg > 0 AND Δm < 0; H2-idiosyncratic ⇔ otherwise.

(H1-weak-structured = statistically detectable but quantitatively minor structure — reported as "map near ceiling, small recoverable residue". The 12-cell × 2-k × 3-space grid is a robustness battery reported as a verdict heatmap; only the primary read drives the lattice.)

Row-coverage: both arms' registered rows are supplied per-context by `data/issue_1482/twoway_stage/pred_{arm}_L{layer}_{fitter}.npz` + `y_parent_L{layer}.npz` (observed arm) and the same staged matrices under the seeded within-column permutation (null arm).

**P1 — Tier A: BCV rank battery (the headline).** Per unit = (cell ∈ 12, parent fold ∈ {0,1}, k ∈ {64,256}, space ∈ {log, raw, normalized}) — 144 fold-units aggregated to 72 pipeline units:

```
Y16, ci = load_layer(layer);  folds = make_folds(9941, seed=1482)   # parent SEED — basis identity with #1482
for (basis_idx, eval_idx) in folds:
    mu, comps, eigvals = pca_basis(Y16[basis_idx], kmax=256)        # parent recipe verbatim
    E    = (P16[eval_idx] - Y16[eval_idx]).astype(f64) @ comps      # (n_e≈4970, 256)
    E_b  = (P16[basis_idx] - Y16[basis_idx]).astype(f64) @ comps    # basis-half residual (for Σ̂_E only)
    R    = E**2; assert (R > 0).all()                               # parent's positivity assert
    for k in (64, 256):
      for space in (log, raw, normalized):
        M   = transform(R[:, :k], eigvals[:k], space)               # log = np.log; norm = /λ_j
        F   = M - twoway_additive_fit(M)                            # parent two_way internals: μ + a_i + b_j removed
        obs = bcv_curve(F, r_grid, row_seed=1945)                   # below
        perm    = batched: B=200 draws, each = independent within-column permutation of F (seeded),
                  IDENTICAL bcv_curve incl. per-draw max-over-r     # destroys row pairing, keeps col marginals
        gauss2m = batched: B=200 draws, rows i.i.d. N(0, Σ̂_E) with Σ̂_E = fp64 cov of E_b[:, :256]
                  (OUT-OF-SAMPLE wrt eval half), row-rescaled to observed ||E_i||, sliced to k,
                  squared → transform → two-way removal → IDENTICAL bcv_curve
        persist per-unit JSONL row + per-draw × per-r matrix (npz)  # checkpoint + resume (regime-keyed)
```

`bcv_curve(F, r_grid)` — Gabriel (2,2) BCV: rows split into 2 seeded halves; columns split into 2 halves by **eigen-rank interleaving** (even/odd ranks, so both column halves span the spectrum); for each of the 4 held-out blocks A11 with complement blocks (A12, A21, A22): SVD(A22) = UΣVᵀ once, then per r ∈ r_grid (truncated to r ≤ k_train/2): Â11(r) = A12·V_r Σ_r⁻¹ U_rᵀ·A21; R²_int(r) = 1 − ‖A11 − Â11(r)‖²/‖A11‖², averaged over 4 blocks × 2 parent folds. r=0 (predict 0) is the additive-only baseline, R²_int(0)=0 by construction. SVDs via Gram eigh (k_train ≤ 128 → trivial); all null draws batched as one `(B, n, k)` tensor per (cell, fold), chunked at 25 draws/chunk (~254 MB fp64) per the vectorize rule — no per-draw Python loop touches the pool.

**P2 — Tier B: input-recoverability (reduced-rank ridge).** Per (cell ∈ 12, parent fold ∈ {0,1}), log space, k=256 only. Features φ(x_i) = [pred_i @ comps[:, :512] (the map's output projected on the fold's answer-PCA basis, 512 dims), ‖pred_i‖, ‖pred_i − proj‖] → d_feat=514. Rows of the eval half split into seeded halves (train ≈2,485 > 514 → well-posed; GCV λ over the default grid with selected-λ + dof reported — not the n_train<d banned regime). Fit full ridge B̂ = `ridge_fit_predict_fast(X_tr, F_tr, X_all, return_info=True)`; rank-r truncation via SVD of the train fitted values (reduced-rank regression, Izenman 1975 / Reinsel & Velu 1998): Ŷ_te(r) = (X_te B̂)V_rV_rᵀ; held-out R²_int(r) on the held-out rows' F. Null: B=200 seeded permutations of the row pairing between φ(x) and F, identical fit budget — the Gram/eigh of X is permutation-invariant, so all draws share ONE factorization and differ only in target projections (batched GEMMs). Companion read: `knn_retrieval` (euclidean + cosine, k ∈ {1, 5, 25} scaled to the ~2,485-row held-out pool; chance = k/n stated) of predicted vs true interaction rows. Scope caveat (registered): φ(x) is a linear image of the map's input through the fitted map — a positive Tier B certifies input-recoverability; a null Tier B does NOT rule out recoverability from the raw input x or from features outside the fitted map's row space. Pre-registered follow-up (not run here): re-stage true X from the #1738 capture if Tier A reads H1 and Tier B reads null.

**P3 — floor netting + figures + summaries.**
(a) Floor-subsample replication: re-run the Tier-A pipeline on the floor subsample (n_sub≈962–973 per arm/layer; the parent's `frac = clip(1 − floor/e2, 0, 1)` row correction, `row_scale=frac`) in raw + normalized spaces — noting explicitly that a scalar row correction is a **no-op in log space** (absorbed by a_i), which is itself a registered observation.

## 8. Risks and Failure Modes

| Risk | Likelihood | Mitigation |
|---|---|---|
| Within-row noise correlation (Σ_E off-diagonal in the PCA basis) makes cross-column prediction possible even without pair-level structure → false H1 vs a permutation-only null | High (the residual SVD *proved* second-moment structure exists) | gauss2m null is the H1 bar; perm null reported as the zero-structure floor only |

## 11. Decision Rationale

`N/A — no model training` (no training hyperparameters). Analysis hyperparameters:

- **BCV scheme (2,2)-fold, Gabriel estimator.** Why: held-out low-rank recoverability is the crux (clarifier); Gabriel BCV is the established cross-validated rank-selection method for a fixed matrix, and (2,2) matches the parent's split-half convention so fold geometry stays comparable. Source: arXiv:0908.2062 (Owen & Perry 2009) + #1482 (`make_folds` split-half). Alternatives: Wold speckled holdout (rejected — entry-wise holdout complicates the two-way removal); larger (h,l) (rejected for v1 — more blocks at little power gain at n≈5k; noted as a cheap robustness knob).
- **Rank grid r ∈ {1,2,4,8,16,32,64}, truncated to ≤ k_train/2.** Source: #1775 `R_GRID` (grep: `scripts/issue1775_bilinear.py:91`). Alternatives: denser grid (unneeded — the curve, not a single r, is reported).
- **Null draws B=200/family; descope floor 50.** Source: #778/#834 null-battery convention (`null_battery.py` batched draws; 200 default). Alternatives: 1000 (rejected — p97.5 stable at 200; wall × 5 for no verdict change).
- **k ∈ {64, 256}; primary 256.** Source: #1482 `K_GRID` (grep: L84) and the parent's floor-correction k (=256). Alternatives: 512 (rejected — eigval tail adds noise-dominated columns; 512 retained only as the draw-generation dimension for nesting).
- **Primary space = log; raw + normalized companions.** Why: multiplicative scale structure (the Gaussian-second-moment prediction E[R]=s_i²σ_j²) becomes additive in log space and is removed exactly by the two-way fit, so log-space BCV isolates structure *beyond* scale coupling; log χ²₁ has constant variance (π²/2), stabilizing the SSE fit. Source: #1482 (the parent's `two_way(np.log(R))` companion, interaction share 0.859 at the primary cell) + standard variance-stabilization for χ² data. Alternatives: raw-primary (rejected — heteroscedastic, largest-mean cells dominate; kept as companion).

Alternatives: pooled verdict over cells (rejected — pooling mixes arms with different constructs; the heatmap reports all).

N(0, Σ̂_E) from the basis half, row-norm matched).** Why: the residual SVD's finding (iii) says E has exactly second-moment structure; H1 must clear that reference or it is re-discovering known covariance.
