# Plan v4 — Issue #2215, same-issue follow-up `discrimination-battery-expansion`: extend the minimal-pair discrimination battery to nine new content-level pair types

**Scope class: AMENDMENT (self-contained).** This plan inherits the executed #2215 rig (plan v3 + the clean-result body's Methodology/Repro) byte-identical except the one design change this round exists to make: a broader pair taxonomy, which requires new paired contexts, new on-policy anchor rollouts + answer-state capture for them, and the same DV3-style discrimination battery per new type. Everything unchanged from v3 is restated here so the document stands alone.

## 0.0 TL;DR (plain English — the user reads this first)

- **What I'll run:** I build nine new kinds of paired conversations the current bank doesn't cover — same conversation twice, differing only in who the user says they are, how formally they write, what the conversation is about, what language it's in, whether a stated fact is true, the sentiment of a pasted review, how pasted data is formatted, whether the request is one the model should refuse, and whether a problem is shown as code or prose. For each new pair type I sample fresh answers from the frozen model, then check whether our existing conversation-to-answer predictors can tell the two paired conversations apart, against the same simple-baseline and chance yardsticks as the last round.
- **What I expect:** the predictors separate most new pair types well above chance, the constant-shift baseline again captures most of that at context-end, and the refusal pairs show a specific signature — easy to tell apart pairwise but hard to retrieve exactly, because refusal answers all look alike.
- **What would change my mind:** if a content-level distinction like sentiment or factual correctness sits at chance while the surface-level ones (language, code) are easy, that says the map carries surface form rather than meaning — sharpening "what the map can vs cannot distinguish" for the paper in the opposite direction from what the last round suggested.
