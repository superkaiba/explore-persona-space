# Plan — #653: Do conditional behaviors decompose cleanly into read and write features? (v4, Option A AMEND)

## 0.0 TL;DR (plain English)

- **What I'll run:** Two experiments asking the same question — when you teach a model "in this role, do this behavior," does that split cleanly into a part that *detects the role* and a part that *produces the behavior*, the way a tidy two-piece edit would? Probe A pokes the base model directly (no training): nudge its hidden state in a random direction, let it write, then read back what an un-nudged copy infers from those words. Probe B trains the behavior in for real at four "edit sizes" (from the smallest one-direction edit up to retraining the whole model) and watches how the hidden states move. I run both across three behaviors and a few roles so the answer isn't a fluke of one setup.
- **What I expect:** The clean split mostly holds for the small edits — the move is low-dimensional and the "write" re-reads roughly as itself — but it gets messier as the edit gets bigger, and a few behaviors won't behave like the others.
- **What would change my mind:** If the small-edit case is *already* diffuse, or if a big full retrain stays just as tidy as a one-direction edit — either would overturn the "small edits are special" story the rank-1 picture rests on.

## 1. Goal

Test whether a conditional behavior — "in context `C`, emit behavior `B`" — decomposes **cleanly** into a separable **read** part (condition-detection) and a **write** part (behavior-production), as the rank-1 LoRA idealization (`ΔW ≈ w·x_C^T`; theory `docs/notes/rank1_leakage_model.tex` A2) assumes. We attack it from two sides: **Arm A** (training-free) characterizes the base model's autoregressive write→read map `ρ` through the token bottleneck under random-bias steering; **Arm B** characterizes how a real fine-tune moves activations (`Δx`) across the edit-rank ladder (rank-1 LoRA → rank-r LoRA → full FT). For each we ask: is the structure **low-rank and read↔write-aligned** (clean — H1), **structured but rotated** (H2), or **diffuse / high-rank** (H3)? Per the user's breadth directive, the verdict is reported **per (behavior × context) cell AND aggregated** across ≥3 behaviors and a few source contexts, so the answer generalizes. This is the empirical instantiation of the theory's central anomaly (`r_b ≠ d_b ≠ v_b`; write cos ≈ −0.03 to the realized marker shift, #521; write cos 0.04 yet 98% ablatable, Soligo) and walks its Assumption-5 relaxation ladder (rank-one → low-rank multi-pair → rich regime).

## 3. Hypotheses

Stated per arm; the verdict is the per-cell ranking of these three plus the cross-cell consistency read.

### 3.0 Spectral definitions (pinned — read before the thresholds)

All spectral DVs are computed on the **eigenvalue (variance) spectrum** `λ_i := σ_i²`, where `{σ_i}` are the singular values of the relevant matrix (SVD of the Jacobian `J` for Arm A, or of the row-centered shift/Δx cloud for Arm B; row set per §3.3). Two quantities, defined ONCE and used everywhere:

- **top-share** `:= σ₁² / Σ_i σ_i²` — the leading eigenvalue (variance) share. NOT the raw-σ fraction `s_top1_frac = σ₁/Σ_i σ_i` stored in `eval_results/issue_521/svd/*.json` (a different quantity, never the registered DV). EM exemplar: 0.81/0.86/0.89 → a 0.7 cut keeps it clean.
- **PR** (participation ratio) `:= (Σ_i σ_i²)² / Σ_i σ_i⁴ = (Σ λ_i)² / Σ λ_i²` on the eigenvalue spectrum. EM exemplar: 1.49/1.34/1.25 → a PR ≤ 2 cut keeps it clean. The raw-σ PR `(Σσ_i)²/Σσ_i²` (4.78/4.21/3.71 on EM) is a DIFFERENT convention, NOT a registered DV.

Both scale-free, non-saturating by construction. **Pinned constants in code:** `TOP_SHARE_LOWRANK = 0.7`, `PR_LAMBDA_LOWRANK = 2.0`, `PR_LAMBDA_H3 = 5.0`, `RANK_K_H3 = 10` (`__init__.py:183-186`).

### 3.1 The three hypotheses

- **H1 — clean decomposition.** Structure approximately linear, low-rank, alignment-preserving. *Arm A:* `ρ(w) ≈ Jw` high variance-explained, low effective rank, round-trip cos(w, ρ(w)) bounded away from 0, `ρ(d_B) ≈ r_B`. *Arm B:* `Δx` near rank-one (top-share ≥ 0.7), top direction aligned to `r_B` (|cos| ≥ 0.5 above random CI), holds across the ladder up to full FT. **Falsified if** PR_λ > 2 / the H3 boundary, or top-share < 0.7 at any rung.
- **H2 — structured but rotated.** Low-rank (top-share ≥ 0.7, PR_λ ≤ 2) but leading direction a stable rotation from `r_B` (|cos| near 0 but reproducible; cross-seed leading-direction cos high). Matches the write⊥read-out anomalies.
- **H3 — diffuse / no clean structure.** **rank-K ≥ 10** OR **PR_λ ≥ 5** (rank-K = smallest K with cumulative variance share `Σ_{i≤K} σ_i²/Σσ² ≥ 0.9`). *Arm B sub-case:* H1/H2 at rank-1 degrading to H3 toward full FT.

### 3.2 Quantitative per-cell thresholds (pre-registered, σ² spectrum)

- **"low-rank"** = PR_λ ≤ 2 OR top-share ≥ 0.7 (`spectral.py:276`).
- **"aligned"** = |cos(top dir, `r_B`)| ≥ 0.5 AND exceeds the norm-matched-random CI upper bound (#503; `spectral.py:281-283`). The 0.5 floor is NOT load-bearing in isolation — the random-CI clause is the gate; §6 reports the realized cos distribution.
- **"rotated"** = top-share ≥ 0.7 but |cos| < 0.5 with cross-seed leading-dir cos ≥ 0.7 (`spectral.py:297`). The 0.7 cut is fragile (#521 EM is 0.65–0.90 stable) — near-threshold calls reported with CI + cross-seed-unverified flag.
- **"diffuse" (H3)** = rank-K ≥ 10 OR PR_λ ≥ 5 (`spectral.py:277`). **H3 wins over low-rank labels** (`spectral.py:291`).

**Grounding:** thresholds inherit #521's verified EM read; the H3 PR_λ ≥ 5 boundary sits well above the exemplar (clear separation). Guarded by `assert_exemplar_calibration()` (`spectral.py:341`).

### 3.3 Per-cell row count (so the SVD is well-determined)

The per-cell shift/`Δx` cloud is the on-policy response-mean shift rows pooled across the full evaluated context panel + prompt set (source + bystander/negative panel + breadth contexts × 20 `EVAL_QUESTIONS`), ≥ several dozen rows per cell. The implementer asserts row count ≥ `MIN_SPECTRUM_ROWS` (14, `__init__.py:189`) before any spectrum; fewer rows → labeled `underdetermined`, unlabeled (`spectral.py:258-274`).

### 3.4 Aggregation rule (the generality claim) + deciding-DV CI sub-spec

A verdict is "consistent" if the same H-label wins in ≥ 5 of 6 (behavior × context) cells per arm at the matched rung; "behavior-dependent" if it splits by behavior; "context-dependent" if by context. Reported as a 3×2 verdict grid per arm + per rung, **with a per-cell ambiguity flag**, never collapsed to a single word.

**The ambiguity flag MUST be computed on the DV that DECIDED the cell's H-label** — this is the v4 fix for BLOCKER `deciding-ci-hardcoded-top-share`. The label is set by a disjunction (`is_low_rank = pr ≤ 2 OR top_share ≥ 0.7`; `is_h3 = pr ≥ 5 OR rank_k ≥ 10`), so the deciding DV is NOT always top-share. A top-share CI ∈ [0,1] can never bracket the PR thresholds 2.0/5.0, so a cell whose H3 label rests on PR_λ = 6.0 is presently always-unambiguous — wrong by construction.

#### Deciding-DV CI specification (pseudocode the implementer CANNOT reinterpret)

`classify_cell` MUST return, alongside the verdict, a `deciding_dv` string ∈ `{"top_share_lambda", "pr_lambda", "rank_k_at_90", "cos_top_to_rb", None}` naming the single DV whose threshold the label rests on. Selection rule (apply in this exact precedence, mirroring the label precedence in `spectral.py:291-311`):

```
def deciding_dv_for_label(top_share, pr, rank_k, cos_top_to_rb,
                          is_low_rank, is_h3, is_aligned, label):
    # H3 wins first (spectral.py:291). The deciding DV is whichever H3
    # criterion actually crossed; if BOTH crossed, pick the one closer to
    # its threshold (smaller fractional margin) so the CI gate is tightest.
    if is_h3:
        cand = []
        if pr >= PR_LAMBDA_H3:      cand.append(("pr_lambda",    abs(pr - PR_LAMBDA_H3) / PR_LAMBDA_H3))
        if rank_k >= RANK_K_H3:     cand.append(("rank_k_at_90", abs(rank_k - RANK_K_H3) / RANK_K_H3))
        return min(cand, key=lambda t: t[1])[0]      # tightest-margin H3 criterion
    # H1 / H2 both require low-rank; the deciding low-rank criterion:
    if is_low_rank:
        cand = []
        if top_share >= TOP_SHARE_LOWRANK: cand.append(("top_share_lambda", abs(top_share - TOP_SHARE_LOWRANK) / TOP_SHARE_LOWRANK))
        if pr <= PR_LAMBDA_LOWRANK:        cand.append(("pr_lambda",        abs(pr - PR_LAMBDA_LOWRANK) / PR_LAMBDA_LOWRANK))
        low_rank_dv = min(cand, key=lambda t: t[1])[0]
        # If the H1 vs H2 split (alignment) is what's live, the alignment cos decides.
        if is_aligned is not None and cos_top_to_rb is not None:
            return "cos_top_to_rb"   # H1↔H2 turns on |cos| vs the 0.5 floor + random CI
        return low_rank_dv
    # boundary cells (H2/H3 boundary, underdetermined): no single deciding DV
    return None
```

Then the ambiguity flag is computed on THAT DV only, against THAT DV's own threshold(s):

```
DV_THRESHOLDS = {
    "top_share_lambda": (TOP_SHARE_LOWRANK,),            # 0.7
    "pr_lambda":        (PR_LAMBDA_LOWRANK, PR_LAMBDA_H3),# 2.0, 5.0
    "rank_k_at_90":     (RANK_K_H3,),                     # 10
    "cos_top_to_rb":    (COS_ALIGNED_FLOOR,),             # 0.5  (+ random_ci_high, below)
}

deciding_dv = deciding_dv_for_label(...)
if deciding_dv is None:
    ambiguous, deciding_ci = True, None     # boundary/underdetermined → already ambiguous
    record deciding_ci_unavailable = True
else:
    ci_lo, ci_hi = cluster_bootstrap_dv(cloud, clusters, deciding_dv, B=10000, seed=653)

    # cos alignment also crosses if the CI straddles the random-CI upper bound:
    if deciding_dv == "cos_top_to_rb" and random_ci_high is not None:

```

## 7. Decision Gates

### §7.A — Arm A coherence gate per-layer-pair sub-spec (pseudocode the implementer CANNOT reinterpret)

This is the v4 fix for BLOCKER `full-ft-gate-coherence-not-per-layer-pair`. Round-4 `_coherence_pass_ok` (`__init__.py:332-341`) takes `best = max` over a FLAT iteration of every coherence key across every payload, then `ok = best >= GATE_ARM_A_COHERENCE_MIN` — one coherent (dist, layer-pair, mag) releases the rung. The coherence keys are `f"{dist}|{layer_in}-{layer_out}|m{mag}"` (`i653_dispatch.py:577`), so the layer-pair `{layer_in}-{layer_out}` is trivially parseable. The gate must require EVERY planned layer-pair to clear the floor.

```
# PLANNED_LAYER_PAIRS is the §10 read-layer set, frozen as a module constant so the
# gate checks against the PLAN, not against whatever happened to be produced:
PLANNED_LAYER_PAIRS = {"10-10", "15-15", "20-20", "25-25", "20-21"}   # §10 Reproducibility Card
# (behavior-specific pairs, if produced, are checked too but are NOT required —
#  only the always-on PLANNED_LAYER_PAIRS set is required.)

def _coherence_pass_ok(arm_a_payloads: list[dict]) -> tuple[bool, dict]:
    # group max coherence pass-rate by layer-pair across all (dist, mag, seed):
    per_pair_best: dict[str, float] = {}
    for payload in arm_a_payloads:
        for key, rate in payload.get("coherence", {}).items():
            if rate is None:
                continue
            # key = "dist|layer_in-layer_out|mMag"  →  layer-pair is field [1]
            parts = key.split("|")
            if len(parts) != 3:
                raise ValueError(f"unexpected coherence key shape {key!r} (expected dist|pair|mag)")
            pair = parts[1]
            per_pair_best[pair] = max(per_pair_best.get(pair, -1.0), float(rate))

    per_pair_pass = {p: (per_pair_best.get(p, -1.0) >= GATE_ARM_A_COHERENCE_MIN)
                     for p in PLANNED_LAYER_PAIRS}
    missing = sorted(p for p in PLANNED_LAYER_PAIRS if p not in per_pair_best)
    ok = (not missing) and all(per_pair_pass.values())   # EVERY planned pair must clear the floor
    detail = {
        "per_layer_pair_best": {p: per_pair_best.get(p) for p in PLANNED_LAYER_PAIRS},
        "per_layer_pair_pass": per_pair_pass,
        "missing_layer_pairs": missing,         # a planned pair with NO coherence read → gate FAIL
        "threshold": GATE_ARM_A_COHERENCE_MIN,
        "passed": ok,
    }
    return ok, detail
```

Rules:
1. **`ok = all(per-planned-pair clears the floor)`, NEVER a global `max`.** A single coherent pair does NOT release the rung.
2. **A PLANNED layer-pair with NO coherence read at all = gate FAIL** (it lands in `missing_layer_pairs`) — silence is not a pass.
3. **`gate_decision.json` records `per_layer_pair_best`, `per_layer_pair_pass`, and `missing_layer_pairs`** so the kill outcome names the un-coherent pair(s) by name (the §7 kill outcome requires this).
4. `PLANNED_LAYER_PAIRS` is the always-on read set from §10. Behavior-specific extra pairs (marker 19–24, syco 1–8 per theory P5) are checked if produced but are NOT in the required set (they are stretch reads, not gating reads) — keeps the gate from FAILing on an optional pair that wasn't generated.

## 11. Decision Rationale

**Shared recipe groups (one Source per unique value, not per condition):**

- **Marker rungs** — lr=5e-6, marker-only loss, band-stop [5,12] nat (`MarkerBandStopCallback` default, `sft.py:611-612`). **Why:** the only demonstrated clean (non-saturating) marker window; marker-only loss has no countervailing term so lr is the over/under dial. **Anchor validity gate:** band-stop reads SOURCE log-prob into [5,12]; the source IS expected to saturate (it IS the implant), so the usability check is on bystander resolution — the on-policy eval must show bystander argmax-emission BELOW ceiling (`marker-training-recipe.md`). **Source:** `marker-training-recipe.md` + `#538`/`#527` (the [5,12]-band landing) + `#329` (5e-6 clean). **Marker recipe overrides parent parity:** lr 5e-6 ≠ the sycophancy/EM 1e-5 (which would saturate the marker, #480). **Alternatives:** lr 1e-5/1e-4 rejected (#397/#451).
