# The context→answer map's error is category-structured: non-English contexts are predicted better than English, and the linear-vs-nonlinear gap concentrates in low-variance answer directions (HIGH confidence)

<!-- clean-result-v4 -->

**Methodology:** [docs/methodology/issue_1482.md](https://github.com/superkaiba/explore-persona-space/blob/531abbb52c1df51a9529c53e1644086daa7b217e/docs/methodology/issue_1482.md) · [gist](https://gist.github.com/superkaiba/fa589d67dc4ed196875a777a88dbdce7)

## Takeaways

- Non-English contexts are predicted better than English (normalized error 0.274 vs 0.291), falsifying the planned direction; the sign survives intrusion exclusion and corpus transfer, and floor adjustment widens the gap to −0.034 (CI95 −0.044 to −0.024).
- Structure inside the arms dwarfs the binary gap: per-language means span German 0.236 to Arabic 0.420; task types span small talk 0.235 to translation 0.337 (all 15 contrasts pass BH-FDR).
- The nonlinear map wins on 90.7% of contexts, and its advantage grows about fourfold toward low-variance answer directions (0.035 to 0.138), surviving per-direction ridge tuning: genuine nonlinearity, not shrinkage.
- Feature predictability is an answer-side property (Spearman 0.93); within-answer consistency dominates at every depth and dictionary (ρ 0.60/0.68/0.60 at layers 19/3/20), with no early-layer inversion (median 0.095 layer 3 vs 0.129 layer 19).
- Training-imposed matryoshka tiers give a judge-free granularity read: median R² falls 0.43 → 0.17 → 0.04 general-to-specific, the gradient survives activity stratification (Spearman −0.39 vs band −0.25 to −0.23) but reverses in the two lowest-activity quintiles; judged labelling stayed frozen.
- The pile-trained twin reconstructs chat worse (variance explained 0.71 vs 0.80) yet reads slightly more predictable (median difference 0.017, unpaired panels); coarse features are shared across training corpora (tier-0 match cosine 0.57 vs 0.08 at tier 2).

## Goal

**This experiment in context:** The parent [#779](https://eps.superkaiba.com/tasks/779) fit five predictors from the last-prompt-token activation `c_last(x)` to the mean-answer activation `v(x)` (layer 19, Qwen-2.5-7B-Instruct) on ~963k real LMSYS/WildChat chat contexts and measured what the map achieves overall: held-out R² 0.754 (ridge) to 0.810–0.813 (MLPs). This experiment asks where the remaining error and the nonlinear-only component live — which contexts, which answer-side SAE features, which directions of the answer representation. The refits here reproduce the parent's committed aggregates on the same pinned split with the same code (directly comparable by construction), and the teacher-forced capture recipe with its token-id-concatenation seam rule and identity gate is inherited from [#1092](https://eps.superkaiba.com/tasks/1092).

**Broader narrative:** the project treats the pre-generation context state as a predictor of what the model is about to do, and the leakage-theory line assumes that context→answer map is linear. Whether the map's error is category-structured (an actionable trust boundary plus a fix path) or diffuse (an intrinsic answer-variability ceiling) decides how far a pre-generation behavior predictor built on this map can be trusted; the per-direction linear-vs-nonlinear decomposition tests what the linear assumption discards.

## Methodology

**Design:** An error-analysis of an existing map — no new training. One GPU run (three GCP 4×A100 attempts, then a RunPod 4×H100 failover pod; checkpointed phases seeded from the surviving partial attempt), then off-pod judging and analysis. Stages: (1) stream the parent's 1,920 capture chunks from HF and rebuild the 963,444-context train matrices (layer-19 last-prompt-token state and mean-answer state), re-asserting the parent's pinned 400-row val / 1,000-row test split by sha; (2) carve a fresh 20,000-context holdout (RNG seed 1482, corpus-stratified, never entering any fit) plus a disjoint 120,000-context SAE fit subsample; (3) refit all five parent fitters three ways — full-train (the reconciliation control), holdout-excluded (the taxonomy read), and LMSYS-only (the corpus-transfer fold) — persisting per-context error; (4) teacher-forced forwards over the parent's persisted prompt+answer text (per-segment token-id concatenation, never re-tokenizing the concatenated string) for the 141,400 SAE-arm contexts, SAE-encoding every token and pooling answer-side features three ways (mean, max, fraction-active); (5) linear and MLP maps in feature space — context features → answer features, dense context state → answer features, and a prefix-arm null — plus a per-direction PCA decomposition of the dense map; (6) one judge call per context labeling language, topic, refusal-adjacency, answer-is-refusal, and format; (7) vectorized bootstrap/permutation analysis and figures. The dense map is the context-based arm (prefix + user query up to the last prompt token). A zero-GPU follow-up round (2026-07-19) added stage (8): a seeded label-permutation null for the per-feature read — answer rows permuted within the 120,000-row SAE fit set, λ pinned to the parent-selected value, feature restriction asserted equal to the parent's feature ids, holdout scored on true pairs; an identity-permutation gate reproduced the parent's committed per-feature R² (median |Δ| = 1.5e-5; pooled 0.6901407 vs 0.6901409). A second follow-up round (`k-resample-noise-floor`, 2026-07-19, ~3.1 realized GPU-h) added stage (9): regenerate K = 4 fresh answers per context (seeds 43–46, the parent decoding recipe) for a 2,000-context language-stratified subsample of the labeled holdout (1,000 per arm, RNG seed 148201), capture each fresh answer's `v` under the parent capture convention (full-template re-tokenization, answer span including the end-of-turn tail), stream the parent seed-42 `v` verbatim from the parent capture chunks (2,000 of 2,000 rows found across 1,233 chunks; no recapture), and compute the per-context answer-sampling floor plus the floor-adjusted language contrast (joint 10,000-draw bootstrap, seed 1482). Two earlier attempts of this round recaptured the parent draw under the generation-time token-id convention and failed the identity gate — generation-time ids differ from the parent's own full-template re-tokenization for 93.1% of rows — so the round switched to the streamed-parent + parent-convention design before any read. Scope caveats:

- The SAE arm covers new-pool rows only — the 1,400 pinned val/test contexts have no reconstructable text, so feature-space λ-selection uses a 2,000-row carve of the SAE subsample.
- The Goal-named 16,384-feature SAE repos are weight-empty on HF, so the run substitutes the only weight-bearing suite (andyrdt layer-19 instruct SAEs, 131,072 features) — better matched to the map layer, validated by the fitness gate below.
- The dense per-context read is context-arm-only: every prompt is single-turn, so the prefix (everything before the user query) is one constant chat-template string — verified live (prefix-end states constant across contexts, min cosine 1.000) — and the prefix arm runs at SAE-subsample scale as a null.
- The encode-the-prediction read is off-distribution (an SAE applied to mean-pooled states) and reported as secondary only.
- The conversation-depth taxonomy axis was dropped (single-turn corpus).
- 4 content + 29 transport judge losses (0.165%) were not re-judged — an adversarial bound assigning all 33 missing rows extreme observed values moves the language contrast by at most +0.011 (to −0.006), so its sign cannot flip.
- `v(x)` is one sampled answer per context, so absolute per-category error levels include an answer-sampling-variance share — measured by the k-resample round at 33–40% of per-context error on the language arms (the paired gap reads are immune — same answer under both fitters).
- The early-layer arm's judged labels are frozen: the planned pooled-depth and within-layer-3 abstraction-level permutation tests are deferred until a validated auto-interp labelling instrument lands (the successor labelling task named in the Context row), so this round carries mechanical reads only.
- The early-layer arm fits 24,000 rows (vs the parent SAE arm's 120,000), so cross-round absolute levels are not comparable; the matched-row layer-19 refits carry the depth contrast. The cross-depth absolute comparison is itself descriptive — the two dictionaries differ in reconstruction quality (measured fraction of variance explained 0.920 at layer 3 vs 0.810 at layer 19).
- The layer-3 MLP read is fit on 24,000 rows (the committed dense MLP fit 963,444), so its deficit against the ridge conflates depth with fit size; all early-layer fits are single-seed (fit seed 0, subsample seed 14823), with the k=128 second dictionary as the replication axis.
- The co-activation covariate saturated at 1.0 for over 99.9% of features at both depths (full-density companion latents), so its near-zero rank correlation is uninformative, not evidence of no effect.
- The matryoshka round's layer-20 jumprelu-matryoshka k=100 numbers are not directly comparable to the committed layer-19 BatchTopK k=64 numbers: the core battery (fits, nulls, baselines, covariates) is recomputed on this round's own arms, no figure splices tier onto committed values, and cross-round correlate comparisons are qualitative only.
- Tier is confounded with firing frequency by construction (general-tier features fire more often), so the raw tier gradient is descriptive; the headline is the within-activity-stratum permutation read, with activity deciles merged to quintiles per the plan's fallback (the sparsest decile-tier cell held 17 features, under the 20-feature floor).
- The matryoshka fits use 24,000 rows and a single fit seed per arm; the tier-stratified target panel keeps every floor-clearing tier-0 feature (1,640 chat / 1,639 pile) but samples tiers 1–2 (6,144 and ~8,600 of the floor-clearing populations), so panel composition affects which features carry R² estimates, not the full-population descriptives. The chat-vs-pile predictability comparison is additionally unpaired over these differently-selected populations: each panel's activity floor is computed on chat tokens, so the pile panel conditions on chat-transferability.
- The tier × judged-abstraction-level agreement item from the round's scope is deferred: judged labelling stayed frozen (zero judge calls), and the judged spec is preserved verbatim in the evidence pack for the successor instrument's resume.

On the fresh 20k holdout the ridge whole-map R² is 0.7243 (mean cosine 0.9566). Two validity gates ran before any read. Reconciliation gate (PASS, no dropped arms): the full-train refits reproduce the committed aggregates on the pinned test — ridge 0.7541708 (|Δ| = 5.6e-16 against a 0.002 tolerance), `mlp_w8192` |Δ| = 1.9e-9 and `mlp_w32768` |Δ| = 1.3e-7 (0.01 tolerance), residual-skip 1.3e-9, KRR 6.6e-15; 13 fit units were seeded from the GCP partial attempt `att-20260718-055220` and reconciled. **Data extraction:** Per-context error arrays join judge labels through the sha-verified scratch row map (19,967 of 20,000 joined). Bootstrap contrasts run as one masked matrix multiply over 10,000 draws. The script-intrusion scan matches CJK and Cyrillic codepoints in the judge-visible completion text (prompt capped at 1,500 chars, completion at 1,000 — 59.5% of completions at cap, so length strata reduce to three usable bins). The per-direction read projects the same holdout predictions as the per-context read onto the top-256 eigenvectors of the train-split covariance of `v(x)` (eigenvalues span 172 → 0.38, roughly 460×) and scores per-direction held-out R² for each fitter. Per-feature R² is feature-standardized over the 20k holdout, with split-half rank stability over two disjoint 10k halves. The k-resample floor for a context is the ddof-1 trace of the covariance of `v` over its four fresh draws divided by the parent's stored denominator; the adjusted contrast subtracts the arm-mean floor difference (subsample) from the raw full-holdout contrast, and the two bootstrap terms resample independently within arms (the ~10% subsample-within-holdout overlap makes them weakly dependent — the subsample-internal estimate is the stated sensitivity check). The shrinkage-control round scores all 38 λ values for all 256 directions off one eigendecomposition as per-λ blocked GEMMs; the tuned arm's holdout projections are gathered from retained per-λ fp16 projection tables, and the 10,000 bootstrap draws run as three GEMMs over per-context per-direction residual matrices. The early-layer arm pools per-token layer-3 SAE codes over the answer span under the reference inlier mask (BOS offset 8, 10× norm-outlier exclusion); the sink-robustness twin adds special-token positions to the mask; per-feature R², the shuffle null, and the covariate battery are computed from the same 6,000 score rows at both depths — the depth contrast holds rows, estimator, restriction recipe, and poolings fixed and varies only the layer. The matryoshka round encodes each token through both dictionaries in one capture pass (fp32, batched over tokens; per-token codes never materialized beyond the batch in flight), pools under the reference inlier mask plus the sink-robustness mask, and consolidates pooled rows into ~64 npz shards per family, uploaded before any fit. Cross-dictionary matching unit-normalizes decoder rows and reduces a chunked fp16 GEMM to each feature's best-match cosine in both directions; the tier permutation shuffles tier labels within activity quintiles and re-pools the Spearman statistic per draw.
