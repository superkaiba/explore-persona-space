### Phase C — estimator + analysis (VM, CPU-only, ~0.2 h)

All single-shot vectorized tensor math (no per-context Python loops):

```python
# V: (n, 5, 3584) fp64-cast; vhat: (n, 3584) from holdout_pred16 (fp16 -> fp64)
# e2_s, denom_s, nerr_s: stored parent arrays for the same rows
vbar   = V.mean(1)                                   # (n, 3584)
trvar  = V.var(1, ddof=1).sum(-1)                    # (n,) answer-entropy floor, raw units
e2_k   = ((V - vhat[:, None, :])**2).sum(-1)         # (n, 5) per-draw errors
m2     = ((vhat - vbar)**2).sum(-1) - trvar / 5.0    # (n,) unbiased ||vhat - E[V(x)]||^2
floor_n  = trvar / denom_s                           # per-context floor, nerr units
nerr_adj = m2 / denom_s                              # per-context map-only error, nerr units
```

- **Gate G1 — recapture reconciliation (HALT on fail):** recomputed e2 for the parent draw (`e2_k[:, 0]`, i.e. ‖v̂ − v_42_recaptured‖²) vs stored `holdout_e2` on the same rows: median relative |Δ| ≤ 2% AND Spearman ≥ 0.995. Failure = capture-convention drift (wrong answer-token range / layer / template) — fix before any read; no result is publishable past a failed G1.
- **Gate G2 — draw exchangeability (fallback, not HALT):** per-context rank of the parent draw's e2 among the 5 draws; |mean rank − 3.0| ≤ 0.15 (SE ≈ 0.032 over n≈2,000). On failure (a parent-vs-now sampling-distribution shift, e.g. vLLM kernel drift), the floor and m2 recompute from the **4 fresh draws only** (ddof=1, n=4; `m2 = ||vhat − v̄_new||² − trvar_new/4`) and the shift is carried as a body caveat.
- **Primary:** Δ_adj = Δ_raw_full − Δ_floor, where Δ_raw_full = mean nerr(non-EN) − mean nerr(EN) over all 19,967 labeled holdout rows (stored arrays; point −0.017498) and Δ_floor = mean floor_n(non-EN sub) − mean floor_n(EN sub). Joint 10,000-draw bootstrap: each draw independently resamples full-holdout rows within arms (raw term) and subsample rows within arms (floor term); percentile CI. The ≈10% subsample-within-holdout overlap makes the two terms weakly dependent — the independence approximation is stated, and the self-contained secondary S1 is the sensitivity check.
- **Secondary S1 (self-contained):** Δ_adj^sub = mean nerr_adj(non-EN sub) − mean nerr_adj(EN sub), own within-arm bootstrap — immune to the overlap approximation, lower power (§11).
- **Secondary S2 (mechanism share):** per-arm floor levels mean floor_n(EN), mean floor_n(non-EN), Δ_floor with CI, and floor share of each arm's mean nerr.
- **Robustness:** the same pipeline against `refit_holdout__mlp_w8192__seed0.npz` predictions (zero extra GPU — v_k are fitter-independent); unnormalized (raw-e2-units) versions of Δ_floor and Δ_adj as a normalization sensitivity.
- **Coherence C1:** subsample stored raw Δ (2k rows) vs parent full Δ — must sit inside the subsample bootstrap CI (a stratification/join bug detector).
- **Diagnostics:** fraction of contexts with m2 < 0 (estimator noise read); per-language-code floor breakdown; floor vs answer-length Spearman (exploratory).

Outputs: `eval_results/issue_1482/kresample/{floor_summary.json, adjusted_contrast.json, gates.json, percontext_floor.npz}` + figures (§6) committed to the branch.

## 11. Decision Rationale

`N/A — no model training` (no training hyperparameters; entries below cover the round's load-bearing design values).

- **K = 4 extra draws (5 total).** What: per-context draw count for the variance estimator. Why: 5 draws give the trace estimator 4 degrees of freedom per dimension; summed over 3,584 dims the per-context floor estimate has ~O(10%) relative noise (effective-dimension argument), and the ARM-level floor mean over 1,000 contexts is tight regardless (SE = sd(floor_n)/√1000). Raising K shrinks only the per-context dof noise — already sub-dominant — while cost scales linearly; the binding noise is BETWEEN-context spread, which only n addresses. K=4 is the smallest K with an unbiased ddof-1 variance and comfortable dof, and 8,000 generations is exactly the 4 GPU-h cheap band. Source: this section's arithmetic + the scope spec (`epm:followup-scope v1`); no literature pin exists for a variance-floor draw count — flagged honest-ungrounded-in-literature, grounded in design arithmetic.
- **n = 2,000 (1,000/arm).** What: subsample size. Why (measured, computed this draft from the parent arrays): per-arm nerr sd = 0.1519 (EN) / 0.1605 (non-EN); full-holdout Δ_raw analytic CI half-width ±0.0046 (reproduces the reported bootstrap exactly); at 1,000/arm a purely subsample-internal contrast has half-width ±0.0137 — marginal against |Δ| = 0.0175, which is WHY the primary is the decomposition estimator Δ_raw_full − Δ_floor: its half-width is √(0.0046² + hw_floor²), and since floor_n is one non-negative component of nerr, sd(floor_n) ≤ sd(nerr) bounds hw_floor ≤ ±0.014 worst-case and plausibly ~±0.007, i.e. combined ~±0.008–0.015. Equal arms maximize contrast precision at fixed n. Source: draft-time computation on `refit_holdout__ridge__seed0.npz` + `labels.json` (join reproducing Δ = −0.017498).
- **Estimator family (unbiased trace + mean-correction m2).** What: `trvar` ddof-1; `m2 = ‖v̂−v̄‖² − trvar/5`. Why: E‖v̂−V‖² = ‖v̂−E V‖² + trΣ decomposes the parent's e2 exactly; both corrections are standard unbiased identities, keeping E[nerr] = E[nerr_adj + floor_n] by construction. Source: this plan §4 pseudocode (algebraic identity; no tuning).
- **Stored per-context denominator kept fixed.** Why: preserves unit-for-unit comparability with the parent Δ; the denominator's own draw noise is second-order and probed by the unnormalized sensitivity read. Source: parent `_percontext` definition (#1482).
- **Generation params (temp 1.0 / top_p 0.95 / max 1,024 / default system).** Inherited verbatim — the floor must be measured under the SAME sampling distribution as the parent draw or it measures the wrong quantity. Source: #779 (`issue779_ffc_n10k_generate_capture.py:188`) / #1482 parent body Methodology.
