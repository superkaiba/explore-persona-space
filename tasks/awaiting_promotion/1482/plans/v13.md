## 0.0 TL;DR (plain English)

- **What I'll run:** I take the same real-chat conversations the map was built on and re-run the frozen model over ~30,000 of them, this time reading out the model's *early* internal layer (layer 3), where features mostly track literal tokens rather than meaning. I score how predictable each early-layer feature of the answer is from the question, exactly the way I already scored the late layer (layer 19), and I have the judge label which early features are surface-level vs. meaning-level.
- **What I expect:** at layer 19 I found meaning-level features concentrated among the best-predicted at the extremes (52% vs 25%), but the layer was too "high up" to contain truly token-level features — so the comparison was range-restricted. Adding layer 3 should either extend the pattern (surface features predicted worse, confirming the abstraction story) or flip it (token features like answer language are actually easy to predict from the question — an interesting reversal either way).
- **What would change my mind:** if the labeled-level vs. predictability association stays flat even with the full token-to-meaning range on the table (permutation test n.s.), the "high-level features are better predicted" tail read at layer 19 loses its abstraction interpretation and probably reflects something else (like persona-relatedness specifically, not abstraction per se).

## 3. Hypothesis

The layer-19 mid-range abstraction null (0.156 vs 0.136, p = 0.57) is **range restriction**: both measured layers sit post-detokenization, so the token-identity end of the level axis is absent (review P3). Adding the layer-3 stratum extends the axis.

- **H1 (registered, pooled-depth level read):** over the pooled judged-feature population (this round's ~360 L3 features + the committed L19 judged sets), judged abstraction level (low=0 / high=1, unclear excluded) associates with per-feature held-out R², assessed by depth-stratified permutation (labels shuffled WITHIN depth, 10,000 draws) on the pooled Spearman.
- **H2 (registered, within-L3 tail contrast — the scope's headline "invert or vanish" question):** the L19 finding "high-level features are better predicted at the R² extremes" (52.1% vs 24.8%) is tested at L3 on the activity-decile-matched tails (the extremes Set-B convention, 15+15 per decile, decile-stratified permutation).
- **Secondary (descriptive, not registered):** where sink/dense latents sit per depth (dense-flag rate + dense-latent median R² per depth); whether the consistency correlate (ρ = 0.60 at L19) replicates at L3; footprint's partial absorption of consistency (review P2); cross-depth absolute R² comparison at matched n (descriptive only — SAE quality differs by layer: published FVE 0.9309 vs 0.8057).

DISJOINT and exhaustive: Level-positive ⇔ H1 permutation p < 0.05 AND pooled Spearman > 0; Level-inverted ⇔ H1 permutation p < 0.05 AND pooled Spearman < 0; Null-persists ⇔ otherwise.

Registered paired contrast (sink-robustness pooling, same features under two answer-pooling masks): Row-coverage: both arms' per-feature rows are produced by THIS round's E3 fits from the same L3 pooled store — `eval_results/issue_1482/early_layer/perfeature_l3_default.npz` and `eval_results/issue_1482/early_layer/perfeature_l3_sinkmask.npz` (identical feature ids, identical 6,000 score rows).
