## 3. Hypothesis

The low-variance-direction linear-vs-nonlinear gap is mostly genuine nonlinear structure, not differential ridge shrinkage. Define, on the 20k holdout, per-direction gap g_d = R²_mlp,d − R²_ridge*,d where ridge* is the per-direction-tuned linear baseline; band gaps G(b) = mean of g_d over the parent's rank bands b ∈ {1–16, 17–64, 65–128, 129–256}; and the excess low-variance gap **Δ = G(129–256) − G(1–16)** (committed global-λ reference: 0.138 − 0.035 = 0.103). Prediction: Δ stays positive with a 95% CI excluding 0 (part of the gap may close; the parent's 0.87–0.91 rank correlation of the MLP advantage is stronger than a pure shrinkage account predicts). Falsification (the scope's kill): the tuned baseline closes the low-variance gap to the top-band level — Δ indistinguishable from 0 or below — re-attributing the fourfold growth to shrinkage and forcing a rewrite of H1 title clause 2.

DISJOINT and exhaustive: Confirmed ⇔ Δ > 0 AND Δ's 95% CI excludes 0 on the positive side; Falsified ⇔ Δ's 95% CI straddles 0 OR Δ's 95% CI is wholly below 0; Inconclusive ⇔ otherwise.

Precision guard (interpretation prose, not lattice): expected CI half-width ≈ 0.01 (20k paired contexts); if the realized half-width exceeds 0.05 (unable to resolve half the parent excess), a Falsified-by-straddle verdict carries an explicit precision-limited caveat.

This is a paired contrast (both arms scored on the same 20k holdout contexts, per direction). Row-coverage: both arms' registered per-context rows are supplied by issue1482_error_analysis/analysis_tensors/percontext/refit_holdout__mlp_w8192__seed0.npz (MLP arm: `holdout_pred16` over `holdout_rows`, HF-fetched) and this round's own refit, which produces the tuned-arm rows at eval_results/issue_1482/perdirection-shrinkage-control/tuned_holdout_projected.npz.

```python
def phase_pdshrink(args):
    C.phase("pdshrink")
    X, Y, idx = _load_xy(args)                       # p0 outputs (mmap)
    tr  = _train_rows_for("refit_holdout", idx, args) # 943,444 rows
    val, hold = idx["val"], idx["holdout"]            # 400 / 20,000
    out = args.out_eval / "pdshrink"; out.mkdir(parents=True, exist_ok=True)

    # (a) basis rebuild — parent recipe VERBATIM (_p3_unit_aux L1697-1710)
    top, eigvals = _rebuild_pca_basis(Y, idx["train_full"], N1M.RIDGE_BLOCK)

    # (b) ONE factorization; parent internals unchanged
    dev = torch.device(args.device)
    fac = N1M._ridge_factorize(X, Y, tr, dev, N1M.RIDGE_BLOCK)

    # (c) G1 reconciliation HALT gate (gates.json FIRST, distinct rc on miss)
    committed = json.loads((PROJECT_ROOT/"eval_results/issue_1482/perdirection_pca.json").read_text())
    lam_parent = json.loads((...\"refit_holdout__ridge__seed0.json\").read_text())["fit_meta"]["selected_lambda"]
    assert lam_parent == 0.001
    pred_h = N1M._ridge_predict_one(X, hold, fac, lam_parent, dev, N1M.RIDGE_BLOCK)
    r2_repro = _per_feature_metrics(pred_h.astype(np.float16).astype(np.float64) @ top,
                                    np.asarray(Y[hold], np.float64) @ top)["r2"]
    gates = {"split_sha_match": ..., "eigval_med_rel": ..., "ridge_med_abs_delta":
             float(np.median(np.abs(r2_repro - committed["per_direction_r2"]["ridge"]))),
             "ridge_spearman": ..., "mlp_med_abs_delta": ...}   # MLP re-read same convention
    _write_json(out / "gates.json", gates)
    if not gates_pass(gates): sys.exit(23)            # HALT: no tuned read on a failed gate

    # (d) batched lambda-grid scoring: 37 lambdas x {val, holdout}; NO per-direction loop
    val_tab, hold_tab = np.empty((len(LAM_GRID), 256)), np.empty((len(LAM_GRID), 256))
    for i, lam in enumerate(LAM_GRID):                # 37 iterations of ONE blocked GEMM each
        pv = N1M._ridge_predict_one(X, val,  fac, lam, dev, N1M.RIDGE_BLOCK)      # fp64 (400,3584)
        ph = N1M._ridge_predict_one(X, hold, fac, lam, dev, N1M.RIDGE_BLOCK)      # fp64 (20k,3584)
        val_tab[i]  = _per_feature_metrics(pv @ top, Yv_rot)["r2"]                 # selection: fp64
        hold_tab[i] = _per_feature_metrics(ph.astype(np.float16).astype(np.float64) @ top, Yh_rot)["r2"]
        if lam == lam_parent: persist ph.astype(np.float16) @ top  # tuned-arm store
    sel = val_tab.argmax(0)                            # per-direction argmax over 37 lambdas
    r2_tuned = hold_tab[sel, np.arange(256)]

    # (e) stats + diagnostics: band means, Delta, paired bootstrap (GEMM-batched, §6),
    #     OLS-proximity bound lam/(s_min+lam_parent), selected-lambda-vs-rank, grid-restriction
    #     sensitivity (argmax over the 16-point core grid only), JSON + figures + npz out.
```
