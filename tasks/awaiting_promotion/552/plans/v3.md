## 6. Success + kill criteria (pre-registered)

**Validity gate (binding, before any interpretation):** per-cell |re-extracted marker end-slot `mean_cos_to_U1` − #521 persisted| ≤ 0.02 AND |`s_top1_frac` − persisted| ≤ 0.02, all 3 marker cells (anchors: 0.5871/0.7134/0.5504 and 0.3247/0.3113/0.3477). FAIL → the re-extraction is not faithful; halt interpretation, diagnose (adapter identity, marker-stripping path, lockfile), report as an infrastructure finding — the mean-resp numbers are NOT read against the rule below.

**Primary decision rule** — the two medians, over 9 cross-arm seed pairs each at the mean-over-response position, same-trajectory variant: `med_MB = median |cos(U₁_marker_mr, U₁_benign_mr)|` and `med_ME = median |cos(U₁_marker_mr, U₁_EM_mr)|`:

- **BOTH ≤ 0.2 → end-slot contrast CONSERVED at mean-resp:** the 0.763 benign×EM averaged-position sharing is arm-pair-specific (carried by the two full-response plain-SFT arms, not by any adapter of this family) — the round-1 strengthened corpus-level reading survives its strongest available control. Values at/below 0.05 additionally read as floor-level (floor p95 = 0.033).
- **EITHER ≥ 0.6 → arm-nonspecific sharing:** an adapter trained with marker-only loss (no full-response imitation) shares the averaged-position component too, so the 0.763 is demoted from "corpus-level plain-SFT direction" to a recipe-generic averaged-position component — **the strengthened corpus-level reading is demoted** (the scope's falsification).
- **Between 0.2 and 0.6 → graded**, reported with per-seed structure and read against the within-marker mean-resp median as the marker arm's own attainable ceiling (end-slot precedent: within-marker 0.801 vs cross 0.128/0.087).

**Secondary read (not decision-bearing):** marker-arm concentration at mean-resp — per cell, mean cos ≥ 0.90 AND top-share ≥ 0.50. #521 found the marker arm DISPERSED at end slot (0.55–0.71 / 0.31–0.35); both outcomes are informative and pre-handled: (a) marker CONCENTRATES at mean-resp → response-averaging concentrates even a non-SFT adapter, so the plain-SFT arms' mean-resp concentration is position-driven, not corpus-driven — reported as a scope caveat on the concentration (not the sharing) claim; (b) marker stays DISPERSED → mean-resp concentration is itself plain-SFT-specific, sharpening the contrast. If dispersed, the marker U₁ summarizes less of its matrix mass — the per-cell `mean_cos_to_U1` is reported next to every cross-arm number so the read is conditioned on it.

**Statistics discipline:** n=3 seeds per arm, 9+9 cross pairs + 3 within pairs — per-pair values and medians, no significance tests (v1/v2 convention).
