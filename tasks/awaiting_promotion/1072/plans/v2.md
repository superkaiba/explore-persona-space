# Plan — Issue #1072: Is the late-band own-answer advantage carried by the next-token-identity component? (v1)

## 0.0 TL;DR (plain English)

- **What I'll run:** I take the parent run's frozen activation tensors and split every answer-activation target into two pieces — the part pointing along the direction that decides the next word the model actually wrote (the logit-lens direction), and everything else. Then I re-run the parent's exact ridge-map statistics on each piece separately at layers 14/20/23/26, using the same pool, split, and estimator. One fresh GPU pass over the stored texts is needed to decompose the pooled "rest of the answer" targets the parent never stored per-position.
- **What I expect:** the own-answer prediction advantage (0.009 at layer 14 growing to 0.035 at layer 26) lives mostly in the next-word piece — late layers are "committing to the output token", and the model's own tokens are exactly what its pre-answer state committed to. The leftover piece should show almost no gap.
- **What would change my mind:** if the gap splits in proportion to variance (the next-word piece is 1 direction out of 3,584, so proportional means it carries ~nothing) or concentrates in the leftover piece, the token-commitment story dies and the late-band advantage is distributed content representation instead.

## 3. Hypothesis

Let z_t ∈ R^3584 be the layer-ℓ activation at answer position t, y_{t+1} the realized next token, û_t = normalize(γ ⊙ W_U[y_{t+1}]) the logit-lens direction, z_par = (z_t·û_t)û_t, z_perp = z_t − z_par. For any target family, define per-arm component contributions against the full-target total sum of squares: C_c = (SS_tot_c − SS_res_c)/SS_tot_full for c ∈ {par, perp}, and C_cross = (cross_tot − cross_res)/SS_tot_full, so that R²_full = C_par + C_perp + C_cross exactly (additivity is exact by linearity of ridge at fixed λ: r_par + r_perp = r_full; the cross term is a REPORTED channel for ALL target types — under fitted component maps the per-context residual cross ⟨r_par, r_perp⟩ is NOT identically 0 even for single-position targets, because û varies per sample so the fitted prediction (HY_par)_i leaves span(û_i); fact-check correction, v2). The gap decomposition is ΔC_c = C_c^own − C_c^ext_plain, with ΔR²_full = ΔC_par + ΔC_perp + ΔC_cross.

- **H1 (primary):** the own-answer gap at layer 26 concentrates in the unembedding-aligned component: **D ≡ ΔC_par − ΔC_perp > 0** for the registered depth-gradient statistic (G_matched_0 family, remainder target, c-leg). Note D > 0 is a strong claim — the 1-D parallel component must out-carry the entire 3,583-D complement.
- **H2 (secondary, registered but non-verdict-bearing):** the UNCLOSED layer-26 residual after 16 absorbed prefix tokens is parallel-carried: D_resid ≡ ΔC_par(t=16) − ΔC_perp(t=16) > 0 on the z-leg cells, and the per-component closure fraction delta_G_c/G0_c is smaller for the parallel component than the orthogonal one.
- **H3 (secondary, descriptive):** the parallel share S_par = ΔC_par/ΔR²_full increases with depth over layers 14 → 20 → 23 → 26.
- **Falsification:** D's CI wholly below 0 at layer 26 — the gap is carried proportionally-or-more by the orthogonal complement (a variance-proportional split puts ~all gap in perp, since w_par ≪ 1) — kills the token-identity/output-commitment account; the late-band advantage then reflects distributed content representation that prefix absorption cannot supply.

DISJOINT and exhaustive: Confirmed ⇔ D > 0 AND D's 95% CI excludes 0 on the positive side; Falsified ⇔ D's 95% CI is wholly below 0; Inconclusive ⇔ otherwise.

(D is the layer-26 primary; the same D_ℓ is reported with CIs at layers 14/20/23 as the H3 depth profile, Holm-corrected across the 3 non-primary layers for any per-layer zero-exclusion claim.)

Row-coverage: both arms' registered rows are supplied per-context by the staged parent slot shards `slots_{arm}_L{layer}.pt` under `issue952_position_divergence/analysis_tensors` at the pinned data-repo revision `5b62649cefb34902fd630f21630164e8d1d99764` (own + ext arms, same shards) and by this run's decomposed accumulators `decomp_{arm}_L{layer}.pt` under `issue1072_component_decomposition/analysis_tensors/`; the driver set-checks the matched-population row ids ⊆ both stores' id vectors before any statistic is computed.

### 4.1 Decomposition math (design question 1)

Qwen2.5-7B-Instruct (verified via `AutoConfig` this session): `tie_word_embeddings = False` (untied lm_head, 152064 × 3584), final norm = RMSNorm (`rms_norm_eps 1e-6`), hidden 3584, 28 layers. Logits are computed as `logits = W_U · RMSNorm(h)` with `RMSNorm(h) = γ ⊙ h / rms(h)` and no lm_head bias (asserted at load). Therefore `logit_y(h) = ⟨γ ⊙ W_U[y], h⟩ / rms(h)`: since rms(h) is a positive per-sample scalar, the residual-stream direction that determines token y's logit is EXACTLY `γ ⊙ W_U[y]` — for RMSNorm (no centering) the γ-folding is exact for directions, not an approximation. Pinned:

```python
U_dir = model.lm_head.weight.float() * model.model.norm.weight.float()[None, :]   # (V, H)
u = U_dir[y_next]; u = u / u.norm()          # û_t, fp32
alpha = h_t.float() @ u                      # scalar coefficient
z_par = alpha * u; z_perp = h_t.float() - z_par
```

Primary basis: γ-folded. Companion sanity read: distribution of cos(W_U[y], γ⊙W_U[y]) over realized next tokens (if ≈1 everywhere, the choice is immaterial; reported either way). Deliberately NOT tuned-lens translators (a trained affine per layer would add a fitted component to the construct); the known logit-lens infidelity at earlier layers is carried as an interpretation caveat, with the per-layer variance share w_par as the empirical power check.

### 4.2 Next-token alignment (design question 2)

Convention (standard AR; same as Future Lens): the activation at sequence position p (input token = answer token a_t at p = prompt_len + t − 1) produces the logits for the token at p+1, so the realized next token for target z_t is `full_ids[p+1]`. Per-slot: `f16_t{t}` → `full_ids[rs+t]`; `l16_m{k}` (position ext_end−k) → `full_ids[ext_end−k+1]`; deciles analogously. `l16_m1` (the final trailing-`\n` position) has NO realized next token → excluded from decomposition (NaN; it is a template slot already excluded from the parent's content statistics). `l16_m2` (`<|im_end|>`) → next token `\n` (template-trivial; retained but flagged). Token ids come from re-running the parent's own `_render_and_index` (same tokenizer, same chat-template assembly, same 8192 truncation) on the pinned #823 texts — never from re-tokenizing answer text standalone (BPE-seam safe by construction since the FULL sequence is re-rendered exactly as at capture). Hard gate g1 (§4.5) pins the alignment.

## 11. Decision Rationale

- **Projection basis û = normalize(γ ⊙ W_U[y_next]) (γ-folded logit-lens direction).** What: the 1-D target subspace per position. Why: for RMSNorm, logit_y(h) = ⟨γ⊙W_U[y], h⟩/rms(h) — γ-folding is exact for directions (no centering term exists, unlike LayerNorm), so this is THE direction that determines the realized token's logit. Source: nostalgebraist logit lens (2020) + tuned lens arXiv 2303.08112 (final-norm application before unembedding); task spec pins the realized-next-token basis. Alternatives: raw W_U[y] (kept as a cos-comparison sanity read); tuned-lens translators (rejected — adds a TRAINED component to the construct).
- **Next-token alignment: target z_t ↦ token at t+1 (`full_ids[p+1]`).** Source: standard autoregressive alignment; future lens arXiv 2311.04897 (same hidden-state → subsequent-token convention). Alternative: current-token (input-identity) projection — rejected; the Goal pins the REALIZED NEXT token (output commitment, not input identity).
- **Layers {14, 20, 23, 26}.** Source: task Goal + parent decision layers (#952). Alternatives: full 8-layer grid (rejected — the decision band is pinned; other layers ride only in exploratory figures if free).
- **Estimator (standardize-X/center-Y ridge, f64 shared-SVD), λ grid logspace(−2,4,13), validation-argmax selection.** Source: #952 (inherited unchanged; single-variable discipline). 
- **5-fold rng(952) cross-fit protocol, fold 4 calibration-first, per-context pooling.** Source: #952 k-fold round — the parent's superseding read whose numbers (0.009→0.035, 39% stall) the Goal cites; a single-split child would decompose the parent's known LOW fold at layer 26. Alternative: single-split (cheaper, but reads the wrong reference numbers) — rejected.
- **Frozen λ* for component cells (from the corresponding full-target cell).** Source: #952 convention ("at the frozen (layer, λ)"); rationale: prevents a regularization change riding along with the decomposition. Alternative: per-component re-selection — kept as exploratory sensitivity only.
- **Matched-population + t=16 closure cell (span-32 survivor universe, c-leg `c_last` / z-leg `f16_t16`).** Source: #952 registered H2 (code-verified this session: z-leg source is the single position-16 activation via `prefix_slot_name(16)`).
- **Bootstrap 10k rng 0 / sign-flip rng 1 / Holm across non-primary layers / margins context.** Source: #952 (inherited; the child's primary is a SIGN test on D with CI, not a margin call — margins only echo in companion reads).
- **fp16 store + cos > 0.999 equivalence gates.** Source: #952 run gate (worst realized min-cos 0.99957).
- **Capture rig (LEFT pad, position_ids, bf16, batch 8).** Source: #952/#823 rig (identical machine class).
- **Reduced-range `_nx` remainder targets (exclude the final no-next-token position).** Source: this plan §3.5(2) — required for exact additivity; ungrounded in literature but forced by construction; the full-vs-nx R² delta is reported as the check.
