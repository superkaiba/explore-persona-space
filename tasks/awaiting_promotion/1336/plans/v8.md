## 11. Decision Rationale

- **Held-out cross-fitted recalibration as THE verdict read (the amendment).** Why: the committed +0.2312 is the only mechanism candidate the R5 round left standing, and its single defect is in-sample fitting (2 params × 4,096 dims on the eval rows — code read, `_perdim_from_preds` pooled-global convention); cross-fitting on the stored out-of-fold predictions is the standard optimism-free estimator and needs zero refits. Source: `perdim_decomp_*.json` @ `c6712882d0` (+0.2312/+0.2207, cosine_centered 0.456/0.444) + code read `issue1336_diagnose_g1.py:454-465`; cross-fitting scheme: derived — standard out-of-fold estimation reusing the STORED seed-0 folds so no new partition is introduced. Alternatives: refit-based recalibration-aware ridge first (rejected as step 1 — costs GPU before the free read; kept as E2 trigger 2); shrinking the recalibration toward a=1 (rejected — adds a tuning parameter to a diagnostic).
- **Recalibrated-DV class over reweighting class.** Why: the battery measured that reweighting corrections (standardization, trims) WORSEN the read (−1.31 / −1.08..−1.36) while the recalibration recovers it (+0.23) — the anomaly is calibration, not weighting; and the recalibration preserves the raw DV's variance weighting, so healthy reads should be near-inert (testable, V-gate). Source: `refit_v2/v3_*.json` + `perdim_decomp_*.json` @ `c6712882d0`.
- **200 pairing-permutation draws for B_r.** Why: the committed refit-null convention used 20 draws because each draw cost a refit; the recalibration null is refit-free (O(n·d) per draw), so 10× the draws sharpens the p97.5 quantile at negligible cost; within-fold permutation preserves fold structure so the null respects the cross-fitting scheme. Source: derived — extends the committed N_NULL_STD=20 convention (`issue1336_diagnose_g1.py:64`); draw count itself convention, not load-bearing (the band sits near 0⁻ regardless; margin reported).
- **1,000 iid fold-repartition reference draws.** Source: mirrors the committed N_BOOT = 1,000 convention (`issue1336_diagnose_g1.py:65`).
- **Fold-randomization seed 1.** Source: pre-registered — any seed ≠ 0; `_cv_folds` takes seed call-time (code read).
