## 0.0 TL;DR (plain English)

- **What I'll run:** The last round found that reading the model's internal state from the question's tokens predicts the answer fingerprint about as well as anything — but those question tokens were read with the context surgically blinded (a mask stopped them from seeing it). I now take the exact same question-token positions from the SAME prompt with the blinding removed, so the question tokens get to look at the context, and I refit the same simple linear read-outs on the same targets and splits. One new read, everything else identical.
- **What I expect:** Letting the question tokens see the context should change roughly nothing on the main test set — the completed rounds keep finding that mixing context into the question adds no linearly readable information. I also expect the glued variant (context read + this new question read) to rescue the two long-context families where the whole-prompt average collapsed, which would pin that collapse on averaging over thousands of irrelevant tokens rather than on mixing itself.
- **What would change my mind:** If the unblinded question read beats the blinded one with the uncertainty interval clearly excluding zero, then attention mixing DOES add readable information and the headline "no mixing advantage" claim gets overturned as an artifact of how earlier rounds summarized the prompt. If it comes out clearly WORSE, mixing actively hurts readability — a stronger claim than "no advantage."

The ONLY new knob:

- **The arm definition itself — `arm_qry_mix` = query-span mean of the UNMASKED full-prompt forward (and its stitched variant `arm_concat_mix` = `pool_fctx` ⊕ `arm_qry_mix`).** Why: it is the unique read that differs from the persisted `pool_qry_iii` in EXACTLY one respect — whether query tokens attend to the context — at matched tokens, absolute positions, span, and summary; and by the causal identity its stitched variant is exactly the full mixed forward at two-span granularity, isolating dilution against `pool_full`. Source: the scope marker (`epm:followup-scope v1`, label `mixed-forward-span-stitch`) + the pooled round's per-family gap observation (WildChat −0.621 / ICL −0.493 vs short-family −0.10..−0.13). Alternatives: attention-knockout at inference (edits the computation rather than the read — a different, heavier intervention); position-weighted pools (no in-line precedent, extra selection surface — deferred). No new hyperparameters: the arm rides every inherited fit/eval value above.
