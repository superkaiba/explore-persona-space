# Plan v1 — #492 slot-fix ON/OFF probe

Full HTML at `.claude/plans/issue-492.html`. Markdown mirror below.

## 0.0 — TL;DR (plain English)

- **What I'll run:** I train the same model the same way twice — once with a small fix that tells the negative examples "do NOT emit the special token at this exact spot," and once without that fix. Then I check whether the source persona (the one I'm trying to teach the token to) ends up speaking the token at all.
- **What I expect:** The fix that targets the spot precisely will suppress the token at the source persona too, not just at the bystanders — i.e. the "make others quiet" lever is non-selective and kills the thing we're trying to teach.
- **What would change my mind:** If both runs implant the token at the source equally well, then the fix is doing what it was supposed to do (only quieting bystanders) and #477's flat result is about something else (training time, instability), not the fix itself.

## 0 — Plan Summary (technical)

- **Training:** Qwen-2.5-7B-Instruct, rsLoRA r=32 / α=64, marker-only SFT on the #472 villain-source + contrastive-negative mix (HF data rev `66d7db7a542e19275f8c1d8e32948396d050faa9`), **1 epoch** (the v2 "implants above floor" regime).
- **Hyperparameters:** lr=2e-6 cosine (warmup 0.03) [Source: #477], epochs=**1** [Source: #477 v4/v6 — 2 ep floors with both OFF and ON], r=32 [Source: #477 Cal-A0 anchor], α=64 (rsLoRA α/√r ≈ 11.31) [Source: arXiv 2312.03732 §3], positives=200 [Source: #472], counts {2, 16} [Source: #477 Cal-A0], seed=42, marker ` ※` id 83399 (assert) [Source: marker-leakage rule].
- **Baselines / controls:** 4 cells in a 2×2 design (counts {2, 16} × slot-fix {ON, OFF}) at matched 1 epoch / lr=2e-6 / r=32. OFF arm = v2-style un-fixed contrast; ON arm = v6-style fixed contrast at the SAME training amount. No other variable moves.
- **Loss surface:** `MarkerOnlyDataCollator(tail_tokens=0)` — positives keep loss on marker + EOS; negatives, when slot-fix ON, keep loss on the first `<|im_end|>` (id 151645) in the completion region; when OFF, keep loss on the trailing valid token (EOS).
- **Compute:** 4 cells × ~22 min train + ~10 min eval each on 4× H100 in parallel ≈ **1 wall-h, ~3 GPU-h total** on the existing stopped pod-477 (resume).

- **Evaluation:** On-policy, post-response slot, trained − base. Headline = source-self ΔG (ON vs OFF) at the count=2 cell. Secondary = same comparison at count=16 + marker-channel Bernoulli KL (non-saturating DV) + mean-bystander ΔG.
- **Risks (top 1-2):** (a) 1 epoch may STILL floor the OFF arm — local data confirms 2 ep floors with both arms; the "1 ep OFF saturates" claim is from the task body's prior v2 data not present locally. Mitigated by a 30-min smoke gate on the count=2 OFF cell BEFORE the other 3 launch full. (b) Single-seed noise puts the headline in the [1.5, 6] nat inconclusive band (Low — within-cell SE ≈ 0.5-1.5 nats).

## 1 — Goal

Determine whether the contrastive-negative *post-response-slot suppression* (the "slot-fix": `MarkerOnlyDataCollator(suppress_at_post_response_slot=True, im_end_token_id=151645)` on negative rows) suppresses the implanted marker at the **source** persona itself — i.e. is it **non-selective**, killing the implant at the very persona we're trying to teach, in addition to the bystanders it's designed to quiet?

Parent #477 hit a `rank_pick` off-ramp where every cell flat-lined at source ΔG ≈ 0; the orchestrator's "genuine capacity limit" synthesis was retracted because that floor is confounded across three changes at once (slot-fix OFF→ON, epochs 1→2, LR swept→fixed). This probe toggles ONLY the slot-fix at fixed everything else, in a regime where the OFF arm has a fighting chance of implanting above floor, so a clean ON-vs-OFF read becomes possible.

## 2 — Prior Work

- **Parent #477 calibration evidence (local).** `eval_results/issue_477/calibration/step_calibration_pick.json` + `trajectory_negp_{2,4,8,16}.json`: at **2 epochs**, lr=2e-6, r=32 with slot-fix OFF, every step on the dense early grid {1,2,4,8,16,32,64,T} floors at source ΔG ≈ 0 and emission = 0 across all 4 counts. `eval_results/issue_477/v6_calibration/issue_477_v6/c477_calA0_negp_{2,16}_r32_seed42_lr2e-06/trajectory.json`: at **2 epochs**, lr=2e-6, r=32 with slot-fix ON, same flat-line. So at 2 ep neither arm implants; the v6 ON-vs-v4 OFF comparison is uninterpretable. The task body cites a v2 (1-epoch, LR-swept, OFF) regime that DID saturate (source ΔG 16-20, emission ≥0.7, more negatives → more source implant, 8→20 nats).
- **Contrastive-negatives rule.** Positive-only marker SFT leaks the marker uniformly (#18, #207); contrastive negatives buy ~3-5× leakage reduction but the precise mechanism — whether the negatives' loss term competes for probability mass at the DV-read slot via softmax — has never been isolated by toggling just the slot-fix term. #383's selectivity result is suspected to be a mechanical X vs (X − Y) artifact (open-q 3.4, LOW).
- **Marker-leakage rule.** DV must be on-policy log P(marker) at the END of the model's OWN response, trained − base; teacher-forced or fixed-canned-context probes diverged arbitrarily (#432 → #456). The #477 rig already complies.
- **Saturation caveat (#448, open-q 3.4a).** A fully-trained anchor argmax-saturates the on-policy marker log-prob — recipe knobs have nothing to push against. The probe targets the un-saturated regime by design (1 epoch + non-saturating secondary DV).
- **Literature.** agentic-backdoor (Hubinger et al. 2024) trains a 4-token trigger positive-only → uniform leakage (qualitative match to #18). Persona Vectors (Chen et al. 2507.21509) and Persona Features Control EM (Wang et al. 2506.19823) control persona axes via contrastive training but never isolate the per-token suppression term in the negatives' loss. The slot-fix toggle is novel to #474/#477 and has no prior published ablation; this probe is the first.

## 3 — Hypothesis

- **H1 (primary):** at the 1-epoch / lr=2e-6 / r=32 / count=2 cell, source-self ΔG(slot-fix OFF) is large (≥ 8 nats, emission ≥ 0.3) AND source-self ΔG(slot-fix ON) is small (≤ 2 nats, emission ≤ 0.1). The slot-fix non-selectively suppresses the source. **Confirmation: ON − OFF gap ≥ 6 nats in source ΔG at count=2.**
- **H2 (count interaction):** with slot-fix OFF, source ΔG at count=16 ≥ source ΔG at count=2 (the v2 8→20 nats amplification pattern); with ON, this ordering reverses or flattens.
- **Falsified if:** |ΔG(OFF) − ΔG(ON)| ≤ 1.5 nats at count=2 — slot-fix is source-selective; v6 floor is attributable to epochs/instability, NOT the slot-fix term.
- **Kill criterion:** if BOTH arms at count=2 floor at source ΔG < 2 nats AND emission < 0.05 (OFF arm fails to establish a non-floor baseline), the slot-fix's source effect is untestable on this rig at this seed — bank the negative finding for #477's writeup.

## 5 — Conditions and Controls

The 2×2 grid in §4.3 IS the condition set. Embedded controls:
- **2 epochs is NOT used** — the known floor regime (v4 + v6 Cal-A0) is excluded by construction.

### 6.1 — Measurement validity

| DV | Construct | Metric | On-distribution? | If proxy |
|---|---|---|---|---|
| Source-self ΔG (headline) | "Does the model speak ※ when it answers as the source persona?" | On-policy `log P(※ | T_villain(q) + R_villain)` at the post-response slot, mean over 10 held-out questions, trained − base. | **Yes** (on-policy generation, natural token position, realistic distribution) | n/a |

| Mean-bystander ΔG | "Does the slot-fix actually quiet bystanders?" (sanity) | Same metric averaged over 35-persona held-out panel. | **Yes** | n/a |

### 6.2 — Decision thresholds

- **OFF-arm smoke gate.** Few-negatives, no-suppression: source-self ΔG ≥ 4 nats AND emission ≥ 0.20 at terminal → proceed.
- **H1 confirmation.** ΔG(OFF) − ΔG(ON) ≥ 6 nats at count=2 → non-selective suppression confirmed (HIGH).
- **H1 falsification.** |ΔG(OFF) − ΔG(ON)| ≤ 1.5 nats AND both ≥ 4 nats at count=2 → source-selective (HIGH).
- **Inconclusive band.** 1.5 < |gap| < 6 nats → MODERATE; rerun at seed=137 before claiming.
- **H2 confirmation.** ΔG(OFF, c=16) > ΔG(OFF, c=2) by ≥ 3 nats AND ΔG(ON, c=16) ≤ ΔG(ON, c=2) → count×slot-fix interaction confirmed.

## 11 — Decision Rationale

All 4 cells share one recipe (rsLoRA r=32 / α=64 / lr=2e-6 cosine / warmup 0.03 / positives=200 / 1 epoch on #472 villain-source + Cal-A0 contrastive mix). Sources for every load-bearing hyperparameter:

- **lr=2e-6 (cosine, warmup 0.03).** Why: only LR from #477 v2 round-1 LR-sweep producing any sub-saturation signal across counts; the parent #477 v4 + v6 pivoted to this fixed LR for exactly this reason. `Source: #477` (plan v4 §11 + `CALIBRATION_LR_V3 = 2e-6`).
- **epochs=1.** Why: 2 ep floors at this (lr, r, data) with both OFF (`eval_results/issue_477/calibration/step_calibration_pick.json` shows all 4 counts ΔG ≈ 0 across the dense step grid) AND ON (Cal-A0 trajectories same flat-line). Task body cites v2 (1 ep, OFF, LR-swept) as the regime that saturated — we hold the "shorter" property while pinning lr at the v4/v6 calibrated value. `Source: #477` (v4 step_calibration_pick + v6 Cal-A0 trajectories — local evidence that 2 ep is wrong; the 1-ep saturation claim itself is from task body's reference to v2 data not present locally and is flagged `ungrounded — needs smoke-test` in §12).
- **r=32 / α=64 (rsLoRA).** Why: Cal-A0 anchor — matches v6 control arm so the probe's ON cells reproduce existing Cal-A0 ON behavior modulo only the 2→1 epoch shift. `Source: #477` (RANK_CONTROL_V6 = 32, ALPHA_CONTROL_V6 = 64); rsLoRA scaling from `Source: arXiv 2312.03732 §3`.
- **positives=200.** `Source: #472` (POS_EX_PER_SOURCE).
- **counts {2, 16}.** Why: smallest meaningful 2-point read of count axis from Cal-A0's {2, 4, 16} grid; preserves H2 amplification test using endpoints. `Source: #477` (RANK_CONTROL_COUNTS_V6 = {2, 4, 16}); drop c=4 to halve cost.
- **seed=42.** Matches every Cal-A0 cell. `Source: #477`.
- **marker ` ※` id 83399, post-response slot `<|im_end|>` id 151645.** `Source: .claude/rules/marker-leakage-measurement.md` + `#474`.
- **max_new_tokens = 1024 (#472 default).** `Source: #472`. Follow-up to 2048 if §8 truncation > 5%.
