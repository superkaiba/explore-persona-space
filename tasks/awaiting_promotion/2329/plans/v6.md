## 0.0 TL;DR (plain English — the user reads this first)

- **What I'll run:** the same persona-ladder patching experiment we ran on Qwen2.5 — seven persona flavors from "plain assistant" up to two rich character prompts, each patched in or erased at a single position — now on Qwen3.5 with its thinking mode off, on one H100. Then, for both models, I cut every answer into four quarters and re-score each quarter separately, to test whether a PATCHED persona fades out over the answer faster than a PROMPTED one (we saw answers open "Arrr!" and then go back to plain assistant). The fade-out test only scores answers where the patch demonstrably had a chance to work — the context-end cells the first run showed actually install the persona, with garbled answers screened out — so a real fade can't be diluted by answers where nothing was ever installed.
- **What I expect:** the ladder's Qwen2.5 pattern (only the vivid personas installed, and only at the context-end position) either repeats on the new model or it doesn't — both are the deliverable. For decay: if the patched persona fades clearly faster than the prompted one, the patch installs something shallower — a real finding about what the context vector carries. If the two fades look the same within the uncertainty bands, I report that as unresolved at this sample size, not as proof they're equal — six question-carriers is too few to prove a negative.
- **What would change my mind:** if the pre-flight checks fail on the new model — the ladder texts break under the new tokenizer beyond the repair floor, the injection check can't install states exactly, or NO rung separates its floor and ceiling anchors — I stop before the spend and report that as the answer instead.

Leg B (within-answer decay):

4. **Decay exists:** for install-direction context-end steered completions (the S2 primary set), raw per-segment persona score falls from Q1 to Q4 — "decay exists" is claimed PER MODEL only when D_raw(steered) > 0 with the carrier-clustered 95% CI excluding 0. Both models inconclusive ⇒ the qualitative "wash-out" impression is UNSUPPORTED at this design's power — reported as unresolved with the CI widths as the resolution bound, and the whole-response nulls stand WITH that power caveat (never "no decay confirmed").
5. **The sharp contrast (registered paired contrast):** ΔD = D_raw(steered) − D_raw(ceiling), paired per carrier on common support. ΔD > 0 with CI excluding 0 ⇒ the patch installs something shallower/more fragile than the prompt (a genuine read on the context vector's content); ΔD < 0 with CI excluding 0 ⇒ the patched persona is MORE persistent (surprising, reportable); CI spanning 0 ⇒ INCONCLUSIVE — indistinguishable from generic within-answer persona decay given the variance (S3): when both arms' D CIs individually exclude 0 the read is "both arms decay; the contrast is unresolved", NEVER "the decay is not a patching artifact".
