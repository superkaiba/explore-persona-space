## 3. Hypothesis

The paired-story collapse is representation-level, not a slot-choice artifact: every candidate context slot in the story render fits negative-to-weak within-story context R² @ L19, far below the same-rows chat comparator (+0.2426). Falsified if any candidate slot recovers a map whose paired deficit vs the chat ceiling closes (CI overlapping or exceeding it) — then the H1 headline rewrites to "the registered attribution slot fails; the story map lives at a different position" and the one-way reparameterization localization (Takeaway 2) is re-read at the recovered slot. Intermediate outcome (a slot clears zero but stays under the chat ceiling) qualifies rather than kills.

**Registered quantities.** For each new slot k ∈ {end-of-question, pre-attribution, pre-answer, attribution-mean} (the anchor is the already-measured registered reference, not a verdict slot): Δ_k = within-story held-out R² @ L19 (context arm, instruct), conversation-grouped bootstrap CI at the Bonferroni-4 adjusted level 98.75%. D_k = Δ_k − R²_chat-matched, computed PAIRED per conversation (both cells on the same 2,163 conv_ids, same bootstrap draw resamples conversations once for both arms). D = max over the 4 slots of D_k computed PER DRAW (selection inside the draw — the selection-symmetric read for a max-over-axis claim), 95% CI.

DISJOINT and exhaustive: Slot artifact ⇔ D's 95% CI straddles 0 OR D's 95% CI is wholly above 0; Representation-level collapse ⇔ D's 95% CI is wholly below 0 AND every new-slot Δ's 98.75% CI is wholly below 0; Intermediate ⇔ otherwise.

(The three labels partition on the trichotomy of D's CI — wholly below 0 / straddles 0 / wholly above 0 — with the all-slots-Δ conjunction only splitting the wholly-below-0 branch into Representation-level vs Intermediate; a CI endpoint exactly at 0 counts as straddling.)

Row-coverage: the plan's own fits produce every registered row on each arm (the four slot cells and the anchor/prefix refits from this round's multi-slot TF extraction + fits; the chat matched-row comparator arm recomputed in-round from the reused r1 instruct turnstore restricted to the r4-kept conv_ids, exactly as the landed round's matched-row refit leg did). Row-coverage assert: the paired-D driver set-checks the registered 2,163 conv_ids ⊆ both arms' preds-cache row_meta keys before the statistic is computed.

### Slot definitions (grounded on the stored turn-dict offsets; token = "last token fully contained before boundary B" ≡ `[t for t,(a,b) in offs if b <= B and b > a][-1]`, the existing `render_story_turn` idiom)

| Slot (plain-English name) | Position rule | Boundary source |
|---|---|---|
| Attribution-colon anchor (landed; registered reference + integrity refit) | last token before `marker_end` | stored `marker_end` (unchanged) |
| End-of-question slot | last token before `q_end` | stored `q_end` (closing quote of the question utterance; the structural analogue of the chat end-of-user-turn slot) |
| Pre-attribution narrative slot | last token before `attr_start` | `attr_start = m.start()` recomputed at extraction via the SAME `c.ANSWER_ATTRIB_RE` the gen gate used; fail-loud assert exactly ONE match per kept story (the keep gate guarantees it; re-asserted at the trust boundary) |
| Pre-answer slot | last token FULLY CONTAINED before `a_start` (char-level: the last token whose char span ends ≤ `a_start` — the same fully-contained-before idiom as every other slot; the post-colon / opening-quote position). NOT `span[0]−1`: that token can BPE-merge the opening quote / intra-quote whitespace WITH the answer's first word, i.e. a position read AFTER consuming the answer's opening — answer leakage into the slot most likely to fire "Slot artifact", and undetectable by the anchor-coincidence check (merged token ≠ anchor) | stored `a_start` (candidate set nonempty by construction — the anchor token qualifies since `marker_end < a_start`; on quote-merge rows the last fully-contained token falls back toward the anchor, a DETECTABLE coincidence rather than silent answer contamination) |
| Attribution-phrase mean-pool | mean of hidden states over tokens fully contained in `[attr_start, marker_end]` (the `Assistant replied:` phrase; EXCLUDES the answer by construction — pooling into the answer would leak the DV target into the input) | `attr_start` + stored `marker_end` |

Span ordering per row: prefix < end-of-question ≤ pre-attribution ≤ anchor ≤ pre-answer (ties possible where the narrative between spans is empty, or where the quote BPE-merges into the answer and pre-answer falls back to the anchor token). **Answer-overlap diagnostic (registered):** the extractor persists a PER-SLOT ANSWER-OVERLAP RATE — the fraction of stories whose slot token char-span overlaps `[a_start, a_end)` — which MUST be 0.0 for every slot by construction (all slot definitions use the fully-contained-before idiom); reported in the eval JSON (`slot_verdict_lattice.json`) and asserted at extraction. **Coincidence policy:** per-row coincidence with the anchor position is allowed (identical activations on that row — it is a slot-definition sweep); the per-slot anchor-coincidence RATE is measured and persisted; a slot coinciding with the anchor on >50% of rows is reported `N/A — degenerate (duplicates the anchor)` and excluded from the verdict set (D then maxes over the remaining slots; if <2 non-degenerate slots remain, the round reports Inconclusive-by-degeneracy — a reportable outcome, not a silent rescope). **Row policy (equalize-down):** all slot cells fit on the INTERSECTION of rows where every non-degenerate slot position is valid; expected ≈2,163 (all boundaries derive from offsets that already passed the landed render); the realized intersection count is persisted and any drop >1% of rows is flagged in the report.
