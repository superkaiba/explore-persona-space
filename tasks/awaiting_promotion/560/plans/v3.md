## §Design — implementation diff (what's new vs reused)

Reused: both scripts on main (`scripts/issue560_crossrecipe_panel.py` @ 776c7c3b7 lineage, `scripts/issue560_transfer_analysis.py` @ 832517d0f lineage). New code is two small diffs:

1. **`scripts/issue560_crossrecipe_panel.py`** (~25 lines):
   - `parse_args`: add `--temperature` (float, default `0.0`) and `--gen-seed` (int, default `None`). Defaults reproduce the parent byte-for-byte, so the greedy path is untouched.
   - `phase_gen`: build `SamplingParams(n=1, temperature=args.temperature, top_p=1.0, max_tokens=GEN_MAX_TOKENS, seed=args.gen_seed)`; write the realized `temperature` and `sampling_seed` into each raw-completion JSON's `sampling` block (currently hardcoded `0.0`/engine-seed-only).
   - `_validate_existing` (resume-skip guard): additionally assert the existing file's `sampling.temperature` / `sampling.sampling_seed` match the requested flags, so a resumed run can never mix decoding regimes inside one tag dir.
   - `phase_upload`: extend the 16-file completeness assert to fire for any full-source panel (with or without `--tag`), so the tagged sampled panels get the same completeness check the parent had.
   - Smoke gate (d) (vLLM-LoRA application) stays greedy — it is a launch-precondition gate calibrated against the committed greedy diagonal, not a measurement.
2. **`scripts/issue560_transfer_analysis.py`** (~20 lines): `--four-float-dir` becomes `nargs='+'`. With one dir: unchanged. With two: build each seed's panel, assert identical (run, persona) cell sets, then average the per-cell DV columns elementwise (equal n per cell ⇒ exactly the 40-generation cell mean) for the pooled panel. Output filename `transfer_i474.json` unchanged; separation comes from distinct `--out-dir`s.

**Smoke/sweep architectural parity:** unchanged from parent — smoke IS the panel path restricted to a tiny cell. The amendment adds one sampled smoke cell exercising the new flags end-to-end before the full runs: `--phase smoke` (inherited gates, fresh pod) then `--phase gen --sources A2 --personas assistant --n-questions 10 --tag smoke_sampled_a --temperature 0.7 --gen-seed 42`, then the SAME generation under a DISTINCT tag `--tag smoke_sampled_b` (identical sampling flags), and a byte-compare of the completions across the two OUTPUT FILES (`smoke_sampled_a` vs `smoke_sampled_b`). The distinct second tag is load-bearing: the driver's resume-skip guard (`_validate_existing`) would otherwise skip generation on a same-tag re-invocation and compare the first output to itself, recording determinism "verified" on a no-op. If the two outputs differ, per-request-seed determinism fails under enable_lora: record it as a scope note (the replication logic needs cross-seed independence, not within-seed determinism) and proceed.

**Pipeline (per seed, sharded one-per-GPU):** gen → score-base → score-trained → upload, with `--tag sampled_gen/seed42` (GPU0) and `--tag sampled_gen/seed43` (GPU1). The tag mechanism suffixes pod-local dirs AND the HF bucket, so the parent bucket is structurally untouched. Analysis (CPU) runs off-pod on the VM after upload-verification, against the uploaded four-float JSONs + the committed geometry; pod terminates first (planner §9 CPU-off-pod rule; parent analysis took ~7 min CPU, ×3 runs here).

## §11 Decision rationale

- **temperature 0.7, top_p 1.0** — Source: project sampled-eval convention, `scripts/run_issue_276_bare_anth.py:167` (`SamplingParams(temperature=0.7, top_p=1.0, ..., seed=42)`), `configs/eval/issue_331_phase{0,1}.yaml`, `run_leakage_v3.py` default. Alternative considered: temp 1.0 (#370) — rejected; 0.7 is the convention the project's sampled marker/leakage evals standardized on, and the scope marker specifies it.
- **Generation seeds 42 + 43** — Source: 42 = project-wide seed convention (#560 engine seed, #553 analysis seed); 43 = next-integer second replicate per the followup-scope spec. Two seeds is the minimum that distinguishes "sampling killed it" from "this draw killed it".
- **Two replicates, not more** — Source: scope marker (est. 8 GPU-h); each additional seed buys ~half the parent's compute for a third point on a 2-point replication question.
- **Pooled read = per-cell average across seeds** — equal n per cell (20+20) makes the elementwise mean exactly the 40-generation cell mean; keeps the inherited panel/inference machinery unchanged (single-variable discipline).
- **All other hyperparameters** — Source: #560 (plan v2 §11 + clean-result Reproducibility), inherited unchanged.
- **Model id** — repo-standard (`Qwen/Qwen2.5-7B-Instruct`), no config-load smoke needed.
