## 0.0 TL;DR (plain English)

- **What I'll run:** No training and no new fits — I re-run the exact same activation-recording pass twice (with different internal batching) on 2,000 of the same prompts, for the base model plus 5 representative trained variants, to measure how much the recording itself jitters between two identical-in-principle passes.
- **What I expect:** The jitter floor is tiny compared to the answer-side shifts the main run measured — every trained variant's shift, including the small marker ones, sits at least ~10× above it, so the "smaller dose" reading for the marker models is real measurement, not noise.

## 11. Decision Rationale

- **Subsample n = 2,000.** Why: p95 of the per-context distance is stable at n=2k (~100 tail points above p95; quantile SE ≪ the 2×/10× decision bands) at ~12% of the full-corpus TF cost. Source: followup-scope spec (verbatim); parent #779 TF-rate basis for the cost side. Alternatives: full 16,400 rows (~8× cost, no decision-relevant precision gain); 500 rows (p95 tail count ~25 — too thin).
- **Replicates = 2.** Why: minimum for a pairwise distance read; the floor is a scale estimate, not a variance decomposition. Source: followup-scope spec. Limitation stated (§12.4): 2 replicates cannot separate geometry-vs-fp16 components; that split is not decision-relevant here.
- **r2 geometry: `tf_batch=13` + seed-1768 row permutation.** Why: changes padded-batch composition AND kernel reduction order — the demonstrated bf16 nondeterminism sources (gotchas.md bf16 padded-batch entries; #779/#1005 parity-gate calibrations). The exact value 13 is non-load-bearing (any ≠8 batch plus permutation suffices) — listed under deviations-allowed. Source: gotchas.md measured bf16 mechanisms; `ungrounded — needs smoke-test` only in the narrow sense that a floor of exactly 0 triggers the §8 fallback.
- **Floor statistic: p95 (median for context).** Why: an upper-tail noise bound is the conservative comparator for a "shift above noise" claim; median alone understates tail noise. Source: followup-scope spec (verbatim); parent v5's floor_p95 convention for the refit floor (same-statistic consistency).
- **Verdict bands 2× / 10×.** Source: followup-scope spec verbatim (falsification ~2×; hypothesis ≥10×); the 2× band also absorbs the √2 two-capture noise composition (§4.4).
- **Intent `lora-7b`, not `eval`.** Why/Source: v5 §9's "never L4" per-unit HBM floor (tool-behavior claim: GCP `eval`→`g2-standard-4` per CLAUDE.md intent table — read at plan time).
- Everything else: `Source: #1768 parent run` (plan v5 §§4.2–4.4, 11) — inherited unchanged.
