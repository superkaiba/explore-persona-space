## 0.0 TL;DR (plain English)

- **What I'll run:** Round 1 measured whether fine-tuning changes the context→answer map, but only on bare user prompts — none of the models ever saw their own training context at test time. I re-run the same map-change instrument on 12 representative trained models with each model's OWN training context (persona prompt / conversation history / worked examples) pasted in front of the same real user queries, plus a swapped-context control, so I can compare map change AT the trained context vs away from it, inside the same model.
- **What I expect:** models whose map looked unchanged on bare prompts (the conversation-history sycophancy models, D ≈ −4.7) show a real map change once their trained context is present; models already changed on bare prompts change at least as much on-target.
- **What would change my mind:** if on-target D is statistically indistinguishable from bare-prompt D everywhere, round 1's bare-prompt verdicts generalize and the "map change hides at the trained context" concern is dead; if the swapped-context control moves D as much as the own context, the effect is "any prefix", not the trained one.
