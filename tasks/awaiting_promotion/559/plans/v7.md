## 0.0 TL;DR (plain English)

- **What I'll run:** The finished run showed a cheap trick works for one hidden
  signature: before any training, you can guess which characters a trained model
  will lean toward the signature on, just by watching how the untrained model
  already leans that way. I'm checking whether the same trick predicts the
  trained behavior rate for three real misbehaviors — flattery, refusing to help,
  and giving harmful advice — reusing trained models we already have, so almost
  no new compute.
- **What I expect:** It transfers for harmful-advice and probably flattery — the
  untrained model already shows those tendencies, so there's something to read.
  Refusing-to-help is the shaky one: the untrained model almost never refuses, so
  there's barely any leaning to measure, and the guess may collapse to noise there.
- **What would change my mind:** If the guess beats the dumb "characters who
  already do it a bit will do it more" baseline on none of the three, then the
  trick was special to that one signature and doesn't generalize — that would
  narrow the original claim instead of widening it.

### Why code, not a model call?

The judge IS a model call (Claude/gpt-4o), per policy. The surrounding pipeline
(load committed completions, dispatch the judge over rollouts, aggregate to a
per-persona graded score, rank, bootstrap) is code because it is deterministic
aggregation over hundreds of rollouts at fixed cost — a single-model-call
formulation would neither be cheaper nor reproducible at this N, and the bootstrap
requires the per-rollout verdicts as structured output. Decision would flip only
if N were small enough (< ~20 rollouts/persona) to score in one prompt.

## 6. Evaluation — metrics, thresholds, measurement validity

**Primary statistic (per behavior):** per usable source panel, Spearman ρ over the
23 held-out bystanders between each ranker and the committed TRAINED LEVEL
(`trained_rate_411` for syco; `trained_rate` for refusal/EM); median over usable
source panels; bootstrap, B = 2,000, seed 42. Paired per-source (self_graded −
self_binary) median difference vs the ±0.10 band. The change `delta` is also
correlated as a labeled SECONDARY read (expected to trend negative/null by
construction — the predictor enters `delta` with coefficient −1, §3.1); it is
never a success criterion.

### Small-N source-axis carve-out (v7 — the registered fix)

The percentile-bootstrap source-axis CI collapses to `[min(ρ_s), max(ρ_s)]` when
the number of usable source panels is tiny (at N=2, the source-axis resample only
ever yields `{ρ_a, ρ_b}` orderings, so the 2.5/97.5 percentiles ARE the min/max —
no inferential content). The "conservative (wider-CI) axis governs" rule would
make that degenerate interval the governing one, which AGGRAVATES the artifact.
Registered carve-out:

- **Inferential floor = 4 usable source panels.** The source-axis bootstrap CI is
  computed and used as a boundary axis ONLY when a behavior has ≥ 4 usable source
  panels. Below the floor the source axis is a **descriptive thin-cluster
  diagnostic only** (its per-source ρ values are reported, but its bootstrap CI is
  NOT a PASS/FAIL/FALSIFY gate).
- **The 23-bystander CELL-axis bootstrap is ALWAYS the governing boundary axis**
  and is computed for every behavior. For arms below the source-axis floor, the
  per-arm verdict is governed by the cell-axis bootstrap alone.
- **Per-behavior application (verified usable counts at delta sd ≥ 0.05):**
  - **sycophancy — N=2 (below floor):** source axis is descriptive only; the syco
    verdict (PASS/PARTIAL/FAIL) is read off the 23-bystander cell-axis bootstrap.
    A degenerate syco source-axis CI straddling zero CANNOT trip the per-arm FAIL
    or the cross-behavior falsification.
  - **refusal — N=4 (at the floor → qualifies):** the floor is N=4, so refusal
    counts; both axes apply, conservative read governs.
  - **EM — N=5 (frozen join) / N=6 (corrected join, the primary), both ≥ 4 →
    qualifies:** both axes apply, conservative read governs.
- **Conservative-axis-governs rule is scoped to N ≥ 4** (refusal, EM). For N < 4
  (syco) the cell axis governs, full stop.

## 7. Decision Gates + per-arm kill/drop criteria

**No run-time gates** — the GPU path (top-up generation) is < 1 GPU-h worst case
and the analysis is CPU-only; there is no expensive intermediate to gate. The
gates below are ANALYSIS-time usability/kill criteria, pre-registered.

- **DV-usability gate (per source panel, pre-registered):** a source panel is
  scored ONLY if its 23-bystander `delta` standard deviation ≥ 0.05 (real ranking
  range; computed on `delta`, which equals the level minus a per-persona constant,
  so its sd equals the level's sd up to the base-rate spread — the usability gate
  is unchanged by the LEVEL DV switch). Verified counts: syco 2/6 usable, refusal
  4/6, EM 5/6 (frozen) / 6/6 (corrected). The count is recomputed live at
  analysis and drives the §6 source-axis floor (≥ 4 usable → source axis is a
  boundary axis; < 4 → cell axis governs). Flat panels are reported as excluded
  (not a misleading zero), with their `source_base_rate` to read no-install vs
  no-leakage.
- **Base-side floor kill (per behavior, pre-registered):** if ≥ 95% of the base
  model's rollouts under the panel personas are judged 0 (binary) AND the graded
  self-score has between-persona standard deviation below a noise floor (graded
  sd < 2 on the 0–100 scale), the base signal is degenerate and rank correlation
  is uninterpretable → the arm is DROPPED and the floor reported as the finding.
  **Refusal is the at-risk arm:** base refusal rate is ≈ 0 under > half the
  personas (49% of cells > 0, 7% > 0.05). If the graded refusal self-score also
  floors, refusal is dropped per the §-hard-rules drop policy.
- **Arm-drop policy (from the task hard rules):** an arm that fails the DV gate on
  ALL source panels or the base-side floor kill is DROPPED with an explicit §12
  note, NOT substituted with another behavior. The user can run it later.

These gates meet the "default to no gates" bar's exception only as analysis-side
usability criteria (not run-stopping); they are jointly satisfiable (each governs
a distinct arm/panel) and grounded in the verified panel statistics above.

## 11. Decision Rationale (load-bearing decisions; Sources)

No training → no training hyperparameters (lr/epochs/LoRA/etc.). The load-bearing
decisions are the predictor + DV + judge + bootstrap parameters.

- **Predictor = base self-scoring (generate-then-judge), inherited concept.**
  Why: the amendment's whole point is to test the parent's predictor on new
  behaviors; the predictor shape is the inherited constant. Source: #559 v4 §1 +
  body `## Findings` A.
- **Primary DV = the trained LEVEL (`trained_rate_411` / `trained_rate`), NOT the
  change `delta`.** Why: #559's positive headline (median ρ ≈ +0.61, parent body
  finding-4 +0.64) correlated the base predictor against the trained-arm LEVEL —
  the trained pressure — not against the change. The predictor enters
  `delta = level − bystander_base_rate` with a mechanical coefficient of −1
  (identity verified 138/138 cells per behavior), so correlating against `delta`
  would falsify the generalization by construction; reconciler-verified medians:
  ρ(base, delta) = +0.091/−0.425/−0.544 (syco/refusal/EM) vs ρ(base, level) =
  +0.276/+0.195/+0.000. The change `delta` is retained as a labeled SECONDARY read
  whose expected sign is the parent's collapse result, never a success criterion.
  Source: #559 parent body finding-4 / finding-3 (prior predicts the LEVEL,
  collapses on the change); `delta == level − bystander_base_rate` identity
  verified at plan time on `join_{sycophancy,refusal,em}.json`.
- **Continuous graded self-score (0–100) as the predictor of record, binary

## 13. Acceptance criteria + how the parent body updates

All criteria are stated against the PRIMARY DV = the trained LEVEL
(`trained_rate_411` / `trained_rate`). The change `delta` is a labeled secondary
read only and never trips any criterion (its expected sign is the parent's
collapse result, §3.1).

- **PASS (per arm):** base self-score median ρ (vs LEVEL) CI entirely > 0 on the
  governing axis (cell axis always; source axis too when N ≥ 4) AND paired
  (self_graded − base-rate) median-diff CI entirely > 0.
- **PARTIAL/INDETERMINATE (per arm):** ρ (vs LEVEL) CI entirely > 0 on the
  governing axis but the paired CI straddles 0 — "ranks held-out personas by
  trained level, but does not separably beat the base-rate baseline at this N."
  Never narrated as collapse (the v4 §14.1 straddle≠collapse rule, transposed). For
  N < 4 (syco) "the governing axis" is the cell axis; the degenerate source-axis CI
  is descriptive only and cannot move the verdict between PASS / PARTIAL / FAIL.
- **FAIL/FALSIFIED (per arm):** ρ (vs LEVEL) CI spans zero on the governing axis.
  For N ≥ 4 the conservative (wider-CI) of the two axes governs. For N < 4 (syco)
  ONLY the 23-bystander cell-axis CI can trip FAIL — a degenerate syco source-axis
  CI straddling zero CANNOT FAIL the arm.
- **DROPPED (per arm):** DV-degenerate on all source panels, or base-side floor kill
  fires (refusal is the at-risk arm) — reported as a knowable scope reduction, not
  substituted.
- **Generalization verdict (cross-behavior):** PASS on all viable arms → the parent
  `## Takeaways` extends from "scoring the base model's own answers ranks held-out
  personas by trained MARKER pressure" to "…by trained pressure for the marker AND
  {behaviors that passed}, before any training" (scoped to the arms that ran). A
  mixed result scopes the win to "marker + <passing behaviors>; <dropped/failed>
  not demonstrated." **The cross-behavior falsification fires only on a governing-axis
  CI spanning zero** — for syco (N < 4) that is the cell-axis CI; the syco
  source-axis CI alone CANNOT escalate to the global falsification. The parent v2
  body migrates to v3 on this same-issue follow-up consolidation (SPEC.md
  § Follow-up consolidation), with a new `### <finding>` per viable behavior arm and
  the Takeaways rewritten to the cross-behavior claim (about the trained level).
