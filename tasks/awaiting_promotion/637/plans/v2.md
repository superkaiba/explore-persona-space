> **v2 revisions vs v1** (after Phase-2 critic ensemble — Statistics REVISE, plus inline Methodology + Alternatives + Consistency BLOCK after 6/7 spawns hit API 529):

## §0.0 TL;DR (plain English)

- **What I'll run:** When you teach a behavior into context A, it "leaks" into other context B at some strength — and the leak A→B is not the same size as B→A. I already measured how much of that asymmetry can be explained by a simple rule: every context has a "how broadly it spreads" number and a "how easily it catches things" number, and the gap between A and B's numbers predicts the direction of the asymmetry. The earlier check said yes for the marker behavior (a simple 2-number-per-context rule explains ~95% of the asymmetry) but only partly for refusal / sycophancy / emergent-misalignment (~35-44%). But that earlier check fit and scored on the *same* cells, so it could be flattering itself. This run re-does it honestly: fit the simple rule on 80% of the context pairs, then score it on the held-out 20% it never saw — and compare against both a no-asymmetry baseline and the full all-pairs model.
- **What I expect:** For the marker, the simple 2-number rule will still beat the no-asymmetry baseline out-of-sample (the ~95% was real, not overfitting). For refusal / sycophancy / emergent-misalignment, the "leftover" structure that looked like it needed a full pairwise rule will mostly evaporate out-of-sample — I bet a lot of that 56-65% was just noise the full model memorized.
- **What would change my mind:** If the full all-pairs model still clearly beats the simple 2-number rule on cells it never saw, that's real pairwise structure, and the leakage rule genuinely has to be more than per-context broadcast + receptivity — which would make the downstream theory (#526) meaningfully harder.

## §1. Goal

Decide how complex the directional leakage predictor `g(source_context, eval_context, behavior)` must be, by testing whether the directional ASYMMETRY of behavior-transfer is **low-rank** — explainable by one per-context "source breadth" scalar `b_i` and one per-context "receptivity" scalar `r_j` (a rank-1 additive antisymmetric structure) — rather than requiring a **full pairwise interaction** term. The parent theory task #526 (Dan's "the leakage rule must be asymmetric AND behavior-dependent") needs to know the minimal functional form of `g`; this analysis answers #526's "how complex must `g` be?" gate by reading it off the #537 16×16-per-behavior transfer matrices. The landed #526 analysis answered this **in-sample**; this issue re-answers it **out-of-sample** (held-out cross-validation) so the rank-1 verdict is not an artifact of fitting and scoring on the same cells.

## §3. Hypothesis

Let `ΔR²_scalar = R²_heldout(sym+scalar) − R²_heldout(sym-only)` and `ΔR²_full = R²_heldout(full-pairwise) − R²_heldout(sym+scalar)`, per behavior, with bootstrap 95% CIs over held-out cells.

- **H1 (rank-1 asymmetry is real for the marker):** for the marker, `ΔR²_scalar` 95% CI excludes 0 (the per-context breadth/receptivity scalars carry genuine out-of-sample signal) AND `ΔR²_full` 95% CI **includes** 0 (no detectable pairwise structure beyond rank-1). **Confirms** the in-sample marker verdict ("scalar=0.95, residual=0.05") survives held-out. **Falsifies** if `ΔR²_scalar` CI includes 0 → the in-sample 0.95 was overfit.
- **H2 (the "needs full pairwise" verdict for refusal / sycophancy / EM is partly train-set overfit):** under the per-cell split (see §4 resolved-design), the full-pairwise arm predicts a held-out cell `(i,j)` from its OBSERVED transpose `(j,i)` whenever the transpose is in train — giving `ΔR²_full` a real out-of-sample signal rather than a mechanical zero. The prediction: for refusal / sycophancy / EM, `ΔR²_full` 95% CI **includes 0** for at least 2 of the 3, i.e. the in-sample 56-65% residual-pairwise shrinks out-of-sample and does not beat the rank-1 model on held-out cells. **Confirms** if held-out full-pairwise is indistinguishable from sym+scalar. **Falsifies** if `ΔR²_full` CI excludes 0 for all 3 → the residual pairwise structure is real, and `g` genuinely needs a full interaction term for non-marker behaviors.
- **Quantitative thresholds:** a behavior is called "rank-1 sufficient (held-out)" iff `ΔR²_scalar` CI excludes 0 and `ΔR²_full` CI includes 0; "needs pairwise (held-out)" iff `ΔR²_full` CI excludes 0; "asymmetry not recoverable out-of-sample" iff both `ΔR²_scalar` and `ΔR²_full` CIs include 0 (the asymmetry is noise-limited at this N).

### The three predictors (exact definitions, fit on TRAIN cells, scored on TEST cells)

Let `M` be the 16×16 transfer matrix for a behavior, off-diagonal cells indexed by `(i,j)`, `i≠j`. Split the 240 off-diag indices independently into `train` (192 cells) and `test` (48 cells), seed 42 — **per-cell** random split.

1. **Symmetric-only** — `g_sym(i,j) = μ + s_i + s_j` from a symmetric additive fit on the train cells (LS on `M_train_ij ~ μ + s_i + s_j` with a single per-context scalar `s` used in both source and target positions). The held-out cell `(i,j)` does not enter the LS fit, so the symmetric mean is leak-free regardless of whether `(j,i)` is in train or test. This is the rank-0-antisymmetry baseline.
2. **Symmetric + scalar (rank-1 antisymmetry)** — `g(i,j) = g_sym(i,j) + (s_i − s_j)`, where `s_i = (b_i − r_i) / 2` and `(b, r)` come from `fit_two_way_additive(M)` restricted to TRAIN cells (REUSED function; matches the antisymmetric part of the additive fit). The asymmetric component `s_i − s_j` is the exact rank-1 antisymmetry: `(s_i − s_j) + (s_j − s_i) = 0` by construction, AND this is the same quantity the in-sample `scalar_antisym_fraction` (`scripts/issue526_asym_gate_ladder.py` `Ahat_ij = s_i − s_j`) measures the 0.95 marker fraction against. Arms 1 and 2 differ by EXACTLY this rank-1 antisymmetric term — clean single-variable contrast.
3. **Full pairwise** — for a TEST cell `(i,j)`, the full antisymmetric component is `A_ij = (M_ij − M_ji) / 2`. Per-pair, this is one free number per pair. Two sub-cases under per-cell split:
   - **Transpose in train (`(j,i) ∈ train`):** estimate the residual per-pair antisym from the observed transpose: `Â_ji,obs = M_ji − g_sym(j,i)`. By antisymmetry `Â_ij = −Â_ji,obs`. Predict: `ĝ_ij_full = g_sym(i,j) − (M_ji − g_sym(j,i))`. Since `g_sym(i,j) = g_sym(j,i)` (symmetric mean), this simplifies to `ĝ_ij_full = 2·g_sym(i,j) − M_ji`. The full-pairwise prediction uses the OBSERVED transpose value directly — a non-degenerate generalization test of "does the seen transpose carry signal beyond the rank-1 scalar summary?"
   - **Transpose also held out (`(j,i) ∈ test`):** no per-pair train data; fall back to the rank-1 prediction `ĝ_ij_full := ĝ_ij_scal = g_sym(i,j) + (s_i − s_j)`. Such cells contribute the SAME prediction to arms 2 and 3, so they neither inflate nor deflate `ΔR²_full` on those cells; the contrast remains clean.

   Under random 80/20 cell-split, expected ≈ `48 × 47/239 ≈ 9.4` cells per behavior have a held-out transpose (small fraction of the 48 test cells, but recorded in the meta.json as `n_full_fallback`).

**Resolved design decision (per-cell split):** v1 proposed a pair-split (hold both `(i,j)` AND `(j,i)` together) but that made `ΔR²_full ≡ 0` mechanically by construction — the test could not distinguish "no real pairwise structure" from "design cannot see it." The Statistics + Methodology + Alternatives critics in Phase-2 all flagged this as a fatal design defect. v2 switches to a per-cell split (240 cells → 192 train / 48 test, seed 42). Under per-cell split: (a) the symmetric-mean fit is leak-free because the held-out cell's own value never enters the LS fit; (b) the scalar arm's `b, r` estimates are unchanged from v1 (they always used all train cells, never the held-out cell directly); (c) the full-pairwise arm has REAL out-of-sample signal — the observed transpose `M_ji` carries the per-pair residual antisym that the rank-1 model approximates with `s_i − s_j`. `ΔR²_full` is now a genuine generalization test, not a mechanical constant.

## §5. Conditions and Controls

| Plain-English name | What it tests | What it controls for | Config slug |
|---|---|---|---|
| **No-asymmetry baseline** | held-out R² of the symmetric prediction `(M_ij+M_ji)/2` (train-fitted symmetric mean on held-out pairs) | the floor: how well leakage is predicted with ZERO directional structure | `sym` |
| **Rank-1 scalar model** | held-out R² of `g_sym + (s_i − s_j)` with `s = (b − r)/2` from train cells (v2 formula — matches `scalar_antisym_fraction`) | whether directional asymmetry is captured by 2 numbers per context — the headline question | `sym_scalar` |
| **Full pairwise model** | held-out R² when each held-out pair is allowed its own free antisymmetry (none, for a held-out pair) | whether per-pair interaction carries OUT-OF-SAMPLE signal beyond rank-1 (it cannot by construction → quantifies in-sample overfit) | `full_pairwise` |
| **Shuffled-context control** | held-out R² of the scalar arm after permuting context ids before fitting `b,r` | rules out that the rank-1 gain is a free-parameter artifact (28 extra DoF) rather than real per-context structure | `sym_scalar_shuffled` |

The shuffled-context control rules out the confound that adding 28 scalar parameters (`b`, `r`, 16 each minus centering) trivially raises in-sample fit; if the scalar gain is real per-context structure it survives the proper fit but collapses under id-permutation, and the held-out gap between `sym_scalar` and `sym_scalar_shuffled` is the real effect size.

## §6. Evaluation

**Metrics:** per behavior (marker, taught fact, refusal, sycophancy, EM), held-out R² of each arm and the two paired differences `ΔR²_scalar = R²(sym_scalar) − R²(sym)` and `ΔR²_full = R²(full_pairwise) − R²(sym_scalar)`, each with a 1000-bootstrap 95% CI over the 48 held-out cells (per-CELL split — v2; was per-pair in v1). Plus the shuffled-context held-out R² as the scalar-arm null. Also reported per behavior: `n_full_fallback` (count of test cells whose transpose was also held out, ≈ 9 expected under random 80/20 cell-split; these contribute the same prediction to arms 2 and 3, so they have zero leverage on `ΔR²_full`).

**Success / threshold:**
- **Rank-1 survives (per behavior):** `ΔR²_scalar` 95% CI excludes 0 (real out-of-sample directional structure). Expected to hold for the marker; tested for all 5.

## §11. Decision Rationale

`N/A — no model training` for all training hyperparameters (lr, schedule, warmup, batch, epochs, LoRA rank/alpha/dropout, weight decay, seq length, optimizer, precision). This is a 0-GPU read-only analysis. The load-bearing **analysis** knobs:

- **What (v2):** split on 240 individual off-diag CELLS, 80/20 → 192 train / 48 test cells, seed 42.
  **Why:** v1 proposed a pair-split (hold both `(i,j)` AND `(j,i)` together) but the Statistics + Methodology + Alternatives critics (Phase-2 ensemble) all flagged this as a fatal design defect: under the pair-split, `ΔR²_full ≡ 0` mechanically by construction (a held-out pair has no per-pair antisym parameter, so full-pairwise FALLBACK to rank-1 is required for every test cell), independent of whether real per-pair structure exists. The H2 test would have been unfalsifiable. v2's per-cell split fixes this: under random per-cell split, each held-out cell `(i,j)` usually has its transpose `(j,i)` in train (expected ≈ 39 / 48 cells per behavior), so the full-pairwise arm can use the OBSERVED transpose `M_ji` as evidence for `A_ij = −A_ji`. If real per-pair structure exists, this prediction beats the rank-1 model; if it's noise, it doesn't. The transpose-also-held-out fallback (~9 cells per behavior) contributes the same prediction to arms 2 and 3, leaving the contrast clean. Tied to the Goal: rank-1 vs pairwise must be a non-degenerate held-out comparison.
  **Source:** ungrounded — small-sample cross-validation convention. The per-cell choice is dictated by needing `ΔR²_full` to be a non-degenerate quantity (the dominant design constraint), not a tunable. Flagged Low-confidence in §12.
  **Alternatives:** pair-split (REJECTED in v2 — see above; v1's rationale was incorrect on the "ΔR²_full ≡ 0 by construction" → "honest null" mapping); leave-one-cell-out (rejected — 240 refits × 5 behaviors × bootstrap is heavier with no accuracy gain at this N, and the 20-seed split-stability loop already covers split variance); per-cell with transpose-NEVER-in-train (rejected — too restrictive, defeats the purpose of giving full-pairwise out-of-sample signal).

- **What (v2):** rank-1 antisymmetry predictor is `s_i − s_j` with `s_i = (b_i − r_i) / 2`, where `(b, r)` come from `fit_two_way_additive` on train cells.
  **Why:** v1 used `(b_i − r_j)` which is NOT antisymmetric: `(b_i − r_j) + (b_j − r_i) = (b_i + b_j) − (r_i + r_j) ≠ 0` in general. The Statistics critic identified this as conclusion-changing: the in-sample 0.95 marker scalar fraction is measured against `s_i − s_j` (the `scalar_antisym_fraction` docstring in `scripts/issue526_asym_gate_ladder.py`), so a held-out comparison with `(b_i − r_j)` would have measured a different predictor than the in-sample anchor — the marker rank-1 verdict could flip on implementation choice. v2 pins the formula to `s_i − s_j` and adds `assert_in_sample_reproduction()` to fail-fast on drift (Kill-4(b)).

Confidence: high (mathematically derived from the reused helper's docstring + the values it produces).
  **Alternatives:** `(b_i − r_j)` (v1's choice, REJECTED — not antisymmetric, would measure a different quantity); per-context base-rate `(p_i − p_j)` (rejected — confounds the rank-1 structure with the base prior; the in-sample finding `corr(scalar, base prior) = 0.03` for marker shows the two are distinct quantities).
