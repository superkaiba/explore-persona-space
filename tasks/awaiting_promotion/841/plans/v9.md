## 7. Decision Gates

**No mid-run compute gates — short run (~4 GPU-h, <4h wall, well under the 4h/16-GPU-h gate bar; the parent's §7 trigger already fired to spawn this round).** The §7 content is discrete correctness kill-gates + named diagnostics + the pre-registered interpretation stop-reads.

### Kill / stop criteria

- **KILL-A (spot-gate, §4.1 step 2):** if the alignment + capture-equivalence spot-gate FAILS (a re-captured regenerated parent context, MIXED into a realistic batch, does NOT match its stored `cx_last` row to rel 1e-3 on the fp32 path), STOP before the full 96k capture. First fall back to the parent's per-sequence batch-1 fp32 path and re-gate; if it still fails, the regeneration is misaligned or the capture path diverges → do NOT spend the capture; diagnose (post `epm:failure`).
- **KILL-B (ridge parity + solver cross-check, §4.2):** (i) if the primal ridge at n=4000 does NOT reproduce the parent's stored ridge R² within |ΔR²|<0.01 after the λ-pin retry, STOP — the scaling curve is not anchored. (ii) if the n=10000 dual-vs-primal `max|ΔR²|` ≥ 0.01, STOP — the primal PRESS-LOO implementation is suspect at the very n≥25k points that have no dual to check against. Diagnose rather than reporting an unanchored/unvalidated curve.
- **STOP-C (one-step retention floor, inherited from parent §7):** if the largest-n one-step (k=1) predicted states retain <~50% of ceiling r for ALL classes AND ALL traits, skip the multi-hop retention grid and report the atlas + one-step table (a complete negative). Single, jointly-satisfiable floor check; grounded in the parent's ceilings (0.46-0.62).

### Named diagnostic (gates a FLAT-H1 attribution)

- **Position-drift check (§4.2 fold-2):** BEFORE attributing a FLAT DV1 curve to genuine data-saturation, read the anchor-vs-late-window 4000-fit R² comparison. If the late-stream 4000-window fits the fixed test comparably to the anchor (within subsample noise), the stream is stationary and FLAT-H1 = genuine saturation. If the late window fits materially WORSE, the added contexts are distributionally drifted → a FLAT H1 read is caveated (the scaling curve mixes "more data" with "different-distribution data") rather than reported as clean saturation.

### Interpretation stop-reads (what folds into the clean-result either way)

**(a) Late-layer affine Δ-R² (DV1)** — on the FIXED test set at the data-limited transitions (17-25), ridge, on identity-relative raw R² r2_id (trigger continuity — the fired §7 trigger was computed there; r2_meancentered reported alongside as a diagnostic):
- **IMPROVED + plateaued:** mean R²(100k) − R²(4000) ≥ +0.05 absolute AND the n=50k→100k marginal gain < 20% of R²(100k). → "late-layer map quality WAS data-limited at n=4000 and closes with ≤25× more data" (removes the "scale follow-up pending" hedge from Takeaway 1; report the plateau n).
- **STILL CLIMBING:** the n=50k→100k gain still exceeds 20% → "data-limited even at 25×; the affine map is not saturable within reach" (a bounded negative — a further-scale follow-up would be a fresh proposal).
- **FLAT:** R²(100k) ≈ R²(4000) within subsample noise → contradicts the parent's trigger read; report as a correction ONLY AFTER the position-drift check clears (else caveat as possible drift, not saturation) — the n=2000→4000 gain would then be a subsample-noise artifact near the n/d≈1.1 interpolation threshold, consistent with the parent's own non-monotonicity caveat.
- **DEGRADED:** R²(100k) < R²(4000) → distribution shift or fit pathology; investigate before reporting.

**(b) Transport-scaling curve (DV2/DV3)** — win-count(n) + mean-paired-delta(n) vs the 4k baseline (20/136), read as a CURVE (fold-5 symmetric):
- **IMPROVED (data-limited):** win-count(n) rises above 20 (monotone or peaked) with the mean-paired-delta(n) CI clearing zero at its best n and the newly-winning subcount surviving BH correction against its ~3-4-by-chance expectation → "the transport advantage IS data-limited" (the surprising, mentor-relevant outcome).
- **NON-MONOTONE / INVERTED-U:** win-count(n) peaks at an intermediate n then returns toward baseline by 100k → "transport has an optimal unsupervised-data budget; beyond it the LMSYS-fit map transfers worse" — cross-check the transport-fidelity(n) curve (fidelity peaking with transport supports the map-OOD reading). A DISTINCT named outcome, NOT FLAT.
- **FLAT:** win-count(n) + mean-paired-delta(n) statistically indistinguishable from the 4k baseline across ALL n (every paired-delta CI includes zero). **"DPI/architecture-bound" narration requires BOTH tight-around-zero paired-delta CIs AND no improvement in fidelity(n)/DV1** — a flat transport alongside an IMPROVED DV1/fidelity is a TRANSFER finding (the map got measurably better but the transported projection did not capture it), not a DPI bound. Report accordingly (extends #841's Takeaway 6 only under the former).
- **DEGRADED (monotone down):** win-count(n) falls below baseline as n grows → cross-check the transport-fidelity(n) curve; a fidelity drop attributes it to LMSYS-overfit map-OOD (a real, reportable transfer finding).

**Either way, DV1 + DV2/DV3 fold into #841's SAME clean-result** (cheap-band same-issue follow-up): Takeaway 1 gains the settled scaling verdict, Takeaway 2 gains the transport-scaling-curve verdict, and the DV1 + transport-scaling figures are added under `## Results`.
