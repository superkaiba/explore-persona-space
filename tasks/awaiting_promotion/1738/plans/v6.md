- **What I'll run:** I take the same 100,000 real multi-turn conversations the run just captured, feed the model ONLY each conversation's final user question (nothing before it), record the model's internal state at that question's last token, and fit the same five maps from that state to the already-captured answer states.

### 4.1 `scripts/issue1738_multiturn_generate_capture.py` — new `--bare-query` mode

1. **Render (the scope's binding mechanic, reconciled):** passing `messages=[user turn]` alone would silently inject Qwen's default system prompt — verified against the cached `tokenizer_config.json` (snapshot `a09a35458c702b33eeacc393d103063234e8bc28`): the template branches on `if messages[0]['role'] == 'system'` and otherwise inserts `You are Qwen, created by Alibaba Cloud. You are a helpful assistant.` The round therefore uses the #1092 empty-system convention (port of `_render_bare_query_empty_system`, `scripts/issue1092_crossed_core_sae.py:1176` on main): `tok.apply_chat_template([{"role":"system","content":""},{"role":"user","content":q}], tokenize=False, add_generation_prompt=True)` where `q = row["messages"][-1]["content"]` (manifest rows end at the last user turn; driver line 604 `"messages": ctx["messages"]`). **Hard asserts per row:** (a) `"You are Qwen" not in text` → RuntimeError; (b) no-prefix-content identity at STRING level (BPE-seam-immune — plan-critique round 1 measured a leading-newline query merging across the template's `user\n` seam, shifting token overhead 13→12, so a token-count identity false-fires deterministically on real LMSYS/WildChat rows): `assert text == TEMPLATE_PREFIX + q + TEMPLATE_SUFFIX`, with `TEMPLATE_PREFIX`/`TEMPLATE_SUFFIX` computed once per process by splitting the empty-system template render around a unique sentinel query; still catches prefix-content / extra-turn leakage. B0 self-test: assert (b) must PASS on a probe query beginning with a literal newline (the seam case) and FAIL on a render with an injected extra turn.
 One worked example render logged verbatim to `bare_pilot_meta.json` + the round report.
