## 4. Method delta vs the parent run (design)

Single conceptual + implementation delta: **where the operators live**. Per (ordered pair, arm, outer fold), both sides are projected into a train-fold-only shared PCA basis before ANY fit; every operator (W_S, W_T, M, B_free, B_derived, B_derived2, identity+bias, class-ladder + rank-rung forms) is fit and evaluated inside that basis. Everything else — pairing, folds, λ selection, verdict rules, null conventions, unit keys, checkpoint/resume — is byte-inherited from the parent drivers.

**The projection layer (the one new mechanism):**
1. Per unit, k_unit = min(1024, floor(min_fold n_train(fold) / 2)) — the MINIMUM train-fold size across the 5 folds sets one k per unit, so n_train ≥ 2k holds on EVERY fold (the well-posedness invariant, asserted in code; violation = unit error, recorded, battery continues). n_train ≈ 0.8·n_common → median k ≈ 186, max 1024 (§2).
2. Per fold × side: center and thin-SVD the STACKED train rows — Q_x = top-k_unit right singular vectors of [X_S[tr]; X_T[tr]] (2·n_tr × d), Q_y likewise from [Y_S[tr]; Y_T[tr]]. ONE basis per side SHARED across source and target (required for identity+bias, kNN, and conjugation coherence in reduced coordinates); train-fold-only (test rows never touch the basis — the leakage discipline of the conv-grouped folds extends to the basis).
3. Project: x → Q_xᵀ(x − μ_x), y → Q_yᵀ(y − μ_y) (train means). All fits run on the (n × k) projected matrices through the UNCHANGED Gram-dual inner-group-cv helpers (`fl._fit_ridge_inner_group_cv_t`; the drivers' existing `--dim-limit` path already proves the fit code is d-agnostic — `issue1689_derived_vs_free.py` L323–327).
4. W_S⁺ truncation grid = {32, 128, 512, eff-rank} ∩ [1, k_unit] — the existing clamp `min(int(r), s.shape[0])` (L373) realizes this automatically; the realized grid is recorded per unit. Rotation nulls (`_haar`, L137) draw in dimension k_unit; matched-capacity null draws (40) refit per draw in the same reduced basis; the random-subspace null matches (k_sub, k_unit).
5. **Evaluation spaces (registered):** the PRIMARY verdict R² is computed in the reduced coordinates (all compared models live in the same k-dim space; the R² denominator is the projected held-out y_T variance — a like-for-like three-model comparison). The ambient-reconstruction companion R² (Q_y·ŷ_red + μ_y against raw y_T) AND the basis's held-out captured-variance fraction are persisted per unit, so the reduced-space verdicts are auditable against ambient scale post-hoc. Readout register: reduced-space verdicts are narrated as conditional on the per-pair estimable subspace, never as ambient-operator claims.
