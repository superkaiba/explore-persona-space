## 1. Goal, hypothesis, falsification

**Goal (inherited from the issue; this follow-up closes its named scope bound):** the completed run answered "persona framing, not mere departure from the trained context, drives the dampening" with the non-persona class represented by ONE bare instruction string. **Hypothesis (primary bet, from the rank-1 proposal):** no instruction-family cell dips. The completed run's decomposition says persona dips are carried by the BASE prior rising under identity framing (and the bare-instruction cell's base prior actually FELL ~0.55 nats, pushing its paired contrast above zero: +0.197 log-prob, +1.775 EOS-margin, 0/12 adapters negative). Instruction prompts assign no identity, so their base prior should stay flat-to-lower and every paired contrast should stay at or above zero. If all four cells classify **no-dip** (and the doctor re-read dips, calibrating the run), "persona framing required" upgrades from panel-bounded (one bare instruction string) to global across the instruction family — five non-persona strings total, zero dips.

**Falsification:** any instruction-family cell classifies **dip** under the inherited rule (D̄_eosm ≤ T_dip = min(0.6·D_doc, −1.0), ≥10/12 negative, log-prob concordant). One such cell kills "persona framing required" and revives the graded-departure account; the run then reports WHICH instruction feature dipped (completeness vs detail vs process vs formatting) — directly seeding the role-syntax/content mechanism follow-up (rank-2 proposal).
