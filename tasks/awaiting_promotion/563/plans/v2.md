## 0.0 TL;DR (plain English)

- **What I'll run:** The last run showed that putting a role prompt ("you are a doctor", "you are
  a French person", ...) in front of the plain model makes it treat a rare bookkeeping token as
  more likely at the end of its answers. But the model also wrote different answers under each
  role prompt, so we couldn't tell whether the prompt itself causes the shift or the changed
  answers do. This time I freeze the answers: I take the 250 answers the model wrote with no role
  prompt and re-score the exact same text under all five prompts. Nothing new is generated; only
  the prompt in front changes.
- **What I expect:** The shift survives on frozen text. Same answers, different prompt, the token
  still looks more likely; that would mean the prompt acts directly on how the model reads the end
  of an answer, not through what it writes.
- **What would change my mind:** If the shift mostly vanishes on frozen text, the earlier effect
  was carried by what the role prompts made the model write, and the earlier run's mechanism story
  gets rewritten as a content effect. Built-in sanity check either way: re-scoring the no-role
  answers under the no-role prompt has to reproduce last run's committed numbers row for row.
