## §0.0 TL;DR

- **What I'll run:** Fit the same ridge map from #779 on four different answer sets — Qwen's own answers (reference, two versions: the original bundle and freshly regenerated), Sonnet plain-style answers, and Qwen's own answers shuffled to a wrong context. No new model training. The work is generating Sonnet answers, regenerating Qwen's own answers via vLLM, extracting hidden states for each answer set under the original contexts, and re-running the ridge fit — separately per arm (each arm gets its own map fit), plus a cross-arm transfer check.
- **What I expect:** The map trained on Qwen's own answers should fit those answers better than Sonnet answers, and should fit deranged answers near zero. If the Qwen-arm R² beats Sonnet-arm R² by more than five points, and the deranged-arm R² is near zero, the map is tracking what Qwen itself will write, not just what the context implies. The cross-arm transfer (A′-trained map scored on B2/C) will be a secondary read — probably lower than the per-arm refits.
- **What would change my mind:** If the per-arm refit R² for Sonnet-plain answers comes within three points of Qwen's own answers at the primary read-out layers, the map is capturing context-side computation and the content of the answer barely matters. That would mean the #779 result is about how the model processes the prompt, not about predicting its own outputs.

## §0 Plan Summary

**Training:** No model training. Frozen Qwen-2.5-7B-Instruct, base weights only. Ridge regression (GCV, λ ∈ [1e-2, 1e4]) refit separately per arm on five arms using the existing #779 substrate (5000 LMSYS contexts, 28 layers, cx_last shape 5000×3584 per layer).

**Hyperparameters:** Ridge GCV λ grid: np.logspace(-2, 4, 13) — inherited from #779 `fit_h.py`; same 5-fold CV split (seed=0), same standardize-X/center-Y protocol. No novel hyperparameters. Source: #779 `fit_h.py::ridge_fit_predict`.

**Baselines / controls:** Arm A (Qwen own answers, reused #779 bundle v_x — harness reproduce-gate + consistency diagnostic only). Arm A′ (Qwen own answers, freshly regenerated via vLLM — primary own-answer arm for headline comparisons). Arm B2 (Sonnet-plain: Claude Sonnet 4.5 plain-style answers, style instruction stripped before TF). Arm C (derangement null: Qwen's own regenerated answer teacher-forced under a different context via a fixed-point-free permutation, seed=42). Arm B1 (Sonnet-weird: adversarial-style answers — diagnostic only, not a hypothesis arm).

**Loss surface:** N/A — ridge regression on mean-pooled residual-stream vectors. Teacher-forcing computes mean over response token span [prompt_len:full_len] at each of 28 layers.

**Compute:** Phase 0.5 (vLLM Qwen regeneration): ~1 GPU-h on 1× A100-80. Phase 3 (TF extraction on GPU, arms B1, B2, C, A′): ~5 GPU-h on 1× A100-80 (`lora-7b`). All other phases CPU on VM. Total GPU: ~6 GPU-h. **Estimated GPU-hours (total): 7**

**Evaluation:** Primary DV = per-arm refit held-out R²_s (each arm s ∈ {A′, B1, B2, C} gets its own ridge fit on (cx_last, v_s) train folds, scored on v_s held-out folds). Secondary DV = cross-arm transfer matrix R²_{s→s′} (h fit on arm s train folds, scored on arm s′ val folds). Decision rule: H1 (own-output specificity) if R²_A′ − R²_B2 > 0.05 AND R²_C < 0.05; H2 (context-side) if all per-arm refits within ±0.03; H3 (content generality) if R²_A′ ≥ R²_B2 > R²_C AND R²_B2 − R²_C > 0.03. All comparisons Bonferroni-corrected α = 0.05/3 = 0.017. Paired t-tests (5 fold values, **4 d.f.**) across folds for each comparison. Context-level bootstrap CI (n≈5000) is the PRIMARY uncertainty estimate; the fold-level t-test is a secondary coarse check.

**Risks (top 2):** (1) Sonnet-plain answers differ in length distribution from Qwen's own answers — mean-pooling over spans of different lengths makes the per-context vectors incomparable. Mitigation: truncate to min(Qwen_len, Sonnet_len) tokens before mean-pooling, record per-context span lengths. (2) Stream-order drift between the prompt reconstruction and the bundle: the bundle stores no prompt text, so prompts are reconstructed by replaying `load_train_contexts` on LMSYS-Chat-1M; an alignment gate (cosine > 0.999 on ≥20 spot-check contexts at all 28 layers) is required before any arm work.

## §1 Goal

**What:** Determine whether the #779 ridge map h: cx_last(x) → v(x) — which achieves held-out R² 0.5977–0.6253 across evil/sycophancy/hallucination traits (evil read-out L14 R²=0.598, sycophancy L26 R²=0.604, hallucination L17 R²=0.625; cross-trait aggregate peak at L19 = 0.677) — is predicting the model's *own* generated content (own-output specificity hypothesis), or whether it is primarily capturing context-side computation that transfers to arbitrary answer text teacher-forced through the same context (context-processing hypothesis), or something in between (content generality hypothesis).

**Why:** If h predicts Qwen's own answers specifically (H1), then #779's result is evidence that the last-context vector encodes a prediction of the model's forthcoming *content*, not just a generic context representation. That changes the interpretation from "the model has a persona-like internal state" to "the model's context vector encodes an output prediction." If h transfers equally to external answers (H2), the result is about context-side computation, not content prediction. The distinction matters for whether h could be used as a predictive probe in deployment versus merely as an alignment diagnostic.

**Formal definitions:**

- v_A(x): mean residual-stream activation over Qwen's OWN generation response tokens, as stored in the #779 pass_b bundle (reused, harness reproduce-gate only).
- v_A′(x): same mean, but freshly regenerated via vLLM with the same #779 recipe (same model, same prompt reconstruction, same sampling params), teacher-forced through the new extraction driver. Primary own-answer arm for headline comparisons.
- v_B2(x): same mean, but over a Sonnet-plain answer to the same question, teacher-forced under x.
- v_B1(x): same mean, but over a Sonnet-weird answer (with style instruction stripped before TF).
- v_C(x): same mean, but over Qwen's OWN regenerated answer to question π(x) (a deranged context), teacher-forced under x. Null/derangement arm.

**Two distinct R² quantities — both registered (task body DVs 1 and 3):**

- **R²_s (per-arm refit, HEADLINE DV 1):** For each arm s ∈ {A′, B1, B2, C}, fit h_s independently on (cx_last, v_s) train folds, score on v_s held-out folds. Five-fold CV, same context split (seed=0) for all arms. This answers: "Is cx_last predictive of arm-s answer activations at all?" and "Which arm's content is most predictable from context?" Refit rows have `fit_arm == score_arm` in metadata. For arm A (bundle v_x): refit R²_A used only for the harness reproduce-gate (must match #779's percontext_recon.json ±0.01).

- **R²_{s→s′} (cross-arm transfer, SECONDARY DV 3):** Fit h_{A′} on arm A′ train folds, score against v_{s′} val folds (same fold assignment) for each s′ ∈ {A′, B1, B2, C}. Also compute the identity baseline: v_A′(x) as a predictor of v_{s′}(x) (zero-parameter baseline). Transfer rows record `fit_arm: arm_a_prime`, `score_arm: arm_s_prime` explicitly. No transfer-path call trains on v_B1, v_B2, or v_C. This answers: "Does the A′-trained map carry over to other arms?" Mechanizable invariant: any result row with `fit_arm != score_arm` is a transfer read; any row with `fit_arm == score_arm` is a refit read; the two are never conflated in narration.

**Kill criterion:** If the GPU extract phase (Phase 3) produces NaN activations for > 5% of contexts in any arm, abort and report as a data-quality finding.

Bundle keys: `{cx_last, cx_mean, v_x, layers, source, metadata}` (metadata is provenance-only: git_commit fc96549e, pass B; contains no prompt texts). This experiment inherits that substrate as arm A (harness reproduce-gate only); arm A′ is freshly regenerated.

**Future Lens (arXiv 2311.04897, Pal et al., 2023):** "Future Lens: Anticipating Subsequent Tokens from a Single Hidden State." Showed that intermediate hidden states can be decoded to predict the model's eventual output token distribution (next-token logits), achieving > 48% accuracy on subsequent-token prediction at some layers in GPT-J-6B using linear approximation. The key distinction from #779 is that Future Lens predicts next-token logits (a token-space prediction), whereas #779 maps to full response activation vectors (a content-space prediction). The present experiment tests whether #779's map is closer to a Future Lens–style own-output prediction or a more generic context encoding. The Future Lens finding supports H1 as a prior: linear maps from context vectors do track own-output content.

**Looking Inward (arXiv 2410.13787, Binder et al., 2024):** "Looking Inward: Language Models Can Learn About Themselves by Introspection." Showed that LLMs can be finetuned to predict properties of their own behavior in hypothetical scenarios, outperforming a different model trained on the same ground-truth behavior — evidence for privileged access to one's own behavioral tendencies. Note: this paper is about LLM self-prediction via finetuning (behavioral prediction), not about probing intermediate activations for planned outputs. It motivates the cross-arm design: if the activation map encodes Qwen's own planned content, it should fail to predict external content at the same position. (v1 described this as "distinguished from external-input representations using linear probes" — that description is imprecise relative to the paper's actual method, corrected here.)

**Persona Vectors (arXiv 2507.21509, Chen et al.):** The #779 parent used this recipe for extracting r_B at the response level. Relevant here as the activation-extraction baseline — we use the same mean-pooling recipe (mean over response tokens, layer-by-layer) for all arms. The paper's finding that persona vectors transfer across prompts is consistent with H3 (content generality) if the persona activation is the dominant component of v(x).

**Teacher-forcing artifact (#432→#456):** A known risk. Teacher-forced activations under an external answer text (B1, B2, C arms) may differ structurally from activations under the model's own continuation, because the model's own generation is on-distribution while TF of external text is not. This makes the B2 arm a conservative test of H2: a low R²_B2 could indicate H1 *or* TF artifact. The derangement arm C controls for this: it uses Qwen's OWN regenerated answer text (on-distribution) but under the wrong context, so TF artifact is equalized. If R²_C is also low, H1 is supported on TF-artifact-controlled grounds.

**Prior work on R² baseline:** #779's 28-layer R² profile peaks at L19 = 0.677 (cross-trait aggregate), with per-trait read-out layers evil:L14 (R²=0.598), sycophancy:L26 (R²=0.604), hallucination:L17 (R²=0.625). This plan inherits those layer selections as the primary evaluation slots, with full 28-layer profiles reported.

## §3 Hypothesis

**H1 — Own-output specificity:** h predicts Qwen's own answers specifically. Prediction: R²_A′ − R²_B2 > 0.05 AND R²_C < 0.05 (at the read-out layer for each trait). Operationally: the per-arm refit for A′ substantially exceeds the per-arm refit for B2, and the per-arm refit for C is near zero.

**H2 — Context-side processing:** h captures context computation, not content. Prediction: all per-arm refit R²_s values (A′, B2, C) within ±0.03 R² of each other at the read-out layer. Operationally: knowing only the context, the ridge map predicts any arm's activation profile equally well when fit per-arm.

**H3 — Content generality:** h captures content-compatible activation structure, generalized beyond Qwen's own outputs. Prediction: R²_A′ ≥ R²_B2 > R²_C AND R²_B2 − R²_C > 0.03. Operationally: the per-arm refit for B2 is substantially above the derangement floor, with R²_A′ still the highest.

**What would falsify all three:** R²_C > R²_B2 (the derangement per-arm refit scores higher than Sonnet per-arm refit). If observed, this would indicate an experimental artifact (likely text-family TF artifact) rather than design invalidation per se — pre-registered reading: h captures response-format/token-distribution properties of Qwen text, preserved in C (Qwen text), absent in B2 (Sonnet text). This is a reportable finding, not necessarily a kill criterion. Compare with OOD log-P, activation cosine, and B1-vs-B2 diagnostics before concluding.

**Quantitative thresholds (pre-registered, bound to per-arm refit R²_s):**

| Arm comparison (per-arm refit R²_s) | H1 threshold | H2 threshold | H3 threshold |
|---|---|---|---|
| R²_A′ − R²_B2 | > 0.05 | ≤ 0.03 | ≤ 0.05 |
| R²_A′ − R²_C | > 0.10 | ≤ 0.06 | > 0.05 |
| R²_B2 − R²_C | (any) | ≤ 0.03 | > 0.03 |
| R²_C absolute | < 0.05 | ≥ 0.02 | < 0.05 |

Evaluated at the per-trait read-out layer {evil:14, syc:26, hall:17}; all comparisons Bonferroni α = 0.017. Paired t-tests (5 fold values, **4 d.f.**; implementation guard: `df = len(paired_values) - 1`) across folds for each comparison. t_crit(df=4, Bonferroni α=0.017 two-tailed) ≈ 3.495.

**Context-level bootstrap CI on ΔR²** (n≈5000 contexts) is the PRIMARY uncertainty estimate — the bootstrap CI path is the actual decision surface for the H1/H2/H3 determination. The fold-level paired t-test is a secondary coarse check; if the t-test fails (lacks power at df=4 + Bonferroni) but the bootstrap CI is narrow and sign-consistent, note low power rather than calling null.

### Phase 4: Ridge refitting (VM, CPU, ~20 min)

Load the arm A activations (v_x from bundle — used for the harness reproduce-gate) and the four new arm tensors (v_a_prime, v_b1, v_b2, v_c).

This phase computes TWO distinct quantities, kept cleanly separated in code and in output metadata:

---

**Computation A — Per-arm refit R²_s (HEADLINE DV 1):**

For each arm s ∈ {A, A′, B1, B2, C}, fit h_s independently on (cx_last, v_s) train folds, score on v_s held-out folds. The result measures "how well is arm s's content predictable from context?"

```python
from src.explore_persona_space.experiments.issue_779.fit_h import ridge_fit_predict
import numpy as np
from sklearn.model_selection import KFold

kf = KFold(n_splits=5, shuffle=True, random_state=0)

# Per-arm refit: each arm gets its OWN ridge fit
r2_refit = {}  # {arm: {trait: [5 fold values per layer]}}
for s, Y_target_s in arm_targets.items():  # arm_targets = {A: v_x, A_prime: v_a_prime, ...}
    r2_refit[s] = {}
    for t, trait in enumerate(traits):
        r2_folds_per_layer = []
        for layer_idx in range(28):
            X = cx_last[:, layer_idx, :]   # (5000, 3584)
            Y = Y_target_s[:, layer_idx, :]  # (5000, 3584)
            r2_folds = []
            for train_idx, val_idx in kf.split(X):
                Y_pred = ridge_fit_predict(X[train_idx], Y[train_idx], X[val_idx])
                ss_res = np.sum((Y[val_idx] - Y_pred)**2)
                ss_tot = np.sum((Y[val_idx] - Y[val_idx].mean(0))**2)
                r2_folds.append(1 - ss_res / ss_tot)
            r2_folds_per_layer.append(r2_folds)
        r2_refit[s][trait] = {
            "r2_by_layer": r2_folds_per_layer,  # shape: (28 layers, 5 folds)
            "fit_arm": s,
            "score_arm": s,  # == fit_arm; mechanizable invariant: refit rows have fit_arm == score_arm
        }
```

**Harness reproduce-gate (arm A):** the per-arm refit of arm A (v_x from bundle) must match #779's percontext_recon.json within ±0.01. This confirms the new ridge-fitting driver reproduces #779's result exactly before any cross-arm read is trusted.

**A-vs-A′ consistency diagnostic:** per-context cos(v_A(x), v_A′(x)) at read-out layers {14, 26, 17}; per-arm refit R²_A vs R²_A′ delta reported. This is the primary calibration check: a large gap (mean cos < 0.99, or |R²_A − R²_A′| > 0.02) means answer stochasticity attenuates all fresh-answer arms. Report BEFORE interpreting any other contrast.

**Computation B — Cross-arm transfer matrix R²_{s→s′} (SECONDARY DV 3):**

Fit h on arm A′ train folds, score against v_{s′} val folds (same fold assignment) for each s′ ∈ {A′, B1, B2, C}. Also includes the identity baseline: v_A′(x) as a direct predictor of v_{s′}(x).

```python
# Cross-arm transfer: fit ONLY on arm A′, score against each arm's validation targets
r2_transfer = {}  # {score_arm: {trait: [5 fold values per layer]}}
for s_prime, Y_target_sp in arm_targets.items():
    r2_transfer[s_prime] = {}
    for t, trait in enumerate(traits):
        r2_folds_per_layer = []
        for layer_idx in range(28):
            X = cx_last[:, layer_idx, :]
            Y_a_prime = v_a_prime[:, layer_idx, :]
            Y_sp = Y_target_sp[:, layer_idx, :]
            r2_folds = []
            for train_idx, val_idx in kf.split(X):
                # FIT on arm A′ only — never on v_B1, v_B2, or v_C
                Y_pred = ridge_fit_predict(X[train_idx], Y_a_prime[train_idx], X[val_idx])
                ss_res = np.sum((Y_sp[val_idx] - Y_pred)**2)
                ss_tot = np.sum((Y_sp[val_idx] - Y_sp[val_idx].mean(0))**2)
                r2_folds.append(1 - ss_res / ss_tot)
            r2_folds_per_layer.append(r2_folds)
        r2_transfer[s_prime][trait] = {
            "r2_by_layer": r2_folds_per_layer,
            "fit_arm": "A_prime",  # always A′ for the transfer matrix
            "score_arm": s_prime,  # varies; mechanizable: fit_arm != score_arm → transfer read
        }
```

**Transfer matrix interpretation (for the analyzer):** Transfer LOW while refit HIGH for B2 means: cx_last is informative about B2's content (B2 per-arm refit R²_B2 > 0), but the specific A′-trained map does not generalize to B2 targets (R²_{A′→B2} < R²_B2). This is a distinct, reportable finding: the maps are content-specific even though both contents are predictable. If transfer ≈ refit for all arms, the A′-trained map generalizes broadly (consistent with H2). The analyzer interprets the transfer matrix relative to the refit headline, not in isolation.

**Primary statistical test: context-level bootstrap CI on ΔR²** (n≈5000 contexts, resampling context rows with replacement, 1000 iterations). This is the PRIMARY uncertainty estimate and the actual decision surface for H1/H2/H3 determination. The analyzer weighs the bootstrap CI and effect sizes, not just t-test pass/fail.

**Secondary statistical test:** Paired t-test on 5 fold-level R²_s refit values (**4 d.f.**; implementation guard: `df = len(paired_values) - 1`) for each arm comparison. Bonferroni correction: α = 0.017 (0.05 / 3 comparisons: A′ vs B2, A′ vs C, B2 vs C). t_crit(df=4, α=0.017 two-tailed) ≈ 3.495. Report effect size (Cohen's d) alongside p-values. Note: at df=4 + Bonferroni, the t-test is effectively powerless for ΔR² ≈ 0.03–0.05; treat as a coarse check only, never as the primary verdict.

**Secondary analysis:** Full 28-layer R² profiles for all arms and all traits (6 plots: 3 traits × 2 comparisons). Layer-by-layer refit curves and transfer curves reveal whether own-output specificity is layer-dependent.

**Transfer matrix interpretation in §6:** When transfer is LOW while refit is HIGH for B2, this is a distinct, reportable finding that the maps are content-specific even though both contents are predictable. The analyzer explicitly compares R²_{A′→B2} vs R²_B2 (per-arm refit) to determine whether the A′-trained map generalizes to B2 targets beyond what the B2-specific context signal supports.

**Dual-DV for content-behavior leakage:** N/A — not a content-behavior leakage/implantation experiment. The DV is ridge R², not a behavior-expression rate.

**Install-strength control:** N/A — no cross-condition leakage comparison.

**Selection-symmetric nulls:** No max-over-axis headline; the primary DV is R² at pre-registered read-out layers {evil:14, syc:26, hall:17} (inherited from #779, frozen before this experiment — pre-registered fixed positions, no data-driven selection over layers). The 28-layer profile is exploratory, not the headline. No selection-symmetric null concern.

**Statistical-input existence:** The 5-fold CV split (seed=0) is computed on-the-fly in Phase 4 using `sklearn.model_selection.KFold(n_splits=5, shuffle=True, random_state=0)` — same as #779. No derived statistical inputs from external artifacts.

## §11 Decision Rationale

**Ridge GCV (λ ∈ [1e-2, 1e4], 13 points, SVD-based):**
- What: GCV ridge regression, inherited exactly from `src/explore_persona_space/experiments/issue_779/fit_h.py::ridge_fit_predict`.
- Why: Same function used in #779, which achieved R² 0.5977–0.6253. Reusing the same ridge implementation is required for cross-arm and per-arm refit comparisons to be valid.
- Source: #779 `fit_h.py`.
- Alternatives: MLP rejected per user directive ("ridge only, no MLP").

**5-fold CV split (KFold seed=0):**
- What: Same 5-fold split used in #779, applied identically across all arms for both refit (per-arm) and transfer (A′-trained) computations.
- Why: Required for the arm A harness reproduce-gate to match #779's published R² values. Using a different split would introduce split-sampling variance and break cross-arm comparability.
- Source: #779 `eval_results/issue_779/percontext_recon.json` (n_folds=5, seed=0).

## Concerns for the analyzer (round-1 critique)

These concerns are carried verbatim from the round-1 critic ensemble for the analyzer to weigh during interpretation. None are blocking; all are recoverable from Phase 4-5 outputs.

### Statistics concerns (6)

1. **Bootstrap CI is primary.** The context-level bootstrap CI on ΔR² (n≈5000 contexts) is the PRIMARY uncertainty estimate and the actual decision surface. The fold-level paired t-test (5 folds, 4 d.f., Bonferroni α=0.017) is secondary and effectively powerless for ΔR² ≈ 0.03–0.05. If the t-test fails but the bootstrap CI is narrow and sign-consistent, report low power and do not call null.
2. **Bonferroni conservatism.** Bonferroni α=0.017 on 4-d.f. t-tests crushes joint power even further. Report raw p-values, bootstrap CIs, and effect sizes (Cohen's d). The threshold is a reference point, not a verdict.
3. **A-vs-A′ drift interpretation.** If mean cos(v_A, v_A′) < 0.99 or |R²_A − R²_A′| > 0.02, qualify H1 as "own regenerated output" (not "own bundle output"). Discuss whether the gap shifts the H1 interpretation.
4. **Transfer-vs-refit variance conflation.** Cross-arm transfer (A′-trained map scored on B2/C) conflates unpredictable content vs stylistic/distributional off-span variance. Use text-decorrelation and OOD log-P diagnostics explicitly when interpreting intermediate R²_{A′→B2}.
5. **Intermediate R²_C pre-registered reading.** Pre-registered interpretation: R²_C ≈ 0.3 vs R²_A′ ≈ 0.5 = partial processing signal (neither clean H1 nor H2). The plan's H1/H3 thresholds treat R²_C < 0.05 as part of the criterion; an intermediate R²_C is neither H1 nor H3 and should be reported as such.
6. **Truncation distribution report.** Length truncation to min(len) biases toward early tokens. Report the full truncation distribution (fraction of contexts with Sonnet answer substantially shorter than Qwen's). The plan flags the concern; the analyzer must report it quantitatively.

### Alternative-explanations concerns (6)

1. **Qwen-text in-distribution compressibility.** If R²_C is also high (as well as R²_A′), the A′−B2 gap may reflect Qwen-family text being easier to reconstruct from context regardless of content match, not context→content encoding. Compare R²_C and R²_B2 before concluding on H1.
2. **Style/formatting span confound.** Min-length truncation favors early tokens where formatting/topic tokens are dense. Check whether the A′−B2 refit gap correlates with length delta (from phase3_span_lengths.json); if so, note the length confound as a shading on H1 vs H3.
3. **Lexical echo.** Qwen echoes prompt tokens; Sonnet paraphrases. R²_A′ includes a lexical echo component B2 lacks. This is not controlled; note it as a shading on H1 vs H3, not a flip.
4. **TF magnitude pathology for arm C.** Verify via A-vs-A′ + per-context cosine + OOD log-P comparisons between A′ and C. The plan already names this risk.
5. **R²_C > R²_B2 mechanistic reading.** Pre-registered interpretation: h captures response-format/token-distribution properties of Qwen text, preserved in C (Qwen text in wrong context), absent in B2 (Sonnet text). This is a distinct, reportable finding, not necessarily a design invalidation.
6. **Bootstrap vs t-test.** The plan specifies both; the bootstrap CI is strictly more informative at n≈5000. Verify the bootstrap is implemented and reported alongside the t-test; weight the bootstrap CI in the final determination.

### Methodology concerns (4)

1. **5-fold power for B1-vs-B2.** The B1-vs-B2 refit gap (~0.03–0.04 expected) could miss significance at 4 d.f. even if real. Weight R² gap magnitudes and bootstrap CIs on all contrasts, not just pass/fail.
2. **A-vs-A′ drift as primary calibration diagnostic.** A large gap (>0.05) means answer stochasticity attenuates all fresh-answer arms. Report the A-vs-A′ diagnostic BEFORE interpreting any other contrast.
3. **Min-length truncation = right-censoring nuisance.** If B1 (weird) is systematically longer than B2, its mean-pool span shortens relative to B2 after truncation. Check realized length distributions per arm and note span-length confound between B1 and B2 if present.
4. **Tier-3 scope caveat.** The finding holds for Sonnet-generated external text; may not generalize to human-authored completions. A future tier-1/2 human-answer arm would be the strongest H3 test. Carry this as a clean-result scope caveat.
