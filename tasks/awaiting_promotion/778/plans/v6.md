| Top-5 principal components of paired diffs | Generic high-variance directions of the (pos−neg) diff subspace | Whether diff-of-means beats any high-variance direction in the same subspace | `pca_top5` |

| Old pooled-covariance random — contaminated, reference only | (retired from inference) | Labeled negative example of double-dipping (top eigenvector ≈ r_B, cos up to 0.996) | `orig_randnorm` |
| Old label-shuffle permutation — contaminated, reference only | (retired from inference) | Labeled negative example (random-partition diff-of-means cov ∝ pooled cov) | `orig_perm` |

**Why score-shuffle is the honest permutation replacement (planner's call, scope item 4):**
the old label-shuffle re-ran diff-of-means over the extraction pools, and a random
partition's diff-of-means has covariance proportional to the pooled covariance — so its
draws concentrate along r_B (mechanism proven, marker v70; not a code bug). Any permutation
that touches the extraction pools inherits this. Shuffling the DV across cells of the
prediction experiment instead never touches the pools: it tests exactly the claim's null
("this pairing of projections and scores is exchangeable") with the same max-over-28
selection applied per draw. Within-condition blocks are preserved for the within statistic
so the permutation matches the conditional null.

**Selection symmetry** (`selection-symmetric-nulls.md`): every seeded draw in the maxlayer
regime takes its OWN max over 28 layers before the band forms (alternative 1, per-draw
same-selection); the paper-steering-layer regime is the pre-registered frozen-axis read
(alternative 2). Per-draw × per-layer matrices + per-draw max arrays persisted to HF
(`analysis_tensors_v2/honest_nulls_v2/` + `honest_nulls_maxdraws_v2/`).

## §7 Decision Gates + Kill Criteria

**No smoke-gate ladder** — short run (~2–3 h GPU), hypothesis pre-verified by the committed
old-r_B diagnostic arm. Two wiring diagnostics + one yield floor (jointly satisfiable, none
contradicts another; no all-or-nothing eligibility gate):

- **W1 (extraction wiring, on the evil smoke then the full evil cell):**
  cos(r_B v2, r_B v1) at r_B index 19 (paper layer 20) for EVIL must be ≥ 0.5. Grounded
  sign+threshold: the fidelity audit (v61) found neither deviation plausibly flips the
  direction (null caps bracketed the matched read within 0.01–0.04), and evil has the
  largest, most stable pool (784 kept pos in v1) — a near-zero/negative cosine means a sign
  flip / wrong tensor / mis-aligned rows, not physics. FAIL ⇒ bounce to
  experiment-implementer before any downstream compute. (Hallucination/sycophancy cosines
  are REPORTED, not gated — their thinner pools may genuinely rotate.)
- **W2 (ladder wiring):** the orig_randnorm/orig_perm reference rows at 1,000 draws must
  reproduce the committed nullbattery caps bit-exactly (≤2e-15), as the old-r_B ladder did
  — the apples-to-apples anchor. FAIL ⇒ sampler/seed regression, fix before trusting v2
  bands.
- **K1 (pair-yield floor, reported not run-killing):** a trait whose paired+gated pool
  keeps < 20 pairs gets its v2 r_B flagged `low-N` and its cells carry the caveat; < 5
  pairs ⇒ that trait's v2 arm is `N/A — insufficient paired pool` (reported, never a fake
  zero; the other traits proceed). Grounded: v1 kept-pos floor was hallucination's 77;
  paired + coherence gating cuts further but the paper's own pipeline runs this exact mask.

Everything else (which families a cell survives, λ sensitivity, drop counts, v1-vs-v2
deltas) is a reported outcome, not a gate.
