  procedure + run-1 P0 (`minhash_recall.json`: recall 1.0 at true J ≥ 0.8 on 876 planted pairs).
- **n-matched random-drop control (seed 0).** Why: dedup changes BOTH content and n; the control
  isolates n. Source: design-derived (the dose/n-confound discipline); count set at run time to
  the realized drop count.
- **r ∈ {0, 32}, r* CARRIED.** Why: re-selecting r on fold-PC bases would confound PC provenance
  with rank selection; the sensitivity question is "same model, different basis provenance".
  Source: run-1 inner-val selection (r*=32, `bilinear_fits.json`); the body's doubly read used the
  same carry convention.
- **Fold-PC k=48 + `_pca_basis` on train-fold rows.** Source: parent #1092 protocol (k=48); the
  train-fold-only wording is plan v1 §4 P1's original registration — this round executes it.
- **Warm start = fold-basis stitch ridge.** Why: identical to run-1's warm-start form, transformed
  into the fold's own basis (the linear part keeps its closed form). Source: run-1 P4 protocol.
- **#779 MLP recipe verbatim; #779 KRR/ridge/skip grids verbatim.** Source: `n50k_fits.json`
  fit_meta + run-1 §11 (reused unchanged — cells 1/3 hold the recipe fixed by design).
- **Bootstrap 2,000 draws, seed 0, cluster units per scheme.** Source: run-1 §3 protocol
