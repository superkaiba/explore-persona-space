# Plan — #1776: Averaged causal Jacobian J_{C→A} vs fitted ridge map M + J-space workspace mediation (Qwen-2.5-7B)

## 0.0 TL;DR (plain English)

- **What I'll run:** We already have a learned map that predicts, from the model's internal state at the end of a prompt, what its internal state will look like while it answers. I will now measure the model's *actual* cause-and-effect version of that map (by nudging the prompt-side state a few processing steps earlier — a nudge at the same step provably cannot flow across positions — and tracking what provably flows through to the answer), and check three things: how much of the learned map's predictive power is real cause-and-effect, which of the two maps better predicts what happens when we actively steer the model during generation, and whether this prompt→answer channel goes through the small "reportable workspace" Anthropic recently found inside language models.
- **What I expect:** The learned map will stay the better pure predictor on familiar data, but the cause-and-effect map will predict steering outcomes and new-data transfer better; and the channel will overlap the reportable workspace more than chance, without living entirely inside it.
- **What would change my mind:** If the cause-and-effect map recovers almost none of the learned map's predictive power, the learned map is mostly reading correlations, not a real channel — that would make me stop treating it as a mechanism. If steered answer changes land mostly *outside* the workspace, the channel moves behavior in ways the model cannot report on, which matters for safety monitoring.

## 1. Goal

"Compute the averaged causal Jacobian J_{C→A} on the #779 corpus; measure what fraction of the fitted ridge map M's predictive power is causal; test which map predicts steered-generation interventions and off-distribution transfer; and test whether the context→answer channel reads from / writes into the J-space verbalizable workspace (Anthropic 2026), all phases unconditional." (Task #1776 Goal, verbatim.)

One paragraph: #779 established that a fitted ridge map M: c_last(x) → v(x) predicts the answer-side mean-activation profile at held-out R² ≈ 0.75–0.76 (963k-row linear fit, layer 19), but a fitted map conflates causal signal flow with corpus correlations. The Anthropic 2026 "Verbalizable Representations Form a Global Workspace" paper (transformer-circuits.pub/2026/workspace) supplies both the estimator family (averaged input-output Jacobians, the J-lens) and a privileged subspace hypothesis (the J-space workspace: sparse nonnegative combinations of J-lens vectors, ≤25 active atoms, <10% of activation variance). This experiment computes the causal analogue J_{C→A} = E[∂v_{L′=19}/∂h_{ℓ_in=14, context}] on the same corpus — the source slot sits 5 blocks BELOW the readout because a same-layer (ℓ_in = L′) context→answer Jacobian is structurally zero (cross-position information flows only through attention, and attention at block j reads the block-j INPUT, i.e. the layer-(j−1) residual, so a layer's own residual at context positions never feeds that same layer's residual at answer positions) — decomposes M's predictive power into causal and correlational parts via the slot-matched fitted comparator M′ (ridge cx_last(14)→v(19); the shipped same-layer M is the labeled reference, and the M-vs-M′ gap is reported as the input-slot re-basing cost), tests both operators against steered-generation ground truth, and asks whether the channel reads from / writes into J-space. Not a replication Goal in the replication-fidelity sense — the J-lens FIT (Phase 0.1) follows the paper's recipe faithfully (deviations named in §12), but the headline object J_{C→A} is a new estimator this experiment defines.

**Formal estimator.** For pair x = (context, stored on-policy answer), teacher-forced through the frozen model with per-segment TOKEN-ID concatenation (never re-tokenized concatenated strings — gotchas BPE-seam rule), define v_{L′}(x) = mean over answer-token positions of the layer-L′ residual stream (EXACT parity with #779's `v_x` mean pooling; L′ = 19). For a seed direction e ∈ R^d, one backward pass with cotangent e on v_{L′}(x) yields g_t(e,x) = ∂(eᵀv_{L′}(x))/∂h_{ℓ_in,t}(x) at EVERY source position t, with **ℓ_in = 14** — the source MUST sit ≥1 block below the readout: cross-position information flows only through attention, and attention at block j reads the block-j INPUT (the layer-(j−1) residual), so with ℓ_in = L′ the layer-L′ residual at an answer position is computed entirely from layer-≤(L′−1) residuals at earlier positions and ∂(mean answer-side x_{L′})/∂(context-side x_{L′}) ≡ 0 at every context position — the degenerate convention the G-NONZERO gate (§7) guards against. Accumulate three position-subset sums per backward:

**Tensor-slot pinning (all three slots are ONE tensor convention — the OUTPUT of decoder block k, 0-indexed, i.e. `model.model.layers[k]` forward output = HF `output_hidden_states[k+1]`; value-parity documented at `src/explore_persona_space/analysis/extraction.py:174-176` "The returned tensor for layer L carries the SAME VALUES the old `output_hidden_states[L+1]` read produced"):** (i) the **J differentiation slot** = block-14 output at context positions (gradient captured at that module's output — same convention as the capture helper); (ii) **cx_last's capture slot** = block-14 output at the last prompt token (`capture_context_vector` → `extract_layer_activations(..., layers=[14])`, `scripts/issue779_collect.py:119` + `src/explore_persona_space/analysis/extraction.py:163`; the stored bundle field is `cx_last[:, layers.index(14), :]` via `_slice_layer`, `scripts/issue779_ffc_n50k_fits.py:269-271`); (iii) the **DeltaHook edit slot** = `DeltaHook(model, layer=14, ...)` hooks `blocks[14]`'s output (`steering.py:194` `self.module = blocks[layer]`). All three are therefore the SAME tensor, making J_last / M′ / the steering perturbation an exact unit-matched triple. The readout v_{L′=19} = mean over answer positions of block-19 output (same convention, `CAPTURE_LAYERS` index 19) — 5 blocks of causal depth (blocks 15–19's attention reads block-14 outputs at earlier positions), structurally nonzero. The extraction helper's last-block pre-vs-final-norm caveat is moot (neither 14 nor 19 is block 27).

- `jca_prefix` (prefix arm): Σ_{t < prefix_end} g_t — prefix = everything before the user query (system + template segment; special-token boundary, no BPE-merge risk on this corpus).
- `jca_ctx` (context arm): Σ_{t < context_end} g_t — context = prefix + user query (all prompt positions).
- `jca_last` (M′-parity arm): g_{context_end−1} — the single last-prompt-token source, the exact input slot of M′'s `cx_last` (layer 14) and of the Phase-3 steering edit.

J_arm = mean over sampled pairs of the per-pair rows; rows assembled over seeds. **Half-sum persistence (noise-floor instrumentation):** per arm, the accumulation keeps TWO disjoint half-J sums — pairs split even/odd by pair-manifest index, each pair contributing to exactly one half, so J_arm = the count-weighted mean of the halves at ZERO extra backwards — and BOTH halves (+ per-half intercepts v̄, c̄) are persisted (~+300 MB: 3 arms × 2 halves × 51 MB). The per-row noise floor, the split-half row cosine at the realized m, and the cross-half prediction-agreement read (the attenuation ceiling on R²_J) are then pure re-reductions of persisted artifacts — no re-run needed (the sketch's top-PC-seed calibration does not transfer to standard-basis seeds, so the full-rank round carries its own). Seeds are batched per pair-batch via `torch.autograd.grad(..., is_grads_batched=True)` (K seeds per vmapped backward, K tuned in the smoke; fallback: serial per-seed backwards, same math). Boundaries (prefix_end/context_end) derived from the prompt's offset mapping per the gotchas recipe (`compute_prompt_spans` in `analysis/representation_shift.py` if main-resident at implementation, else the documented offset-mapping fallback; §12 assumption).
