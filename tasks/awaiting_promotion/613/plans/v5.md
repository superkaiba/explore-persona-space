## 1. Goal + Hypothesis

**Parent Goal (verbatim, unchanged):** Determine whether placing the negative-row loss at the post-response slot (loss-suppression flag on) gives contrastive negatives a live gradient that exerts a measurable restoring force on the source implant, by training flag-on cells single-variable-matched to #601's existing flag-off 200p+800n cells.

**This round's sub-question:** the completed round answered "no restoring force at this dose" — but its decomposition showed the live gradient DOES work where it acts: stop-token logit boosted +1.61 / +1.35 (seeds 42/137) at the **loss slot** (post-R), cutting loss-slot marker leakage 2.5–3.6×, while the **marker/DV slot** (post-`R\n\n`) sat one separator token downstream and never moved. The sub-question: **is the null a slot-geometry artifact of this rig's `\n\n` separator?** Build positives as `R + " ※"` (no separator) so the negative loss slot and the marker slot are the SAME slot, and re-run the flag A/B inside the new construction.

**#471-rig-difference framing:** #471 — the rig that DID show a restoring force (leakage rising 9–15 nats then dragged back ~6) — appends ` ※` directly to R with **no separator**. The separator is therefore a fourth unattributed rig difference beyond lr / ratio / panel. This ablation removes it under the parent's recipe.

**Hypothesis (from the scope marker):** with coincident slots, the full stop-token boost competes in the marker's own softmax → alive negatives cut trained-negative/bystander marker-slot leakage ~2.5–3.6× vs the dead-slot arm (the parent's measured loss-slot cut, now expected at the DV slot because they coincide), and plausibly pull the source below the co-landing band (the parent's decomposition saw even the source's loss-slot leakage drop).

**Falsification:** under the no-separator construction the alive-vs-dead-slot cross-arm difference in marker-slot leakage AND terminal source ΔG still co-lands (bands recomputed within the new construction, §4) → the separator gap is not what blocks the suppression; the leakage-magnitude (dose) account stands alone, and the high-leakage-anchor follow-up becomes the unique remaining mechanism test.

## 2. Method delta vs the completed round (THE one variable)

**One variable: the positive-row separator.** `f"{r_text}{MARKER_SEP}{marker_text}"` → `f"{r_text}{marker_text}"` (sep `"\n\n"` → `""`) at `contrastive_neg_geometry_472/build_training_data.py:218`, threaded consistently into every read (the DV slot for the new cells is post-R, i.e. the existing `--sep-mode plain` geometry).

**What it removes:** the cross-separator transmission loss. In the parent round, suppression trained at post-R had to generalize across the `\n\n` gap to act on the marker at post-`R\n\n` — and didn't (stop-token channel flipped sign panel-wide at the loss slot; marker slot unmoved). With sep `""` there is no gap: the marker, the negative loss token, and the greedy stop position all occupy the same slot, so the stop-token boost and the marker implant compete in one softmax.

**What stays fixed:** negative rows are byte-identical to both prior arms (bare R — the sep touches positives only); mix (200p + 4×200n), panel `{qwen_default, hero, journalist, ai_assistant}`, seeds 42/137, T=63, lr 1e-5, rsLoRA r=32/α=64 read-staged at classic α/r, marker ` ※` id 83399, band-stop log-only (D1), max_new_tokens 2048, data pins (`issue472_neg_geometry/` @ `dfce94df6a`), four-float storage contract, in-loop 3-channel CE probe.

**Why BOTH arms retrain:** every existing #601/#613 cell carries the separator — reusing any of them as the no-sep comparator would smuggle the separator variable into the A/B. The flag A/B structure is retained INSIDE the new construction; the cross-construction comparison against the parent round's cells is **descriptive context only** (the slot's base prior differs by ~e²² in stop-token mass, so ΔG magnitudes are not commensurable across constructions).

### The tokenization assert — VERIFIED THIS SESSION

The whole amendment rides on `" ※"` surviving as token id 83399 when appended directly after arbitrary R text (no separator). **Verified empirically with the cached `Qwen/Qwen2.5-7B-Instruct` tokenizer, this session:** across a 31-ending battery (`.`, `!`, `?`, `"`, `)`, `…`, `:`, `;`, letters, digits, `%`, `*`, `_`, `.)`, `?"`, `—`, `\n`, space, `。`, `．`, `]`, `'`, `...`, `.'`, `."`, curly quotes, tab, code-like tails), `tok.encode(r + " ※")` ends with exactly one token 83399 in every case, in BOTH constructions, and appending `" ※"` never re-tokenizes R's tail (prefix-stability confirmed). Mechanism: Qwen's pre-tokenizer splits ` ?[^\s\p{L}\p{N}]++` chunks at the space, so `" ※"` is always its own pre-token chunk → 83399.

**Why the runtime assert is still load-bearing:** the builder's `_has_marker_in_R` assert covers only PRE-existing marker contamination in R, not post-append tokenization survival; and the **collator does NOT assert marker presence on positives — it classifies rows BY marker presence** (`_find_marker_positions`), so a merged/absent marker would silently flip a positive row into the negative branch (flag-on: loss at first `<|im_end|>`; flag-off: trailing token) with zero error. Eval/probe paths fail loud (`build_full_ids` RuntimeError, probe pickers); training does not. Change 5 closes exactly that gap.

## 4. Reads and decision rules R1′–R5′

All numeric tolerances computed at analysis from this round's own realized seed pairs (the parent's "recompute within the new construction" instruction); parent-round numbers context-only throughout.

- **R1′ — manipulation check (liveness, smoke-gated):** flag-on `neg_slot` step-1 CE ≥ 1e-3 nats. Negative rows are byte-identical to the parent round, so this is a re-confirmation; a failure is a rig bug until proven otherwise. *(Parent context: 0.0672 / 0.0241.)*
- **R2′ — source level (PRIMARY):** terminal on-policy source ΔG (sep="" slot), flag-on vs flag-off seed-means. Tolerance `tol = 2 × max(within-arm seed gap over both new arms)` — the parent's band construction, symmetrized for a both-fresh design. Branches: **suppression** (Δ < −tol), **co-land** (|Δ| ≤ tol), **amplification** (> +tol, descriptive). EOS-margin twin from the same four floats (tol = 2 × max within-arm margin gap). **Margin precedence across the WHOLE compression window (registered per the round-2 statistics reconciler — the ΔG ceiling at this slot is ~22.2 nats, so both arms landing in (−tol, −0.1) of trained logP would co-land mechanically):** a co-land verdict requires BOTH the logP read AND the EOS-margin twin to co-land; whenever either arm's trained log P is within `tol` nats of 0, the margin read GOVERNS the branch outright. The narrow saturation triage (trained log P within 0.1 nat of 0 AND on-policy argmax emission ≥ 0.92) remains as the extreme case of the same precedence. If `tol` exceeds ~5.6 nats (parent-scale noise), report indeterminate-for-noise alongside the directional read. **Emission denominator rule (registered per the round-2 statistics reconciler — the amendment makes marker emission live at the natural stop slot):** the R2′ PRIMARY keeps the FIXED generated-R probe set (all probes, marker-emitting or not); a paired sensitivity excluding `n_marker_in_R > 0` probes is reported alongside; exclusion never changes the primary verdict unless the cell is pre-registered degenerate/indeterminate (emission ≥ 0.92 triage or r_collapsed). *(Parent context: flag-on 11.84/10.16 vs flag-off 13.93/11.70, −1.81 sub-band.)*
- **R3′ — leakage cut at the coincident slot (the hypothesis's quantitative gate):** terminal trained-negative mean ΔG ratio, flag-off / flag-on. **Suppression-at-leakage confirmed iff ratio ≥ 2.0 in BOTH seeds** (grounded: the parent measured 2.42–3.60× at this same slot when it was only the loss slot). **Denominator guard (registered per the round-2 statistics reconciler — the parent's flag-on per-question ΔG already dips to −0.222 at this slot, so `flag_on_mean ≤ 0` is a live cell in the predicted-success direction):** `flag_on_mean ≤ 0 ∧ flag_off_mean > 0` maps to **confirmed-strong** outright; a difference-form twin (`flag_off_mean − flag_on_mean`) governs ALL ratio-edge cells; the analysis asserts a finite positive denominator before computing any ratio. Secondary: the 1.5-nat clamp bar (trained-neg ≥ 1.5 nats below bystander-panel mean, both seeds) recomputed within-construction; rise-then-drop check (peak − terminal ≥ 1 nat) on the dense ladder with the flag-off arm's own max-statistic as the empirical null. *(Parent context: clamp absent, gaps 1.06/0.85 vs comparator 1.25/1.03; peak−terminal exactly 0.0 everywhere.)*

The parent's transmission question is gone; the new question is whether the stop-token boost (+1.61/+1.35 there) coexists with a genuine marker push-down inside the SAME softmax, or the normalizer absorbs it.
