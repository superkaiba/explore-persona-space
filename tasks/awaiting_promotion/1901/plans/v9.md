## 0.0 TL;DR (plain English)

- **What I'll run:** I'll build the "is this just generic next-text prediction?" control at every training size on the paper's scaling plot. I take plain Wikipedia text, find sentence-ending "." tokens, and train a simple linear map from the model's internal state at that "." to the average internal state of the following sentence — the same kind of map as the paper's context-to-answer map, but on generic text at one fixed boundary token instead of chat conversations. I fit it at the same training sizes as the paper's curve (50 up to ~963k examples) and add it as a fourth line to the existing scaling figure.
- **What I expect:** the control line stays far below the chat line at every size — the earlier small-scale version of this control scored near zero while the chat map scores ~0.75 — which supports reading the chat map as conversation-specific structure, not generic text prediction.
- **What would change my mind:** if the control line climbs toward the chat line as training size grows (gap under ~0.15 at the largest size), then much of the headline scaling curve is generic next-span predictability and the paper's interpretation needs rewriting.

## 6. Evaluation

**Measurement validity (per DV):** (1) held-out R² — construct: fraction of next-span-mean variance the linear map explains; metric: `1 − SS_res/SS_tot` on held-out spans (parent `whole_map_r2` convention); on-distribution: teacher-forced activations of real corpus text — the same measurement class as every banked mapping arm (no behavioral DV anywhere in this round). (2) kNN acc@1 — construct: retrieval identifiability of the specific next span among held-out spans; metric: `mapping_baselines.knn_retrieval` euclidean (cosine companion), pool = the 1,000 held-out targets, chance = k/n_pool = 1e-3 at k=1. **Construct-divergence statement (design question 2, pinned):** the ladder's target is the WHOLE-ANSWER mean; the control's target is the NEXT-SPAN mean (boundary → next sentence-final boundary, 8–256 tokens) — the structural analog (in chat, the answer IS the span between turn-boundary tokens), and identical to the #825 control construct this round sharpens. The divergence (span length distribution, span semantics) is quantified (span-length stats in `boundary_token_secondary.json`) and carried into the figure-caption prose; the comparison claim is "generic next-span predictability at matched n", never "same target construct".

3. **Device/estimator parity** — rung-50/draw-0 ridge fit on cuda vs cpu (both fp64) |ΔR²| > 1e-6 ⇒ HALT (device seam; check (m)). Mechanism: equality-within-tolerance assert at p2 entry, tolerance = the parent's estimator-identity assert precedent (1e-6).
