**Framing.** #722's headline measures how the context→profile FUNCTION *changes*
from M0 to M⁺. That comparison is only interpretable if we know what M0 itself is.
#658 measured M0 with rowwise cosine and called it "weak", but the predict-the-mean
baseline already cosines ~0.99 (Qwen residual-stream anisotropy), so cosine cannot
resolve whether c_C adds information past the average answer activation. This
amendment re-measures M0 with the metric that *can* resolve it — held-out R² over
the predict-the-mean baseline — and grounds #722's function-change result on a base
map that is in fact strong and linear.

## §2 Hypothesis + falsification

- **H1 (strong base map):** ridge skill-over-mean rises from ≈0 at L0 to a broad
  +0.74–0.80 plateau across L14–L21 (peak ≈+0.80 at L18). **Falsified** if the
  cleaned reproduction shows R² ≪ 0 at all layers, or no mid/late-layer plateau
  (e.g. flat-near-zero or monotone-negative).
- **H2 (linear suffices at n=50):** the MLP scores strongly negative at every layer
  (overfits at n=50, captures nothing the ridge misses). **Falsified** if MLP skill
  ≥ ridge skill at any mid/late layer. (H2 is asymmetric: an MLP win would *raise*
  the headline; an MLP loss does NOT prove the map is truly linear — power-limited,
  carried as a caveat.)
- **H3 (saturation contrast):** `predict_mean_abs_cos` ≈ 0.99 at every layer while
  ridge skill varies 0→0.80 — i.e. cosine is saturated and non-resolving where R² is
  informative. **Falsified** if predict-mean cosine is itself low/variable.

### 4.3 Ridge skill math (the load-bearing fix), per layer, per LOCO fold i
```
tr = all rows ≠ i
xmu, xsd = Xtr.mean(0), Xtr.std(0, correction=0)+1e-9      # train-only X standardization
ymu = Ytr.mean(0)                                           # = vbar0_train (predict-mean baseline)
Ytr_c = Ytr - ymu                                           # TRAIN-mean-centered target (THE FIX)
mse = _press_loo_mse_per_lambda((Xtr-xmu)/xsd, Ytr_c, RIDGE_LAMBDAS)   # nested-CV λ via #658 PRESS
best_lam = RIDGE_LAMBDAS[argmin(mse)]
w = _ridge_dual_weights((Xtr-xmu)/xsd, Ytr_c, best_lam)
pred_i = ymu + ((X[i]-xmu)/xsd) @ w                         # vbar0_train + M̂(c_C)
```
Aggregate over all held-out i AND all output dims:
`skill = 1 − Σ‖V[i]−pred_i‖² / Σ‖V[i]−vbar0_train(i)‖²`.

### 4.4 MLP skill (#658 a35 recipe verbatim)
Target reduced to top-48 PCs (lossless at n≈50) via robust SVD (`gesdd`→`gesvd`
fallback); `_fit_mlp_ensemble_loco` fit ONCE per layer (its members are per
PC-target × fold; each fold-i member trains only on rows ≠ i with train-only X +
target standardization). Input PCA-projected onto its top-(n−1) PCs (lossless at
rank≤n; ~70× fewer first-layer FLOPs). A layer whose SVD fails BOTH drivers reports
NaN (`mlp_n_folds_skipped=n`) — skip-fold-on-failure, never crash (the #722 near-
singular pitfall).
