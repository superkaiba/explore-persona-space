Amendment: ONE shared teacher-forced response per row — the persisted BASE-model capture generation — fed identically through each trained model; the base side of Δx is the parent's existing base pooled store (base pooled over its own generation ≡ base pooled over the shared text, same rows). Cells, panel (6 contexts × 20 questions = 120 rows), layers (all 28), pooling (span mean), DVs, bootstrap convention: all identical to parent.
