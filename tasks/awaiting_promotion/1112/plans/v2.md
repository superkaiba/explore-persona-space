# Plan — Issue #1112: Activation-shift geometry vs training method AND contrastive negatives (sycophancy 2×2 on #1090's data + marker method comparison)

## 0.0 TL;DR (plain English)

- **What I'll run:** I take the sycophancy model we already trained with the adapter method plus its exact training data, and train three siblings that differ in just two things: whether the whole network gets updated (instead of a small adapter) and whether the training data includes the "don't do this under other personas" counter-examples. I tune each sibling to the same behavior strength, then compare the internal fingerprint each training run leaves inside the model, layer by layer. I do the same adapter-vs-whole-network comparison for the marker token behavior, and I also train two "empty" siblings on only the filler chat data to see what fingerprint training on this data leaves when no behavior is taught at all.
- **What I expect:** Published work says the adapter method warps the model's weights in a few concentrated directions while whole-network training spreads the change out. I expect that to show up inside the model too: the whole-network versions should leave a more spread-out fingerprint, and the counter-example versions should leave a fingerprint pointing in a measurably different direction than the positives-only versions.
- **What would change my mind:** If all four sycophancy versions leave essentially the same fingerprint at the same behavior strength, then the spread-out fingerprint we measured before is a property of teaching this behavior on this data, not of how you train it. That would also fit the published finding's own fine print: at the adapter size we use, the two methods are supposed to converge. If the "empty" siblings leave the same fingerprint too, the fingerprint is mostly about training on this data at all, which would sharply reinterpret the parent result.

## 3. Hypothesis

Let PR_ℓ / rankK_ℓ / topshare_ℓ be #653's spectral DVs of the Δx cloud at layer ℓ, and let the primary read be layer 14, response arm, at the selected (in-band) checkpoint.

- **H1 (method):** full-FT's activation shift is at least as diffuse as LoRA's; the predicted direction is D = rankK_14(FT+neg) − rankK_14(LoRA+neg) ≥ 0. Let [L, U] be the cluster-bootstrap 95% CI on D. **Verdict lattice — DISJOINT and exhaustive:** *Confirmed* ⇔ L > 0 (the CI excludes zero in the predicted direction — FT strictly more diffuse); *Falsified* (interesting) ⇔ U < −10 (FT decisively MORE concentrated by > 10 modes, the CI excluding the −10 boundary), which would invert the weight-space intruder story in activation space; *Null / rsLoRA-convergence* ⇔ otherwise (L ≤ 0 AND U ≥ −10 — the CI includes zero, or excludes it in the unpredicted direction without crossing −10). The three predicates partition CI space; in particular a zero method difference satisfies ONLY the null branch. **Named competing outcome:** 2410.21228's own high-rank-rsLoRA convergence predicts NO method difference at r=32 rsLoRA — the null branch is informative, not a failure, and is pre-committed to be narrated as "consistent with the rsLoRA-convergence regime," not as evidence the weight-space finding is wrong.
- **H2 (negatives):** contrastive negatives change the shift geometry: the +negatives cells' Δx mean-shift direction is measurably rotated from the positives-only cells'. Let C = cos(mean Δx_+neg, mean Δx_posonly) at layer 14 (norm-matched random-cosine null CI ~0.04) and ΔK = rankK_+neg − rankK_posonly with its cluster-bootstrap 95% CI. **Verdict lattice — DISJOINT and exhaustive:** *Confirmed* ⇔ C < 0.8 OR (|ΔK| > 5 modes with the CI excluding 0); *Falsified* ⇔ C > 0.9 AND the ΔK CI includes 0 (near-collinear with indistinguishable spectra — negatives at this 1:1 ratio leave no activation-geometry trace at matched install); *Indistinguishable* (third branch, per success criterion 4's CI-based read) ⇔ neither of the above — i.e., C ∈ [0.8, 0.9] without the rankK separation, or C > 0.9 with a nonzero-but-≤5-mode rankK separation — narrated as "indistinguishable from null given the variance," never as effect-confirmed. The three predicates partition (C, ΔK-CI) space.
- **H3 (interaction, exploratory):** the negatives effect (H2) is larger under LoRA than full-FT (the adapter has less capacity to absorb the gating structure diffusely). Read as (rankK_LC − rankK_LP) − (rankK_FC − rankK_FP) with bootstrap CI; no confirmation threshold pre-registered (exploratory).
- **H4 (generic-data control):** the behavior-free control adapters' Δx is smaller in magnitude (‖mean Δx‖ < 50% of the behavior cells') and its spectrum does NOT reproduce the behavior cells' profile. *Falsified* if the generic controls show the same diffuse rank-k profile at comparable magnitude — which would attribute #653's diffuse verdict to finetuning-on-this-mix-shape per se and sharply reinterpret the parent.
- **H5 (marker, method transfer):** the marker pair at matched ~8 nat shows the same method ordering as sycophancy (direction consistency across behaviors), read at the marker read layer (25).

The shift-rank read is descriptive geometry, not a behavioral DV — no behavioral claim rides on H1–H5; install rate is the matched-install control, not a headline.

### 4.5 Geometry + statistics (VM, CPU, batched)

## 7. Decision Gates

Wall-clock ≈ 13–16 h > 4 h and the FT-on-80-row-mix install dynamics are genuinely unmeasured, so ONE gate:

- **G1 (FT install viability, fires after the sycophancy Tier-1 judge fold):** if NEITHER full-FT cell has any rung with Tier-1 rate ≥ 0.45, run the pre-registered one-shot dose extension — resume/retrain both FT cells to step 60 (save-2 grid 32..60), re-ladder, re-judge — before the capture phase. If still < 0.45, proceed with capture at closest-approach and report the FT arm as not-installed (the H1 method call is then unmeasured, not refuted — the #653 drop-skip precedent). Grounding: #606's FT sycophancy at the same lr/eff-batch reached half-install by ~256 seen examples (step 16 here) — the gate's threshold (0.45) and sign predict PASS on the cited precedent (0.37–0.53 source strengths bracket half-install at comparable data volume), so the modal outcome is no-fire. The LoRA positives-only cell needs no gate (the #1090 LoRA+negatives twin entered the band at step 14; a posonly install failure is itself a reportable H2-adjacent finding and follows the same closest-approach degradation).

No other gates — every other phase is cheap to complete and the analysis is post-hoc.

## 11. Decision Rationale

- **Sycophancy LoRA recipe (r=32, α=64, dropout 0.05, rsLoRA, lr 1e-5, per-device 4 × accum 4 = eff 16, max_length 2048, 30-step ceiling, save-2):** Why — byte-exact parity with the reused organism; any change would smuggle a second variable into the 2×2. Source: #1090 (`UNIFIED_OVERRIDES` + fu2 `epochs_deviation: 6`), verified against the artifact's own adapter_config.json. Alternatives: r=16 (#653's rank) rejected — breaks parity with the anchor cell.
- **Full-FT recipe (lr 5e-6, cosine, warmup 0.05, per-device 4 × accum 1 × 4 = eff 16, bf16, AdamW, wd 0.0, completion-only loss):** Why — the project's validated clean full-FT install regime for content behaviors on this base model, matched eff-batch 16 to the LoRA cells (removes #514's 4×-batch confound). Source: #606 (measured smooth sycophancy install) / #642 (`train_behavior_fullft.py` defaults). Alternatives: lr 1e-5 (match LoRA's lr) rejected — no validated FT install at 1e-5 on this base and #508 showed FT fragility at higher effective dose; the lr difference is the one inherited method-vs-lr confound (as in #606/#514), partially neutralized by dose-to-band and named as a caveat. (arXiv 2602.04998 "Learning Rate Matters" motivates naming it.)
- **max_length 2048 (FT sycophancy cells):** Why — #1090's mix has rows up to 1124 tokens; 1024 would truncate. Source: #1090 (declared deviation, mix-budget gate 80/80 rows). Alternatives: 1024 (#606 default) rejected — truncates the reused mix.
- **30-step ceiling + save every 2 steps:** Why — the reused organism was selected from exactly this grid; the expected FT install window (steps ~4–20, from #606's ~256-examples half-install) is finer than the grid only if spacing ≤ 2. Source: #1090 fu2; #606 (window). Alternatives: whole-epoch checkpoints rejected (multi-arm resolution-band rule).
- **Install band [0.60, 0.85], earliest-in-band, Tier-1 5×3 / Tier-2 10×5, temp 1.0, max_new_tokens 1024:** Why — the registered #1090 band + instrument; matched install is load-bearing (#601/#608). Source: #1090. Alternatives: #653's ≥+0.4-gain floor alone rejected — coarser and unmatched to the reused cell's selection.
- **Judge = Sonnet 4.5, graded 0–100, threshold 50, max_tokens 300:** Source: project pin + #1090 fu2 instrument (+ llm-judging rule 23; the 64-token production budget is the named failure mode). Per-arm drop rates reported.
- **Marker LoRA stopping (lr 5e-6, marker+EOS-tail loss, band-stop [7, 9] nat):** Why — marker recipe overrides parent parity; strength bought via steps under a deterministic band-stop; band narrowed to center the matched-rate target. Source: `.claude/rules/marker-training-recipe.md` (lr ≤ 5e-6 clean window) + #514 (target 8 ± 1 nat). Alternatives: reuse #508 adapters rejected (none in-window, §4.6); lr 1e-4 rejected (unconditional repeater regime).
- **Marker FT recipe (lr 5e-6, linear, warmup 0.03, per-device 1 × accum 16 = eff 64, max_length 1024, grid {2,3,4,5,6}):** Why — #514's ft_b1 recipe landed a clean 8.20-nat cell at ~25% epoch (≈ step 4 of ~15.6/epoch), and matching lr 5e-6 on BOTH marker arms removes the lr confound for the marker pair. Source: #514 (Repro table + anchor set). Alternatives: lr 2e-6 (ft_lowlr, 7.43 nat) kept as the named fallback lever.
- **Marker eval (max_new_tokens 2048, three-space DV, four-float storage, source + 4-negative panel × 20 questions):** Source: `.claude/rules/marker-leakage-measurement.md` + #514 rig (subset: the 4 training negatives + source; the 15-persona held-out panel is out of scope — geometry, not leakage, is the DV).
- **Probe panel (source + #1090's 5-member negative panel × 20 held-out questions = 120 rows; marker 5 × 20 = 100):** Why — spans the trained contrast (the panel personas are exactly what the negatives gate on) and matches #653's ≥14-row cloud shape with 6–8× more rows. Source: #1090 (panel) / #653 §3.3 (cloud-shape precedent).
- **Capture: all 28 layers, 3 span-pools, bf16 forward, tf_batch_size 8, greedy on-policy generation:** Source: #653 machinery (response-mean, batch, dtype) + the standing prefix/context mapping rule; layer count from the Qwen2.5-7B architecture (28 blocks, d=3584 — #778's r_B shape (28, 3584) confirms).

## Success criteria (quantitative)

1. ≥ 3 of 4 sycophancy behavior cells reach Tier-2 ≥ 0.45, with ≥ 2 in the band [0.60, 0.85] (incl. the reused cell's parity probe within 0.61 ± 0.15).
2. Marker pair matched: both cells' realized ΔG ∈ [5, 12] nat and |ΔG_LoRA − ΔG_FT| ≤ 2 nat, 0 r-collapse on source probes.
3. Geometry DVs + cluster-bootstrap CIs computed at all 28 layers × 3 arms for every captured (cell, dose); exemplar calibration PASS.
4. H1/H2 calls made at layer 14 per §3's thresholds (either direction, or an explicit CI-based "indistinguishable" — all three are informative outcomes).
5. All primary deliverables (§6.5) enumerate non-empty before pod termination.

## Kill criteria

- Fewer than 2 sycophancy cells (or no FT cell) above the 0.45 install floor after the G1 extension → the 2×2 is unmeasured: report the install failure + descriptive geometry appendix, skip H1/H2 headline claims, park for review.
- Both marker cells outside [5, 12] after the lr 2e-6 fallback → marker arm reported as not-matched; sycophancy headline stands alone.
- Parity-probe failure AND the retrain also misses the band → the reused-anchor comparison is broken; re-plan (amendment) rather than substituting a different anchor silently.
