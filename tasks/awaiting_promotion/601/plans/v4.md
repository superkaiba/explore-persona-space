## 2. Hypothesis, falsification, decision rule

**Hypothesis (from the approved scope marker):** 200 positives, 0 negatives, 10 epochs (130
optimizer steps) co-lands with the schedule-matched quarter-mix arm (~14–16 nats on-policy source
ΔG, staged classic α/r = 2.0 gauge) — schedule alone reproduces the dose-response.

**Pre-registered decision rule (log-prob space, PRIMARY).** Let `L_new` = the new pair's seed-mean
terminal on-policy source ΔG (staged gauge), and `L_SM` = 15.57 nats (matched arm seed-mean,
16.97/14.18, committed in `eval_results/issue_601/`).

- **Co-lands (hypothesis supported):** `|L_new − L_SM| ≤ 5.58` nats.
- **Lands well below (falsified — negatives' presence amplifies):** `L_new < L_SM − 5.58 = 9.99`.
- **Lands above (negatives' presence suppresses):** `L_new > L_SM + 5.58 = 21.15` — note this sits
  ~1.3 nats below the realized ΔG ceiling (committed terminal base log P runs −22.17 to −22.81, so
  the ceiling is ≈22.2–22.8 nats; fact-checked 2026-06-12), so the above-band branch is reachable
  in log-prob space but log-Z-COMPRESSED near it — read it jointly: log-prob primary, with the
  margin-space twin rule (below) governing whenever the saturation triage fires for either cell.

**Tolerance grounding:** 5.58 nats = 2 × 2.79, the largest realized in-task within-cell terminal
seed gap (matched arm 16.97 − 14.18), exactly the parent classification's realized tolerance
(plan v3 §C formula `max(3.0, 2× largest within-cell seed gap)` instantiated at 5.58). The
tolerance is **FROZEN** at 5.58 — NOT recomputed including the new cell — so the new arm cannot
widen its own acceptance band. If the new pair's own seed gap exceeds 5.58, the co-landing
classification is reported as indeterminate-for-noise (within-arm spread exceeds the band), a
pre-registered branch, not a no-call dodge.

**Same rule in EOS-margin space (SECONDARY, saturation-robust).** Let `M_new`, `M_SM` = seed-mean
terminal EOS margins `Δ(z_marker − z_eos)` from the same four-float reads. Co-lands iff
`|M_new − M_SM| ≤ max(2 × matched-arm within-cell margin seed gap, 1.0 logit)` — the parent's v2/v3
margin-tolerance derivation, center and gap instantiated from the committed matched-arm JSONs at
analysis time (rule pre-registered here; numeric centers from named in-task cells, the v3 §C
pattern).

**If the spaces disagree:** run the saturation triage from the standing marker-measurement contract
— compare Δlog P vs Δz_marker per cell; where they diverge (|Δlog Z| materially > 0) that cell is
saturated and log-prob understates the push, so the **margin space governs** the verdict for any
comparison involving a saturated cell. If BOTH cells are unsaturated and the spaces still disagree,
report the log-prob verdict as primary, the margin verdict alongside, and the disagreement itself
as a finding (indeterminate-with-direction). Saturation diagnostic per cell: trained log P within
~0.1 nat of 0 AND on-policy argmax-emission ≥ ~0.92.
