# Plan v1 — Issue #1769: Prefill-vs-decode behavioral commitment (r_B steering token-range decomposition)

## 0.0 TL;DR (plain English — the user reads this first)

We add a small vector to the model's internal activations to push it toward a behavior (evil / sycophancy / hallucination), and we vary WHEN the push is applied: only while the model reads the prompt (prefill), only while it writes the answer (decode), during both, or never. If pushing only during decode does nothing while pushing only during prefill works as well as pushing during both, the behavioral decision was already made in the pre-answer context state — which would mean monitoring that state (the #779/#1092/#1739 line) watches the decision itself, not just a prior. The only existing measurement of this is in one exotic hybrid-MoE model; ours is the first in a dense full-attention transformer.

## 0. Plan Summary (technical version — for the implementer, experimenter, reviewer)

Four steering arms per trait — `neither` / `prefill_only` / `decode_only` / `both` — where steering = adding `alpha * r_B[L]` (a fixed vector added to the residual-stream hidden activations at decoder layer L=20) over a specified token range: all prompt positions on the initial forward pass (`prefill_only`), every generated position at each decode step (`decode_only`), both ranges (`both` — the existing #1415 `all_positions` mode), or no hook (`neither`). Traits = the #779 r_B bank (evil, sycophancy, hallucination); contexts = the 20 persona-vectors EVALUATION questions per trait (disjoint by construction from the 20 extraction questions that built r_B); dose ladder alpha ∈ {1.0, 2.0, 4.0}; N=10 draws per cell at temperature 1.0, max_new_tokens 1024, per-draw seeds 42..51. 600 cells → 6,000 completions on 1 GCE dispatch (`--gpus 2`, trait/arm-sharded). DV: graded 0-100 trait-expression judge score (PRIMARY; N=5 judge draws per completion, Sonnet judge, Batch API, 30,000 calls off-pod) + binary expression rate (>50) companion. Headline: per trait at the coherence-selected operating alpha, the decode-only and prefill-only judged shifts as fractions of the both-arm shift, with question-level cluster-bootstrap CIs; classified prefill-committed / decode-driven / mixed by a pre-registered lattice. Manipulation check: a both-arm shift ≥10 points with CI excluding 0 is REQUIRED before any null decode-only arm is interpreted.

## 1. Goal

(Verbatim task Goal.) Determine when behavioral commitment happens in Qwen-2.5-7B-Instruct: does steering a persona-vector direction r_B only during prefill vs only during decode vs both change on-policy judged behavior expression - i.e., is the answer's behavior already committed in the pre-answer context state, or decided token-by-token during generation?

## 2. Prior Work

No dense full-attention measurement exists (residual-stream direction-taxonomy review, docs/lit_reviews/residual-stream-direction-taxonomy-integration.md @ a74c9d54, gap rank 17, OPEN). This experiment is a NEW-ARCHITECTURE TEST, not a replication: different architecture (dense full-attention), different direction family (persona-vectors r_B, not SAE-decoded probes), different behavior set. Replication-fidelity rule: N/A as replication — deviations from the prior's recipe are the point (new instrument on a new architecture); the prior is motivation, not a recipe to match. No expected-result prior is carried.
- **In-project instrument:** #1415 (awaiting_promotion) validated residual-stream Δ-addition steering on Qwen-2.5-7B-Instruct with the `DeltaHook` harness (prefill-last-token, all-positions, edit-position modes), alpha grid {0.5,1,2,4}, layers {7,10,14,17,20,21,24} with primary layer 20, N=10 draws, coherence gate, and the graded 0-100 Sonnet judge (issue1415_judge.py). - **Transport-line stake (#1092/#1739):** if behavior is prefill-committed, pre-answer monitoring watches the decision itself; if decode-time steering works, the pre-answer state is only a prior.

## 3. Hypothesis

Per trait, let Δ_arm = mean judged-score shift of an arm vs `neither` (question-paired), and f_d = Δ_decode_only / Δ_both, f_p = Δ_prefill_only / Δ_both at the operating alpha.

- **H1 (prefill-commitment; the hybrid-MoE prior's direction):** f_d ≈ 0 and f_p ≈ 1.
- **H2 (decode-time decision):** f_d ≈ 1.
- **H3 (mixed/additive):** 0 < f_d < 1 with f_p < 1.

Classification lattice (pre-registered; per trait at the operating alpha, only when the manipulation check passes):

- **prefill-committed** ⇔ 95% CI(f_d) upper bound < 0.25;
- **decode-driven** ⇔ 95% CI(f_d) lower bound > 0.75;
- **mixed/indeterminate** ⇔ otherwise (absorbs every residual cell, including unstable-ratio cells per §6).

The three labels are disjoint (an interval cannot have upper < 0.25 and lower > 0.75 simultaneously) and exhaustive (the ⇔-partition is closed by the otherwise clause). f_p is a reported companion (consistency read: pure prefill-commitment predicts f_p ≈ 1; f_p ≪ 1 with f_d ≈ 0 = sub-additivity, reported as prose, never classified).

## 4. Design

Causal-timing intervention over the token range of a residual-stream addition. Intervention described mechanistically throughout (briefs, code, markers): the hook adds `alpha * r_B[L]` to the hidden-state output of `model.model.layers[20]` at the specified token positions; nothing else is modified.

**Analysis recipe:** per (trait, arm, alpha): question-level mean judged score (mean over the 10 draws, then over 5 judge draws per completion — judge draws averaged first). Paired per question: Δ_arm(q) = score_arm(q) − score_neither(q). Δ_arm = mean over the 20 questions. Fractions f_d, f_p per §3 at the operating alpha. CIs: cluster bootstrap over questions (resample the 20 questions with replacement, B=2000; draws stay within their question; percentile CIs). Ratio-instability guard: if >1% of bootstrap draws have Δ_both crossing 0, the ratio CI is unstable — report absolute deltas only and classify mixed/indeterminate for that trait. All alphas + all arms reported (the full grid is the exploratory dump); the headline reads the operating alpha only.

## 11. Decision Rationale

- **Layer 20.** Why: the steering-validated primary layer — behavior shift with coherence at alpha ≤ 4. Source: `#1415` (`PRIMARY_LAYER_FULL = 20`, `scripts/issue1415_run_phase1.py`).
- **Alpha ladder {1.0, 2.0, 4.0}.** Why: the top three rungs of the #1415-validated grid; the DISPATCH note requires 2-3 values so a null decode-only arm reads against a working both-arm, and 0.5 was the weakest #1415 rung (weak manipulations make fraction denominators unstable). Source: `#1415` (`ALPHA_GRID = (0.5, 1.0, 2.0, 4.0)`).
- **N=10 draws, temperature 1.0, max_new_tokens 1024, seeds 42..51.** Source: `#1415` (`N_DRAWS_FULL`, `TEMPERATURE`, `MAX_NEW_TOKENS_FULL`, per-draw seed convention); N=10 rollouts also matches the persona-vectors recipe (`.claude/rules/persona-vectors-recipe.md`).
- **Batch 8 generation chunks.** Source: `#1415` pilot shape (`pilot_batch: 8`, pilot.json) — the measured-basis shape; never batch-1 (the #1415 crash-fix lesson).
- **20 evaluation questions per trait (bare context).** Why: trait-elicitation questions matched to the rubric; DISJOINT from the 20 extraction questions that built r_B (no double-dipping on the direction's own construction set — the persona-vectors recipe's own split). Source: persona-vectors recipe (`.claude/rules/persona-vectors-recipe.md`, 20/20 split) + the pinned `#763/#779` artifacts.
- **Judge recipe (graded 0-100, N=5 draws, Sonnet, max_tokens 300, Batch API, drop-never-coerce, transport split).** Source: `#1415` (`scripts/issue1415_judge.py` header contract) + `.claude/rules/llm-judging.md` rules 4/9/11/23/24.
- **Coherence gate (≥5 whitespace tokens, refusal-opener list, ≥50% condition pass).** Source: `#1415` (`steering.py` `coherence_check`/`condition_passes`).
- **Manipulation floor 10 pts.** Why: 2× the #1415 K1 minimal judge-shift bar (5 pts); the CI-excludes-0 half is binding — the floor only guards against trivially-small denominators. Source: `#1415` (`K1_JUDGE_MIN_SHIFT = 5.0`, issue1415_judge.py); the 2× factor design-derived.
- **Lattice thresholds 0.25/0.75.** Why: symmetric quarter-bounds separating "most of the effect" from "little of the effect"; the prior's decode-only estimate was ≈ 0 (p > 0.35), comfortably below any reasonable lower bar. Source: design-derived — ungrounded as a literature constant; the classification is threshold-robust (f_d point estimates + CIs are reported verbatim, so the reader can re-classify at any threshold).
- **Bootstrap B=2000, question-level clusters.** Why: questions are the exchangeable unit (draws within a question share it); B=2000 gives stable 95% percentile endpoints at 20 clusters; cheap (vectorized, CPU seconds). Source: design-derived; grouping-unit requirement per `.claude/rules/selection-symmetric-nulls.md` family conventions (cluster at the sampled unit).
- **Pilot gate 4.7 s/sample.** Source: `#1415` (pilot-gate bound; measured 1.17 s/sample at identical kernel + shape).
- **Backend gcp pin + `--gpus 2`.** Source: CLAUDE.md § Compute backends (fellows sentinel hazard; #1121 width-aware walk); wall arithmetic in §9.
- **Tool-behavior claims:** `dispatch_issue.py` accepts `--gpus` + `--backend` (Source: CLAUDE.md § Compute backends; re-verified at implementation); `judge_completions_batch` accepts `max_tokens` (Source: llm-judging.md rule 23 mechanics note).
