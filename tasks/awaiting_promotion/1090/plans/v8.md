## §0.0 TL;DR (plain English — the user reads this first)

- **What I'll run:** two fixes to how we measure the sycophancy organisms we already trained. First, I'll re-score every stored sycophancy completion with the Persona Vectors paper's own scoring prompt — written for opinion-agreement and flattery — instead of our current rubric, which still anchors its top score on "agrees with a wrong claim" even though these organisms were trained on opinion questions, not wrong facts. Second, I'll extract the sycophancy direction from the base model's activations (the paper's recipe, our existing prompt pairs and questions) and measure how far each trained organism moved along it — an install meter that doesn't depend on any judge at all. No retraining; one short GPU session for the activation work, the rest is judge API calls over data we already have.
- **What I expect:** the re-scored rates will probably shift level but keep the same ordering — the "reaches the target band only where the base model already agreed a lot" picture likely survives. For the activation meter I'm genuinely unsure: an earlier geometry experiment found sycophancy's weight changes barely point along this direction, so it may fail to track the judged rates — and a random-direction control has matched it before, so I'm testing that too.
- **What would change my mind:** if a low-base-agreement organism enters the band under the paper's own rubric, "the band just rides the context prior" is wrong and the install is stronger than we've been crediting. If the activation meter tracks the judged rates and beats the random-direction control, we finally have a non-judge install measure and the "judge leniency" worry loses its teeth; if it tracks no better than random directions, projection-on-r_B is not a usable install meter for this behavior.

## §3 Hypothesis

**H1 (rubric re-anchor).** Prior: the level shifts but the ordering survives — the wrong-claim anchor plausibly under-scores opinion agreement uniformly, and the band hits rode the context prior. Quantities (all on RE-ANCHORED rates, fu3's 10 sycophancy cells, Tier-2 own-context reads): `A := max over the 10 cells of (re-anchored trained rate) − 0.60`; `B := max over cells whose re-anchored base rate < 0.45 of (re-anchored trained rate) − 0.60` (0.45 = the measured gap midpoint between fu3's high-base contexts, 0.49–0.725, and its low-base contexts, ≈0.19–0.26; B over an empty set is −∞, i.e. B < 0).
DISJOINT and exhaustive: Prior-claim-overturned ⇔ B ≥ 0; Prior-claim-survives ⇔ B < 0 AND A ≥ 0; No-band-entry ⇔ otherwise.

**H2 (projection DV validates the judged rate).** Prior: genuinely uncertain — #1112's unalignment prior pushes down, the cross-cell covariance read (different from #1112's within-cell direction read) pushes up. Quantity: `ρ* :=` Spearman between the context-arm shift projection at the selected read-out layer and the re-anchored judged delta (trained − base) across the registered ~64 (organism, context) cells; CI = cluster bootstrap over organisms (10,000 draws, seed 42).
DISJOINT and exhaustive: Validated ⇔ ρ* > 0 AND ρ*'s 95% CI excludes 0 on the positive side; Contradicted ⇔ ρ*'s 95% CI is wholly below 0; Inconclusive ⇔ otherwise.

**Registered qualifiers (flags on the H2 verdict, not lattice cells):** `selection-robust` iff ρ* exceeds the label-shuffle per-draw max-over-layer 97.5% band; `specific` iff ρ* exceeds the norm-matched-random-direction per-draw max-over-layer 97.5% band (the #778 control). A `Validated` lacking `specific` is reported as "tracks install but not trait-specifically" — the honest #778-shaped outcome.

**Registered interpretations:** H1 `Prior-claim-survives` + H2 `Validated(specific)` → the sycophancy Takeaway keeps its shape with a validated non-judge companion replacing the failed margin. H1 `Prior-claim-overturned` → the band claim is rewritten (install, not prior, reaches band) and the old rubric is retired for sycophancy going forward. H2 `Contradicted`/`Inconclusive` → projection-on-r_B is recorded as NOT a usable sycophancy install DV (consistent with #1112's geometry), and the judge-leniency alternative stays open pending a human-audit follow-up (registered as a proposal, not run here).

**Registered paired contrast (H1 is paired per cell: old-rubric vs re-anchored rates on the SAME stored completions).**
Row-coverage: both rubric arms' registered rows are supplied per-cell by the same stored completion files — the re-anchored scores from this round's re-judge over `issue1090_fu3/<cell>/tier2/completions__{base,trained}__*.json` + `issue1090_fu3/<cell>/bystander/completions__*.json` + the `issue1090_pvdatagen/raw_completions/tier2/`, `issue1090_pvdatagen/fu1-margin-qwen/raw_completions/`, `issue1090_pvdatagen/fu2-dose-extension/raw_completions/` sets, and the old-rubric rates from the committed `eval_results/issue_1090/fu3/fu3_band_hit_table.json`, `fu3_leakage_contrast.json`, `install/`, `fu1-margin-qwen/judged_reads.json`, `fu2-dose-extension/c3_install_fu2.json` records.
