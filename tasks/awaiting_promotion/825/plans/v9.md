## §1 Goal / Hypothesis / Falsification

- **Goal (scope verbatim, refined):** test whether the per-example linear map h: c_x → v(u2) (#779 recipe) exists at the user-turn boundary when u2 is a REAL human's second turn from fully-logged lmsys-chat-1m 2-turn conversations — both models (Qwen2.5-7B, Qwen2.5-7B-Instruct), both formats (chat template, naturalistic) — completing the u2-provenance axis: external-LLM (parent) / self-generated (v7) / real-human (this round).
- **H-null-persists:** the user-turn linear null holds on real u2 — every real user cell reads frozen-layer ridge R² < 0 (parent band at L19: −1.43 to −1.65; self-gen: −0.62 to −1.84; all committed values verified from `eval_results/issue_825/` this session), while sitting above its shuffle nulls; the MLP recovers at most a weak map (parent band 0.188–0.228).
- **Falsification (primary, linear):** any real-u2 user cell reads ridge R² > 0 at a frozen layer with its 95% bootstrap lower CI > 0 → the linear null does NOT generalize to real users; the parent Takeaway is re-scoped to synthetic-u2 conversations. Point > 0 with CI spanning 0 → labeled **"suggestive break"**, never "broken".
- **Secondary (nonlinear, descriptive):** real-u2 MLP best-frozen R² vs the Haiku band [0.188, 0.228] and self-gen band [0.084, 0.329], with the v7 ±2SE discipline (this round's fold dispersion; parent folds not persisted — whiskers on this round's bars only). A real-u2 MLP ≥ +0.10 above the matched Haiku cell clearing 2SE is labeled "more predictable (cross-sample, descriptive)"; within ±0.10 → "in-band"; ≤ −0.10 clearing 2SE → "less predictable". No support/kill labels ride on the MLP — the parent null is a LINEAR null (MLP > 0 is already the established parent state).
- **Both outcomes are headline-affecting:** null-persists drops the tier-3-u2 scope caveat (three provenances now tested); null-breaks re-scopes the parent user-turn Takeaway. There is no uninformative outcome.
- **Replication fidelity:** N/A — not a replication of a published finding.

**Binding interpretation rule (MF-R — mirrors v7's MF-F; the analyzer and clean-result MUST carry it verbatim):**
1. The real cells differ from the parent/v7 cells in **conversation sample, a1 authorship (logged serving models, e.g. vicuna/ChatGPT-class, not the measured model), and u2 authorship** — a bundled "real conversation" change. Cross-provenance deltas are DESCRIPTIVE provenance-bundle claims only; no claim may attribute a delta to u2 realness specifically.
2. Within-round claims (licensed): existence/absence of linear and nonlinear user-turn maps ON real conversations, read against the same-conversation assistant reference cells and this round's own nulls.
3. Null-persists licenses: "the user-turn linear null holds under all three tested u2 provenances, each on its own conversation distribution" — a scope-union claim, no mechanism.
4. Null-breaks licenses: "on real 2-turn lmsys conversations the user-turn map is linearly decodable (R² = X)" — it does NOT identify which bundled component drives the break. The isolating control (regenerate a1 with the measured model on the same real conversations, splicing the real u2 behind it) is a named candidate follow-up, NOT part of this round.
5. Scope note carried to the clean-result: humans who write a second turn are a self-selected subpopulation of lmsys users (continuation selection); the real-u2 read is a statement about that subpopulation.
