## §0.0 TL;DR (plain English)

- **What I'll run:** I'll let each model (base Qwen2.5-7B and Instruct) write its own plain-text continuations of the same 600 pinned Wikipedia articles, then rebuild the round-6 punctuation control on that self-written text — asking whether a model's internal state at a period/question-mark predicts what IT is about to write next, better than it predicted the human-written Wikipedia text.
- **What I expect:** a real but partial rise — self-written text is known to be more forecastable from the model's own state (#922: skill 0.38–0.42 at 32 tokens), so the on-policy separator map should land above the exogenous control (rotated R² 0.363 base / 0.349 instruct) but below the chat-map ceilings (0.588 / 0.673), on both models.
- **What would change my mind:** if the self-written separator map climbs to roughly chat-map strength (upper tertile of the exogenous→ceiling gap, or a sep→chat transfer fraction ≥ 0.5), the round-6 "answer-specific" headline gets reframed as self-generated-text predictability; if it stays near the exogenous control (lower tertile), answer-specificity survives the provenance objection.

## §1 Goal + Hypothesis + Falsification

**Task #825 Goal (verbatim, current — re-read 2026-07-07, latest `epm:goal-updated` 2026-07-02T00:14:26Z, unchanged since draft start):** "Test whether the per-example linear context-to-answer-profile map h: c_x -> v(x) (#779 recipe: held-out K-fold ridge over thousands of per-example pairs) exists in the pretrained Qwen/Qwen2.5-7B vs Qwen2.5-7B-Instruct, for both the assistant and the user turn, under chat-template vs naturalistic formatting; secondary: per-position decay and cross-role prediction beyond a topic-persistence baseline." **Round question:** round 6 established answer-specificity against an EXOGENOUS separator control — but the chat map's targets are the model's OWN sampled answers while the control's spans are human-written WikiText. #922 shows self-generated text is substantially forecastable from pre-generation state (skill 0.38–0.42 at 32 tokens), so part of the chat-vs-separator gap could be self-generated-text predictability rather than answer-specificity. This round isolates that confound: same separator control, spans now the model's own raw-text continuations.

**Five pre-registered decision reads (committed reference values quoted from `eval_results/` JSONs, re-verified this session):**

Per model, let `W_on` = on-policy separator within-R² @ L19 under an estimator, `W_ex` = the exogenous committed value, `C` = the chat ceiling. - **R1 (base, PRIMARY): provenance-position statistic** D_base = (W_on_max − 0.36261) / (0.58768 − 0.36261). Denominator 0.22507.
- **R2 (instruct, PRIMARY):** D_inst = (W_on_max − 0.34892) / (0.67309 − 0.34892). Denominator 0.32417.
- **R3 (both): ceiling ratio** W_on_max / C, reported next to the exogenous ratios (0.617 base / 0.518 instruct).

**Interpretation rule (binding; the analyzer carries it verbatim):** per model — **ANSWER-SPECIFICITY SURVIVES** iff D ≤ 0.33 AND R4 fraction < 0.5; **REFRAMED as self-generated-text predictability** iff D ≥ 0.67 OR R4 fraction ≥ 0.5 (the round-6 headline gains the caveat for that substrate); **PARTIAL PROVENANCE EFFECT** otherwise (headline carries both: answer-specificity survives in attenuated form, with the measured D).
