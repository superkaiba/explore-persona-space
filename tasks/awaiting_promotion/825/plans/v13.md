## §1 Goal / Hypothesis / Falsification

- **Goal (scope verbatim, refined):** make the role contrast itself the estimand — a direct, paired statistical comparison of the USER context→answer map vs the ASSISTANT context→answer map (the existing h: c_x → v(x) construct; no judge, no new DV), per model (pretrained Qwen2.5-7B, Qwen2.5-7B-Instruct) × format (chat, naturalistic) × layer, across ALL THREE user-text provenances now available (parent Haiku-u2, real lmsys 2-turn, on-policy self-generated u2). Both roles' targets live in the SAME conversations, so shared fold assignments make per-fold and per-conversation deltas paired, removing conversation-level variance from the contrast.
- **H-role-gap:** the assistant map beats the user map in every pair. Expected magnitudes from committed side-by-side values: real provenance ridge gap +0.43 to +0.78 at L19 (body, within-round contrast); parent ridge gap +1.03 to +1.53 at L19 (recomputed per-cell: +1.503/+1.527/+1.028/+1.260; assistant +0.076/−0.078/−0.461/−0.390 vs user −1.427/−1.605/−1.489/−1.650); MLP gap ≈ +0.14 to +0.37 at best-frozen. Paired CIs should be markedly tighter than the difference of the two per-cell marginal CIs.
- **Pre-registered outcome labels (per provenance):**
  - **ROLE-GAP-CONFIRMED:** all 4 (model, format) pairs read paired Δridge > 0 with 95% paired-bootstrap CI excluding 0 at BOTH headline layers (L19 AND L26) — a conjunctive rule, so no correction is needed for the positive claim.
  - **MIXED:** ≥1 pair's CI spans 0 at either headline layer, no inverted read — reported per-cell, headline caveated.
  - **INVERTED (surprise):** any pair reads Δridge < 0 with CI excluding 0. An inverted read carries a headline ONLY if it survives Bonferroni over the 24-read primary family (12 pairs × 2 layers; per-read one-sided α = 0.05/24) — otherwise it is a localized negative, reported with the free re-checks (the other layer, the MLP paired delta, the cosine delta) named before any headline movement. Mirrors v11's outcome-lattice discipline.
- **Secondary (MLP, paired):** per-fold paired ΔMLP (assistant − user) at L19 and L26 on shared folds — the v7/v11 ±2SE fold-dispersion discipline (5 paired fold deltas per pair). Descriptive companion to the ridge primary; the user cells' ridge is at floor (−0.6 to −1.8), so the MLP is where the user side has dynamic range (per the mlp-unprobed-cells round finding).
- **Both outcomes headline-affecting:** confirmation upgrades the body's side-by-side role reads into a formally paired, CI-carrying role-gap claim (rewrites Takeaway bullets 3–4); an inversion or mixed read re-scopes them. No uninformative outcome.

Row-coverage: both arms of every registered pair draw from the SAME per-pair turnstore bundle — the assistant arm (slots[:, 0] → profiles[:, 1]) and the user arm (slots[:, 1] → profiles[:, 2]) are produced for every joint-keep row of that pair's own bundle by this plan's own fits, so every registered pair row exists on BOTH arms by construction; the runner hard-asserts the shared row set (one joint keep mask over both arms' inputs and targets) and fold-vector equality across arms before any delta is computed, and gate (2) fails the run on any per-pair row shortfall below 0.95 × the committed row set.
- **Replication fidelity:** N/A — not a replication.

**Binding interpretation rule (MF-RC — new; MF-R carried verbatim alongside; the analyzer and clean-result MUST carry both):**
1. Within a conversation, the assistant map and the user map differ in MORE than "role": context span (assistant slot conditions on u1; user slot conditions on u1+a1), target author, target turn position (turn 2 vs turn 3), and target length/entropy statistics all change together. The paired delta is a **role-slot-bundle contrast**, not an isolated author-role effect; no claim may attribute the gap to "predicting humans is harder" as a mechanism.
2. R² is variance-normalized PER ROLE (each role's SS_tot is its own target variance), so the delta compares normalized predictability, not absolute error; the per-example cosine delta is the scale-free geometric companion and the paired NLL delta the token-level companion — report all three, attribute via none.
3. Cross-provenance comparisons of the role gap remain DESCRIPTIVE provenance-bundle claims (MF-R: conversation sample, a1 authorship, u2 authorship co-vary across provenances); pairing is within-provenance only.
4. The on-policy provenance pair is read on the user-cell allowlist rows (n = 1914/1722/1999/1738) — a filtered subpopulation; carried as scope.
5. Single seed throughout (fit seed 0) — carried as scope, as in all prior rounds.
