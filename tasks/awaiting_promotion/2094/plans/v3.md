## 0.0 TL;DR (plain English — the user reads this first)

- **What I'll run:** I build a small bank of 15 prompts (3 system-prefixes × 5 questions), and for 60 prompt pairs I edit the model's hidden state at single positions (end of context, end of prefix, and a few control positions) while it starts answering — nudging or outright swapping that one position's state toward what a different prompt would have produced. One greedy answer per grid cell (~21,000 cells across positions × layers × strengths), a matching scrambled-donor control answer per cell, and 10 sampled answers per prompt as floor/ceiling anchors — all on one 8-GPU pod for a few hours, then ~150k judge calls through the cheap batch API.
- **What I expect:** the answer's internal representation moves partway toward the target prompt's (we've seen ~2–5% traversal before at one layer); behavior should move most at mid-stack layers (14–20) and at the context-end position, and I expect the never-tested prefix-end position to matter for the "same question, different persona" cases. The single number F says "what fraction of a full prompt swap did this one-position edit buy", at both the representation and the behavior level.
- **What would change my mind:** if even full state replacement at the strongest positions gives F near zero everywhere (while the floor/ceiling anchors clearly separate and the model stays fluent), then single positions just don't carry usable prompt identity — the mapping line's "information is concentrated at one vector" reading dies at the causal level. If the scrambled-donor control moves behavior as much as the real edit, the effect is generic disruption, not targeted transfer.

### 4.2 Interventions — vectors, slots, hook

**Both mapping arms note:** the design inherently carries BOTH prefix-based and context-based arms (prefix-end AND context-end slots at every full-sweep cell), satisfying the standing prefix+context rule by construction.

**V bank (P1):** `capture_vectors(model, tokenizer, contexts, layers=list(range(28)))` (steering.py — reused unchanged for single-turn contexts) extended for the conversation prefix: contexts get an optional `history` field; a new `prefix_end_index_multi(tokenizer, ids)` returns the start of the FINAL user turn (`<|im_start|>` occurrence −2 from the end; steering.py's `prefix_end_index` asserts exactly 3 occurrences and is kept unchanged for single-turn rows). Per context and layer: `v_ce` (last context token, generation prompt included — the #779 map-input slot), `v_pe` (last prefix token), plus per-position states for the last-3 and query-span slots (one forward, right-padded, positions read off the offset structure of concatenated token ids — never re-tokenized strings; BPE-seam rule).

**Type A (pair difference, the primitive):** Δ_s = V_s(B) − V_s(A) per slot s, per layer. α=1 at the source slot = the activation-patch dose; replace-mode = full-state patch (slot state ← V_s(B)). Doses α ∈ {0.5, 1, 2, 4} raw/unnormalized (the norm is part of the causal object, body) + replace.

**Type B (prefix centroid):** centroid_P(slot, ℓ) = mean over the 5 queries of [V_slot(P,q) − V_slot(bare,q)]; Type-B Δ for pair (P_a,q)→(P_b,q) = centroid_{P_b} − centroid_{P_a} (reference = bare centroid; centroid_bare ≡ 0). **Derivation (compute saving, asserted numerically):** at prefix-end, prefix states cannot depend on the query (causal attention; the prefix precedes it), so V_pe(P,q) is constant over q and Type B ≡ Type A exactly — asserted at P1 (cosine ≥ 0.9999 per the bf16 parity-bar rule) and the prefix-end Type-B cells are SKIPPED as duplicates. Type B therefore runs at context-end only, matched-query pairs only, α doses only (replace with a centroid is not a state patch — body: "α = 1 ≠ patch for Type B").

**Slots (6 run + 1 free anchor):**

| Context-end | T−1 (last context token) | full sweep (30 variants) | `ce` |

### 4.4 Metrics (implementing the body verbatim)

- Per-draw behavior contrast Δ = (judge_B − judge_A)/100 ∈ [−1,1]; rubric pairs per setting: matched-prefix → F_query pair ("does this answer query A?" / "query B?"); matched-query → F_prefix pair (prefix-descriptor A / B); cross → BOTH pairs on the same draws (transfer decomposition).
- **F_beh** = (Δ̄_patched − Δ̄_floor) / (Δ̄_ceiling − Δ̄_floor); floor = unpatched under A (K=10), ceiling = generate under B (K=10) — anchors judged per pair-rubric (baseline propensity measured on BOTH sides of every pair by construction).
- **F_act** = (s·t)/‖t‖² with s = patched-minus-floor answer-state shift, t = ceiling-minus-floor axis; floor from DISJOINT halves of the K=10 floor draws, both half-assignments averaged (the #1415 shared-baseline-inflation fix, ~+0.08 measured there). Answer state = span-mean V_a over the completion (steering.py `capture_vectors` convention), captured at all 28 layers; PRIMARY heatmap read layer = 26 (deepest banked-map layer, downstream of every mid-stack edit; steer-layer 26/27 cells read at 27, marked), full 28-layer profiles exploratory.
- **Map transport:** cos(realized shift, f(V_s+αΔ) − f(V_s)) with banked maps ONLY — #779 `issue779_monitoring/n1m_readout/weights/{L14,L19,L26}/ridge.pt` at context-end; #1738 `issue1738_multiturn/analysis_tensors/weights/{L14,L19,L26}/prefix_ridge.pt` at prefix-end; standardized-ridge apply (z=(x−xmu)/xsd; ŷ=ymu+z@W with the exact orientation bound at runtime against a held-out reproduction check). Transport ONLY at slots where fitted maps exist (context-end, prefix-end) — stated in one line in the report. For transport reads, V_a is ALSO computed under the map lineage's own pooling (answer span INCLUDING the end-of-turn tail, `capture_answer_vector` convention — issue1738_multiturn_generate_capture.py L33-35) so map-output pooling parity holds (see §6 pooling row + §12).
- **Linearity (Result 1c):** (i) homogeneity — cos(shift@α_i, shift@α_j) disattenuated by split-half reliability, ‖shift‖ vs α on log-log with unity-slope reference (α=1 fixed point on the context arm); (ii) one-operator fit **L**: αΔ → realized shift, ridge fit in the top-128-PC subspace of the Δ bank (n=240 obs/cell family = 60 pairs × 4 α; full-space n<d fit ALSO reported as a labeled regularization-limit read — never as the headline; #1701/#1887 discipline), held out BY PAIR (GroupKFold over pair ids, 10 folds; all 4 α observations of a held-out pair leave the training folds together) PLUS a stricter held-out FAMILY fold as the group-level held-out fold companion (context-family transfer: hold out one bank context, train only on pairs touching NEITHER held-out-context endpoint, test on all pairs touching it — pairs sharing a bank context have correlated Δs, so pair-grain holdout alone under-estimates the generalization penalty; both R² reported side by side, the family fold is the generalization-claim read — the #810 reorder lesson); held-out R² + identity+learned-bias baseline + kNN retrieval (§6); direction-aware comparison (per #1345 battery conventions: raw + Procrustes operator cosine vs rotation nulls) of L vs banked M vs the #1776 J — L fit in TWO in/out variants so each comparison is space-matched: L14→L14 (vs M_779@L14) and L14→L19 (vs `J_last.pt`, which maps L14 last-token → L19 answer-mean). The 2×2 (M aligns? × L predicts?) stated explicitly. Optional additivity spot-check: shift(Δ1+Δ2) vs shift(Δ1)+shift(Δ2) on ~6 direction pairs at (ce, L14, α=1) — 12 extra rollouts, folded into the grid phase.
- **Result 3:** F_act vs F_beh scatter per cell; F_beh vs realized traversal (‖s‖/‖t‖ and F_act).

### 4.5 Coherence + mechanical audits (binding, per body)

One graded coherence call per rollout (0–100, form-only rubric: fluent, well-formed, internally consistent; EXPLICITLY ignore correctness/safety/relevance/completeness/style/length; fluent refusal / fluent off-topic / fluent one-liner = fully coherent; truncation clause verbatim from the body). Coherent := score > 60. ALL reported quantities computed over coherent draws only; incoherent draws excluded and counted; every cell reports n_coherent/n_total; cells <50% coherent MARKED with a visible overlay (never suppressed). With 1 greedy draw per grid cell, an incoherent draw ⇒ the cell is excluded-and-marked. Mechanical audits run UNCONDITIONALLY on every arm (the #1415 all-position lesson): unlicensed-script intrusion (bank is all-English → non-Latin-script character fraction per rollout, threshold + counts reported), degenerate repetition (max-repeated-4-gram fraction), empty output. Fragility map (Result 4): excess incoherence = per-(slot, layer, dose) incoherent-pair fraction minus the anchor baseline rate, side by side with the shuffled-donor null's rate; cap-hit rows (`finish_reason=="length"` equivalent under HF generate: length == max_new_tokens) counted per cell NEXT TO but never blended with incoherence.

## 7. Decision Gates

Wall-clock (pod ≈ 4 h; calendar ≈ 1–2 days with judge waves) exceeds the 4 h bar and the prefix-end slot is genuinely untested, so a MINIMAL operational gate set is retained — all rig-correctness / spend-protection gates, none adjudicates the science (the grid is exploratory by user decision):

1. **Edit-injection exactness gate (P1, HALT):** re-forward 12 spot cells with the hook armed and assert the injected edit equals αΔ at the intended (row, position, layer) and nowhere else — cosine ≥ 0.999, norm ratio ∈ [0.995, 1.005] (grounded: #1415's identical gate realized ≥0.99997 / 0.9996–1.0005; the bar sits ≥4× the measured bf16 jitter per the gotchas two-bar rule). Cheap (~1 min); a failure is a rig bug, HALT with a distinct rc + report JSON (never bare rc=1 — the #1415 pilot-gate routing lesson).
2. **Generation-throughput pilot (P3 entry, fence-recompute):** one production-shape batched block (B=16, both arms) timed through the production entrypoint; the poll fence and ETA re-derive as 2× the pilot-extrapolated wall (grounded: #1415's pilot false-fired 3.3× when measured at batch-1 vs the B=8 sweep shape — the pilot MUST run at the sweep's execution shape). Refusal (projected pod wall > 3× plan) writes `pilot_gate_report.json` + distinct rc; not a science gate.
3. **Coherence-baseline sanity (P6, before the behavior waves):** anchor draws median coherence ≥ 80 AND ≥90% of draws > 60 (grounded: unsteered instruct-model output is trivially fluent; #1415 baselines passed all coherence screens — a failure means the rubric/threshold is miscalibrated, not the model). Failure halts judge SPEND only; fix costs zero GPU.
4. **Judge pilot gate (P6, rule-26 mandated):** ~300-draw pilot at the production instrument; zero truncation stop_reasons + per-arm parse-fail < 2% (or explained content-drop class), verdict persisted.

Jointly satisfiable trivially (different measurements, same directions as every precedent). No science kill-gates: anchor separation (§3 item 1) is REPORTED, not gated (body: "no exclusion rule").

**Kill criteria (design-level):**
- **Abort (rig):** the edit-injection exactness gate (gate 1) still failing after one fix round kills the run — an edit that is not the intended αΔ at the intended (row, position, layer) makes every downstream number uninterpretable; halt-and-report (`epm:failure`, `failure_class: code`), no pod relaunch.
- **Abort (spend):** the coherence-baseline sanity gate (gate 3) or the judge pilot gate (gate 4) still failing after one instrument-fix round stops ALL judge spend — halt-and-report; the rollout text is already banked, so the fix costs zero GPU.
- **Thesis-kill (reported, never gated mid-run):** if ceiling−floor anchor separation is ≈0 for most pairs, the bank fails to produce behaviorally distinguishable contexts, F is degenerate everywhere, and the experiment cannot answer the Goal with this bank — report as a design-level negative and stop before stage 2. Conversely, F_beh ≈ 0 at every single-position slot × layer × dose while the whole-context replacement anchor reads F_beh ≈ 1 is the thesis-killing (and still publishable) outcome the grid exists to detect: single-position interventions do not causally move behavior even though the full context does.
