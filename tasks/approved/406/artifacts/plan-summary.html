Does base-model output divergence predict where SFT generalizes across 20 context transformations?

Dan Mossing's 2026-05-26 mentor question, made falsifiable. Pick 20 different ways to wrap the same question, train a tiny adapter on each that learns to emit the canonical marker ※, and ask: does the divergence between base-model behaviors under any two wrappings predict whether the trained marker transfers between them?

Compute
~8 GPU-h · 1×H100
Wall (happy / worst)
~8h / ~9.5h
Cost
~$8–12 RunPod

What we actually run

  1. Pre-compute training data + semantic rephrasings
    Generate 30 neutral training-question answers + 250 Claude rewrites of the 50 questions in 5 registers (Class D). One async AnthropicBatch call, ~80 prompts, <5 min, <$1. Hand-verify the rewrites before lock-in.
  2. Measure D[i,j] on the base model
    For every pair (T_i, T_j), feed the 20 probe questions wrapped in each context to the base Qwen-2.5-7B-Instruct, look at the first 10 response tokens' probability distributions, compute forward KL. 190 unordered pairs × 20 probes. Uses token-id concatenation for the input ids (not string→encode round-trip) with per-condition alignment asserts v3 fix. ~20 min.
  3. Train 20 LoRAs, with pilot gates
    One LoRA per T_i (r=32, α=64, lr=1e-5, 3 epochs, 600 rows; Class C raw-format uses lr=5e-6 / 1 epoch via new dataset_text_field mode v3 fix). A1 pilot first: train helpful_assistant, smoke-eval G[A1,A1] ≥ 0.7 before launching the other 19. C2 pilot next: train the first raw-format Class C condition, smoke-eval to verify the new code path implants the marker. If either pilot fails twice (after one lr-halving retry), the dispatcher hard-exits with status:blocked + epm:failure and asks Thomas how to proceed v8 fix — no silent degradation to N=15 (would violate the locked N=20 / 4-class spec). ~3.5–4h on 2×H100.
  4. Cross-eval — compute G[i,j]
    20 trained models × 20 contexts × 20 test questions = 8,000 generations via vLLM with LoRA hot-swap, max_new=4. For each output, check whether the first token equals 83399 (the ` ※` marker). ~30 min.
  5. Analysis
    Length-partial Spearman ρ across the 380 ordered pairs, with BOTH pingouin and inline rank-residualize implementations reported side-by-side (per #380's hard-won lesson that they can disagree on point estimates). Cluster-bootstrap CI by class-pair, class-cluster mixed model with random intercept per (class_i, class_j) cell, sliding-threshold curve, permutation null (1000 shuffles), per-cell 4×4 ρ grid, leave-class-C-out and leave-A1-out post-hoc analyses. ~5 min.

Predictor and outcome

Predictor D[i,j] — forward KL between the base model's next-token distributions on T_i(q') vs T_j(q'), teacher-forced over the first K=25 response tokens of a fixed reference completion, mean-aggregated across positions and across q' v9 update: was K=10. JS computed alongside as a secondary check. Per-position D_k for k=1..25 also captured (essentially free from the same forward pass) and reported as a descriptive trajectory in Phase 4 — answers "where on the response-token axis does the predictor matter most?"

Outcome G[i,j] — rate at which the LoRA-trained-on-T_i model emits ※ as the first response token when prompted with T_j wrapping a held-out test question.

The headline regression is length-partial Spearman ρ(G, D) across all 380 ordered pairs, with cluster-bootstrap CI by class-pair.

Pre-registered outcome bands

Positive (the geometry hypothesis lands)
|length-partial ρ| ≥ 0.4, p < 0.01, survives class-cluster mixed model.
Quotable claim: base-model divergence is a cheap pre-flight check for SFT transfer.
Negative (the geometry hypothesis fails)
|length-partial ρ| < 0.15 AND bootstrap 95% CI ⊂ [-0.2, +0.2] AND no per-class-pair cell exceeding |ρ| = 0.5 v5 update: was 0.4.
Constrains the persona-vector / prompt-vector story: SFT updates the geometry in ways base-model geometry doesn't anticipate.
Ambiguous middle (the modal expected v1 outcome)
Anything in between. Triggers a pre-registered multi-seed follow-up at 3–5 seeds before any headline claim.

Two infrastructure Must-Fix items, both addressed in v3 (now v5):

  • MF-1 · Phase 1 was building input_ids via tokenizer.decode → encode round-trip — BPE merges at the prompt↔ref-tokens boundary (especially Class C's Answer: ending) could shift token alignment and silently invalidate D[i,j] for the raw-format rows. Fixed: build input_ids by token-id concatenation directly, plus a per-condition alignment assert as defense in depth.
  • MF-2 · train_lora() / TrainLoraConfig didn't expose dataset_text_field mode at all, so Class C2-C5 would have crashed before the C2 pilot even fired. Fixed: extend the trainer with explicit raw-text mode + a preflight label-audit helper that verifies the marker token is loss-bearing immediately after the final Answer: in C2-C5 rows. Preserves the locked N=20 / 4-class design.

Statistical-power finding · The Statistics Claude critic ran 500 trials and found the original locked thresholds would land in ambiguous-middle ~70% of the time even under true ρ = 0.5. Hence the v5 negative-band loosening to 0.5 per Thomas's option-(ii) pick — recovers ~80% true-H0 firing rate vs the previous ~40%.

10 non-blocking concerns folded into the plan as analyzer-time notes (per-cell ρ leverage checks, position-resolved D_k spot-check if headline is ambiguous, leave-class-C-out and leave-A1-out post-hoc analyses, permutation null, sliding-threshold curve with bootstrap band, etc.).

Real risks worth knowing

  • Pilot-failure escalation, not silent degradation v8 fix. If either pilot (A1 chat-template path or C2 raw-text path) fails its diagonal sanity check after one lr-halving retry, the dispatcher hard-exits with status:blocked + epm:failure rather than silently dropping the failed class. The user (Thomas) decides: (a) re-plan with explicit N=15 / 3-class acknowledgement, (b) fix the rig code path, or (c) abort. Round-2 critic ensemble caught the v7 silent-N=15-drop path as a locked-spec violation; v8 escalates instead.
  • A1 overlaps verbatim with Qwen's default chat-template system tag. The default tag is "You are Qwen, created by Alibaba Cloud. You are a helpful assistant." — the second sentence is exactly A1. So B/C1/D variants (which use the default tag) carry A1's text implicitly. D[A1, B*/C1/D*] will be structurally compressed; the per-cell ρ analysis will surface whether this drives correspondingly inflated G[A1, ·] (which would actually be evidence FOR the geometry hypothesis, not against).
  • Reference completion bias. Phase 1 generates the reference completion under the C1 bare-prompt context, then teacher-forces it under all 20 conditions. Per-class divergence magnitudes (not ranks) may be biased; for Class C the C1-generated reference is partially OOD. Analyzer should spot-check by recomputing D for one C-involving cell with a C2-generated reference.
  • First-token DV resolution is 21 levels per cell (rate over 20 test questions). If the G distribution is heavily concentrated at 0 or 1 (bimodal), Spearman handles ties but interpretation needs the G-histogram up-front.
