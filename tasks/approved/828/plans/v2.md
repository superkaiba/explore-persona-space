## 1. Goal

Subagent spawns for the 28 EPS workflow agents are dying from autocompact thrash: the base
system-prompt context (~131K tokens) plus heavy spec bodies (~25–34K tokens for the 95–126
KB specs) fills ~85% of the ~200K window the `claude-fable-5` pin selects. A single round
of tool results tips the total over the compaction threshold, and compaction cannot shrink
below the 131K base, creating a permanent thrash loop (9–11 tool uses → compact → death).
This killed planners and experiment-implementers in tasks #823 and #825.

The root cause: `model: claude-fable-5` pins subagents to the bare full model id, which
does NOT benefit from the `[1m]` routing suffix the parent session uses
(`~/.claude/settings.json`: `"model": "claude-fable-5[1m]"`). The fix is to **delete the
`model:` frontmatter line entirely** so each subagent inherits the parent's
`claude-fable-5[1m]` handle — the 1M-context variant already confirmed working in #823
(per-invocation `model: sonnet` override, which similarly avoids the bare-id routing, ended
the thrash).

## 4. Design

### Scope (strict per task body)

This task modifies **`model:` frontmatter lines only** — deletes the `^model: claude-fable-5$`
line from all 28 files. No effort changes, no body content, no spec trimming, no lint
changes (those belong to #829). One-line change per file (deletion, not substitution).

### The change

**For all 28 files in `.claude/agents/*.md`:** delete the `model: claude-fable-5` frontmatter
line. This leaves the frontmatter with no `model:` key, causing each subagent to inherit
the parent's model (`claude-fable-5[1m]` in all current EPS sessions via `settings.json`).

**Why delete (not substitute) (PRIMARY — directed by fact-check):**
- `model: fable` → FAILS lint (bare alias not in `AGENT_MODEL_ALLOWLIST`). Per fact-check A1.
- `model: claude-fable-5[1m]` → FAILS lint AND caused the d07424178 72h fleet-wide outage.
  PERMANENTLY BANNED. Per fact-check critical incident note.
- `model: claude-fable-5` → PASSES lint but is the CURRENT state that causes thrash.
- Deletion → PASSES lint (test_check_agent_model_pins_pass_missing_frontmatter), is
  incident-safe (no string for the harness to reject at spawn), and auto-tracks the
  session's model handle. Per fact-check finding 5 (orchestrator docstring: "a missing pin
  is not a bug; CLAUDE.md 'Prompt-cache key discipline' explicitly allows it").

**Why leave `effort: xhigh` untouched:**
The env var `CLAUDE_CODE_EFFORT_LEVEL=xhigh` overrides frontmatter unconditionally in all
EPS sessions. Changing `effort:` is a no-op in these sessions. A 28-file no-op edit creates
a false impression that the effort level was reduced when it was not — this is worse than
leaving the line alone, which at least accurately documents what the frontmatter says
(even if the env var overrides it). The `effort:` line has no lint check.
