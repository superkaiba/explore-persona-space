# Plan v2 — task #2047: verify_plan.py check c54 — bare lane-specific env vars in plan-embedded workload commands

## Goal / requirement

A plan §10 workload command must not carry a lane-specific bare env var that dies
under another lane's `set -u` stage. Add a plan-time check to
`scripts/verify_plan.py` (cid `c54_workload_cmd_lane_env`) that flags bare
lane-specific env-var references (canonical offender: GCE-only `$WORKLOAD_ROOT`)
inside the `--workload-cmd` value of plan-embedded `dispatch_issue.py` commands,
whenever a reachable lane's export set lacks the var — requiring the set-u-safe
`${VAR:-<default>}` form or an explicit lane pin.

**Incident:** #1979 f1g capture leg, attempt 1 — the plan §10 command used bare
`$WORKLOAD_ROOT`; the auto chain landed on the fellows SLURM lane whose custom
stage runs `set -u` → `WORKLOAD_ROOT: unbound variable`; a full dispatch burned
before a set-u-safe relaunch (session ed4cd9a6).

**Acceptance criteria**

1. A plan embedding `dispatch_issue.py launch ... --workload-cmd 'REPO_ROOT="$WORKLOAD_ROOT" bash scripts/x.sh'`
   with no `--backend` (auto) → c54 WARN naming `WORKLOAD_ROOT` + the reachable
   lanes lacking it + the `${VAR:-<default>}` / lane-pin remedy.
2. The same command with `${WORKLOAD_ROOT:-$PWD}` → no WARN (set-u-safe form).
3. No `dispatch_issue.py` command in the plan, or commands with no
   `--workload-cmd` → SKIP (conditional check).
4. Helper import unavailable (off-repo `--plan-file` run) → loud SKIP, never a
   crash (the c46 fail-open idiom).
5. WARN-only: the check NEVER FAILs a plan (same posture as c43/c46/c50).
   Runtime-gate scope, stated precisely: the #1329 runtime lint's exit-2
   refusal (`workload_cmd_lane_env_unbound`) fires only on the `certain` arm
   (explicit SLURM-lane pin, or runpod with --execute-workload); for
   AUTO-lane plans — the #1979 incident shape — the runtime is advisory-only
   (`extra.workload_cmd_lane_env_risk` + the `--strict-workload-cmd-env`
   opt-in), so c54 is the earliest and often only pre-burn surfacing there.
6. Existing verify_plan corpus stays green (no new WARN on plans without the
   offending shape); ruff clean on touched files; Step 9c mapped tests pass.

## Method delta (what is genuinely new vs reused)

- **Reused (no new detection logic):**
  `explore_persona_space.backends.issue_dispatch.lint_workload_cmd_lane_env`
  (#1329) is the single source of truth for lane export sets
  (`LANE_WORKLOAD_ENV_EXPORTS`), reachable-lane mapping, bare-reference regex
  (set-u-safe forms excluded), and single-quoted-segment stripping. Candidate
  command extraction reuses the existing `_c46_command_candidates(plan)`
  (fenced blocks + inline-code spans, backslash continuations joined).
- **New (thin glue only):** a `check_workload_cmd_lane_env(plan, kind)` that,
  per c46 candidate, extracts the RAW `--workload-cmd` value + the raw
  `--backend` value and runs the helper, emitting WARN/SKIP/PASS.

## File paths + concrete changes

1. `scripts/verify_plan.py`
   - New section `# ─── Check 54 — bare lane-specific env vars in --workload-cmd ───`
     after c53.
   - `check_workload_cmd_lane_env(plan: str, kind: str) -> CheckResult`, cid
     `c54_workload_cmd_lane_env`, name
     `"--workload-cmd bare lane-specific env vars"`. Logic:
     a. `candidates = _c46_command_candidates(plan)`; empty → SKIP.
     b. Lazy import inside the check:
        `from explore_persona_space.backends.issue_dispatch import lint_workload_cmd_lane_env`
        wrapped in `try/except Exception` → SKIP with
        `f"lane-env lint helper unavailable ({exc})"` (c46 fail-open idiom;
        cache the resolved fn in a module-level 1-slot list like
        `_c46_argparser_cache`).
     c. Per candidate: strip `_C46_COND_EXPANSION_RE` (whole `${VAR:+...}`
        spans — set-u-safe by construction and unsplittable otherwise), then
        `shlex.split`; `ValueError` → per-line note, continue (c46 shape).
        CRITICAL: do NOT apply `_C46_PLACEHOLDER_RE` substitution — the raw
        `$VAR` text IS the evidence this check scans.
     d. Extract the token following `--workload-cmd` (also the
        `--workload-cmd=<value>` form) and the token following `--backend`
        (both forms; absent → `None` → helper treats as auto — the exact
        "unpinned/auto-lane plans" scoping from the task body). No
        `--workload-cmd` token in any candidate → SKIP
        ("no --workload-cmd in plan-embedded dispatch commands").
     e. `lint = lint_workload_cmd_lane_env(wcmd, backend_value=backend_raw)`
        (backend_raw passed as-is; an unparseable placeholder value degrades
        to auto inside the helper). `lint.flagged` non-empty → collect
        offender line `f"{cmd[:70]!r}: {var} bare but unexported on lane(s) {lanes}"`.
     f. Offenders → `_warn(...)` with remedy text: "use the set-u-safe
        `${VAR:-<default>}` expansion or pin `backend:` to a lane exporting
        it; runtime refusal: workload_cmd_lane_env_unbound (#1329); incident
        #1979/#2047: bare $WORKLOAD_ROOT died under the fellows lane's set -u".
        Cap shown offenders at 3 + "(+K more)" (c46 shape). Else PASS with
        `f"{n} --workload-cmd value(s) clean of bare lane-specific env vars"`.
   - Check docstring documents the accepted v1 false negative: a
     `--workload-cmd "$WCMD"` indirection (value held in a shell variable)
     scans `$WCMD`, which is outside the helper's lint universe — no WARN
     (same class as the helper's own documented v1 false negatives,
     issue_dispatch.py ~L437-440).
   - Register `check_workload_cmd_lane_env` at the tail of `CHECKS`.
   - Add the c54 row to the module-docstring check table (after the c53 row),
     marked `WARN-only, conditional` / `all kinds`.
2. `tests/test_verify_plan.py`
   - New test group (follow the existing c46 test conventions): the 6
     acceptance cases above, plus: `--backend fellows` pin with bare
     `$WORKLOAD_ROOT` → WARN (slurm lane lacks it); `--backend gcp` with bare
     `$WORKLOAD_ROOT` → WARN (runpod failover lane lacks it — matches helper
     semantics); var inside single quotes only → no WARN (helper strips
     single-quoted segments); helper-unavailable monkeypatch → SKIP.
   - `test_c54_registered_in_checks`: membership assert
     `check_workload_cmd_lane_env in CHECKS` (mirror of
     `test_c46_registered_in_checks` — guards the forgotten-registration
     ships-green failure mode).
   - Verbatim-incident fixture: pin the literal #1979 plan v6.md offender
     command (fenced block, backslash continuation, no `--backend`,
     `--workload-cmd 'bash ... $WORKLOAD_ROOT/...'`) → WARN — exercises the
     continuation-join + shlex-dequote path end to end, not just the
     synthetic shape.
