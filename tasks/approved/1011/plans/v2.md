```python
# Check 30: per-unit companion-figure basename patterns. The lookbehind
# stops mid-word matches ("supercontext"); `indiv` is deliberately
# EXCLUDED — it names the per-question REGIME in this project
# (#928's pooled hero `mlp_indiv_hero_4arm.png`), not a per-unit view.
_PER_UNIT_FIG_RE = re.compile(r"(?<![a-z0-9])per[-_]?(context|unit|cell)", re.IGNORECASE)
```

**Check function** (placed after `check_figure_tracked_at_head`, so the figure checks stay adjacent):

```python
def check_orphaned_per_unit_figures(body: str, *, issue: int | None = None) -> CheckResult:
    """Check 30 (WARN, #1011): a committed per-unit companion PNG at a
    body-cited figure SHA is unreferenced by any body image URL.
    <full docstring: incident #928, semantics, escapes, fail-soft rules>
    """
    name = "per-unit companion figures embedded"
    # (1) cited (sha, issue-dir) pairs from the inline figure URLs
    cited: dict[str, set[str]] = {}          # dir_prefix -> {sha, ...}
    referenced_paths: set[str] = set()       # repo-relative figure paths the body embeds
    for url in _gather_figure_image_urls(body):
        url = url.strip().split(None, 1)[0] if url.strip() else ""
        m = _RAW_GITHUB_FIGURE_RE.match(url)
        if not m or (m.group("owner").lower(), m.group("repo").lower()) != _THIS_REPO_SLUG:
            continue
        pm = _ISSUE_FIGURE_PATH_RE.match(m.group("path"))
        if not pm:
            continue
        cited.setdefault(f"figures/issue_{pm.group('issue')}/", set()).add(m.group("sha"))
    if not cited:
        return CheckResult(name, True, "no same-repo `figures/issue_<N>/` figure URLs to check")
    # (2) issue scoping: --issue / numeric-parent-dir mode scans ONLY this
    # task's dir (a cross-issue embed must not surface ANOTHER task's
    # orphans); issue=None (--body-stdin) falls back to every cited dir.
    if issue is not None:
        cited = {k: v for k, v in cited.items() if k == f"figures/issue_{issue}/"}
        if not cited:
            return CheckResult(name, True, "no cited figure URLs under this task's figures dir")
    repo = _resolve_repo_root()
    if repo is None:
        return CheckResult(name, True, "skipped — repo root unresolved (running outside the repo)")
    # (3) referenced set: EVERY image URL anywhere in the body (broader than
    # the result-narrative scan — an embed in ## Methodology still counts)
    for url in _IMAGE_RE.findall(body):
        u = url.strip().split(None, 1)[0] if url.strip() else ""
        m = _RAW_GITHUB_FIGURE_RE.match(u)
        if m:
            referenced_paths.add(m.group("path"))
    # (4) enumerate per-unit PNGs at each reachable cited sha; union per dir
    orphans: dict[str, list[str]] = {}       # path -> sorted short-shas found at
    n_unreachable = 0
    for prefix, shas in sorted(cited.items()):
        for sha in sorted(shas):
            tracked = _git_tracked_under(repo, sha, prefix)   # ls-tree; None = unreachable
            if tracked is None:
                n_unreachable += 1            # hard constraint: skip SILENTLY, no WARN
                continue
            for p in tracked:
                base = p.rsplit("/", 1)[-1]
                if not base.lower().endswith(".png"):
                    continue
                if not _PER_UNIT_FIG_RE.search(base[: -len(".png")]):
                    continue
                if p in referenced_paths:     # path match — SHA-independent by construction
                    continue
                stem = base[: -len(".png")]
                if stem in body:              # prose disclosure/exemption escape
                    continue
                orphans.setdefault(p, []).append(sha[:8])
    if orphans:
        listed = "; ".join(
            f"`{p}` (committed at {', '.join(sorted(set(shas)))})"
            for p, shas in sorted(orphans.items())
        )
        return CheckResult(
            name, True,
            f"{len(orphans)} committed per-unit figure(s) at body-cited SHA(s) are not "
            f"embedded by any body image: {listed} — embed the per-unit companion under "
            "the relevant `### <result>`, or state the exemption in prose (naming the "
            "file silences this WARN); substantive owner: clean-result-critic Lens 11 "
            "(incident #928)",
            is_warn=True,
        )
    detail = "no orphaned per-unit figures at body-cited SHAs"
    if n_unreachable:
        detail += f" ({n_unreachable} cited SHA(s) not locally reachable — skipped)"
    return CheckResult(name, True, detail)
```

**Exact matching rules (decisions, stated):**
- **Pattern set:** basename stem matched case-insensitively against `(?<![a-z0-9])per[-_]?(context|unit|cell)`. This covers all three task-named spellings (`percontext`/`per_context`/`per-context` — the #928 filename `mlp_indiv_percontext_delta` contains `percontext` and matches) plus `per_unit`/`perunit`/`per-unit` and `per_cell`/`percell`/`per-cell` (the two other per-unit-view nouns Lens 11's own vocabulary uses — "low-level per-unit data", "per-cell artifacts"). `indiv` is EXCLUDED with cause: in the incident body itself, `mlp_indiv_hero_4arm.png` is a POOLED hero figure where `indiv` names the per-question regime — including it would misfire on pooled figures. The lookbehind blocks mid-word matches (`supercontext`). Justification trade-off: this set is one regex, covers the incident plus the project's two sanctioned per-unit nouns, and adds no demonstrated false-match surface; anything broader (e.g. `scatter`, `points`) would flood.
- **Referenced-set matching:** repo-relative **path equality** (`figures/issue_<N>/<basename>.png`), extracted from URLs on both sides — inherently SHA-independent, so an orphan committed at SHA A and embedded via a URL pinned at SHA B counts as referenced (the "path-suffix match" requirement, realized as exact repo-relative-path match since both sides come from the same `_RAW_GITHUB_FIGURE_RE.group("path")` extraction). The referenced set scans the WHOLE body (`_IMAGE_RE.findall(body)`), not just the result-narrative section — conservative in the fewer-false-WARNs direction.
- **Prose-disclosure escape:** an unembedded figure whose stem appears anywhere in the body text is treated as disclosed (mechanizes "exemptions stated in prose are legitimate"; also gives bodies a zero-cost acknowledgment path for the CLAUDE.md "WARNs ship only when acknowledged in body" convention). The pre-fix #928 body named only the bare commit SHA in its Repro footer, never the filename stem, so this escape would NOT have suppressed the incident WARN.
- **Issue-number scoping:** `--issue <N>` mode and `--file` mode with a numeric parent dir (both already resolve `issue` in `main()` / `_resolve_file_siblings`) scan ONLY `figures/issue_<N>/` — a body embedding one cross-issue parent figure must not be WARNed about the parent's whole figure dir. `issue=None` (`--body-stdin`, non-task-layout `--file`) falls back to per-cited-dir scanning (each cited `figures/issue_<K>/` scanned; documented in the docstring). Note the deliberate divergence from check 29 (which always keys on the path's own N): check 29 validates the linked paths themselves; check 30 enumerates unlinked siblings, where another issue's dir is out of scope.
- **PNG-only:** `.pdf` / `.meta.json` sidecars never flagged.
- **Dedup:** `orphans` is keyed by path — the same orphan at 3 cited SHAs is ONE WARN entry (listing the short SHAs it was found at).
- **Version gating (explicit decision):** generation-agnostic — v2 AND v3 AND v4 AND pre-sentinel legacy. Grounds: `_gather_figure_image_urls` already routes per generation (`## Results`/`## Findings`/`## TL;DR`); check 29 (the WARN precedent) is generation-agnostic; and the forward-only rule ("v3/v2/legacy bodies are NEVER newly hard-FAILed by a v4 rule") is satisfied by construction since a WARN keeps `passed=True` — no grandfathered body can regress.
- **`verify_paper.py` interplay:** out of scope — this is the markdown verifier only. `paper: true` bodies branch to `_verify_paper_stub` before `CHECKS` runs (L7917), so check 30 never executes on a paper stub; no `verify_paper.py` change.
- **Subprocess budget:** one `git ls-tree` per unique (cited SHA, issue dir) pair, each with the existing 10 s timeout — the live #928 body is the worst recent case at 5 unique figure-URL SHAs × 1 dir = 5 subprocesses (fact-checker-verified count; check-29's documented budget style; asserted in test 1 like `test_figure_missing_everywhere_warns` does).
- **Fail-soft inventory:** repo unresolved → skip-PASS; ls-tree error/unknown SHA → that SHA silently skipped (counted in the PASS detail, never a WARN); no cited same-repo figure URLs → vacuous PASS; empty dir at SHA → empty set → PASS. A network call is never made (satisfies the no-network hard constraint; `git cat-file` isn't even needed — `ls-tree` on an unreachable SHA already fails soft via `_git_tracked_under`'s `returncode != 0 → None`).
