**a5. `allow_nan=False` backstop decision: INCLUDE, on the canonical write only.** Change :855 to

```python
    out_path.write_text(json.dumps(payload, indent=2, allow_nan=False))
```

Rationale (one line each):
- Complementary coverage: the gate covers the 6 contract keys in held_out leaves with a *routed* error; `allow_nan=False` backstops every OTHER float in the payload (`g_logp`, `b_logp`, `kl`, `delta_g`, source means, `byte_identical_rate`, `delta_z_marker`/`delta_margin`) at zero code cost.
- It also keeps the canonical artifact strict-RFC JSON — Python's default serializes NaN as the literal `NaN`, which `jq`/JS `JSON.parse` reject.
- It deliberately fires even under `allow_subcontract_output=True`: the opt-out licenses *missing* fields (which serialize as `null` and pass `allow_nan=False` fine), never corrupted values — a smoke artifact with NaN is corruption in any mode. This does not break the opt-out constraint: opt-out's purpose (persist post-softmax-only smokes) is unaffected.
- The two `.partial.json` writes (:660-ish Phase A, :812 Phase B) keep the default `allow_nan=True` — partials are crash-recovery, exempt by design; a NaN there is caught at the final write anyway. **Partial-write interaction confirmed:** the gate has exactly one call site (:850), partials never call it, and the new checks live entirely inside the gate + the one canonical dumps — no interaction.

### (b) AST ordering pin — `tests/test_marker_slot_contract.py`

Extend `test_trajectory_partials_marked_noncontract_and_gate_fires_once` (:369–398), which already parses the module and collects `gate_calls`. Append:

```python
    write_calls = [
        n
        for n in ast.walk(fn)
        if isinstance(n, ast.Call)
        and isinstance(n.func, ast.Attribute)
        and n.func.attr == "write_text"
        and isinstance(n.func.value, ast.Name)
        and n.func.value.id == "out_path"
    ]
    assert len(write_calls) == 1, "exactly one canonical out_path.write_text expected"

    def _stmt_index(call_node) -> int:
        for i, stmt in enumerate(fn.body):
            if any(n is call_node for n in ast.walk(stmt)):
                return i
        raise AssertionError("call not found in run_trajectory_eval body")

    assert _stmt_index(gate_calls[0]) < _stmt_index(write_calls[0]), (
        "storage-contract gate must execute BEFORE the canonical out_path.write_text"
    )

    # #629 backstop pin: the canonical dumps refuses NaN/Inf payloads.
    dumps_call = write_calls[0].args[0]
    assert isinstance(dumps_call, ast.Call), "out_path.write_text(json.dumps(...)) shape expected"
    allow_nan_kw = [k for k in dumps_call.keywords if k.arg == "allow_nan"]
    assert allow_nan_kw and allow_nan_kw[0].value.value is False, (
        "final canonical json.dumps must pass allow_nan=False (#629)"
    )
```

Statement-index order (not bare `lineno`) is the chosen ordering predicate: it asserts execution order of the two top-level statements in the function body, and is immune to multi-line-call lineno ambiguity. Filtering on `out_path` excludes the two `partial_path.write_text` calls. The `assert checkpoints` minor needs no AST pin — it gets a behavioral unit test (below).
