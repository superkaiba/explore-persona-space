```bash
    # MAPPED INVARIANT-TEST LEG (#1147). GLOB_SCAN_TESTS-covered payloads
    # (scripts/issue*_*.py, dispatcher scripts) land via this gate with ZERO
    # pytest on the experiment auto-merge path (Step 9c is code-change-kinds-
    # only) — #1144: 34 thread-caps offenders accreted this way. Map the
    # own-diff to its scanning tests via the selector's single-source map;
    # empty map => leg skipped (no pytest run).
    TG_RC=0; TG_BASE_RC=0; TG_CRASH=no
    : > /tmp/issue-<N>-tg-new.txt
    if ! uv run python "$REPO_ROOT/scripts/select_step9c_tests.py" \
        --map-files /tmp/issue-<N>-own-diff.txt --repo-root "$WT" \
        > /tmp/issue-<N>-tg-map.txt 2>/tmp/issue-<N>-tg-map-err.txt; then
      TG_CRASH=yes   # helper failure: cannot classify the payload — fail CLOSED
    fi
    if [ "$TG_CRASH" = no ] && [ -s /tmp/issue-<N>-tg-map.txt ]; then
      # matched payload paths (attribution grep list) + gated test list:
      cut -f2 /tmp/issue-<N>-tg-map.txt | sort -u > /tmp/issue-<N>-tg-files.txt
      mapfile -t TG_TESTS < <(cut -f1 /tmp/issue-<N>-tg-map.txt | sort -u)
      # BASELINE leg — root copy on the payload-free main tree (each scan
      # test derives its scan root from its own __file__, so the root copy
      # scans the root tree). Only tests present on the baseline tree run
      # there: a branch-NEW scan test has no baseline, so its gated hits are
      # NEW by construction (correct — block).
      mapfile -t TG_BASE_TESTS < <(uv run python \
        "$REPO_ROOT/scripts/select_step9c_tests.py" \
        --map-files /tmp/issue-<N>-own-diff.txt --repo-root "$REPO_ROOT" \
        2>/dev/null | cut -f1 | sort -u)
      if [ "${#TG_BASE_TESTS[@]}" -gt 0 ]; then
        ( cd "$REPO_ROOT" && timeout --kill-after=30s 300s \
          env OMP_NUM_THREADS=8 MKL_NUM_THREADS=8 OPENBLAS_NUM_THREADS=8 \
              NUMEXPR_NUM_THREADS=8 \
          uv run pytest "${TG_BASE_TESTS[@]}" -q -p no:cacheprovider ) \
          > /tmp/issue-<N>-tg-baseline.txt 2>&1 || TG_BASE_RC=$?
      else
        : > /tmp/issue-<N>-tg-baseline.txt
      fi
      # GATED leg — worktree copy on the payload-bearing branch-tip tree:
      ( cd "$WT" && timeout --kill-after=30s 300s \
        env OMP_NUM_THREADS=8 MKL_NUM_THREADS=8 OPENBLAS_NUM_THREADS=8 \
            NUMEXPR_NUM_THREADS=8 \
        uv run pytest "${TG_TESTS[@]}" -q -p no:cacheprovider ) \
        > /tmp/issue-<N>-tg-gated.txt 2>&1 || TG_RC=$?
      # rc 0 = green, 1 = test failures (attributable); ANY other rc
      # (timeout 124, collection/internal/usage error 2-5) = crash-class.
      if [ "$TG_RC" -gt 1 ] || [ "$TG_BASE_RC" -gt 1 ]; then TG_CRASH=yes; fi
      # FILE-grain payload attribution: a scan test asserts per-file
      # invariants and aggregates every offender into ONE red node, so
      # node-level subtraction is degenerate (baseline-red node == gated-red
      # node masks a NEW offender). Attribution = output lines naming a
      # payload-matched path; line numbers blanked so main-vs-branch drift of
      # the SAME pre-existing offense cannot fake a NEW line.
      for leg in baseline gated; do
        grep -F -f /tmp/issue-<N>-tg-files.txt "/tmp/issue-<N>-tg-$leg.txt" \
          | sed -E 's/at line [0-9]+/at line N/g; s/:[0-9]+:/::/g' | sort -u \
          > "/tmp/issue-<N>-tg-$leg-hits.txt" || true
      done
      comm -23 /tmp/issue-<N>-tg-gated-hits.txt \
        /tmp/issue-<N>-tg-baseline-hits.txt > /tmp/issue-<N>-tg-new.txt
    fi
```

### Edit D — `scripts/select_step9c_tests.py` helper

New pure function + CLI flag (single-sources the mapping so the skill text never hardcodes globs; #1146's rewrite of the test file keeps working through the existing drift pins):

```python
def map_scan_tests(files: list[str], work_root: Path) -> list[tuple[str, str]]:
    """Map *files* to (scan_test, matched_file) pairs via GLOB_SCAN_TESTS.

    Pure path arithmetic over the pinned map (no git); a scan test absent
    from *work_root* is dropped (the caller's tree cannot run it). Returns
    sorted unique pairs.
    """
    pairs: set[tuple[str, str]] = set()
    for f in files:
        for scan_test, scan_globs in GLOB_SCAN_TESTS.items():
            if _matches_any(f, scan_globs) and (work_root / scan_test).exists():
                pairs.add((scan_test, f))
    return sorted(pairs)
```

CLI: `--map-files FILE` (newline-delimited repo-relative paths — the gate's existing `/tmp/issue-<N>-own-diff.txt` / `additive-files.txt` shape). When present, `main()` skips the diff-based selection entirely: read FILE (unreadable → one stderr line, exit 1), resolve `work_root` as today (`--repo-root` honored), call `map_scan_tests`, print one `f"{test}\t{path}"` line per pair to stdout, exit 0 (empty output on no match is a SUCCESS — the gate's skip signal). A stderr WARN names any pair dropped by the existence check. Module docstring Usage section updated.

2. **Attribution grain + baseline mechanism — file-level payload grep with line-number-blanked baseline subtraction; not junit-node subtraction; not `step9c_baseline.py` reuse.**
   *What:* hits = gated/baseline pytest output lines naming payload-matched paths; NEW = `comm -23`; block iff gated rc≠0 AND NEW non-empty.
   *Why:* a scan test is ONE node aggregating every offender — node subtraction is degenerate (red==red masks new offenders); file-grain is exact for per-file invariants; the baseline leg is required for the M-status case (payload modifies a pre-existing offender — own-path grep alone would false-block); line-number blanking keeps a drifted-but-identical pre-existing offense subtracted. The ledger machinery (`step9c_baseline.py`) is node-grain, needs freshness (1800 s refreshes), and itself marks scan-set nodes unstrippable — wrong tool for a 15 s check.
   *Source:* live failure-output format (measured 2026-07-08); `step9c_baseline.py:1-60` (#1022); the lint gate's own two-arm attribution (SKILL.md ~8734-8776).
   *Alternatives:* single gated run + A-status-only attribution (no baseline) — simpler but false-blocks M-status pre-existing offenders, kept only as the §7 flakiness fallback; full failure-line-set subtraction without the payload grep — admits blocking on non-payload lines that drift between trees, rejected.

3. **Helper (`--map-files`) vs hardcoding globs in SKILL.md.**
   *What:* new `map_scan_tests()` + `--map-files FILE` CLI printing `test<TAB>path` pairs.
   *Why:* single-source the mapping — `GLOB_SCAN_TESTS` already carries drift pins (`tests/test_select_step9c_tests.py`, #895), so the gate inherits map updates for free; hardcoded globs in skill prose drift silently (the exact failure class #895 fixed in the selector).

   *Alternatives:* paths-as-argv (`--map-files p1 p2 ...`) — ARG_MAX exposure on big diffs and the gate already has list FILES, rejected; a separate new script — violates reuse-first, rejected.

4. **Wall-time budget + per-leg 300 s timeout.**
