### 4.1 New helpers (insert immediately above `_filer_cmd`, ~line 801)

```python
def _target_tokens(target: str) -> set[str]:
    """Normalized target tokens of a manifest ``target`` (#1678): split on commas,
    whitespace-stripped, leading './' removed (removeprefix, NOT lstrip), empties
    dropped. A glob string is a LITERAL token — two identical globs overlap; a glob
    vs a concrete path under it does NOT (accepted false negative: the Step 10d
    recovery shapes remain the backstop)."""
    return {t.strip().removeprefix("./") for t in str(target).split(",") if t.strip()}


def compute_target_holds(manifest: list[dict]) -> dict[str, dict]:
    """slug -> {"with": <earliest overlapping route-2 slug>, "shared": [tokens]}
    for every route-2 item that must file WITHOUT dispatch (#1678 same-target hold).

    Positional + deterministic over the FULL manifest (never the --start/--end
    slice, so multi-slice and resume invocations compute the identical map):
    a route-2 item is HELD iff any EARLIER route-2 item shares >=1 normalized
    target token; attribution goes to the EARLIEST such sibling. Route-3 items
    neither hold nor are held (they already file --no-dispatch, so they are not
    a contention source). Deliberately ledger-state-independent: holding a
    sibling whose earlier group-head deduped/errored is harmless (the watcher
    dispatches it ~10 min later) and buys invocation-order determinism."""
    holds: dict[str, dict] = {}
    seen: list[tuple[str, set[str]]] = []
    for item in manifest:
        if item["route"] != 2:
            continue
        toks = _target_tokens(item["target"])
        for earlier_slug, earlier_toks in seen:
            shared = toks & earlier_toks
            if shared:
                holds[item["slug"]] = {"with": earlier_slug, "shared": sorted(shared)}
                break
        seen.append((item["slug"], toks))
    return holds
```

Overlap predicate justification (brief item 3): exact-token intersection after comma-split — conservative, no `fnmatch`, false negatives acceptable by design (glob-vs-concrete-path pairs don't hold; Step 10d recovery remains the backstop). `target` is guaranteed present: `REQUIRED_ITEM_KEYS` includes it (line 105) and `load_and_validate_manifest` fails loud at zero filings on a miss (line 505-509).

## 11. Decision Rationale

**Fork: (a) hold-dispatch vs (b) WARN + `shared_target_group` record — I choose (a), with (b)'s observability riding along.**
- **What:** later same-target route-2 siblings file with `--no-dispatch`; the ledger row + stdout carry the group attribution (so (b)'s record exists too — only the pure-WARN *dispatch* behavior is rejected).
- **Why:** the driver runs unattended at ~3 AM inside `/daily`; a WARN has no consumer that can alter dispatch timing before contention occurs, so (b) alone leaves the Goal ("reduce contention") unmet — it's a no-op with paperwork. (a) mechanically guarantees at most one driver-dispatched session per target group per wave, and its worst case (delayed dispatch via the sweep) is an already-accepted state the filer itself produces on cap-full/daemon-down. Tie-break per the brief: (a) is also the SIMPLER runtime story — it reuses the existing route-3 `--no-dispatch` argv mechanism verbatim rather than inventing a new staggering channel.
- **Source:** watcher sweep predicate verified at `autonomous_session_watch.py:17727-17785` + `decide_proposed_infra_sweep` (cap/backoff, 17823-17910) + M3 marker-freshness gate (18069); filer stdout shape at `file_infra_task.py:443`; route-3 precedent at `daily_drive_filings.py:821`; prior art #1059 (time-only stagger, orthogonal).
- **Alternatives rejected:** ledger-coupled hold (release the hold if the group head deduped/errored) — adds resume-state coupling for negligible benefit (~10 min extra latency in a rare case) and breaks invocation-order determinism; union-find connected components — the pairwise-earlier rule gives identical contention protection with simpler code; `fnmatch`-based glob overlap — rejected per brief item 3 (keep simple, false negatives acceptable).

**Constants introduced:** none — no time-based knobs, no env vars; the watcher's existing knobs (`PROPOSED_INFRA_SWEEP_*`, cap 5, 600 s marker gate) govern the backstop cadence.

**Grouping scope = full manifest, not the slice.** Source: the module docstring's own batch-driving contract (`--start/--end` slices, lines 5-9) — a slice-scoped map would miss cross-slice siblings and make hold decisions invocation-dependent.
