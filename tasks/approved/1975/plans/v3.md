## Goal / Requirement

Add an input-space parity check to the #1739 map-projection path: record the
fit-space (whitened/raw, with whitening provenance + train-input norm stats)
in the persisted map payload, and assert it against the inputs at apply/load
time, so a whitened-fit map can never silently score raw activations again
(the #1739 incident: sycophancy headline 0.577 quoted+committed, corrected to
0.486 ~21 h later).

**Acceptance criteria:**
1. New map payloads written by `scripts/issue1739_fits.py::_save_map` carry
   machine-checkable `fit_space` metadata (space tag + whitening provenance +
   train-input norm stats), for BOTH the linear `.npz` and nonlinear `.pt` forms.
2. A shared assert helper exists in
   `src/explore_persona_space/experiments/issue_1739/fits.py` that (a) RAISES on
   an undeclared input-space mismatch (norm-band check — the durable form of the
   `issue1739_map963k_applycheck.py` OOD signal), (b) allows an EXPLICIT
   declared mismatch (loud log naming the reason — the natpv `--space raw`
   disclosed provisional read), (c) on a LEGACY payload without `fit_space`
   emits a loud warning naming the #1739 incident (never silently assumes raw,
   never crashes existing healthy consumers).
3. Every persisted-payload consumer gets the check: `scripts/
   issue1739_map963k_readout.py` (the incident site, ~L465-475),
   `scripts/issue1739_natpv.py` (`_map_projectors` + the whitened fold, with
   the raw path passing an explicit declared-mismatch reason), and
   `scripts/issue1739_fits.py::_load_nl_map` (persisted-`.pt` reuse across
   invocations — the legacy-warn / `fit_space` presence read at load). The
   implementer additionally SWEEPS for further map-payload load sites
   (grep `MAPS_PREFIX` / `__ufull` / `_load_nl_map` / the maps/ path shape) and
   confirms `scripts/issue1739_bareq_score.py` does NOT load the payloads
   directly (critic probe says it consumes upstream projections — verify, and
   wire the helper if that read is wrong).
4. Unit tests pin the raise / warn / declared-mismatch / legacy behaviors, the
   writer round-trip, AND the POSITIVE fold-parity path (a matched
   persisted-whitening pair passes the check).
5. Committed whitened main-grid values and the corrected 0.486 headline are
   UNCHANGED — this is a guard, not a re-fit. No numeric output and NO new
   raise on any existing well-matched pipeline path (the healthy whitened fold
   must PASS the new check by construction).

## Method delta (vs current state)

Current state (verified 2026-08-03): the payload meta carries only a PROSE
`apply` string mentioning "(whitened space)"; nothing is machine-checked at
apply time; `issue1739_map963k_applycheck.py` computes the norm-based OOD signal
but is a one-off diagnostic. This plan makes the disclosure machine-readable and
the diagnostic a hard gate at the consumer seam.

## File paths + concrete diffs

1. **`src/explore_persona_space/experiments/issue_1739/fits.py`** (shared
   module both script sides already import) — ADDITIVE, appended near the
   existing `Whitening` / map helpers:
   - `def whitening_provenance(...) -> dict` — the PARITY OBJECT (critic
     Must-Fix 1: two independent `fit_whitening` invocations are NOT
     byte-identical — device/BLAS reduction order + the natpv fp32 persist —
     so a sha256 of recomputed float tensors can NEVER match on the healthy
     path). Two forms, recorded by the writer whichever is available:
     (a) **artifact form** (preferred): when the fit consumed a PERSISTED
     whitening file, record `{"whitening_file_sha256": sha256 of the file
     bytes, "whitening_path": repo/HF-relative path}` — both sides share the
     artifact, so equality is exact and stable;
     (b) **recipe form** (the fits-CLI fresh-fit case): the
     recomputation-STABLE discrete tuple `{"variant", "u_label",
     "whiten_seed", "n_u_rows", "gamma_per_layer": [...]}` (gammas are
     grid-selected from a discrete set — stable across recomputation);
     float matrices are NEVER hashed; any float cross-check is
     tolerance-based (e.g. per-layer `mu` norm at rtol ~1e-5, fp32-persist
     tolerant) or omitted.
   - `def map_space_meta(x_fit, *, fit_space: str, whitening_prov: dict | None) -> dict`:
     returns `{"fit_space", "whitening_provenance", "train_input_norm_mean"
     (per-layer, pre-standardization L2 row-norm mean of the FIT inputs),
     "train_input_norm_std"}`.
   - `def assert_map_input_space(meta, x, *, declared_mismatch=None, band=2.0)`:
     - `meta.get("fit_space")` absent → `logger.warning` naming the #1739
       incident + "re-persist to gain the check"; return (backward compat —
       live #1739 rounds consume existing HF payloads; refusing would break
       healthy runs).
     - `declared_mismatch` provided → `logger.warning` with the verbatim
       reason; return.
     - else per-layer mean L2 norm of `x` within `[mean/band, mean*band]` of
       `train_input_norm_mean` → violation raises `ValueError` naming the
       #1739 incident, the payload's fit_space, observed vs train norms, and
       the offending layers. Band default 2.0 (whitened ≈ sqrt(d)≈59.9 vs
       raw several-fold larger — the applycheck signal); the implementer
       sanity-checks the separation on a real payload's recorded stats and
       documents the measured margin in the test.
   - `def check_whitening_parity(map_meta, loaded_prov, *, on_legacy_warn=True)`:
     compares the provenance dicts — artifact form by exact sha equality;
     recipe form by exact equality on the discrete fields; MIXED forms (one
     side artifact, other recipe) fall back to the recipe fields present in
     both, else the legacy warning; mismatch on comparable fields RAISES.

## Kill criteria

- Norm leg: if the norm-band signal does NOT separate whitened from raw at the
  real payload's recorded stats (band overlap), the norm check is DROPPED in
  favor of provenance-only parity + the fit_space tag; a report-only round
  with that finding is the fallback, never a silently weakened band.
- Fingerprint/provenance leg (critic Must-Fix 1 extension): if even the
  recipe-form parity cannot be made to PASS on a healthy matched pair (a
  discrete field turns out unavailable at the writer, or genuinely unstable
  across recomputation), the fold check DEGRADES to the legacy-warn path
  (loud, named, never silent) + the fit_space tag, and the finding is
  reported — never a tolerance silently widened until it passes.
