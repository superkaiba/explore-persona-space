## Requirement + acceptance criteria

From the task body's five bug classes, each becomes one clause:

1. **Superlative/coverage-extremum sweep (compose-time).** A superlative or
   coverage-extremum claim written into any artifact ("largest n ever
   tested", "first/only", "never above X") is grounded by a cross-issue
   SWEEP (grep `eval_results/` + sibling issues' fit/scaling summaries for
   the quantity), never a single-artifact re-read. Incident: a "largest n
   ever tested = 3,600" headline was committed+pushed while #779's scaling
   fits reached n=963,444; the wrong ceiling drove several turns of sizing
   advice.
2. **Banked-compute check for chat-authored plan/theory docs.** A plan or
   theory doc authored in chat (outside the /issue plan pipeline) that
   labels a fit/eval stage "new compute" first runs the same
   banked-artifact search the /issue reuse checklist mandates and cites
   what is banked. Incident: a four-arm theory plan called kernel/MLP fits
   "new compute" while #779 had same-protocol fits banked at n=50k AND
   n=963k — two corrections before the doc was fixed.
3. **Counts define their unit + counting rule in the same sentence**, and a
   quantity question is answered in the asked unit FIRST (a GPU-hours
   question gets a GPU-hours number, then the breakdown). Incident: "12 vs
   36 vs 56 arms" took 3 asks to pin down; a GPU-h question answered in
   milestones had to be re-asked.
4. **Discard-directive acks LEAD with the sunk-vs-remaining compute
   split** — before mechanics, state what is already paid vs what the
   directive saves, so the decision is made with the cost picture.
   Incident: an ack to "remove the 200-draw bootstrap" led with mechanics
   rather than the ~44 A100-h already-paid split; a 2-turn round trip ended
   in a reversed directive.
5. **Chat-only analysis folds into its doc in the SAME turn** (or the
   completion note states the explicit deferral: who folds it, when) —
   chat text is not a durable home. Incident: a prior session's null-space
   analysis existed only in chat; the user had to ask whether it ever
   reached the doc (it had not).

Acceptance: each clause present verbatim-greppable in its target file;
no-flags `workflow_lint.py` + the parity leg PASS on the payload; the
mapped invariant tests (rules-pin arm for artifact-reuse.md, if any) stay
green.
