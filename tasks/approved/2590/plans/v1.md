### 4.1 Check 71 — plan-embedded jq probe dry-run (`c71_jq_probe_dryrun`, **FAIL**, kind ∈ {experiment, analysis})

Banner: `# ─── Check 71 — plan-embedded jq probe dry-run against committed targets (#2590) ──` with the incident narrative (#2588 v2 lines 108/240/411; the `|`-binds-looser-than-`,` precedence trap that defeated both critics' repairs; the design point that execution needs no jq grammar model), the corpus-calibration snapshot (filled at implementation), and the accepted-FN list below.

**Module-level constants:**

```python
_C71_REPO_ROOT = Path(__file__).resolve().parent.parent  # tests monkeypatch (c34/c41/c42 pattern)
_C71_JQ_TOKEN_RE = re.compile(r"(?<![\w-])jq(?![\w-])")          # cheap candidate pre-filter
_C71_ALLOWED_FLAGS = frozenset({
    "-c", "-r", "-e", "-j", "-a", "-S", "-s", "-M",
    "--compact-output", "--raw-output", "--exit-status", "--sort-keys",
})
# Refuse-to-execute: ANY other '-'-leading token (notably -f/--from-file, --args,
# --jsonargs, --arg, --argjson, --slurpfile, --rawfile, -n, --stream, -i) — skip
# the instance with a note, never guess (the task-body "which tokens you refuse" ask).
_C71_EXPECT_RE = re.compile(
    r"(?i)(?:→|->|=>)?\s*expect(?:ed|s)?\s*[:=]?\s*([0-9][\d,]*(?:\s*/\s*[0-9][\d,]*)*)"
)
_C71_MAX_INSTANCES = 12       # executed per plan, deterministic document order; rest noted
_C71_TIMEOUT_S = 5            # per instance
_C71_MAX_BLOB_BYTES = 5_000_000   # git cat-file -s gate; larger targets skip with a note
_C71_MAX_STDOUT = 4096        # comparison/detail bound
```

**Extraction (the c46 pattern, adapted):**

1. Candidates = `_c46_command_candidates`-shaped harvest generalized into a shared local helper (do NOT call the c46 function — it filters on `dispatch_issue.py`; factor a `_command_candidates(plan, token_re)` used by a thin c46 wrapper *only if* the refactor is zero-risk, else duplicate the 30-line walker as `_c71_candidates` with a comment naming the c46 origin — implementer's call, noted in the report). Each candidate carries its raw line index and source kind (`fenced` | `inline`).
2. Per candidate matching `_C71_JQ_TOKEN_RE`: skip if the RAW line matches `_C70_SUPERSEDED_RE` (corrected plans quote broken probes verbatim — the house convention c70 already handles). `shlex.split` (unsplittable → note, skip). Split tokens into segments at `_C46_SHELL_OPS`; each segment containing token `jq` yields an instance with `argv = segment[segment.index("jq")+1:]`.
3. Per instance, classify argv left-to-right: leading tokens in `_C71_ALLOWED_FLAGS` are flags; any other `-`-leading token → **refuse-instance** (noted). Next token = filter. Next token, if present and not an expectation leader (`→`, `->`, `=>`, `#`, `expect*`), = target path. Remaining tokens must begin an expectation clause or the instance is refused (shape-violation note). **No target path → skip-instance** ("target not stated in the invocation" — the #2588 line-411 table shape, where the path lives in a sibling cell: accepted FN, disclosed; the widening path — same-line single-candidate `.json` fallback — is named in the banner as a future revision, deliberately not shipped v1 because it adds a mis-execution channel to a FAIL-posture check).
4. Placeholders: `_C46_PLACEHOLDER_RE` match in filter or path → skip-instance (illustrative command).
5. **Target resolution ("committed in the repo", the disk-vs-HEAD question answered):** reject absolute paths and any path whose `(_C71_REPO_ROOT / path).resolve()` is not relative to the root (skip-instance). Committedness AND content both come from git, never the working tree: `git cat-file -s HEAD:<path>` (size gate; nonzero rc → target does not resolve → skip-instance; > `_C71_MAX_BLOB_BYTES` → skip with note) then `git show HEAD:<path>` → the input bytes. This deliberately tests the *committed* artifact (what the plan's probe registers) and is immune to a locally-modified working tree. Git subprocesses use the c42 conventions (timeout 10, cwd=`_C71_REPO_ROOT`, retry-once on `OSError`, whole-check fail-open SKIP if git is unusable).
6. **Execution (the safe-execution contract):** `jq_bin = shutil.which("jq")`; absent → whole-check SKIP ("jq unavailable — dry-run not possible"), never FAIL. Then:

```python
r = subprocess.run(
    [jq_bin, *flags, filter_text],           # argv list, shell=False by construction
    input=blob_bytes, capture_output=True,
    timeout=_C71_TIMEOUT_S, check=False, cwd=str(_C71_REPO_ROOT),
)
```

Read-only is **structural**, not promised: jq receives the committed bytes on stdin and no file argument, so the process touches no filesystem path at all; jq-1.6 filters have no write primitive (`$ENV`/`env`/`debug` are read-only/stderr); `--args`-family and `-f` flags — the channels by which extracted text could reach the filesystem or reinterpret arguments — are on the refuse-list. `TimeoutExpired` → offender? No: **skip-instance with a note** (a hung jq on committed bytes is an environment anomaly, not plan evidence — fail-open, c42 doctrine). Cap at `_C71_MAX_INSTANCES` executed instances.

7. **Offender arms (any → FAIL):**
   - (a) `r.returncode != 0` — the wrong-path AND precedence shapes both land here for free (the body's central design insight);
   - (b) stdout stripped empty, or every non-empty stdout line == `null` — jq's "path missed" tell;
   - (c) expectation mismatch: parse `_C71_EXPECT_RE` from the raw-line remainder after the inline span (inline instances) / the trailing tokens of the logical line (fenced instances); tokens = comma-stripped ints split on `/`; arm only when ≥1 numeric token; offender when stdout's non-empty lines are not exactly that integer sequence (count + values; non-numeric output lines count as mismatch).
8. **Verdict:** offenders → `_fail` with per-offender detail (plan line no, probe head ≤70 chars, rc, stderr head ≤120 chars, got-vs-expected) + remedy text quoting the two verified working forms from the task body (parenthesized filter / `jq -c '.counts'`) + both escape phrases. No executable instance → `_skip` (reason breakdown: none found / all unresolved / all refused). All executed clean → `_pass` with counts (`N executed, M skipped-unresolved, K refused`).
9. **Order of gates in the function:** kind gate → candidate harvest (none → SKIP) → escapes (`_standalone_na_declared`) → resolve+execute → verdict. Escapes: `N/A — no registered jq probe` (tail `no registered jq probe\b`) and `N/A — quoted jq probe is historical or a sibling's, not this plan's gate input` (tail `quoted jq probe is historical or a sibling'?s`).

**Severity: FAIL, agreeing with the body** — a probe that demonstrably errors against its own committed target is a factual defect of the c42 class (typo'd SHA precedent, also FAIL), not a judgment call. Fleet-wedge control: (i) kind gate excludes infra/batch/survey plans (which quote broken probes by design — this task's own plan included); (ii) only *committed-target, fully-resolved, allowlisted* probes execute — every ambiguity is a skip, never a guess; (iii) superseded-line + placeholder guards; (iv) two escapes; (v) the SKILL.md two-bounce PASS-with-override valve already exists for verifier false positives; (vi) **pre-registered demotion rule:** if the §5 corpus calibration adjudicates even one false-positive FAIL on an ACTIVE (non-terminal) plan that the grammar cannot cleanly exclude, c71 ships WARN-posture instead, with the body's FAIL ask and the demotion reason recorded in the banner and the implementer report (deviation class: allowed-without-asking, §9-dev).

**Smoke blind-spot enumeration:** none — smoke executes every production gate (the check has no smoke-conditional branch; its tests run the real `check_jq_probe_dryrun` against real tmp git repos and the real `/usr/bin/jq`, with jq-absent and git-absent paths covered by monkeypatching the resolver — the monkeypatch substitutes the *environment probe result*, not the implementation).
