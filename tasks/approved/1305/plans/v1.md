## 3. Method delta (what differs from the current specs)

The duty added is **enumerate always; run the diff-linked + pin-linked subset; defer the invariant-only remainder** — a proportionate middle ground between "enumerate only" (would NOT have prevented #1288: `test_step10d_guard3.py` appears in EVERY round's enumeration as `invariant`, so its name alone carries no signal that it pins the changed literal) and "run the full selected set" (median ~11 min / max ~21+ min per round inside a single bounded implementer turn, mostly re-running invariant tests unrelated to the diff, duplicating the Step 9c gate the pipeline runs anyway):

1. **Enumerate (MANDATORY, every code-change round, before posting the report marker):** from the issue worktree, `uv run python scripts/select_step9c_tests.py --json` — the DEFAULT invocation (fetched `origin/main` base; NEVER `--base main`, which is the pre-#1289 escape hatch — the clarifier ruled this). Cost: seconds (+ ≤120 s bounded fetch).
2. **Changed-literal pin-sweep (MANDATORY):** for each literal / command fragment / pinned symbol the diff CHANGES or DELETES, grep the ENUMERATED selection's test files for (a) distinctive fragments of the OLD text, (b) the NEW text, and (c) — for workflow-surface edits (`.claude/**`, `CLAUDE.md`, workflow-helper `scripts/`) — the edited file's basename. Restricting the sweep to the enumerated selection bounds it (~37-45 files) and is sufficient by construction: the gate can only FAIL on tests it runs. Every hit is a pinning test — update it if stale, and it JOINS the mandatory run set. This is the #1288 closer: the 3 `test_step10d_guard3.py` pins contain the old command text and would grep-hit.
3. **Mandatory local run set:** union of (i) selected tests with a diff-linked `selection_reasons` entry (`touched-test`, `stem-map:*`, `import-map:*`, `glob-scan:*`), (ii) pin-sweep hits, (iii) test files the diff itself edits. Run to completion in-turn — foreground with a `timeout` wrapper for small sets, or `run_in_background` + bounded same-turn poll for multi-minute sets, per the EXISTING § "Local runs are same-turn, synchronous work" rule (no new mechanics). Typical cost: 2-8 files ≈ 2-6 min.
4. **Invariant-only remainder** (reason `invariant` only, no pin hit): NOT required locally — Step 9c is its gate; the report states the deferred count explicitly. If a mandatory-set file genuinely cannot finish in-turn (e.g. a pin hit on `test_workflow_lint.py`, 319-771 s), the existing NOT-RUN escape applies: mark it NOT-RUN with the exact copy-pasteable command — never silently skip.
5. **Report:** `(c) How to verify` gains a **Gate-scope check** line: selector `n_tests` + base, the locally-run subset, the deferred invariant-only count, and a one-line pin-sweep summary (fragments grepped → hits).

**Failure mode closed:** a changed pinned literal now either (a) grep-hits its pinning test → run locally → fails pre-report → implementer fixes the pins in the same round, or (b) the diff-linked selection already covers it (stem/import/scan-mapped code changes). The residual (a regex pin containing neither old nor new literal nor the edited basename) is narrowed by axis (c) and remains caught by the gate as today.

**experiment-implementer variant (mapped-leg-scoped):** experiment kinds never reach Step 9c, so the full duty is wrong there; instead ONE new checklist item: pin-sweep greps over `tests/` for changed literals + `select_step9c_tests.py --map-files <own-diff-list> --repo-root "$WT"` enumeration of the Step 10d mapped scan tests for touched payload files; run all hits locally before the report. Same failure family (#1144), proportionate to the experiment path's actual test surface.

## 10. §11 Decision Rationale (design choices as "hyperparameters")

- **Selector invocation form = DEFAULT (fetched `origin/main` base), never `--base main`.** Why: matching the gate byte-for-byte is the whole point; `--base main` is the pre-#1289 escape hatch and diverges when the shared root lags origin (the #1280/#1281 foreign-file pollution). Source: SKILL.md 9c step 1a text + `select_step9c_tests.py` module docstring (#1289) + clarifier ruling in the spawn brief. Alternative rejected: the task body's sketch (`--base main`) — predates #1289.
- **Duty shape = enumerate + pin-sweep + run diff-linked∪pin-hit subset (not full set, not enumerate-only).** Why: enumerate-only does not close #1288 (the pinning test is `invariant`-reason on every round — no diff signal in its name); full-set run costs median ~11 / max ~21+ min per round inside a single bounded turn and duplicates Step 9c; the subset closes exactly the incident shape (changed literal → grep hit → local run) at 2-6 min typical. Source: #1288 incident; SKILL.md 9c step 1b gate timings (26 junits, 2026-07-04/05); implementer.md § Local runs are same-turn.
- **Pin-sweep scoped to the ENUMERATED selection (+ edited-file-basename axis for workflow-surface edits).** Why: the gate can only fail on tests it runs, so the enumeration bounds the sweep (~37-45 files) with zero missed gate-fail-capable pins for literal changes; the basename axis covers regex pins not containing the literal verbatim. Source: `select_step9c_tests.py` WORKFLOW_INVARIANT/selection semantics (read in full).
- **Target-file set = implementer.md + SKILL.md Step 4b + experiment-implementer.md (mapped-leg variant).** Why: implementer.md is where #1288's agent reads its duty; Step 4b briefs surface it per-round (the deferred-production-path-duty precedent, #509); experiment-implementer has the same gap in mapped-leg form (grep: 0 hits; #1144). Source: task body Scope; grep verification; SKILL.md L9300 mapped-leg comment.
- **Pin test = new token-presence file (house pattern).** Why: SKILL.md prose has a demonstrated silent-drop risk (#1134/#1045/#884 lineage; the #1242 pin family is the established pattern); token pins survive rewording. Source: verify_plan.py c31 rationale in planner spec; `tests/test_issue_skill_marker_contract.py` family.
