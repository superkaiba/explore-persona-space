## 3. Method delta vs the #963 precedent

1. **Multi-surface (from #842), per-surface token lists (new):** #963 pins one file; #842 pins one shared anchor across three files with NO per-surface tokens. This check pins three files, each with its OWN unique anchor AND its own required-token tuple + a shared negative regex — a data-table generalization: `(relpath_parts, anchor, end_regex, human_name, tokens)`.
2. **Span end regex is per-surface (from #842), not a fixed `\n\n` (from #963):** the experimenter.md D3 paragraph has NO trailing blank line — line 335 is immediately followed by `3. **Run preflight on the pod.**` at column 0 (verified by Read) — so its span terminator is `\n\s*\n|\n\d+\. ` (first blank line OR next top-level numbered item). The other two surfaces use `\n\s*\n` (blank line; falls back to EOF — the crash-fix-rounds.md paragraph is the file's last, ending at line 357/EOF).
3. **Negative regex has a lookahead exemption (new):** `\bresolves?\s+empty\b(?!\s*/)` (IGNORECASE, applied to the normalized span) — the lookahead deliberately SPARES the healthy three-way trio wording "resolves EMPTY / to the fresh path / …" (crash-fix-rounds.md line 323 is the only live occurrence of "resolves EMPTY" in the three files; verified by `grep -inE 'resolves?\s+empty'` — it is followed by ` / `) while catching a regression back to the unconditional "resolves EMPTY" wording the #1081 round-2 blocker fix replaced. #963's negative regex has no such exemption because its healthy paragraph contains no near-miss phrasing.
4. **Everything else is verbatim #963:** unique-anchor rule (`count == 0` → missing FAIL; `> 1` → duplicate FAIL, stale-copy hazard), whitespace-normalized token matching (`re.sub(r"\s+", " ", span)`), `repo_root: Path | None = None` test override, no-flags bundling, and the three documented scope limitations.

### 4.2 Check function (same insertion point)

```python
def check_crash_fix_relaunch_contract(*, repo_root: Path | None = None) -> list[str]:
    """FAIL if the #1081 crash-fix-relaunch contract prose regresses on any of
    its three surfaces (#1181): the fix-commit ancestry probe + fail-loud, the
    disposition-conditional three-way resume-glob confirm (the #1081 round-2
    blocker fix, concern retain-disposition-d3-empty-glob), and the fix_sha=
    note-token / brief duty.

    Scope notes (inherited verbatim from the #963 precedent):
    (a) The negative regex is a LITERAL-COUPLING BACKSTOP only — the positive
        tokens are the primary defense; do not weaken a token "because the
        regex covers it".
    (b) Paragraph-scoped — a contradictory instruction OUTSIDE an anchored
        span is invisible to it (inherent to the token-lint class).
    (c) A mid-paragraph blank line truncates the span and FAILs all downstream
        tokens at once — a deliberate restructure requires a deliberate lint
        update in the same commit.

    ``repo_root`` is a unit-test override hook; production callers pass None.
    Bundled into the no-flags default run.
    """
    root = repo_root if repo_root is not None else _REPO_ROOT
    errors: list[str] = []
    for parts, anchor, end_re, name, tokens in _CRASH_FIX_CONTRACT_SURFACES:
        path = root.joinpath(*parts)
        if not path.is_file():
            errors.append(
                f"{path}: missing — the #1081 crash-fix-relaunch contract "
                f"({name}) must live here (#1181)."
            )
            continue
        text = path.read_text(encoding="utf-8")
        n_anchors = text.count(anchor)
        if n_anchors == 0:
            errors.append(
                f"{path}: missing the anchor {anchor!r} (#1081) — the {name} pins the "
                f"crash-fix-relaunch fix-engaged contract and must not be removed or "
                f"renamed without updating this lint (#1181)."
            )
            continue
        if n_anchors > 1:
            errors.append(
                f"{path}: {n_anchors} anchors {anchor!r} found — the {name} must be "
                f"UNIQUE (a stale duplicate could satisfy the token scan while the "
                f"operative paragraph regresses; #1081/#1181). Remove the duplicate."
            )
            continue
        start = text.find(anchor)
        end_m = re.search(end_re, text[start:])
        end = start + end_m.start() if end_m is not None else len(text)
        span = re.sub(r"\s+", " ", text[start:end])
        for token in tokens:
            if token not in span:
                errors.append(
                    f"{path}: {name} missing token {token!r} (#1081) — note: the span "
                    f"ends at the first blank line / next numbered item, so a split "
                    f"paragraph FAILs all downstream tokens at once (a deliberate "
                    f"restructure needs a lint update, #1181)."
                )
        if _CRASH_FIX_RESOLVES_EMPTY_RE.search(span):
            errors.append(
                f"{path}: {name} couples the resume-glob confirm to an unconditional "
                f"'resolves EMPTY' (#1081) — the confirm is disposition-CONDITIONAL "
                f"(empty / the fresh path / exactly the RETAINED expected paths; "
                f"round-2 blocker retain-disposition-d3-empty-glob)."
            )
    return errors
```

### 4.3 Leg (a) — events-aware fix_sha presence check: DESCOPED (reasoned report)

The task body pre-authorizes this descope ("the planner may legitimately descope it to the anchor-phrase leg with a reasoned report"). Reasons, in force order: (1) **wrong layer** — `workflow_lint.py` lints the workflow SURFACE; `tasks/*/events.jsonl` is runtime task state, explicitly read-only/out-of-scope for workflow-fix sessions, and making the fleet-wide pre-push gate's exit code depend on mutable runtime state means any historical task whose relaunch predates #1081 (or whose failure-round attribution the lint mis-reconstructs) FAILs every contributor's push forever — grandfathering by timestamp would be brittle and semantically arbitrary. (2) **non-determinism/flakiness** — classifying "this `epm:run-launched` followed a `code`-row fix round" requires reconstructing the failure→review→relaunch marker sequence per task, duplicating `poll_pipeline.py`/SKILL.md Step 7 routing logic in a second place that would drift. (3) **performance** — `tasks/` holds 1000+ task folders; scanning every `events.jsonl` on every pre-push run adds IO to a gate already at ~4.5–6 min wall. The DETERMINISTIC CHEAP ALTERNATIVE the brief offers — "checking prose surfaces mandate the token" — is exactly what leg (b) implements: the `fix_sha=<sha>` note-token duty is pinned in crash-fix-rounds.md (tokens 1–3 of surface 2), and the brief-carries duty is pinned in the experimenter.md anchor itself plus SKILL.md tokens 1/3. Runtime enforcement of the token stays where it lives today: the `/issue` orchestrator + experimenter agents executing the pinned prose. If a runtime check is ever wanted, it belongs in per-task tooling (`tick_triage.py` / the poller), not this lint — noted for the record, no follow-up filed (this session runs under the recursion guard; the body already made this call).
