### 3.1 New module-level constants (near `NON_RED_PREFIXES`, line ~78)

```python
SECTION_FENCE_RE = re.compile(r"^=+ .+ =+$")
WARNINGS_SUMMARY_TITLE_RE = re.compile(r"^=+ warnings summary\b[^=]*=+$", re.IGNORECASE)
# Attribution rows inside the warnings summary: a bare node id (space-free,
# `::`-joined — covers class-based + parametrized ids) or pytest's aggregated
# `<path>: N warnings` row. FAILED/ERROR rows carry spaces + tokens => never match.
WS_ATTRIBUTION_ROW_RE = re.compile(r"^(?:\S+(?:::\S+)+|\S+: \d+ warnings?)$")
```

`\b[^=]*` in the title regex tolerates trailing qualifiers ("warnings summary (final)"), case-insensitively.

### 3.2 New helper

```python
def warnings_attribution_idxs(pytest_lines: list[str]) -> set[int]:
    """Indices of pytest-leg lines that are warnings-summary attribution rows
    (node-id headers / `path: N warnings` aggregates) — report-class, never
    payload-naming hits (#1585; the #1112 false-block incident)."""
    idxs: set[int] = set()
    in_section = False
    for i, line in enumerate(pytest_lines):
        row = line.rstrip()
        if SECTION_FENCE_RE.match(row):
            in_section = bool(WARNINGS_SUMMARY_TITLE_RE.match(row))
            continue
        if in_section and WS_ATTRIBUTION_ROW_RE.match(row):
            idxs.add(i)
    return idxs
```

Matching against the raw (rstripped, not lstripped) line keeps indented warning bodies out (`^\S`). Any other fenced header (PASSES, short test summary info, a later section) closes the window.

### 3.3 `evaluate()` change (the combined-line loop, lines ~320–331)

```python

combined = [(ln, False) for ln in lint_lines] + [
    (ln, i in ws_idxs) for i, ln in enumerate(pytest_lines)

...
for line, ws_attr in combined:
```

## 11. Decision Rationale

- **D1 — Reclassify in the combined-line loop, before hit assignment (fixes NEW + MODIFIED branches uniformly).** What: attribution rows never become `hits[p]`. Why: a NEW green test file triggering an environmental warning has the identical false block (the NEW branch blocks on ANY non-WARN naming hit); classifying at line level fixes both with one mechanism and zero changes to branch logic. Source: code read (`evaluate()` lines 337–353) + task-body open design point. Alternatives: patch only the MODIFIED conservative branch (leaves the NEW-branch false block live; rejected).
- **D2 — Section tracking scoped to `legs.pytest_output` only.** What: `warnings_attribution_idxs` runs on pytest lines; lint lines always `ws_attr=False`. Why: lint output cannot contain a pytest warnings summary; scoping prevents a lint line that happens to look fenced from opening a whitelist window over lint red. Source: task-body design point; `LegResults` already keeps the legs separate (its docstring exists for exactly this class of cross-leg masking). Alternatives: track over the combined list (rejected — needless over-whitelisting surface).
- **D3 — Double predicate (inside-section AND row-shape).** What: whitelist requires both. Why: shape alone would whitelist bare node ids anywhere (e.g. captured stdout in the `-rA` PASSES section); section alone would whitelist arbitrary lines a plugin prints there. Source: §2 probe (PASSES section is fenced ⇒ closes the window) + incident logs. Alternatives: shape-only (task sketch's minimal form; rejected as over-broad), section-only (rejected).
- **D4 — Regex forms.** What: `SECTION_FENCE_RE = ^=+ .+ =+$`; title `^=+ warnings summary\b[^=]*=+$` case-insensitive; row `^(?:\S+(?:::\S+)+|\S+: \d+ warnings?)$`. Why: fence shape probe-verified under `-q`; qualifier tolerance covers "(final)"; row arm 1 covers class-based/parametrized ids while excluding anything with spaces (`FAILED …` rows); row arm 2 covers the aggregated shape (A3/A4). Source: §2 probe on pytest 9.0.2 + incident logs (#1112 gate5/gate6). Alternatives: the sketch's `^\S+::\w+` (misses class-based/parametrized ids and the aggregated row; rejected).
- **D5 — Parse-and-report rather than `--disable-warnings` on the pytest leg.** What: keep the warnings section in leg output and classify it. Why: the Goal directs report-not-block (warnings remain visible in the audit file + `epm:progress` report — a real warnings regression in a payload stays observable); suppression would also change the leg invocation contract. Source: task `## Goal` verbatim + incident evidence. Alternatives: `--disable-warnings` (1-token diff; retained as the §5 kill-criterion fallback).
- **D6 — Labeled report line (`[warnings-summary attribution]` prefix).** What: distinct tag inside `verdict.reported`. Why: the gate log must distinguish this class from `PASSED`/`WARN` rows for auditability without changing `main()`'s print format. Source: gate5/gate6 log legibility (the incident diagnosis depended on reading these prints). Alternatives: untagged append (rejected — silent reclassification is harder to audit), new Verdict field (rejected — larger diff for no consumer).
