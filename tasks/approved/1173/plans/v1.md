### 5.1 `scripts/daily_drive_filings.py` — inject (the mechanical fix)

**New pure helper** (module level, near `_resolve_body_path`):

```python
WF_FIX_TARGET_KEY = "workflow_fix_target:"
PROVENANCE_HEADING_RE = re.compile(r"^## Provenance[ \t]*$", re.M)

def ensure_wf_fix_provenance(text: str, target: str, fp: str) -> tuple[str, bool]:
    """Idempotently ensure the durable recursion-guard Provenance lines (#1173).

    Returns (new_text, changed). The `- workflow_fix_target: <target>` line is the
    DURABLE signal task_workflow.is_workflow_fix_session() reads (the env-var leg is
    lost on a watcher crash-recovery respawn); `- fingerprint: <fp>` is the body-side
    dedup fallback (task_workflow.is_open_workflow_fix_task; sweep _fp_tag_scan).
    Substring contracts (do not reformat): 'workflow_fix_target: {target}' and
    'fingerprint: {fp}' with a single space after the colon.
    """
    lines = []
    if WF_FIX_TARGET_KEY not in text:
        lines.append(f"- workflow_fix_target: {target}")
    if "fingerprint:" not in text:
        lines.append(f"- fingerprint: {fp}")
    if not lines:
        return text, False
    block = "\n".join(lines)
    m = PROVENANCE_HEADING_RE.search(text)
    if m:
        # Insert immediately after the existing heading line.
        insert_at = m.end()
        new = text[:insert_at] + "\n\n" + block + text[insert_at:]
    else:
        new = text.rstrip("\n") + f"\n\n## Provenance\n\n{block}\n"
    return new, True
```

**Wire-up in `process_item`** (route-2 only, keyed on the SAME condition that applies the `wf-fix` tag in `_filer_cmd` — today `item["route"] == 2`): after the dedup check (current L428-442) and at body resolution (current L444), i.e. before the `attempting` row and the filer subprocess:

```python
body_path = _resolve_body_path(item, dirpath)
if item["route"] == 2:  # same condition as _filer_cmd's wf-fix tagging
    text = body_path.read_text(encoding="utf-8")
    new_text, changed = ensure_wf_fix_provenance(text, item["target"], fp)
    if changed:
        tmp = body_path.with_suffix(".md.tmp")
        tmp.write_text(new_text, encoding="utf-8")
        os.replace(tmp, body_path)   # temp+rename, same pattern as load_ledger L184-186
        print(f"INJECTED {slug}: workflow_fix_target provenance (#1173 recursion-guard signal)")
```

- **Dry-run:** extend the existing dry-run FILE branch (current L410-419) to report intent WITHOUT writing: compute `ensure_wf_fix_provenance(...)[1]` read-only and append e.g. ` [will inject workflow_fix_target provenance]` to the `FILE {slug} ...` print. Preserves the pinned "no subprocess, no ledger writes" dry-run property, extended to "no body writes".
- **Ledger schema unchanged** (no new row fields — the documented row shapes in the module docstring stay valid); the `INJECTED` stdout line is the audit trace, and the mutated durable-dir body itself is the durable record of what was filed.
- **Module docstring:** add one sentence documenting the route-2 provenance normalization.
- Crash-safety: injection is idempotent, so a kill anywhere (before/after the `attempting` row) re-normalizes harmlessly on resume; recovery/dedup/skip paths return before injection (no pointless writes for items that don't file).

   - *What:* wherever the driver stamps wf-fix tags, it now also stamps the durable body signal — tag and body signal can no longer diverge on the driver path.
