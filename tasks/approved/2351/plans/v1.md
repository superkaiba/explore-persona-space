# Plan v1 — #2351: make `workflow_lint._hf_routing_file_errors` string-aware

**Kind:** infra (workflow-surface fix). **Workflow:** v1. **Paper:** no.

## 1. Requirement

`scripts/workflow_lint.py::_hf_routing_file_errors` — the per-file body behind the
`--check-live-hf-retry-routing` check (`#1547`), **bundled into workflow_lint.py's
no-flags default run** — is line-based. It skips only lines whose `lstrip()` starts
with `#` or `what=`, so any line whose *text* matches `HF_ROUTING_CALL_RE`
(`hf_hub_download(` / `.upload_file(` / `.upload_folder(` / `create_commit(` /
`push_to_hub(`) is flagged as a "bare HF Hub call in LIVE code" even when that text
sits inside a string literal (module docstring, triple-quoted constant) or a trailing
comment.

This is a **standing** false-positive, not a one-off: the Schema-from-artifact rule
(`.claude/agents/experiment-implementer.md` § "Before writing code" item 8) MANDATES
pasting the exact probe command into the consuming file as an
`Observed schema — probe:` docstring block, so every compliant consumer of a banked
HF artifact trips a false FAIL on its own docstring.

Requirement: a regex match located inside a string literal or a comment MUST NOT be
reported; a match at a real call site MUST still be reported, with the emitted
message text byte-identical to today's.

## 2. Method delta (what differs from prior related work)

`#1547` introduced the check line-based (a deliberate cheap heuristic) and worked
around the string-literal class **per file** with two constants:
`HF_ROUTING_PATTERN_STRING_FILES` (`workflow_lint.py`, `verify_plan.py` — the
predicate strings themselves) and `HF_ROUTING_GENERATED_CODE_FILES`
(`backends/gcp.py` — pod-side crash-persist heredocs). `#1568` added the frozen
snapshot + the regen flag for staleness, and the message-edit hazard note.

The delta: replace the per-file workaround pattern with a per-**span** mask derived
once per file from `tokenize`, so the class is fixed for every current and future
file instead of one file at a time. Deliberately NOT a full AST rewrite: the check's
wrap heuristic (`_hf_routing_call_is_wrapped`) is line-and-paren-balance based, and
an AST rewrite would change which lines are reported for true positives — which the
message-stability constraint in §4 forbids while main is red.

## 4. File paths + concrete change

### 4.1 `scripts/workflow_lint.py` — new module-private helper + one call-site guard

Insert immediately above `_hf_routing_file_errors` (i.e. after
`_hf_routing_scan_files`, ~L10996):

```python
# Token types whose SPANS are masked out of the routing scan: a predicate
# match inside a string literal or a comment is text, never a call site
# (#2351). Built defensively so a py3.12+ interpreter (where an f-string is
# FSTRING_START/MIDDLE/END rather than one STRING token) masks the literal
# text parts too.
_HF_ROUTING_MASK_TOKEN_TYPES: frozenset[int] = frozenset(
    {tokenize.STRING, tokenize.COMMENT}
    | {
        tok
        for tok in (getattr(tokenize, name, None) for name in ("FSTRING_MIDDLE",))
        if tok is not None
    }
)


def _hf_routing_masked_spans(source: str) -> dict[int, list[tuple[int, int]]]:
    """Map 1-based line number -> masked ``[start_col, end_col)`` column spans.

    A span covers a string-literal or comment token, so
    :func:`_hf_routing_file_errors` can drop a predicate match whose start
    column falls inside one (#2351: the line-based scan flagged the
    Schema-from-artifact ``Observed schema — probe:`` docstring blocks that
    `.claude/agents/experiment-implementer.md` MANDATES).

    FAIL-SAFE by design: a file that does not tokenize (unterminated
    triple-quote, decode error) returns ``{}`` — no masking, i.e. exactly
    today's line-based behavior. The check then OVER-flags rather than
    under-flags; a silent skip of an untokenizable file would be the
    under-flag this check exists to prevent.
    """
    spans: dict[int, list[tuple[int, int]]] = {}
    lines = source.splitlines()
    try:
        tokens = list(tokenize.generate_tokens(io.StringIO(source).readline))
    except (tokenize.TokenError, IndentationError, SyntaxError, UnicodeDecodeError):
        return {}
    for tok in tokens:
        if tok.type not in _HF_ROUTING_MASK_TOKEN_TYPES:
            continue
        (srow, scol), (erow, ecol) = tok.start, tok.end
        for row in range(srow, erow + 1):
            start = scol if row == srow else 0
            if row == erow:
                end = ecol
            else:
                end = len(lines[row - 1]) if row - 1 < len(lines) else scol + 1
            if end > start:
                spans.setdefault(row, []).append((start, end))
    return spans
```

Then in `_hf_routing_file_errors`, after `lines = py.read_text(...).splitlines()`,
read the source once and consult the mask before appending. Concretely:

```python
    errors: list[str] = []
    source = py.read_text(encoding="utf-8")
    lines = source.splitlines()
    masked = _hf_routing_masked_spans(source)          # #2351
    for i, line in enumerate(lines):
        stripped = line.lstrip()
        if stripped.startswith("#") or stripped.startswith("what="):
            continue
        m = HF_ROUTING_CALL_RE.search(line)
        if m is None:
            continue
        # #2351: the match text sits inside a string literal or a comment —
        # not a call site. (The pre-existing full-line `#` and `what=` skips
        # above are kept: they are cheap and their behavior is unchanged.)
        if any(start <= m.start() < end for start, end in masked.get(i + 1, ())):
            continue
        if "# NO_RETRY:" in line or (i > 0 and "# NO_RETRY:" in lines[i - 1]):
            continue
        ...
```

## 9. Kill criteria

- **Kill (revert to the narrower approach):** if A2 fails — i.e. token-based
  masking changes ANY existing true-positive message line — abandon the
  `tokenize` mask and fall back to the task body's alternative (track triple-quote
  state while iterating lines, docstrings only, comments left as-is), which cannot
  move a true positive's line number.
- **Kill (abandon the task):** if the mask is shown to suppress a real call site in
  the live tree (i.e. A5 reports fewer than 2 `[live-hf-retry-routing]` lines).
  Under-flagging a live bare HF call is strictly worse than the false positive this
  task fixes; the check's whole purpose is 429 single-point-of-failure detection.
