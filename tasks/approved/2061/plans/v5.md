## §6 Measurement validity

**Per-DV declaration** (planner.md §6):

- **Construct**: which SAE features of the ANSWER state at layer 29 become MORE linearly predictable from the pooled context activation (also at layer 29) after each adjacent post-training stage transition.
- **Metric**: per-feature held-out R²_j from a ridge regression `g: c_x → f(a_x)` fitted per (stage, corpus, arm) cell, K=5 group folds, fold seed 0, pooled R² with fold-local test means. ΔR²_j = R²_j(stage_after) − R²_j(stage_before). Headline statistic: `max_{j, cell} ΔR²_j` vs a GLOBAL selection-symmetric null (per-draw max over `(feature j, delta cell)` under one shared `draw_seed_schedule` across all 64 (stage-pair, corpus, arm) delta cells; per-cell p97.5 retained as a secondary diagnostic).
- **On-distribution**: **YES** — the map is fit on the ACTUAL post-training checkpoints' activations (Llama-3.1-8B Tülu-3 base / SFT / DPO / RLVR / longer-RLVR), on-policy contexts sampled from the same 8 corpora #1336 banked (real-user LMSYS chat, established GSM8K / MATH benchmarks, IF/UF/SFT rows). No off-policy substitution, no teacher-forcing artifact (the SAE encode of the answer state is a forward pass on the same banked activations).
- **Saturation check**: per-stage FVE / L0 / dead-feature-count on the fixed dictionary (§ Cross-stage SAE-fitness confound control below) is the pre-registered saturation / instrument-fitness gate. A stage whose FVE falls below 80% of the base-stage FVE is reported per-transition with an explicit scope caveat, not aggregated.
- **Dual-DV**: N/A — the DV is R²_j (continuous by construction — a scalar from a well-posed ridge regression per feature per fold). The selection-symmetric null is the multiple-comparisons discipline, not a companion DV.

## §7 Success + kill criteria

**Success criteria (quantitative thresholds)**:
- **Primary decision rule (GLOBAL max, cell-level selection-symmetric)**: **At least one (feature j, delta cell) pair exists** with true ΔR²_j exceeding the p97.5 quantile of the null distribution of `max_{j, cell} ΔR²_j` — the GLOBAL max over both the feature axis (d_sae=262144) AND the delta-cell axis (64 cells) taken per draw under one SYNCHRONIZED draw-index schedule. This closes the cell-level selection-asymmetry loophole a per-cell p97.5 would leave open (a positive rate of ~5% per cell yields ~3.2 spurious cells at random over 64 cells; the global max rides both axes per draw). Report the winning (feature id, stage-pair, corpus, arm) tuple, its ΔR²_j, the GLOBAL null p97.5, and the fraction of (j, cell) pairs clearing the global bar.
- **Secondary per-cell reads** (retained diagnostics, non-headline): (i) per-cell p97.5 of null `max_j ΔR²_j` — the local-only quantile the global test dominates; (ii) cross-corpus rank-agreement of the top-100 improved features per transition (are the same features improving across corpora, or is each corpus surfacing corpus-specific features?). Higher rank-agreement supports a stage-general improvement mechanism; lower agreement supports corpus-specific fits.
- **Diagnostic pass bar**: per-stage FVE ≥ 0.8 × base_FVE on all 5 stages, L0 ∈ [10, 200] for the fixed dictionary applied at each stage, dead-feature fraction < 10% of d_sae. ## Hypothesis

**If** the Llama-3.1-8B Tülu-3 post-training stages (SFT / DPO / RLVR / longer-RLVR) preferentially strengthen the LINEAR predictability of specific interpretable SAE features (of the answer state) from the pooled context activation, **then** at least one (feature j, delta cell) pair exists whose true ΔR²_j exceeds the p97.5 quantile of the GLOBAL selection-symmetric null (per-draw max over `(feature j, delta cell)` across all 64 (stage-pair, corpus, arm) delta cells, under one shared `draw_seed_schedule`).

**Falsification**: the maximum ΔR²_j over the true assignment (max over both j AND delta cell) lies within the GLOBAL selection-symmetric null band. (Bright-line quantitative test: `max_{j, cell} ΔR²_j` vs the GLOBAL null p97.5 computed over `{global_max_d = max_cell max_j_d : d = 0..499}` — 500 draws per the amended §Design default.)

### Per-cell fit

For each (stage s, corpus c, arm a) cell:
- **Input** X = the context-side activation at layer 29 (shape `(n_c, d_in=4096)`), reused from #1336's `issue1336_rlvr_ladder/` banked turnstores. **Realized convention (amended v5 — the v4 "mean-pool over prefix tokens / prefix+query" prose was factually wrong; neither mean is banked):** #1336's producer (`scripts/issue1336_extract_turnstore.py:333-348`) writes `slots` as SINGLE-TOKEN header states (`slot_vecs = acts[:, i, slot_pos, :]`) and `profiles` as span-MEANS over TURN CONTENT (`acts[:, i, s:e, :].float().mean(dim=1)`); the u1 profile is query-content-only, so no prefix-token mean exists anywhere in the payload. Inherited from `scripts/issue1336_fit_cells.py::_cell_xy_1336` (L242-255: "context arm: a1-header slot -> a1 profile"; slots ordered prefix=0, a1=1): the `prefix` arm input = the **prefix-header single-token slot state** (slot index 0); the `context` arm input = the **a1-header single-token slot state** (slot index 1 — the assistant-header position, conditioned on the full prefix+query). Landed in unit A's shared loader (`scripts/issue2061_turnstore.py`, commit `aaf9c75d5c`, test-pinned in `tests/test_issue2061_loaders.py`).
- **Target** Y = SAE feature vector of the **answer** state — the **a1 profile: span-mean over the answer turn's content tokens** at layer 29 (the realized #1336 convention above; `target_turn_index 1` in `_cell_xy_1336`) — encoded by the fixed EleutherAI/sae-llama-3.1-8b-64x at `layers.29/`. Shape `(n_c, d_sae=262144)`. TopK activation with k=32, so Y is sparse per row but the target matrix is not sparse across rows.
- **Fit** g: X → Y as a ridge regression in the INPUT space (n × 4096; well-posed at n_train ≫ d_in). Per-feature R²_j is derived column-by-column from the fitted map's held-out predictions — d_sae does NOT gate ridge well-posedness, since each output column is one scalar regression on the same 4096-dim input.
- **Folds** K=5 group-level folds with fold seed 0, inherited from #1336. LOFO / LOCO groupings match #1336's own convention.
- **Estimator**: the shared factorization `ridge_fit_predict_fast_layer_batched` (`src/explore_persona_space/experiments/issue_779/fit_h.py:180`) — one Gram/dual-space eigendecomposition per (stage, corpus, arm) cell, applied to every column of the SAE target simultaneously. GCV over `np.logspace(-2, 4, 13)` for λ (the #779/#823 convention), with the opt-in `gcv_dof_cap=0.9` engaged per the §7 under-determined-cell mitigation (realized mechanism there; landed `d2b36fc0ce`). Numeric-parity gate against the SVD reference on 3 slices per cell family at production shape (per its docstring; landed as `run_parity_gate` in `scripts/issue2061_fit_per_feature.py`, cap=None on both sides).
- **Per-feature R²_j**: `1 - ||f_j − ĝ_j||² / ||f_j − mean(f_j)||²` on the held-out folds (K-fold aggregated). Stored as an `(n_stages × n_corpora × n_arms × d_sae)` array = 20800 × d_sae = ~5.4B floats total; store as sparse-per-cell (only features with any nonzero activation in the pool are informative) OR chunked (recommended: `(d_sae,)` per (stage, corpus, arm) cell = ~1 MB per cell = ~80 MB total).

### Cross-stage delta

For each adjacent stage pair (base→SFT, SFT→DPO, DPO→RLVR, RLVR→longer-RLVR) × 8 corpora × 2 arms = **64 (stage-pair, corpus, arm) delta cells**:
- ΔR²_j = R²_j(stage_after, corpus, arm) − R²_j(stage_before, corpus, arm), per feature.
- **Headline statistic**: max_j ΔR²_j (per delta cell); tail-shape distribution over j.

### Cross-stage SAE-fitness confound control

Per-stage FVE / L0 / dead-feature-count on the FIXED dictionary applied to EACH stage's banked activations (LMSYS validation slice, ~1k rows; the same slice for every stage). Follows the #1482 SAE token-pool recipe (`.claude/rules/gotchas.md` #1482 entry): BOS-offset strip (first 8 positions), outlier-norm filter (L2 > 10× pool median), var-based FVE (`1 − var(x − x̂) / var(x)` summed per-dim unbiased variance).

Pre-registered pass/fail bar (per `.claude/rules/gotchas.md` #1482 published-reference figure for the andyrdt Qwen2.5-7B suite of ~0.806 FVE at k=64; for the EleutherAI Llama base SAE at k=32 the published FVE benchmark is not reported on the model card — verify at implementation time; if unavailable, use the BASE stage's own measured FVE as the reference and require **≥ 80% of the base-stage FVE** at every post-training stage):

- **Base FVE reference**: measured on `meta-llama/Meta-Llama-3.1-8B` layer 29 (~1k LMSYS validation rows, same BOS-strip + outlier filter).
- **Pass**: every post-training stage's FVE on its own banked activations ≥ 0.8 × base_FVE; L0 stays in [10, 200] on the fixed dictionary; dead-feature fraction stays < 10% of d_sae.
- **Fail**: any stage's FVE < 0.8 × base_FVE → the fixed-dictionary assumption is broken for that stage; the clean-result carries the fitness drift as a scope caveat and the headline is reported per-stage-pair, not aggregated.

### Pre-registered prefix-arm degeneracy (scope caveat — the analyzer inherits this verbatim)
