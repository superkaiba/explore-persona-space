## Goal / Requirement

Make the measurement GRAIN — the unit of analysis (per-query vs
per-prefix vs per-arm vs per-cell) plus the aggregation from raw rows to
that unit — a NAMED per-DV plan field in the Measurement-validity block
(planner §6), with a matching statistics-critic lens item that REVISEs a
plan whose DV grain is unstated or mismatched to the Goal's construct.
This closes the #1900→#1979 failure class: a plan naming its DVs'
constructs / metrics / on-distribution status while leaving grain
implicit lets a per-(prefix, query) row-level implementation ship a
result the user wanted at per-prefix — a whole run's spend on a
grain the plan never bound.
