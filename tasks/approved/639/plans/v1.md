## 4. Design (two coupled changes)

### 4.1 CLI entrypoint — NEW `scripts/gcp_audit.py` (option b)

**Fork resolved → standalone script.** The task description prefers extending
`dispatch_issue.py` ONLY if its argparse already has a `gcp` subparser group.
It does not: `dispatch_issue.py::_build_argparser` (`scripts/dispatch_issue.py:1316`)
declares a flat `sub = parser.add_subparsers(dest="action", required=True)` with
exactly two actions, `launch` and `finalize` — no `gcp` group, and `main()`
hard-branches on `args.action in {launch, finalize}`. Adding a nested `gcp
audit-stale` would force a restructure of that contract. The RunPod analogue is
itself a standalone `scripts/pod_audit.py` (forwarded by `pod.py`), so a
standalone `scripts/gcp_audit.py` mirrors the established pattern with zero blast
radius on the dispatcher. (See §11 row 1.)

Near-real Python:

```python
#!/usr/bin/env python3
"""Audit (and optionally reap) stale GCP ``eps-issue-*`` VMs.

GCP analogue of ``scripts/pod_audit.py`` (the RunPod stale-pod sweep). Thin
CLI wrapper over ``backends.gcp.audit_stale_gcp_vms`` — the predicate lives in
the library; this script only parses flags, injects the production config +
runner, prints the records, and maps the result to an exit code. Invoked by
``scripts/cron_gcp_audit.sh`` daily; runnable by hand for a dry-run probe.
"""
from __future__ import annotations

import argparse
import json
import os
import sys

from explore_persona_space.backends.gcp import (
    GcpConfig,
    audit_stale_gcp_vms,
    default_gcloud_runner,
    default_gcp_config,
)
from explore_persona_space.orchestrate.env import load_dotenv  # explicit-path safe wrapper


def build_parser() -> argparse.ArgumentParser:
    p = argparse.ArgumentParser(
        prog="gcp_audit",
        description="Audit live GCP project for stale eps-issue-* VMs (credit-leak backstop).",
    )
    p.add_argument(
        "--delete",
        action="store_true",
        help="Actually delete reaped VMs (passthrough to audit_stale_gcp_vms(delete=True)). "
             "Default is report-only (delete=False). Overridden OFF by EPS_GCP_JANITOR_DRY_RUN=1.",
    )
    p.add_argument(
        "--max-age-hours",
        type=float,
        default=24.0,
        help="EXITED/old VMs older than this are reaped (passthrough to max_age_seconds). "
             "Default 24h matches the function default + CLAUDE.md auto-delete fence.",
    )
    p.add_argument(
        "--terminal-phase-max-age-min",
        type=float,
        default=10.0,
        help="RUNNING VMs in a terminal eps/phase (done/failed) older than this floor are "
             "reaped promptly (passthrough to terminal_phase_max_age_seconds). Default 10 min.",
    )
    p.add_argument(
        "--json",
        action="store_true",
        help="Emit machine-readable JSON (one list of per-instance records), no headers.",
    )
    return p


def main(argv: list[str] | None = None) -> int:
    load_dotenv()  # gcloud reads ADC, but keep parity w/ dispatch_issue.main()
    args = build_parser().parse_args(argv)

    # Belt-and-suspenders dry-run override: a global env flag forces report-only
    # regardless of --delete, so the cron / a smoke can be neutered centrally.
    delete = args.delete and os.environ.get("EPS_GCP_JANITOR_DRY_RUN", "") != "1"

    records = audit_stale_gcp_vms(
        config=GcpConfig(  # production injection: ALWAYS thread --configuration=eps-gcp
            **{**default_gcp_config().__dict__},  # start from prod defaults
        ),
        runner=default_gcloud_runner,
        max_age_seconds=int(args.max_age_hours * 3600),
        terminal_phase_max_age_seconds=int(args.terminal_phase_max_age_min * 60),
        delete=delete,
    )

    if args.json:
        print(json.dumps(records, indent=2))
    else:
        reaped = [r for r in records if r["action"] in ("would-delete", "deleted")]
        failed = [r for r in records if r["action"] == "delete-failed"]
        print(f"GCP janitor: {len(records)} eps-issue-* VM(s) inspected; "
              f"{len(reaped)} reaped ({'delete' if delete else 'report-only'}), "
              f"{len(failed)} delete-failed.")
        for r in records:
            if r["action"] != "skipped":
                age_h = (r["age_seconds"] / 3600) if r["age_seconds"] is not None else None
                print(f"  {r['action']:<13} {r['name']}  zone={r['zone']}  "
                      f"status={r['status']}  reason={r['reason']}  "
                      f"age={age_h:.1f}h" if age_h is not None else
                      f"  {r['action']:<13} {r['name']}  age=unknown")

    # Exit code: 0 always on a clean inspection (mirrors cron_pod_audit's
    # "no email on found-and-reaped"); only a delete-failed bucket returns 2 so
    # a human / monitoring catches a reaper that could not reclaim a VM.
    return 2 if any(r["action"] == "delete-failed" for r in records) else 0


if __name__ == "__main__":
    sys.exit(main())
```

> NOTE on `GcpConfig(...)` construction: `default_gcp_config()` already returns
> the production config with `gcloud_config="eps-gcp"`. Simplest correct form is
> to pass `config=default_gcp_config()` directly (the `**__dict__` splat above is
> illustrative of "start from prod defaults"; the implementer SHOULD just call
> `default_gcp_config()` — it threads `--configuration=eps-gcp` on every gcloud
> call per `backends/gcp.py:1030`). The `--delete=False` default + the
> `EPS_GCP_JANITOR_DRY_RUN` override are the two safety seams.

**Output contract (`--json`):** a single JSON list of the records
`audit_stale_gcp_vms` returns verbatim (keys `name, zone, status, created_at,
age_seconds, phase, reason, action`). This matches the spirit of
`pod_audit.py --json` (a list of per-instance dicts), adapted to the GCP record
shape rather than copying RunPod's pod-specific keys.

### 4.2 Cron entrypoint — NEW `scripts/cron_gcp_audit.sh` (option b)

**Fork resolved → separate cron script + separate log dir.** Appending to
`cron_pod_audit.sh` (option a) would couple two distinct backends into one log
trail and one exit-code surface; a GCP gcloud-auth failure would muddy the
RunPod audit log. A separate script with its own dated log dir
(`logs/gcp_audit/YYYY-MM-DD.log`) mirrors `cron_pod_audit.sh` 1:1 and keeps the
backends independently diagnosable. (See §11 row 2.)

Real bash (clone of `cron_pod_audit.sh` with GCP substitutions):

```bash
#!/bin/bash
# Daily GCP-VM janitor — invoked from system crontab.
# Reaps eps-issue-* GCE instances that escaped the canonical teardown:
#   - any eps-issue-* VM older than 24h (orchestrator-crash credit-leak backstop)
#   - a RUNNING VM in a terminal eps/phase (done/failed) past a 10-min floor
#     (the metadata-runner-SIGPIPE zombie class, #634).
# GCP analogue of cron_pod_audit.sh. Output: logs/gcp_audit/YYYY-MM-DD.log.

set -uo pipefail

# cron's minimal PATH lacks ~/.local/bin (bare `uv` exit-127s silently under
# the `exit 0` below). Put uv on PATH; fail LOUD if still missing.
export PATH="$HOME/.local/bin:$PATH"
if ! command -v uv >/dev/null 2>&1; then
    echo "$(date -Iseconds) FATAL: uv not on PATH ($PATH); cannot run gcp audit" >&2
    exit 1
fi

PROJECT_DIR="/home/thomasjiralerspong/explore-persona-space"
DATE=$(date +%Y-%m-%d)
LOG_DIR="${EPS_GCP_JANITOR_LOG_DIR:-$PROJECT_DIR/logs/gcp_audit}"
LOG_FILE="$LOG_DIR/$DATE.log"

mkdir -p "$LOG_DIR"

# First-run-of-day pointer line into the crontab redirect file (the block below
# redirects into $LOG_FILE, so without this the redirect file reads "never ran";
# mirrors cron_pod_audit.sh + cron_autonomous_session_watch.sh, #580 item-3).
FIRST_RUN_OF_DAY=0
[ -f "$LOG_FILE" ] || FIRST_RUN_OF_DAY=1

{
    echo "=== $(date -Iseconds) gcp_audit start ==="
    cd "$PROJECT_DIR" || exit 1
    uv run python scripts/gcp_audit.py --delete --json
    rc=$?
    echo "=== $(date -Iseconds) gcp_audit exit=$rc ==="
} >> "$LOG_FILE" 2>&1

if [ "$FIRST_RUN_OF_DAY" = 1 ]; then
    echo "$(date -Iseconds) gcp_audit: per-pass output → $LOG_FILE (this file receives only this daily pointer line)"
fi

# Exit 0 even on rc=2 (delete-failed) — no cron email on routine reaps; the log
# is the audit trail. A delete-failed surfaces in the log's exit=2 line.
exit 0
```

Reuse the existing `_Runner` mock from `test_gcp_backend.py`. Three scripted VMs
in one `list_results` payload; the RUNNING-terminal-phase VM additionally needs a
`guest_attr_results` entry returning `phase=done`. Call the library directly
(the CLI's `main()` is a thin wrapper; a CLI-level smoke is §10.2):

```python
import json
from explore_persona_space.backends.gcp import audit_stale_gcp_vms, GcloudRunResult
# reuse _Runner + _test_config from test_gcp_backend (import or duplicate the fixture)

def test_audit_reaps_exited_age_and_terminal_phase_keeps_healthy():
    now = datetime(2026, 6, 14, 12, 0, tzinfo=UTC)
    payload = json.dumps([
        # (i) old EXITED-equivalent: created 30h ago → age reap
        {"name": "eps-issue-100", "status": "TERMINATED",
         "zone": ".../zones/us-central1-a", "creationTimestamp": "2026-06-13T06:00:00+00:00"},
        # (ii) RUNNING, 20 min old, terminal eps/phase=done → terminal-phase reap
        {"name": "eps-issue-200", "status": "RUNNING",
         "zone": ".../zones/us-central1-a", "creationTimestamp": "2026-06-14T11:40:00+00:00"},
        # (iii) healthy RUNNING, 5 min old (under both thresholds) → skipped
        {"name": "eps-issue-300", "status": "RUNNING",
         "zone": ".../zones/us-central1-a", "creationTimestamp": "2026-06-14T11:55:00+00:00"},
    ])
    runner = _Runner(
        list_results=[GcloudRunResult(0, payload, "")],
        guest_attr_results=[GcloudRunResult(0, "done", "")],  # for eps-issue-200's probe
        delete_results=[GcloudRunResult(0, "", ""), GcloudRunResult(0, "", "")],
    )
    records = audit_stale_gcp_vms(
        config=_test_config(), runner=runner, now=now, delete=True,
    )
    by_name = {r["name"]: r for r in records}
    assert by_name["eps-issue-100"]["reason"] == "age"            and by_name["eps-issue-100"]["action"] == "deleted"
    assert by_name["eps-issue-200"]["reason"] == "terminal-phase" and by_name["eps-issue-200"]["action"] == "deleted"
    assert by_name["eps-issue-300"]["reason"] is None             and by_name["eps-issue-300"]["action"] == "skipped"
    # gcloud list was issued (Acceptance #1)
    assert any("list" in c for c in runner.calls)
```
