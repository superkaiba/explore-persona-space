## 4. Design

### 4.1 Scope + trigger (precision-first — grounded in measured corpus usage)

Measured 2026-08-27 (see §12 A-4): of 105 live v4 bodies, 102 have a Sample slot and only **8** carry `(verbatim)` inside it; the DOMINANT body-wide usage of "(verbatim)" is the footer `**Context:** … Originating prompt (verbatim): …` row, which is outside `## Methodology` and therefore outside scope by construction. Scoping to the Sample slot is what makes the check precise.

Gate ladder (each rung a PASS-skip with a stating detail):
1. `is_v4(body)` false ⇒ `PASS "not a v4 body (forward-only) — verbatim-stem scan skipped"`. **Grandfathered bodies are skipped entirely, not WARNed** — consistent with "NEVER newly hard-FAILed" and with the check-54 precedent; a WARN would add standing noise to ~100 parked v3/v2 bodies for zero enforcement value (they are never re-promoted under v4 rules).
2. `## Methodology` or its Sample slot absent ⇒ PASS-skip (check 18 owns presence).
3. Slot does not contain `(verbatim)` (case-insensitive literal, parenthesized) ⇒ PASS-skip.
4. No candidate artifact link in the slot ⇒ PASS-skip ("checks 10/11 own sample-link discipline").

### 4.2 Verbatim-group extraction (three arms, matching the 8 live in-slot shapes)

A **verbatim group** is text from which stems are extracted:
- **Line arm:** any slot line containing `(verbatim)` ⇒ the line itself (live shapes: #931 ``Worked example row (verbatim): `"Emma": "AUST"` ``; #2333 `Eval input (verbatim): system "…" → user "…"`).
- **Details-summary arm:** a `<details>` block (via the existing `_DETAILS_BLOCK_RE` / `_SUMMARY_OPEN_RE`) whose `<summary>` text contains `(verbatim)` ⇒ the block's inner content after `</summary>` (live shapes: #2474, #1090, #952, #1774, #1902).
- **Fence-prelude arm:** a `(verbatim)`-carrying line with zero extractable stems immediately preceding (≤2 non-blank lines) a fenced block ⇒ the fence content.

**Sanitization guard:** a group whose label line/summary ALSO carries a sanitization token (`sanitiz`, `redact`, `paraphras`, `renamed`, `substitut`) is SKIPPED with a note ("mixed verbatim+sanitized label — not mechanically checkable") — the #1090 summary "…(verbatim) and impolite ICL-gate excerpts (sanitized)" must never FAIL (display-substitution disclosures are sanctioned by CLAUDE.md).

### 4.3 Stem extraction

From each group, collect:
- backtick code spans (`_CODE_RE`),
- double-quoted spans `"..."` and curly-quoted `“...”` spans (new regex, non-greedy, bounded ≤500 chars).

Keep a token as a stem iff, after normalization (§4.4): length ≥ **12 chars** AND ≥ **2 whitespace-delimited tokens** (drops ids like `obj_flip_00`, bare paths, short codes) AND it is not link-shaped (contains `://`, or is slash-separated with no spaces). Cap: first 40 stems per body.

### 4.4 Normalization pipeline (the false-FAIL defense — specified exactly)

Body-side stem, in order:
1. strip surrounding quote/backtick characters;
2. markdown-unescape: `\\<punct>` → `<punct>` for CommonMark-escapable punctuation (`\*`, `\_`, `\[`, `\]`, `` \` ``, `\|`, `\\`, …);
3. literal two-char escapes `\n`, `\t`, `\r` → single space (bodies quote JSON strings with visible escapes);
4. fold curly quotes/apostrophes to ASCII (`“”„` → `"`, `’‘` → `'`), fold ` ` (nbsp) → space;
5. collapse all whitespace runs (incl. newlines from wrapped table cells) to one space; strip;
6. casefold.

**Truncation markers** (acceptance A4): split the *pre-normalization* stem at `…`, `...`, `[...]`, `[…]`, `[truncated]` (case-insensitive); normalize each literal run; verify EVERY run that clears the §4.3 floor — each above-floor run must independently match ≥1 searched artifact (each genuinely-verbatim run substring-matches its own artifact region, so false-FAIL risk stays ~zero, while fabrication living in a shorter above-floor run is caught — a longest-run-only match would let it pass). Runs below the floor are SKIPPED (counted in the detail as "skipped: truncated below floor"); a stem whose runs ALL sit below the floor is skipped entirely. Disclosed residual (check docstring + §5.3 SPEC entry): sub-floor fragments are unverified — a fabrication living entirely in below-floor fragments of a truncation-marked stem passes silently. A stem with no marker is matched whole.

Haystack, per artifact (built once, memoized):
- **View R (raw):** file text with steps 4–6 applied (quote-fold, whitespace-collapse, casefold).
- **View D (decoded):** all string values (and keys) recursively collected from `json.loads` of the file (`.jsonl`: per-line loads, bad lines skipped), joined by a SENTINEL that survives normalization (`\x00`, excluded from stems by construction) rather than `\n` — a `\n` join would concatenate adjacent unrelated string values into one searchable run after whitespace-collapse, so a stem spanning a JSON string boundary (the concatenation of two adjacent bank values) would spuriously MATCH, a false negative in exactly the direction the check exists to catch. Steps 4–6 then apply (the whitespace collapse leaves `\x00` intact; the no-space variant strips whitespace but keeps the sentinel). Fail-soft: unparsable ⇒ View R only.
- **No-space variants** of both views (all whitespace stripped) — matched against the no-space stem only when the no-space stem is ≥ 12 chars. This kills `"Emma": "AUST"` vs `"Emma":"AUST"` formatting mismatches.

A stem MATCHES an artifact iff it is a substring of any view. This handles the stated JSON-escaping concern both ways: View D decodes `\"`/`\n`/`\uXXXX` stored escapes; step 3 handles bodies that quote the escaped form.

### 4.5 Candidate links + resolution

Collect from the slot: markdown-link URLs (`_LINK_RE`) + backtick paths (`_CODE_RE` hits that look path-like). Classify:
- **Searchable:** (a) same-repo GitHub blob URL pinned to a sha with path ending `.json`/`.jsonl` (`_GITHUB_BLOB_TREE_URL_RE`, `_THIS_REPO_SLUG` guard) ⇒ load via `_git_json_text_at_sha(repo, sha, path)` with `_working_copy_json_text` fallback (both existing, `scripts/verify_task_body.py` — check-54 section; they carry the `git cat-file -s` size probe + 10 MB cap + fail-soft semantics); (b) repo-relative backtick path ending `.json`/`.jsonl` ⇒ working-copy read at `_resolve_repo_root()` with the same size cap, only when the file exists AND is tracked (`git ls-files --error-unmatch` or `git cat-file -e HEAD:<path>` — committed, not scratch).
- **Unsearchable candidates:** HF URLs (`huggingface.co`), other-repo GitHub links, directory/`tree` links whose path names no `.json[l]` file, oversized artifacts, unparsable paths. These never load but DO gate the FAIL/WARN split (§4.6).
- Anything else (figure PNGs, commands, non-data links) is ignored entirely.
Per-body load cap: `_VERBATIM_STEM_MAX_LOADS = 8` (own constant; the check-54 `_ARTIFACT_CONTENT_MAX_LOADS` precedent), memoized per URL/path.

### 4.6 Verdict lattice (disjoint and exhaustive over fired cases)

With ≥1 stem extracted:
- **All stems found** in ≥1 searched artifact each ⇒ PASS: "N verbatim stem(s) verified against M linked artifact(s)".
- **≥1 stem missing** AND ≥1 searchable artifact was searched AND **zero unsearchable candidates** remain ⇒ **FAIL**, detail naming each missing stem (≤3, truncated ~80 chars each) + every artifact searched — the fully-checkable case, and the only FAIL path.
- **≥1 stem missing** AND ≥1 unsearchable candidate (HF/dir/other-repo/oversized) ⇒ **WARN**: the stem may live in the unsearched artifact; detail names missing stems + searched + unsearched. Rationale: the #1902 live shape links a committed bank AND HF raw completions — a completion excerpt legitimately lives only in the HF artifact; FAILing there is the false-FAIL class the acceptance criteria ban. A real fabrication in a mixed-link slot still surfaces (WARN + named stem) for critic/human triage.
- **Zero searchable artifacts** (remote-only) ⇒ **WARN** "remote-only artifact link(s) — verbatim stems unverifiable offline" (task-body requirement).
- **Zero extractable stems** ⇒ PASS with note ("(verbatim) label but no extractable quoted stems").

Skipped stems (truncation-below-floor, sanitized groups) never enter the missing set.

```python
def check_v4_verbatim_sample_stems(body: str) -> CheckResult:
    """Check 62 (v4-only, FAIL-capable; #2635): every quoted sample stem in a
    '(verbatim)'-labeled group of the ## Methodology Sample slot must exist in
    ≥1 locally-resolvable linked JSON/JSONL artifact. Incident #2617 r1
    (substituted noun presented as a verbatim bank row); family #657.
    Offline-only; remote-only links WARN; forward-only (non-v4 skip)."""
    name = "Verbatim sample stems exist in the linked artifact (v4)"
    if not is_v4(body):
        return CheckResult(name, True, "not a v4 body (forward-only) — skipped")
    methodology = section_text(body, "Methodology")
    if methodology is None: return CheckResult(name, True, "## Methodology missing — check 18 will report")
    slot = _v4_methodology_sample_slot(methodology)
    if slot is None: return CheckResult(name, True, "no Sample slot — check 18 will report")
    if "(verbatim)" not in slot.casefold():
        return CheckResult(name, True, "no `(verbatim)` label in the Sample slot")
    stems, skipped = [], []
    for group in _iter_verbatim_groups(slot):          # 3 arms + sanitization guard
        stems.extend(_extract_verbatim_stems(group))   # floor + truncation handling
    searchable, unsearchable = _classify_slot_artifact_links(slot)
    if not searchable and not unsearchable:
        return CheckResult(name, True, "no artifact links in the Sample slot — checks 10/11 own linking")
    if not stems:
        return CheckResult(name, True, "`(verbatim)` label but no extractable quoted stems")
    views = {}   # memoized loads, capped at _VERBATIM_STEM_MAX_LOADS
    missing = [s for s in stems[:40] if not any(_stem_match_views(s, _load(views, a)) for a in searchable)]
    if not missing:
        return CheckResult(name, True, f"{len(stems)} verbatim stem(s) verified against {len(views)} linked artifact(s)")
    named = "; ".join(f"'{s[:80]}'" for s in missing[:3]) + (" …" if len(missing) > 3 else "")
    arts = ", ".join(f"`{a}`" for a in sorted(views))
    if not views:      # nothing was searchable/loadable
        return CheckResult(name, True, f"remote-only / unloadable artifact link(s) — {len(stems)} stem(s) unverifiable offline", is_warn=True)
    if unsearchable or (load_failures):
        return CheckResult(name, True, f"{len(missing)} stem(s) not found in {arts}, but unsearched link(s) remain ({...}) — verify manually: {named}", is_warn=True)
    return CheckResult(name, False, f"{len(missing)} `(verbatim)` stem(s) absent from every linked artifact ({arts}): {named}")
```
