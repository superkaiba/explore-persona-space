# Plan — Issue #665 · Phase 3 (A3.6–A3.10 + joint factorization on the trained store)

(48 `tensors.pt` cells, `v⁺`/`v0`/`c_C`/probe-split, 50 ctx × 28 layers × 3584-d,
float32) + #658's `sigma_c.pt` (the whitened-gate metric `Σc`, 28×3584×3584). All
A3.6–A3.10 + joint-factorization arms are CPU linear algebra streamed cell-by-cell.
The ONE GPU arm is **A3.6c** (causal context-vector patch): forward passes with
hooks on the #664 fleet adapters + base model — no training, one `eval`-intent GPU.

**Hyperparameters (load-bearing, all inherited — no training):** read layer per
behavior = #658's locked linear read-out layer (harmful_compliance **L8**, broad_em
**L0→mid-L caveat**, fact_expression **L2 a32**) `Source: #658`; `c_C` recipe =

A3.6c L-sweep {7,14,21} `Source: test-plan §4 A3.6c (manipulated variable)`.

**Baselines / controls:** raw cosine gate `cos(c_C,c_C')`; predict-zero / predict-mean;
shuffled-key / shuffled-query; A3.6c self-patch identity null + random/other-context-CV
floor + norm-matched variant; base-behavior-prior `E0(C',B')`; install-magnitude (‖ŵ‖)
partialled out per §6 install-strength control.

**Loss surface:** N/A (no training). Reads are answer-side mean residual activations
(`v`) at the per-behavior layer + on-policy behavioral DV `E` (judge over HF completions).

**Compute:** A3.6c GPU arm only — 1× GPU (`eval` intent, GCP `eval`→1×L4 auto-lane or
`lora-7b`→1×A100 if L4 OOMs on 7B+hooks), ~6 GPU-h. Everything else CPU off-VM
(footprint ≤ 50 GB by cell-streaming). `Estimated GPU-hours (total): 8`

**Evaluation:** PRIMARY = activation realized gate `ĝ^real=ŵᵀΔv(C')/ŵᵀŵ` (B1), per-behavior
locked layer, family/source-clustered bootstrap CIs (C4) + independent-probe-split

(ii) the boxed whitened-`c_C` predictor holds. A3.9/A3.10 PASS iff base gate predicts
ĝ^real with Spearman ρ above the probe-split reliability floor AND beats raw cosine.

Σc=I/equal-norm/δ∥r_B limit) before any A3.9/A3.10 number is reported.

**Risks (top 2):** (1) The marker spine never installed (#664 kill a+b) — so Phase 3's
primary read-out is the **content spine** (bad-medical / taught-fact / EM), not the
marker; the marker arm is a labeled at-floor degenerate read. (2) The base-behavior
prior may dominate (C7/C10) — if so A3.6/A3.10's drift decomposition adds little and
the result is reported result-conditionally, not as a predictor win.

## 1. Goal

**Phase 3 — test A3.6–A3.10 + joint factorization on the Phase-2 trained store:
activation realized gate, whitened key-query gate (key/metric ablations), base-gate
validity, drift decomposition; clustered CIs + single-context arm. Includes A3.6c —
the causal context-vector patch (input-vs-map localization, R12-1).**

This is Phase 3 of the leakage-predictor program (#660). The theory's predictor
`L̂ = η·(r_B'ᵀδ)·g_C(C')` has three factors; Phase 1 (#658) tested the base-model
chain (A3.2–A3.5) and Phase 2 (#664) built the trained store + measured ground-truth
leakage `ĝ^real`. Phase 3 tests the *training-dependent* assumptions that connect the
two: is the realized off-source update a scalar-gated copy of the source write (A3.8
rank-one)? Is that scalar a normalized key–query similarity (A3.9), and specifically
the boxed whitened-`c_C` form (B3)? Does the *base-model* gate predict the realized
gate (A3.10) — the central pre-fine-tuning prediction claim? And the causal control
(A3.6c): is leakage carried by the context vector `c_C` (input) or by the map `M`
(function)? **Inherited kill-criterion caveat (#664):** the marker spine never reached
its install band (kill a) and its gate sits at the measurement-noise floor (kill b),
so the marker yields no usable ground truth — Phase 3's primary read-out is the
**content transfer spine** (bad-medical / taught-fact / insecure-code-EM cells, which
do install on-policy and carry gate dynamic range), with the marker reported only as a
labeled at-floor degenerate arm. The #664 finding that content gate SNR co-varies with
install magnitude is the reason §6 registers an **install-strength control** as a
required headline read.

## 3. Hypothesis (per arm; falsifiable predicate + falsifier)

Throughout, the PRIMARY DV is the **activation realized gate** `ĝ^real` (B1); the
behavioral DV `E` (judge over on-policy completions) is the SECONDARY companion. The
pre-registered **primary read layer per behavior** is #658's locked read-out layer
(C3); the 28-layer sweep is exploratory (FDR). Verdicts are reported with
family/source-clustered bootstrap CIs against the probe-split reliability floor (C4).

- **A3.6 (base read-out valid post-FT, `r⁺≈r`).** *Predicate:* base `r_{B'}ᵀ(v⁺−v0)`
  predicts the measured change `(E⁺−E0)` with `E0` PARTIALLED OUT (C10), Spearman ρ
  above the reliability floor. `cos(r⁺,r)` high (diagnostic only). *Falsifier:* partial-ρ
  indistinguishable from zero (base read-out predicts only the level via the prior, not
  the change) — read-out does not survive FT. PRIMARY DV = behavioral change (this arm is
  about the read-out, not the gate).
- **A3.6a (context vector stable, `c⁺≈c0`).** *Predicate:* `‖c⁺−c0‖²_W < s_W(C)` (drift
  smaller than within-condition spread), `cos(c0,c⁺)` high. *Falsifier:* displacement
  exceeds the within-condition spread → A3.10 robustness load-bearing (characterization,
  not a hard fail). PRIMARY DV = activation (`c_C` from the store).
- **A3.6b (context→profile map stable, `M⁺≈M0`).** *Predicate:* base map `M0·(c⁺−c0)`
  predicts the change `v⁺−v0` (v0 partialled out) within the refit-`M⁺` noise floor.
  *Falsifier:* prediction-transfer ρ below the refit floor → map does not transfer.
  PRIMARY DV = activation change.
- **A3.6c (causal context-vector patch; the GPU arm).** *Predicate:* `f_CV ≈ 1`
  (P↑θ0+c⁺→(v⁺,E⁺) ∧ P↓θ⁺+c0→(v0,E0)) ⇒ leakage carried by the context vector (input);
  `f_CV ≈ 0` ⇒ carried by the map (function). *Falsifier of "input-localized":* patches
  do not move the profile toward the FT shift (`f_CV` indistinguishable from the random-CV
  floor) OR self-patch nulls are not no-ops (measurement artifact). PRIMARY DV = both `v`
  AND `E` (the causal read needs both).
- **A3.7 (FT displaces source toward data target).** *Predicate (positive-only arm,
  PRIMARY/clean per B5):* `cos(ŵ,δ)` (δ=t−v0) EXCEEDS a shuffled-δ null (cos of a
  different behavior's δ), small scalar-fit residual. *Contrastive arm (diagnostic):*
  `cos(ŵ,δ^contra)` with `frac_ctx=‖v0(C)−v0(C_neg)‖/‖δ^contra‖` reported alongside.
  *Falsifier:* positive-only cos not above the shuffled-δ baseline → the source write is
  not aligned with the data displacement. PRIMARY DV = activation.
- **A3.8 (off-source = scalar-gated source write, rank-one).** *Predicate:* per-target
  rank-one residual `‖Δv(C')−ŵĝ^real‖/‖Δv(C')‖` small; stacked ΔV near rank-one
  (σ₁²/Σσ² high, σ₂/σ₁ low, cos(u₁,ŵ) high). *Falsifier:* large residuals / ΔV high-rank
  → the gate is not scalar (low-rank fallback). PRIMARY DV = activation (`ĝ^real`).
- **A3.9 (gate = normalized key–query similarity).** *Predicate (two verdicts, B1/B3):*
  (i) SOME key/metric beats raw cosine in predicting `ĝ^real` (general gate exists);
  (ii) `c_C` key + `Σc⁻¹` metric SPECIFICALLY wins (boxed predictor). Key ablation
  {c_C, ψ(t), ψ(δ), c_C+ψ(δ)}; metric ablation {I, diag(Σc+λI)⁻¹, (Σc+λI)⁻¹}.
  *Falsifier:* no key/metric beats cosine (i fails) OR c_C+Σc⁻¹ does not beat the other
  cells (ii fails — a general gate without the boxed form). PRIMARY DV = activation.
- **A3.10 (base gate predicts realized gate; central claim).** *Predicate:* `g⁰` predicts
  `ĝ^real` ≈ as well as the oracle `g⁺` (no fatal drift) at fixed base metric M⁰, Spearman
  ρ above the floor AND above the base-behavior-prior. *Falsifier:* `g⁰` ρ at/below the
  floor while `g⁺` is well above → fatal gate-relevant drift, base-model prediction fails.
  PRIMARY DV = activation. Drift decomposition (key/query, metric folded into residual
  unless the opt-in Σc⁺ pass runs) localizes any failure.
- **Joint factorization.** *Predicate:* latent `S_{ij}=r_{B'_j}ᵀΔv(C'_i)` near rank-one
  (σ₁²/Σσ² high) AND `L̂_{C',B'}≈L̂_{C',B}·L̂_{C,B'}/L̂_{C,B}` (no interaction).
  *Falsifier:* S high-rank / multiplicative identity violated → behavior × context do not
  factorize. PRIMARY DV = activation (latent Δs scale).
- **Single-context arm (§1.10).** *Predicate:* per-prompt geometry predicts per-prompt
  leakage `δ_x→δ_{x'}` (continuous DV primary) ABOVE the within-context noise floor.
  *Falsifier:* per-prompt ρ within the within-context floor → measurement noise, NOT a
  falsified assumption (reported as such, never as a fail).

### A3.6 — base read-out valid post-FT (CPU)
- *Inputs:* `v_plus`, `v0` (the change `v⁺−v0`), `r_B` (base read-out, #658 recipe),
  the behavioral `E⁺`/`E0` (§6 judge recompute).
- *Statistic:* partial-Spearman ρ between predicted change `r_{B'}ᵀ(v⁺−v0)(C')` and
  measured change `(E⁺−E0)(C')`, `E0` partialled out (C10); `cos(r⁺,r)` where `r⁺`
  refit on the trained store (diagnostic). Per behavior × layer; source + bystanders.
- *Controls:* base-behavior-prior `E0(C',B')=r_{B'}ᵀv0(C')` partialled out; shuffled-`r_B`.
- *Comparison:* against the probe-split reliability floor + the base-prior null.

### A3.6a — context vector stable across FT (CPU)
- *Inputs:* `c_C_base` (c0), `c_C_trained` (c⁺), `v0_probe` (within-condition spread input).
- *Statistic:* per context (source + bystanders) × layer: `cos(c0,c⁺)`, rel-norm
  `‖c⁺‖/‖c0‖`, displacement `‖c⁺−c0‖²_W` vs within-condition spread `s_W(C)` (W=I then
  `(Σc+λI)⁻¹`); pre-registered kernel `‖c⁺−c0‖²_W < s_W(C)`.
- *Controls:* same metric W for displacement + spread (no metric mismatch).

### A3.6b — context→profile map stable across FT (CPU)
- *Inputs:* `c_C_base`, `c_C_trained`, `v0`, `v_plus`, the base map `M0` (refit here from
  `c_C_base→v0` by ridge at #658's CV-chosen λ/k; #658 stored A3.5 λ — **Decision: default
  λ=1e-2 if #658's exact A3.5 λ is not recoverable from `a34_a35.json`, swept {1e-3,1e-2,1e-1}**).
- *Statistic (primary, change):* partial-ρ between `M0·(c⁺−c0)` and `(v⁺−v0)` (v0 level
  partialled out) vs the refit-`M⁺` noise floor. *Operator companion:* refit `M⁺:c⁺→v⁺`
  at the same λ/k; `‖M⁺−M0‖/‖M0‖` + principal angles of the top-k subspaces.
- *Controls:* refit-`M⁺` noise floor as the ceiling; shuffled-`c` null.

### A3.6c — causal context-vector patch (GPU; the ONE GPU arm)
- *Inputs:* the #664 fleet adapters (`adapters/issue_664/<cell>/`, 48 verified present) +
  base Qwen-2.5-7B-Instruct; `c_C_base`/`c_C_trained` from the store (the patch vectors).
- *Procedure:* at read layer L, per context (source + ≤8 representative bystanders) × cell:
  **P↓** run θ⁺ (base+adapter) with the layer-L context-position residual overwritten with
  base `c0(C)`; **P↑** run θ0 (base) with the layer-L context position overwritten with
  `c⁺(C)`. Read the answer profile in BOTH the activation DV `v` (mean answer-side residual)
  AND the behavioral DV `E` (on-policy judge over the patched generation).
- *Statistic:* `f_CV` = patch effect projected onto the FT shift `d=(v⁺−v0)/‖·‖` (and the
  `E` analog). `f_CV≈1` ⇒ context vector moved (input-localized); `f_CV≈0` ⇒ map changed.
- *Controls:* self-patch identity null (`c0→c0`, `c⁺→c⁺` MUST be no-ops — measurement
  validity gate); random/other-context-CV floor (patch a random or wrong-context CV);
  norm-matched variant (rescale `c⁺`→`‖c0‖`, separates direction from magnitude);
  patch-scope {last-input-token primary, full-context-span upper bound}; L-sweep {7,14,21}.
- *Scope decision:* run A3.6c on a representative subset — **the 2-4 highest-install
  content cells** (bad-medical default+librarian, taught-fact default) × source + 8
  bystanders × 3 layers × 2 scopes × {P↑,P↓,2 nulls,norm-matched} — to bound the GPU arm
  (~6 GPU-h). The CPU arms (A3.6a/b) supply the correlational complement on the full grid.

### A3.7 — source-write displacement (CPU)
- *Inputs:* `r_plus` (ŵ=Δv(C) at source), `t_CB` (target activation), `v0` (δ=t_CB−v0(C));
  for the contrastive arm, `t⁻` is NOT separately stored — **Decision: the store lacks
  `t⁻`, so `δ^contra=t⁺−t⁻` cannot be formed from the store alone; report the positive-only

- *Controls:* shuffled-δ baseline (the PRIMARY null — ŵ and δ are both displacements from
  v0(C), so cos>0 is partly expected; the falsifier is cos > shuffled, not cos > 0).

### A3.8 — rank-one gated write (CPU)
- *Inputs:* `v_plus`, `v0` (Δv(C') per target), `r_plus` (ŵ at source).
- *Statistic:* `ĝ^real(C')=ŵᵀΔv(C')/ŵᵀŵ` (import `gate_per_layer`); per-target rank-one
  residual `‖Δv(C')−ŵĝ^real‖/‖Δv(C')‖`; stack ΔV over bystanders, report σ₁²/Σσ², σ₂/σ₁,
  cos(u₁,ŵ). Low-rank fallback (m=2,3) if rank-one fails.
- *Controls:* shuffled-context ΔV (the residual under a permuted target set).

### A3.9 — key–query gate, key/metric ablations (CPU; net-new whitened code, B3)
- *Inputs:* `c_C_base` (key + query candidates), `t_CB`/δ (ψ candidates), `Σc` (metric).
- *Statistic:* predicted gate `g^pred(C')=kᵀMq_{C'}/kᵀMq_C` vs `ĝ^real`; Pearson/Spearman/
  sign/MAE. Key ablation {c_C, ψ(t), ψ(δ), c_C+ψ(δ)} (ψ=identity with co-layer extraction
  default; ψ=M for cross-layer); metric ablation {I, diag(Σc+λI)⁻¹, (Σc+λI)⁻¹}. vs raw
  `cos(c_C,c_C')`. **The whitened gate clears the §5 reduction unit test first (B3).**
- *Controls:* shuffled-key / shuffled-query; denominator stability `|kᵀMq_C|`.
- *Verdicts (separate, B1):* (i) some key/metric > cosine; (ii) c_C+Σc⁻¹ specifically wins.

### A3.10 — base-gate validity + drift decomposition (CPU)
- *Inputs:* base `g⁰` (k⁰=c_C_base, q⁰=c_C_base, M⁰=Σc⁻¹), oracle `g⁺` (k⁺/q⁺ from
  c_C_trained, M⁰ held at base per the test-plan default), `ĝ^real`.
- *Statistic:* `g⁰` vs `ĝ^real` (Pearson/Spearman/sign/MAE) across held-out C'; `g⁺`
  diagnostic; key+query drift decomposition (g(k⁺,q⁰,M⁰), g(k⁰,q⁺,M⁰)); metric drift
  folded into an UNATTRIBUTED residual unless the opt-in Σc⁺ pass runs (test-plan default;
  **all default verdicts labeled "at fixed base metric M⁰"**). residual ≈ A_drift·(c⁺−c0).
- *Controls:* base-behavior-prior partialled out (C7/C10); clustered CIs + probe-split
  replication (C4).
- *Opt-in (budgeted, conditional):* one background-corpus pass on a single representative
  θ⁺ for Σc⁺, run ONLY if the M⁰-scoped residual is large + unexplained by key/query drift
  (GPU; folded into the A3.6c provision if it fires).

### Joint factorization (CPU)
- *Inputs:* `v_plus`, `v0`, `r_B` per behavior (the latent `S_{ij}=r_{B'_j}ᵀΔv(C'_i)`).
- *Statistic:* σ₁²/Σσ², rank-one residual of S; multiplicative identity
  `L̂_{C',B'}≈L̂_{C',B}·L̂_{C,B'}/L̂_{C,B}` (no-interaction check).

### Single-context arm (§1.10, CPU)
- *Inputs:* the per-probe granularity `v_plus_probe`/`v0_probe` (50 probes/context).
- *Statistic:* per-prompt `δ_x→δ_{x'}` gate prediction (continuous DV primary), reported
  vs the within-context noise floor (probe-split half-mean differences). A3.8/A3.9/A3.10
  each get a `C=δ_x` single-context variant on the highest-install content cell.

**Why code, not a model call?** The gate statistics (ĝ^real, whitened g_C, rank-one
residuals, drift decomposition, joint factorization) are deterministic linear algebra over
stored activation tensors — there is no unstructured-data heuristic, no classification/
parsing of free text in the CPU arms, so a code path is required (a model call cannot
compute `ŵᵀΔv/ŵᵀŵ`). The ONE place a model is in the loop is the behavioral DV `E` (judge
over completions) — that uses the standard Claude judge (§6), not a code heuristic, because
scoring whether a generation expresses the behavior is exactly the unstructured-text
judgment a code substring-match would get wrong (project rule: no substring match for
behavior eval).

**Contrastive negatives / completion provenance / persona vectors / marker stopping /

## 11. Decision Rationale

- **Read scope = content spine primary, marker degenerate.** *Why:* #664 kill (a)+(b) —
  the marker never installed (‖ŵ‖≈1.2 nat, ~17–42× below content), so its gate is at the
  noise floor and yields no ground truth. The content cells install on-policy and carry
  gate dynamic range. *Source:* #664 clean-result. *Alt rejected:* marker-primary (gives
  a null read of measurement noise, not a test of the assumption).
- **Per-behavior read layer from #658's read-out lock.** *Why:* the gate must be read where
  the behavior's linear read-out exists (C3 single primary path). harmful_compliance L8
  (ρ=0.692), broad_em L0 (ρ=0.444, +L13 sensitivity for the embedding-layer caveat),
  fact_expression L2 (a32, weakest — flagged). *Source:* #658 assumption_verdicts.json.
  *Alt rejected:* a single fixed layer for all behaviors (#664's L14 is a reference, not
  the per-behavior optimum); best-of-28 (selection-biased — exploratory only).
- **`c_C` = last-input-token.** *Why:* #658 locked it (held-out ridge-cos 0.307 vs
  mean-prompt 0.209). *Source:* #658 locked_recipe.json. *Alt:* mean-prompt (within 0.02
  margin, swept as sensitivity).
- **Whitened metric `(Σc+λI)⁻¹`, λ=1e-2 default (swept {1e-3,1e-2,1e-1}).** *Why:* the
  paper's boxed gate uses `Σc⁻¹`; regularization is needed for the 3584×3584 inverse;
  λ chosen to stabilize the inverse without over-shrinking. *Source:* paper §a:bilinear-gate
  (`M=(Σc+λI)⁻¹`). *Alt:* unregularized Σc⁻¹ (numerically fragile, rejected); diag-only
  (the metric-ablation arm, kept as a control).
- **A3.6c L-sweep {7,14,21}, patch-scope {last,full}.** *Why:* the layer grid IS the
  manipulated variable (input-vs-map localization across depth); the three values bracket the
  per-behavior locked read-out layers Phase 3 reads (harmful_compliance L8, broad_em L13
  sensitivity, fact_expression L2 sit at/below 7/14, with 21 a late-depth upper bound) so the
  patch effect is measured at, below, and above the read layers. *Source:* #658
  assumption_verdicts.json (the locked read-out layers the grid brackets) + test-plan §4 A3.6c
  (the input-vs-map localization design). *Alt:* single layer (loses the pre-vs-post-L
  localization the mixed-`f_CV` case needs).
- **FDR α=0.05, clustered bootstrap B=2000.** *Why:* C3 multiple-comparison + C4 shared-store
  dependence. *Source:* test-plan §1.7 (C3/C4). *Alt:* naive n=50 CI (banned by C4).
- **Behavioral DV `E` via Claude Sonnet 4.5 Batch judge.** *Why:* dual-DV requirement +
  closes the #664 `judged_rates` gap; project judge policy. *Source:* CLAUDE.md judge rule.
  *Alt:* substring match (banned for behavior eval).
- **A3.7 positive-only `cos(ŵ,δ)` primary, `δ^contra` deferred.** *Why:* B5 — the
  positive-only arm is the clean theory-faithful identification test; `δ^contra=t⁺−t⁻`
  needs `t⁻` which the store does NOT hold, so fabricating it would violate B5/R3-1.
  *Source:* test-plan §1.5 (B5), §4 A3.7. *Alt:* invent `δ^contra` from available tensors
  (rejected — would not be the theory's δ).
- **No training, no marker recipe.** *Why:* Phase 3 is CPU analysis on a fixed store; the
  marker stopping recipe / parent parity rules are N/A (nothing trained).
