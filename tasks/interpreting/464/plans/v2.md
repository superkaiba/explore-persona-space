## 0.0 TL;DR

- **What I'll run:** Earlier in this issue I found that when a persona is announced by a single bare word ("You are a pirate." vs a bare `pirate` role header), the role header still localizes a trained end-of-response marker better — but I only checked that in the strongest training setup, where two personas compete on the same model. I'm now re-running the same bare-word comparison in the gentler setup, where one persona is trained with "don't do this" examples for the other persona and the plain assistant. 12 small fine-tunes, about 2 hours on one GPU, almost entirely reusing code that already ran clean twice.
- **What I expect:** the role header keeps a small edge (around 1 nat, like it did with the wordy persona descriptions in this setup), showing that edge wasn't an artifact of the wordy system prompt.
- **What would change my mind:** if the edge vanishes or flips once both sides use one bare word, then the role header's advantage in this setup came from the elaborate system instruction being leaky, not from the role slot itself. Also possible: every cell lands so close to the measurement floor that the comparison is too compressed to call — the same caution flag this setup raised last time — in which case I report it hedged, exactly as before.
