L̂ vs cosine + base-prior + noise floor

Estimated GPU-hours (total): 2 (expected 0; pure CPU analysis on Phase-2's store)  ·  TDD: yes  ·  Backend: auto-lane (GCP-first)

TL;DR (plain English)

  • What I'll run: I take the activation snapshots Phase 2 already saved (one per trained model, no new training) and assemble the theory's full leakage-prediction formula. Then I check, for each trained behavior, whether that formula correctly ranks which other contexts the behavior leaks into — and I race it against three simpler guesses: a plain cosine-similarity version, "just use the model's own baseline tendency," and "predict nothing."
  • What I expect: On the content behaviors (taught-fact, bad-medical) the full formula ranks leakage targets meaningfully better than chance and at least as well as the cosine version. But I expect the model's own baseline tendency to be a stubbornly strong competitor — in three past experiments it beat geometry — so the honest headline is "does our formula beat the base-rate guess after we strip out how strongly the behavior got installed." On the marker behavior I expect the formula to be useless, because Phase 2 showed the marker never actually installed, so there is no real signal to predict.
  • What would change my mind: If the full whitened formula clearly beats both cosine and the base-rate guess on content behaviors even after controlling for install strength, that's a real win for the theory. If instead the base-rate guess wins everywhere, the theory's geometry story doesn't add predictive value on this model — also a clean, publishable answer.

2. Prior Work

The theory under test (docs/leakage_theory_paper.tex): the boxed predictor is L̂_{C,B→C',B'} = η_{C,B} · (r_{B'}ᵀδ_{C,B}) · [c_Cᵀ Σc⁻¹ c_{C'}] / [c_Cᵀ Σc⁻¹ c_C] with δ = t_{C,B} − v_{θ0}(C). The cosine special-case (§Relation-to-cosine): L̂^cos ∝ cos(r_{B'},r_B)·cos(c_C,c_{C'}) = L̂ in the limit (i) δ ∥ r_B, (ii) ‖r_{B'}‖,‖c_{C'}‖ constant, (iii) Σc ∝ I. These three toggles are the ONLY allowed differences (C7). η drops out of all relative tests at a fixed source and is recoverable from one on-source measurement: η = L̂_{C,B→C,B}/(r_Bᵀδ).

What Phase 2 (#664) delivered + recoverable: the trained store has, per cell, v_plus/v0, v_plus_probe/v0_probe (probe-split noise floor), c_C_base (= the BASE context vector c0(C') per battery context — the key Phase-4 input), c_C_trained (q⁺ diagnostic), t_CB (= t), r_plus (implant shift at source), v0_neg, context_ids, and meta.json roles/behavior/source/arm/dose/seed. Scientific caveat carried forward: the marker spine NEVER installed (source log P trained−base = −0.34 to +1.81 nat, never the 5-12 band; ‖ŵ‖≈1.2, ~17-42× below content) → marker gate at the probe-split noise floor (kill (a)+(b)). Content-behavior gate SNR co-varies with install magnitude — designed null cells clear the floor as strongly as real behaviors. judged_rates.json aggregate NOT produced this round but recomputable from per-cell completions on HF.

The recurring null (#532/#541/#649): base-model behavior prior beats geometry for the absolute level; geometry predicts the shift. → frame the latent Δs (a shift) as where geometry has a chance; ALWAYS include the base prior; a geometry win counts only after the install confound is partialled out. #637: rank-1 leak-transfer generalizes OOS for marker + taught-fact but FAILS for content → expect A3.8 rank-one behavior-dependent.

Published precedent: the latent Δs projection is exactly the activation-space trait-change projection of Persona Vectors (Chen/Arditi/Sleight/Evans/Lindsey, arXiv 2507.21509 — the paper's §Evaluation cites chen2025 for the Pearson-r comparison). The OpenAI persona-features-control-EM paper (Wang et al., arXiv 2506.19823, Mossing) motivates the leakage-as-conditional-behavior framing. Phase 4 produces THE paper's headline table — the first end-to-end test of whether the boxed whitened-context-gate predictor beats a plain cosine predictor on an open-weights model with full activation access (the project's comparative advantage; the sibling papers used GPT-4o and could not measure the latent activation Δs directly).

3. Hypothesis

  • H1 (latent, content): On content behaviors with install dynamic range (taught-fact, bad-medical; EM where ‖ŵ‖ permits), full L̂ Spearman ρ vs Δs (LOBO + LOCO) EXCEEDS apples-to-apples cosine ρ AND base-prior ρ, non-overlapping family-clustered 95% CIs, after install magnitude (‖ŵ‖) is partialled out. Falsified if L̂ ρ ≤ base-prior ρ once install is partialled out (a clean #532/#649 null, also publishable).
  • H2 (cosine isolation): L̂ beats L̂^cos because of the three toggles, isolated by toggling one at a time on the shared frozen recipe. Falsified if the whitened gate does not beat raw cosine (A3.9 verdict (ii) fails).
  • H3 (behavior scale): after per-behavior affine φ (TRAIN only), calibrated MAE of L̂ near φ's affine mid-range below predict-mean and base-prior MAE.
  • H4 (marker sentinel): marker L̂ ρ FLOORS at the noise floor (no install → no signal). Pre-registered EXPECTATION, not a kill — the marker validates the harness reports "no signal" where Phase 2 proved none.
  • Thresholds: "beats" = point estimate higher AND clustered-CI lower bound above the comparator's point estimate; "near floor" = ρ within the test-retest ceiling (a ρ at the floor is the ceiling, not a failure).

4c. Net-new whitened-gate + Σ_c module (src/.../analysis/leakage_predictor.py) — TDD-first

4d. Assemble L̂ (scripts/issue666_predictor.py)

Per cell (source C, behavior B) × target C' × evaluated B': L̂ = η · (r_{B'}ᵀ δ) · g_C(C'), δ = t_CB − v0[src_idx] (positive-only; δ^contra a contrastive-cell-only sensitivity, read with frac_ctx). Relative tests drop η. Grid: behavior-transfer (vary B' at fixed C), context-gate (vary C' at fixed B). The source-anchor (ĝ^real(C)=1) EXCLUDED from the bystander correlation (same as #664).

4e. Apples-to-apples cosine (--variant cos)

L̂^cos ∝ cos(r_{B'},r_B)·cos(c_C,c_{C'}) from the SAME r_B, c_C, layer 14, recipe — toggling ONLY δ→r_B / drop norms / Σc⁻¹→I as three independent booleans so each toggle's marginal contribution is isolable (C7). Also the raw un-whitened cosine gate + predict-zero/predict-mean.

4f. Base-behavior-prior (--variant prior)

E0(C',B') = r_{B'}ᵀ v0(C'). Two reports (C7): (1) partial Spearman ρ(L̂, Δs | E0) — install-confound-clean headline; (2) ΔS predictive power above prior. Install control (§6 required): L̂ ρ with ‖ŵ‖ partialled out + leakage-as-fraction-of-install in EOS-margin logit space for the marker sentinel (NEVER raw log P). Never correlate the fraction back against install (#383 family).

4g. LOBO + LOCO (scripts/issue666_lobo_loco.py)

LOBO (hold out one of {marker, bad-medical, EM, taught-fact}); LOCO (hold out one battery context). φ = per-behavior monotone affine link fit on TRAIN only. Latent-scale tests need no φ; φ only for the behavior-[0,1]-scale MAE.

4h. η recovery (--recover-eta)

η = Δs_on-source / (r_Bᵀδ), Δs_on-source = r_Bᵀ r_plus. Anchor = bm_default_contra_d1_seed42 (highest-install content cell, #664 SNR 7.55). η needed only for the cross-source/absolute arm (sensitivity).

4i. Noise floor (scripts/issue666_noise_floor.py)

Test-retest ρ between two independent probe-split halves of v_plus_probe/v0_probe (reuse probe_split_floor half-split), recompute Δs per half. MC: 200 resamples × 3 seeds. Every headline ρ reported against this floor. Single-context arm raises the continuous-DV primary per §1.10.
