## 0.0 TL;DR (plain English)

- **What I'll run:** In the last experiment, the reference model we compare everything against assigned more probability to the marker token whenever a role prompt ("you are a doctor", "you are a French person", ...) was in the context. But we measured that on text the fine-tuned models had written. Here I ask the plain, untrained model to write its own answers under the same five role prompts and the same questions, and read its marker probability at the end of its own answers. No fine-tuned model is involved anywhere.
- **What I expect:** The rise shows up again. That would mean the role prompts themselves push the plain model's marker probability up, so any "trained minus base" comparison read under a role prompt has a moving reference point regardless of what was trained.
- **What would change my mind:** If the rise vanishes when the plain model writes its own answers, then the effect was carried by what the fine-tuned models wrote, and the parent finding needs a scope caveat. A side question either way: if the French-person prompt is again the biggest mover, the unexplained French anomaly from the parent lives in the plain model, not in the training.

## 1. Goal + Hypothesis

**Goal (canonical, from frontmatter):** Determine whether the persona-prompt-driven rise in the base model's marker prior (the main driver of the contrast shrinkage in #558) is intrinsic to the base model's context processing or depends on the fine-tuned models' completion content, by reading the base model's 4-float slot statistics at the end of its OWN greedy completions under the same five system-prompt contexts with no adapter in the loop.

Goal is sharp; no refinement proposed. N/A — not a replication of a published finding.

**Hypothesis (registered):** The base-prior rise reproduces on base-own completions. Quantitatively: in ≥3 of the 4 persona cells, the paired per-question Δ base log P(marker) vs the assistant cell is positive with 95% CI excluding 0 and magnitude ≥ 0.5 × that cell's #558 rise (#558 rises, 12-adapter means on FT completions: doctor +0.505, software engineer +0.484, French person +1.438, police officer +1.156 nats; recomputed this session from `eval_results/issue_558/rollup.json` `cell_summaries`).

**Falsification:** ≥3 of 4 persona cells FLAT (95% CI upper bound < 0.5 × that cell's #558 rise) → the rise measured in #558 was carried by the fine-tuned models' completion content, and #558 finding 2 takes the scope caveat "on fine-tuned-model completions".

**Bonus read (registered, secondary):** French-person base-side localization — if Δ_french − mean(Δ_doctor, Δ_swe) ≥ +0.5 nats with the paired-bootstrap CI of that difference excluding 0, the #558 French over-dip localizes to the base model's context processing (parent gap on FT completions: 1.438 − 0.494 ≈ +0.94 nats; threshold = half).

## 5. Evaluation

**Primary DV:** paired per-question Δ base log P(marker id 83399) at the end-of-own-completion slot: persona cell − Plain-assistant cell, same question, n=250 pairs per persona cell.

**Measurement validity (construct / metric / distribution):**

| DV | Construct (what the Goal cares about) | Metric (computed) | On-distribution? | If proxy |
|---|---|---|---|---|
| Base marker prior per context | the marker log-prob the base model assigns at the natural end of an answer it would itself produce under context c | mean log P(83399) at the final slot of the base model's OWN greedy completion (HF forward, teacher-forcing only the model's own text back) | **yes — on-policy by construction**; this run exists to replace the parent's off-policy base-side read (base prior on FT completions) | n/a — not a proxy |
| Cross-context rise | whether the persona prompt itself moves that prior | paired per-question Δ vs assistant cell | yes | n/a |
| Secondary (mechanistic) | same movement free of softmax compression | Δ EOS-margin (z_marker − z_eos), paired; plus Δz_marker and ΔlogZ decomposition | yes | Logit reads need no gauge check here: there is NO adapter, both sides of every contrast come from the SAME frozen model, so W_U is identical by construction. Cross-context raw z_marker is still not gauge-clean (common-mode shifts differ per context); the EOS margin is the gauge-invariant logit read, per `.claude/rules/marker-leakage-measurement.md`. |
| Sanity | probability-space read | mean exp(logp) per cell (expect ~1e-10–1e-9) | yes | sanity only |

All three spaces reported in the rollup, per the project rule. Where Δlog P and Δ(EOS margin) disagree in sign or grossly in magnitude, the logZ decomposition is reported next to them (the parent's French cell had the panel's worst logp-vs-z_marker agreement; the same diagnostic is computed here).

**Uncertainty:** ONE model, so the resampling unit is the question: 10,000-draw paired bootstrap over the 250 question indices, seed 563, percentile 95% CI per cell mean. Grounding for expected precision (computed this session from the parent's committed per-row r50_seed42 base-side stats): per-question paired SD 1.78–2.19 nats → SE ≈ 0.11–0.14 at n=250 (vs 0.25–0.31 at n=50, which cannot resolve the two +0.48/+0.51 cells — the reason for divergence 2). Sign counts + Wilson CI as the distribution-free robustness read.

**Registered classification rule** (per persona cell c, with R_c = that cell's #558 base-side rise: doctor +0.505, swe +0.484, french +1.438, police +1.156):

- **REPRODUCES:** 95% CI of Δ_c excludes 0 from below AND mean Δ_c ≥ 0.5 × R_c.
- **FLAT:** 95% CI upper bound < 0.5 × R_c (rules out half the parent effect).
- **INDETERMINATE:** otherwise (reported as such; no forced call).

**Panel verdict:** **intrinsic-context** if ≥3/4 cells REPRODUCE; **completion-content** if ≥3/4 cells FLAT; **mixed** otherwise (per-cell reads stand on their own). The 0.5×R_c scaling follows the parent's instrument-scaled threshold convention (#558's T_dip = 0.6 × within-run doctor re-read = −1.647 nats); the half-effect fraction is the registered split between "most of the rise is context-intrinsic" and "most of it was completion-carried".

**Bonus read:** French localization per §1 (gap ≥ +0.5 nats with CI excluding 0).

**Robustness recomputes (free, registered):** (a) excluding truncated rows; (b) excluding French-language-flagged rows in the French cell; (c) [0:50] parent-parity subset vs full 250.

## 7. Decision Gates

**No scientific gates — short run (<1 GPU-h), pre-verified instrument.** The instrument anchor (§3.2) is a launch-validity assert (an adapter-application-check analogue), not an intermediate scientific decision gate; it fires once, before any panel generation, and hard-stops on breach.

**Kill criteria:**
1. `marker_preflight` FAIL (` ※` ≠ [83399], bare ※ collision, EOS ≠ 151645) → abort; tokenizer drift.
2. Instrument anchor breach (mean |Δlogp| > 0.05 OR max |Δlogp| > 0.20 nats over the 50 re-read rows) → halt before generation; diagnose attn implementation / dtype / batch shape; zero panel GPU spend.
3. Assistant-cell base mean log P outside the chain's b̂ sanity range (−30, −15) → template/slot breakage or contaminated read; halt and diagnose (Source: #543 b̂ diagnosis, measured −25.88).
4. Truncation rate > 20% in any cell → that cell's natural-end slot is invalid; re-run the cell with `max_new_tokens=3072` (fits `max_model_len=4096` with ~80-token prompts; allowed deviation, logged).
5. >10% of any cell's completions under 5 generated tokens → severe degeneration; classification proceeds with the scope caveat + the registered excluding-degenerate robustness recompute.

**Jointly satisfiable:** criteria 1–3 are instrument checks that any healthy run passes (the parent passed all three equivalents); 4–5 are per-cell data-quality bounds with non-contradictory remedies. No two demand opposite outcomes on the same measurement.
