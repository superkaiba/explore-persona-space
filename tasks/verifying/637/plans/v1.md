# Plan v1 — Issue #637: Is leakage-transfer asymmetry low-rank (per-context source-breadth + receptivity), not pairwise interaction?

`kind: analysis` · parent #526 · 0 GPU · autonomous-mode

---

## §0.0 TL;DR (plain English)

- **What I'll run:** When you teach a behavior into context A, it "leaks" into other context B at some strength — and the leak A→B is not the same size as B→A. I already measured how much of that asymmetry can be explained by a simple rule: every context has a "how broadly it spreads" number and a "how easily it catches things" number, and the gap between A and B's numbers predicts the direction of the asymmetry. The earlier check said yes for the marker behavior (a simple 2-number-per-context rule explains ~95% of the asymmetry) but only partly for refusal / sycophancy / emergent-misalignment (~35-44%). But that earlier check fit and scored on the *same* cells, so it could be flattering itself. This run re-does it honestly: fit the simple rule on 80% of the context pairs, then score it on the held-out 20% it never saw — and compare against both a no-asymmetry baseline and the full all-pairs model.
- **What I expect:** For the marker, the simple 2-number rule will still beat the no-asymmetry baseline out-of-sample (the ~95% was real, not overfitting). For refusal / sycophancy / emergent-misalignment, the "leftover" structure that looked like it needed a full pairwise rule will mostly evaporate out-of-sample — I bet a lot of that 56-65% was just noise the full model memorized.
- **What would change my mind:** If the full all-pairs model still clearly beats the simple 2-number rule on cells it never saw, that's real pairwise structure, and the leakage rule genuinely has to be more than per-context broadcast + receptivity — which would make the downstream theory (#526) meaningfully harder.

## §1. Goal

Decide how complex the directional leakage predictor `g(source_context, eval_context, behavior)` must be, by testing whether the directional ASYMMETRY of behavior-transfer is **low-rank** — explainable by one per-context "source breadth" scalar `b_i` and one per-context "receptivity" scalar `r_j` (a rank-1 additive antisymmetric structure) — rather than requiring a **full pairwise interaction** term. The parent theory task #526 (Dan's "the leakage rule must be asymmetric AND behavior-dependent") needs to know the minimal functional form of `g`; this analysis answers #526's "how complex must `g` be?" gate by reading it off the #537 16×16-per-behavior transfer matrices. The landed #526 analysis answered this **in-sample**; this issue re-answers it **out-of-sample** (held-out cross-validation) so the rank-1 verdict is not an artifact of fitting and scoring on the same cells.

## §3. Hypothesis

Let `ΔR²_scalar = R²_heldout(sym+scalar) − R²_heldout(sym-only)` and `ΔR²_full = R²_heldout(full-pairwise) − R²_heldout(sym+scalar)`, per behavior, with bootstrap 95% CIs over held-out cells.

- **H1 (rank-1 asymmetry is real for the marker):** for the marker, `ΔR²_scalar` 95% CI excludes 0 (the per-context breadth/receptivity scalars carry genuine out-of-sample signal) AND `ΔR²_full` 95% CI **includes** 0 (no detectable pairwise structure beyond rank-1). **Confirms** the in-sample marker verdict ("scalar=0.95, residual=0.05") survives held-out. **Falsifies** if `ΔR²_scalar` CI includes 0 → the in-sample 0.95 was overfit.
- **H2 (the "needs full pairwise" verdict for refusal / sycophancy / EM is partly train-set overfit):** for refusal / sycophancy / EM, `ΔR²_full` 95% CI **includes 0** for at least 2 of the 3, i.e. the in-sample 56-65% residual-pairwise shrinks out-of-sample and does not beat the rank-1 model on held-out cells. **Confirms** if held-out full-pairwise is indistinguishable from sym+scalar. **Falsifies** if `ΔR²_full` CI excludes 0 for all 3 → the residual pairwise structure is real, and `g` genuinely needs a full interaction term for non-marker behaviors.
- **Quantitative thresholds:** a behavior is called "rank-1 sufficient (held-out)" iff `ΔR²_scalar` CI excludes 0 and `ΔR²_full` CI includes 0; "needs pairwise (held-out)" iff `ΔR²_full` CI excludes 0; "asymmetry not recoverable out-of-sample" iff both `ΔR²_scalar` and `ΔR²_full` CIs include 0 (the asymmetry is noise-limited at this N).

### The three predictors (exact definitions, fit on TRAIN cells, scored on TEST cells)

Let `M` be the 16×16 transfer matrix for a behavior, off-diagonal cells indexed by `(i,j)`, `i≠j`. Split off-diag indices into `train` (192) and `test` (48).

1. **Symmetric-only** — `g_sym(i,j) = (M_ij + M_ji) / 2`. Note `M_ji` is itself an off-diagonal cell; to keep the held-out test honest, the symmetric prediction for a TEST cell `(i,j)` uses the *transpose-paired value `M_ji`* only when `(j,i)` is in TRAIN; if `(j,i)` is also in TEST, the symmetric prediction uses the train-fitted **symmetric two-way mean** `μ_sym + s_i + s_j` from a symmetric additive fit on train cells (so no test-cell value leaks into its own prediction). This is the rank-0-antisymmetry baseline.
2. **Symmetric + scalar** — `g(i,j) = g_sym(i,j) + (b_i − r_j)`, where `b` (source breadth) and `r` (receptivity) come from `fit_two_way_additive(M_train)` restricted to TRAIN cells (REUSED function; the additive antisymmetric part is exactly `(b_i − r_j)` minus its symmetric component, i.e. the rank-1 antisymmetry). The symmetric part `g_sym` is the same train-fitted symmetric mean as in arm 1, so arms 1 and 2 differ by EXACTLY the rank-1 antisymmetric term — the clean single-variable contrast.
3. **Full pairwise** — the model is allowed the full per-cell antisymmetry. For a TEST cell `(i,j)`: predict `g_sym(i,j) + A_ij` where the antisymmetric part `A_ij = (M_ij − M_ji)/2` is taken from TRAIN **only if** the transpose pair `(j,i)` is in TRAIN (then `A_ij` is recoverable from the seen transpose, since `A_ij = −A_ji` and `M_ji` is seen — but `M_ij` itself is the held-out target, so `A_ij` is NOT directly recoverable; instead use `A_ij = M_ji,seen − g_sym` sign-flipped). **Honesty constraint:** the full-pairwise antisymmetry for a held-out cell can only be estimated from its seen transpose; where the transpose is also held out, full-pairwise falls back to the rank-1 prediction (it has no information). This is the correct construction — it asks "does knowing the *exact* seen transpose cell beat the rank-1 scalar summary?" Cells with held-out transpose are scored under fallback for all three arms identically, so the contrast stays clean.

   *(Implementation note for the experimenter: the cleanest equivalent that avoids the leakage subtlety is to do the split on PAIRS `{(i,j),(j,i)}` (120 pairs → 96 train pairs / 24 test pairs) rather than individual cells. Then a test pair has BOTH directions held out, full-pairwise has zero information on it and must use the rank-1 fallback, and the comparison is unambiguous: full-pairwise = rank-1 on every test cell by construction → ΔR²_full ≡ 0 out-of-sample. THIS IS THE CORRECT NULL RESULT and is the point — it mechanically demonstrates that "full pairwise" carries NO generalizable information the rank-1 scalars don't, because antisymmetry is by definition a per-pair quantity with one free number per pair. **The plan therefore splits on PAIRS, not cells** — see Decision Rationale §11. The per-cell split is described above only to motivate why the pair split is the honest construction.)*

**Resolved design decision (pair-split):** split the 120 off-diagonal **pairs** 80/20 → 96 train pairs (192 cells) / 24 test pairs (48 cells), seed 42. Fit `g_sym` (symmetric two-way mean) and `(b,r)` scalars on the 192 train cells; score all three arms on the 48 test cells. Full-pairwise has no per-pair free parameter for an entirely-held-out pair, so on held-out pairs it necessarily equals the rank-1 prediction — making `ΔR²_full` a direct, honest test of whether per-pair antisymmetry generalizes (it cannot, by construction, beyond what the scalars capture). The informative comparison is therefore `ΔR²_scalar` (does rank-1 antisymmetry beat zero-antisymmetry out-of-sample?) plus a **complementary in-sample-vs-held-out gap** read for full-pairwise (the in-sample full-pairwise R² is 1.0 trivially since it interpolates seen cells; the held-out collapse to the rank-1 level quantifies how much of the in-sample residual-pairwise "structure" was per-pair noise the full model memorized).

## §11. Decision Rationale

`N/A — no model training` for all training hyperparameters (lr, schedule, warmup, batch, epochs, LoRA rank/alpha/dropout, weight decay, seq length, optimizer, precision). This is a 0-GPU read-only analysis. The load-bearing **analysis** knobs:

- **What:** split on 120 off-diagonal **pairs** (not 240 individual cells), 80/20 → 96 train / 24 test pairs.
  **Why:** antisymmetry `A_ij = (M_ij − M_ji)/2` is a per-PAIR quantity (one free number per pair). Splitting on individual cells would leak a held-out cell's information into its own prediction via its seen transpose, biasing the full-pairwise arm upward. Splitting on pairs holds out both directions, making the full-pairwise vs rank-1 comparison honest and the `ΔR²_full` null mechanical-and-correct (a held-out pair has no free antisymmetry parameter). Tied to the Goal: the Goal asks whether asymmetry is rank-1 vs pairwise, and only a pair-split can fairly test pairwise generalization.
  **Source:** ungrounded — small-sample cross-validation convention (no paper specifies this exact split for an antisymmetric matrix; the pair-split is dictated by the antisymmetry structure, not a tunable). Flagged Low-confidence in §12.
  **Alternatives:** per-cell split (rejected — leaks transpose into own prediction); leave-one-pair-out (rejected — 120 refits × 5 behaviors × bootstrap is heavier with no accuracy gain at this N, and the 80/20 + split-stability loop already covers split variance).

- **What:** bootstrap n=1000, resampling the 48 held-out CELLS (with replacement), NOT re-splitting.
  **Why:** the CI we want is on the held-out R² given the trained predictors — i.e. test-set sampling variance. Re-splitting would conflate test-set variance with split-choice variance; the latter is measured separately by the 20-seed split-stability loop. Tied to the Goal: the headline "CI excludes 0" must reflect genuine out-of-sample uncertainty, not split luck.
  **Source:** ungrounded — standard bootstrap-CI convention. Flagged Low-confidence in §12.
  **Alternatives:** n=5 (allowed deviation if wall-time tight, per brief — rejected as default: too few for stable 2.5/97.5 percentiles); analytic R² CI (rejected — no clean closed form for the paired R² difference at n=48).

- **What:** random seed 42 for the split; 20-seed split-stability loop (seeds 42-61).
  **Why:** reproducibility + a check that the headline is not an artifact of one lucky split.
  **Source:** standard (seed 42 is the project default; see countless prior issues).
  **Alternatives:** single seed (rejected — fragile headline); the brief explicitly allows seed choice as a free deviation.
