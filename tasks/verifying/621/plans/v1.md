# Plan — Task #621: Train rank-1 LoRA implants and compare the A (read) and B (write) vectors to persona-context and behavior vectors

## 0.0 TL;DR (plain English)

- **What I'll run:** I'll train the smallest possible version of our marker implant — an adapter that learns exactly one input-detector vector and one output-push vector per weight matrix — into four personas, placed either on the "reading" side of the network or the "writing" side. Because the adapter is this small, there is no decomposition step: the learned detector and push vectors can be read directly off the weights and compared to each persona's internal fingerprint and to the direction that makes the marker more likely.
- **What I expect:** Based on the parent analysis, I'm betting the push vector comes out reproducible and pointed at the marker, while the detector vector barely moves from its random starting point. If that holds, the implant is an ungated write: it fires for everyone, and which bystanders leak is set by something other than a learned persona detector. The sharpest test is parameter-free: each bystander's fingerprint dotted with the detector should predict, with no fitting, how strongly the marker leaks into that bystander.
- **What would change my mind:** If the detector vector rotates clearly toward the trained persona's fingerprint, or if the detector-times-fingerprint score cleanly orders bystander leakage where simpler explanations (like the base model's prior tendency to emit the marker) don't, then persona gating really is written into the weights in readable form, and the parent's negative result was an artifact of using bigger adapters.

## 1. Goal

Test whether a rank-1 LoRA's read vector `a` aligns with the source persona's context vector `v_c`, whether its write vector `b` aligns with the behavior direction (the marker-unembedding direction / measured activation shift), and whether the per-persona firing strength `s·(a·v_c′)` rank-orders measured bystander leakage with zero free parameters. At r=1 the per-module update is exactly `ΔW = s·b·aᵀ` — `a` IS the learned context detector and `b` IS the learned behavior writer, no SVD needed. This is the cleanest possible test of the read/write leakage model, and it adds the A-init control that parent #604 (which decomposed r=16/32 adapters) structurally could not run. ## 3. Hypothesis

Let â, b̂ be unit-normalized; s = α/√r = 8; sign fixed per §4.5. All weight reads in module-input/output space, band L14–24 unless stated.

- **H1 (read identity).** If persona gating is written into the rank-1 read vector, |cos(â, v̂_c_source)| beats the dedup wrong-context null (p95 + top-3 rank, ≥3 contiguous layers in L14–24) at ≥1 of the 3 token positions in the majority of read-arm cells. **Prediction (from #604): FAILS** — confirms at-null read identity at the rank where no decomposition ambiguity exists. Confirm-H1 threshold: passes in ≥6/12 read-arm cells with selectivity margin > 0.02.
- **H2 (A-init / ungated write).** Band-mean |cos(a_trained, a_init)| > 0.9 AND ‖Δa‖/‖a_init‖ < 0.15 in ≥9/12 read-arm cells ⇒ the implant is an **ungated write** (pre-registered finding, per arXiv 2402.16842). Secondary read: cos(Δâ, v̂_c) — does what little rotation exists point at the persona?
- **H3 (write identity).** On the write arm, cos(b̂, Ŵ_U[※]) rises in late layers (max over L20–27 ≥ 0.20, vs random floor 1/√3584 ≈ 0.017 and a frequency-matched wrong-token null), and the EOS-margin direction read cos(b̂, Ŵ_U[※]−Ŵ_U[eos]) agrees. Secondary: cos(b̂_L20, measured L20 source shift) — layer-matched, avoiding #604's failed propagation pooling (caveat: cumulative shift still includes earlier-layer writes). Kill: write-arm b̂ at the wrong-token null everywhere ⇒ the write is not a direct marker push at any layer (would contradict #604's logit findings — investigate before reporting).
- **H4 (sharp zero-free-parameter test).** Per cell, Spearman ρ between predicted firing and measured per-persona leakage across the 17–18 true bystanders: write arm uses the signed prediction `Σ_lm s·(a·x_c′,lm)·(W_U[※]·b_lm)` vs Δz_marker (and Δ log P); read arm uses |firing| `Σ_lm s·|a·v_c′,lm|·‖b_lm‖` vs Δ log P. **Success:** median per-cell ρ ≥ +0.5 with ≥75% of cells positive, AND ≥ the base-prior comparator's ρ on the same cells. **Kill:** median |ρ| < 0.2 ⇒ firing strength does not order leakage; if the base-prior comparator wins, the #532 fallback explanation stands.
- **H5 (seed stability at r=1, descriptive).** Cross-seed |cos| of b stays high (≥0.8, matching #604's 0.92–0.95 for concentrated writes); cross-seed |cos| of a is the open question — #604's 0.015 at r=16 either persists (gate not a function of the data) or collapses to stable (rank constraint changes learning). Either outcome is reportable; no gate.

Falsification of the overall read/write leakage model = H1 fail + H2 ungated + H4 kill (the model's remaining surface here is then exhausted; what survives is #532's behavior-prior account + query-key routing per #604).
